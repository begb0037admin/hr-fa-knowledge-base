Core (GX2) Enhancements

The UI and UX of Core have been updated.

This is the first set of UX enhancements. Others will follow in subsequent releases.

In addition to the enhancements described in the sections below, to improve visual navigation and overall ease of use, the fonts and colors have been made consistent across the platform’s solutions.

Login Screen

The login screen functions the same, but its spacing and usability have been improved.

The image on the login screen will update periodically and be used at times by Cority to provide pertinent information. It is not configurable.

Logo

The logo on the login screen and at the upper left of the user interface can be configured to be your company logo, for example, using the ‘Logo – Login Page and Main Application’ system setting.

If a logo is not provided for the system setting, the default CorityOne logo will display.

Home Screen and Left Navigational Menu

The Home screen has undergone a significant amount of housecleaning. For example, to improve organization and use of space, the Profile menu has been moved from the upper right corner of the UI to the lower portion of the left navigational menu. With these enhancements, when the menu is collapsed, the user has access to much more of the screen for performing work tasks.

As part of this effort, the left navigational menu has been refreshed. Its items are better organized, it functions more efficiently, and its icons are more modern and self-explanatory. When the menu is open, the user moves right and left through an intuitively leveled structure, and when collapsed, the user can mouse over a solution to open just that solution’s menu items. At any time, the user can right-click a menu item to open the underlying destination in a new tab or window. Search functionality is also provided for the menu.

Also, the menu will now remain preserved the way the user viewed it last. This makes pinning within the menu unnecessary, so pinning has been removed.
Note: If the user or the user’s profile has a menu configuration saved, that configuration will still be retained each time the user logs into the system.

The information architecture of the left navigational menu has not changed. If rules have been configured to display only a certain set of left-menu items in a particular order, the new enhancements to the menu will not affect that.
