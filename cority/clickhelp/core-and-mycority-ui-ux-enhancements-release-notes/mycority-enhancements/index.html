myCority Enhancements

The UX of myCority has been enhanced.

The changes made help optimize myCority for the mobile experience and on the hardware platforms it supports.

Its usability, content legibility, use of space, and accessibility compliance have all been improved, which enhances the overall UX.

This is the first set of UX enhancements. Others will follow in subsequent releases.

Login Screen

The login screen functions the same, but its spacing and usability have been improved.

The image on the login screen will update periodically and will be used at times by Cority to provide pertinent information. It is not configurable.

Logo

The new myCority logo will always display on the login screen and at the top left of the myCority UI.
The logo at the top right of the myCority UI can be configured to be your corporate logo, for example, using the ‘Logo – Letters, Portal/myCority, and Reports’ system setting.
If a logo is not provided for that system setting, the CorityOne logo will display at the top right of the myCority UI.

Home Screen Tiles

On the Home screen, there are two panes: ‘Create New’ and ‘Create New Workflow and My Tasks – Filtering’. On each pane, the items have a new tiled layout and users can now change the order of the tiles within a pane. The administrator still controls which tiles each user sees, but a user can now re-arrange their order. For example, a user might want to arrange items from most to least used or in the order of a frequently used daily workflow.

Each tile has a handle at the top right for dragging it to a new location. Dropping a tile in a new location will move other tiles in the same pane to the right and/or down.
Note: Tiles can be re-arranged while using any supported hardware platform, however this is something you are not likely to do often and is easiest on a desktop, so we recommend using a desktop for that. Once the tile order is set, it will be retained when logging in and out on any supported hardware.

If an administrator adds permission to or removes permission from a tile, that will shift the layout of the tiles, so you might want to re-tweak their order afterward.

Left Navigational Menu

The left navigational menu has been refreshed. Its items are now better organized, it functions more intuitively, and its icons are more modern and self-explanatory.

Also, to ease accessibility, for better organization, and to improve use of space, the Account menu has been moved from the upper right corner of the user interface to the lower portion of the left navigational menu. Note: The Account menu no longer supports a personal picture or initials.

The left navigational menu is still collapsible. In the collapsed state, it supports slim-style navigation, where just the item selected and its submenu expand. The look and feel while in the collapsed state has also been refreshed.
Note: When emulating a cellular phone, the left navigational menu is collapsed fully by default, and when expanded it opens into an overlay.
