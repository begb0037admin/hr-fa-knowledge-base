GX2 Design Improvements and Fixes

The table below lists the design improvements and fixes we have made in the GX2 2025.1.1 release. The items are organized by component and the components are arranged in alphabetical order.

Item #Component(s)ReportedDescription
CCC-21333Business Intelligence - DashboardsN/A

When a 'Flex Field' questionnaire has been added to a 'Clinic Visit' layout, a Query Builder 'Clinic Visit' indicator that has related source 'Flex Field', a concatenate column function, max length 'Flex fields' question, and 'Field to graph' concatenate column function will now function as expected (including any drill-downs) if added to a dashboard and without generating an invalid query error.

 

CCC-21332Business Intelligence - Query BuilderN/A

When a Flex Field questionnaire has been added to a 'Clinic Visit' layout, for a Query Builder 'Clinic Visit' report with related source 'Flex Field' and a filter applied to a Flex Field check box question, that question will now filter correctly.

 

CCC-20125
Business Intelligence - Query Builder
N/A

In Query Builder, and for associated visuals in Advanced Dashboard, for a Flex Fields question with 128 or more characters, the question will now render properly as a table.


CCC-17276Business Intelligence - Query BuilderN/A

In Query Builder, for the RSIRaw entity, the 'Arithmetic with Rounding' function now works properly.

 

CCC-9603Business Intelligence - Query BuilderN/A

For a Query Builder report, scheduled using Report Scheduler, that will categorize based on a date field and has a range calculation based on today's date, any added conditional formatting will now will now be applied correctly when the report runs.

 

CCC-20832
Environmental - Chemical Management

N/A

On the Chemical Phrase layout (ML-000408), the maximum character count for the Code field has been increased to 30 and the maximum character count for the Description field has been increased to 250.


CCC-20731
Environmental - Chemical Management
N/A

The SDS offline backup (ZIP file) logic has been improved to be more robust and reliable.


CCC-19086
Environmental - Chemical Management

N/A

To custom versions of the ‘SDS Request Alert’ layout (ML-003833), the new ‘SDS Request Alerts ID’ field can now be added. The corresponding column can be added to applicable custom layouts. The field is available for use in business rules and display rules, can be reported on using Query Builder and Report Writer, and can be updated/edited using the Import Utility.


CCC-20888Environmental - ComplianceN/A

The API endpoint used for acquiring and/or updating applicability data, requirements, and regulations from Enhesa has been updated.
Also, issues with the 'Last Call Date' for regulations and with 'Process Status & Log' events have been resolved.

 

CCC-16299Environmental / Safety - ComplianceN/A

If a questionnaire is mapped to create a Safety or Environmental Permit and a business rule is configured to auto-post such a questionnaire, when the Permit record is created the questionnaire will now be reflected on its Compliance Checklist.

 

CCC-10782Environmental - Emission InventoryN/A

On an 'Emission Source Test Data' record, the user can now successfully inline edit all applicable values on the 'Sample Results' sublist without encountering any unexpected errors.

 

CCC-10530Environmental - Emission InventoryN/A

In Emissions Inventory, from a new 'Emission Source Test Data' record that has 'Agent Hazards' on the 'Sample Results' sublist, a user with a role that is granted 'All Sites and All Modules' can now successfully delete an 'Agent Hazard' record without encountering an unexpected error.

 

CCC-18107
Ergonomics
N/A

For troubleshooting, the RSIGuard Installation table is now available in Query Builder and Report Writer.


CCC-16168Industrial HygieneN/A

On the Industrial Hygiene 'Lab Requisitions' list, for users with the proper security configuration, the 'Display Results' action will now function properly and without generating any unexpected errors for samples with the 'Lab Work Complete' status.

 

CCC-19680Management of ChangeN/A

For MOC Approval workflows, while using supported functionality (editing the layout, updating the workflow status, rejecting, etc.), all expected approvals will now continue to be shown on the workflow banner.

 

CCC-20704Occupational Health - AppointmentsN/A

An issue that was causing an unexpected error when booking (creating and saving) an appointment has been resolved.

 

CCC-20421Occupational Health - AppointmentsN/A

Issues that were causing errors when setting up, updating, or deleting appointment recurrences have been resolved.

 

CCC-18109Occupational Health - AudiometricN/A

In the Audiometric module, on the Hearing Classification list for a record, text in the Ear column (Left or Right) that should not be clickable no longer is, therefore will no longer generate unexpected errors.

 

CCC-19897Occupational Health - Case ManagementN/A

For 'Occupational' Cases that have a 'Nature of Injury' specified and marked 'OSHA Recordable', when the 'Automatic: Adding Cases to the log (OSHA Logic)' system setting is selected, the 'OSHA Recordable' check box on the case will now function as expected.

 

CCC-20954Occupational Health - Clinic VisitN/A

A user who has the required security configuration can now successfully open signed Clinic Visit notes that have large content (text and/or table format) without encountering any unexpected errors.

 

CCC-15321Occupational Health - Clinic VisitN/A

From the 'Clinic Visit' module, when exporting a list of notes within which one or more use lineout, the notes all now export with the proper formatting.

 

CCC-19996Occupational Health - eRxN/A

All users with the proper security configuration can now prescribe medications electronically.

 

CCC-19245Occupational Health - ImmunizationN/A

When the 'Short Date Style' is set to a three-letter month format (for example, mmm-dd-yyyy), the 'Vis Publication Date' field has been added to a custom myCority 'Vaccination/Immunization' layout, and the field is configured to have a default value, the default value will now populate on a 'Vaccination'Immunization' record newly created in myCority.

 

CCC-17261Occupational Health - ImmunizationN/A

In OH 'Immunization', for custom layouts, the 'Declined' and UDF flags (check boxes) will now function properly.

 

CCC-15978Occupational Health - ImmunizationN/A

When the 'Automatically select global employee' option is chosen and the name of the global employee specified contains an apostrophe, in the Immunization module the 'Add multiple immunizations' action now functions properly.

 

CCC-9553Occupational Health - LettersN/A

If configured properly, for a letter template with merge table 'Clinic Visit' and <<Employee.Gender>> query in the body, when used in a letter the employee's gender will now translate as expected into the language set for the user.

 

CCC-13926Occupational Health - Medical NotesN/A

When the 'Render Clarity' system setting is selected, Medical 'Sticky Notes' will now appear and function as expected.

 

CCC-8811Occupational Health - Medical RecordsN/A

If running the 'Medical Records' report for 'Problem List' items when one or more notes or smart notes are flagged 'Problem List', there will no longer be any note or smart note issues on the report (for example, with HTML).

 

CCC-20035Occupational Health - Questionnaire DistributionN/A

In OH 'Questionnaire Distribution', from the 'Assignees/Recipients' sublist, the user can now clone a layout, save the clone successfully, then access the new layout without encountering a server error.

 

CCC-18558Platform Administrator - Business Rules, EmailsN/A

For properly configured business rule email actions, the CC recipients functionality is now working as expected.

 

CCC-19569Platform Administrator - Business Rules, MetricsN/A

An issue that was causing a scheduled business rule configured to create a metric finding if a measure value is out of range has been fixed.

 

CCC-21029Platform Administrator - Business Rules, SchedulingN/A

A business rule with Scheduled/Recurrent trigger will now function as expected regardless of whether the 'Short Date Style' system setting is Global or User.

 

CCC-20475Platform Administrator - Business RulesN/A

A 'Create Record' BRA, through questionnaire mapping, can now be configured to populate Clinic Visit 'Medical Code' data.

 

CCC-20449Platform Administrator - Display RulesN/A

A display rule for the Safety or Environmental 'Incident' entity will now be listed, as expected, on the 'Display Rules' tab when editing any associated layouts. From there, it can be edited or deleted.

 

CCC-20428Platform Administrator - Display RulesN/A

When a display rule is properly configured to filter the Environmental/Safety 'Permit Type' look-up selector, the list will now be filtered correctly and will not generate an unexpected error.

 

CCC-19323Platform Administrator - Display RulesN/A

Display rules that have a filter, required, read-only, or message action type will now trigger successfully based on the value selected or auto-populated for the 'Geographic Location' field.

 

CCC-8186Platform Administrator - Employee Demographics2022.1.0.0

In My Favorites > Employee Demographics, when applicable, for adding a new Job Position inline on the Job Position sublist, the GDDLOFB fields now populate as expected.

 

CCC-13372Platform Administrator - Findings & Actions, Flex FieldsN/A

On a new 'Finding & Action' open in a layout that has a 'Flex Fields' subsection, if 'Add New Action To Finding' is used, any details added to the new Action record will now be retained when the record is saved.

 

CCC-19907Platform Administrator - Questionnaires2024.3.0.4

An issue that was not allowing an exported questionnaire (JSON format) with previously created single questions (valid choices) to be imported has been fixed.

 

CCC-18921Platform Administrator - QuestionnairesN/A

For a document attached to a questionnaire, the 'Print HTML' action now functions as expected.

 

CCC-16044Platform Administrator - RolesN/A

When using the 'Import Role Configurations' action, any '*.delete' security actions will now be present and configured as expected.

 

CCC-9884Platform Administrator - QuestionnairesN/A

From within the Questionnaires look-up table, the user can now successfully execute the 'Import Questionnaire Configurations' action, with the 'Update existing records' setting enabled, to import a JSON file. That will not generate any unexpected errors.

 

CCC-5532Platform Administrator - QuestionnairesN/A

For a questionnaire, a parent question that has one or more dependent child questions can no longer be deleted without first deleting the child question(s).

 

CCC-21055Quality2025.1.0.0

When archiving an approved, published record, an approval email is no longer triggered.

 

CCC-11125Platform End-User - Safety Event ReportingN/A

If configured properly, on an event report that has radio button field values selected and is then posted to an incident investigation, when the record locks (for example, at final approval), translations for the field values will now all function as expected.

 

CCC-10496Occupational Health - Medical Notes, TranslationsN/A

When the system is set to use Spanish, that no longer introduces formatting issues for smart notes.

 

CCC-8922Management of Change2022.1.2.3

From a clone MOC layout that has a sublist expanded by default at the top and 'Link Document' to the 'MOC Type', the user can now successfully open the document without encountering an unexpected error.

From a clone 'Findings & Actions' layout that has a sublist expanded by default at the top and 'Link Document' to the 'Action Type', the user can now successfully open the document without encountering an unexpected error.

 

CCC-6335Platform End-UserN/A

When applicable, if 'Enable Multiple Values' is selected for a picklist field, the user can now add new values to the associated look-up table from the picklist.

 

CCC-20122Platform End-User - TranslationsN/A

When a user changes the language on the login screen, then clicks the Log In button (with or without SSO) and logs in, the user is now directed through the process with appropriate screens.

 

CCC-8020Platform End-User - TranslationsN/A

When the language for the system is set to French, the 'Geographic Location' look-up selector will now function properly (for example, it will no longer cause a timeout).

 

CCC-19143Safety - Compliance ManagementN/A

For Safety 'Findings & Actions', when configuring recurrence, the X button on the 'Recurrence Settings' modal box now functions properly.

 

CCC-6163Safety / Environmental - IncidentN/A

On a Safety 'MVA Incident', for any records on the 'Related Motor Vehicle Accidents' tab, the Year field default will now function properly.

 

CCC-19811Safety - IncidentN/A

On applicable Safety 'Incident' records, the FRA 57 form will now function, format, display, and print correctly.

 

CCC-19529Safety - IncidentN/A

On any Safety 'Incident' record, if the user opens the MVA 'Related Assets' tab, clicks 'Add multiple records', adds at least one record, then selects one of those newly added records and clicks Delete, the record will now be deleted successfully and without generating an unexpected error.

 

CCC-20843Safety PermitsN/A

The Permit UDF fields 1 through 10 are now available within and can be updated using the Import Utility.
