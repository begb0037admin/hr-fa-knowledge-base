myCority Design Improvements and Fixes

The table below lists the design improvements and fixes we have made in the myCority 2025.1.1 release. The items are organized by component and the components are arranged in alphabetical order.

Item #Component(s)ReportedDescription
CCC-20863Management of ChangeN/A

When configured properly, and where applicable, translated approval role names will now display as expected in myCority.

 

CCC-21138Platform End-User N/A

All screen labels functioning as headings are now formatted properly, and screen labels that were not functioning as headings are no longer formatted as headings.

 

CCC-21097Platform End-User N/A

Dialog boxes that function similarly are now formatted consistently.

 

CCC-21024Platform End-User N/A

A 'Skip to Main Content' button has been added where applicable.

 

CCC-20874Platform End-User N/A

When and where applicable, the keyboard focus is now always indicated visually.

 

CCC-20802 and 20553Platform End-User N/A

For applicable images, informative hover-over text has been added.

 

CCC-18459Platform End-User N/A

If applicable, in myCority 'My Records', you can now successfully search by name.

 

CCC-13413Platform End-User - Workflows, Translations2023.1.2.0

For a workflow (with source and module specified) that has a few steps and a corresponding Workflow Source value that has a French translation, when the user's language is French and the workflow is assigned to any layout and then executed for the specified module, in the Workflow History the values in the 'Destination Status Name' and 'Signed' columns will now be translated properly.

 

CCC-21013Safety Event Reporting 2024.3.0.0

When creating a new Event Report using myCority, the user can now populate the GDDLOFB (for example, the Organization value) successfully.

 

CCC-20468Safety PermitsN/AUsers whose roles are configured with access to the 'Permit to Work' module can now open and save the associated questionnaires and Findings & Actions, as expected.
CCC-19758Safety PermitsN/A

When a 'Work Permit' record that has a workflow is opened in myCority, the 'Workflow History' for that record will now be accessible in myCority without generating an unexpected error.
