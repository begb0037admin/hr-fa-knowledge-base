Summary of Occupational Health Enhancements

The table below contains design improvements we have made in the Occupational Health cloud. The items are organized by component, and the components are arranged in alphabetical order. Descriptions of any larger features follow the table.

ItemComponent(s)Description
CCC-25784Case Management, Injury/Illness

The following two new text UDF fields can be added to custom versions of Case Management and Injury/Illness (ML-001332 and MLs-001332) layouts: UDFEmployee1 and UDFEmployee2.
The corresponding columns can be added to custom versions of applicable list views.
The new fields are available for use in business rules and display rules, can be populated and updated using import, and can be reported on using Query Builder and Report Writer.

 

CCC-25186Case Management, Injury/Illness

The following new UDFs can now be added to custom versions of Case and Injury/Illness layouts:

  • CaseUDFText1 - CaseUDFText6
  • CaseUDFFlag1 - CaseUDFFlag6
  • CaseUDFDate1 - CaseUDFDate6
  • CaseUDF1 - CaseUDF6

The look-up table fields (CaseUDF1 – CaseUDF6) have new corresponding look-up tables: CaseUDF1 – CaseUDF6.
