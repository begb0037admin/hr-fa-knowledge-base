CCC-20864: In myCority, the printing and exporting of questionnaires has been improved

N/A

In myCority, for Questionnaires, the following enhancements have been made to Print and Export to PDF:

  • The overall layout of questionnaires when exported to a PDF or printed has been optimized so that files are easier to read.
  • When questionnaires are using section titles, all sections and pages are printed and exported to PDF. The section title name is included in the output to indicate new sections.
  • If images are attached to a questionnaire, the image file will now be included when a questionnaire is printed or exported to PDF.
  • When non-image files are attached to a questionnaire, the file names will be listed above any images.
  • Score classification for individual questions will now be included when a questionnaire is printed or exported to PDF.
  • The total score will now be included in the questionnaire when printed or exported to PDF.

The improvements listed above have the following limitations:

  • For all sections to print or export, the first question must have a section title.
  • Most HTML codes, such as bolding (<b>) or italicizing (<i>), applied to questions are ignored in the print and export. Underlining (<u>) and font color (<font color = "color">) are maintained.
  • The Advice pop-up and Legal Requirement pop-up are not included in the print or export.
  • Attached images from the Single Question look-up table, such as a reference image that never changes on a question, are not included in the print or export.
