Summary of Safety and Environmental Enhancements

The table below contains design improvements we have made in the Safety and Environmental clouds. The items are organized by component, and the components are arranged in alphabetical order.

ItemComponent(s)Description
CCC-28048Chemical Management

The following new UDFs can now be added to custom versions of ‘Chemical Inventory’ layouts:

  • UDFText05 - UDFText15

The new fields can be used in business rules and display rules, populated or updated through import, and reported on using Query Builder or Report Writer.

The corresponding columns can be added to custom versions of applicable list views.

Also, the ‘Tank ID’ column is now available for adding to custom versions of ‘Chemical Inventory’ list views.

 

CCC-27862Chemical Management

The following new fields can now be added to custom versions of any Agent Hazard layout (including in the Chemical Products, Chemicals, and Waste Profiles modules):

  • UDFLU01 - UDFLU25
  • UDFDate01 - UDFDate03
  • VOC Content - a numeric field
  • VOC Content UOM - a picklist to the Units of Measure look-up table

The look-up table fields (UDFLU01 - UDFLU25) have new corresponding look-up tables: LU_AgentHazard_UDF01 - LU_AgentHazard_UDF25.

The fields can be used in business rules and display rules, populated or updated through import, and reported on using Query Builder or Report Writer.

The corresponding columns can be added to custom versions of applicable list views.

Also, the character limit for the existing text UDFs in Chemical Handling has been extended.

 

CCC-26302
Environmental Asset Management – Reporting

The new EquipmentUDF365RollingLeakRate BRA method will calculate the total 356-rolling leak rate for an asset. It is for use in business rules and applies a 365-day roll back even in leap years. If properly configured with an incident leak rate (real number UDF) field and a 365-rolling leak rate (real number UDF) field, the BRA will make the necessary calculation and populate the latter with the result.

For information on working with business rules, business rule actions (BRAs), and UDFs, see the Cority User Guide.


CCC-18967Safety – Management of Change

Safety MOC records can now be linked to other, associated records across applicable clouds and modules. For more information on the record linking functionality, see the release note for CCC-15799 in the GX2 2024.3.0 New Features Release Notes.

 

CCC-27465Waste Management

A new business rule BR-100672 that uses new subquery BR_WasteManifest_ManifestNumber_Subquery prevents users from updating the Manifest Number on a Waste Shipment record to an already existing Manifest Number. The business rule is set to inactive (off) by default.

For information on working with business rules, see the Cority User Guide.
