CCC- 27958: The Audiometric functionality for Alberta has been updated

Mandatory

To the Audiometric Regulation system setting, a new 'Alberta – CSA Z107.6-16 standard' option has been added. When that option is selected, the system will provide what is necessary for the new regulation.

Also, the Audiometric ‘Employee Hearing Summary’ and ‘Shift and Impairment’ reports have been updated to reflect the newly implemented ‘Significant Threshold Shift (STS)’ calculation and hearing status classification.
Where applicable, the width of the Hearing Status columns has been adjusted to account for concatenated hearing status (for example, Abnormal Audiogram / Abnormal Shift / Significant Threshold Shift).
