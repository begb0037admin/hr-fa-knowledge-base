Summary of Platform Enhancements

The table below contains design improvements we have made to the platform. The items are organized by component, and the components are arranged in alphabetical order. Descriptions of any larger features follow the table.

ItemComponent(s)Description
CCC-28378Analytics

The OData SQL query timeout is now set to 10 minutes (600 seconds) by default. With that set, the ‘Query Time Out (in seconds)’ system setting no longer affects the OData SQL Query timeout. This will help to ensure more stable and efficient OData connections.

 

CCC-13999Archive and Purge

When using the Archive, Mark for Purge, and Purge functionality, the action will now be applied to all child records (Documents, Questionnaires, etc.) of any specified parent records (for example, Safety Incidents).
For information on how to use this feature set, see the Cority System Guide.

 

CCC-26028myCority

A number of changes have been made to improve the accessibility of myCority. Those include:

  • Where applicable, Action, Actions, and related controls are now operable using the keyboard.
  • Where applicable, under More actions, all available controls are now operable using the keyboard.
  • Where applicable, the following controls are now operable using the keyboard: New, Save, Delete, Cancel, and Restore Profile Menu Configuration.
  • The buttons on the Details, Employee Work Demographics, and Responses accordions are now operable using the keyboard.
  • The overall accessibility of the pagination controls has been improved.
  • The overall accessibility of the ‘Enter a code’ functionality has been improved.

 

CCC-27186myCority

The ‘Prohibit guest users in myCority’ system setting is now selected by default for all new client sites.

 

CCC-19275REST API

For GX2 REST API GET requests, advanced conditions now support O in replacement of OR and A in replacement of AND.

 

CCC-25679REST API

Enhancements have been made to the tools used by Cority Support and Engineering for troubleshooting the REST API.

 

CCC-25954User Community

The Cority User Community now requires a username and password login from any access point, including from within GX2.
