Version 2024.1

Release Date: Mar 22nd (first group deployment) and Mar 29th (second group deployment)

WeSustain version 2024.1 provides the following features:

  • The performance of the WeSustain website has been improved to have faster load times and quicker system responsiveness, allowing users to collect, manage, and calculate data from multiple sources seamlessly. 
  • In the Data module, a new feature has been added where users can now export Excel queries multiple times and save them locally. This allows users to capture and store frequently used queries and retrieve them easily, reducing manual input time.
