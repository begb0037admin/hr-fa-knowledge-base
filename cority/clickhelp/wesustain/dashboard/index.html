Dashboard

The dashboard is a way of displaying various types of visual sustainability data in one place.

There are two types of Dashboards:

  • Personal Dashboards: Admin users and editors have access to personal dashboards. They can customize the data information displayed on their dashboard.  
  • User Group Defined Dashboards: Admin users can customize the data information displayed on these dashboards and assign these dashboards to user groups. Users assigned to a user group can view data displayed on the dashboard.
