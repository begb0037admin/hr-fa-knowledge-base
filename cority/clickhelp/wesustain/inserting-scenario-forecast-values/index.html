Inserting Scenario Forecast Values

To Insert Scenario Forecast Values

 

1On the left navigation panel, click Data.
2Click Scenarios & Targets.
3Select a numeric or formula KPI.
4Information on the KPI is displayed to the right.
5Click the Scenarios tab.



6
Scroll down to the target section of the Scenario.
7
Select a Base Year for which you have approved values (baseline, etc.) that you are not likely to change, and select a Target Year. Your planning period is from the base year to the target year.
8
Select the checkbox infront of any or all Organizational units. 
9

Click Insert forecast values. Insert forecast values prompt appears. 

This function is only available for KPIs that have forecast values set and enabled under the Forecast tab in Settings > Standard & KPI.



10

On the Insert forecast values prompt, click OK.  The forecast values display in the information chart for the KPI.
