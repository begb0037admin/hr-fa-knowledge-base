Deleting a User Group Defined Dashboard

To Delete a User Group Defined Dashboard

 

1On the left navigational panel, click the Home icon. The Home menu appears.
2Click Dashboard. The Dashboard window appears.
3Click Edit Dashboard Templates. The Edit Dashboard Templates window appears.


4Click Create and edit dashboard templates. The Edit Dashboard Templates window opens.

5On the Edit Dashboard Templates window, select a Dashboard.
6Click the Delete icon.  The Confirm Deletion prompt appears.

7On the Confirm Deletion prompt, click Delete. The Confirm Deletion prompt closes, and the Edit Dashboard Templates window appears. On the Edit Dashboard Templates window, the Dashboard Template is removed.

8On the Edit Dashboard Templates window, click Save.
