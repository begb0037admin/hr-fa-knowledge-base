SETUP

The SETUP area contains the following modules: 

  • Organizational Models allow you to model the structure of your company.
  • Standards & KPIs allow you to set which targets and standards must be met in the next recording period and which Key Performance Indicators (KPIs) you want to record. In the system the most important standards, such as GRI, IÖW/future-Ranking, ISO 26000 etc., are always kept up to date by WeSustain with your company's own KPIs. You can add further KPIs and create individualized standards.
  • Workflow & Reminders offers you the opportunity to create and manage responsibility sets, as well as view and manage approval processes and reminder mails.
  • Tags & Categories serves as a structuring aid. Assigning tags simplifies filtering, for example, indicators. Here you can also create and edit categories for your indicators.
  • The Units & Currencies module stores the most common units (e.g. euros, litres, kilowatt-hours, etc.) that each KPI should be assigned to. You can add other units. This module also allows you to create conversion factors (e.g. for CO2 equivalents), which may be adjusted each year. Conversion factors are used in formulas in data collection.


 In general, the settings in this area are only rarely adjusted within a reporting period. We recommend supervision and coordination by one or a small number of appointed persons.
