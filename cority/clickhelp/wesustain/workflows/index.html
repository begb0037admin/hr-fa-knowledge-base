Responsibility Sets

A set of responsibilities links the organizational model, indicators and people in charge. They are created to view and edit data in Data Management.


1

There are two ways to allocate KPIs to the responsibility set. Select one or more KPIs and click  to open a window with the organizational model. In addition, you can find a detail view of a KPI in the Organizational model tab.

You can also edit responsibilities in the Workflows & Reminders menu entry for an overall view.

2 By using this drop-down list you can change the organizational model and the time period.

3

Any changes will be applied to all KPIs within this responsibility set. You can Edit Responsibility Set and Save as New to save any changes to an entirely new responsibility set for the selected KPI. This will not change any other KPIs assigned to the current responsibility set.

Click  to assign different responsibility sets. You can Assign another Responsibility Set to choose and assign from existing responsibility sets. You can also Edit the current Responsibility Set itself (if one has been assigned to this KPI already).
4 Here you can see the current values and the values from the previous year, which were recorded for the selected organizational unit. Click  to view details. Click  to go to the relevant place in Data Management where you can edit the values.
5 A Deviation threshold and a Target value* for the quantitative KPI can be assigned to every selected organizational unit. The deviation threshold notifies if the current year’s value differs from the previous year’s value. The target value can be seen in the Data Management and Charts modules.

    *  The visibility of this function depends on your settings.

 

1 Here you can view and edit the Responsibility Sets in the menu Workflows & Reminders.
2 Select the desired checkboxes and click the desired action symbols to Delete (), Edit () and Export () the selected sets.  
3 A Blank Set is an empty responsibility set, which is assigned to all KPIs in the beginning. As long as the KPIs are assigned to this set, they are not displayed in the Data Management module.
4 Here you can choose the responsibility set you want to edit. You can see the details on the right side.
5 If you see the warning symbol , you are being alerted to the presence of identical responsibility sets with the same configuration. These can be summarized in detail view of the sets (see point 8).
6 Click  to add a new responsibility set or click  to export the sets to Excel.
7 Click  to copy the entire set and click  to save your changes.
8 Here you can see and edit the Name, Type, Description and the parent Folder. In addition, you can see the Identical Responsibility Sets with names, which can be summarized by clicking  (see point 5).
9 Click  to export the responsibility set to Excel.
10 Use the Search function to browse through the organizational model. You can collapse and expand all entries or Show more filters to filter and reduce the view to individual categories.
11 A Deviation threshold for the quantitative KPI can be assigned to every selected organizational unit (for quantitative KPIs). It checks if the current value differs from the previous value and issues a warning when the Target value* is exceeded, which you will see in the Data Management and Charts modules.

12

 

The overview displays the organizational units assigned to the selected responsibility set. By selecting the checkbox on the right side, you can enter data for this organizational unit. By selecting the left checkbox, this organization unit is saved as a consolidation unit. You can select users as "Responsible" person(s) for various organizational units, which gives rights in Data Management. The list of assigned KPIs to the organizational model can be seen on the KPIs tab and additional KPIs can be added. 

*  The visibility of this function dependents on your settings.
