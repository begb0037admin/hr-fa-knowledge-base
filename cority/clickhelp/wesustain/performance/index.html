PERFORMANCE

The PERFORMANCE area enables the efficient execution and documentation of analyses to identify fields of action, set goals and define measures. It comprises the following modules:

  • The Analytics module enables you to analyze collected data directly in WeSustain. Data from Data Management can be filtered based on specific criteria and displayed in tabular form in Analytics.
  • The Charts module allow you to graphically represent the KPIs (defined under Strategy & Governance and entered under Data Management) using various types of charts.
  • The Reporting module lets you create reports based on your performance indicators. This function can be used, for example, for creating a sustainability report or as part of a certification. The reports are divided into Articles, and you can create text areas and use the created KPIs and charts. 
  • An additional module, GRESB Interface, is available as an optional add-on in the ESG solution to facilitate the collection of real estate ESG data that can be uploaded to the GRESB portal for yearly assessment.
