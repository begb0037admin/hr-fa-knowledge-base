Version 2024.2

Release Date: July 19th (first group deployment) and July 26th (second group deployment)

WeSustain version 2024.2 provides the following features:

  • In the Data Module, both a Scenarios History tab and a Targets History tab have been added for KPIs. These history tabs show the changes and the specifics of changes made to the KPIs over time and by whom. 
  • Full access users can now import emissions factors.  
  • In the Units and Currency Module, under the CO2 Factors tab, the “ORG-UniqueID” column has been added to the C02 factor export. This allows users to export and re-import emission factors in bulk, with accuracy and ease in data management.   
  • In the Organizational Models module, the export list document now has an org units total weight column which displays when the start/end date (time-period) is activated in portal settings.  
  • The visibility of Analytics queries marked as "public" is now adjusted to user permissions (r-set rights) for enhanced data security. In the export, users will only see the KPIs and org units they are responsible for in the r-sets.  
  • In the Standards and KPI module:
    • Forecast Settings of numeric KPIs that are set for a year, can now be carried over to all years going forward.
    • Admin users can now connect and disconnect KPIs for different time periods.  
    • Users now can easily update KPI units and measurements that span across time periods. The changes will be reflected in all areas where the KPI is mentioned, saving customers administrative time and effort while ensuring data accuracy across their entire sustainability program. 
    • Re-importable queries are now identified with an indicator in the Saved Exports overview. 
  • In the User Management module, data fields of user excel documents can now be imported for existing users. Previously, imports could only be done for new users.   

User excel document imports will not update login credentials and user roles. 

  • In the Admin module, under Interfaces, admin users can now renew API access tokens.
