Simple and Advanced Filters

The filters allow you to filter for specific criteria. Cells that do not meet these criteria are hidden.


1Click  to set the simple filter. First, select the element to be filtered from the variables and then choose a comparison operator under operation (e.g. ‘>’',‘ <’ or ‘=’). Finally, you can set a value the variable should be compared with. This value can also be specified as a parameter (see point 5).
2You can link multiple filters with AND or OR filters by clicking on the corresponding buttons.

3

Click Advanced Filter to set a simple filter as an advanced filter. Advanced filters are a combination of two filters. The first filter acts as a simple filter, while the second filter specifies to which areas the first filter should be applied (e.g. individual rows, individual columns or individual cells). The area to which the filter can be applied is selected via the dropdown. If the corresponding area is detected by the second filter but not by the first one, it will be removed - otherwise it will persist. The advanced filter is only recommended to experienced users.
