User Management

The User Management module in the Administration area provides an overview of existing user profiles.

1Use the drop-down filter to search directly within specific categories (first or last name, login, or email address), or use the Search to display specific user profiles.
2Here you can set the number of entries you want to display on one page.
3Click  to create a single user, or click  to create multiple users in one step. You can also Export () users to Excel.
4Some key user details are listed in a clear manner in tabular form.
5Click  to change the details in a user profile. Click  to view notes.

6

When the table exceeds the number of entries specified under item 2, it will be divided across multiple pages. The arrows allow you to browse between the pages. The double arrows allow you to jump directly to the first and last page respectively. To jump directly to a specific page, click on the corresponding page number.
