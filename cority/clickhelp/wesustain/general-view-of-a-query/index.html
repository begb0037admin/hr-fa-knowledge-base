General View of a Query


1Select this checkbox to display the query in text form and edit it. This feature is only recommended to advanced users.
2In the above area, variables for the query can be selected and seen. The lower area is the result table in which the variables represent the rows, columns, and cells (here including own cell headings). Several variables can be selected for the display; the table adapts accordingly.
3Click to delete variables. Click  to open a window with an overview of all variables. Here you can select and add variables to the query.
4The order of the variables indicates their positioning in the result table. These icons can be used to arrange the order of selected variables. You can move variables downwards () and upwards ().
5Click “GO!” to start the query and create the result table.  
6Click  to export the results to Excel.
7

Click  to sort the columns in ascending or descending order. On the third click, the sorting is removed, and default sorting is restored.
