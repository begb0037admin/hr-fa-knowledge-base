Standards & KPIs

In the Standards & KPIs module you can manage your KPIs (Key Performance Indicators). This module allows you to create, delete, move and rename KPIs. You can also add KPIs to several standards. The standards and KPIs are arranged in a tree structure with any chosen number of levels. The module is divided into two columns: In the left column, all KPIs are displayed while the right column shows the detail view of a KPI. The division into two columns allows you to work clearer and faster.

Creating KPIs

Click   Create KPI in the detail view of a standard to opens a window with different KPI types to choose from:


1Click on a green bar to select the KPI type.
2You can cancel the process at any time by clicking Close or x. This also applies to the subsequent steps.

Basic Types

 FolderA folder is used for structure. With this type of KPI, you can summarize or group several KPIs. No data is entered for the folder itself.
 Textual (qualitative)Use this category for KPIs that cannot be recorded as numbers or as pure yes/no categories. For example, the implementation of an existing code of conduct into everyday business life.
 Numeric (quantitative)This category is for KPIs that can be recorded as a value and expressed in figures, e.g., power consumption in kWh.
  Conversion formula (quantitative)This KPI type allows you to calculate CO2 equivalents via multiplication of a numeric KPI with a CO2 factor.
  Formula (quantitative)

This KPI type can pool several quantitative KPIs. It outputs the sum of the KPIs assigned to it. The detailed KPIs can be weighted with various factors.

Note: Yearly and sub yearly KPIs can be inputted as formula content.

Yes/No (compliance)A KPI of this type is used if a criterion can either be met or not met and if there are either no intermediate steps or these are of no interest. For example, the existence of a code of conduct.
  ChoiceA Choice KPI allows you to define a number of predefined choices, such as ‘Good’, ‘Medium’, ‘Bad’ etc.

Simple text (qualitative)

This is a text indicator with a defined maximum number of characters.

Advanced Types

  Composite IndicatorThis KPI type is used as a structural element which summarizes a group of sub KPIs and allows a compact and clear view on associated KPIs. Furthermore, it provides an additional sub KPI type ‘ Option’, which is particularly relevant for questionnaires.
 Validation formulaThis KPI automatically validates entered data with definable rules.
 DateThis KPI enables the entry for date and time.
 PersonThis KPI offers an input field for registered or new persons.  
 FileThis KPI is specifically for file uploads.
 Repeating structureA repeater is a structural element. This is a KPI container whose underlying structure can be repeatedly added.
