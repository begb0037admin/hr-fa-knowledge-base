Version 2022.2.1

Release Date: October 23rd

WeSustain version 2022.2.1 provides the following features:

  • The new Collections & Approval module allows users and managers to view, edit, and approve open KPIs assigned to them. The color status of KPIs changes from red to orange once approved by data collectors, and orange to green once approved by managers.

The approval colors are default colors. They can differ in client systems.

  • In the Data Management module, the Derived Approval pop-up window has been updated to allow users to approve KPIs in bulk on an aggregated level.
  • In the Data Management module, the new Data Import button allows users to import comma-separated values (CSV) data files.
