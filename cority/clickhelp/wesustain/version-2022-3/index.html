Version 2022.3

Release Date: Nov 19th (first group deployment) and Nov 26th (second group deployment)

WeSustain version 2022.3 provides the following feature:

  • The new Data Forecast Tool allows users to compare KPIs of actual performance with forecasted performance.
  • In the Organizational Module, on the Edit Organization unit window, users can now input start and end dates of organizational units such as subsidiaries, investee companies, or suppliers with regards to quantitative KPIs. This can effect the weight of an organizational unit on a company based on the duration that an organizational unit is with a company.
  • The new Sub Yearly KPI function, now allows users to incorporate sub yearly KPI values in formulas. For example, inputting a few monthly KPI values for a given year in a formula.
  • Single Sign-On (SSO) is now available for WeSustain allowing users to navigate easily through different Cority Systems.
  • Users can input Target values for a KPI in the Standards & KPI module. These Target Values can be displayed in analytic queries and in charts, providing users with visual comparison against actual KPI values.
