Version 2024.3

Release Date: Sept 27th (first group deployment) and Sept 30th (second group deployment)

WeSustain version 2024.3 provides the following features:

  • In the Dashboard module, in the Progress Overview table, users can now click the icon to the right of an organizational unit and navigate directly to the Data Management System for that value.

For the Progress Over widget to be visible on the Dashboard, you will need to add the widget.


For the Progress Overview table to display the icon, you will need to filter for organizational units.

  • In the Standards & KPIs module, users can now update data to existing KPI entries by importing from an excel.
  • In the Analytics module, users can now view measurement unit values originally inputted, side-by-side to the converted measurement unit value configured in the system.

For users to view measurement unit values originally inputted, users will have to add the “Value in selected unit” in the Cell parameter.

  • In the Time Periods Module, user can click icon to freeze a time period and stop any recalculations of values or updates to KPIs for that time period.
  • In the Chart module, where a drilldown-chart has more than one time period and more than one KPI, and a specific bar is clicked in the bar graph, the KPI’s organizational unit and value now displays in a chart format with the time period displayed as a sub label at the top of the chart. This reduces confusion for users when determining the year being viewed for a specific data chart.  

This functionally is for charts where the x-axis of the chart is the KPI name.

  • Four filter flags have been added to the non-delta GET endpoint in the values section: ‘onlyValues’, ‘onlyInput’, ‘onlyUpdated’ and ‘excludeNullInstance’. These filter flags previously only existed for delta calls. The API description in the interface module provides further information for each filter flag.
