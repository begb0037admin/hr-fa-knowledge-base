Saving and Loading Queries

  1. Click Load query to view previously saved queries. Select the desired query and the stored variables appear. The query is executed directly.
  2. Click Save query to save the currently-set query in order to retrieve it at a later stage.

Requests can be saved as private (only visible to the creator), for all heads (visible to all editors), or as public (visible to all data editors and viewers).
