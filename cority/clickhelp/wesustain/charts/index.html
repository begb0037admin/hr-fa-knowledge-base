Charts

In the Charts module, the KPIs defined under DATA and entered under Data Management can be represented graphically in charts.

Click on a chart to display its details on the right side of the page.


1Select the checkboxes in combination with these action symbols to delete charts (), move them to a folder (), or replace the time periods ().
2The Search function allows you to search for the displayed charts. Click Show more filters to filter the charts. In addition, you can collapse and expand all entries.
3

Click   to create a new chart as follows:

1. Select the time periods (and, if available, select the months)
2. Select the organizational units;
3. Select the KPIs;
4. Select the chart type (you can only select the types of charts that are suitable to represent your previous selections);
5. Chart options (e.g. if you want to show values in a chart, enter custom labels or set target values and comparisons);
6. Enter name, description, etc.

4Here you can see the selected chart. Click the entries in the legend to hide or show the individual indicators or the organizational units.
Click  to edit the chart, or click to copy the chart, or click  to save the chart as an image.
5

In the Data Analysis section, all the values of the diagram are displayed in a tabular form. Click  to export all the values to Excel.
