Security Settings

The Security settings are separated into two sections: General security settings and Password settings.




1

 The General security settings of the portal allow you to specify the following:

  • Allow "remember me" should be shown on login.
  • Only allow Single Sign-On (SSO) login.
  • Allow autocompletion of the login form.
  • The number of allowed login attempts until a CAPTCHA check is performed.
  • The time, in minutes, before a user is logged out due to inactivity.
  • Allow login with either email or username.
  • Require two-factor authentication. The user will be emailed a code that they must enter when attempting to log in.  


2

 The Password settings allow you to specify the following password requirements:

  • How long the password is valid.
  • Require numeric characters, mixed casing, and/or special characters.
  • Minimum password length. 
  • The number of previous passwords that must be unique.
