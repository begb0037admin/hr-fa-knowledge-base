Version 2023.3

Release Date: Nov 19th (first group deployment) and Nov 26th (second group deployment)

WeSustain version 2023.3 provides the following features:

  • Analytics queries can now be displayed on the Dashboard.
  • Access to Dashboards, charts and analytics queries can now be restricted so that data editors can only view data that has been assigned to them based on their responsibility sets.
  • In the User Management module, admin users can now allocate Dashboards, charts and analytic user roles directly to module users.
  • In the Performance Module, a second Y-Axis can now be added to new or existing charts to compare multiple data sets. The second Y-Axis will consist of KPI values.

This function can only be added to charts that have one organizational unit included, and when the X-axis does not consist of KPI values.

  • In the Standards and KPIs module, rolling calculations is a new feature that automatically calculates sub-yearly KPIs based on the number of last rolling KPI values included by the user.

For rolling calculations to work for new reporting time periods, they need to be created before the year ends. If they are not, your rolling calculations will need to be set up again for the new year.

  • In the Scenarios and Targets module, the Target Value document can now be downloaded, filled in, and then uploaded back into the module.
