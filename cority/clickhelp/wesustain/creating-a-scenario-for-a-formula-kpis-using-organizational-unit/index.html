Creating a Scenario for a Formula KPIs using Organizationl Unit

To create a Scenario for a Formula KPI using Organizational Unit


1On the left navigation panel, click Data.
2Click Scenarios & Targets.
3Select a formula KPI.
4Information on the KPI is displayed to the right.
5Click the Scenarios tab.
6Click Create scenario. The Create Scenario window opens.



7

Fill in Name*, and Short name*.

Note: Filling in Description is optional.

8In the Type* dropdown textbox select Organizational Unit.
9Click Save. A Scenario section is created for the KPI in the information section.
