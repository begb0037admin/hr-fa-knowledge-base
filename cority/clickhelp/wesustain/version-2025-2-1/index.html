Version 2025.2.1

Release Date: July 4th 

WeSustain version 2025.2.1 enhances access tokens to improve security and compliance. These enhancements include:

  • The length of access tokens can be adjusted up to 128 characters.
  • Access tokens can now be set to rotate automatically at a specified interval. The rate can be set to never, 30 days, 60 days, 90 days, 120 days, or a custom rate.
