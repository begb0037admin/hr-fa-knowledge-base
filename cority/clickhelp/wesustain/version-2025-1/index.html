Version 2025.1

Release Date: Feb 21st (first group deployment) and Feb 24th (second group deployment)

WeSustain version 2025.1 provides the following features:

  • The text editor has been replaced. The new editor is more user-friendly and provides better layout and formatting options.
  • A number of user-inspired improvements have been made. These include:
    • A bulk action has been added, to the Cog icon, for replacing time periods for multiple charts at once.
    • In Data Management, a new 'Change units' button now enables users to update sub-yearly KPI units of measure in bulk, and a new 'Change type' button enables users to change the type for KPIs in bulk.
    • A bulk action has been added for email reminders. The bulk action drop-down is provided next to the Delete button. The 'Target Date', 'Send Date', and/or 'Message' can be edited in bulk.
    • Similar to the KPI settings, on the Forecast tab in Data Management, a user will now see the pertinent forecast settings information as well as the year(s) on which his or her forecast are based. The forecast settings information will be read-only (not editable).
    • When applicable, emission factor time periods (along with their parameters) will no longer be editable and their parameters can no longer be imported.
