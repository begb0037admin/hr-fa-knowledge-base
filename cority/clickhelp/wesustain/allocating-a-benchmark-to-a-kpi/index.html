Allocating a Benchmark to a KPI

To allocate a benchmark to a KPI

 


1 On the left navigation panel, click Setup.
2 On the Setup menu, click Standards & KPIs.
3 Select either a numeric or formula KPI.
4 Information on the KPI displays to the right.
5 Click the Organizational Model tab.
6

For the Organizational unit you want to add a Benchmark to, click the Edit icon under Benchmark. The Select benchmark window opens.

For Organizational units that do not have an edit icon, it is because the organizational unit has not been activated with responsibilities sets, and therefore no data was collected for these units.

 


7

On the Select benchmark window, select a Benchmark.  

Only one Benchmark can be selected for any KPI. Only benchmarks with an identical unit can be selected. 

If Values are not assigned to a benchmark, the value column for that Benchmark will be empty.

8 Click Save.

 


9 This symbol indicates a benchmark has been allocated to the KPI.
