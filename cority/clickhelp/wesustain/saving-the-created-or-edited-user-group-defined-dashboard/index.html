Saving the Created or Edited User Group Defined Dashboard

To Save the Created or Edited User Group Defined Dashboard

 

1Once the Dashboard is set up as needed, click Save & Update all users dashboards. A prompt displays “Save & Update all user dashboards”.

2Click Save & Update all users dashboards. The created or edited User Defined Dashboard is now viewable by users assigned to the dashboard.
