Version 2025.2

Release Date: May 23rd (first group deployment) and May 26th (second group deployment)

WeSustain version 2025.2 provides the following feature:

  • In the Admin module, in the Security settings tab, admin users can now enable two factor authentication for members using the 'Require 2-factor authentication via Email' checkbox. When enabled, users will receive an email with an access code that they will have to enter to log in.
