Version 2023.1

Release Date: March 19th (first group deployment) and March 26th (second group deployment)

WeSustain version 2023.1 provides the following features:

  • WeSustain user interface has been updated to be consistent with the different Cority systems.
  • In the Standards & KPIs module under the Targets tab, users can now select a KPI and use Bulk Flow action to assign and edit targets to various organizational units.
  • In the Standards & KPIs module under the Forecast Settings tab, users can now use Bulk Flow action to edit forecast settings for multiple numeric KPIs at once.
  • In the Data Management module, users can now use the target deviation function to see the difference between the actual value and target value. This can be used to analyze actual performance.
