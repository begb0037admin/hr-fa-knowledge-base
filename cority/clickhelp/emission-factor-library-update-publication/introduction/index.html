Emission Factor Library Updates

This page communicates the latest updates to the emission factor methodologies available in the Sustainability Performance Management solution. Previous updates are listed in the table of contents on the left. 

The updates include an outline of the methodologies being updated and any notable changes compared to the previous release.

Existing data files must be reprocessed to apply the updated emission factors for the dates of the following and previous updates. New factors are not automatically applied to data that was previously uploaded to the system. For support on managing this process or any other questions, please contact Cority Support.
