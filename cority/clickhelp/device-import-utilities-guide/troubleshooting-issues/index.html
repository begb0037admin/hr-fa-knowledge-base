Troubleshooting Issues

Reason for Rejection: [Employee.EmployeeNumber]: Employee record with [Employee #] 'XXXXXXX' does not exist. (MG-000365)

Description: This error occurs when you attempt to transfer a test result for an employee whose Employee Number is not present in Cority. Ensure that the Employee / Patient Number used on the device and the Employee Number used in Cority match exactly.

Remedy: If the Employee Number is not known or if the Employee’s SSN is preferred for the transfer, select the appropriate system setting (either Match tests to National Security ID for import of Audiometric Tests or Match tests to National Security ID for import of Pulmonary Tests) and use the Employee’s SSN number for the Employee Number on the device. Cority will then match the test results to the employee using the SSN.

After you have corrected the employee number issue, re-process the record.

Reason for Rejection: Employee Record with SSN Value XXXXXXX does not exist. (MG-000365)

Description: This is an issue with a Cority system setting (either Match tests to National Security ID for import of Audiometric Tests or Match tests to National Security ID for import of Pulmonary Tests). The system setting allows the Employee’s SSN number to be used as the unique identifier on the device if you do not know the employee number.

Remedy: If you are not using this, for example you do not have the SSN entered for each employee, go to System Settings and deselect the appropriate setting.

Re-process the file.

Reason for Rejection: [L1K]: Invalid value.

Description: This error means that the value entered in the L1K field is invalid. This error message will be similar for any result field with an invalid value on the record. The field with the invalid value will be identified in the brackets.

In most cases, this error occurs when a value has not been entered into the field.

For an audiometer, there is an additional issue if the test result that is being transferred is AA. This is not a valid value for Cority.

When this happens, a status popup indicates that zero records were added, rejected or updated. That is, no results have been imported.

Remedy: Modify the value and then re-process the record or transfer the result again.
