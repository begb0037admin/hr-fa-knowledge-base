Imported Fields

In this example, Cority is attempting to import information from an Audiometer. For any devices, it is best to leave as much of this as possible undefined on the device in order to leave most of the record-keeping to the Cority application. This will simplify the transfer process and reduce the possibility for errors.

  1. Employee Number – The Patient ID / Employee Number in the device must match the Employee Number in Cority exactly.
  2. Test Results
  3. Administered By Login Name – It is recommended that you leave this field in the device empty. If this field is populated, there must be a matching value for a user name within Cority for the transfer to be successful.
  4. Calibration Date – This can be tracked and recorded in the Equipment record in Cority. Therefore, it is best to leave it empty in the device if possible.
  5. Device Code – This must match the code used in the Equipment record for this device.
