Compatible Devices

We will not be building any new custom interfaces for the Device Import Utilities. Any devices we do not support already must push data to our new Cority REST API.

The Device Import Utilities support the following devices:

Audiometers

  • WAHTS Hearing
  • Benson CCA200
  • Tremetrics RA660
  • Amplivox 116, 170, PC850, 240, 260, 270, Otosure
  • Smart Tone
  • MI5000

Spirometers

  • Benson CCS200
  • EasyOne Air
  • Easy on-PC
  • ndd EasyOne Plus
  • Depisteo Q13

Vision Testers

  • Depisteo VT1
  • Titmus v4

Respirator Fit

  • Portacount Respirator Fit Testers
