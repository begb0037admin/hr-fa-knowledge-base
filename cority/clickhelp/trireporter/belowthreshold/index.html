Below Threshold Chemicals

If you have chemicals in the system with below threshold emissions, you do not need to file FormRs for those chemicals. However, you may wish to keep the FormR data for your own record-keeping purposes. You can change the status of those chemicals to Below Threshold.

To apply the Below Threshold status, the chemical must first be Validated, then Submitted.

To change the status of a chemical to Below Threshold:

  1. First, if you transferred data from last year, review and add any required information on the FormR. All sections must be validated (all tabs green).

    When you return to the Home page, the status of the chemical will be Validated if everything is correct.

  2. Select the chemical and click Submit. Status will now be Submitted.
  3. Select the chemical and click Change Threshold.

The status will now be "Below Threshold Submitted". If you print the FormRs, the print view will show the "Not Validated" watermark, to indicate that it is not for filing. No EFiles will be created for this chemical.
