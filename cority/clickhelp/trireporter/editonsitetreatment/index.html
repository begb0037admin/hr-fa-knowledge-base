Edit Onsite Waste Treatment

Onsite Waste Treament Methods are entered Part II Section 7A.

To add an onsite waste stream for the chemical:

  1. In section Part II, Section 7A, uncheck NA. Click Add Stream.
  2. In the Onsite Treatment screen, first select a General Waste Stream type from the list.

  3. Select one or more Waste Treatment Methods from the list, and click Add Method.

    For more information, see Waste Treatment Method Sequence.

  4. Select the Waste Treatment Efficiency Estimate from the list.

    For more information, see Waste Treatment Efficiency Estimate .

Edit Recycling Methods (Part II Section 7C)

To add or remove a recycling method for the chemical:

  1. In Part II, section 7C, uncheck NA, then click Edit Methods.

    To add a method, select a method in the left pane and click Add Method.

    To remove a method, select the method in the right pane and click Remove Method.

  2. Click Save when you are done.
