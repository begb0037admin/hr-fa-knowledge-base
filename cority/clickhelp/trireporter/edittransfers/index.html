Edit Transfers to Offsite Locations

Transfers to Offsite Locations are entered Section 6.2.

To add an off-site transfer: 

  1. Click Add Location. Select an off-site location from the drop-down list. Click Save.
  2. Click Add Release.

  3. Select the Waste Management Type code.

    For more information, see Type of Waste Management.

  4. Select the Basis of Estimate.

    For more information, see Basis of Estimate.

  5. Enter the quantity and click Save.

To edit the transfer details: 

  1. Click the button next to the RCRA ID, then click Edit Location.

To delete an offsite transfer: 

  1. Click the button next to the RCRA ID, then click Delete Location.
  2. Click OK to confirm that you want to delete the off-site transfer location for this chemical.
