Base Reports

From the main menu button , select Base Reports.

Three types of reports are available:

  • Section 5.1 to 5.5.4, 6.1, 6.2: Shows numbers by facility and chemical reported in Sections 5.1 to 5.5.4, 6.1 and 6.2
  • Section 8.1 to 8.8: Shows changes in values by chemical from one year to the next.
  • Management Report: Shows the number of FormRs and the overall status by facility (Submitted, Validated, In Progress, EFile).

Select the tab for the report type you want to run.

To run a Section 5.1 to .5.5.4, 6.1, 6.2 report:

  1. Select the reporting year.
  2. Check the facilities to include. You can check the box at the top of the column to select all.

  3. Select your preferred output format:

    Report in HTML: View the report in the browser.

    Report in Excel: Save the report to your computer and open in Excel

To run a Section 8.1 to 8.8 report:

  1. Select a Report Year 1 and Report Year 2 to compare data from two years.
  2. Check the facilities to include. You can check the box at the top of the column to select all.

  3. Select your preferred output format:

    Report in HTML: View the report in the browser.

    Report in Excel: Save the report to your computer and open in Excel

To run a Management Report:

  1. Select the reporting year.

  2. Select your preferred output format:

    Report in HTML: View the report in the browser.

    Report in Excel: Save the report to your computer and open in Excel
