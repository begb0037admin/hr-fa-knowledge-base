Submitting or Desubmitting a FormR

In order to create your electronic data files for filing with the EPA you must first "submit" the validated FormR. The FormR must have passed all validation tests first in order to submit it. See Form Validation.

When the form is submitted, the status of the FormR changes to Submitted and editing on the form is disabled. Electronic file creation is enabled. You may also print a final copy.

Note:  The buttons Create EFiles and Change Threshold are displayed only if there is at least one FormR with Submitted status. These actions will only be allowed for FormRs with the status Submitted.

To submit one or more FormRs:

  1. On the Home page, check the boxes for the FormRs you are ready to proceed with.

  2. Click the Submit button.

    If you decide you need to edit the FormR further, you can "desubmit" the form to edit it. Simply check the FormR and click DeSubmit.
