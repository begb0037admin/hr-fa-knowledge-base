Tagging Data for TRI Reporter

In order to use all of the functionality of EMS TRI Reporter, the TRI system data must be stored in the Management System in a TRI system tree with the objects tagged according to the conventions described here. Once the data has been created in the system, the prior year TRI data is pulled into TRI Reporter in a data transfer operation.

The data tagging process requires creating a series of unique tags in the System. The Unique Tag is a custom field which can be applied to requirements and tree objects in the System Model. Requirements are used to store the data that will be transferred and tree objects are used to organize and identify TRI locations like Facilities, Streams and Off-Site Locations. POTWs are not identified in the system.

Instructions for the tagging structure is included in this section. You can download a pdf of these instructions here: TRI Data Tagging
