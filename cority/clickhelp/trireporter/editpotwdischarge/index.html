Edit Discharges to POTWs

Discharges to Publicly Operated Treatment Works (POTWs) are entered Section 6.1.

To add a POTW for the chemical:

  1. Click the Edit POTWs button.
  2. From the All POTWs list, select a POTW, then click Add Selected POTW. Click Save.

To view the POTW details, with the POTW selected, click POTW details.

To create a new POTW, click the "Create new POTW" link on the bottom. See .

To remove a current POTW for the chemical:

  1. Click the Edit POTWs button.
  2. Select the POTW in the Current POTWs list and click Remove Selected Row.
