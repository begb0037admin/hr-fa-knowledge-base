EMS TRI Reporter

With EMS TRI Reporter you can complete, print and electronically file all your Toxic Release Inventory FormRs. EMS TRI Reporter creates the electronic files required to submit reports with the EPA's TRI-MEweb application.

Electronic Reporting Requirement: Electronic report submission via TRI-MEweb is required, except for facilities submitting TRI reports containing trade secrets which are accepted on paper. The electronic reporting requirement includes late submissions for prior years, revisions and withdrawals.

If this is your first time using the EMS TRI reporting tool, see Getting Started with EMS TRI Reporter.
