myCority Design Improvements and Fixes

The table below lists the design improvements and fixes we have made in the myCority 2024.1.1 release. The items are organized by component and the components are arranged in alphabetical order.

Item #Component(s)ReportedDescription
CCC-9277Dashboards, TranslationsN/A

When translations are properly provided for dashboard view names, those translations will now also be applied successfully in myCority.

 

CCC-16099Environmental – ComplianceN/A

In the Permits module, the maximum character length of the Description and Text UDF fields has been increased to 8000. The maximum character length of the Work Order field has been increased to 1000.

 

CCC-16263Environmental – Waste ManagementN/A

The PCB Load Type and Special Handling  fields can now be added to custom versions of the Waste (ML-000393) layout.

The Special Handling field can now be added to custom versions of Waste Manifest (ML-003510) layout.

 

CCC-15293Findings & ActionsN/A

From Action records, a user with the appropriate security configuration can now download from 'Attach Documents' or 'Attach Completion Documents' when applicable.

 

CCC-14996InspectionsN/A

On Inspections in myCority, for Action layouts, dynamic sections now function as expected.

 

CCC-16189Occupational Health – Case ManagementN/A

If the Medical Records report is configured as a standard query and to include Case Notes, and one or more Case Activity Codes being used are translated within the look-up table, when a user with the required security configuration downloads the report from myCority, those Case Activity Codes will now be translated as expected.

 

CCC-16306Occupational Health – Pre-Placement Process2023.3.2

For the pre-placement process, when applicant registration bypass is configured, the user experience if copying and pasting the password from the system generated email has been improved.

 

CCC-15885Platform – InfrastructureN/A

For self-hosted clients, if properly configured, a myCority proxy user will now function as expected.

For information on proxy users, see the GX2 User Guide.

 

CCC-14377Safety, PDFsN/A

In the Safety cloud, for a record (for example, a Permit to Work) with mapped fields for a linked and published PDF form, when the PDF form is opened from the record in myCority, the correct data will now be provided and displayed.

 

CCC-16005Translations, EmailN/A

When configured properly, the email body in an email sent from myCority 'My Records' will now translate correctly, including the 'here' link (where applicable).

 

CCC-7909Translations, My RecordsN/A

When applicable, translations are now properly applied in myCority 'My Records'.
