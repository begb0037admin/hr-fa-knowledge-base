GX2 Design Improvements and Fixes

The table below lists the design improvements and fixes we have made in the GX2 2024.1.1 release. The items are organized by component and the components are arranged in alphabetical order.

Item #Component(s)ReportedDescription
CCC-16249Business Intelligence – Query Builder, Report WriterN/A

For creating custom views in Query Builder or Report Writer, the 'Disable Site Security' and 'Modified By' columns are now available.

 

CCC-14640Business Intelligence – DashboardsN/A

When the 'Application Message' system setting is configured, on an Advanced Dashboard the text for a number indicator will no longer mix with the application message text.

 

CCC-14260Business Intelligence – Query Builder2023.2.0

In Query Builder, when filtering after aggregation and then saving, filters will now save. They will be retained after saving.

 

CCC-16884Chemical Management2024.1.1

When applicable, 'NFPA Dimond' will now be available in the Phrase Translations list.

 

CCC-16390Chemical Management2024.1.1

The Chemical Management 'Print Standard Labels' and 'View/Print Labels' phrases are now available in the 'Phrase Translations' module.

 

CCC-15392Chemical ManagementN/A

If a user language is properly configured, the Public Chemical Product link and contents will now respect that.

 

CCC-15390Chemical Management, MOCN/A

An Environmental 'Chemical Product Request' (MOC) that has a Flex Fields questionnaire with an attachment can now be saved and submitted by a user who has the required security configuration without generating an unexpected security validation error.

 

CCC-14808Environmental – ComplianceN/A

In the Permits module, the maximum character length of the Description and Text UDF fields has been increased to 8000. The maximum character length of the Work Order field has been increased to 1000.

 

CCC-16397Environmental – MOC, EquipmentN/A

For Change Requests, when creating and then saving a new related Equipment record, an unexpected object reference error is no longer generated.

 

CCC-14964Environmental – Legal RequirementsN/A

A display rule using the 'Environmental Legal Requirement' entity that is properly configured to filter 'Requirement Types' look-up table values will now function as expected.

 

CCC-16333Industrial HygieneN/A

For IH Monitoring Samples, on the Agent tab, the 'Result' and 'Non-Sampled' concentration fields now both record up to a maximum of four decimal places only.

 

CCC-15834Industrial HygieneN/A

On a custom IH Monitoring layout that has Flex Fields, the 'Save & Close' action now functions as expected. Flex Field data will save.

 

CCC-15320Industrial HygieneN/A

When making changes to Flex Fields on a Hearing Fit or Respirator Fit record, the user will no longer encounter a flashing screen.

 

CCC-15882Management of ChangeN/A

In the Safety MOC module, the Record History now shows names for specified approver field values instead of numbers.

 

CCC-14791Management of ChangeN/A

A user with the required role security configuration can now clone, open, and use the 'Parallel Approval Workflow Action' (ML-003545) layout.

 

CCC-14272Management of Change, WorkflowsN/A

In Management of Change, if a workflow has parallel approval steps and an approver rejects at one of them, both will now be cleared of any approval and the workflow will revert successfully to the expected previous step.

 

CCC-13870Management of ChangeN/A

The Cority Data Integration Utility can now be used to successfully update data in the Environmental 'Management of Change' module.

 

CCC-6161Management of Change, Incident, EquipmentN/A

A user can now successfully associate equipment (add related assets) to an applicable record (a Safety/Environmental Incident, Change Request, etc.) and without encountering any unexpected issues.

 

CCC-16451Occupational Health – Drug TestingN/A

On a custom 'Drug Testing Results' layout with a Flex Fields subsection, a user can now fill in field values and successfully 'Save and Close' the record without generating an unexpected error.

 

CCC-16253Occupational Health – Medical QuestionnairesN/A

The archive and purge business rule feature set now functions properly for medical questionnaires and questionnaire responses.

 

CCC-16233Occupational Health – Medical QuestionnairesN/A

A user can now delete a large medical questionnaire from within a record without receiving a timeout error.

 

CCC-16040Occupational Health – AppointmentsN/A

When a user books a single appointment in a specific slot, the system no longer books multiple appointments in that same slot.

 

CCC-15678
Occupational Health - Billing
N/A

The OH Billing solution now provides the HCFA-1500 (CMS-1500) PDF form, out of the box. It maps using the GX2 Form Mapper tool, will populate automatically with available pertinent information, and is printable.

To support this:

  • A new ‘PDF Short Date Style’ (mm dd yy) option has been added to the ‘PDF Forms Mapper’ look-up table.
  • A new ‘Include on HFCA Form’ check box can be added to custom versions of the Clinic Visit ‘Billing Items’ (ML-003804) layout.
  • A new HCFA Totals (Charges)’ field can now be added to custom versions of the Invoice (ML-003780) layout.

For the two new fields, the equivalent column can be added to custom versions of applicable list views.

For more information on the Billing solution, Form Mapper, or configuring either custom layouts or list views, see the GX2 User Guide.


CCC-14490Occupational Health – MedicationN/A

When a user creates a custom 'Medication Lot' layout through cloning, that layout will now be available in the 'Medication Lot' look-up table for creating new table entries.

 

CCC-15641Occupational Health – Medical MonitoringN/A

On a custom 'Drug Testing Battery' layout with a Flex Fields subsection, a user can now fill in the field values, attach a document if required, and successfully 'Save and Close' the record without generating an unexpected site security error.

 

CCC-8381Occupational Health – Case Management2022.1.1

For a Case record with forms attached, if the user selects one or more forms from the Forms tab and clicks the Print action, those forms will now process and display properly.

 

CCC-16300Platform – AdministratorN/A

In Demographics, UDFs and the linking of records (including any known restrictions) now function together as expected.

 

CCC-16261Platform – AdministratorN/A

When a business rule (BR) is properly configured with an email action that has an attached PDF and the BR is scheduled, the BR will now function as expected.

 

CCC-16239Platform – Administrator, CorAnalyticsN/A

An administrator can now grant to a user a role that is already granted to 500+ users and has the CorAnalytics Viewer module without generating an unexpected error and timeout.

 

CCC-14684Platform – Administrator, Findings & ActionsN/A

A display rule configured correctly to display the Verification section on an Action layout when certain criteria are met will now function properly.

 

CCC-10059Platform – AdministratorN/A

If selected, the new ‘Lock List View Record Counts’ system setting ensures that the value set for the ‘Number of Records Displayed on List’ system setting is not editable by end users.

 

CCC-5338Platform – Administrator, TranslationsN/A

For a hard-enforce business rule with a message (phrase) that contains a carriage return, phrase translations will now function properly and without generating any unexpected errors.

 

CCC-16265Platform – End-User, Job PositionN/A

On list views, the Job Positions column now functions the same in all applicable areas.

 

CCC-16237Platform – End-UserN/A

When a layout has a date field (for example, End Date) that requires a value, if the user enters an invalid value and attempts to save the record, an error message will now display and the record will not save. Previously, the record would save leaving the date field empty.

 

CCC-10026Platform – End-User, WorkflowsN/A

When a workflow is configured and a record moves from one step to another (the status changes), either by business rule or manually using a button, the Workflow History will now update as expected.

 

CCC-16034Platform – InfrastructureN/A

If the database goes down (fails) and restarts, all time-driven business rules (TDBRs) will now refresh properly.

 

CCC-15146Quality, Document ManagementN/A

A custom 'Published Document' layout that has 'Reviewer' and/or 'Document Content Type' fields will now open without generating any unexpected errors.

 

CCC-15215QuestionnairesN/A

For questionnaire questions that use parent-child functionality, the default response feature now functions properly.

 

CCC-14686QuestionnairesN/A

For users with site security configured, site security now applies properly to questionnaires.

 

CCC-10998QuestionnairesN/A

You can now export a questionnaire, with a question response or response comment that has one or more angle bracket symbols (<>), successfully to XML and open it in Microsoft Excel without encountering any unexpected errors.

 

CCC-16124Safety – Incident 

For FRA Form 54, ‘Special Study Block A – Primary’ and Special Study Block A – Secondary’ are now text field / data types and now function accordingly.

 

CCC-15586Safety – Incident, Event ReportingN/A

For a Safety 'Event Report', when there are identical job positions on the 'Job Position' sublist (with or without end dates) and a value is provided for the 'Person Involved' field, the correct Supervisor will now auto-populate.

 

CCC-15730Safety – IncidentN/A

For Incident reports created in Query Builder, when applicable, 'Deviation End Time' values will now be accurate.

 

CCC-15533Safety – Incident, WorkflowsN/A

For workflow actions on Incident records, the 'Display as button' option now functions properly and consistently.

 

CCC-15248Safety – IncidentN/A

If set up properly, a business rule configured to trigger on the submission of a Safety 'Incident Self Report' (with or without an embedded questionnaire) will now do so without any unexpected issues.

 

CCC-16628Safety – Permit To WorkN/A

For a 'Permit to Work' record, on the 'Linked Records' tab (sublist), the 'Type of Work', 'Permit Type', and 'Workflow Status' values will now display instead of codes.

 

CCC-16488Safety – Permit To WorkN/A

If a business rule configured to lock a 'Permit to Work' record is triggered, the tabs (sublists) on the record will now become locked as well.

 

CCC-16366Safety – Permit to WorkN/A

A business rule correctly configured to trigger soft-enforce when a user cancels a Work Permit will now function as expected in GX2.

 

CCC-7174TranslationsN/A

When properly configured, if the translation API is set to be Microsoft Azure, the system will now translate properly into Portuguese (Portugal) and Portuguese (Brazil) when and where expected.

 

CCC-16497Waste Management – EnvironmentalN/A

The PCB Load Type, PCB Serial No, and Special Handling  fields can now be added to custom versions of the Waste (ML-000166) layout.

The Special Handling field can now be added to custom versions of Waste Manifest (ML-000229) layout.

The PCB Weight field can now be added to custom versions of the Waste Container (ML-000228) layout.

 

CCC-15505Waste Management – EnvironmentalN/A

For e-Manifest submission, the following enhancements have been made:

  • Two Special Handling fields now map.
  • The PCB Load Type field now maps.
