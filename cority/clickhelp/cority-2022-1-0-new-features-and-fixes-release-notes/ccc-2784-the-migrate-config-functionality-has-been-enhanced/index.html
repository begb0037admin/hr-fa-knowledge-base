CCC-2784: The Migrate Config functionality has been enhanced

  • Where applicable, links to dashboards (for example, links from the My Views dashboard gadget) will now be exported/imported when using Migrate Config. Note: For import, the dashboard(s) must already exist in the target environment.
  • Two new endpoints and improved structure and format across the Migrate Config back-end will enable the Cority Quality Assurance team to perform quick and accurate regression testing for the support of new, related GX2 features.
  • All business rules (including any subqueries) with newly added business rule actions (Bulk change, Create record, etc.) can now be exported from and/or imported into a GX2 environment.
  • Note: Migrate Config assumes all associated look-up table and GDDLOFB fields already exist in the target environment.
  • Overall, this expanded functionality will help GX2 Administrators migrate their configurations completely and accurately, which will in turn help ensure the quality of their production systems.
  • For more information on working with Migrate Config, see the Cority GX2 User Guide.
