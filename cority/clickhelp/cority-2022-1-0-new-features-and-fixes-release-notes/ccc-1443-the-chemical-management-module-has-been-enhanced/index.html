CCC-1443: The Chemical Management module has been enhanced

  • A 'Start new Change Request' action can now be added to custom versions of the GX2 'Chemical Product' and 'Chemical Inventory' layouts, and to the myCority 'Chemical Product' layout. The new action will initiate a chemical change request that will open in an appropriately semi-populated MOC layout.
  • The new 'Ingredient Screening' tab (sublist) can now be added to custom versions of the GX2 and myCority chemical 'Change Request' layouts. This will enable CAS pre-screening.
    The new sublist has a default 'Ingredient Screening for This Product' list view with appropriate columns and standard actions.
  • A new out-of-the-box 'Agent Hazard' layout, which is configured for pre-screening materials on 'Change Request' records, is now provided.
  • To enable users to capture additional information related to inventory movements and enhance chemical inventory reporting, additional fields have been added to the 'Chemical Inventory' and 'Current Inventory Amount' data tables. In addition to the 'Current Inventory Amount' and 'UOM', users will now have the ability to capture the:
    • Type of Transaction (used, wasted/lost, transferred, inventory correction)
    • Transaction Amount
    • Transaction UOM
  • Additional UDF Fields have also been added to those tables. This will provide increased configuration flexibility.
  • To support the functionality above, additional UDFs have been added to and a few of the fields enhanced in the 'Agent Hazard' (Chemical Product) look-up table. The functionality of the updated fields has not changed.
