CCC-6892 and 5431: The Display Rules module has a new Layout action

  • The Display Rules module is used for creating rules that dictate what should happen to a layout or set of layouts as a record moves through a workflow.
  • A display rule is similar to a business rule, except display rules trigger immediately on values changing, as opposed to triggering on Save.
  • The Display Rules module is included with the Administrator set of tools.
  • For more information on the module, see the release note for CCC-227 in the Cority 2021.3.0 New Features Release Notes document.
  • When creating a display rule with a Layout action, the user will be able to choose from the list of layouts that are compatible with the entity specified.
  • If a Layout display rule is created, when the rule's conditions are met within a workflow step, any record produced or opened that is for the specified entity will be associated with and always opened in that layout.
  • A Layout display rule will override any associated, pre-configured layout logic, and the layout selector on applicable records will be disabled.
  • Only one of each display rule action type can be used per display rule.
    • For example, you can't add two Layout actions to one display rule.
