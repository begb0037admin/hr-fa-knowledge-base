CCC-5661: The Layout Editor has been centralized, and restructured with enhancements.

  • This functionality will simplify the creating and configuring of custom layouts, making that process easier and more user-friendly.
  • Each of the following is now directly accessible for configuration from its own new sublist on the Layout Editor:
    • Business Rules
    • Display Rules
    • Look-up Tables
    • Related Layouts
  • If its corresponding look-up table has entries, each of the following is now directly accessible for configuration from its own link on the Layout Editor:
    • Flex Fields
    • Workflow Steps
  • Any of the above items accessed through the Layout Editor and then newly created will be displayed immediately on the appropriate list view(s).
  • Also, the new Layout Editor will simplify adding and configuring:
    • Tabs (Sublists)
    • Sections
    • Buttons
    • Actions
    • Fields
    • Granted Roles
  • All of the functionality for adding and configuring such items is retained, but is now more intuitive and easy to use. For example, all available layout fields for the entity selected are now displayed, added/removed, and configured using a single dialog box. Simply click an added field to access its configuration options.
  • As on the previous version of the Layout Editor, all applicable security configuration will be respected.
  • The Cority GX2 User Guide, when updated for the Production release, will provide a couple of generic, workflow examples.
