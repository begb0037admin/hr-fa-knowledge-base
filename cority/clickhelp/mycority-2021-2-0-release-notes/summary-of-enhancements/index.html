Summary of Enhancements

The table below describes the enhancements we have made in 2021.2.0.

Item #Component(s)Description
CCC-3197Appointments, Scheduling

The standard GDDLOFB fields can now be added to custom versions of the myCority 'Schedule Entry' layout (ML-000396).

 

CCC-3128Appointments, Scheduling

The following standard user-defined fields (UDFs) can now be added to custom versions of the myCority 'Schedule Entry' layout (ML-000396):

  • 6 new alphanumeric UDF fields
  • 6 new date/time UDF fields
  • 6 new flag (check box) fields
  • 6 new look-up table UDF fields

For each new look-up table field, an accompanying LU_SCH_UDF look-up table has been created.

These new fields are all configurable using the standard UDF field functionality. For information on working with UDF fields, see the Cority User Guide.

 

CCC-356Chemical Management

myCority has new Chemical Management functionality. This includes:

  • A Chemical Products option on the myCority Home screen
  • A Chemical Products list view with 'SDS Link' column
  • A new myCority Chemical Product layout
  • The ability to create Chemical Product records from myCority

 

CCC-3174Clinic Visit, Vaccinations

The appointment confirmation email can now include the employee barcode, so that it can be scanned during the appointment. To support this, three new employee barcode merge fields are now available under Employee 'Merge Fields' for business rule email actions:

  • Employee Barcode Text
  • Employee Barcode 1D Barcode
  • Employee Barcode 2D QR Code

If you clone BRA-100542 and add the desired barcode (text, 1D, or QR) to the clone, the barcode will display in the body of resulting emails.

 

CCC-243Dashboards

In 'My Dashboards', an indicator title will now display up to two lines of text. If the title exceeds two lines, it will be truncated and followed by an ellipsis.

 

CCC-2841Event Reporting, Incidents

When the Witnesses and Contacts tab (sublist) is added to a myCority layout, it now has the Save button.

 

CCC-3586General

The myCority login screen has been updated to reflect new branding.

 

CCC-1366General

The performance for using Help while offline is now improved.

 

CCC-1181General

jQuery has been updated from version 3.4.1 to version 3.5.0.

Note: Self-hosted clients must upgrade that library on their own.

 

CCC-1036General

Using the Migrate Config functionality, profiles with assigned myCority security modules and myCority questionnaires can now be exported and imported successfully.

 

CCC-957 and 955General

Each ‘Coordinates’ field in myCority is now accompanied by an intuitive and navigable map. The map is a helpful visual aid and can be used to adjust the coordinates.

 

CCC-798General

A new global system setting labelled 'Enable Absence Reporting and My Records for Non-SSO/LDAP myCority Users' allows Administrators to specify whether or not My Records and Absence Reporting tools in myCority are available to users who are not SAML SSO or LDAP authenticated. The setting is a check box, and by default it is not selected. The setting is categorized under the Portal/myCority security module.

 

CCC-569, 2833, 2834, and 3231General, My Account

There is a new myCority 'My Account' layout (ML-20003532) that replaces the hard-coded 'My Account' screen.

By default, the layout has all of the existing fields that were on the 'My Account' screen.

The following three fields can be added to custom versions of the myCority 'My Account' layout:

  • Date Format
  • Number Format
  • Time Format
  • Employee Barcode

 

CCC-321General

When the user is offline, then goes online, he or she is presented with the login screen. After successfully logging in, myCority will be functional online with loaded data, as expected.

 

CCC-264General

If the 'Concurrent Sessions Per User' system setting for a site is configured (not empty/blank), then the number of concurrent myCority sessions for a single user will be restricted to the limit specified in that setting. Note: Anonymous users (myCority/Portal guest users or standalone users) are not counted.

If a session beyond (above) the limit is attempted, once logged in, the oldest session will be eliminated.

 

CCC-393Questionnaires

A questionnaire in myCority can now be configured to display a custom questionnaire header with accompanying fields (that may or may not be required). To support this, there is a new 'myCority Questionnaire Response Header' layout, and a new 'myCority Header' field has been added to the Questionnaires look-up table.

 

CCC-749Reports

For the 'Medical Records Report' in both Cority and myCority, when the 'Document' option is selected in either 'Print Preview' or 'Print', email-type documents (EML, MSG, and MHT formats) are now also supported.

 

CCC-357Waste Management

myCority has new Waste Management functionality. This includes:

  • A Waste Management option on the myCority Home screen
  • A myCority Waste Management list view and accompanying layout
  • A myCority Waste Containers list view and accompanying layout
  • A myCority Waste Manifests list view and accompanying layout
  • The ability to create Waste records, record waste container information, and generate waste manifests using myCority

 

CCC-725Waste Management

You can now create new 'Waste', 'Waste Container', and 'Waste Manifest' records when you are offline.
