Fix Descriptions

The table below describes the fixes we have made for 2021.2.0.

Item #Component(s)Reported VersionDescription
CCC-3748Appointments, Vaccinations2021.1.2

A user can now successfully update a vaccination appointment using myCority. The infinite loop issue has been resolved.

 

CCC-3573Appointments, SchedulingN/A

On custom Scheduling layouts in myCority, set default values now display as expected.

 

CCC-1803Dashboards2020.2.2

For a Data Cube view published to a dashboard, the Y-axis title will now properly display in myCority.

 

CCC-3592EnvironmentalN/A

When adding an Environmental document, the document can now be saved with either a Doc HTTP link or an attached import file.


CCC-3689Event ReportingN/A

A user logged in as a guest can now successfully save an Event Report.

 

CCC-2872Event ReportingN/A

When the user prints or exports an Event Report, the action details for any 'Findings & Actions' records will now be included.

 

CCC-3602GeneralN/A

The dynamic form functionality now works as expected when more than ten conditions are defined.

 

CCC-3425General2020.1.0

On the 'My Tasks' list, when using filters such as Investigations, Questionnaires, etc., the 'items per page' functionality now works properly.

 

CCC-3363GeneralN/A

On an Android device, the Location field now works as expected (without any overlap issues).

 

CCC-3986Incident, Injury/Illness2021.1.1

For an Incident 'Injury/Illness', the user can now successfully select a 'Physician' field value and save the record.

 

CCC-3692 and 3362IncidentN/A

When the 'Filter Root Cause by Cause Category' system setting is selected, myCority will now show only the root causes that are linked to a cause category.

If the setting is not selected, myCority will now show all of the root causes.

 

CCC-3822MetricsN/A

Campaign records now load faster. Also, where applicable, the user is now able to successfully enter decimal values in number fields using either comma(s) or period(s), based on the number format specified in 'My Account'.

 

CCC-2643QuestionnairesN/A

For questionnaires in myCority, check box questions now function as expected when selecting/deselecting and saving.

 

CCC-2334Questionnaires2021.1.0

When selecting a questionnaire, inactive Questionnaire records are no longer listed.

 

CCC-4185Waste ManagementN/A

For Waste records, on picklists with the Code and Description columns, the smart search now works as expected for both.
