myCority Design Improvements and Fixes

The table below lists the design improvements and fixes we have made in the myCority 2024.2.1 release. The items are organized by component and the components are arranged in alphabetical order.

Item #Component(s)ReportedDescription
CCC-17626BI – Dashboards2024.1.2

In 'My Dashboards', the search functionality on the dashboards picklist now works properly.

 

CCC-17331Demographics, Display RulesN/A

For the 'New Employee' Short Form, if a display rule is configured to make a field required, that field will now become required and editable as soon as the condition(s) for the display rule are met.

 

CCC-17336
Event Reporting, Findings & Actions
N/A

On an Even Report for Injury/Illness, if a questionnaire has two questions for which each have an answer that should create actions, the correct number of actions will now be created.


CCC-7445Findings & ActionsN/A

On custom Findings and Actions layouts in myCority, added fields now render how and where expected.

 

CCC-17896QuestionnairesN/A

Where applicable, when declining the consent for a questionnaire the 'Consent Declination Reason' field will now accept up to 2000 characters.

 

CCC-17993PlatformN/A

The reset password feature now functions properly when the user's credentials contain the '#' character.

 

CCC-16687Safety – Permit to WorkN/A

A display rule for the RecordRelatedRisk entity that is configured to ensure a specific layout is presented when the rule's conditions are met will now function as expected in myCority.

 

CCC-17594TranslationsN/A

When applicable, a phrase added using the Import Utility and then translated will now render where and as expected in myCority.
