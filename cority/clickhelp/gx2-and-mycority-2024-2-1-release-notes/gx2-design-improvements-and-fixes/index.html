CCC-17660Ergonomics - ReportsN/A

The Ergonomics cloud now provides the ‘Progress Report’.

You can access the report from Ergonomics > Ergo Reports. It will also be available in Business Intelligence > Reports.

The report respects the user’s site security configuration.

The report provides the risk breakdown by progress, according to filters applied by the user, for a group of people on a specified date or over a user-specified period of time.

The user can compare the provided progress bars at different dates to see how the risk levels for a population have changed.

 

The report can be exported to PDF.

For information on working with GX2 reports, see the GX2 User Guide.

CCC-11946Platform - InfrastructureN/A

The RESTful API now has an IP whitelist that is separate from that of GX2/myCority.

To support this, the existing 'IP Whitelist' system setting has been renamed 'GX2/myCority IP Whitelist'. If not empty, only the IPs listed (or within the ranges listed), can access the GX2/myCority environment. If empty, all IPs can access the GX2/myCority environment.

Also, there is a new 'RESTful API IP Whitelist' system setting. If not empty, only the IPs listed (or within the ranges listed), can access the RESTful API. If empty, all IPs can access the RESTful API.

Note: This does not affect the AdminIPWhitelist server setting. The IPs listed in AdminIPWhitelist will still have access to GX2, myCority, and the RESTful API.
