CCC-342: On a permit, the process for specifying a legal requirement / regulation has been enhanced

  • On a Safety or Environmental permit, when you inline-add a record to the 'Legal Requirements' (Safety) or 'Regulations' (Environmental) tab, the resulting dialog box now has the following new columns: Regulation/Standard Name and Subsection Name.
  • The new columns are provided on each standard view.

Impact to Existing Users:

  • These are additional identifiers to help users differentiate between legal requirements / regulations when linking them to a permit.  

Additional Configuration Considerations:

  • No new configuration is required.
