CCC-802: The Contractor layout has a new 'Share With Group' tab (sublist)

  • The new 'Share With Group' tab can be added to custom versions of the layout (ML-003295).
  • The 'Share with Group' tab has one list view named 'All Groups for this Contractor'. The list view has the Group, Start Date, End Date, and Contractor columns.
    • The list view provides the Edit and Delete buttons and an Actions menu with the 'Export List to Excel' and 'Show Record History' options.
    • The list view has the Create/Clone View and inline-edit features.
  • The 'Share With Group' table is available for use in business rules. In business rules, its entity is named 'Contractor Group'.
  • The 'Share With Group' table and its fields are available for use in Query Builder, Report Writer, and the Import Utility. It is grouped under the Contractor module.

Impact to Existing Customers:

  • A user can now identify employee groups that share contractors, so that they can receive related updates through automated email notifications.

Additional Configuration Considerations:

  • Beyond what is described above, no additional configuration is required.
