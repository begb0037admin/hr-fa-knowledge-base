CCC-1431 and 3657: The Employee Banner can now provide alerts for the selected employee

  • The new Alerts icon can now be added to custom versions of the Employee Banner layout (ML-003001).
  • When added:
    • The icon will appear next to the employee's name at the top of the banner.
      • The icon will be orange when there are records for the selected employee in the Problem List module.
      • The icon will be gray when there are no records for the selected employee in the Problem List module.
    • The icon will be accompanied by a 'View Alerts (count)' link. For example: View Alerts (3).
      • The count is the number of records that are in the Problem List for the selected employee.
      • The user can click the Alerts icon or accompanying link to navigate to the Problem List module for the selected employee.
  • To navigate using the icon or link to the Problem List, the user's role must be granted the Problem List security module.
  • Note: The Problem List still includes inactive and/or closed records. This will be addressed in a future release.

Impact to Existing Users:

  • A practitioner can now see alerts for the selected employee on the Employee Banner. This helps ensure the practitioner is aware of the employee's issues before making any clinical decision(s).

Additional Configuration Considerations:

  • Beyond what is described above, no additional configuration is required.
