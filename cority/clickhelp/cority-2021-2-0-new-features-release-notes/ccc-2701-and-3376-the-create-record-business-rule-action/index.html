CCC-2701 and 3376: The 'Create Record' business rule action has been enhanced

  • When the user creates a new record, a business rule with the 'Create Record' action can now create a child record on a tab (sublist) of that newly created record.
    • For example, when the user creates an Equipment record, a new record will automatically be created on the 'Findings & Actions' tab (sublist) of the Equipment record.
  • When the user creates a new record, a business rule with the 'Create Record' action can now create a related record.
    • For example, when the user creates a Clinic Visit record, a related CaseMaster record will automatically be created.
  • The two functions above can be combined in one business rule.

Impact to Existing Users:

  • The 'Create Record' business rule action is now more powerful and versatile.

Additional Configuration Considerations:

  • Beyond what is described above, no additional configuration is required.
  • For information on working with business rules and business rule actions, see the Cority User Guide.
