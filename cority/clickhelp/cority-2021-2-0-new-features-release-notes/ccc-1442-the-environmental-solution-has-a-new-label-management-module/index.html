CCC-1442: The Environmental solution has a new Label Management module

  • With this new module, EHS Managers can generate secondary GHS container labels for each of their chemical products.
  • To use the new module, a user's role must be granted the 'Label Management' security module.
  • The module's main list provides a 'Label Templates' view with the following columns: Label Template Name, Default Stock, and Created Date.
  • The module's main layout (ML-003608) has the New, Save, Cancel, and Delete buttons, as well as an Actions menu with the Save Layout, Show Record History, and Edit Layout options.
    • The layout has a 'Details' subsection with the following fields:
      • Template Name (required) - A text field (that accepts a maximum of 50 characters)
      • Label Stock (required) - A look-up selector, from which you can select one of the entries in the 'Label Stock' look-up table
      • Font (required) - A drop-down menu with the following options: Arial (default), Verdana, Impact, and Comic Sans MS
      • Font Size (required) - A drop-down menu that provides font sizes 12 (default) through 30
      • Padding Top (required) - A drop-down menu provides options 0 (default) through 10
      • Padding Left (required) - A drop-down menu provides options 0 (default) through 10
  • To the right of the 'Details' subsection, a 'Label Preview' pane will display a preview of the label according to the label details you have selected. You can reposition the items in the preview can be drag-and-dropping within the 'Label Preview' pane.
      • The layout has the standard 'Applicable Locations' tab, as well as a 'Chemical Product Fields' tab.
        • The 'Chemical Product Fields' default view has a Field Name column, and a multi-add button that allows you to add one or more 'Agent Hazard' fields.
  • The 'Chemical Products' (ML-000831) layout has two new tabs: 'Symbols' and 'Phrases'.
      • The 'Symbols' tab has a 'Symbols for this Product' view with a 'Code' column and a multi-add button.
        • When you click the multi-add button, the 'Chemical Symbol' dialog box will open, from which you can select one or more records from the 'Chemical Symbols' look-up table.
      • The 'Phrases' tab has a 'Phrases for this Product' view with the 'Code' and 'Description' columns and a multi-add button.
        • When you click the multi-add button, the 'Chemical Phrase' dialog box will open, from which you can select one or more records from the 'Chemical Phrase' look-up table.
  • The 'Chemical Products' list view has a new 'Print Labels from Template' action.
      • The new action can also be added to custom versions of the 'Chemical Products' (ML-000831 and ML-000706) layouts.
      • When you select the new action for a chemical product, you will be directed to the 'Select Label Template' list view.
      • The list has two default views: Label Template and Saved Labels.
      • The list has an Actions menu with the Show Record History and Export List to Excel options, and the following columns: Label Template Name, Default Stock, and Created Date.
      • When you select a record from the list, it will open in the 'Chemical Product Label' (ML-003622) layout.
        • The layout will display all of the fields and label details that were selected on the 'Label Template' (ML-003608) layout, and a preview of the label to the right.
        • The layout has the following two tabs: Symbols and Phrases. Each tab provides the same fields and functionality as its equivalent on the 'Chemical Products' (ML-000831) layout.
  • A 'Label Stock' look-up table is now available.
      • The new look-up table has a standard view, the New, Edit, and Delete buttons, an Actions menu with the Export List to Excel and Show Record History options, and the following columns: Code, Description, Width, and Height.
      • The new look-up table provides a 'Label Stock' (ML-003607) layout with the New, Save, Delete, and Cancel buttons, as well as an Actions menu with the Print Form, Show Record History, and Edit Layout options.
      • The layout has the following default fields:
        • Code (required) - A text field (that accepts a maximum of 20 characters)
        • Description - A text field (that accepts a maximum of 100 characters)
        • Width (required) - A number field
        • Height (required) - A number field
        • Labels per Sheet (required) - A drop-down menu with the following options: 1/sheet, 2/sheet, 4/sheet, 6/sheet, 10/sheet, 12/sheet, and 30/sheet options.
      • The layout has the standard 'Translation' tab.
  • The following new label types have been added to the 'Label Stock' look-up table: A3, A4, AstroNova 1, AstroNova 2, Avery 5160, Avery 5163/60505, Avery 5164, Avery 5168, Avery 5526/60513, Avery 60501, Avery 60502, Avery 60503, Avery 60504, Avery 60506 Avery 60508/60512, Custom 1-5, Dymo 1951462, Dymo 30256, and ULINE S-6743.
    • To the 'Label Stock' (ML-003607) layout, a 'Default Stock' field has been added.
      • The new field is a drop-down menu with the following options: 1/sheet, 2/sheet, 4/sheet, 6/sheet, 10/sheet, 12/sheet, and 30/sheet.

    • EHS Managers can now create custom label templates that display all of the OSHA-required fields and hazard warnings for a product.
