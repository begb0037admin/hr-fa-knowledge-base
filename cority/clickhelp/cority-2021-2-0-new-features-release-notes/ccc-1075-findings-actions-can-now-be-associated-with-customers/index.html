CCC-1075: 'Findings & Actions' can now be associated with customers

  • A 'Findings & Actions' tab (sublist) has been added to the default Customer layout (ML-003448).
  • This new tab has the same functionality as the 'Findings and Actions' tab in Quality 'Audits' (ML-003189).
  • The tab has New, Save, Cancel, and Delete buttons and an Actions menu with the standard 'Findings & Actions' options.
  • The tab has two default views:
    • Findings & Actions for This Customer, which has the following columns: Finding Date, Location, Finding Type, Finding Details, Risk [Description], Risk [Icon], Action Details, Due Date, Assigned To, and Completed Date.
    • Findings (w/Risk) & Actions for This Customer, which has the following columns: Finding Date, Finding Details, Finding Type, Probability, Severity, Risk [Icon], Action Details, Action Type, Assigned To, Due Date, and Completed Date.
  • New create, edit, delete, and clone security actions have been added for those list views.
  • The system will automatically generate 'Findings & Actions' for the Customer record from an answer (that is flagged to do so) on an associated questionnaire.
  • The source for any 'Findings & Actions' on the new tab is 'Quality Customer'.
  • The 'Findings & Actions' generated in association with a Customer record can be viewed, with proper security permissions, on the 'Findings & Actions' list in the Quality suite.

Impact to Existing User:

  • The user can now link 'Findings & Actions' to the Customer record, so that the level of product quality for that customer can be managed more easily.

Additional Configuration Considerations:

  • Beyond what is described above, no additional configuration is required.
