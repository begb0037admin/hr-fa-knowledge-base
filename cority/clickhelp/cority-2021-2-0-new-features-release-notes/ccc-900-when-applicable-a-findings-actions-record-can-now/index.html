CCC-900: When applicable, a Findings & Actions record can now provide a link to its current source

  • In the Safety, Environmental, and Quality suites, the new 'Current Source' field can now be added to custom 'Findings & Actions' layouts.
  • The field will provide a hyperlink to the current version of the source Risk Assessment, Task Hazard, or FMEA record. Note: If there is no active current source, the field will simply display the original source.

Impact to Existing Users:

  • From a Findings & Actions record, the action owner can now quickly and easily view, open, and analyze its current active source.

Additional Configuration Considerations:

  • Beyond what is described above, no additional configuration is required.
