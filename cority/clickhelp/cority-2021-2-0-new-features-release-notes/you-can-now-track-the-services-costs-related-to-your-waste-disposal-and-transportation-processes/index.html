CCC-823 You can now track the service costs related to your waste disposal and transportation services

  • A new 'Vendor Services' tab (sublist), with corresponding data table (DT_VendorService), has been added to the 'Vendors' look-up table layout (ML-000165).
  • The new tab has the following three views: All (default), Active, Inactive
  • The views have the following columns:
    • Vendor Service ID (Required) - a read-only text field that will accommodate up to 50 characters
    • Vendor (Required) - a read-only text field that is auto-populated with the vendor's name
    • Service (Required) - a text field that will accept up to 100 characters
    • Service Description - a text field that will accept up to 100 characters
    • Rate - a numeric field
    • Unit of Measure - a picklist to the 'Units of Measure' look-up table
    • Inactive - a check box
    • End Date - a date field
  • The views have the standard buttons and the Create/Clone View functionality.
  • When the user opens or creates a new record from the sublist, the new 'Vendor Service' layout (ML-003547) is used.
    • By default, the layout has the following fields:
      • Vendor - the vendor's name, auto-populated from the parent record
      • Service - a text field that will accept up to 100 characters
      • Service Description - a text field that will accept up to 100 characters
    • The following fields can be added to custom versions of the layout:
      • End Date - a date field
      • Inactive - a check box
      • Vendor Service ID - a read-only text field that will accept up to 50 characters
    • The values for the fields above can be populated/updated using the Import Utility.
    • All of the fields above are available for use in Query Builder and Report Writer.
    • The new layout has GDDLOFB (which is not populated from the parent 'Vendor' record) and 'Vendor Services Rates' subsections, New, Save, Cancel, and Delete buttons, and an Actions menu with the 'View Record History',' Add a New Rate Data Version', and 'Delete Current Data Version' options.
    • When User selects the 'Add a New Rate Data Version' action, the 'Add Vendor Service Rate Version' dialog box opens.
      • The dialog box has an 'Effective Date' field and CANCEL and OK buttons. The field is populated with the current date.
      • If the user clicks OK on the dialog box, a new 'Vendor Service Rate' record will be created.
      • 'Vendor Service Rate' records can be versioned based on the 'Effective Date' value.
    • The 'Vendor Services Rates' subsection (with corresponding new DT_VendorServiceRate data table) on the 'Vendor Service' layout  has the following columns:
      • Vendor Service (Required) - a text field that is auto-populated from the 'Vendor Service' record
      • Rate - a numeric field
      • Unit Of Measure - a picklist to the 'Units of Measure' look-up table
      • Effective Date (Required) - a date field
      • Inactive - a check box
    • When the user opens or creates a new record from the 'Vendor Service Rates' subsection, the new 'Vendor Service Rate' layout (ML-003595) is used.
    • The layout has the Create/Edit functionality, the New, Save, Cancel, and Delete buttons, and an Actions menu with the standard layout actions as well as the 'Add a New Rate Data Version' and 'Delete Current Data Version' actions.
    • By default, the layout has the following fields:
      • Rate - a numeric field
      • Unit Of Measure - a picklist to the 'Units of Measure' look-up table
      • Effective Date - a date field
    • The 'Inactive' check box field and a GDDLOFB subsection can be added to custom versions of the layout.
    • The values for the fields can be updated using the Import Utility.
    • The fields are available for use in Query Builder and Report Writer.
    • 'Vendor Service Rate' records can be versioned based on the 'Effective Date' value.
  • When a 'Vendor Service Rate' record is added/saved with a 'Service' and 'Effective Date' combination that match those on another 'Vendor Service Rate' record, an informative error message is displayed.
  • The following new field has been added to custom versions of the 'Vendors' look-up table layout (ML-000165):
    • Waste Handler - a check box
  • The field value can be populated/updated using the Import Utility.
  • The field is available for use in Query Builder and Report Writer.
  • The equivalent column can be added to custom 'Vendors' look-up table list views.
  • A new 'Transportation Service Cost' tab (sublist) can now be added to custom versions of the 'Waste Manifest' layout  (ML-000229).
  • The sublist has a default 'Transportation Service Costs' list view.
  • The list view has the following columns:
    • Vendor
    • Service
    • Service Description
    • Rate
    • Rate Unit of Measure
    • Quantity
    • Effective Date
  • All are auto-populated from the 'Vendor Services Rate' record. Note: Only the Quantity value is editable on the list view.
  • The list view has the Edit and Delete buttons, an Actions menu with the 'Export List to Excel' and 'Show Record History' options, the multi-add feature and the Create/Clone View functionality.
  • When the user clicks the Multi-Add button, the 'Vendor Services' dialog box will open.
    • The dialog box has the following list views: All Services for this Vendor (default) and Active Services.
      • The views are filtered to active 'Vendor Service' records for which the Vendor Service Rate 'Effective Date' =< today's date.
      • The views are also filtered to only show the services provided by the active (based on effective date of the corresponding Vendor Service record) vendors selected as the Waste Transporter 1, Waste Transporter 2, Waste Transporter 3, or Waste Transporter 4 on the main form.
    • The list views have the Clone/Edit View functionality and the multi-add feature.
    • To use the multi-add feature, the user must first select a value for at least one of the Waste Transporter fields on the main layout.
  • The following new fields can be added to custom versions of the 'Waste Manifest' layout (ML-000229):
    • Transport Service Cost - a calculated currency field
      • This field should be populated with the summed totals of all 'Transportation Service Cost' records from the 'Transportation Service Costs' sublist (the aggregated total of the quantities multiplied by the rates).
    • Total Disposal Service Cost - a calculated currency field
      • This field should be populated with the summed totals of all 'Disposal Service Cost' values from all related Waste records.
  • The values for these fields cannot be updated using Import Utility.
  • These fields are available for use in Query Builder and Report Writer.
  • The corresponding columns can be added to custom versions of the 'Waste Manifest' list view.
  • The new 'Disposal Service Cost' tab (sublist) can be added to custom versions of the 'Waste' and 'Waste Manifest' layouts.
  • The new 'Transportation Service Cost' tab (sublist) can be added to custom versions of the 'Waste Manifest' layout.
  • Both sublists are supported by / correspond to the new 'Vendor Service Cost' data table.
  • The new table has the following fields:
    • Vendor Service Cost ID (Required) - an auto-populated, read-only field
    • Vendor Service Rate (Required) - a read-only field auto-populated from the 'Vendor Service Rates' look-up table
    • Quantity (Required) - a number field
    • Disposal Service - a check box field that is not available on the layout or in the Import Utility and is auto-populated to selected when the record is saved to the 'Waste' record's 'Disposal Service' sublist
    • Transportation Service - a check box field that is not available on the layout or in the Import Utility and is auto-populated to selected when the record is saved to the 'Waste Manifest' record's 'Transportation Service Cost' sublist
  • A new 'Vendor Service Cost' (ML-003548) layout is provided.
    • The layout has the Save and Delete buttons, an Actions menu with the 'View Record History' and 'Export List to Excel' actions, and the Create/Clone functionality.
    • The layout has the following fields:
      • Vendor Service Rate - a picklist to the 'Vendor Service Rates' look-up table
      • Quantity - a number field
  • All of the fields above, unless otherwise stated, can be populated updated using the Import Utility and are available for use in Query Builder and Report Writer.
  • The new 'Disposal Service Cost' sublist can now be added to custom versions of the 'Waste' layout (ML-000166).
  • The new sublist has the default 'Disposal Service Costs' list view.
  • The list view has the following columns:
    • Vendor
    • Service
    • Service Description
    • Rate
    • Rate Unit of Measure
    • Quantity
    • Effective Date
  • Only the Quantity value is editable on the list view.
  • The list view has the Edit and Delete buttons, an Actions menu with the 'Export List to Excel' and 'Show Record History' actions, and the Create/Clone Views functionality.
  • The list view also has the multi-add feature for adding any active 'Waste Handler' vendor services that have a vendor service rate with an Effective Date = < today's date. - To use the multi-add functionality, the user must first select a value for the 'Waste Hauler' field on the main 'Waste' layout.
  • The following new fields can now be added to custom versions of the 'Waste' layout (ML-000166, and ML-000393 for myCority):
    • Waste Handler - a picklist to the 'Vendors' look-up table, filtered to those vendors with a vendor type of 'Waste Handler'
    • Disposal Service Cost - a read-only calculated currency field populated with the summed totals of all 'Disposal Service Cost' records from the "Disposal Service Cost" sublist (the aggregated total of the quantities multiplied by the rates)
      • For example: $35/hour x 2 hours (for Truck loading) + $20/hour x 1 hour (for container inspection) = $90 in the 'Disposal Service Cost' field
  • The 'Waste Handler' field value can be populated/updated using the Import Utility, both fields are available for use in Query builder and Report Writer, and both fields can be added as columns to applicable list views.

Impact to Existing Users:

  • The ability to track the service costs related to waste disposal and transportation processes will enable users to report on and audit the associated spending.

Additional Configuration Considerations:

  • Beyond what is described above, no additional configuration is required.
  • For information on working in Waste Management or creating/configuring list views or layouts, see the Cority User Guide.
