CCC-347: The Environmental suite now has a Site Selector

  • The Site Selector is located at the top of the Environmental menu.
  • The Site Selector provides a tree picker, from which you can select a GDDLOFB node.
  • Records in the Environmental modules will be filtered by the site selected.

Impact to Existing Users:

  • You can now filter Environmental records by site (or location).

Additional Configuration Considerations:

  • No new configuration is required.
