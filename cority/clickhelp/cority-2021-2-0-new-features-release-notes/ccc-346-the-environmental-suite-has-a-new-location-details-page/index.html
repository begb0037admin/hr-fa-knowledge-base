CCC-346: The Environmental suite has a new 'Location Details' page

  • The new page has the same functionality here as it does in the Emissions Inventory suite.
  • A link to the 'Location Details' page is provided in the left navigation menu of the Environmental suite, under the Site Selector.
  • When a location is specified using the Site Selector:
    • The 'Location Details' link is active.
    • Its text is blue. Note: This is only the case in the Clarity theme and if the user setting 'Render Updated Menu in Clarity' is selected.
    • The link takes the user to the 'Location Details' page for the location specified in the Site Selector.
  • When a location is (null) not specified in the Site Selector:
    • The 'Location Details' link remains inactive.
  • If the system setting 'Default Location' is set, then the 'Location Details' link will be active and take the user to the 'Location Details' page for the default location.
  • The 'Location Details' page has the new Environmental 'Location Details' layout (ML-003546).
  • The layout has the following tabs by default:
    • Assets (Asset Management)
    • Permits, Policies & Procedures
    • Compliance Obligations
    • Regulations
    • Inspections
  • The following tabs can be added to custom versions of the layout:
    • Applicability Assessment
    • Chemical Inventory
    • Documents
    • Environmental Activities
    • Environmental Aspects
    • Environmental Objectives
    • Risk Registry
    • Stakeholders
    • Audits
    • Events (Event Management)
    • Incidents (Incident Management)
    • Sample Data
    • Questionnaires
    • Waste Container (Waste Container Management)
    • Waste Management
    • Waste Shipment
    • Change Request
    • Communications
    • Corrective Actions
    • Environmental Action Plan
  • The tabs (sublists) of the 'Location Details' layout are filtered by the location selected.
  • The default list view for each tab is 'All Active'. 'All' and 'All Inactive' list views are also provided.
  • The layout has the Save and Cancel buttons and an Actions menu with the 'Save Layout' and 'Edit Layout' options.
  • To view the 'Location Details' main form, the user's role must be granted the 'Environmental Compliance Management' security module. To edit the form, the user's role must be granted access to the appropriate look-up tables or the user must have the Admin role.
  • To edit records on any of the layout's tabs, the user's role must be granted access to the corresponding security module(s).

Impact to Existing Users:

  • An Environmental Manager can now see the details of specific locations, so he or she can more easily confirm record accuracy and manage assets/compliance at specific locations.

Additional Configuration Considerations:

  • Beyond what is described above, no additional configuration is required.
  • For information on roles and role security, see the Cority User Guide.
