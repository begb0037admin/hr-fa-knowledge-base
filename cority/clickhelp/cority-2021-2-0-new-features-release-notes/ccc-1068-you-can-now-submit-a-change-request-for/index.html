CCC-1068: You can now submit a change request for a chemical

  • To support this, the 'Change Request' list now provides the 'Environmental Chemical Request' option.
    • When you select the new option, you will be directed to the 'Environmental Management of Change - Chemical Request' (ML-003571) layout.
    • The layout has the New, Save, Cancel, and Delete buttons, and an Actions menu with the Print Form, Save Layout, Show Record History, New Action, Submit, Approve, and Reject actions.
    • The layout has a 'Chemical Request Details' subsection with the following fields:
      • Request ID - A read-only field that displays a unique, system-generated number
      • MOC Type (required) - A look-up selector, from which you can select one of the entries in the 'Environmental Management of Change Types' look-up table
      • Summary of Change (required - A text field (that accepts a maximum of 100 characters)
      • Technical Basis (required) - A text field (that accepts a maximum of 8000 characters)
      • Chemical/Product Name - A look-up selector, from which you can select one of the entries in the 'Chemical Products' look-up table
      • Requested By (required) - A look-up selector, from which you can select one of the entries in the Employees list
      • Start Date (required) - A date field
      • Request Status (required) - A read-only field that will display the current workflow status
    • The layout has an 'Applicable Location' subsection with the standard location fields, as well as the following tabs (sublists): Applicable Locations, Approval Status, Questionnaires, Documents, and Related Records.
  • You can now copy an existing change request.
    • To support this, the 'Management of Change' list views each have a new 'Copy Request(s)' action.
    • When you select one of more records from the list view and then select the new action, a copy of the record(s) will be created. On a copied record:
      • The 'Start Date' will display today's date
      • The 'Request Status' will display the first workflow step.
      • The GDDLOFB fields will be blank (null).
  • You can now add a 'Chemical Standards' tab to custom versions of the Chemical Products (ML-000831 and ML-000706), Product (Split Screen) (ML-000006), and myCority Chemical Products (ML-003504) layouts.
    • The new tab provides a default view with the following columns: Source, Type, Effective Date, End Date, Standard, and Standard Units.
    • The tab inline-add functionality, the New, Edit, and Delete buttons, and an Actions menu with the Export List to Excel and Show Record History options.
    • When you open a record from the tab, it will open in the pinned 'Agent Standard' layout.

Impact to Existing Users:

  • Chemical Managers can now submit chemical requests, associate those requests with one or more storage locations, and record the agent standard information for a chemical.

Additional Configuration Considerations:

  • No additional configuration is required.
