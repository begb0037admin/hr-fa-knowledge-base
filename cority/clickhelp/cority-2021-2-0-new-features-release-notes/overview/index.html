2021.2.0 New Features Release Notes

At Cority we are committed to continually enhancing our product. The 2021.2.0 release contains new and improved functionality in several areas—including new features for configuring the platform, streamlined clinical operations, updates to the RESTful API, and enhancements to geo-location capabilities, chemical management, applicability assessments, and to waste field operations and cost optimization.

Tips:

  • We use the number(s) assigned to each enhancement to identify them internally. If you have a question about a feature, its number(s) will help the Cority technical contact quickly access all of the relevant information.
  • For any items that require configuration, it is described in the context and flow of the release note body.
  • Below each item, we have categorized it as either:
    • Opt-in - The feature is available, but its use is optional.
    • Mandatory - An element of the feature is likely to affect one or more of your current workflows or changes the way data is grouped and/or displayed.
    • N/A - The feature cannot easily be categorized as either opt-in or mandatory.
  • Due to the large feature set and extensive configurability of the Cority platform and its modules, the Cority New Features Release Notes document is published the week prior to the Test environment release. The myCority Release Notes document is published on or shortly after the Test release.
  • Until Cority is released to Production environments, please check this document for updates.
  • For previous versions of the Release Notes, see the Documents section of the User Community.
