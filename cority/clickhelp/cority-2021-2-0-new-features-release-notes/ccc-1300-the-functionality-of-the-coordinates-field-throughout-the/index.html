CCC-1300: The functionality of the Coordinates field (throughout the platform) has been enhanced

  • Now when the user clicks the Pin icon next to the Coordinates field, a map window will open.
  • On the map, if the Coordinates field is populated, the coordinates will be displayed under 'Current Coordinates' and marked with a red pin.
  • If the Coordinates field is empty, 'Current Coordinates' will reflect the user's current location, which will be marked on the map with a red pin.
  • The map provides a street view, the ability to zoom in and out, Update and Cancel buttons, and an 'X' icon for closing it.
  • If user clicks/taps the map:
    • The pin will move to the clicked location.
    • 'Current Coordinates' will update accordingly.
  • Clicking the Compass icon will populate 'Current Coordinates' with the user's current location.
  • When the user clicks Update, the map will close and the Coordinates field will update to reflect any changes that were made on the map.
  • Note: Clicking the 'X' icon will close the map, but will not update the Coordinates field values.

Impact to Existing Users:

  • Users can now visualize coordinates on a map, so they can easily adjust coordinates values on applicable records.

Additional Configuration Considerations:

  • Beyond what is described above, no additional configuration is required.
