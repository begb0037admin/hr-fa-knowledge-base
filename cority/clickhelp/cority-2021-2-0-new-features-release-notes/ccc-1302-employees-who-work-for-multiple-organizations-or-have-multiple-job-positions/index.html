CCC-1302: Our Health Cloud now supports employees who work for multiple organizations and/or have multiple
job positions

Multiple Organizations/Employers

The My Favorites menu has a new Global Passport module

  • The module was created primarily for clients that provide health services to other organizations, therefore have one or more employees who work for more than one organization and have a unique employee number with each. This means those employees can each be identified by more than one employee number within the GX2 platform.
  • For each employee in that situation, the new module will create and provide a single, rolled-up unique Global Passport ID that links all of his or her employee numbers. The Global Passport ID allows the medical team to search for and view the holistic, comprehensive set of medical records for such an employee, even though the employee works for multiple organizations.
  • The Global Passport module provides a centralized location for storing and managing an employee's employer information.
    • For existing users, the module is not available in the My Favorites menu by default. It must be made available to the user through Menu Configuration.
    • To use the new module, a user's role must be granted the Global Passport security module.
    • The new module's main list has a 'Global Passports' view with the 'Show Record History' and 'Export List to Excel' actions, and the following columns: Global Passport ID, Full Name, National Security ID, and Date of Birth.
    • The module's main layout (ML-003567) has an Actions menu with the Save Layout, Show Record History, and Edit Layout options.
    • The layout has the following default fields: Global Passport ID, First Name, Last Name, National Security ID, Date of Birth, Medical Insurance Number, and Gender. Each field will display the corresponding value from the employee's 'Demographics' record, in read-only format.
    • The layout has a 'Linked Employees' tab that will display a list of related Employee records.
    • The layout has a 'Job Positions' tab that provides the same fields and functionality as its equivalent in the 'Demographics' module.
  • A 'Global Passport ID' field/column can now be added to custom versions of most layouts and list views within the Health Cloud, as well as to custom Employee Banners. The field will display the 'Global Passport ID' value from the employee's 'Demographics' record, in read-only format.
  • There is a new 'Conditions to Match Employees with Global Passport Record' global system setting. That new setting is associated with the 'General' module and controls the criteria that will be used to identify a matching employee when you create a new 'Global Passport' record.
    • The setting provides a drop-down menu with the following options:
      • Blank (default)
      • National Security ID
      • National Security ID, Date of Birth
      • National Security ID, Date of Birth, First Name and Last Name
      • Medical Insurance Number
      • Medical Insurance Number, Date of Birth
      • Medical Insurance Number, Date of Birth, Fist Name and Last Name
  • A new business rule method action (BRA-100498) has been added. The action enables administrators to control when and how often Cority will create a new Global Passport record for an employee based on the value of the 'Conditions to Match Employee with Global Passport Record' system setting.

Multiple Job Positions

  • To better support clients that have employees who work in more than one job position, we have made several enhancements to the existing job position functionality on the 'Demographics' layout.
  • In the 'Demographics' module, the 'Employees' list has three new views: Active Multi-job Employees, Inactive Multi-job Employees, and All Multi-Job Employees.
    • Each new view has the following additional columns: Additional Jobs, Position Start Date, and Position End Date.
  • The multi-job views allow the user to quickly identify multi-job employees and each of their job positions.  Along with the job positions, the GDDLOFB stored with each position will also be transferred to any medical record created for the employee.
    • For example, an employee works in both the cleaning and packaging departments. The cleaning job is supplied by the HR feed and is considered by Cority to be the main job position. The packaging job is added separately to the Job Positions sublist in Demographics. The GDDLOFB of the two jobs is different because each is in a different building. Should the employee need medical care, any Clinic Visit record created for the employee will now reflect the accurate GDDLOFB based on the job position specified.
  • The new multi-job views are available in the following modules (and on Employee picklists within those modules):
    • Clinic Visit
    • Case
    • Audiometric
    • Clinical Testing
    • PFT
    • Medical Questionnaire
    • Immunization
    • Schedule Entry
    • Medical Correspondence
  • In an upcoming release, we will provide the same multi-job support for the other Health Cloud modules.
  • To be able to visualize the job position that was selected during record creation, the new 'Additional Jobs' field/column can be added to custom versions of the following layouts and equivalent list views:
    • Audiometric Test
    • Case
    • Clinic Visit
    • Clinical Test
    • Employee Related Questionnaire: Medical
    • Immunization
    • Pulmonary Function Test
    • Schedule Entry
  • For existing records, when the field is present on a layout, it will display the main job position from the employee's 'Demographics' record.
    • The new field is a look-up selector. When you click the Magnifying Glass icon to the right of the field, the 'Employee Job Position' dialog box will open. The dialog box will display each of the job positions saved to the employee's 'Demographics' record.
      • If you change the 'Additional Jobs' value on a record of any of the types listed above, the record's GDDLOFB values will be updated accordingly.

GDDLOFB in Health Cloud Look-up Tables

  • To allow for the additional filtering of certain look-up tables in the Health Cloud, the option to add a GDDLOFB subsection is now provided for the layouts that correspond to the look-up tables listed in this spreadsheet provided on the User Community.

Impact to Existing Users:

  • This new functionality will help you maintain accurate employee records for employees who work for multiple organizations and/or have multiple job positions.

Additional Configuration Considerations:

  • Beyond what is described above, no additional configuration is required.
