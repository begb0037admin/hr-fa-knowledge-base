CCC-2062: The functionality of the 'Related Object' icon has been enhanced

  • In the layout editor, for applicable fields, there is now a 'Display Icon For Linking To Related Record' check box.
  • By default, the check box is not selected.
  • If for a field the check box is selected, on the layout the 'Related Object' icon will be displayed next to the field.
    • When the 'Related Object' icon is displayed, clicking the icon will take the user to the corresponding table, if the user's role is granted the required display action. For example: On a 'Clinic Visit' layout, if the user clicks the "Related Object' icon next to the 'Clinic Visit Reason' field and the user's role has access to the clinicvisitreason.display security action, the 'Clinic Visit Reason' look-up selector will open listing the entries in the 'Clinic Visit Reason' look-up table.
    • Note: The 'Related Record' icon is no longer functional for subqueries in business rules.
  • The value of the 'Display Icon For Linking To Related Record' check box for a particular field in the layout editor can be imported using the 'Import Layout Configuration' list action and exported using the 'Export Layout Configuration' list action.
  • Also, that new check box is supported by the 'Migrate Config' feature set.

Impact to Existing Users:

  • For each applicable field, the 'Related Object' icon is now unavailable by default. An Administrator can turn it on to allow users access to the underlying table.

Additional Configuration Considerations:

  • Beyond what is described above, no additional configuration is required.
