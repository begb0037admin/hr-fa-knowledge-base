CCC-281, 1355, and 1419: The Medical Records report has been enhanced

  • In the report, there are new 'Travel', 'Case Notes', and 'Case Letters' check boxes.
  • By default, the new check boxes are not selected.
  • The user can select any or all of the new check boxes in conjunction with one or more of the existing check boxes (when 'Select All' is not used).
  • 'Select All' will of course include the three new check boxes.
  • Note: As has always been the case, for 'Print Preview' only one check box can be selected.
  • When the 'Travel' check box is selected, a report named 'Travel Clearance History' will be generated that:
    • Is included in the Medical Records report's zip file.
    • Displays the employee's name and number in the header on each page.
    • Uses a date filter based on the value in the 'Date Requested' field.
    • Has the following columns:
      • Date Requested
      • Practitioner
      • Health Center
      • Travel Kit
      • Clearance Type
      • Clearance Status
      • Clearance Date
      • Destination
      • Initial Date
      • Final Date
  • The data is sorted on 'Date Requested' first, then on 'Destination' (alphabetically).
  • When the 'Case Notes' check box is selected, a report named 'Case Notes' will be generated that:
    • Is included in the Medical Records report's zip file.
    • Displays the employee's name and number in the header on each page.
    • Includes all Case notes related to the selected employee.
    • Uses a date filter based on the value in the 'Note Date' field.
    • Has the following columns:
      • Note Date
      • Note Time
      • Case Number
      • Practitioner
      • Activity
      • Outcome
      • Notes
  • If a Case note is lined out, and the report has 'Include Line-out selected', the note appears in the report but it is lined-out/struck-through.
  • The functionality of the existing 'Notes From All Modules' option and report remain unchanged, but they have been renamed 'Notes from All Medical Modules'.
  • When the 'Case Letters' check box is selected, a report named 'Case Letters' will be generated that:
    • Is included in the Medical Records report's zip file.
    • Displays the employee's name and number in the header on each page.
    • Includes all Case letters related to the selected employee.
    • Uses a date filter based on the value in the 'Created Date' field.
    • Has output formatted the same as that of the output for the existing 'Letters' check box / report.
  • The existing 'Letters' check box and report have been renamed 'Medical Letters'.
  • For 'Case Notes' and 'Case Letters':
    • Case Type security will be applied, therefore when the 'Apply case type security on canned reports' system setting is selected, the report will omit any data for cases restricted from the user.
    • The functionality of the 'Include Private Data' check box remains unchanged. For example: If a 'Case Activity Note' record has Private Data = True, the record will not appear in the report unless the 'Include Private Data' check box is selected in the Medical Records report.
  • This new functionality also applies if the user runs the Medical Records report using myCority.

Impact to Existing Users:

  • A medical user can now run the Medical Records report for Travel records in order to see the complete history of an employee's travel clearances.
  • To help ensure compliance when there is a need to provide the employee's entire medical history, a medical user can now:
    • Configure the Medical Records report to extract all Case notes associated with an employee.
    • Configure the Medical Records report to extract all Case records (including Case letters) associated with an employee.

Additional Configuration Considerations:

  • Beyond what is described above, not additional configuration is required.
