CCC-409 and 726

Applicability Assessments

2020.2.0

For audit questionnaires that have been auto-created from ENHESA or RegScan applicability assessments, the 'Enable User to Attach Documents' field value now applies. This means that for questions on such questionnaires, when the 'Enable User to Attach Documents' field value is set to Optional, the user (compliance auditor) who is assigned the questionnaire can attach a document to the question response.

 

2021.2.0

CCC-457

Business Rules, Workflow

N/A

There is a new merge field value called 'Current Workflow Step Owners'. It is available for use in business rule email actions.

When a record is in a workflow and a business rule that uses the email action and the 'Current Workflow Step Owners' merge field value is applied to a particular step, at that step an email notifying its owners will be sent. The owners' email address(es) will be in the To or CC field of the email, depending on where 'Current Workflow Step Owners' is used.

Note: Only the email addresses of active employees for which the current date is between their start and end dates will be included.

CCC-1299

Inventory, Vaccines, Medication

N/A

The Inventory module has the following two new standard views:

  • The 'All Inactive Vaccine Inventory' view lists any inventory record for which the vaccine is marked inactive.
  • The 'All Active Vaccine Inventory' view lists any inventory record for which the vaccine is not marked inactive.

The Inventory module has the following two new standard views:

  • The 'All Inactive Medication Inventory' view lists any inventory record for which the medication is marked inactive.
  • The 'All Active Medication Inventory' view lists any inventory record for which the medication is not marked inactive.

The views are granted by default to those with a role that has the appropriate permissions. The views can be prohibited.

CCC-411

Quality, Corrective Actions

2020.2.1

In MAEN settings, under Actions, there is now a 'Quality Actions' tab. This tab enables administrators to control and configure the email notifications for Quality actions. This also enables administrators to ensure that when MAEN notifications for non-Quality actions are enabled, Quality suite users are not receiving two sets of MAEN notifications. That was a potential issue prior to this change.

CCC-377

Quality, Corrective Actions

N/A

For Quality corrective actions, a business rule (BR) can now be configured to email the assignee a standalone link to the corrective action. A business rule action (BRA) is provided for this purpose, and is inactive by default. To set this up, for each finding type / recipient combination:

  1. Copy BRA-00022r.
  2. Set Quality = True.
  3. Rename the BRA.
  4. Configure the link for the quality actions.
  5. Save the BRA.
  6. Set up a BR to use the action.

CCC-1459

Translations

2020.2.2

In Administrator > Translations > Phrase Translations, when the 'Reset Phrases' action is executed, a message is now displayed conveying that the process has been added to the Business Rule Action Queue and is scheduled. The user can then open the queue to view the status of the process. Once the process has finished, the new translated phrase(s) will appear in the 'Phrase Translations' module. Also, the performance of the 'Reset Phrases' process has been improved, and is now far less likely to timeout.
