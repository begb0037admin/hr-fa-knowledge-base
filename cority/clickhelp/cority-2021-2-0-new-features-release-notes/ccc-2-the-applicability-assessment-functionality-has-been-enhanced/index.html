CCC-2: The applicability assessment functionality has been enhanced

  • The new global 'Regulatory Content Type' system setting enables your administrator to specify whether imported regulatory content is stored as Environmental regulations or Safety legal requirements.
    • The setting's default option is Environmental.
    • The setting is categorized under the Regulations/Legal Requirements module.
  • On the 'Regulations' list view, when you select the 'Refresh Requirements' action:
    • Any applicability assessments that have been completed in ENHESA or RegScan for your location since the last refresh will be inserted in the 'Applicability Assessment' module.
      • If an applicability assessment results in an audit, a record of that audit, as well as any related questionnaires, will be automatically inserted in the 'Audits' module.
      • On a related questionnaire, a user will be able to attach a document to each of the response questions.
      • For ENHESA regulations, on the 'Questionnaires' tab of the audit, the 'Description' column now displays the regulation name instead of the regulation ID. Note: When the regulation name has more than 100 characters, the name will be concatenated. If you want, you can edit the name, adding the additional characters.
      • For 'Yes or No' type questions, a user will be able to select 'Not Applicable' as the response. On the 'Question' (ML-000470) look-up table layout, when the 'Question Type' is 'Yes or No', the 'Valid Choices' tab now has a 'Not Applicable' entry.  
      • If a questionnaire response results in the creation of a 'Findings and Actions' record, any comments for the response will now automatically be added in the new record's 'Finding Details' field.  
      • For ENHESA, if there is a regulation URL associated with a questionnaire response, it will display in the 'Display Legal Requirement as Popup Message' field on the 'Questionnaire Question' (ML-000729) layout. When the popup message displays to the user, the URL will be a clickable link.
    • Any new or updated regulations will be inserted in the 'Regulations' module automatically.
    • For ENHESA regulations, any new or updated applicability topics will be inserted in the new 'Applicability Topics' look-up table automatically.
  • The new 'Applicability Topics' look-up table is categorized under the 'Applicability Assessments' module.
    • The look-up table has a standard view with the following columns: Code, Title, and Description.
    • The view has inline-add functionality, the New, Edit, and Delete buttons, and an Actions menu with the 'Export List to Excel' and 'Show Record History' options.

  • The new look-up table provides an 'Applicability Topic' (ML-003503) layout.
    • The layout has the New, Save, Delete, and Cancel buttons, and an Actions menu with the Save Layout, Show Record History, and Edit Layout options.
    • The layout has the standard suite check boxes, as well as the following default fields:
      • Code (required) - A text field (that accepts a maximum of 20 characters)
      • Title (required) - A text field (that accepts a maximum of 100 characters)
      • Description - A text field (that accepts a maximum of 3000 characters)
      • Level - A text field (that accepts a maximum of 10 characters)
      • Inactive - A check box
  • A 'Topics' tab can now be added to custom versions of the following layouts:
    • ENHESA Regulations (ML-000061)
    • ENHESA Safety Legal Requirements (ML-000062)
    • Environmental Legal Requirements (Split Screen) (ML-000009)
    • RegScan Environmental Regulations (ML-000173)
    • RegScan Safety Legal Requirements (ML-000174)
    • Regulations (ML-001316)
    • Safety Legal Requirements (ML-001263)
  • The new tab will list all of the applicability topics for the respective suite.
  • The tab provides a standard view with the 'Code' and 'Description' columns.
  • The tab has the Delete button, multi-add feature, and an Actions menu with the Export List to Excel and Show Record History options.
  • When you open a record from the tab, it will open in its pinned layout.
  • Values for each of the new fields (columns) listed above can be populated/updated using the Import Utility, and the fields are available for use in Query Builder / Report Writer.
  • Also, for ENHESA, when the 'Update Applicability Data' action in the Publications look-up table is executed, the corresponding regulatory audit and applicability assessment questionnaires will be translated into the appropriate language for each of the entries in the 'Country Regional Codes' look-up table that have the ENHESA check box selected.
    • Note: This will also add the required translation entries to the 'Translations' tab of each applicable 'Single Question' record.

Impact to Existing Users:

  • This functionality improves the overall user experience for Environmental Managers working with applicability assessments (ENHESA or RegScan) and related regulations.

Additional Configuration Considerations:

  • Beyond what is described above, no additional configuration is required.
