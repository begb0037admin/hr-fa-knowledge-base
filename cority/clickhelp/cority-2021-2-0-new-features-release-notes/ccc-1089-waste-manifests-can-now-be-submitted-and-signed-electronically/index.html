CCC- 1089: Waste Manifests can now be submitted and signed electronically

  • To support this, new 'Submit Manifest Electronically' and 'Sign Manifest Electronically' actions have been added to the default 'Waste Manifest' layouts (ML-000229 and ML-003510).
  • Each of the two new actions must be granted manually to the user's role.
  • Note: To use either of the new actions, the associated generator(s) and transporter(s) must first be set up in the Environmental Protection Agency (EPA) system, and their codes must match the equivalent values (for Firm Code and Vendor) in the Cority system.
  • There are three new e-Manifest User settings:
    • e-Manifest API ID - a text field that accepts up to 50 characters
    • e-Manifest API Key - a text field that accepts up to 50 characters
    • e-Manifest API URL - a text field that accepts up to 100 characters
  • All are empty by default and categorized under the 'Waste Shipment' module.
  • When the user selects either of the two new actions, the values provided for the three new system settings are used.
  • When the user selects the new 'Submit Manifest Electronically' action:
    • If the one or more of the e-Manifest system setting values are empty or invalid, an explanatory error message is provided.
    • If the 'Manifest Number' value is not null, an explanatory error message is provided.
    • If the 'Manifest Number' value is null, the e-Manifest system setting values are valid, and all other validations (see below) pass, the 'Manifest Validation' pop-up will open and provide the following message: The EPA IDs for all generators, transporters, and TSD facilities are being validated with the e-Manifest system.
    • If the associated manifest EPA IDs do not pass validation or the user does not have the required permissions for all associated generators, transporters, and/or TSD facilities, the 'Validation Errors' pop-up will open and provide the following message: Manifest not submitted to e-Manifest System. Check error messages below.
      • All validation errors will be written to the DT_emanifestlog table.
    • When there is an error, you will be notified that the validation failed. Otherwise, you will be notified that the new manifest uploaded successfully or the existing manifest updated successfully.
  • Note: When a manifest is submitted electronically, and a related Waste record's 'Waste Stream' has a value set for 'PCB Type', the 'PCB Weight' and 'PCB Removal' field values will be submitted with the manifest.
  • When a new manifest is submitted successfully or an existing manifest updated successfully, you will be provided with a "Click here" link for signing it electronically.
  • When clicking the link for signing, or when clicking the new 'Sign Manifest Electronically' action (for signing an existing waste manifest) on the 'Waste Manifest' layout:
    • If the manifest has already been signed, a message will inform the user that it cannot be signed again.
    • If one or more of the e-Manifest system setting values are empty or invalid, an explanatory error message will be provided.
    • If the associated manifest EPA IDs do not pass validation, a 'Validation Errors' pop-up will appear and provide the following message: Manifest not able to be electronically signed in e-Manifest System. Check error messages below.
    • If the manifest has not been signed and all validations pass, then a separate tab will open to enable the user to sign the manifest.
    • The 'Sign Manifest Electronically' action will be disabled if the manifest has not been submitted electronically or has just been submitted electronically and was signed then.
  • The following two new fields can now be added to the default 'Waste Manifest' layouts (ML-000229 and ML-003510):
    • e-Manifest Submitted (Read-only) - an auto-populated check box
    • e-Manifest Signed (Read-only) - an auto-populated check box
  • The fields cannot be updated using import utility.
  • The fields are available for use in Report Writer and Query Builder.
  • A new 'e-Manifest Log' has been added to the Waste Management module.
    • The log's default list view has the following columns:
      • User Name (Required) - the name of the user who executed the 'Submit Manifest Electronically' action (a concatenation of the first name and last name from the corresponding User record)
      • Timestamp (Required) - the date and time the e-Manifest transaction was executed
      • e-Manifest API ID (Required) - the API ID of user who executed the e-Manifest transaction
      • URI (Required) - the API URI that was called for the attempted process (up to 200 characters)
      • Payload - the transaction information sent to the e-Manifest system (up to 8000 characters)
      • Response - the transaction information sent back from the e-Manifest system (up to 8000 characters)
      • Validation Message - the message indicating validation of the e-Manifest transaction
      • e-Manifest ID - the e-Manifest tracking number (up to 50 characters)
  • The values for these fields cannot be updated using the Import Utility.
  • The fields are available for reporting use only, therefore only in Query Builder and Report Writer.
  • The following new field, for e-Manifest mapping and for recording additional information about the waste profile for e-Manifest use, can now be added to custom versions of the 'Waste Profile' look-up table layout (ML-003326):
    • Waste Determination - a picklist to the 'Agent Hazards' look-up table
      • The 'Waste Determinations' picklist has the following views: All, All Active (default), All Inactive.
      • The picklist displays only the 'Agent Hazard' records that have the 'Waste' check box selected.
      • The picklist views have the New button, the Create/Clone View functionality, and Code and Description columns.
  • The field's value can be updated using Import Utility.
  • The field is available for use in Report Writer and Query Builder, and can be added as a column to custom 'Waste Profile' list views.
  • The following new fields, for e-Manifest mapping and for recording additional info about the waste record for e-Manifest use, can be added to custom versions of the Waste layout (ML-000166, and ML-000393 for myCority):
    • PCB Weight - a text field
    • PCB Weight UOM - a picklist to the 'Units of Measure' look-up table
      • The 'Units of Measure' picklist has the following views: All, All Active, All Inactive, All Environmental Units (default).
      • The picklist displays only the 'Units of Measure' records that have the 'Environmental' check box selected.
      • The picklist views have the New button, the Create/Clone View functionality, and Code and Description columns.
    • PCB Removal Date - a picklist to the 'Removal Dates' records
  • The values of the fields above can be updated using the Import Utility.
  • The fields are available for use in Report Writer and Query Builder, and each can be added as a column to custom 'Waste' list views.

Impact to Existing Users:

  • Waste Managers can now submit and sign waste manifests electronically through Cority, which will help them comply with EPA standards.
  • An e-Manifest log table, that records API interaction with the EPA e-Manifest system, is now provided.
  • This simplifies submitting and tracking the manifest for each hazardous waste shipment.

Additional Configuration Considerations:

  • Beyond what is described above, no additional configuration is required.
  • For information on working with Waste Management or security roles and permissions, see the Cority User Guide.
