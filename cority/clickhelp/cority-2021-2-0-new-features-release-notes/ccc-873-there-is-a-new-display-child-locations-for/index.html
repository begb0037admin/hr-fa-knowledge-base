CCC-873: There is a new 'Display Child Locations for Location Details Landing Page' system setting

  • In System Settings, it is categorized under the 'Environmental' module.
  • The setting provides a check box. By default, the check box is not selected.
  • When the new setting is selected and you choose a location from the 'Environmental' or 'Emissions Inventory' Site Selector, the 'Location Details' (ML-003314) layout will display information for the site's location and its child locations.

Impact to Existing Uses:

  • This will help Site Managers view and track all of the locations for which they are responsible.

Additional Configuration Considerations:

  • Beyond what is described above, no additional configuration is required.
