CCC-747: For uploading documents, additional file formats are now supported

  • Cority now supports the following file types:
    • ZIP
    • 7ZIP
    • RAR
  • Note: You cannot print or preview files that use the above formats.

Impact to Existing Users:

  • You can now upload and store additional file types in Cority.

Additional Configuration Considerations:

  • No configuration is required.
