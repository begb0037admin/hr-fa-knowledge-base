CCC-3489: Server-wide SMTP default settings can now be specified

  • The following parameters have been added to the server.config file:
    • SMTPServerAddress - for providing a text string value
    • SMTPServerUsername - for providing a text string value
    • SMTPServerPassword - for providing a text string value
    • SMTPServerPort - for providing an integer value
    • SMTPServerSSL - for providing a true or false value
  • SMTPServerPassword will be encrypted automatically when the system starts.
  • SMTP Setting in System Settings:

SMTP Server System Setting

Result

Populated

System uses SMTP information from system setting

Empty

System uses SMTP information from server.config

  • SMTP Setting in MAEN:

MAEN SMTP Server Setting

Result

Populated

System uses SMTP information from MAEN

Empty

System uses SMTP information from server.config

Impact to Existing Users:

  • The SMTP service a customer is using to send email can now be managed more easily.

Additional Configuration Considerations:

  • Beyond what is described above, no additional configuration is required.
