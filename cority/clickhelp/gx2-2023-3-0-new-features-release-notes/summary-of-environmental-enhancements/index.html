Summary of Environmental Enhancements

The table below lists the smaller design improvements we have made in the Environmental cloud. The items are organized by component and the components are arranged in alphabetical order. Descriptions of any larger features follow the table.

ItemComponent(s)Description
CCC-12874Chemical Management

From the Environmental 'Chemical Inventory' list view, when the user selects the 'Inventory Chemicals in Bulk' action, a modal box opens for entering information related to the bulk request. Previously, the layout for the modal box was not configurable. Now, a user with the appropriate security configuration can use the layout editor to configure one or more custom versions of the ‘Chemical Inventory Bulk’ (ML-003802) layout for the modal box.

 

CCC-13536Chemical Management

In Display Rules, when the entity is set to Chemical Product, only Environmental 'Chemical Product' layouts will now be available.

 

CCC-13571Emissions Inventory

In Emissions Inventory, on layouts within the Texas STARS module, the 'Site Name' field value can now be edited.

 

CCC-13570Emissions Inventory

In the Emissions Inventory 'Texas STARS' module, the standard search functionality (with Search icon and fields) has been added to the following tabs (sublists):

  • Emission Sources
  • Emission Points
  • Control Devices
  • Control Paths
  • Emissions

 

CCC-13565Emissions Inventory

In Emissions Inventory 'Texas STARS' module you can now use the Import Utility to update the:

  • Emission Sources sublist (associate Texas STARS FINS to Cority emission sources)
  • Emission Points sublist (associate Texas STARS EPNS to Cority emission point assets)
  • Control Devices sublist (associate Texas STARS CINS to Cority control device assets)

 

To support this, the following data tables are now available in the Import Utility:

  • DT_STARSEmissionSource
  • DT_STARSEmissionPoint
  • DT_STARSControlDevice

 

For information on working with the Import Utility, see the GX2 User Guide.

 

CCC-14328Environmental Compliance

For a Safety 'Audit' or Environmental 'Inspection' that has one or more legal requirements, when a response to one of its questionnaire questions creates a 'Finding & Actions' record, the legal requirement(s) will now be added to the 'Legal Requirements' tab of the 'Finding & Actions' record.

 

CCC-12861Environmental Compliance

In the Environmental cloud, when the user selects a location with the Site Selector and then navigates to the Requirements module, the records in the Requirements list view will now filter as follows:

  • If the 'Display Child Locations for Location Details Landing Page' system setting is not selected, only the records that have a location matching the Site Selector will be listed.
  • If the 'Display Child Locations for Location Details Landing Page' system setting is selected, the records and their children that have a location matching the Site Selector will be listed.

 

CCC-14329Waste Management

The EPA e-Manifest transporter site ID now maps to the vendor EPA ID number instead of the vendor code (Vendor.Code).

This is the new mapping:

transporters.epaSiteId -> Manifest.VendorWasteTransp1.EPANumber

 

CCC-10254Waste Management

A manifest can now be submitted successfully to the EPA e-Manifest system without a Waste Container record. All information required for e-Manifest submissions can now be retrieved from the Waste Management and Waste Shipment records. If an associated Waste Container record is not present, the container type entered on the Waste Management record will be used for submission.
