CCC-13857: A user can now configure the header, footer, and/or add a watermark to a controlled document

  • This will help ensure controlled documents have all the information necessary for meeting compliance requirements and that users of the documents can be sure of their authenticity and that they are the latest revisions.
  • To support this, the final Reviewer/Publisher layout in Administrator > Look-up Tables > Document Library > Approval Workflow now has the new 'Headers and Footers' checkbox and 'Watermark' text field.
  • Note: These new fields are only available when the 'Render as PDF' checkbox on the layout is selected.
  • When the 'Headers and Footers' checkbox is selected, a rich text HTML editor (similar to the one in the Letters module) and a merge table selector will both become enabled.
  • The text editor can be used to create, format, and display free text and add a logo in the document's header and/or footer.
  • The merge table can be used to add any metadata, by adding the corresponding metadata fields, from the Document Control record (the main form and/or the Approval History section) to the header and/or footer.
  • All content added will be published in the header/footer on each page of the resulting PDF document.
  • The new 'Watermark' field has a character limit of 40.
  • When the PDF of the document is published, the watermark will overlay diagonally from the bottom left to the top right of each page.
  • The watermark will be grey and transparent.
