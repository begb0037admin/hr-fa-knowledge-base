Summary of Ergonomics Enhancements

The table below lists the smaller design improvements we have made in the Ergonomics cloud. The items are organized by component and the components are arranged in alphabetical order.

ItemComponent(s)Description
CCC-14185Case Manager

In the Ergonomics cloud, an unnecessary preference verification that was hindering Case Manager notifications has been removed.

 

CCC-13361Case Manager – Reports

In GX2 2023.2.2, a Case Manager ‘Reports’ link was added to the Ergonomics side menu bar. In this release, the following reports have been migrated and are now accessible through that link:

  • Ergonomic Case & Task Status
  • Rapid Response
  • Rescheduled Cases & Tasks
  • Risk and Discomfort Post Evaluation
  • Time To Perform

 

CCC-14584Desktop Summary

In the Summary section of Desktop Summary, ‘Hours Using Computer’ and ‘Overall Break Compliance’ charts have been added.

 

CCC-14172Personal Risk

Ergonomic personal risk can now be calculated automatically once per week.

This will help ensure each user's risk calculation remains up to date.

The following new system settings have been created:

  • Weekly Personal Risk Recalculation Day - a picklist with each day of the week
  • Weekly Personal Risk Recalculation Time - a picklist with times of the day, in 30-minute increments
  • Weekly Personal Risk Recalculation Time-Zone - a picklist with all time-zones

These system settings are categorized under the 'Personal Risk' module.

Each week, all personal risk will be recalculated in accordance with the values for these settings.

 

CCC-14326Reporting, Employee Activities

The OES Employee Activities table is now available for reporting in both Query Builder and Report Writer.

 

CCC-13788Reporting, Background Jobs

The OES BackgroundJobLog and OnlineTrainingJobLog entities are now available for reporting in both Query Builder and Report Writer.

Also, BackgroundJobLogService.CheckBackgroundJobLogs now checks for automatic background jobs that have failed to trigger again since the last completion date.

To support this, the 'Recalculate Risk For All Employees' job (ID = -1) is now flagged as an ad hoc job, because it is triggered manually.
