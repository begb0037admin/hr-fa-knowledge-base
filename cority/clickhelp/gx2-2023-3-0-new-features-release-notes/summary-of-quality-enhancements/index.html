Summary of Quality Enhancements

The table below lists the smaller design improvements we have made in the Quality cloud. The items are organized by component and the components are arranged in alphabetical order. Descriptions of any larger features follow the table.

ItemComponent(s)Description
CCC-13419Audits

On a custom Quality 'Audit' layout, you can now use multi-select for the 'External Entity' and 'Customer' fields to successfully link multiple suppliers and customers to a single Quality 'Audit'.

 

CCC-12568Document Management

A user can now create a custom version of the 'Published Document' (ML-001261) layout by adding and editing fields. The layout is accessible by navigating to My Favorites > Published Documents and opening a record. Note: The fields will remain read-only and auto-populate from the original record.

 

CCC-12567Document Management

For a published Quality 'Document Control' record, if a user changes the name of one of the approvers on the main tab and then initiates a new review for the document (for example, if the document gets revised and needs to be re-published and approved by a new approver), that will no longer change any previous approver's name in the Approval History for the record.

 

CCC-12907Products, Events

Four new look-up table fields, UDFLU1 through UDFLU4, can now be added to custom versions of the ML-003236 and ML-003212 'Products and Managed Products' module layouts.

The corresponding look-up tables have been added and are categorized under the 'Quality Events' module: LU_QE_ProdUDF1 (Product User Defined Field 1) through LU_QE_ProdUDF4 (Product User Defined Field 4).

The fields are available for use in Query Builder and Report Writer.

The fields can be used in business rules, business rule actions, and display rules.

The corresponding columns can be added to applicable custom list views.
