Summary of Occupational Health Enhancements

The table below lists the smaller design improvements we have made in the Occupational Health cloud. The items are organized by component and the components are arranged in alphabetical order. Descriptions of any larger features follow the table.

ItemComponent(s)Description
CCC-13650Employee Care

For adding to custom versions of Allergy layouts, six new user-defined date/time fields are now available.

The fields can be used in business and display rules, and are available in both Query Builder and Report Writer.

The equivalent columns are available for adding to applicable custom list views.

 

CCC-13042Employee Care – Appointments

For GX2, within the Appointments module, a new soft-enforce business rule will now warn scheduling users if they are about to double-book someone for an appointment. This applies across multiple health centers. Once notified, the scheduling user can choose instead to look for another date/time combination that does not conflict.

The code for the new business rule is BR-100640. By default, the rule is inactive. It will have to be activated to function.

 

CCC-14199
Employee Care – Medical Letters 

When an employee is sent his or her medical letters, a new business rule (with accompanying BR method action) can now be used to send the letter password to the employee through SMS. This will help ensure only the right person receives the confidential information.

Specifications:

  • BR Code - BR-100643
  • Entity - Letters
  • BR Method Action Code - BRA-100643
  • Triggers On - Insert/Update
  • Execution Type - Immediate

Conditions:

  • Password Protected - when checkbox is selected on the Letter layout
  • SMS Twilio Account SID - provided through the system setting
  • SMS Twilio Auth Token - provided through the system setting
  • Twilio Sender Phone Number for Encrypted Letters Password Delivery – the number that will ensure the SMS is sent from the phone number associated with the configured Twilio account
  • Cell Phone - cell phone number used must be provided on employee's Demographics record

The method action will generate the PDF, add it as an attachment, and send the email with the PDF and the SMS with the password.

The execution will get logged in the SMS log.


CCC-14239Employee Care – Medical Records

The Medical Records report can now be filtered by GDDLOFB. This will enable an Occupational Health user to filter the report according to employment location.

This does not apply to either of the 'Problem List' or Restriction' entities because they do not have GDDLOFB:

Note: This is for GX2 only. For myCority, this functionality will be added in a future release.

 

CCC-13453Employee Care – Duty Disposition Report

When a practitioner is generating and emailing the Duty Disposition Report (Actions > Email as Attachment), the screen will now dim until the modal box appears.

 

CCC-8419Pre-Employment

To support the OH pre-employment process, the translation drop-down list has been added to the myCority 'Applicant Registration Portal' screen. 

If the user selects a language from the list, the phrases on the screen will be translated into that language.
