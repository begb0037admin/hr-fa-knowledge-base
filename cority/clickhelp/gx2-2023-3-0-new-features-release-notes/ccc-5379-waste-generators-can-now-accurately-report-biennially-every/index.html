CCC-5379: Waste Generators can now accurately report biennially (every other year) on the amount of waste generated onsite, received onsite, managed onsite, and/or shipped offsite

  • The following files can be generated:
    • Site Identification Information (SI ID)
    • Waste Generation and Management (GM)
    • Waste Received Offsite (WR)
    • Offsite Identification (OI)
  • Note: Only manifested waste will be considered for either on-site or off-site treatment. That is, Waste Records must have a relationship to a Waste Manifest whether the waste is shipped off-site or treated on-site.
  • For data gathering and preparation, to populate, generate, and download biennial waste forms automatically:
  1. Navigate to the Environmental ‘Location Details’ layout (ML-003546).
  2. Click the ‘Generate Biennial Report’ action.
  3. On the ‘Generate Biennial Report ‘ modal box, select a Form Type (of the forms listed above) and a Reporting Period.
    If you select the ‘Include in National Report’ checkbox, the EPA will include the generated data in the national report.
  4. Click the ‘Select’ button on the modal box.
    Flat files of the forms specified will be generated and downloaded in the appropriate file format (for example, ZIP). The flat files will conform to the specifications outlined by the RCRA.
  • File names will be formatted in this manner: SSFFFNNN.FIL
    • where:
      • SS – is the state postal code
      • FFF – is the flat file identifier (for example, SI2 for Site Identification Information Form 2)
      • NNN – is the date the file was created
    • Therefore, the correct name for the SI2 file, containing KS data, produced on February 4th, would be KSSI3035.FIL.
  • A biennial report file can then be submitted to the RCRA.
  • Notes:
    • The SI2 flat file will always contain two lines, one for Owner and one for Operator, even if all questionnaire answers for those sections are null (blank).
    • For SI3, if all NAICS codes in the questionnaire are null, an SI3 file will be generated but empty. NAICS codes that do not have values will be ignored.
    • When there is no entered data to pull into the file, the file will still be generated but empty.
    • For the GM1 file to be created properly, the following value must first be added to the ‘Units of Measure’ look-up table:
      • Code: "lbs/gal"
      • Description: Pounds per Gallon
      • That is required to map the ‘Density Unit of Measure’ information for the flat file.
    • For the Off-Site Identification (OI) Form, a new line is added when the same site contains a combination of Generator, Receiving Facility, or Transporter flags. Once imported into RCRA, a separate entry will be created for each type.
  • The generated reports are stored in the following new data tables:
    • DT_BiennialReportHeader – This will store all of the data generated. The appropriate flags (SI, GM, WR, OI) will be applied to the data.
    • DT_BiennialReportGM - This will store the generated GM data.
    • DT_BiennielReportWR - This will store the generated WR data.
    • DT_BiennielReportOI - This will store the generated OI data.
  • The tables are available for reporting in both Query Builder and Report Writer.
  • The tables cannot be populated or updated using import.
  • The tables are not available for use in business rules, business rule actions, display rules, or workflows.
