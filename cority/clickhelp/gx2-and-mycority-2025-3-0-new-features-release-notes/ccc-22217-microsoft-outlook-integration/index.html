CCC-22217: A new harmonious integration enables seamless appointment management between GX2 and Outlook

This integration, which includes a new Scheduling Assistant and automated emails, is provided with the GX2 OH license.

The new integration is the only one in GX2. The previous, display-events-only integration is no longer available.

This feature set will improve scheduling efficiency, prevent double-bookings, and expand virtual care options with a built-in Microsoft Teams integration.

It provides:

  • Seamless calendar sync: Overlay Outlook calendars within GX2 and automatically send Outlook meeting invites.
  • Integrated virtual care: Link GX2 appointments with Microsoft Teams for secure, efficient telehealth visits.
  • A New Scheduling Assistant: Checks employee availability within Outlook to prevent double-booking.
  • Streamlined communication: Outlook meeting responses feed directly back into GX2, through the new Notification Bell, for real-time status updates.
  • Time savings: Automates scheduling and notifications, reducing administrative effort for clinicians and employees.

Configuration:

  • An Azure App is required to connect GX2 with Outlook.
    Engagement between your IT Team and Cority Professional Services is required for the Azure App build and initial testing/setup. Contact your Cority Account Manager or Customer Success Manager for more information.
  • Ensure that the ‘Enable OAuth 2.0 Authentication’ system setting is selected.
  • Ensure that the ‘Synchronize Appointments from Outlook Exchange Server’ system setting is selected.
  • Note: Configuring the Microsoft Graph system settings (listed below) will effectively turn on the Outlook Integration for every user. Meeting invitation emails will begin to be sent automatically.

Azure App configuration and new system settings:

  • The new  'Scheduling Assistant' field requires the following system settings configuration:
    • Microsoft Graph Client ID → from the Azure ‘Application (client) ID“
    • Microsoft Graph Client Secret → from the Azure value
    • Microsoft Graph Tenant ID → from the Azure ‘Directory (tenant)’
  • The following system settings are now deprecated for Outlook use with the Appointments module, but should remain populated, especially if using the Inbox feature:
    • Exchange AAD Client ID
    • Exchange AAD Client Secret
    • Exchange AAD Tenant ID

Once the integration is configured, the Appointments module will automatically send meetings created within GX2 to Outlook.

Outlook Toggle

The existing Outlook toggle in the Appointments module has been renamed .

Turning the toggle on will allow the user's Outlook calendar to be viewed in the GX2 Appointments calendar. The Outlook events will display.

Important: Again, populating the Microsoft Graph system settings turns on this enhanced Outlook Integration.

New Schedule Entry Fields

The following new fields have been added to the Schedule Entry layout (ML-000658):

  • Scheduling Assistant
  • MS Teams – Telehealth
  • MS Teams Meeting Link
  • Outlook Event ID
  • Outlook iCalUid

New Scheduling Assistant

The new ‘Scheduling Assistant’ field can be added to Schedule Entry layouts in the Appointments module.

For the Scheduling Assistant to populate, the following fields must have values:

  • Scheduling user
  • Employee
  • Date
  • Time

If all required values are not entered, the Scheduling Assistant will not load.

Scheduling Assistant – Time Slots

The available times will be displayed as chips for up to 10 days in the future, which mimics Outlook behavior.

Availability slots respect the workday/worktime for users as configured in Outlook.

Navigation arrows are provided for displaying additional timeslots.

Note: The system does not verify the Scheduling User against GX2 availability because it is assumed the person creating the appointment is looking at that calendar.

If no availability is displayed, the user must select a new date and time.

Scheduling Assistant – Statuses

  • “All users are available at the selected time” – the users are available
  • “Not all users are available at the selected time” – either the Scheduling User or the employee is not available
  • “No users are available for the next 10 days” – the users are unavailable

Microsoft Teams Integration

New Microsoft Teams fields can be added to custom Schedule Entry layouts.

To link the appointment record to a Teams meeting, the user must first obtain the license key for Remote Expert users.

  • If the user adds Teams fields to a custom layout but does not have a license key that includes the Remote Expert license, those fields will be disabled.

If the user has Teams as part of their corporate license, has the enhanced Outlook Integration configured in GX2, but does not have the Remote Expert license:

  • If booking within GX2, the default email will not include a Teams link.
  • If booking within Outlook, the default email will have a Teams link.

Fields for Troubleshooting

These fields are optional, but should be used for troubleshooting.

When a meeting is successfully sent to Outlook, these two fields populate.

  • Outlook Event ID: This is the ID of an event resource type, which is a unique identifier for an individual event on a particular calendar.
    Important: This ID is specific to the calendar in which the event is stored and could change if the event is moved to a different calendar.
  • Outlook iCal UID: This is returned by the calendar event resource type in Microsoft Graph, and is a unique, read-only identifier shared by all instances of an event across different calendars.

Automated Meeting Emails

There is a new 'Define the Email template to be used with Outlook integration' system setting.

The system will merge the BRA's email body with the Outlook meeting details (subject, additional recipients, any Teams information, etc.). Note: If the subject is blank, an error will occur. Ensure you always populate the recipients, subject, and email body.

The 'Send Email' field on the Schedule Entry layout is to be used for resending 'ics files (if necessary) or for recurring GX2 appointments. Recurrences are otherwise not supported. Responses for recurrences from Outlook will be given the status TBD within the Notification Bell (described below).

The GX2 Appointments module invitation will map to the Outlook invitation: The current logged in GX2 user will be the Organizer, the Scheduling User will be Attendee #1, and the Employee will be Attendee #2.

The integration automatically includes Teams meeting information (if applicable) in the body of the invitation.
Note: If the user does not have a Remote Expert license, the Teams meeting details will be omitted.

If the user has not configured a custom version of BRA-000542 (business rule email action) and defined it in system settings, the system will instead send out a default email that contains the basic appointment information.

Meetings booked within GX2 will be sent automatically to Outlook, and any edits made within GX2 will be reflected in Outlook.

Notification Bell (Meeting Responses)

The notification bell in the Appointments module:

  • Provides a count of the inbound notifications for all Accepted, Declined, and Tentative responses that have not been viewed
  • Provides the status of the meeting
  • Updates every 5 minutes

Note: The notifications are for meetings the logged-in user created.

Reports and business rules can be configured for this functionality and will apply for all responses received by GX2, regardless of the meeting creator (organizer).

The entity for this data table is Inbound Notifications.
