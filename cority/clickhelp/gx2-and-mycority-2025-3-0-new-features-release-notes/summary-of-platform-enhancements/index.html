Summary of Platform Enhancements

The table below contains design improvements we have made to the GX2 Platform. The items are organized by component, and the components are arranged in alphabetical order. Descriptions of any larger features follow the table.

ItemComponent(s)Description
CCC-18295Questionnaires, myCority

For identifying assigned questionnaires in myCority, the summary information (Due Date, Complete For, Status, etc.) is now more helpful.

 

CCC-22378REST API

The REST API can now be used to import controlled documents in the published state.

To support this, the REST API has a new PublishDocument endpoint.

If the format of the imported document is supported, the published document within its new Document record will be made available in PDF format. The header, footer, and watermark defined in the Document Library to which the Document record belongs will be applied to the PDF. If the original format of the imported document is not supported for PDF conversion, the original format will be retained. If a record cannot be converted to PDF, that will be noted in the Event Log.

The new endpoint does not support multiple requests at once, but does support bulk processing of documents.

 

CCC-18600
REST API

For REST API authentication, the less secure method of using a token in the URL is no longer an option. Authentication is now possible only through the header or with OAuth 2.0.

If using the the Refresh Token method for generating an access token, the following changes now apply:

  • The GET request to https://CORITY_SITE_URL/api/token?t=<<REFRESH_TOKEN>> is no longer valid.

  • The GET request must instead point to https://CORITY_SITE_URL/api/token and specify the Refresh Token in the Headers section by using Authorization: Bearer <<REFRESH_TOKEN>>.

If using OAuth 2.0, your requests remain unchanged.
