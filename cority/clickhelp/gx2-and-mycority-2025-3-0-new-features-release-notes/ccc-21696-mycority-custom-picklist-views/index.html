CCC-21696: myCority now supports custom picklist views for Safety and Environmental Incident Investigations and Safety, Environmental, Quality, and Ergonomics Event Reports

Opt-In

Note: This new functionality applies to picklists for non-Employee/User look-up tables only.

myCority users will now see any out-of-box (OOB) and customer-configured picklist views that have ‘Standard View’ specified.

Standard picklist views do not have to be added to Roles > Granted Views to be available in myCority if you want them available for all users.

myCority users will not see OOB views or standard picklist views that meet one of the following conditions:

  • Added to ‘Prohibited Views’ for a role associated with the user.

  • Added to ‘Granted Views’ for one or more roles and the user is not assigned that role.

Note: When a sublist or picklist view is explicitly added to ‘Granted Views’, it will then be hidden from users not associated to a role granted that view.

On the interface, the standard OOB and custom picklist views will be listed in the following order:

  • OOB views, if not hidden (All Active, All Inactive, then All)

  • Custom views, alphabetically by custom view name

On the picklist views, the typical search functionality (including smart search) for columns with text values is provided.

Note: Custom picklists will not be available when offline.
