Summary of Occupational Health Enhancements

The table below contains design improvements we have made in the Occupational Health cloud. The items are organized by component, and the components are arranged in alphabetical order. Descriptions of any larger features follow the table.

ItemComponent(s)Description
CCC-22090Appointments

Where applicable, for 'My Settings' and for the Appointments filter in the Appointments module, the 'Health Center' picklist now supports the custom list views functionality.
All columns available on the sublist can be added and removed from a custom list view.
All other standard list view features apply to any custom list views created.
For information on working with custom list views, see the GX2 User Guide.

 

CCC-21443Appointments

In the Appointments module, on the 'Employee History' tab, the 'Schedule History' section now supports the custom list views functionality.
All columns available on the sublist can be added and removed from a custom list view.
All other standard list view features apply to any custom list views created.
For information on working with custom list views, see the GX2 User Guide.

 

CCC-18889Billing

The following new fields can now be added to custom versions of OH Billing 'Payment Tracker' layouts:

  • 3 new look-up table UDFs, numbered 1 through 3

Each of the look-up table fields has a corresponding new look-up table. Each look-up table has a default list view and layout with appropriate columns/fields, and each functions as a typical GX2 look-up table.

For each new field, the equivalent column can be added to applicable custom list views.

The fields can be used in business rules, display rules, and workflows, and can be reported on using Query Builder and Report Writer.

Each of the new fields can be prohibited from user roles.

Values for the fields can be added or updated through import (Import Utility or REST API).

CCC-21197Clinical Testing

For ‘Clinical Test Sample’ and ‘Clinical Test Sample Battery’, for the bar code QR code field, when the user clicks the Print button, the code and numeric value will now open in a PDF viewer for printing. If the field is null, the Print button will be disabled.

 

CCC-22047Employee Care

For the following Medical Record Reports, employee identifiers can now be included in the report output:

  • Body Fluid Exposure Summary
  • Case Management History
  • Case Notes 
  • Clinical Test History
  • Immunization History
  • Problem List
  • Employee Restrictions
  • Medical Questionnaire Responses
  • Clinic Visit History
  • Notes From all Medical Modules
  • Travel History

To support this, there is a new 'Display Employee Identifiers' checkbox. If the checkbox is selected, the Employee Name and Date of Birth will be included in the report header.
