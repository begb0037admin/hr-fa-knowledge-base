CCC-22130: Enhancements have been made to the Office Ergonomics solution

Opt-In

Organizations with large data sets can now export the following reports to Microsoft Excel:

  • Desktop Aggregate
  • Desktop Statistics
  • Employee List
  • Historical Personal Risk
  • Issue Frequency
  • Organizational Status

To support this, an Export to Excel button is now provided on the report’s screen. After the report is configured and saved, the creator can simply click the button to export the report.

An email address must have been provided for the creator of the report. If it was, a link for downloading the report will be emailed to the creator once the report is ready. If it isn’t, the report will not be emailed to the creator, but will always be accessible from the new Ergonomics Reports Export Log. The log can be opened using the new link to it under the Ergonomics Reports link in the Ergonomics module. The user will be able to see all report jobs he or she has initiated and all he has permission through role security to access.

Note: The Break Compliance report has been renamed Desktop Statistics.

Also, for Self-Assessments, the font size for the issue resolution content has been reduced for better fit in myCority.
