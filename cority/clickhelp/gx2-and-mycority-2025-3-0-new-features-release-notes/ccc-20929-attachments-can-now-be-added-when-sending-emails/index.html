CCC-20929: Attachments can now be added when sending emails

Opt-In

Users can add attachments when using the 'Email' action from any module that supports documents.

Updates made to support this feature include:

  • A new 'Attach Document' field that must be added to custom versions of 'Email' layouts.
    • Users can drag-and-drop documents or browse and select files from your device.
  • When sending an email with attachments from a module with the 'Documents' tab:
    • A copy of the attachment(s) is added to the Documents list.
    • Existing documents can be selected as attachments using the 'Select Existing Document' option.
  • A new ‘Additional Attachments' tab can be added for custom versions of ‘Email Log’ layouts.
    • All attachments sent with an email are listed in the Additional Attachments view.
  • When using the 'Resend Email' action, the email resends with the original attachments.

Attachments have the following limitations:

  • The total size for all attachments must not exceed 20MB.
  • The maximum number of attachments is 100.

Note: If the maximum size or number of attachments is reached, a warning will display, and the email will not be sent.
