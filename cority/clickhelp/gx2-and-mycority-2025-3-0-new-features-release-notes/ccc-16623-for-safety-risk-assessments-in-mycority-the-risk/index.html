CCC-16623: For Safety ‘Risk Assessments’ in myCority, the Risk Matrix is now available

Opt-In

The 'Matrix' sublist can now be added to custom Risk Assessment layouts.

From the Risk Matrix, users can:

  • Select a square from the Risk Matrix Grid to view all associated risks.
  • Toggle to view the risks with No Controls, Current Controls, or Future Controls.

The table below the matrix lists all tasks when no square in the matrix is selected.

The color scheme of the Risk Matrix is inherited from GX2.

Users can open a task to view the task details and configure the risk controls.

From the task details:

  • Users can set the risk level for each Risk Control by:
    • Selecting the corresponding square on the grid for each Risk Selector OR
    • Choosing a Severity and Probability value for each Risk Selector (Severity and Probability for Risk Selector 1, Severity2 and Probability2 for Risk Selector 2, etc..)

Note: Selecting a square on the grid automatically updates the values for the Severity and Probability fields and vice versa.

  • Users can click 'Clear' below the grid of each Risk Selector to remove the risk from the given Risk Control.
  • Save any changes made to the task details.
