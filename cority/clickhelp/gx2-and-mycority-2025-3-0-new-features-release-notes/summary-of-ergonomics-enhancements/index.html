Summary of Ergonomics Enhancements

The table below contains a design improvement we made in the Ergonomics cloud. Descriptions of any larger features follow the table.

ItemDescription
CCC-19567

For Case Manager, if an image larger than 1 MB is uploaded, it will be reduced to 1 MB. If an image less than 1 MB is uploaded, its size will be retained.

Also, the email attachment limit in Case Manager has increased from 5 MB to 10 MB.
