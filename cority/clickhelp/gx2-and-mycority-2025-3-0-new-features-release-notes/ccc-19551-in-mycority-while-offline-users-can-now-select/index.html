CCC-19551: In myCority, while offline, users can now select GDDLOFB values when creating a record

Opt-In

While offline, users can now select GDDLOFB values when creating records in the following areas:

  • Event Reports
  • Waste Related Records
  • IH Samples
  • Public Questionnaires (myCority Headers)

In GX2 System Settings, a new global setting, 'Make [Organizational Tree] available for Offline', is now available for each organizational tree. Administrators must select which trees will be made available offline.

It is recommended that no more than two trees be made available offline.

The following System Settings related to trees will also be applied when offline:

  • Apply Site Security to Tree Picker in myCority – When selected, will reduce the trees available for selection for users with limited Site Security.
  • Restrict leaf member selection on [Organizational Tree] picker – When selected, will require that the user selects at the lowest level within a given branch of the tree (those without child nodes)

This functionality has the following limitations:

  • Only the first 1,000 records will be downloaded and available offline.
  • When there are related trees configured for a given tree record, the relationships will be ignored when offline (the related tree(s) will not populate).
  • Changes made to organizational trees will not be automatically downloaded for trees available offline. A manual update will be needed to make the changes available offline.
  • Offline is not available for the Guest User.
  • When 'Treat [Organizational Tree] as a Lookup Table' is enabled in GX2, the GDDLOFB field will still display as a tree in myCority.
