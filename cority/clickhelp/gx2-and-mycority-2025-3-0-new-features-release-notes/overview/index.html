Overview

At Cority we are committed to continually enhancing our products. The 2025.3.0 release contains new and improved functionality in several areas—including additional UDFs in the OH, Safety, Environmental, and Quality clouds, email attachment updates, Microsoft Outlook integration with the OH Appointments module, enhancements to IH and Safety risk assessment, and improvements to chemical management.

Tips:

  • We use the number(s) assigned to each enhancement to identify it internally. If you have a question about a feature, its number(s) will help the Cority technical contact quickly access all of the relevant information.
  • For the larger items after the tables, we have categorized each as either:
    • Opt-In – The feature is available, but its use is optional.
    • Mandatory – An element of the feature is likely to affect one or more of your current workflows or changes the way data is grouped and/or displayed.
    • N/A – The feature cannot easily be categorized as either opt-in or mandatory.
  • Until the software is released to Production environments, please check this document for updates.
  • For previous versions of the Release Notes, see the Documents section of the User Community.
  • The version number on the cover (landing) page is the document version. A number greater than 1.0 indicates one or more updates have been made.
