Summary of Industrial Hygiene Enhancements

The table below contains design improvements we have made in the Industrial Hygiene cloud. The items are organized by component, and the components are arranged in alphabetical order. Descriptions of any larger features follow the table.

ItemComponent(s)Description
CCC-20348Monitoring and Noise Monitoring

For Monitoring and Noise Monitoring plans, completion percentage can now be tied to a specified Job Name and Task.

 

Prior to this, the % Complete calculation was tied to an agent, limit type, sample type, and exposure group. That resulted in misrepresenting % complete when multiple Job Names and Tasks existed for the same plan.

 

Now, the overall completion percentage will represent a 1 to 1 match to the plan. That is, only samples that match the Job Name and Task fields will count in the % Complete calculation.

 

CCC-16393Risk Assessments

Additional sublists are now available for Risk Assessments in myCority.

 

For IH, the following sublists can now be added to custom Risk Assessment layouts:

  • Notes
  • Interviewed Employees
  • Share with Group
    • Groups can only be created in GX2 and can be viewed in the sublist in myCority.
  • Letters

Letters can only be created in GX2 and can be viewed in the sublist in myCority.

 

CCC-22075Timecards

The new 'SEG Worked' field (a picklist to the 'Exposure Group' look-up table) is now available for adding to custom versions of the 'Timecard Location' layout.
The equivalent column can be added to custom versions of the 'Timecard by Locations' sublist.
As always, timecards are entered using myCority and also display in GX2.
Note: An employee can have multiple locations worked for the same day and same SEG. 
Record History will capture any updates to the field.
The field can be reported on using Query Builder and Report Writer.
