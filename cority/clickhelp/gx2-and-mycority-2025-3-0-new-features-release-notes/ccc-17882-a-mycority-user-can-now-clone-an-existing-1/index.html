CCC-17882: A myCority user can now clone an existing ‘Risk Assessment’ (for reassessment) and inactivate the original, and clone an existing ‘Risk Assessment’ to use as a template for others

Opt-In

For the former, on both IH and Safety ‘Risk Assessment’ records, there is a new ‘Clone and Inactivate’ action. When selected, the original ‘Risk Assessment’ will become inactive, and a new ‘Risk Assessment’ for reassessment will be created with an ID that is next in sequence. All relevant field values (Job name, Job Description, etc.) and sublists will be copied over to the new record, and today’s date will populate for the ‘Created Date’.

Any user who is an ‘Assessor 1-5’ on the Assessors sublist or is populated in the ‘Assigned To’ or ‘Created By’ field will be able to use the new ‘Clone and Inactivate’ action.

For the creation of a template from an existing IH or Safety ‘Risk Assessment’, there is a new system setting ‘Role allowed to create/edit Risk Assessment Template’. The setting is global, cannot be changed, is categorized under ‘Risk Assessment’, and is a picklist to the ‘Roles’ look-up table.  Only users with this role will be able to designate ‘Risk Assessments’ as templates (that is, select the ‘Template' check box on ‘Risk Assessments’) or edit existing 'Risk Assessment’ templates.

To support the use of templates, the new Template check box can now be added to custom versions of the following ‘Risk Assessment’ layouts:

  • Safety: ML-003509, ML-001225
  • IH: ML-001282
  • Environmental: ML-001341, ML-000010
  • Ergonomics: ML-001340
  • Safety COSHH: ML-001301
  • OH/Medical: ML-001338

By default, the check box is not selected. When selected for a record, the record will become available for use as a ‘Risk Assessment’ template.

The equivalent column is available for adding to applicable custom list views.

On applicable list views, there is a new ‘All Risk Assessments and Templates’ view. which includes both ‘Risk Assessment’ records and templates.

Now in myCority, if a user selects ‘Create New’ on an IH or Safety ‘Risk Assessment’, the following options will display:

  • New Assessment
  • Copy/Clone an Existing Assessment (from a template)
  • Conduct Reassessment (clone and inactivate)

If the user selects ‘New Assessment’, the existing workflow will apply.

If the user selects ‘Copy/Clone an Existing Assessment’, a picklist with all ‘Risk Assessments’ that have been marked Template and are not marked Inactive will be provided. The default views for the picklist are: Active Risk Assessment Templates, Inactive Risk Assessment Templates, and All Risk Assessment Templates. The default columns for the picklist views are Job Name and Job Description. Custom views can be created for the picklist. The user then selects a template from the list. It will open read-only and have the new ‘Copy and Create New Risk Assessment’ option. The Save button on the read-only template will be disabled. When the user clicks ‘Copy and Create New Risk Assessment’ on the template, the new ‘Risk Assessment’ will be created, all relevant field values (Job name, Job Description, etc.) and sublists will be copied over, and today’s date will populate for the 'Created Date’.

If the user selects ‘Conduct Reassessment' (equivalent to ‘Clone and Inactivate’). A picklist with all ‘Risk Assessments’ that are assigned to the user (through the ‘Assessor 1-5’ fields on the Assessors sublist or the ‘Created By’ or ‘Assigned To’ field) that have not been flagged as Inactive will be provided. The default views for the picklist are: Active Risk Assessments, Inactive Risk Assessments, and All Risk Assessments. The default columns for the picklist view are Job Name and Job Description. Custom views can be created for the picklist. The user then selects a ‘Risk Assessment’ from the list. When the ‘Risk Assessment’ opens, the user then clicks ‘Clone and Inactivate’. The original ‘Risk Assessment’ will become inactive, and a new ‘Risk Assessment’ for reassessment will be created with an ID that is next in sequence. All relevant field values and sublists will be copied over to the new record, and today’s date will populate for the 'Created Date’.
