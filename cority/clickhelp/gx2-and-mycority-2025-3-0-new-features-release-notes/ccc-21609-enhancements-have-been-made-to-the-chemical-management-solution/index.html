CCC-21609: Enhancements have been made to the Chemical Management solution

Opt-In

For the ML-000408 layout, and custom versions of it, the Chemical Phrase Code character limit has been increased to 500 and the Chemical Phrase Description character limit has been increased to 5000.

For all applicable layouts, the SDS shortcut icon has been added to the main form (tab).

In Environmental > Chemical Products, for when you are searching the SDS Library for a product then adding it or when you are exporting as an offline backup, the messaging has been updated.

The ‘Refresh Chemical Content’ action can now be scheduled. To support that, the RefreshChemicalContent BRA (BRA-100606) can now be used in a scheduled business rule. For example, you could create a scheduled business rule with a Start Date of today, a Start Time of 1:00 AM, recurrence set to 'Every 1 day(s) with no end date, and a condition of: ID = 1 (check that Chemical product with ID 1 exist, before scheduling, otherwise use any other ID).

On Environmental Change Requests (Chemical Request type) in both GX2 and myCority, there are two new views for the ‘Ingredient Screening’ sublist (tab):

Ingredients Screening (Active Regulatory Lists)

Ingredients Screening (Inactive Regulatory Lists)

The existing view for the sublist has been renamed ‘Ingredients Screening (All Regulatory Lists)’.

The lists have applicable default columns and can be cloned for customization. The lists have all applicable sublist (tab) functionality.
