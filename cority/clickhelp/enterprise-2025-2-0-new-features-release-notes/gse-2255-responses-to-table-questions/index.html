GSE-2255: Responses to table questions can now be made using the Microsoft Excel or SFTP template.

From the Frameworks module, questionnaires are sent to users, and one of the question types is table (or matrix). Previously, table question responses would be made through the UI only. Responses to such questions can now also be made using the existing Excel or SFTP template. To download the template, in Frameworks > Inputs, click a questionnaire, click Import Responses, then click Export Template.

To support this feature, three columns have been added to the Excel template (Table Column Number, Table Row Number, and Table Column Title), and two columns have been added to the SFTP template (Table Column Number and Table Row Number).
In the template, each table type question will be ordered by Table Column Number, then Table Row Number, so that one row in the template equates to one cell in the table question response.
For example, if you want to add data to column one, row two in your table question response, in your upload template you would have:
Table Column Number = 1, Table Row Number = 2, and the other cells in that row of the template (including the Response) filled in as you would before.

If there is a response for an existing table type question (even if just partial) prior to exporting the template, the corresponding row(s) will be pre-populated in the template.

Note: Consumption and Emission question responses cannot be updated using import so will be ignored.
