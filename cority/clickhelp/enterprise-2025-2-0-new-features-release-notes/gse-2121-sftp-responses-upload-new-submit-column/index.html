GSE-2121: For Frameworks response uploads, you can now specify whether the question is to be submitted to the next approval stage.

In the past, when users uploaded responses to the Frameworks module through SFTP, the responses would all have the Data Input status. The SFTP upload template now supports a Submit column for specifying whether the question is to be submitted to the next stage of the approvals workflow.

When uploaded:

  • If Approvals for the question is not switched on, the question response will be saved, but the status of the question will not change regardless of the value in the Submit column.
  • If the response status for the question prior to upload is not Data Input or Rejected, the new response will not be saved and the status of the question will not change regardless of the value in the Submit column.
  • If the response status for the question prior to upload is either Data Input or Rejected and the value in the Submit column is null or marked FALSE, the response will be saved and the response status will remain the same.
  • If the response status for the question prior to upload is either Data Input or Rejected and the value in the Submit column is marked TRUE, the response will be saved, the question will get submitted to the next stage of the approvals process, and its response status will change accordingly.
Note: The status and cell values must be valid to avoid an error and rejection of the row.
