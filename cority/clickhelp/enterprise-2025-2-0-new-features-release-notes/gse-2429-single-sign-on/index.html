GSE-2429: Single Sign-On (SSO) can now be set up by your Administrator for all users.

To support this, there is a new Admin Settings > Single Sign-On page. Near the top left of the page, your Administrator can simply click ‘Add Configuration’ and then specify:

  • Identity Provider(s) – One or more identity providers
  • Login Button Label – The label for the button that will be added to the existing Login page
  • Identity Provider Link(s) – A redirection link for each identity provider
  • Certificate Expiry Date – Populated automatically after attaching the SSO certificate
  • SSO Certificate – An SSO certificate for each identity provider

Once configured, the page will be used by the system to authenticate (validate) all users.

The Admin page also has a toggle that if set to on will require SSO users to log in by SSO. If toggled on, a simple user name and password will not be allowed.
