Employee Import File Format

The employee import file must be a comma-delimited text file. The following conventions must be used:

  • All fields are to be separated by a single comma.
  • Dates should not be enclosed in quotes (e.g., 11/29/2017).
  • Numbers should not be enclosed in quotes.
  • Yes/No and True/False are denoted as true and false, respectively.
  • Male and Female are denoted as 0 and 1, respectively.
  • To denote the value NULL, leave an empty space between commas (e.g., text, ,text2).
