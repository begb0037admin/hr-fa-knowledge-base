Silent/Automated Running

The HR Integration Utility can be run automatically with no interaction using previously saved settings. The command line parameter “/s” may be used to initiate silent running. This is useful for automated imports that are scheduled to run on a regular basis.

When configuring the HR Integration Utility to run silently (saving the configuration to the ini), ensure you do that as the user who will be running the task. This is required so that the password saved to the ini file can be decrypted properly for the execution. If this is not configured properly, the task will fail.

Example: C:\Program Files (x86)\Cority\HR Integration Utility.exe /s
