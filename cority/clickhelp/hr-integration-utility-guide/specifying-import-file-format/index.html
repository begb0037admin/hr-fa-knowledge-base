Specifying Import File Format

Before running the HR Integration Utility, you must specify the import file format in one of the following ways:

  1. In the Cority ini configuration file (which resides in the HR Integration Utility installation directory).
  2. After you have opened the HR Integration Utility and clicked ‘Save’, locate the file and append it with a line that uses the following format: importFormat|EmployeeNumber,FirstName,MiddleName,LastName
  3. Through the Cority Import Utility:
  1. Log in to the HR Integration Utility.
  2. In the Data Tables view, select Administrator > Import Utility > Employees.
  3. Using the Available Fields, set up the Selected Fields to match the import format (columns) you will be using in the import file. Note: You can skip an import file column by using the Add Filler option.
  4. Select Actions > Save Format.  This allows you to import files that follow this format.

Important: The format you specify must match the format of your import file; the EMPLOYEENO column is required.

Note: If an import format is specified in your configuration file, that format will take precedence over one specified in the Cority Import Utility. Also, if you update the import format in your configuration file, you must restart the HR Integration Utility for the changes to be reflected.
