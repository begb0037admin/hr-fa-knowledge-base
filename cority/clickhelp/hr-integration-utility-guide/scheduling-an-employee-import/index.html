Scheduling an Employee Import

The HR Integration Utility allows administrators to automate the import task with scheduling utilities such as Scheduled Tasks (Windows workstations/servers). Administrators can schedule the import to run once or to automate reoccurring imports at any date and time.

Important: If you have updated the HR Integration Utility web client from GX2t or earlier to GX2u or later, you must update the Program/Script field of your scheduled task to reference the new executable filename (.exe), because that filename changed.

  1. Select Start > Programs > Accessories > System Tools > Task Scheduler.
  2. Select Create Basic Task. The Create Basic Task Wizard will open.
  3. Enter a name and description (optional) for the task.

  1. Click Next.

  1. Select when you want the task to start.

  1. Click Next.
  2. Select the start date for the task and specify how often the task should recur.

  1. When asked what action you want the task to perform, select ‘Start a program’.

  1. Click Next.
  2. Click Browse. Select the ‘Cority Import Program’ and click Open.

  1. In the ‘Add arguments (optional)’ field, enter “/s”. This denotes silent or automated execution of the command.

  1. Click Next.
  2. Click Finish.
