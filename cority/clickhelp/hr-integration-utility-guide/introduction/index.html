Introduction

The Cority HR Integration Utility is a standalone utility that allows you to import employee demographics information from a separate HR system using a comma-delimited export file. The HR Integration Utility can be run interactively or silently as a scheduled task.

The HR Integration Utility can be scheduled to execute automatically on the Windows operating system using any scheduler (Scheduled Tasks, for example).
