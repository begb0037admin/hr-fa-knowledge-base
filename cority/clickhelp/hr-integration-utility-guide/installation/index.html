Installation

  1. If you have installed any previous version(s) of the HR Integration Utility , uninstall the older version before proceeding with this new installation.
  2. Install Microsoft .NET Framework 4.8. The download and instructions are available from the Microsoft website.
  3. Extract the Cority zip file or the HR Integration Utility zip file and locate the HR Integration Utility folder.
  4. Open the folder and run the setup by double-clicking the HR Integration Utility msi icon. The HR Integration Utility - InstallShield Wizard will open.
  5. Click Next.

  1. Select a destination folder and click Next.

  1. Click Install to begin the installation, or Back to review or change your installation settings.

  1. The InstallShield Wizard will begin installing the HR Integration Utility. This process may take several minutes.

When the installation is complete, click Finish to exit the InstallShield Wizard.
