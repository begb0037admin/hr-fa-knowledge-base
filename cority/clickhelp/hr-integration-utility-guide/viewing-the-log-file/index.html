Viewing the Log File

To view the results/statistics of an import run or to view any error messages that may have occurred during the import, you can view the log file by clicking on View Log. The log file, HR Integration Utility.log, will be saved in the same directory as HR Integration Utility.exe.

By default, the path is C:\Program Files (x86)\Cority\HR Integration Utility.log.
