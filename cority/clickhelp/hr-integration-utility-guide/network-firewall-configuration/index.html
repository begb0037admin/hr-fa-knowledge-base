Network/Firewall Configuration

Communication with Cority-hosted sites is always done through https (SSL) to ensure that all data is encrypted during transport. Given that, the HR Integration Utility configuration file must contain Security Mode= “Transport”, and client firewalls should allow access through port 443.

On self-hosted sites, it is possible to use standard http without SSL, which requires access to port 80 unless otherwise configured by the web administrator. In this case, the HR Integration Utility configuration file must contain Security Mode=“None”.

Important: The HR Integration Utility does not explicitly encrypt the data. Instead we rely on transport level encryption through https/SSL. All our production sites enforce the use of SSL so that the HR Integration Utility cannot send data unencrypted.
