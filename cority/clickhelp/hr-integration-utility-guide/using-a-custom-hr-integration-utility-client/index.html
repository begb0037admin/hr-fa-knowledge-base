Using a Custom HR Integration Utility Client

It is possible to write your own import client instead of using the client provided by Cority.

The provided HR Integration Utility client imports records into Cority via the HR Integration Utility Web Service, which is available to use in your own custom clients.

See the HR Integration Utility Web Service API section for more details.
