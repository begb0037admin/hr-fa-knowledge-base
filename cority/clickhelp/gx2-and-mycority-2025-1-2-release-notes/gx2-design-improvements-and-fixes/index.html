GX2 Design Improvements and Fixes

The table below lists the design improvements and fixes we have made in the GX2 2025.1.2 release. The items are organized by component and the components are arranged in alphabetical order.

Item #Component(s)ReportedDescription
CCC-21531Business Intelligence - Query Builder, Advanced DashboardN/A

For a Query Builder report using the Action entity, the user can now successfully add GDDLOFB columns, with or without a Finding join, switch between the Build, Visualize, and More Settings tabs multiple times, and navigate to Advanced Dashboard and back, without encountering any loading issues.

 

CCC-21415Business Intelligence - Query Builder, Advanced DashboardN/A

Query builder reports and Advanced Dashboards configured with flex fields prior to release 2025.1.1 now all function as expected.

 

CCC-21271Business Intelligence - Advanced DashboardN/A

An issue that was causing indicators to be missing and/or obscured when an Advanced Dashboard is exported to PDF has been fixed.

 

CCC-20789Business Intelligence - Query Builder, Report Writer, Advanced Dashboard2024.3.1

For applicable Query Builder and Report Writer reports, the 'Export to PDF' action now generates results successfully without timing out and with the expected data. Also, Advanced Dashboards with charts and tables drawing from such reports and with records limited to 10,000 by system setting now function as expected.

 

CCC-20159Business Intelligence - Scheduled ReportsN/A

With the system setting 'Wrap report columns with high character count' selected, after a scheduled report configured with grouping and containing a URL column is run, if exported to PDF, the URLs in the report will no longer get truncated.

 

CCC-5904Business Intelligence - Query BuilderN/A

When the 'Employee Number' field is prohibited from a role, for users with that role its value will now be masked where expected (Query Builder, Questionnaires, Findings & Actions, etc.).

 

CCC-20369Business Rules - Email ActionsN/A

For properly configured business rule email actions, the CC recipients functionality is now working as expected.

 

CCC-20955Environmental - Chemical ManagementN/A

Reset Last Call Date' now resets the 'Refresh Requirement Last Call Date' instead of the 'Update Applicability Last Call Date', as expected, so now no longer adversely affects Enhesa content updates.

 

CCC-20971Environmental - ComplianceN/A

If a user creates two Enhesa Applicability Assessments and then executes the 'Get Applicable Regulations' action for them, one after the other, the second will now have the correct number of questionnaires linked.

 

CCC-19690Environmental - ComplianceN/A

The EnableCorsDynamicDomains setting is now at the GX2 site file level, which allows client organizations to set their own domains.

 

CCC-19446Environmental/Safety - IncidentN/A

For extracting a single Safety or Environmental 'Incident' record, a GET RESP API call will now function properly.

 

CCC-21330ErgonomicsN/A

The 'Enable Motion Capture' option is now only available for Ergonomics ‘Risk Assessment Entry' layouts.

 

CCC-20919Industrial HygieneN/A

On an IH Lab Requisition, a user with the proper security configuration can now open a sample, add an agent (results, with accompanying information) successfully, and save without encountering an unexpected error.

 

CCC-3249Industrial HygieneN/A

On a Risk Assessment record, if additional current and/or future controls are deleted, that will now be reflected as expected in a properly configured Query Builder report that uses the RecordHistories.RAS.IHRisk
AssessmentControlEntryRecordHistory entity.

 

CCC-21043Occupational Health - Case ManagementN/A

For Case record, if configured properly in the Case Type look-up table, when the user selects a certain Case Type, the Case Status will now auto-populate and the user can then successfully save the record.

 

CCC-21033Occupational Health - Clinic VisitN/A

From the Notes sublist of a Clinic Visit record, when working on a note, the Add Note look-up selector now functions successfully and as expected.

 

CCC-21492Occupational Health - Medical MonitoringN/A

After importing Quest drug testing results, when reprocessing in the log, the functionality for changing the employee number on one or more records now works properly.

 

CCC-21145Occupational Health - SEGsN/A

When recall activities for a SEG are end-dated, they will no longer affect the Clearance Expiration Date calculation for that SEG.

 

CCC-19938Platform Administrator - Email ActionsN/A

If the employee's language is different (for example, German) than the supervisor's (for example, English), a business rule with email action that is configured properly to do so will now send emails in each language.

 

CCC-20075Platform Administrator – Importing N/A

In the Import Utility, for the Tree Master, there is a new 'Rebuild Tree Lineage' action. The action is for rebuilding the tree lineage based on parent relationship(s) if errors occurred while performing Tree inserts/updates through import.

The user's role must be granted the treemaster.rebuildtreelineage security action to use this feature.

 

CCC-9781Platform Administrator - LayoutsN/A

When editing a look-up table layout (for example, 'Incident Investigation Email'), if the user adds a default value for any applicable field, that value will now be retained on Save and for subsequent edits of the layout.

 

CCC-19738Platform Administrator - Organizational TreesN/A

Historical Organizational Trees now respect the 'Short Date Style' system setting value.

 

CCC-18994Platform End-UserN/A

On a custom layout with a Text Area field, if 'Column Span' for the field is 1 and 'Row Span' for the field is increased, that will no longer add additional, unexpected space around the field.

 

CCC-19312Platform - Interfaces2024.2.2

In the REST API, for the TreeMaster endpoint, POST and PUT calls now function as expected.

 

CCC-5465QuestionnairesN/A

When completing a questionnaire in the Clarity theme, with the 'Render Updated Questionnaire Response in Clarity' system setting selected, errors will now be called out in red on a collapsed section that has been expanded.

 

CCC-21282Safety - Compliance Management, EnhesaN/A

On an Applicability Assessment, with a large number of questionnaires selected, the 'Create Compliance Audit' action will now function successfully and without generating any unexpected errors.

 

CCC-17614Safety - Incidents, ContractorsN/A

On a Safety 'Incident' record, if the 'Contractor' or 'Contractor Project' field has multiple values enabled, the associated picklist will now open without generating any unexpected errors.
