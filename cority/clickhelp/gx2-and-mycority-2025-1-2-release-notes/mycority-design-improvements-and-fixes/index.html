myCority Design Improvements and Fixes

The table below lists the design improvements and fixes we have made in the myCority 2025.1.2 release. The items are organized by component and the components are arranged in alphabetical order.

Item #Component(s)ReportedDescription
CCC-21459End-UserN/A

Where applicable, the Scan Code, Near Me, and Offline links are now completely visible when the display resolution is set to 1280 x 768 and the browser zoom is 200%.

 

CCC-21196End-User - AccessibilityN/A

Where applicable, to improve visibility, the contrast ratio for text and its background has been increased.

 

CCC-21152End-User - AccessibilityN/A

For accessibility, effort has been made to ensure labels (button names, column headings, hover-overs, etc.) are descriptive and unique.

 

CCC-10781End-User - DocumentsN/A

Where applicable, when using the Attach Document (or similarly labelled) button, if you remove an attachment, before or after saving the record, the attachment will now be removed entirely, as expected.

 

CCC-13325End-User - PerformanceN/A

When concurrent users are logged into GX2 and a myCority user is on a record open in a custom layout that has a higher number of UDFs (10 or more) configured with radio buttons, the record will continue to display without generating an unexpected error and there will not be any performance issues.

 

CCC-6521Occupational Health - AbsencesN/A

When configured to be, 'Absence To-Dos' are now accessible from the myCority Home screen.

 

CCC-15975Occupational Health – Case ManagementN/A

Case Supervisor messages can now be used successfully, without generating any unexpected errors, to send messages to the supervisor.

 

CCC-20085Permit to WorkN/A

On a 'Work Permit' record, for a custom 'Permit to Work Risk' sublist view that has the Permit column, when in Inline Edit mode, the value for any Permit field will now be correct.

 

CCC-20720Safety Incident, Why TreeN/A

For a Fire/Explosion investigation, on the 'Cause Analysis' tab, when the user populates a cause using the Why Tree then clicks the Star button, the cause will now auto-populate 'Root Cause'.

 

CCC-11970Wellness, Vital SignsN/A

A user with the proper security configuration can now open a Wellness (Clinic Visit 'Vital Signs') indicator without encountering any unexpected errors.
