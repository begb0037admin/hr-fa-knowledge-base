CCC-220Occupational Health - Employee CareN/A

The ePrescription module has been enhanced to comply with the latest Surescripts updates.

Cority uses the Surescripts clinical network to connect ePrescribers to pharmacies, enabling ePrescribers to place and manage electronic prescriptions.

The changes to the ePrescription module include:

  • Updates to Cority’s Surescripts relay so that it can use the new URLs provided by Surescripts, manage SPI-to-client mapping in a central database, and continue to control (add, update, and disable) provider location transactions.
  • Updates to Cority’s ePrescription and directory services models and code to ensure they conform to the new NCPDP SCRIPT 2017071 structure and namespace.
  • An upgrade to the newer Surescripts protocols.
  • Minor updates to the ‘eRx Renewal Request’ workflow.
  • A new ‘eRx Change Request’ workflow.
  • The implementation of mTLS authentication between Cority and Surescripts.
  • Recertification with Surescripts and Dr. First.

This will ensure that the Cority ePrescription module is in sync with the latest Surescripts updates and functioning efficiently.

CCC-5311
Platform - Interfaces
N/A
Previously, the Cority Data Integration Engine (CDIE) client took care of the entire batching and importing process, and that will remain the case if you provide a batch size from 0 - 100.
If, however, you are using the CDIE to import a file into a Cority data table or look-up table and you provide a blank (null) batch size or batch size greater than 100, now the CDIE will instead pass the full file to the server, and the server will process the import.
  • For such batch sizes, the CDIE is now only responsible for passing the file to the server. The server is then responsible for the batching and importing process.
Once the CDIE successfully passes the file to the server, the CDIE log file will reflect that the file has been passed and recommend you check the results in the Cority Process Status and Log.
In the Process Status and Log, the administrator will be able to review the status of the records being imported.
  • The overall import log record will show a "Started" date and time, and when the overall import is finished, a "Completed" date and time.
  • During the process, you can click the username for the overall import record to display the status for each individual record. All records being imported will start with the Unprocessed status. Throughout the import process, each record's status will change from Unprocessed to Added, then to either Updated or Rejected.
