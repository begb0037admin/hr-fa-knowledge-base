myCority Design Improvements and Fixes

The table below lists the design improvements and fixes we have made in the myCority 2021.2.2 release. The items are organized by module and the modules are arranged in alphabetical order.

Item #Component(s)ReportedDescriptionUpdated / Created
CCC-4929Business IntelligenceN/A

For a dashboard with several time datasets, the data for all of the datasets will now be displayed.

v2021.2.2
CCC-1783Business Intelligencev2020.3.0

A myCority user can now successfully generate the Medical Records Report, regardless of the date format used.

v2021.2.2
CCC-4371Event ReportingN/A

When the user drags and drops a document to an event report in myCority and then submits the event report, the Supervisor can now access the document in all expected locations.

v2021.2.2
CCC-3721Event ReportingN/A

Documents uploaded to an event report using myCority are now also available where applicable in Cority.

v2021.2.2
CCC-4737Findings & ActionsN/A

Assigned actions that have been deleted from the Cority platform will no longer be accessible in myCority.

v2021.2.2
CCC-4731IncidentsN/A

When updating a Safety 'Incident Self Report' in myCority, business rules configured to fire on an update to a Safety 'Incident' record will no longer fire.

v2021.2.2
CCC-5053Platform - End Userv2021.2.0

When the user creates a questionnaire that is configured to have a header, field values will now save as expected.

v2021.2.2
CCC-4977Platform - End UserN/A

The search functionality within 'My Resources' now functions as expected.

v2021.2.2
CCC-4835Platform - End UserN/A

A custom layout that has one or more empty placeholder fields no longer causes an error when the user is trying to log into myCority as a guest.

v2021.2.2
CCC-4356Platform - End UserN/A

myCority now fully supports the FedRAMP security compliance framework.

v2021.2.2
CCC-1493Platform - End Userv2020.3.0

While offline, the 'Copy' action can now be used successfully for records downloaded from 'My Tasks'.

v2021.2.2
CCC-30Platform - End User, DocumentsN/A

An action assignee can now attach verification documents to an Action record. For this purpose, a new 'Attach Documents' option has been added to myCority Action layouts.

v2021.2.2
