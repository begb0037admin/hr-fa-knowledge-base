Summary of Industrial Hygiene Enhancements

The table below contains a design improvement we have made in the Industrial Hygiene cloud. Descriptions of any larger features follow the table.

ItemComponent(s)Description
CCC-21105Monitoring

The following new fields can now be added to custom versions of Monitoring layouts:

  • 15 new numeric UDFs, numbered 21 through 35
  • 5 new alphanumeric (nvarchar, 1000 characters) UDFs, numbered 1 through 5
  • 10 new date/time UDFs, numbered 1 through 10
  • 5 new look-up table UDFs, numbered 3 through 7

 

Each of the look-up table fields has a corresponding new look-up table. The look-up tables each have a default list view and layout with appropriate columns/fields, and each function as a typical GX2 look-up table.

 

For each new field, the equivalent column can be added to custom Monitoring list views.

 

The fields can be used in business rules, display rules, and workflows, can be reported on using Query Builder and Report Writer, and are available in the Equation Library.

Each of the new fields can be prohibited from user roles.

 

Values for the fields can be added or updated through import (Import Utility or REST API).
