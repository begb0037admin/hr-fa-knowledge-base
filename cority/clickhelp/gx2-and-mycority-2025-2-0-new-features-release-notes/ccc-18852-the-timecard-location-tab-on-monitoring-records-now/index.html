CCC-18852: The Timecard Location tab on Monitoring records now links to the Equation Library calculation engine

Opt-In

This enables IH users to use GDDLOFB locations from the Timecard module to create equations and perform corresponding calculations.

The changes made to support this include:

  • A new IH system setting ‘Dimension to be used for the Timecard Location field’ has been added. This sets the dimension you want used for linking Timecard Location records to an associated Monitoring Sample record. It is recommended this dimension be treated as a look-up table. The options provided are the GDDLOFB tree dimensions. Global is the default option.
  • For use in business rules, ‘Timecard Location’ is a new entity.
  • There are new business rule methods in the Timecard, Timecard Location, Monitoring, and Monitoring Results sublists for creating the items the user views on the Timecard Location tab that match the desired sample date and GDDLOFB field as selected in the new system setting. These will handle any changes (updates, insertions, or deletions) to the Location and Date fields after the creation of either the Timecard or the Monitoring record.
  • Timecard Locations are now exposed to the Equation Library, so all fields from Timecard Locations can now be selected within the Equation Library calculation engine. Also, the ‘Equation Set’ field has been added to Timecard Location.
  • The new Timecard Location tab (sublist) can be added to custom versions of applicable IH Monitoring Sample layouts.
    • The tab has a default list view with applicable columns.
    • The tab has a ‘Run Equation Set’ action that will force all linked timecards on the Timecard Location tab to calculate. The tab also provides the ‘Export to Excel’ and ‘Show Record History’ actions.
    • The existing Timecard sublist for Timecard SEGs has been renamed Timecard SEGs.

  • New Timecard Location calculated fields (1 through 10) are now available for adding to custom versions of the Timecard Location layout. These fields will be used for Equation Library calculation outputs.
    • All calculated fields within the Timecard, IH Sample, and IH Sample Results modules display the ‘Equation Calculation’ icon. When a user clicks the icon, the equation associated with that field will be displayed, if applicable. When the user clicks the equation itself, the 'Equation Library' will open for the user to make any changes to it, if necessary.

For more information on using the 'Equation Library' for calculations, see CCC-12020 in the GX2 2024.1.0 New Features Release Notes document and the GX2 User Guide. For more information on working with business rules or look-up tables, see the GX2 User Guide.
