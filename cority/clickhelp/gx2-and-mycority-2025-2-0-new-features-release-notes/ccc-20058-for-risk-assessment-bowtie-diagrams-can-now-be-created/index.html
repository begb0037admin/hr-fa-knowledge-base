CCC-20058: For risk assessment, bowtie diagrams can now be created

Opt-In

Bowtie diagrams are configured in GX2 and edited in Bowtie Master.  

To create bowtie diagrams:

  • The new safetybowtie.bowtieaction security action must be assigned to the user's role.  
  • The new Bowtie sublist must be added to a custom version of the Safety 'Risk Assessment' layout. In the Bowtie sublist, a user can create, edit, or delete bowtie diagrams.  

When a user creates a new bowtie diagram, they will:

  1. Enter a Top Event and choose a Hazard.
  2. Click Save.
    This will enable the 'Start Bowtie' button. Once saved, the Top Event and Hazard cannot be changed.
  3. Click Start Bowtie.

The user will then be taken to Bowtie Master where Barriers, Threats, Consequences, and Escalation Factors can be dragged and dropped to create the diagram. Metadata can be added to provide additional information for each item in the diagram.  

Once the bowtie diagram is configured, the user will click 'Update Diagram Image' within Bowtie Master and then in GX2, click 'Sync Bowtie'. This will bring the diagram image into GX2 and list the added Barriers, Threats, Consequences, and Escalation Factors in their respective sublists. The metadata is not listed in GX2.

If additional changes are made in Bowtie Master, the user will have to click 'Update Diagram Image' again and then resync again in GX2.

Bowtie diagrams can also be added to safety documents.

To use this functionality, a subscription to Bowtie Master is required. For more information about that, contact your Cority representative.
