Summary of Safety Enhancements

The table below contains design improvements we have made in the Safety cloud. The items are organized by component and the components are arranged in alphabetical order. Descriptions of any larger features follow the table.

ItemComponent(s)Description
CCC-10528 and 10524Compliance Management

The following new fields can now be added to custom versions of Actions (Corrective Actions) layouts, in all clouds that support them:

  • 4 new alphanumeric (nvarchar, 8000 characters long) UDFs, numbered 4 through 7
  • 10 new look-up table UDFs, numbered 1 through 10

 

Each of the look-up table fields has a corresponding new look-up table. The look-up tables each have a default list view and layout with appropriate columns/fields, and each function as a typical GX2 look-up table.

 

For each new field, the equivalent column can be added to custom Actions list views.

 

The fields can be used in business rules, display rules, and workflows, and can be reported on using Query Builder and Report Writer.

 

Each of the new fields can be prohibited from user roles.

 

Values for the fields can be added or updated through import (Import Utility or REST API).

 

CCC-21250Event Reporting – myCority

In myCority, when an Event Report with the Accident Jurisdiction field is downloaded and the user is offline, if the user makes changes to the Event Report that trigger a display rule, the Accident Jurisdiction field will no longer be affected if the display rule is not configured to alter it.

 

CCC-19432Event Reporting – myCority

In myCority, an embedded questionnaire can now be completed while offline. This is beneficial because questionnaires are used to obtain additional, critical information not collected through the Event Report layout.

An automatic or manual download of an Event Report template or in-progress Event Report will now include any associated, embedded questionnaire(s).

While offline, the embedded questionnaire will now function as if online. It can be completed offline and then uploaded/submitted when back online.

 

CCC-16840Event Reporting – myCority

For the Event Reporting, Sampling, and Waste solutions, for a form or record downloaded in myCority, any filter display rules associated with the corresponding entity will now also download so that they can execute offline.

When the display rule criteria are met, the rule(s) will execute as expected dynamically (without save).
