Summary of Platform Enhancements

The table below contains design improvements we have made to the GX2 Platform. The items are organized by component and the components are arranged in alphabetical order.

ItemComponent(s)Description
CCC-14439Views and Layouts

For creating or cloning a layout or list view, or updating an existing custom layout or list view, the editor now provides Administrators with the ability to add or remove actions from the Actions menu.

 

When cloning an existing view, the Available Actions will be copied to the clone view.  When creating a new view, the Available Actions list in the editor will remain empty until actions are added. This is something to consider, if as an Administrator, you want to be sure certain actions are not made available to end users (for example, you might want to hide the out-of-box views using role security).

 

Note: There is no option to make these actions available as buttons.

 

Actions prohibited from the user's role will remain unavailable.

 

This functionality works similarly to adding fields/columns using the editor.

This does not apply to myCority layouts or list views.

 

For more information on how to create, clone, or update layouts or list views, see the GX2 User Guide.

 

CCC-15167 and 14441Findings & Actions

The following new fields can now be added to custom versions of Findings layouts, in all clouds that support Findings:

  • 2 new alphanumeric (nvarchar, 8000 characters long) UDFs, numbered 7 and 8
  • 8 new look-up table UDFs, numbered 1 through 8

 

Each of the look-up table fields has a corresponding new look-up table. The look-up tables each have a default list view and layout with appropriate columns/fields, and each function as a typical GX2 look-up table.

 

For each new field, the equivalent column can be added to custom Findings list views.

 

The fields can be used in business rules, display rules, and workflows, and can be reported on using Query Builder and Report Writer. Each of the new fields can be prohibited from user roles.

 

Values for the fields can be added or updated through import (Import Utility or REST API).

 

CCC-18984Infrastructure

GX2 is now supported on Microsoft Windows 11.
