Summary of Ergonomics Enhancements

The table below contains design improvements we have made in the Ergonomics cloud. The items are organized by component and the components are arranged in alphabetical order. Descriptions of any larger features follow the table.

ItemDescription
CCC-21621

The SCORM 'Completion Fix' job now counts the number of records it repairs and logs that in the Event Log.

One entry is created in the log for each Training record that is updated. Each entry is marked: Online Training Record Completion Updated.

 

CCC-20554

The LU_OES_PersonalRiskHelpText look-up table has been added to the Import Utility so that an Admin can import text into its fields. All of its available fields are included.

 

CCC-19543

When an employee is removed from or leaves a group/team, his or her incomplete online training sessions can now be inactivated.

This will prevent duplicate sessions being created when the employee is added to another group/team that uses the same course(s).

To support this, an Inactive check box has been added to the Details section of all Online Training Sessions. When the check box is selected for a session, this functionality will apply to that session.

Any risk data recorded from a self-assessment is retained, even if the session is inactivated prior to completion because the user has been removed from the group/team.

Inactivated sessions are not displayed in myCority.

The column corresponding to the Inactive check box can be added to applicable list views.
