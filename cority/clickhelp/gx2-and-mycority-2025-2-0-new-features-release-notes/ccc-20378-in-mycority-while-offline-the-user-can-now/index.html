CCC-20378: In myCority while offline, the user can now complete subquery type questions as well

Opt-In

While offline, for any download of an inspection and/or questionnaire (including a download of all templates, a manual download of an Event Report with an embedded questionnaire, etc.) that has one or more subquery type questions, an end-user can now complete the subquery type questions as well.

The user will be able to fill out and submit the downloaded inspection or questionnaire while offline, in the same way as if online.

Note: If a subquery used by a question has been edited in GX2, the user can simply click the Ellipses then the Update button to download the updated question.

This functionality has the following limitations:

  • Findings & Actions cannot be auto-created based on question responses while offline, so if the user clicks Submit while offline, the Inspection will now successfully submit even if Findings & Actions are to be created, without providing the opportunity to assign them in myCority before the submission.
  • Subquery results for a subquery type question will not be updated until the user is back online.
  • The number of values returned in a subquery cannot be more than 100.
  • The number of subquery question types cannot be more than 10 across all downloaded questionnaires.
  • The total number of questionnaires available offline cannot exceed 100.
  • The full search in a look-up selector field will not work, however the smart search will. Therefore, a look-up can be used for questions with a limited number of options. Note: The length of the options list shown will vary depending on the size and resolution of the device's screen.
  • An informative error will be generated if there are changes to any questionnaire question after the initial download and before an auto-submission.
