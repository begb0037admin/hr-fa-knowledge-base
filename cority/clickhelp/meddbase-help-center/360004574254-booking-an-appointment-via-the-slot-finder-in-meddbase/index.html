What is the context?

There are many ways to book appointments within Meddbase, using advanced search tools to ensure you get the best appointment for your patient.

One of the ways to book an appointment is via the Slot Finder. 

What is the purpose of the article?

This article will walk you through the process of booking an appointment via the Slot Finder in Meddbase, as well as discuss the options during the booking process. 

This article will cover the following topics:

  • Introduction
    • Booking via Slot Finder from the Patient Record
    • Booking via Slot Finder from the Start Page

Introduction

The Slot Finder tool is used to search for the next available slot in your clinic so that bookings can be made quickly without having to search for free space in the side-by-side schedules. 

Click here for details on booking via the Side-by-side-Scheduler.

Furthermore, there are specific settings for the Slot Finder in Admin > Configuration > Booking. Click here for more details.

Booking via Slot Finder from the Patient Record

  1. From the Start Page click Find Patient.
  2. Search for the patient using the available search criteria and click on the search result.
  3. Click Book an appointment (via slot finder).
  4. In the Parameters section, you can specify conditions to receive accurate available appointment slots:
    • After - this field allows defining the earliest date for result displayed.
    • Results - this dropdown allows specifying how many results would you like to see.
    • Creditor - this dropdown allows changing the Creditor. Only Internal companies can be Creditors. The chamber company is typically the Default Creditor. Click here for more details.
    • Payer - this dropdown allows changing the Payer (Debtor) and accessing different Charge Band(s) for this booking. This will default to the Patient's Preferred Payer selected on their Personal Details. Click here for more details.
    • Charge Band - this dropdown allows selecting the Charge Band to be used for this booking. Click here for more details.
    • Case/auth - this field allows associating the booking to an existing Case or creating a New Case. Furthermore, you can type in/select an Authorisation Code. Click here for more details.
    • Type - this dropdown allows selecting the Appointment Type for this booking available from the currently used Charge Band.
      Once the Appointment Type has been selected, more conditions become available:
    • Module - this dropdown allows adding an available module to the booking.
    • Add/modify services - clicking here opens the Add Service dialog where you can add services to the booking.
    • Referral letter and details - clicking here opens a page that you can use to search for the referring clinician or clinic. You can also attache a referral letter here if there is one.
    • Specialism - this dropdown allows you to specify the Specialism of the clinicians you wish to see available slots for.
    • Role - this dropdown allows you to specify the Role Group of the clinicians you wish to see available slots for.
    • Sex - this dropdown allows you to specify the Sex of the clinicians you wish to see available slots for.
    • Time of Day - this dropdown allows you to specify AM or PM to narrow down available slots you wish to see.
    • Duration - this dropdown allows you to specify a duration to narrow down available slots you wish to see. The 'source of truth' for the available slot search result can be set in Admin > Configuration > Booking. Click here for more details.
    • Distance - this dropdown allows you to specify the vicinity of the Site the available Slots you wish to see should be from:
      • Patient's home address - as per the Patient's Details page
      • Patient's billing address - as above
      • Patient's employer address - as per the patient's Employer Company Details page.
      • Custom address - this option allows specifying a custom address in a pop-up dialog window.
    • Priority - here, you can set the slot search priority to Site or Clinician.
  5. If needed, click Add/modify services.
  6. Click the available slot you wish to book and click Proceed.
  7. Review the booking, make changes if needed and click Save to book the appointment.

Booking via Slot Finder from the Start Page

  1. From the Start Page click Slot Finder on the Clinician tile.
  2. Fill in your patient search criteria and click Search (you may also be presented with Previous Search Results for quick access; if the patient doesn't exist in the database, click Add patient).
  3. As described above, in the Parameters section, you can specify conditions to receive accurate available appointment slots.
  4. Select the Appointment Type to book and, if needed, specify additional conditions.
  5. If needed, click Add/modify services.
  6. Click the available slot you wish to book and click Proceed.
  7. Review the booking, make changes if needed and click Save to book the appointment.
