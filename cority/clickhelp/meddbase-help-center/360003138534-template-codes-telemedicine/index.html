What is the purpose of the article?

This article outlines the different codes that can be used to include Telemedicine information in templates.

List of template codes for Telemedicine and a related description

Below is a list of template codes for Telemedicine and an associated description for each item.

The following codes can be used within the various Telemedicine related templates found under Admin > Configuration > Telemedicine. 

CodeDescription
{Patient.X}Patient's details; X can be replaced by any code relating to patients - see below under Patient template codes
{Appointment.X}Appointment details; X can be replaced by any code relating to appointments - see below under Appointment template codes
{Doctor.X}Details of the appointment's primary doctor; X can be replaced by any code relating to doctors
{Appointment.TelemedicineConnection}Displays a link for joining the telemedicine consultation

 

Patient Template Codes

To find patient template codes, please review the article Template Codes - Patient. 

Appointment Template Codes

To find appointment template codes, please review the article Template Codes - Appointment. 

Doctor Template Codes

To find doctor template codes, please review the article Template Codes - Appointment. 

Additional Information

The codes above can be used within the various Telemedicine related templates found under Admin > Configuration > Telemedicine.
