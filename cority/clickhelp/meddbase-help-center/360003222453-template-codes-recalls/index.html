What is the purpose of the article?

This article outlines the different codes that can be used to include Recall information in templates.

List of template codes for Recalls and a related description

Below is a list of template codes for Recalls and an associated description for each item.

CodeDescription

{Patient.X}

For example: {Patient.Surname}

Any details about the patient in question; X can be replaced by any code relating to patients, see relevant article on Appointment / Patient Template Codes
{Recall.Due}Date when the recall is due
{Recall.Reason}

Any notes written against the recall

{Recall.CompanyName}

Name of the chamber owner company

{Recall.Services}

Name of the service

{Today}

Date now
