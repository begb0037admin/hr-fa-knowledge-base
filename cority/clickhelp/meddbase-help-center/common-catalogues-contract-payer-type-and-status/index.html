What is the context?

Common Catalogues is an area in Meddbase where dropdown lists are defined. It allows users to customize these lists by adding, updating, or removing elements to meet specific needs.
When creating contracts, payer types and contract status must be configured. The values for both fields can be set in the Common Catalogue. 

What is the purpose of the article?

This article explains how to add a new contract payer type and contract status. 

Using Common Catalogues to add new contract payer type

  1. Navigate to Start Page > Admin > Common Catalogues.

  2. In the Common Catalogues menu, find and expand the folder named Contract Payer Types.

  3. Scroll to the bottom of the list and select New contract Payer Type. 

  4. Enter the payer type. For example, 'Employer'. 

  5. Click the Save button.

Meddbase will automatically assign a unique Id for the new payer type. The newly added payer type now appears as an option when creating a new contract. 

Using Common Catalogues to add contract status

  1. Navigate to Start Page > Admin > Common Catalogues.

  2. In the Common Catalogues menu, find and expand the folder named Contract Statuses.

  3. Scroll to the bottom of the list and select New contract status. 

  4. Enter a new status. For example, 'Pending'. 

  5. Check the Active checkbox to mark this status as being an active contract. 
    When a status is marked as active, it will appear in the Active folder. Statuses not marked as active appear under Inactive.

  6. Click the Save button.

Meddbase will automatically assign a unique Id for the new status. The newly added status now appears as an option when creating a new contract.
