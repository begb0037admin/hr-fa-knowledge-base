What is the purpose of the article?

This article outlines the different codes that can be used to include Profile information in templates.

List of template codes for Profile and a related description

Below is a list of template codes for Profile and an associated description for each item.

Code

Details

{Profile.Username}

Username

{Profile.FullName}

Full Name

{Profile.Email}

Email address

{Profile.Company.Name}

Company Name

{Profile.Company.Link}

Direct Link To Company in Meddbase

{Profile.Company.Address}

Address of Company

{Profile.Company.BillingAddress}

Billing Address of Company

{Profile.Account}

Logged In user's Account Type (i.e. consultant)

{Profile.Account.FullName}

Logged In user's Full Name (i.e. the name in the doctor / non medical staff record)

{Profile.Account.Title}

Logged In user's Title

{Profile.Account.Signature}

Logged in user's signature
