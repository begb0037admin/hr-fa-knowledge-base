What is the context?

Meddbase System Administrators/Superusers with access to the Admin section of the Start Page can view and modify a host of configuration options and settings controlling the behaviour and workflows in the application. Many of the above are configured/controlled via the Configuration section*.

* Access to the Admin section and the ability to add/change configuration and settings are determined by the User's Role Group membership and Security Policy permissions granted. Please refer to the below articles for more details.

Understanding Role Groups - Definitions, related workflows and behaviours

Security policies - Overview

What is the purpose of the article?

This article is an overview of the Admin > Configuration section in Meddbase and links to subsequent articles that explain Configuration sub-sections in detail. 

Admin > Configuration

To access the Configuration section, a permitted User should:-

  1. From the Start Page navigate to Admin.
  2. Click Configuration.
  3. Navigate to the required sub-section as needed

Admin > Configuration - Sub-sections

Below is a list and a brief description of all the sub-sections available under Admin > Configuration. Each sub-section's title is a link to a related article: 

Sub-sectionDescription
Admin > Configuration > Accountancy

This section contains general accountancy settings, as well as external accountancy application integration settings, quotes and invoicing template.

Admin > Configuration > ApplicationThis section contains settings governing static values e.g. start and end of a working day, VAT rate, as well as settings for prompts and other chamber behaviours.
Admin > Configuration > AppointmentsThis section contains settings governing episodes, advanced clinical form behaviour, and meetings.
Admin > Configuration > Booking

This section contains settings governing the slot finder.

Admin > Configuration > Charge bandsThis section contains settings governing V2 Charge Bands.
Admin > Configuration > System featuresThis section contains a feature list allowing activating additional Meddbase features.
Admin > Configuration > ConsentThis section contains settings governing contact consent prompts, display options and defaults.
Admin > Configuration > Documents

This section contains settings governing document upload and download, as well as document preview settings and medical history document display option.

Admin > Configuration > EmailThis section contains automated and manual email settings, as well as SMTP, document sharing and attachment options, and Mail Merge settings (click here for more details on Mail Merge setup).
Admin > Configuration > NotificationsThis section contains settings governing chamber default behaviours of incoming notifications.
Admin > Configuration > Online portal

This section contains settings governing patient portal settings incl. links, general settings, OH and non-OH templates, online payment settings and more.

Admin > Configuration > PACS and RISThis section contains settings governing desktop and web viewers for PACS and RIS
Admin > Configuration > Pathology

This section contains settings governing pathology critical results.

Admin > Configuration > PhysioTec

This section contains API settings for the PhysioTec integration (Click here for more details on PhysioTec setup)

Admin > Configuration > Printing

This section contains settings governing chamber defaults for invoice print preview, as well as page size and margin settings.

Admin > Configuration > ReferralsThis section contains settings governing referral v1 confirmation and referral letter emails, as well as referral record settings.
Admin > Configuration > Schedule and Day sheetThis section contains settings governing schedule and day sheet display options and behaviours.
Admin > Configuration > SMS and FaxThis section contains settings governing chamber SMS and FAX.
Admin > Configuration > Task CheckerThis section contains settings governing triggering automated email and/or SMS messages, as well as iCal attachments and admin task. These messages are triggered for various reasons, incl. Appointment Confirmations, Appointment Reminders, Questionnaire Reminders, and more.
Admin > Configuration > TelemedicineThis section contains settings governing telemedicine integration details, appointment confirmation and reminder messages. (Click here for more details on Telemedicine setup)
Admin > Configuration > AdvancedThis section contains settings governing advanced chamber defaults and behaviours.
