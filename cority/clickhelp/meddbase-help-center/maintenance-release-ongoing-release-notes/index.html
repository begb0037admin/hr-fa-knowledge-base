Maintenance Release Ongoing Release Notes

Here you'll find an up to date list of all changes made during Maintenance releases in 2026. 

The next maintenance release is scheduled for the 3rd of August 2026 at 10:30 PM UK time. 

27th July Release

Main Application

  • Fixed an issue where, when a pathology work item was marked completed, patients were unable to access results.
  • Improved the performance of Clinical Forms and the discharge action. 
  • Added the ability to include a route of administration to Custom Preparations. 

Enterprise API

  • Added a new endpoint for returning user account information. 
  • Added new endpoints for creating, updating, and deleting tracking categories.
  • Updated the appointment booking endpoints to now include a parameter to specify if, when a booking form includes required questions, the appointment can be booked without responses for the required questions. 

20th July Release

Main Application 

  • Added rate limiting to Patient Portal registration from the Portal API. 
  • Fixed an issue where, when patients are moved from a Charge Band with a membership to one without a membership, the membership was not being removed. 
  • Fixed an issue where credits were credits were not appearing correctly in some circumstances. 
  • Added a 'Prescribed By' column to the Prescriptions Report.
  • Fixed an issue where pathology results were not visible in the Patient Portal.
  • Fixed an issue where, when the list of Contracts is very long, it was not possible to scroll down on the page. 
  • Fixed an issue where, when typing a long invoice number in the Payment Match window, an error was occurring. 
  • Fixed an issue where, when advanced payment for a patient was made and an invoice was raised, the patient's name was not appearing in the Match Invoices window. 
  • Updated error messaging when there is a blank date field in the Match Invoices window.

Enterprise API

  • Added new endpoints to amend appointments and appointment items using the Enterprise API. 

13th July Release

Main Application

  • Improved the performance when loading the Session Templates menu.
  • Updated icons and capitalization for patient data fields. 
  • Added the ability to restrict mobile phone number country codes that can be used for signing up with the Patient Portal. 
  • Added the ability to filter pathway triggers by tracking category. 
  • Added the ability to hover over documents to view the entire document name.
  • Fixed an issue where an expiration date was displaying unnecessarily when sending pre-placement questionnaires. 

Enterprise API

  • Added new endpoints for retrieving appointment form responses 

6th July Release

Main Application

  • Added the ability to edit service price in from the Service Picker even when the service is taking a credit or is being populated from a Dynamic Price rule.
  • Fixed an issue where Day Notes were not formatting correctly.
  • Fixed an issue where, when a signature image link is broken, the User's Profile Settings page was not loading. 
  • Fixed an issue where, when a company logo image link was broken, the Company page failed to load.
  • Fixed an issue where the filters panel was not displaying correctly.
  • Updated the Appointments Home page to include the appointment payer(s) and the total price of the appointment.
  • Updated the Appointment History page to now include the Appointment ID. The Appointment ID can also be searched for using the Quick Search.
  • Updated the dispense stock dialogue within a consultation to prevent dispensing stock items that have not been added as appointment services.

Import Layers

  • Fixed an issue where, when importing a new contract, an error was indicating that the user did not have permissions when permissions were set. 
  • Fixed an issue where, when importing a new contract, the optional End Date was showing as required.
  • Improved the performance when importing fields.
