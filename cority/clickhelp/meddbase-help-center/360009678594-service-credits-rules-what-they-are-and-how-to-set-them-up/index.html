What is the context and purpose of the article?

The Service Credits Rule is a billing rule which limits the number of times a service can be applied within a specified time frame. These can be used to offer patients free or discounted service/appointments over a renewable time period.

This article:

  • Explains what a Service Credit Rule is
  • Provides a walk-through example of how to set them up
  • Outlines the features on the Service Credit Rule page. 

What is a Service Credit Rule?

The Service Credit Rule can best be thought of as a 'temporary' Provide Services Rule. So, if perhaps you add a Service Credit Rule that allows 1 'Initial Consultation' within a one year period, it will provide that appointment type to be selected for any patient that has not had an 'Initial Consultation' within the given period. Once a patient has their 'Initial Consultation', this pseudo Provide services rule disappears and the appointment type can no longer be selected.

An important point to note

An important note is that this rule does not work well with an actual Provide Services Rule. For example, if you have your above Service Credit Rule as the first rule on your Charge Band, and a Provide Services Rule below it that does allow 'Initial Consultation'. The Service Credit Rule will be rendered obsolete, as it will not deny services, only not explicitly provide them. So if a patient has an 'Initial Consultation', the Service Credit Rule will no longer provide the appointment, but it won't deny it, which allows the Provide Services Rule to allow the appointment. You often do not want a Provide Service Rule and a Service Credit Rule on the same Charge Band specifying the same appointments/services. 

Types of Credit 

When creating a Service Credit Rule, you must choose a Credit Type to decide how the credits are applied. There are 2 types: 

Fixed Amount of Credits:

  • Patients receive a set number of credits against appointment types in a defined period.
  • Once used, the credit expires until the period resets.
  • Works best when you want to give a specific number of free or discounted appointments per year, month, or week.

For example, a patient is given 5 free Physiotherapy Sessions per year. Once all 5 are used, they cannot book another free session until the year resets.

*Minimum Booking Interval:

  • Controls how often a patient can book a specific appointment type.
  • The interval starts from the date of the last appointment.
  • Credits remain available until used, so patients do not lose them if they skip a period.
  • Works best when you want to space out services like annual health checks.

For example, a patient books a Health Assessment in March 2025. Their next eligible booking is from March 2026. If they do not book in March 2026, the credit remains available until they use it.

How to set up a Fixed Amount Service Credit Rule - A walk-through example

To show you how to set up the feature, we'll step through a walk-through example. It will illustrate how customers who are part of a membership Charge Band can receive 5 free consultations per year. 

Step 1: Create a new Charge Band for the patient group who will receive 5 free appointments

To do this:

  1. Go to Admin > Billing Rules
  2. Expand the record for the company where you want to add the rule
  3. Click on + Add Rule
  4. From the menu that appears, select New Charge Band
  5. In the Charge Band Details screen, add a Name for the Charge Band

The new Charge Band is automatically saved.

Step 2: Create and set up the new appointment type for the 'free' appointments

To do this:

  1. Go to Admin > Appointment Admin
  2. In the Appointment Types list, select the New button
  3. In the New Appointment Type window that appears add in key details (such as Name, Default Duration, Clinical Form, 
  4. Save the appointment type

The new appointment type is saved.


 

Step 3: Create and set up a Price List for the 'free' appointments or services you want to offer

To do this:

  1. Go to Admin > Billing Rules
  2. Expand the record for the company where you want to add the rule
  3. Click on + Add Rule
  4. From the menu list that appears, select New Price List
  5. In the Price List Details screen that appears on the right-hand side, add a Name for the Price List.
  6. In the Service Details panel on the lower right-hand side, select + Show All
  7. Click on +Add next to Appointments
    All available appointments are displayed.
  8. Scroll through to the newly created Appointment type and input the value 0
  9. In the top half of the screen, untick Provide services with prices?

Step 4: Create and set up the new 'Service Credits Rules'

To do this:

  1. Go to Admin > Billing Rules
  2. Expand the record for the company where you want to add the rule
  3. Click on +Add Rule
  4. From the menu list that appears, select New Service Credits Rule
  5. In the Service Credit Details screen add in a Name and First Included Day
  6. Select Enable Periodic Renewal
  7. In the expanded Periodic renewal panel, input a Years value of 1 and a Maximum Periods value of 5
    The value of Maximum period value of 5 will allow a maximum of 5 renewals (for 5 years).
  8. In the Services to Credit panel select + Show All and find the appointment created in Step 2
  9. In the field next to your selected appointment type input the number of credits you want to allocate to one patient for this appointment type in one year.

In this example by populating the box with '5', the patient has access to a maximum of 5 appointments of this type in 1 year.  

Step 5: Add the rules to the membership Charge Band

To do this:

  1. Select the Charge Band created in Step 1
  2. In the Rules panel on the right-hand side click + Add rule...
  3. In the Add Rule To Set dialogue that appears, navigate through the list and select.
    • The Price List created in Step 3.
    • The Service Credit Rule created in Step 4. 


The different features of the Service Credit Rules page are explained below. 

Step 6: Add this Charge Band to any patients who are eligible for these free annual appointments

Now the Charge Band has been created it is possible to link to patients who are eligible. To do this:

  1. Go to Start > Find patient > [Select Patient]
  2. From the patient record select Personal details
  3. In the Account panel set the Billing Company
  4. Select Charge Band created in Step 5
  5. Then Save

Summary

To summarise what we've done - we have created a new Charge Band which we can assign to our patients, this Charge Band will allow that patient to book 5 free appointments per year, the other appointments and services will still be available for them to book (as I have added other default Price Lists into that charge band).
