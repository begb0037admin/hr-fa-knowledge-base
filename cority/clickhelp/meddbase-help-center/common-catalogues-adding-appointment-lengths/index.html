What is the context?

Common Catalogues is an area in Meddbase where dropdown lists are defined. It allows users to customise these lists by adding, updating, or removing elements to meet specific needs.
Meddbase includes a set of standard appointment lengths when booking appointments. Additional appointment lengths can be added and existing ones can be updated or removed within the Common Catalogues area.

What is the purpose of the article?

This article explains how to add a new appointment length for your chamber. 

Using Common Catalogues to add a new appointment length

  1. Navigate to Start Page > Admin > Common Catalogues.

  2. In the Common Catalogues menu, find and expand the folder named Appointment Lengths. 

  3. Scroll to the bottom of the list and select New appointment length. 
    Alternatively, click +Add new after selecting the Appointment Lengths folder.


  4. Enter the new appointment length in the provided field. For example, '50 mins'. 

  5. Click the Save button.

Meddbase will automatically assign a unique Id for the new appointment length. 

The newly added appointment length will now appear as an option in the dropdown menu in any Appointment Length field.
