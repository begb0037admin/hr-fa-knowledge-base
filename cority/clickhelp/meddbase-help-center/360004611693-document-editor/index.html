What is the context?

The Document Editor within Meddbase is a powerful tool designed to enable users to create, format, and edit documents efficiently. It offers a familiar interface for anyone accustomed to working with text editors, ensuring ease of use and flexibility. Whether drafting reports, letters, or notes, the Document Editor streamlines the process of content creation, providing essential tools to maintain consistency throughout documents.

What is the purpose of the article?

The purpose of this article is to provide users with a comprehensive overview of the features available in the Meddbase Document Editor.

What is the Document Editor?

The Document Editor provides users with a comprehensive and intuitive platform for template and document creation and management. Key features include a highly-customisable Styleset tool, which allows users to pre-define the look and feel of various document elements like tables, headings, and formatted text. To learn more, see Document Editor Stylesets.

This ensures uniformity and professionalism in documents. The following section outlines the features available within the Meddbase text editor to help users make the most of its capabilities.

Helpful hints and tips

Tables - Fixed Column width (with CSS styling)

When adding a table to the editor, you may notice the column width changing as you type in the cell.

To stop this from happening, we can fix the layout. To do this, click Source and look for <table style="">


 If you have a set width, after the px, paste in 

 ;table-layout: fixed;
