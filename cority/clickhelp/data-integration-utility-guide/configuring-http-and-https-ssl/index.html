Configuring http and https (SSL)

To use https with the Data Integration Utility web service the web.config must be configured as follows:

  • The end point binding for the service must contain a base address starting with https.
  • The mex end point must use the binding “mexHttpsBinding”.
  • The security mode for the wsHttpBinding should also be set to “Transport”.

Examples:

  • <security mode="Transport"><!--change to "None" for http-->
  • <endpoint address="https://myserver/gx_pr/webservice/Data Integration Utilityservice.svc" binding="wsHttpBinding”
  • <endpoint address="mex" binding="mexHttpsBinding" contract="IMetadataExchange"/>

If you are not using https (SSL), the base address should start with http, the mex binding should be mexHttpBinding, and the security mode should beset to None.
