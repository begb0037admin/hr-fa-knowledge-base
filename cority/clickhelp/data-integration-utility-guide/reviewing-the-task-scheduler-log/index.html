Reviewing the Task Scheduler Log

A log file containing the results if your import will be saved in your  Data Integration Utility program folder. Open the file to see a log of all  Data Integration Utility activity.

You can see the results of your import in the log. The log is saved in the same folder where you installed the program. The log file has the “.log” extension.
