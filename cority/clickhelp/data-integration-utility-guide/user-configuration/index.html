User Configuration

To log into and work with the Data Integration Utility web service, the ‘Data Integration Utility User’ checkbox must be selected in the user's record. The checkbox is not available on the default User layout, but can be added to custom User layouts. Follow the steps below to create a custom layout that has the  ‘Data Integration Utility User’ checkbox, and provide a user with access to the Data Integration Utility web service:

  1. Clone the ‘User’ layout (ML-000002).
  2. Add the ‘MGIP User’ field to the new custom layout.
  3. Open the user’s record using the custom layout.
  4. Select the ‘MGIP User’ check box and save the record.
