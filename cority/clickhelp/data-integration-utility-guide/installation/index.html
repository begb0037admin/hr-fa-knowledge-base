Installation

If you have installed a previous version(s) of the  Data Integration Utility, please uninstall the old version before proceeding to this new installation.

  1. Install Microsoft .NET Framework 4.8. The download is available from the Microsoft website.
  2. Extract the Cority application zip file or the Data Integration Utility application zip file and open the Data Integration Utility folder.
  3. Double-click  Data Integration Utility Setup to run the setup file. The Data Integration Utility - InstallShield Wizard will open.

  1. Click Next.

  1. Click Change to select a destination folder for the Employee Merge Utility, or click Next to use the default folder.

  1. Click Install to begin the installation, or Back to review or change your installation settings.

  1. The InstallShield Wizard will begin installing the  Data Integration Utility. This process may take several minutes.

  1. When the installation is complete, click Finish to exit the InstallShield Wizard.

 

  1. After the program has finished installing, you will need to restart your computer. Once you have restarted your computer, the program will appear in your Windows > Start Menu > Cority folder.
