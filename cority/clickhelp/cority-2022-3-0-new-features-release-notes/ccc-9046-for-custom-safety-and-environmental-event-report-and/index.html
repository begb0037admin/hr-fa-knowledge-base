CCC-9046: For custom Safety and Environmental ‘Event Report’ and ‘Incident’ layouts, additional UDFs are now provided

Opt-In

  • The following new UDFs are now available for adding to custom versions of Safety and Environmental ‘Event Report’ layouts:
    • UDF_Text_19 to UDF_Text_24 – six new text fields
    • UDF_Cost_4 to UDF_Cost_9 – six new cost (number) fields
    • UDFLU17 to UDFLU54 – 38 new look-up table fields, with accompanying, correspondingly named look-up tables and the new ML-000426 look-up table layout
  • When posting an Event Report that has a value for one or more of the new fields to an Incident, the corresponding data will carry over to the Incident record. Note: If posting to an existing incident that has the field already populated, the value in that field on the Incident record will not be replaced/modified.
  • The following new UDFs are now available for adding to custom versions of Safety and Environmental ‘Incident Investigation’ layouts:
    • UDF_Text_19 to UDF_Text_24 – six new text fields
    • UDF_Cost_4 to UDF_Cost_9 – six new cost (number) fields
    • UDFLU17 to UDFLU54 – 38 new look-up table fields, with accompanying, correspondingly named look-up tables and the new ML-000426 look-up table layout
  • The following new UDFs are now available for adding to custom versions of ‘Case Master’ and Incident ‘Injury/Illness’ layouts:
    • UDF_LU_21 to UDF_LU_26
  • Now UDF_LU_1 to UDF_LU_6 and UDF_LU_21 to UDF_LU_26 are shared between the Case Master data table and the Safety and Environmental ‘Incident’ data table and their layouts.
  • All of these new fields can be used for business rules and display rules, and for reporting using Query Builder and Report Writer.
  • For each new field, the equivalent new column can be added to applicable list views.
