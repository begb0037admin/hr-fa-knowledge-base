Summary of Occupational Health Enhancements

The table below lists the smaller design improvements we have made in the Occupational Health cloud. The items are organized by component and the components are arranged in alphabetical order. Descriptions of any larger features follow the table.

ItemComponent(s)Description
CCC-9788Case Management

The following new user-defined fields (UDFs) can be added to custom versions of the 'Case Activity Notes' layouts (ML-000071 and MLs-000071):

  • Six new alphanumeric UDFs (each with a character maximum of 1000)
  • Six new date/time UDFs
  • Six new check box UDFs
  • Six new look-up table UDFs, with accompanying and correspondingly named look-up tables that are categorized under the 'Case Activity' module

The fields can be used in business rule actions, in business rules, and in Query Builder and Report Writer.

Values can be imported into the fields.

The equivalent columns can be added to applicable custom list views.

 

CCC-6257Email Inbox

In Occupational Health, the Email Inbox timeout threshold has been increased to 60 seconds.

 

CCC-8424Employee Care

In the Clinic Visit module, the Medical DOT Exam Report now includes the Medical Examiner's Certificate (MEC, Form MCSA-5876).

 

CCC-7441Employee Care

In the Appointments module, on the Master View, the Scheduling User column now displays 30 characters instead of 15.

Also, the Master View now displays the day of the week beneath the calendar (above the time).

 

CCC-7399Employee Care

On the calendar in the Appointments module, the 'Today' button now populates the current date instead of opening a calendar widget requiring an additional click.

 

CCC-3983Employee Care

Users is now able to generate much larger ‘Medical Summary’ reports without the system timing out.

 

CCC-9748Medical Monitoring

In Occupational Health, the MDGuidelines URL has been updated. It is now app.mdguidelines.com.
