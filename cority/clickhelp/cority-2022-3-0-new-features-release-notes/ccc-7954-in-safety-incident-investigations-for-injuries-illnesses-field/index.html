CCC-7954: In safety incident investigations, for injuries/illnesses, field-level security has been enhanced

Opt-In

  • On the ‘Incident Role’ layout, there are two new check boxes:
    • Can only view employee name if supervisor
    • Can only view employee name if investigating supervisor
  • For a user with the ‘Incident Role’ and the ‘Can only view employee name if supervisor’ check box selected:
    • When filtering by employee on applicable list views or picklists, only the supervisor’s employees will be available for filtering.
    • Filters applied on new custom views will be limited to employees of the supervisor.
    • On all Incident, Injury/Illness records of all employees for which the user is not the supervisor or the employee is not the user’s employee, the employee’s name will be masked. This applies to the records themselves and the records when they appear in lists.
  • For a user with the ‘Incident Role’ and the ‘Can only view employee name if investigating supervisor’ check box selected:
    • When filtering by employee on applicable list views or picklists, only the investigating supervisor’s employees will be available for filtering.
    • Filters applied on new custom views will be limited to employees of the investigating supervisor.
    • On all Incident, Injury/Illness records of all employees for which the user is not the investigating supervisor or the employee is not the user’s employee, the employee’s name will be masked. This applies to the records themselves and the records when they appear in lists.
  • Note: This feature will not mask the employee's picture or date of birth on the Employee Banner or the employee's name on Absences or Notes records. Those fields and sublists must not be used (must be omitted through configuration), if you do not want such information exposed.
  • This feature does not apply to:
    • Events
    • Record History
    • Queries/Reports
    • myCority
    • Older Portal
  • The added security will help protect the privacy of individuals who have been involved in safety incidents.
