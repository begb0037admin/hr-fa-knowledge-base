CCC-6458: For working with letter templates and letters, the text editor has been enhanced

Mandatory

  • The following improvements have been made:
    • The editor is more intuitive, user-friendly, and makes much better use of space.
    • The output (when exporting, printing, or emailing) is formatted with a more modern, professional look.
    • For working with letter templates, the usability and format of the task list (of check boxes) is greatly improved. To leverage the improved task list functionality on letter templates already created, it must be added to them.
  • Note: For an email body template created using the improved editor, there might be formatting/styling discrepancies if it is used in a front-end business rule email. This will be addressed in an upcoming release.
  • For information on working with letter templates and letters, see the Cority GX2 User Guide.
