CCC-8216: The ENHESA workflows have been redesigned

N/A

  • The following enhancements are provided:
    • There is a new ‘Applicability Topics’ look-up table, with accompanying layout.
    • The Applicability Assessment and Audit layouts have a new ‘Applicable Topics’ tab (sublist).
    • The Applicability Assessment ‘Get Applicable Regulations’ action will now populate the new ‘Applicable Topics’ sublist on the assessment with the topics received from the results of the ENHESA assessment.
    • You can now associate the audit questionnaire to one or more regulations / legal requirements.
    • On the Applicability Assessment’s ‘Questionnaire’ tab (sublist), the new ‘Create Compliance Audit’ action will create the audit and populate:
      • The ‘Related Legal Requirements’ sublist on the audit with the regulations associated to the questionnaires selected on the applicability assessment.
      • The ‘Applicable Topics’ tab (sublist) on the audit with all the applicable topics from the questionnaires selected for that audit.
    • Applicability Assessments and Audits list views can now be filtered by applicable topic.
    • You can now create a semi-auto-populated reassessment from an applicability assessment.
    • The ENHESA mapping has been modified to accommodate the new functionality.
    • A number of additional UX improvements help make the overall workflow even more intuitive and user-friendly.
  • For information on working with questionnaires, applicability assessments, audits, or the ENHESA interface, see the Cority GX2 User Guide. The applicable, associated information in that guide will be updated for the 2022.3.0 Production release.
