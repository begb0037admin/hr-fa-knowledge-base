CCC-8428: In the Emissions Inventory module, enhancements have been made to the calculation engine

Opt-In

  • For calculating air emissions for ‘source profile’ related assets, you can now:
    • Execute equations that reference stream information (physical properties, for example) calculated in previous sequences.
      • To support this, new fields have been added to the Equation Builder for the ‘EI Emission Calculation’ entity. The fields are formatted ‘AllRelatedAsset[X].EmissionParameter.Stream.<field>, where X is the sequence number of any Related Asset record for the corresponding Source Profile that has IsSecondarySequence = False, and <field> is the field name.
      • When a ‘source profile’ related asset equation contains fields in that format and IsSecondarySequence = True, the calculation will execute for each record in the DT_EIEmissionCalculation table.
    • Execute equations that reference the chemical attributes of streams calculated in previous sequences.
      • To support this, new fields have been added to the Equation Builder for the ‘EI Emission Calculation’ entity. The fields are formatted ‘AllRelatedAsset[X].StreamComposition.Chemical.<field>, where X is the sequence number of any Related Asset record for the corresponding Source Profile that has IsSecondarySequence = False, and <field> is the field name.
      • When a ‘source profile’ related asset equation contains fields in that format and IsSecondarySequence = True, the calculation will execute for each record in the DT_EIEmissionCalculation table.
