CCC-7798: A number of enhancements have been made to Management of Change (MoC), Inspections/Audits, and Quality ‘Nonconformances’ and ‘Complaints’

Opt-In

  • You can now deactivate and remove Management of Change (MoC) approvers.
  • A new Letters tab can now be added to custom Quality, Safety, and Environmental MoC layouts.
  • An MoC merge table is now available for use within the Letters look-up table.
  • Three new date user-defined fields can now be added to custom Inspection/Audit ‘Assignee/Recipient’ layouts.
  • Three new text, six new date, six new event check box, six new event integer, and six new ‘Employee’ picklist UDFs can now be added to custom Quality ‘Nonconformance’ and ‘Complaint’ layouts.
  • When business rule BR-00158 with accompanying ‘Create findings for root cause’ business rule action (BRA) triggers, the actions it creates will now become linked to the corresponding nonconformance root cause and be visible/available within the Quality ‘CAPA’ module as well as in the ‘Findings & Actions’ list.
    • Also, a message will notify the user that the actions have been created.
  • If the new ‘Allow Quality CAPAs to have multiple actions’ system setting is selected, the user will now be able to link multiple actions to any Quality nonconformance/complaint CAPAs.
  • For document management, a user can now reference a support document with a URL.
    • On the document control (ML-003172) layout, a new ‘Document Location’ field with ‘Local’ and ‘Remote’ options and accompanying ‘Doc. HTTP Link’ field are now provided. By default, ‘Document Location’ is set to ‘Local’ and ‘Doc. HTTP Link’ is disabled. If the user selects ‘Remote’ for the ‘Document Location’ field, he/she will be able to add a URL for the document within the ‘Doc. HTTP Link’ field.
  • For information on working with MoC approvers, custom layouts, merge tables, business rules, or document management, see the Cority GX2 User Guide.
