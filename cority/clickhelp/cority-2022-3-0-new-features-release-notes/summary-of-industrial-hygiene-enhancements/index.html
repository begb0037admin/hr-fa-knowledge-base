Summary of Industrial Hygiene Enhancements

The table below lists the smaller design improvements we have made in the Industrial Hygiene cloud. The items are organized by component and the components are arranged in alphabetical order.

ItemDescription
CCC-9698

Using the Import Utility, an IH user can now import new and/or changes to 'Monitoring Sample' records and corresponding child 'Monitoring Sample Results' records from the same file.

This will automatically link the parent and child records, and reduce the time required to import.

To support this, in each Administrator > Import Utility > Monitoring Sample data table:

  • All 'Monitoring Sample Results' fields have been added to the Available Fields list
  • Any 'Monitoring Sample Results' field can now be added to the Selected Fields list

When adding a 'Monitoring Sample Results' field, any required child field(s) will be added automatically.

When removing a required child 'Monitoring Sample Results' field, other associated child field(s) will be removed as well.

 

CCC-8888

On I.H. Noise Sample layouts, for the 'dB Lower Limit' and 'dB Upper Limit' fields, the lowest value available is now 0, not 20. Values of 15, 10, 5, and 0 are now options.

 

CCC-7596

For IH Sample Results records, the following two options have been added to the hard-coded Units drop-down list: NG, PG

The drop-down list now enables the system to automatically calculate:

  • Sample amounts entered in nanograms (NG) into concentrations of pg/m3, ng/m3, ug/m3, mg/m3, ppm, ppb
  • Sample amounts entered in picograms (PG) into concentrations of pg/m3, ng/m3, ug/m3, mg/m3, ppm, ppb
  • Sample amounts entered in micrograms (UG) into concentrations of ng/m3, pg/m3
  • Sample amounts entered in milligrams (MG) into concentrations of ng/m3, pg/m3

This reduces the amount of work required for such calculations and eliminates the potential for errors caused when calculating by hand.

 

CCC-5818

For the 'Exposure Group Statistical Report' and the 'Exposure Group Statistical Report (Australian)', the formatting of and content within exports to CSV have been improved so that it is now easier to perform additional analysis.
