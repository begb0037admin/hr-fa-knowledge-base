CCC-8215: Our Environmental/Safety compliance management workflow has been enhanced.

Opt-In

  • The following improvements have been made:
    • There is a new ‘Requirements’ module and look-up table with an accompanying layout that has Applicable Locations, Regulations, Compliance Obligations, Permits, and Assets tabs (sublists). In addition to relevant default fields, the ‘Requirements’ layout also has two look-up table UDFs (with two correspondingly named look-up tables) and five check box UDFs. Users can import into the look-up tables and sublists, use them in business rules, and report on them using Query Builder / Report Writer.
    • To custom versions of the existing ‘Findings & Actions’ layouts, the new ‘Assets’ and ‘Requirements’ tabs (sublists) can now be added.
    • To custom versions of the existing Permits, Regulations / Legal and Other Requirements, and Compliance Obligations layouts, the new ‘Requirements’ tab (sublist) can now be added.
    • There is a new Citations look-up table with accompanying layout. Users can import into the look-up table, use it in business rules, and report on it using Query Builder / Report Writer.
  • Our Compliance Management solution is now a dedicated tool for seamlessly tracking environmental and safety-related compliance requirements. It can be used to easily track periodic reviews of applicable compliance requirements and associate them with relevant regulations, permits, audits, and compliance actions. This will help ensure your organization remains continuously in compliance with its obligations.
  • For information on working with Safety/Environmental compliance management, custom layouts, and/or user-defined fields, see the Cority GX2 User Guide.
