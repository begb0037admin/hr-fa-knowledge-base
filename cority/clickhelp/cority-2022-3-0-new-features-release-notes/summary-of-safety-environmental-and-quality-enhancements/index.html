Summary of Safety, Environmental, and Quality Enhancements

The table below lists the smaller design improvements we have made in the Safety and Environmental clouds. The items are organized by component and the components are arranged in alphabetical order. Descriptions of any larger features for all three clouds follow the table.

ItemComponent(s)Description
CCC-7421 and 7422Safety – Contractor Management

The following new user-defined fields can be added to custom versions of the Safety/Environmental 'Permit' layout:

  • UDF_Text_7 to UDF_Text_12 - Six new text fields (each with a character maximum of 1000)
  • Flag7_Permit to Flag9_Permit - Three new check box fields
  • UDF_Employee1 to UDF_Employee9 - Nine new Employee picklist fields
  • Num4_Permit to Num12_Permit - Nine new integer fields
  • UDF_Date_7 to UDF_Date_9 - Three new date fields
  • PermitUDF7 to PermitUDF10 - Four new look-up table fields, with accompanying identically named look-up tables that use the new ML-003517 layout and are categorized under the Demographics module

The fields can be used in business rule actions, in business rules, and in Query Builder and Report Writer.

Values can be imported into the fields.

The equivalent columns can be added to applicable custom list views.

 

CCC-9760Waste Management

The following new user-defined fields are now available for adding to custom versions of the Waste Container (ML-000228) layout:

  • 30 check box fields (Flag9_WC - Flag39_WC)
  • 10 text fields (Text18_WC - Text28_WC)
