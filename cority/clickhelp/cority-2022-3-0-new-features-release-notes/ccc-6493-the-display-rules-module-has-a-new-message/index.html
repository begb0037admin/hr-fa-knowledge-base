CCC-6493: The Display Rules module has a new Message/Toast action

Opt-In

  • The Display Rules module is included with the Administrator set of tools.
  • The module is used for creating rules that dictate what should display, or change in what is displayed, as a record moves through a workflow or when a layout is altered.
  • A display rule is similar to a business rule, except display rules trigger immediately on one or more changes, as opposed to triggering on Save.
  • For more information on the module, see the release note for CCC-227 in the Cority 2021.3.0 New Features Release Notes document.
  • When creating a display rule with a Message/Toast action, the user must provide values for the following:
  • Action Type, which is Message/Toast (fixed text)
  • Name - text
  • Description - text
  • Message - text
  • Message or Toast toggle – a check box for specifying a standard message or toast message
  • Inactive – a check box that while selected will prevent the action from executing
  • When the display rule action is triggered, the message/toast will display immediately.
    • If configured to be a standard message, the pop-up must be removed by the end-user.
    • If configured to be a toast message, the pop-up will fade after 5 seconds.
  • This display rule action can be used in conjunction with other display rule actions in the same display rule.
  • If multiple display rule actions are executed for the given conditions, the message/toast action will be executed last.
  • The message provided will be translatable.
  • For information on working with translations, see the GX2 User Guide.
