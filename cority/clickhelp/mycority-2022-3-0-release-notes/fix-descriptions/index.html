Fix Descriptions

The table below describes the fixes we have made for 2022.3.0.

Item #Component(s)Reported VersionDescription
CCC-5939Findings & ActionsN/A

For a custom 'Finding & Action' layout with one or more 'Always Apply Default Value' fields, those fields will now display the correct value in myCority.

 

CCC-9378Event ReportingN/A

For Event Reports, the Category field now functions without generating an unexpected error.

 

CCC-9487Occupational Health, AppointmentsN/A

For health centers with multiple scheduling users, 'Appointment Availability' now displays the correct days/times for all activities.

 

CCC-6844Platform – Administrator2022.1.0

In System Settings, when the limit for attachments is set to either 5 or 10 MB, using myCority you can now upload an attachment of 3-10 MB to an Incident record and submit the record without generating an unexpected error.

 

CCC-9890Platform – End-UserN/A

When consent has been provided and 'share with supervisor' is specified, the supervisor can now successfully open a questionnaire without generating an unexpected error.

 

CCC-9417Platform – End-User2022.1.2

If myCority displays an in-app, mini-guide, this no longer generates unexpected errors.

 

CCC-8773Platform – End-UserN/A

Editable fields and disabled or read-only fields have now been made more distinguishable from each other.

 

CCC-7612Quality, Event ReportingN/A

For custom versions of Quality 'Event Report' layout MG-003280, translated label names will now be reflected in myCority.

 

CCC-7246Questionnaire, GDDLOFBN/A

The GDDLOFB of an employee-based record created through questionnaire auto-post now reflects the GDDLOFB of the questionnaire's header, not the GDDLOFB of the employee's demographics.

 

CCC-6217QuestionnairesN/A

On questionnaire picklists, questionnaire codes are no longer displayed, only their descriptions.

 

CCC-3065Safety, ActionsN/A

For a custom Safety 'Action' layout with a dynamic section added, that section will now function as expected in myCority.
