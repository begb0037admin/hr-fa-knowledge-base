Summary of Enhancements

The table below describes the enhancements we have made in 2022.3.0.

Item #Component(s)Description
CCC-9730Platform

Angular has been upgraded from version 10 to version 13.

 

CCC-8774Platform – End-User

The usability (UX) of questionnaires/inspections in myCority has been improved. This will not alter existing workflows.

 

CCC-3275Platform – End - User

The new bar/QR code scanning feature enables a GX2 user to associate a task with an equipment or asset bar/QR code and then a myCority user to complete the task with myCority by first scanning the bar/QR code.
