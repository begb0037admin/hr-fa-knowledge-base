CCC-1179: A Waste Administrator can now filter Waste Profiles
by locations

  • To support this, there is a new Waste Profiles module in the Environmental cloud.
  • The module is filterable using the 'Site Selector'.
  • The Waste Profiles module appears below the 'Sample Data' module and above the 'Waste Container Management' module.
  • The new Waste Profiles module has the 'All Active Waste Profiles' list view.
    • The list view contains all records in the Agent Hazards look-up table that meet the following criteria:
      • The 'Waste Profile' check box is selected.
      • The 'Inactive' check box is not selected.
    • The list view has the Code and Description columns and New, Edit, and Delete buttons.
    • The list view also has an Actions menu with the 'Show Record History' and 'Export List to Excel' options.
    • When the user clicks a record on the list view, the record will open in the user's pinned Waste Profile layout.
  • The new module has read, update, insert, clone, and delete security actions.
  • The module appears in 'My Menu'. It is not enabled for existing users by default, but will be enabled by default for any user created after this functionality becomes available.
  • To access the module, the user's role must be granted the existing 'Waste Profile' security module.
  • The new module is pre-filtered based on the location specified using the 'Site Selector'.
    • When the user specifies a location using the 'Site Selector' and then clicks the module, the module's list view will be filtered based on the locations selected in the 'Applicable Locations' sublist.
    • The results are also filtered according to the 'Display Child Locations for Locations Detail Landing Page' system setting.

Impact to Existing Users:

  • This will enable the Waste Administrator to see his or her relevant Waste Profiles.

Additional Configuration Considerations:

  • Beyond what is described above, no new configuration is required. For information on working with Waste Profiles or configuring security for a user, see the Cority User Guide.
