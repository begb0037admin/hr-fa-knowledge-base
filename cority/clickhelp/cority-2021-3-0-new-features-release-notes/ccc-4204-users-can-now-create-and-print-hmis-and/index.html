CCC-4204: Users can now create and print HMIS and NFPA label templates, and record HMIS and NFPA ratings

  • If NFPA or HMIS is selected as the Label System value in the Label Template, the appropriate, representative diamond object will now display on the Label Preview panel.
    • The diamond object can be moved and resized.
  • From the Chemical Products module:
    • The diamond object is visible when the template is selected.
    • The product's NFPA or HMIS ratings will overlay the diamond object.
    • The following fields are now provided:
      • NFPA or HMIS Health -A blue row
      • NFPA or HMS Flammability – A red row
      • NFPA or HMIS Reactivity – A yellow -row
      • NFPA Special – A white row
      • HMIS PPE – A white row
  • If any of the values for the fields above is modified, the overlaid values on the diamond object will be updated.
    • If one or more of those field(s) is blank (empty), no corresponding value will display on the diamond.
    • The diamond can be moved and the overlaid values will move accordingly.
    • The diamond can be resized and the overlaid values will scale accordingly.
  • A user can print NFPA or HMIS labels using:
    • Chemical Product List > Actions > Print Labels from Template > Select Template > Print
    • Chemical Product Record > Actions > Print Labels from Template > Select Template > Print
    • Chemical Inventory List > Actions > Print Labels from Template > Select Template > Print
  • When the Print button is clicked, a print preview page will open.
    • The print preview displays the NFPA and HMIS objects.
  • The following new fields have been added by default to the Agent Hazard look-up table layout to store information related to HMIS ratings:
    • Flammability (HMIS) – a field with values 0,1,2,3,4
    • Health (HMIS) – a field with values 0, 1, 2, 3, 4
    • Reactivity (HMIS) – a field with values 0, 1, 2, 3, 4
    • Personal Protection (HMIS) – a field with values A, B, C, D, E, F, G, H, I, J, K, X
  • The Chemical Product layouts (ML-000831 and ML-000706) have been modified to include a new HMIS Rating section at the bottom with the four new fields mentioned above.
  • The four new fields are available for use in Query Builder and Report Writer, and can be populated/updated using the Import Utility.

Impact to Existing Users:

  • A Chemical Management Administrator can now create and print NFPA and HMIS label templates, so that he or she can communicate the acute and chronic hazards of a product to chemical handlers.

Additional Configuration Considerations:

  • Beyond what is described above, no additional configuration is required.
