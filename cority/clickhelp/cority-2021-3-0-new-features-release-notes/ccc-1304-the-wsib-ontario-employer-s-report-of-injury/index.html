CCC-1304: The 'WSIB Ontario - Employer's Report of Injury/Disease (Form 7)' can now record a fraction of a work hour

  • On the 'WSIB Ontario - Employer's Report of Injury/Disease (Form 7)', fields that record work hours will now accommodate up to three decimal places when the value is entered manually.

Impact to Existing Users:

  • This is compliant with the WSIB format and will improve the accuracy of the form when submitted.

Additional Configuration Considerations:

  • No new configuration is required.
