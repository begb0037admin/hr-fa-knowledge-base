CCC-907: In Waste Container Management, when a Waste record is created by the Dispose action, a notification is now displayed

  • On the 'Waste Container Management' list view, when the user selects one or more containers and executes the 'Dispose' action, a notification will now appear indicating that the corresponding Waste record(s) have been created.
  • If the user selects one container, the notification will provide a link to the new Waste record.
  • If the user selects more than one container, the notification will not provide links, but it will indicate the number of Waste records that were created.

Impact to Existing Users:

  • This makes the disposing of containers from the 'Waste Container Management' list view more user-friendly.

Additional Configuration Considerations:

  • No new configuration is required.  

Mandatory
