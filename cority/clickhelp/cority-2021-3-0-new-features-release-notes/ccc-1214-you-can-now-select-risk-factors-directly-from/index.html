CCC-1214: You can now select risk factors directly from the risk matrix itself

  • The user can now either select individual risk factors from a table (as before), or select them by clicking the matrix itself.
  • To support this, three new clickable-matrix fields can now be added to custom versions of any Risk Assessment Entry layout:
    • Risk 1 Selector
    • Risk 2 Selector
    • Risk 3 Selector
  • For each:
    • The X and Y axes are appropriately labeled.
    • The cell colors are grey by default.
  • The selectors react (display risk) for the associated Risk Factor fields only (Risk 1 Selector for Risk Factor 1, etc.)
  • If the Risk Factor fields are set and the values are for risk, each corresponding Risk Selector field will display risk in the correct cell with the appropriate text and color.
  • Notes:
    • The three new fields can only be added to layouts for which the Risk Setting is Matrix.
    • The Risk Selector field axes will update if the user manually changes a value for any of the Risk Factor fields defined as a matrix axis.
  • When the user clicks a cell on one of the new fields:
    • The associated RiskDefinition.Description will display in the selected cell.
    • The color of the cell will change to the one defined for the Risk Definition.
    • The related Risk Factor fields (fields set as X and Y axes in Risk Settings) will populate.
    • The Risk Definition field will populate.
  • When the user changes a selected cell, the cell color, Risk Definition, and Risk Factor fields will update.
  • Each of the new fields has a Clear button, which will:
    • Remove the values in the Risk Definition and Risk Factor fields.
    • Return the matrix to the incomplete state (all cells grey, none selected).
  • The three Risk Selectors are not available for use in business rules, cannot be populated/updated using the Import Utility, and cannot be added as columns to list views.
  • We recommend that if one or more Risk Selector fields is used, the Risk Factors for the X and Y axes and Risk Definition should be disabled (or not selected) on the layout. That is, clients should use only one method to select risk, either by selecting individual risk factors from the table (as before) or by selecting them directly on the matrix itself.
  • Also, the assessment category concept has been expanded to the matrix. You can now filter the matrix view by category (Financial, Environmental, Safety, Health, etc.) and add a tooltip with a description for the selected assessment category.
  • If the system setting 'Enable Risk Factor Qualifier For Risk Factor Picklist in <Module> Risk Assessment Entry' is selected, an Assessment Category drop-down field will be provided on the Matrix sublist in Risk Assessment. The drop-down field will default to null (empty).
    • The drop-down lists all active Assessment Categories flagged for the respective Risk Assessment module.
  • When an assessment category is selected, only risk entries with that assessment category will display on the matrix.
  • All of the functionality above applies to the Safety, CoSHH, Environmental, Ergonomics, Medical, and IH 'Risk Assessment' modules.

Impact to Existing Users:

  • An operational risk assessor:
    • Can now select risk factors directly on the matrix. He or she no longer has to select them from the table.
    • Can now filter tasks on the matrix by Assessment Category, so that he or she understands the business impact of the risks.
  • The matrix and task list will now display on the risk assessor's screen without any scrolling, so that the task list does not get overlooked.

Additional Configuration Considerations:

  • Beyond what is described above, no additional configuration is required.
