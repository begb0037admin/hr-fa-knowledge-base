CCC-1699: The Case Master entity can now be mapped to a questionnaire

  • To do this, the user simply selects the Case entity for the Data Table field value on the questionnaire.
  • If a management referral starts by a manager sending a referral questionnaire to the clinic using myCority, and that questionnaire has the CaseMaster entity mapped (for best example here), the questionnaire will then auto-post to the Case Management module, creating a new Case record for the referral process.
    • The auto-post mechanism will bypass the Questionnaire Inbox as before, the new Case record will be created automatically, the questionnaire will be available in the Questionnaire sublist of the newly created case, saving the clinician from doing that manually.
    • The clinician will then kick off the rest of the referral process by booking an appointment from within the Case record (see CCC-1568) using either the New button on the Schedule History tab or the Schedule Referral action.
    • If the questionnaire has questions mapped to the Case module, then on the new Case record, answers to those answers would auto-populate the corresponding fields.

Impact to Existing Users:

  • This will help automate the early stages of the management referral process, and save clinicians’ time.

Additional Configuration Considerations:

  • Beyond what is described above, no additional configuration is required. For information on working with questionnaires or custom layouts, see the Cority User Guide.
