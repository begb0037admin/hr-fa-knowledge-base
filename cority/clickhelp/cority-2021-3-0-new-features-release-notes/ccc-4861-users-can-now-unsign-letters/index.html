CCC-4861: Users can now unsign letters

  • To accommodate this, the new Unsign action can be added to custom versions of the following layouts:
    • Medical Letter (ML-000187)
    • Case Management Letter (ML-000914)
    • Safety Letter (ML-000915)
    • Ergonomics Letter (ML-001449)
    • IH Letter ML-000916)
    • Survey Letter for Monitoring (ML-003463)
    • Survey Letter for Noise Monitoring (ML-003462)
    • Quality Letter (ML-003444)
  • To use the action, an administrator must grant the user’s role the corresponding security action:
    • medicalletter.unsign
    • casemanagementletter.unsign
    • safetyletter.unsign
    • ergonomicletter.unsign
    • ihletter.unsign
    • enviromentalletter.unsign
    • qualityletter.unsign
  • Also, the following new fields can be added to the eight layouts listed above, and as columns to applicable list views:
    • Unsign Date/Time - a read-only date/time field
    • Unsign Reason - a read-only text field that will accommodate up to 500 characters
    • Unsigned By - a read-only employee name field
  • Changes to the values of the new fields will be tracked in Record History.
  • Any user who is granted the new Unsign action can use it. The user does not have to be the author of the letter.
  • When a user selects the new action, that user will be asked to confirm if he or she wants to unsign the record.
    • If the user confirms the unsigning, a dialog box will open prompting the user to provide a reason for unsigning.
    • If the user enters a reason and then clicks OK, the dialog box will close, the letter will become unsigned, the Signed Date, Signed Time, and Signed By fields will be cleared, and the Unsign Date/Time, Unsign Reason, and Unsigned By fields will automatically be populated. If the Topaz device has been used to sign the letter, the Employee and Staff Signature fields will also be cleared.
    • Note: If the system setting 'Prompt For Password When (Un) Signing Records' is selected, after the user enters his or her reason for unsigning, he or she will be prompted to enter his or her password.

Impact to Existing Users:

  • Users can now make corrections to letters that have been signed.

Additional Configuration Considerations:

  • Beyond what is described above, no additional configuration is required.
