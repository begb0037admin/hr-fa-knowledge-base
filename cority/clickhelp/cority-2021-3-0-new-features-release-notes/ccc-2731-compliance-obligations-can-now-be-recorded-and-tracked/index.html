CCC-2731: Compliance obligations can now be recorded and tracked on 'Stakeholders' layouts

  • You can now add the 'Related Compliance Obligations' tab (sublist) to custom versions of the following layouts:
    • Environmental Stakeholders (ML-003436)
    • Quality Stakeholders (ML-003433)
    • Safety Stakeholders (ML-003437)
  • Depending on the layout, the tab will have the following view:
    • Environmental: Compliance Obligations for this Stakeholder
    • Safety: Compliance Obligations for this Stakeholder
    • Quality: Findings for this Stakeholder
  • The view will have the New, Edit, and Delete buttons and an Actions menu with the following options:
    • Add to Action Plan
    • Add Action to Finding
    • Set Assignee / Due Date
    • Copy Action
    • Delete Action
    • Email
    • Show Finding's Record History
    • Show Action's Record History
    • Export List to Excel
  • The 'Inline Add' feature is not available on the view.
  • The view has the Create/Clone functionality
  • In the Environmental and Safety clouds, the view will have the following columns by default:
    • Date Added
    • Location
    • Finding Type
    • Compliance Details
    • Risk [Description]
    • Risk [Icon]
    • Action Details
    • Due Date
    • Assigned To
    • Completed Date
  • All available columns in the Environmental 'Compliance Obligations' module can be added to custom versions of the view.
  • In the Quality cloud, the view will have the following columns by default:
    • Finding Date
    • Location
    • Finding Type
    • Compliance Details
    • Risk [Description]
    • Risk [Icon]
    • Action Details
    • Due Date
    • Assigned To
    • Completed Date
  • All available columns in the Quality 'Findings & Actions' module can be added to custom versions of the view.
  • The sublist can be populated using the Import Utility. The existing DT_FindingStakeholder table is used for imports.
  • Depending on the cloud, when the 'New' button on the view is selected, the following layout will open:
    • Environmental: Compliance Obligations (ML-001318)
    • Safety: Compliance Actions (w/Risk) (ML-001309)
    • Quality: Findings & Actions (ML-003189)
  • When the 'New' button is selected, the 'Source' and 'Source ID' fields will link to the appropriate 'Stakeholder' record.

Impact to Existing Users:

  • This will make it easier for a Compliance Manager to record and manage obligations to stakeholders.

Additional Configuration Considerations:

  • Beyond what is described above, no additional configuration is required. For information on working with custom layouts or list views, see the Cority User Guide.
