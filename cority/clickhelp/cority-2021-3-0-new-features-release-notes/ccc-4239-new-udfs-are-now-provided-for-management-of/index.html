CCC-4239: New UDFs are now provided for Management of
Change (MoC) layouts

  • The following new UDFs can now be added to custom versions of the MoC layout:
    • UDF_Text_4 to UDF_Text_12 - Each a text field (accommodating a maximum of 1000 characters)
    • UDF_Flag4 to UDF_Flag12 - Each a check box
    • UDF_Number1 to UDF_Number10 - Each an integer field
    • UDF_ExtraApproval3 to UDF_ExtraApproval22 - Each a picklist to the Employees look-up table
    • UDF_Date_4 to UDF_Date_22 - Each a date field
    • UDF_Lookup_1 to UDF_Lookup_10 - Each a picklist to the corresponding new look-up table (LU_MOC_UDF1 to LU_MOC_UDF10)
  • The new LU_MOC_UDF look-up tables have the standard features and functionality (Translations tab, standard buttons, standard actions, etc.).
  • The new fields are available in all clouds (formerly suites) that use the MoC module.
  • The equivalent columns can be added to custom versions of corresponding list views.
  • The fields can be updated using the Import Utility, and are available for use in Query Builder, Report Writer, and business rules.
  • Note: The extra approver and approval date UDFs will be paired in the MoC approval sequence and should be configured in the same manner as the existing approvers and approval dates.

Impact to Existing Users:

  • This will enable users of the MoC module to more accurately report on and track their MoC business processes

Additional Configuration Considerations:

  • Beyond what is described above, no additional configuration is required. For information on working with the MoC module, or on configuring custom layouts and list views, see the Cority User Guide.
