CCC-640: Subqueries can now be used to base role security on something other than, or in addition to, site/location (GDDLOFB)

  • This functionality is referred to as Row Level Security in reference to the rows returned by the added subquery or subqueries.
  • To support this, a ‘Security Query’ check box has been added to Query Builder and a Row Level Security tab (for adding subqueries to a role) has been added to the Administrator > Role Security module.
  • Notes:
    • Only users with an Administrator role can see security queries.
    • To configure Row Level Security, the user's role must be granted the SecurityModule.Admin.
  • This is an example use case:
    • The administrator creates a security role named Contractor Manager that is granted the appropriate modules and actions.
    • The administrator next creates a security query named Contractor Manager that restricts to only records accessible by the Contractor Manager’s contractors. For information on using Query Builder to create reusable subqueries, see the Cority User Guide.
    • The administrator then adds the Contractor Manager security query to the Contractor Manager role using the new Row Level Security tab.
    • Notes:
      • If more than one security query is added to a role, the queries will essentially be added together and will be respected together.
      • Any added site security will continue to be respected as well.
    • The administrator now assigns the Contractor Manager role to the Contractor Manager.
    • If configured properly, the Contractor Manager will now only be able to see the records to which his or her contractors have access.
    • If the Contractor Manager tries to open or inline-edit a record for which he or she now does not have access, an informative error notification will be displayed.
    • If the Contractor Manager wants only to see the records for which he or she has access, custom list views and a dashboard table can be created to accomplish that.

Impact to Existing Users:

  • Security configuration for users is now more powerful and flexible.

Additional Configuration Considerations:

  • Beyond what is described above, no additional configuration is required.
