CCC-3304 and 3798: It is now easier to associate stakeholders with their
action plans

  • To support this, a new ‘Related Action Plans’ tab (sublist) can now be added to the following layouts:
    • Environmental Stakeholder (ML-003436)
    • Safety Stakeholder (ML-003437)
    • Quality Stakeholder (ML-003433)
  • For each, the sublist has an ‘All <Cloud Name> Action Plans’ list view. The view has standard buttons and actions, multi-add functionality, and the Create/Clone view feature set.
  • The view has default columns, but all ‘Action Plan’ fields can be added as columns to custom versions of the view.
  • Also, a new ‘Related Stakeholders’ tab (sublist) can now be added to the following layouts:
    • Environmental Action Plan (ML-001461)
    • Safety Action Plan (ML-001460)
    • Quality Action Plan (ML-001466)
  • For each, the sublist has an ‘All <Cloud Name> Stakeholders’ list view. The view has standard buttons and actions, multi-add functionality, and the Create/Clone view feature set.
  • The view has default columns, but all ‘Stakeholder fields can be added as columns to custom versions of the view.
  • All of the related fields are available for use in Query Builder / Report Writer, and in business rules, and can be populated/updated using the Import Utility.

Impact to Existing Users:

  • This will make it easier to record, track, and report on stakeholders who have action plans.

Additional Configuration Considerations:

  • Beyond what is described above, no new configuration is required.
