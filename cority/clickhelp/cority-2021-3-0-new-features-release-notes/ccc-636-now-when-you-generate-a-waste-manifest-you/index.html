CCC-636: Now when you generate a waste manifest, you can prevent it from immediately opening

  • In the 'Waste Management' list view, when you select the 'Generate Waste Manifest for Selected Records' action, the resulting dialog box now provides an 'Open auto-generated manifest in a separate window' check box. By default, the check box will be selected.
  • If you leave the check box selected and click SAVE, the generated waste manifest will open in a new tab.
  • If you deselect the new check box and click SAVE, the manifest will not open.
  • The generated waste manifest will be available in the 'Forms' tab on each applicable waste record's layout.

Impact to Existing Users:

  • This will help users better manage their waste manifest workflow.

Additional Configuration Considerations:

  • No new configuration is required.
