CCC-2719: Our Chemical Management Solution (Environmental cloud) now provides an out-of-the-box product summary sheet for each chemical product

  • There is a new Chemical Handling data table (DT_ChemHandling) that can be added as a section to custom versions of the following Chemical Products layouts:
    • ML-000831
    • ML-000706
    • ML-003504
  • The table is for storing relevant chemical safety and handling information that is not already contained in the Agent Hazards look-up table.
  • Note: When the Chemical Handling section is added to one or more of those layouts, it will also be displayed (with appropriate records) in the equivalent location in myCority.
  • There is also a new accompanying Chemical Handling Information layout with all of the fields and sections required for a Chemical Manager to store chemical safety summary sheet information.
  • The new layout has the New, Delete, Cancel, and Save and Close buttons, and an Actions menu with the Show Record History, Save Layout, and Edit Layout options.
    • The fields on the new layout can be added as columns to custom versions of 'Chemical Products' list views.
    • The fields can be used in Query Builder and Report Writer, in business rules (through the ChemicalHandling entity), and can be populated/updated using the Import Utility.
    • The following unique key is used by the Import Utility for the new table: ChemProductID.
  • Each single-page, short-form summary sheet will be created through the mapping of fields onto the summary sheet template.
  • A new Product Summary Sheet PDF document (form) is created when a Chemical Product record is saved.
    • The document's Source and Source ID values link to the associated Chemical Product record.
    • The following fields are mapped to the new PDF form:
      • ChemProduct.Description - Trade Name
      • ChemProduct.Synonyms - Synonyms
      • Manufacturer.Description - Manufacturer
      • ChemHandling.EmergencyPhone - Emergency Phone
      • ChemProduct.HMISHealth - HMIS Health
      • ChemProduct.HMISFlammability - HMIS Flammability
      • ChemProduct.HMISReactivity - HMIS Reactivity
      • ChemProduct.HMISPPE - HMIS PPE
      • ChemProduct.NFPAHealth - NFPA Health
      • ChemProduct.NFPAFlammability - NFPA Flammability
      • ChemProduct.NFPAReactivity - NFPA Reactivity
      • ChemProduct.NFPASpecial - NFPA Special
      • ChemicalSymbol - PPE (selected by default)
      • ChemicalSymbol - GHS (selected by default)
      • ChemHandling.EyeContact - Eye Contact
      • ChemHandling.SkinContact - Skin Contact
      • ChemHandling.Ingestion - Ingestion
      • ChemHandling.OtherFirstAid - Other First Aid
      • Date - System Generated Printed Date
    • When any of the values for those fields are modified, and a new Summary Sheet is generated, the values update accordingly.
  • The following new check box fields have been added by default to the Chemical Symbols look-up table layout (ML-000147):
    • Personal Protective Equipment (not selected by default)
    • GHS (not selected by default)
  • The purpose of these check boxes is to ensure differentiation between symbols that belong in the PPE section or the GHS section of the product summary sheet.
  • Those two fields can be populated/updated using the Import Utility, but are not available for use in Query Builder and Report Writer, or in business rules.
  • The fields can be added as columns to applicable list views.
  • As well, the following new GHS Symbols records have been added to the Chemical Symbols look-up table:
    • GHS01 - Flammable, Self-Reactive, Pyrophoric, Self-Heating or Organic Peroxide
    • GHS02 - Acute Toxicity, Skin Irritation/Corrosion, Skin Sensitizer
    • GHS03 - Respiratory Sensitizer, Mutagen, Carcinogen, Reproductive Toxin, Aspiration Hazard
    • GHS04 - Acute Toxicity
    • GHS05 - Explosives, Self-Reactive, Organic Peroxides
    • GHS06 - Oxidizer
    • GHS07 - Corrosive, Irritation or Serious Eye Damage
    • GHS08 - Gas Under Pressure
    • GHS09 - Acute or Chronic Hazard to Aquatic Environment

Impact to Existing Users:

  • This will enable Chemical Managers to store chemical safety summary sheet information so that they can communicate a chemical's acute and chronic hazards to fellow employees.
  • These Summary Sheets will provide chemical handlers with an overview of the product information, associated hazards, required PPE and First Aid instructions for the chemical products that they handle.

Additional Configuration Considerations:

  • Beyond what is described above, no additional configuration is required.
