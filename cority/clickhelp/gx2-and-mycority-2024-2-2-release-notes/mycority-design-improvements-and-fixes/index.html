myCority Design Improvements and Fixes

The table below lists the design improvements and fixes we have made in the myCority 2024.2.2 release. The items are organized by component and the components are arranged in alphabetical order.

Item #Component(s)ReportedDescription
CCC-13487Business Intelligence - DashboardsN/A

If the 'No records available' phrase is translated, the translation will now display when applicable for a dashboard indicator in myCority.

 

CCC-18391Ergonomics - TrainingN/A

If GX2 is used to assign an employee self-assessment training course for the first time, the employee will now be able to open the self-assessment training record using myCority without encountering an unexpected error.

 

CCC-16940Event ReportingN/A

An Event Report record can now be saved successfully and without generating any unexpected error messages after one or more of its GDDLOFB values have been edited either manually or by business rule action.

 

CCC-11572Event ReportingN/A

On an Event Report layout that has one or more temperature or UDF integer, numeric, or cost fields, a user can now successfully add a value to any of those fields, save the record, delete the value, and then save the record again. Also, this will not cause any unexpected errors.

 

CCC-11622Event Reporting - SafetyN/A

On an Event Report using a layout with an FRA section, the user can now successfully add values to enum fields, save the record, then remove one or more of the enum field values and save the record again without generating any unexpected errors.

 

CCC-15442Findings & ActionsN/A

For an assigned Action, if a user populates all required fields along with the 'Completed Date' and 'Completed By' fields and then saves the record to complete it, the record will now successfully save and move to the 'Completed' tab without generating any unexpected errors.

 

CCC-18443Incidents, Display RulesN/A

For Incident layouts, display rules with the Require action now function as expected in myCority.

 

CCC-9747Industrial HygieneN/A

For IH Monitoring layouts in myCority, the 'Direct Reading' flag now functions as expected.
Also, the following layouts are now available for the Sampling Equipment look-up selector in myCority:

  • All Active Direct Reading Monitoring Equipment
  • All Inactive Direct Reading Monitoring Equipment
  • All Direct Reading Monitoring Equipment

 

CCC-17869Platform - AdministratorN/A

Users logged into myCority will no longer be prompted to change their password when clicking the link to go to GX2.

 

CCC-15722Platform - AdministratorN/A

For a display rule in myCority, configured for example to make a free-text field on a layout required when a certain look-up selector value is specified on the same layout, advanced conditions are no longer case-sensitive.

 

CCC-18126Platform - End UserN/A

A workflow action on a layout will now remain disabled until all required fields are populated and the record saved. Until then, an applicable workflow cannot move to the next step.

 

CCC-11861Quality - CAPAN/A

When an assignee adds a document to a CAPA Finding in myCority or GX2, the correct document source is now reflected, and when applicable, translated. Also, the document will now display wherever applicable and remain uploaded and displayed when the user navigates away and then back.

 

CCC-17750Safety - Audits & InspectionsN/A

A user with the appropriate security configuration can now fill in the required fields for an Inspection and save and submit the Inspection without encountering an unexpected null reference error.

 

CCC-16681Safety - Audits & InspectionsN/A

For Inspection (Survey/Observation) questionnaires that are configured to auto-create actions, if the questionnaire does auto-create any actions, the 'Success # action(s) created' message will now display stating the number of new actions.

 

CCC-16208Safety - Permit To Work2023.3.2

For Safety 'Work Permits', myCority now filters the 'Permit Types' and Risk 'Control Types' lists correctly.
