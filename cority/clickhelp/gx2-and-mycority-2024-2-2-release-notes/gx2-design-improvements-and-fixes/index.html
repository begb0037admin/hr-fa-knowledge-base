GX2 Design Improvements and Fixes

The table below lists the design improvements and fixes we have made in the GX2 2024.2.2 release. The items are organized by component and the components are arranged in alphabetical order.

Item #Component(s)ReportedDescription
CCC-18136Business Intelligence - Query BuilderN/A

A Query Builder report with a few fields for 'Field to Graph' and a data source that is a subquery Query Builder report with some functions (for example, Categorize, Accumulation, etc.), when used as an indicator on an advanced dashboard, the indicator's drill-down functionality will now work properly and without error.

 

CCC-17214Business Intelligence - Query BuilderN/A

On a Query Builder report with Safety 'Incident' as the main data source, count aggregation set for Accident Type, Building, and Geographic Location, non-aggregated fields set for 'Field to Graph' and 'Count of Records', an aggregated field set for 'Value to Graph', and series used, the user can now drill down to applicable records without encountering any unexpected errors.

 

CCC-10453Business Intelligence - Report WriterN/A

From the Data tab of a Report Writer report, the Employees look-up selector for use when emailing the report now functions properly.

 

CCC-18419Environmental - ComplianceN/A

When a user tries to upload a document or add a doc HTTP link on the Documents tab (sublist) of an Environmental 'Compliance Obligation' if the source for the record is an Environmental 'Requirement', the Document will now upload and save without generating a security validation error.

 

CCC-18389ErgonomicsN/A

Under Menu Configuration > Ergonomics > Personal Risk, the 'Ergonomics Reports' item is now spelled properly.

 

CCC-17961ErgonomicsN/A

For assigning risk profiles (to employees that are part of a Group/Team or not) using linked queries, the performance of the job that is used has improved to support up to 200,000 employees.

 

CCC-17427Ergonomics - ReportingN/A

The Ergonomics cloud now provides the ‘Desktop Aggregate Report’.

You can access the report from Business Intelligence > Reports.

The report respects the user’s site security configuration.

The report provides aggregated desktop results over a user-specified date range.

The report can be exported to Microsoft Excel.

For information on working with GX2 reports, see the GX2 User Guide.

 

CCC-6799Event ReportingN/A

When cloning within the 'Event Report Type' look-up table, if the length of the Code value exceeds 16 characters, the value will now be truncated and a suffix added. The user can then update the Code and Description on the new record and save it.

 

CCC-18073Findings & Actions, Business RulesN/A

For business rule email actions on the Actions entity, the email popup will now trigger as expected.

 

CCC-15810Findings & ActionsN/A

For a Finding Owner who has both first and last name on the Finding & Actions (Compliance Obligations, Compliance Calendar, etc.) record, both names will now appear on all applicable list views and sublists.

 

CCC-13030Findings & ActionsN/A

On a custom 'Findings & Actions' list view that has the Reviewer (ToBeReviewedBy) column, if the column uses a custom Employee picklist, the column header filtering for that picklist will now function properly.

 

CCC-18655Industrial HygieneN/A

A user with the appropriate security configuration can now export a Lab Requisition, modify values for any Amount, Filter Amount, and Concentration fields, and then re-import the record successfully without encountering any unexpected errors.

 

CCC-18493Industrial HygieneN/A

When applicable, from an IH 'Monitoring Sample' or 'Noise Monitoring Sample' record, the 'Related Record' icon can now be used to successfully open a related Equipment record.

 

CCC-18081Industrial HygieneN/A

On a clone of the Monitoring Results view, criteria for filtering can now successfully be configured for the Sample Status column.

 

CCC-15216Industrial HygieneN/A

On a 'Noise Monitoring' Sample record with 'Hearing Protection' field configured to allow users to open a related Equipment record, a user whose role has the necessary security configuration can now successfully open the related record without encountering an unexpected error.

 

CCC-18512Management of Change - Environmental2024.2.1

The 'Environmental' check box for ManagementofChangeUDF7 look-up table entries now filters the 'MOC UDF 7' look-up selector properly.

 

CCC-18378Management of Change, Event Management, Findings & ActionsN/AIf the 'Employee Number' field is prohibited from the user's role, the user will no longer be able to see it.

CCC-18229Management of Change - Safety2024.2.0

For a Safety MOC record that has three parallel approval workflow steps, a rejection at the third step back to the second will no longer clear approvers from the first step.

 

CCC-17274Management of Change - SafetyN/A

A Safety 'Change Request' of the type 'Standard Change' that has an associated workflow and parallel approval actions, if properly configured, will now function as expected without error when moving through the approvals and workflow steps.

 

CCC-16578Management of Change - SafetyN/A

For a Safety 'Change Request' that has a questionnaire with attach documents enabled for a question, attached documents will now be visible in all applicable views of the Safety Documents module.

 

CCC-14272Management of Change, WorkflowsN/A

In Management of Change, if a workflow has parallel approval steps and an approver rejects at one of them, both will now be cleared of any approval and the workflow will revert successfully to the expected previous step.

 

CCC-10354Management of Change2022.2.2

For a newly created Safety/Environmental/Quality 'Change Request' with all required fields populated, if the layout being used has a sublist added to the top of its main form, saving the new record will no longer cause the screen to flicker.

 

CCC-18549Occupational Health - AppointmentsN/A

When booking an appointment correctly, a message "The following fields are required: Health Center" no longer displays if not applicable.

 

CCC-17894Occupational Health - AppointmentsN/A

A time-driven business rule scheduled to update the status of an employee appointment that is linked to an OH Case record will now function properly.

 

CCC-16655Occupational Health - AudiometricN/A

On a custom Audiometric layout that has test result tabs for several regulations, when a test is created (with required fields populated) and saved, each tab will now be populated where applicable and colored red where expected.

 

CCC-18388Occupational Health - BillingN/A

In the Billing module, on a custom view that does not have the 'Invoice Due Date' column, the 'Days Overdue' value(s) will now be accurate.

 

CCC-18377Occupational Health - BillingN/A

In the Billing 'Invoices' module, the 'Show Record History' action now functions properly and without generating any unexpected errors.

 

CCC-18290Occupational Health - BillingN/A

In the Billing 'Invoice' module, for a custom layout that has the 'Payment Tracker' section (or Tab), if the user clicks 'Create new record' in that section, the 'Payment Type' look-up selector icon will now be available, as expected.

 

CCC-18173Occupational Health - BillingN/A

In the 'Un-invoiced Items' module, the 'Fee' look-up selector now functions properly and without generating any unexpected errors.

 

CCC-18640Occupational Health - Case Management, Clinic VisitN/A

When a new Case and/or Clinic Visit is created for an employee, the GDDLOFB on the new record will now match the GDDLOFB on the Employee's Demographics record.

 

CCC-15583Occupational Health - Case ManagementN/A

On a Case Record, when adding multiple restrictions from the Restrictions tab and the date popup is required, the popup is now the expected size. The popup is now also the expected size everywhere it is used.

 

CCC-10132Occupational Health - Case Management2022.3.0

Any 'Case Activity' UDFs that should be available for prohibiting now are, and any that have been prohibited will now function as expected.

 

CCC-17770Occupational Health - Clinical TestingN/A

When importing Clinical Test results, HTML tags are now being parsed correctly.

 

CCC-18374Occupational Health - Clinic VisitN/A

In Clinic Visit, a custom 'Exam Activities' list view with 'Activity = Audiogram' condition can now be edited successfully without generating any unexpected errors.

 

CCC-17578Occupational Health - Clinic VisitN/A

In OH 'Clinic Visit' Referrals, for creating a new record, a custom layout can now be used successfully. The custom layout will now render properly and will not generate any unexpected errors.

 

CCC-8225Occupational Health - Clinic VisitN/A

For cloning Clinic Visit 'Documents' views, the 'Created Date' column is now available.

 

CCC-17930Occupational Health - SEGs2024.2.0

From the SEG Management (Surveillance Groups) list view, a new Exposure Group can now be created successfully, with mandatory Code entered, and saved without generating any unexpected errors.

 

CCC-18373Platform - AdministratorN/A

When a workflow with business rule actions is exported using Migrate Config, in the export the business rule actions will now be clearly marked hidden. When that workflow is imported into another database, the business rule actions will now be linked to the workflow in both the database and the UI, as expected.

 

CCC-18022Platform - AdministratorN/A

In all applicable scenarios, the business rule action queue will now show the full list of actions.

 

CCC-14055Platform - AdministratorN/A

Where applicable, all active languages now apply when searching for look-up table entries (descriptions).

 

CCC-9219Platform - AdministratorN/A

Where applicable (for example, in the 'Group and Team' look-up table), the 'Add Multiple Employees' label is now correct. It is no longer 'Add Multiple Allergies'.

 

CCC-17978Platform - End UserN/A

For letters, the 'Export to PDF' action will now function successfully on multiple browser tabs at the same time.

 

CCC-18070Platform - InfrastructureN/A

The PublicQuestionnaireResponse record type is now supported by the REST API.

 

CCC-11861Quality - CAPAN/A

When an assignee adds a document to a CAPA Finding in myCority or GX2, the correct document source is now reflected, and when applicable, translated. Also, the document will now display wherever applicable and remain uploaded and displayed when the user navigates away and then back.

 

CCC-18167Quality - CAPAN/A

On a CAPA Action layout, the 'Action Type' look-up selector will no longer list look-up table entries that are marked for other clouds (for example, Safety).

 

CCC-17202Quality - Document ControlN/A

For a Quality 'Document Control' record, if the Approver name gets changed, that will no longer change any of the existing data in the 'Approval History'.

 

CCC-2813Quality - Document ControlN/A

On the 'Approval History' tab of a Quality 'Document Control' record, for non-published documents, null published and revision dates now remain null. They no longer default to 01/01/0001. Also, the 'Approval History' can now be exported to Microsoft Excel without generating any unexpected errors.

 

CCC-18450Quality - NonconformanceN/A

When using a custom layout with a Flex Fields subsection, an Admin user or a user with limited site security can now successfully save a Nonconformance 'Product' record without encountering any unexpected errors.

 

CCC-17438Quality - NonconformanceN/A

A Query Builder report for the Nonconformance entity that is properly configured to be a subquery will now be available for use in business rule change actions, as expected.

 

CCC-17110Quality - NonconformanceN/A

On a NonConformance, Customer Complaint, or Quality Event layout that does not contain the Product field, if the user navigates to the Products tab, adds a new product, then returns to the main tab and saves the record, records on the Products tab no longer get deleted unexpectedly.

 

CCC-17309Questionnaires, InspectionsN/A

A user whose role has the required security configuration can now open a submitted Inspection questionnaire without encountering any unexpected errors. Also, importing a questionnaire with multiple-choice questions that do not have blank valid choices will no longer create blank valid choices.

 

CCC-14786QuestionnairesN/A

For a questionnaire using SmartNote controllers, a 'Yes/No' question configured to branch when the answer is 'Yes' will now function properly.

 

CCC-14633QuestionnairesN/A

A user with limited site security but appropriate module security can now open a public questionnaire from the OH 'Questionnaire Inbox' that is not yet validated (does not yet have an employee assigned).

 

CCC-9523Questionnaires2022.2.1

To an applicable questionnaire response, a document can now be added and then deleted successfully without generating any unexpected errors.

 

CCC-16032Respirator FitN/A

A Respirator Fit record with an attached document can no longer be deleted without first deleting the document. This will make it impossible for there to be an orphaned Respirator Fit document that cannot be deleted.

 

CCC-16364Safety Action PlanN/A

On a Safety 'Action Plan' record that has a custom 'Finding & Actions' view with the 'Finding Super Type' column renamed, if a translation has been provided for the column name, when applicable the column name will now translate.

 

CCC-3636Safety Action PlanN/A

On a custom Safety 'Action Plan' view that has the 'Master Plan' column, the view can now be filtered by 'Master Plan' without generating any unexpected errors.

 

CCC-4952Safety - Audits & InspectionsN/A

In the Audits module, for emailing a new or existing letter, the 'Letter Sent To' field now functions as expected.

 

CCC-17743Safety/Environmental MVAN/A

When a user creates a Safety/Environmental MVA display rule, it will now be made available in the appropriate views.

 

CCC-15739Safety - IncidentN/A

On a Safety 'Incident' record, for the case details of an 'Injury/Illness', a user can now change the employee without generating an unexpected error, regardless of whether or not one or more sublists are configured to display at the top of the 'Injury/Illness' layout's main form and/or whether the sublist is expanded or collapsed.

 

CCC-12701Safety - IncidentN/A

On a custom Safety 'Incident' or 'Injury/Illness' view that has the 'Workflow' and/or 'Weather Conditions' column, if either column has filter criteria or the user sorts the view using either column, that will no longer generated any unexpected errors.

 

CCC-18433Safety - Permit to WorkN/A

On a new or existing 'Work Permit' record, when inline adding a record to the Risk tab (sublist), if the user clicks the Save button one or more additional times while it is still accessible, duplicate records are no longer created.

 

CCC-17618Waste ManagementN/A

A user whose role has the necessary security configuration can now open Waste Management records (Waste Manifest, Waste Shipment, etc.), make changes, and save them without encountering any site security errors.
