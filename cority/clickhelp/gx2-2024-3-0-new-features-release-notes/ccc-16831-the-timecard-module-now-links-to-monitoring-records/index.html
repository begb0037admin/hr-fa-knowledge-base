CCC-16831: The Timecard module now links to Monitoring records and the calculation engine

This enables IH users to calculate individual exposures on a Monitoring record using the Equation Library calculation engine. It allows for line-by-line calculations of individual exposures on a daily basis.

The changes made to support this include:

  • New business rule methods for the Timecard, Timecard SEG, Monitoring, and Monitoring Results sublists. These will handle any changes (updates, insertions, or deletions) to the SEG and/or Date fields after the creation of either the Timecard or the Monitoring record.
  • Timecard SEGs are now exposed to the Equation Library, so all fields from Timecard SEGs can now be selected within the Equation Library calculation engine. Also, the ‘Equation Set’ field has been added to Timecard SEG.
  • For use in business rules, Timecard SEG is a new entity.
  • The new Timecards tab (sublist) can be added to custom versions of applicable IH Monitoring Sample layouts.
    • The tab has a SEG Timecards list view with appropriate columns.
    • The tab has a ‘Run Equation Set’ action that will run calculations for each linked Timecard from the list view. The tab also provides the ‘Export to Excel’ and ‘Show Record History’ actions.
  • Additional calculated fields are now available for adding to custom versions of Monitoring, Agent (Monitoring Results) and Timecard SEG layouts. These fields will be used for Equation Library calculation outputs.
  • All calculated fields within the Timecard, IH Sample, and IH Sample Results modules now display the ‘Equation Calculation’ icon. If a user clicks the icon, the equation associated with that field will be displayed, if applicable. If the user clicks the equation itself, the 'Equation Library' will open for the user to make any changes to the equation, if necessary.
  • The Timecard list view has new Submitted and Approved columns.
  • The Delete button has been removed from that list view.
  • Minor cleanup changes along with functional improvements have been made to the Timecard module.
  • Functional improvements, related to support for the IH Sample and IH Sample Results entities, have been made to the 'Equation Library'.

For more information on using the 'Equation Library' for calculations, see CCC-12020 in the GX2 2024.1.0 New Features Release Notes document and the GX2 User Guide.
