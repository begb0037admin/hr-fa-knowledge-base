CCC-15202: For Monitoring and Noise Monitoring samples, % complete is now provided within a survey for both the agent and SEG under analysis

This enables the tracking, for compliance purposes, of surveys across multiple sites/groups. It also eliminates the need to keep an external spreadsheet with the number of samples collected for each SEG/agent.

Prior to this, % complete was tied to an agent and limit type only, not to any SEGs attributed to the agent. That resulted in misrepresenting % complete for SEGs because the completion calculation was looking only at agents. For instance, if there were two SEGs in a survey for the same agent, then the % complete only tracked the overall completion of the agent between the two, not the individual completion of the agent within each SEG.

Hygienists can now track their survey completion rates by agents and exposure groups, not just by agent.

For Monitoring Samples:

The ‘Percent Complete’ field calculation is now a 1 for 1 match to the plan. That is, only those that match in all of the following fields will count into the ‘Percent Complete’ calculation:

  • Agent
  • Exposure Group
  • Limit Type
  • Sample Type  

The workflow is:

  • A plan is entered on the Plan tab by an EHS professional or overseer. This specifies which samples and how many are needed.
  • The Technician then looks at the Plan tab and enters the new sample on the Sample tab.

A Monitoring SEG can now be associated with the Agent (and the samples attributed to that Agent – both area and personal).

SEG + Agent + Limit Type + Sample Type (ensuring the sample is approved) = % Complete sampling of that Agent for that SEG

Null values can be allowed in the SEG or Limit Type.
Note: 'Sample Type' and 'Agent' are currently required fields.

  • Null values should count into the % Complete calculation if on the Plan tab the corresponding fields were left null.
    • Example – The IH user has a plan with Phenol, TWA8, and Personal Sample, but Exposure Group is left null. All Samples that meet Phenol, TWA8, and Sample Type = Personal would count into the completion percentage (regardless of a SEG value or SEG null on the sample).

IH -> Sampling Plan Completion Status -> Summary and Detail Report will reflect the updated % Complete calculation. The Detail report will display the Exposure Group value beside the Agent value.

For Noise Monitoring Samples:

The ‘Percent Complete Noise’ field calculation is now a 1 for 1 match to the plan. That is, only those that match in both the following fields will count into the ‘Percent Complete Noise’ calculation:

  • Exposure Group
  • Sample Type

The workflow is:

  • A plan is entered on the Plan tab by an EHS professional or overseer. This specifies which samples and how many are needed.
  • The Technician then looks at the Plan tab and enters the new sample on the Sample tab.

A Monitoring SEG can now be associated with the Agent (and the samples attributed to that Agent – both area and personal).

Sample Type + Exposure Group = % Complete Noise sampling of that Agent (noise) for that SEG

Null values can be allowed in the SEG.

  • Null values should count into the % Noise Complete calculation if on the Plan tab the corresponding fields were left null.
  • Example – The IH user has a plan with Noise as the Agent and Personal sample, but Exposure Group is left null. All Samples that meet Noise as Agent and Sample Type = Personal would count into the completion percentage (regardless of a SEG value or SEG null on the sample).
  • The 'Exposure Group' field value can be null.
    If the 'Exposure Group' is left blank or null for the plan, for the Admin essentially the exposure group does not matter. Therefore if the Sample Type and the Agent (noise) match, the samples would count into completion percentage.

IH -> Noise Sampling Plan Completion Status -> Summary and Detail Report will reflect the updated % Complete calculation. The Detail report will display the Exposure Group value beside the Sample Type value.
