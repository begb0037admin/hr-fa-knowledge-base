CCC-17687: On a Risk Assessment, a link to external content based on hazard type can now be added

The character limit of the 'URL Link' field in the 'Agent Hazard' look-up table has been extended from 255 to 1000. This new limit is supported wherever the field can be used.

A new 'Hazard URL Link' text field with a character limit of 1000 can now be added to custom 'Risk Assessment Entry' layouts in the following areas: Safety, Safety COSHH/Process Hazard Analysis, OH/Medical, Ergonomics, IH, Environmental, Quality Design FMEA, and Quality Process FMEA.

When the user specifies an Agent Hazard (Hazard Type) on a layout that has a 'Hazard URL Link' field, then the 'Hazard URL Link' field will be populated using the "URL Link' value for that hazard from the 'Agent Hazard' table (as long as it is populated).

Note: For a single hazard, the 'Hazard URL Link' field will populate if the 'URL Link' field in the 'Agent Hazard' look-up table is populated correctly. If multiple hazards are specified, the link for the first hazard listed will populate the field.

If the 'Hazard URL Link' field is populated on the layout, then a Globe icon will appear for the 'Risk Assessment Entry' on any associated Tasks-Hazards-Controls sublists (tabs). Simply clicking the Globe icon will open the URL link in a separate browser tab. The 'Risk Assessment Entry' record will remain open in the original browser tab.
