CCC-6468: In Administrator > Logs, there is a new ‘REST API Log’

Within it, a new 'REST API Log' view and layout (ML-003852) are provided. The view has two default list views: 'All REST API Logs' and 'All My REST API Logs'.

The following items are logged:

  • All GX2 GET requests and responses.
  • All GX2 POST requests and responses.
  • All GX2 PUT requests and responses.
  • All GX2 DELETE requests and responses.

Note: For token calls, all sensitive token-related information is hidden.

For each item, the expected information is logged, including user name, date and time, request/response body, and IP address.

If your list should not be empty but is and/or you are receiving an error message, contact your Cority Administrator.

Also, the existing 'API Log' for business rules has been renamed 'BR API Log'.

For information on working with Administrator logs, list views, or layouts, see the GX2 User Guide.
