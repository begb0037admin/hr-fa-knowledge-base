CCC-18972: Improvements and fixes related to the ‘In Progress’ check box in the ‘Inspection Questionnaire’ header have been implemented

This will ensure that the inspection questionnaire workflow functions well whether completed in the GX2 platform, myCority, or a combination of the two.

This requires that the ‘In Progress’ check box be added to the ‘Non-Employee Related’ Questionnaire header (if not already present). When saving a Due/Overdue inspection questionnaire in GX2, you will be required to select the ‘In Progress’ check box and save. That will move the ‘Inspection Questionnaire’ to ‘In Progress’ for GX2 views and cause the associated questions to display.
Note: In myCority, ‘In Progress’ inspections will continue to display on the ‘Incomplete’ My Tasks list.

When the user finishes the questionnaire in GX2, he or she will deselect the ‘In Progress’ check box and save the record. That will move the ‘Inspection Questionnaire’ from the ‘Incomplete’ to the ‘Complete’ My Tasks list in myCority and to the ‘Completed Views’ in GX2.

In addition, there is a new a business rule BR-100653. This BR will automatically update the questionnaire ‘Response Date’ for an Inspection when it is completed in GX2 (that is, when the ‘In Progress’ check box is deselected). By default, this BR is inactive. Your administrator can make it active so that the ‘Response Date’ automatically updates. ‘Response Date’ is considered the completion date for Inspection questionnaires. In GX2, ‘Response Date’ auto-populates with the date the user starts the questionnaire; however, if the questionnaire takes more than one day to complete, that provides the wrong date for reporting.

Note: myCority selects the ‘In Progress’ check box automatically when an Inspection questionnaire is first saved, even though that is not visible. It deselects the check box and sets the ‘Response Date’ (completion date) when the Submit button is clicked.

These changes will make the GX2 platform workflow more consistent with that of myCority and better support the Inspection questionnaire workflow in both the GX2 platform and myCority. This will also help ensure more accurate reporting of completion date.
