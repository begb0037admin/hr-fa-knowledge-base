CCC-11146: A mechanism is now provided for bulk-synching a client site’s chemical regulations with those of the GX2 Master Library

This will help ensure the client site regulations are up to date, which will help clients maintain compliance.

The changes made to support this include:

  • A new ‘Update Chemical Regulatory Lists’ action on the Regulations list view
    • The action will add the process to the business rule action queue, run the process, and then notify the user when the process is complete.
  • A new ‘Reset Chemical Regulatory List Last Call Date’ action on the Regulations list view, for updating the date manually
  • A new ‘Reset Last Call Date’ action on the Chemical Products list view, for updating the date manually
  • On the Regulations list view, the existing ENHESA related actions have been renamed to show they are ENHESA related
  • On the Environmental 'Regulations' and Safety 'Legal & Other Requirements' sublists, unnecessary actions have been removed
  • A new 'Anonymous Master Library' role, which has the same security configuration as the 'All Sites' role without its delete capability
  • New and updated mapping from the Chemical Products 'Master Library' to client sites
  • Improved 'Master Library' logging
  • The following new fields for Regulations layouts: Universal ID, Master Regulation ID, and Cority Managed
    • The older ‘Cority Managed’ field on the Regulations layouts has been renamed ‘Maintenance Status’, but continues to function the same.
  • The following new fields for Standard Sources layouts: Universal ID and Master Standard Source ID
  • The following new fields for Limit Types layouts: Universal ID and Master Limit Type ID

The actions are securable through security role configuration.

For the fields, the equivalent columns can be added to applicable corresponding list views.

For information on working with the Chemical Products 'Master Library' or Chemical Management 'Regulations', see the GX2 User Guide.
