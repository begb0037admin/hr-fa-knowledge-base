CCC-17563: For recurring actions, a number of enhancements have been made to reduce the administrative work required

The following improvements are included:

  • The No End Date option has been enhanced so that users can simply revisit and edit recurring actions without having to reconfigure them entirely.
  • Additional applicable parameters, other than just ‘Assigned To’, can now be updated in bulk without having to end and rebuild the recurring actions.
  • The modifying of future recurrences for fields (Action Details, Assigned To, etc.) that should copy values to future actions is now much easier.
  • A Config screen is provided for specifying which fields trigger certain behavior, specifying which get copied, assisting with bulk changes, etc.
  • The performance when a large number of actions (for example, daily actions) is being created or deleted has been improved.
    Note: A more frequently recurring action (daily vs. yearly, for example) will still take the system longer to set up than less frequently recurring actions.
  • In myCority, for Actions, the ‘Is Recurrent’ check box has been disabled.

These enhancements are balanced with the need and existing capability to create comprehensive reports that include future actions (one year out for daily and weekly, five years out for monthly and yearly, etc.).

Note: Regarding actions for which you do not know the end date, to save effort we recommend you use the No End Date option. For example, a permit you are likely to renew will probably not require many changes at renewal time. If you apply no end date, then at renewal time you can simply make the small set of changes required to the existing recurring action.
