Summary of Occupational Health Enhancements

The table below lists smaller design improvements we have made in the Occupational Health cloud. The items are organized by component and the components are arranged in alphabetical order.

ItemComponent(s)Description
CCC-13470Drug Testing

Four new text UDFs (user-defined fields) and two new date UDFs are now available for adding to custom versions of Drug Test Battery layouts.

Ten new text UDFs, three new date UDFs, and two new checkbox UDFs are now available for adding to custom versions of Drug Test Results layouts.

The equivalent columns can be added to custom versions of corresponding list views.

The new fields are available for use in Query Builder, Report Writer, business rules, and display rules.

 

CCC-18072ESR Import

For employee match-checking during ESR import, the 'Organization (Trust) ID' (employee.organization.trustid) can now be excluded.

This new feature is for specifying how an employee working in more than one entity/organization will be handled by the system. For example, you might not want employees with more than one 'Organization (Trust) ID' to have more than one record in GX2 (one employee number for each Trust ID).

To support this, there is a new 'Organization (Trust) ID' check box on the ESR Config screen.

Its hover-over text reads: "This flag determines whether the 'Organization (Trust) ID' must be used when matching data on ESR import."

If the check box is selected (default), the 'Organization (Trust) ID' (employee.organization.trustid) will continue to be included in employee match-checking during import.

If the check box is not selected, the system will no longer check the 'Organization (Trust) ID' during import.

Note: This feature applies only to 'Demographics' records in GX2 that have multiple 'Job Position' records and to 'Immunization' records in GX2.

 

CCC-17705Demographics

The following new user-defined free-text fields have been added to the Demographics module: UDF_Text_7 through UDF_Text_10

Each field supports a maximum of 2000 characters.

The fields can be populated through import.

They can be reported on using Report Writer and used in business rules, business rule actions, display rules, and workflows.

The equivalent columns can be added to applicable list views.
