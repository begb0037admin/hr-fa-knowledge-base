CCC-7665: The 'OEL Adjustment' can now update automatically

The 'OEL Adjustment' (on ML-000367, or custom versions of it) will now update automatically if the 'Shift Code' is selected from the 'Shift Code' look-up table on the 'Personal Monitoring Sample' layout (ML-000579, or custom versions of it). The Industrial Hygienist will no longer have to make manual OEL adjustments for extended shifts.

This can benefit organizations that have different shifts.

In the 'Shift Code' look-up table, 'Shift Length' and 'Hours per Week' fields have been added.

If a 'Shift Code' is selected on the Monitoring record from the 'Shift Code' look-up table, the 'Shift Length' field on the Monitoring record will now display automatically and be calculated using the information from the selected 'Shift Code' look-up table value.

  • 'Shift Length' = ((Day 1 + Day 2 + Day 3, etc.) / (Total Number of days worked )) X 60 minutes, where days worked equals any day that is not null or zero.

The 'Shift length' will continue to round to nearest minute.

Also, if a 'Shift Code' is selected on the Monitoring record from the 'Shift Code' look-up table, the 'Hours per Week' on the Monitoring record will now display automatically and be calculated using the information from the selected 'Shift Code' look-up table value.

  • 'Hours per Week' = ((Day 1 + Day 2 + Day 3, etc.) / (Shift Duration)) X 7

The 'Hours per Week' will continue to round to the nearest hour.

'Shift Length' and 'Hours per Week' remain editable, but selecting a 'Shift Code' look-up table value on the Monitoring record will always override current 'Shift Length' and 'Hours per Week' values.

On the 'Personal Sampling' layout (ML-000579), the 'Hours per Week' defaults to 40. That will be overridden if 'Shift Code' is populated on the Monitoring record.
