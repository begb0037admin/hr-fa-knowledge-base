Summary of Platform Enhancements

The table below lists smaller design improvements we have made to the GX2 Platform. Descriptions of larger features follow the table.

ItemComponent(s)Description
CCC-17447, 17215, and 17501Administrator

For the following, Microsoft .NET has been upgraded to version 8:

  • The SDS microservices
  • The Ergonomics microservices
  • myCority
CCC-16326
Administrator, OH Regulatory Requirements

On Questionnaire layouts, the signature modal box can now be configured to have just the Practitioner Signature field and will now function as expected with just that field.

Adding just the Practitioner Signature or Employee Signature field will adjust the signature modal box accordingly.


CCC-9896Administrator

GX2 now provides an anti-CSRF (Cross-Site Request Forgery) token for any sensitive form available in an active, authenticated session.

 

CCC-12805
End-User

The filter display rule functionality that dynamically adjusts a look-up field's list of values based on the value in another field now works the same in myCority as it does in GX2. 


CCC-2769
End-User,
OH - Billing

When a letter that has a subquery mapped to it is generated, the subquery is rendered as a table. The letter now has a 1000-row limit for that table. If the subquery generates more than 1000 results, the table will only show 1000 rows, and an informative footer message will be displayed.
