myCority Design Improvements and Fixes

The table below lists the design improvements and fixes we have made in the myCority 2023.3.1 release. The items are organized by component and the components are arranged in alphabetical order.

Item #Component(s)ReportedDescription
CCC-15095Event Reporting2023.2.2

For Event Reports when offline, the Save and Submit functionality now works as expected.

CCC-13370Findings & Actions, Groups and Teams2023.2.0

When the 'Allow Assignment of Actions to Multiple Groups (Teams) and/or Assigned To' system setting is not selected, and the Actions layout for an action associated to a finding does not have the 'Is Recurrent' field and does have the 'Assigned To', 'Assigned To Group', and 'Complete as Team' fields, those fields now function as expected.

CCC-14942InspectionsN/A

For Inspection Questionnaires, the performance and content of the summary have been improved.

CCC-14762InspectionsN/A

On an Inspection, when the assigned employee answers a question, attaches a document and creates an action, changes the answer to the question, then saves the questionnaire, all related functionality will now work properly and without generating any unexpected errors.

CCC-15169Occupational Health – Pre-Placement N/A

In the pre-placement workflow, when an applicant bypasses the registration process and the system auto-creates a myCority user for that applicant, the out-of-the-box Applicant Profile will now be assigned automatically to the myCority user. 

CCC-14979
Occupational Health – Pre-Placement
N/A
Previously, in the pre-placement workflow, the system would only allow applicants to register if it was able to match both the employee number and email address provided. Now, the system will allow an applicant to register successfully if only the employee number matches.
All related functionality will continue to work as originally designed.
For detailed information on all of the recent enhancements to the pre-placement functionality, see the GX2 2023.3.0 New Features Release Notes.
CCC-15212
Platform – Administrator
N/A

For myCority requests that use the RESTful API, a timeout limit has been added. The new setting is located in server.config: <MyCorityTimeoutInMilliseconds>

The default is 64,800 ms (~18minutes).

CCC-14576Platform – End-UserN/A

On a record (an Event Report, for example), if the user adds text to a text field and saves the record, then adds more text to the text field and presses the Enter key, all added text will now be retained.

CCC-13618
Platform – End-User
N/A

myCority ‘My Tasks’ has new period filter settings.

The new global system setting ‘myCority My Tasks Default Period Filter for Incomplete’ has the following options: Due in Next 7 Days, Due in Next 30 Days, Due in Next 60 Days, Due in Next 90 Days, Show All / No Period.

The setting can be used to specify the default period filter that will apply to the incomplete tasks list for all myCority users.

The setting is categorized under the Portal/myCority module.

Also, the new ‘Default Period Filter’ field can be added to custom versions of the myCority ‘My Account’ Layout (ML-20003532). The field has the same options as the new system setting described above. For a particular user, if a value is specified for the field, that value will override any value specified for the new system setting.

The records in the My Tasks list can still be filtered by type, and the system setting or field value will continue to apply.

When used, these new settings can improve the performance of the My Tasks list and help users focus on the tasks they have coming due.

CCC-12189Platform – End-User 2023.2.0

On mobile devices (phones or tablets), read-only or disabled text fields are now visibly clear.

CCC-14763Quality – Permit to WorkN/A

For a workflow that is linked to a permit and has an action step with group permission and no button and an action step with no permission and a button, an approval user for the permit that has the 'Permit to Work' and 'myCority' roles will now be able to log into myCority and view the permit without encountering any unexpected issues or errors.

CCC-11989Quality – Permit to WorkN/A

For a 'Permit to Work' created in myCority that has one or more auto-created 'Finding & Actions', the Actions will now be listed on the corresponding Actions list in GX2.

CCC-14772Safety – Audits & InspectionsN/A

On an Inspection, the assigned user can now answer a multi-select checkbox question and add an action to the question without encountering any unexpected issues.

CCC-15103Safety – Audits & InspectionsN/A

For an Inspection question answered in myCority that has an attached document and added 'Finding & Action', if the user alters the response to the question and then navigates to the GX2 Safety 'Documents' list, the correct response source ID for the document will now be displayed and the 'Finding & Action' will be cleared.

CCC-15129TranslationsN/A

When applicable, in 'My Applicants', the 'Not Assigned' phrase will now translate as expected.
