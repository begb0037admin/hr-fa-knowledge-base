GX2 Design Improvements and Fixes

The table below lists the design improvements and fixes we have made in the GX2 2023.3.1 release. The items are organized by component and the components are arranged in alphabetical order.

Item #Component(s)ReportedDescription
CCC-15430Business IntelligenceN/A

The Data Cube can now process 'Findings & Actions' with descriptions longer than 1400 characters without encountering any unexpected issues.

CCC-15042Business IntelligenceN/A

When creating a business rule email action, the user can now choose for a merge field a Query Builder query that uses the Employees entity, has a title with special characters, and distribution list selected.

CCC-15014Business Intelligence, Occupational Health – Employee CareN/A

In Reports -> Medical Records, if the user prints medical documents that contain a Gmail email, that will now function as expected.

CCC-12110Business Intelligence – Query BuilderN/A

Query Builder now has a new 'User Temp Tables for Concatenate Rows' check box. The check box is under 'More Settings'. If you have queries that use the concatenate feature and those queries are running slow, selecting the new check box might help improve their performance.

CCC-3158Business IntelligenceN/A

In reports, the fields available for sorting will now translate when expected.

CCC-14818Document Control – Query Builder / Report WriterN/A

The 'Document Control Approval History' is now an available data source in both Query Builder and Report Writer.

CCC-14770Environmental – ComplianceN/A

For an applicability assessment on a location node with an ENHESA ID, if you make sure the status is 'Completed', save the record, and then select 'Get Applicable Regulation', the correct number of regulations will now be added to the assessment.

CCC-14243Environmental – Emissions InventoryN/A

The importing of STARS (Texas) data files now functions as expected.

CCC-13544
Environmental – Emissions Inventory
N/A

The following enhancements have been made in Emissions Inventory:

  • When the new ‘Calculate on Exact Reporting Period Dates’ checkbox on the ‘Reporting Period’ modal box is selected, the ‘Generate Emission Calculation Report’ action for Source Profiles will now calculate emissions only for the reporting period defined. The Emission Parameter ‘Effective Date’ will equal the Reporting Period ‘Start Date’, and the Emission Parameter ‘End Date’ will equal the Reporting Period ‘End Date’.
  • When calculating Source Profile asset sequences, each chemical DRE will now be captured in the DRE field within the Emissions Inventory ‘Emission Calculation’ table. This will enable organizations to report on chemical DREs using GX2.
  • For specifying that the ‘Emission Parameter Variable Value’ is static, the new ‘Static Variable’ checkbox field is now available to be added to custom versions of the ML-003566 layout.
CCC-8368Environmental – ESG2022.1.1

When applicable, Business Intelligence 'Metric Tree' nodes can now be inactivated.

CCC-6757Environmental – ESGN/A

For a Metrics Campaign, any assigned metric can now be deleted from the Associated Metrics list.

CCC-15435
Environmental – Waste Management
N/A
When submitting a manifest to the RCRA e-manifest system, if populated, values for the following fields will now be sent:
  • Waste Disposition
  • State Code 1
  • State Code 2
  • State Code 3
  • State Code 4
  • Federal Code 1
  • Federal Code 2
  • Federal Code 3
  • Federal Code 4
  • Federal Code 5
  • Federal Code 6
CCC-13376Environmental – Waste ManagementN/A

On the Waste Manifest 'Forms' tab, the out-of-the-box blank PDF will now open successfully and without generating an unexpected error.

CCC-15314ErgonomicsN/A

The RESTful API can now be used to successfully create GDDLOFB nodes (records).

CCC-13362Ergonomics – Case ManagerN/A

The 'Evaluation' and 'Completed Evaluations' reports are now accessible through the Case Manager ‘Reports’ link in the Ergonomics side menu.

CCC-15312Occupational Health – Appointments2023.3.0

In the Appointments module, the coloring feature now functions properly.

CCC-15016Occupational Health – Medical RecordsN/A

In Reports -> Medical Records, when in 'Print Preview' for medical documents for an employee who has at least one Gmail email document, the 'Report' option will now function correctly and without generating an unexpected error.

CCC-14795Occupational Health – Medical RecordsN/A

To the following out-of-the-box reports, the character display has been increased and word-wrapping added:

  • Audiometric Employee Hearing Summary
  • Audiometric Test Graph
  • Audiometric Standard Threshold Shift
  • Medical Record Audiometric

Also, the left and right margins have been adjusted to prevent information from getting truncated.

CCC-14239Occupational Health – Medical Records N/A

The Medical Records report can now be filtered by GDDLOFB. This will enable an Occupational Health user to filter the report according to employment location.

This does not apply to either of the 'Problem List' or Restriction' entities because they do not have GDDLOFB:

Note: This is for GX2 only. For myCority, this functionality will be added in a future release.

CCC-14981Occupational Health – Pre-PlacementN/A

For the pre-placement workflow, when a recruiter uses the 'Resend Email' action on the 'My Applicants' layout, the 'To' field will now pre-populate with the email address(es) used in the corresponding business rule(s).

CCC-15682
Platform – Administrator
N/A

There is a new global system setting labelled 'Treat Blank Query Condition Values as True'. By default, the setting is selected.

If the setting is selected, for a query with 'Equals' conditions that have blank values, the system will evaluate those conditions and return any records that conform.

If the setting is not selected, for a query with 'Equals' conditions that have blank values, the system will not evaluate those particular conditions when running the query.

This applies to all queries (in Query Builder, Report Writer, Advanced Dashboard, etc.).

CCC-15034Platform – AdministratorN/A

When a letter template contains headers and footers and the letter is printed to PDF, the printed letter will now be formatted correctly.

CCC-14692Platform – Administrator2023.2.1

For custom Demographics 'Document' layouts, the user can now successfully rename UDFDT fields.

CCC-14547Platform – AdministratorN/A

When creating a change action business rule using the Clinic Visit entity, the user can now successfully configure Field Reference as the change type without generating an unexpected error.

CCC-13855Platform – AdministratorN/A

When the DD/MM/YYYY short date style is specified in system settings, the user then answers a date-type question on a questionnaire, saves the questionnaire, and then locks it, the date will now be retained and displayed in the correct format.

CCC-13627Platform – AdministratorN/A

In the Clinic Visit module, for Flex Fields subsections, site security now functions as expected.

CCC-13307Platform – AdministratorN/A

From the Letter Templates look-up table, a letter template can now be exported to PDF successfully and without generating an unexpected error.

CCC-12163Platform – AdministratorN/A

When a language other than English is specified in system settings and the user enters a date manually in that language within a date field, the field is no longer case-sensitive and the value will now be retained.

CCC-14453Platform – Business RulesN/A

When a hard-enforce business rule (BR) is triggered and an exception occurs, the BR code will now be included with exception message in the Event Log.

CCC-15055Platform – End UserN/A

On a Clinic Visit record that has the Exam Activities tab, when the user navigates to the tab without first saving the record, selects an Exam Activity record and changes it to complete, then clicks 'Save & Close', the user will now be taken back to the Clinic Visit record, not to the list of Clinic Visit records.

CCC-12448Platform – End UserN/A

When applicable, for a Safety 'Incident', the Flex Fields entity will now be available in both Query Builder and Report Writer.

CCC-1931Platform – End User, Interfacesv2020.2.1

When using the Cority Data Integration Utility to import multiple documents into a Safety 'Incident' record, all documents will now import properly, not just the first one referenced.

CCC-14620Platform – InfrastructureN/A

SimpleInjector has been updated to version 4.10.

CCC-11214Safety – Contractor ManagementN/A

In Safety 'Contractor Management', the character limit for the Email field in 'Key Contacts' has been increased to 250. All related functionality will now support that limit.

CCC-14816Safety – Permit To WorkN/A

For a workflow linked to the 'Permit to Work' layout, the Lock Record business rule action now functions as expected and without error.
