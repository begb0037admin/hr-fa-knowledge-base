Task App Release Notes

Version Release date: 5/16/2016

  • Task App previously only showed tasks assigned to the current user. The ability to see tasks assigned to other users (where the viewer has permission) was added. A control allows turning on or off the view of tasks assigned to others.

Version 2.0 Released 7/7/2015

The Task Completion App now includes options for workflow-related tasks.

  • If the task is associated with a workflow, workflow information will be displayed and workflow fields will also be available for viewing or editing, depending on user permissions.
  • When completing a workflow-related task, users can choose the End Workflow option.
  • Task App Settings: The Task App settings are for tasks only. For workflow-related tasks, the task fields to show are configured in the Workflow tab of the Task setup screen.
  • View tasks due 'next month' and in future months
  • Attach documents (such as a picture taken with your phone) to a scheduled workflow
