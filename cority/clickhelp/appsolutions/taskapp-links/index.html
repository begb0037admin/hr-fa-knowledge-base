Email Links to the Task Completion App

Links to Apps can be configured in Notification Templates, for use in email notifications so that users can easily access their work assignments. 

Links to the TaskApp can be used in Task Notification emails. The task completion link can only be used with a custom notification set up with a Task Notification Template. Standard task email links go to the main application.

The first part of the link is the {url:basepath} macro, to which the App name is appended, followed by a slash, as shown below:

{url::basePath}TaskApp/

Three task/email related values may be specified within the link:

{task::id} – The Task ID (GUID)

{task::due date param} – The task due date and time (url encoded).

{recipient::email} – The email address of the recipient of the email

No https:// prefix is required, as the URL basepath macro link resolves to: https://go.enviance.com/goto/{SystemID}/

Some sample links are shown below. Other combinations are available. Required syntax includes using "hash" for "#" in the search part of the string.

To the Task List page {url::basePath}TaskApp/?hash=tasks
To Task Completion page {url::basePath}TaskApp/?hash=task?{task::id}?{task::due date param}
To Task Description page {url::basePath}TaskApp/?hash=task?{task::id}?{task::due date param}/description
To Settings page {url::basePath}TaskApp/?hash=/settings

To use the link in a Notification Template:

  • Create the text for the notification and add the link in the format shown above.

Use the source editor to create link text in place of the url string. In the notification editor, click the Source button to open the html editing window. Edit the text to add the link with the correct html syntax like this:

Example:

<p>To complete this task <a href="{url::basePath}TaskApp/?hash=tasks?{task::id}?{task::due date param}">YOUR LINK TEXT</a>.</p>

Be sure to remove any extraneous html that was added by the editor. Be careful that no html tags or extra spaces are inside the url.

Test the link on a test task assigned to yourself before applying the template to actual system tasks.
