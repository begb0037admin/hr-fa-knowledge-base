Release Date: Nov 30th

General Improvements & Bug Fixes

ComponentTicketDescription
WABWAB-5727The performance of Quick Search has been improved. This applies to when searching for a unique workflow ID or searching for workflows within a specific date range.
WABWAB-6054

Users no longer need to type in %%% in object selectors for an open search. Now users just need to click in the object selector textbox on a form and the first 50 (in alphabetical order) appears. To view more options, scroll down to the bottom and the next 50 will appear, etc.

Note: The wild card search %%% will still function in the updated user interface.

WABWAB-6199

When the previous step is applied to a form in the WAB, The WAB now correctly shows the previous workflow step, regardless of the complexity of the workflow.
