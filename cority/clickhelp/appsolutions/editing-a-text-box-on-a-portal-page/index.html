Editing a Text Box on a Portal Page

To Edit a Text Box on a Portal Page

  1. In the Portal, navigate to a portal page with the Text Box you want to edit, and then click the Page Settings icon.
  2. Scroll to the Text Box you want to edit on a Portal page.
  3. Click the Edit icon on the Text Box.
    The Edit Text Box window opens.
  4. Make changes as required.
  5. Click Save.

While editing the textbox if you decide you would like to delete the textbox click Delete Text Box found at the bottom left of the Edit Text Box window.
