InspectionApp Quick Link

You can set up a link to the InspectionApp on a Quick Links panel in the Portal to allow users to easily navigate to the InspectionApp in either online or offline mode.

To set up a Quick Link from the Portal to the InspectionApp:

  1. Open the InspectionApp in a new browser window by select the pop-out button for the App from the menu.

  2. Select and copy the URL for the app (Ctrl+C).
  3. In the Management System, create a Quick Link.
  4. Select Setup > Quick Links.
  5. Select New Quick Link and choose the option "To an external Web Site or Resource."

  6. Paste the URL into the address window and save.

  7. Publish the Quick Link to make it available to the desired users.
  8. Open the Portal App.
  9. Select the portal page on which you want to make the link available. In a new or existing Quick Links panel, add the Quick Link you created.

  10. For more info, see Quick Links Panel Configuration.
