Bulk Import Workflow Data Page Button

Import Workflow Data header buttons allow users to import bulk workflow data from a spreadsheet. See Bulk Import Workflows for more information. 

To guide users, you can add instructions in text boxes on the portal page and add tooltips to template cells.

To configure a bulk import button:

  1. Click Add Page Button or Add Header Button and select Import Workflow Data.
  2. Enter the Button Label, select the Color for the button, and optionally, an Icon to appear before the label.
  3. For Generic Template:
    • If users will be providing their own template, select Yes.
    • If you will be providing users with a data-stream-specific import template, select No and then click in the Template File Location field to upload the template. Once it has finished uploading, click Done.
  4. For Require all columns to be completed, select Yes if every column with a header value should be processed. If a row does not have a value for a column, that row will not be processed and will produce an error.
  5. For Allow multiple files to be uploaded, select yes to allow users to import multiple files.
  6. For Specify a workflow type, select Yes and choose a Workflow Type. If you select No and do not specify a type, the imported file will require a column that specifies the workflow type for each row. 
  7. Click Apply.

Template Tips

  • Templates can be in xls, xlsx, or xlsm format.
  • Templates can have multiple worksheet tabs but only the one named "Data Import" will be imported. The Data Import tab can contain formulas or macros but only the results are imported.
