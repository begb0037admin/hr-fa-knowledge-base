Required Form Fields

A few fields are required or recommended on the Incident Detail or Incident Type Detail forms, as they are used in dashboards or elsewhere by the App. These fields are described below.

Form Type (=Form Template name) Step Name Required Field Notes
EII-Incident Collect Incident Details

Incident Type

(EII-IncidentType)

The valid options for this multi-select list field may be customized. Each option may be associated with a specific child workflow using the Form Designer.

Field is not required but recommended for full function. Display of the various Detail Type pages (which represent the child workflows) is set up via Conditions based on user selection(s).

OSHA Recordable

EII-OshaRecordable)

Required. True/false checkbox. Default value is false.

Risk Rank

(EII-RiskRank)

When the user clicks the button on this field a pop-up appears so the user can select a value for the field from a matrix. For configuration details, see Risk Rank Matrix.
EII-IncidentType-InjuryOrIllness Log Incident Details

Injury Or Illness?

(EII-InjuryOrIllness)

 Required. Dropdown list with 2 values (Injury/Illness).

Body Part

(EII-BodyPart)

 Required if Injury Or Illness? = Injury. Multi-select list.
