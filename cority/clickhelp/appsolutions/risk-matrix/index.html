Risk Matrix

The Risk Matrix field is designed to allow a risk value to be assigned to any Advanced Workflows (WAB) app that contains a numeric dropdown list. The field may be used to prioritize severity of responses. The matrix is configurable according to your own requirements and purpose. The user selects a value to assign to the field by selecting a cell from the matrix in the pop-up dialog.

View and use a Risk Matrix in a Workflow

  1. Navigate to a numeric dropdown list in a workflow step.

  1. Under the Risk Matrix field click the Matrix icon.
    The Risk Matrix window will open.

  1. Select a cell based on the Risk Matrix that you want to observe.
  2. Click Save.
    The Risk Matrix Color and numeric value will display in the Risk Matrix icon, and to the right of the icon you will see the likelihood along with severity of the value selected.

Configure the Risk Matrix

 To configure the Risk Matrix.

  1. From the main menu dropdown, select a WAB.
  2. From the WAB main menu dropdown, select Designer to open Forms Designer.
  3. Click the Forms tab.
  4. Click the Form Type dropdown textbox and select a workflow.
  5. Select the Workflow Step where you would like to create a Risk Matrix.
  6. In the Fields Section, scroll to a field that contains a numeric dropdown list in which you want to set up a Risk Matrix.

  1. Under Control type, select Risk Matrix.
  2. Once Risk Matrix is selected, click Risk Matrix Setup.
    The     Risk Matrix Setup window will open.
  3. To add a column, click Add Column.
    A column is added to the right of the Risk Matrix table.
  4. To remove a column, click Remove Column. 
    A column is removed from the right of the Risk Matrix table.
  5. To add a row, click Add Row.
     A row is added to the bottom of the Risk Matrix Table.
  6. To remove a row, click Remove Row.
    A row is removed from the bottom of the Risk Matrix table.


    1. To edit a heading cell, click either a Row Heading Cell (on the left of the table), or a Column Heading Cell (on the bottom of the table).
      The       Cell Setup window will open.

    1. In the Cell Setup window, input a text value, select a text color, and select a background color for the cell.
    2. Click Set.
    3. For the cells within the table, click the cell.
      The cell setup window will open.
    4. In the Cell Setup window, select a value from the Value dropdown textbox, select a text color, and select a background color for the cell.

    1. Click Set .
    2. Once the Risk Matrix Setup window is setup the way you want, click Save.
