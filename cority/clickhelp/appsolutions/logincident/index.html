Log New Incident

To log a new incident:

  1. From the home page, select Log New Incident, or from any other screen, use the button at the top of the page.

  2. Enter an Incident Name.

  3. Select the facility where the incident occurred and the employee.

    In the Facility box, enter a few characters for the facility name, then select the facility from the matching results.

    In the Employee box, start typing employee name (first or last), then select the employee from the matching results.

    To see a list of all Facilities or Employees to select from, type %%%.

    You may add more than one employee or facility by repeating the search.

  4. Select the Incident Type box then select the type from the dropdown list. If more than one incident type is involved (i.e., Vehicle and Property Damage), select the box again to add another type.
  5. Select an Incident Date and the Time of Incident.
  6. Enter an Incident Description.

  7. Select Submit Incident.

    You may be required to choose an assignee for the next step, unless assignment is automatic. If you are working offline, you will have to wait until you are connected to transition the workflow.

    To assign the next step, select from the users or groups offered. You can click the plus sign to show users in the group and select an individual.

If you are automatically assigned to the next step, the main (parent) incident form will be displayed, which includes details to complete, depending on the type of incident. Action buttons are available at the top to create other forms, depending on the incident type(s), such as witness details, root cause, etc. See Log Incident Details.
