Version 2023.1   

Release Date: March 21st

New Features

  • In Form Designer a new setting called “Reprocess on Source Field Value Change” has been added. When this setting is checked for, each field with default values in the WAB will now be reprocessed (computed, recomputed, and written to the workflow).

Note: Field values not retrieved from the server (offline, connectivity, etc), will not be reprocessed. 

  • On the WAB, a “Clear Cache” button has been added on the config offline panel to clear the whole browser's cache without losing sensitive data and pending transactions.
