Administration and Configuration

The InspectionApp will be configured for use by Cority in the customer implementation process. However, company administrators may need to perform some tasks to keep the app up to date with changes in users and equipment. 

Some common administrative tasks include:

  • Edit the Inspectors who are allowed to create inspections in the app. See Manage App Users.
  • Edit the assignees for corrective actions to account for personnel changes. See Manage App Users.
  • Add or edit Inspection Points. See Edit Inspection Points.
  • Edit the Facility information (manager, address, phone) that is displayed in the InspectionApp. See Division and Facility Info.
  • Create new inspection types with the required forms and questions. See Create or Edit Inspection Forms.
  • Set up new scheduled workflows. See Scheduled Inspections.

Configuration Details

The facilities and equipment shown in the App interface are System Model tree components whose details and visibility are controlled through a combination of object properties and Tags. For details, see:

  • Facility and POI Details

Whether or not an inspection type or a specific question in the inspection is applicable to a particular inspection point is determined by the configuration of the questions. Library questions are used for current configurations. A few older implementations may still use the Legacy question configuration.

  • Library Questions
  • Legacy Questions (pre release version 2.2)

The actual inspection records are stored in a set of process workflows which are pre-configured for the App. These workflows should not be edited. For information, see:

  • Inspection Records

The inspection types, the questions associated with them and the findings and corrective actions are defined as workflows. For details on their configuration, see:

  • Inspection Definition Workflows
