Generate QR Codes  

QR codes can be generated to link directly to a specific portal page or a pre-filtered quick entry panel for easier data entry. The URL for the QR code can be built automatically using the Generate QR Code option on a portal page or manually using URL parameters.  

Generating a QR code for an existing page 

QR codes can be generated to link directly to a specific portal page. This can be useful for users who need to land on a certain page. For example, users who manage inspections may want to navigate directly to a page where they can see their current and previous inspections. 

To generate a QR code for an existing page: 

  1. From the Portal page, click Settings.  

  2. Click Generate QR code and select This page.  

  3. Configure the QR code:

    1. Image - Choose an image to display in the center of the QR code.

    2. Image Size - Select the size of the image.

    3. Label - Enter a label to display below the QR code. 

  4. Click Export as Image or Export as PDF. 


The QR code generated will open to the portal page when scanned.  

Generating a QR code to a Quick Entry Page 

QR codes can be generated to link to a pre-filtered page for quick data entry. This can be useful for users who need to frequently enter data for one or more assets. For example, users can scan a QR code and be taken to a quick entry panel that is pre-filtered for an asset, where they can then enter data.  

The quick entry page does not exist within the portal and can only be accessed from the QR code URL. Users can navigate back to a specified portal page after entering data or scan another code to continue entering data.  

To generate a QR code for a filtered page:  

  1. From the Portal page, click Settings.

  2. Click Generate QR code and select Quick entry page. 
  3. Configure the QR code:
    1. Location - Select the requirement(s) to include. You can use the Division, Facility, Unit, and POI options to filter requirements.  
    2. Date Range - Choose the date range of data to display on the page.  
    3. Interval - Choose the interval to show for data entry. 
    4. Back to Portal Page - Select a page for users to navigate to from the Quick Entry Page. If no page is selected, users will be taken to the last page they visited.  
    5. Image - Choose an image to display in the center of the QR code. By default, this will be the Cority logo.  
    6. Image Size - Select the size of the image. 
    7. Label - Enter a label to display below the QR code.  
  4. Click Export as Image or Export as PDF.  

The QR code generated will link to the Quick Entry Page where users can enter the required data. For more information on entering data from a Quick Entry Page, see Quick Data Entry from QR codes. 

Building URLs for bulk QR code creation 

When many QR codes are needed, you can create them in bulk using a third-party QR code creation tool. Many tools allow you to import an Excel sheet with URLs from which to create QR codes.  

You can build a URL for a Quick Entry Page using the following URL format:  

#/baseURL?requirements&fromType&fromUnit&fromCount&fromAbsolute&toType&toUnit&toCount&toAbsolute&interval&intervalNumber&datesSelect&backPageId 

Parameter 

Value 

Description 

requirements 

11111111-1111-1111-1111-111111111111[,22222222-2222-2222-2222-222222222222...] 

Requirements GUIDs.  

For multiple requirements, GUIDs must be separated by a comma.  

This parameter is required.  

fromType 

[0-5] 

Number from 0 to 5: 

  • 0 = absolute, 1 = current, 2 = prior to current date, 3 = after current date, 4 = previous, 5 = next. 

  • Default = 1 (current) 

fromUnit 

[0-4] 

Number from 0 to 4: 

  • 0 = day, 1 = week, 2 = month, 3 = quarter, 4 = year 

  • Default = 1 (day) 

fromCount 

[1+] 

Positive integer. 

Default = 1 

fromAbsolute 

[YYYY-MM-DD] 

Date in format YYYY-MM-DD. 

Default = current date 

toType 

[0-5] 

Number from 0 to 5: 

  • 0 = absolute, 1 = current, 2 = prior to current date, 3 = after current date, 4 = previous, 5 = next. 

  • Default = 1 (current) 

A value of 2 (prior to current date) is not applicable for "to" and will be changed to 3 (after current date). 

toUnit 

[0-4] 

Number from 0 to 4: 

  • 0 = day, 1 = week, 2 = month, 3 = quarter, 4 = year 

  • Default = 1 (day) 

toCount 

[1+] 

Positive integer.

Default = 1 

toAbsolute 

[YYYY-MM-DD] 

Date in format YYYY-MM-DD. 

Default = current date 

interval 

[Minute | Hour | Day | Month | Quarter | Year] 

Interval type.  

Default = Day 

intervalNumber 

[1+] 

Positive integer. 

Default = 1 

datesSelect 

yes 

If present and value = yes, dates can be selected in quick data entry panel. 

If absent or not set to yes, dates cannot be selected. 

backPageId 

11111111-1111-1111-1111-111111111111 

GUID of page to return to from quick data entry panel. 

If absent, the last visited page will open (default Portal navigation).
