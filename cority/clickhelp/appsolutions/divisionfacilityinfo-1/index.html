Division and Facility Info

Facilities shown in the InspectionApp as part of the Facility List are grouped by Division. In order to be visible in the InspectionApp, a facility:

  • Must be under a parent Division
  • Have the tag EIA-InspectionAppConfiguration: EIA-InspectionAppFacility.

Users must have at least Report permission on the Divisions and Facilities. Users will only see those facilities for which they have this permission.

The Facility details (address, phone) are derived from the standard object properties. The Facility Manager is a custom property. The geographical coordinates (longitude and latitude) are standard object properties and are used to locate the facility on the map.

The following properties are used in the InspectionApp:

To edit the Facility information:

  1. Select System Model from the menu button.

  2. In the System Model tree, find the Facility. Right click the Facility and select Edit.

  3. After making your changes, click Save.
  4. To remove a Facility from display in the InspectionApp, in the Tags section of the Facility properties, remove the tag EIA-InspectionAppConfiguration: EIA-InspectionAppFacility.
  5. To rename the Facility or Division, right click the Facility and select Rename.
