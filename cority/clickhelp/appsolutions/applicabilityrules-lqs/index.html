Inspection and Question Applicability

Tag Schemes and Tags are used with a Library Question configuration to define the applicability of an inspection type to an area and specific questions to an inspection point.

For configurations prior to version 2.2, see Applicability Rules for Legacy Questions.

Library Questions are configured as workflows associated with a library object. The library object is a non-numeric requirement that must have one Tag from the Tag Scheme called EIA-InspectionType which is used to identify inspection types that use Library Questions.

The library objects and their associated workflows are independent of inspection points and are organized in a separate part of the system model tree as a question library.

Additional tags are used to determine the inspection points to which the questions apply. Tag Schemes and Tags are applied to the library objects and to the objects representing the inspection points and their parent objects.

One or more Tags may be applied to the library objects and to the inspection points (and their parent objects) to define the applicable criteria. Each Tag Scheme can be considered a property and each Tag can be considered a value. The tag scheme-tag, or property-value, selections are filtered dynamically.

Example:

Question ID "POC1-Q2-Widget-Acme-009" workflow is associated with an inspection library object which has these Tags (Tag Scheme: Tag).

Manufacturer: Acme

POI Type: Widget

POI Type: Gadget

The question will apply to Inspection Points with Tag Schemes and Value:

Manufacturer: Acme AND (POI Type: Widget OR POI Type: Gadget)

Tag values may be inherited from parent objects, so could be applied at different levels of the tree.

The System Model has this sample Facility-Unit-POI structure, with tags applied:

Facility 123

Machine Shop A (Tag Scheme: Manufacturer; Tag Value: Acme)

Drill (Tag Scheme: POI Type; Tag Value: Widget)

Machine Shop B (Tag Scheme: Manufacturer; Tag Value: Black)

Drill (Tag Scheme: POI Type; Tag Value: Widget)

Result: Question "POC1-Q2-Widget-Acme-009" will apply to Machine Shop A, but not to Machine Shop B.

Machine Shop A meets the applicability criteria:

Manufacturer: Acme AND (POI Type: Widget OR POI Type: Gadget)

Machine Shop B does NOT meet the applicability criteria because only one criteria is met:

Manufacturer: Black AND POI Type: Widget

Any number of Tag Scheme:Tags may be applied and used as filter criteria for inspection questions. Tag Schemes applied to the Inspection Point (and its parents) which do not relate to those applied to the question library objects are ignored.
