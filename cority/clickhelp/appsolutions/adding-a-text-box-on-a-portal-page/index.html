Adding a Text Box on a Portal Page

To Add a Text Box on a Portal Page:

  1. In the Portal, navigate to a Portal Page, and then click the Page Settings icon.
  2. On the Page Settings window, click +Text Box.
    The New Text Box window appears.

  1. To select the background color of the text box, click the color box, and then click a color from the options displayed.
  2. If you want a border for the textbox click yes under Border.
  3. To select the Text color that will be in the text box, click the Text color box, and then click a color from the options displayed.
  4. To edit the text alignment that is to be displayed in the textbox, under Text Align, click align left, center, or align right.
  5. Input content into the Text textbox.
  6. Click Create.
