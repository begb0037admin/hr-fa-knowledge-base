Data View Tables in the WAB

Data View tables in Form Fields allows users to include templates that can be used for various workflow use cases. This includes variables such as facility information, lists of assets, and attributes associated with the listed assets. Providing this information in a tabular format allows information to be presented in an efficient manner for end users. Data View tables allow users to have all related workflow items to be displayed in one table, rather than in multiple fields.
