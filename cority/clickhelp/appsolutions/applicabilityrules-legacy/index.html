Applicability Rules for Legacy Questions

Legacy questions are used in InspectionApp configuration prior to release of InspectionApp 2.2. The workflows that define the questions are directly associated with the inspection points to which they apply.

When the user selects an area and starts a new inspection, the inspection types dropdown list is filtered the inspection points at that area. Based on the inspection type, the app presents the user with all of the Inspection Points to which at least one question in the chosen inspection type are applicable.

Whether an inspection type applies to a particular inspection point is dependent on the question workflows associated with the inspection point. If no questions of an inspection type are applicable to the inspection point then that inspection type does not apply to that inspection point. If at least one question is associated with the inspection point, then the inspection type applies.

The list of questions presented for an Inspection Point will be only those where the question definition workflow is associated with the inspection point object.
