Portal Release Notes

Version 2026.2

Release date: July 14th

New Features and Enhancements

  • On Bulk Workflow panels, the following updates are now available:
    • A new option is available to allow users to create new workflows directly in the panel.
    • A new option is available to allow users to attach documents to workflow instances directly in the panels. 
    • When configuring the panel, a specific folder can be selected for where attached documents are uploaded. When set, if users attach documents to workflow instances, they will not be able to select a different destination folder. 
    • A new 'Select All' button is available for columns that close or transition workflows.

Version 2026.1

Release date: March 24th 

New Features and Enhancements

  • On panels with filtering, multiple filters can now be configured before the panel is filtered. Once all filters are configured, users can click the 'Apply filters' button to filter the panel. Additionally, the following new filters are available:
    • For text filters, there is now a 'is not empty' option.
    • For date filters, there is now a calendar picker to accept dates. There are also several new filter operators.
    • For number field filters, there are now additional operators, 'Between', 'Greater than', and 'Less than'.
  • On Bulk Workflow panels, the following updates are now available:
    • The Edit column on the far left of the table will now always remain frozen.
    • When configuring the panel, the left-most column now includes a 'Freeze column' option. For each column that is frozen, the next left-most column will have the option.
    • A new download option is available for documents columns. Multiple documents can be selected for download.
    • A new option is available is export the panel to an Excel file.
  • For iFrame panels, SSO can now be configured to allow automatic authentication when viewing embedded PowerBI reports.

Version 2025.3

Release date: November 11th 

New Features and Enhancements

  • QR codes that link directly to a pre-filtered quick entry page can now be generated to make data entry more efficient. The QR code can be built using the new 'Generate QR Code' option in the settings of any portal page. The quick entry page cannot be edited and can only be accessed from the QR code. Users can navigate back to the portal after entering data or select the 'Scan another QR code' option to continue entering data.

    Fixes

    PORT-6109  An issue causing requirement names to display incorrectly has been fixed.

    Version 2.5

    Release date: 3/23/2017

    • Link from Table to EMS App

    A configurable set of Links has been added to the “Link” Action in the Workflow Panel which allows for direct navigation to a record in the appropriate App (via a new browser tab). The Link can be configured per workflow type inside the Link Action for any given Panel with these options:

    • Platform Link: Opens the workflow form in the Management System (in a new tab). (Same as existing Platform Link.)
    • Portal Form: Opens the workflow step form in the portal. (Same as existing Form action.)
    • EMS App: Opens the item in the appropriate EMS app (global apps only), when the panel shows workflow data from another app (InspectionApp, AuditApp, IncidentApp or MOCApp). The App will load in a new tab.
    • URL Macro: Functions similar to syntax for email notifications. Designed to support Custom WAB Apps.

    Release date: 2/24/2017

    • Desktop UI was re-designed to minimize headers and maximize viewing space. Page Library, Panel Library and Offline Data buttons were moved to smaller icons above the page menu.
    • Panel and page settings were consolidated under one Settings button. Page and Panel editing functions were added directly to Object Selector and Date Range selector and to other relevant locations on the page.

The Requirement alias is stored in a custom field on the Requirement. In addition, the path to the requirement (parent objects) be shown as full or partial, or disabled altogether in the column head.
    • Table data may be downloaded to Excel for numeric data, workflows and events.
    • Workflow and Event panels allow users to select the columns to display, in the same way as Numeric Data panels. Users can click a button on panel header, then turn display on or off for different columns.

    Version 2.1

    Release date: 8/1/2016

    • Object Selector Improvements (All Panel Types):

      Page Settings Object Selections and Property Filters now apply to both the runtime Page Object Selector (same as previous) AND every Panel on the Page (new). Page level selections no longer are auto-selected and disabled in the Panel; instead, they are merely used as a filter on the available options for the user to select in the Panel.

      The Numeric Panel requirements grid is now limited to the scope selected in the Page and Panel Settings. Previously, those Settings were only applied when the user selected far enough down into the Object Selector. Now, they are applied as filters on the relevant requirements immediately when the panel loads at runtime.

      As a result, pages and panels can be re-used more easily and there is less confusion for designers as object selections and filters are now globally applied from the Page down to the Panel.

    • Workflow Panel Inline Filters for Tables and Charts allow users to filter data displayed by any field shown and view aggregations based on different filter settings. Chart result sets can be quickly filtered to analyze the data for relevant business conclusions. Designers can set up a table containing workflow data with filters already applied to either hidden fields added to the table in Settings or pre-applied to visible fields that the user can change at runtime.

    • Workflow Panel Table UI Enhancements:

      Multiple values for fields such as Assignee and multi-select fields now display more clearly separated by new lines and with text wrapping. When values exceed character limits, the user can click on the cell to see the full text.

      For Workflow Panels, fields with value histories display the value relevant to the date of the workflow instance.

      For both Numeric Panels and Workflow Panels, user settings for column width, column order and filtering were formerly lost when a page designer edited the panel. Now users' settings for column width and column order will be retained when changes have been made. Settings for page designers will be reset in order for the designer to see the effects of changes in default view.

    • Parent/Grandparent Workflow Fields Included in Table/Chart. This allows for more relevant data and filtering options, such as filtering and ordering corrective actions by parent or grandparent.
    • Workflow Form View/Edit: Users may now select a workflow from the Workflow Panel and view or edit the workflow (at the current workflow step). After editing a form, the user can save or cancel changes. Users may also choose to end a workflow from the form. All actions are subject to user permissions.
