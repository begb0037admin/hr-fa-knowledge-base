Connect to Cloud Storage

For large data sets, you can connect to and transfer data to your own data lake. The connection can be configured to publish on a schedule, or you can manually publish data as needed. 

 To set up a list of connections, please contact the Cority Support Team. For each connection, you will need a Name, Description, Address, Port, Username, and Password. Currently, only SFTP connections are supported.

To connect a data view: 

  1. In the Data View, under Cloud Publish, click Add.    

  1. Configure the following connection settings:

    • Connection – Select a connection option.

    • Mode – Select a recurrence; One-time with Split, Recurrent, or Recurrent with Increment.

    • File Format – Select a file format, either CSV or Parquet.  

    • Path – Enter the data path. 

    • Cron expression – Enter a string to define the schedule at which data should transfer.

    • Split column - When the One-time with Split mode is selected, choose a column from the data view to split. 

    • Incrementing column - When the Recurrent with Increment mode is selected, choose a column from the data view to increment on. 

    • Start from - When the Recurrent with Increment mode is selected, choose the start date. 

    • Resuming Mode - When the Recurrent with Increment mode is selected, choose how to handle suspended periods.

    • Suspended – Select the checkbox to turn off cloud publishing.  

  1. Click Save. 

 In the Data View, the Cloud Publish status indicates that the data view is connected to cloud storage.
