Selecting When a Field Action is Required Upon in a Form

  1. In the Designer mode, under the Fields ribbon of a particular workflow, click Global Field Actions Settings found on the right of the Fields ribbon. A drop-down window appears. 

    Global Field Actions Settings can be used to set when field actions are required upon, and to set which field actions user can create their own actions for.


    1. In the Field Actions Required Upon section, you can select when the field actions will be required upon, whether is it when you click Save on the form, or at a particular transition.
    2. In the All Users to Create Their Own section, select all the Field Actions you want to allow users to create their own actions for, and click Apply to All Fields.
    3. Click Save at the bottom right of the designer screen.
