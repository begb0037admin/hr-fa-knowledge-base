Editing an Existing Object Selector

To Edit an Existing Object Selector:

  1. From the main menu dropdown, select Designer to open Forms Designer.
  2. Click the Forms tab.
  3. Click the Form Type dropdown textbox and select a child workflow type.
  1. Click the Workflow Step dropdown textbox and select a workflow step where forms are present.


  2. Click the Fields ribbon.
    The Field ribbon will expand with a menu of Field types below it, and two sections display to the right, Header Fields, and Field Sections. 
  3. Scroll through the Fields Sections to find an added Object Selector Field.
  4. To update the name of the Object Selector, click the Editicon to the right of the Object Selector name.


    1. Type in the name you want the Object Selector to be called.
    2. Click the check mark to the right of the Object Selector name textbox.


    3. To edit the location level search results for the object selector, Click the plus icon.
      The Object Selector window expands.


    4. Select whether you want to Object Selector to populate results that are either at the Division level, Facility level, Unit level, or POI level.
    5. When multiple Objects are selected, select the Enforce Hierarchy checkbox so that objects of varying levels can be organized and filtered by the higher object level.
    6. When Allow Multiple is selected, end users on the form can select more than one object in the object selector dropdown textbox.
      This can be used when more than one object is to be inspected.
    7. Click Save.
