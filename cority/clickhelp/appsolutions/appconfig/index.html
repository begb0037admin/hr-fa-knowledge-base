IncidentApp Configuration

The IncidentApp is provided as a global app with a default configuration that includes several incident types. There are many options for customization.

Incident types may be chosen to suit the customer. The default incident types supplied may be disabled if they are not needed. New incident types may also be created and added to the app. See Edit Incident Types.

Incident forms are customizable and may contain any custom fields the customer desires to suit their process. The process can be modified with conditions defined within the forms. See Form Designer.

The main system configuration assumes a set of facilities and a set of employees. These system objects will need to be configured in the system. See System Objects (Facilities and POIs).
