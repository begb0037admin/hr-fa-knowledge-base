Inline Assignment Based on Control Content Settings

Control Content settings determine which specific entities (users and/or user groups) will display for the user to select from in the Assignee textbox. List options displayed in the Assignee textbox, may be all users and user groups in the system or workflow specific users and user groups. For example, if a workflow has to do with the investigation team, specifically the safety investigation team, then that user group and the users in the that user group may display as the only options to select from in the Assignee textbox.
