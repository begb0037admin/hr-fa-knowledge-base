Download Workflows to Excel

You can download workflow data from the Workflows panel and the Bulk Workflow Management panel to Excel, for use in reporting or other purposes. Before downloading workflows, you can set the column display and date range to show only the desired data to download.

To download the contents of the table to Excel:

  1. Set the table to display the data that you want to download, including the date range and columns.

    See Edit Workflow Column Display to choose the columns. Only the visible columns will be downloaded.

  2. Click the Export button.

    All rows matching the date range and visible columns will be included (even if the rows are not visible due to panel size).
