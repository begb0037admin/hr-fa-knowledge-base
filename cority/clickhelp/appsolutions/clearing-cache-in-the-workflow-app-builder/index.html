Clearing Cache in the Workflow App Builder

Clearing Cache is available in the Work Offline section of Advanced Workflows (WAB). The Advanced Workflows (WAB) cache can be cleared without losing sensitive data and pending transactions. Many systems use browser cookies to store session information. Sometimes these cookies can be corrupted resulting in data display issues. This section explains how to clear your cache and cookies in Advanced Workflows (WAB).

To Clear Cache in the Workflow App Builder:

  1. In Advanced Workflows (WAB), click the Main menu button.
  2. Select Offline Settings from the main menu.

    The offline Data window opens to the right of the page.

  3. Click Clear cache.


    The Clear cache prompt opens. 

  4. On the Clear Cache window, you can clear cache two ways:

    1. If you want clear cache for the current Advanced Workflows (WAB) instance in use, click Ok.

    2. If you want to clear cache for all instances in your browser, toggle Clear all site data on, and then click Ok.

In your Advanced Workflows (WAB) browser, if you choose to clear all data from an instance you have open in one tab, that will also clear the data from any instances you have open in other tabs. The current tab will reload, but each of the other instances will have to be reloaded for them to function properly. This will not affect anything in any other browser tabs.
