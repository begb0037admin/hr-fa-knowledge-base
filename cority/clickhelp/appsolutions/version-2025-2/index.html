Version 2025.2

Release Date: July 1st 2025 

New Features

  • For numeric and text fields, the following macros can now be used to pull the number of days or hours between two dates or date/times: 
    • {DateDiffDay::Date field 1:Datefield 2} 
    • {DateDiffHour::Date field 1:Datefield 2} 
  • For numeric and text fields, the following macros can now be used to pull the specific date part from a specified field: 
    • {DateParts::Month:field} 
    • {DateParts:Day:field} 
    • {DateParts::Year:field} 
  • For text fields, the following macro can now be used to pull the month from a specified field: 
    • {DateParts::Monthname:field} 
  • Date and time fields can now be set using data view fields in date and time formats.  
  • In the Form Designer, the following new options are available for default values for dates: 
    • Use {x} days before today 
    • Use {x} days before {field}
