Run Report Page Button 

Customized Run Report page buttons can be added to a specific page in the portal, based on Data view. The page buttons will display at the bottom of a given portal page. Users can have set formats in populating excel reports with an excel template included. Users can also create reports based on their contextual datasets. The reports can be customized based on user’s preferences such as compliance objects, date ranges, and fields on the report.

To Run a Report using a Run Report Page Button

  1. Scroll to the bottom of the page and click a Run Report page button.


    The Run Report window will open. 

    1. Under Report Objects, click Select.
      The Compliance Object Filter  window will open.


    2. Filter for the Object of interest, by filling in the dropdown textboxes.
    3. Click Apply.
      1. The Compliance Object Filter window will close.
      2. On the Run Report window, click Run Report.
      3. A spinner icon will display in the header of the portal page indicating the excel file is being created.
      4. The Report Log window will open, once the excel report is generated. 


      To download the excel document, on the Report Log window, click the green download button.

      The Report log, that has a green download button is the report that was just generated but has not been downloaded. The Issued date and time will also be an indication of when the Report was generated. The Report logs, that have a blue download button indicates that the generated excel document was previously downloaded and viewed.

      If there is an excel template included, the excel document being downloaded will include the template format. If an excel template is not included, the excel document being downloaded will have the same format as panel exports.

      If sub-report(s) were configured for the Run Report header button, they will also be included in the excel document as tabs.

      To add a customized Run Report Page button

      1. In the Portal, navigate to a portal page, and then click the Page Settings  icon
      2. On the Page settings page, click + Page Button.
      3. Click Run Report.
        The Run Report window will open.

      1. On the Run Report window, enter a Button Label. 
      2. Select a button color and an icon.
        A preview will display next to the Button Label field. 
      3. Fill in all mandatory field (*).
      4. Fill in remaining fields, as required.
      5. To create the Run Report page button:
        1. Click Create. The Run Report window will close, and the Run Report page button is created at the bottom of the page.
        2. Click Report Designer.
          The Run Report page button is created, and the Report Designer window will open.

      On the Report Designer window, the Report name will be the same value inputted in the Worksheet textbox on the Run Report window.

      1. To add fields that you would like to include on your report, in the Field Selector section (left navigation panel) search fields using the search textbox, and click + to the right of a field. The field will move to the Applied Filters section.  
      2. To open a Column Edit window, left click a column field.
      3. To remove a column field, on the Column edit window click Remove Column.

      1. The field is removed and will display in the Field Selector Section.

      By default, the first 10 fields will be added to the report. 


      1. If there is no existing excel template associated to the Run Report page button:
        1. Click Upload Excel Template button to import an excel template.
          The Upload File window will open.


          1. Drag or browse for the file you want to upload.
          2. Once upload is completed, click Done.

        1. If there is an existing excel template associated to the Run Report page button, the button is replaced with a drop-down textbox value set to Template uploaded.​


        1. To edit an uploaded template
          1. Click the drop-down textbox and click Edit Template.
            The Upload File window will open.
          2. Upload the updated excel template.
            The new template will be saved as a new version of the original template.
        2. To view an uploaded template
          1. Click the drop-down textbox and click View Template.
            The template will be downloaded and can be opened.
        3. To delete an uploaded template
          1. Click the drop-down textbox and click Delete.
            A “This will remove the template and all its previous versions. Are you sure?” prompt appears.
          2. Click on the message to confirm.

        1. To add Sub-Reports, click the + icon to the right of the Sub-Reports section.

        Sub-Reports contain more specific information that can be linked to the main report but will not display on your main report.

        The Sub-Reports section expands below.

        1. In the Sub-Reports section, fill in all fields.
        2. To add another sub-report, click + Add sub-report.
        3. To filter for a date range in which you want to view a data report, click the Date Range textbox.
          The Data Range window will open.

        1. Users can select a pre-existing date range or Add New Date Range.
        2. Click Apply.
        3. In the Table Column Settings section, click a Columns Field.
          A Fields window will open.
        4. To name the Field, fill in the Column Label name.
        5. To turn on runtime filter capability, toggle on the Filter at Runtime option.

        1. Click Apply.
        2. Click Report Objects textbox.
          Report Object Selector window will open.  

        1. Fill in information as needed, and select preferred settings, and then click Apply.
          The Report Object Selector window will close.
        2. Click Save.
