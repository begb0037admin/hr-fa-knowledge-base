IncidentApp Navigation

If the IncidentApp is not displayed by default when you log in, open it from the menu. 

From the default login screen you can create a new Item (or record) using the large button on the welcome page or the small button top right.

After opening the App in a separate tab, add the page to your browser bookmarks to access it directly in future. If you will be working offline, you will need to use this link to access the offline data cache.

For other options, select the menu button top left.

Access a specific incident record

  1. From the main menu dropdown, select Quick Search.
    A list of current incidents is displayed, with summary info. You can use the search options to filter the list. Search by date range or a text string. The text search includes all visible text fields in the summary (ID, facility, name, status).

    When you are offline, only the records that have been downloaded for offline use will be displayed. When you re-connect, refresh the search to search online records.

  2. Select an incident from the list to open the record.
    The incident details are displayed. Tabs contain related forms for sub-processes or requested actions.
    An optional Process Bar may be displayed to give an overall view of the workflow progress. You can hide or show the Process Bar with the button to the right of the action buttons.

To see your assigned action items, from the main menu dropdown, select My Actions. The actions or other secondary items assigned to you are displayed.

Other menu items

The following other menu items are available in the IncidentApp:

Metrics: Allows entering facility data to calculate incident rates and lost/restricted time rates. (Used in the Incident App.)

Charts: Displays the dashboards.

Reports: Allows you to select and run a report for specified dates.

Designer opens the Form Designer for editing forms. It is only available if you have the appropriate permission.

Offline Settings opens the Offline Data dialog for viewing cached data and editing settings.
