Version 1.0 Release date: 8/12/2020

The User Management App allows administrators to create and maintain universally unique identifier (UUID) mappings that link user accounts across different platforms. This allows end users to access each of their Cority applications using a single login, eliminating the need to log in and out of each application.

Features: 

  • Users can create or delete links between user accounts
