Inline Assignment Based on Default Value Settings

The Assignee textbox may or may not be auto populated with assignees which can either be users and/or user groups.

To add an Assignee to a blank Assignee textbox:


  1. Click the Assignee textbox.
    A dropdown menu appears based on Control Behavior settings and Control Content settings.
  2. Select Assignee(s) from the dropdown menu.
    As you select users/user groups, they will be added to the Assignee textbox.


  3. Once all the appropriate assignees have been selected, click outside the menu for the menu to disappear.


  4. Ensure all other appropriate fields have been filled in, and then click Save (Action Name).

To add an assignee to an auto-populated Assignee textbox:

  1. Click Edit at the top right of the Assignee textbox.
    The Assignee text box is cleared.


  2. Click the Assignee textbox.
    A drop-down list displays with two sections, the top section is titled as Current with users or user groups in bold, and below it is a list of users or user groups based on setting in designer more of the control behavior section.


  3. Select Assignee(s) from the dropdown menu.
    As you select users/user groups, they will be added to the Assignee textbox.
  4. Once all the appropriate assignees have been selected, click outside the menu for the menu to disappear.


  5. Ensure all other appropriate fields have been filled in, and then click Save (Action Name).

To add an Inline Assignee in Designer Mode

  1. Click the Fields ribbon.
  2. On the left horizontal panel under the Field ribbon, click the Workflow tab, a list of workflow fields will appear.
  3. Click Set of Edit Assignee.
    The Assignee field is added in the form Fields section as Assignee.

This feature is not exclusive to just Field Actions.
