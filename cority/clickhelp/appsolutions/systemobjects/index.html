System Objects (Facilities and POIs)

The Facilities and Employees that are available for the IncidentApp are configured in the Management System. The Employees are configured as POIs in the "Employees" facility.

The Facilities and POIs that are used in the app must have the custom field "Include in Incident App?" (name: EII-IncludeInIncidentApp) with the value set to "true" to be visible in the App.

Other custom fields may vary, according to what fields you want to use on your forms.

The default POI properties on the Employee custom field template are defined below:

Field Data Type Caption Notes
EII-IncludeInIncidentApp True/False Include in Incident App? Value must = true to be visible in App
EII-EmployeeFirstName Text First Name  
EII-EmployeeMiddleName Text Middle Name  
EII-EmployeeLastName Text Last Name  
EII-EmployeeJobTitle Text Job Title  
EII-EmployeeDateOfBirth Date/Time Date of Birth  
EII-EmployeeSex Text Male or Female? List values: Male, Female
EII-EmployeeDateHired Date/Time Date Hired  
EII-SupervisorName Text Supervisor name  
EII-SupervisorPhoneNumber Text Supervisor phone number  
EII-Street Text Street  
EII-City Text City  
EII-State Text State List (include all relevant states)
EII-ZIP Text Zip  

In addition, the Facility must have certain numeric requirements that are configured for use in reports and dashboards. See Facility Metrics Data Configuration.

Workflow Role Membership Overrides

You will need to set up Workflow Membership Overrides for each Facility to allow users to create, respond to, and document incidents, according to their roles. See Managing Users with Workflow Overrides.
