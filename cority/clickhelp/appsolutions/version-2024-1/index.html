Version 2024.1

Release Date: March 18th

New Features

  • Administrators can now configure WAB forms to show all sections of a workflow by default. A new setting is available for admins to select in the form designer.
  • In the WAB, users can now locate and select system objects using a Map View interface.
  • In the Form Designer, Copy Step and Paste Step buttons were added. Admins can use these buttons to copy settings between similarly configured steps.
  • In the Form Designer:
    • The Export button will now have additional options to export the App Config tab and Process tab settings to a JSON file.
    • The Import button has been added to manage the import of JSON files containing app config, processes, and form settings.

Note: Dropdown list selections with associated conditions should match in both the source and destination WFs to avoid validation errors at run time. 

Note: Roles for the source and destination WF types should match to ensure automatic transition settings are assigned correctly and/or the appropriate manual assignment selections are available. 

  • In the Form Designer:
    • In the Edit Conditions window, the “Only Process When True” checkbox has been added. Admins can now select this checkbox when users are required to have a field or workflow step to be true to move onto the next field or workflow step in  the WAB. 
    • In the Conditions section, admins can now disable conditions for troubleshooting without the need to rebuild conditions.
    • In the Conditions section, conditions can now be reordered by clicking and dragging or using the arrow buttons.

In the WAB, users can now upload multiple documents.

In the Add Document window users can upload multiple documents by:
