Delete Inspection Records

Occasionally you may need to delete inspection records that were created by mistake or used for testing or training purposes. In order to delete inspection records you will need to delete the workflow instances that record the inspection. You will also need to delete the task instance that is tied to the inspection.

If a user creates a inspection for a facility to which the user does not have access, or for a different facility than the inspection is configured for, the task may be created with no subsequent workflow, since there was no associated equipment to select to begin the inspection. In this case, there may be a task with no workflow, and you only need to delete the task.

To delete unwanted inspection records:

  1. Select Tasks and Workflows from the menu button, then select Workflows.
  2. In the Search pane, select the Workflow Type link. For the workflow type, select EIA-Inspection.
  3. For the Version, select >=1. You can add other filters, such as the due date or creator, if you know these.
  4. Click Search.

  5. Find the workflow that matches the inspection you want to delete.

    To ensure you have identified the right inspection to delete, you can select the workflow to view it and drill down to the child workflows and view the inspection sections. Just click Back to return to the workflow list.

  6. When you are sure of the workflow you want to delete, right click the workflow and select Delete, then click Delete again confirm.

    When the master workflow is deleted all child workflows, including corrective actions that were created as part of this inspection will also be deleted.

    Next you will also need to delete the inspection task that appears on the calendar.

To delete an inspection task from the calendar:

  1. Take note of the name of the task in the InspectionApp calendar.
  2. Filter for the InspectionApp tasks from the system model. Open the system model pane and find the facility that was configured for the InspectionApp, with the POIs that represent the equipment/areas to inspect. Right click the facility and choose Tasks (Including Children).
  3. Find the inspection task to delete by name. Right click the task and select Delete Task Series. Click OK to confirm.
