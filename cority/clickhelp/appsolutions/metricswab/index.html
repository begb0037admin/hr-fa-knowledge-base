Metrics

Metrics data are used by certain reports and charts in the IncidentApp to calculate incident rates and lost/restricted time rates. It can be enabled for other Advanced Workflows (WAB) solutions if needed from the configuration file.

The metrics data includes the total number of employee hours and the number of employees per month. You can enter the metrics data directly from the App.

To enter the monthly metrics data:

  1. Select Metrics from the main menu button.

  2. Select a Facility.
    Enter a few characters of the facility name in the box, then select the facility from the matching entries offered.
  3. Select a year and a month.
  4. Enter the total number of employee hours.
  5. Enter the number of employees.
  6. Click Save.
