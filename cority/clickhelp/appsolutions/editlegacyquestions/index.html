Edit Legacy Questions

Each inspection question is defined by an instance of the EIA-InspectionQuestionDefinition workflow type. Legacy questions are related to the Inspection Type to which they belong as child workflows.

Library questions (implemented in version 2.2) are typically organized under a question library in the System Model and are associated with requirements. To edit library questions, you can use the form builder. See Create or Edit Inspection Forms.

All Sub-questions are child workflows of the parent question workflow and are instances of the type EIA-InspectionSubQuestionDefinition workflow type.

To edit a question, find and edit the workflow instance that defines that question or sub-question.

If you don't know the name of the question definition workflow, you can start by finding the inspection type workflow and work your way down to the question by selecting the child workflow that represents it.

To edit a legacy question:

  1. Select Tasks and Workflows from the menu button, then select Workflows.

  2. In the Search pane, filter for the workflow type EIA-InspectionTypeDefinition.

    The resulting workflows represent the inspection type definitions for your system.

    If you do not see any workflow, in the Search pane, check "Workflows I can manage" and set start date to 1/1/2000. Click Search.
    The search selection should now remain your default.

  3. Select the inspection type workflow that represents the inspection type you want to edit.

    In the inspection type workflow the questions defined for that inspection type are shown as child workflows.

  4. In the Child Workflows list, select the child workflow that represents the question you want to edit.

    To edit a sub-question, select the child workflow that represents the sub-question.

  5. Select the Question Definition step to open the step form.
  6. Select Edit.
  7. On the step form, make the desired changes.
  8. When you are done, click Save and Exit.
  9. Click Back to return to the parent workflow step.

All workflows should be left open in order to allow editing, if necessary. If the workflows have been closed, you will need to re-open them to edit. However, the audit will still function if the definition workflows are closed.
