Getting Started

If the InspectionApp is not displayed by default when you log in, select it from the menu.

After opening the App in a separate tab, add the page to your browser bookmarks to access it directly in future. If you will be working offline, you will need to use this link to access the offline data cache.

The navigation buttons at the top of the screen access the major display areas and functions in the app.

The button functions are shown below. 

Facility Sidebar: Displays or hides the sidebar that contains the Facility List (mobile version).

Calendar: View the scheduled inspections and corrective actions on a calendar.
Map: View your facilities by location on a map.
Search: Search for inspections or corrective actions by keywords and date range.

Dashboard: View and filter statistical information on inspections in graphical form.

Forms: Manage Inspection Forms (Administrators only)
Offline Inspections: Shows cached offline inspections.
