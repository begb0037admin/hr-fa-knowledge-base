Adding Predefined Action: Existing and Optional

Changing existing actions so that they are optional, allows users to choose an action that best suits their specific situation or process they want to follow.

  1. If Existing Action and Optional are selected, click Select Field Action drop-down text box, and then click a Field Action.
  2. Click the Select Existing Action text box.
    A drop-down menu appears with a list of existing actions.
  3. Select the action you want to include.
    An Existing Action section displays with fields filled in.
