Aggregates for Workflows and Events

Aggregate values may be added for numeric field types for Events and Workflows, including numeric lookups using the numeric value. Aggregates for numeric fields include SUM, MIN, MAX, AVG, STDEV, COUNT.

COUNT is also available for the following workflow fields: Workflow Unique ID, Parent Workflow Unique ID, or Grandparent Workflow Unique ID. It may also be available for other types of custom fields, depending on type.

Aggregations are displayed at the bottom of the table in view mode. Aggregate calculations are based on the filter applied to the page. Only the visible rows after filters are applied are used in the aggregation.

To add an aggregation for a field in a workflow or event panel:

  1. From the Settings page, select Edit Panel Content for the panel.

    Fields for which aggregations are available will show a box in the Aggregates row with the appropriate aggregation types in a drop-down list.

  2. Choose the desired aggregate type to include from the drop-down list. (Default value is None.)
  3. Select Save to save the panel content changes, then Save again to save the page.
