Portal

Your Portal provides a streamlined dashboard approach to your compliance data and tasks. The Portal allows you to access the data and the functions you need to perform and monitor information specific to your responsibilities. Portal Administrators can configure different pages to address the needs of different users.

You can access the Portal through the Advanced Calculations (EMS) solution or through the Embedded mode in the Cority application. See Embedded Mode for Portal for more information.

The Portal currently supports access to numeric data, workflows, events and tasks of all types. Users can:

  • View location-specific data in convenient table or chart format and filter data by location or object type.
  • Enter numeric data into pre-filtered tables, including pasting data directly from an Excel file into a table.
  • Download numeric data and enter new data in offline mode, then upload locally cached data once connection is restored.
  • View data for workflows, events and tasks in table, chart and calendar formats.
  • Complete workflow assignments through easily accessible forms.
  • Complete workflow and task assignments in offline mode, then upload changes once connection is restored.
  • View and edit event information and complete associated tasks.
  • Access quick links to run reports, view documents, and navigate to other internal and external links.

Browser Support & License Information

The Portal supports the following HTML5 compliant browsers:

  • Chrome (desktop, tablet, Android)
  • iOS Safari (Mac, iPad, iPhone)
  • Edge (desktop, tablet, Android)
