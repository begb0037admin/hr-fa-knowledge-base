Add Corrective Actions (Legacy Questions)

The following information is provided for Legacy Question configuration created prior to version 2.2. With Library Questions created with InspectionApp 2.2 or later, you can use the Form Builder to create and edit corrective actions.

Each Corrective Action is defined by an instance of the EIA-CorrectiveActionDefinition workflow type. The Corrective Action workflows are child workflows of the EIA-InspectionQuestionDefinition workflow. To add a corrective action to a question, you can create a child workflow to define the corrective action. (The same procedure applies to corrective actions for subquestions, except that the parent workflow is of the type EIA-InspectionSubquestionDefinition.)

To add corrective actions to an existing inspection type with Legacy Questions:

  1. Select Tasks and Workflows from the menu button, then select Workflows.

  2. In the Search pane, filter for the workflow type EIA-InspectionTypeDefinition.

    The resulting workflows represent the inspection types defined for use in the app.

  3. Select the inspection type workflow you want to edit.

    In the inspection type workflow the questions defined for that inspection type will be shown as child workflows.

  4. From the Child Workflows section, select the workflow that defines the question for which you want to create a corrective action.

    To create a corrective action for a subquestion, select the subquestion from the child workflows list.

  5. Select the Question Definition step.

    The question definition form is displayed. To add a new corrective action, you must create a child workflow.

  6. Click Next Steps > Define Corrective Action.
  7. For the workflow name, enter a name (use something that will help identify what question it applies to).
  8. Click Create.

  9. In the step form, define the corrective action using the fields on the form:

    Default Corrective Action Name: This text will appear in the dropdown list for corrective action types.

    Default Recommended Corrective Action: This default action text will be pre-populated in the corrective action field in the app.

    Default Corrective Action Due Date: Enter the number of days after the inspection date upon which the Corrective Action should be due. This value will be pre-populated in the due date field based on the corrective action name chosen.

    Require Action Taken?: To require that the Actual Action Taken field be completed, check this option. This will prevent closing an inspection (along with the child corrective actions) if all corrective actions have not been documented.

  10. Select Save And Exit to finish.

Leave all definition workflows open to make it easy to edit them. If you close the workflow instances, you will not be able to edit the definition unless you reopen it. However, the InspectionApp will still function if the definition workflows are closed.
