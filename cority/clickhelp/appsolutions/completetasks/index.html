Complete Tasks

The Task Completion App displays a list of your assigned tasks. Tasks may be sorted by due date by selecting from the dropdown list. Options are: This Week (default), Today, Last Week, This Month, Last Month, Next Month.

Choose whether to Show Complete Tasks or not with the On/Off toggle (default is Off). Completed tasks are indicated by a checkmark.

To complete a task:

  1. Select the task from the task list.
  2. To view the task description and details, select the Description button. The related objects, assignor and assignee(s) are shown. Click Back to return to the task completion page.

  3. Complete the task fields provided.

    Status defaults to 100% (complete). For partial task completion, you may select a percentage to update the task. The task will not be marked complete, but the status will be update).

    Completion date and time defaults to today's date and time. If enabled, you may edit these fields. Other task fields may also be visible, depending on the configuration (Time and Cost to Complete, Comments, etc.).

    If the task is associated with a workflow, workflow information will be displayed and workflow fields will also be available for viewing or editing, depending on your permissions.

    If associated documents are visible, you may select the document link to view a document.

  4. Save Task and/or End Workflow:

    For task completion only:

    • Select Save.

      Cancel will undo changes only if you have not yet saved. Workflow fields may still be editable after the task is saved, if the workflow is not yet closed.

    For tasks with a related workflow:

    • To end the workflow, select End Workflow.

      If the task is set to be automatically completed, the task will also be saved and completed, if the workflow submission is valid. If workflow data is invalid (required field missing or field values not valid), you will receive an error message for correction.

      If the task is not set to be automatically completed, you will need to select Save to complete the task separately.
