Sample Task Email Notifications

A sample email template is provided for your use in setting up email notifications for tasks. The Standard Task Notification template includes two button options to go to either the task completion form in the Management System or to the Task App. It also includes an optional button for users to add task to their local calendar (i.e., Outlook).

A different sample email notification is provided to allow users to go to the Portal to view and complete tasks. See Sample Email Notifications for Portal Workflows and Tasks

Download the HTML text file from the link in the table below to your system. Then follow the instructions for setting up the Notification Template.

To create the Notification Template:

  1. From the main menu button, select Setup > Notifications > Templates.
  2. Select New Notification Template.

  3. For the Type, select Task Notification.

  4. Enter a name for the template.

  5. Enter the Subject line shown above (editing as desired).

  6. For the HTML message body, click Source.
  7. Open the notification text file in a text editor (i.e., Notepad or Notepad++) and copy and paste the contents into the Source window.
  8. Decide which buttons you want to appear in the message.
    If you want to link to the TaskApp, you can delete the System link. Delete the code sections for the button(s) you don't want.
  9. Click Save.
    A preview of the message will be displayed.
  10. Click Confirm to save the template.

The notification template for a task must then be associated with a Task Template used to create the task.
