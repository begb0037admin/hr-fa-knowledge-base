Task Completion App

With the Task Completion App you can complete tasks on mobile devices, tablets and multiple browsers. The Task Completion App can be accessed from the main menu in the Management System, or accessed directly through email or local links which have been properly configured by your system administrator.

To access the Task Completion App, select the Task Completion App from the main menu.

To access the Task Completion App from an email notification:

  1. Click the link in the email.
    Must be a custom notification with the correct configured link; standard task emails go only to the main application.
  2. Log in on the login screen.
    The Task Completion App is displayed with a list of your assigned tasks.

Tasks may be sorted by due date by selecting from the dropdown list. Options are: This Week (default), Today, Last Week, This Month, Last Month, Next Month.

By default you see all tasks assigned to yourself that are not completed yet.

Toggle settings are available to:

  • Show Complete Tasks: Turn setting on to show tasks that have been completed. Completed tasks are indicated by a checkmark.
  • Show Other's Tasks: Turn setting on to show tasks assigned to others. The tasks shown depend on your permissions.

If the task list is long, you can quickly return to the top of the list when you have scrolled down.

To return to the top of the task list, click My Tasks in the blue bar at the top of the screen.

Supported browsers for the Task App

The Task Completion App is supported in the following browsers:

  • iPhone iOS 7 Safari
  • Android with native browser
  • Windows Mobile with native IE
