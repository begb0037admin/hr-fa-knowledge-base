Version 2022.3  

Release Date: November 29th

New Features

  • In designer mode, Risk Matrix has been added as a new control type. Here are some highlights of this new feature:

    • The Risk Matrix now supports multiple numeric drop-down lists.
    • Default values and colors for each cell are disabled when Risk Matrix control type is enabled.
    • Each cell in the Risk Matrix will now not only display values but also field/form descriptions in brackets at run-time.

  • Color coding thresholds can now be applied to Numeric fields, Calculated Numeric fields, and Data View fields, providing users with a visual indicator of numeric ratings. In designer mode users can specify threshold naming, value range, and colors.

General Improvements & Bug Fixes

WAB
WAB-5588

On a WAB form, the system no longer rewrites all metadate based on who last saved the form. Instead, it will only rewrite the signatory's name on the field that the user is changing.
