Reports

To run a report:

  1. Select Reports from the main menu button.

  2. In the Reports screen, select the report to run from the dropdown list.
    The reports available depend on your particular system.

  3. Select a date range from the popup calendars.
  4. Select the report type: HTML, Excel or Excel Template.

  5. Click Run Report.


Reports run from the App are stored in the Reports library in the main application in a folder whose name is configured in the configuration file. Users must have permission on the report folder to run reports.
