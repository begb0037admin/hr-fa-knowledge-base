Version 2023.3

Release Date: Nov 7th

General Improvements & Bug Fixes

ComponentTicketDescription
WABWAB-6097PDFs can now be attached automatically to closed workflows. The attached PDFs will be available in the Portal within workflow tables. This eliminates the need to open numerous workflows for generating regulatory documentation.
WABWAB-6127

In WAB Form Designer, users will now be able to transfer settings from one workflow step to another using an import/export process. This will include all form field settings, associated conditions, and common step actions.

Note: Any missing fields, or associated conditions on the destination step will display as an error and will need to be resolved prior to saving changes on the destination step. 

WABWAB-6195

On the Offline Data window, users can now choose to clear the cache that has been storing data for the current WAB instance in use or to clear all data cached by EMS in your browsers.

Note: In your WAB browser, if you choose to clear all data from an EMS instance you have open in one tab, that will also clear the data from any EMS instances you have open in other tabs. The current EMS tab will reload, but each of the other instances will have to be reloaded for them to function properly. This will not affect anything in any Non-EMS browser tabs.
