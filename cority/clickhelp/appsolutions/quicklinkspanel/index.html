Quick Links Panel Configuration

A Quick Links panel gives a set of links to users that they can use to easily access system functions or to navigate to external links. The Quick Links that are used on the panel must be System Quick Links that are shared with users. Users will only see those System Quick Links that have been shared with them.

Quick Links can also be used to allow you to navigate from the Portal to other apps.

Create a Quick Link

To create a Quick Links panel you will first need to identify or create the Quick Links that you want to place on the panel.

  1. To view existing Quick Links, click your user profile from the bottom of the main menu, then select Quick Links.
    The Quick Links panel opens and you can view existing Quick Links.

  2. To create a new Quick Link, from the main menu, select Setup > Quick Links, then click New Quick Link.
  3. Alternatively, you can click the + button from the Quick Links panel to create a new Quick Link.
  4. You can then choose to create either an internal link or external link to a URL.

Create a Quick Links Panel

To create a new Quick Links panel:

  1. From the page view, select Settings.

  2. Click Add Panel.

  3. Select Create New Panel.

  4. Enter a name for the panel and optional description.
  5. Choose a panel color (the color for the top bar on the panel.)

  6. For the Panel Type, select Quick Links.

  7. Click Create.
    Once the panel has been created, you can configure the panel and add Quick Links to it.

To add and configure links:

  1. From the page view, click Settings.

  2. Click Edit Panel Content on the panel.
    A list of available Quick Links are displayed on the left. You can enter a key word to use the Search or scroll to find the links you want to add.
  3. Click the + sign for a link or drag and drop to add it to the panel.

  4. Once the link is on the panel, select the link box to choose display options. You can:

    • Change the wording on the link Label.
    • Select a background color.
    • Select an optional icon.

  5. Click Apply after making your selections.
