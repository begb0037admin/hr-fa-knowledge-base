Calendar Settings

The Calendar View for Workflows and Tasks is configured in the Calendar Settings tab in the Edit Panel Content view.

Default Time Frame can be Day, Week or Month. For Week or Month, you can choose a Calendar Week/Month or a Progressive Week/Month.

The Month view shows six weeks (five for mobile). The first week for a Calendar Month is the week containing the first of the month. The first week for a Progressive Month is the week before the current week.

The Week view shows one week. The first day for a Calendar Week is Monday of the current week. The first day for a Progressive Week is today's date.

Requirement Label: You may use the requirement name as the display name for the calendar item, or a custom name that is stored in a pre-configured custom field.

To use a custom name: Uncheck "Use Requirement Name". Click in the Select box and enter a few characters of the name of the custom field that contains the name value, then select the field from the list.

Show Location Labels: You can include the location along with the requirement label by checking the parent object whose name you want to include. The object name will appear before the requirement name in the summary.
