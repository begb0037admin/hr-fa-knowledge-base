Workflow Solutions

Release Notes

Workflow Solutions are used to quickly build and deploy custom apps based on workflows configured in the Management System. These solutions are used for many customer-specific apps. It is also the basis for some global app offerings.

You can access the Workflow Solutions through:

  • Advanced Calculations (EMS). See App Navigation.
  • Embedded mode in the Cority application. See Embedded Mode for Workflow Solutions.

The general look and feel is the same for all apps built on this model. However, the names of items, the forms that are used, and the action buttons that represent what users can do are all customizable according to the purpose of the app. This help explains the generic interface, the app components, and the basic interface for apps built on the Advanced Workflows (WAB) model.

Browser Support & License Information

Apps are best viewed on an HTML5 compliant browser. Supported browsers are:

  • Chrome for Windows Desktop (latest)
  • Edge (desktop, tablet, Android)
  • Safari for iOS/iPadOS (latest)
  • Chrome for Android (latest)

Some custom apps might be designed to function across additional platforms and browsers. See  Apps for more information.

Recommended minimum screen resolution: 1024x768
