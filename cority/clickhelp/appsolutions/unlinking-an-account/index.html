Unlinking an Account

Linked accounts can be unlinked from the User Management App.

  1. Open the User Management App.
    A list of active users will display.
  2. From the Application drop-down menu, select the application whose user(s) you want to unlink.  
  3. Click the Edit   icon to the right of the user you want to link.
    The Link Accounts dialog box will open.
  4. Click the Link  icon to the right of the account you want to unlink.
    The icon will change to a broken link, indicating the accounts have been unlinked. 
  5. Click Close to exit the dialog box.
