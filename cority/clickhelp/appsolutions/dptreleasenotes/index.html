Data Preparation Tool Release Summary

Version 1.1 Release date: 9/27/2019

This release is focused on providing Ergonomics users access to their data through the Data Preparation Tool.

  • The user interface now has options to switch between Environmental and Ergonomics data (appropriate permissions required).

Version 1.0 Release date: 8/1/2019

The EMS Data Preparation Tool is an advanced query building application that will enable you to quickly and visually create the EQL queries you need to gather your data for reporting and analysis. You will be able to easily explore your data in business-friendly terms and create your own reports using a simple drag-and-drop interface as well as export your data for distribution or further analysis.

v1.0 Features: 

  • Query Editor

Users can create queries using drag-and-drop functionality with the Visual Editor, or through standard EQL syntax with the EQL Editor.

  • Query Library

Users can save queries that can be viewed and run by others.

  • Data View Library (appropriate permissions required)

Advanced users can save queries as Data Views so that other users can easily generate reports from a more targeted set of data.

  • Export to Excel

Data can be exported to Excel in both .xlsx and .csv formats.
