Print

You can create a printable version of a record (incident, change, etc.), an action, or a dashboard by clicking the Print button on the top bar.

A print preview will be displayed.

You can filter out fields that do not have data by deselecting the Include Blank Fields checkbox at the top.

If the preview screen does not appear after clicking the Print button, your browser's popup blocker is likely the issue. For Advanced Calculations (EMS), you will have to update your browser settings to allow popups.
