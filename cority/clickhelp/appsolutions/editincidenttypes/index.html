Edit Incident Types

A set of default incident types are provided in the initial configuration. The incident types are all child workflows of the main EII-Incident workflow. You may use these default incident types or create your own. The default incident types may be edited, copied, removed, or added to as needed. See Default Forms for a list of the default incident types.

If you have already configured forms in Form Designer, editing the step names in the workflow type or changing the workflow name may cause you to lose the form design in Form Designer.

To remove an incident type:

  1. In the App, in Form Designer, bring up the Form Type=EII-Incident and Step Name=Collect Incident Details.
  2. Delete the Action button for the incident type you do not want. (Click the x on the button to remove it.)

  3. In the Conditions section, find the condition related to that incident type, check it and click Delete Selected.

    The incident type will no longer be displayed in the App. An optional step is to edit the EII-Incident workflow and remove the child workflow for the incident type. However, you may leave this association in case it might be needed in future.

To add an incident type:

  1. Copy an existing IncidentType workflow.
  2. Copy or create a new form template and add the custom fields needed to document the incident type.
  3. Create a new SME role (SME-[IncidentType]) for the incident type.
  4. Edit the new incident type workflow. Edit the step Log Incident Details and change the associated Form Template and Assigned Role. Give the new SME role the same permissions as the previous role: View All Form Fields, Edit All Form Fields, Associate Documents and Report.
  5. Edit the parent EII-Incident workflow and add the new incident type workflow as a child workflow with a new initiator named "[IncidentType] Details". (The name of the Workflow Initiator will be used as the name of the tab in the App.)
  6. Edit the custom field EII-IncidentType. Add a list option for the new incident type.
  7. In the App, in Form Designer, select the Form Type=EII-Incident and Step Name=Collect Incident Details.
  8. In the Actions list, find the Action for the incident type and add it to the form by dragging it to the area below the form fields that holds the group of action buttons.

  9. In the Conditions section, add a Condition for the new incident type, using the format as shown for the other incident types:

    If Incident Type Contains "[list option]" Then "[IncidentType] Details" is VISIBLE

  10. Save your changes.
