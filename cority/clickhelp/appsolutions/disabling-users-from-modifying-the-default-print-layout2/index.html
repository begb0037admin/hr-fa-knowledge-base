Disabling Users from Modifying the Default Print Layout

Users who have access to Forms Designer can be permitted to create a custom default layout and design for their printouts. This feature can also be disabled. When disabled, all printouts will display in the global, default layout. However, users with access to Forms Designer can still change the layout and design for a specific printout, if necessary; that will not affect the underlying default layout.

To disable users from modifying the default print layout:

  1. From the main menu dropdown, select Designer to open Forms Designer.
  2. Click the App Config tab.
  3. Navigate to the Application Behavior section, and disable Allow Users to Modify Printout by clicking x.

  1. Click Save App Config at the top right.
