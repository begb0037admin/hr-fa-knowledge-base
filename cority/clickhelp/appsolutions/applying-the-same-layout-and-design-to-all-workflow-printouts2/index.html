Applying the Same Layout and Design to all Workflow Printouts

Only users who have access to Forms Designer will be able to see and use the required Save as Default button in the Settings window.

To apply the same layout and design to all workflow printouts:

  1. Click the Print icon.
    The layout will open in a new tab.
  1. Click the Settings (vertical ellipsis) icon.
    The Settings window will open.

  1. In the Images section, click the Include Photos and Include Signature checkboxes.

  1. To make changes to the layout and design, click the Advanced Settings dropdown icon.

  1. Once you have configured the layout and design as required, click Save as Default. A prompt will display.

  1. Click Yes.

Unless configured otherwise, all forms printed using the same workflow application will have the same default layout and design.
