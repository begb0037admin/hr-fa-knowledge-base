Legacy Questions

Each inspection question is defined by an instance of the EIA-InspectionQuestionDefinition workflow type.

Legacy questions are related to the Inspection Type to which they belong as child workflows. Applicability is determined by the association of the question workflow to the system objects representing the inspection points.

Library questions, used after release version 2.2, are associated with the Inspection Type through Tags in a Tag Scheme and do not need any parent-child relationship to the Inspection Type workflow. See Library Question Configuration.

The two types of questions cannot be mixed. If your inspection configuration is of the Legacy type, you can add new questions to an existing inspection with the following procedure.

To create Legacy questions for an inspection type:

  1. Select Tasks and Workflows from the menu button, then select Workflows.

  2. In the Search pane, filter for the workflow type EIA-InspectionTypeDefinition.

    The resulting workflows represent the inspection type definitions for your system.

    If you do not see any workflow, in the Search pane, check "Workflows I can manage" and set start date to 1/1/2000. Click Search. (The search selection should now remain your default.)

  3. Select the inspection type workflow that represent the inspection type you want to edit.

    In the inspection type workflow the questions defined for that inspection type will be shown as child workflows. To create a new question, you must create a new child workflow to define it.

  4. Select the workflow step (name Inspection Type Template or similar).

  5. Click Next Steps > Create Question.

    A new child workflow is created for defining the question.

  6. Enter a Name for the question.

    The Question Name is displayed in the Dashboard panel "Questions most frequently requiring Corrective Action," so it is recommended that you use a name that enables you to identify the question easily.

  7. For the System Model Components, select all of the objects (Units/POIs) that represent the equipment/areas for which the question is applicable.

    Associated components will be inherited from the parent workflow, if they were added there. You can remove any components that represent inspection points for which the question is not applicable or add others, as needed.

  8. Click Create.

  9. In the step form, complete the applicable fields:

    Question Text: The question as it will appear on the inspection form. Required value.

    Question Type: Required. Type of field for the response is one of the following: 

    Dropdown: Dropdown list with up to 10 possible options.

    Label: Label field. The Question Text will be displayed as view-only on the form.

    Text: Text box for user to enter free text.

    Button: For Yes/No or Yes/No/NA questions. Form will display buttons with labels as defined in options 1-3 (by default Yes/No or Yes/No/NA).

    Dropdown Question Possible Answers (1-10): To set the list options for the dropdown list type, enter the text option in each of the fields. Up to ten possible options may be set. These options will override the default values set on the Inspection Type form.

    Automatically Create a Corrective Action for these dropdown options: If you want a corrective action to be automatically created for any of the dropdown list options (above), select the corresponding option numbers.

    This is a general question....: If this is a general question which should be present on all inspections of this type, set the value of this field to True. (The question will be shown in a general section at the beginning of the inspection form.) Otherwise, set to False.

    Sort Order specifies the display order on the inspection form. (If not specified, the Workflow Id is used to sort.)

    Related Hyperlinks (1-5): You may set up to five hyperlink fields, and define special formatting.

    LibraryQuestion For legacy questions, the value must be False (do not check).

    For all field definitions, see Inspection Definition Workflows.

  10. When you are finished, choose one of these options:

    Save And Exit to return to the parent workflow, where you can add additional questions if desired.

    Save And Define Sub Question to define an associated sub-question. When creating a sub-question, you must indicate which responses(s) to the primary question will make the sub-question visible.

    Save and Define Corrective Action to define a corrective action to be initiated for this question.

  11. When you are done creating questions, from the parent workflow select Save And Exit to finish.

Leave all definition workflows open to make it easy to edit them. If you close the workflow instances, you will not be able to edit the definition unless you reopen it. However, the InspectionApp will still function if the definition workflows are closed.
