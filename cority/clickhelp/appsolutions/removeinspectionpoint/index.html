Remove Inspection Points

Objects representing inspection points, such as equipment that has been removed from service, areas that are no longer relevant, or an object created for temporary use, can be removed for future use in inspections by simply disabling them so that they are no longer visible in the app. Any previous inspection records for the objects will preserved.

To remove inspection points from the InspectionApp:

  1. Find the object in the System Model that represents the inspection point. Right click it and select Properties > Edit.

  2. In the Tags section at the bottom of the properties, remove the tag EIA-InspectionAppConfiguration:  EIA-InspectionAppFacility.

  3. Save and Confirm.

The object will no longer be shown in the app. If you want, you can rename the equipment in the system model (right click and select Rename) with an X prefix or some other indicator that will let you know the equipment is no longer active, or set an inactive date on it so it will be marked inactive in the tree.

If you are confident you no longer want to preserve the object and its previous records, you can delete it, but be aware that if you make an error and select the wrong object, you will not be able to recover it. Therefore, it is recommended that you simply disable it instead.
