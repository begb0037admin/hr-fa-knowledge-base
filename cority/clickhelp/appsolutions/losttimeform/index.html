Lost Time Form

The Lost Time form is associated with the incident type Injury/Illness. If the Injury/Illness Type includes Lost Time or Restricted Days, the user can select the Enter Lost/Restricted Time button which adds a tab called Lost/Restricted Time to the Additional Details and Follow-Up section, if one does not already exist. A child workflow of the type EII-LostRestrictedTimeSummary is created. On this form the IncidentApp calculates and displays the Lost Time Days and Restricted Days based on the records of Lost/Restricted time.

The user can add a new record by selecting the New button at the bottom of the Lost/Restricted Time table which displays a pop-up for providing the details. When saved, the app creates a workflow (Type = EII-LostRestrictedTimeLog) as a child of the EII-LostRestrictedTimeSummary workflow. Each child workflow is represented as a row in the Lost/Restricted Time table on this form. The gear icon next to a record allows the user to View, Edit or Remove the record. View opens a pop-up for viewing. Edit opens a pop-up to allow the user to edit the fields. Remove deletes the workflow record. (Edit requires the user to have the permission to edit the fields; Delete requires permission to delete the workflow.)

Because there are standard dashboards and rates which are based on lost time logs there are some standard, pre-defined fields for this solution. In general, you will not need to edit this form. The description of fields is provided for information only.

Field Data Type Workflow/Field Notes
Effective Date Date EII-LostRestrictedTimeLog /EII-LostRestrictedTimeDate Required. Default=Today
Medical Status Dropdown list EII-LostRestrictedTimeLog /EII-MedicalStatus Required. Default values: Lost Time, Restricted Time, Full Duty
Job Transfer Required True/False EII-LostRestrictedTimeLog /EII-Transfer Required. Default=No
Explanation of Status Text (250) EII-LostRestrictedTimeLog /EII-ExplanationOfStatus Not required.
Lost Days Number EII-LostRestrictedTimeSummary /EII-LostDays Required. The app will count the number of days between Lost Time effective date and the effective date of the next Medical Status != Lost Time
Restricted Days Number EII-LostRestrictedTimeSummary /EII-RestrictedDays Required. The app will count the number of days between Restricted Time effective date and the effective date of the next Medical Status != Restricted
