Inspection Reports

You can generate an inspection report at any time during the course of an inspection or after an inspection is complete. The report will include a summary section at the top that shows the general workflow information:

  • Facility
  • Date of Inspection
  • No. of Corrective Actions
  • Inspector (user who created the inspection)
  • Inspection Points

Following the summary is a table showing the information from the completed form, including:

  • QuestionID
  • Question text
  • Answer
  • Comments
  • Corrective Actions
  • Attached documents

You may view and print a report directly from the browser, or save it as a pdf file, with or without images.

To generate an inspection report:

  1. Open the inspection (in any view).
  2. Click the Report button (top right) and choose how to save the report:
    • Print opens the report in a browser window, where you can view it. You can use the Print button to print it directly. Attached images are embedded in an appendix at the bottom of the report.
    • Save As PDF + Pictures saves the report as a pdf file, with attached images displayed in an appendix.
    • Save As PDF saves the report as a pdf file but does not include images.
    • Save as Excel saves the report in Excel format.
