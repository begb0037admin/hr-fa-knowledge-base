Requirement Names in Numeric Panels

You can set up alternative names to be used in numeric data panels to make the tables and charts more comprehensible or to better fit the views. A custom field on the requirements stores the display name which will be used when enabled in the panel. The system substitutes the value in the requirement custom field. If the value is null, the requirement name is used.

Additionally, if you have multiple requirements with the same name, you can include the names of one or more parent objects to distinguish them, or substitute a parent object name instead of the requirement name.

To configure requirement aliases to be used in a numeric panel:

In the Management System, configure a custom field to hold the name you want to use:

  1. Create a custom field to hold the alternate name (alias).

    The field can be small text, medium text, text dropdown list, or dropdown list with text box. Value history fields are not supported. 

  2. Add the custom field to a custom field template and apply it to the requirements to be used in the panel.
  3. Edit the requirement properties and insert the name value in the custom field.

In the Portal:

  1. Open the page that contains the numeric data panel.
  2. Click Settings.

  3. On the panel, click Edit Panel Content.

    In the Numeric Table Settings section, if "Use Requirement Name" is checked, the name of the requirement will be displayed in the column head. This is the default setting.

    Any objects checked under Show Location Labels will also be displayed in the column head.

  4. Uncheck "Use Requirement Name".

    To use only the Location Label in the column head (instead of the requirement name): Check the parent object(s) to use and uncheck "Use Requirement Name". As a result, the name of the Facility (or other selected object type) will be used as the column head.

    To use a requirement alias, stored in a custom field: Uncheck "Use Requirement Name". In the Requirement Label field, enter a few characters of the name of the custom field that contains the value for the alias, then select the field from the list. If the custom field on the requirement has no value, the name of the requirement will be used.

  5. Click Save to save the panel settings, then Save again to save the page.
