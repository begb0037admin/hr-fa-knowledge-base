View Numeric Data

Numeric Data Panels can be used both to view numeric data in table or chart mode and to enter data in an easy interface. Features include:

  • Enter data directly into a data table, including the ability to copy and paste from an Excel sheet
  • Download Numeric Data to Excel
  • Download Charts to Image or PDF
  • Bulk import data from an Excel spreadsheet
  • Edit the data display by choosing the columns you want to see and re-arrange columns to maximize the view for your own purposes
  • View aggregate data
  • View data in table form or in data summary charts for managers

To change the panel view, click the table or chart icon on the panel bar. 

To refresh data in the panel, click the Refresh  icon. 

To expand the panel to full screen size (depending on device), click the Expand  icon.

Table View

In Table View, you can enter or edit data, view existing data, and export the contents of the table to Excel. You can also customize the table display by resizing and re-arranging columns, or choosing columns to show or hide.

Various other options may be available to you, according to the configuration of the panel, including:

  • Panel objects selector: If an object selector is visible on the panel and can be edited, you may select the objects whose data you want to see (i.e., change the Facility).
  • Panel date selector: If a date selector is visible on the panel and can be edited, you may set the desired date range.
  • Interval: Shows the expected data entry period. Data display is filtered and new data entry rows are pre-dated according to this value.
  • Show All Data: If this option is checked, the interval period will not be used to filter data. All data within the date range will be displayed.

Aggregates, if included, will be shown at the bottom of the data table for columns, or on the right for rows.

Data limit exceedances are color-coded. A yellow highlighted cell indicates an internal limit exceedance, red indicates a regulatory exceedance. Hover over the cell to see the limit values.


To resize a column:

  • Hover over the right edge of the column header until the slider appears, then select and hold while you drag and drop to the desired width.

To re-order columns (move a column):

  • Hover over the column header to select the column, click and hold, and drag and drop the column to the desired position.

To select columns to show or hide:

  1. Select the Columns button on the right side of the panel header.

    The names of the numeric requirements, calculations and data quality (DQT) fields available for the page are shown.

  2. Use the toggles to show or hide a data type (Parameters, Calculations, and Data Quality fields).

  3. Check or uncheck specific items to show or hide them in the panel display. .

  4. Click OK to apply your preferences

Chart View

You can view data in graphic format in the chart view.

  • Select the table editor button to choose Chart display options, including data and limits to display. See Edit Data Display
  • Hover over a chart element (bar or line) to see the value and requirement name and path.

  • Show or hide the legend by clicking the arrow.

    Click and hold to drag the legend to another position.

  • Use the slider at the top to reduce or increase the date range on the horizontal axis.

  • Click Show All to return to the original page date range.

  • Limits may be shown as dotted lines in the Line, Column and Area chart types. The line color matches the requirement color. A heavy line is a regulatory limit, a lighter line is an Internal limit. You can hide individual limits by clicking on them in the legend. You can turn off limit display in the chart display options.
