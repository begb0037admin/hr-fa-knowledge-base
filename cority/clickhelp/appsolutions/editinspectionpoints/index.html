Edit Inspection Points

Inspection Points available for inspections are Units or POIs under the Facilities. In order to be available in the InspectionApp they must have the Tag EIA-InspectionAppConfiguration: EIA-InspectionPointUnitorPOI.

The custom field "EIA-IncludeInInspectionApp" is no longer required and has been replaced by the tag in the EIA-InspectionAppConfiguration scheme.

To edit the properties for an InspectionPoint:

  1. Select System Model from the menu button.

  2. In the System Model tree, expand the facility, then find the Unit or POI that represents the Inspection Point you want to edit.

  3. After making your changes, click Save.
  4. To rename the Unit or POI, right click the object and select Rename. 
  5. To make the inspection point visible in the app, right click the object and select Edit. In the Tags section at the bottom of the properties, add the tag EIA-InspectionAppConfiguration: EIA-InspectionPointUnitorPOI. 
  6. To remove the inspection point from visibility in the app, remove the tag EIA-InspectionAppConfiguration: EIA-InspectionPointUnitorPOI.

To add Inspection Point types:

  1. From the main menu button, select Setup > Custom Fields.
  2. Search for the field "EIA-Equipment|Area Type."
  3. Right click the field and select Edit.
  4. Click Add to add list items and enter the list values.

  5. Click Save and Confirm.

    The Equipment/Area type is used as a filter option in dashboards in the InspectionApp.

To add an image to represent an Inspection Point:

  1. From the main menu button, select System Model.
  2. In the System Model tree, expand the Documents section and select the folder EIA-InspectionApp \ Equipment|Areas.
  3. Select Add Document.
  4. Enter a file name. 
  5. Leave the Upload a File option selected.
  6. Click Browse to find and select the image you want.
  7. Click Save.
  8. Once the file has uploaded, right click the file and select Associate.
  9. Click Add Association.
  10. Click Add in the Objects to Associate box.
    Browse to select the Units or POIs that represent the equipment or areas to which the image should apply.
  11. Click Save.
