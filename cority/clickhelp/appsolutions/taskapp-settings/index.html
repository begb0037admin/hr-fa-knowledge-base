Task App Settings

To manage the settings for the Task Completion App you must be a member of the ETA-TaskAppAdministrator group. Users in this group will see the Settings button in the top right corner of the Task Completion App tab.

The Settings screen allows administrators to set global settings for viewing Task and Workflow fields. Users will only see those tasks to which they are assigned. There is no search capability other than the filter for the task time period and the option to toggle on/off display of completed tasks.

To view/edit settings:

  1. Select the Settings button on the Task Completion App.

  2. Select the fields that should be visible on the Task Completion Page for users by selecting On (visible) or Off (not visible) for the field.

    These fields are configurable for simple tasks with no workflow association. If a workflow is associated with the task, the task fields to show are configured in the Workflow tab of the Task setup screen.

    Dismiss: Allows users to dismiss tasks, if On. If setting is Off, users may not dismiss tasks.

    Date: Completion date defaults to current date. If On, users may edit completion date.

    Status: Completion status of task.

    Time: Time of completion defaults to current time. If On, users may edit field.

    Time to Complete: If On, allows users to enter time in hours to complete the task.

    Cost to Complete: If On, allows users to enter cost (in $)to complete.

    Task Comments: If On, Comments field is displayed for standard tasks.

    Workflow Name: Show name of workflow associated with a task.

    Workflow Comments : Show comments for workflow associated with a task.

    Workflow Documents: Show link to documents associated with a workflow-related task

    Workflow Field Position: Determines whether workflow fields or task fields appear first on the Task Completion page. Values are Top (Workflow fields first) or Bottom (Task fields first).

    End Workflow Button: Should the button to end a workflow be available to users?

    End Workflow Button Label: Default label on the button to end a workflow is Mark Complete. Edit the field to enter your own text label. Limited to 20 characters.

  3. Click Save to save the settings.
  4. Select Back to return to the task display.
