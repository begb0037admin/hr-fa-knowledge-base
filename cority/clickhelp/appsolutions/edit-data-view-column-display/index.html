Edit Data View Column Display

You can choose to show or hide columns in the Data View panel.

You can use this feature to filter for the columns you want before downloading data to Excel. Only those columns that are visible in the table will then be downloaded.

To choose data to show or hide:

  1. Click the Filter icon on the right side of the panel header.

    The column names will display.

  2. Uncheck columns to remove them from the panel display.
  3. Click OK.

Reorder Columns

You can also re-order columns in the table view by dragging and dropping. Click and hold the column header until the move icon displays, and then drag and drop to the new position.
