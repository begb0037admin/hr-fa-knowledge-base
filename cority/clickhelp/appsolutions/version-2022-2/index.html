Version 2022.2   

Release Date: August 9th

New Features

  • In the Workflow Application Builder, Data Views can now be added and deleted and Data View options can now be selected and configured.

  • In the Work Application Builder, the risk matrix can now be accessed from the various workflow types. 

  • The Workflow Application Builder has a new feature that can be configured to color-code a numeric field based on thresholds. A description is required for each threshold range.

  • The Workflow Application Builder can now be configured to provide Single-Touch for drop-down lists and multi-select lists.
