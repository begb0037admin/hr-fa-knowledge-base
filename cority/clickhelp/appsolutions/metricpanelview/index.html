Metric Panel Views

Metric panels are presented as small boxes on a page that show a single aggregate value for an easy quick visual indicator of key performance data.

For numeric data, the aggregate displayed is a sum total of all values included in the data set. Some Numeric Metric examples:

For workflows or events, the aggregate displayed is a count of all workflows or events in the data set. Some Workflow Metric examples:

The last time the metric value was updated is indicated in text in the lower right corner. The value will automatically update when the page is re-loaded. To manually refresh the data, just click the panel.

The panel may be expanded to show the underlying data, in either table or chart view.

To view the underlying data:

  1. Click the Expand icon (small arrow top right) on the panel.
  2. Choose the table or chart view from the panel's top bar.
    You may filter data from the table view, or apply different chart settings. However, when returned to metric view, any filters or settings from those views will be removed.
    For a metric panel based on numeric data, you may enter data in table view in the same manner as a numeric data panel.
  3. When finished viewing, click the Collapse icon on the panel (top right) to return to the page view.
    Any filters applied in table or chart view will be removed.
