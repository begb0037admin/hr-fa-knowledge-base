Scheduled Inspections

You can set up a recurring schedule for an inspection, which will be displayed on the calendar in the InspectionApp. The inspection schedule is determined by the recurrence schedule for an associated task.

To set up a recurring inspection schedule:

  1. In the InspectionApp, create a new inspection by clicking New Inspection. Select the inspection type. For the due date, select a date far enough in the future so it will not create an immediate task and you can edit it easily. (The due date will be replaced with the inspection schedule.)

    When the inspection is created, a task will be created in the Management System by the same name. The assignee(s) for the task will be the inspector you selected for the inspection. Next, you need to find the task in the Management System to edit the schedule.

  2. In the Management System, expand the Facility for which the inspection was created. Right-click the InspectionApp unit and select Tasks (Including Children).

    Use the search pane to find the task (if necessary). You can use the task name (same as inspection name), start date (same as the inspection due date), assignor (you) or assignees to help find it. Select Tasks I May View to see all tasks (not just those assigned to you).

  3. Select the task, right click and select Edit Task Properties.

    In the General tab, the due date you selected in the InspectionApp is shown as the Task Due Date. The hour defaults to 9 PM in the creator's time zone. This due date will be replaced with the recurrence schedule that you create.

  4. Select the Recurrence tab.

  5. Click Add New Schedule and create a recurring schedule for the task that reflects the desired inspection schedule.

  6. Click Save and Confirm.

Once the task has been set up in the system, the inspection schedule will appear on the calendar for the facility and in the inspection list.

To edit or delete an inspection schedule:

  1. From the main menu, select Tasks and Workflows > Tasks.
  2. Search for the task by name. The name of the task is the name that appears on the calendar in the App.
  3. Right click the task and choose Edit Task Properties.
  4. In the Recurrence tab, select the current schedule. Enter an end date for the schedule.

  5. To create a new schedule, click Add New Schedule.

    Create the new schedule for the task. Include the date to start the new schedule (defaults to one day after previous schedule ends), and a date to end the new schedule (or select No End Date).

  6. Click Save and Confirm to save the task changes.

In order to complete inspections, a user must be associated with the EIA-Inspectors role through a workflow override on the applicable facility, and have the required permissions on the facility. See Manage App Users.

The inspection type name must not contain any special characters and cannot be more than 35 characters long.
