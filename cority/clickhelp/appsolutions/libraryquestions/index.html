Library Question Configuration

Library questions are organized in a library section of the System Model tree.

When you use the Form Builder to build your inspection form, the Form Builder automatically builds the requirements and workflows to define the questions in an inspection. Each question is defined by a library object (a non-numeric requirement) with an associated workflow.

The following configuration details are provided for information and diagnostics only.

The library object that represents a question in the Management System is a non-numeric requirement with the following tags applied:

  • One tag from the EIA-InspectionType tag scheme to identify the inspection type (inspection types defined by customer).

  • One or more tags from one or more tag schemes that are used to identify which inspection points the question applies to (e.g., EIA-InspectionPoint). These tag schemes are specific to the customer's requirements, depending on the type of objects that are subject to inspection.

    Questions that are designated "Include in all Inspections" will appear in a general section at the top of the form. When multiple inspection points are included in an inspection, they will not be repeated for every object. General questions do not need inspection point-specific tags. (However, they currently require at least one of the inspection point tags.)

    For details on how the filtering criteria are used, see Inspection and Question Applicability.

The workflow associated with the library object is an instance of the EIA-InspectionQuestionDefinition workflow type, which defines the question: the question type, text of the question, and dropdown list options. These selections are made in the Form Builder. The workflow may optionally have:

  • One or more child workflows of the workflow type EIA-FindingDefinition, which defines a finding, if the Findings option is turned on.
  • One or more child workflows of the workflow type EIA-CorrectiveActionDefinition, which defines a corrective action. If the Findings option is turned on, corrective actions will be associated with a Finding rather than directly with the Question.
  • One or more child workflows of the workflow type EIA-InspectionSubquestionDefinition, which defines a subquestion. (Subquestions may also have findings and corrective action workflows.)

For all field definitions, see Inspection Definition Workflows.
