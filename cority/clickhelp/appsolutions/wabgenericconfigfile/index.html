Configuration File

The Advanced Workflows (WAB) app configuration file contains the settings for the App. It is set up by Cority when the App is deployed, and is not editable. Custom settings may be requested for different App implementations.

Download the Excel template file: WAB Configuration Settings and Instructions.xlsx

The default configuration file settings and fields for Advanced Workflows (WAB)-based apps are shown in the following table, with an example of settings for a fictional app called MyApp. The prefix WAB is used as an example to identify App components.

BackToButtonText
Back to Portal

This setting allows you to customize the Back to Portal label. 


In the upper left menu control, the top option redirects the user to an external URL. Traditionally, that URL has simply been the system's Portal App and the text was "Back to Portal". This option allows that label to be modified. It should be a short description of where the user is expected to 'land' after clicking. If left undefined, the label will remain "Back to Portal".
BackToButtonDestinationUrl
/goto/{SystemId}/Portal/{mode}

The {mode} macro ensures that when the Portal is loaded, it is loaded on either general mode or embedded mode, depending on the mode in which the Workflow Solutions App is currently loaded.

In the upper left menu control, the top option redirects the user to an external URL. Traditionally, that URL has simply been the system's Portal App. This option allows the external URL to be modified, typically to allow particular Apps to redirect the user to a SPECIFIC Portal page rather than the last page the user loaded in the Portal. If left undefined, the URL will take the user back to the system's Portal App.

See Portal Embedded Mode and Workflow Solutions Embedded Mode for more information on the URL syntax.
