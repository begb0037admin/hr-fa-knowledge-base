Assigning a Workflow Step to a System Model Object

To Assign a Workflow Step to a System Model Object

  1. On a form click the Object Selector dropdown textbox.
  2. If you would like to do an open search, click the Object Selector dropdown textbox and the first 50 Objects in alphabetical order populate. Scroll to find and select an Object.
    If you do not find your Object in the first 50 that display, as you continue to scroll more Objects will populate at the end of the list.

You can also input %%% to perform an open search.

  1. If you type in the Object Selector dropdown textbox, your open search will be cancelled and results matching the text entered will display.
