Sample Email Notifications for Portal Workflows and Tasks

Sample email templates are provided for your use in setting up email notifications for workflows or tasks that will take users to the Portal to view and complete their workflow assignments.

Download the HTML text file from the link in the table below to your system. Then follow these instructions for setting up the Notification Template.

Notification Template Name Subject HTML text file
Portal Form for Workflows You have been assigned a workflow: {flow::name} Portal Form for Workflows.txt

Portal Form Task Only

(Notification type=Task)

You have been assigned a task:  {task::name} Portal Form Task Only.txt

To create the Notification Templates:

  1. From the main menu button, click Setup > Notifications > Templates.
  2. Click New Notification Template.

  3. For the Type: 

    • For the Portal Form for Workflows (for a panel that displays workflows), select Workflow Notification. 

    • For the Portal Form for Tasks Only (used for tasks not associated with a workflow), select Task Notification.

  4. Enter a name for the template.

  5. Enter a Subject line. Suggested Subject lines are given in the table below.

  6. For the HTML message body, click Source.
  7. Open the notification text file in a text editor (i.e., Notepad or Notepad++). Select and copy the contents, then paste it into the Source window.

  8. Click Save.
    A preview of the message appears.

  9. Click Confirm to save the template.

The Portal Forms for Workflows or Tasks contain a link that will take users to the completion form in the Portal for a specific Pageset, Page and Panel. You will need to edit the link on the button to include the appropriate names. Search for the following text in the source, depending on whether it is a workflow or task form:

  • {url::basePath}Portal/index.html?route=form&path=/Demo%20Pageset/Workflows/Workflow%20Assignments/&uniqueID={flow::unique id}
  • {url::basePath}Portal/index.html?route=formByTask&path=/Demo%20Pageset/Tasks/Task%20Assignments/&taskID={task::id}&taskDueDate={task::due date param}
  • {url::basePath}Portal/?ForceDefaultLogin=true/index.html?route=form&path=/Demo%20Pageset/Workflows/Workflow%20Assignments/&uniqueID={flow::unique id}

Replace the names of the Pageset (Demo%20Pageset), Page (Workflows or Tasks) and Panel (Workflow%20Assignments or Task%20Assignments) with your own.

Names must be URL-encoded (include %20 for spaces).
