Embedded Mode for Workflow Solutions

Embedded mode allows you to use Advanced Workflows (WAB) solutions directly from Core (GX2) without having to perform any configuration or installation tasks. 

You cannot work offline using the embedded mode. Additionally, Help and Sign Out settings are not available.

To view the Workflow Solutions in Core (GX2):

  1. From the menu, go to the Business Intelligent > Advanced Dashboard
  2. Click New.

  3. From the Add Indicator(s) pop-up window, select Others from the drop-down list.
  4. Check Other Web page.
  5. Click Select.
  1. From the Web Page pop-up window, click in the middle of the page.

  2. In the Set a URL window, enter the URL: 

    https://go.enviance.com/CustomApp/{INSERT_WAB_GUID}/embedded.html?SystemID={INSERT_SYSTEM_GUID}
    For example, the link https://go.enviance.com/CustomApp/a0d5f1dd-9a41-448d-adc8-d61f47f1c261/embedded.html#/?SystemID=b840d8cd-121a-4827-8fbc-d9147695af7a has WAB GUID "a0d5f1dd-9a41-448d-adc8-d61f47f1c261" and SYSTEM GUID "b840d8cd-121a-4827-8fbc-d9147695af7a". To construct the correct link syntax for your use, see Links to Workflow Solutions.

  3. Click Set. 

In order for the Advanced Workflows (WAB) App to be loaded in the embedded mode and be able to load the Portal in the embedded mode, you need to set the following URL, containing  the macro mode, "/goto/{SystemId}/Portal/{mode}", in the Workflow Solutions' Configuration file. See Configuration File.
