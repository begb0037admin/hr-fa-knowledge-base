Adding Object Selectors to a Form

Adding Object Selectors allows users to assign a workflow to a System Model Object.

To add an Object Selector

  1. From the main menu dropdown, select Designer to open Forms Designer.
  2. Click the Forms tab.
  3. Click the Form Type dropdown textbox and select a child workflow type.
  1. Click the Workflow Step dropdown textbox and select a workflow step where forms are present.

 

  1. Click the Fields ribbon.
    The Field ribbon will expand with a menu of Field types below it, and two sections display to the right, Header Fields, and Field Sections. 
  2. Click the Object Selector ribbon.
    The Object Selector menu expands.


  3. Click an Object Selector.
    The Object Selector is added to the bottom of the Field Sections.
  4. Click and drag where you want to place the Object Selector field in the Field Sections.
  5. To update the name of the Object Selector, click the Editicon to the right of the Object Selector name.


    1. Type in the name you want the Object Selector to display. 
    2. Click the check mark to the right of the Object Selector name textbox.

    1. To edit the location level search results for the object selector, Click the plus icon.
      The Object Selector window expands.


      1. Select whether you want to Object Selector to populate results that are either at the Division level, Facility level, Unit level, or POI level.
      2. When multiple Objects are selected, select the Enforce Hierarchy checkbox so that objects of varying levels can be organized and filtered by the higher object level.
      3. When Allow Multiple is selected, end users on the form can select more than one object in the Object Selector dropdown textbox.
        This can be used when more than one object is to be inspected.
      4. Click Save.
