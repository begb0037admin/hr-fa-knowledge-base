Sample InspectionApp Email Notifications

A sample email template is provided for your use in setting up email notifications with links that will take users to the InspectionApp to complete their workflow assignments.

Download the HTML text file from the link in the table below to your system. Then follow the instructions for setting up the Notification Template.

Notification Template Name Subject HTML text file
Inspection - Corrective Action Assignments Dashboard You have been assigned a Corrective Action Inspection - Corrective Action Assignments Dashboard.txt

To create a Notification Template:

  1. From the main menu button, select Setup > Notifications > Templates.
  2. Select New Notification Template.
  3. For the Type, select Workflow Notification.
  4. Enter a name for the template.

  5. Enter a Subject line.
    Suggested subject line with macro is given in the table above (edit as desired).

  6. For the HTML message body, click Source.
  7. Open the notification text file in a text editor (i.e., Notepad or Notepad++). Copy and paste the contents into the Source window.
    You can edit the text as desired.
  8. Click Save.
    A preview of the message will be displayed.
  9. Click Confirm to save the template.
  10. Create the Workflow Policies shown below and associate the Notification Templates listed, then associate the policies to the Workflow Type in the last column.

Workflow Policy Notification Template Roles Time to Notify Workflow Type
