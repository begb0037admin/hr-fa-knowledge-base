Charts

Key data is available in chart form. Different kinds of charts may be available, according to the configuration. For example:

  • Count of App Items
  • Count of Actions

You can filter the panels by available criteria, such as Type of App Item or Areas, for example.

View Charts

You can view all charts and customize the data shown. 

  1. Select Charts from the main menu button. 
    Each chart may be filtered by date or location.
  2. To filter data in a chart, do the following:
    1. Select the filter button on the top bar.
    2. Start typing in the text box, then select from the matches offered. Repeat to add more than one criteria. Click Apply. 
    3. Click the Refresh button at the top right corner of the panel.

  3. To expand a chart to the full window, click the double arrow button  on the top right. Click again to reduce it to original size.
  4. To apply a date filter, on the top navigation bar, enter From and To dates.
  5. To view the chart data in list form, click the List button in the top left corner of the graph. 
  6. To drill down to data from the graph, select any graphical bar to show a list of the changes or actions it represents.
