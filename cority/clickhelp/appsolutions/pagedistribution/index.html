Page Access for Users

The Page Library shows the users that have View and Edit access to each page. You can choose the Users and User Groups that have permission to each page in the portal.

To set up page access:

  1. Select the Page Library icon from the main menu button.

  2. Select the Edit pencil  for the page.

  3. In the edit dialog choose the users and/or groups for View access and Edit access.
    Begin typing the user or group name to find and select a match.

  4. You may add multiple users and groups by initiating a new search.

  5. When you are done, click Save to save your edits.
