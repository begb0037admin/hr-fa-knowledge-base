Edit Inspection Types

Each Inspection Type is represented by an instance of the EIA-InspectionTypeDefinition workflow type.

You may edit an Inspection Type in the following ways:

  • Edit the name of the inspection type. (See below.)
  • Change the default question response options shown in the dropdown lists.

To edit an inspection type:

  1. Select Tasks and Workflows from the menu button, then select Workflows.

  2. In the search pane, filter for the workflow type EIA-InspectionTypeDefinition.

    The resulting workflows represent the existing inspection types.

    If you do not see any workflow, in the Search pane, check "Workflows I can manage" and set start date to 1/1/2000. Click Search. (The search selection should now remain your default.)

  3. Select the workflow that represents the inspection type you want to edit.
  4. Select the Step (Inspection Type Template).

  5. Select Edit.

    Inspection Type: This is the name of the inspection type that will be used in the InspectionApp.

    Dropdown Question Possible Answers (1-10): To set the default list options for the inspection questions that use dropdown list answers, enter the text option in each of the fields. Up to ten possible options may be set. These options may be overridden by values set for specific questions on the question definition workflow.

    The field Use Library Questions? is no longer used. It is replaced by the Tag Scheme called EIA-InspectionType to identify inspection types that use Library Questions.

  6. After editing the form, click Save and Exit to save the workflow (leaving the workflow open).

Leave all workflows open to make it easy to edit them if necessary. If you close the workflow instances, you will not be able to edit the definition unless you reopen it. However, the InspectionApp will still function if the definition workflows are closed.

If you are using Legacy Questions for configuration, you will need to edit the inspection type workflow to add associated questions as child workflows. See Legacy Questions for more details.
