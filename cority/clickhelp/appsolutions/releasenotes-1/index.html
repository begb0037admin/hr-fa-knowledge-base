InspectionApp Release Summary

Version 2.5 Release date: 7/10/2017

  • Export Inspection Report to Excel
  • Display Question text in Findings/Corrective Action list on Search page
  • Ability to edit inspection name
  • Ability to edit Inspection date and due date after creation
  • Updated Color Scheme

General Enhancements and Bug Fixes:

IA-714 – Updated Scoring Logic to properly ignore questions in scoring calculations when a response with a NULL weight value is selected (making the question N/A).

IA-716 – Calendar displays all Inspections even if the User has no Permissions

InspectionApp 2.4

Release date: 4/20/2017

New Features and Improvements:

  • Optional Scoring feature was added. When Scoring is enabled, a weight can be added to each question and values assigned to answers, resulting in an overall score for an inspection, which is displayed in the Inspection summary and allows users to easily identify problem inspections.
  • Findings: The option to create Findings for inspections was added. When Findings are enabled, users can create Findings for a question. Corrective Actions are then associated with Findings, rather than directly to the question.
  • Tags: Support Unit/Element as POIs for tag associations
  • Support for General question without applicability criteria tags
  • Form Preview now segments General questions and Inspection Point questions.

General Enhancements and Bug Fixes:

IA-616 – Dashboards: The chart showing Number of CAs Outstanding vs. Complete counts General Question CAs incorrectly

IA-588 – Title of Inspection Completion window is cut off on IE11

IA-418 – Form Builder: No warning when trying to save questions to inspection points with no object associations

IA-409 - Change error message shown when selecting Inspection Type name that exceeds field length
