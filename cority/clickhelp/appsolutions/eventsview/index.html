Events Panel

An Events Panel shows event instances and associated data recorded in event logs. Users can edit the event forms if needed. The event data may be filtered by various criteria.

The panels can be viewed in table or chart mode.

To change the panel view:

  • Choose the table , chart or Calendar icon on the panel bar.

  • To refresh data in the panel, Click the Refresh icon:
  • To expand the panel to full screen size (depending on device), click the Expand icon:

Table View


You can view the table as follows:

  • The table can be scrolled horizontally and vertically.

  • The Form icon will take you to the Event form, where you can view or edit event data. See View or Edit Events. 

  • The Link icon will take you to the event form in the Management System.

  • To sort records by a column, click the column head. Click again to change sort order to ascending or descending.

  • To resize a column, hover over the right edge of the column header until the slider appears, then select and hold while you drag and drop to the new width.

  • To move a column, hover over the column header to select the column, click and hold, and drag and drop the column to the desired position.

If the filter criteria are visible above the display list, you can add a filter for the data in a column. Click the filter box at the top of the column you want to add a filter to. Depending on the field time, you can enter a value, or a partial value for a text field, or choose from a dropdown list. Click the icon next to the box to choose the filter condition.

Any filters that have been applied are displayed above the panel.

Chart View

In Chart View you can view event data in graphic format.

From the chart view, you can do the following:

  • Hover over a chart element (bar or line) to see the value it represents.

  • Show or hide the legend by clicking the arrow.

    Click and hold to drag the legend to another position.

  • Use the slider at the top to reduce or increase the date range on the horizontal axis.

    Click Show All to return to the original page date range.
