Workflow Application Builder Page Button

Workflow Application Builder page buttons allows users to go from the Portal to a Workflow Application Builder seamlessly. Multiple page buttons can be added to ease users experience in navigating between pages within the software.

To Access a Workflow Application Builder from the Portal Using the Page Button

  1. In the Portal, navigate to the portal page with page button of interest.
  2. Scroll to the bottom of the portal page.
  3. Click a Workflow Application Builder page button.


      The Workflow Application Builder page will open. 

    To Add a Customized Page Button that Links to a Workflow Application Builder

    1. In the Portal, click the Page Settings  icon
    2. On the Page Settings window, click the + Page Button.
      A drop-down menu will open.

    1. Click Add New Workflow.
      The Add New Workflow window will open.

    1. On the Add New Workflow window, enter a Button Label.
    2. Select a button color and an icon. A preview will display next to the Button Label field.
    3. Select a Workflow App that the button will link to.
      The list displays available WAB apps in the system. To link to a custom app, select Other App and enter the app name.

      Auto-populate Page Object Selector Levels to Workflow App: This option will auto-populate the object selector on the New Item page with the objects selected for the page. Choose which object levels should auto-populate.

      Open Workflow App in New Browser Tab: You can choose whether to open the app in a new browser tab, or to open in the same window as the Portal (allowing for a smoother transition).

    4. Click Apply.
      The Workflow Application Builder header button is added to the header of the portal page.  
    5. Click Save.
