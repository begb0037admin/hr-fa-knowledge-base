Download Numeric Data to Excel

You can download numeric data to Excel, for use in reporting, creating custom charts, or for other purposes.

Before downloading data, you can customize the column display and the date range to show only the desired data to download.

To download the contents of the table to Excel:

  1. Set the table to display the data that you want to download, including the date range and columns.

    See Edit Data Display to choose the columns. Only the visible columns will be downloaded.

  2. Click the download button.

    All data rows matching the date range and visible columns will be included (even if the rows are not visible due to panel size).
