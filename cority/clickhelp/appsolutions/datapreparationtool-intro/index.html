Data Preparation Tool

If you are looking for information on the EQL Query Language, see the EQL User Guide.

The Data Preparation Tool is an advanced query building application that will enable you to quickly and visually create the EQL queries you need to gather your data for reporting and analysis. You will be able to easily explore your data in business-friendly terms and create your own reports using a simple drag-and-drop interface as well as export your data for distribution or further analysis.

Users can:

  • Design queries using a simple drag-and-drop interface that can intelligently join related tables together.
  • Explore data sets using tables that may be sorted, filtered, grouped, and even displayed in simple charts.
  • Create Data Views that will allow users quick and easy access to just the data sets they need (Data View creation requires appropriate permissions).
  • Save queries that can be viewed and run by others in the Query Library. 
  • Export data to Excel in both .xlsx and .csv formats.
  • Utilize the full power of the EQL engine by using the EQL Editor to create more complex queries and data structures.
