Linking an Account

  1. Open the User Management App.
    A list of active users will display.
  2. From the Application drop-down menu, select the application whose user(s) you want to link. 

  3. Click the  icon to the right of the user you want to link.
    The Link Accounts dialog box will open.
  4. If the user has an account in one or more other applications, those accounts will display below the Source Account details.
    In the following example, the selected user has both an Environmental account (the source account) and a Chemical account. 


    By default, the User Management App will search for matching accounts by email address. If a user has accounts in different applications that use a different email address, you can search for matching users using other criteria, like User ID, First Name, or Last Name.

  5. Click the Link icon to the right of the account.
    The icons will change to green, indicating the accounts have been linked.


  6. Click Close to exit the dialog box.
  7. Repeat these steps for each user whose accounts you want to link.
