Version 2021.1 

Release date:  July 2021

Release Improvements

  • In-App Transition Performance

    • The application will now load the next screen for the user without waiting for information to be returned from the server. The result will be significantly shorter wait times when moving between steps, creating child workflows, etc. The data will be uploaded to the server in the background, and the user will be notified by non-intrusive messages about the status of their changes.

  • Low-Bandwidth Form-Loading Performance

    • The application has been fine-tuned for lower-bandwidth form-loading by requesting only configuration data that has changed since the last time the user loaded the application. The result will be faster load times for repeat users, particularly for slower or higher latency connections.

Pre-Release Improvements & Bug Fixes

ComponentTicketDescription
FormsWAB-4473

Objects selected on parent workflows will now consistently be inherited by child workflows.

OfflineWAB-2884

The “Enable Offline” button has been replaced with an “Install App” button. Installation on Android devices will now also place the App on the user’s home screen and enable a full-screen experience (i.e., no browser URL bar).

OfflineWAB-3699

Offline operations have been upgraded to use browser service workers, improving the performance and integrity of operations in working environments that have changing connectivity (except in Microsoft IE 11).
