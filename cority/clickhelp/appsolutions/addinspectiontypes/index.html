Add Inspection Types (Legacy Questions)

The following information is provided for Legacy Question configuration created prior to version 2.2. With Library Questions created with InspectionApp 2.2 or later, you can use the Form Builder to create and edit Inspection Types.

Each Inspection Type is represented by an instance of the EIA-InspectionTypeDefinition workflow type.

To create a new inspection type, you need to first create a workflow instance for the EIA-InspectionTypeDefinition workflow type.

To create a new Inspection Type:

  1. Select Tasks and Workflows from the menu button, then select Workflows.

  2. In the Search pane, filter for the workflow type EIA-InspectionTypeDefinition.

    The resulting workflows represent the inspection types defined for your system.

    If you do not see any workflow, in the Search pane, check "Workflows I can manage" and set start date to 1/1/2000. Click Search. (The search selection should now remain your default.)

  3. Click Create New Workflow. For the workflow type, select EIA-InspectionTypeDefinition.

  4. For the Workflow Name, enter a name for the inspection type.

  5. Click Create.

  6. To set the list options for the dropdown list type, enter the text options in each of the Dropdown List Possible Answer fields. You can enter up to ten values. These will be the default list options, which may be overridden for any question, if the values are defined otherwise on the question.

  7. Select Save and Exit when you are done to save the inspection type workflow.

Leave all definition workflows open to make it easy to edit them if necessary. If you close the workflow instances, you will not be able to edit the definition unless you reopen it. However, the InspectionApp will still function if the definition workflows are closed.

Create questions for the inspection type from the step editing form by creating child workflows. Create one child workflow for each question. Click Save And Create Question to create a child workflow. To create subquestions for each question, triggered by particular responses to the question, click Save And Define Sub Question. See Legacy Questions for more. When you are finished, select Save And Exit to return to the parent inspection type workflow.

When you create the workflow type definition workflow, select and associate all the System Model Components for which you want this inspection type to be available. The question workflows that will be created as children will then inherit the initial set of objects, which can then be edited as necessary.
