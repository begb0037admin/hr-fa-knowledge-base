Release Notes for Health & Safety (OES) v1.8.34.20221130 

Release Date: 11/30/2022


    New functionality

    • Added a new report to track discomfort and assessment risk after the opening of a Case Manager case. Report provides a view of risk/discomfort: When case is opened; When case is closed; 30 days after case is closed; 60 days after case is closed. Provides an objective measure of effectiveness of the case management process. (Cority ticket HS-6910)
    • When a user’s login session times out, they now receive a popup letting them know that they are about to be logged out (with option to continue session). (Cority ticket HS-7042)
    • Improvements to internal diagnostic logging to better respond to any future OES issues. (Cority ticket HS-7091)

    Bug fixes

    • Corrected an issue where users with changing roles may not be shown in the list of people available to assign cases to. (Cority ticket HS-7067)
    • Corrected a screen-reader accessibility issue on reading of fields in Discomfort Update popup. (Cority ticket HS-7082)
    • Reports using “My Saved Criteria” with hidden employee ID column might not be downloadable. This was corrected. (Cority ticket HS-6219)
    • Searches with “My Saved Criteria” with multiple pages of output might not properly page through results. This was corrected. (Cority ticket HS-7023)
    • Corrected an issue that in some scenarios prevented bulk emails from the Progress Report results. (Cority ticket HS-7074)
    • Corrected an issue where RSIGuard reported a keyboard or mouse device to OES and OES was unable to record the result. (Cority ticket HS-7079)
    • Fixed a spelling error in a couple reports. (Cority ticket HS-6855)
    • If the assignee on a Case Manager case changed, the Approve/Deny email could go to the original assignee. Corrected. (Cority ticket HS-6991)
    • When an admin views a supervisor’s MyTeam tab, they could click on the “Check In Completed” button. They shouldn’t be able to do this, and this has been corrected. (Cority ticket HS-7053)
    • Corrected issues that could prevent a new Captivate training from being preview-able on the Alpha server. (Cority ticket HS-7057)
    • Corrected an incorrect “system error message” that could appear when closing a Case Manager case. (Cority ticket HS-7066)
    • Corrected an issue where a log point would not be generated when a case is closed in Case Manager after the user didn’t respond to their completion survey. (HS-7080)

    Security updates

    • Preventative improvements to security header configurations. (Cority ticket HS-7110 (partial) & HS-7111)
    • The OES allows file uploads and removes any detected viruses. Preventative improvements to this system were implemented. (Cority ticket HS-7112)
    • Added rules to allow a customer to require stronger passwords for stronger preventative security. (Cority ticket HS-7113)
