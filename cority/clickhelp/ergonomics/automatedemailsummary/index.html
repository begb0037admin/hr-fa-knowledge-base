Automated Email Summary

Automated emails are set up in the system configuration for your organization. Different email types can be turned on or off for your system, as required.

To preview the emails, select Preview OES Emails from the left menu on the Administration Home page.

The OES automated email texts may be viewed in multiple languages. Select the language you would like to view for each email. See Appendix C for the text of the automated emails in US English.

Emails shown with Status "On" are automated emails generated by the OES system (except for the Recent Change Self-Assessment Update email and the Workstation Self-Assessment Review email which are sent manually).

Those emails with Status "Off" are Case Manager emails not automated by the system.

All emails sent via OES are logged in the individual's Email Log.
