Issues Details & Notes

The Issue Details & Notes Report allows you to view the physical workstation configuration for employees, including any workstation-related notes. You can filter by employee attributes (such as a particular department) or set filters to relate it to various issues.

The columns included in the report are:

  • Name
  • Employee ID
  • Chair Type
  • Keyboard Tray
  • Multiple Monitors
  • Other Workstation Needs
  • Seated Work Surface Height
  • Shares Workstation
  • Workstation Layout

Click on a user name to go to the Employee Summary for that person.

To make it easy when doing a workstation visit and review you can print the report or export it to Excel by clicking Print Results or the Export to Excel button.
