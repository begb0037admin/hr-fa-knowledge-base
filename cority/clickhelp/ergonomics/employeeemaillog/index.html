Message Log

The Message Log for a user may be viewed from the Employee Summary. You can view all automated system-generated emails and notifications, as well as emails sent using the "Email Employee" option.

To view the Message Log for a user:

  1. From the Employee Summary, select Message Log from the left menu.

Emails may be viewed and re-sent from the Email Log if required.

Note:  When resending an email to a user, the exact same email is resent to the user. The system does not generate a new one. However, if the email includes a temporary password (e.g., Invitation email), a new temporary password will be generated and referenced in the re-sent email.

For details on how to email a user, see Custom Emails.
