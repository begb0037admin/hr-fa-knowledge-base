Case Manager Evaluators User Guide

Download a print version of this guide here: Case Manager Evaluator (PDF)

Cority's Office Ergonomics Suite (OES) Case Manager System is an integrated system designed to document Ergonomic Workstation Evaluations and Follow Up Reports.

Worksheets and employee reports can be completed and viewed according to each Administator's, Evaluator's, and Scheduler's access role.

The Evaluation Worksheet can be accessed from the To Do List. If an evaluation has been scheduled for an individual, Start Evaluation will be displayed as the default action. If an evaluation has not yet been scheduled, you can select Schedule to schedule it.
