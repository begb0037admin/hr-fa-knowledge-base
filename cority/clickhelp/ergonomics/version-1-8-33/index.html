Release Notes for Health & Safety (OES) v1.8.33.20220505 

Release Date: 5/5/2022


Corrected Accessibility Issues

  • Dashboard pages contain H2 (header tag) without H1. This creats an issue for screen readers. Corrected. (Cority ticket ID HS-7032, CustRef: 8247217)
  • Unable to navigate discomfort frequency options in Discomfort Update page (on dashboard) in NVDA screen reader. Corrected. (Cority ticket ID HS-7044, CustRef: 8247211)
  • Corrected issue where at 200% magnification, some elements could overlap. (Cority ticket ID HS-7031, CustRef: 8247206)
  • On the Discomfort Update page, pressing enter on a radio button should cause a screen reader to announce status. Addressed. (Cority ticket ID HS-7033, CustRef: 8247232)
  • Added a "Keep Me Signed In" window to let user know that they are about to be logged out (and give user option to stay logged in). (Cority ticket ID HS-7042, CustRef: 8247252)
  • Using a screen reader, pressing the down arrow does not go to relevant content on logout page. Corrected. (Cority ticket ID HS-7043, CustRef: 8247224)
