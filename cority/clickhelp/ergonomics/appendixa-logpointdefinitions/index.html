Appendix A:  Log Point Definitions

Standard system-generated log points are listed below. Additional log points may be added for specific customers.

LOG POINT

MEANING

been added to the database

User has been added to the OES database (either through the HR GPD feed or manually by a OES administrator).

been sent the invitation email

An invitation email has been sent to the user (either by the system through an automated invite or manually by a OES administrator). Log point triggers on-line program option on the user's Welcome page to become recommended option.

logged in

User has logged in to the OES system.

-- gotten past the initial assessment

This log point is always associated with "finished the on-line program (Assessment)" log point. If this log point exists without the "finished…" log point, the user has not yet completed the full Assessment & Training.

-- finished the on-line program

User has completed the Assessment & Training. (This is the date that shows in the "Last Trained" column when running reports.)

visited issue resolution

User has visited the Issue Resolution tab

no unreviewed items left in to-do list

Users has clicked on "I have resolved this issue", "I am still working on this issue", or "I am unable to resolve this issue" for all issues in their To-Do List (under Issue Resolution). Log Point only applicable after July 1, 2015.

been sent the completion reminder email

User has been sent a reminder email to complete the OES assessment. Email is sent if user has started, but not completed the Assessment & Training, a Risk Profile Update, OR a scheduled update).

linked an RSIGuard installation to their OES profile

User has installed RSIGuard on their computer and linked it to their profile in OES.

stopped sending RSIGuard usage data to the OES (noted on the 30th day of silence)

RSIGuard has not transferred data to the user's profile in the last 30 days (i.e. user has turned RSIGuard off or has not logged into that computer in 30-days, etc.)

been sent the [first] follow-up (i.e. 30-day)

User with high or moderate risk or with constant or frequent discomfort 20 days after finishing an assessment was sent a follow-up email with a reminder to visit the Issue Resolution tab.

been sent the [second] follow-up (i.e., 60-day)

User with high or moderate risk or with constant or frequent discomfort 90 days after finishing an assessment was sent a follow-up email with a reminder to visit the Issue Resolution tab.

completed an email-initiated Instant Reassessment

User has completed an update through an emailed link (e.g., 20-day update, or one manually sent by an administrator). NOTE:  This log point is not generated when customer uses dashboard because users can address outstanding issues via their dashboards (Issue Resolution tab).

been sent the Risk Profile Update email

User with some specified assessment risk or discomfort was automatically sent an email to complete the Risk Profile Update option on the dashboard home page.

gotten past initial assessment (1st part of on-line program)

This log point is always associated with the "completed a Risk Profile Update (Office)" and prior to the dashboard implementation was associated with the "completed an email-initiated Instant Reassessment (Assessment)" log point. If log point exists without the "completed…" log point, the user has not yet completed the profile update

completed a Risk Profile Update

User has completed a Risk Profile Update.

Discomfort Information Updated User made an update to their discomfort status

been marked as a managed case

User has been marked as a Managed Case by an administrator

had their managed case override expire

The Managed Case override was manually removed by a OES administrator OR the specified time period has passed since user last completed the full OES Assessment & Training. After recompletion of Assessment & Training the user may be placed in "Managed Case" override status again by an OES administrator if needed.
opted out of managed case via login The user has logged into OES and the Managed Case status has been removed. The user will begin receiving automatic emails from the OES system.
had a Cartevia case created for them A Cartevia case was created for the user (either through auto-creation or manually by a Cartevia administrator/evaluator/scheduler). Deprecated.
had a Cartevia case closed A Cartevia case was closed for the user manually by a Cartevia administrator/evaluator/scheduler. Deprecated.
had their case created A Case Manager case was created for the user (either through auto-creation or manually by a Case Manager administrator/evaluator/scheduler).
had their case closed A Case Manager case was closed for the user manually by a Case Manager administrator/evaluator/scheduler.
