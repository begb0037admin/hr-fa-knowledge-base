Release Notes for Health & Safety (OES and Case Manager) v1.8.30

Release Date: 10/22/2021


Newly-Available Customer Options

  • Added option for reportable log point to be created when MyTeam Tab has been visited. This feature allows you to report on which supervisors/managers have visited the MyTeam Tab. If your organization uses the MyTeam Tab and would like the ability to report on this, please contact your Customer Success Manager. (Cority ticket ID HS-6907)
  • Added option for reportable log point to be created when users visit Update Discomfort dashboard page. This feature allows you to report on which users are engaging with OES by visiting "Update Discomfort". If your organization would like the ability to report on this, please contact your Customer Success Manager. (Cority ticket ID HS-6908)


New Functionality

  • Desktop Risk is present for all customers with integrated RSIGuard. previously, this functionality was only available by special configuration per organization. It is now available for all OES+RSIGuard customers. (Cority ticket ID HS-6976)
  • RSIGuard notifications take users to specific locations within the dashboard. Please ask your Customer Success Manager how you can use RSIGuard notifications to boost engagement with the OES to increase training compliance, use of Issue Resolution, reading of messages, and updating of discomfort status. (Cority ticket ID HS-6987)
  • RSIGuard can now get additional menu items to make it easier for employees to engage with your organization's internal systems. Please ask your Customer Success Manager how you can use this to add menu items to connect to any web-based internal resource, external applications, informational websites and more. (Cority ticket ID HS-6986)


Informational Items

  • Annual Accessibility Review. Each year we conduct an accessibility review using automated tools and manual examination using the most recent accessibility guidelines. The identified items will be corrected in our next release. (Cority ticket ID HS-6939)


Corrected Bugs

  • Corrected an issue in which attempts to send more than 98 emails at a time failed. (Cority ticket ID HS-6914)
  • Corrected an issue with Setup Manager that limited access to Security Groups and other setup functionality. (Cority ticket ID HS-6966)
  • Corrected issue that caused Case Manager Survey and "Approve Deny" functionality to not work. (Cority ticket ID HS-6969)
