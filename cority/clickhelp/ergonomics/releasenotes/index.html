Health & Safety (OES and Case Manager) Release Summary

Version 1.8 Release date 1/11/2019

Advanced Scheduling

integrates Case Manager with Microsoft Exchange Services, allowing scheduling of appointments with visibility into calendar availability of both Evaluators and Employees. Includes three views:

  • Employee Scheduling View: For scheduling appointment for a selected employee.
  • Evaluator Scheduling View: For scheduling multiple appointments for an Evaluator.
  • Bulk Scheduling View: For scheduling multiple cases with available Evaluators.

Expanded To Do List Filters

  • Discomfort and Status Filters
  • Multi-select of Filters – Risk level, Discomfort, Status
  • Directed HR Attribute Search

Version 1.7 Released 9/20/2018

New Worksheet Image Element 

New worksheet image element allows Evaluators to associate images with specific worksheet assessment areas or questions, uploading images from a photo library or mobile device camera. The element can be placed within an grid in the worksheet. Images can be edited from the worksheet to zoom, rotate or crop, and captions may be added.

Version 1.6.3 Released 8/2/2018

Case Manager To Do List enhancement:

Next Best Action: With a single click, evaluators and schedulers are taken to the

function for action completion. Automatic analysis of To Do List items determines

most likely action.

Action Drop-Down: Alternative, permission-controlled actions are consolidated

into a single drop-down list for each To Do List item.

Clear All Filters: With a single click, evaluators and schedulers can clear all filters

set in both top-level and column criteria.

Dynamic Date Column: Personal configuration of the date column allows the user

to focus on the most important date for the task at hand. Date column can be

configured to show:

  • Requested Date or Target Date for Scheduling tasks
  • Scheduled Date for Assessments
