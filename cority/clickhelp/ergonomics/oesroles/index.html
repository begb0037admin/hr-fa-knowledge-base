OES Roles

Roles define what users can do in the OES system. Several administrator roles providing different levels of access are commonly used. Additional roles may also be defined for your system. Some typical roles are discussed below.

Primary Administrator

This role is typically assigned to lead Administrators those who require access to all administrative tools and user data stored in the system. A Primary Administrator can assign any role, create or edit user accounts, view data for the entire organization, and run all reports.

OES Administrator

This role is typically assigned to users who do not require access to all administrative tools and who may require user data-access restrictions. OES Administrators are usually able to assign roles, create or edit user accounts, and run all reports.

Default User

This applies to all users in the OES who are not administrators. Default users have access to their own dashboard (see discussion of user dashboards for details), but have no access to the OES administration area.
