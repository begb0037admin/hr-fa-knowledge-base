My Team Tab

The My Team tab is an optional tab available from the Dashboard for managers who have users directly or indirectly reporting to them (in the management hierarchy).

Summary data is shown for each user under the manager's supervision. Fields are configurable per system, but may typically include:

  • Current Risk levels
  • Link to Action Items
  • Last Self-Assessment date (self-assessment completion date)
  • Last Training date (online training completion date)
  • Last Ergonomic Evaluations
  • Number of unresolved items on To Do List

The users included are all users who report to the manager logging in, including users who report to managers who directly report to the manager logging in.

A drill-down option may be available, if that has been configured for the system. If the preference is to drill down, the manager will see a tree list of users sorted by the manager they report to. If not, all users will be shown in a single view, not separated by manager.
