Assign HR Attributes in Bulk

HR profile attributes may be changed in bulk by running an Employee List Report for the users and selecting users to edit from the results list.

See Employee List Report for information on running this report.

You may also assign "Active" and "Not Active" status in bulk and (if applicable) apply the Active Status Override. See Edit User Active Status .

To assign an HR attribute in bulk:

  1. First select the users you want to edit.

    Click the Name box to select all users in the results, or select users individually.

    To select or de-select all users on the current page only, see the instructions on Making Bulk Selections below.

    When there are multiple pages of results, and you navigate to a new page, the previously selected users are remembered.

  2. Once you have selected the users you want, click Assign Attribute.

  3. Choose the attribute to assign and click Continue.

  4. You will be asked to confirm the changes. A list of the all users affected will be shown. If the changes are correct, click Yes. If the changes are not correct, click Cancel.
  5. Select OK to confirm the changes.

    6. You will then receive a confirmation that the changes have been made. You will need to re-run the Employee List Report to see the changes.

    You can also Send Email and Update the Active Status of all individuals included in a report at one time; however, you can only Assign Attributes to 1000 users at a time.

    Attempting to assign an attribute to more than 1000 users at a time will result in the following error message:

Making Bulk Selections

To select all users on the current page only:

  1. Check the box next to Name to select all users in the report.
  2. Uncheck the box next to the first name.

  3. Re-check the box next to the first name.

The result is only the users on the current page are now selected (maximum of 100 per page).

To clear all selections on the current page:

  1. Check the box next to Name to select all users in the report.

  2. Uncheck the box next to Name.

The users on the current page will have been cleared. Note that any selections on other pages will remain.

To select all users in entire Employee List Report (all the pages):

  1. Check the box next to Name.

    Once you have checked the Name box to select all:

    • If you navigate to another page without unchecking Name or any accounts on the 1st page, the 100 accounts on the 1st page will remain selected and all other accounts will now be unselected.
    • If you check the Name box on your new (2nd) page, it will again select ALL users' accounts in the report. However, this time, if you uncheck Names on the 2nd page, it will unselect all remaining names, leaving the 100 names on the 1st page still selected.
    • If you check Name on the 2nd page and then navigate to another (3rd) page without unchecking Name, the names selected on the 1st and 2nd pages will remain selected and the remaining names will now be unselected. This process can be repeated with every subsequent page.

To clear all selections in entire Employee List Report (all the pages):

  1. Select Run with criteria below from the Employee List Report button in the Reports menu.top right.
