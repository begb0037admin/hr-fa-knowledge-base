Helpful Files and Links

The Helpful Files and Links (or Help Documents) page can be accessed from the left menu on the Administration Home page .

You can add files or links to documents on your company intranet as you wish.

To add a file from your own computer or network:

  1. Click Add File.
  2. Enter a name for the file and an optional description.
  3. Click Browse to locate and select the file to upload.

  4. If you want the file to be available as an attachment to OES emails, select "Yes -- Make available as an OES email attachment".

  5. Click Upload New File.

To add a link to a file on a website or local intranet:

  1. Click Add Link.

  2. Enter a display name for the link and an optional description.

  3. Click Add New Link.

To change the display order for items:

  1. Click Change Order.

  2. Edit the numerical order of items in the far right column.

  3. Click Save.
