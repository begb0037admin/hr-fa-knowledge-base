Cases Page

The Cases tab allows you to view and search for all cases within the system. The rich filtering options provide several ways to view, filter and find cases based upon your criteria. This page can be used by schedulers and administrators to search and perform tasks for various cases assigned to different evaluators. You can create your own saved filter settings and easily re-load them when needed.

To select an action for a case:

  1. Hover over the link in the case Type column and select an action. Actions will depend on case type and permissions.

    Clicking the Type link (rather than selecting an action) will take you to the Case Summary.

  Hover over the info icon to see a pop-up showing case schedule information.

To filter cases:

  1. Select the filter criteria from the top of the page.

  2. Click Apply.

    The refresh button will refresh the results.

To save case filter settings:

  1. After apply the filter, click the Save Settings button.

  2. In the dialog, give the filter a name and click Save.

To load saved filter settings:

  1. Select the named filter from the Load Settings drop-down list.

To modify the saved settings:

  1. First, load the saved settings. Then change the filter criteria as desired.
  2. Click Apply.
  3. Click the Save Settings button.

  4. In the dialog rename the filter (optional) if desired and click Update.
