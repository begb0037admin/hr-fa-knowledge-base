OES Invitation Email

The invitation email should be sent to new users when the user accounts are set up and the system is ready for rollout.

For new users and users who may have lost the original email invite, the invitation email can sent manually. Prior to sending this email, ensure that:

  • The user has not already completed a Full Self-Assessment & Training within the last 18 months. If the user has completed a Full Self-Assessment & Training within the last 18 months, the Recent Change Self-Assessment Update email should be sent instead.

To send an Invitation email manually:

  1. From the Employee Summary, select Email Employee from the menu on the left.
  2. In the email dialog, check Send a pre-fabricated email.

  3. Select "Invitation email" from the dropdown list.

When invitation emails are manually sent, the invitation will be sent to the user from your email address.

Manually sending a invitation to a user who has already participated will reset the user's password. Please note auto invites must be enabled for the user to receive the two follow-up invitation emails.

To trigger an automated Invitation email:

  1. In HR Profile under Access Settings, ensure the users account is Active and the user's Current Policy is "Logins OK".

    Ensure required fields have been populated.

    For Contractors, you may want to assign the Active Status Override.

  2. Click Save.

Once the automated invites have been activated, the user will receive an automated email invitation as long as the user is otherwise eligible to receive the invitation. Because this is dependent on the server refresh (in California USA), the user may not receive the email until the next workday.

Please note if auto invites are turned "ON" all eligible users will receive an invite overnight unless email participation exceptions apply to certain users.
