CME_Glossary

Action Items: These are reminders to schedule and take action on equipment orders and other actions.

Case: An ergonomic evaluation for an employee is the core component of a case. Follow-up evaluations are conducted as part of the same case.

Close: Cases should not be closed by anyone other than the Case Manager Administrator. Once a case is closed, no additional documentation can be made in that case.

Finish: Workstation evaluations get finished when no additional information needs to be added during that individual session.

Evaluation Worksheet: The primary information and data collection tool for every case.

OES: Office Ergonomics Suite

Recommendations: These are specific behavioral and posture instructions given to the employee to assit in improving posture, lowering their risk levels and reducing their discomfort.

Target Date: Can be used by any user if their process requires a target completion date.

Task: An action item is an example of a task in Case Manager.

To Do List: Is the first page displayed when a user logs into Case Manager. What cases and tasks are visible to a user depends upon their role and access permissions.
