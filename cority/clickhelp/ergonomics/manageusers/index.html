Manage Users

As an administrator you can view user data for an individual user in the system and edit user accounts as needed.

The People tab from the Administration Home page allows you to search for and access user accounts.

For convenience, at the top of the page is:

  • A list of your 25 most recently viewed users
  • The date and time that you last viewed their profile

Click on the user's name to access the user profile.

The Find a Person search function in the left menu pane is a shortcut to the People page.

To find a user account:

  1. Under Find a Person enter the first/last name, email address or employee ID and click Search.

    The user must match all of the search criteria entered. If you have a lot of users, employee ID is the most reliable search criteria, as many users have similar names.

  2. From the search results, select the user name.

    The Employee Summary is displayed.

From the user's Employee Summary you can:

  • View User's Dashboard
  • View or Edit the user's HR Profile
  • View Issues & Facts for the user
  • View user's Activity Log
  • See the OES Historical View for the user
  • View Email Log to see the emails sent from the system to the user
  • Email the user
  • View the Notes Log and add notes
  • View Recommendations for the user

To view data for a group of users:

  1. Run an Employee Summary Report for the users whose information you want to view.

    See Employee List Report and Report Criteria for details on setting up report criteria.

    From an Employee List Report you can:

    • Assign HR Attributes in Bulk
    • Edit User Active Status
