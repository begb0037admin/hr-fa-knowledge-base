Summary of Enhancements

The table below describes the enhancements we have made in 2022.2.0.

Item #Component(s)Description
CCC-6781Asset / Equipment Management

myCority now provides geofencing, which is the use of GPS or RFID technology to create a virtual geographic boundary (within myCority) that will enable each user to view the details of assets (equipment) that are “near” his or her present location.

This functionality provides:

  • A Near Me menu link to a map showing the user's current location and area near that location
  • A visual display of the user's location on that map
  • A visual display of the assets/equipment within the map boundaries
  • Security so that only equipment to which the user has access is displayed
  • A list view of the items on the map
  • Zoom in/out capability for viewing the map
  • Refresh/update of the map, based on the user's movement
  • The ability to define search areas (for examples: a Permitted area, an Exposure area)

 

CCC-6421Employee Care – Occupational Health

A user self-scheduling an appointment can no longer unintentionally create a double-booking:

  • When the user submits the appointment request using the self-booking functionality, myCority will now check for any date/time conflict, and if true, will not submit the request.
  • Once the user has submitted the appointment request, if another employee (in a separate session) has successfully booked an appointment with that user for the same date and time, a message to that effect will display asking the user to select a different timeslot.
  • If the user navigates away without first submitting the appointment request, the date and time will remain available (not booked).

 

CCC-7919 and 7752Event Reporting

For the 'Primary Category' field on Event Reports / Incidents, you can now select and save multiple values.

 

CCC-7125Platform – End User

If a recruiter is using a custom Employee (Applicant) Demographics layout, when he or she clicks 'Save and Close', if any of the following fields are on that layout, their value(s) will now be saved into the Employee Job Position data table.

  • Medical Insurance Number
  • Work Status
  • Employee Type
  • Job Position Group
  • Job Type
  • Supervisor
