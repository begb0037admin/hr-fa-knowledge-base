Fix Descriptions

The table below describes the fixes we have made for 2022.2.0.

Item #Component(s)Reported VersionDescription
CCC-7599Occupational Health – Employee N/A

In the GX2 Appointments module, when availability is edited, that is now reflected properly in myCority.

 

CCC-8668DashboardsN/A

If a user views a dashboard, logs out, his or her role then becomes restricted from viewing that dashboard, and then the user logs back in directly to that dashboard, an error message will now display but the user will be able to continue working with other dashboards, views, layouts, etc.

 

CCC-6015Event Reporting – Injury/Illness N/A

When the user creates and submits an 'Injury/Illness' Event Report, a related investigation record will no longer be duplicated.

 

CCC-7634Platform – Administrator2022.1.0

For My Tasks, unused code has been removed.

 

CCC-7243 and 7244Platform – Administrator 

To improve security, myCority now validates user input on both the client and server side.

 

CCC-8111Platform – End UserN/A

A custom Employee view with the Job Position 'Start Date' and/or 'End Date' columns will now load data properly without generating an unexpected error. This is also the case when switching between Employee views.

 

CCC-4872Platform – End UserN/A

When applicable, if the 'Disable Auto-Fill' field for a custom layout is selected, the layout's 'Coordinates' field will no longer auto-populate.

 

CCC-7837QuestionnairesN/A

When a user is assigned a profile and no questionnaires are added to the myCority Questionnaires tab, any questionnaire configured to display as a button will now do that.

 

CCC-7744QuestionnairesN/A

When configured to do so, a questionnaire will now display as a button in myCority.

 

CCC-7631QuestionnairesN/A

For a completed and submitted questionnaire displaying in myCority 'My Tasks', if the questionnaire gets posted to the Questionnaire module from the Questionnaire Inbox, the Completed Date value in 'My Tasks' will no longer change to the posted date.

 

CCC-8070Waste ManagementN/A

If a user creates a new Waste record in myCority, populates fields, adds a document, and then clicks Save, now the Disposed details will be retained, the document will be available on the myCority Documents tab, and the disposal information will get transferred to Cority.

 

CCC-5997Waste Management2021.2.2

On a Waste list view, for each record the correct waste container details will now load and display when applicable.
