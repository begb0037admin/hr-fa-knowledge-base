GX2 Design Improvements and Fixes

The table below lists the design improvements and fixes we have made in the GX2 2023.2.1 release. The items are organized by component and the components are arranged in alphabetical order.

Item #Component(s)ReportedDescription of the Issue
CCC-13359Business Intelligence2023.2.0

In Report Writer, if the user clicks New, selects a data table, then without saving the report selects a field, a single, unique Report Writer record will now be created, as expected.

 

CCC-11851Business IntelligenceN/A

When an Admin user creates and shares a dashboard, a user with the appropriate security configuration can now change the filters for the dashboard and save it.

 

CCC-13268Environmental – Chemical ManagementN/A

The PDF form mapper functions as expected for 'Chemical Products' records.

 

CCC-12556 and 10632Environmental – ComplianceN/A

When importing translations with the ENHESA API integration, the performance is now improved and duplicate translations are no longer created.

 

CCC-12998Environmental / Safety – ComplianceN/A

On a custom version of the ML-003369 layout, a user with the appropriate security configuration can now deselect the Required checkbox for any of the Condition Number, Section, or Condition Description fields, save the layout, and then use the layout when creating an Environmental or Safety 'Permit Condition' without generating an unexpected error.

 

CCC-13444
Environmental / Safety - Incidents
N/A
It is now easier for users to focus on recent incidents.
There is a new global system setting labelled 'Filter Existing Incidents For Event Report Posting'. A time value can be specified that will filter existing incidents for 'Post to Existing Incident' from the Event Report Inbox.

The setting has the following options:
  • 30 Days
  • 60 Days
  • 90 Days
  • 6 Months
  • 1 Year
  • 2 Years
This applies to Safety and Environmental incidents.

When set, this will also improve the performance of the Incident list view while it is loading, particularly for users with limited site security.

CCC-13922ErgonomicsN/A

For Ergonomics 'Case Manager', if a request is made for a PDF to be generated (created, downloaded, and/or emailed), that now functions properly.

 

CCC-13795ErgonomicsN/A

For Ergonomics 'Case Manager', in Configuration > Workstation Evaluation > Task Type > Ergonomic Evaluation, any configured and saved HR Attributes will now be retained.

 

CCC-12760ErgonomicsN/A

In the Ergonomics cloud, when applicable, all phrases for the 'Employee Summary' tab will now translate properly.

 

CCC-4928Industrial HygieneN/A

When configured to do so, if the user selects New > Portacount (Qualitative), the Qualitative layout will be used, and if the user selects New > Portacount (Quantitative), the Quantitative layout will be used.

 

CCC-13111Management of ChangeN/A

When a user creates a custom 'Management of Change' layout and sets a default value for the 'Change' field, that value will now appear in the corresponding field on the custom layout, as expected.

 

CCC-12576Management of Change N/A

A new or existing Safety 'Management of Change' record can now be submitted successfully without generating an unexpected error.

 

CCC-11911Management of ChangeN/A

For Management of Change, when configured properly, the workflow Reject button will now only display for designated Authorizers/Approvers.

 

CCC-13082Occupational Health – Medical ChartN/A

When the employee has the same Health Center but different Division/Country/Site as the user, and in the Medical Chart for the employee the user adds a new diagnosis / medical condition marked 'Problem list', that will now appear in both the 'Problem list" and 'Diagnosis / Medical Conditions' section, as expected.

 

CCC-3235Occupational Health – Medical DocumentsN/A

In the Occupational Health cloud, when a user creates and saves a new 'Medical Document' record, the breadcrumbs will now display the correct information and function as expected.

 

CCC-13455Occupational Health – Medical RecordsN/A

The Medical Records report now only provides data for the specified employee.

 

CCC-13511Occupational Health – PFTN/A

For the OH > PFT 'Transfer From Spirometer with Employee Data' action, when importing spirometer records duplicate records are no longer created.

 

CCC-13579Permit to WorkN/A

When creating a business rule (BR) from the Work Permit layout, the BR will now use the Work Permit entity instead of the Safety Permit entity.

 

CCC-10625Platform - AdministratorN/A

You can now successfully delete ten or more documents from a list view. This will no longer cause an unexpected error.

 

CCC-6003Platform - AdministratorN/A

You can now successfully update Master Tree nodes (activate, inactivate, and add descriptions) using import.

 

CCC-2740Platform - Administrator2021.1.0

You can now successfully clone or create custom views that have translations without encountering an unexpected 'Invalid String Length' error.

 

CCC-13475Platform – End-User2023.1.2

When the user creates a new Safety 'Finding & Action' using the 'Finding (w/ Risk) & Actions Multiple' layout and copies that 'Finding & Action', if the user then attempts to create a new Safety 'Finding & Action' using the same layout, the 'Assigned To' and 'Assigned To Group' fields will no longer be auto-populated with default values from the copied 'Finding & Action'.

 

CCC-12573Platform – End-UserN/A

A user who has the required security configuration can now successfully clone a Safety or Environmental 'Incident' list view with 'Enable Multiple Values' selected for one or more columns.

 

CCC-12066Platform – End-UserN/A

When a user is entering data and moving from one field to another, the cursor no longer moves on its own back to the previous field.

 

CCC-11820Platform – End-UserN/A

For 'Findings & Actions' and inspection questionnaire attachments, the organizational trees will now auto-update correctly when the organizational trees in the Assignee record get updated.

 

CCC-7474Platform – End-User2021.3.0

For Display Rules, an 'Equals Today' condition will now function as expected.

 

CCC-3584Platform – End-User, Event ReportingN/A

When configured properly in the 'User Icons' look-up table and associated with one or more Event Report Types, both PNG and SVG icons now function and display as expected.

 

CCC-13354Platform – InterfacesN/A

The RESTful API can now post more than one 'Document Control Approval History' record associated to a given 'Document Control' record.

 

CCC-12380Platform – InterfacesN/A

The timeout length for the employee merge process has been extended to help ensure success.

 

CCC-13032QuestionnairesN/A

In questionnaires, branching now functions as expected for 'Multiple Choice Checkbox' questions.

 

CCC-2968QuestionnairesN/A

For Yes/No questionnaire questions, both options (Yes/No) will no longer become selected.

 

CCC-10459Safety – Compliance ManagementN/A

When a layout is specified for the system setting 'Layout: Questionnaire Response Header Note Form' and the user creates a note on a Safety 'Compliance Action' or Environmental 'Compliance Obligation', the note will now open in the appropriate layout without generating an unexpected error.
