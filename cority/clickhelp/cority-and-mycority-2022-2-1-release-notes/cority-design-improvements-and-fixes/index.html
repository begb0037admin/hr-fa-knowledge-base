CCC-6083Occupational Health - Employee CareN/A

For users who want to connect to their Microsoft Outlook account through the Appointments module, GX2 now supports OAuth 2.0.

  • Note: At present, the user's Outlook appointments will only display in the Appointments calendar view when the 'Hide Complete Appt' toggle is off. That will be addressed in a future release.

To enable this functionality, there is a new global system setting named 'Enable OAuth 2.0 Authentication', which is categorized under the General module. The setting is a check box.

When selected:

  • OAuth 2.0 authentication will be enabled for the Appointments module.
  • OAuth 2.0 will be used to access MS Outlook (including Office 365) appointments.

When not selected, the default logic will be used to access MS Outlook appointments.

Also, the following, existing system settings have been renamed:

  • 'Inbox Email AAD Client Id' is now 'Exchange AAD Client Id'
  • 'Inbox Email AAD Client Secret' is now 'Exchange AAD Client Secret'
  • 'Inbox email AAD Tenant Id' is now 'Exchange AAD Tenant Id'

The changes will have no effect on functionality for clients who have configured those system setting prior to this release.

CCC-7100Platform – Interfaces N/A

For the Depisteo Q13 spirometer, the 'Spirometric Device Import Utility' now supports the Depisteo Spirowin Expert software's 'Ethnic Group' field. This is based on the 'Ethnic Group' picklist field value set for the employee on his or her GX2 Demographics record. Note: The Cority 'Ethnic Groups' look-up table must have the following values, the same values as the Depisteo Spirowin Expert software's 'Ethnic Group' field:

  • 0 - Caucasian
  • 1 - Hong Kong Chinese
  • 2 - American of Japanese Origin
  • 3 - Polynesian
  • 4 - Northern Indian/Pakistani
  • 5 - Southern Indian
  • 6 - African Origin
  • 7 - Mexican
  • 8 - South East Asian
  • 9 - North East Asian
  • 10 - Other

The numbers are the Cority Ethnic Group Code and the mapped values are the Spirowin Expert Ethic Group / Cority Ethnic Group Description.

CCC-5360Waste ManagementN/A

The default Inspection and Audit layouts now have a new Vendor field, which is a picklist to the Vendors look-up table. This enables you to link an inspection or audit and its corrective actions to a specific vendor, to run reports on upcoming and expired inspections/audits for specific vendor disposal sites, and to deactivate the vendor from a site when the site's inspection has not been completed on time.
