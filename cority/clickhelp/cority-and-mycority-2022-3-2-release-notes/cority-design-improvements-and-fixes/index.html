Cority Design Improvements and Fixes

The table below lists the design improvements and fixes we have made in the Cority 2022.3.2 release. The items are organized by component and the components are arranged in alphabetical order.

Item # Component(s) Reported Description
CCC-10687 Business Intelligence N/A

When graphing the Value field for one or more Custom Metrics entries and using the Date field for the X-axis, the data now displays properly on the resulting visualization(s).

 

CCC-10121 Business Intelligence N/A

When the Report Writer Utility is scheduled using Report Scheduler to run a report that has a lot of records (90000+), this will now function properly and generate the correct data.

 

CCC-4665 Business Intelligence N/A

In the Data Cube, when the same month is selected for different fiscal years, the chart will now display the expected axes, axes labels, and correct data.

 

CCC-10822 Ergonomics, Training N/A

In the Ergonomics cloud, SCORM tokens mapped to a Self-Assessment no longer display as unmapped.

 

CCC-10618 Industrial Hygiene N/A

For importing Survey and/or Monitoring Plan layout configurations, the Administrator > Layout module's 'Import Layout Configuration' action now functions properly and without generating any unexpected errors.

 

CCC-10490 Industrial Hygiene, Respiratory Fit N/A

A user who has the appropriate role security configured will now be able to access the IH Respiratory Fit module without encountering any issues.

 

CCC-9880 Industrial Hygiene, Reports N/A

In the Reports module, the 'Individual Samples Noise Results Notification Letter' report now includes any applicable merged data.

 

CCC-7957 Industrial Hygiene, Risk Assessment N/A

On an IH risk assessment, after running statistical analysis on a task, the Statistics tab will now function without generating an unexpected error.

 

CCC-5226 Industrial Hygiene, Risk Assessment N/A

When the agent is changed on a risk assessment, if applicable, the severity value will now be updated.

 

CCC-4904 Industrial Hygiene, Letters N/A

In the Letters module, the Source ID link now functions as expected without generating any unexpected errors.

 

CCC-10259 Management of Change N/A

Business rule change actions (BRAs) that allow you to populate a field based on the result of a query now support 'Management of Change' queries. That is, configured 'Management of Change' queries are now available in the list of subquery options for such BRAs.

 

CCC-11188 Occupational Health, ESR Interface N/A

When applicable with the ESR interface, for employee merge the employee ID now gets updated in the ESR database.

 

CCC-10656 Occupational Health, Appointments N/A

In the Appointments module, the recurrence functionality now works as expected.

 

CCC-5389 Occupational Health, Clinic Visit N/A

For any applicable biometric values, the Framington Risk Score will now be calculated correctly.

 

CCC-11144, 11142, 11112, 11110, and 7789 Platform – Administrator N/A

A number of potential security vulnerabilities have been addressed. This will help thwart any malicious attackers.

 

CCC-11111 Platform – Administrator N/A

ASP.net in the API server has been upgraded to version 4.7.2.

 

CCC-10965 Platform – Administrator N/A

The Lodash JavaScript library has been upgraded to version 4.17.21.

 

CCC-9905 Platform – Administrator N/A

In AWS-hosted environments, the Swagger API documentation now loads without error.

 

CCC-10455 Platform – End User N/A

On the right pane of a split-screen layout, the user can now expand and collapse applicable sublists without encountering any issues.

 

CCC-9110 Platform – End User, Documents N/A

On a Documents list view, for a link to a document the URL will now function as expected.

 

CCC-8770 Platform – End User N/A

On a split-screen layout, when applicable, scrolling on any smart search box now functions as expected.

 

CCC-10805 Questionnaires 2022.3.1

In the Questionnaires look-up table, the 'Import Questionnaire Configurations' action now functions properly without generating any unexpected errors.

 

CCC-10961 Risk Assessment, Safety / Environmental N/A

The following breadcrumb phrases now appear in the Phrase Translations module and are translatable:

  • COSHH Risk Assessment Master (Safety > COSHH Assessments)
  • COSHH Risk Assessment Entry (Safety > COSHH Assessments > Task/Hazard/Controls section)
  • Environment RAS Job List (Environment > Environmental Activities)

 

CCC-10704 Quality, Non-conformances N/A

For the Why Tree in the Quality 'Nonconformance' module, the pencil and + icons are now available.

 

CCC-4754 Safety Incidents, Reports N/A

An 'Incident-Worksafe Submission Summary - Weekly' report with extra/altered criteria that is scheduled using Report Scheduler will now generate the correct data.
