Cority Design Improvements and Fixes

The table below lists the design improvements and fixes we have made in the Cority 2022.3.1 release. The items are organized by component and the components are arranged in alphabetical order.

Item #Component(s)ReportedDescription
CCC-3035Business RulesN/A

When creating and saving a business rule with a business rule action that's Source field value has more characters than its target field, the resulting error will now indicate the issue.

 

CCC-9273Case Management, Injury/IllnessN/A

On 'Case' and 'Injury/Illness' layouts, Incident UDFs now respect the values of their filter check boxes.

 

CCC-6305Employee Merge, IncidentN/A

For an employee with an 'Incident Self Report' record that has the 'Driver/Employee Involved' field populated, the Employee Merge functionality will now work as expected without generating any unexpected errors.

 

CCC-9349Environmental – Chemical ManagementN/A

For Environmental 'Chemical Management', the 'Public Chemical Products' list view now provides the 'Print Standard Labels' action. Also, the 'Save as' button has been removed from the 'Chemical Product Labels' layout.

 

CCC-10507Environmental ComplianceN/A

For Environmental Compliance, in the Requirements look-up table, the character limit of the following fields has been extended to 30000:

  • Description
  • UDFText1
  • UDFText2
  • UDFText3

 

CCC-10375Environmental – Risk RegistryN/A

When a 'Finding & Action' is created in Environmental 'Risk Registry', it is now added to the Actions entity, therefore can be selected and used in Query Builder and/or Report Writer queries.

 

CCC-10365Environmental – Risk RegistryN/A

In Environmental 'Risk Registry', after creating a Finding & Action record, the Source and Source ID links on the record now function as expected.

 

CCC-9628Environmental – Emissions InventoryN/A

When calculating emissions, secondary calculation results are no longer incorrectly multiplied. They are now accurate.

 

CCC-6020Environmental – Emissions Inventory2021.3.0

In Emissions Inventory, when the user creates a new Document record, the Source ID for the new record now populates correctly.

 

CCC-10227Ergonomics, TrainingN/A

For training, on the 'Online Sessions' list view, when the 'Course Status' for a course gets updated, if applicable, the 'Completion Status' will now update automatically.

 

CCC-9142Event ReportingN/A

On 'Event Report' layouts, Incident UDFs now respect the values of their filter check boxes.

 

CCC-8346Industrial Hygiene, Risk AssessmentN/A

There is a new business rule method named 'Risk Assessment Entry Product Has Ingredients Allow Duplicates'.

When this new method is used with the existing BR-01016 business rule, a user can create a Task-Hazard-Control record with ingredient on a Risk Assessment record and then create other Task-Hazard-Control records with duplicate ingredient on the Risk Assessment record.

If you want to use this new method, clone the existing BR-01016 business rule, rename the clone, on the clone replace its method with the new method, and then inactivate the Cority-created BR-01016.

 

CCC-8270Industrial HygieneN/A

On a Job Inventory 'Risk Assessment' record, a SEG without duplicate already linked can now be linked to the record without generating an unexpected error regarding a duplicate.

 

CCC-8923 and 9049Management of ChangeN/A

Management of Change approvers can now be assigned and complete workflow actions and parallel approval actions. This applies to the Quality, Safety, Environmental, and Business Intelligence 'Management of Change' entities.

Management of Change approvers are active approvers in the LU_GLB_Approver look-up table, including those created using UDFs.

Note: Approvers are assigned automatically based on the GDDLOFB of the 'Management of Change' record.

For more information on the Management of Change module, see the GX2 User Guide.

 

CCC-10463Platform – Administrator N/A

For a picklist field, when the look-up options are configured to be radio buttons and the user selects a value then saves the record, cross-site scripting attacks are no longer possible, therefore an unexpected error is no longer generated.

 

CCC-9751Platform – Administrator N/A

On a layout that has a Flex Fields tab, when a new record is saved, the questionnaire configuration and questions are now drawn from the look-up table instead of from a placeholder questionnaire. This will ensure the data is always correct.

 

CCC-9423Platform – AdministratorN/A

Users of GX2 and WeSustain can now use a single set of credentials (SSO) to log into both.

To support this, in GX2 there is:

  • A new module enabled by default named 'Sustainability Solutions' on the 'Menu Configuration' screen and in 'My Favorites'
  • A 'WeSustainUrl' destination URL property in the GX2 site configuration file that requires format https://<wesustaindestinationurl?>
    accountid=<customer_account_id
  • A new 'WeSustain Login Name' field, with a limit of 255 characters, on the 'User' layout.

Note: The WeSustain public key is stored as /config/wesustain.txt on the GX2 server, and the GX2 server has the standard Cority private key, if populated in the 'SSO SAML 2.0 Private Key' system setting.

 

CCC-5207Platform – Administrator 2021.2.1

If applicable (configured properly), when exporting a look-up table list view, the values from the list will now be translated in the export, as expected.

 

CCC-2922Platform – Administrator N/A

When the user adds to a subsection on a custom layout an advanced condition that has a string surrounded by double-quotation marks, the layout will now function as expected without generating any unexpected errors.

 

CCC-10291Platform – End User2022.3.0

When the user clones a layout that has a Flex Fields subsection, on the new layout the subsection will now appear toward the bottom of the main form but above any sublists.

 

CCC-10471Platform – End UserN/A

Where applicable, the text editor now provides Undo, Redo, and Horizontal Line buttons.

 

CCC-7987Platform – End User2021.3.0

A user can now change his or her profile picture without encountering any unexpected errors. That functionality now works as expected.

 

CCC-7945Platform – End UserN/A

When the value for a field on a record is a look-up table option that contains a special character (an apostrophe, for example), that value will now appear correctly in Microsoft Excel exports.

 

CCC-10464Platform – InfrastructureN/A

To prevent attackers from directly targeting unauthorized resources, for generating web pages, per-user or session indirect object references are now exclusively used.

 

CCC-9742Platform – Infrastructure N/A

The SMTP log level has been adjusted so that only meaningful errors are shown in the TDBR logger.

 

CCC-7829Quality N/A

If the user creates a business rule using the 'Quality Incident Self Report' entity, that business rule will now be available for linking to a new Action created within the 'Quality Incident Self Report'.

 

CCC-10079SchedulingN/A

If the user makes a 'Schedule Entry' or 'Schedule Available Entry' RESTful API endpoint call, any applicable appointment IDs will now be returned in the response body.

 

CCC-10571TrainingN/A

For online training sessions, batch jobs now function properly.

 

CCC-102530Workflow ManagementN/A

When an approver within a workflow clicks the Approve or Reject button and is required to add comments, if he/she then clicks Cancel, that will now cancel the approve or reject actions and no longer generate an unexpected error.

 

CCC-8829Workflow ManagementN/A

Users can now inactivate parallel workflow actions.

 

CCC-7193Workflow Management2021.3.2

Within a workflow step, for an action that requires comments and/or an eSignature, that functionality now works as expected.

 

CCC-5810Workflow Management2021.2.0

In either a 'Management of Change' or 'Incident' workflow, when parallel workflow actions each have more than one approver and an individual approver and/or group approver is assigned to each action, that functionality now works as expected.
