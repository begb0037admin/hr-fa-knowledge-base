myCority Design Improvements and Fixes

The table below lists the design improvements and fixes we have made in the myCority 2022.3.1 release. The items are organized by component and the components are arranged in alphabetical order.

Item #Component(s)ReportedDescription
CCC-9794Appointments, SchedulingN/A

For My Tasks > Appointments, the word 'Attend' can now be translated and translated 'Scheduled Activity' look-up table values now appear as translated when and where applicable.

 

CCC-8998Appointments, Scheduling N/A

A scheduling user who is not registered under a certain health center can no longer be booked into appointments for that health center. Also, a scheduling user who is not available for portal scheduling can no longer be booked for appointments using myCority.

 

CCC-10174 and 10546PlatformN/A

If applicable (configured properly), in myCority, look-up table values on sublists and layouts that should be translated into the user's preferred language will now be translated as such.

 

CCC-9524Platform, My AccountN/A

When editing text field values for 'My Account' settings, you no longer have to click Save twice.

 

CCC-9064PlatformN/A

A user can now complete, save, and submit an audit questionnaire that has 2100+ parameters without encountering an unexpected error.

 

CCC-8112PlatformN/A

When applicable, employee data on list views in GX2 will now display on the same list views in myCority.

 

CCC-1466Platform, Event ReportingN/A

For an event reporter using myCority, when the system setting 'Enable Filtering of Incident Investigators Based on the Job Position of the Employee Involved' is selected, job positions will now filter to only those that apply to the reporter.

This feature requires that:

  • The applicable 'Populate Safety (or Environmental) Inv Supervisor / Manager / Gen Mgr' check box(es) are selected.
    • For these selections, the supervisor and trees will extract from the 'Job Position' sublist, not from the primary Demographics record.

Note: This functionality does not work in offline mode because communication with the database is required.
