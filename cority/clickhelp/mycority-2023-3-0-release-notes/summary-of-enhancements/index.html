Summary of Enhancements

The table below describes the enhancements we have made in 2023.3.0.

Item #Component(s)Description
CCC-10390Appointments – Accessibility

When creating a new appointment, after selecting an activity, and the date automatically populates with the first date in availability, new keyboard navigation is now provided:

  • Alt + Down Arrow – will open the date-selector to the current date
    • Arrow keys – will move forward through the dates
      • Down Arrow – will change focus to the same day of the following week
      • Right and Left Arrows – will move one day forward / one day back, respectively, through the dates
      • Page Down – will move to the next month
        • Up Arrow – once further along, will move to the same day of the prior week, if not in the past
        • Left Arrow – will move to the prior day, if not in the past
        • Page Up – will move to the prior month, if not in the past
    • ENTER – when on an acceptable date, will return to the Date field and populate it
  • Next tab – will move to the first time available on the date
    • Arrow keys – will move between the different times, which will be read out by voice reader

 

CCC-11157Case Management

When the user clicks ‘Go to Record’ for a message notification that was pushed from GX2 to myCority, the 'Case' record linked to the message will now open, instead of the message itself.

Also, on the myCority 'Case' layout (ML-003175), the 'Messages' tab is now a section on the main form. This enables users to see the case details, discern the context, and view the messages all on the same screen. If you have created your own myCority 'Case' layout, we recommend you modify that layout by adding the 'Messages' tab to its main form.

 

CCC-9992Display Rules

The Display Rules functionality is now supported by myCority. Display Rules enable system administrators to create a more intuitive, streamlined, and user-friendly experience—enhancing efficiency, reducing errors, and ensuring that users are always presented with the information they need. These rules can be applied in a number of scenarios, from defining conditions for fields to be required or made read-only at specific steps in a workflow to selecting specific layouts based on certain field values.

 

CCC-13309Environmental – Chemical Management

The performance of the Chemicals list view has been improved.

 

 Incident Investigation

On the My Tasks list, for Incident Investigations, the summary information has been changed to be more helpful and make investigations easier to locate.

 

CCC-12903Findings & Actions

When the ‘Add Action To Finding’ option is available on the ‘Findings and Actions’ layout, after clicking the option, it will now be disabled until the record is saved again.

 

CCC-13899, 13217, and 8863Inspections, Surveys, Observations – Questionnaires, Findings & Actions

For Inspection, Survey, Observation questionnaires, when applicable, the user can now create Actions from all question types (that is, the ‘Add Action’ button is available for all question types).

In support of this, the following two fields can now be added to custom versions of Questionnaire layouts:

  • Select Finding Type – a picklist to the Finding Types look-up table, for which only one value can be selected
  • Copy Comments to Finding – a checkbox that is only active if the ‘Select Finding Type’ field is populated

 

CCC-11157Occupational Health – Case Management

The myCority Case layout (ML-003175) now has a 'Messages' section (sublist).

When the user clicks ‘Go to Record’ for a message notification that was pushed from GX2 to myCority, the Case record linked to the message will now open, instead of the message itself.

 

CCC-8419Occupational Health – Employment Plus

To support the OH pre-employment process, the translation drop-down list has been added to the myCority 'Applicant Registration Portal' screen. 

If the user selects a language from the list, the phrases on the screen will be translated into that language.

 

CCC-12458Occupational Health – Questionnaires

In GX2, for a questionnaire, when either 'Assigned to <Employee>' or 'Assigned to <Team>' is populated from an OH solution, the questionnaire will now be made available for the applicable user(s) in myCority. Any existing role and site security will apply.

 

CCC-11723Organizational Tree – Accessibility

For the Organizational Tree, additional keyboard navigation is now provided to allow selection while typing the name of the record in smart search:

  • ALT + Down Arrow – will place focus on the suggestions for the tree (when typing) or tree-selector in the drop-down list
  • TAB key – will traverse down through the tree values
  • SHIFT + TAB – will traverse up through the tree values
  • ALT + Up Arrow – will re-focus on the input field for the tree (if, for example, you want to modify the text to narrow the search or correct a typo)
  • ENTER – when the emphasis is on a tree node symbol, will toggle between expanding and collapsing a node (for example, for hierarchical trees)
  • ENTER – when emphasis is on an entity name, will select that value

Note: When one or more of the system setting(s) ‘Restrict leaf member selection on <X> tree picker’ are selected, then emphasis will not be given to the entity name on levels that are not the lowest (for example, if the entity has children), therefore they cannot be selected.

After selecting a tree value, TAB will take you to next field.

 

CCC-13136Platform – End-User

The load performance of the Home and My Tasks pages has been improved.

 

CCC-11459Platform – End-User

With accessibility functionality, server error and hard-enforce business rule messages are read aloud and the Esc key now dismisses the message from the screen. The user no longer has to tab around the screen to dismiss the message.

 

CCC-11175 and 14090Questionnaires

For saving and submitting questionnaires with a number of attachments, the performance has been improved.
Also, there is a new ‘Compression of photos % quality maintained’ system setting that if deselected will reduce photo size, but degrade the image somewhat to accomplish that.
Note: PNG files will compress; however they will reduce by a small percentage only.
