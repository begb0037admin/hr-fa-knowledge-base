Fix Descriptions

The table below describes the fixes we have made for 2023.3.0.

Item #Component(s)Reported VersionDescription
CCC-13588AppointmentsN/A

While creating a new appointment with typical parameters specified, when the date-selector is open and the user clicks outside of it, the date-selector will now close.

 

CCC-6951Occupational Health – Case Management / Safety – Audits & InspectionsN/A

When properly configured, 'Finding & Actions' will now be created automatically for numerical range questions from a Questionnaire response submitted through either GX2 or myCority.

 

CCC-13492Platform – End-UserN/A

On a mobile device (an iPhone, for example), when clicking within a time field, the time-selector will now open automatically. The user can select the hour and minutes, along with AM/PM, and click Accept, or use the red NOW to enter the current time. From mobile devices, the user will no longer be able to enter the time on the keypad manually. This will stabilize the page.

 

Desktop users can still use either the keyboard or time-selector for time fields.

 

CCC-12920Platform – End-UserN/A

When offline use is enabled and the user clicks 'Continue' to download form templates for offline use, the templates will now download successfully.

 

CCC-14247Platform – Infrastructure N/A

If you have correctly created a business rule on Medicalpublicqrh to auto-post a medical questionnaire from Inbox to the Questionnaire module, a business rule on MedicalQuestionnaireResponseHeader to update the Score classification field with the Cleared value when the score is 0, and a business rule on MedicalQuestionnaireResponseHeader to notify employees who are cleared, these will now all function as expected.

 

CCC-14284QuestionnairesN/A

After adding a file for a required 'attach file' field on a questionnaire and saving the questionnaire, the Download icon will now be displayed and available.

 

CCC-10007Questionnaires2022.1.2

In 'My Tasks', a supervisor (manager) viewing questionnaires filtered for a direct report and an employee viewing his or her questionnaires will now see the same thing.

 

CCC-14182Safety – Event Reporting2023.2.1

For a Safety 'Event Report' questionnaire that has branching questions, regardless of the branching question types and combination of questions, when the user populates the required values, the questionnaire can now be saved without issue.
