Creating/Updating Environment files

Request: POST {baseUrl}/EnvironmentInput/

Note: Setting the fileID differs when creating versus updating. When creating a new file, set the fileID as 0 in your request. When updating an existing file, set the correct fileID. This allows the API to know which file you want to update.

How to edit/create/delete the individual rows of the file

The individual rows within the files are created, updated, or deleted using the RowNumber (1,2,3,4,etc) and Operation ("Create", "Update", "Delete") properties.

  • Creating a new row - The RowNumber should be set to 0 and the Operation set as "Create"
  • Updating a row - The RowNumber should be set to the RowNumber you wish to update and the Operation set as "Update"
  • Deleting a row - The RowNumber should be set to the RowNumber you wish to delete and the Operation set as "Delete"

Example of Delete row number 2:

"RowData": [
  {
    "Operation": "DELETE",
    "RowNumber": 2
  }
]
