Troubleshooting

If you are having trouble with authenticating, do the following:

  • Double check your username and password.
  • Check your tenantName is correct. This should match your URL you use to log on to SPM.
    • For example, if you use https://secure1.greenstoneplus.com/ExampleCustomer1 to access SPM, then the tenantName will be ExampleCustomer1

If you are still having trouble, please contact support.
