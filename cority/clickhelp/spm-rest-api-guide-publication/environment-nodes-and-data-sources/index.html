Environment Nodes and Data Sources

Getting Nodes

  • Request: POST {BaseUrl}/nodes
  • Example Body (with optional filters)
{
  "responseType": "Lightweight",  // Request type
  "pagination": {
    "page": 1,                     // Current page
    "pageSize": 20,                // Number of results per page
    "sortBy": "nodeName",          // Field to sort by
    "sortOrder": "desc",           // Sort order: "asc" or "desc"
    "filters": [
      {
        "name": "nodeId",          // Filter by node ID
        "filterType": "equals",    // Exact match
        "value": 4                 // Example node ID
      },
      {
        "name": "nodeName",        // Filter by node name
        "filterType": "contains",  // Partial match
        "value": "green"           // Example text
      },
      {
        "name": "startDate",       // Filter by start date
        "filterType": "equals",    // Exact date match
        "value": "2020-01-01"      // Example date (YYYY-MM-DD)
      },
      {
        "name": "startDate",       // Filter by start date range
        "filterType": "range",     // Range filter
        "value": "2009-01-01",     // Start of range
        "value1": "2011-01-01"     // End of range
      }
    ]
  }
}

The responseType can be used in this nodes endpoint, to get a lightweight or full node object back.

  • Request: POST {BaseUrl}/nodes
{
  "responseType": "Full",  // Request type
  "pagination": {
    "page": 1,                     // Current page
    "pageSize": 20,                // Number of results per page
    "sortBy": "nodeName",          // Field to sort by
    "sortOrder": "desc",           // Sort order: "asc" or "desc"
    "filters": []
  }
}

Getting Datasources

  • Request: POST {BaseUrl}/datasources
{
  "responseType": "Lightweight",          // Type of response
  "pagination": {
    "page": 1,                             // Current page
    "pageSize": 5,                         // Number of results per page
    "sortBy": "DatasourceId",              // Field to sort by (can also use DatasourceName)
    "sortOrder": "desc",                   // Sort order: "asc" or "desc"
    "filters": [
      {
        "name": "country",                // Filter by country
        "filterType": "equals",           // Exact match
        "value": "spain"                  // Example country value
      }
    ]
  }
}
