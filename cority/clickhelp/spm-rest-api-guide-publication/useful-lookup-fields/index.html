Useful Lookup Fields

To get the most out of the API, you will need to know the identifiers of some lookup values.

Observation Categories

Request: GET {baseUrl}/EnvironmentInput/Lookups/observation-categories

Needed for notes and attachments: category.

Estimation Categories

Request: GET {baseUrl}/EnvironmentInput/Lookups/estimation-categories

Needed for environment files: estimationCategory.

Custom Fields

Request: GET {baseUrl}/EnvironmentInput/Lookups/custom-fields/{ActivityTypeId}

Needed for environment files: CustomFields.

See Supported Activity Types for the ActivityTypeId.
