Finding Environment Files

Find existing environment files

  • Request: POST {baseUrl}/EnvironmentInput/files
  • Body example:
{
  "viewId": 2,
  "nodeId": 12,
  "includeHierarchy": true,
  "pagination": {
    "page": 1,
    "pageSize": 10,
    "sortBy": "DateFrom",
    "sortOrder": "Desc"
  }
}
  • Response example:
{
  "isSuccess": true,
  "message": "File records successfully returned.",
  "validationErrors": [],
  "data": {
    "data": [
      {
        "fileId": 5722,
        "nodeId": 10,

Getting the file data

You will need to know the fileId and the activityType.

  • Request: POST {baseUrl}/EnvironmentInput/get
  • Body example:
{
  "fileid": 5722,
  "activitytype": "ElectricityGrid",
  "Pagination": {
    "page": 1,
    "pageSize": 10,
    "sortBy": "rowNumber",
    "sortOrder": "Asc"
  }
}
