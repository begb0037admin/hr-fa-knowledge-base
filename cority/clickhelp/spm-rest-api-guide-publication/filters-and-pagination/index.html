Filters and Pagination

When you are retrieving data, filtering and pagination can be applied.

Pagination

Example: Get the first page, and limit it to 10 results per page, sorted by DateFrom descending. 

{
  "pagination": {
    "page": 1,
    "pageSize": 10,
    "sortBy": "DateFrom",
    "sortOrder": "Desc"
  }
}

Filtering

You can also specify filters in the body. You can specify the name of the field to filter on, how to filter (the operator), and the value to filter on.

Below is an example request (for data sources), with the structure of the filters shown.

This example is filtering for where the nodeName contains the word green, and has a start date between 2009-01-01 and 2011-01-01 

{
  "responseType": "Lightweight",  // Request type
  "pagination": {
    "page": 1,                     // Current page
    "pageSize": 20,                // Number of results per page
    "sortBy": "nodeName",          // Field to sort by
    "sortOrder": "desc",           // Sort order: "asc" or "desc"
    "filters": [
      {
        "name": "nodeName",        // Filter by node name
        "filterType": "contains",  // Partial match
        "value": "green"           // Example text
      },
      {
        "name": "startDate",       // Filter by start date range
        "filterType": "range",     // Range filter
        "value": "2009-01-01",     // Start of range
        "value1": "2011-01-01"     // End of range
      }
    ]
  }
}

The following filter types are compatible:

  • Equals
  • NotEquals
  • StartsWith
  • LessThan
  • LessThanOrEqual
  • GreaterThan
  • Range
  • Contains
