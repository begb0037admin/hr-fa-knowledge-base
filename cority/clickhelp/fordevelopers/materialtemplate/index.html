enviancesdk.materialTemplates.materialTemplateInfo

Description

Represents a Material Activity Template definition.

Properties

id The id string (GUID) for the Material Activity Template.
Ignored for:  Create Material Activity Template, Update Material Activity Template

name The name of the Material Activity Template.
Required for: Create Material Activity Template

description The description of the Material Activity Template.

fields Array. An array of group id strings (GUIDs) and/or UDF field names associated with the Material Template. The order in which the fields are specified in this array will be the order in which they are used in the template.
Required for:  Create Material Activity Template

Example

envianceSdk.materialTemplates.MaterialTemplateInfo (name, description, fields)

 

{

"name": "Material Template Name",

"description": " Material Template Description",

"fields": ["udf field name 1", "udf field name 2", "7ef9655e-916b-414f-8c88-5753fa731558"]

}
