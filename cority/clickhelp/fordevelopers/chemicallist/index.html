enviancesdk.chemicallists.createChemicalList

Version 2.0

Other Versions:

None

Description

Creates a new Chemical List.

Parameters

chemicalListInfo An instance of the chemicalListInfo object. Some properties of this object are ignored by this function; see details of this object for more info.

Return Value

The id for the new Chemical List.

Example

envianceSdk.chemicallists.createChemicalList (chemicalListInfo, onsuccess, onerror)

enviancesdk.chemicallists.copyChemicalList

Version 2.0

Other Versions:

None

Description

Creates a new Chemical List by copying an existing Chemical List.

Parameters

chemicalListInfo An instance of the chemicalListInfo object. Optional information to set the properties of the new Chemical List.

copyFrom The id string (GUID) of an existing Chemical List whose properties will be copied and used as the properties of the newly created Chemical List.

Return Value

The id for the new Chemical List.

Example

envianceSdk.chemicallists.copyChemicalList (chemicalListInfo, copyFrom, onsuccess, onerror)

enviancesdk.chemicallists.updateChemicalList

Version 2.0

Other Versions:

None

Description

Updates a Chemical List.

Parameters

chemicalListIdOrName Either an id string (GUID) or a name uniquely identifying the Chemical List. Any string that matches the pattern of a GUID is interpreted as an id string, and not a name.

chemicalListInfo An instance of the chemicalListInfo object. Some properties of this object are ignored by this function; see details of this object for more info.

Return Value

None

Example

envianceSdk.chemicallists.updateChemicalList (chemicalListIdOrName, chemicalListInfo, onsuccess, onerror)

envianceSdk.chemicallists.chemicalListInfo

Description

Represents a Chemical List definition.

Properties

id The id string (GUID) for the Chemical List.
Ignored for: Create Chemical List, Update Chemical List

name The name of the Chemical List.
Required for: Create Chemical List

description The description of the Chemical List.

chemicalListHistoryItem An array of chemicalHistoryItemInfo structures specifying records which should be part of the Chemical List Limits history.
Required for: Create Chemical List

Example

envianceSdk.chemicallists.ChemicalListInfo (name, description, chemicalListHistoryItems)

 

{

"id": "080AD86D-1FEF-4D77-A528-C8E03594751F",

"name": "Chemical List Name",

"description": "Chemical List Description",

"chemicalListHistoryItems": [

{"beginDate": "2012-01-01T20:00:00",

"limits": [

{"chemicalIdOrAlias": "ChAlias1",

"limit": "1"},

{"chemicalIdOrAlias": "5376DF01-45B5-4153-ACCF-8E208DB69979",

"limit": "2"}]

}]

}

envianceSdk.chemicallists.chemicalHistoryItemInfo

Description

Represents a Chemical History Item definition.

Properties

beginDate Date. A date and time value. Begin date of history item.

limits Array. An array of chemicalHistoryItemLimit.

Example

envianceSdk.chemicallists.ChemicalHistoryItemInfo (beginDate, limits)

 

 

{

"beginDate": "2012-01-01T20:00:00",

"limits": [

{"chemicalIdOrAlias": "FF710D9F-4367-4C0C-A5CB-497CB18FA842",

"limit": "1.1"},

{"chemicalIdOrAlias": "5376DF01-45B5-4153-ACCF-8E208DB69979",

"limit": "2"}]

}

envianceSdk.chemicallists.chemicalHistoryLimitInfo

Description

Represents a Chemical List History Item definition

Properties

chemicalIdOrAlias Either an id string (GUID), or the alias for the Chemical. Any string that matches the pattern of a GUID is interpreted as the id string, and not the alias of the Chemical. An alias string must be URL encoded.

limits Number. A floating point numeric value. Limit data of Chemical history item.

Example

{

"chemicalIdOrAlias": "FF710D9F-4367-4C0C-A5CB-497CB18FA842",

"limit": "1.1"}

}
