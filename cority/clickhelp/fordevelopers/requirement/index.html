envianceSdk.requirements.createRequirement

envianceSdk.requirements.createRequirementAsync

Version 2.0

Other Versions:

None

Description

Create new requirement.

Parameters

reqInfo Array An array of reqInfo.

Return Value

None

Notes

Requirements are created asynchronously in the Management System. Use the Async version to continue process without waiting for reponse. You can use the returned command id with the getCommand function to check on the status of the command. With the non-Async version, it may take up to 30 seconds for the command to be processed successfully.

Example

envianceSdk.requirements.createRequirement(

{

"name": "Requirement Name",

"requirementType": "RequirementType",

"activeDate": "2010-02-22T00:00:00",

"requirementTemplateIdOrName": "Requirement Template 1",

"responsibleUserIdOrName": "BTaylor",

"parentPath": "Division\Facility",

"frequencies": [

{ "beginDate": "2011-02-22T00:00:00", "endDate": "2012-03-22T00:00:00", "occurences": 1 },

{ "beginDate": "2014-02-22T00:00:00", "endDate": "2014-03-22T00:00:00", "occurences": 2 }

],

"limitHistory": [

{ "beginDate": "2011-02-22T00:00:00", "endDate": "2012-03-22T00:00:00", "comparisonOperation": "> LOW", "regLowLimit": 1, "regHighLimit": 4 }

],

"regulatoryLimit": {

"templateIdOrName": "task-template-m-1",

},

}

None

Description

Deletes Requirement.

Parameters

requirementIdOrPath String Either an id string (GUID) or path of requirement. Any string that matches the pattern of a GUID is interpreted as an id string, and not a name.

Return Value

None

Notes

Requirements are deleted asynchronously in the Management System. Use the Async version to continue process without waiting for reponse. You can use the returned command id with the getCommand function to check on the status of the command. Deletions are permanent.

Example

envianceSdk.requirements.deleteRequirement(

{

"bac982d2-0a2f-48ae-ba27-a38a3749cc6a"

});

dataColFrequency Number. Collection frequency number of periods.

precision Number. Number of decimal places to display.

limitHistory An Array of Limit History Data.

internalLimit A Limit Task Data.

notifyRecipients A Notify Recipients Data.

documents An Array of Document paths, specifying zero or more Documents which are or should be attached to the object.
