FormTemplate

Name Form Template Name

Description Form Template Description

Created Date created

VersionComments Form Template Version Created Comments

IsCurrentVersion Indicates if form template record is the most recent version.

CustomField.ID, CustomField.Name, ... Composite column to CustomField table (includes all fields from CustomField)

CustomField.ListItemUserAdded User Added text value into Numeric/Text Custom Field with Entry Method DropDownList with TextBox

CustomField.Validation.EnforceTextPatternOnSave Enforce a Text Pattern when saving (Boolean)

CustomField.Validation.EnforceTextPatternOnTransition Enforce a Text Pattern when transitioning (Boolean)

CustomField.Validation.EnforceValueRangeOnSave Enforce a Value Range when saving (Boolean)

CustomField.Validation.EnforceValueRangeOnTransition Enforce a Value Range when transitioning (Boolean)

Example: Get form template with custom fields.

select

ft.Name,

ft.CustomField.Name

from FormTemplate ft

Example: Get list of values to use in workflow step on custom field with Entry Method DropDownList with TextBox, filtered by Current Form Template Version and Form Template “IncidentTemplate”.

select

ft.Id,

ft.Name,

ft.CustomField.ListItemUserAdded

from FormTemplate ft

where ft.IsCurrentVersion = 'true'

and ft.Name = 'IncidentTemplate'

Example: Get name of workflow step with its associated form template and custom fields.

select

wts.Name,

wts.FormTemplate.name,

wts.FormTemplate.CustomField.Name

from WorkflowTypeVersionStep wts

See WorkflowTypeVersionStep.

Permissions:  Manage Workflows right is required to query this table. Manage Custom Fields right is required to query CustomField composite fields.
