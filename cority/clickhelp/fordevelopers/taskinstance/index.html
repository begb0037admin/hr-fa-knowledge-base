Permissions:  Requires View permission on the target object.

A date range must be specified for column DueDateTime. Two examples:

where DueDateTime BETWEEN 'Date' AND 'Date'

where DueDateTime >'Date' AND DueDateTime <'Date'

Example: Get task instances with due dates between 01/01/2018 and 02/01/2018.

select

t.Name,

ti.DueDateTime,

t.TimeZone.Name

from Task t

join TaskInstance ti on t

where ti.DueDateTime between '01/01/2018' and '02/01/2018'

Example: Get task and associated workflow instances for specified date range

select

t.ID as TaskID,

t.Name As TaskName,

ti.DueDateTime As TaskInstanceDueDate,

t.VersionID As TaskVersionID,

co.Name As ObjectName,

wi.Name As WFName,

wi.ID

from Task t

join TaskInstance ti on t

join ComplianceObject co on co.ID = ti.ObjectID

join WorkflowInstance wi on wi.Task.InstanceDueDateTime = ti.DueDateTime

where t.Object.Path Like '%parent object path%'

and ti.DueDateTime >= '2017-01-30' and ti.DueDateTime <= '2020-12-31'

and ti.DueDateTime = wi.Task.InstanceDueDateTime

and ti.TaskVersionID = wi.Task.VersionID

order by ti.DueDateTime

When querying for Task Instances, you may want to include a filter for .isCurrent='true' which will return only tasks using the current task version. However, if the task has been edited during the time period being queried, tasks created with older versions will not be returned. See Notes on task versioning for the Task table.
