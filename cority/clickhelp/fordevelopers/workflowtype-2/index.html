Security: Allowed for Users with Manage Workflows right or User in Workflow Managers role of WF, or User with Manage Workflows on any objects associated with the workflow.

SDK API: envianceSdk.workflows.getWorkflowType (typeIdOrName, onsuccess, onerror)

Parameters
Name Located in Description Required Schema
typeIdOrName path Either an id string (GUID) or a name uniquely identifying the Workflow Type. Any string that matches the pattern of a GUID is interpreted as the id string and not the name of the Workflow Type. A name must be URL encoded. Yes string
