/chemicalGroups

POST

Description:

Creates a new Chemical Group, alternately by copying an existing Chemical Group.

Security: Requires Manage Materials and Activities system right.

SDK API (create): envianceSdk.chemicalgroups.createChemicalGroup (chemicalGroupInfo, onsuccess, onerror)

SDK API (copy): envianceSdk.chemicalgroups.copyChemicalGroup (chemicalGroupInfo, copyFrom, onsuccess, onerror)

Parameters
Name Located in Description Required Schema
chemicalGroupCreate body Create Chemical Group body info. Yes chemicalGroupCreate
Responses
Code Description Schema
200 The id string (GUID) for the new Chemical Group. string
Copy Code
JSON
