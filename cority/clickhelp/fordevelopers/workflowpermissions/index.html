/workflows/{workflowIdOrName}/steps/{stepIdOrName}/users/{userId}

GET

Description:

Gets permissions for specified user(s) in a given workflow instance and step, taking into account Role memberships, as well as Manage Workflows right or permission.

Security: Requires Manage Enviance Apps system right.

SDK API: envianceSdk.workflows.resolvePermissions (workflowIdOrUniqueId, stepIdOrName, userId, onsuccess, onerror)

Parameters
Name Located in Description Required Schema
workflowIdOrName path The id string (GUID) of the Workflow instance, or the unique id of the Workflow instance. Any string that matches the pattern of a GUID is interpreted as the id string, and not the unique id of the Workflow. Yes string
stepIdOrName path The id string (GUID) or name of the Step. Any string that matches the pattern of a GUID is interpreted as the id string, and not the name of the Step. Yes string
userId path An array of one or more user ids (GUIDs). Yes string
Responses
Code Description Schema
200 Set of read/write fields; set of read only fields; available step actions; available workflow initiators; available workflow actions (i.e. assign, schedule, add comment, etc.); Assignee Role workflowStepPermissionsInfo

/workflowtypes/{workflowTypeIdOrName}/guessPermissions

POST

Description:

For a given Workflow Type and optional set of compliance objects, this method returns the permissions for all Roles and their resolved members (users and groups), taking into account Role Overrides. (“What are the users and user groups and what are their permissions in a workflow of this type?”)

Security: Requires Manage Enviance Apps system right.

SDK API: envianceSdk.workflows.guessPermissions (workflowTypeIdOrName, options, onsuccess, onerror)

Parameters
Name Located in Description Required Schema
workflowTypeIdOrName path The id string (GUID) of the Workflow type, or the unique id of the Workflow type. Any string that matches the pattern of a GUID is interpreted as the id string, and not the unique id of the Workflow. Yes string
options body Optional filters Yes [ options ]
Responses
Code Description Schema
200 Set of read/write fields; set of read only fields; available step actions; available workflow initiators; available workflow actions (i.e. assign, schedule, add comment, etc.); Assignee Role workflowStepPermissionsInfo

/workflowtypes/{workflowTypeIdOrName}/users/{userId}/guessPermissions

POST

Description:

For a given Workflow Type and user and optional set of compliance objects, this method returns the permissions for the specified user(s), taking into account all Roles with which the users would be associated.

Security: Requires Manage Enviance Apps system right.

SDK API: envianceSdk.workflows.guessPermissionsByUser(workflowTypeIdOrName, userId, options, onsuccess, onerror)

userId path An array of one or more user Ids (GUIDs). Yes string
options body Optional filters Yes [ options ]
Responses

Models

options 

Optional info for workflow

Name Type Description Required
objects string An array of Compliance Model object id strings (GUIDs) or paths, specifying zero or more Compliance Model objects to which the Workflow is associated. Any string that matches the pattern of a GUID is interpreted as an id string, and not a path. No
version string (number) Version number for the workflow No
stepIdOrName string (string) The id or name of specified Workfllow Type. If not specified returns info for first Workflow type step No

workflowInfo 

Represents a single instance of a Workflow.

Name Type Description Required
id string The id string (GUID) of the Workflow. Ignored for: Create Workflow, Update Workflow, Initiate Child Workflow No
uniqueId string The unique id of the Workflow. No
name string Name of the Workflow. Required for: Create Workflow, Initiate Child Workflow No
workflowTypeName string The name of the Workflow Type. Required for: Create Workflow. Ignored for: Update Workflow, Initiate Child Workflow No
parentUniqueId string If the Workflow has a parent Workflow, the unique id string of the parent Workflow, otherwise empty. Ignored for: Create Workflow, Update Workflow, Initiate Child Workflow No
dueDate dateTime The due date of the Workflow. No
status string A string representing the current status of the Workflow, formatted as “Primary Status (Custom Status)”. Ignored for: Create Workflow, Update Workflow, Initiate Child Workflow No
creator string The User name of the person who created the Workflow. Ignored for: Create Workflow, Update Workflow, Initiate Child Workflow No
created dateTime The date and time the Workflow was created. Ignored for: Create Workflow, Update Workflow, Initiate Child Workflow No
lastRun dateTime The date and time the Workflow was last run (saved and/or transitioned). Ignored for: Create Workflow, Update Workflow, Initiate Child Workflow No
assignedBy string The user name of the person who last assigned the Workflow. Ignored for: Create Workflow, Update Workflow, Initiate Child Workflow. No
assignedTo string A set of assignees (User name or id and/or Group name or id) for the Workflow. If at least one assignee is not specified when creating a Workflow, the current User is assigned the Workflow. If the assignee(s) specified here are not part of the assigned Role for the current Step, the assignee(s) will be added to the Role. No
calendars string An array of strings listing the types of Enviance calendars on which this Workflow is shown. Valid values are “My”, “Object”, “System”. No
objects string An array of Compliance Model object id strings (GUIDs) or paths, specifying zero or more Compliance Model objects to which the Workflow is associated. Any string that matches the pattern of a GUID is interpreted as an id string, and not a path. No
documents string An array of Document id strings (GUIDs) or paths, specifying zero or more Documents attached to the Workflow. Any string that matches the pattern of a GUID is interpreted as an id string, and not a path. No
comments string A comment. When retrieving information on an existing Workflow, this value is the current latest comment on the Workflow. No
