DataQualityTemplate

Used to retrieve values from Data Quality Template attached to a Parameter.

Columns

ID DataQuality Template ID

Name DataQuality Template Name

Description DataQuality Template Description

CustomField.ID, CustomField.Name, ... Composite column to CustomField table (includes all fields from CustomField)

CustomField.[Order] Order of the custom field in the template

ExistingCalculatedField.FieldName Calculated Numeric Name

ExistingCalculatedField.FieldID Calculated Numeric ID

ExistingCalculatedField.BeginDate Calculation Definition Begin Date

ExistingCalculatedField.EndDate Calculation Definition Begin Date

ExistingCalculatedField.DivideByZero Calculation Error Handling Divide By Zero

ExistingCalculatedField.Overflow = Calculation Error Handling Overflow

ExistingCalculatedField.Other Calculation Error Handling Other

Created Date created

Updated Date updated

Natural Joins

Requirement

Example: Get Data Quality Templates and their field names.

select

q.Name as QualityTemplate,

q.CustomField.Name,

q.ExistingCalculatedField.FieldName

from DataQualityTemplate q

Example: Get requirements with DQTs and the DQT fields.

select

r.Name as Requirement,

q.Name as QualityTemplate,

q.CustomField.Name,

q.ExistingCalculatedField.FieldName

from Requirement r

join DataQualityTemplate q on r

Example: Get requirement data points with raw value and value of a DQT field.

select

r.Name as Requirement,

d.Value,

d.RawValue,

d."DQBelowLimit"

from Requirement r

join DataPoint d on r

where r.DataQualityTemplate.name like 'DQWater'

and d."DQBelowLimit" like 'true'

Permissions:  Manage Data Quality Templates right is required to query this table. Manage Custom Fields right is also required to query CustomField composite fields.
