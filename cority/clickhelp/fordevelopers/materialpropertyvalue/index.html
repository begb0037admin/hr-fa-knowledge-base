EndDate End Date of Value

[Material Property Name].BeginDate Begin Date of Value

[Material Property Name].EndDate End Date of Value

Natural Joins

Material

Example: Get Activities and Material Property Values for Material Property AVBP.

select

a.Name as Activity,

mpv.Value,

mpv.BeginDate,

mpv.EndDate

from MaterialPropertyValue mpv

join Activity a on mpv.ActivityID = a.ID

join MaterialProperty mp on mp.ID = mpv.PropertyID

Where mp.name = 'AVBP'

order by a.Name, mpv.BeginDate

Example: Get all values for specified Material property. Material Properties applied to an object are supported like native fields.

select

mpv.[ Material Property Name].Value,

mpv.[ Material Property Name].ChemicalId,

mpv.[ Material Property Name].BeginDate,

mpv.[ Material Property Name].EndDate

from MaterialPropertyValue mpv

Permissions:  Manage Materials and Activities right is required to query this table.
