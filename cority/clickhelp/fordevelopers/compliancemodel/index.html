envianceSdk.compliance.createLocation

envianceSdk.compliance.createLocationAsync

Version 2.0

Other Versions:

None

Description

Creates a new Location in the Compliance Model. Supported object types are Division, Facility (Program), Unit (Element), and Point of Interest.

Parameters

locationInfo An instance of a LocationInfo object. Some properties of this object are ignored by this function; see details of this object for more info.

Return Value

None

Notes

Locations are created asynchronously in the Management System. Use the asynchronous version of this function to continue processing without waiting. The non-Async function will take up to 30 seconds to wait for the command to be processed successfully.

Example

envianceSdk.compliance.createLocation(locationInfo,

function(response) {

alert("Location created successfully.");

});

envianceSdk.compliance.updateLocation

envianceSdk.compliance.updateLocationAsync

Version 2.0

Other Versions:

None

Description

Updates (and potentially moves) an existing Location object in the Compliance Model.

Specifying a new parent path moves the Location underneath another parent Location.

Updating the Custom Field Template of a Location object, if that object currently has no Template, adds the Template to the object.

When switching from one Template to another Template, those values that belong to fields which are common to both Templates are kept, any values for Fields not in the new Template are removed permanently. Setting the Template to null permanently removes all Custom Field values.

Parameters

locationIdOrPath The id string (GUID) or full path to the Location in the System Model. Any string that matches the pattern of a GUID is interpreted as the id string, and not the path of the Location.

locationInfo An instance of the locationInfo object. Properties of this object will be used to update the existing Location. Some properties of this object are ignored by this function; see details of this object for more info.

Return Value

None

Notes

Locations are updated asynchronously in the Management System. Use the asynchronous version of this function to continue processing without waiting. The non-Async function will take up to 30 seconds to wait for the command to be processed successfully.

Example

envianceSdk.compliance.updateLocation(

"/Division A/Facility X",

locationInfo,

function(response) {

alert("Location updated successfully.");

});

Version 2.0

Other Versions:

None

Description

Gets information about the specified Location object in the Compliance Model. Supported object types are Division, Facility (Program), Unit (Element), and Point of Interest.

Parameters

locationIdOrPath The id string (GUID) or full path to the Location in the System Model. Any string that matches the pattern of a GUID is interpreted as the id string, and not the path of the Location.

Return Value

A locationInfo object will be passed to the onsuccess callback in the result property.

Example

envianceSdk.compliance.getLocation("/Division A/Facility X",

function(response) {

alert("Facility X active date: " + facility.activeDate);

});

envianceSdk.compliance.locationInfo

Version 2.0

Other Versions:

None

Description

Constructs a locationInfo object instance in JavaScript.

Parameters

name The name of the Location.

type The type of the Location. Valid values are "Division", "Facility", "Unit", and "POI".

parentPath The full path for the parent object. When creating an object, in order to place it at the top level of the System Model, you may specify a path value for the root "/". Updating the parent path serves to move an existing object to another parent.

description A description of the Location.

activeDate Date. The active date for the Location.

inactiveDate Date. The inactive date for the Location.

responsibleUser The user name for the optional responsible manager of the Location.

fieldTemplate An id string (GUID) or name of a Custom Field Template. Any string that matches the pattern of a GUID is interpreted as an id string, and not a name.

fieldValues Array. An array of Custom Field values.

documents Array. An array of Document id strings (GUIDs) or paths, specifying zero or more Documents attached to the Workflow. Any string that matches the pattern of a GUID is interpreted as an id string, and not a path.

timeZone A supported timeZone structure. Only the name of the time zone is used when creating Facility objects.
Required for: createLocation (when creating a Facility – only the name is used)
Ignored for: createLocation (when not creating a Facility), Update Location

address An instance of an address object.

geoLocation An instance of a geoLocation object.

Return Value

An instance of the LocationInfo class.

Instance Methods

setActiveDate(activeDate) This is a convenience method to set the activeDate property.

setInactiveDate(inactiveDate) This is a convenience method to set the inactiveDate property.

setResponsibleUser(userName) This is a convenience method to set the reponsibleUser property.

setFieldTemplate(fieldTemplateName) This is a convenience method to set the fieldTemplate property.

setTimeZone(timeZoneName) This is a convenience method to set the timeZone property.

addDocument(path) This is a convenience method to add a Document by path to the documents property.

addScalarFieldValue(fieldName, value) This is a convenience method to add a ScalarFieldValue value to the fields array property.

addDateFieldValue(fieldName, value) This is a convenience method to add a DateFieldValue to the fields array property.

addTimeFieldValue(fieldName, value) This is a convenience method to add a TimeFieldValue to the fields array property.

addUrlFieldValue(fieldName, label, url) This is a convenience method to add a UrlFieldValue to the fields array property.

addLinkedFieldValues(fieldName, values) This is a convenience method to add a LinkedFieldValues instance to the fields array property.

addMultiFieldValues(fieldName, values) This is a convenience method to add a MultiFieldValues instance to the fields array property.

Example

var facility = new envianceSdk.compliance.LocationInfo(

"Facility X",

"Facility",

"/Division A",

"A new facility.",

"2013-09-30T00:00:00",

null, // no inactive date

"jsmith",

"Facility Template",

null, // no field values in constructor

["/Folder 1/File.xls"],

"Pacific Time (US & Canada) (UTC-08:00) (With DST)",

address,

geoLocation

);

facility.addScalarFieldValue("Field A", 1);

facility.addMultiFieldValues("Field B", ["Option1", "Option2"]);
