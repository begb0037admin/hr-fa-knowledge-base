DashboardPermission

Columns

DashboardID Dashboard ID

PermissionView True if View permission present

PermissionEdit True if Edit permission present

PermissionManage True if Manage permission present

ExplicitUser Composite column to User table (includes all fields from User)

ExplicitGroup Composite column to Group table (includes all fields from Group)

User Composite column to User table (includes all fields from User) Returns combination of users with explicit permission and users who are members of permitted groups (no duplicates).

Example: Get all permissions for current user

select

d.DashboardID

from DashboardPermission d

where

d.user.Id = getCurrentUser()

Permissions:   Requires View or Edit permission on the target object.
