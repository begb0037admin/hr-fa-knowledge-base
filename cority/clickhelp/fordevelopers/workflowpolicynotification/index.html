WorkflowPolicyNotification

Columns

ID Workflow Policy Notification ID

Notify Before Due Date, When Overdue, On Step Completion, On Step Non-Completion, On Assignment, On Completion, On Deletion, On Field Value Change, On Execution Failure

BeforeDueDateDays Workflow Policy Notification Before Due Date

OnAnyStepNonCompletionDays On Any Step Non-Completion Days

OnFieldValueChangeCustomField.ID, OnFieldValueChangeCustomField.Name, ... Composite column to Custom Fields table (includes all from CustomField)

RecipientRole.ID, RecipientRole.Name Composite column to WorkflowRole table (includes all fields, native and composite, from WorkflowRole)

NotificationTemplate.ID, NotificationTemplate.Name, ... Composite column to NotificationTemplate table (includes all fields, native and composite, from NotificationTemplate)

DeliveryToInbox Workflow Policy Notification Delivery To Inbox

DeliveryToEmail Workflow Policy Notification Delivery To Email

Natural Joins

WorkflowPolicy

Example: Get workflow policy with notification details.

select

wp.name,

n.Notify,

n.BeforeDueDateDays,

n.OnAnyStepNonCompletionDays,

n.OnFieldValueChangeCustomField.Name,

n.RecipientRole.Name as Role,

n.NotificationTemplate.Name as Template

from WorkflowPolicyNotification n

join WorkflowPolicy wp on n

Permissions:  Manage Workflows right is required to query this table. Manage Users, Manage Groups, Manage Task Templates, Manage Custom Fields rights are also required to query OnFieldValueChangeCustomField, RecipientRole, NotificationTemplate fields.
