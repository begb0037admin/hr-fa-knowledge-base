ReportPermission

Columns

ReportID Report ID

Permission.View True if View permission present.

Permission.Edit True if Edit permission present.

Permission.Unrestricted True if Unrestricted permission present.

ExplicitUser.ID, ExplicitUser.FirstName... Composite column to User table (includes all fields from User). Returns only those users granted explicit permission.

ExplicitGroup.ID, ExplicitGroup.Name... Composite column to Group table (includes all fields from Group).

User.ID, User.FirstName... Composite column to User table (includes all fields from User). Returns combination of users with explicit permission and users who are members of permitted groups (no duplicates).

Note:  Columns will return null if User is an access user.

Natural Joins

Report

Example: Get all users with View or Edit permission on a report folder (includes both users with explicit permission and users who are members of permitted groups).

select

r.Name,

p.Permission.View,

p.Permission.Edit,

p.User.FirstName,

p.User.LastName

from Report r

join ReportPermission p on r

where r.Name like 'xxx' and r.IsFolder=1

Permissions:  Requires View, Edit or Unrestricted permission on the target object.
