MaterialProperty

Columns

ID Material Property ID

Name Property Name

Description Property Description

MaterialID Identifier of Material where property is used

ActivityID Identifier of Activity where property is used

PropertyType Text, Property Type (eg: Specific Use Variable, Formula Based Tertiary…)

DataType Text, Property Data Type (Numeric, Boolean)

FormulaBased.ID, FormulaBased.ParentProperty, ... Composite column to MaterialScript table (include all fields from MaterialScript)

ValueBased.ID, ValueBased.ContainerID, ... Composite column to MaterialPropertyValue table (include all fields from MaterialPropertyValue)

Created Date Created

Updated Date Updated

SuvTag "Unique Tag" property of SUV (SuvTag.Tag)

Natural Joins

None

Example: Get all material properties for Material 'SUV MET'.

select

mp.name,

mp.description,

mp.PropertyType,

mp.DataType

from Material m

join MaterialProperty mp on mp.MaterialID = m.ID

where m.name = 'suv met'

Permissions:  Manage Materials and Activities right is required to query this table.
