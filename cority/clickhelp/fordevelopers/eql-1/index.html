/query

POST

Description:

Executes an EQL query batch, returning the results in one or more tables of row/column format. Maximum page size is 1000. If either page or page size are unspecified the entire result set will be streamed in one response.

SDK API: envianceSdk.eql.execute(eql, page, pageSize, onsuccess, onerror)

Parameters
Name Located in Description Required Schema
eql query The EQL batch (string) to execute. The EQL batch must be URL encoded. Yes string
page query The page number within the entire result set to return. Optional. No number
pageSize query The number of records for each page. Maximum page size is 1000. Optional. No string
Responses
Code Description Schema
200 An instance of eqlTable structure eqlTable
Copy Code
JSON

/query/eql

GET

Description:

Executes an EQL query batch, returning the results in one or more tables of row/column format.

SDK API: envianceSdk.eql.executeWithFormat(eql, page, pageSize, format, onsuccess, onerror)

SDK API: envianceSdk.eql.executeWithFormatBinary (eql, page, pageSize, format, filename, cachecontrol, onsuccess, onerror)

Parameters
Name Located in Description Required Schema
eql query The EQL batch (string) to execute. The EQL batch must be URL encoded. Yes string
page query The page number within the entire result set to return. Optional. No number
pageSize query The number of records for each page. Optional. No number
format query One of csv, json, xml or xlsx. If unspecified, JSON is used. Optional. No string
filename query The name of the file containing the results of the query. Optional. No string
cachecontrol query Cache size (Mb). Optional. No number
Responses
Code Description Schema
200 An instance of eqlTable structure eqlTable
