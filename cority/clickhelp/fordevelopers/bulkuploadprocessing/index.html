Bulk Upload Processing Rules

  • Some tools have multiple worksheets. The upload tool recognizes any valid worksheet names in the file and ignores any worksheets it does not recognize.
  • Each worksheet is a separate tool and can be run independently. Any worksheets you do not need can be deleted from the upload file.
  • You can choose which worksheet(s) to process per upload transaction. When there is a logical order to the process (i.e., create objects, then edit), it is best to process one sheet at a time in order to make debugging easier.
  • If you process more than one worksheet in a single upload, the order of the worksheets is the order of processing. Worksheets can be re-ordered as desired.
  • You can combine worksheets from different templates in one file.
  • The tool identifies each field to edit by the address of the column in the Excel file. The names in the column heads are not important. Some instructions and guidance as to expected values or restrictions have been included in the column heads to help you, but these can be edited or deleted for your own use.
  • The tool assumes that the first row is the column heads and begins processing with row 2. Processing continues until a blank row is encountered.
  • Columns or rows may be hidden for editing convenience. However all hidden rows or columns will be processed normally in the upload transaction.
