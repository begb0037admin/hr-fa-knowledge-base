UoMType

Note: The 'UoMType' function is only available for the Chemical Management EQL.

Returns type of unit of measure Volume or Mass.

Syntax

UOMTYPE(expression)

Example:

select top 1

UOMTYPE ( c.UnitOfMeasure)

from Container c
