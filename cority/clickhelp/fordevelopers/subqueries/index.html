Subqueries

A subquery is a SELECT statement that is nested within another SELECT statement and it is executed independently of the SELECT statement, in which it is nested.

Examples

Use of a Subquery in the FROM clause

Select

subquery.id,

subquery.childcount

from

(select count(co.id) as childcount, f.id

from Facility f

join ComplianceObject co on f is parent co

group by f.id )

subquery

where subquery.childcount>0

Query returns IDs of facilities that have one or more children objects

Joining Virtual Tables

Select

co.name,

subquery.childcount

from

ComplianceObject co

left join (

select count(co.id) as childcount, f.id

from Facility f

join ComplianceObject co on f is parent co

group by f.id )

subquery on subquery.id = co.id

where subquery.childcount>0

Query returns facilities that have one or more children objects

Use of a Subquery in the Column List of a SELECT Statement

Select

co.name,

( select count(co1.id) as childcount

from Facility f

join ComplianceObject co1 on f is parent co1

where f.id =co.id

group by f.id ) as d

from

ComplianceObject co

Query returns facilities and count of children objects

Use of a Subquery in the WHERE clause

Select

co.name

from

ComplianceObject co

where

co.id in

( select f.id

from Facility f

)

Query returns only facilities from ComplianceObject table
