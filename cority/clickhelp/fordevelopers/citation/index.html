Default Filtering

By default Citation shows data for the Last citation version only. If Version or IsLastVersion column are used in query, data for all versions will be shown.

Example: Get citations with dates and associated requirements and event logs.

select

c.Name,

c.Version,

c.EffectiveDate,

c.FederalApprovalDate,

c.FederalEnforceableDate,

c.AssociatedRequirement.Name,

c.AssociatedEventLog.Name

from Citation c

 

Permissions:  Manage Citations right OR View/Modify Permission on specific citation(s) is required to access this table. If User does not meet both requirements, no security error occurs, but empty data is returned. Manage Users right is required to query Users composite fields. Report permission is required to query Event Log and Report fields; see EventLog and Report for more.
