TagScheme

Columns

ID Identifier

Name Name

Description Description

EnforceUniquenessOnObject Boolean. When True it enforces that for any object, only one tag from this scheme may be related to that object

EnforceUniquenessOnLevel Boolean. When True, it enforces that for any tag in this scheme, only one object at a given location may be related to the tag

Tag[Tag] CC column to Tag

Created DateTime created

Updated DateTime updated

IsTrackValueHistoryEnabled Boolean, indicating if tags of scheme have date periods

Natural Joins

None

Example:

select

ts.Tag.Name as Tag

from TagScheme ts

Permissions:  Manage Tags right is required to query this table.
