Example: List Facilities in "Texas" division and get values for facility custom fields:

select

div."State or Territory" as State,

f."Facility Number" as FacilityNumber,

f."Region" as Region,

f."Market/District" as MarketDistrict,

f."Facility Category" as Category

from

Facility f

left join ComplianceObject div on div is parent f and div.Type'D'

where

div."State or Territory" = 'Texas'

order by

div.State, f."Facility Number"

Permissions:  Requires Report permission on the target object. Manage Custom Fields right is also required to query CustomFieldTemplate fields.
