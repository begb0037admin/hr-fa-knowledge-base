EMS App Packages

A convenient unit of deployment for an EMS App is called an "EMS App package".

An EMS App package is a single zip archive file, which can contain any number of directories and files.

Package Upload

The application supports uploading of an EMS App package into an EMS App during the following operations:

  • EMS App Creation
  • EMS App Update

Upon uploading an EMS App package, its contents are extracted, and each file saved as an EMS App Item.

When uploading an EMS App package as part of an update of an existing EMS App, the current content and settings in the EMS App will be replaced entirely with the content and manifest settings in the package.

To update just the content of an EMS App, upload a package without a manifest file.
