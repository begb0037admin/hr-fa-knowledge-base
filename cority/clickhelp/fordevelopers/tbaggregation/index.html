PATCH

Description:

Updates an existing Time Based Aggregation Requirement. Updating the collection of history data (Calculation Definition, Expected Frequency History or Limits History) causes merge of old and new collections. Records with the same begin date are updated. Records with different begin dates are inserted. If period is set without any other data, any record that exists with the same period is deleted.

Updating the Custom Field Template of a Requirement object, if that object currently has no Template, adds the Template to the object. When switching from one Template to another Template, those values that belong to fields which are common to both Templates are kept, any values for Fields not in the new Template are removed permanently. Setting the Template to null permanently removes all Custom Field values.


SDK API: envianceSdk.requirements.updateRequirement(requirementIdOrPath, reqInfo, onsuccess, onerror)

SDK API: envianceSdk.requirements.updateRequirementAsync(requirementIdOrPath, reqInfo, onsuccess, onerror)

Represents a Requirement definition. Used for all numeric requirement types, distinguished by “requirementType” property value: Parameter (ParameterRequirement), Calculated Requirement (CalcRequirement), System Variable (SystemVariable), Time-Based Calculated Requirement (TBRequirement), Count-Based Calculated Requirement (CBCRequirement), Time-Based Aggregation (TBARequirement), Time-Based Subtraction (TBSRequirement), Material Activity Calculated Requirement (MACRequirement). Some properties of this structure are ignored during this operation.
