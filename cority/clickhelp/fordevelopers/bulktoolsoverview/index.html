Bulk Tools Overview

The Bulk Upload Tools are used to automate the creation and editing of objects in the Management System based on a set of instructions provided in specifically formatted Excel files.

The following tools are currently available. Download the Excel file for each tool from the link provided in the right column.

Click the link in the left column to access instructions.

Object Copy

Copy existing system model objects and compliance objects to multiple locations (within the same System Model only). Copy, paste and rename system objects.

Object Copy Tool

Object Move

Move objects (with children) from one location to another in the same System Model.

Object Move Tool

Object Delete

Delete objects within the System Model.

Object Delete Tool

Object Properties Editing

 

Assign or edit property values for existing objects in the system. Assign property values for new objects after creating them with the Object Copy Tool.

Three versions of this tool are available:

Simple Properties Tool: Use to edit simple properties with single property:value relationships.

Complex Properties Tool: User to edit complex properties that entail more than one field value.

Monitored Requirements Tool: User to edit monitored requirements for Event Logs with one requirement per row (instead of multiple requirements on one row).

Object Names Localization: Use to add localized values for object names.

Citation Management

Create citations and citation folders, edit citations, and associate citations with objects.

Citation Management Tool

Permissions Editing

Create and edit users and groups and assign permissions. Includes object permissions; permissions to reports, documents and citations; workflow permissions; and TRI permissions.

Permissions Editing Tool

Search Tags Under Settings

Search tags under specific object path and under system levels (EntireSystem, Division, Facility, Unit, POI).

The tool for Search Tags Under Settings allows you to specifiy system levels or specific objects under which Calculated Requirement will search other requirements to resolve them in Tag Aggregation Calculation.

Search Tags Under Settings Tool

Tag Schemes and Tags

Create, Edit, Copy and Delete Tag Schemes and Tags.

Tag Schemes Tool

Task Editing

Edit existing tasks in the system. You can edit general task properties, task recurrences and task notifications, and add task exceptions. You cannot create new tasks for an object with this tool; however, you can copy a template object with an associated task with the Object Copy tool, then edit the task properties and add or change associated objects.

Task Editing Tool

Template Update

Add, change or delete object associations for Custom Field Templates; change associations for Event Templates and Requirement Templates; add, change or remove Task Template associations with Event Logs or Requirements.

Template Update Template

Document Management

Move documents and document folders, add new document folders, edit document properties and values, associate documents to compliance objects, and delete documents.

Document Management Template

Calc Edit

Edit formulas for calculated requirements. In addition, you can edit limits and calculation template fields (UDFs on a Calculation Template).

Calc Edit Tool

Workflow Overrides

Edit Workflow Role Overrides and Workflow Policy Overrides for system objects.

Workflow OverrideTool (roles and policies)

Workflow Role Override Tool

Workflow Policy Override Tool

Units of Measure

Create, edit, and delete units of measure and unit of measure categories in the units of measure library.

Unit of Measure Category Template

Unit of Measure Template
