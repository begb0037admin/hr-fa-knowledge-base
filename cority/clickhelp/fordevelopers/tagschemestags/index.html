Tag Schemes and Tags

The bulk tool for Tag Schemes allows you to create and edit Tag Schemes and Tags, and associate Tags with requirements.

Download the Excel template file:

Tag Schemes and Tag Editing Tool

The Tag Schemes tool includes eight worksheets:

  • New Tag Scheme: Create a new Tag Scheme.
  • Edit Tag Scheme: Edit Tag Scheme name, description and restrictions
  • Delete Tag Scheme: Delete Tag Scheme (not allowed if tags have existing associations)
  • Copy Tag Scheme: Copy Tag Scheme (includes copying all tags)
  • New Tag: Create new Tag for named Tag Scheme
  • Edit Tag: Edit name, description, associated Tag Scheme(s)
  • Delete Tag: Delete Tags (not allowed if tags have existing associations)
  • Edit Tag Associations: Add or Remove Object-Tag associations

New Tag Scheme columns:

Tag Scheme: Name of the Tag Scheme. Required.

Description: Optional description

Enforce Only One Tag: Enforces rule that for any object, only one tag from this scheme may be related to the object.

Enforce Only One Object: Enforces rule that for any tag in this scheme, only one object at a given location may be related to the tag.

Track Value History: Tracks the history of requirements values associated with tags in the scheme.

Edit Tag Scheme columns:

Tag Scheme: Name of the Tag Scheme. Required.

Rename: New name for Tag Scheme (if renaming)

Description: Optional description

Enforce Only One Tag: Enforces rule that for any object, only one tag from this scheme may be related to the object.

Enforce Only One Object: Enforces rule that for any tag in this scheme, only one object at a given location may be related to the tag.

Delete Tag Scheme column: 

Tag Scheme: Name of the Tag Scheme. Required.

Copy Tag Scheme columns: 

Tag Scheme: Name of the Tag Scheme. Required.

New Name: Name for new Tag Scheme. Required.

New Tag columns:

Tag: Name of new tag. Required.

Tag Scheme: Name of the Tag Scheme to which tag belongs. Required.

Description: Optional description

Edit Tag columns: 

Tag: Name of new tag. Required.

Tag Scheme: Name of the Tag Scheme to which tag belongs. Required.

Rename: New name for Tag

Description: Optional description

New Tag Scheme: New Tag Scheme to associate with Tag, if any.

Delete Tag columns: 

Tag: Name of new tag. Required.

Tag Scheme: Name of the Tag Scheme to which tag belongs. Required.

Edit Tag Associations columns: 

Object Path and Name: Full path and name of object to associate: \Division\Facility\Unit\POI\Requirement

Tag Name: Name of Tag to associate

Tag Scheme Name: Name of Tag Scheme

Action: Options are Add, Remove or <clear>)

Start date: Start Date defines the moment of time when datapoints of requirements start aggregating into Tag Aggregation Calculation. Required.

End date: End Date defines the moment of time when datapoints of requirements stop aggregating into Tag Aggregation Calculation. It can be specified or left blank.
