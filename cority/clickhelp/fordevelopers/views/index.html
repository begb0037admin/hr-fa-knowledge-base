Views

Note: Views are only available for the Management System EQL.

EQL allows the use of Inline Table-Valued Function (ITVF). An ITVF must be previously created in the database with the prefix "eql_view_user_".

An ITVF can also contain parameters (order does not matter). Parameters in the database must start with prefix "@__".

Round brackets are optional in case of parameter-less view.

In EQL all views and parameters must be used without the database prefix.

All parameters named "USER", "APP", "SYSTEM" are optional.

A parameter can be used as condition in "where"/ "on" clause if there is no conflict with the column name.

Example: Simple ITVF

select

irv."FirstName",

irv."LastName",

irv."Incident_ID",

irv."IncidentName",

irv."FacilityID"

from IncidentReportView irv

Example: ITVF with parameters

select

irv."FirstName",

irv."LastName",

irv."Incident_ID",

irv."IncidentName",

irv."FacilityID"

from IncidentReportView(User='e9e52190-459b-47c3-a4ec-8368a7d876b2' , ObjectsPaths = ['\apath\obj1','\bpath\obj2']) irv

Example: ITVF with parameter in "where" clause and skipped optional parameter "User"

select

irv."FirstName"

from IncidentReportView irv

where

irv.ObjectsPaths = ['\apath\obj1','\bpath\obj2']
