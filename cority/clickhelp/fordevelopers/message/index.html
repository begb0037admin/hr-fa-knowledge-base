envianceSdk.messages.createMessage

Version 2.0

Other Versions:

None

Description

Queues a message for delivery to the specified recipient's EMS Inbox, as well as optionally to the recipient's e-mail address.

Parameters

messageInfo An instance of the messageInfo object. Some properties of this object are ignored by this function; see details of this object for more info.

Return Value

None

Notes

Upon successful creation of a new message, the message is queued for delivery. There is no way to determine delivery status at this time.

Example

envianceSdk.messages.createMessage(messageInfo,

function(response) {

alert("Message successfully queued.");

});

envianceSdk.messages.getMessage

Version 2.0

Other Versions:

None

Description

Gets a message from the User's EMS Inbox.

Parameters

messageId The id string (GUID) of the Message.

Return Value

A messageInfo object will be passed to the onsuccess callback in the result property.

Notes

A User may only retrieve messages from his own Inbox. Getting a message through this API does NOT mark the message as "read".

Example

envianceSdk.messages.getMessage("2d4fc954-b062-433d-9405-ce709c36a353",

function(response) {

var message = response.result;

alert("Message content:" + message.body);

});

envianceSdk.messages.deleteMessage

Version 2.0

Other Versions:

None

Description

Deletes a message from the User's EMS Inbox.

Parameters

messageId The id string (GUID) of a Message in the User's EMS Inbox.

Return Value

None

Notes

A User may only delete messages from his own Inbox.

Deletions are permanent.

Example

envianceSdk.messages.deleteMessage("2d4fc954-b062-433d-9405-ce709c36a353",

function(response) {

alert("Message deleted.");

});

envianceSdk.messages.messageInfo

Version 2.0

Other Versions:

None

Description

Constructs a messageInfo object instance in JavaScript.

Parameters

recipientIdOrUserName The id string (GUID) or username for the User to whom this message was delivered. Any string that matches the pattern of a GUID is interpreted as the id string, and not the username.

subject The subject of the message.

body The main text or body of the message. Any HTML content will be escaped.

sendByEmail Boolean. A flag to indicate whether or not the message should be sent to the recipient's email (in addition to their EMS Inbox). The default is false.

Return Value

An instance of the messageInfo class.

Example

var message = new envianceSdk.messages.MessageInfo(

"jsmith",

"We really need to talk.",

"Let's get together soon to go over the checklist.",

true

);
