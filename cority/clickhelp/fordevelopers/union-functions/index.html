Union Functions

The Union function is used to combine the EQL result set of two or more SELECT statements:

  • Each SELECT statement within UNION must have the same number of columns
  • The columns must have similar data types and be in the same order

Union Function

Union Syntax:

select column_name(s)from table1

union

select column_name(s)from table2  

Example:

select f.Id, f.Name from Facility f where f.Name = 'example facility'

union

select 

f.Id, f.Name

from

Facility f

join ComplianceObject co on f.Id = co.Id  

where f.Name = 'example facility'

union

select f.Id, f.Name from Facility f where f.Name = 'example facility'

Result: EQL returns only distinct values.

The UNION operator selects only distinct values by default. To allow duplicate values, use UNION ALL.

Union All Function

Union All Syntax:

select column_name(s)from table1

union all

select column_name(s)from table2  

Example:

select f.Id, f.Name from Facility f where f.Name = 'example facility'

union all

select

f.Id, f.Name

from

Facility f

join ComplianceObject co on f.Id = co.Id  

where f.Name = 'example facility'

union all

select f.Id, f.Name from Facility f where f.Name = 'example facility'

Result: EQL returns distinct and duplicate values.
