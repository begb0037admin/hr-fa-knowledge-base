Edit Task Properties

The fields on the Edit Properties worksheet correspond to the fields in the General tab of the Task Properties in EMS.

Identifying fields for the task (required) are in cols A-F (see Task Editing). You may edit any of those fields in the columns to the right, along with the additional fields shown. Fields left blank will not be edited. To clear a field, enter <clear>. Use one row for each task.

Editable fields (columns G-R) are:

Task Name: Name of task

Task Description: Description (text)

*Task Due Date: Date: Due date of task (if different than due date in ID field, column C).

*Task Due Date: Time: Due time of task (if different than time in ID field, column D).

*Task Time Zone: Required. Use for single-instance tasks. Note that Task Time Zone may be different than Assignee User Time Zone. If different, user will see due date/time adjusted for their own time zone (UTC ±). For a recurring task, specify time zone on the Add or Edit Recurrence worksheet. For time zone formats, see Time Zones.
