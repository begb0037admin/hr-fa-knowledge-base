TaskTemplate

Columns

ID Task Template ID

Name TaskTemplate Name

Description TaskTemplate Description

AssignorCalendar Display Task in Assignor's Calendar

ObjectCalendar Display Task in Object Calendar

SystemCalendar Display Task in System Calendar

DueDateCount Display Task Due Date Count

DueDatePeriod Display Task Due Date Period

Created Date created

Updated Date updated

Document.ID, Document.Name, ... Composite column to Document table (includes all fields, native and composite, from Document)

Workflow.TypeID ID of workflow type

Workflow.Name Workflow Name

Workflow.ShowInMyCalendar Indicates if Calendar Show In My Calendar is selected

Workflow.ShowInObjectCalendar Indicates if Calendar Show In Object Calendar is selected

Workflow.ShowInSystemCalendar Indicates if Calendar Show In System Calendar is selected

Workflow.CompletionFieldCosttoComplete Indicates if Task Completion Fields Cost to Complete is selected

Workflow.CompletionFieldTimeToComplete Indicates if Task Completion Fields Time To Complete is selected

Workflow.CompletionFieldStatus Indicates if Task Completion Fields Status is selected

Workflow.CompletionFieldComments Indicates if Task Completion Fields Comments is selected

Workflow.CompletionFieldComply Indicates if Task Completion Fields Comply is selected

Workflow.CompletionFieldDismissed Indicates if Task Completion Fields Dismissed is selected

Workflow.CompletionFieldCompliancePeriod Indicates if Task Completion Fields Compliance Period is selected

Workflow.CompletionFieldDate Indicates if Task Completion Fields Completion Date is selected

Workflow.DueDateFlags Due Date Flags (TaskDueDate, [Before/After]QuarterHour, [Before/After]Hour, [Before/After]Day, [Before/After]Week, [Before/After]Month, [Before/After]Year)

Workflow.DueDateValue Due Date Value

Workflow.CreateByDueDate Indicates if Time to Create By Due Date is selected

Workflow.CreateOnPastDue Indicates if Time to Create On Past Due is selected

Workflow.CreateByCompletionStatus Indicates if Time to Create By Completion Status is selected

Workflow.CreateWhenDismissed Indicates if Time to Create When Dismissed is selected

Workflow.CreateValue Create Value

Workflow.CreateCompleteStatus Create Complete Status

Workflow.AssigneeUser.ID, Workflow.AssigneeUser.FirstName, ... Assignee User. Composite column to User table (includes all fields from User)

Workflow. AssigneeGroup.ID, Workflow. AssigneeGroup.Name, ... Assignee Group. Composite column to Group table (includes all fields from Group)

Note:  Columns will return null if User is an access user.

Natural Joins

TaskTemplateNotification

EventLog

Example: Get requirements and the task templates associated with the regulatory limit.

select

r.name as Requirement,

r.path,

l.RegulatoryTaskTemplate.name as TaskTemplate

from Requirement r

join Limit l on r

Example: Get event logs and associated task templates

select

el.path,

el.name,

el.TaskTemplate.Name

-- assignee

-- assignor

-- limittype

-- objecttype

from Eventlog el

Example: Get requirements and associated task templates for limits with assignee and assignor.

select

r.path,

r.name,

l.RegulatoryTaskTemplate.Name,

l.InternalTaskTemplate.Name,

l.TaskRegulatoryAssignorID,

l.TaskInternalAssignorID,

l.TaskRegulatoryUserAssigneeID,

l.TaskRegulatoryGroupAssigneeID,

l.TaskInternalUserAssigneeID,

l.TaskInternalGroupAssigneeID,

from Requirement r

join Limit l on r

Permissions:   Manage Task Templates right is required to query this table. Manage Documents right is also required to query Document composite columns; Manage Users right is required to include CreatedBy composite columns.
