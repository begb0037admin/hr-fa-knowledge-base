EQL Information Schema Tables

EQL information schema tables are available as a method of returning metadata about EQL tables. Three schema tables are available: TABLES, COLUMNS and RELATIONS, as defined below.

TABLES: Returns all Tables available for querying in EQL. Includes:

TableName: Name of EQL table

TableSubsystem: Name of the subsystem where that table belongs to. For example:

Model, returned for tables:

ComplianceObject

Division

Unit

Facility

POI

Requirement

Limit

Event, returned for tables:

EventLog

EventInstance

Data, returned for tables:

DataPoint

DeletedDataPoint

Report , returned for tables:

Report

Workflow, returned for tables:

Workflow tables

Template, returned for tables:

Template

CustomField

Access , returned for tables:

System

User

Group

TimeZone

COLUMNS : Returns all columns for all tables. Includes custom field columns. Custom field columns are determined by identifying all templates associated with table, and returning a combination of all custom fields for those templates.

TableName: Column Name in case of Native column. UDF Name in case of custom field.

ColumnName

DataType

IsIdentifier (primary key)

isCustomField

CustomFieldID

RELATIONS: Includes natural Joins, primary-foreign keys.

SourceTableName

SourceColumnName

DestinationTablename

DestinationColumnName

IsNatural: Indicates if Natural join is present between tables.
