Natural Joins

WorkflowInstance – Natural joins only the current workflow step. Consider an explicit join (WorkflowInstanceID) for querying all workflow steps.

Example: Get the data entered (on specified custom fields) for the current step of a given workflow.

select top 1

ws."Custom Field 1",

ws."Custom Field 2"

from WorkflowInstance w

join WorkflowStep ws on w

join WorkflowHistory wh on wh. WorkflowStepID = ws.ID

where

w.Name = 'My Workflow'

order by wh.Created desc

Example: Natural join returning just the current step for the instance:

select …

from workflowinstance wi

join workflowstep ws on wi

Example: Explicit join returning all steps for the instance:

select …

from workflowinstance wi

join workflowstep ws on ws.workflowinstanceid = wi.id

Permissions:  Requires Report permission on owner workflow. Manage Groups right is also required to query AssigneeGroup fields. Manage Users right is also required to query AssignedBy,AssigneeUser fields.
