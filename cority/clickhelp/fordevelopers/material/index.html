enviancesdk.materials.createMaterial

Version 2.0

Other Versions:

None

Description

Creates a new Material.

Parameters

materialInfo An instance of the materialInfo object. Some properties of this object are ignored by this function; see details of this object for more info.

Return Value

The id for the new Material.

Example

envianceSdk.materials.createMaterial (materialInfo, onsuccess, onerror)

 

enviancesdk.materials.copyMaterial

Version 2.0

Other Versions:

None

Description

Creates a new Material by copying an existing material.

Parameters

materialInfo An instance of the materialInfo object. Optional information to set properties of the new material.

copyFrom The id string (GUID) of an existing Material whose properties will be copied and used as the properties of the newly created Material. Specifying this property allows you to copy an existing Material to another Material.

Return Value

The id for the new Material.

Notes

None

Example

envianceSdk.materials.copyMaterial (materialInfo, copyFrom,onsuccess, onerror)

None

Example

enviancesdk.materials.materialInfo

Description

Represents a Material definition.

Properties

id The id string (GUID) for the Material.
Ignored for: Create Material, Update Material

name The name of the Material.
Required for:  Create Material

description The description of the Material.

chemicals An array of chemicalConcentrationHistoryInfo.
Required for:  Create Material

properties An array of materialPropertyMapInfo structures.
Required for:  Create Material

templateIdOrName An id string (GUID) or name of a Material Template. Any string that matches the pattern of a GUID is interpreted as an id string, and not a name.

fields An array of Custom Field values for Material Template properties.

materialAvailabilityFlag Boolean value "true" or "false"

envianceSdk.materials.chemicalConcentrationHistoryInfo

Description

Represents a single Chemical Concentration Value History definition.

Properties

idOrNameThe id string (GUID) of the Chemical Concentration Item record.
Ignored for: Create Material

beginDate Date. A DateTime value, representing begin date for the Item.

endDate Date. A DateTime value, representing end date for the Item.

present Boolean. True/false value indicating whether chemical is present in history.

min Number. A decimal value between 0 and 100. If unspecified, the default is 0.

avg Number. A decimal value between 0 and 100. If unspecified, the default is 0.

max Number. A decimal value between 0 and 100. If unspecified, the default is 0.

Example

envianceSdk.materials.ChemicalConcentrationHistoryInfo(id, beginDate, present, minConc, avgConc, maxConc, created)

 

{

"beginDate": "2012-01-01T00:15",

"endDate": "2013-01-01T00:15",

"present": "true",

"minConc": "0.5",

"avgConc": "1",

"maxConc": "2.8"

}

envianceSdk.materials.materialPropertyMapInfo

Description

Represents a Material Value-Based Property definition.

Properties

propertyIdOrName An id string (GUID) or name of a Material Property.
Required for: Create Material

valueHistory Array. An array of one or more materialPropertyValueHistoryItem structures.
Required for: Create Material

envianceSdk.materials.materialPropertyValueHistoryInfo

Description

Represents a single Value History Item definition for a Material Value-Based Property.

Properties

idThe id string (GUID) of the Value History Item record.
Ignored for: Create Material

beginDate Date. A DateTime value specifying begin date for the Item.

value Number. Numeric or Boolean value for the Item. (Boolean values represented by "0" and "1" values).

Example

envianceSdk.materials.MaterialPropertyValueHistoryInfo (id, beginDate, value)

 

{

"beginDate": "2012-01-01T00:15",

"value": "123"

}
