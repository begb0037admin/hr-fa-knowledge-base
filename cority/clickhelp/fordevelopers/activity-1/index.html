Activity

Columns

ID Activity Unique ID

Name Activity Name

Description Activity Description

Created Date created

Updated Date updated

Property.ID, Property.Name, … Composite columns to MaterialProperty table (includes all fields, native and composite, from MaterialProperty)

MaterialActivityTemplate.ID, MaterialActivityTemplate.Name, ... Composite column to MaterialActivityTemplate table (includes all fields, native and composite, from MaterialActivityTemplate)

ValueHistory.Value, ValueHistory.EndDate, ... Composite column to MaterialPropertyValue (includes all fields, native and composite, from MaterialPropertyValue)

Natural Joins

MaterialDataLineGroup

Example:

select

a.name,

a.description,

a.MaterialActivityTemplate.Name,

a.MaterialActivityTemplate.CustomField.Name

from Activity a

Permissions:  Manage Materials and Activities right is required to query this table. Manage Material Templates and Manage Custom Fields rights are required to query MaterialActivityTemplate composite fields.
