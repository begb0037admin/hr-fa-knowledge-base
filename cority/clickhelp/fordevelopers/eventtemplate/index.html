EventTemplate

Columns

ID Event Template ID

Name Event Template Name

Description Event Template Description

Created Date created

Updated Date updated

IncludeComplianceCertificationStatus Value of Boolean field Include Compliance Certification Status

CustomField.ID, CustomField.Name, ... Composite column to CustomField table (includes all fields from CustomField)

CustomField.[Order] Order of the custom field in the template

Document.ID, Document.Name, ... Composite column to Document table (includes all fields, native and composite, from Document)

Natural Joins

EventLog

Example:

select

et.Name,

et.CustomField.Name

from EventTemplate et

order by et.name

Permissions:  Manage Event Templates right is required to query this table. Manage Custom Fields right is required to query CustomField fields. Manage Documents right is required for Document composite columns; in addition Manage Users right is required for CreatedBy composite fields for document.
