GetUsers

This method works in a similar way to the Search for Users functionality in the MainApp user interface. It accepts one or more search filters and retrieval options. For example, you can search for a user with a specific First Name and User Time Zone. Retrieval options are used to order the results. The method returns a User element array, each User returned contains all information about that user. This object can be edited and sent back via UpdateUser method.

UpdateUser

This method takes a single User element (same one returned from GetUsers, or one built up from scratch), uses the UserLogin value to find the user in the system and then updates other values in the User element on the actual User in the system. If values are not set in the element, the corresponding values in the system are left unchanged. Some values cannot be changed via this method (UserLogin and Password for example). Note that User can be assigned or revoked rights via this method. Also Users can be assigned to or removed from UserGroups via this method.

CreateUser

Creates a new home user on EMS customer system, with optional access rights and group assignment.

Users are created on the same system where API caller defaults to. Password field is required. It is sent as a plain text value. Property MustChangePassword can be set in order to force user change his password on first login.

DeleteUser

Marks user as deleted and closes existing user sessions.
