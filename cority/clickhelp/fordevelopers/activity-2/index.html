/activities

POST

Description: 

Creates a new Activity, alternately by copying an existing Activity

Security: Requires Manage Materials and Activities system right.

SDK API (create): envianceSdk.activities.createActivity (activityInfo, onsuccess, onerror)

SDK API (copy): envianceSdk.activities.copyActivity (activityInfo, copyFrom, onsuccess, onerror)

Parameters
Name Located in Description Required Schema
activityCreateInfo body Create Activity body info Yes activityCreateInfo
Responses
Code Description Schema
200 The id string (GUID) for the newly created Activity. string



Copy Code
JSON
//EXAMPLE (Create)
POST/ActivityService.svc/activities HTTP/2
Content-Type: application/json; charset=UTF-8
 
{
  "activityInfo": {
    "name": "Activity Name",
    "description": "Activity Description",
    "properties": [
      { "propertyIdOrName": "SUV Name" },
      {
        "propertyIdOrName": "83ed6d63-151d-45aa-befd-b47da3decc23",
        "valueHistory": [
          {
            "Date": "2013-12-01T23:55",
            "Value": "12"
          }
        ]
    } ],
    "templateIdOrName": "Template Name",

      {"name": "Unique Tag ID", "values": ["abcd-1234"]},
      {"name": "Custom Text Field", "values": ["text"]},
      {"name": "Date Field", "values": ["2013-12-01T23:55"]}
    ]
  }
}

activityInfo 

Represents the description of an Activity for material-based calculations.

Name Type Description Required
id string The id string (GUID) for the Activity. Ignored for: Create Activity, Update Activity No
name string Name of the Activity. Required for: Create Activity No
description string Description of the Activity. No
templateIdOrName string An id string (GUID) or name of a Custom Field Template. Any string that matches the pattern of a GUID is interpreted as an id string, and not a name. A name string must be URL encoded. Ignored for: Update Activity No
properties [ activityPropertyInfo ] An array of activityPropertyInfo. Required for: Create Activity No
fields [ customFieldValue ] An array of Custom Field values for Material Template properties. No

 customFieldValue 

A set of one or more values for a Custom Field, identified by name.

Name Type Description Required
name string The name (not caption) of the Custom Field. No
values string An array with one or more string values, representing the values (one or more) for the Custom Field. Note that even non-string simple values are encoded as strings for custom fields, and are parsed and validated on the server according to the Custom Field type. No


Copy Code
JSON
// Scalar value
{"name": "Aspect", "values": ["Air pollution control"]}

// Scalar date/time value
{"name": "Start Date", "values": ["2012-09-19T20:00"]}

// Multi-select values
{"name": "Type", "values": ["Spill", "Near Miss"]}

// Linked-list values
{"name": "Category", "values": ["Cat1", "Cat1.1", "Cat1.1.1"]}

// Hyperlink values
{"name": "Google", "values": [{ "label": "Google": "url": "http://www.google.com"]} }
