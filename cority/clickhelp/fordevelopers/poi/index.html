Example: Get POI with specified name and parent Facility.

select

p.ID,

p.Name,

f.Facility

from POI p

join Facility f on p is under f

where

p.name like '%POI%'

Example: List all POIs and their parent objects, excluding the division named 'zTemplate Division'.

select

d.Name as Div,

f.Name as Facility,

u.Name as Unit,

p.Name

from

POI p

join Facility f on p is under f

join Division d on p is under d

join Unit u on p is under u

where d.Name != 'zTemplate Division'

Permissions:  Requires Report permission on the target object. Manage Custom Fields right is required to query CustomFieldTemplate fields. Manage Calculation Templates right is required to query CalculationTemplate fields.
