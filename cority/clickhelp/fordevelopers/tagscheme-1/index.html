tagSchemeInfo 

Represents a Tag Scheme definition.

Name Type Description Required
id string The id string (GUID) for the Tag Scheme. Ignored for: Create Tag Scheme, Update Tag Scheme No
name string Name of the Tag Scheme. Required for: Create Tag Scheme No
description string Description of the Tag Scheme. No
enforce uniqueness integer Numeric value that represents a Tag Scheme uniqueness flag:(0 = no uniqueness, 1 = uniqueness for object, 2 = uniqueness for parent location, 3 = unique for both object and parent location) Required for: Create Tag Scheme No
