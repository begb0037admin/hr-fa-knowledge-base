Workflow Overrides

The bulk tool for Workflow Overrides allows you to edit the Workflow Role Memberships and Workflow Policies applied as overrides to a System Model tree object.

Download the Excel template file with both Role and Policy Overrides included:

Workflow Override Tool

Workflow Role Overrides

Download the Excel template file for Workflow Role Overrides only:

Workflow Role Override Tool

There are four related worksheets:

  • Add Role Overrides: Add Role Overrides for a System Model object.
  • Replace Role Overrides: Replace existing Role Overrides on an object with a new set of associated users/groups.
  • Remove Role Overrides: Remove named users/groups from an existing Role Override.
  • Delete Role Overrides: Delete named Role Override for the object. Columns are Object Path and Role.

The columns are:

Object Path: Path and name of the System Model object to which the override will be applied.

Role: Name of the Workflow Role.

User: List of users to associate with the Role.

Group: List of group names to associate with the Role.

Each user or group should be on a separate row. All changes for that Role will be combined in the update. If an override already exists for the Role, it will be replaced with this set of users/groups. If an override for the Role does not exist, it will be added.

Workflow Policy Overrides

Download the Excel template file for Workflow Policy Overrides only:

Workflow Policy Override Tool

There are three related worksheets:

  • Add Policy Overrides
  • Replace Policy Overrides
  • Delete Policy Overrides

The columns are:

Object Path: Path and name of the System Model object to which the override will be applied.

Workflow Type: Name of the Workflow Type to which the policy override applies.

Policy: Name of the Workflow Policy to associate with the Workflow Type for this System Model object.
