DataViewHistory

Columns

ID DataView ID

EqlName DataView name

EqlText DataView EQL text

Description Description

Metadata Metadata

Title DataView title

Created Modification date

User Composite column to user table for user that performed DataView changes

Example: Get last changes of DataViews.

select

top 10

dvh.User.FirstName,

dvh.EqlName,

dvh.EqlText

from DataViewHistory dvh

order by dvh.Created desc
