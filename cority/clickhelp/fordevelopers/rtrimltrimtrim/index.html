Rtrim

Returns a text after truncating all trailing blanks.

Syntax

RTRIM (text_expression )

Example:

Select

f.id,

RTRIM(f.name)

from Facility f

Ltrim

Returns a text after truncating all leading blanks.

Syntax

LTRIM ( text_expression )

Example:

Select

f.id,

LTRIM(f.name)

from Facility f

Trim

Returns a text after truncating all leading and trailing blanks.

Syntax

TRIM ( text_expression )

Example:

Select

f.id,

TRIM(f.name)

from Facility f
