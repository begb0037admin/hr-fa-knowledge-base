Quick Tips

The following tips may be helpful to someone just starting out.

Developers should be familiar with:

  • Basic HTTP URL syntax
  • Basic file structure; Angular Seed is a good framework if using AngularJS
  • Javascript Style Guidelines
  • Chrome and IE developer tools (F12)

Developers should get familiar with:

  • EMS SDK docs (see the EMS SDK developer docs)
  • EQL syntax and have a copy of the EQL Entity-relationship model (see the EQL docs)

Some libraries that developers should use:

  • jQuery (Required)
  • AngularJS (Preferred but not required)

Libraries or Programs that may be helpful:

  • jQuery-Migrate (Very useful if you need a version of jQuery later than the SDK uses)
  • RequireJS (Useful for loading multiple files; especially helpful for large apps)
  • DateJS (Very useful when dealing with dates and times)
  • ySlow or Google Page Speed (For page optimization)
