Example: Get document information (latest version)

select

d.name,

d.Fullpath,

d.IsFolder,

dv.Kilobytes,

dv.CreatedBy.Email,

d.createdDate,

max(dv.createdon) as LatestCreated,

max(dv.version) as version

from Document d

JOIN DocumentVersion dv on d

group by d.name, d.Fullpath, d.IsFolder, d.createdDate, dv.Kilobytes, dv.CreatedBy.Email

Example: Get document associated with an Event Instance

SELECT

d.Name,

d.EventInstanceID,

ei.DocumentID

from Document d

JOIN EventInstance ei on d

WHERE ei.InstanceId = 'd07d312d-7108-4281-8e15-408a46d2e531'

Example: Get Event Instances and associated documents

SELECT

d.Name,

d.EventInstanceID,

ei.DocumentID

from Document d

JOIN EventInstance ei on ei.DocumentID = d.ID

Permissions:  Requires View permission on the target object or Manage Documents right. Manage Users right is required to query CreatedBy composite columns.
