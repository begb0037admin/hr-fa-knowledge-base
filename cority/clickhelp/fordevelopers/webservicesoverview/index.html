Web Services Overview

To integrate client data sources with the Management System, EMS uses Web Services, a proven method for integrating complex systems cross-platform and cross-language.

Unauthorized use is prohibited. Please contact Customer Service or your Cortiy Sales Representative for further information.

The EMS APIs can be accessed by any application that can send data to Web Services (APIs). If your company already uses another third-party application to send data to Web Services, you can leverage the same infrastructure to send data to EMS.

For a full list and description of the EMS REST APIs see Using the REST API.

If your company does not have an infrastructure or the IT staff does not have the resources to work on the project, then EMS provides an easy-to-install application called EIFL Connector for sending data to EMS.

EMS Web Services are the key to the integration solution, whether you use EIFL or a custom solution. The EMS Web Services are a programming interface (API) to the Management System. They provide a very robust, scalable, and secure (SSL) way to interact with the Management System from another program. With these APIs you can:

  • Integrate to your internal data systems with EMS.
  • Extract EMS data for use with external reporting tools.
  • Integrate EMS data into your organization's portal.
