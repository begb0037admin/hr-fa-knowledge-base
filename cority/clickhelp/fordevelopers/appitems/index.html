EMS App Items

EMS App Items are the files which define the content and behavior of an EMS App. EMS App Items can be just about any type of file.

Items are retrieved from an uploaded EMS App package, and saved for later retrieval.

Each Item is uniquely identified by its path within the EMS App.

Items are given a type, based on their extension, as follows:

  • Page for ".htm" or ".html" files.
  • Script for ".js" files.
  • Style for ".css" files.
  • Image for ".jpg", ".jpeg", ".png", ".gif", ".bmp", ".ico" files.
  • EQL Query for ".eql", ".eqlx" files.
  • Font for ".eot", ".ttf", ".woff" files.

  • Data Object for "*.json" or "*.xml" files other than the manifest.

    Certain JSON files have special treatment as configuration files.

  • Manifest for the manifest file.
  • Unknown for all others.

Each EMS App Item also has a single set of permissions which controls access to the Item.
