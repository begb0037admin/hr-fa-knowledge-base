/{eventLogIdOrTag}/events

POST

Description:

Creates a new Event in the specified Event Log. Events can only be created for manual Event Logs. Attempting to create an Event on an automatic Event Log will result in an error.

Security: All users.

SDK API: envianceSdk.events.createEvent(eventLogIdOrTag, eventInfo, onsuccess, onerror)

Parameters
Name Located in Description Required Schema
eventLogIdOrTag path The id string (GUID) or unique tag of the Event Log. Any string that matches the pattern of a GUID is interpreted as the parent id string, and not the parent tag. A tag string must be URL encoded. Yes string
eventInfo body An eventInfo structure. Yes eventInfo
Responses
Code Description Schema
200 The id string of the new Event. string

DELETE

Description:

Deletes an existing Event. Events can only be deleted from manual Event Logs. Attempting to delete an Event from an automatic Event Log will result in an error. Deletions are permanent.

Security: All users.

SDK API: envianceSdk.events.deleteEvent(eventLogIdOrTag, eventIdOrTag, onsuccess, onerror)

Parameters
Name Located in Description Required Schema
eventLogIdOrTag path The id string (GUID) or unique tag of the Event Log. Any string that matches the pattern of a GUID is interpreted as the parent id string, and not the parent tag. A tag string must be URL encoded. Yes string
eventIdOrTag path The id string (GUID) or unique tag of the Event. Any string that matches the pattern of a GUID is interpreted as the id string, and not the tag. A tag string must be URL encoded. Yes string
Responses
Code Description
204 Event deleted.

Models

eventInfo 

Represents an Event.

Name Type Description Required
id string The id string (GUID) for the Event. Ignored for: Create Event, Update Event No
name string Name of the Event. No
beginDate dateTime The begin date for the Event. Required for: Create Event. Ignored for: Update Event if the Event is an Automatic Event. No
endDate dateTime The end date for the Event. Required for: Create Event. Ignored for: Update Event if the Event is an Automatic Event. No
taskId string The id string for the Task associated with the Event, if there is one. Ignored for: Create Event, Update Event No
state string One of either “Open” or “Closed”. No
complianceType string One of either “Internal” or “Regulatory”. No
acceptAsDeviation boolean A Boolean flag indicating whether or not this Event should be accepted as a compliance deviation. No
requirementIdOrPath string A Compliance Model object id string (GUID) or path, specifying a Requirement to which the Event is associated. Any string that matches the pattern of a GUID is interpreted as an id string, and not a path. Ignored for: Update Event if the Event is an Automatic Event. No
fields [ customFieldValue ] An array of CustomFields, representing the Event Field values for the Event. No
documents [ docPath ] An Array of Document paths, specifying zero or more Documents which are or should be attached to the object. No

customFieldValue 

A set of one or more values for a Custom Field, identified by name.

Name Type Description Required
name string The name (NOT caption) of the Custom Field. No
values string An array with one or more string values, representing the values (one or more) for the Custom Field. Note that even non-string simple values are encoded as strings for custom fields, and are parsed and validated on the server according to the Custom Field type. No
Copy Code
JSON
// Scalar value
{"name": "Aspect", "values": ["Air pollution control"]}

// Scalar date/time value
{"name": "Start Date", "values": ["2012-09-19T20:00"]}

// Multi-select values
{"name": "Type", "values": ["Spill", "Near Miss"]}

// Linked-list values
{"name": "Category", "values": ["Cat1", "Cat1.1", "Cat1.1.1"]}

// Hyperlink values
{"name": "Google", "values": [{ "label": "Google": "url": "http://www.google.com"]} }

docPath 

The hierarchical path to a document as represented by the system model folder structure, beginning with a single forward slash and with elements separated by a single forward slash "/". Does not include the container object (Documents) Example: /Folder1/Subfolder1/Sub-subfolder/DocumentName

Name Type Description Required
docPath string The hierarchical path to a document as represented by the system model folder structure, beginning with a single forward slash and with elements separated by a single forward slash "/". Does not include the container object (Documents) Example: /Folder1/Subfolder1/Sub-subfolder/DocumentName
