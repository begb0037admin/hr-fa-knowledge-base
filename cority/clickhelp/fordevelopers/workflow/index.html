envianceSdk.workflows.createWorkflow

Version 2.0

Other Versions:

Version 1.0

Description

Creates a new instance of the specified Workflow Type, and places it on the "Init" Step. Information about Form Field values and Step Actions (aka Transitions) may optionally be specified in order to update or take action on the Init Step.

Parameters

workflowInfo An instance of the WorkflowInfo object.

initStepInfo An instance of the WorkflowStepInfo object.

Return Value

The id string (GUID) of the new Workflow will be passed to the onsuccess callback in the result property.

Example

envianceSdk.workflows.createWorkflow(workflowInfo, initStepInfo,

function(response) {

alert("Created new workflow with id: " + response.result);

});

envianceSdk.workflows.updateWorkflowStep

Version 2.0

Other Versions:

Version 1.0

Description

Updates one or more values in the Form Fields of an existing Workflow's Step. A Step Action (aka Transition) to invoke may also be specified, which will move the Workflow from the Step to the destination Step of the Step Action.

Parameters

workflowIdOrUniqueId The id string (GUID) of the Workflow, or the unique id of the Workflow. Any string that matches the pattern of a GUID is interpreted as the id string, and not the unique id of the Workflow.

stepIdOrName The id string (GUID) or name of the Step to update. Any string that matches the pattern of a GUID is interpreted as the id string, and not the name of the Step.

stepInfo An instance of the WorkflowStepInfo object with which to update the Step. Some properties of this object are ignored by this function; see details of this object for more info.

Return Value

None

Example

envianceSdk.workflows.updateWorkflowStep(

"2012.08.02.11.11B885AE98DE",

"Record Incident",

stepInfo,

function(response) {

alert("Updated workflow step 'Record Incident'.");

});

envianceSdk.workflows.initiateChildWorkflow

Other Versions:

None

Description

Executes a Workflow Initiator action on the active Step of an existing Workflow, thereby creating a new "child" Workflow, and places the child on its "Init" Step. Information about Form Field values and Step Actions (aka Transitions) may optionally be specified in order to update or take action on the Init Step of the child Workflow.

Parameters

childWorkflowInitiationInfo An instance of the childWorkflowInitiationInfo object with which to update the child Workflow.

Return Value

The id string (GUID) of the new child Workflow will be passed to the onsuccess callback in the result property.

Example

envianceSdk.workflows.initiateChildWorkflow(

"2012.08.02.11.11B885AE98DE",

childWorkflowInitiationInfo,

function(response) {

alert("Created new child workflow with id: " + response.result);

});

envianceSdk.workflows.generateUniqueIds

Version 2.0

Other Versions:

Version 1.0

Description

Gets a requested number of unused Workflow unique ids, using the unique id generation scheme that has been configured for the specified Workflow Type. For generation schemes that use numeric counters, the counter will be incremented for each generated unique id, whether or not the unique id is subsequently used.

Parameters

workflowTypeIdOrName The id string (GUID) or name of the Workflow Type. Any string that matches the pattern of a GUID is interpreted as the id string, and not the name of the Workflow Type.

count Number. The number of unique ids to generate.

Return Value

An array of unique id strings will be passed to the onsuccess callback in the result property.

Example

envianceSdk.workflows.generateUniqueIds("Spill Incident",1,

function(response) {

var uniqueIds = response.result;

alert("First Workflow unique id generated: " + uniqueIds[0]);

});

envianceSdk.workflows.guessPermissions

Version 2.0

Other Versions:

None

Description

For given Workflow Type and optional set of compliance objects, this method returns the permissions for all Roles and their resolved members (users and groups), taking into account Role Overrides. (Answers the question: "When a workflow of this type is created, what users and groups are associated and what are their permissions?")

Parameters

workflowTypeIdOrName The id string (GUID) of the Workflow type, or the unique id of the Workflow type. Any string that matches the pattern of a GUID is interpreted as the id string, and not the unique id of the Workflow.

options:

objects Array. An array of Compliance Model object id strings (GUIDs) or paths, specifying one or more Compliance Model objects to which the Workflow is associated. Any string that matches the pattern of a GUID is interpreted as an id string, and not a path.

version Number. Workflow type version number (optional).

Return Value

Set of read/write fields; set of read only fields; available step actions; available workflow initiators; available workflow actions (i.e. assign, schedule, add comment, etc.); Assignee Role

Example

envianceSdk.workflows.guessPermissions("ddef6b59-6289-41c9-ac7a-ee87a773ce0e",

 

"workflowTypeIdOrName",

{

"objects": ["objectIdOrPath1", "objectIdOrPath2", ...]

,"version":6

},

envianceSdk.workflows.WorkflowInfo

Version 2.0

Other Versions:

None

Description

Constructs a WorkflowInfo object instance in JavaScript.

Parameters

workflowTypeName The name of the Workflow Type.

name The name of the Workflow.

uniqueId The unique id string of the Workflow.

dueDate Date. The due date of the Workflow.

objects Array. An array of Compliance Model object id strings (GUIDs) or paths, specifying zero or more Compliance Model objects to which the Workflow is associated. Any string that matches the pattern of a GUID is interpreted as an id string, and not a path.

documents Array. An array of Document id strings (GUIDs) or paths, specifying zero or more Documents attached to the Workflow. Any string that matches the pattern of a GUID is interpreted as an id string, and not a path.

comment A comment. When retrieving information on an existing Workflow, this value is the current latest comment on the Workflow.

calendars Array. An array of strings listing the types of EMS calendars on which this Workflow is shown. Valid values are "My", "Object", "System".

Return Value

An instance of the WorkflowInfo class.

Instance Methods

addPathAssociatedObject(objectPath) Convenience method to add an object path to the objects array property.

addIdAssociatedObject(objectId) Convenience method to add an object id to the objects Array property.

addUserAssignee(userIdOrName) Convenience method to add a UserAssignee to the assignedTo Array property.

addGroupAssignee(groupIdOrName) Convenience method to add a GroupAssignee to the assignedTo Array property.

addDocument(path) Convenience method to add a Document by path to the documents property.

Example

var workflow = new envianceSdk.workflows.WorkflowInfo(

"Incidents",

"Incident One",

"ABC123",

"2013-09-30T00:00:00",

["/Division A/Facility X", "/Division A/Facility B"],

["/Folder 1/File.xls"],

"A new incident has occurred on the tank.",

["My", "Object"]

);

workflow.addUserAssignee("jsmith").addGroupAssignee("Administrators");
