SubmitNumericDataBatch

This method allows users to submit a batch of data points, with or without Data Quality Template (DQT) values. The method returns a BatchID. The BatchID is used by the GetBatchStatus method.

The method accepts the following additional Boolean parameters:

partialProcess

If this parameter is “true” then the batch will succeed even if there are some invalid Data Points in the batch.

If all Data Points in the batch are invalid, then Batch will fail.

If this parameter is “false” then the batch will fail if any invalid data points are found.

autoResubmit

This parameter indicates if the batch will be re-submitted automatically if failed.

Warning: Use this parameter with caution. If set to “true” the execution order of batches may change. For example, batches 1, 2, 3 are submitted. Batch 1 succeeds, batch 2 fails, and batch 3 succeeds. Batch 2 is re-submitted and succeeds. As a result, batches are executed out of order: 1, 3, 2.

Also note that if there are failed rows in “partial batch processing” mode, such batch is considered successful and auto-resubmit will not happen.

SubmitNumericDataBatchbyTag

This method allows users to submit a batch of data points identified by its Tag, with or without Data Quality Template (DQT) values. The method returns a BatchID. The BatchID is used by the GetBatchStatus method.

GetBatchStatus

Using this method with the BatchID, it is possible to discover the status of your data batch as it moves through the EMS command log. Statuses are: Waiting, Processing, Succeeded, Failed, Resubmitted, Delayed.

Also returns the ProcessMode, which indicates which mode the batch was submitted with.

GetInvalidBatchData

Returns an array of records for a given BatchID that identifies invalid data points in a batch and describes the reason for failure.

InvalidBatchData class contains the member DataDetails, which gives the Tag, Complete Date and Value for failed data points. DataDetails is an abstract type in order to support information for errors for other batch types than Data Point. When the batch is of the type Data Point, the concrete instance type is NumericDataPointValues.

InvalidBatchData.Error contains a text description of the error.

GetBatchStatusesByDateRange

This method takes a date range and returns all batch statuses in that range. (See GetBatchStatus.)

DeleteNumericData

This method deletes all data points for a given tag and date range. It returns a BatchID.

SubmitNonNumericDataBatch

https://webservices.enviance.com/2010/DataService.asmx

https://webservices.enviance.com/2010/DataService.wsdl

This method sends in a batch of Non Numeric data points to a Non Numeric Requirement. The expected inputs are: RequirementID of the target Non Numeric Requirement, Collector, Comply Status, Comments (required on Comply Status 'YesWithComments'), Completion Date, Compliance Begin Date and Compliance End Date. RequirementID can be a PathID (path to the object without the System Name, but with the actual object name included), GUIDID or TagID. A batchID is returned.
