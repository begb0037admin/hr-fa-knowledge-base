enviancesdk.activities.createActivity

Version 2.0

Other Versions:

None

Description

Creates a new Activity.

Parameters

activityInfo An instance of the activityInfo object. Some properties of this object are ignored by this function; see details of this object for more info.

Return Value

The id for the new Activity.

Example

envianceSdk.activities.createActivity (activityInfo, onsuccess, onerror)

enviancesdk.activities.copyActivity

Version 2.0

Other Versions:

None

Description

Creates a new Activity by copying an existing Activity.

Parameters

activityInfo Optional information to set properties of new Activity. An instance of the activityInfo object.

copyFrom The id string (GUID) of an existing Activity whose properties will be copied and used as the properties of the newly created Activity.

Return Value

The id for the new Activity.

Example

envianceSdk.activities.copyActivity (activityInfo, copyFrom, onsuccess, onerror)

enviancesdk.activities.updateActivity

Version 2.0

Other Versions:

None

Description

Updates an Activity.

Parameters

activityIdOrName Either an id string (GUID), or a name string uniquely identifying the Activity. Any string that matches the pattern of a GUID is interpreted as the id string, and not the name of the Activity. A name string must be URL encoded.

activityInfo An instance of the activityInfo object. Some properties of this object are ignored by this function; see details of this object for more info.

Return Value

None

Example

envianceSdk.activities.updateActivity (activityIdOrName, activityInfo, onsuccess, onerror)

envianceSdk.activities.activityInfo

Description

Represents an Activity definition.

Properties

id The id string (GUID) for the object.
Ignored for: Create Activity, Update Activity

name The name of the Activity.
Required for:Create Activity

description The description of the Activity.

templateIdOrName An id string (GUID) or name of a Custom Field Template. Any string that matches the pattern of a GUID is interpreted as an id string, and not a name.
Ignored for: Update Activity

properties An array of activityPropertyMapInfo.
Required for: Create Activity 

fields An array of Custom Field Values.

Example

envianceSdk.activities.ActivityInfo (name, description, templateIdOrName, fields, properties)

envianceSdk.activities.activityPropertyMapInfo

Description

Represents an Activity ValueBasedProperty definition.

Properties

propertyIdOrName An id string (GUID) or name of a Material Property.
Required for: Create Activity

valueHistory An array with one or more materialValueHistoryItem.
Required for: Create Activity

Example: Property without history (SUV)

envianceSdk.activities.ActivityPropertyMapInfo ("9cc07086-590f-4d2c-a8bb-6eda2ed48eba")

envianceSdk.activities.ActivityPropertyMapInfo (propertyIdOrName, valueHistory)

envianceSdk.activities.materialValueHistoryInfo

Description

Represents a single History Item definition.

Properties

id The id string (GUID) of the History Item record.
Ignored for: Create Activity

beginDate Date. A DateTime value, representing begin date for the Item.

endDate Date. A DateTime value, representing end date for the Item.

value Numeric or Boolean value for the Item. (Boolean values represented by "0" and "1" values)

Example

envianceSdk.activities.MaterialValueHistoryInfo (beginDate, value)

 

{

"beginDate": "2012-01-01T00:15",

"endDate": "2013-01-01T00:15",

"value": "123"

}
