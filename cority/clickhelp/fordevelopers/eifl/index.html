EIFL Connector

The Management System allows customers to customize, integrate and extend the Management System using standards-based Web services and market-leading development tools.

For most standard integration needs, customers can use EMS's out-of-the box integration tool EIFL Connector, a Windows-based tool which can be installed behind the firewall on the customer's own network. Customers who need a dedicated, enterprise approach may set up a custom integration solution using EMS Web Services.

EIFL Connector is a client-side software package run on the customer's own network that provides the following functionality:

  • Robust and secure integration to EMS
  • Pluggable architecture to simplify your integration projects
  • Queued messages for reliability and throttling
  • Error logging and notification

EIFL Connector provides a .NET library of re-usable functionality that can be configured for multiple data integration scenarios.

EIFL Connector accepts several different types of input, including:

  • File (xls, xlsx, csv, txt, xml, mdb)
  • SQL Database
  • EMS via APIs

Outputs include:

  • File (xls, xlsx, csv, txt, xml, mdb)
  • SQL Database
  • EMS via APIs

Once EIFL has been deployed and configured for your system, it can be run by two methods:

  • Run EIFL on demand by clicking on the executable.
  • Use Windows task scheduler to set up an automatic run schedule.

Error logs are retained for review. EIFL Connector can also be configured to be send error logs automatically by email.
