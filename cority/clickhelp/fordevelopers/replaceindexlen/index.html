Replace

Replaces all occurrences of a specified text value with another text value.

Syntax

REPLACE ( expression, pattern, replacement )

Example:

Select

f.id,

REPLACE(f.name,'pattern','new text')

from Facility f

Index

Searches an expression for another expression and returns its starting position if found. If expression not found, return 0 . If either expression is null, return null. Return start position is 1 based.

Syntax

INDEX ( expressionToFind ,expressionToSearch [, start_location (optional) ] )

Example:

Select

f.ID,

INDEX('partial name',f.name)

from Facility f

Len

Returns the number of characters of the specified text expression, excluding trailing blanks.

Syntax

LEN (expression )

Example:

Select

f.ID,

LEN(f.name)

from Facility f
