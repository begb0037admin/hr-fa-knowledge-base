envianceSdk.getSessionId

Version 2.0

Other Versions:

Version 1.0

Description

This function retrieves the current saved session id for the User.

Parameters

None

Return Value

Current user's session id

Example

var sessionId = envianceSdk.getSessionId();

envianceSdk.setSessionId

Version 2.0

Other Versions:

Version 1.0

Description

This function saves the User's session id, for subsequent use in other SDK functions that call the EMS APIs.

Typically, you will not call this function directly, unless you have manually authenticated the User and have a new session id. Note that envianceSdk.authentication.authenticate calls this function automatically for you to save the resulting session id.

Parameters

sessionId The session id string.

Return Value

None

Example

envianceSdk.setSessionId("68f5e005-e060-4699-8741-a80d8b788189");

envianceSdk.utilities.uri.toDocumentDownload

Version 2.0

Other Versions:

Version 1.0

Description

This function creates the URI to download a Document which has been uploaded to the Management System.

Parameters

documentIdOrPath The id string (GUID) or path for a Document in the Management System. Any string that matches the pattern of a GUID is interpreted as the id string, and not the path of the Document.

Return Value

The URI.

Example

var uri = envianceSdk.utilities.uri.toDocumentDownload("/Checklists/Checklist1.xls");

window.open(uri, "Document Download");

envianceSdk.utilities.uri.toQuickLink

Version 2.0

Other Versions:

Version 1.0

Description

This function creates the URI to a Quick Link which has been configured in the Management System. Unlike envianceSdk.packages.utilities.uri.toQuickLink, this function will return the URI to load the Quick Link in the content frame of the Management System.

Parameters

id The id string (GUID) for a Quick Link in the Management System.

Return Value

The URI

Example

var uri = envianceSdk.utility.uri.toQuickLink("67fed526-4787-4fed-9627-32cd01a44c32");

envianceSdk.utilities.uri.gotoUrl(uri);
