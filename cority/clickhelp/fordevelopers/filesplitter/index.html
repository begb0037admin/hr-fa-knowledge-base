File Splitter

The Prepare Upload Files tool is designed to split large Excel upload files into smaller files for upload and processing.

Size guidelines for each job vary depending on the tool. It is recommended that each job (file) not run more than 1 hour. Testing in the Sandbox environment will help determine the maximum size of your job files.

Download the Excel tool:

Prepare Upload Files Tool

To use the tool:

  1. Open the Prepare Upload Files tool in Excel. Enable macros, if they have been disabled by your security settings.
  2. Open the job file you have prepared for uploading to the system.

  3. Select and copy all the data from your job file to a new worksheet in the Prepare Upload Files tool. Include the column head in your copy and paste operation. The tool assumes that the first line in the file is the column labels.

    Use separate worksheets for each worksheet in your job file. Name each worksheet to match the name of the operation, as shown in the first column on the default worksheet. For example, if you are going to be copying objects, the worksheet will be named "Copy Objects."

    Note:  Select and copy the data cells, NOT the worksheet. If you copy the worksheet, Excel will truncate cell contents to 255 characters.

  1. In cell D1 (row 1, column 4) on the PrepareUploadFiles worksheet, enter the name of the worksheet to process.

  1. Click the Prepare Upload Files button.
  2. Select OK, then follow the instructions in each dialog.
  3. Select Yes to start the operation.
  4. If files are for Sandbox testing, select No. If you are generating files for Production upload (after all testing is complete), select Yes.
  5. Enter Customer name.
  6. Enter number of lines to be contained in each file. The number of lines per files will depend on the extent of the edits and the length of time it takes to run each file, which should be no more than one hour. The number of files that can be created at one time is limited to 35.
  7. Enter a short description.
  8. Click OK.

After the files are generated, the tool tells you where the files are located. This will be a subfolder of the folder in which the tool is located.
