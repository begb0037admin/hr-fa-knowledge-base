Package Local Script

The EMS App SDK supports the use of a "local" script to allow for functionality to be replaced when an EMS App is running outside of the Management System.

The local script should be a JavaScript file with the name "package.local.js", placed in the same directory as the display page of the App.

When hosted within the Management System, this file is always ignored by the EMS App SDK and has no effect on behavior.

However, when an EMS App is being run outside of the Management System (for instance, within a development environment), this file is executed by the SDK on initialization if the option "enablePackageLocalScript" is set to true (the default is false).

The following variables and objects can be replaced in the local configuration script:

packageId An EMS App ID obtained from the Management System by creating a new EMS App in the EMS App Manager.

envianceSdk.packages.appData An optional javascript object which will be used to handle app data requests instead of the EMS App runtime.

The object specified can override the following methods:

get

set

del

envianceSdk.packages.userData An optional javascript object which will be used to handle user data requests instead of the EMS App runtime.

The object specified can override the following methods:

get

set

del

envianceSdk.packages.user A javascript object which will be used to handle authentication and authorization calls instead of the EMS App runtime.

The object specified can override the following methods:

authenticate

hasAccessTo

isInRole

availableRoles

Also, the following event handlers can be used to execute code at different points during the init() function execution of the EMS App SDK:

envianceSdk.packages.configStarting This event is called just before the configuration options (either specified in the call to init() or placed in the package.cfg file) are used to set behavior of the SDK. The loaded options are passed as the single parameter to the event handler, such that options can be conditionally changed during this event. The following is an example of setting an event handler for this event:

envianceSdk.packages.configStarting.add( function(options) { ...; } );

envianceSdk.packages.configComplete This event is called just after the configuration options have been used to set behavior of the SDK. The following is an example of setting an event handler for this event:

envianceSdk.packages.configComplete.add( function(options) { ...; } );
