enviancesdk.materialData.enterMaterialData

Version 2.0

Other Versions:

None

Description

Processes a set of one or more Material Data Line Groups.

Parameters

mdlGroupsInfo A mdlGroupInfo data structure.

partialProcess Boolean. True/false flag to choose the validation mode strategy. "True" allows saves a detailed message for each MDL group record in the command log. "False" throws exceptions, generates a detailed error message for batch records and returns it to the client, and does not save partially valid batch MDLGroups to DB.

Return Value

The id for the queued command.

Example

envianceSdk.materialData.enterMaterialDataAsync (mdlGroupsInfo, partialProcess, onsuccess, onerror)

enviancesdk.materialData.getMaterialData

Version 2.0

Other Versions:

None

Description

Gets information about Material Data Line Groups.

Parameters

activityIdOrNameOrUniqueTag An id string (GUID) or a name string or the Unique Tag uniquely identifying the Activity. Any string that matches the pattern of a GUID is interpreted as the id string and not the name of the Activity. A name string must be URL encoded.

completeBegin Date. Begin range date and time value for MDLGroup.

completeEnd Date. End range date and time value for MDLGroup. Parameter completeDate uniquely identifies an MDLGroup in a MAC.

locationIdOrPath Either an id string (GUID) or a path string uniquely identifying the Location object in the Compliance Model. Any string that matches the pattern of a GUID is interpreted as the id string and not the path of the Location. A path string must be URL encoded.

Return Value

An array of mdlGroupInfo.

Example

envianceSdk.materialData.getMaterialData (activityIdOrNameOrUniqueTag, completeBegin, completeEnd, locationIdOrPath, onsuccess, onerror)

enviancesdk.materialData.deleteMaterialData

Version 2.0

Other Versions:

None

Description

Deletes Material Data Line Groups.

Parameters

locationIdOrPath Either an id string (GUID) or a path string uniquely identifying the Location object in the Compliance Model. Any string that matches the pattern of a GUID is interpreted as the id string and not the path of the Location. A path string must be URL encoded.

mdlGroupIds Array. An array of MDLGroup id strings (GUIDs).

waitForCompletion  Boolean. True/false value indicating whether system should wait for processing to complete before returning response.

Return Value

The id for the queued command.

Notes

Deleting Material Data Line Groups is an asynchronous process. Upon successfully receiving and queueing the data, a command id is returned. With this command id, envianceSdk.commands.getCommand can be used to track completion or failure of the data entry command.

Deletions are permanent.

Example

envianceSdk.materialData.deleteMaterialDataAsync (locationIdOrPath, mdlGroupIds, waitForCompletion, onsuccess, onerror)

envianceSdk.materialData.MdlGroupInfo

Description

A numeric measurement for a single MDLGroup with set of Data Lines. A MDLGroup is tied to the location, activity and a single date and time.

Properties

parentIdOrPath Either an id string (GUID), or a path string uniquely identifying the Location object in the Compliance Model. Any string that matches the pattern of a GUID is interpreted as the id string, and not the path of the Location. A path string must be URL encoded.

activityIdOrNameOrUniqueTag An id string (GUID) or a name string or the Unique Tag uniquely identifying the Activity. Any string that matches the pattern of a GUID is interpreted as an id string, and not a name.

complete Date. A date and time value, complete is uniquely identifying an MDLGroup in the MAC.

collector Name of user entering data.

dataLines Array. Array of materialDataLinesInfo.

Example

"complete": "2015-05-29T00:00:00",

"collector": "Create MdlG-Happy path",

"dataLines": [{

"materialIdOrName": "Material 1 for MDLG",

"startTime": "2015-05-27T00:00:00",

"endTime": "2015-05-28T00:00:00",

"data": [

{"propertyIdOrName": "SUV10", "value": "1" },

envianceSdk.materialData.materialDataInfo

Description

A set of one or more values for a Specific Use Variables, identified by name. SUV's tied to the one of Activities from MAC.

Properties

propertyIdOrName The name (not caption) of the SUV

value Number. A floating point numeric value. Both standard and scientific notation are valid formats.

Example

envianceSdk.materialData.MaterialDataInfo (dataLineId, propertyIdOrName, value)

 

{

"propertyIdOrName": "SUV10",

"value": "1"

}
