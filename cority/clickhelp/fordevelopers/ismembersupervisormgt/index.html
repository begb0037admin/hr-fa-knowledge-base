IsMember

This function will return TRUE for any given workflow instance if the calling user resolves to any of the supplied roles for the workflow instance.

Syntax

IsMember(WorkflowInstanceID, text_expression [,text_expression])

WorkflowInstanceID is the WorkflowInstance to be checked.

text_expression Name of workflow role

Example:

select

wi.ID, wi.Name

from WorkflowInstance wi

where

IsMember(wi.ID, 'Creator', 'Assignee') = 'true'

IsSupervisor

Note: The 'IsSupervisor' function is only available for the Management System EQL.

This function will return TRUE for any given workflow instance if the calling user is listed as the direct Supervisor on the user profile of any user that resolves to any of the supplied roles for the workflow instance.

Syntax

IsSupervisor(WorkflowInstanceID, text_expression [,text_expression])

WorkflowInstanceID is the WorkflowInstance to be checked.

text_expression Name of workflow role

Example:

select

wi.ID, wi.Name

from WorkflowInstance wi

where

IsSupervisor(wi.ID, 'Creator', 'Assignee') = 'true'

IsManagement

Note: The 'IsManagement' function is only available for the Management System EQL.

This function will return TRUE for any given workflow instance if the calling user is UP the "chain of command" based on the user profile of any user that resolves to any of the supplied roles for the workflow instance.

Syntax

IsManagement(WorkflowInstanceID, text_expression [,text_expression])

WorkflowInstanceID is the WorkflowInstance to be checked.

text_expression Name of workflow role

Example:

select

wi.ID, wi.Name

from WorkflowInstance wi

where

IsManagement(wi.ID, 'Creator', 'Assignee') = 'true'
