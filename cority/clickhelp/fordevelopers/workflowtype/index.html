envianceSdk.workflows.WorkflowTypeInfo

Description

Represents a Workflow Type definition.

Properties

idOrName The id string (GUID) for the object. Ignored for: Create Workflow Type, Update Workflow Type

newName New name of the workflow type. Optional. Update operations only, used for re-name.

description The description of the Workflow Type. Optional.

shouldCreateNewVersion Boolean. True for create new version of Workflow Type, False for update the old version. Update operations only. Optional.

versionComments Comments for workflow type version. Optional.

idGenScheme The id string (GUID) for the generating scheme. Optional. If not specified or empty it uses default value.

isUsedForConfig Boolean. Is used for App configuration (true/false)

/*WorkflowStepInfo*/workflowSteps Array of WorkflowStepInfo structure. Optional for Partial Update operation.

/*StepRoleInfo*/stepRoles Array of Roles used in Steps and predefined role Workflow Manager. Optional. A RoleInfo structure.

otherRoles Any roles Not used in Steps or not any predefined Role. Optional. A RoleInfo structure.

localFields Array of Id or Name of local UDFields from Form Templates. Optional. All fields are Global by default.

globalFields Array of Id or Name of UDFields are changed to global. Optional. Partial Update operation only.

/*WorkflowPermissionInfo*/workflowPermissionss Array of workflowPermissionsInfo. Optional.

/*StepPermissionInfo*/stepPermissions Array of workflowStepPermissionsInfo. Optional.

policies Array of Id or Name of removed policies. Optional. Partial Update operation only.
