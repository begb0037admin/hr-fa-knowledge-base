Natural Joins

ComplianceObject

Example: Get users who have the View, Enter and Edit Data permissions on compliance objects.

select

co.Name,

co.Path,

p.User.FirstName,

p.User.LastName

from ComplianceObject co

join ComplianceObjectPermission p on co

where p.Access.ViewEnterEditData=1

and co.Name like 'Audit Protocols'

order by p.User.LastName

Permissions:  Requires Report permission on the target object.

Note:  The Access... properties relate to the permissions that are assigned to objects in the system model, as seen in the UI:



The Permission... properties are more granular permissions, which are a superset of the user-facing permissions. In most cases you will want to use the Access... properties in your queries.
