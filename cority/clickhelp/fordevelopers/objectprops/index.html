Object Properties Tool

The Object Properties Editing Tool is used to assign property values to existing objects in the system. You can run it after creating objects with the Object Copy Tool to assign property values for the new objects, or to edit properties for any existing System Model objects.

Preparation

Create the objects first, using the Object Copy Tool, if necessary. Determine the number and type of properties to be edited.

If custom fields are required for the objects, create the custom fields and Custom Field Templates and associate them with the objects. Note: There is no bulk tool for creating custom fields and templates. However once the fields and custom field template(s) are created, you can use the Template Edit Tool to associate objects with templates using the template bulk tool.

These templates are available, depending on the types of properties you want to edit:

  • Object Properties Editing Tool - Simple Properties
  • Object Properties Editing Tool - Complex Properties 
  • Object Properties Editing Tool - Monitored Requirements 
  • Object Names Localization

Simple properties are single property fields with one-to-one property-value associations. Complex properties are those that involve multiple related fields—for example, Data Collection/Sampling Frequency on a parameter has two fields, one for numerical value and one for the time period (hour, day, week, month).

The Monitored Requirements tool can be used to edit just the "Monitored Requirement(s)" field for Event Logs. It allows you to enter one requirement per row, rather than including all requirements on the same line (as required on the other tools).

Note:  Property names are not case-sensitive.

Tip:  Grouping the same properties in a job file will get the best results from the Object Properties tool. You may group the properties by type—simple fields vs. complex fields—and use the appropriate tool if only a few properties are being edited per object. However if many properties are being edited for the same objects then all properties (both simple and complex) for the objects should be included in the same job file. You can edit both simple and complex properties on the complex properties template, or on separate worksheets in the same file.

Blank values in a property value field are ignored and existing property values in the system will not be changed. 

To delete an existing value for a field, enter <clear> in the value column.

Excluded Fields

The following types of fields cannot be edited with the Object Properties Editing Tool:

  • ID Control
  • Hyperlink field types other than Default URL
  • Label
  • Time zone updates
  • Parent object update (i.e., cannot move objects by editing parent object path)
  • Valid range limits

For the following types of fields, use the Calculations Edit Tool:

  • Calculated Numeric
  • Number fields of type Numeric Lookup

    Note: When a field of this type is on the custom field template, then use the Object Properties Editing - Complex Properties tool and load the alias value (not the numeric value) in the appropriate column.

  • Calculation Template fields
  • Fields that trigger calculations (includes limits, scripts, calculated UDFs)
