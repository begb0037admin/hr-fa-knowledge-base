Add Task Exception

You can create a task exception for a recurrent task whenever a single instance of the task needs to be changed. When you create a task exception, the original task instance gets "dismissed" status. A new single-instance task is created. In the main app, the new task has the same name as the original task plus the suffix "(exception)".

The properties on the Add Task Exception sheet correspond to the properties on the New Task Exception form (same as Task Properties General tab).

Task Name: Name of task

Task Description: Description (text)

Show in Options (My Calendar/Object Calendar/System Calendar): Yes/No

Task Due Date: Date: Due date of new "exception" task. Due date in ID field, column C, must be the date of the instance for which you want to create the exception.

Task Due Date: Time: Time of new "exception" task.

Task Time Zone: May be changed for new "exception" task, although this is not likely. Leave blank to keep same time zone.

Task Assignor: User: Username of assignor.

Task Assignee(s): User (s): Assignee username (not First/Last). In the case of more than one user assignee, separate usernames with "|" character. Example:

Username1 | Username2

Task Assignee(s): User Group(s): Group Name. In the case of more than one assignee group, separate group names with "|" character. Example:

Group1 | Group2
