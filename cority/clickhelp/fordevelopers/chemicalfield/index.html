ChemicalField

Columns

ID Chemical Meteo Field identifier

FieldCode Field Code

FieldName Encoded Field Name

FieldUnit Encoded Field Unit

FieldType Text, Field Type(Numeric, Boolean or Standard

Natural Joins

None

Example: Get all ChemicalField used in MaterialScript

select

cf.ID

from MaterialScript s

join MaterialScriptDependency d on s.id = d.MaterialScriptID

join ChemicalField cf on cf.id = d.ChemicalFieldID

where d.ChemicalFieldID is not null

Permissions:  Manage Materials and Activities right is required to query this table.
