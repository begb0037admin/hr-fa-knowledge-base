Sandbox Testing

Execute all bulk uploads first in the Sandbox environment before scheduling them for execution on Production. You will be able to find and correct any errors in your files from Sandbox testing, before performing the updates in the Production system.

Access your EMS Sandbox system at: https://go-sandbox.enviance.com

Use your production system login with ".sb" appended to it. (Example: If your production login is "rkramer@anycompany.com" your login to sandbox will be "rkramer@anycompany.com.sb".)

The tools are run from the System Admin Tools web site at: https://bulktools-sandbox.enviance.com

Login user must be in the Administrators group for the system (with ".sb" appended to the user id, as noted above).

After logging into the System Admin Tools, you can upload your job file(s) to the system. After the file is posted, the tool processes the instructions contained in the file. Click the Batch Status tab to monitor the progress, check status and access error logs. View and check the results in the EMS Sandbox system.

New Sandbox users may need to request that their system model be copied to the Sandbox environment. You may also need to request a refresh of your system if the version on Sandbox is old. Please allow 24 hours for your system to become available or to be refreshed.
