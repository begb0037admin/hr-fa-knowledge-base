Example: Get the list of custom roles, the default group associated with the role, and a list of any facility overrides.

select

r.Name,

r.Group.Name,

r.OverrideGroup.Name,

f.Name as Facility

from WorkflowRole r

join Facility f on r.OverrideGroup

where r.Roletype=0

Permissions:  Manage Workflows right is required to query this table. Manage Groups right is also required to query OverrideGroup fields. Manage Users right is also required to query OverrideUser fields.
