envianceSdk.common.configureFileInput

Version 2.0

Other Versions:

None

Description

Creates a file upload control that uses either the FileReader API or Flash for older browsers, in order to return the file content directly to JavaScript code as Base64 encoded data.

Parameters

fileObjectId The id to be used for a generated file upload control.

onchanged The event handler that will be called if the User chooses a file with the file input control.

Return Value

None

Notes

The onchanged callback will be called with the following parameters:

fileObjectId The id of the generated file input control.

fileName The name of the chosen file.

fileContent The Base64 encoded content of the chosen file.
