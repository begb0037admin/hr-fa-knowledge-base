ReportExecuteLog

Columns

Created Date Created

Updated Date updated

Status ReportExecuteLog Status

Priority Report Priority

ErrorMessage Report Error Message

Started Report Started

Finished Report Finished

SendNotification Indicates if user gets notified upon report completion

IsDataOutput Indicating if report output format is data output

ExecutedByScheduler Indicating if report was triggered by Scheduler

ExecutionMessage Potential error message generated during execution phase

ExecutionStarted Representing report execution phase start date

ExecutionFinished Representing report execution phase finish date

ExecutionFileSize File size of intermediate file

FormattingStarted Representing report formatting phase start date

FormattingFinished Representing report formatting phase finish date

FormattingMessage Potential error message generated during formatting phase

FormattingFileSize File size of output file

FormattingFormat Output file format (html, Excel, Excel template)

User.ID, User.Name Composite column to User table (includes all fields from User)

Report.ID, Report.Name Composite column to Report table (includes all fields from Report)

Example:

select

r.name,

-- path r.Created,

-- Updated r.IsFolder,

rl.User.FirstName,

rl.User.LastName,

rl.User.Email,

rv.LastRun,

rl.ExecutedByScheduler,

max(rv.Version) as latestversion,

max (rl.Created ) as latestexecution from Report r

join ReportVersion rv on r join ReportExecuteLog rl on r

group by r.name, r.Created, r.IsFolder, rv.LastRun, rl.ExecutedByScheduler, rl.User.FirstName, rl.User.LastName, rl.User.Email

Permissions:  Requires Report permission on the target object or Manage Reports right.
