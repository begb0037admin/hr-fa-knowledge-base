TaskTemplateNotification

Columns

Comments Task Notification Comments

AssigneeNotify Indication if notification is sent to Assignee

AssignorNotify Indication if notification is sent to Assignor

OtherNotify Indication if notification is sent to Others

EmailDelivery Indicating if notification is delivered via email

InboxDelivery Indicating if notification is delivered via inbox

TimeToNotify The time to notify

UserNotify.ID, UserNotify.FirstName, ... Notify User. Composite column to User table (includes all fields from User)

GroupNotify.ID, GroupNotify.Name, ... Notify Group. Composite column to Group table (includes all fields from Group)

UsersNotify.ID, UsersNotify.FirstName, ... Notify Users. Composite column to User table (includes all fields from User)

NotificationTemplateId ID of Task Notification Template

Natural Joins

TaskTemplate

Example: Get notification schedule for Task Templates

select

tt.Name,

ttn.TimeToNotify,

ttn.AssigneeNotify,

ttn.AssignorNotify,

ttn.OtherNotify,

ttn.UserNotify.FirstName,

ttn.UserNotify.LastName

from TaskTemplate tt

join TaskTemplateNotification ttn on tt

order by tt.Name

Permissions:  Manage Tasks right is required to query this table. Manage Users right is also required to query UsersNotify and UserNotify fields. Manage Groups right is also required to query GroupNotify fields.
