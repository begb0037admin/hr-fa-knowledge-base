Managing EMS Apps

To manage (create, edit, update, delete, etc.) EMS Apps in the Management System, you must have the Right "Manage Enviance Apps".

To configure and manage EMS Apps from the Management System, EMS Apps Manager must be enabled for the system. When EMS Apps Manager is disabled, it is not available in the application, regardless of user rights. However, disabling management does not disable the use of any Apps configured for the System.

In EMS Apps Manager you can:

  • Upload a new EMS App package (see Package Upload).
  • Copy an existing EMS App package.
  • Create an empty EMS App in order to generate a GUID to be used in app development. The app ID is shown as part of the Link url on the General tab. You can then copy this ID to use in App development. An index file is created as an empty .htm file, which may be edited or replaced in development.
  • Preview an App using the Run button on the View page (see Running EMS Apps).
  • View the permissions granted to the EMS App Roles. Permissions are assigned to App Roles from the package contents and cannot be edited from EMS App Manager.

Providing an App is not locked, you may also edit an existing EMS App in the following ways:

  • Update an App by uploading a new package (see Package Upload).
  • Map User Groups to Roles (see App Roles).
  • Edit the display page (the default page displayed on running the app from the custom tab).
  • Select an icon to associate with the App.
  • Delete an EMS App.
