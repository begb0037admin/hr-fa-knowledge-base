enviancesdk.chemicalgroups.createChemicalGroup

Version 2.0

Other Versions:

None

Description

Creates a new Chemical Group.

Parameters

chemicalGroupInfo An instance of the chemicalGroupInfo object.

Return Value

The id for the new Chemical Group.

Example

envianceSdk.chemicalgroups.createChemicalGroup (chemicalGroupInfo, onsuccess, onerror)

enviancesdk.chemicalgroups.copyChemicalGroup

Version 2.0

Other Versions:

None

Description

Creates a new Chemical Group by copying an existing Chemical Group.

Parameters

chemicalGroupInfo Optional information to set properties of new Chemical Group. An instance of the chemicalGroupInfo object.

copyFrom Either an id string (GUID) or name string of the Chemical Group to copy. Specifying this property allows you to copy an existing Chemical Group to another Chemical Group.

Return Value

The id for the new Chemical Group.

Example

envianceSdk.chemicalgroups.copyChemicalGroup (chemicalGroupInfo, copyFrom, onsuccess, onerror)

enviancesdk.chemicalgroups.updateChemicalGroup

Version 2.0

Other Versions:

None

Description

Updates a Chemical Group.

Parameters

chemicalGroupIdOrName Either an id string (GUID) or a name string uniquely identifying the Chemical Group. Any string that matches the pattern of a GUID is interpreted as the id string, and not the name of the Chemical Group. A name string must be URL encoded.

chemicalGroupInfo An instance of the chemicalGroupInfo object.

Return Value

None

Example

envianceSdk.chemicalgroups.updateChemicalGroup (chemicalGroupIdOrName, chemicalGroupInfo, onsuccess, onerror)

envianceSdk.chemicalgroups.chemicalGroupInfo

Description

Represents a Chemical Group.

Properties

id The id string (GUID) for the Chemical Group.
Ignored for: Create Chemical Group, Update Chemical Group

name The name of the Chemical Group.
Required for: Create Chemical Group

description The description of the Chemical Group.

chemicals Array. An array of Chemical id strings (GUIDs) or aliases.
Required for: Create Chemical Group

Example

envianceSdk.chemicalgroups.ChemicalGroupInfo (name, description, chemicals)
