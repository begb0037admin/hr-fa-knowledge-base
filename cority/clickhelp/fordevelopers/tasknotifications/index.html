Add/Edit/Delete Notification

The fields on the Add Notification, Edit Notification and Delete Notification worksheets correspond to the fields on the Notifications tab of Task Properties.

On the Edit Notification and Delete Notification sheets, in addition to identifying the task to edit (columns A-F), you must identify the notification to edit in the required ID fields in columns G-U. All ID values must exactly match the notification in the system.

For the Edit Notification sheet, identify the existing notification in the first set of ID fields, then use the second set of corresponding fields (columns V-AJ) to make your changes. Use one row for each unique notification.

Editable fields are:

Time to Notify: Immediately: Yes/No

Time to Notify: By Due Date (number): Number of days, weeks, etc.

Time to Notify: By Due Date (duration): 1/4 Hour | Day(s) | Week(s) | Month(s) | Year(s)

Time to Notify: By Due Date (before/after): Relative to due date

Time to Notify: On Past Due: Yes/No.
