GetTree

This method returns the system tree or a subset of the system tree as an XML structure. The properties returned are: Object Name, Object Tag, Parent Tag, and Object Type.

CopyTreeObject

Copies one tree object to a specific location on EMS customer system. It is an asynchronous operation, full batch process. It includes all children by default.

GetBatchStatus

Using this method with the BatchID, it is possible to discover the status of your data batch as it moves through the EMS command log. Statuses are: Waiting, Processing, Succeeded, Failed, Resubmitted, or Delayed.

Also returns the ProcessMode, which indicates which mode the batch was submitted with.

GetComplianceObject

This method returns detailed information on a specific system object. The input value is a unique tag and the returned values are Object Name, Object Tag, Parent Tag, Object Type, Native Fields, Custom Field Name, Value, Begin and End Dates.

CheckTagsExist

This method is for checking whether any of the unique tags in a list of unique tags exist in the system model. The return value is the set of all non-existent tags.

GetSystems

Some users can have access to multiple systems. This method allows you to discover the name and unique EMS identifier for each system that a user has access to.

GetCurrentSystemID

Returns System identifier of the system associated with current user session.

GetDescendants

Returns all child objects of a given source object. Input is:

  • rootObjectID: Start point
  • Level: how many levels deep into the three to look for descendents.

Search

Returns a list of objects based on a search criteria. Input is:

  • Type: Type of the object to search for. Can be one of the following:

    Undefined

    System

    Division

    Facility

    Unit

    POI

  • NumericRequirement
  • NonNumericRequirement
  • EventLog
  • SystemVariable
  • Name: name of the object as filter criteria
  • Tag: object tag as filter criteria
  • templateName: name of the template as filter criteria
  • onlytaggedobjects: if to search for tagged objects only
  • rootObjectID : Start point

UpdateComplianceObject

Update native and custom fields of compliance object. Input is ComplianceObject state representing target object to be updated.
