envianceSdk.events.createEvent

Version 2.0

Other Versions:

None

Description

Creates a new Event in the specified Event Log.

Parameters

eventLogIdOrTag The id string (GUID) or tag of the Event Log. Any string that matches the pattern of a GUID is interpreted as the id, and not the tag of the Event Log.

eventInfo An instance of the eventInfo object. Some properties of this object are ignored by this function; see details of this object for more info.

Return Value

The id string (GUID) of the new Event will be passed to the onsuccess callback in the result property.

Notes

Events can only be created for manual Event Logs.

Example

envianceSdk.events.createEvent(

"Spill Events",

eventInfo,

function(response) {

alert("Event generated with id: " + response.result);

});

envianceSdk.events.eventInfo

Version 2.0

Other Versions:

None

Description

Constructs an EventInfo object instance in JavaScript.

Parameters

name The name of the Event.

beginDate Date. The begin date for the Event.

endDate Date. The end date for the Event. state One of either "Open" or "Closed".

complianceType One of either "Internal" or "Regulatory".

acceptAsDeviation Boolean. True/false value indicating whether the Event should be accepted as a compliance deviation.

requirementIdOrPath A Compliance Model object id string (GUID) or path, specifying a Requirement to which the Event is associated. Any string that matches the pattern of a GUID is interpreted as an id string, and not a path.

fields Array. An array of CustomField value objects for the Event Fields of the Event.

documents Array. Optional array of Document id strings (GUIDs) or paths, specifying zero or more Documents attached to the Event. Any string that matches the pattern of a GUID is interpreted as an id string, and not a path.

Return Value

An instance of the EventInfo class.

Instance Methods

addScalarFieldValue(fieldName, value) This is a convenience method to add a ScalarFieldValue value to the fields Array property.

addDateFieldValue(fieldName, value) This is a convenience method to add a DateFieldValue to the fields Array property.

addTimeFieldValue(fieldName, value) This is a convenience method to add a TimeFieldValue to the fields Array property.

addUrlFieldValue(fieldName, label, url) This is a convenience method to add a UrlFieldValue to the fields Array property.

addLinkedFieldValues(fieldName, values) This is a convenience method to add a LinkedFieldValues instance to the fields Array property.

addMultiFieldValues(fieldName, values) This is a convenience method to add a MultiFieldValues instance to the fields Array property.

Example

var event = new envianceSdk.events.EventInfo(

"Uh oh",

"2013-09-30T00:00:00",

"2013-09-31T00:00:00",

"Open",

"Internal",

false,

"/Division A/Facility X/Meter Tracker 1",

null, // no fields here

["/Folder 1/File.xls"]

);

event.addScalarFieldValue("Field A", 1);

event.addMultiFieldValues("Field B", ["Option1", "Option2"]);
