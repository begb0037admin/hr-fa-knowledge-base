envianceSdk.tagSchemes.tagSchemeInfo

Description

Represents a Tag Scheme definition.

Properties

id The id string (GUID) of the Tag Scheme.
Ignored for: Create Tag Scheme, Update Tag Scheme

name The name of the Tag Scheme.
Required for: Create Tag Scheme

description The description of the Tag Scheme.

enforceUniqueness Number. A numeric value that represents a Tag Scheme uniqueness flag:
(0 = no uniqueness, 1 = uniqueness for object, 2 = uniqueness for parent location, 3 = unique for both object and parent location)
Required for: Create Tag Scheme

Example

{

"name": "TagScheme Name",

"description": "TagScheme Description",

"enforceUniqueness": "1"

}
