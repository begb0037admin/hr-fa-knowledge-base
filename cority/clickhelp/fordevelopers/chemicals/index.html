chemicalInfo 

Represents a Chemical definition.

Name Type Description Required
id string The id string (GUID) for the Chemical. Ignored for: Create Chemical, Update Chemical No
name string Name of the Chemical. Required for: Create Chemical No
casNumber string The CAS number for the Chemical. Required for: Create Chemical No
alias string An alias for the Chemical to be used in scripts. Required for: Create Chemical No
description string Description of the Chemical. No
historyItems [ chemicalHistoryInfo ] An array of ChemicalHistoryInfo structures,specifying records which should be part of the Chemical property history. A new Chemical must have at least one Chemical history record. Required for: Create Chemical No

chemicalHistoryInfo 

Represents a Chemical History Item definition

Name Type Description Required
beginDate dateTime Begin date for the chemical history. No
mW string (number) Molecular weight of the chemical. A non-negative decimal value. If unspecified, the default is 0. No
antA string (number) Value of the Antoine A constant for calculating vapor pressure with temperature in Centigrade. A non-negative decimal value. If unspecified, the default is 0 No
antB string (number) Value of the Antoine B constant for calculating vapor pressure with temperature in Centigrade. A non-negative decimal value. If unspecified, the default is 0. No
antC string (number) Value of the Antoine C constant for calculating vapor pressure with temperature in Centigrade. A non-negative decimal value. If unspecified, the default is 0. No
antAk string (number) Value of the Antoine A constant for calculating vapor pressure with temperature in Kelvin. A non-negative decimal value. If unspecified, the default is 0. No
antBk string (number) Value of the Antoine B constant for calculating vapor pressure with temperature in Kelvin. A non-negative decimal value. If unspecified, the default is 0. No
antCk string (number) Value of the Antoine C constant for calculating vapor pressure with temperature in Kelvin. A non-negative decimal value. If unspecified, the default is 0. No
vp60 string (number) Vapor pressure at 60 deg Fahrenheit. A non-negative decimal value. If unspecified, the default is 0. No
density string (number) Density at 60 deg Fahrenheit. A non-negative decimal value. If unspecified, the default is 0. No
dipprA string (number) Value of the A constant for calculating vapor pressure by the DIPPR method. A non-negative decimal value. If unspecified, the default is 0. No
dipprB string (number) Value of the B constant for calculating vapor pressure by the DIPPR method. A non-negative decimal value. If unspecified, the default is 0. No
dipprC string (number) Value of the C constant for calculating vapor pressure by the DIPPR method. A non-negative decimal value. If unspecified, the default is 0. No
dipprD string (number) Value of the D constant for calculating vapor pressure by the DIPPR method. A non-negative decimal value. If unspecified, the default is 0. No
dipprE string (number) Value of the E constant for calculating vapor pressure by the DIPPR method. A non-negative decimal value. If unspecified, the default is 0. No
dipprF string (number) Value of the F constant for calculating vapor pressure by the DIPPR method. A non-negative decimal value. If unspecified, the default is 0. No
dipprG string (number) Value of the G constant for calculating vapor pressure by the DIPPR method. A non-negative decimal value. If unspecified, the default is 0. No
rcraHax string (boolean) Is on Resource Conservation and Recovery Act (RCRA) Hazardous list. A true or false flag. If unspecified, the default is false. No
hap string (boolean) Is listed as Hazardous Air Pollutant (HAP). A true or false flag. If unspecified, the default is false. No
tri string (boolean) Is on the Toxic Release Inventory reporting list. A true or false flag. If unspecified, the default is false. No
ehs string (boolean) Is listed as an Extremely Hazardous Substance. A true or false flag. If unspecified, the default is false. No
pbt string (boolean) Is listed as a Persistent Bioaccumulative Toxic (PBT) chemical. A true or false flag. If unspecified, the default is false. No
dioxin string (boolean) Is a dioxin or dioxin-like chemical. A true or false flag. If unspecified, the default is false. No
caa112r string (boolean) Is on the Clean Air Act Section 112(r) list of regulated substances. A true or false flag. If unspecified, the default is false. No
pac string (boolean) Is on the Protective Action Criteria (PAC) list. A true or false flag. If unspecified, the default is false. No
diisocyan string (boolean) Is a diisocyanate chemical. A true or false flag. If unspecified, the default is false. No
cerclaHaz string (boolean) Is on the Comprehensive Environmental Response, Compensation, and Liability Act (CERCLA) hazardous chemical list (commonly known as Superfund). A true or false flag. If unspecified, the default is false. No
airToxicEmissionInventory string (boolean) Is listed on the Air Toxic Emission Inventory. A true or false flag. If unspecified, the default is false. No
solid string (boolean) Is a solid. A true or false flag. If unspecified, the default is false. No
nonEvaporative string (boolean) Is non-evaporative. A true or false flag. If unspecified, the default is false. No
rcraVoc string (boolean) Is an RCRA VOC. A true or false flag. If unspecified, the default is false. No
rcraSvoc string (boolean) Is an RCRA SVOC. A true or false flag. If unspecified, the default is false. No
caaVoc string (boolean) Is a Clean Air Act VOC. A true or false flag. If unspecified, the default is false. No
