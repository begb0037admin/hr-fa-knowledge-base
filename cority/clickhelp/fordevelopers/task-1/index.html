Notes on Task Versioning:

In most cases, when querying for Task properties, the query should include a filter for .isCurrent='true' in order to select only the latest version of the task.

Multiple versions (with unique VersionIDs) are stored, with a new version created each time a task is modified. So querying for tasks without the 'isCurrent' filter may return multiple versions of a task, where only one is active. If you need to see a history of task changes, the VersionID and VersionCreated fields can be used.

When querying for Task Instances, filtering by .isCurrent='true' will return only tasks using the current task version at the time of the query. If the task has been edited during the time period being queried, tasks created with older versions will not be returned. So in this case, do not include the 'isCurrent' filter if you want to see all tasks in the time period.

Example: Get monthly scheduled tasks, task assignees and schedule details.

select

t.Name as TaskName,

t.Description,

t.AssignedToUser.FirstName,

t.AssignedToUser.LastName,

t.AssignedToGroup.Name as GroupAssignee,

t.Schedule.RecurrenceType,

t.Schedule.Detail

from Task t

where t.Schedule.RecurrenceType like 'Monthly'

and t.name not like '%test%'

and t.isCurrent='true'

Example: Get task instances for the year.

select

t.Name,

ti.DueDateTime

from

Task t

join TaskInstance ti on t

where ti.DueDateTime between '01/01/2014' and '12/31/2014'

Permissions:  Requires View permission on the target object. Manage Users right is required to query AssignedUsers or AssignedToUsers fields. Manage Documents right is required to query Document composite columns. Manage Calculation Templates right is required to query Object.CalculationTemplate fields. Manage Custom Fields right is required to query Object.CustomFieldTemplate fields.
