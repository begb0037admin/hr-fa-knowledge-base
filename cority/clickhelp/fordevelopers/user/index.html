Example: Get the rights granted to a specific user, and the user's group memberships.

select

u.FirstName,

u.LastName,

u.RightID,

u.RightName,

u.GroupID,

u.GroupName

from User u

where

u.FirstName = 'John'

and

u.LastName = 'Smith'
