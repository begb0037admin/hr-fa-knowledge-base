EQL Syntax

EQL syntax is designed to be as close to the "classic" SQL syntax as possible. EQL differs from SQL in areas where we can express specific EMS operations in shorter and simpler expressions. The EQL language is not case sensitive.

Supported statements: USE, SELECT. There are no plans to support DELETE, UPDATE or INSERT statements.

Aliases are mandatory in column and tables naming.

Character escape

ANSI SQL standard is used to escape special characters:

'Mike''s' – correct (single quote, single quote)

'Mike\'s' – error

'Mike says "yes"' – correct

'Mike\nJohn\n' – correct

'System\\Facility\\Unit\\' – correct

Wildcards

Use '%' as a wildcard in a name search string. Example:

select

r.Name,

d.value

from Datapoint d

join Requirement r on d

where r.Name like 'Used Tires%'

A single unqualified * can be used to select all columns from all tables in the select expression. For example, the following query will return all columns from the selected Facility table:

SELECT * FROM Facility f

Only native columns (no UDFs) are returned.

The * may also be used with the table alias as <table_alias>.* For example, the following query will return all columns from the select Facility and Unit tables:

SELECT f.*, u.* FROM Facility f JOIN Unit u on u is under f

Modifiers

EQL syntax is described in the BNF Syntax section. However there are some differences with classic SQL.

The modifier TOP can be used with integer number (integer_number) only to specify how many rows will be returned.

If the query includes an ORDER BY clause, the first integer_number rows ordered by the ORDER BY clause are returned. If the query has no ORDER BY clause, the order of the rows is arbitrary.

The modifier ALL specifies that duplicate rows can appear in the result set. ALL is the default.

The modifier DISTINCT specifies that only unique rows can appear in the result set. Null values are considered equal for the purposes of the DISTINCT keyword.

Syntax errors

EQL parser provides user readable syntax errors generation with the location where the error occurred in the source code.

BNF Syntax

<Batch> ::= *<*Statement>[ ...n]

<Statement> ::= <SelectStatement | UnionStatement | SetStatement | UseStatement | ImpersonateStatement>

<UnionStatement> ::=

<SelectStatement> union [all] <SelectStatement> [order by <OrderExpression>[,...n]]

<SetStatement> ::=

SET string [=] {number|string|Boolean}

<UseStatement> ::=

use string

<SelectStatement> ::=

select *[*distinct | all] [top integer_number] <SelectColumn>[,...n]

from <TableSource> [indexed temp| temp] table_alias [{join | left join | right join | inner join} <TableSource> [indexed temp| temp] table_alias on

{table_alias | <BoolExpression>}][...n]

[where <BoolExpression>]

[group by <Expression>[,...n] ?[with cube | with rollup]]

[order by <OrderExpression>[,...n]]

<SelectColumn> ::= <Expression> [as column_alias]

<TableSource> ::= <table_name | SelectStatement | view_name>

BoolExpression> ::=

{<Expression> { < | > | = | != | <> | >= | <= } <Expression> |

<BoolExpression> and <BoolExpression> |

<BoolExpression> or <BoolExpression> |

not <BoolExpression> |

<Expression> like string |

<Expression> not like string |

<Expression> in ({number[,...n] | string[,...n]}) |

<Expression> not in ({number[,...n] | string[,...n]}) |

table_alias {is under | is above | is child | is parent} table_alias} |

<Expression> between <Expression> and <Expression>} |

<Expression> not between <Expression> and <Expression>}

<OrderExpression> ::= <Expression> [asc | desc]

<Expression> ::= { number | string | <TableColumn> | <Function>| CaseExpression }

<TableColumn> ::= {[table_name . ]column_name}

_integer_number --_any integer number

number – float or integer number

string – string marked by single quotation mark (')

table_alias – table alias

column_alias – table column alias

table_name – table name or view

column_name – column name (if contains spaces, should be marked by double quotation mark ("))

<CaseExpression>::= case

     when <BoolExpression> then <Expression> [when <BoolExpression> then <Expression>n ]   

     [else <Expression>] end
