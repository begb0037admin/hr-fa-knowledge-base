Substring

Returns part of a text. Start and Length shall be passed as arguments. Start character is 1 based.

Syntax

SUBSTRING ( expression ,start , length )

Example:

Select

f.id,

SUBSTRING(f.name, 1,2)

from Facility f

Right

Returns the right part of a text expression with the specified number of characters. Number should be a positive integer.

Syntax

RIGHT ( text_expression , number_expression )

Example:

Select

f.id,

RIGHT(f.name,2)

from Facility f.

Left

Returns the left part of a text expression with the specified number of characters. Number should be a positive integer.

Syntax

LEFT ( text_expression , number_expression)

Example:

Select

f.id,

LEFT(f.name,2)

from Facility f.

Upper

Returns a text with lowercase characters converted to uppercase.

Syntax

UPPER ( text_expression )

Example:

Select

f.id,

UPPER(f.name)

from Facility f

Lower

Returns a text with uppercase characters converted to lowercase.

Syntax

LOWER ( text_expression )

Example:

Select

f.id,

LOWER(f.name)

from Facility f
