Scim Identity APIs and Data Types

The EMS SCIM API is used by SSO partners to help provision and manage users and groups within EMS system. The SCIM API is based on the open standard Simple Cloud Identity Management: Protocol 1.1.

Models

user 

Represents a User definition. Used for all SCIM user operations.

Name Type Description Required
schemas [ string ] SCIM version specific schema as well as any schema extensions. EMS currently supports SCIM 1.1 (i.e. urn:scim:schemas:core:1.0) and schema extension urn:scim:schemas:enviance:user No
id string Identifier (Guid) of a user. No
externalId string External identifier that is usually similar to username. No
meta object Metadata for a user No
userName string Unique name of the user, typically used by the user to directly authenticate to EMS system No
password string The User’s clear text password. This attribute is intended to be used as a means to specify an initial password when creating a new User or to reset an existing User’s password No
name object The components of the user’s real name. No
title string Title for the User. No
displayname string Display name of a user in EMS system. No
emails object An active date of the Requirement. No
timezone string (Olson Time zone) The User’s time zone in the “Olson” timezone database format. No
preferredLanguage string Indicates the User’s preferred written or spoken language. Generally used for selecting a localized User interface. e.g., ‘en_US’ No
active boolean A boolean value indicating status of user. No
groups object A list of groups that the user belongs to. No
usertype string Type of the User. Possible values are Homeuser and Accessuser. No
address object A physical mailing address for the user. No
phoneNumbers object Phone number(s) for the User. No
urn:scim:schemas:enviance:user object Extended schema attribute. No

schemas [ string ] SCIM version specific schema as well as any schema extensions. EMS currently supports SCIM 1.1 (i.e. urn:scim:schemas:core:1.0) and schema extention urn:scim:schemas:enviance:group No
id string Identifier (Guid) of a group. No
externalId string External identifier that is usually similar to groupname. No
meta object Metadata for a group No
displayName string Unique name of the group in EMS system. No
members object A list of members (user) of the Group. No
urn:scim:schemas:enviance:group object Extended schema attribute. No
