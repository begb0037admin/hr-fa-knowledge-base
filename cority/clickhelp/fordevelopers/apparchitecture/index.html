EMS App Architecture

All EMS Apps have:

  • A Name.
  • A Description.
  • A set of one or more Items (files), one of which must be the html Display Page.
  • A set of one or more App Roles.
  • Optional Application Data, saved as key/value pairs.
  • An optional Content Security Policy.
