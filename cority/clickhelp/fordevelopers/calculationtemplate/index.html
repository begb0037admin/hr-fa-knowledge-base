Example: Get the Calculation Template name and field names for template(s) with "Fixed Roof Tank" in its name.

select

ct.Name as CalculationTemplate,

ct.CustomField.Name as Field

from CalculationTemplate ct

where ct.name like '%Fixed Roof Tank%'

Example: Get custom field names on calculation template applied to a POI, then get custom field values.

select

p.name as POI,

p.CalculationTemplate.Name as CalculationTemplate,

p.CalculationTemplate.CustomField.Name as Field

from POI p

where POI name like 'Tank #1'

 

-- then get calculation template field values (and optionally the begin and end dates if applicable)

select

p.Calculation."Working volume (gals)",

p.Calculation."Hs",

p.Calculation."TX_Ds",

p.Calculation."Hla",

p.Calculation."Hlx"

p.Calculation."Hlx".BeginDate

p.Calculation."Hlx".EndDate

from POI p

where p.name like 'Tank #1'

 

Permissions:  Manage Calculation Templates right is required to query this table. Manage Custom Fields right is required to query CustomField composite fields.
