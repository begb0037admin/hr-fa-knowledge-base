Authenticate

This method is used to authenticate login. It takes the user name and password and returns a sessionID. The sessionID is required in the header of all other web service calls and expires after a given period of inactivity, typically 1 hour.

AuthenticateByCert

This method is an alternative way to authenticate login. It takes an encrypted user name and the unique CertificateID and returns a sessionID. Before using this method, a trust agreement must be set up with EMS.

CloseSession

This method closes the Authenticated session represented by the sessionID in the header.

ObjectsIdentifiers

Starting with 2010 Web Services, EMS uses the concept of abstract object identifier. In WSDL the object ID is usually EnvianceId, which is abstract object without properties. This allows the client to submit objects by either TagID or GUIDId, whichever is more convenient. Each concrete service will state which ID type it returns and accepts.
