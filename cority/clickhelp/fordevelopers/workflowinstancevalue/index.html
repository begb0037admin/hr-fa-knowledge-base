Example: Get all values of global fields of  specified Workflow Instance

select

v.WorkflowInstanceID,

v.CustomFieldID,

v.CustomFieldName,

v.Value

from WorkflowInstanceValue v

where v.WorkflowInstanceID = 'FAD3BD9A-B6EF-4945-BD25-ACD060CF3765'

Permissions:  Requires Report permission on the target object or Workflow Managers' role.
