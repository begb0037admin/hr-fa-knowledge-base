Quick Start

You can get started building an EMS App, by following these steps:

First, create an HTML page (such as index.html) to act as the default display page for the EMS App. This is the page that is going to be loaded in the browser first when the App runs.

The display page will be loaded anytime the EMS App URI is referenced without a page specified, or if the display page is explicitly included. This includes explicit requests inside the Management System via "Run" or via the Main Menu, as well as direct requests.

The display page for an EMS App is specified using the package manifest or via settings when creating the App.

Second, the display page (and every distinct HTML page) should include the EMS App SDK and required libraries using the following path:

<script src="/Packages/Libs/jquery.1.8.3.min.js"></script>

<script src="/Packages/Libs/json2.js"></script>

<script src="/Packages/Api/Enviance.Packages.ver2.js"></script>

 

"EMS Packages" is the informal name for EMS Apps.

Third, the page should call (and ensure completion of) the init method of the EMS Apps Library:

<script type="text/javascript">

envianceSdk.packages.init({}, function() {

// On completion callback.

}

</script>

 

That is it. You can now perform any desired work/calls to the SDK after the page has loaded. Authentication is not required because the security context of the User running the EMS App in the Management System is used.
