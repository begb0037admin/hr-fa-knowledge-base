Cast

EQL can convert an expression of one data type to another

Syntax

CAST(expression as data_type data_type[(length)])

Example:

select

CAST(f.InactiveDate as varchar(11))

from Facility f

or

select

CAST(d.Value as decimal(18, 3))

from Datapoint d
