Using App Roles

App Roles may be used in one or both of the following ways:

  1. Allow or Deny access for a Role to one or more EMS App Items or App Data keys in the EMS App manifest. This method ensures that any User or Group mapped to the Role, will (or will not) be able to load the Item from the server when using the EMS App. This approach is a strict approach in the sense that permissions are checked on the server and if a User does not have access to an EMS App Item or Data key, the server will respond with a "403 Forbidden".
  2. Use the provided EMS App Javascript Library methods to dynamically determine Role membership at run time and enable or disable functionality appropriately on the client side.

Note:  With either approach, all Permissions and Rights assigned to the User either directly or through Group memberships in the Management System will be strictly enforced when calling the REST APIs.
