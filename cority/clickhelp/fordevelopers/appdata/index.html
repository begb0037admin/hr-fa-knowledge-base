envianceSdk.packages.userData.get

Version 2.0

Other Versions:

None

Description

This method gets previously saved data which are available only to the current User.

Parameters

keys Array. An array of key strings to uniquely identify each value in a set of values. If an empty array is passed, all data will be returned.

Return Value

None

Callbacks

onsuccess A callback function to use upon success. The single parameter will be a dictionary of key to value (JavaScript object) pairs corresponding with the requested keys.

onfailure An optional callback function to use upon error.

Notes

Use only for user-specific settings that are not required for application functioning.

Example

envianceSdk.packages.userData.get(

["firstSearch", "lastSearch"],

function(values) {

alert(values["firstSearch"]);

});

envianceSdk.packages.userData.set

Version 2.0

Other Versions:

None

Description

This method saves an arbitrary set of key-value pairs which are available only to the current User.

Parameters

dataSet A dictionary of key to value pairs.

Return Value

None

Callbacks

onsuccess An optional callback function to use upon success.

onfailure An optional callback function to use upon error.

Notes

Use only to store user-specific settings that are not required for application functioning.

Example

envianceSdk.packages.userData.set(

{

"lastSearch": JSON.stringify({

"fieldList": ["A","B","C"],

"sortOrder": ["C","B","A"]

}),

"firstSearch": JSON.stringify({

"fieldList": ["A","B","C"],

"sortOrder": ["C","B","A"]

})

}, function() {

alert("Saved!);

});

>envianceSdk.packages.userData.getUpdated

Version 2.0

Other Versions:

None

Description

This method gets previously saved data which is available only to the current User since requested date.

Parameters

keysArray. An array of key strings to uniquely identify each value in a set of values. If an empty array is passed, all allowed data will be returned.

updatedAfter (string or Date). Date value or its string presentation of UTC in ISO format.

Return Value

Gets previously saved data and service key "_Updated" that stores latest date of modification or requested keys.

Callbacks

onsuccess A callback function to use upon success. The single parameter will be a dictionary of key to value (JavaScript object) pairs corresponding to the requested keys.

onfailure An optional callback function to use upon error.

Notes

Use only for user-specific settings that are not required for application functioning.

Example

envianceSdk.packages.userData.getUpdated(

["firstSearch", "lastSearch"], "2018-01-01T01:01:01.000Z", function(values) {

alert(values["firstSearch"]);

});

envianceSdk.packages.userData.getUpdated(

["firstSearch", "lastSearch"], newDate(2018, 1, 1, 1, 1, 1), function(values) {

alert(values["firstSearch"]);

});
