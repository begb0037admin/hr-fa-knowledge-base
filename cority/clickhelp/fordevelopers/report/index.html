envianceSdk.reports.execute

envianceSdk.reports.execute.Async

Version 2.0

Other Versions:

None

Description

Executes an "Ad Hoc" Report that has been configured in the Management System. Custom Reports are not supported (use EQL instead).

Parameters

reportExecutionInfo An instance of the reportExecutionInfo object.

Return Value

None

Notes

Reports are executed asynchronously in the Management System. Use the asynchronous version of this function to continue processing. The non-Async version will take up to 30 seconds to wait for the command to be processed successfully.

Example

envianceSdk.reports.execute(reportExecutionInfo,

function(response) {

alert("Report executed successfully.");

});

 

envianceSdk.reports.reportExecutionInfo

Version 2.0

Other Versions:

None

Description

Constructs a reportExecutionInfo object instance in JavaScript.

Parameters

reportIdOrPath The id string (GUID) or path of the Report. Any string that matches the pattern of a GUID is interpreted as the id string, and not the path. A path string should be URL encoded.

format Must be one of "HTML", "Excel", or "Excel Template".

from Date. The date and time that will be used as the start of the Report's date range filtering. The Time Zone used for this value, and the field to which it applies, depends upon the Report being executed.

to Date. The date and time that will be used as the end of the Report's date range filtering. The Time Zone used for this value, and the field to which it applies, depends upon the Report being executed.

Return Value

An instance of the reportExecutionInfo class.

Instance Methods

addObjectPathFilter(objectPath) This method adds an object by path to the object filter set during the Report execution.

addObjectIdFilter(objectId) This method adds an object by id to the object filter set during the Report execution.

setWorkflowDateFilterBy(dateType) This method specifies the type of due date filtering to use when executing a Workflow Report. Valid options are "Due Date" and "Creation Date".

Example

var reportExec = new envianceSdk.reports.ReportExecutionInfo(

"/Audit Reports/Open Audits Report",

"Excel",

"2013-09-30T00:00:00",

"2013-09-31T00:00:00"

);

reportExec.addObjectPathFilter("/Division A");

reportExec.setWorkflowDateFilterBy("Due Date");
