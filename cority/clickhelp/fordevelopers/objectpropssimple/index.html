Object Properties Editing Tool - Simple Properties

For simple properties with one-to-one property-value associations, you can use the simplified template for object properties editing.

Download the Excel template file:

Object Properties Editing Tool – Simple Properties

The names of the standard properties are shown in the initial templates. You can add your custom properties to the file. Custom properties and Custom Field Templates must first be created in the system and applied to the objects you are editing. You can use the Template Update Tool to associate the Custom Field Template with your objects first if necessary.

Note:  Custom properties are identified by their Name (ID field), not the Caption field in the bulk upload template. If the Name is different from the Caption, be sure you use the correct name in the template. The name is not case-sensitive.

You must use a separate line for each object-property association to edit. For example, to edit the City, State and Country address fields for two facilities, you would have 6 rows in the Excel file, as shown:

  A B C
1 Path and Name Property Name Property Value
2 path/object A facility/program address city San Francisco
3 path/object B facility/program address city Dallas
4 path/object A facility/program address country United States
5 path/object B facility/program address country United States
6 path/object A facility/program address state California
7 path/object B facility/program address state Texas

 

The order of edits is important for some standard properties. In this example with the Facility/Program Address fields, a Country must be selected before a State, since State selections are filtered by Country. Note that City is independent of the country/state selections, so it is possible to edit this field in any order.

The "monitored requirement(s)" field may be edited on the simple template by listing all requirements on one line (with all required). To add or delete monitored requirements singly, use the Object Properties Editing Tool - Monitored Requirements .
