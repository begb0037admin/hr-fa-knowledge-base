ReportTreeStructure

Columns

ReportId Report ID

ParentReportID ID of parent report

Level ReportTreeStructure level

Example: Find the parent folder of a given report.

select

r.id,

r.name,

r.isfolder,

r2.name as parentname

from report r

join ReportTreeStructure rts on rts.ReportID = r.id

join report r2 on r2.id = rts.parentreportid

where r.name = 'My Form Report'

and r2.name <> 'My Form Report'

Permissions:  Requires Report permission on the target object or Manage Reports right.
