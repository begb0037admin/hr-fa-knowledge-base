RequirementScript

Columns

ID Requirement Script ID

RequirementID Link to Requirement table

BeginDate Requirement Limit Begin Date

EndDate Requirement Limit End Date

Created Date created

Updated Date updated

ScriptWithId Requirement calculation script with identifiers of all referenced objects (requirements, UDFs, tags)

ScriptWithName Requirement calculation script with name of all referenced objects (requirements name without path, UDFs, tags)

ScriptWithPath Requirement calculation script

ScriptWithFullPath Requirement calculation script with full path of all referenced requirements

DivideByZero Value specified for Divide By Zero error

Other Value specified for Other(other than Overflow and Divide by Zero) error

Overflow Value specified for Overflow error

FixedPeriodValue Time-Based Calculated Requirement Fixed Period Value

FixedPeriodType Time-Based Calculated Requirement Fixed Period Type: Hour(s), Day(s), Week(s), Month(s), Quarter(s), Year(s)

RollingPeriodValue Time-Based Calculated Requirement Rolling Period Value

RollingPeriodType Time-Based Calculated Requirement Rolling Period Type Hour(s), Day(s), Week(s), Month(s), Quarter(s), Year(s)

IntermediatePeriod Time-Based Calculated Requirement Intermediate Period: Hourly, Daily, Weekly, Monthly, Quarterly

Natural Joins

Requirement

select

r.name,

r.path,

r.CustomFieldTemplate.Name,

rs.ScriptWithFullPath,

rs.BeginDate,

rs.EndDate,

l.RegulatoryLow,

l.RegulatoryHigh,

l.InternalLow,

l.InternalHigh

join RequirementScript rs on r
