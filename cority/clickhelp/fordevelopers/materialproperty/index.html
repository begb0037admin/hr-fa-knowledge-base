enviancesdk.materialProperties.createMaterialProperty

Version 2.0

Other Versions:

None

Description

Parameters

Return Value

Example

envianceSdk.materialProperties.createMaterialProperty (materialPropertyInfo, onsuccess, onerror)

enviancesdk.materialProperties.copyMaterialProperty

Version 2.0

Other Versions:

None

Description

Creates a new Material Property by copying an existing Material Property.

Parameters

materialPropertyInfo An instance of the materialPropertyInfo object. Some properties of this object are ignored by this function; see details of this object for more info.

copyFrom The id string (GUID) of an existing Material Property whose properties will be copied and used as the properties of the newly created Material Property. Specifying this property allows you to copy an existing Material Property to another Material Property.

Return Value

The id for the new Material Property.

Example

envianceSdk.materialProperties.copyMaterialProperty (materialPropertyInfo, copyFrom, onsuccess, onerror)

enviancesdk.materialProperties.materialPropertyInfo

Description

Represents a Material Property definition.

Properties

id The id string (GUID) for the Field.
Ignored for: Create Field, Update Field

name The name of the field.
Required for:  Create Field

description The description of the Field.

propertyType The type of the Field. Valid values: MaterialVBP | ActivityVBP | SUV | PrimaryFBP | SecondaryFBP | TertiaryFBP
Ignored for: Update
Required for:  Create Field

dataType If specified, must be one of "Numeric" or "Boolean". This property is only valid for VBPs, and cannot be modified on an existing field.
Ignored for: Update Field

uniqueTag If specified, this must be a string that is unique among all SUVs in the system. This property is only valid for SUVs.

isChemLogical Boolean. True/false value indicating whether this field is a Chemical Logical field. The default is false. A value of true is only valid for FBPs. This value cannot be modified on an existing field.
Ignored for: Update Material Field

valueHistory Array. An array of formulaHistory structures.
Required for: Create Material Property if propertyType set to "Formula Based Primary", "Formula Based Secondary", "Formula Based Tertiary"
Ignored for: PropertyType set to "Value Based Material", "Value Based Activity", "Specific Use Variable"

Example

envianceSdk.materialProperties.MaterialPropertyInfo (name, propertyType, description, dataType, uniqueTag, formulaHistory)

 

{

"name": "Material Template Name",

"description": " Material Template Description",

"propertyType": "Formula Based Primary",

"dataType": "Numeric",

"formulaHistory": [{

"beginDate": "2012-01-01T20:00:00",

"Script": "1 + SUM([Chem_MW])"

}]

}
