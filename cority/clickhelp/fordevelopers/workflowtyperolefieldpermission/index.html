Example: Get field permissions for the workflow roles in the Corrective Action workflow type.

select

wt.Name as WorkflowType,

r.Name as Role,

cf.name,

fp.Permission

from WorkflowType wt

join WorkflowTypeVersionRole vr on wt

join WorkflowRole r on vr

join WorkflowTypeRoleFieldPermission fp on vr

join CustomField cf on fp

where wt.Name = 'Corrective Action'

Permissions:  Manage Workflows right is required to query this table.
