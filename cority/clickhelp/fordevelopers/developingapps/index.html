Developing Apps

Developing an EMS App is similar to writing any JavaScript/HTML/CSS application which utilizes the EMS SDK and AJAX calls to APIs (as opposed to server POSTs to re-render page displays).

An EMS App is hosted directly inside of the Management System, whereas a non-EMS App written against the EMS SDK need not be hosted inside of the Management System. Additionally, an EMS App can take advantage of some runtime features such as configurable Roles and permissions, data storage, and caching.

The startup and lifecycle for an EMS App is simplified (as compared to an external application using the JavaScript SDK alone) because authentication and context can be automatically provided by the Management System host.
