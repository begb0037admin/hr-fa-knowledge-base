Data View

An EQL query can be saved as a DataView and then used in the same way as any other table. For example, you can create a view:

Name: AllChildrenOfSomeComplianceObject

select

co.ID,

co.Name

from ComplianceObject co

where

ParentID = '5EEA224C-5A5C-4308-BE51-B7C59C785322'

 

You can then use this view in a valid EQL query as follows:

select

ID,

Name

from AllChildrenOfSomeComplianceObject

 

A complete list of existing saved views can be obtained with the following EQL query:

select

TableName

from Tables

where

TableSubsystem = "DataView"
