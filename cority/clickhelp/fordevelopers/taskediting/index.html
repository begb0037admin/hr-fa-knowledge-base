Task Editing Tool

The Task Editing Tool allows you to edit existing tasks in the system. Note that it is not possible to create new tasks with the tool. To create new tasks, you can:

  • Create a generic requirement with an associated task.
  • Copy the requirement using the Copy Objects Tool. The copy operation will also copy the associated task.
  • Use the Task Editing tool to edit the properties of the tasks associated with the new objects. You can also change the associated objects for the task, if necessary.

Task Editing Tool

You can:

  • Edit general task properties (see Edit Task Properties)
  • Change associated objects (see Edit Task Properties)
  • Add or edit notifications (see Add/Edit/Delete Notification)
  • Add or edit recurrences (see Add Recurrence/Edit Recurrence)
  • Create task exceptions (see Add Task Exception)

The Task Editing Tool Template file has seven worksheets. The first six columns in each worksheet are identical. These six fields are used to uniquely identify the task to be edited. When editing task recurrences, additional fields are required to identify the recurrence schedule to edit. The required Task ID fields on all worksheets are:

TaskName: Name of task

Associated Object(s): Path to associated object. Include the Requirement name if the associated object is not a tree object. For multi-object tasks, list ALL associated objects. Full path must be specified, with each object separated with a new line (Alt+Enter). Include "\" at beginning, but not at the end. Example:

Task Due Date: Date: Due date of any task instance. For a recurring task, you may use the due date of any task instance in the recurrence schedule. To create a task exception, specify the due date of the task instance for which the exception is to be created.

Format: mm/dd/yyyy

Task Due Date: Time: Time of task instance (corresponding to Due Date).

Format: hh:mm AM/PM

24-hr time format cannot be used in the upload file. However, if the culture of the user (as specified on the user profile) typically uses 24-hr time, the task will be displayed that way for the user in the UI.

Note:   Due Date and Time must be specified in the Task Time Zone. This may be different than the Assignee's time zone. The assignee will see the due date as UTC ± the Task Due DateTime. You can edit the Task Time Zone in column AQ on the Edit Recurrence sheet for a recurring task, or in column N on the Edit Properties sheet for a single-instance task.

Tip:  The task due date is shown in your own time zone. This may be confusing if your time zone is different than the task's facility. You can temporarily change your time zone in your profile to the task time zone to make it easier to check configuration.

Task Assignee(s): User (s): Assignee username(s). In the case of more than one user assignee, ALL assignees must be listed. Separate Usernames with "|" character. Example:

Username1 | Username2

Task Assignee(s): User Group(s): Group Name. In the case of more than one assignee group, ALL Groups must be listed. Separate Group Names with "|" character. Example:

Group1 | Group2
