Group

Columns

ID Group ID

Name Group Name

UserID IDs of users in the group

UserName Names of users in the group

RightID All effective group right IDs

RightName All effective group right names

Created Group created date

Updated Group updated date

Natural Joins

User

Example: Get group membership.

select

g.name,

g.RightName,

u.FirstName,

u.LastName,

u.Email,

u.login,

u.IsHomeUser,

u.Deleted,

u.Locked,

u.expires

-- groupmodified

-- usermembershipmodified

from User u

join Group g on g.ID = u.GroupID

Permissions:  Manage Groups right is required to query this table.
