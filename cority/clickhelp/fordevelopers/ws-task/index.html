GetTaskHistoryIDByInstanceTag

When given an array of Event Instance Unique Tags it returns an internal TaskHistoryID for every Tag given. These TaskHistoryIDs can then be used to Complete Tasks via the other method of this Webservice.

CompleteTask

For each TaskStatus element given (TaskStatus consists of a TaskHistoryID, Due Date of the task, Complete Status, Completion Date and Comments) this method attempts to Complete the corresponding Task (found via TaskHistoryID/DueDate combination) to the CompletionStatus given on the CompletionDate given. An optional Comment is added if given. CompletionStatus is a multiple of 10 in the 0 to 100 range corresponding to the percentile of task completion. For example you may mark a Task only 20% complete via this method. If the Task is set to 100% complete, the Task becomes marked as Completed and will no longer be editable via this method. If the Task is only partially complete, it can still be edited. For example you may reset a 90% complete task back to 50% complete via this method, but you cannot reset a 100% complete task to any other value. No meaningful response is given by this method, so to check that it worked the Tasks must be inspected manually in the system.
