Models

commandInfo 

Information about a User-requested asynchronous operation.

Name Type Description Required
id string The id string (GUID) of the command. No
description string The system description of the command. No
issued string The date and time the command was issued. The value is in the User’s time zone. No
startedProcessing string The date and time the command begin processing. The value is in the User’s time zone. The value is null if processing has not yet begun. No
finishedProcessing string The date and time the command finished processing. The value is in the User’s time zone. The value is null if processing has not yet finished. No
status string The status of the command; which will be one of: Waiting, Processing, Succeeded, Failed, Resubmitted. No
objects string An array of object paths No
reports string An array of Report paths No
user string The user name of the User who submitted the command. No
result string An optional URI pointing to the result of the command. No
errorInfo string An array of JSON object literals with the following properties:error The text of the error description. No
details string An array of JSON object literals describing the error details for each error. The format depends upon the type of data submitted. No
