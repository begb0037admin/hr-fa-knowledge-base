Configuration Functions

JavaScript Functions

configure

envianceSdk.configure

Version 2.0

Other Versions:

Version 1.0

Description

Sets configuration parameters that control the behavior of the SDK. If you are writing an EMS App, calling the init function of the EMS Apps library will in turn call this function with the typical and appropriate configuration values, so you should not have to call this function yourself.

Parameters

A JSON object literal with the following properties:

baseAddress A string containing the full URI to the EMS API host. Typically, this will be https://api.enviance.com. Default is null.

variables Either "simple" or "cookies". This setting specifies which VariablesManager (i.e. local state manager) will be used by the SDK. Default is "simple".

systemId The current system id string in which APIs should operate. Typically the system id is set upon calling authenticate, so it should not be specified. Default is null.

crossDomainWorkaround Specifies whether or not the SDK will use alternative methods for making cross domain calls. Options are "ifneeded", "always", "off". When set to "ifneeded", the SDK will detect if the browser make and version requires it. Default is "ifneeded".

resubmitConfirmationOnError Boolean. True/false value that controls whether or not the SDK will automatically prompt the User to retry an API call if it has timed out. Default is true.

refreshPageOnUnauthorized Boolean. Ture/false value that controls whether or not the SDK will automatically refresh the page when an authorization error occurs. This would typically cause the current page to reload and potentially re-authenticate. Default is false.

Return Value

None

Example

envianceSdk.configure({

baseAddress: "https://api.enviance.com"

});
