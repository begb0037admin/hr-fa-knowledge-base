Impersonation

Note: Impersonation is only available for the Management System EQL.

Impersonation can be used for executing a query in other user's context. Impersonation can only be executed by Administrators.

Impersonation supports the following syntax:

IMPERSONATE userid WITH [Rights]

<userid> user's ID as string.

WITH [Rights] (Optional) one or more rights that will be granted to user for query.

Possible options for rights:

ManageUsers

ManageGroups

ManageAccess

ManageMessages

ManageRequirementTemplates

ManageDocuments

ManageSecurityPolicy

ManagePackages

ManageMainMenu

ManageReports

ManageMaterials

ManageCommandLog

ManageCitations

ManageSystemDashboards

ManageQualityTemplate

ManageCalcTemplate

ManageMaterialTemplate

ManageTaskTemplates

ManageTags

ManageUdf

ManageEvents

ManageWorkflows

ManageQuickLinks

ManageAnyTemplate

SetupRights

AllRights

ManagePortal

ViewLocationsAndPrograms: EQL specific right. It allows users to see all locations.

 Example:

IMPERSONATE '56de46d4-8db2-4952-b732-4b9360d49023' WITH [' ManageUsers','ManageGroups']

select

f.FirstName

from user f

 

IMPERSONATE '56de46d4-8db2-4952-b732-4b9360d49023'

select

f.FirstName

from user f


IMPERSONATE '0c88e45b-bc53-4b17-a86b-c32317d603f9'  WITH ['ViewLocationsAndPrograms']

 select

wf.ID, wf.Name, wf.UniqueID, wf.IsParticipant

 from WorkflowInstance wf

 join ComplianceObject co ON wf.Object

 where co.Name Like 'EQLTest'
