TaskNotification

Columns

Comments Task Notification Comments

Created Date created

Updated Date updated

AssigneeNotify Indicates if notification is sent to Assignee

AssignorNotify Indicates if notification is sent to Assignor

OtherNotify Indicates if notification is sent to Others

EmailDelivery Indicates if Notification shall be delivered via email

InboxDelivery Indicates if Notification shall be delivered via inbox

TimeToNotify The Time to Notify

UserNotify.ID, UserNotify.FirstName, ... Notify User. Composite column to User table (includes all fields from User)

GroupNotify.ID, GroupNotify.Name, ... Notify Group. Composite column to Group table (includes all fields from Group)

UsersNotify.ID, UsersNotify.FirstName, ... Notify Users. Composite column to User table (includes all fields from User)

NotificationTemplateId ID of Task Notification Template

Natural Joins

Task

Example: Get Tasks with notification details

select

t.name,

t.Object.Path,

t.Object.Name,

t.Assignor.FirstName,

t.Assignor.LastName,

t.AssignedToUser.FirstName,

t.AssignedToUser.LastName,

t.AssignedToUser.Email,

t.Notification.TimeToNotify,

t.Notification.EmailDelivery,

t.Notification.InboxDelivery,

t.Notification.OtherNotify,

t.Notification.Comments,

t.Notification.AssigneeNotify,

t.Notification.AssignorNotify,

t.Notification.UserNotify.FirstName,

t.Notification.UserNotify.LastName,

t.Notification.UserNotify.Email,

t.Notification.Created,

t.Schedule.PeriodStart,

t.Schedule.PeriodEnd,

t.Schedule.RecurrenceType

from Task t

Permissions:  Requires View permission on the target object. Manage Users right is required to query UsersNotify and UserNotify fields. Manage Groups right is required to query GroupNotify fields.
