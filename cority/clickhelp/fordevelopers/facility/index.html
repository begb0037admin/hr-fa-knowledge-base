Example: List Facilities in "Texas" division where the Unique Tag field is not empty and get values for facility custom fields:

select

div."State or Territory" as State,

f."Facility Number" as FacilityNumber,

f."Region" as Region,

f."Market/District" as MarketDistrict,

f."Facility Category" as Category

from

Facility f

left join ComplianceObject div on div is parent f and div.Type = 'D'

where

f."Unique Tag-Integration" != '' and div."State or Territory" = 'Texas'

order by

div.State, f."Facility Number"

Permissions:  Requires Report permission on the target object. Manage Custom Fields is required to query CustomFieldTemplate fields. Manage Calculation Templates right is required to query CalculationTemplate fields.
