enviancesdk.materialGroups.materialGroupInfo

Description

Represents a Material Group definition.

Properties

id The id string (GUID) for the Material Group.
Ignored for: Create Material Group, Update Material Group

name The name of the Material Group.
Required for: Create Material Group

description The description of the Material Group.

materials Array. An array of Material id strings (GUIDs) or names. Any string that matches the pattern of a GUID is interpreted as an id string, and not a name.
Required for: Create Material Group

Example

envianceSdk.materialGroups.MaterialGroupInfo (name, description, materialIdOrNames)

}
