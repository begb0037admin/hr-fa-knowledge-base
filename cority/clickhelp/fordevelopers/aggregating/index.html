Aggregating

Aggregation functions include:

SUM

COUNT

AVG

MIN

MAX

STDEV

STDEVP

VAR

VARP

GROUPING (Management System EQL only)

CUBE (Management System EQL only) (see below)

ROLLUP (see below)

STRING_AGG (Management System EQL only) (see below)

Aggregate functions return a single result row based on groups of rows, rather than on single rows. In a query containing a GROUP BY clause, EQL applies the aggregate functions to each group of rows and returns a single result row for each group. Each table column in any non-aggregate expression in the SELECT list must be included in the GROUP BY list.

There is no specific in its usage, distinct/all options are supported. Notice that aggregation functions (and corresponding Group By) can be used for Custom Fields as well.

Example 1:

select

avg(distinct dp.Value)

from Requirement r

inner join DataPoint dp on r

where

r.Name like 'Parameter%'

Example 2:

select

avg(distinct dp.Value)

from

Requirement r

inner join DataPoint dp on r

where

r.Name like 'Parameter%'

Example 3:

select

sum(dp.Value)

from

Requirement r

inner join DataPoint dp on r

where

r.Name like 'Parameter%'

Example 4:

select

sum(l.InternalLow)

from limit l

Example 5:

select

count(co.TemplateName),

co.TemplateName

from ComplianceObject co

group by co.TemplateID,co.TemplateName

order by count(co.TemplateName) desc

ROLLUP

ROLLUP generates a result set that shows aggregates for a hierarchy of values in the selected columns.

GROUP BY Item, Color WITH ROLLUP

Item Color Quantity
Chair Blue 101
Chair Red 210
Chair ALL 311
Table Blue 124
Table Red 223
Table ALL 347
ALL ALL 558

CUBE

Note: 'CUBE' is only available for the Management System EQL.

CUBE generates a result set that shows aggregates for all combinations of values in the selected columns.

CUBE result set is the same, except these two additional rows are returned at the end:

ALL Blue 225
ALL Red 433

 

Full list with CUBE:

GROUP BY Item, Color WITH CUBE
