CheckEmail

Checks if a given email exists in the system. Returns dummy Identifier. An error is returned if no email found.

SendEmail

Sends an email message to a target email address.

SendEmailWithNamesByIDs

Sends an email message to a target email address passing a list of objects identified by their ID as a parameter.

SendEmailWithNamesByTags

Sends an email message to a target email address passing a list of objects identified by their Tag as a parameter.
