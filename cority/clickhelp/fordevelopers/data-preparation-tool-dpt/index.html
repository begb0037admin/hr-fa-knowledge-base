Data preparation tool (DPT)

DPT is an interface for interacting with the EQL web service. DPT  is an EMS App which can be copied to customer systems on request.

Supported Browsers for the DPT App include IE, Firefox and Chrome. It can be accessed via tablet or mobile device using a compatible browser.

From the DPT you can:

  • Construct and run EQL queries and visualize results.
  • Click an example query to copy it to the query editor, then edit it as desired.
  • View available tables and properties and click to add an item to your query.
  • Download results in Excel/CSV, XML, or JSON formats
  • Create multiple queries and save queries for re-use.

By default the result is displayed in table view, but can be switched to one of the alternate formats.

Constructing a query

You can construct a query in several ways:

  • Select a Recent Query or an Example Query from the list in the pane on the right. The query is copied into the query editor, where you can edit it as desired.
  • Type your query directly in the query editor. To help you in selecting properties and syntax, you can select a table from the lower pane on the right to expand it and view properties. You can enter the property name or click it in the table list to add it to the query editor window at the current cursor position.
  • To re-run a saved query, select the appropriate query tab. You can then run the query as is, or edit it first.
  • Click Run to run the query.

Error messages are displayed at the top of the results pane. In case of syntax error, the editor highlights the specific batch/line raised by the error. Correct any errors and click Run again.

When the query is successful, the first 10 results are displayed in the results table. To view more results, change the number of results with the "Page size" drop-down. You can view as many as 1000 results in the console. However, page size is disregarded when downloading.

To download all results:

  1. Select the desired format (CSV/Excel, XML or JSON).
  2. Click Download All. (Page size in view is disregarded.)

The file is saved as a text file. To convert CSV/Excel results to Excel, change the extension to .csv. Open the file in Excel and choose Save As Excel.

DPT  Features:

  1. Support for EQL code highlighting
  2. Support for auto-completion. As you type, press CRTL+SPACE to activate auto-completion
  3. Full screen mode ( CRTL+F)
  4. Highlighting of the current line
  5. Selected word highlighting
  6. Auto indent like in previous line

DPT Keyboard shortcuts:

Keyboard ShortcutAction
Ctrl-SpaceAuto completion after a table alias.
Ctrl-RRun query.
Ctrl-A (PC), Cmd-A (Mac)Select the whole content of the editor.
Ctrl-D (PC), Cmd-D (Mac) Deletes the whole line under the cursor, including newline at the end.
Ctrl-Backspace (PC) Cmd-Backspace (Mac) Delete the part of the line before the cursor.
Ctrl-Z (PC), Cmd-Z (Mac) Undo the last change.
Ctrl-U (PC), Cmd-U (Mac) Undo the last change to the selection, or if there are no selection-only changes at the top of the history, undo the last change.
Ctrl-Up (PC), Cmd-Up (Mac) Move the cursor to the start of the document.
Ctrl-Down (PC), Cmd-End (Mac), Cmd-Down (Mac) Move the cursor to the end of the document.
Alt-Left (PC), Cmd-Left (Mac), Ctrl-A (Mac) Move the cursor to the start of the line.
Alt-Right (PC), Cmd-Right (Mac), Ctrl-E (Mac) Move the cursor to the end of the line.
Home Move to the start of the text on the line, or if already there, to the actual start of the line (including white space).
Ctrl-F Toggle fullscreen mode
ESC Exit from the fullscreen mode
Ctrl-Del Alt-D (Mac) Delete up to the end of the word after the cursor.
Shift-Tab Auto-indent the current line or selection.
Ctrl-] (PC), Cmd-] (Mac) Indent the current line or selection by one indent unit.
Ctrl-[ (PC), Cmd-[ (Mac) De-indent the current line or selection by one indent unit.
Tab If something is selected, indent it by one indent unit. If nothing is selected, insert a tab character.
