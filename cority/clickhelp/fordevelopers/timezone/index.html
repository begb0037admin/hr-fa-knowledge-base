Example (converts datetime to a time zone):

select top 20

dp.Collected as dbTime,

localtime(dp.Collected, tz) as localtimeCollected

from Facility f

join TimeZone tz on f

join Requirement r on r is under f

join DataPoint dp on r

Example: Get task due dates with task time zone.

select

t.Name,

ti.DueDateTime,

t.TimeZone.Name

from Task t

join TaskInstance ti on t

where ti.DueDateTime between '01/01/2014' and '06/01/2014'
