ComplianceObjectLock

Columns

ComplianceObjectID Compliance Object ID

DaysPreviousCurrentDate Indicates the number of days locked previous to the current date.

ExplicitUser.ID, ExplicitUser.FirstName... Composite column to User table (includes all fields from User). Returns only those users granted explicit lock to ComplianceObjectID. Native ObjectUserAccessLag.UserID .

ExplicitGroup.ID, ExplicitGroup.Name... Composite column to Group table (includes all fields from Group). Returns only those groups granted explicit lock to ComplianceObjectID. Native ObjectGroupAccessLag.GroupID .

User.ID, User.FirstName... Composite column to User table (includes all fields from User). Returns combination of users with explicit lock and users who are members of lock groups (no duplicates).

Natural Joins

ComplianceObject

Example: 

select

c.path,

c.name,

col.ComplianceObjectID,

col.DaysPreviousCurrentDate,

col.ExplicitGroup.Name,

col.ExplicitUser.ID,

col.ExplicitUser.email,

col.user.Email

from ComplianceObjectLock col

join ComplianceObject c on col

Permissions:  Requires Report permission on the target object.
