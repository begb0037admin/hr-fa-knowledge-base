Search Tags Under Settings

The tool for Search Tags Under Settings allows you to specify system levels or specific objects under which Calculated Requirement will search other requirements to resolve them in Tag Aggregation Calculation.

Download the Excel template file:

Search Tags Under Settings Tool

Use the Edit Calc Tag Settings worksheet to search requirements with applicable tags.

Edit Calc Tag Settings columns:

Calculation Requirement Path and Name: In this column, the full path and name of the calculated requirement are specified. Do not include the System Model or Locations and Programs names. The path starts with a backslash ( \ ); a backslash at the end is optional. Example of a valid path: \Division\Facility\Unit\POI\Calc.    

Search Tags Under System Levels: In this column, only Search Tags Under property can be specified. Available values are: Entire System, Division, Facility, Unit, and  POI. Only one property can be specified in the cell; only parents' locations can be specified. For example: if Calc is located under Facility, only EntireSystem, Division or Facility values can be specified.

Search Tags Under Specific Object Path: In this column, the location path is specified. Tags associated with a tree object in the requirements' direct hierarchy path are searched. The path starts with a backslash ( \ ).
