Path Report full path

IsFolder Is a report folder?

Natural Joins

ReportVersion

ReportPermission

Example: Get report details with last run date.

select

r.Name,

r.Description,

r.Type,

r.Created,

v.LastRun

from Report r

join ReportVersion v on r

Permissions:  Requires Report permission on the target object or Manage Reports right.
