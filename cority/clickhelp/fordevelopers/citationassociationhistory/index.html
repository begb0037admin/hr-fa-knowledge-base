CitationAssociationHistory

Columns

CitationVersionID Citation version ID

ObjectID Citation object ID

AssociationType Association Type Text value: ' LatestVersion' or ' FixedVersion'

AssociationDate Date Association made

RemovalDate Date Association removed

Created Created date

Updated Updated date

Natural Joins

Citation

Example: 

select

c.Name as Citation,

c.AssociatedRequirement.Name as Requirement,

h.AssociationDate,

h.AssociationType

from Citation c

join CitationAssociationHistory h on h.CitationVersionID=c.VersionID

Permissions:  Manage Citations right OR View/Modify Permission on specific citation(s) is required to access this table. If User does not meet both requirements, no security error occurs, but empty data is returned.
