Planning for Data Integration

Planning for data integration should be done as early as possible in the implementation process. Following are some important considerations.

Data Source

Define the incoming data source: Typically data may need to be pulled from several sources. For each source, you will need to define:

File

  • File location on customer server
  • Sample file to be sent to EMS
  • Column mapping or custom formatting

Database

  • Type of database
  • Query to pull data
  • Editable list of tags/requirements to send to EMS
  • Connection type (connection string, DSN)
  • Sample database

Time Zone issues

Most data collected by continuous emission monitoring equipment never switches between daylight saving time and standard time. Often this will also apply to data that is utilized in more than one time zone. If this is the case, the Management System needs to be configured to collect data on standard time only. Determine if the time stamp on the collected data switches between daylight saving time and standard time.

Important:   The time zone must be correctly set up before any data is entered in the system. (This includes any auto parameters which may be used.) For any project that will include data integration, determine the time zone early on, before any major system implementation is begun.

Legacy Data

If you have legacy data that will need to be imported into the system, you will need to define the import scope. Some questions to ask: How much legacy data will need to be imported into the system? How many years? How many data points? Should notifications be turned off during this period? Can the legacy data be aggregated?

Application Used to Send Data

EMS Web Service APIs can be accessed by any application that can send data to Web Services. Many companies already have applications for sending and receiving data from third-party APIs, which can be leveraged for your EMS integration. For those who do not have an existing application or the resources to develop one, EMS provides an easy-to-install application called EIFL Connector.
