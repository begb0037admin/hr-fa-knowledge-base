WorkflowHistory

Columns

ID ID

WorkFlowInstanceID WorkFlow Instance ID

Created Date created

EventType Type of event that may occur during a workflow. Accepts one of these values: AddComment, EditStepData, ManualTransition,  EditWorkflow, CloseWorkflow, ReopenWorkflow, CreateChildWorkflow, DeleteChildWorkflow, CreateWorkflow, WorkflowAssignment

WorkflowStepID Workflow Step ID

CreatedByUser.ID, CreatedByUser.FirstName, ... Composite column to User table (includes all fields from User)

Natural Joins

WorkflowHistoryItem

WorkflowInstance

Example: Get "Incident" workflows created as child workflows, when they were created, and the user who created them.

select

wi.ID,

wh.EventType,

wt.Name,

wh.Created,

wh.CreatedByUser.FirstName,

wh.CreatedByUser.LastName

from WorkflowInstance wi

join WorkflowHistory wh on wi

join WorkflowHistoryItem hi on wh

join WorkflowType wt on wi

where wh.EventType = 'CreateChildWorkflow'

and wt.Name = 'Incidents'

Permissions:  Requires Report permission on owner workflow.
