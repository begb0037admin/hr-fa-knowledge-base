/chemicallists

POST

Description:

Creates a new Chemical List, alternately by copying an existing Chemical.

Security: Requires Manage Materials and Activities system right.

SDK API (create): envianceSdk.chemicallists.createChemicalList (chemicalListInfo, onsuccess, onerror)

SDK API (copy): envianceSdk.chemicallists.copyChemicalList (chemicalListInfo, copyFrom, onsuccess, onerror)

Parameters
Name Located in Description Required Schema
chemicalListCreate body Create Chemical List body info. Yes chemicalListCreate
Responses
Code Description
200 The id string (GUID) for the newly created Chemical List.

/chemicallists/{chemicalListIdOrName}

PATCH

Description:

Updates an existing Chemical List.

Security: Requires Manage Materials and Activities system right.

SDK API: envianceSdk.chemicallists.updateChemicalList (chemicalListIdOrName, chemicalListInfo, onsuccess, onerror)

Parameters
Name Located in Description Required Schema
chemicalListIdOrName path Either an id string (GUID) or a name uniquely identifying the Chemical List. Any string that matches the pattern of a GUID is interpreted as an id string, and not a name. A name string must be URL encoded. Yes string
ChemicalListInfo body A ChemicalListInfo structure. Some properties of this structure are ignored during this operation; see the details of this structure for more info. Yes chemicalListInfo
Responses
Code Description Schema
200 The id string (GUID) for the updated Chemical List. string

chemicalListCreate 

Creation info for Chemical List

Name Type Description Required
chemicalListInfo [ chemicalListInfo ] A chemicalListInfo structure No
copyFrom string The id string (GUID) of an existing Chemical List whose properties will be copied and used as the properties of the newly created Chemical List. No

chemicalListInfo 

Represents a Chemical List definition.

Name Type Description Required
id string The id string (GUID) for the Chemical List. Ignored for: Create Chemical List, Update Chemical List No
name string The name of the Chemical List. Required for: Create Chemical List No
description string Description of the Chemical List. No
chemicalListHistoryItem [ chemicalListHistoryItem ] An array of ChemicalListHistoryItem structures, specifying records which should be part of the Chemical List Limits history. Required for: Create Chemical List No
