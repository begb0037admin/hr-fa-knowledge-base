Date Functions

Among other SQL-like functions EQL supports datetime oriented function Day(), Month(), Year(), Datepart() IsNull(). Its syntax is similar to SQL syntax.

Day, Month, Year

Those functions return an integer that represents day, month or year of the specified date.
For example:

   Day (u.CreatedOn),

   Month(u.CreatedOn),

   Year(u.CreatedOn)

   from user u

DatePart

Returns an integer that represents the specified datepart of the specified date.

Syntax

DatePart(datepart, date)

The following table lists all valid datepart arguments.

Datepart Abbreviations

year

yyyy

quarter

qq, q

month

mm, m

dayofyear

dy, y

day

dd, d

week

wk, ww

weekday

dw

hour

hh

minute

mi, n

second

ss, s

millisecond

ms

The following example returns the same value as previous example using the Day, Month, Year functions.

   select

   DatePart(dd, u.CreatedOn) as [Day],

   DatePart(mm, u.CreatedOn) as [Month],

   DatePart(yyyy, u.CreatedOn) as [Year]

   from user u

DateDiff

Returns an integer that represents the difference between two specified dates.

Syntax

DateDiff(datetype, date, date)

The following table lists all valid datediff arguments.

Datetype Abbreviations

year

year, yyyy, yy

quarter

quarter, qq, q

month

month, mm, m

dayofyear

dayofyear, dy, y

day

day, dd, d

week

week, wk, ww

weekday

weekday, dw

hour

hour, hh

minute

minute, mi, n

second

second, ss, s

millisecond

millisecond, ms
nanosecond nanosecond, ns

Example :

  select
  DateDiff(dd, u.CreatedOn, u.LastVisit) as [Day],
  DateDiff (mm, u.CreatedOn, u.LastVisit) as [Month],
  DateDiff (yyyy, u.CreatedOn, '12.12.2017' ) as [Year],
  DateDiff (hh, u.CreatedOn, u.LastVisit ) as [Hour],
  DateDiff (minute, u.CreatedOn, u.LastVisit ) as [Minute],
  DateDiff (mcs, '1:00:00 PM', '1:00:01 PM' ) as [Microsecond]
  from user u

Now

Function returns the current UTC date and time as a datetime value without a time zone offset. Syntax:

Now()

Example:

select f.name, now() as [Now], f.createdOn

from Facility f

where datepart(mm, now()) = datepart(mm, f.CreatedOn)
