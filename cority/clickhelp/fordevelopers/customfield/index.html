addScalarFieldValue

Version 2.0

Other Versions:

Version 1.0

Description

This function will add a value for any scalar (single value) type of Custom Field other than date/time. For date/time values, see addDateFieldValue.

Parameters

name The name (not the caption) of the Custom Field.

value A scalar value.

Return Value

None

Example

object.addScalarFieldValue("SmallTextField", "small text");

object.addScalarFieldValue("NumericField", 2.5);

object.addScalarFieldValue("NumericAliasField", "pi");

object.addScalarFieldValue("BooleanField", true);

Or, using call chains:

object

.addScalarFieldValue("SmallTextField", "small text");

.addScalarFieldValue("NumericField", 2.5);

.addScalarFieldValue("NumericAliasField", "pi");

.addScalarFieldValue("BooleanField", true);

addDateFieldValue

Version 2.0

Other Versions:

Version 1.0

Description

This function will add a value for any date/time type of Custom Field.

Parameters

name The name (not the caption) of the Custom Field.

value Date. A date and time value or JavaScript Date object.

Return Value

None

Example

object.addDateFieldValue("DateTimeField", "2012-12-01");

Or:

object.addDateFieldValue("DateTimeField", new Date(2012, 11, 1));

addTimeFieldValue

Version 2.0

Other Versions:

None

Description

This function will add a value for any "time-valued" Custom Field.

Parameters

name The name (not the caption) of the Custom Field.

value A string in the format "hh:mm" for hours and minutes using the 24 hour clock or a JavaScript Date object. If a full date is included, only the hours and minutes will be extracted for the time, and the current local Date is used as the day.

Return Value

None

Example

object.addTimeFieldValue("TimeField", "13:00");

Or:

object.addTimeFieldValue("TimeField", new Date(2012, 11, 1, 13, 0));

addUrlFieldValue

Version 2.0

Other Versions:

Version 1.0

Description

This function will add a value for any hyperlink type of Custom Field.

Parameters

name The name (not the caption) of the Custom Field.

label The text label to use when displaying the hyperlink.

url A valid URL.

Return Value

None

Example

object.addUrlFieldValue("HyperLinkField", "google", "http://www.google.com");

addLinkedFieldValues

Version 2.0

Other Versions:

None

Description

This function will add a value for any linked-list style Custom Field.

Parameters

name The name (not the caption) of the Custom Field.

values Array. An array of strings. Each index N of the value array corresponds with level N+1 of the linked field.

Return Value

None

Example

object.addLinkedFieldValues("LinkedField", ["Animals", "Mammals", "Dogs"]);

addMultiFieldValues

Version 2.0

Other Versions:

Version 1.0

Description

This function will add a value for any multi-select style Custom Field.

Parameters

name The name (not the caption) of the Custom Field.

values Array. An array of strings. Each item in the value array corresponds with a selected value of the multi-select field.

Return Value

None

Example

object.addMultiFieldValue("MultiSelectField", ["Cats", "Horses", "Dogs"]);
