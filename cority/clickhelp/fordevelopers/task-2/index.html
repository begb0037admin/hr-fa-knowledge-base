/tasks

POST

Description:

Creates a new simple (single occurrence) Task definition, optionally copying the definition from another Task to the new Task.

Security: Requires Manage Tasks right.

SDK API (create): envianceSdk.tasks.createTask(taskInfo, onsuccess, onerror)

SDK API (copy): envianceSdk.tasks.copyTask(taskInfo, copyFrom, onsuccess, onerror)

Parameters
Name Located in Description Required Schema
taskCreateInfo body Task Create body parameters Yes taskCreateInfo
Responses
Code Description Schema
200 The id string (GUID) for the newly created Task. string
Copy Code
JSON
POST /ver2/TaskService.svc/tasks HTTP/1.1
Content-Type: application/json; charset=UTF-8
 
{
  "taskInfo": {
    "name": "Check Valves Monthly",
    "description": "Perform a spot check every month on the steam valves.",
    "dueDate": "2012-12-08T09:00:00",
    "timeZone": "USA Pacific",
    "assignor": "CGauss",
    "assignees": [{"userName": "LEuler"}, {"groupName": "Group A"}],
    "calendars": ["System", "My"],
    "objects": [
      "/A Facility/A Unit/A POI/Check Valves",
      "/A Facility/A Unit/B POI/Check Valves"
    ],
    "documents": ["/A folder/A subfolder/A document.doc"]
  }
}


/tasks/{taskId}

PATCH

Description:

Updates the properties of a simple (single occurrence) Task definition, potentially moving it to a new Location. Updating the object Location(s) of a Task effectively moves that Task to the new Location(s).

Security: Requires Manage Tasks right.

SDK API: envianceSdk.tasks.updateTask(taskId, taskInfo, onsuccess, onerror)

Parameters

GET

Description:

Gets information about an existing Task definition. Though it can be used to retrieve information about single occurrence or recurring Tasks, this API currently does not provide information about the notification or scheduling setup of the Task. For details of a particular Task occurrence on a given date and time, use getTaskOccurrence.

Security: Requires Manage Tasks right.

SDK API: envianceSdk.tasks.getTask(taskId, onsuccess, onerror)

taskOccurrenceInfo 

Represents a Task occurrence, on a single date and time, for a single object related to the Task.

Name Type Description Required
statusChangeDate dateTime An optional date and time at which the Task occurrence status was last updated. Default is the current date and time, in the Task time zone. Ignored for: Complete/Dismiss Task Occurrence No
objectIdOrPath string An id string (GUID) or path of a Compliance Model object, related to the Task, for which this Task occurrence information applies. Any string that matches the pattern of a GUID is interpreted as an id string, and not a path. If no object property is specified, the Task occurrence information relates to all objects associated with the Task. Ignored for: Complete/Dismiss Task Occurrence No
dismissed boolean An optional Boolean flag indicating whether or not this task occurrence should be dismissed (and not completed). If this value is True, no update will be made for percentComplete and statusChangeDate. Default is False. No
percentComplete number An optional integer between 0 and 100 specifying the percent completion of the Task occurrence. Default is 0 percent. No
hoursToComplete number An optional decimal value indicating a whole or partial number of hours required to complete the Task occurrence. Default is 0. No
costToComplete string An optional decimal value indicating the cost to complete the task occurrence. Currently, this value is in US dollars. Default is 0. No
comment string An optional comment about the completion of the Task occurrence. No
eventInstanceId string An id string (GUID) of an associated event instance. No

taskScheduleInfo 

Represents a simple (one time) Task definition. Properties startDate, endDate, startTime, endTime are specified in the timezone of the containing task (see timeZone property of taskInfo structure).

Name Type Description Required
recurrenceType string A string that defines the recurrence pattern of the Schedule. Required for any TaskScheduleInfo. No
startDate dateTime The date when the schedule becomes active (time portion of the date is ignored). Required for any TaskScheduleInfo Yes
endDate dateTime The date when the schedule becomes inactive (time portion of the date is ignored). If not specified then the schedule does not have an end date. No
startTime dateTime The time of a day at which the scheduled event should occur (in Hourly recurrence pattern, the time of a day when the schedule becomes active). Note that hours must be specified in the 24h format. For minutes only four values are allowed: 0, 15, 30, 45. Seconds are ignored. Yes
endTime dateTime The time of a day when the schedule becomes inactive (used only by Hourly recurrence pattern). Note that hours must be specified in the 24h format. For minutes only four values are allowed: 0, 15, 30, 45. Seconds are ignored. No
recurrenceInterval string Either an integer value or recurrenceInterval structure which defines the frequency of the recurring event. The structure is used for AfterLastCompletion recurrence pattern and integer value is used for all other patterns. Depending on the pattern the integer value could mean days, weeks, months, or years. No
daysOfWeek string An array of strings which defines the days of a week to use in certain recurrence patterns. Recognized day names are: Sunday, Monday, Tuesday, Wednesday, Thursday, Friday, Saturday. Shortcut names that can also be used are: All, Weekdays, Weekends. No
dayOfMonth string Either an integer value or DayOfMonth structure which defines the day of a specific month. Integer value specifies the number of the day within a month (possible values are 1 to 31). The structure is used for more advanced specification of the day of a month. This property is used only for Monthly and Yearly recurrence patterns. No
monthOfYear integer An integer value which defines the month of a year. Possible values are: 1 to 12. No
TalLogicVersion integer Time After Last Completion Schedule logic version. Ignored for: Create Task, Update Task. No

recurrenceInterval 

Represents the advanced specification of a recurring interval. Used by AfterLastCompletion recurrence pattern only. The purpose of this structure is to simplify specification of long intervals. The resulting value of the structure can be expressed as a single integer value specifying the number of hours of the interval.

Name Type Description Required
hours string (integer) An integer value which defines the number of hours of the recurrence interval. No
days string (integer) An integer value which defines the number of days of the recurrence interval. No
weeks string (integer) An integer value which defines the number of weeks of the recurrence interval. No
month string (integer) An integer value which defines the number of months of the recurrence interval. No

dayOfMonth 

Represents the advanced specification of the day of a month. The actual day of a month is uniquely identified by a combination of two properties. Using this structure the day of a month can be identified using the following rules: first day, last Friday, second weekday etc.

Name Type Description Required
dayOccurrence string A string that specifies the occurrence of the day within a month. No
dayOfWeek string A string that specifies the day of a week. No

notificationConditions 

Defines a set of conditions that will trigger the notification. It corresponds to the “Time To Notify” section on the task notification UI. All properties are optional, but at least one of them must be specified. Additional limitation is that “byDueDate” condition cannot be specified if “CompletionStatusCondition.onlyWhenPastDue = true”.

Name Type Description Required
immediately boolean A boolean value which indicates whether the notification should be triggered immediately upon the creation. No
whenDismissed boolean A boolean value which indicates whether the notification should be triggered when the task is dismissed. No
byDueDate string A dueDateCondition structure which defines whether the notification should be triggered when certain conditions for the task Due Date are met. No
byCompletionStatus string A completionStatusCondition structure which defines whether the notification should be triggered when certain conditions for the task completion status are met. No
