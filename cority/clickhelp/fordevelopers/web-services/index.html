Web Services

Note: Web services are only available for the Management System EQL.

Among a set of services EMS  provides is a Web service to execute EQL queries. Web service location:

https://webservices.enviance.com/eql/Eql.asmx

Methods

Tables ExecuteQuery(string eql)

This method returns result DataSet in xml representation.

Tables ExecuteQueryWithPaging(string eql, int currentPage, int pageSize)

This method returns result in pages.

int[] GetRecordsCount(string eql)

The number of records in the query result.

Session is identified from SessionHeader value of soap header.

This web services is used by EIFL projects.

Example of client code

string eql = "select top 10 f.name from facility";

var eqlService = new EqlSrv.Eql

{

Url = AppVars.EqlServicePath,

SessionHeaderValue = new SessionHeader { SessionID = UserSession.Current.SessionID }

};

 

Tables result;

result = eqlService.ExecuteQuery(eql);

 

For detailed information on Web Services (SOAP APIs), see the Web Services documentation.
