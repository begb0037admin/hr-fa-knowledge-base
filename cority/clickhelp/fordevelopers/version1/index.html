envianceSdk.authentication.authenticate

Version 1.0

Other Versions:

Version 2.0

Description

Creates a new session in the Management System by authenticating via username and password.

The result value is the id string for the newly created session.

Parameters

userName The user name string of the EMS User account.

password The password string of the EMS account.

onsuccess An optional callback function to handle the call result.

onerror An optional callback function to handle any call error.

Return Value

The id string (GUID) for the newly created session.

Notes

Upon successful authentication, the session id and home system id for the User are automatically persisted during the rest of the browser session, and used for all subsequent calls to the EMS APIs. Therefore, you should not have to worry about tracking the session id and passing it along to each API when using the SDK functions.

Example

envianceSdk.authentication.authenticate(“JSmith”, “1234”,

function(response) {

alert(“You have been logged in!”);

},

function(response) {

alert(“An error occurred trying to login: ” + response.error);

});

Notes

This API is is replaced in version 2.0 with envianceSdk.authentication.getCurrentSession

});

envianceSdk.compliance.selectComplianceObjects

Version 1.0

Other Versions:

Version 2.0

Description

This function queries for all Compliance Objects in the System Model to which the current User has access. An optional name filter may be specified.

Parameters

page The page number within the entire result set to return.

pageSize The number of records to assign to each page.

onsuccess An optional callback function to handle the call result.

onerror: An optional callback function to handle any call error.

nameFilter An optional string to filter Compliance Objects by name (full substring matching is used).

Return Value

The result is an EQL Table with the following columns:

ID

Name

Type

Path

WarningNotificationInbox

WarningNotificationEmail

TemplateName

CreateOn

ActiveDate

InactiveDate

ResponsibleUser

For more information on these fields, see the EQL documentation.

Example

envianceSdk.compliance.selectComplianceObjects(1, 10,

function(response) {

alert("First well by name: " + response.result.rows[0].values[0]);

},

function(response) {

alert("Error occurred retrieving well information.");

},

"Well"

);

None

Return Value

None

envianceSdk.configure

Version: 1.0

Other Versions:

Version 2.0

Description

Sets configuration parameters that control the behavior of the SDK.

Parameters

A JSON object literal with the following properties:

baseAddress A string containing the full URI to the EMS API host. Typically, this will be https://api.enviance.com. Default is null.

variablesManager Either "simple" or "cookies". This setting specifies which VariablesManager (i.e. local state manager) will be used by the SDK. Default is "simple".

sessionId The session id string of the current authenticated User. Typically the session id is set upon calling authenticate, so it should not be specified. Default is null.

systemId The current system id string in which APIs should operate. Typically the system id is set upon calling authenticate, so it should not be specified. Default is null.

crossDomainWorkaround Specifies whether or not the SDK will use alternative functions for making cross domain calls. Options are "ifneeded", "always", "off". When set to "ifneeded", the SDK will detect if the browser make and version requires it. Default is "ifneeded".

resubmitConfirmationOnError This Boolean setting controls whether or not the SDK will automatically prompt the User to retry an API call if it has timed out. Default is true.

Return Value

None

Notes

If you are writing an EMS App, calling the init function of the EMS Apps library will in turn call this function with the typical and appropriate configuration values, so you should not have to call this function yourself.

Example

envianceSdk.configure({

baseAddress: "https://api.enviance.com",

variablesManager: "simple",

crossDomainWorkAround: "ifneeded",

resubmitConfirmationOnError: false

});
