Permission Settings

Permission Settings are used to specify which App Roles have access to the Items and App Data in the EMS App.

For more information about how permission settings can be defined and how they are used to enforce access constraints, see EMS App Item Permissions and App Data Permissions.

The following is an example of permissions settings within a manifest.

<permissions>

<appData key="Default Options">

<allowRead roles="Everyone" />

</appData>

<appData key="Admin Options">

<allowRead roles="Admins" />

<allowWrite roles="Admins" />

</appData>

<item path="/manage/manage_plant.htm">

<allow roles="Manager; Auditor" />

<deny roles="Operator" />

</item>

<item path="/operate.html">

<allow roles="Everyone" />

</item>

<item path="/test.html">

<deny roles="Everyone" />

</item>

</permissions>
