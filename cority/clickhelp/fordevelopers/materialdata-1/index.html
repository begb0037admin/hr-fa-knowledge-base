/materialdata/deletedatacommands/{locationIdOrPathOrUniqueTag}

POST

Description:

Deletes all MDLGroups for a set of one or more Ids. Deleting MDLGroups is an asynchronous process. Upon successfully receiving and queueing the data, a command id is returned. With this command id, the Get Command API can be used to track completion or failure of the data entry command. Deletions are permanent.

SDK API: envianceSdk.materialData.deleteMaterialData (locationIdOrPathOrUniqueTag, mdlGroupIds, waitForCompletion, onsuccess, onerror)

Parameters
Name Located in Description Required Schema
locationIdOrPathOrUniqueTag path Either an id string (GUID) or the path or unique tag string for the object. A path string must be URL encoded. Yes string

Models

enterMdlData 

Wrapper for enter mdl data body parameters

Name Type Description Required
mdlGroupsInfo [ mdlGroupInfo ] An array of mdlGroupsInfo instances. No
partialProcess boolean Parameter for setting the validation mode (true=partial, false=full] No

deleteMdlData 

Delete mdl data body parameters

Name Type Description Required
mdlGroupIds [ string ] An array of MDLGroup ids (GUIDs) No
waitForCompletion boolean True/false indicator, whether system should wait for processing to complete before returning response. No

mdlGroupInfo 

A numeric measurement for a single MDLGroup with set of Data Lines. MDLGroup tied to the location, activity and a single date and time.

Name Type Description Required
parentIdOrPathOrUniqueTag string Either an id string (GUID) or path string for the object or Unique Tag. A path string must be URL encoded. No
activityIdOrNameOrUniqueTag string An id string (GUID) or name of the Activity or Unique Tag. No
complete string A date and time value, complete is uniquely identifying an MDLGroup in the MAC. No
collector string Name of user entering data. No
dataLines [ materialDataLinesInfo ] An array of materialDataLines. No

materialDataLinesInfo 

A set of one or more values for a MDLGroup tied to the material.

Name Type Description Required
startTime string A DateTime value, represent begin date for the Data Line. No
endTime string A DateTime value, represent end date for the Data Line. No
data [ materialDataLineValueInfo ] An array of Data Line Values No

materialDataLineValueInfo 

A set of one or more values for a Specific Use Variables, identified by name. SUV’s tied to the one of Activities from MAC.

Name Type Description Required
propertyIdOrNameOrUniqueTag string The name (not caption) of the SUV or Unique Tag No
value number A floating point numeric value. Both standard and scientific notation are valid formats. No
