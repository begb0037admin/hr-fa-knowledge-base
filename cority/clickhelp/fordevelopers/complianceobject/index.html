Example: Get compliance objects matching a name string and the associated custom field templates and calculation templates.

select

co.Name,

co.Path,

co.CustomFieldTemplate.Name,

co.CalculationTemplate.Name

from ComplianceObject co

where co.Name like '%Tank%'

Example: List the top 20 compliance objects where the value for a numeric UDF is between 5 and 20.

select top 20

co.ID,

co."Numeric Udf"

from

ComplianceObject co

where

co."Numeric Udf" between 5 and 20

Permissions:  Requires Report permission on the target object. Manage Calculation Templates right is required to query CalculationTemplate fields. Manage Custom Fields right is required to query CustomFieldTemplate fields.
