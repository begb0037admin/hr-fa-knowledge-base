/packages

Description:

Creates a new EMS App (package), optionally with content copied from another existing EMS App.

Security: Requires Manage EMS Apps system right.

SDK API: envianceSdk.packages.createPackage(packageInfo, onsuccess, onerror)

Parameters

Responses
Code Description Schema
200 The id string (GUID) for the new EMS App. string

/packages/{packageIdOrName}/data/{key}

GET

Description:

Retrieves an existing EMS App (Package) data key-value pair, using the specified unique key. If user does not have permissions to retrieve data it returns empty string. No Errors thrown.

Security: Requires Manage EMS Apps system right.

SDK API: envianceSdk.packages.getPackageAppData(packageIdOrName, key, onsuccess, onerror)

Parameters
Name Located in Description Required Schema
packageIdOrName path The id string (GUID) or name of the EMS App. Any string that matches the pattern of a GUID is interpreted as the id and not the name. A name string must be URL encoded. Yes string
key path The unique key for the data value, URL encoded. Yes string
dtype query The type of data. json for JSON object, otherwise - string. No string
Responses
Code Description
200 The string data (typically JSON) stored with the key.

JSON

PUT

Description:

Saves an EMS App (package) data key-value pair, associated with a specified unique key. Keys must be unique for a single EMS App, but can be non-unique across EMS Apps. If the key specified already exists, any data currently saved with that key will be overwritten. If user does not have permissions to retrieve data then it throws Error.

Security: Requires Manage EMS Apps system right.

SDK API: envianceSdk.packages.savePackageAppData(packageIdOrName, key, value, onsuccess, onerror)

Parameters
Name Located in Description Required Schema
packageIdOrName path The id string (GUID) or name of the EMS App. Any string that matches the pattern of a GUID is interpreted as the id and not the name. A name string must be URL encoded. Yes string
key path The unique key for the data value, URL encoded. Yes string
value body The body is a simple JSON object that can hold any string or JSON object literal. Yes string
dtype query The type of data. json for JSON object, otherwise - string. No string
Responses
Code Description
204 None
Copy Code
JSON
PUT /ver2/PackageService.svc/packages/Incident%20Tracker/data/pageconfig HTTP/1.1
 
{
"field1": { "type": "text", "values": ["a","b","c"] },
"field2": { "type": "numeric" }
}

packageInfo 

The properties and metadata for an EMS App (Package).

Name Type Description Required
id string The id string (GUID) for the EMS App. Ignored for: Create EMS App, Update EMS App No
name string The name of the EMS App. Required for: Create EMS App No
description string The description of the EMS App. No
content string The content of the Package in a zip file, Base64 encoded. No
displayPage string The path, relative to the root of the EMS App, to an Item which can serve as default page to be displayed when loading the App. This should be an HTML page. No
iconSrc string The path, relative to the root of the EMS App, to an Item which can serve as the icon for the EMS App, typically an image file. No
isLocked boolean A Boolean flag indicating whether or not the EMS App is locked. No
created string The date and time when the EMS App was first created. Ignored for: Create EMS App, Update EMS App No
createdBy string The User name of the User who first created the EMS App. Ignored for: Create EMS App, Update EMS App No
lastModified dateTime The date and time when the EMS App was last modified. Ignored for: Create EMS App, Update EMS App No
