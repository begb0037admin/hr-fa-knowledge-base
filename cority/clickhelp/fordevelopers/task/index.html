envianceSdk.tasks.createTask

Version 2.0

Other Versions:

None

Description

Creates a new simple (single occurrence) Task definition.

Parameters

taskInfo An instance of the taskInfo object. Some properties of this object are ignored by this function; see details of this object for more info.

Return Value

The id string (GUID) of the new Task will be passed to the onsuccess callback in the result property.

Example

envianceSdk.tasks.createTask(taskInfo,

function(response) {

alert("Created new task with id: " + response.result);

});

envianceSdk.tasks.copyTask

Version 2.0

Other Versions:

None

Description

Creates a new Task definition as a copy of an existing Task definition.

Parameters

});

Description

Specifying path(s) associates the Task to the specified Location(s) – and removes any unspecified associations.

Parameters

taskId The id string (GUID) for an existing Task.

taskInfo An instance of the taskInfo object. Some properties of this object are ignored by this function; see details of this object for more info.

Return Value

None

Example

"ddef6b59-6289-41c9-ac7a-ee87a773ce0e",

taskInfo,

function(response) {

alert("Task updated.");

});

envianceSdk.tasks.getTask

Version 2.0

Other Versions:

None

Description

Gets information about the specified Task definition. Though it can be used to retrieve information about single occurrence or recurring Tasks, this function currently does not provide information about the notification or scheduling setup of the Task.

Parameters

taskId The id string (GUID) for an existing Task.

Return Value

A taskInfo object will be passed to the onsuccess callback in the result property.

Example

envianceSdk.tasks.getTask("ddef6b59-6289-41c9-ac7a-ee87a773ce0e",

function(response) {

var task = response.result;

alert("Retrieved task with name: " + task.name);

});

envianceSdk.tasks.getTaskOccurrence

Version 2.0

Other Versions:

None

Description

Gets information about a Task occurrence.

Parameters

taskId The id string (GUID) for an existing Task.

dueDate Date. The date and time when the Task occurrence is due.

objectIdOrPath An optional object specifier, as an id string (GUID) or path, uniquely identifying an object in the Compliance Model to which the Task is associated. Any string that matches the pattern of a GUID is interpreted as the id string, and not the path of the object.

Return Value

An array of TaskOccurrenceInfo objects, one for each object to which the Task is associated, will be passed to the onsuccess callback in the result property. When an object id or path is specified, this array will have only a single element.

Example

envianceSdk.tasks.getTaskOccurrence(

"ddef6b59-6289-41c9-ac7a-ee87a773ce0e",

"2013-09-19T20:00:00",

"2d4fc954-b062-433d-9405-ce709c36a353",

function(response) {

var occurrence = response.result;

alert("Task occurrence is % complete:" + occurrence.percentComplete);

});

envianceSdk.tasks.taskInfo

Version 2.0

Other Versions:

None

Description

Constructs a TaskInfo object instance in JavaScript.

Parameters

name The name of the Task.

description A description.

dueDate Date. The due date of the Workflow.

timeZone The name of a time zone for the Task.

assignor The assignor of the Task.

assignees Array. An array of UserAssignees and/or GroupAssignees.

calendars Array. An array of strings listing the types of EMS calendars on which this Workflow is shown. Valid values are "My", "Object", "System".

objects Array. An array of Compliance Model object id strings (GUIDs) or paths, specifying zero or more Compliance Model objects to which the Task is associated. Any string that matches the pattern of a GUID is interpreted as an id string, and not a path.

documents Array. An array of Document id strings (GUIDs) or paths, specifying zero or more Documents attached to the Workflow. Any string that matches the pattern of a GUID is interpreted as an id string, and not a path.

schedules Array. An array of strings specifying the task schedules.

notifications Array. An array of strings specifying the task notifications.

templateIdOrName Array. An array of strings specifying the notification template ID or name.

workflowtrigger Array. An array of strings specifying the workflow trigger options.

Return Value

An instance of the TaskInfo class.

Instance Methods

addPathAssociatedObject(objectPath) This is a convenience method to add an object path to the objects array property.

addIdAssociatedObject(objectId) This is a convenience method to add an object id to the objects array property.

addUserAssignee(userIdOrName) This is a convenience method to add a UserAssignee to the assignees array property.

addGroupAssignee(groupIdOrName) This is a convenience method to add a GroupAssignee to the assignees array property.

addDocument(path) This is a convenience method to add a Document by path to the documents property.

addSchedule This is a convenience method to add a Schedule to the schedules array object.

addNotification This is a convenience method to add a notification to the notifications array object.

Example

var task = new envianceSdk.tasks.TaskInfo(

"One Time Walk Through",

"In response to a hazard report, walk through the facility.",

"2013-09-30T00:00:00",

"Pacific Time (US & Canada) (UTC-08:00) (With DST)",

"jsmith",

null, // no assignees here

["My", "Object"],

["/Division A/Facility X", "/Division A/Facility B"],

["/Tasks/WalkthroughChecklist.xls"]

);

task.addUserAssignee("jsmith").addGroupAssignee("Administrators");

envianceSdk.tasks.TaskOccurrenceInfo

Version 2.0

Other Versions:

None

Description

Constructs a TaskOccurrenceInfo object instance in JavaScript.

Parameters

objectIdOrPath An id string (GUID) or path of a Compliance Model object, related to the Task, for which this Task occurrence information applies. Any string that matches the pattern of a GUID is interpreted as an id string, and not a path. If no object property is specified, the Task occurrence information relates to all objects associated with the Task.

dismissed An optional Boolean flag indicating whether or not this Task occurrence should be dismissed (and not completed). If this value is True, no update will be made for percentComplete and statusChangeDate. Default is False.

percentComplete Number. An optional integer between 0 and 100 specifying the percent completion of the Task occurrence. Default is 0 percent.

hoursToComplete Number. An optional decimal value indicating a whole or partial number of hours required to complete the Task occurrence. Default is 0.

costToComplete Number. An optional decimal value indicating the cost to complete the Task occurrence. Currently, this value is in US Dollars. Default is 0.

comment An optional comment about the completion of the Task occurrence.

statusChangeDate Date. An optional date and time at which the Task occurrence status was last updated. Default is the current date and time, in the Task's time zone.

eventInstanceId String. The id (GUID) of an associated event instance.

Return Value

An instance of the TaskOccurrenceInfo class.

Example

var taskOccurrence = new envianceSdk.tasks.TaskOccurrenceInfo(

"/Division A/Facility X/Unit Y",

false,

80,

2.5,

1200.25,

"Still some more work to do here.",

2017-04-17T16:28:55,

"7d431e4d-ea20-43a9-b0ef-81e191504eb2"

);

envianceSdk.tasks.TaskNotificationInfo.NotificationConditions

Description

Constructs a NotificationConditions object instance in JavaScript.

Parameters

immediately Boolean. True/false value indicating whether the notification should be triggered immediately upon the creation.

whenDismissed Boolean. True/false value indicating whether the notification should be triggered when the task is dismissed.

byDueDate A DueDateCondition structure which defines whether the notification should be triggered when certain conditions for the task Due Date are met.

byCompletionStatus A CompletionStatusCondition structure which defines whether the notification should be triggered when certain conditions for the task completion status are met.

Return Value

An instance of the NotificationConditions class.

Notes

All these properties are optional, but at least one of them must be specified. There is an additional limitation: you cannot specify "byDueDate" condition if "CompletionStatusCondition.onlyWhenPastDue = true

envianceSdk.tasks.TaskNotificationInfo.DueDateCondition

Description

Constructs a DueDateCondition object instance in JavaScript.

Parameters

conditionType A string which specifies the type of the condition. Must be one of the following:
"IntervalBefore" - The notification must be triggered the specified interval before the task Due Date.
"IntervalAfter" - The notification must be triggered the specified interval after the task Due Date.
"PastDue" - The notification must be triggered when the task is past due.

intervalValue Number. An integer value which defines the interval (ignored for conditionType=PastDue)

intervalType A string which defines the type of the interval (ignored for conditionType=PastDue). Must be one of the following:
"QuarterHour", "Hour", "Day", "Week", "Month", "Year"

Return Value

An instance of the DueDateCondition class.

envianceSdk.tasks.TaskNotificationInfo.NotificationRecipients

Description

Constructs a NotificationRecipients object instance in JavaScript.

Parameters

toAssignees Boolean. A boolean value which indicates whether the notification should be delivered to the task assignee(s).

toAssignor Boolean. A boolean value which indicates whether the notification should be delivered to the task assignor.

users An array of id strings (GUIDs) which defines specific users to deliver the notification to.

groups An array of id strings (GUIDs) which defines specific groups to deliver the notification to.

Return Value

An instance of the NotificationRecipients class.

Notes

All properties are optional but at least one of them must be specified.

envianceSdk.tasks.TaskNotificationInfo.CompletionStatusCondition

Description

Constructs a CompletionStatusCondition object instance in JavaScript.

Parameters

completionPercent An integer value which defines the percentage of the task completion that should trigger the notification. Possible values are from 0 to 100, with increments of 10 percent.

comparisionLogic A string which defines how the task's completion status should be compared to the completionPercent property to trigger the notification. Must be one of the following:
"=", "<", ">", "<=", ">="

onlyWhenPastDue A boolean value which indicates that the notification must be triggered only if the task is past due. Optional.

Return Value

An instance of the CompletionStatusCondition class.
