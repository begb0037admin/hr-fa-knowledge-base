Citation Management Tool

The Citation Management Tool can be used to create citation folders, create and edit Citations, and associate Citations with objects.

Download the Excel template file:

Citation Management Tool

Preparation

Consult any build documents used to identify and specify all citations and associations to be placed in the system. Identify and mark any assets that are not currently in the system but that have associated citations. Use the Object Copy Tool or manual configuration to add these to the system.

Run a Citations Report if you will be using the upload tool to edit properties or object associations of existing Citations. You can then copy identifying information into the upload file.

The Citation Management Template file contains four worksheets:

  • Citation Folders to be Added
  • Citations to be Added
  • Citation Properties and Values
  • Associations

Keep in mind that each worksheet may be processed separately. So you may create your folders and citations first, then use the same file to add or edit property values and associations in a subsequent processing job.

Citation Folders to be Added

Use this worksheet to add new folders to the system.

Parent Path and Name: Path to folder from Citations root. Do not include the System Model name or Citations root folder name. Include a backslash (“\") at the beginning but not at the end. To add folders and/or citations directly under the root (Citations), use only the backslash ("\").

Folder Name: Name of new Citations folder to create.

1 Parent Path and Name New Folder Name
2 \ NPDES
3 \NPDES Folder 1

 

Citations to be Added

This worksheet is for new citations only. If you are editing properties of existing citations, you do not need to complete this sheet.

Parent Path and Name: Path to parent folder. (See path notes above.) Enter an existing folder or select a folder path from the drop-down list, which is populated with the folders created on the previous worksheet.

Citation Name: Display name for citation

Citation Identifier: Citation ID (generally citation number)

Active Date: Must be valid date format (mm/dd/yy or mm/dd/yyyy)

  A B C D
1 Parent Path and Name Citation Name Identifier Active Date
2 \NPDES\Folder 1 Citation 1 AB 123 1/1/2010
3 \NPDES\Folder 1 Citation 2 AB 456 1/1/2010

 

Citation Properties and Values

Use this worksheet to enter property values for existing citations, or new citations created with the previous sheet. Use the Identifier (not the name) to identify Citations. You will need one row for each property. (For example, if you are entering values for four properties of the same citation, you will need four lines for that citation.)

Identifier: Select the identifier from the drop-down list. The list is populated with the citation identifier values from the previous worksheet. Or enter the citation identifier for an existing citation in the system.

New Version: If you are editing an existing citation and want to create a new version with the new property value, select Yes. If you select No, the current version values will be edited. If you are creating new citations, select No.

Version Number: Enter the version number to which the value applies. If you are creating new citations, use '1' for the version number. If blank, the New Version? field defaults to 'yes' and the system will automatically increment the version number.

Note:  Since each line is processed sequentially, to avoid creating multiple versions, you will need to know the next version number of the citation and use the same version number on all subsequent lines if you are editing multiple property values. Otherwise, each new property line will create a new version.

Property Name: Select the property name from the drop-down list. The list contains all standard citation properties.

Property Value: Enter the property value. To delete an existing value, enter <clear>.

Associations

Use this worksheet to associate citations with objects in the System Model.

Path and Name of Object: Path of object to associate, from Locations & Programs root up to and including the object name. Do not include System Model name. Include"\" at beginning, but not at the end.

Citation Identifier: Select the identifier from the drop-down list. The list is populated with the citation identifier values from the previous worksheet. Or enter the citation identifier for an existing citation in the system.

Associate Current Version? Select Yes to associate object with latest version. Select No if you want to associate the object with a specific version, and enter version number in next column.

Version Number to Associate: Enter citation version number to associate. If Associate Current Version?=Yes, leave blank and the system will associate the current version.

Action: Enter"add" to add association. Enter "delete" to delete existing association.
