Overview of EMS Apps

A runtime environment called EMS Apps allows customers and third parties to upload "packages" of static files (typically HTML and JavaScript files) to be hosted within the Management System. These EMS Apps are subject to, and able to utilize, EMS User context and authorization controls.

EMS Apps provide customers and third parties the ability to extend the look and feel of the interface, and combine existing data and functionality in new ways.

What Are EMS Apps?

An EMS App is a collection of client side (web browser) code which is deployed, configured, and managed, within the Management System.

It is important to note that an EMS App executes its custom code almost entirely within the User's browser. EMS Apps use JavaScript, HTML, and CSS to define visualizations and the logic behind them.

EMS Apps utilize the EMS Apps SDK in order to push data to, or pull data from, the Management System.
