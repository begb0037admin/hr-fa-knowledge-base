TaskSchedule

Columns

RecurrenceType Task Schedule Recurrence Type (Single, Hourly, Daily, Weekly, Monthly, Yearly, TimeAfterCompletion)

PeriodStart Task recurrence schedule: Period Start DateTime

PeriodEnd Task recurrence schedule: Period End DateTime

Created Date created

Updated Date updated

HourlyStart Task recurrence schedule for hourly tasks: Start time

HourlyEnd Task recurrence schedule for hourly tasks: End time

NextOccurrenceTime This is an internal schedule used by recurrent services, which is not intended for external use. To get due date/time for of next task occurrence, use TaskInstance.DueDateTime.

Detail Task Schedule details

TalLogicVersion Version number of logic for Time After Last Completion Schedules

Natural Joins

Task

Example: Get monthly scheduled tasks, task assignees and schedule details.

select

t.Name as TaskName,

t.Description,

t.AssignedToUser.FirstName,

t.AssignedToUser.LastName,

t.AssignedToGroup.Name as GroupAssignee,

t.Schedule.RecurrenceType,

t.Schedule.Detail,

t.Schedule.PeriodStart

from Task t

Permissions:  Requires View permission on the target object.
