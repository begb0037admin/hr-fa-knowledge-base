MaterialActivityTemplate

Columns

ID Material/Activity Template ID

Name Material/Activity Template Name

Description Material/Activity Description

Created Date Created

Updated Date Updated

CustomField.ID, CustomField.Name, ... Composite column to CustomField table (includes all fields from CustomField)

CustomField.[Order] Order of the custom field in the template

Natural Joins

None

Example: Get Material Activity Template name and associated fields.

select

mt.name,

mt.CustomField.Name

from MaterialActivityTemplate mt

Permissions:  Manage Material Templates right is required to query this table. Manage Custom Fields is required to query CustomField composite fields.
