Geographical Functions

Distance

Note: The 'Distance' function is only available for the Management System EQL.

Function returns the distance in kilometers between two points, using the latitude and longitude properties of the object. Value is rounded to 6 numbers after the decimal point.

Example:

select

distance(f1.LatDecimal,f1.LongDecimal, f2.LatDecimal, f2.LongDecimal)

from facility f1

inner join facility f2 on f2.name = 'Facility 2'

where f1.name = 'Facility 1'
