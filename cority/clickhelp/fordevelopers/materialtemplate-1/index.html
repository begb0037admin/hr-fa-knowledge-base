/materialTemplates

POST

Description:

Creates a new Material Template, alternately by copying an existing Material Template.

SDK API (create): envianceSdk.materialTemplates.createMaterialTemplate (materialTemplateInfo, onsuccess, onerror)

SDK API (copy): envianceSdk.materialTemplates.copyMaterialTemplate (materialTemplateInfo, copyFrom, onsuccess, onerror)

Parameters
Name Located in Description Required Schema
materialTemplateCreate body Create materialTemplate info body. Yes materialTemplateCreate
Responses
Code Description Schema
200 The id string (GUID) for the new Material Template. string
Copy Code
JSON
/EXAMPLE (Create)

POST/MaterialTemplateService.svc/materialTemplates HTTP/1.1
Content-Type: application/json; charset=UTF-8
 
{
  "materialTemplateInfo ": {
    "name": "Material Template Name",
    "description": "Material Template Description",
    "fields": ["udf field name 1", "udf field name 2"]
  }
}
Copy Code
JSON
EXAMPLE (Copy)
POST/MaterialTemplateService.svc/materialTemplates HTTP/1.1
Content-Type: application/json; charset=UTF-8
 
{
  "materialTemplateInfo": {
    "name": "Copied Material Template Name",
    "description": "Copied Material Template Name Description"
  },
  "copyFrom": "bac982d2-0a2f-48ae-ba27-a38a3749cc6a"
}

materialTemplateInfo 

Represents a Material Activity Template definition.

Name Type Description Required
id string The id string (GUID) for the Material Template. No
name string Name of the Material Template. No
description string Description of the Material Template. No
fields string An Array of group id strings (GUIDs) and/or UDF field names associated with the Material Template. The order in which the fields are specified in this array will be the order in which they are used in the template. No
