envianceSdk.packages.init

Version 2.0

Other Versions:

None

Description

This function initializes the current User context as well as the EMS SDK.

Parameters

A JSON object literal with the following properties:

webAppVirtualPath The path to the EMS web application. The default is calculated automatically.

packageId The id string (GUID) for the App. An EMS App automatically detects its own id when hosted inside the Management System. This option should only be used during local development to specify an id while the App is being run outside of the Management System runtime.

baseAddress A string containing the full URI to the EMS API host. Typically, this will be https://api.enviance.com. The default is null.

ensureIsHosted BooleanTrue/false value that specifies whether or not the EMS App should force itself to be hosted inside the Management System. The default is false.

setupSessionTimeoutHandling BooleanTrue/false value that specifies whether or not the SDK shall alert the User when their session is about to timeout on the Management System. The default is true.

enablePackageConfig BooleanTrue/false value that enables the use of the package.cfg file. The default is true.

enablePackageLocalScript BooleanTrue/false value that enables the use of the package.local.js file. The default is false.

crossDomainWorkaround Specifies whether or not the SDK will use alternative methods for making cross domain calls. Valid options are "ifneeded", "always", "off". When set to "ifneeded", the SDK will detect if the browser make and version requires it. Default is "ifneeded".

Return Value

None

Callbacks

oncomplete An optional callback function to use upon completion.

Example

envianceSdk.package.init({

ensureIsHosted: false

}, function() {

alert("Init is complete!");

});

envianceSdk.packages.user.isInRole

Version 2.0

Other Versions:

None

Description

This method checks to see if the current User is a member of a specified App Role.

Parameters

roleName The name of the App Role.

Return Value

True or false

Example

if (envianceSdk.packages.user.isInRole( "Plant A Managers" ) {

alert("You may proceed.");

}

else {

alert("Access denied.");

}

envianceSdk.packages.user.authenticate

Version 2.0

Other Versions:

None

Description

This function is a no-op function which can be overridden if needed in the package.local.js file in order to handle authentication outside of the EMS App runtime.

Note: Hosted EMS Apps have NO reason to call this function.

Parameters

username The username of the User.

password The password of the User.

Return Value

None

Callbacks

onsuccess An optional callback function to use upon success.

onfailure An optional callback function to use upon error.

Example

envianceSdk.packages.user.authenticate(user, pass,

function() {

console.log("Authenticated");

});

envianceSdk.packages.user.hasAccessTo

Version 2.0

Other Versions:

None

Description

This method checks to see if the current User has access to an Item in the EMS App.

Parameters

itemPath The path, starting from the root of the EMS App, to the EMS App Item.

Return Value

True or false

Example

if (envianceSdk.package.user.hasAccessTo( "/Management/Unit_Upkeep.html" ) {

alert("You may proceed.");

}

else {

alert("Access denied.");

}
