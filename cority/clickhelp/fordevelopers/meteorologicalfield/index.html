MeteorologicalField

Columns

ID Chemical Meteo Field identifier

FieldCode Field Code

FieldName Encoded Field Name

FieldUnit Encoded Field Unit

FieldType Text, Field Type(Numeric, Boolean or Standard

LinkedChemicalFieldID ID of parent Chemical Meteo Field

MeteorologicalData.Id, MeteorologicalData.Location.City, ... Composite column to MeteorologicalData table (includes all fields, native and composite, from MeteorologicalData)

Natural Joins

MeteorologicalData

Example: Get meteo data for Cold Bay (AK) on January - March

select

field.FieldCode,

data.jan,

data.feb,

data.mar

from

MeteorologicalData data

join MeteorologicalField field on field.id = data.Field.ID

where

data.Location.State = 'AK'

and data.location.city = 'Cold Bay'
