envianceSdk.data.enterNumericData

envianceSdk.data.enterNumericDataAsync

Version 2.0

Other Versions:

None

Description

Processes a set of one or more numeric Data Points.

Parameters

numericDataPoints Array. An array of NumericDataPointInfo objects.

Return Value

None

Notes

Numeric Data is entered asynchronously in the Management System. Use the Async version to continue process without waiting for reponse. You can use the returned command id with the getCommand function to check on the status of the command. With the non-Async version, it may take up to 30 seconds for the command to be processed successfully.

Example

envianceSdk.data.enterNumericData(data,

function(response) {

alert("Data entry entered successfully.");

});

envianceSdk.data.NumericDataPointInfo

Version 2.0

Other Versions:

None

Description

Constructs a NumericDataPointInfo object instance in JavaScript.

Parameters

parameterIdOrTag The id or tag of the Parameter. Any string that matches the pattern of a GUID is interpreted as the parent id string, and not the parent tag.

completeDate Date. A date and time value.

value Number. A floating point numeric value. Both standard and scientific notation are valid formats.

qualityData Array [customFieldValues]. An optional array of Custom Field value objects. Only small text, numeric, and Boolean data can be specified for quality data, and submitting data for any other type of Custom Field will result in an error.

collector Id or name of Collector

Return Value

An instance of the NumericDataPointInfo class.

Instance Methods

addScalarFieldValue(fieldName, value) This is a convenience method to add a ScalarFieldValue value to the fields array property.

addLinkedFieldValues(fieldName, values) This is a convenience method to add a LinkedFieldValues instance to the fields array property.

Example

var datapoint = new envianceSdk.data.NumericDataPointInfo(

"ABC12345", // parameter tag

"2013-09-30T00:00:00",

2314.098,

null

);

datapoint.addScalarFieldValue("Field A", 1);

datapoint.addLinkedFieldValues("Field B", ["Level 1", "Level 2"]);

envianceSdk.data.NumericDataRangeInfo

Version 2.0

Other Versions:

None

Description

Constructs a NumericDataRangeInfo object instance in JavaScript.

Parameters

parameterIdOrTag The id or tag of the Parameter. Any string that matches the pattern of a GUID is interpreted as the parent id string, and not the parent tag.

beginDate Date. A date and time value. This is the beginning of the date range in which all existing Data Points for the Parameter will be deleted.

endDate Date. A date and time value. This is the end of the date range in which all existing Data Points for the Parameter will be deleted.

Return Value

An instance of the NumericDataRangeInfo class.

Example

var dataRange = new envianceSdk.data.NumericDataRangeInfo(

"ABC12345", // parameter tag

"2013-09-30T00:00:00",

"2013-10-31T00:00:00"

);
