envianceSdk.packages.createPackage

Version 2.0

Other Versions:

None

Description

Creates a new Package (aka EMS App) in EMS Apps Manager.

Parameters

packageInfo An instance of the packageInfo object. Some properties of this object are ignored by this function; see details of this object for more info.

Return Value

The id string (GUID) of the new Package will be passed to the onsuccess callback in the result property.

Notes

You can use the envianceSdk.common.configureFileInput function to create a file input control and retrieve the Base64 encoded content of a chosen file. In the case of uploading the content for an App Package, the file should be a zip file with the display page of the App at the root of the zip.

The User making this function call must have the System Right to "Manage Enviance Apps".

Example

envianceSdk.packages.createPackage(packageInfo,

function(response) {

alert("Created new app with id: " + response.result);

});

envianceSdk.packages.packageInfo

Version 2.0

Other Versions:

None

Description

Constructs a packageInfo object instance in JavaScript.

Parameters

name The name of the Package.

description The description of the Package.

content The content of the Package in a zip file, Base64 encoded. You can use configureFileInput to enable file upload and content retrieval in JavaScript for later browsers.

displayPage The path, relative to the root of the Package, to an Item which can serve as the default page to be displayed when loading the App. This should be an HTML page.

iconSrc The path, relative to the root of the Package, to an Item which can serve as the icon for the App. This Item must be an image file.

isLocked BooleanTrue/false value that indicates whether or not the Package is locked.

Return Value

An instance of the PackageInfo class.

Example

var app = new envianceSdk.packages.PackageInfo(

"Daily Metrics",

"A Dashboard App.",

content, // base64 encoded bytes

"/index.htm",

"/img/icon.png",

false);
