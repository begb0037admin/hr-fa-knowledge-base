envianceSdk.chemicals.createChemical

Version 2.0

Other Versions:

None

Description

Creates a new Chemical.

Parameters

chemicalInfo An instance of the chemicalInfo object.

Return Value

The id string (GUID) of the new Chemical will be passed to the onsuccess callback in the result property.

Example

envianceSdk.chemicals.createChemical(chemicalInfo,

function(response) {

alert("Created new chemical with id: " + response.result);

});

envianceSdk.chemicals.copyChemical

Version 2.0

Other Versions:

None

Description

Creates a new Chemical by copying an existing chemical.

Parameters

chemicalInfo Optional information to set properties of new chemical. An instance of the chemicalInfo object.

copyFrom The id string (GUID) or alias of an existing Chemical to be copied.

Return Value

The id string (GUID) of the new Chemical will be passed to the onsuccess callback in the result property.

Example

envianceSdk.chemicals.copyChemical(chemicalInfo,copyFrom,

function(response) {

alert("Created new chemical with id: " + response.result);

});

envianceSdk.chemicals.updateChemical

Version 2.0

Other Versions:

None

Description

Updates a Chemical.

Parameters

chemicalIdOrAlias Either an id string (GUID) or the alias for the Chemical. Any string that matches the pattern of a GUID is interpreted as the id string, and not the alias of the Chemical. An alias string must be URL encoded.

chemicalInfo An instance of the chemicalInfo object.

Return Value

None

Example

envianceSdk.chemicals.updateChemical (chemicalIdOrAlias, chemicalInfo, onsuccess, onerror)

envianceSdk.chemicals.chemicalInfo

Version 2.0

Other Versions:

None

Description

Represents a Chemical definition.

Parameters

id String. The id string (GUID) for the Chemical.
Ignored for: Create Chemical, Update Chemical

name String. The name of the Chemical.
Required for: Create Chemical

casNumber String. The CAS number for the Chemical.
Required for:  Create Chemical

alias String. An alias for the Chemical to be used in scripts.
Required for:  Create Chemical

description String. The description of the Chemical.

historyItems Array. An array of chemicalHistoryItemInfo structures, specifying records which should be part of the Chemical property history. A new Chemical must have at least one Chemical history record.
Required for:  Create Chemical

Example

envianceSdk.chemicals.ChemicalInfo (name, casNum, alias, description, historyItems)

envianceSdk.chemicals.ChemicalHistoryItemInfo

Description

Represents a Chemical History Item definition.

Properties

beginDate Date. A date and time value. Begin date of history item.

mW Number. Molecular weight of the chemical. A non-negative decimal value. If unspecified, the default is 0.

antA Number. Value of the Antoine A constant for calculating vapor pressure with temperature in Centigrade. A non-negative decimal value. If unspecified, the default is 0.

antB Number. Value of the Antoine B constant for calculating vapor pressure with temperature in Centigrade. A non-negative decimal value. If unspecified, the default is 0.

antC Number. Value of the Antoine C constant for calculating vapor pressure with temperature in Centigrade. A non-negative decimal value. If unspecified, the default is 0.

antAk Number. Value of the Antoine A constant for calculating vapor pressure with temperature in Kelvin. A non-negative decimal value. If unspecified, the default is 0.

antBk Number. Value of the Antoine B constant for calculating vapor pressure with temperature in Kelvin. A non-negative decimal value. If unspecified, the default is 0.

antCk Number. Value of the Antoine C constant for calculating vapor pressure with temperature in Kelvin. A non-negative decimal value. If unspecified, the default is 0.

vp60 Number. Vapor pressure at 60 deg Fahrenheit. A non-negative decimal value. If unspecified, the default is 0.

density Number. Density at 60 deg Fahrenheit. A non-negative decimal value. If unspecified, the default is 0.

dipprA Number. Value of the A constant for calculating vapor pressure by the DIPPR method. A non-negative decimal value. If unspecified, the default is 0.

dipprB Number. Value of the B constant for calculating vapor pressure by the DIPPR method. A non-negative decimal value. If unspecified, the default is 0.

dipprC Number. Value of the C constant for calculating vapor pressure by the DIPPR method. A non-negative decimal value. If unspecified, the default is 0.

dipprD Number. Value of the D constant for calculating vapor pressure by the DIPPR method. A non-negative decimal value. If unspecified, the default is 0.

dipprE Number. Value of the E constant for calculating vapor pressure by the DIPPR method. A non-negative decimal value. If unspecified, the default is 0.

dipprF Number. Value of the F constant for calculating vapor pressure by the DIPPR method. A non-negative decimal value. If unspecified, the default is 0.

dipprG Number. Value of the G constant for calculating vapor pressure by the DIPPR method. A non-negative decimal value. If unspecified, the default is 0.

rcraHaz BooleanTrue/false value that indicates whether chemical is on Resource Conservation and Recovery Act (RCRA) Hazardous list. A true or false flag. If unspecified, the default is false.

hap BooleanTrue/false value that indicates whether chemical is listed as Hazardous Air Pollutant (HAP). A true or false flag. If unspecified, the default is false.

tri BooleanTrue/false value that indicates whether chemical is on the Toxic Release Inventory reporting list. A true or false flag. If unspecified, the default is false.

ehs BooleanTrue/false value that indicates whether chemical is listed as an Extremely Hazardous Substance. A true or false flag. If unspecified, the default is false.

pbt BooleanTrue/false value that indicates whether chemical is listed as a Persistent Bioaccumulative Toxic (PBT) chemical. A true or false flag. If unspecified, the default is false.

dioxin BooleanTrue/false value that indicates whether chemical is a dioxin or dioxin-like chemical. A true or false flag. If unspecified, the default is false.

caa112r BooleanTrue/false value that indicates whether chemical is on the Clean Air Act Section 112(r) list of regulated substances. A true or false flag. If unspecified, the default is false.

pac BooleanTrue/false value that indicates whether chemical is on the Protective Action Criteria (PAC) list. A true or false flag. If unspecified, the default is false.

diisocyan BooleanTrue/false value that indicates whether chemical is a diisocyanate chemical. A true or false flag. If unspecified, the default is false.

cerclaHaz BooleanTrue/false value that indicates whether chemical is on the Comprehensive Environmental Response, Compensation, and Liability Act (CERCLA) hazardous chemical list (commonly known as Superfund). A true or false flag. If unspecified, the default is false.

airToxicEmissionInventory BooleanTrue/false value that indicates whether chemical is listed on the Air Toxic Emission Inventory. A true or false flag. If unspecified, the default is false.

solid BooleanTrue/false value that indicates whether chemical is a solid. A true or false flag. If unspecified, the default is false.

nonEvaporative BooleanTrue/false value that indicates whether chemical is non-evaporative. A true or false flag. If unspecified, the default is false.

rcraVoc BooleanTrue/false value that indicates whether chemical is an RCRA VOC. A true or false flag. If unspecified, the default is false.

rcraSvoc Is an RCRA SVOC. A true or false flag. If unspecified, the default is false.

caaVoc BooleanTrue/false value that indicates whether chemical is Clean Air Act VOC. A true or false flag. If unspecified, the default is false.

Example

envianceSdk.chemicals.ChemicalHistoryItemInfo (beginDate, mw, antA, antB, antC, antAk, antBk, vp60, density, dipprA, dipprB, dipprC, dipprD, dipprE, dipprF, dipprG, rcraHaz, hap, tri, ehs, pbt, dioxin, caa112R, pac, diisocyan, cerclaHaz, airToxicEmissionInventory, solid, nonEvaporative, rcraVoc, rcraSvoc, caaVoc)
