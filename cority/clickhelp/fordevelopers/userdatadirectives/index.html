User Data Directives

User Data Directives may be used in the package manifest file to remove User Data key/value pairs.

When removing a key/value pair, it is important to note that the key, with potentially different values, will be removed for all Users of the EMS App.

<userData>

<remove key="Default Color" />

</userData>

The above Directive results in the following operations being sequentially executed during upload of this manifest:

  1. The "Default Color" key is removed for all Users.
