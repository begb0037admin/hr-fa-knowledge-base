WorkflowTypeChanges

Columns

ID Workflow Type ID

Updated Update date of workflow type

Example: Get the latest update date of workflow type.

select

wt.Id,

wt.Updated

from WorkflowTypeChanges wt

where wt.Id= '78d05fff-769c-4868-82b0-ad4cff095e43'

Order by wt.Updated desc

Permissions:  All users have access to the table.
