Object Properties Editing Tool - Monitored Requirements 

The "monitored requirement(s)" field for Event Logs may be edited on the regular Object Properties editing tool, but the alternate template for editing just monitored requirements offers a couple of advantages when many requirements are monitored by one Event Log.

  • You can enter one monitored requirement per row (where the Object Properties Editing tool requires all requirements to be listed in the same row).
  • There is no need to list all monitored requirements in order to add or delete one (as required on the Object Properties Editing tool).

Download the Excel template file:

Object Properties Editing Tool - Monitored Requirements

Use "add" or "delete" in the MR Action column (column AS) to add or delete monitored requirements. Requirements already included on the Event Log will not be changed, unless explicitly deleted.

Use <clear> in the Requirements column to remove all monitored requirements.

Note:  If you use <clear> to clear all monitored requirements, you should also consider adding at least one requirement. You will not be prevented from saving an Event Log with no monitored requirements. However, no warning will be issued to alert you of this condition.

  A B C AS
1 Path and Name Property Name One Requirement per row (leading \) or<clear> MR Action
2 Division\Facility 1\Event Log 1 Monitored Requirement(s) <clear>  
3 Division\Facility 1\Event Log 1 Monitored Requirement(s) Parameter 4 add
4 Division\Facility 1\Event Log 2 Monitored Requirement(s) Parameter 1 delete

 

In the above example, all monitored requirements for Event Log 1 are removed, then one requirement is added. One monitored requirement is removed from Event Log 2; existing monitored requirements for Event Log 2 will be unchanged.
