Ranking Functions

Row Number

Function returns the sequential number of a row within a partition of a result set, starting at 1 for the first row in each partition.

Syntax

ROW_NUMBER ( ) OVER ( [ PARTITION BY expression , ... [ n ] ] order_by_clause)

Example:

SELECT wis.name, wis.create

FROM (

SELECT wi.Name, wi.Created, ROW_NUMBER()

OVER (Partition BY DATEPART(day, wi.Created)

ORDER BY wi.Created DESC ) AS ROW_NUMBER

FROM WorkflowInstance wi WHERE wi.Created BETWEEN '2017-12-01' AND '2017-12-31'

) wis WHERE wis.ROW_NUMBER <= 10

ORDER BY wis.Created DESC
