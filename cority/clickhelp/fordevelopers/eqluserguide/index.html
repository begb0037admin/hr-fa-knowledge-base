EMS Query Language (EQL ) is a SQL-like language used to query the EMS database.

EQL allows users to retrieve data from the system and subsequently manipulate that data with other integration tools.

Some of the things you can do with EQL:

  • Retrieve users and user attributes
  • Retrieve user data and history
  • Retrieve

The results of EQL queries can be saved in several formats (including Excel, XML and JSON). Aggregation functions are also supported. A Web Service is available to execute EQL queries used by EIFL projects.

EQL syntax is designed to be as close to classic SQL syntax as possible. EQL differs from SQL in areas where specific EMS operations may be expressed in shorter and simpler expressions. The "natural joins" function takes advantage of in-built table relationships without having to be concerned with the actual data organization.

This user guide details the rules, syntax, functions, and the tables and columns of information that can be obtained through EQL.
