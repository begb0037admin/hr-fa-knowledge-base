Executing EQL Queries with the EQL Rest API

The EQL Rest API can be used to execute EQL queries without page size limits. This may be useful for integration purposes. Some large queries may be handled better with the EQL Rest API service, in lieu of the EQL console. The base URL for the EQL Rest API is:

https://api.enviance.com/ver2/EqlService.svc/query?format=csv&filename=results.csv&eql=

There are three parameters:

format: can be either csv, xml or json

filename: the name of the file containing the results of the query

eql: your EQL query, URL encoded

You must encode your EQL, which means making your query a single line, browser-friendly (basically replacing the spaces with '%20'). To URL encode a query, you can use the following web site:

http://meyerweb.com/eric/tools/dencoder/

Example

Plain text: select f.name from facility f

Encoded: select%20f.name%20from%20facility%20f

Copy the encoded string and append it to the end of the base URL.

Example:

https://api.enviance.com/ver2/EqlService.svc/query?format=csv&filename=results.csv&eql=select%20f.name%20from%20facility%20f

Open the URL in a supported browser. Log in with your EMS user and password in the popup dialog. You should be asked to save the result before downloading.
