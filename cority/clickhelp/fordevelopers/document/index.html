envianceSdk.documents.createDocument

Version 2.0

Other Versions:

None

Description

Creates a new Document in Document Manager.

Parameters

documentInfo An instance of the documentInfo object. Some properties of this object are ignored by this function; see details of this object for more info.

Return Value

The id string (GUID) of the new Document will be passed to the onsuccess callback in the result property.

Notes

You can use the configureFileInput function to create a file input control and retrieve the Base64 encoded content of a chosen file.

Example

envianceSdk.documents.createDocument(documentInfo,

function(response) {

alert("Created new document with id: " + response.result);

});

});

envianceSdk.documents.documentInfo

Version 2.0

Other Versions:

None

Description

Constructs a documentInfo object instance in JavaScript.

Parameters

name The name of the Document. May be empty or null for Update Document and field will not be modified.

description The description of the Document.

folderIdOrPath The id string (GUID) or full path of the Document Folder in which this Document is placed. Must include a trailing slash ("/"). Any string that matches the pattern of a GUID is interpreted as the id string, and not the path of the Folder.

content The content of the Document, Base64 encoded. You can use configureFileInput to enable file upload and content retrieval in JavaScript for later browsers.

fileName The original file name of the Document. This is only required when the content property is used – it allows the system to detect the mime type and use it for the Download Document API. May be empty or null for Update Document and field will not be modified.

mimeType The mime type of the Document. If left unspecified when creating or updating a Document the application will assign a mime-type according to the file extension.

Return Value

An instance of the documentInfo class.

Instance Methods

addPathAssociatedObject(objectPath) This method adds an associated System Model object by path to the Document.

addIdAssociatedObject(objectId) This method adds an associated System Model object by id to the Document.

addAssociatedTask(taskId) This method adds an associated Task by id to the Document.

addAssociatedWorkflow(workflowIdOrUniqueId) This method adds an associated Workflow by id or unique id to the Document. Any string that matches the pattern of a GUID is interpreted as the id string, and not the unique id of the Workflow.

setContentUrl(contentUrl) This method sets the URL to which this Document will be linked, instead of having its own content.

Notes

None

Example

var doc = new envianceSdk.documents.DocumentInfo(

"Checklist1",

"A Facility checklist.",

"/Checklists/",

content, // base64 encoded bytes

"Checklist1.xls");

doc.addPathAssociatedObject("/Division A/Facility X");
