Document Management Tool

With the Document Management tool you can move documents and document folders, add new document folders, edit document properties and values, associate documents to compliance objects, and delete documents.

Download the Excel template file:

Document Management Tool

All documents must first be uploaded to EMS Document Manager. Use the Permissions Editing tool to grant permissions to documents. (See Document Permissions.)

The Document Management tool has six worksheets:

  • Associate Documents
  • Delete Documents
  • Document Folders to be Added
  • Document Properties and Values
  • Move Documents
  • Move Folders

Associate Documents

Use this sheet to associate existing documents in Document Manager to existing compliance objects in the system model.

Inputs include:

Document Folder Path and Name (required)

Object Path and Name

The active version of the document will be associated to the compliance object.

Delete Documents

Use this sheet to delete documents from Document Manager. You can delete specific versions of a document, remove all versions, or delete history (all previous versions, leaving just the current version). If you delete all versions, all object associations will be removed. If you delete specific versions, only object associations specific to a deleted version will be deleted.

Inputs include:

Document Folder Path (required): The location of the document to be deleted from Document Manager.

Document Name (required): Name of the document (including extension).

Document Version (optional): The version to delete can be specified as:

Version number – numeric version number.

"All" – All versions of the document will be deleted, including the current version. This is the default.

"History" – All previous versions of the document except the current version will be deleted.

Document Folders to be Added

Use this sheet to add document folders to Document Manager.

Inputs include:

Parent Folder Path (required)

New Folder Name (required)

You will need to create parent folders first in one pass, then create subfolders under the parents in a second pass.

Document Properties and Values

Use this sheet to edit properties of existing documents in Document Manager or properties of document folders.

Inputs include:

Document Folder Path and Name (required): To edit properties of document, include path and document name. To edit properties of folder, include the path with name of folder to edit.

Property Name (required): "Description" and"Name" are the only options.

Property Value (required)

You can edit both properties in one pass, using the existing name.

Move Documents

Use this sheet to move documents from an existing document folder to a different document folder. If the target folder does not exist, you can create it at the same time.

Inputs include:

Current folder path (required)

Current document name (required)

Target folder path (required)

Target Document Name (required)

Create new folder if it does not exist (Yes/No, default Yes)

The move operation will retain the document version history and all existing document associations. You must supply the target document name, even if it is the same as existing.

Move Folders

Use this sheet to move existing document folders to a different document folder path. If the target folder does not exist, you can create it at the same time.

Inputs include:

Current folder path (required)

Current Folder Name (required)

Target folder path (required)

Target Folder Name (required)

Create new folder if it does not exist (Yes/No, default Yes)

The move folder operation will always retain the documents existing in the folder. You must supply the target folder name, even if it is the same as existing.
