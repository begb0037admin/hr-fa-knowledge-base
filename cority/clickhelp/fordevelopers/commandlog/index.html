envianceSdk.commands.getCommand

Version 2.0

Other Versions:

None

Description

Gets information about the specified Command log.

Parameters

commandId The id string (GUID) for a previously submitted command.

Return Value

A commandInfo object will be passed to the onsuccess callback in the result property.

Example

envianceSdk.commands.getCommand("2d4fc954-b062-433d-9405-ce709c36a353",

function(response) {

var command = response.result;

alert("Command status:" + command.status);

});

envianceSdk.commands.deleteCommand

Version 2.0

Other Versions:

None

Description

Deletes an existing Command log.

Parameters

commandId The id string (GUID) for a previously submitted command.

Return Value

None

Notes

Deleting a Command log record serves to delete the record of the operation, but not the operation itself. The results of the operation, if completed, will not be removed.

Deletions are permanent.

Example

envianceSdk.commands.deleteCommand("2d4fc954-b062-433d-9405-ce709c36a353",

function(response) {

alert("Command record deleted.");

});

commandInfo

Description

Information about a User-requested asynchronous operation.

Properties

id The id string (GUID) of the command.

description The system description of the command.

issued Date. The date and time the command was issued. The value is in the User's time zone.

startedProcessing Date. The date and time the command begin processing. The value is in the User's time zone. The value is null if processing has not yet begun.

finishedProcessing Date. The date and time the command finished processing. The value is in the User's time zone. The value is null if processing has not yet finished.

status The status of the command. One of: Waiting, Processing, Succeeded, Failed, Resubmitted.

objects Array. An array of object paths.

reports Array. An array of Report paths.

user The user name of the User who submitted the command.

result An optional URI pointing to the result of the command.

errorInfo Array. An array of JSON object literals with the following properties:error The text of the error description.

details Array. An array of JSON object literals describing the error details for each error. The format depends upon the type of data submitted.
