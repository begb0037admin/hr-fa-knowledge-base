Example: List Custom Fields in an Event Log

select top 20

el.ID,

el.Name,

cft.CustomField.Name

from CustomFieldTemplate cft

join EventLog el on cft

order by el.Name

Permissions:  Requires Report permission on the target object. Manage Custom Fields right is required to query CustomFieldTemplate composite fields. Manage Event Templates right is required to query EventTemplate fields. Manage Documents right is required to query Document composite columns; in addition Manage Users right is required for CreatedBy composite fields for document.
