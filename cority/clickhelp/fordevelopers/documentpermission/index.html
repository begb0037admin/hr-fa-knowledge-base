DocumentPermission

Columns

DocumentID Document ID

Permission.View True if View permission present

Permission.Edit True if Create and Edit permission present

Permission.Delete True if Delete permission present

Created Date Created

Updated Date Updated

ExplicitUser.ID, ExplicitUser.FirstName... Composite column to User table (includes all fields from User). Returns only those users granted explicit permission.

ExplicitGroup.ID, ExplicitGroup.Name... Composite column to Group table (includes all fields from Group).

User.ID, User.FirstName... Composite column to User table (includes all fields from User). Returns combination of users with explicit permission and users who are members of permitted groups (no duplicates).

Note:  Columns will return null if User is an access user.

Natural Joins

Document

Example: Get all users with View or Edit permission on a document (both users with explicit permission and users who are members of permitted groups).

select

d.name,

p.Permission.View,

p.Permission.Edit,

p.User.FirstName,

p.User.LastName

from Document d

join DocumentPermission p on d

Permissions:  Requires View or Edit permission on the target object.
