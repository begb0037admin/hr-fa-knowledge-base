Commands

UDFMETADATA

Values: ON (TRUE) / OFF (FALSE)

When ON: "SELECT * from sometable" will return NATIVE + All UDF columns that are associated with that Object and related templates. When OFF: returns only NATIVE columns. Do not contain extension "Historical".

COMPOSITECOLUMNS

Values: ON (TRUE) / OFF (FALSE)

When ON: "SELECT * from sometable" will return NATIVE + All Composite columns. When OFF: returns only NATIVE columns.

Syntax:

SET <Command> [=] <Value>

COMPOSITECOLUMNSUPPRESS

Values: ON (TRUE) / OFF (FALSE)

When ON: only allows column notation without "."

LOCALIZED

Values: ON (TRUE) / OFF (FALSE)

When ON: column (or UDF) that support localization will return localized result.

Example:

set localized = true

select c.Caption from CustomField c

 

CULTURE

Name of any supported culture. Currently allowed: "en-US", "ru-RU”, "zh-CN", "en-GB", "es-MX", “es-CR”, “es-GT”, “es-SV”, “es-HN”, “es-NI” 

Specifies culture that will be used for localization of query result.

Example:

set localized = true

set culture = 'en-GB'

select c.Caption from CustomField c

 

Syntax:

SET <Command> [=] <Value>
