/materials

POST

Description:

Creates a new Material, alternately by copying an existing material.

Security: Requires Manage Materials and Activities system right.

SDK API (create): envianceSdk.materials.createMaterial (materialInfo, onsuccess, onerror)

SDK API (copy): envianceSdk.materials.copyMaterial (materialInfo, copyFrom, onsuccess, onerror)

Parameters
Name Located in Description Required Schema
materialCreateInfo body Create Material body Yes materialCreate
Responses
Code Description Schema
200 The id of the queued command. string

Security: Requires Manage Materials and Activities system right.

SDK API: envianceSdk.materials.updateMaterial (materialIdOrName, materialInfo, onsuccess, onerror)

Models

materialCreate 

Creation info for Material

Name Type Description Required
materialInfo [ materialInfo ] A materialInfo structure No
copyFrom string The id string (GUID) of an existing Material whose properties will be copied and used as the properties of the newly created Material No

materialInfo 

Represents a Material definition.

Name Type Description Required
id string The id string (GUID) for the Material. Ignored for: Create Material, Update Material Yes
name string The name of the Material. Required for: Create Material No
description string The description of the Material. No
chemicals [ chemicalConcentrationHistoryInfo ] An array of chemicalConcentrationHistoryInfo structures. Required for: Create Material No
properties [ materialPropertyInfo ] An array of Material Property info structures. Required for: Create Material No
templateIdOrName string An id string (GUID) or name of a Material/Activity Template. Any string that matches the pattern of a GUID is interpreted as an id string, and not a name. A name string must be URL encoded. No
fields [ customFieldValue ] An array of Custom Field values for Material Template properties. No
materialAvailabilityFlag boolean Boolean value true or false indicating whether material should be shown for data entry. No
Copy Code
JSON
{
  "name": "Material Name",
  "description": "Material Description",
  "templateIdOrName": "Template Name",
  "materialAvailabilityFlag": "true",
  "fields": [
    {"name": "Unique Tag","values": ["ID_string"]},
    {"name": "Start Date","values": ["2012-09-19T20:00:00"]},
    {"name": "Type","values": ["value1", "value2"]} ],
  "chemicals": [
    {"chemicalIdOrAlias": "Chemical Alias",
    "chemicalConcentrationHistory": [
      { "beginDate": "2012-01-19T20:00:00", "present": "true", "minConc": "0", "avgConc": "1", "maxConc": "2"},

 }

chemicalConcentrationHistoryInfo 

Represents a single Chemical Concentration Value History Item definition.

Name Type Description Required
idOrName string The id string (GUID) of the Chemical Concentration Item record. Ignored for: Create Material No
beginDate dateTime A DateTime value, representing begin date for the Item. No
present boolean A boolean value. No
min integer A decimal value between 0 and 100. If unspecified, the default is 0. No
max integer A decimal value between 0 and 100. If unspecified, the default is 0. No
avg integer A decimal value between 0 and 100. If unspecified, the default is 0. No
Copy Code
JSON
{
  "beginDate": "2012-01-01T00:15",
  "present": "true",
  "minConc": "0.5",
  "avgConc": "1",
  "maxConc": "2.8"
}

valueHistoryItem 

Represents a single Value History Item definition.

Name Type Description Required
id string The id string (GUID) of the Value History Item record. Ignored for: Create Material No
beginDate dateTime A DateTime value specifying begin date for the Item. No
value number Numeric or Boolean value for the Item. (Boolean values represented by 0 and 1 values). No
Copy Code
JSON
{
  "beginDate": "2012-01-01T00:15",
  "value": "123" 
}

customFieldValue 

A set of one or more values for a Custom Field, identified by name.

Name Type Description Required
name string The name (not caption) of the Custom Field. No
values string An array with one or more string values, representing the values (one or more) for the Custom Field. Note that even non-string simple values are encoded as strings for custom fields, and are parsed and validated on the server according to the Custom Field type. No
Copy Code
JSON
// Scalar value
{"name": "Aspect", "values": ["Air pollution control"]}

// Scalar date/time value
{"name": "Start Date", "values": ["2012-09-19T20:00"]}

// Multi-select values
{"name": "Type", "values": ["Spill", "Near Miss"]}

// Linked-list values
{"name": "Category", "values": ["Cat1", "Cat1.1", "Cat1.1.1"]}

// Hyperlink values
{"name": "Google", "values": [{ "label": "Google": "url": "http://www.google.com"]} }
