Example: List all workflow types and each workflow step, using the most recent version of each step

select

wt.name,

wts.name as stepName,

max(wtv.Version) as Version

from Workflowtype wt

join WorkflowtypeVersion wtv on wt

join WorkflowtypeVersionStep wts on wtv

group by wtv.Version, wt.name, wts.name

Permissions:  Manage Workflows right is required to query this table.
