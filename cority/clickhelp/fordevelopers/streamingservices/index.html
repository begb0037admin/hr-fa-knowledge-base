Streaming Services

Note: Streaming services are only available for the Management System EQL.

Methods

Tables ExecuteReader(string query)

This method returns DataSet in xml.

Example of client code

string eql = "select top 10 f.name from facility";

var eqlService = new EqlSrv.Eql

{

Url = AppVars.EqlServicePath,

SessionHeaderValue = new SessionHeader { SessionID = UserSession.Current.SessionID }

};

\\

Tables result;

result = eqlService.ExecuteReader(eql);
