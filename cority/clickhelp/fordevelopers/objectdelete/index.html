Object Delete Tool

The Object Delete Tool can be used to delete unwanted objects or parts of the system model. You can also use it as a cleanup tool after testing or copying dummy objects. Both fields are required.

Download the Excel template file:

Object Delete Tool

Path: Location in the System Model of object to be deleted (path from Locations & Programs root to parent object). Do not include the model name. Include a backslash ( "\") at the beginning but not at the end. Example: \Division\Facility 1\Unit B

Name: Name of object to be deleted. If the object is a tree object, deletion will include all children, providing that all references to the objects are self-contained.

Note:  If there are external references, the operation will fail. Rules for object deletion are the same as in the main application.
