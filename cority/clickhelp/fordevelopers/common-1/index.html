addressInfo

Describes a physical mailing address.

Name Type Description Required
street1 string The street address. No
street2 string A second line for the street address. No
street3 string A third line for the street address. No
city string The city. No
county or region string An optional county, region or district. No
stateOrProvince string The two-character state or province code. No
country string The two-character country code. No
postalCode string The ten-character zip or postal code. No

Copy Code
JSON
"address": {
    "street1": "1028 Arch Ave",
    "city": "San Diego",
    "countyOrRegion": "San Diego",
    "stateOrProvince": "CA",
    "country": "US",
    "postalCode": "92024"
  }

customFieldValue

A set of one or more values for a Custom Field, identified by name. Scalar Custom Fields are represented as an array with only one string. Multi-Select Custom Fields are represented as an array with multiple string values, one for each selected option. Linked List Custom Fields are represented as an array with multiple string values, where index n of the array holds the chosen value for level n+1 of the linked list. For example, the values array [“One”, “Two”, “Three”] for a linked list will map to the item “One” chosen in level one, “Two” in two, etc. Hyperlink Fields are represented as an array with a single UrlItem.

Name Type Description Required
name string The name (NOT caption) of the Custom Field. No
values [ string ] An array with one or more string values, representing the values (one or more) for the Custom Field. Note that even non-string simple values are encoded as strings for custom fields, and are parsed and validated on the server according to the Custom Field type. No

Copy Code
JSON
// Scalar value
{"name": "Aspect", "values": ["Air pollution control"]}

// Scalar date/time value
{"name": "Start Date", "values": ["2012-09-19T20:00"]}

// Multi-select values
{"name": "Type", "values": ["Spill", "Near Miss"]}

// Linked-list values
{"name": "Category", "values": ["Cat1", "Cat1.1", "Cat1.1.1"]}

// Hyperlink values
{"name": "Google", "values": [{ "label": "Google": "url": "http://www.google.com"]} }

timeZone

Describes a time zone, including its offsets from UTC.

Name Type Description Required
name string (number) The name of the time zone. No
stdOffset string (number) The offset in minutes from UTC during standard time. No
dstOffset string (number) The offset in minutes from UTC during daylight savings time (DST). This property will be identical to “stdOffset” for time zones that do not observe DST. No
currentOffset string (number) The current offset in minutes from UTC (which can change upon whether the time zone is currently observing DST or not). No

Copy Code
JSON
{
  "name": "USA Pacific",
  "stdOffset": -480,
  "dstOffset": -420,
  "currentOffset": -420
}

docPath

The hierarchical path to an object as represented by the folder structure in the UI, beginning with a single forward slash and with elements separated by a single forward slash “/”. Does not include the System name or the container object (Locations & Programs, Documents, etc).

Name Type Description Required
docPath string The hierarchical path to an object as represented by the folder structure in the UI, beginning with a single forward slash and with elements separated by a single forward slash “/”. Does not include the System name or the container object (Locations & Programs, Documents, etc).
