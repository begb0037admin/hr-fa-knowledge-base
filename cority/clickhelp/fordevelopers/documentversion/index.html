CreatedBy.ID, CreatedBy.Name, ...User who created document. Composite column to User table (includes all fields from User).

Natural Joins

Document

Example:

select

d.name,

d.Fullpath,

d.IsFolder,

dv.Kilobytes,

dv.CreatedBy.Email,

d.createdDate,

max(dv.createdon) as LatestCreated,

max(dv.version) as version

from Document d

join DocumentVersion dv on d

group by d.name, d.Fullpath, d.IsFolder, d.createdDate, dv.Kilobytes, dv.CreatedBy.Email

Permissions:  Requires View permission on the target object or Manage Documents right. Manage Users right is required for CreatedBy composite columns.
