DateFromParts

Function returns a date value that maps to the specified year, month, and day values. 

Syntax:

DateFromParts (year, month, day)  

Example:

select

f.name, DateFromParts(2020,01,20) , f.createdOn

from facility f

where datepart(mm, now()) = datepart(mm, f.CreatedOn)
