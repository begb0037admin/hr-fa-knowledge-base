Object Move Tool

The Object Move Tool can be used to move objects from one parent object to another in the tree. All child objects will be moved with the parent object, as in the main application.

The Object Move Tool is similar to the Object Copy Tool, except that since no new objects are being created, there is less risk of spam email notifications. However, one circumstance should be considered: If advance notifications for tasks due in the future have already been sent out, those advance notifications will be re-sent when the object is moved. For example, if a 1-week task notification was sent out for a task that is due in 2 days, that 1-week notification will be re-sent when the task is moved.

Care should still be used to ensure that the paths are correct and that the Destination Path exists. The destination path will not be created if it does not already exist.

Object Move Tool

The first three fields on the Object Move Template file are required. The Destination Name field may be used to rename the new object. Otherwise, the name will be the same as the object copied, if it is copied to another parent object, or renamed "Copy of [Name]" if it is under the same parent.

Source Path: Location in the System Model of object to be moved (path from Locations & Programs root to parent object). Do not include the model name. Include a backslash ( "\") at the beginning but not at the end. See example below.

Source Name: Name of object to be moved.

Destination Path: New location for object (same path rules as above).

Destination Name: New Name of object, if it is to be renamed. Leave blank to use Source Name. Do not use special characters. Disallowed characters in names include: "\", "/", "[", "]". It is also recommended that you clean up and eliminate any extra white spaces and limit use of dashes to a simple dash (not the m-dash or n-dash). Note that dashes can often be changed by auto-correct features in other documents from which you may copy your object names, so be careful that this does not introduce characters such as m-dashes and n-dashes that may be hard to identify and thus edit later.
