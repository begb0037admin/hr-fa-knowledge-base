Models

groupInfo 

Represents a Group of Users in the Management System.

Name Type Description Required
id string The id string (GUID) for the Group. Ignored for: Create Group, Update Group No
name string Name of the Group. Note: You cannot create a new Group called “Administrators”. Required for: Create Group No
rights string An array of System Rights granted to the Group. No
members string An array of member User id strings (GUIDs) and/or user names. No
