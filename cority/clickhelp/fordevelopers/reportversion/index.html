Example: Get report details with creation date of version and last run date.

select

r.Name,

r.Description,

r.Type,

r.Created,

v.Created as VersionCreated,

v.LastRun

from Report r

join ReportVersion v on r

Permissions:  Requires Report permission on the target object or Manage Reports right.
