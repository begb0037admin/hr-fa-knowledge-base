Object Names Localization

Localized values for the names of all system model tree objects and requirements may be set through bulk tools. The culture values supported by the Management System are allowed.

Download the Excel template file:

Object Names Localization

When presenting localized values to users in the system, the following rules apply:

  1. If there is a localized value for the user's chosen Culture, then the localized value will be shown.
  2. If no localized value is given, the default value is used. The default value is the non-localized invariant value.

The relevant columns in the Object Edit template are:

  • A - Path and Name
  • B - Property Name
  • C - Property Value
  • AU - Localization Culture

Use one row for each culture value.
