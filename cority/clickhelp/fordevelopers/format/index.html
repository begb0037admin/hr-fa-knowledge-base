Format

Note: The 'Format' function is only available for the Management System EQL.

Returns a value formatted with the specified format

Syntax

FORMAT (value, format_pattern)

FORMAT (value, format_expression)

value Expression of Number or Date/Time

format_pattern Double-quoted String containing format pattern


Number
Format specifier

Name

"C" or "c"

Currency

"D" or "d"

Decimal
"E" or "e" Exponential (scientific)
"F" or "f" Fixed-point
"G" or "g" General
"N" or "n" Number
"P" or "p" Percent
"R" or "r" Round-trip

"X" or "x"

Hexadecimal

 

DateTime
Format specifier

Description
"d"

Short date pattern

"D"

Long date pattern

"f"

Full date/time pattern (short time)

"F"

Full date/time pattern (long time)

"g" General date/time pattern (short time)
"G" General date/time pattern (long time)
"M", "m" Month/day pattern
"O", "o" Round-trip date/time pattern
"R", "r" RFC1123 pattern
"s" Sortable date/time pattern
"t" Short time pattern
"T" Long time pattern
"u" Universal sortable date/time pattern
"U" Universal full date/time pattern
"Y", "y" Year month pattern


format_expression String or any expression that produce format_pattern

Example:

Select

Format (f.createdOn, "D")

from Facility

or

Select

FORMAT(d.Value, CONCAT('N', r.Precision))

from Datapoint d

JOIN Requirement r on r.ID = d.ParentRequirementID
