HasUserObjectPermission

Note: The 'HasUserObjectPermission' function is only available for the Management System EQL.

Returns True if given user has permission to respective Compliance object (including Group membership, defaults, and taking into account override inheritance)

Syntax:

HasUserObjectPermission (ObjectID, Permission[, UserID])

ObjectID: Compliance Object ID. Identifier of object to be checked. Required.

Permission : Permission, text. One of the following values is accepted:

NoAccess = No access permission present

ReadData = Full Access permission present

ReadProperties = Read Properties or Full Access permission present

ReadPermissions = Read Permissions or Full Access permission present

WriteData = Write Data or Full Access permission present

WriteProperties = Write Properties or Full Access permission present

WritePermissions = Write Permissions or Full Access permission present

CreateObject = Create Object or Full Access permission present

DeleteObject = Delete Object or Full Access permission present

RenameObject = Rename Object or Full Access permission present

CreateTask = Create Task or Full Access permission present

ViewEvents = View Events or Full Access permission present

AddData = Add Data or Full Access permission present

ViewTasks = View Tasks or Full Access permission present

LockData = Lock Data or Full Access permission present

Report = Report or Full Access permission present

ManageWorkflow = Manage Workflow or Full Access permission present

FullAccess = Full Access permission present

UserID : User ID to be used on permisson check. Optional. If not provided, assume current user's ID.

Examples

select

r.id,

r.name,

HasUserObjectPermission(r.id, 'ReadProperties', getCurrentUser())

from requirement r

or (shortened version with same result):

select

r.id,

r.name,

HasUserObjectPermission (r.id, 'ReadProperties')

from requirement r

or (if userId is known ):

select

r.id,

r.name,

HasUserObjectPermission (r.id, 'ReadProperties', 'AE6E9DA2-2BA6-4AE8-AC50-89C7524237A7')

from requirement r
