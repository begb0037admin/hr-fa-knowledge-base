Natural Joins

MaterialDataLine

Example: Get all values for specified Data Line Id

select

dl.value

from MaterialDataLineValue dl

where dl.DataLineID = '{0b9c9809-8f8f-44c7-ba3e-00a25e529675}'

Example: Get all values for specified Material property. Material Property applied to an object are supported like native fields

select

dl.[Material Property].Value,

dl.[Material Property].ChemicalId

from MaterialDataLineValue dl

Permissions:  Manage Materials and Activities right is required to query this table.
