SubmitWorkflows

Create a batch of new Workflow Instances. For each Workflow Instance the required parameters are Workflow Type Name and Workflow Instance Name. Optional items are: Due Date, any attached Compliance Objects, any attached Documents, a Comment field, and a UniqueId that can later be used for CompleteWorkflows method to identify the Workflow Instance you wish to interact with.

CompleteWorkflows

Edit Workflow Instances on their current steps and/or transition them to their next step or close them. Only required parameter is the Unique ID of the Workflow Instance. Optional parameters are a Comment field, a set of UDF values for the UDFs on the current step and an element of type Transition designed to describe the Step Action you wish to perform on that Workflow Instance. Transition requires the Name of the Step Action you wish to invoke (closing the instance via “End Workflow” is allowed). Optional properties are a set of Assignees (user or group), and a Due Date field.

GenerateUniqueIDs

Generate an array of Workflow Unique IDs according to the UniqueID schema for the given Workflow Type. Requires the Workflow Type in string format and the count of UniqueIDs you wish to generate. Returns an array of IDs in string format. These IDs can then be used to create Workflow Instances using the SumbitWorkflows method.
