MaterialDataLine

Columns

ID Material Data Line ID

GroupID Material Data Line GroupID

MaterialID Material Data Line MaterialID

StartTime Material Data Line StartTime

EndTime Material Data Line EndTime

Created Material Data Line Created Date

Updated Material Data Line Updated Date

Property.Value Material Data Value

Property.ChemicalID Material Data ChemicalID

Property.ID … Property.Created Composite column to MaterialProperty table (includes all fields from MaterialProperty)

[Material Property Name].Value, [Material Property Name].EndDate, … Composite column to MaterialDataLineValue (includes all fields, native and composite, from MaterialDataLineValue )

Natural Joins

None

Example : Get material data line information

select

co.path,

co.Name,

a.Name as ActivityName,

(select m.name from material m where m.id = mdl.MaterialID) as MaterialName ,

mdl.StartTime,

mdl.EndTime,

mdl.Property.Name,

mdl.Property.Value,

mdl.Property.MaterialID

from MaterialDataLine mdl

 

LEFT JOIN MaterialGroup mg on mg.ID = mdl.GroupID

LEFT JOIN Material m on m.ID = mg.MaterialID

JOIN MaterialDataLineGroup mdlg on mdl.GroupID = mdlg.ID

JOIN ComplianceObject co on mdlg.ParentID = co.ID

JOIN Activity a on a.id = mdlg.ActivityID

 

Where co.Path Like 'Division\Facility\POI'

And mdl.Property.PropertyType = 'Specific Use'

Permissions:  Manage Materials and Activities right is required to query this table.
