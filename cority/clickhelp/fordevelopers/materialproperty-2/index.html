/materialProperties

POST

Description:

Creates a new Material Property, alternately by copying an existing Material Property.

Security: Requires Manage Materials and Activities system right.

SDK API (create): envianceSdk.materialProperties.createMaterialProperty (materialPropertyInfo, onsuccess, onerror)

SDK API (copy): envianceSdk.materialProperties.copyMaterialProperty (materialPropertyInfo, copyFrom, onsuccess, onerror)

Parameters
Name Located in Description Required Schema
materialPropertyCreate body Create Material Property body Yes materialPropertyCreate
Responses
Code Description Schema
200 The id string (GUID) for the newly created Material Property, or the id for the queued command if async. string
Copy Code
JSON
POST/MaterialPropertyService.svc/materialProperties HTTP/1.1
Content-Type: application/json; charset=UTF-8

{
  "materialPropertyInfo": {
    "name": "Property Name – VBP",
    "description": "Material Property Description",
    "propertyType": "Value Based Material",
    "dataType":"Numeric"
  }
}


/materialProperties/{materialPropertyIdOrName}

PATCH

Description:

Updates a Material Property.

Security: Requires Manage Materials and Activities system right.

SDK API: envianceSdk.materialProperties.updateMaterialProperty (materialPropertyIdOrName, materialPropertyInfo, onsuccess, onerror)

Parameters
Name Located in Description Required Schema
materialPropertyIdOrName path Either an id string (GUID), or a name string uniquely identifying the Material Property. Any string that matches the pattern of a GUID is interpreted as an id string, and not a name. A name string must be URL encoded. Yes string
materialPropertyInfo body A materialPropertyInfo structure. Some properties of this structure are ignored during this operation; see the details of this structure for more info. Yes materialPropertyInfo
Responses
Code Description Schema
200 The id string (GUID) for the updated Material Property. string

JSON

Description:

Security: Requires Manage Materials and Activities system right.

SDK API: envianceSdk.materialProperties.deleteMaterialProperty (materialPropertyIdOrName, onsuccess, onerror)

Parameters

Models

materialPropertyCreate 

Creation info for Material Property

Name Type Description Required
materialPropertyInfo [ materialPropertyInfo ] A materialPropertyInfo structure. No
copyFrom string The id string (GUID) of an existing Material Property to copy. No

materialPropertyInfo 

Name Type Description Required
id string The id string (GUID) for the Material Property. Ignored for: Create Field, Update Field No
name string Name of the Material Property. Required for: Create Field No
description string Description of the Material Property. No
propertyType string The type of the Field. Ignored for: Update. Required for: Create. No
dataType string If specified, must be one of Numeric or Boolean. This property is only valid for VBPs, and cannot be modified on an existing field. Ignored for Update Field No
uniqueTag string If specified, this must be a string that is unique among all SUVs in the system. This property is only valid for SUVs. No
isChemLogical string (boolean) A flag indicating whether or not this field is a Chemical Logical field. The default is false. A value of true is only valid for FBPs. This value cannot be modified on an existing field. Ignored for: Update Material Field No
valueHistory [ materialPropertyFormulaHistory ] An array of MaterialPropertyFormulaHistoryInfo structures. Required for: Create Material Property if propertyType set to PrimaryFBP, SecondaryFBP, TertiaryFBP. Ignored for PropertyType set to MaterialVBP, ActivityVBP, SUV No
