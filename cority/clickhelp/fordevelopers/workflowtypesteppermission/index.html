WorkflowTypeStepPermission

Columns

WorkflowTypeVersionRoleID Version Role ID

WorkflowTypeStepID Step ID

LocalPermission Permission (numeric): 0-None, 1-View, 3-View and Edit, 7-View , Edit and Override

LocalPermission.View Boolean, true if Local Permission View is checked

LocalPermission.Edit Boolean, true if Local Permission Edit is checked

LocalPermission.Override Boolean, true if Local Permission Override is checked

GlobalPermission Permission (numeric): 0-None, 1-View, 3-View and Edit, 7-View ,Edit and Override

GlobalPermission.View Boolean, true if Global Permission View is checked

GlobalPermission.Edit Boolean, true if Global Permission Edit is checked

GlobalPermission.Override Boolean, true if Global Permission Override is checked

Natural Joins

WorkflowTypeVersionRole

Example: Get Step permissions for the Corrective Action workflow type.

select

st.name as Step,

role.name as Role,

sp.LocalPermission,

sp.GlobalPermission

from Workflowtype wt

join WorkflowTypeVersionStep st on wt

join WorkflowTypeStepPermission sp on sp.WorkflowTypeStepID = st.id

join WorkflowTypeVersionRole r on r.id = sp.WorkflowTypeVersionRoleID

join WorkflowRole role on role.id = r.workflowroleid

where

wt.name = 'Corrective Action' and

wt.iscurrentversion = 'true'

Permissions:  Manage Workflows right is required to query this table.
