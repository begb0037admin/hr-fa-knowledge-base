/currentSession

GET

Description:

Gets information about the current session. The current session is determined using the session id specified in the Authorization header.

Security: All users.

SDK API: envianceSdk.authentication.getCurrentSession(onsuccess, onerror)

Responses
Code Description Schema
200 An instance of the sessionInfo data structure. sessionInfo
Copy Code
JSON
GET /ver2/AuthenticationService.svc/currentsession HTTP/1.1

DELETE

Description:

Ends the current session, logging off the User. The current session is determined using the session id specified in the Authorization header.

Security: All users.

SDK API: envianceSdk.authentication.endCurrentSession(onsuccess, onerror)

Responses
Code Description
204 Current session ended.

Copy Code
JSON
DELETE /ver2/AuthenticationService.svc/currentsession HTTP/1.1

timeZone 

Describes a time zone, including its offsets from UTC.

Name Type Description Required
name string (number) The name of the time zone. No
stdOffset string (number) The offset in minutes from UTC during standard time. No
dstOffset string (number) The offset in minutes from UTC during daylight savings time (DST). This property will be identical to “stdOffset” for time zones that do not observe DST. No
currentOffset string (number) The current offset in minutes from UTC (which can change upon whether the time zone is currently observing DST or not). No
