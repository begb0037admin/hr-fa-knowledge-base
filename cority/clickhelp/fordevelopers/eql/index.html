envianceSdk.eql.execute

Version 2.0

Other Versions:

Version 1.0

Description

This function executes a batch of one or more EQL queries.

Parameters

eql The EQL batch to execute. For details on EQL syntax, see the documentation on EQL.

page Number. The page number within the entire result set to return.

pageSize Number. The number of records to assign to each page.

Return Value

An array of EQL Tables.

Example

envianceSdk.eql.execute(

"SELECT TOP 1 f.Name FROM Facility f ORDER BY f.Name",

1,

10,

function(response) {

alert("result set 1, row 1, column 1: " + response.result[0].rows[0].values[0]);

});

envianceSdk.packages.eql.executeEqlItem

Version 2.0

Other Versions:

None

Description

This method executes an EQL Query Item.

Parameters

executeParameters A JSON object literal with the following properties:

path The relative path to the EQL Query in the App.

page Number. The page number within the entire result set to return.

pageSize Number. The number of records to assign to each page.

format One of JSON, CSV, or XML. The default is JSON.

parameters A dictionary of parameter names (without any leading @ sign) to string value pairs. Use an empty dictionary if no parameters are to be used.

Return Value

An array of EQL Table objects.

Callbacks

onsuccess A callback function to use upon success.

onfailure An optional callback function to use upon error.

Example

envianceSdk.packages.eql.executeEqlItem(

{

"/path/to/query.eql ",

"page": 1,

"pageSize": 10,

"format": "CSV"

},

{

"param1": "1,2,3",

"param2": "2011-01-01"

},

function(result) {

console.log(result[0].rows[0].values[0]);

});
