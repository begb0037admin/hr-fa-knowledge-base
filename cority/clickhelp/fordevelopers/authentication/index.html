envianceSdk.authentication.authenticate

Version 2.0

Other Versions:

Version 1.0

Description

Creates a new session in the Management System by authenticating via username and password.

Parameters

userName The user name string of the EMS User account.

password The password string of the EMS account.

Return Value

The newly created session id will be passed to the onsuccess callback in the result property.

Notes

Upon successful authentication, the session id and home system id for the User are automatically persisted during the rest of the browser session, and used for all subsequent calls to the EMS APIs. Therefore, you should not have to worry about tracking the session id and passing it along to each API when using the SDK functions.

Example

envianceSdk.authentication.authenticate("JSmith", "1234",

function(response){

alert("Logged in with session id: " + response.result);

});

envianceSdk.getCurrentSession

Version 2.0

Other Versions:

None

Description

Retrieves information about the current User's session.

Parameters

None

Return Value

A SessionInfo object will be passed to the onsuccess callback in the result property.

Example

envianceSdk.authentication.getCurrentSession(

function(response) {

var session = response.result;

alert("Home system id: " + session.homeSystemId);

});

envianceSdk.endCurrentSession

Version 2.0

Other Versions:

None

Description

Ends the current User's session, logging the User off.

Parameters

None

Return Value

None

Example

envianceSdk.authentication.endCurrentSession(

function(response) {

alert("Logged off!");

});
