Debugging

Debugging tips:

  • The line number is the row number on the Excel upload file (row #1 will always be the column heads, row #2 will be the first process row).
  • Review errors top to bottom. Some errors may be a result of failure on previous items.
  • Highlight error lines on the source file before deleting rows for corrective uploads.
  • You can also copy error rows to the top of the file and insert a blank row after them, to preserve the original rows while uploading corrections. Processing will stop when the tool hits a blank row.
  • For more information on the error types, see the documentation for each tool.

Note:  For any bulk tool editing operation, the same rules apply as do when performing the operation manually in the System. This means that execution will fail for the same reasons that it does if you were performing the edit in the system manually.

Common errors:

  • Object cannot be copied because its source path and name cannot be correctly resolved.

    The object you are trying to copy cannot be found. Check the name and the path to the object you are trying to copy.

  • Object cannot be copied because its destination path and name cannot be correctly resolved.

    The destination to which you are trying to copy does not exist in the system. Check the path.

  • Object cannot be deleted because its path and name cannot be correctly resolved.
  • Validation error has occurred. An object with this name already exists under this parent object.
  • Validation error has occurred. Name contains symbols which are not allowed.
  • Validation error has occurred. The value given for Name cannot be greater than 255 characters.
  • Validation error has occurred. [Field] value cannot be null.
  • Cannot resolve compliance object. Path: [path]
  • Cannot resolve group(s) with name '[Group Name]'.
  • Cannot resolve compliance object(s). Path(s): [path]
  • Cannot resolve task with name 'Task 1'.
  • Cannot resolve task notification to Edit at line #167.
  • Validation error has occurred. Missing or redundant options for [field].
  • Username(s) '[userid]' already exists.
  • Cannot resolve template: [template name]
