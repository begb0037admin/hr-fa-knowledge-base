POST /documents

Creates a new Document, alternately by copying an existing Document. When creating a Document, the Document will be created in the specified parent folder. If a value is not specified, the Document will be created in the root Folder of Document Manager. The new Document will inherit the security permissions of its parent Folder.

Security: Requires Edit permissions on the parent Folder, or the Manage Documents right.

SDK API (create): envianceSdk.documents.createDocumentBinary (fileInput, documentInfo, onsuccess, onerror)

SDK API (create): envianceSdk.documents.createDocument(documentInfo, onsuccess, onerror)

SDK API (copy): envianceSdk.documents.copyDocument (documentInfo, copyFrom, onsuccess, onerror)

POST /folders

(createCopyDocumentFolder)

If a value is not specified, the Folder will be created in the root Folder of Document Manager. The new Folder will inherit the security permissions of its parent Folder.

DELETE /folders/{documentFolderIdOrPath}

(delete)

Deletes an existing Document Folder, including all of its sub-Folders, Documents, their versions and their content. Deletions are permanent.

Security: Requires Edit permissions on the parent Folder, or the Manage Documents right.

SDK API: envianceSdk.documents.deleteDocumentFolder(documentFolderIdOrPath, onsuccess, onerror)

Path parameters

documentFolderIdOrPath (required)

Path Parameter — The id string (GUID) or path of the Folder. Any string that matches the pattern of a GUID is interpreted as the id string, and not the path. A path string must be URL encoded.

PATCH /folders{documentFolderIdOrPath} 

(update)

Updates the properties of a Document Folder, potentially moving it to a new Folder. Updating the parent Folder of a Folder effectively moves that Folder to the new parent folder. When updating a Folder, if the value specified for parentFolder is different from the current parent Folder of the Folder being updated, the Folder will be moved to the specified location.

Security: Requires Edit permissions on the parent Folder, or the Manage Documents right.

SDK API: envianceSdk.documents.updateDocumentFolder(documentFolderIdOrPath, documentFolderInfo, onsuccess, onerror)

Creation info for Document

documentInfo (optional)

array - [documentInfo]

A documentInfo structure

copyFrom (optional)

String - The full path to an existing Document whose content will be copied and used as the content of the new Document. Specifying this property allows you to copy an existing Document to another location in Document Manager. This property will be ignored if the "content" property of documentInfo has a value.


documentFolderInfo 

- Up

Information about a Folder in Document Manager.

String - The id string (GUID) of the Folder. Ignored for: Create Document Folder, Update Document Folder

name (optional)

String - The name of the Folder.

description (optional)

String - The description of the Folder.

parentFolderIdOrPath (optional)

String - The id string (GUID) or full path of the Document Folder in which this Folder is placed. Any string that matches the pattern of a GUID is interpreted as the id string, and not the path of the parent Folder. The path of a Folder should be URL encoded.

copyFrom (optional)

String - The full path to an existing Document whose content will be copied and used as the content of the new Document. Specifying this property allows you to copy an existing Document to another location in Document Manager. This property will be ignored if the "content" property of documentInfo has a value.

documentInfo

- Up

Information about a Document in Document Manager. If contentUrl is specified during a call to Create Document or Update Document, then the latest version of the Document will simply be a URL to the content hosted at this location.

id (optional)

String - The id string (GUID) of the Document. Ignored for: Create Document, Update Document

name (optional)

String - The name of the Document. May be empty or null for Update Document and field will not be modified

mimeType (optional)

String - The mime type of the Document. If left unspecified when creating or updating a Document the application will assign a mime type according to the file extension.

fileName (optional)

String - The original file name of the Document. This is only required when the content property is used. It allows the Management System to detect the mime type and use it for the Download Document API. May be empty or null for Update Document and field will not be modified. Required for Create Document, Update Document if content is specified. Ignored for Get Document

description (optional)

String - The description of the Document.

folder (optional)

String - The id string (GUID) or full path of the Document Folder in which this Document is placed. Any string that matches the pattern of a GUID is interpreted as the id string, and not the path of the Folder.

content (optional)

String - The content of the Document, Base64 encoded.

contentUrl (optional)

String - The url for the Document content. In the case of Documents hosted outside of Document Manager, this url will be the value specified for the Document location.

version (optional)

Integer - The version number of the Document. Currently, only the latest version is returned. Ignored for: Create Document, Update Document

objects (optional)

String - An optional array of Compliance Model object id strings (GUIDs) or paths, specifying zero or more Objects to which the Document is associated. Any string that matches the pattern of a GUID is interpreted as an id string, and not a path.

tasks (optional)

String - An optional array of Task id strings (GUIDs), specifying zero or more Tasks to which the Document is associated.

workflows (optional)

String - An optional array of Workflow id strings (GUIDs) or unique ids, specifying zero or more Workflows to which the Document is associated. Any string that matches the pattern of a GUID is interpreted as an id string, and not a unique id.

comments (optional)

String - An optional. String of the version comments.

nameSuffixOnDuplication (optional)

String - An optional field which provides a way of generating new unique name with the suffix on document duplication during it creating. Can be: "Timestamp||Guid||Increment||None(by default)".
