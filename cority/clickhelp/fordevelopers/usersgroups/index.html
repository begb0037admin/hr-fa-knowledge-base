envianceSdk.groups.createGroup

Version 2.0

Other Versions:

None

Description

Creates a new User Group in Group Manager.

Parameters

groupInfo An instance of the groupInfo object. Some properties of this object are ignored by this function; see details of this object for more info.

Return Value

The id string (GUID) of the new Group will be passed to the onsuccess callback in the result property.

Example

envianceSdk.groups.createGroup(groupInfo,

function(response) {

alert("Created new group with id: " + response.result);

});

envianceSdk.groups.getGroup

Version 2.0

Other Versions:

None

Description

Gets information about the specified User Group in Group Manager.

Parameters

groupIdOrName The id string (GUID) or name of the Group in Group Manager. Any string that matches the pattern of a GUID is interpreted as the id string, and not the name of the Group.

Return Value

A groupInfo object will be passed to the onsuccess callback in the result property.

Example

envianceSdk.groups.getGroup("Auditors",

function(response) {

var group = response.result;

alert("Retrieved group with rights:" + group.rights.join(","));

});

envianceSdk.groups.setGroupMembers

Version 2.0

Other Versions:

None

Description

Sets the members of an existing User Group in Group Manager, overwriting the existing set of members.

Parameters

groupIdOrName The id string (GUID) or name of the Group in Group Manager. Any string that matches the pattern of a GUID is interpreted as the id string, and not the name of the Group.

members Array. An array containing the id string (GUID) or user name of the Users. Any string that matches the pattern of a GUID is interpreted as the id string, and not the user name of a User.

Return Value

None

Notes

You cannot set the members of the "Administrators" Group.

Example

envianceSdk.groups.setGroupMembers(

"Auditors",

["90d69025-4741-4797-98c8-c8351f6853ef", "jtsmith"],

function(response) {

alert("Group members set.");

});

Description

function(response) {

envianceSdk.groups.groupInfo

Version 2.0

Other Versions:

None

Description

Constructs a groupInfo object instance in JavaScript.

Parameters

name The name of the Group.

rights Array. An array of System Rights granted to the Group.

members Array. An array of User id strings (GUIDs) and/or usernames, who are the members of the Group. Any string that matches the pattern of a GUID is interpreted as the id string, and not the username of a User.

Example

var group = new envianceSdk.groups.GroupInfo(

"Auditors",

["Manage Documents", "Manage Reports"],

["90d69025-4741-4797-98c8-c8351f6853ef", "jtsmith"]);
