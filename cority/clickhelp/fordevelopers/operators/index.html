Operators

EQL can do basic arithmetic, with the following operators:

x * y (multiplication)

x / y (division)

x + y (addition)

x - y (subtraction)

x % y (modulo)

Examples

select f.LongDeg +f.LatDeg

from

Facility f

Will return sum of Latitude and Longitude degrees

select f.LongDeg *360

from

Facility f

Will return Longitude degrees in seconds

select f.LongDeg -45

from

Facility f

Will return offset of Longitude degree

select f.LongMin % 60

from

Facility f

Will return the remainder in seconds of Longitude minutes
