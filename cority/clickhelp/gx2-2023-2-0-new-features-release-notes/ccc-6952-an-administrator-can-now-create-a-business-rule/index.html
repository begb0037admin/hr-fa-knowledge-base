CCC-6952: An administrator can now create a business rule to archive and/or purge ‘Login Log’ records

This will help organizations comply with data retention policies.

To support this:

  • There is a new 'Login Log Archive' table.
    • The table is accessible using the 'Show Record History' action on the 'Login Log' list view. On this view, the action will list archived Login Log records (provided they have not been purged). It will not list viewed/created/updated Record History records because they are not applicable here.
    • The table has the same columns as the 'Login Log' table and an additional column that specifies if a record has been archived or marked for purge.
  • The 'Login Log' entity is now available for use in business rules.
    • The entity can be used to:
      • Archive 'Login Log' records
        • When archived through a business rule, the records will move to the new 'Login Log Archive' table.

      • Mark 'Login Log' records for purge
      • Purge 'Login Log' records
        • When purged through a business rule, the records will be removed from the 'Login Log Archive' table.
  • Login Log Archive, Mark For Purge, and Purge business rule actions are now available.
