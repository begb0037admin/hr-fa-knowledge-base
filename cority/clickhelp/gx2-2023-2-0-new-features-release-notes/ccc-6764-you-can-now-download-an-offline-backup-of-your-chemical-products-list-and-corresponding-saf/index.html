CCC-6764: You can now download an offline backup of your Chemical Products list and corresponding Safety Data Sheets

  • This will ensure you have access to these valuable resources locally, in case you lose or at times do not have internet access.
  • The download should be conducted periodically to ensure the content is up to date.
  • To support this, the Chemical Products list has a new 'Export Offline Backup' action.
  • To access the action, the user's role must be granted the new chemproduct.exportofflinebackup security action.
  • When executed, a dialog box will open prompting the user to enter an email address.
    Note: By default, the logged-in user's email address will be populated. The email address can be changed to that of another user, if necessary.
  • When an email address is present in the field and the user clicks GENERATE, a link for downloading a ZIP file will be emailed. The link will be valid for 30 days.
  • Once downloaded, the ZIP file will contain a Microsoft Excel spreadsheet the Chemical Products list view and content. It will also contain a folder of the corresponding SDSs in PDF format.
  • From within the Excel file, each applicable row in the list will provide a direct link to the corresponding SDS contained in the accompanying folder.
  • In Administrator tools, there is a new 'SDS Backups' module, which is accessible from the left-hand menu. The module lists all of the backups that have been executed. For any that have not expired (still within the allotted 30 days), the ZIP file will be downloadable there also.
  • Note: The module must be added to the Administrator tools using Menu Configuration.
