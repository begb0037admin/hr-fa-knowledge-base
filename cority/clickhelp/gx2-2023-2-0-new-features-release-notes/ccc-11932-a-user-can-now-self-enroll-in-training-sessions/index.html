CCC-11932: A user can now self-enroll in training sessions

  • To support this, a new training series 'SelfEnrollSeries' with description 'Training Series' has been added to the 'Online Training Series' look-up table. The series has an ID of -1 and the following characteristics:
    • Its code cannot be modified.
    • Its description can be modified.
    • The series cannot be deleted.
    • Its start date is set to 01/01/2023 and its end date is not set.
    • Its recurrence is set to 'One Time' and cannot be modified.
    • Inactive is false and can be modified.
    • Days to Complete is not set and can be modified.
    • Its sequence cannot be changed.
  • The following new fields have been added to the default 'Training Session' layout for in-person training:
    • Enable Self-Enroll - a check box, which by default is not selected
    • Classroom Max Capacity - a number field that's value must be a positive whole number
  • The number of attendees allowed for a training session cannot exceed the classroom's maximum capacity.
  • In GX2, if the user tries to enroll an attendee when the classroom is already at maximum capacity, a pop-up will indicate that.
  • In GX2 Administrator > Profiles, in the My Tasks section of the 'myCority Modules' sublist, a new slider button labelled 'Enroll in Online Training' has been added.
  • By default, it is disabled.
  • When the slider is enabled for a user's profile, that user will have the ability to self-enroll in online training from myCority.
  • In myCority, an equivalent slider has been added to the My Tasks section of the 'Personalize myCority by User Profile' screen. By default, the slider is disabled.
    • If 'Enroll in Online Training' has been selected for the user's profile within GX2 and 'Enroll in Online Training' has been selected on the 'Personalize by User Profile' screen in myCority, the new 'Enroll in Online Training' icon will be added for the user to the 'Create New' section of myCority.
  • When a user whose role has the required security configuration clicks the new 'Enroll in Online Training' icon, a dialog box with the following options will be displayed:
    • Enroll in Online Training
    • Enroll in In-Person Training
  • If the user clicks 'Enroll in Online Training', a layout for enrolling in a single training session is presented.
    • When the user selects a course, the values of the other fields on the layout will populate automatically.
    • When the user clicks 'Schedule Training', he or she will be enrolled in a single session of the course and redirected to My Tasks, which will be filtered for training to courses for which today is => the start date and < the end date.
  • If the user clicks 'Enroll in In-Person Training', a dialog box will display that has a picklist of all in-person training sessions for which the following are true:
    • 'Enable Self-Enrollment' is selected.
    • 'Course Max Capacity' has not been reached.
    • 'Course Date' is not in the past.
      • When the user selects a course session, he or she will be added to its attendees list, and a confirmation pop-up with the course details will display.
      • If no courses are available, a pop-up will indicate that.
