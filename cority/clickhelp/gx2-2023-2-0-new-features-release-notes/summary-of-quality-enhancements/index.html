Summary of Quality Enhancements

The table below lists the smaller design improvements we have made in the Quality cloud. The items are organized by component and the components are arranged in alphabetical order.

ItemComponent(s)Description
CCC-10910Audits

For recording additional employee details, the following three new user-defined text fields can now be added to custom versions of the Audit layout:

  • UDFEmployee1
  • UDFEmployee2
  • UDFEmployee3

The fields can be populated through import, and are available for use in business rules and in Query Builder.

 

CCC-2928Document Management

For custom versions of the 'Document Reviewer' layout (ML-003168), a new 'Render as PDF' field is now available.

  • The field will be disabled unless the Publisher check box is selected.
  • The field will be enabled, and selected by default, when the Publisher check box is selected.
  • If both check boxes are selected, files of supported types will be converted to and rendered as PDF.
  • If 'Render as PDF' is not selected, the 'Headers and footers' check box cannot be selected.

 

CCC-2356Document Management

For document management, if a document is rejected at a particular stage, the document's status will now be reverted to its original. If approval at that step is required, the email sent to the document owner will indicate the document was rejected.

 

CCC-11764Management of Change

The following new UDFs can now be added to custom versions of the Environmental, Quality, and Safety 'Management of Change' layouts:

  • UDFText13 through UDFText34 - text fields, each with a maximum character limit of 1000
  • UDFdate23 through UDFdate29 - date fields
  • UDfFlag13 through UDfFlag18 - checkbox fields

The fields can also be added to custom versions of the 'Approval Workflow' layout.

The new fields are available for use in Query Builder and Report Writer, can be used in Business Rules, Business Rule Actions, and Display Rules.

They can be populated and updated using the Import Utility or the Cority Data Integration Engine.

The equivalent columns can be added to applicable custom list views.

 

CCC-11761Management of Change

For Management of Change (MOC) records, in the Approvers look-up table, there is a new 'Secondary Approver for this Location' check box.

If selected, the user will be able to add one more approver per GDDLOFB location and MOC approver role.

When selected and there is more than one approver for a given GDDLOFB location, a new Management Of Change record will auto-populate with the specified primary approver.

Note: You cannot specify a secondary approver for a location if all GDDLOFB fields use 'Equals' and 'Equals and Below' is available.

If there is a primary and secondary approver on a Change Request, it auto-populates approver.

If no primary approver is specified, nothing gets auto-populated.
