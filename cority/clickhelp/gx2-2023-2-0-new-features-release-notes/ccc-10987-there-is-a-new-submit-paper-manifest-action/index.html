CCC-10987: There is a new 'Submit Paper Manifest' action that can be added to custom versions of the Waste Manifest (ML-000229 and ML-003510) layouts

  • The action appears on the Waste Shipment tab.
  • To use this action, the user's role must be granted the wastemanifest.importpapermanifest security action.
  • When a user selects the new action, the 'Submit Paper Manifest' modal will display, prompting the user to attach a manifest file. The supported file types are PDF and TXT.
  • The modal has Cancel and Submit buttons.
  • When the user attaches a supported manifest file and clicks Submit, the file will be submitted to EPA.
  • If the submission is successful, the fields described below will get updated.
  • The following four fields can also be added to custom Waste Manifest layouts:
    • Paper Copy Submitted - a read-only checkbox
    • Transporter Receipt Date - a date field
    • TDSF Receipt Date - a date field
    • Generator Certification Date - a date field
  • The equivalent columns can be added to applicable list views.
  • The latter three fields:
    • Are available in Query Builder and Report Writer, and for use in business rules and display rules.
    • Can be populated and/or updated using the Import Utility or the Cority Data Integration Engine.
