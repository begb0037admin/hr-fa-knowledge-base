Summary of Platform Enhancements

The table below lists the smaller design improvements we have made within the GX2 Platform. The items are organized by component and the components are arranged in alphabetical order. Descriptions of larger features follow the table.

ItemComponent(s)Description
CCC-12923Administrator

GX2 now supports up to three SSO buttons on the Login screen.

This will make it easier for users of a GX2 implementation serving multiple regions or departments to log in through Single Sign-On (SSO). It will improve such users' login experience and save them time.

Note: This is only supported when using Mixed Mode authentication.

Each SSO button must be configured as a separate ‘SAML Keys’ look-up table entry. For information on how to configure SAML Keys, see the GX2 User Guide.

Each 'SAML Keys' look-up table entry has new 'SSO Login Button Text' and 'Show on Login Screen' fields.

The 'SSO Login Button Text' field supports a maximum of 100 characters. The text entered will be used as the label for the SSO login button.

If the 'Show on Login Screen' checkbox is selected, the SSO login button with text provided will display on the Login screen.

If not selected, the button will not display.

If no checkbox is selected, no SSO login buttons will display.

A maximum of three checkboxes can be selected.

 

CCC-12085Administrator

The performance of actions that pull data from the ENHESA API has been improved.

 

CCC-10941Administrator

For users of multiple CorityOne solutions (GX2, EMS, ReadySet, WeSustain), each now has a Waffle icon at the top right of the user interface. When clicked, a menu with an icon for each of your CorityOne solutions will display. This will enable users to move easily between solutions.

Also, the login screens for GX2 and myCority have been refreshed.

 

CCC-9886Administrator, Questionnaire

When a questionnaire with one or more Draw type questions is printed, any added background and/or drawing on the background (a signature, for example) for such questions will now be displayed in the printout.

 

CCC-9980Administrator, Demographics

The following new user-defined picklist fields can now be added to custom versions of the Employee layout:

  • UDF_Employee_1
  • UDF_Employee_2

This will allow additional contacts (an HR contact, a Safety contact, for examples) to be added.

The new fields can be populated through import, and are available for use in business rules and in Query Builder.

 

CCC-843End-User

While a user's account is inactivated/locked, access to the system for that user is now always denied.

 

CCC-11352Infrastructure

The jQuery UI library has been updated to version 1.13.2.

 

CCC-10638Infrastructure

The Event Log has two new columns:

  • Server Time Zone - This is the time zone the server is set to at the time of the event. Depending on the platform or service (GX2, myCority, TDBR, etc.), the server might be different, so this provides the administrator with a way to understand the date and time logged in the Date column.
  • User Date Time - This is the date and time the event was logged, converted to the user's time zone.

If the Server Time Zone value is not available for an event, neither value will be provided (both fields will be empty).

If the event occurred prior to the 2023.2.0 release, neither value will be provided.

 

CCC-10702Interfaces

For the RESTful API, the character limit of the 'Access Token' field in the 'API Token' look-up table has been increased to 4096 characters.

Note: Due to technological constraints, this is the maximum limit that can be accommodated, therefore this limit cannot be extended any further in the near future.
