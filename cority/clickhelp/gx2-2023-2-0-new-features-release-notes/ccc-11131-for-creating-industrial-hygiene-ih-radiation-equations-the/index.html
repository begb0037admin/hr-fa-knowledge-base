CCC-11131: For creating Industrial Hygiene (IH) ‘Radiation’ equations, the Equation Library is now available in the IH cloud

  • The Equation Library is now available in the Industrial Hygiene (IH) cloud and accessible using the IH left-hand menu.
  • An IH user can create equations using the library and have results display on 'IH Sample' records.
  • By default, the module is granted to all roles.
  • The module is also accessible through the 'My Shortcuts' gadget in Advanced Dashboard by clicking 'New Radiation Calculation'.
  • For further accessibility configuration, it has been added to the 'Menu Configuration' selection tree.
  • The module is available in Query Builder and Report Writer and for use in business rules, business rule email actions, and workflow steps.
  • To support its use in the IH cloud, the Equation Library has a new 'IH and Radiation Equations' list view with the following columns: 
    • Code
    • Description
    • Entity
    • Field
  • For creating IH equations, the following IH equation entities have been added to the library:
    • IHSAMPLE
    • IHSAMPLERESULT
    • IHRISKASSESSMENTMASTER
    • IHNOISESAMPLE
  • An additional 'Emission Parameter Variables' tab is also included.
  • An 'IH Related Equation' can be added from the 'IH Related Equation Set' list to the 'Equation Set' list.
  • To be used with the Equation Library, the following calculated fields have been added to the 'Results' subsection of the default 'IH Sample Results' layouts (therefore, to all 'IH Sample Results' records):
    • Calculated Field 1
    • Calculated Field 2
    • Calculated Field 3
    • Calculated Field 4
  • The equivalent columns can be added to applicable custom list views.
  • Also, the 'Equation Set' field can be added to custom versions of the 'IH Sample', 'IH Sample Results', 'IH Risk Assessment Master', and 'IH Noise Sample' layouts.
  • An IH radiation user can define fields for custom calculations within the Equation Library.
  • To support this, 20 new numeric UDF fields are now available for adding to custom versions of the 'IH Sample' and 'IH Sample Results' layouts.
  • The new fields can store and display numbers that have up to three decimal places. 
  • In IH, the Equation Library itself functions the same way it does for the 'Emissions Inventory' module.
  • For information on working with the Equation Library to create and edit equations, see the GX2 User Guide. For the 2023.2.0 Production release, that guide will be updated to reflect the library's availability in the IH cloud.
  • In addition, a numeric 'Nuclear Energy Worker Cumulative Exposure' field can now be added to custom versions of the employee Demographics record. The field can accommodate a number that has a maximum of three decimal places.
  • It is accompanied by a drop-down menu for specifying the units. The drop-down menu will list all IH-flagged units.
  • The 'Nuclear Energy Worker Cumulative Exposure' and corresponding units fields are available for adding to custom versions of 'IH Sample' layouts.
  • If a user populates the value and units on an employee Demographics record, that will then be displayed in the read-only 'Nuclear Energy Worker Cumulative Exposure' field on applicable 'IH Sample' records.
  • The value can also be used in equations created within the Equation Library. Note: The value cannot yet be updated as a result of a calculation.
