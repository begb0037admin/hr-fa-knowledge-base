CCC-10540: A user can now assign an action or compliance obligation to multiple individual assignees, multiple teams, or a combination of those

  • These assignees will be treated as a team. For example, only one action per due date (if recurring) will be created. You will be unable to deselect the 'Complete as Team' checkbox.
  • Then any assignee can complete the action from within myCority or GX2 and receive the configured (through business rules) notifications.
  • To support this:
    • A new global 'Allow Assignment of Actions to Multiple Groups (Teams) and/or Assigned To' system setting has been added to enable the functionality.
    • In layout configuration, on applicable GX2 and myCority 'Actions' and 'Compliance Actions' layouts, a new 'Enable Multiple Values' checkbox has been added for both the 'Assigned To' and 'Assigned To Group' fields. The checkbox is only visible if the new system setting mentioned above is selected.
      • When the checkbox is selected for a field, that field will accommodate multiple values.
      • Note: For multiple values to display in the equivalent column on applicable list views, that column will have to be added to a custom version of the list view and multiple values enabled for the column.
  • When business rule emails are sent for the assignment(s), all of the following individuals can be included:
    • AssignedTo - all employees specified
    • AssignedToGroup - all current members in all groups specified
    • GrouporTeamMembers - all current members in all groups and teams specified
    • VerifiedByEmployee - only the first selected
  • Note: After configuring this functionality for use, you might have to end some recurring actions (tasks) and then set them up again.
  • The following are known limitations:
    • Because the system setting is global (set for all users), if you configure this functionality in support of your safety or environmental compliance actions, for example, its behavior will apply for all new and existing ‘Findings & Actions’ in the system.
    • The new system setting can be selected without ‘Enable Multiple Values’ being configured for a field, which would still allow a user with the appropriate security setup to assign an action to a single person and to a single team, unless a business rule is created to prevent that.
    • With this functionality configured, a single action is assigned to each individual added and to each member of each team added. Any of those people can complete the action. Without this functionality configured, it can be determined for each individual 'Finding & Action' or 'Compliance Obligation/Calendar' item whether it will be treated as a Group or Team assignment (that is, the 'Complete as Team' checkbox is editable).
    • MAEN cannot be used for sending out the reminders. It will not include the secondary assignees.
    • The system emails allow for a maximum length of 1000 characters in each of the 'To' and 'CC' fields. If all recipients' email addresses combined for the given field exceeds that, then no emails will be sent.
    • Neither the Import Utility nor Data Integration Utility can be used to create actions and assign to multiple assignees.
    • This functionality is not available for use with the assignment of actions for Corrective Plans. For recurring actions for Permits or Legal Requirements, 'Assigned to Group' is used, however 'Findings & Actions' are created for each team member who has the tree combination matching either the Permit or Legal Requirement location.
    • This functionality does not apply to the use of 'Groups and Teams' with inspections.
    • For 'Verified By Employee', only the first specified (primary) will be able to access and edit the action or obligation.
