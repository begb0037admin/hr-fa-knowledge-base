CCC-11024: Enhancements have been made to the
Office Ergonomics cloud

These include:

  • Bug fixes related to SCORM files and tokens
  • Bug fixes related to translations
  • An RSIGuard endpoint design improvement
  • Additional error reporting
  • Performance improvements
  • A new 'Legacy Ergo Data Log' accessible from the Ergonomics sidebar
    • Note: The user’s role must be granted the ‘Personal Risk’ security module to see and use this log.
    • The log has a list view with the following columns:
      • Employee ID
      • Activity Type
      • Activity
      • Date
      • Details
      • Attachments (icon has a hover-over preview)
    • The log has an Actions menu with the following:
      • Show Record History
      • Print
      • Export List to Excel
    • Clicking a record from the list view will open it in a layout that provides a field corresponding to each column listed above.
    • The data from the log is available in Query Builder and Report Writer.
