CCC-9683: Enhancements have been made to the Telehealth functionality

  • Telehealth now supports the creating, updating, and cancelling of recurring meetings.
  • Note: Zoom does not support the following:
    • Yearly recurrence
    • More than 50 occurrences
    • A daily recurrence pattern with a repeat interval greater than 90
    • A weekly recurrence pattern with a repeat interval greater than 12
    • A monthly recurrence pattern with a repeat interval greater than 3
  • A user can now join a Telehealth meeting from myCority.
    • The myCority user will be notified about the meeting according to the meeting's notification schedule. The user can then simply click 'Go To Zoom Meeting' on the notification.
  • Some minor UX improvements have also been made.
  • For in-depth information on working with Telehealth appointments, see the CCC-9100 in the GX2 2023.1.0 New Features Release Notes document.
