CCC-11633: There is a new 'Job Description' field that can be added to custom versions of the 'Risk Assessment Master' layouts

  • A value for the field is not required.
  • The field has a maximum character limit of 500.
  • The new field maps to the 'Job Description' field in Job Inventory.
  • If the user does not populate this new 'Job Description' field, when the Risk Assessment record is saved, the value of the 'Job Name' field will populate both the 'Job Name' and 'Job Description' fields on the Job Inventory record.
  • Note: The combination of the GDDLOFB values and the 'Job Name' field value on the Risk Assessment record must be unique (that is, the Risk Assessment must not already exist in the DT_RASJobList).
  • After saving the Risk Assessment record, the 'Job Name', 'Job Description', and GDDLOFB field values on the record will become read-only.
  • Note: On the Risk Assessment, if you select an existing 'Job Name' from the picklist instead of creating one, the fields from the existing Job Inventory record will overwrite any fields that have already been populated. An active Risk Assessment should not exist for the job when creating a new Risk Assessment for it.
  • The new field is available in Query Builder and Report Writer, and for use in business rules and display rules.
