GSE-3218: In Environment > Inputs > Consumption, there is a new tabular data-entry page.

You can use this for faster data entry. It also allows you to add supportive notes and attachments. In 26.1, this page replaces the input form and data editing pages for Electricity (Grid), Fuel, Water, and Heat (Grid). Tabular data entry will be made available for the remaining activity types in a subsequent release.

The new page can be used to view and edit data previously uploaded through any method, including input forms, Microsoft Excel uploads, SFTP, and the API.  On the Environment > Inputs > Consumption page, to view a previous upload, click the file name. When the upload opens on the interface, at the top of the page you will see the file status and data classification. Below that, you will see the business activity data. Scroll to the right to see additional data columns and use the drop-down options at the bottom right to expand the number of visible/accessible rows. At the bottom of the screen, any supporting information provided (notes and/or attachments) is available. For an attachment, you can click on the file name to download it. To navigate back to the original screen, simply click the Back button.

For a particular consumption type, new data can be entered by clicking its Input Form link. That will open the ‘Manage Consumption Data’ screen. On that screen, to add a new row of data, click the + button and populate the data in the relevant columns. For columns that require data (mandatory columns), that is indicated by an asterisk in the column header. Data for mandatory columns must be added before clicking Save Changes. Additional rows can be added by repeating that process.

Some columns are dependent on one another (for example, the Cost and Currency columns). If data in one is populated for a row, data must also be populated in the other. If that is not done for two dependent columns, you will be reminded when you click Save Changes. When you are finished making your updates, click the Save Changes button. That updates the status of the file to Draft. If you have made a set of changes prior to clicking Save Changes, you can instead click the Discard button to discard those particular changes. That will revert to the last saved version.

You can make additional edits to saved rows by clicking into them and updating your selection(s).

As mentioned above, additional rows can also be added. A row added but not yet saved can be discarded by clicking the X button to its left. A saved row can be discarded by clicking the check box next to the row and then the Delete button at the upper right. Deleting a row by that method cannot be undone, and deletion of the last remaining row will delete the entire file.

Below the data rows, notes and attachments can be added and removed in a similar fashion. Select either Notes or Attachments from the drop-down options at the left, click the + button to add a row, fill in the relevant fields, for an attachment use the + Add Attachment button to add one, then click Save Changes.

The 26.1 release introduces the Draft status for upload files. The Draft status exists before any variance review, approval, or calculation status and is applicable to the activity types using tabular data entry: Electricity (Grid), Fuel, Water, and Heat (Grid). Additional activity types will begin using the Draft status in a subsequent release. Files are set to the Draft status upon clicking the Save Changes button. This means, files get the Draft status when entering and saving new data using input form or API, or through saving edits to existing files. A list of files in the Draft status can be seen in the Status Hub.

Once you have made all the changes you need, files can be progressed beyond the Draft status by clicking the Save and Submit button, which saves any unsaved changes and sends the file to the next stage of the approvals workflow.

If variance thresholds are turned on and your upload exceeds the expected variance, you will be prompted with a pop-up. Click the Add Now button to add an explanation for the variance now and proceed with the upload. Click the Add Later button to provide the explanation at some time after the upload and proceed.
