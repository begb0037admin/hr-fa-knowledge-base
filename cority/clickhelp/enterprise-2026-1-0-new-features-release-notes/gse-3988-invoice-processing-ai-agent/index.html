GSE-3988: Invoice Processing AI Agent

This new integrated AI agent enhances the efficiency of extracting invoice data.

Note: The agent is available at an additional fee. For information on acquiring it, please contact your Cority account manager.

To use this agent, the user must be granted the ‘Environment Invoices AI’ role.

The agent is located in Environment > Inputs > AI Invoice Processing. It is now the inbox for all incoming invoices. Users no longer have to upload invoices into the system. They can simply designate an email address for the inbox and email all invoices to it. Once the invoices reach the Inbox, they are added to ZERO Q, and the AI agent begins processing. The AI agent reads each invoice, extracts the necessary information, and automatically directs the information into the appropriate workflow.

If the agent deems that the invoice needs additional human attention (further validation), the invoice will be moved to the Manual folder. The AI agent is designed to be cautious, to avoid any errors or forced data entries. It will seek human verification whenever uncertainty arises. That helps ensure the utmost accuracy and reliability of the data entering the solution.

There are additional folders in the inbox, such as those for invoices with incorrect types, missing site references, or duplicates, which allows administrators to quickly manage any such cases.

All of the data is pre-filled in the exact format required by the solution. The AI maps the information to the same categories and structures used across the system, eliminating any need for manual adjustments. Any missing or inconsistent details are clearly marked. That allows administrators to make only the necessary corrections, without having to re-queue the entire invoice. The rest of the fields can be reviewed and edited as well, for those users who want to do that.

Once an administrator approves the invoice, he or she can click READY FOR EXPORT.

The agent has the ability to learn from each correction made. As the system learns, the need for manual validation decreases, which will reduce the workload significantly over time.

All fully-validated invoices are located in the READY FOR EXPORT folder. They are moved there either automatically by the agent or after a brief human check, when necessary. From there, a user can click PUBLISH and the system will then distribute the data automatically to the relevant node or data source. The user can choose to publish everything at once or select specific sites, giving users control over when the data is published and to where, which enables if necessary a final review before the data goes live.

For global sustainability teams, the AI invoice processing agent can translate languages on, for example, multilingual invoices. Once an invoice is uploaded, the agent automatically detects its language and translates it instantly. It also standardizes the terminology to align with that of your organization’s fields, removing language barriers and reducing human error.

Overall, the agent will cut down significantly on manual work, enhance accuracy, and continuously adapt to your needs, all while keeping your teams in complete control over the data that enters the system.
