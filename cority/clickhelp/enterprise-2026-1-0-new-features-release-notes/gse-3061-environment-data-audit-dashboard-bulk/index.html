GSE-1883: In Environment > Inputs > Consumption, updates have been made to the Value Chain data source.

That data source is used to upload raw emissions to the system—no consumption, no business activity data, no emissions calculation; you just provide the emissions. Previously, all of that data was market-based emissions; you could only upload market-based emissions and the data on reports or dashboards would only be for market-based emissions. We have adjusted this so that you can now give us both location-based (LB) and market-based (MB) emissions.

We have updated the Input form and the corresponding Microsoft Excel upload sheet in the same way. Previously, they had only market-based fields on them; now they have the applicable fields for both MB and LB emissions. Note: A value for at least one of the six parameters (three for each) with its associated units must be provided on the Input form to save.

This new functionality will have no impact on your existing historical data, however if you have added market-based emissions in the past, you can now add location-based emissions for that node as well.

All relevant reports and dashboards have been updated to support these changes.

There is a helpful training video for this on the Cority Academy.
