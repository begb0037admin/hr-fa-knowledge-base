GSE-3482: In Emission Factors, on the FERA tab there is a new check box for gap filling.

In Environment > Settings > Customisation > Emission Factors, the FERA tab has a new gap-filling check box.

When this option is selected, the system retains all available FERA emission factors from the original methodology. Any identified data gaps are then systematically filled using the mapped methodology. If unselected, all FERA factors will get overwritten with the mapped methodology.

All applicable reports and dashboard have been updated to ensure such calculations will be reflected in those exports.

Also, the Data Audit dashboard in Environment > Dashboards > Data Audit has a new column named ‘Mapped FERA Factors’ that specifies which methodology and emission factors from the mapped methodology were used.

There is a helpful training video for this on the Cority Academy.
