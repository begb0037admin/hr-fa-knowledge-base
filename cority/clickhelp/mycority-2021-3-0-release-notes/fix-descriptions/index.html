Fix Descriptions

The table below describes the fixes we have made for 2021.3.0.

Item #Component(s)Reported VersionDescription
CCC-136Business Intelligence2019.1.0

If the user saves campaign metrics in myCority, when applicable, an associated approval workflow will now launch as expected and be displayed where expected.

 

CCC-4815Inspections, Findings & ActionsN/A

When a Findings & Actions record is auto-created from an assigned inspection in myCority, a duplicate Findings & Actions record is no longer created.

 

CCC-5185Occupational Health - Medical MonitoringN/A

The 'New Vaccination' layout no longer shows inactive immunization codes.

 

CCC-5247Platform2021.2.2

When the 'Duplicate child records when posting an Event to Incident' setting is not selected and an Event Report is posted to an Incident record, documents uploaded to the Event Report using myCority will no longer be copied over to the Incident record.

 

CCC-4994PlatformN/A

Where applicable, the Comments field is now a text area box in both GX2 and myCority.

 

CCC-4668 and 4667Platform2021.1.2

When the specified date format in User Settings is 'mmm dd, yyyy', that will now be respected where applicable.

 

CCC-4486PlatformN/A

A user assigned a campaign that contains a particular metric can no longer see other campaigns containing that metric to which he or she is not assigned.
