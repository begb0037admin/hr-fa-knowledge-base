Summary of Enhancements

The table below describes the enhancements we have made in 2021.3.0.

Item #Component(s)Description
CCC-4251Event Reporting

When necessary, for Event Report instruction text will now wrap.

 

CCC-3063Platform – Administrator, Safety – Incident

All tooltips will now function as expected.

 

CCC-2593Platform – Administrator, Questionnaires

You can now configure a questionnaire so that it requires the employee’s consent. For an in-depth description, including configuration details, see CCC-2593 in the Cority 2021.3.0 New Features Release Notes.

 

CCC-1121 and 4926Platform – Administrator

The ‘Authentication Mode’ system setting for myCority has a new 'Mixed Mode (SSO SAML 2.0 and UserID/Password)' option. Also, the myCority user layout now has a new ‘Allow Mixed Mode Authentication’ check box. By default, the setting is not selected. When the check box is not selected, the user must log in using SSO even if the system setting for myCority login is ‘Mixed Mode (SSO SAML 2.0 and UserID/Password)’. If the check box is selected, the user will have the option to log in using SSO or userpass.

 

CCC-4078Platform – End User

The myCority icons have been updated.

 

CCC-3958Platform – End User

myCority no longer supports Microsoft Internet Explorer 11.

 

CCC-5452Occupational Health – Medical Monitoring

With the 'New Vaccination' layout (ML-003606) open, when scanning the Vaccine Lot Number, the value that populates will now be matched to the lot associated with the selected Health Center.

Also, when manually typing the Vaccine Lot Number value, the first smart search option presented will now be the lot number that matches the selected Health Center.

If the user specifies a Vaccine Lot Number value that is not associated with the selected Health Center, a pop-up will now open asking if the user wants to update the Health Center value on the record.

 

CCC-4617Occupational Health

Regardless of the value selected for the 'Portal/myCority Authentication Method' system setting, the appropriate medical records will now display for the user.

 

CCC-4205Occupational Health – Employee CareThe Appointments module in myCority has been enhanced.
CCC-1568Occupational Health – Case Management

There is a new management referral workflow. For an in-depth description, including configuration details, see CCC-1568 in the Cority 2021.3.0 New Features Release Notes.

 

CCC-4273Safety - Incidents, Audits, Contractors / Projects

myCority now supports stakeholder management for incidents, audits, and contractors/projects.
