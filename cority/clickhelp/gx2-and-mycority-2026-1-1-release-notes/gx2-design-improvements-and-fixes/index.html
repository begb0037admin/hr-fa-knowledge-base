GX2 Design Improvements and Fixes

The table below lists the design improvements and fixes we have made in the GX2 2026.1.1 release. The items are organized by component, and the components are arranged in alphabetical order (generally).

Item #Component(s)Description
CCC-26011Clinical Monitoring - Audiometric

When applicable, the Hearing Status field on the Alberta Audiometric layout now displays all statuses in an additive, concatenated format.

 

CCC-26423Clinical Monitoring - Audiometric

The Alberta audiometric standards have been updated to meet the latest requirements.

 

CCC-22636Clinical Monitoring - Case Management

For custom versions of the Case Master layout, the Occupational check box field now functions as expected.

 

CCC-23282Clinical Monitoring - Case Management

On a Case record for a particular employee, the ‘All Case Questionnaires’ view now lists all questionnaires for all cases for that employee.

 

CCC-25368Clinical Monitoring - Case Management

In Case Management, a user with the proper security configuration can now successfully save a BFE record without encountering any unexpected errors.

 

CCC-26120Clinical Monitoring - Case Management

The OH Case workflow functionality, when updating and saving, now functions properly, even when there are associated business rules configured to trigger.

 

CCC-26352Clinical Monitoring - Case Management

For Case and Clinic Visit letters, when exported to Microsoft Excel, the created date and time on the export now matches the user interface.

 

CCC-25089Clinical Monitoring - Case Management

An issue preventing a case closure notification business rule that uses a subquery and filtered distribution list from functioning properly has been resolved.

 

CCC-25992Clinical Monitoring - Reporting

An issue that was causing performance degradation while exporting and printing certain custom and Cority-created reports (the Medical Records Report, for example) has been resolved.

 

CCC-26194Clinical Monitoring - Reporting

The Medical Records report will now generate (print) successfully and without causing any unexpected errors.

 

CCC-26381Clinical Monitoring - Vision Testing

An issue that was preventing the import of valid vision test results using the Vision Import Utility has been resolved.

 

CCC-26464Clinical Operations - Appointments

The Outlook integration microservice URL had two question marks. That was causing issues with appointment creation and syncing. This has now been fixed.

 

CCC-27303Clinical Operations - Appointments

When applicable, for a Clinic Visit appointment in GX2, if the user reduces Exam Activity service units or removes an Exam Activity, that will now be reflected in Meddbase.

 

CCC-27757Clinical Operations - Appointments

Custom ‘Schedule Entry’ layouts with ‘Granted Roles’ now function properly without generating unexpected errors.

 

CCC-25416Clinical Monitoring - Immunization

On an Immunization record, when the Dose Date gets updated, the Recall Dose Date will now update automatically.

 

CCC-25433 and CCC-25421
Clinical Operations - Clinic Visit

The following new UDFs can now be added to custom versions of Clinic Visit layouts:

  • UDF_Text_7  - UDF_Text_12
  • UDF_Flag_7 - UDF_Flag_12
  • UDF_DT_7 - UDF_DT_12
  • LU_CV_UDF7 - LU_CV_UDF12

The look-up table fields have new corresponding look-up tables: ClinicVisitUDF7 - ClinicVisitUDF12.


CCC-27476
Clinical Operations - Clinic Visit

You can now add the new 'Recent Clinic Visit' picklist field to a custom version of the Questionnaire layout. When you complete a questionnaire on the Questionnaires sublist of an existing Clinic Visit (or for an existing Clinic Visit from within the Questionnaires module), which creates a Vital Sign for the employee, you can then use the new 'Recent Clinic Visit' field to link the Vital Sign to the most recent Clinic Visit for that employee.

The new 'Recent Clinic Field' is available for use in Create Record action business rules, display rules, and for reporting in both Query Builder and Report Writer.


CCC-27667
Clinical Operations - ePrescribing

With the proper security configuration, you can now successfully register users for EPCS Gold without encountering any issues.


CCC-27336Clinical Operations – Medical Scribe Agent

For users of the Medical Scribe AI agent, on newly created Clinic Visit records, when applicable, the agent now opens and functions as expected, and notes can be saved to the records without any issues.

 

CCC-20014Clinical Operations - Notes

If the user attempts to sign a smart note that has unsaved changes, a message will now notify the user that the note must first be saved to retain the changes.

 

CCC-26426Clinical Operations - Notes

An issue that was preventing the saving of a smart note (with or without using a questionnaire) has been resolved.

 

CCC-27191Clinical Operations - Notes

On the Notes sublist of a Clinic Visit record, if the user creates a new note and saves it, the current note with saved changes will now remain on the screen.

 

CCC-24938
Clinical Operations - Patient Diagnosis

Six new check box UDFs are now available for adding to custom versions of Medical Codes look-up table layouts.


CCC-20054Communication & Migration - Platform

A correct set of Migrate Config GET and PUT (export and import) requests for business rules will not function properly.

 

CCC-26449Communication & Migration - Platform

CCC-25563Environmental

CCC-25684Environmental - Emissions

CCC-25843Environmental

CCC-25891Environmental - Change Request

CCC-24608
Environmental - Chemical Management

  • In order to see and use the 'Add to Library' action, the user's role must be granted the mastersdschemicalproduct.addtolibrary security action.
  • In order to see and use the 'Request Product' action, the user's role must be granted the mastersdschemicalproduct.requestproduct security action.


CCC-26310Environmental - Chemical Management

CCC-25264Ergonomics - Reporting

When the Historical Personal Risk Report is run with ‘Daily’ selected as the Output Configuration ‘Date Range’*_,_* the range is now capped at 30 days unless the report is also filtered to a single user with either the ‘Employee Full Name’ or ‘Employee Number’ filters.

When the Historical Personal Risk Report is run with ‘Weekly’ selected as the Output Configuration ‘Date Range’, the range is now capped at 26 weeks.

When the Historical Personal Risk Report is run with ‘Monthly’ selected as the Output Configuration ‘Date Range’, the range is now capped at 6 months.
