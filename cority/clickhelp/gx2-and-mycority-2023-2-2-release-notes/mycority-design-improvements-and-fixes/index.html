myCority Design Improvements and Fixes

The table below lists the design improvements and fixes we have made in the myCority 2023.2.2 release. The items are organized by component and the components are arranged in alphabetical order.

Item #Component(s)ReportedDescription
CCC-14202ErgonomicsN/A

A user whose role has been changed can now successfully log into myCority and navigate to Case Manager without encountering an unexpected error.

 

CCC-14059ErgonomicsN/A

The OES 'Action Report' will now show only identified issues (separated by risk type) from My Tasks > Ergonomics, filtered for the specific employee. If a Risk Inventory is made inactive or a Risk Profile from the Risk Profile look-up table is made inactive, any related issues will be omitted from the report.

 

CCC-14046ErgonomicsN/A

In Personal Risk > My Team, if the user has access to his or her employees (My Team is available), the Action Items column is now provided whether or not the 'Enable Baseline Risk' system setting is enabled or 'Baseline Risk' is added to the layout.

 

CCC-13983Platform – End-UserN/A

On a mobile phone or other mobile device, a myCority user can now download from 'My Records' by email and then open the emailed ZIP file and PDF(s) without having to manually rename any file.

 

CCC-13958Platform – End-User 2023.2.0

If any one or more of the system settings for the myCority footer are configured, the myCority footer will now display.

 

CCC-14214Safety – Incident N/A

On an Incident Investigation, if a user clicks a Related Asset record, the correct record will now open.

 

CCC-9359QualityN/A

A license key that includes the Quality cloud will now be able to access all of the expected look-up tables.
