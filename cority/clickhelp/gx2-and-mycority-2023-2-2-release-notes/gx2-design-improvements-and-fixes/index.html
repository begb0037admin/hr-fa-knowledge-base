CCC-13279Document Control, Quality – Management of ChangeN/A

There is a new granted action DocumentControl.Coordinator that enables a Cority user who is not in the document approval workflow to have full-permission access to all Document Control records. The action can be added to any role on the Granted Actions list.

The new action allows the user to:

  • Access all the document control records
  • Add, remove, or reassign any users in the document approval workflow
  • View and edit rights to all document control records

The coordinator is unable to approve, reject, or publish documents on behalf of another user.

Any action taken by the coordinator will be captured in the record history.

CCC-12451Ergonomics – RSIGuard NotificationsN/A

You can now configure RSIGuard notifications, so employees are reminded to work safely.

To support this, the default layout of the ‘In-App Notification’ business rule action type has the new ‘RSIGuard Notification’ checkbox.

When selected, the user is provided with options for configuring the notification, which include:

  • Number of notifications per day
  • Number of days to deliver notification(s)
  • The notification title
  • The notification body
  • Where the user will be directed if he or she clicks the notification link (No action, Simple display of notification, Personal Risk Dashboard, etc.)
  • A follow-up email

 Example workflows:

  • The user's risk for a particular risk type has been high for >n days. The user is sent a notification. Clicking the notification takes the user to myCority 'My Tasks', filtered to his or her ergonomics issues.
  • The user has a risk type flagged as discomfort that has changed to high. The user is sent a notification. Clicking the notification directs the user to his or her ‘update discomfort’ screen in myCority.
  • The user has a self-assessment that is past due. The user receives a notification. Clicking the notification opens the corresponding training session.
