CCC-11805: GX2 has an updated chemical label designer

This will allow for more flexibility and customization when creating label templates.

The updated designer can be accessed the same way as it was previously, from the Environmental > Label Management ‘Label Templates’ list view.

Now when you open to edit an existing template or create a new one, you can use the toolbar from the designer in the Preview panel to add Chemical Product fields, demarcate an area for symbols and/or an area for phrases, add HMIS and NFPA symbols, and add custom text boxes.

You can also rearrange and re-size those items, change and format the font and colors within the text boxes, and remove anything you add.

Limitations:

  • When resizing an item, it will seem like the font size within it is also resizing, however once you click Save, the font will return to the size indicated in the Font Size drop-down field.
  • It is best practice to click Save when you make a change so you are sure to be viewing the latest set of updates.
  • Although there are a few fonts in the ‘Font Selection’ drop-down field, the only font available at present is Arial. We intend to add fonts in a future release.
  • Overlapping of items on the label template designer is not supported. The order in which the items will overlap is not predictable.
  • You cannot add more than one text box with the same title.
  • For creating label templates, the out-of-box layout is required. Cloned layouts are currently not supported.

Zoom in and out on the preview by hovering over the label template, holding down the Ctrl key, and using your cursor scroll button. To reset the zoom to the original size, click the Reset button.

Once you have created a label template and saved it, the template will appear on the ‘Label Templates’ list view.

Now a floor employee, for example, can use the template to create Chemical Product labels.

The employee can simply navigate to the Environmental ‘Chemical Products’ list view, select the check box for the chemical product (Propanol, for example), then select the ‘Print Labels from Template’ action. If the employee wants to edit an existing Product Label, he or she should select the ‘Saved Labels’ view from the View drop-down list. If the employee is looking to create a new product label, he or she should select the ‘Label Template’ view from the list. The ‘Select Label Templates’ list view will open, and from there the employee can choose a template or an existing chemical product label to open. If creating a new label from template, when it opens, the label preview will automatically populate with the appropriate Chemical Product field values (read-only), symbols, phrases, etc. associated with the selected Chemical Product.

Note: All of those items (for example, symbols and phrases) will have to be on (associated with) the selected Chemical Product record beforehand.

For each text box you added, a corresponding field with added title will appear on the left panel. You can add or change text for each (up to a maximum of 500 characters) of the text boxes using those fields.

At this stage of the process, you can re-arrange and resize items on the preview, but the template designer tools are not available for adding items. To add items to the template, you would have return to and open it from the Environmental > Label Management ‘Label Templates’ list view.

Also at this stage, if some of the content is not what you want (for example, you want only symbols and phrases for Europe, yet you are seeing them for both Europe and North America), you can simply remove the unwanted items from the ‘Symbols’ and/or ‘Phrases’ tab.

Note: Within each symbols and phrases area on the label, the order of the contents cannot be adjusted. It is strongly recommended that you add less than ten symbols and ten phrases, to avoid overcrowding the label and potential performance issues.

When you are content with the label’s appearance, click Save and then click Print. The label, or multiple versions of the label on a single sheet (depending on the Label Stock specified on the label template), will open in PDF format on a new tab.

Note: When selecting a label template to associate with a chemical product, if you are looking to edit an existing product label, it is recommended that you change the view on the ‘Select Label Template’ list view.
