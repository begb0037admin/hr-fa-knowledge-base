Modifying the Task

If you want to change the properties if the Email Notification Utility task, follow the steps in the previous section to open the Windows Task Scheduler.

  1. Open the Windows Task Scheduler and select Task Scheduler Library.
  2. Right-click the Email Notification Utility task and select Properties.
  3. In the Triggers tab, select the trigger you want to modify and click Edit.
  4. Make the necessary changes to the Edit Trigger form and click OK.

  1. Click OK to close the task properties screen.
