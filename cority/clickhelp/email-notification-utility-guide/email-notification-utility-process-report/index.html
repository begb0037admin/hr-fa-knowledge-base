Email Notification Utility Process Report

Upon completion or termination of Email Notification Utility, Email Notification Utility will generate a report outlining any errors encountered during the process. You can enable/disable the report or change the recipient or FROM field in the Email Notification Utility Settings screen.

Sample Process Report

Process Report - Statistics

The following table outlines each line of the information inside the Statistics section.

Statistic

Description

Run Start Time

The time at which Email Notification Utility began processing emails.

Run End Time

The time at which Email Notification Utility finished/terminated processing emails.

Entire task completed

Indicates if the entire email task has been completed (terminated otherwise).

Duration

The amount of time it has taken Email Notification Utility to complete (or complete until termination) the email process, in DD:HH:SS format.

Number of Sent Emails

Number of emails dispatched.

Number of undispatched emails due to connection problems

Number of emails that could not be dispatched after Email Notification Utility has sent a request to the SMTP server. If EMAIL NOTIFICATION UTILITY is recording a high number in this field, please adjust your SMTP server setting to allow a more generous restriction to Cority.

Process Report - Errors

The Errors section displays any errors the Email Notification Utility encountered while dispatching emails. The following table explains each possible error that may appear in this section.

Error

Description

Missing Employee Emails

The Email Notification Utility tried to send an email to an employee without a valid email address. This can occur because email is not a required field of employee records. To correct the error, enter a valid email for the employee.

Employees with Invalid Email address

When the Email Notification Utility tries to send an email but realizes the employee’s email address is not in the correct format, the Email Notification Utility will create an entry in this section, with an indication of the employee with invalid email address.

Generic Problems

When the Email Notification Utility tries to send an email and encounters a fatal error due to an internal problem an entry will be created here. Please contact Cority’s help desk if you see an entry here. The error message will indicate what types of email have been skipped.
