Before Running Email Notification Utility

Proceed to the Email Notification Utility Setting screen (Administrator > Settings > Email Notification Utility Settings) in Cority and configure all required fields. For more information on Email Notification Utility settings, see the User Guide. Since Email Notification Utility relies on a SMTP server to dispatch email messages, you must have an SMTP server ready. Ensure Cority has access to your SMTP server for dispatching emails. The prepared SMTP server must be fast and responsive and should have no restrictions of maximum requests or the interval between each email request.

Although the Email Notification Utility will attempt to resend emails if the SMTP server is unresponsive, emails that have been retried too many times will be discarded and logged as ‘Number of undispatched emails due to connection problems’ entry in the Email Log. (See the following section for more information.)

During the email process, please be advised that Email Notification Utility will pull data from the database, and will send commands to the SMTP server constantly until all emails have been dispatched or the termination time has been reached. While Email Notification Utility is running you may experience degraded performance of the Cority application, web server, and database; therefore, it is important to run Email Notification Utility during off hours when the server load is minimal.
