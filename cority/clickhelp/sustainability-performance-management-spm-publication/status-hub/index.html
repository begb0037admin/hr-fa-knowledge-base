Status Hub

The Status Hub provides information about Queued Files, Pending Files, Calculation Errors, FTP Log, Threshold Alerts and Notices. The tile to access the Status Hub is found at the bottom of the shortcut tiles in the Environment module and the number of items of interest is displayed in brackets after the name. To view the details within each one selects the appropriate tab.

 

Please use the Status Hub area to check on the data that you have uploaded. Various statuses can be checked using the corresponding status hub tab. The ‘Queued Files’ tab can be used to check for files that are awaiting processing or that have failed to upload. Similarly, the “Approval Status” tab can be used to identify files that are awaiting approval or that have been rejected. The ‘Calculation Process’ identifies files for which emissions values are currently being calculated, or those which have failed the calculation process. Finally, the ‘Locked Files’ tab can be used to unlock files in bulk. Files become locked when a user begins editing them. They remain locked until the changes are saved or cancelled. This section allows where the user has forgotten to save or cancel their edits to be unlocked.
