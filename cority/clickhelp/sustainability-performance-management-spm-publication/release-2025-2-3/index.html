Release 2025.2.3

In release 2025.2.3, we have made the following updates:

GSE-2473 – In Frameworks > Approvals, the loading performance for questionnaires has improved.

GSE-3082, 3080, 3079, and 2660 – In Environment > File Management, the overall performance has improved.

GSE-3187 – In Environment > File Management, when reprocessing a file, if the user selects the file-level check box then deselects any single associated child record, the check box in front of that parent file to be reprocessed will now become deselected.

GSE-3454 – In Environment > Input > Consumption, for when the user expands a node and clicks a file name, the loading performance has improved.

GSE-3581 – An issue that was causing the 2025 radiative forcing factor to remain 1.9 has been fixed.

GSE-3481 – For any UI-completed input data in Environment > Inputs > Consumption or any file in Environment > Approvals, if the user changes the category in the Estimated data field and saves, the new value will now be retained.

GSE-2711 – In Environment > Inputs > Consumption, input list exclusions are no longer shared across consumption types. For example, road business exclusions will now only apply to road business.

GSE-2778 – In Inputs, a template with an empty first sheet will now upload properly.

GSE-2954 – In Admin Settings > Environment > Customisation > Emission Factors, on the Market-Based tab, if the user clicks Edit Link for any record, then attempts to update an Emission Factor record, the record will now update successfully and without generating any unexpected errors.

GSE-3213 – In Environment > Input > Consumption, for any entries with a status of Awaiting Approval, if the user opens the entry, updates any value, then saves, the Awaiting Approval status will be retained, and the entry will appear on the Data Approval page (and in the Status Hub).

GSE-3277 – When an Input user accesses a questionnaire, answers one or more questions, then clicks ‘Save & Submit for Approval’, the button will become inactive and display ‘Submitted’.

GSE-3571 – In Frameworks > Settings > Configure Questionnaire, if a user creates a questionnaire with one or more questions that require supporting documents, then in Frameworks > Inputs > Framework Questionnaires, if a user accesses the questionnaire, answers one of those questions, clicks the Attach Document icon, and uploads a Microsoft Excel file, that file will then be downloadable and open successfully without error when downloaded.
