Environment – Variance Groups

The variance groups page allows users to set the checks that are conducted within the variance tracker. The variance tracker can be used to highlight and justify or resolve where consumption has changed to a greater degree than might be expected by chance. To set up a variance group select Add Variance Group button. Provide the group a name and select the type of consumption data you would like to include in your variance group, for example, Electricity (Grid) has been selected in the screenshot below.

If you only wish to conduct checks on a specific sub-type, select it in the sub type dropdown. Alternatively, leave this selection blank to include all sub types. Specify the units in the associated dropdown. Certain consumption types, such as fuel, allow data to be uploaded across a number of unit types, for example, fuel consumption can be uploaded as a weight, volume or energy value. Using the convert fuel button allows the user to convert these values into a consistent metric allowing for greater comparability.

Comparisons can be run between months, quarters, half years or years using the time period dropdown and the starting month can be specified. Finally the threshold value beyond which variance will be highlighted by the variance tracker can be specified in the Range (%) field.
