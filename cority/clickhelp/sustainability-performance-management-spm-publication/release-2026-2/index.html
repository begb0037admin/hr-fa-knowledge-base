Release 2026.2

In release 2026.2, we have made the following fixes and design improvements:

GSE-4726: For road business where distance is uploaded, if the electricity columns for the emission factor are empty, the system will now show null for  emissions, instead of zero.

GSE-4425: If water is uploaded in cubic meters and cubic meters is added properly in 'My Units', the Bespoke Fields Report will now show cubic meters for water.

GSE-4386: When running the Data Audit Bespoke Fields Report, any apportionment factors will now be applied properly and apportioned consumption data will now appear correctly.  

GSE-4326: Where applicable, the consumption on the Waste Report will now match that of the Data Audit Report and Data Audit Dashboard.

GSE-4534: When environment emissions are linked with Frameworks questions, Value Chain emission categories will now filter correctly.

GSE-4255: When clicking a filename in the Inputs section to edit/view a file of uploaded data, if the data source is custom, the consumption information will now appear as expected.

GSE-4784: To address an issue that was causing the Bespoke Fields Report to fail, the maximum report size has been increased.

GSE-4383: In the Fields_DependencyWaste table, therefore in the applicable Input form drop-down menus, 'Recycling (Closed Loop)' has been added to the 'Toner Cartridge' material type. 

GSE-4687: The following updates have been made to the Field Dependency table: 

  • Additional options have been added for the GHG AR6 methodology.
  • Field dependencies that should be linked to EPA (not DEFRA) are now linked to EPA instead of DEFRA.
  • Duplicates field dependencies have been removed.

GSE-4622: Email notifications will no longer be sent to any expired or locked users.

GSE-4345: When applicable, for Heat (Grid) inputs, the Variance Review popup will now display the correct comparison.

GSE-4673: On the Data Approvals page, when applicable for a custom data source, the consumption data for the current and previous period will now be summarized as expected. 

GSE-4674: For Heat (Grid) data sources, market-based emissions can now be calculated for heat types.
