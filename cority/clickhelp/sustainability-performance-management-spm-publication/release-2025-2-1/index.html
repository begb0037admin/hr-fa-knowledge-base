Release 2025.2.1

In release 2025.2.1, we have made the following updates:

GSE-3141 – In Admin > Organisation > Nodes and Data Sources, when adding a data source, for the Country drop-down field the ‘China (PR of China and Hong Kong China)’ option is now provided.

GSE-2662 and 3036 – For the Home Page, there are a number of performance improvements. For examples, the number of outstanding issues in your Status Hub now loads faster, and for each Frameworks questionnaire the progress bar now loads faster.

GSE-3131 and 3037 – Performance improvements have been made to the Frameworks Inputs, Frameworks Approvals, and Frameworks configuring questionnaires pages.

GSE-3058, 3057, and 2663 – Pagination has been introduced in the Status Hub, which improves loading overall. Also, each tab now loads independently, which further improves the loading performance of the Status Hub.

Note: The loading speed of a page will still always depend on the amount of data on it.

This is the first batch of performance enhancements. We plan to make more in upcoming releases. For the pages listed above, while this release includes significant improvements, further optimization work might be deployed in future updates.
