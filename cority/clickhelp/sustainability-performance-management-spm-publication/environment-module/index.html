Environment Module

Depending on the areas of the Environment module that you have access to, you will be able to select up to 5 shortcuts that will appear on your customized homepage.

If you click on any of the shortcuts that have been created, then you will be taken to this screen within the Environment module of SPM.

To populate the Environment module graph please select the view that you would prefer, then either set the dates or select ‘Display the last 12 months of data’ option. If you set from and to dates, these will not change until you come back to this screen to change them. If you select ‘Display the last 12 months of data’ option, the homepage will show data for the current calendar month and the preceding 11 months.

The selected year will be shown in blue bars and an orange line will show the data for the corresponding 12 months in the previous year. If you hover over the bar or yellow circle a pop up will display the actual emissions for that time period.

The grey arrow indicates the % change in emissions for the selected time period compared to the previous 12 months and is orientated up or down depending on whether the emissions have increased or decreased.

The Homepage graph includes all nodes, data source and emissions scopes within the selected View and excludes modelled data.
