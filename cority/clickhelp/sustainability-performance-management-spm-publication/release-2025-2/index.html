Release 2025.2

In release 2025.2, we have made the following fixes and improvements:

GSE-2771 – When used in bespoke fields, special characters (such as &) now display correctly when the Data Audit Dashboard or Bespoke Fields Report are exported.

GSE-2720 – For travel data, users can now successfully enter the origin and destination so that the system will calculate distance. The Google Maps API is used for the calculation.

GSE-2688 – Unless a change to the radiative forcing has been requested specifically prior to this release, a script will be run immediately following the deployment of version 2025.2 to update the radiative forcing values on the site. Radiative forcing will be set to 1.9 for the period up to 31/12/2022, and to 1.7 from 01/01/2023 onward. This applies to the following consumption types:

  • Air Freight
  • Air Commuter
  • Air Business

GSE-2687 and 1083 – Date-dependent radiative forcing values are now supported. If required, the client must contact the Cority Support Team to have this set up.

GSE-2578 – When applicable, for Frameworks questions, attachments can now be added or removed by:

  • The approver during his or her own approval stage.
  • The Supervisor during a Supervisor update.

GSE-2519 – In the Custom Question Library, when editing or copying a question, linked and non-linked questions are now displayed (listed) using pagination. By default, five are displayed per page. That can be adjusted. Note: The questions are ordered with linked questions first.
Also, to improve performance here, unnecessary permission checks have been removed.

GSE-2054 – For the Admin > Environment > File Management page, performance has been improved so that it loads faster, and refreshes faster when performing actions on it.

GSE-2033 – For the Admin > Environment > Approvals page, performance has been improved so that it loads faster, performs bulk actions faster, and Expand Grid executes faster.

    GSE-2031 – For the Admin > Environment > Inputs page, performance has been improved so that it loads faster, and refreshes faster when performing actions on it.

    GSE-1945 – For the Admin > Frameworks > Configure Questionnaires > Assign Groups page, performance has been improved so that it loads faster, and refreshes faster when performing actions on it.

    GSE-1937 – For the Admin > Frameworks > Custom Question Library > Add Custom Question page, performance has been improved so that it loads faster, and refreshes faster when performing actions on it. Also, the Emission and Consumption user controls now load only when selected by the user.
