Secure File Transfer Protocol (SFTP) Setup

The secure File Transfer Protocol (sFTP) allows for files to be uploaded to SPM without the need to log in. SFTP is a folder on the internet accessed via Secure File Transfer Protocol. In order to use this service you will require an additional software tool on your computer. Cority suggests you use FileZilla however you may already use a similar SFTP tool within your organisation and would prefer to use this.

This service allows users to transfer or drop files into an online folder and Cority will automatically upload these files to Cority.
