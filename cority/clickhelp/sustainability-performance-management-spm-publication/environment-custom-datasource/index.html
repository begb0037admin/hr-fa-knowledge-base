Environment - Custom Data Source

This is where custom consumption categories and emissions factors can be set up (or uploaded) for calculating emissions. Consumption types and subtypes can be created, and for each subtype emissions factors for specific time periods, countries, and units can be set.

To get started, select Add Custom Data Source Type and specify the consumption type. To add a subtype, select the arrow to the left of the consumption type and select Add Custom Data Source Subtype. Emissions factors can be added for each subtype by clicking the arrow next to the associated subtype and selecting Add Emission Factor.
Note: The country of the emissions factor must match that of a data source in order for the calculation to be successful.

In addition to market-based emissions factors, the user can add factors for location-based emissions and for FERA (fuel and energy related activities). FERA emissions can be calculated by uploading emissions factors to the columns SC, T&D, and SC T&D, which are Supply Chain, Transmission & Distribution, and Supply Chain Transmission & Distribution. Emission factors must be defined using base units (for examples: liters, kWh, tonnes, kilometers, and other). When entering data in the Inputs section, any unit that belongs to the same unit group as the selected emission factor can be used.

Once entered and saved, each emission calculation that is run will use the applicable emissions factors. Anything volume-based, for example, will use the applicable volume-based emissions factor(s).

When creating types and subtypes, names support numbers and special characters.

Note: Each type and subtype must have a unique name. Duplicate subtypes are not supported. For example; Milk 1 and Milk 2 could be used, if required.

Also, users can edit and/or delete a type or subtype after creating it, as long as no calculations have used it.

Exports show subtypes rather than types.

The input list exclusion feature can be used for the custom data source. For input forms, it can be used to exclude specific categories and/or subcategories, which will make them unavailable in applicable drop-down field(s). For example, if you do not want a category or subcategory that is no longer useful or relevant to be available (perhaps Milk) in the applicable drop-down field(s) when entering data, you can exclude it.

Users can bulk upload emissions factors. The user can download them using the Download button, make adjustments (to their numbers, by adding new categories, etc.) on the spreadsheet, and then re-upload them. When uploaded, all of the adjustments will be made within the system (in the Custom Data Source Management table).
