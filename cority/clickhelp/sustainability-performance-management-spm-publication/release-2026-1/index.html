Release 2026.1

In release 2026.1, we have made the following fixes and improvements:

GSE-3177: In Environment > Approvals, if the user makes changes to a file, those changes must now be saved before the contents can be subsequently approved or rejected.

GSE-4187: The Pakistani Rupee (PKR) is now available on applicable input form / upload template drop-down menus for uploading cost data.

GSE-3300: In Environment >Settings > Customisation > Bespoke fields, the Download icon now functions as expected and does not generate any unexpected server errors.  

GSE-3351: In Environment > Inputs, for multi-node upload, when a file is uploaded without the required data, the validation check will now stop the upload from processing and trigger an informative error message.

GSE-3987: IEA electricity emission factors (data source countries) have been added to the system.
