Release 2024.4

In release 2024.4, we have made the following fixes and improvements:

GSE-16    An issue with the allocation of haulage type for EPA air data, where the distance is exactly 300 miles, has been resolved.

GSE-1104     An issue downloading Frameworks attachments with commas in the file name has been resolved.

GSE-1306     For Frameworks approval rejection emails, the records awaiting approval have been removed.

GSE-1310     An issue with carriage returns in the upload of comments to Frameworks using SFTP has been resolved.

GSE-1372     Frameworks awaiting approval emails are now sent to the user group associated with the questionnaire assignments, rather than to all users with the approval user role.

GSE-1470     For Frameworks rejection emails, question titles are now included. Note: A maximum of 100 records is shown per email.

GSE-1383     For Frameworks reports, the Units parameter has been added as a new column.

GSE-1430     For large Frameworks questionnaires when using 'View by Question', the performance of the inputs and approvals section has been improved.
