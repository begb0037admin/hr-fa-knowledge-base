Release 2025.3

In release 2025.3, we have made the following fixes and improvements:

GSE-2689 – In Admin > Environment > Variance Groups, when the user is adding a variance group with a custom data source, the Unit field will now provide the applicable unit options, therefore the variance tracker group can be set up successfully and then selected in Environment > Variance > Variance Tracker. Also, the units for the variance tracker group will convert properly.

GSE-2696 – The Data Audit > Data Audit Report will now take less time to run.

GSE-2926 – The performance of the Environment > Dashboards > Data Audit dashboard has been improved.

GSE-3088 – In Environment > Dashboards > Data Audit, when the user clicks into a file (node) or data source, the performance of grid generation at the bottom of the screen is now improved.

GSE-3486 – In Frameworks > Inputs and Frameworks > Approvals, for a questionnaire, when the user selects ‘View by period’ and there are more than 20 questions (for example, 50), the performance is now improved. To support this, on the UI, the maximum number of questions per output screen has been decreased to 20.

GSE-3483 – In all applicable Frameworks areas, the performance for obtaining data for one or more questions is now improved.

GSE-3528 – In Environment > Targets, the Targets list now loads faster.

GSE-3574 – The Environment > Initiatives > Inputs screen now loads faster.

    GSE-3584 – In Frameworks > Inputs > Frameworks Questionnaire, the performance of node expansion is now improved.

    GSE-3589 – The Frameworks > Approvals > Date Approvals screen now loads faster.
