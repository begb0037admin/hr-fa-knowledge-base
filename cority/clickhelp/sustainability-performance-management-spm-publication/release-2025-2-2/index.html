Release 2025.2.2

In release 2025.2.2, we have made the following updates:

GSE-2652 – The performance of the left navigational menu has been improved.

GSE-2664 – When specifying the settings for an environmental report, the performance has been improved.

GSE-2952 and 3241 – In Environmental > Inputs > Consumption : Edit File Data, the page loading and page functionality performance have been improved.

GSE-2953 and 3276 – In Admin Settings > Users > User Groups, when editing a user group, the page loading and page functionality performance have been improved.

GSE-2968 – In Admin Settings > Organization > Views, performance improvements have been made.

GSE-3086 – The Admin > General > Organisation > Nodes and Data Sources, the page loading performance has been improved.

GSE-3414 and 3175 – Bespoke fields now support special characters.

GSE-3347 – In Admin Settings > Users > User Groups, after editing or updating a group’s report permissions for a report category and clicking Update, the changes will now be retained.

GSE-3339 - In Admin Settings > Users > User Groups, under Reports, after changing the report name using the drop-down field, the new report name will now display on the user interface.

Note: The loading speed of a page will still always depend on the amount of data on it.

This is the second batch of performance enhancements. We plan to make more in an upcoming release. For the pages listed above, while this release includes significant improvements, further optimization work might be deployed in future updates.
