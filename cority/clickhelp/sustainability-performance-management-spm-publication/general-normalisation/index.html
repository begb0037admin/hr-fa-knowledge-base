Normalisation

Normalisation data enables carbon emissions to be displayed as an intensity measurement by a consistent metric. Normalisation data can be managed in the Normalisation Metrics and Delete Normalisation pages found under Admin Settings > Normalisation.

The Normalisation Metrics page allows users to set up Client specific custom metrics. To create a metric select the ‘Create Metric’ button. Enter a metric name, unit and measurement type. Static Value measurement types will average multiple uploads of a normalization metric. Multiple uploads of a normalization metric with a Rate measurement type will be summed. Once any data has been uploaded for a normalisation metric it is no longer possible to edit or delete this metric.

Normalisation data can be deleted in bulk in the delete normalization page. Please use the filters at the top of the page to display the files you wish to target. Select the files you wish to delete using the selection box (red outline) or the select all button at the top of the table. To delete the files select Next Step and Delete to confirm you wish to delete the data. Please note, deletions cannot be reversed.
