Analyzing Scenarios

Users can project their consumption and emissions data into the future and apply certain sustainability initiatives to it in order to see what would happen if they carried out those initiatives. For example, in an office building, how would electricity data be impacted if we switched to more efficient light bulbs?

In Target > Analysis, the orange line represents projected consumption or emissions. It is a straight-line projection based on the last complete year of the user's data. The last complete year is represented by the last vertical blue line for which the end date is before the date specified in the 'Include Data Until' field on that same page. The orange line projects from it to the end of the graph.

From the drop-down field, the user can select existing initiatives for planning how to reduce consumption and/or emissions. The drop-down field populates with only the initiatives relevant to the user's target (for examples: if the target is for electricity, electricity-based initiatives; if the target is for fuel, fuel-based initiatives like reduction of diesel or natural gas consumption). The initiative must be applicable to a node in the target. Also, the initiatives that populate for selection in the drop-down field will only be those that apply in terms of date relevance. An initiative relevant five years ago, for example, will not populate within the drop-down field if it is no longer relevant. Note: If the savings dates of the initiative only apply prior to the final complete year of the target, the savings are then only applicable to the past, and will not be reflected in the projection line.

The user selects the initiatives for which he or she wants to evaluate the impact from the drop-down field and then clicks ‘Refresh Table and Plot’. That will then subtract any savings obtained from the projection line, so the projection line then lowers in accordance with those savings.
