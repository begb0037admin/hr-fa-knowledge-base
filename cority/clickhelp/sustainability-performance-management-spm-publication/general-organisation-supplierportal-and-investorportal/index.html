Organisation – SupplierPortal and InvestorPortal

Organisations that make use of the InvestorPortal or SupplierPortal solutions can import GHG Emissions Wizard data into the environment module. Please note, this functionality requires activation before it can be used. Please contact your Cority account manager to do so.

First, nodes which can accept data from InvestorPortal (IP) or SupplierPortal (SP) should be created. Please navigate to ‘Admin Settings > Organisation > Nodes & Data Sources’ and create a node with the entity types of InvestorPortal or SupplierPortal for the respective solutions. Value chain data sources should be created to accept the emissions data.

To map data from IP and SP, navigate to ‘Admin Settings > Organisation > SupplierPortal’ or ‘Admin Settings > Organisation > SupplierPortal’. Select the supplier or portfolio company data you would like to import (red outline), the Wizard you would like to import (blue outline) and the node to which you would like to link it to (green outline). Finally, select the wizard data you would like to import from the left table, and the value chain data source you would like to import it to in the right table (purple outline) and click ‘Import Mapped Data’. Data which has already been imported will be highlighted in green.
