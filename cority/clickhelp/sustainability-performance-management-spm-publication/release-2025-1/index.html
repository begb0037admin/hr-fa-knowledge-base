Release 2025.1

In release 2025.1, we have made the following fixes and improvements:

GSE-1518 – In Frameworks > Inputs, for a questionnaire question, after clicking ‘Submit for approval’, the user will now remain on the same page of the questionnaire.

GSE-361 – In Frameworks > Inputs, for a questionnaire question, the ‘Submit for approval’ button will now also save any responses that were added or updated for the question before the button was clicked.

GSE-1953 – In Frameworks > Approvals, after approving or rejecting a questionnaire question, the user will now remain on the same page of the questionnaire and the question will now refresh to reflect any update to its status.

GSE-212 – In Frameworks, for applicable questionnaires with approvals, the ‘Select All’ button now functions as expected.

GSE-1536 – In Environment > Targets, normalised target calculations are now correct.

GSE-674 – In Environment > Targets > Target Boundary, the Remove icon for removing nodes is now provided again.

GSE-1503 – In Environment > Inputs, for EPA methodology ‘Road’ or ‘Rail’ Business data sources with a distance of 300 or 600 miles exactly, when saved and calculated, an unexpected error is no longer generated.

GSE-1841 – In Admin Settings > Nodes and Data Sources, when creating data sources, GHG AR6 is now an available methodology for calculations.

GSE-1474 – In View Categories, Label auto-views now only appear under the Label category and Country auto-views now only appear under the Country category.

GSE-1907 – In the Environment module, when adding consumption data for Road Business, Road Commuter, or Road Freight, for Vehicle Model Year, 2025 is now an available option.

GSE-1996 – In Environment > Inputs, when opening a frozen file, its status will no longer change to Locked.

GSE-1838 and 1537 – An issue with the adapter.Fill(importData) call that was causing crashes when importing some Microsoft Excel files has been fixed.

GSE-1826 – When applicable, added consumption labels will now show in the Data Audit Bespoke Fields Report.

GSE-1828 – Where applicable, PDF files now upload successfully.

GSE-1898 – In Frameworks > Settings > Custom Question Library, when adding or importing questions, ‘KPI Reference’ is now a mandatory field.

GSE-1965 – In Environment > Approvals, Previous Period dates are now always correct.

GSE-1872 – When adding data sources that are EPA methodology and either Road Business or Road Commuter:

  • If the Vehicle Category is Motorcycle, the ‘Upper Medium (125-500cc)’ and ‘Lower Medium (50-125cc)’ subcategories are now available.
  • If the Vehicle Category is LCV, the Class I, Class II, and Class III subcategories are now available.

GSE-2288 – When running the Data Audit Bespoke Fields Report, the units used for and displayed in the report now match what is expected.

GSE-2104 – When adding data sources that are EPA methodology and have the ‘Supply Chain Spend’ consumption type, additional cost categories are now available.
