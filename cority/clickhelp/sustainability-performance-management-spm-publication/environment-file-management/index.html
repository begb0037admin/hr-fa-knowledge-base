Environment – File Management

Files can be bulk reprocessed, deleted, frozen or unfrozen in ‘Environment > Settings > File Management’. Please see the table below for details of what each of these actions refers to.

To manage files in bulk, first select the button associated with the action you would like to complete. Step 1 is to select the file(s) that need to be managed by searching for a specific file, a date of upload or a node. Once the file(s) are selected, click ‘Next Step’ to proceed. Please double check your files and select Delete, Freeze, Unfreeze or Reprocess to confirm your selection.

 

ActionExplanation
Reprocess FilesSend a file back through the calculation process. This may be useful to ensure your data is using the most up to date emissions factors.
Delete FilesRemove uploads from the system. Deleted files cannot be recovered.
Freeze FilesPrevent uploads from being edited, reprocessed, or deleted by any user.
Unfreeze FliesRevert the freezing process to allow users to change to a file to be made.
