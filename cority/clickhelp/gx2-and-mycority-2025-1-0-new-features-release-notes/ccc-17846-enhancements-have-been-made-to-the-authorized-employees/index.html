CCC-17846: Enhancements have been made to the Authorized Employees sublist (tab)

Mandatory

For the Authorized Employees sublist, the following columns have been added:

  • Permit Role
  • Start Date
  • End Date
  • Start Time
  • End Time
  • Comments

The values of these columns can be modified inline for each employee in the sublist, in both GX2 and myCority.

Note: There is no Layout associated with the ‘Authorized Employees’ sublist.

These enhancements will help track employees added to a permit.
