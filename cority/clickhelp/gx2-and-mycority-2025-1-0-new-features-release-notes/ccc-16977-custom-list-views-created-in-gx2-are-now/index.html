CCC-16977: Custom standard views that have been created in GX2 are now available in myCority

Opt-In

In myCority, custom views created in GX2 can now be selected from the ‘View’ dropdown list and used. This functionality is available for all sublists for all solutions.

When creating a new view, adding more than 17 columns will trigger a warning message that the view is not optimal for myCority. The warning must be acknowledged to continue. For optimal viewing, we recommend limiting the view to eight columns. That limitation will be addressed in an upcoming release.

Granting and prohibiting sublist views through security roles functions the same in myCority as GX2.
