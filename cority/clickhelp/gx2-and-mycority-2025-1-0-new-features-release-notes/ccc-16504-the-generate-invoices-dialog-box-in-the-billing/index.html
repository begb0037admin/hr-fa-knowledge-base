CCC-16504: The ‘Generate Invoices’ dialog box in the Billing solution’s ‘Un-Invoiced Items’ list has been enhanced

Opt-In

  • The following additional invoice criteria have been added:
    • Health Center
    • Fee Schedule
      Multiple fees can be selected that will be grouped within the same invoice.

    These criteria will work in conjunction with the Employer and Payer when generating invoices.

  • A new ‘Include invoice associated to Payer’ check box is provided.
    • When this option is selected, the letter template associated with the Payer in the Payer look-up table is added, un-drafted, to each created invoice.
      To configure the invoice letter associated with a specific Payer, clone the 'Payer Type' layout (ML-003778) in the PayerType look-up table and include the new 'Invoice Letter Template' field.
    • If a change needs to be made to the invoice letter, the user can use the ‘Revert to Draft’ action and make any changes.
    • If the user needs to change the invoice template, they can delete the letter and re-add a different one.
  • A new ‘Move invoices to Submitted status’ check box is provided when the ‘Include invoice associated to Payer’ check box is selected.  
    • The newly created invoice records will go straight to the Submitted status.
    • The PDF version of each letter will be added to the ‘Documents’ tab of each respective invoice
  • When an invoice moves to the Submitted status, UDF fields are no longer locked for editing and additional information can continue to be documented.
