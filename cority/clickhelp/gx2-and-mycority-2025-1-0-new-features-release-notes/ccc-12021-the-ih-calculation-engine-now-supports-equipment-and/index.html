CCC-12021: The IH Calculation Engine now supports Equipment and Noise Monitoring calculations

Opt-In

The IH Calculation Engine now supports Equipment and Noise Monitoring calculations

The following new fields can be added to custom versions of the Equipment layouts:

  • 17 new number UDFs (that accommodate up to 6 decimal places), numbered 4 through 20
  • 20 new calculated fields, numbered 1 through 20
  • 4 new date fields:
    • Last Efficiency Date
    • Next Efficiency Date
    • Last Chi Square Date
    • Next Chi Square Date
  • Efficiency Result, a numeric field (rounded to 4 decimal places)
  • Chi Square Result, a numeric field (rounded to four decimal places)

The four date and two result values display on the Equipment record when 'Sampling Equipment' is selected. The results shown are those that match the most recent testing date, similar to how calibration pulls and displays the calibration information.

The calculated fields use the 'Equation Set' look-up table, which pulls data from the Equation Library.

The calculated fields will calculate given the equation in the equation library and display up to 8 characters (for example, 1.222222 or 11.22222; anywhere from 1-6 decimals, depending on the whole number characters).

The following new fields can now be added to custom versions of the Noise Monitoring Sample layouts:

  • 20 new number UDFs (that accommodate up to 9 digits before the decimal point and up to 9 digits after the decimal point), numbered 1 through 20
  • 20 new date UDFs, numbered 1 through 20
  • 2 new date fields:
    • Next Efficiency Date
    • Next Chi Square Date
  • Efficiency Result, a numeric field (rounded to 4 decimal places)
  • Chi Square Result, a numeric field (rounded to 4 decimal places)

The two date and two result values display on the Noise Monitoring Sample record when 'Sampling Equipment' is selected. The results shown are those that match the most recent testing date, similar to how calibration pulls and displays the calibration information.

The calculated fields use the 'Equation Set' look-up table, which pulls data from the Equation Library.

For each new field, the equivalent column can be added to applicable custom list views.

The fields can be used in business rules, display rules, and workflows, and can be reported on using Query Builder and Report Writer.

Each of the new fields can be prohibited from user roles.

Values for the fields can be imported and are supported by the REST API.

There are two new sublists (tabs) that can be added to custom versions of the Equipment layouts called 'Efficiency History' and 'Chi Square History'.

  • The sublists will store historical readings for the equipment. They function very similarly to 'Calibration/Inspection History.
  • The default list view has the following standard columns:
    • Last Efficiency Date or Last Chi Square Date, depending on sublist
    • Efficiency Result or Chi Square Result, depending on sublist
  • Additional applicable columns (corresponding to the other new fields) can be added to custom versions of the list views.
  • The list views have the following buttons:
    • New
    • Edit
    • Delete
  • The list views have the following actions:
    • Export to Excel
    • Show Record History
  • When viewing a record from the list view screen on either of the sublists, the last testing date will be a clickable link, which works in the same manner as those on the 'Calibration/Inspection History'.
  • When the user selects the New button on the sublist, the following fields display: Equipment, Serial No, Date, Assigned to, Description, and Results.

Also, some cleanup has been done to ensure that when a user enters a new equation in the equation library and the entity selected is either Equipment or IHNoiseSample, the available fields are the supported fields only.

For more information on how to use the Calculation Engine, see the GX2 User Guide.
