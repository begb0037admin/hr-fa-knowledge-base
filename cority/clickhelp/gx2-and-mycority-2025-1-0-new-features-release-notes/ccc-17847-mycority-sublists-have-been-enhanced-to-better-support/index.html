CCC-17847: myCority sublists have been enhanced to better support the Permit to Work solution

Mandatory

For myCority, on mobile devices and tablets, sublists will now be displayed as cards instead of with horizontal columns for a better viewing experience. You can select a particular sublist view using the ‘View’ dropdown list.

The new card design applies to all solutions in myCority.

The following enhancements have been made to the ‘Permit To Work’ sublist views:

  • If there are more than eight lines on the card, or additional lines are truncated to maximize space in a 'Permit to Work' sublist, the user can click ‘View All’ to expand the entire card and display all columns and values.
  • For the ‘Control Type’ field in the sublist 'Risks for this Permit', the user can now scroll horizontally through the values when the 'enable multiple values' functionality is configured.
  • Users can now inline-edit fields on the sublist view in the Authorized Employee, Permit Condition, and Work Permit Risk sublists.
    When editing, the user can choose to edit within the modal box for the selected sublist view or click ‘Go to record’ to open the full layout for editing.
  • Users can now inline-add records by clicking ‘New Record’ on the Authorized Employee, Permit Condition, and Work Permit Risk sublists.
    When adding a new record, only the fields in the selected view will appear in the modal box. The user can choose to enter data in the sublist view fields then save and return to the sublist view or click ‘Go to record’ to navigate to the full record. Any values added to the modal box will be saved when they navigate to the full record.
