Summary of Platform Enhancements

The table below lists smaller design improvements we have made to the GX2 Platform. The items are organized by component and the components are arranged in alphabetical order. Descriptions of larger features follow the table.

ItemComponent(s)Description
CCC-18302Administrator

The following changes have been made to the text editor:

  • The height of the letter 'Header' field has been increased to 200 pixels.
  • The height of the letter 'Footer' field has been increased to 150 pixels.
  • The height of the 'Letter Body' and 'Email Body' fields have been increased to 500 pixels.

 

CCC-19836Security

For license keys, a stronger cryptographic scheme has been implemented.

 

CCC-19240Security

Improvements have been made to prevent reverse tabnabbing attacks.

 

CCC-18365Security

Improvements have been made to ensure the BR API Log is sanitized of sensitive data.
