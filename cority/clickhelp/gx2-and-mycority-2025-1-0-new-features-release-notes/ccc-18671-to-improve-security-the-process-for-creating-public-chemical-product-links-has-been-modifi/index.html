CCC-18671: To improve security, the process for creating public chemical product links (list URLs) has been modified

Mandatory

A tokenized public URL will now be generated.

This will:

  • Simplify the process for creating chemical product public links.
  • Ensure such links cannot be easily deciphered and altered by users to access other public product lists (including lists not intended for those users).

Now, when a user edits an Environmental ‘Chemical Product’ view, a new button labelled ‘Generate Public Link’ is provided if:

  • The user’s role is assigned the listconfiguration.generatepublicchemproductlink security action
    AND
  • The view is marked ‘Standard View’

When the user clicks the ‘Generate Public Link’ button, a modal box displays with:

  • The full URL path containing the generated tokenized read-only link
  • A look-up field for selecting the language (populated by default with the user's current language from System Settings)
    • If another language is selected, the link will update dynamically.
  • A 'Copy' button for copying the generated URL to the clipboard
  • A 'Cancel' button for closing the modal box

When pasting the URL into a web browser after using the copy functionality, the user will be directed to the appropriate public product link.
