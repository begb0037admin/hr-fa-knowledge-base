CCC-14347Occupational Health – OSHA ReportingN/A

Organizations that are required to submit the combined 300 Log and 301 data to the OSHA ITA (Incident Tracking Application) can now do so by the March 2nd deadline using GX2.

This is being released to align with the new OSHA requirements effective January 1st, 2024.

To support this, there is a new ‘OSHA 300/301 Electronic Submission’ report in Business Intelligence > Reports.

The report is categorized under the Injury/Illness module.

The report provides 13 filters, including the ability to report on the previous full year.

Note: The year filter will always reflect the current year, as well as the prior seven years, and default to the prior year.

Once the report is fully configured, the user simply clicks Submit > ‘Export to CSV’ to generate the report file.

The user will then have to upload the CSV file to the OSHA ITA site.

The report can also be exported to Microsoft Excel.

Note: Site security will not apply because this is generating a CSV file for an interface not for a report, and the file should not contain any PII data.

Additional information can be found on Cority Academy under GX2 > Safety > OSHA Electronic Reporting Changes for 2024.

 

CCC-15133Platform – InfrastructureN/A

Users of GX2 and Greenstone can now log into both with a single set of credentials (SSO).

To support this, in GX2 there is:

  • A new 'Sustainability Solutions' module enabled by default on the 'Menu Configuration' screen and in 'My Favorites'.
  • A 'GreenstoneUrl' destination URL property in the GX2 site configuration file that requires the format https://<greenstonedestinationurl?>accountid=
    <customer_account_id>.
  • A new 'Greenstone Login Name' field, with a limit of 255 characters, on the 'User' layout.

Note: The Greenstone public key is stored as /config/greenstone.txt on the GX2 server and the GX2 server has the standard Cority private key, if populated in the 'SSO SAML 2.0 Private Key' system setting.
