myCority Design Improvements and Fixes

The table below lists the design improvements and fixes we have made in the myCority 2023.3.2 release. The items are organized by component and the components are arranged in alphabetical order.

Item #Component(s)ReportedDescription
CCC-15212PlatformN/A

For myCority requests that use the RESTful API, a timeout limit has been added. The new setting is located in server.config: <MyCorityTimeoutInMilliseconds>

The default is 64,800 ms (~18minutes).

 

CCC-13894QuestionnairesN/A

When printing or exporting a questionnaire that contains one or more longer comments and/or a large amount of text in a question's text area, the full comment(s)/text will now print or export.

 

CCC-1152SecurityN/A

myCority now supports the use of SQL Server 2019 for the database server.
