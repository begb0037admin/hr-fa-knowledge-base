GSE-1181, 1182, 1183, 1640: Threshold validation functionality is now provided.

  • You can now define a threshold so that if any new data added exceeds that threshold (in variance) relative to the applicable historical data, the new data will be flagged for additional commentary (for example, commentary on potential reasons the difference). Once configured, any new data added is immediately checked against the historical data.
  • To support this, there is a new Admin page labelled Input Variance Thresholds, which is accessed by navigating to Environment > Settings > Data Validation > Input Variance Thresholds. On that page a user could specify, for example, that for new electricity grid uploads, comments will be required if the variance exceeds 10% when compared with historical data. The user could also specify for a particular data type that additional commentary is required if the variance is not applicable (if the variance cannot be calculated, which happens if there is no historical data, for example). There would be no historical data with which to compare if it is a new type of data.
  • Once set up on the new Admin page, when the user uploads new data, the data will be assessed against the applicable historical data, and if the new data exceeds the defined threshold, the user will receive an email notification that commentary on the new data must be provided. Comments can be provided on the Input Variance Thresholds page. When the comments have been entered and submitted, they will be added to the audit log and the approvals commentary, which will then be made available in the next steps for the approver(s) to read.
  • If the data is entered through an input form rather than being uploaded, then the user will be prompted immediately within the system itself to provide the required comment(s).
  • An edited upload will return the process to the beginning and require comments to be added again.
