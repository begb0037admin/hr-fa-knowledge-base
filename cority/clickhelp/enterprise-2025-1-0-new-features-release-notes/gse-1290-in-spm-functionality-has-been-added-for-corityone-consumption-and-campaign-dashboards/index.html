GSE-1290: In SPM, functionality has been added for CorityOne Consumption and Campaign Dashboards.

  • In SPM, from the left side menu, click Dashboard to open the dashboards.
  • You can use the top-level filters to filter the dashboard by view, hierarchy, time period, and date. Filtering options are dependent on the user's permissions.
  • Dashboard indicators can be moved, expanded, and removed.
  • Users can switch dashboards by clicking Switch Dashboard.
  • Any changes made to the dashboards will not be saved.
  • Note: It is not possible to create a new dashboard in SPM.
