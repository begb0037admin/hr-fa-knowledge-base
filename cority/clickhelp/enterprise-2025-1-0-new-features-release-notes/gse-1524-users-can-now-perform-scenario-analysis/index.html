GSE-1524: Users can now perform scenario analysis.

  • They now can project their consumption and emissions data into the future and apply certain sustainability initiatives to it in order to see what would happen if they carried out those initiatives. For example, in an office building, how would electricity data be impacted if we switched to more efficient light bulbs?
  • This feature set uses existing functionality within the system. To Target Analysis, a new orange line has been added, which represents projected consumption or emissions. It is a straight-line projection based on the last complete year of your data. The last complete year is represented by the last vertical blue line for which the end date is before the date specified in the 'Include Data Until' field on that same page. The orange line projects from it to the end of the graph.
  • A new drop-down has also been added from which you can select existing initiatives for planning how you will attempt to reduce your consumption and/or emissions. The drop-down populates with only the initiatives relevant to your target (for examples: if the target is for electricity, electricity-based initiatives; if the target is for fuel, fuel-based initiatives like reduction in diesel or natural gas consumption). The initiative must be applicable to a node in the target. Also, the initiatives that populate for selection in the drop-down will only be those that apply in terms of date relevance. An initiative relevant five years ago, for example, will not populate within the drop down if it is no longer relevant. Note: If the savings dates of the initiative only apply prior to the final complete year of the target, the savings are then only applicable to the past, and will not be reflected in the projection line.
  • The user selects the initiatives for which he or she wants to evaluate the impact from the drop-down and then clicks ‘Refresh Table and Plot’. That will then subtract any savings you get from your projection line, so the projection line then lowers in accordance with those savings.
