GSE-871 and 1016: The Custom Data Source functionality has been enhanced.

  • The Custom Data Source functionality is used to upload custom emissions factors for calculating emissions.
  • In the past, all calculations using the custom data source were for market-based emissions only. Now in the Custom Data Source area, the user can add more emissions factors than before, and in addition to market-based emissions factors, the user can add factors for location-based emissions and for FERA (fuel and energy related activities). FERA emissions can be calculated by uploading emissions factors to the columns SC, T&D, and SC T&D, which are Supply Chain, Transmission & Distribution, and Supply Chain Transmission & Distribution.
    • Once entered and saved, each emission calculation that is run will use the applicable emissions factors. Anything volume-based, for example, will use the applicable volume-based emissions factor(s).
    • Users can now create types and subtypes with names that use numbers and special characters.
    • Each type and subtype must now have a unique name. There can no longer be duplicate subtypes. For example; Milk 1 and Milk 2 could be used, if necessary.

    • Users can now edit and/or delete a type or subtype after creating it, as long as no calculations have used it.

      • Exports have been enhanced to show subtypes rather than types.
      • The existing input list exclusion feature is now available for the custom data source. For input forms, this can be used to exclude specific categories and/or subcategories, which will make them unavailable in applicable drop-down field(s). For example, if you do not want a category or subcategory that is no longer useful or relevant available (perhaps Milk) in the applicable drop-down field(s) when entering data, you can exclude it.
      • Users can now bulk upload emissions factors. The user can download them using the Download button, make adjustments (to their numbers, by adding new categories, etc.) on the spreadsheet, and then re-upload them. When uploaded, all of the adjustments will be made within the system (in the Custom Data Source Management table).
      • A greater variety of units can now be used when uploading data. In the past, if an emissions factor was in a particular unit (for example, liters), the user could only upload data in those units. Now, even if the emissions factor is in liters, the data can be uploaded in cubic feet, or if in kilometers, the data can now be uploaded in miles, for examples.
      • Also, some minor user interface improvements have been made.
