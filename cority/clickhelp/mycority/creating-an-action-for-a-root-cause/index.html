Creating an Action for a Root Cause

If you are completing an investigation for which a root cause has been identified, you may wish to link an action to that root cause. To create an action:

  1. Select an investigation from the My Tasks view.
  2. Select the Root Cause Analysis tab.
  3. Select the cause for which you want to assign an action.
  4. Click the vertical ellipsis at the top right.
  5. Select Create Action for this Root Cause. The Finding (w/ Risk) & Actions screen will display.

  6. Complete the Finding (w/ Risk) & Actions record to the best of your ability, ensuring you provide a value for all required fields.
  7. When you are finished, click Save.
