Pre-requisite settings required by the Administrator:

  • Ensure the auto-post to case feature is configured (see the Cority User Guide), so that the referral questionnaire from the manager will auto-post to a case for the clinician.
  • Add the Case Number field to the custom Schedule Entry layout. This allows the appointment to be linked to the case number, which links the appointment to the Case record.
  • In the Case Management module, add the Schedule Referral action on the Case tab. This allows the clinician to make the appointment from the Case Management module.
  • In the Case Management module, add the Schedule History tab. This allows the clinician to see the history of the Case record (past appointments, upcoming appointments, etc.).
  • To the custom myCority and GX2 Case layouts, add the Messages tab. This allows free text messages between the Manager and the clinician. For example, the clinician might want further information/clarification on the initial referral, or the Manager might want to know how long the referral process will take.
