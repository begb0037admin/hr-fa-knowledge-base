Completing a New Questionnaire

  1. Select My Tasks from the side menu.
  2. Click the Create New button.
  3. Click New Questionnaire.

You can also create a new questionnaire by clicking the New Questionnaire icon on the Home screen, and then continuing with the steps below.

  1. Select a questionnaire from the Select a Questionnaire list.
  1. Complete the questionnaire to the best of your ability, ensuring you provide a response for all required fields.


    Some questions may accept a drawn response, either over an image or in a blank field. If this is the case, a Clear button will display below the question, allowing you to clear your drawn response. You can provide a drawn response using your cursor, or if you are using a tablet or mobile device, using your finger or a stylus.

    If applicable, the questionnaire score will display at the top of the questionnaire.  

    If you are completing a questionnaire for an inspection and a response results in the creation of one or more actions, the message "Actions created. Click to assign" will display. If you click the message, you will be directed to the Action layout where you can complete the action assignment.

    Attachments added to questions on an Environmental, Ergonomics, Quality, or Safety Inspection questionnaire can be accessed by the Assignees from the Documents sub list of any corresponding auto-created 'Action' records, and any solutions that support auto-creation of Findings & Actions from a questionnaire (Incident, Audits, Management of Change, etc.)

    1. To save the questionnaire to complete it later, click Save. You can return to it from the Incomplete list in the main My Tasks view.
      If you have finished the questionnaire, click Submit.

    ​Administrator Notes

    • The Select a Questionnaire list displays questionnaire templates that have the Public Questionnaire checkbox selected and the Questionnaire Inbox field populated in the Questionnaire look-up table in Cority GX2.
    • For subquery questions it is no longer necessary to grant the corresponding security actions to the user's role. That is still required though to create/update business rules that use subqueries.
    • When creating a subquery report for the Subquery question type, a sort order should be stipulated for one (or more) of the columns. If it is not, myCority will simply sort by the first column and the Record ID value. The column header sort functionality available in the GX2 platform is not possible in myCority.
