Creating a New Absence Request

This functionality is only available for the LDAP and SSO authentication methods.

  1. Select My Tasks from the side menu.
  2. Click Create New.
  3. Click New Absence Request.

You can also create a new absence request by clicking the New Absence Request icon on the Home screen, and then continuing with the steps below.

  1. Complete the absence request to the best of your ability, ensuring you provide a response for all required fields.

If you assign a case type to the absence request, and the case type has one or more linked to-do activities, those activities will display in the To-Do tab on the absence request. Depending on how the administrator has configured myCority, the same activities may also display in your My Tasks view.

  1. When you are finished, click Submit. The absence request will display in your My Records view.

Once you submit an absence request, it will be reviewed by a Cority platform user. If the Cority user posts the absence request to a Case record, it cannot be cancelled or modified from within myCority. You will still be able to upload new documents and complete your assigned to-do activities for the request.
