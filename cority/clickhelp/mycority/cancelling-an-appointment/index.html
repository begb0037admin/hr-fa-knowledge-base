Cancelling an Appointment

  1. Select an appointment from the Incomplete list. The appointment will open.
  2. Click Cancel Appointment.
  3. An ‘Are you sure you want to cancel this appointment?’ message will display. Select Yes. The appointment will be cancelled and will no longer display the My Tasks view.
