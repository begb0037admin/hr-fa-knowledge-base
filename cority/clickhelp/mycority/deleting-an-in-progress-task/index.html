Deleting an in-Progress Task

You can only delete tasks that you have created.

  1. Select a task from the Incomplete list. The task will open.
  2. Click Delete.
  3. An ‘Are you sure you want to delete this record?’ message will display. Select Yes. The task will be deleted and will no longer display the My Tasks view.
