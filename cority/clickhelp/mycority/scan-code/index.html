Scan Code

The Scan Code view allows you to scan, upload, or search for an asset code, and associate one or more waste records with a code. This will help you track and manage your organization’s waste management obligations.

It is recommended that you use the barcode scanner to scan a code, rather uploading an image from your device. This will help ensure the code can be easily read by the system. If your device is an iPhone, you can only scan asset codes using the Safari browser. 

  1. Click Scan Code from the side menu.
  2. To scan a code, hold the scanner over the code. If this is your first time scanning a code with your device, a prompt will ask if you would like to access the camera. Click OK.

    To upload a code:
    1. Click Upload image.
    2. Select an image from your device and click Open.
    3. Once you have uploaded the image, you will be directed to the Asset Details screen. The Asset Details screen will display the barcode or QR code image you just uploaded.

    To enter a code manually:

    1. Click Enter a code.
    2. Enter the code and click Submit.​
  3. If the code is related to an existing asset, the myCority Asset View screen will open, displaying the equipment code, equipment type, and other details associated with the asset.
    If the code does not relate to an existing asset, you will be prompted to create a new one. The myCority Asset View screen will open. Complete the form to the best of your ability. When you are finished, click Save. See Adding Related Records to an Asset for instructions on how to add one or more related records to the asset.
