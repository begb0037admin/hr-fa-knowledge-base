Ergonomics Dashboard

This dashboard provides a visual representation of your ergonomics data as configured in GX2 and RSIGuard.

To access this dashboard, first select My  Dashboards from the side menu or from the Home view. The first time you access My Dashboards, you will be presented with a welcome message that will instruct you to select a dashboard.

Click the Magnifying Glass icon and search for the Ergonomics Dashboard. Note: The dashboard must be granted to your role. Contact your administrator if it is not.


Each indicator on the dashboard (except for any number only, table, and map type indicators) has Show legend / Hide legend at the bottom. If you click Show legend, the indicator will open in full-screen mode and display a legend. If you click Hide legend, the legend will be hidden again.

If you are using a desktop or laptop computer, click the Full Screen icon at the top right of an indicator to view it in full screen mode. If you are using a tablet or mobile device, simply tap an indicator to view it in full screen.

To exit full screen mode, click X at the top right.

Each time you access My Dashboards, the view will display the dashboard you last accessed.
