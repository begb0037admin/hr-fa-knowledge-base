Redis

A server-side caching mechanism is used to optimize the performance of the application. The application connects to REDIS (an open-source cache), which is used to store system data that is accessed regularly by the application (for example, system settings, translations, or form information). Redis runs as a separate service and does not need to be on the same server as the application.
