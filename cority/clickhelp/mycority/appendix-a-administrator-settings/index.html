Administrator Settings

If you are an administrator, you can use the settings described in this section to configure the appearance and behavior of myCority, and to define who can register for the service.

Prior to the 2019.2 release, an administrator could grant or limit users’ access to the views and record types in myCority using the Disable <module> in myCority system setting. In 2019.2, this setting was removed and replaced by a series of Personalize myCority settings, which an administrator can access from within myCority. For instructions on creating myCority customizations, see Personalize myCority.
