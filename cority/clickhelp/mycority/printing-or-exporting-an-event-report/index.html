Printing or Exporting an Event Report

  1. Select an event report from the Event Report view.
  2. Click the vertical ellipsis at the top right.
  3. Click Print or Export. A read-only view of the event report will display. The view will have Print, Export to PDF, and Back to previous view buttons.

  4. To print the event report, click Print. If your device is connected to a printer, a Print dialog will display. Select your desired printer settings and click Print.


  1. To export the event report to PDF format, click Export to PDF. A PDF copy of the event report will download to your device.
  2. Click X to return to the event report.
