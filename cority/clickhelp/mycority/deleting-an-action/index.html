Deleting an Action

  1. From the Event Report, navigate to the Findings & Actions tab.
  2. Place a checkmark next to the record(s) you want to delete.
  3. Click Delete.
  4. An ‘Are you sure you want to delete this record?’ confirmation prompt will display. Select Yes. The record will be deleted and will no longer display in the Findings & Actions tab.

When a response on an inspection with a manually-triggered action is changed, or when a comment or attachment is added or modified, the Finding Details automatically update with the new information. Manually-created findings and actions can be deleted before the inspection is submitted. 

Automatically-created findings and actions are deleted when a response or comment is changed.
