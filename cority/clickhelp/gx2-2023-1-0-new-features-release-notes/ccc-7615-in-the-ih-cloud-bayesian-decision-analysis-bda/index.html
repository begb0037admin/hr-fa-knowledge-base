CCC-7615: In the IH cloud, Bayesian Decision Analysis (BDA) will now calculate exposure ratings to make a recommendation for respirator (PPE) selection

Opt-In

  • This feature set includes the ability to:
    • Define and store the Assigned Protection Factor (APF) respirators available to the organization.
    • Specify default APF values and have those populate automatically when running BDA PPE Analysis.
    • Run BDA PPE Analysis.
  • The results will be displayed on a PPE (Respirator) Selection chart with an APF x-axis and a Decision Probability y-axis.
    • If a change is made to the original BDA data, the chart will clear (no longer display).
    • To re-populate the chart with the new result, the user can simply re-run the BDA PPE Analysis.
  • Note: This feature set is only available to EASi Solutions Software users.
  • For information on entering or importing IH data and running BDA, see the GX2 User Guide.
