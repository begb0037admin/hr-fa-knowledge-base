CCC-9564 and 8719: The 'Pulmonary Interpretation Standard' system setting now has the new 'ATS 2019' option

Opt-In

  • If that option is selected:
    • Only records created after its implementation will be affected.
    • All PFT records will use the ATS algorithm/calculations to interpret and display results.
