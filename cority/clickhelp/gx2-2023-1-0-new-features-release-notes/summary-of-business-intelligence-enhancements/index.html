Summary of Business Intelligence Enhancements

The table below lists the smaller design improvements we have made in Business Intelligence. The items are organized by component and the components are arranged in alphabetical order. Descriptions of any larger features follow the table.

ItemComponent(s)Description
CCC-9155Reporting

In Query Builder, Report Writer, and Report Scheduler, there is a new 'Take Ownership' action.

An active user with the Administrator role, or with a role that is granted the querybuilder.allowupdatedelete (for Query Builder) or reportwriter.allowupdatedelete (for Report Writer) security action, can use the new action to take ownership of one or more reports from an inactive user. The user will not be able to take ownership of reports owned by an active user.

If the user's role is not granted the necessary security action, 'Take Ownership' will not be available.

When 'Take Ownership' is performed, the action is logged in the Record History and in the Event Log.

 

CCC-8210UI

The Kendo UI framework has been updated to the latest version to prevent any potential security issues.
