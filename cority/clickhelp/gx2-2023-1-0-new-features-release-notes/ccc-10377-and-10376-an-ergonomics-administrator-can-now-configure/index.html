CCC-10377 and 10376: An Ergonomics Administrator can now configure criteria sets for Case Manager that can be used to auto-create ergonomics cases

Opt-In

  • To support this, the left-hand menu in the Ergonomics cloud has a new 'Ergo Case Manager' section.
    • Under that heading, there is a new 'Criteria Set Configuration' link that takes the user to the new 'Criteria Sets' look-up table.
  • The new look-up table has a default list view and layout (ML-003765) with the following columns/fields:
    • Criteria Set Code
    • Criteria Set Description
    • Inactive
  • The fields are available in the Import Utility, can be reported on using Query Builder / Report Writer, and can be used in business rules.
  • The default layout has main, Group and Team, and Translation tabs.
