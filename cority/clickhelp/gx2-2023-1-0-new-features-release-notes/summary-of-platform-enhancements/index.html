Summary of Platform Enhancements

The table below lists the smaller design improvements we have made within the GX2 Platform. The items are organized by component and the components are arranged in alphabetical order. Descriptions of larger features follow the table.

ItemComponent(s)Description
CCC-11039Administrator

When and where applicable, the 'Additional Parameters' column can now be added to the 'Business Rule Action Queue' list.

 

CCC-9944Administrator

The default Role layouts now have the Clone button and functionality. Using that button, the user can create a new role by cloning and modifying an existing one.

The following will not be cloned (auto-populated) to the new role:

  • Assigned Users
  • Site Security
  • Case-type Security
  • Row-level Security

For information on working with the clone functionality, see the GX2 User Guide.

 

CCC-7901Administrator

When an environment has a large number of Portal users configured (300,000, for example), a Portal role can now be assigned to additional users, or removed from users, without encountering any timeout issues.

 

CCC-7517Administrator

In the Phrase Translations module, the following new default list views have been added:

  • Null Translations
  • Not Null Translations

The latter filters to only phrases that have been translated into the current user's language.

For example, if the user's Language setting value is French, all English phrases that have a French translation will be listed in alphabetical order with the French translation displayed in the Translation column.

The two new views can be cloned, and conditions for the Translation column in custom 'Not Null Translations' views can be added and/or changed. 

Also, the 'Not Null Translations' view has the following new columns:

  • Created Date - the date the translation was created
  • Modified Date - the date the translation was last modified, if applicable

 

CCC-5012Administrator

A business rule change action can now be configured to set a field (for example, employee.secondaryemail) to the value of an existing flex field (for example, flexfields.emailprovided). For information on working with business rule change actions and/or flex fields, see the GX2 User Guide.

 

CCC-9883End-User

If a layout is configured to have dynamic tabs (sublists) and/or sections, when applicable, those tabs and sections will now support multi-select fields and their values.

 

CCC-1017End-User, Documents

For document management, the 'Document Link' field will now accept up to 2000 characters.

 

CCC-9655Infrastructure

The Moment.js library has been upgraded to version 2.29.4.
