CCC-9713: Query Builder now fully supports multi-select fields

Opt-In

  • Query Builder has new 'Enable Multiple Values' and 'Disable Multiple Values' options. The latter is selected by default.
  • When 'Disable Multiple Values' is selected, only the first value for the field will be returned in the report data (as was the case previously), even if the field itself has 'Enable Multiple Values' selected on the applicable layout.
  • When 'Enable Multiple Values' is selected, you can:
    • Select up to three of the look-up table values to be included in the query/report
    • Choose for the resulting data to be rendered on a table in multiple rows (the default) or concatenated.
  • For numeric and date multi-select fields, neither concatenation nor aggregation are supported.
  • If data is rendered in multiple rows, aggregation works for string multi-select fields. If data is concatenated, aggregation is disabled.
  • If aggregation on more than one multi-select field is required, use 'count distinct' on the aggregation menu to obtain accurate counts.
  • This multi-select fields functionality includes the ability to filter and visualize the data.
    • When the visual indicator is added to an advanced dashboard, the table displays and will update if/whenever the entity property changes between 'Enable Multiple Values' and 'Disable Multiple Values'.
  • Note: This feature is disabled if:
    • No applicable layouts have multiple values
    • The field itself is not a look-up selector field
    • The field's look-up table is empty (has no values/entries)
  • This functionality is not currently supported for subqueries.
