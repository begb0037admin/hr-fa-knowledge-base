CCC-1728: A number of enhancements have been made to the Safety ‘Incident’ module

Opt-In

  • For questionnaires linked to an Incident record, the new 'All Related Questionnaires' list view is now provided. The view has the following columns: Questionnaire, Date of Response, Source, and Source ID for Questionnaires
  • For findings & actions linked to an Incident record, the new 'All Related Findings & Actions' list view is now provided. The view has the following columns: Finding Date, Finding Details, Due Date, Action Details, Assigned To, Completed Date, Source, and Source ID
  • For documents linked to an Incident record, the new 'All Related Documents' list view is now provided. The view has the following columns: Description, Document Type, Document Date, Source, and Source ID
  • For each, the view shows the questionnaires / findings & actions / documents that are linked to the Incident record and that are linked to all event reports listed on the Incident record's 'Related Event Reports' tab (sublist).
  • If the user detaches an event report from the Incident record, the questionnaires, findings & actions, and documents linked to the event report will no longer be listed on the view.
  • This functionality applies in myCority as well.
