CCC-7418 and 7417: In the Ergonomics cloud, you can now assign and manage RSIGuard Desktop Actions

Opt-In

  • This functionality is only available to users who have an active installation of RSIGuard.
  • The ‘Manage Employee Risk’ screen has a new RSIGuard tab with an ‘Assigned Desktop Actions’ section. The section has the following columns:
    • Desktop Action – a description of the action
    • Assigned Date – the date the action was assigned
    • Installations – the number of installations to which the action is currently assigned
      • The installations count is a link that will open a list labelled ‘RSIGuard Installations’. The list has the following columns:
        • Desktop Action – description of the action
        • Installation – installation ID/code
        • Installation Date – the date the desktop action was applied to that installation
  • There is also a new ‘RSIGuard Desktop Actions’ look-up table. It functions like a typical look-up table, providing an intuitive list view with appropriate columns, a layout for RSIGuard desktop actions, and standard actions that can be performed from the list view and layout.
    • The layout has an Employees tab. Adding an employee to an RSIGuard Desktop Action record will assign that action to the employee.
    • The layout also has a 'Group and Team' tab.
      • An automatic batch operation is run daily to update the values on the Employees and 'Group and Team' tabs (for example, an employee who has left the organization will no longer be assigned any desktop actions).
    • The look-up table also provides the new ‘Redeliver’ check box for each employee assigned one or more actions. If the check box is selected for an employee, whenever that employee installs/reinstalls RSIGuard, he/she will also receive the assigned desktop actions for the new installation.
    • The look-up table values are available for use in Query Builder and Report Writer, in business rules, and can be created/populated using the Import Utility.
    • To access the look-up table quickly, on the Ergonomics cloud menu there is a new RSIGuard item with a ‘Desktop Actions’ link.
  • Also, the ‘Manage Employee Risk’ screen has a new ‘Assign Desktop Actions’ option. To assign desktop actions to one or more employees, simply select the employee(s), click ‘Assign Desktop Actions’, and on the picklist that opens select one or more RSIGuard desktop actions.
    • The employee(s) will be assigned the desktop action(s). In the look-up table, any employee that was selected will be added to the Employees tab on any desktop actions that were selected.
    • To use the new ‘Assign Desktop Actions’ option, the user’s role must be granted the AssignDesktopActions security action.
  • In addition, there is a new global ‘Enable RSIGuard Risk’ system setting, which is categorized under the RSIGuard security module. By default, the setting is disabled. When enabled, RSIGuard personal risk calculations will be turned on (that is, GX2 risk inventories will be connected to RSIGuard so that desktop risk can be calculated).
