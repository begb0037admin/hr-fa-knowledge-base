myCority Design Improvements and Fixes

The table below lists the design improvements and fixes we have made in the myCority 2021.3.1 release. The items are organized by module and the modules are arranged in alphabetical order.

Item #Component(s)ReportedDescription
CCC-5030DocumentsN/A

When a new version of a published document is under review, it will still be available in myCority.

 

CCC-5387Event ReportingN/A

When an Event Report questionnaire with scoring is filled out in myCority, the scoring now works as expected.

 

CCC-5055IncidentsN/A

For incidents, when saving related records (a Finding record, for example), any capitalization and punctuation in applicable fields is now retained.

 

CCC-4993MetricsN/A

When a measure or metric description is translated, the translation will be provided in myCority.

 

CCC-6037Occupational Health -
Case Management		2021.3.0.0

On the Messages tab of a Case record for a user whose full name is not defined in the system, the 'Created By' field value will now display the user's login ID.

 

CCC-6695Occupational Health - Employee CareN/A

A user can now book an appointment with health center and activity, without encountering any unexpected issues.

 

CCC-5073Occupational Health - Employee CareN/A

In myCority, when applicable, a business rule email action triggered by an appointment schedule entry will now send an Outlook-compatible .ics file with the necessary parameters.

 

CCC-4572Occupational Health - Employee CareN/A

For myCority, the 'New Vaccination' label can now be translated.

 

CCC-5972Platform - AdministratorN/A

A business rule (BR), with actions, configured to trigger when a user updates a Safety 'Incident' record and marks the investigation as complete (in either GX2 or myCority) will now fire successfully with all actions executing as expected.

 

CCC-6372Platform –
End User		N/A

On a custom layout (for example, Event Reporting – Near Miss) with an added UDF_Flag field, the check box for the field can now be selected/deselected and the layout saved without generating any unexpected errors.

 

CCC-3181Platform -
End User		N/A

When a guest user logs into myCority, if a privacy agreement is set up, the guest user will now see and be able to interact with the privacy agreement.

 

CCC-4720Platform - InfrastructureN/A

For myCority SSO logins, the GX2 Event Log now provides more detailed information.

 

CCC-5941QuestionnairesN/A

A guest user whose role has the required security configured can now create an employee account on the myCority questionnaire header.

 

CCC-5940QuestionnairesN/A

For any field on the myCority questionnaire header, smart search now functions properly.

 

CCC-5918QuestionnairesN/A

When applicable, a questionnaire will now open in the layout expected.

 

CCC-5893QuestionnairesN/A

In myCority, when a supervisor or manager should not be able to see an employee's questionnaire (for example, when saved and in progress), the supervisor or manager no longer can.

 

CCC-5892QuestionnairesN/A

A questionnaire using the newer myCority questionnaire response header layout that has scoring can now be saved without generating any unexpected errors.

 

CCC-5589Questionnaires2021.3.0.0

For a public questionnaire with myCority header, when created in myCority, the 'Consent Declination Reason' and 'Date Consent Declined' fields will no longer become locked on first save.

 

CCC-5355QuestionnairesN/A

A questionnaire with an attachment can now be saved and/or submitted without generating any unexpected errors.
