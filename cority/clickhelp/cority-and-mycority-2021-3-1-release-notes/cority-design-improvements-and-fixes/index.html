CCC-6122Business IntelligenceN/A

Query Builder has a new 'Arithmetic with Rounding' function.

The function returns the result of simple arithmetic calculations.

For data types that allow it, the system supports a maximum of 19 rounding places. For calculation, the following symbols are supported: + - * / ( )

Otherwise, its functionality is the same as that of the existing 'Arithmetic' and 'Rounding' functions.

For information on working with Query Builder, see the Cority User Guide.

CCC-5832  

A GX2 administrator can now obtain a list of roles for a user and update/assign a user's granted roles through the RESTful API.

Note: This does not support the creation of roles, only the ability to update a user's role(s).

To support this functionality, there is a new GET and POST endpoint for roles and GET and POST endpoint for security:

  • <virtualdirectory>/api/role
  • <virtualdirectory>/api/security

In addition, for any data values saved by the RESTful API through a POST/PUT call (for example, <script>confirm(1)</script>), on GET those values will be encoded so that there are no pop-ups. This ensures that saved potential cross-site scripting (XSS) values are not output through GET calls.

As well, when a user of business rule (BR) API actions makes an API call to a token endpoint that returns an access token in text/plain format, that token can then be mapped in the response body to the GX2 API Token look-up table (therefore, you are not limited to the application/JSON and multipart/form-data formats).

Also, a user of BR API actions can now map multiple records from the received RESTful API response.

For information on working with BR API actions, see the Cority User Guide. For information working with the RESTful API, see the Cority RESTful API Guide.
