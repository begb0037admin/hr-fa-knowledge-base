myCority Descriptions

The table below lists the fixes and minor improvements we have made in myCority 2025.3.0. They are organized by module, and the modules are in alphabetical order.

Item #Component(s)Description
CCC-12450Environmental / Safety – Incident

In both GX2 and myCority, where applicable, Five-Why Tree entries now wrap as expected. Also, any relationships between parent and child nodes are clearly indicated.

 

CCC-16970Environmental – Waste Management

The loading performance of the Waste records list has been improved.

 

CCC-22430
Event Reporting, Accessibility

Updates have been made to ensure that live regions are indicated on dynamically changing content areas.


CCC-22623Ergonomics

Office Ergonomics users who do not have an active Office Ergonomics risk profile assigned are no longer able to engage in activities to which they should not have access (take training flagged as ‘Self-Assessment’ or ‘Re-Assessment’, view their Risk Profile information, etc.).

 

CCC-5562Occupational Health – Immunizations

In all situations where applicable, a user with the appropriate role configuration can now successfully add a vaccination using myCority when there is an existing appointment for that activity.

 

CCC-22169Platform Administrator

A BRA configured to use a distribution list that is populated using Location ID when an event report is submitted will now function properly in myCority.

 

CCC-23067Platform End-User

Default values set in GX2 for myCority layouts will now display as expected in myCority when offline after the user has had the templates auto-updated.

 

CCC-22833Platform End-User

The auto-update form templates functionality now works properly for all templates, not just questionnaire.

 

CCC-22652Platform End-User

When logging into myCority, the user will now be directed to the correct screen (home or dashboard).

 

CCC-22429
Platform End-User - My Records, Accessibility

Updates have been made to ensure that live regions are indicated on dynamically changing content areas.


CCC-22059Platform – Translations

An issue that was causing the translations for some questions in myCority to be inconsistent with the translations of the same questions in GX2 has been resolved.
