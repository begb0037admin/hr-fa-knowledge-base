GX2 Descriptions

The table below lists the fixes and minor improvements we have made in GX2 2025.3.0. They are organized by module, and the modules are in alphabetical order.

Item #Component(s)Description
CCC-22533Environmental - Chemical Management

During a Regulatory List sync, Chemical Product records are now batched, which helps prevent system timeouts when the list contains a large number of chemical products.

 

CCC-23034Environmental / Safety - Event Reporting

For a site that only has licenses for Environmental users, none for Safety, on any ‘Environmental Event Report Selection’ look-up table record, the ‘Event Report Types’ tab can now be opened successfully and without generating any unexpected errors.

 

CCC-12450Environmental / Safety - Incident

In both GX2 and myCority, where applicable, Five-Why Tree entries now wrap as expected. Also, any relationships between parent and child nodes are clearly indicated.

 

CCC-23543Ergonomics

When applicable, if an Inseer Composite Risk Score is applied to a Motion Capture Assessment and synced back to GX2, the Composite Risk Score field in Query Builder (DT_RASIEInseerData) now populates as expected.

 

CCC-23079Ergonomics

For Case Manager, a failed email will no longer be marked successful. The system will now attempt to re-send it again later in a batch, as expected.

 

CCC-23021Ergonomics

The Employee Risk Report now includes Baseline Risk.

 

CCC-22792Ergonomics

For online training sessions, when added to the layout and/or list view, the Inactive check box is now operational.

 

CCC-22010Ergonomics

For Case Manager, criteria sets are no longer sending to inactive employees within Groups and Teams or to employees in inactive Groups and Teams.

 

CCC-22979Industrial Hygiene

When a user populates the Sampling Equipment field on an IH Monitoring record that has a related Equipment record, if that Equipment record has a Serial Number and Next Calibration Date, that information will now automatically transfer to the Monitoring record.

 

CCC-5254Industrial Hygiene

In IH > Monitoring, when completing a monitoring sample and any change in pre/post flowrate is >5%, the void sample popup now remains available for use.

  • If the user selects Yes, the sample is voided and the user is taken back to the Monitoring record.
  • If the user selects No, the sample status does not change and the record remains editable.

When the sample is incomplete, the user can choose to approve the sample using Actions > Approve.

 

CCC-23284Industrial Hygiene

Where applicable (for example, in IH Noise Monitoring), translations with the ; character now function properly.

 

CCC-23434Industrial Hygiene / Safety - Risk Assessment

For an IH or Safety ‘Risk Assessment’, on the Matrix sublist, under ‘Task Details for Selected Cell’, the Risk Selectors and Clear buttons now function as expected and without generating any errors.

 

CCC-23677 and 23675
Occupational Health - Appointments, Accessibility

For the Schedule Entry screen, updates have been made to help ensure custom controls provide the proper textual name, role, and state information.


CCC-23370
Occupational Health - Appointments, Accessibility

Updates have been made to ensure that all image buttons on the side bar can be navigated to and operated by just the keyboard.


CCC-23368
Occupational Health - Appointments, Accessibility

Updates have been made to ensure the hover-over tooltips in table rows have accurate name and role information. 


CCC-23118
Occupational Health - Appointments, Accessibility

Updates have been made to ensure that each visual label on a combo-box is programmatically associated with the correct control.

CCC-22062Occupational Health - Appointments

In the Appointments module, the state of the Outlook toggle now remains tied to each individual user, regardless of the browser used.

 

CCC-22606Occupational Health - Case Management

For an OH Case record, from the Case Notes tab, after specifying an activity, when the screen refreshes the cursor will now remain in the Activity field. Also, in OH Appointments, when selecting a Health Center, the cursor will now remain in the proper field.

 

CCC-23399Occupational Health - Clinic Visit, Billing

When opening the Cority-created ‘Clinic Visit Status’ (ML-000613) layout to create a custom version, by default the ‘Clinic Visit Status Type’ field will now be displayed under Available Fields.

 

CCC-22462Occupational Health - Clinic Visit, Billing

For HCFA forms available from within a Clinic Visit record, when applicable, the ‘Patient Account No’ field will now populate with the invoice number.

 

CCC-23096Occupational Health - Clinic Visit

Both the ‘Clinic Visit Progress Notes’ report and ‘Medical Records’ report now run successfully for the given employee and date range for date ranges that contain long notes, a lot of notes, and/or multiple clinic visits.

 

CCC-15487Occupational Health - Clinic Visit

On the Notes tab of a Clinic Visit record, the user can now click New and then successfully navigate away using the breadcrumbs without encountering an unexpected error.

 

CCC-22408Occupational Health - Clinic Visit, Reporting

When applicable, in Query Builder reports, Clinic Visit notes now display properly.

 

CCC-13259Occupational Health - Clinic Visit, Notes

For a Clinic Visit record, on the Notes tab, notes are now displaying properly.

 

CCC-16769Occupational Health - Clinic Visit, Smart Notes

A user can now successfully create a Clinic Visit ‘Note’, containing words with apostrophes, using the smart notes functionality with a questionnaire as a template. The note will display properly, and that workflow will no longer generate any unexpected errors.

 

CCC-21719Occupational Health - Employee Care

Views that have more than one row-level security permission applied now filter properly on Employee ID.

 

CCC-22956 and 22954Occupational Health - eRx

For electronic prescriptions (eRx), the following fields are no longer available (including through import) to users for editing:

  • User.EpcsInviteFromMedgate
  • User.EpcsStatus
  • User.SPIRoot
  • ScheduleAvailableTime.ServiceLevel
  • ScheduleAvailableTime.SPI

 

CCC-2889Occupational Health - Exam Activities

When an exam activity is completed using the ‘Mark all activities as complete’ action, its Due Date now displays where expected.

 

CCC-2996Occupational Health - Immunizations, Questionnaires

When creating or editing a questionnaire, and in the Questions section editing a record, the user can now select ‘ImmunizationCode’ for the ‘Map To Entity Field’ without encountering an unexpected error.

 

CCC-21017Occupational Health - Incident, Injury/Illness

For an Incident record that has multiple FRA records and a linked Injury/Illness record, a PDF on the Injury/Illness record will now download and open successfully.

 

CCC-23471Platform - Action Plans, Workflows

For all Action Plan workflows, the Workflow Status is now provided as a value for the Workflow Source.

 

CCC-23165
Platform Administrator - Settings, Accessibility

For configuration settings, updates have been made to ensure all interactive controls can be navigated to and operated by just the keyboard.

CCC-22582Platform Administrator

Where applicable, the License Key user counts are now correct.

 

CCC-20450Platform Administrator

Migrate Config will now successfully import a report configuration that contains a date range filter of date(s) relative to today without generating any unexpected errors.

 

CCC-4717Platform Administrator - Migrate Config

Where applicable, when using Migrate Config to export and import configurations with workflows, linked fields now transfer and populate correctly.

 

CCC-21651Platform Administrator - Migrate Config

When exporting a workflow configuration from one environment to another environment, the sequence of the steps will remain in the correct order regardless of any differences in languages between the environments.

 

CCC-23477Platform - Business Rules

When setting up a business rule that will use a previously created subquery (for the Safety Action Plan entity) to change the Description field value, if properly configured, the subquery will now appear in the list and be selectable.

 

CCC-15372Platform - Business Rules

A business rule, with a 'Modified By' 'Has Role' condition, that is exported then imported will now retain the condition and function properly.

 

CCC-19546Platform - Business Rules, Email

For a business rule (BR) email action with the ‘Enable HTML Formatting’ check box selected and before-update.html added to the email body, when the user gets the source for the HTML from the body by clicking on the View HTML tool from the editor, the original CSS class is no longer being replaced after saving the record.

 

CCC-23485Platform End-User - Bar Codes

Where applicable, the bar code value will now render properly.

 

CCC-22917Platform - Import Utility, Demographics

An issue that was causing an unexpected TreeMastercodetype.Code error when importing into the DT_LinkedDemographic data table using the Import Utility has been resolved.

 

CCC-11151Platform - Organizational Tree

If a user attempts to create a node under the Root level, an informative message, instead of an unexpected error message, is now displayed.

 

CCC-23305Platform - REST API

An Administrator with an API or Admin Role that has the treemaster.apiwrite granted action and with API Refresh Token can now successfully perform a REST API GET call for the token to be created and then a PUT call using that token to /api/treemaster/{ID}. The resulting treeconnector value will not be null and no unexpected errors will be generated.

 

CCC-22957Platform - REST API

A user with an API or Admin Role who has the treemaster.apiwrite granted action can now generate an API refresh token, use it with the REST API to create an access token, and then use the access token with the REST API to successfully make Treemaster post calls.

 

CCC-15017Platform - REST API

With the REST API, when performing a POST or PUT call into the /api/document endpoint, providing a base64 value into the documentblobdata will put an entry into the documentblob table and associate it with the Document record. Similar calls to the DocumentControlApprovalHistory endpoint will now correctly retain the blob information.

 

CCC-23273Quality - Inspections

When a Quality Inspection with questionnaire generates findings, the Finding records will now inherit the GDDLOFB from the Inspection record, as expected.

 

CCC-23430Quality, Safety - Risk Assessment

If a user creates a new Quality ' Design FMEA' or ‘Process FMEA’ record, saves it, adds a couple of entries to the ‘Failure Mode’ sublist, then selects Actions > New Version, the FMEA will now increment to the new next version and the Failure Mode records will copy over to the new version. An unexpected error will not be generated.

 

CCC-19044Questionnaires

For the Questionnaires look-up table, where applicable, the ‘Define Parent Branch Choices’ check box and feature now functions properly and will set up questions that use it properly.

 

CCC-22675Safety Audit - Findings & Actions

On a Safety ‘Audit’ record with the ‘Findings & Actions’ list on the main form, the ‘New’ button (create record functionality) will now initiate its workflow properly and that ‘New’ workflow can now be carried out successfully (whether or not the user populates any unnecessary fields) without generating any unexpected errors.

 

CCC-23173Safety Audits & Inspections

When an Inspection Report with questions that have no responses is generated, those questions will no longer have responses in the generated report.

 

CCC-18021Safety Equipment - Bar Codes, Work Permits

On a Safety Equipment record with the Barcode field, the popup now provides the ‘Work Permit’ check box, the barcode value now populates correctly, the user is able to modify the barcode value and save it, and the updated value will now display correctly.

 

CCC-19401Safety - Incident, MVA

When and where applicable, a user can now successfully delete an MVA record from an Incident record without encountering an unexpected error.

 

CCC-23280Safety - Incident, Questionnaires

When posting a questionnaire from the Questionnaire Inbox to an existing Incident, the smart search functionality is now provided and works properly.

 

CCC-22809Safety - Risk Assessment

On A Safety ‘Risk Assessment’, a user can now add duplicate controls and save without being redirected to the wrong record or generating any unexpected errors.
