Design Flaw Descriptions

The table below lists the design flaws we have addressed in 2025.2.0. The fixes are organized by module and the modules are arranged in alphabetical order.

Item #Component(s)Description
CCC-20340Ergonomics

The Personal Risk help text regarding RSIGuard has been updated.

 

CCC-18062Ergonomics

In the following Ergonomics reports, you can now filter by Employee Number and Employee Full Name:

  • Historical Risk report
  • Desktop Statistics
  • Employee List

 

CCC-285Platform - Administrator

For a business rule with advanced conditions, those conditions are now validated whenever the rule is saved. Also, if the business rule has date range conditions, save will now validate that both dates are provided.

 

CCC-21723 and 16696Platform End-User - myCority

In server.config, MaxLoadableTreeNodeChildren is to be used for configuring the maximum number of node children a tree can have for loading (expanding) in either GX2 or myCority. The default is 1000. If the limit specified is exceeded by a tree the user is attempting to expand (load), the tree will not expand and an error message will notify the user that the tree will have to be re-configured.

 

CCC-276Platform End-User

Dynamic forms now also support the following field types: Check Box, Yes/No Check Box, Multiple Choice Check Box, UDF Flag, UDF Look-up, Radio Button, Calculated, Date, Boolean, Note, DateTime, Rich Text Editor, Yes Or No, Chip, and Enum.

Note: This only applies to GX2. This will be addressed in myCority in a future release.

 

CCC-3114Platform - Interfaces

Using the REST API, a GET call of clinicvisitexamactivity without an ID now functions as expected. A list of Clinic Visit exam activities to which the user has access will be returned.

 

CCC-20247Quality

In the Quality 'Nonconformance' module, on layout ML-003208, the character limit for the 'Short Description' field has been increased to 250.

This also applies to all existing custom versions of that layout.

 

CCC-14342Quality, Safety - Audits & Inspections

The 'Quality Audit Questionnaire' entity has been added to business rules and business rule actions.

Note: The scheduled/recurrent trigger must be used because the insert, new, and update triggers will not respond to the system creating audit questionnaires.

The 'Quality Audit Questionnaire' entity is only for Inspection questionnaires that have not been started. It will exclude any that are in progress. For in-progress ones, a separate existing business rule is required.

 

CCC-21727Safety - Audits & Inspections, Findings & Actions, Questionnaire, myCority

In the out-of-box business rule BR-00096, Quality Audit has been added to the conditions. The method related to BRA-00096 now also considers Quality Audit.

In GX2, upon completion of a Quality Audit questionnaire with a question response that has a Finding Type with associated Action Type(s), both the Finding and the related Action(s) will be created.

 If a myCority user completes an assigned questionnaire from Quality Audit, the Finding and Action(s) will be created and available in the associated Quality Audit for a GX2 user to assign.

 

CCC-14999Safety - Audits & Inspections, Findings & Actions

In GX2, assigned questionnaires from the Audit solution (in the Environmental, Ergonomics, and Safety clouds) will auto-create any Finding & Actions.

Limitations:

  • The assigning  must occur within GX2.
  • Assigned questionnaires completed in myCority will not create Finding & Actions for the Formula Question Type.
    Note: This is a limitation for any currently auto-created within myCority.
  • If you are approving Audits, it is recommended you create a hard enforce BR for preventing this from occurring if either:
  • There are assigned questionnaires that do not have a Submitted Date; or,
  • There are Actions that are unassigned.

 

CCC-21591Safety - Audits & Inspections, Findings & Actions

From an assigned questionnaire that has a parent/source of Audit, if the user changes the selection for a Single Question that previously generated a Finding & Action(s) then saves the questionnaire, the associated Finding & Action(s) will now be deleted.

Note: Any attachments for that Single Question will remain on the Single Question in both myCority and GX2.

If the new response has a Finding Type associated, then a new Finding and related Action(s) will be created, along with any attachments.

 

CCC-14855Safety - Contractor Management, Import

When importing a Document (using the Import Utility or Data Integration Program), you can now associate it to a Contractor > Key Contact (e.g. Contractor Employee) as the parent source record.

 

This is handled through a new unique key ContractorContact.Id, which has been added to the DT_ContractorContact table. The equivalent field can be added to applicable layouts and the equivalent column can be added to applicable list views. The field is read-only.

 

CCC-15077Safety - Risk Assessment

In IH Risk Assessment, when using the 'Copy Process/Task' action for an item that has one or more duplicate additional current controls or duplicate additional future controls, those duplicates will now successfully copy.

 

CCC-15076Safety - Risk Assessment, myCority

In myCority, for an IH Risk Assessment, the workflow for adding future or current controls is now the same from the sublist view as from the layout (including if adding duplicates).

 

If both the additional future controls and additional current controls are on the same tab (for example, on an Additional Control Group), then a manual refresh of the list will be required to update all controls.

 

Note: This workflow update does not apply to the Task-Hazards-Control sublist of the Risk Master.
