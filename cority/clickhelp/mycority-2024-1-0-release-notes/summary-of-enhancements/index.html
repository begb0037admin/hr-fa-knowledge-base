Summary of Enhancements

The table below describes the enhancements we have made in 2024.1.0.

Item #Component(s)Description
CCC-15792Occupational Health – Pre-Placement Process

For the bypass registration workflow, the email with the myCority password that is sent to the applicant will now be stored in the Email Log. This will enable the recruiter to obtain that password if it must be re-sent to the applicant.

 

CCC-14536 and 14537Occupational Health – Pre-Placement Process

To start an application for an existing employee, a recruiter can now simply select the employee from the Employee picklist in the myCority questionnaire header.

The rest of the workflow remains the same.

 

CCC-15389Occupational Health – Pre-Placement Process

When the system setting for bypassing the applicant registration process is selected, the recruiter selects an existing employee from the Employee picklist instead of clicking the + symbol, and the recruiter changes the job and/or GDDLOFB on the questionnaire header before submitting the Employment Registration Form, then:

If the recruiter has selected an employee from the picklist who does not have a myCority ID, upon submission of the questionnaire a myCority user ID and password will be created automatically for the applicant.

Note: The applicant will still be sent the two emails that include his or her myCority credentials.

 

CCC-12886Occupational Health – Pre-Placement Process

In My Applicants, a recruiter can now view the status of his or her applicants.

  • Application email in queue – Indicates that the employee has been registered through myCority / selected from the associated picklist, and the application email will soon be sent by time-driven business rule.
  • Application email sent – Indicates that the application email has been sent to the applicant.
  • PPQ Saved – Indicates that the applicant has saved the Applicant Starter Questionnaire, but has not yet submitted it.
  • PPQ Submitted – Indicates that the applicant has submitted the Applicant Starter Questionnaire.

Also, a new read-only ‘Application Status’ field can now be added to custom versions of both the GX2 and myCority ‘Employee Job Position’ layouts. The field will populate automatically as outlined above.

 

CCC-14458Occupational Health – Pre-Placement Process

A new Letters tab (sublist) can now be added to custom versions of the myCority ‘My Applicants’ layout. The sublist has a default ‘Letters for this Job Position’ view with Letter Description and Created Date columns.

The recruiter will not be able to create or edit any letters on this sublist. This simply enables the clinician to send any necessary documentation (for example, the applicant’s Medical Clearance Certificate) back to the recruiter.

 

CCC-14194Platform – End-User

A user can now navigate more quickly between GX2 and myCority. For more detailed information, see the release note for CCC-14194 in the GX2 2024.1.0 New Features Release Notes document.

 

CCC-13311Platform – End-User

The user interface (lists, tabs, buttons, checkboxes, text fields, progress indicators, etc.) has a more consistent and polished look and feel. It also provides improved accessibility.

 

CCC-14799IH Risk Assessment

To the myCority home screen, the following two new icons can now be added:

  • IH Risk Assessment – Will open the GX2 IH Risk Assessment list view
  • New IH Risk Assessment – Will open the GX2 IH Risk Assessment layout

This enables a myCority user to quickly access the GX2 IH Risk Assessment feature set for creating and editing IH Risk Assessments.

Note: GX2 is not supported on devices smaller than a tablet.

The new ‘Return To Home’ button can be added to custom versions of IH Risk Assessment list views and layouts. The user can click that button to quickly and easily return to myCority.

This workflow does not support myCority offline functionality.

The user’s security configuration must have access to both myCority and GX2, and to the necessary IH Risk Assessment features and records. For example, the Portal checkbox on his or her User record must be deselected.

For information on working with IH Risk Assessments, custom list views and layouts, or security configuration, see the GX2 User Guide.
