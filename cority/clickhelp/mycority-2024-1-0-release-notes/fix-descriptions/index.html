Fix Descriptions

The table below describes the fixes we have made for 2024.1.0.

Item #Component(s)Reported VersionDescription
CCC-15859 and 15770Display RulesN/A

When two or more display rules are compatibly configured for the same field and their conditions trigger at the same time, that now functions properly.

 

CCC-8787Event ReportingN/A

For an Event Report created in either GX2 or myCority, a file with GPS information stored in properties can now be uploaded, regardless of how the GPS information is formatted.

 

CCC-11844Platform – End-UserN/A

When user confirmation (a valid pin) is required for obtaining myCority updates (for example, downloading new offline templates), that will now be enforced.

 

CCC-10622Platform – End-UserN/A

For employee fields (Person Involved, for example), searching by typing now functions as expected.

 

CCC-7893Platform – End-UserN/A

For picklist (look-up table) fields, searching by typing now supports commas.

 

CCC-11625QuestionnairesN/A

On a questionnaire in myCority, when 'Enable Branching' it set to false, that functionality now works as expected for child questions.
