Redis Setup

Setting up Redis is optional. Redis is used as the distributed cache of the application. By default, in-memory storage is used. The values for Redis and RedisInstanceName can be left blank if Redis isn’t required. If the Redis property does not have a password, it may be configured to only be accessible by our internal web servers.

In the same file, locate the following property and change the name of the Redis connection:

"Redis": "localhost:6379,password=123"
