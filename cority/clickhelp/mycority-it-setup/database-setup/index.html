Database Setup

In the appsettings.json file, locate the following property and change the server and database names:

"ConnectionStrings": {

"Default": "Server=SqlServerInstanceName;Database=DatabaseName;Trusted_Co nnection=True;"

}


Depending on the database permission set-up, you may also have to change  

Trusted_Connection=True to User Id=userid;Password=password

If the server has an instance name, an extra slash (\) will need to be added after the slash. For example, the server ‘SERV1\INSTANCE1’ would need to be changed to ‘SERV1\\INSTANCE1’).
