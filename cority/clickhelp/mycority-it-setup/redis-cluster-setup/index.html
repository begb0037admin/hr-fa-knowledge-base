Redis Cluster Setup

Redis clusters will help optimize your redis server architecture. Redis cluster setup is optional. If only one IIS server is configured, this section can be skipped. This section is only applicable when multiple IIS servers are configured. If only one IIS server is configured, Ruby does not need to be installed.

  1. Using the following URL, select Redis-x64-3.2.100.msi to download the Redis MSI: https://github.com/MicrosoftArchive/Redis/releases

  1. Once the installation is complete, the Redis will be installed in C:/Program Files/Redis.
  2. Using the same URL, select Source code (zip) to download the source code. Once the installation is complete, a source folder containing the contents of the ZIP file will be added to C:/Program Files/Redis.
  3. Install Ruby for Windows.
  4. In administrator mode, open a command prompt and enter the following command: gem install Redis

For clients that do not have an internet connection, use the following command: gem fetch Redis
This will retrieve a Redis gem. Replace X.X.X below with the version retrieved: gem install –local ./Redis-X.X.X.gem

  1. Create a Redis cluster that has six nodes across two workstations (three for each workstation - maspvm033, and maspvm033-c1, for example).
  2. Log into the first workstation (maspvm033, for example).
  3. Navigate to C:/Program Files/Redis and create a new folder called cluster-test.
  4. Open the newly created cluster-test folder and create three subfolders called 7000, 7001, and 7002.
    These folders represent the ports for the Redis cluster on the first workstation.
  1. Open each of the three subfolders and create a Redis.config file using the parameters below. Make sure you replace the port with the corresponding folder name and replace 7000 with the subfolder name.

port 7000

cluster-enabled yes

cluster-config-file cluster-test/7000/nodes.conf cluster-node-timeout 5000

protected-mode yes bind 0.0.0.0

dbfilename cluster-test.rdb syslog-enabled yes

syslog-ident Redis loglevel warning logfile ""

  1. Log into the second workstation (maspvm033-c1, for example).
  2. Navigate to C:/Program Files/Redis and create a new folder called cluster-test.
  3. Open the newly created cluster-test folder and create three subfolders called 7003, 7004, and 7005.
    These folders represent the ports for the Redis cluster on the second workstation.
  1. Open each of the three subfolders and create a Redis.config file using the parameters above. Ensure you replace the port with the corresponding folder name, and replace 700X with the subfolder name.
  2. Return to the first workstation (maspvm033).
  3. In administrator mode, open a command prompt and enter the following commands:

cd C:/Program Files/Redis

Redis-server –-service-install –-service-name Redis_cluster-test-7000 cluster-test/7000/Redis.conf

Redis-server –-service-install –-service-name Redis_cluster-test-7001 cluster-test/7001/Redis.conf

Redis-server –-service-install –-service-name Redis_cluster-test-7002 cluster-test/7002/Redis.conf

Redis-server --service-start --service-name Redis_cluster-test-7000

Redis-server --service-start --service-name Redis_cluster-test-7001

Redis-server --service-start --service-name Redis_cluster-test-7002

  1. The first three Redis services will be installed. Each will run in cluster mode on the corresponding port.
  2. Return to the second workstation (maspvm033-c1).
  3. In administrator mode, open a command prompt and enter the following commands:

cd C:/Program Files/Redis

Redis-server –-service-install –-service-name Redis_cluster-test-7003 cluster-test/7003/Redis.conf 

Redis-server –-service-install –-service-name Redis_cluster-test-7004 cluster-test/7004/Redis.conf

Redis-server –-service-install –-service-name Redis_cluster-test-7005 cluster-test/7005/Redis.conf 

Redis-server --service-start --service-name Redis_cluster-test-7003 Redis-server --service-start --service-name

Redis_cluster-test-7004

Redis-server --service-start --service-name Redis_cluster-test-7005

  1. The last three Redis services will be installed. Each will run in cluster mode on the corresponding port.
  2. Return to the first workstation (maspvm033).
  3. In administrator mode, open a command prompt and enter the following command, replacing maspvm033 with the name of the workstation.

The command prompt will display the IP address for the workstation.

  1. Repeat steps 20-21 to retrieve the IP address for the second workstation.
  2. In administrator mode, open a command prompt and enter the following commands, replacing 10.100.110.11 and 10.100.110.12 with the IP addresses for your respective workstations.

cd C:/Program Files/Redis/src

Redis-trib create --replicas 1 10.100.110.11:7000 10.100.110.11:7001

10.100.110.11:7002 10.100.110.12:7003 10.100.110.12:7004

10.100.110.12:7005

A cluster configuration prompt will display. Select Yes. The cluster is now ready.
