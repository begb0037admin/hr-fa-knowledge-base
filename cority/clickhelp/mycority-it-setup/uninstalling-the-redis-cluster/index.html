Uninstalling the Redis Cluster

  1. Login to the first workstation (maspvm033).
  2. In administrator mode, open a command prompt and enter the following commands, ensuring you replace ‘700X’ with the subfolder name.

cd C:/Program Files/Redis

Redis-server –-service-stop –-service-name

Redis_cluster-test-7000 Redis-server –-service-stop –-service-name

Redis_cluster-test-7001 Redis-server –-service-stop –-service-name

Redis_cluster-test-7002 Redis-server –-service-uninstall –-service-name

Redis_cluster-test-7000 Redis-server –-service-uninstall –-service-name

Redis_cluster-test-7001 Redis-server –-service-uninstall –-service-name

Redis_cluster-test-7002

  1. Log in to the second workstation.
  2. Repeat step 2.
