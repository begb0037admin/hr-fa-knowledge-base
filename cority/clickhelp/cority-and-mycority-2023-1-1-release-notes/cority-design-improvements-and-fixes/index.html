Cority Design Improvements and Fixes

The table below lists the design improvements and fixes we have made in the Cority 2023.1.1 release. The items are organized by component and the components are arranged in alphabetical order.

Item #Component(s)ReportedDescription
CCC-11778Business IntelligenceN/A

The performance of Query Builder dashboard indicators that use the Select Row Count option has been improved.

 

CCC-11504Business IntelligenceN/A

A Corrective Action (Finding & Action) record created from Emissions Inventory > Asset Management will now be available in Query Builder / Report Writer.

 

CCC-10899Business IntelligenceN/A

For a 'Drug Pool Employees' report, when you search for a drug pool, add it, and then run the report, the appropriate data will now be returned.

 

CCC-8467Business IntelligenceN/A

On a letter that uses a Query Builder subquery with conditional formatting, the conditional formatting will now render properly.

 

CCC-4981Business IntelligenceN/A

A filter added and saved to a query, report, or dashboard will no longer lose any of its parameters over time. This was occurring occasionally.

 

CCC-1905Business Intelligence2020.3.0

A user with the required permissions can now navigate from an Advanced Dashboard directly to a record without encountering an internal server error.

 

CCC-11109Environmental – Compliance N/A

Enhancements have been made to support ENHESA regional codes.

 

CCC-10742Environmental / Safety - ComplianceN/A

Any 'Compliance Obligations' created for either a Safety or Environmental Requirement record will now be available in Query Builder.

 

CCC-12196ErgonomicsN/A

For Office Ergonomics, on the 'Manage Employee Risk' screen, if the employee's 'Date of Termination' is set, an unexpected error is no longer generated.

 

CCC-11607ErgonomicsN/A

For Office Ergonomics, when applicable, the column labels on the 'Manage Employee Risk' screen will now translate properly.

 

CCC-10800Industrial HygieneN/A

In Industrial Hygiene, a user whose role does not permit the voiding of monitoring samples is no longer capable of that.

 

CCC-11135Occupational Health – Case Management N/A

GET calls for large letter templates now function properly.

 

CCC-3601Occupational Health - Case ManagementN/A

In Case Management, the auto-generated Absence 'Off Work' row now functions as expected.

 

CCC-10407Occupational Health – Clinic VisitN/A

When applicable, from within the Clinic Visit module, a TIF document with multiple pages will now print in entirety.

 

CCC-11631Occupational Health – Clinic Visit2022.3.2

In the Clinic Visit module, when a note is saved, HTML tags are no longer added.

 

CCC-10826Occupational Health – Exam ActivitiesN/A

For Exam Activities, the Complete status and ‘Date Completed’ are now both accurate when used in Query Builder.

 

CCC-12106, 11156, 11044Platform - AdministratorN/A

A number of potential security vulnerabilities have been addressed.

 

CCC-11760Platform - AdministratorN/A

After moving child nodes in an organizational tree, applicable associations, site security, and inactivating/activating now all function as expected.

 

CCC-11748Platform - AdministratorN/A

The Lodash JavaScript library has been upgraded to version 4.17.21.

 

CCC-11596Platform - Administrator2022.3.1

When a Finding entity business rule (BR) that has a BR Email action with 'Send in Background' on and a body or subject that contains the <<Action.ActionId>> merge field triggers on insert, the 'Action ID' on the new record will now populate.

 

CCC-11579Platform - Administrator2022.3.1

On a 'Change' business rule action that has a non-string field (date, look-up, Boolean, etc.) for the 'Property to Change', you can no longer select a Flex Field for the 'Field Reference'.

 

CCC-11578Platform - Administrator2022.3.0

A hard or soft enforce business rule configured to display a message when it fires will now display the correct message.

 

CCC-10281Platform - AdministratorN/A

A hard enforce business rule that will not allow a particular value to be provided for a field will now revert the field back to the previous value, as expected.

 

CCC-9535Platform - Administrator2022.2.1

A Display Rule created for Risk Assessment look-up tables that should filter based on the selection of a category will now function as expected even after working with / changing the category and/or task type.

 

CCC-9514Platform - AdministratorN/A

Microsoft Access Database Engine Redistributable has been upgraded to the latest version.

 

CCC-7828Platform - AdministratorN/A

An imported business rule email action with scheduled recurrence configured and a large amount of body text should now function properly.

 

CCC-3863Platform - AdministratorN/A

The Cority Notification System Email address system settings now function properly.

 

CCC-11954Platform – End-User2022.3.2

Previously, an administrator user could not change the question type for a single question if:

  • The single question was being used on a questionnaire

and

  • It had at least one child question linked to it on a questionnaire

 

This has been updated. Now an administrator cannot change the question type for a single question if:

  • The single question is being used on a questionnaire

and

  • It has at least one child question linked to it on a questionnaire

and

  • Any child question for it has a valid choice ID specified

 

CCC-11889Platform – End-UserN/A

For questionnaires that have one or more parent 'Normal Abnormal' type questions, child questions now all appear under the correct parent(s) and in the correct order.

 

CCC-11735Platform – End-UserN/A

For custom 'Management of Change' (MOC) and MOC 'Approvers' look-up table layouts, default field values can now be specified, as expected.

 

CCC-10748Platform – End-User2022.2.0

From an Environmental 'Risk Registry' record with the GDDLOFB populated, any new 'Findings & Actions' records created will now inherit that GDDLOFB automatically.

 

CCC-9860Platform – End-UserN/A

The Documents module now supports FTP links.

 

CCC-11975Quality – Management of ChangeN/A

For a 'Management of Change' record of the 'Chemical' type, when the 'Approved' workflow status is used in a workflow action, the action will now execute properly (and if applicable, the status will update and the chemical will move to the appropriate location).

 

CCC-11603Quality2022.3.2

For a Design FMEA workflow step, the workflow action button will now function as expected and without generating any unexpected errors.

 

CCC-10023Quality – Event Reporting N/A

The mapping for posting Quality ‘Event Reports’ (complaints and nonconformances) has been updated.

 

CCC-9532Safety - Audits & Inspections2022.1.0

On a Safety 'Inspections & Surveys' record with a recurrence frequency configured and a large number of assignees (280+), additional assignees/recipients can now be added.

 

CCC-12292Safety - IncidentN/A

When saving or executing the 'Post and create new incident' action on a non-posted Safety 'Event' record, or when saving a Safety 'Incident' record, an unexpected database timeout error will no longer be generated.

 

CCC-11108Safety - IncidentN/A

On the FRA (Federal Railroad Administration) F 6180.97 form, Box 8 is now editable.

 

CCC-7778Safety - IncidentN/A

For cloning PDF forms, the time duration allowed has been increased.

 

CCC-11473TrainingN/A

Users with the appropriate security configuration can now successfully import into the 'Online Training Sessions' data table without generating any unexpected errors.
