myCority Design Improvements and Fixes

The table below lists the design improvements and fixes we have made in the myCority 2023.1.1 release. The items are organized by component and the components are arranged in alphabetical order.

Item #Component(s)ReportedDescription
CCC-12100Event ReportingN/A

An 'Event Report' with one or more attachments can now be saved and submitted as successfully and without generating any unexpected errors.

 

CCC-11007ImmunizationN/A

When submitting an Immunization record, the Employee value will now clear regardless of whether or not the 'Lot #' value is provided.

 

CCC-11869Inspections & SurveysN/A

The BRA-100426 TDBR now functions properly, and its performance has been improved. It now ignores inspection profiles with an End Date earlier than the current day’s date.

 

CCC-11576Inspections & SurveysN/A

When the finding details for an action created on an Inspection/Survey are being viewed in myCority, if there are a lot of details, the content displayed will now be limited to 500 characters so at least those characters all display.

 

CCC-8861Inspections & SurveysN/A

Each Inspection record now has an Information icon that provides access to read-only information from My Tasks for confirming the inspection questionnaire is the correct one.

 

CCC-3957Management of Change, Findings & ActionsN/A

From a 'Management of Change' (MOC) record in myCority, if questionnaire answers auto-create 'Findings & Actions' records, those new records will now inherit the organizational tree assignments from the original MOC record, as expected.

 

CCC-11401Questionnaires2022.3.2

When a questionnaire that has one or more HTML tags in a string field (text, text area, for examples) is saved, the HTML tag(s) will now be removed without having to refresh the screen.

 

CCC-11893Workflows2023.1.0

When the workflow status gets changed, if applicable the workflow action will now also change without the user having to refresh the screen.
