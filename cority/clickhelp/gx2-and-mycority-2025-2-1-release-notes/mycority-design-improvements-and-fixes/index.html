myCority Design Improvements and Fixes

The table below lists the design improvements and fixes we have made in the myCority 2025.2.1 release. The items are organized by component and the components are arranged in alphabetical order.

Item #Component(s)ReportedDescription
CCC-17145BI - DashboardsN/A

Where applicable, on a dashboard in myCority, the user can now adjust the column width.

 

CCC-15453BI - DashboardsN/A

When applicable, for dashboards in myCority, percentages will now display on pie charts.

 

CCC-1504Event Reporting - Injury/IllnessN/A

When applicable, for an Injury/Illness Event Report, when the Employee Involved is added, that employee's saved phone number will now auto-populate.

 

CCC-13219InspectionsN/A

When applicable, on a myCority Inspection questionnaire, information about the Asset Association (Equipment) and/or Asset Group (Equipment Group) will be reflected in the Info Summary, matching what is shown in My Tasks.

 

CCC-12412Maps - Near MeN/A

In myCority 'Near Me', the blue dot is no longer clickable and now provides descriptive hover-over text. Attempting to click it will no longer generate an unexpected error.

 

CCC-5526OH - ImmunizationN/A

When applicable, if an 'Immunization Code' is selected in myCority 'Immunizations', the 'Immunization Route' will now auto-populate.

 

CCC-18952OH - Management Referral QuestionnaireN/A

For questionnaires (Management Referral, for example), the mandatory fields, save, and submit functionality now all work as expected.

 

CCC-22616OH - RecruitmentN/A

Business rule BR-100641 has been updated to ensure the functionality for emailing applicants a link to the Starter Questionnaire to bypass myCority registration now works as expected.

 

CCC-21249OH - RecruitmentN/A

For the recruitment functionality in myCority, an issue where some emails to applicants were not getting sent and retained a status of 'Application in queue to be sent', even though everything was set up correctly, has now been resolved. 

 

To address this, we have made changes to the BR-100641 and BR-100583 business rules (BRs). If you have created a custom version of either or both of those, you will have to re-create them from the new Cority versions.

 

To do that:

  1. Inactivate or delete your custom version(s).
  2. Clone the new, updated version(s).
  3. Make the necessary changes to your newly created custom version(s).
  4. Inactivate the Cority version(s) once your new custom version(s) are running successfully.

 

CCC-20742Platform End-User- EmailsN/A

For email addresses with top-level domain (TLD) longer than three characters, the myCority 'forgot password' functionality now works properly.

 

CCC-22755Platform  End-User - LoginN/A

When applicable, after successful Microsoft Azure authentication, login and logout with SAML SSO and user/password functions properly as does navigation between GX2 and myCority with SAML SSO.

 

CCC-20848Platform  End-User - Login2024.3.1

At login, myCority is now handling IP addresses correctly. It is storing the public IP address of the user correctly in logs and is now in sync with GX2.

 

CCC-10926Platform  End-User - LoginN/A

An issue that was breaking the myCority password reset link has been resolved.

 

CCC-22186Platform End-User - My ResourcesN/A

To enhance accessibility, in line with WCAG, additional labeling and instructions have been added in myCority 'My Resources'.

 

CCC-22521Questionnaires, Corrective ActionsN/A

When a questionnaire with a large number of questions that will auto-create corrective actions based on their answers is submitted using myCority and then from the Questionnaire Inbox is posted to the applicable Equipment record, the questionnaire will now post successfully and all of the corrective actions will now be created successfully.

 

CCC-21806Questionnaires, TranslationsN/A

Questionnaires that are translated (for example, into Simplified Chinese) will now remain translated when downloaded to PDF.
