CCC-21768BI - ReportingN/A

The Query Builder > More Settings > Export panel and Report Writer > Formatting tab both have a new drop-down field labeled 'Wrap report columns with high character count'.

 

It provides the following three options:

  • Same as System Setting - This is the default, and it will use the option specified in the system setting 'Wrap report columns with high character count' for the export behavior.
  • Wrap Text - For the export, in columns with text that exceeds the column width, the text will be wrapped so that the content appears on multiple lines.
  • No Wrap - For the export, in columns with text that exceeds the column width, the text will remain on a single line. This could result in hidden or truncated text, requiring the user to manually expand the column to see it all.

CCC-21693
Environmental - Chemical Management
N/A

The ‘Refresh Chemical Content’ action can now be scheduled using a business rule.

To do this, create a new business rule method action or use the existing BRA-100606 in a scheduled business rule. The entity for the method action and business rule will be Chemical Product and the method is RefreshChemicalContentAction.

For example, the following configuration parameters could be used:

  • Business Rule Action: RefreshChemicalContentAction
  • Condition: ID = 1 ( check that the Chemical Product with ID 1 exists before scheduling)
  • Scheduled/Recurrent: Selected
  • Start Date: Today’s date
  • Start Time: 1:00 AM
  • Recurrence: Every 1 day(s) with no end date
