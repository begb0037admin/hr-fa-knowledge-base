Fix Descriptions

Item #Component(s)Reported VersionDescription
CCC-6996Audits and Inspections2021.3.2

Inspections now filter properly by enrollment date(s) and active/inactive status.

 

CCC-4195Chemical Management2021.2.0

On a Chemical Product record that has multiple related SDSs with links, for the SDSs, the Inactive setting now functions as expected.

When editing a Compliance Action, on the Documents tab of the ML-002065 layout (or custom versions of it), the + icon for adding documents is now provided and working as expected.

For the Health Essentials package, in either GX2 or myCority, when the employee changes the consent status on the management referral response questionnaire to Consent Provided and submits, the OHC1-MANREF-CONSPROV business rule will fire, sending the notification email to the supervisor and updating the 'Share with Supervisor' check box to selected.

 

CCC-6644PlatformN/A

The system setting for configuring privacy agreement content now functions as expected.

 

CCC-6209PlatformN/A

A guest user is now no longer able to access records created by previous guest users.

 

CCC-5521Platform - QuestionnairesN/A

For a questionnaire completed and submitted using myCority, when opened from the Inbox in GX2, the expected employee fields will now be populated.
