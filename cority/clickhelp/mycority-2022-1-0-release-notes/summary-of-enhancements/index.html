Summary of Enhancements

The table below describes the enhancements we have made in 2022.1.0.

Item #Component(s)Description
CCC-4068 and 3253Employee Care – Occupational Health

There is a new pre-employment, recruitment process. For configuration and workflow information, see the release note for CCC-4068 and 3253 in the Cority 2022.1.0 New Features and Fixes Release Notes document.

 

CCC-6821Platform – Administrator

The performance of the myCority form cache has been improved.

 

CCC-6775 and 4518Platform

For the Employees picklist, everywhere it occurs, custom views can now be created and saved.

 

CCC-3386
Platform - End User
If the user is assigned a profile, that profile has a questionnaire on its myCority Questionnaires tab (sublist), and the 'Display questionnaire as a button in myCority' setting for that questionnaire is selected, the questionnaire will then be displayed as a button within myCority.
If the user has not been assigned a profile, any questionnaire based on profiles for which the ‘Display questionnaire as a button in myCority’ is selected will also display as a button within myCority.
Note: If the user has been assigned a profile that does not have any questionnaires added to its myCority Questionnaires tab, then any questionnaires with the 'Display questionnaire as a button in myCority' setting selected will not be displayed as a button for the user. This is a bug and will be fixed in an upcoming release.

CCC-4571Platform – End User

The new 'Secondary Email' field can now be added to custom versions of the myCority ‘My Account’ layout. The field will enable users to provide, and receive email notifications to, a secondary email account. Note: The 'Allow Portal/myCority users to change their email and home address information' applies to this field.
