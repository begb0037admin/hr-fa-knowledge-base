Survey Properties

The tabs provided differ depending on whether Survey Properties is opened from within an existing survey or while creating a new survey.

  • To create a new survey and fill out the Survey Properties, click New.
  • To access survey properties for an existing survey, right-click the survey name and select Properties.

Details Tab

Field
Use
Name

Name of the survey visible to anyone using it.

Description

Additional information, visible only within survey configuration.

Auto-Order Charting Forms

For selecting an Exposure Protocol (group of charting forms) that can be auto-ordered once the survey is submitted. Additional configurations is required within the survey.

Program Type

Only used for HRA (Health Risk Assessment) surveys. Leave this blank in surveys other than HRA.

Hide All Groups

If selected, groups within the survey will be hidden by default. It is best practice to leave this unselected.

Jobs Tab

The Jobs tab will only be visible by organizations that have the Jobs functionality enabled. This is typically only for clients with multiple regions or partitions. If you do not see the Jobs tab, you do not need to be concerned about any configurations here because everything will be done for you automatically.

  1. The Jobs tab only appears if you have the feature enabled. Most organizations do not use this.
  2. After saving the Survey Details tab, the Jobs tab will be enabled to view and edit.
  3. By default, all jobs will be selected. Typically, jobs reflect a partition or region.
  4. If you do not want the survey available to be ordered for participants (and only those with a particular job setting), de-select the job(s) for which you do not want it available using the box next to each description.
  5. Once complete, save and close.
  6. A job cannot be removed from the survey once it has been published. Submit a Helpdesk ticket for assistance, if necessary.
  7. One or more jobs must be assigned to the survey prior to publishing. You will receive an error message if you try to publish a survey without a job assigned to it.

Event / Associated Tests Tab

The Event / Associated Tests tab becomes available once the survey has been saved. Adding an Exposure Test (Charting Form) on this tab will make the survey available to Event Manager users on the Event Manager tab and will provide Event Manager users with the Charting Form that is selected from the Exposure Test (Charting Form) list.

  1. Click the Event / Associated Tests tab.
  2. If an exposure test / charting form has already been associated with the survey, it will appear in the list.
  3. To add a new test / charting form, click New and select the desired test from the list.
  4. Only one survey can be associated with each test / charting form.
  5. You can associate multiple tests / charting forms with one survey.
  6. If you do not have any tests / charting forms listed here, the survey will not be available in Event Manager.

Meta Tab

The Meta tab also only appears after the survey properties have initially been saved. This tab is simply used to view changes that have occurred over time, including:

Section
Details

Published Form

Date and time stamp when the survey was published

Survey

Survey ID: Unique identifier automatically assigned to the survey

Creation Date: Date and time stamp when the survey was created

Created By: User name of the user who created the survey

Last Updated Date: Date and time stamp of the last save

Last Updated By: User name of the user who performed the last update (save/publish)
