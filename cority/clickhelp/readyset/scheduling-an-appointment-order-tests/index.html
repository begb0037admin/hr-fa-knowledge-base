Scheduling an Appointment and Ordering Tests

In EHS Manager, you can schedule appointments and order tests for participants. 

To schedule an appointment and order tests: 

  1. Select the EHS Manager tab.
    You will be at the     Home/Calendar view.
  2. On the Participant Management tab, search by Last Name, First Name, or by any option.
  3. Click Search.
  4. Click the Edit icon to open the record.
    The Medical Chart will open    . 
    Note: Before ordering tests, view the participants Medical Considerations (see Viewing Medical Considerations).
  5. Choose Order Tests in the left menu.
  6. Select a Visit Type from the different program types or the Protocol which displays the charting forms by grouping, for example, all charting forms associated with Hepatitis A.
  7. Select the checkbox(es) to select desired tests or click Select All at the top of the list.
  8. Select the Location at bottom of the screen.
  9. In the Contact field, select the correct calendar.
  10. Select the Calendar Picker and choose appointment date and time by clicking on Click to Book at the date and time selected.
    This will return you to the previous screen.
  11. Click Assign To Above Tests, click OK to Updated Tests box.
  12. Click Order Selected Tests.
    A message, “The selected tests have been ordered.”, will display.
  13. Return to Home/Calendar view on the primary navigation menu and the appointment will display on the Provider’s calendar at the date and time selected.

Rescheduling Exams/Charts/Tests

  1. Search and select desired participant from the Participant Management on the primary navigation menu.
  2. Choose Edit Appointments from the menu on the left.
    The screen opens to Exam Groups by Appointment dates.
  3. Click on the correct date to view the forms.
    This opens a region on the right side with all tests attached to that date.
  4. Click the checkbox next to the charting form(s) that need to be rescheduled.
  5. Click the Reschedule icon.
    This open a dialog box that will allow you to edit the Location, Provider or Date/Time.
  6. Select your new date/time and click Save.
