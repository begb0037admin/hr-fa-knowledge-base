Appointment Status Indicator Icon

Client admin users can add and edit Appointment Statuses Indicator Icons using five different icons , and seven different colors (red, orange, yellow, green, blue, white, and black).

This functionality can be made available through a request to the Support team.

Only Client Admin users can add or edit “Appointment Status Indicators icons”. Since Individual users can set the color of their calendar, they will need to ensure the color used for their calendar does not match the colors set for Appointment Status Indicators.

Client Admin users can edit or delete Appointment status except for hard-coded “Appointment Statuses” such as “Booked” or “Cancelled”. These appointment statuses have several different functionalities associated with them across the application.

Each icon can be associated with more than one appointment type. For example, users can choose to use one icon with 7 different colors to indicate an appointment status.

When the status of an appointment changes, the colored icon will update accordingly providing users a visual indication.

After an appointment status has been updated, the user will have to reload the page so that the associated appointment status indicator is reflected on either the calendar or the whiteboard views.

The icons are visible:

  • On the Calendar/Schedule view in split, day, week, & month layouts.
  • On the Whiteboard view or in Appointment view in a new column next to the appointment status

The Whiteboard view, and Appointment view are only available to clients who have this view. 

  • Next to the self-scheduling icon if it is in use by the client.
