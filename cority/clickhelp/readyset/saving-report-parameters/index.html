Saving Report Parameters

To Save Report Parameters:

  1. Click the Reports tab on the horizontal navigation panel. 
  2. Click the Custom Reports tab in the horizontal navigation panel below. 
  3. On the Filter Criteria section, click the Add  icon to the right of any desired filter criteria (see Custom Reports).
  4. Once the Search Criteria is filled in, the Save As My Report button is enabled.
  5. Fill in the Reports Name textbox. 
  6. Click Save As My Report.
    The "Select the folder you want to save the report to" window opens. 
  7. On the "Select the Folder you want to save the report to" window, you can either select an existing folder or create a new folder to save the report in:



    1. To select an existing folder, click an existing folders listed. 
    2. To create a new folder
      1. Click +New Folder Reports.
        1. On the New Folder prompt, fill in the Folder name in the Textbox. 
        2. Click OK.
    3. Once a folder has been selected, click Save to Selected Folder.
      The report is now saved.
