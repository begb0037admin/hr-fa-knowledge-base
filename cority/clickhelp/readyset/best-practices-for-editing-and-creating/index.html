Best Practices for Editing or Creating Custom Surveys

It is best to edit when:

  • Only altering a small number of questions
  • Making only slight changes to question wording that does not alter the intent or meaning of the question
  • Making changes to surveys that are already configured as part of visit types, communications, or Event Manager access and you do not want to replace them with new surveys
  • Comfortable using Custom Reports instead of Standard Reports to report on any added questions

It is best to create when:

  • A similar survey does not already exist
  • Making significant changes to question wording that alters the intent or meaning of the question
  • Desiring multiple versions of the same survey
  • Comfortable adding the survey to any visit types, communications, and Event Manager as needed
  • Comfortable using Custom Reports instead of Standard Reports to report on survey contents
