Health Risk Assessment (HRA) Surveys

HRA surveys have the following unique configuration attributes:

  • Within Survey Properties > Details > Program Type, the 'HRA' option must be selected from the drop-down list.
  • There is an additional tab titled 'Program Period' on which a start and end date must be configured.
  • There is an additional question type called Table', which cannot be edited.
  • There is the option to add Notification text within the Answer Properties Details.

Adding or Editing Program Periods

A program period can be added to an HRA survey. A program period is used for outputting the data in Standard Reports.

To add or edit a program period:

  1. Right-click the name of the HRA survey and select Properties.
  2. Click the Program Period tab.
  3. Click New to add a new program period or Edit to edit an existing one.
  4. Enter the start and end dates you want.
  5. Enter a description.
  6. Click Save.

Removing a program period is not recommended. It is best to create a new one, without removing the old one.

If you choose to remove a program period:

  • A warning message will display asking if you want to proceed.
  • Reporting will no longer be available for the survey.

Best Practices for Editing an HRA Survey

It is best practice to make changes within the existing HRA survey rather than create a new one if the table that displays biometric data is required or if Standard Reports will be used.

The following additional best practices should be considered:

  • The table that appears at the top of the HRA survey is hard-coded to pull in data from specific questions and perform calculations based on that data. Therefore, it is recommended you do not alter in any way questions that generate data for that table.
  • Questions can be removed, but be aware that could impact what is included in the table.
  • It is recommended you do not change the meaning of the questions or any associated answers.
  • Questions and answers can be added to the survey, however data from additional questions and/or answers will not be included in the table or in the HRA Report Letter.
  • Ensure a program period is used/present, and do not remove an existing program period.
