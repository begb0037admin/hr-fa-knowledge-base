Creating Email Distribution Lists from ReadySet Reports

ReadySet allows authorized users to create email distribution lists from ReadySet Reports with specified criteria. Distribution lists can be uploaded to a C3 Mass Email or Initialize Program Notification, making it easier to send out notifications to targeted audiences.

Before You Begin

  • The report must be a .csv report (usually denoted in the name as “Details” report)
  • You must output Participant ID in the report.
  • The column heading name in the .csv file must be PARTICIPANT_ID
  • Your final .csv file can have only one column named PARTICIPANT_ID (data anomalies, such as spaces, dashes or hyphens, may prevent your spreadsheet from uploading).
  • You cannot use a file in Excel (.xls or .xlsx) or another format (.docx).
  • You cannot change the file extension from another format (e.g. .xls) to .csv
  • There is no limit on the number of participants in a distribution list.

What You Can Do With This Feature

There are many cases where EHS may want to create a distribution list to email a large group of participants. For example, if you would like to send a reminder notice to everyone who has a follow up vaccination next month. In ReadySet, you will create a report with this information, including Participant ID, save the information in .csv format to your computer, and then upload it to a C3 email reminder notification that you have created.

Creating a Distribution List From a ReadySet Report

  1. On the Reports tab, click Standard Reports.
  2. Select the report that you wish to generate a distribution list for.

    The report must be in .csv format (usually denoted in the name as “Details” report).

  3. Select your Filters.
    You may not want terminated workers in your distribution list. You may want to filter on:
    • Specific employment statuses (e.g., Active and/or Leave of Absence)
    • Specific population types (e.g., employees only)
    • Compliance status (e.g., due current month).
  4. Select the Columns you wish to output.

    You must include Participant ID.

  5. Run the report, download it and save as CSV file format.

    The distribution list will only load if the column heading is PARTICIPANT_ID.
  8. Save output as .csv file format.

    Do not save or change the file to an Excel (.xls or .xlsx) or another format. The distribution list will only load if it is .csv file format.

  9. Upload your distribution list to your C3 notification.
  10. Create a notification in either Mass Email or Initialize Programs and click Save.
  11. On the Recipients tab at the top of the notification, click Upload CSV.
  12. Click Select a File.
  13. Navigate to your .csv file and click Upload.

    The distribution list will upload into the notification recipients list.
  14. Send or Save and Close the notification.

If you have more than one distribution list that you wish to upload into the same notification, you can repeat the above process to add participants to the list. If the participant already exists in the list, a duplicate will not be created.

Troubleshooting Error Messages

If any of the following conditions exist, you may receive an error message and your file may not upload:

  • file is not a .csv
  • you changed a .xls or .xlsx file extension to .csv
  • PARTICIPANT_ID is not in the file or is incorrectly named
  • you have columns other than PARTICIPANT_ID in your .csv file.
  • a Participant ID is not in your ReadySet system.
