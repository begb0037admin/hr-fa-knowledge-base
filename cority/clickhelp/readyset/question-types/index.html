Question Types

The following question types are supported:

Check Box

  • Allow just one answer per question

Radio Button

  • Provide the participant with multiple answers from which to choose
  • Allow only one answer to be selected
  • Should be used if the group has been set to 'Question in Title'
  • Must be used to open a hidden group
  • Must be used for advanced auto-scheduling configurations

Date

  • A minimum date value can be set to require participants to enter a date after that one, or a 'today minus X days' value can be set to require participants to enter a date by a certain number of days from today
  • Useful if the date should not be a historical one, or if there is only a certain acceptable time frame

Number

  • Within Number questions, the number of decimals accepted can be specified, as well as a maximum and/or minimum value

Integer

  • Within the answer properties of an Integer question, a format code can be specified in the 'Time/Number Answer Format' field
