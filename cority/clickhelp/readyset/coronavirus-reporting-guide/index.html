Report Features

  • Create and save your own report templates.
  • Schedule reports to autorun.
  • Share a downloaded report with those that have EHS Manager access.
  • Must have access to the Report tab.

All reports are found under the Reports > Standard Reports. Below are suggested criteria for setting up your Coronavirus reports. This includes filter Selection Criteria, Columns for output, and Auto Scheduling settings. Also included on some items, instructions on what to do with the report results.

You can select the desired Selection Criteria and/or Column outputs to give you the intended report results or use the default criteria that is pre-selected for you.

Saving a Report Template to My Reports

  1. Go to Reports > Standard Reports.
  2. Select the report needed.
  3. Make your selections.
  4. Click Save As My Report to save the report template to your My Reports.
    1. Select New Folder. If the folder already exists select the folder and save to that folder.
    2. Enter the Name of the Folder, e.g. COVID- 19.
    3. Click OK.
    4. Click Save to Selected Folder.

Setting Up a Schedule for the Report to Autorun

To schedule a report to autorun, the report must be in your My Reports.

  1. Go to Reports > My Reports.
  2. Select the folder/report to open.
  3. Click the Schedule tab in the right panel.
  4. In the Common Settings drop down, select the appropriate setting.
    For example, "Once a week" will run at midnight every Sunday.
  5. Click Save.

Go to My Reports to make any edits or changes to a saved template.

Available Reports

COVID-19 Staff Exposure Survey

This report will provide the survey status, all survey answers, creation date and completion date.

  1. Go to Reports > Standard Reports >  Programs > COVID-19 > COVID-19 Staff Exposure Survey.
  2. Edit the Report Name – COVID-19 Exposure Survey and add the date (or what makes sense to you).
  3. Selection Criteria: Select "Employment Status – Active" and "Leave of Absence", and any other criteria as needed.
  4. Column Outputs: You can output all items available or select only the items wanted. Recommended outputs:
    • Participant Identifiers:
      • Participant ID
      • First & Last Name
      • Job Title
      • Job Category
      • Employment Status
    • General Information – select any needed items:
      • Occupation
      • Dept
      • Population Type
      • Supervisor
    • Survey Results, Reason for Survey, Close Contact, PPE, Symptoms: select all or the data needed.
  5. Click Run Now for an immediate report.
  6. Click Download Reports to view the report results.
  7. Recommendation: Add to your My Report:
    • Set up to Auto Schedule.
    • Common Settings = Once a Day.
  8. Review the data and follow-up as necessary.

Temperature and Symptom Tracker

This report will output all tracked temperatures and symptoms entered by participants.

The Temperature and Symptom Tracker will have a status of Incomplete until the participant has select Submit Final at the end of tracking symptoms. Do not search only for a status of complete because you need to see the data as they enter the information.

  1. Go to Reports > Standard Reports >  Programs > Ebola Virus Disease >  Exposure > Symptom and 21-Day Symptom Survey.
  2. Edit the Report Name – "Temperature and Symptom Survey".
  3. Selection Criteria: Select "Employment Status – Active" and "Leave of Absence".
  4. Column Outputs: You can output all items available or select only the items wanted. Recommended output listed below:
    • Alert Status.
    • Participant Identifiers:
      • Participant ID
      • First & Last Name
      • Employment Status
      • Job Title
      • Job Category
    • General Information – select any needed items:
      • Occupation
      • Dept
      • Population Type
      • Supervisor
    • Exposure & Symptoms Survey Results - select "None".
    • 21-Day Symptom Survey Results.
      • Select "All".
      • You can deselect from Day 15 – Day 21.
  5. Click Run Now for an immediate report.
  6. Click Download Reports to view the report results.
  7. Optionally, add to your My Report:
    1. Set up to Auto Schedule.
    2. Schedule for 'Once a Day'.
    • Next Steps:
      • Filter Alert Status column to “Alert”, these are the participants who have a temperature at or above 100.4 or symptoms.
      • Filter Alert Status column to “Blank”, these are the participants who have a normal temperature and no symptoms.

    Incident Details

    This report will output all details for incidents created under the Incident tab. Use this report only if using the Incident tab to track multiple participants exposed to COVID-19.

    1. Go to Reports > Standard Reports > Health & Safety >Incident > Incident Details.
    2. Edit the Report Name – Enter an appropriate title for the report.
    3. Selection Criteria:
      • Enter the Incident ID if you only want the details for that incident.
      • Select the Incident Type – Coronavirus.
      • Select Incident Date Range, you can enter just the start date.
    4. Column Outputs: You can output all items available or select only the items wanted. Recommended output listed below:
      • Incident Information. Select "All".
      • Injured/Witness Information. Select "All".
      • Survey Information. Select "All".
      • Test Information. Select "All".
      • Demographic Information:
        • Participant ID
        • First & Last Name
        • Employment Status
        • Corporate HR ID
        • Dept
        • Population Type
        • Supervisor
        • Job Title
        • Job Category
        • Occupation
    5. Click Run Now for an immediate report.
    6. Click Download Reports to view the report results.
    7. Optionally, add to your My Report:
      1. Set up to Auto Schedule.
      2. Schedule for the appropriate cadence.
