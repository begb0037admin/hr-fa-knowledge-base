Provider Tests

Allows you to add new test/charting forms to the Order Tests process, inactivate or activate test/charting forms listed for the location.

Add New Charting/Testing Forms

  1. Choose Client Admin > Provider Locations.
  2. Select the location that you want to add a chart/test form, by clicking the Edit icon.
    This will open a Provider Location dialog box displaying three tabs.
  3. On the Provider Tests tab, click Add New. 
    This opens the Add Provider Client Tests.
  4. Select the correct Client Site.
  5. Select the checkbox beside each form that you want to add, or select the top box to select all.
  6. Click Add Tests.

Activate Selected/Inactivate Selected Tests

The Provider Tests options of Activated Selected and Inactivate Selected allows reactivating or inactivating a charting/test form.

  1. Choose Client Admin > Provider Location.
  2. Click the Edit icon for the correct location.
  3. On the Provider Test tab, select the checkbox for the charting/test form to be activated/inactivated.
    You may need to click Show Inactive to display the inactive forms.
  4. Click Activate Selected or Inactivate Selected as appropriate.
  5. Click Save.
