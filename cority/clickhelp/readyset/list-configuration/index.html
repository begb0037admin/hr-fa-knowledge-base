List Configuration

Use List Configuration to add, edit and inactive options available in specific dropdowns located in the Case Mgmt./WC tab, EHS Manager tab and Surveys.

Adding a New Option

  1. Choose Client Admin > List Configuration.
  2. Select the folder for the group.
  3. Click New to add options.
  4. In the Active field, select "Yes".
  5. Enter the Name.
  6. Click Save Changes.

Inactivating or Activating List Configuration Items

  1. Select the checkbox and then click the appropriate option.
  2. Select the Show Inactive Entries checkbox to display items already inactivated.
