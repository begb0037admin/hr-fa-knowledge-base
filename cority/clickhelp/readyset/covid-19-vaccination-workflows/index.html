COVID-19 Vaccination Workflows

Use this document to assist with planning your COVID-19 vaccination program. The program consists of a COVID-19 (SARS_CoV_2) Immunization Survey, COVID-19 (SARS_CoV_2) Immunization Record and Reporting.

Before you begin

  • The charting form will be auto ordered when survey is completed, unless the participant declines to receive vaccine.
  • The charting form will be auto ordered to Event.  If you have multiple event calendars, you will need to alert Support as to the Event calendar you prefer.

High Level Workflow

  1. Create Communication Template.
  2. Create Distribution List.
  3. Launch using C3/Initialize Program.
  4. Vaccinate using Event or EHS Manager.
  5. Use Reports to find those who declined the vaccination. Use Order Forms to batch process those that declined.
  6. Use Reports to create second dose distribution list.
    • Launch using C3/Initialize Programs if you want the participant to complete a new survey.
    • Vaccinate using Event.

Event Workflow Setup

  1. Set up a notification template in Client Admin > Communication > Template:
    1. Click New.
    2. Enter a Description.
    3. Select the Email Template checkbox.
    4. Select the Include Survey(s) checkbox.
    5. Enter the Subject.
    6. Enter the instructional text.
    7. Click Save.
    8. Click the Survey(s) tab.
    9. Click New.
    10. Select the checkbox in front of the desired survey(s).
    11. Click Submit.
    12. Click Save and Close.
  2. Launch program
    1. Go to C3 > Initialize Programs.
    2. Click New Notification.
    3. Initialization Method – "Initialize Program with Email".
    4. Communication Template – Select the desired template.
    5. Select From.
    6. Subject and Message will display the template and message information created in the template.
    7. Click Save.
    8. Click the Recipients tab.
    9. Use either Upload CSV (see below for creating a distribution list) or use the Add Employee(s) option.
    10. Click Send. 
      This launches the email and turns on the survey for all listed.

Create a Distribution List from a ReadySet Report

  1. On the Report tab click Standard Reports.
  2. Select the report that you wish to generate a distribution list. 

    The report must be a .CSV report (usually denoted in the name as “Details” report).

  3. Select your Selection Criteria carefully. You may want to filter on:
    • Specific employment statuses (e.g. Active and/or Leave of Absence)
    • Specific population types (e.g. employees only)
  4. Select the Columns you wish to output.

    You must output at a minimum Participant ID (aka Axion ID).

  5. Run the report, download it and save as CSV file format.

Reports Related to the COVID-19 Vaccination

  • COVID-19 Immunization Details Report – outputs all data charted in the COVID-19 immunization charting form
  • COVID-19 Immunization Survey Report – outputs all data completed by the participant in the COVID-19 Survey
  • COVID-19 Titer Details Report – outputs all data charted in the COVID-19 Titer charting form
  • Vaccination Details – Use the create distribution lists from Next Due Date for the COVID-19 Immunization
