Using the Compliance Report to Quickly View Compliance Status

The Compliance Report allows you to display the compliance status and next due date for all participants in an organization. You can use the normal demographic parameters filters of supervisor, location, department, etc. If you have purchased the Supervisor module, the data is refreshed nightly; if not, the data is refreshed each weekend. This report allows you to check on program compliance and due dates, with no other medical information/PHI.

Programs covered: Respirator Fit, Seasonal Flu and TB. We will notify our customers as additional programs become available.

Using the Supervisor Compliance Report

  1. On the Report tab, click on Operational > Supervisor > Compliance Details report.
  2. Use the Selection Criteria to build the report you need. The options listed below are valuable in creating meaningful reports:
    • Supervisor – if your HR Feed includes supervisors, you can create reports by supervisor or group supervisors together to create division level reporting
    • Program – Respirator Fit, Seasonal Flu and TB
    • Compliance – Due Current Month, Due Next Month, Due, Compliant, Non-Compliant, Not in Program, Error in Results (definition of each is listed below)
    • Compliant Due Date Range - ability to search by due date range
  3. Use the Columns to select the output of your report. Two important sections:
    • Refresh Date – This will display that last time the report data has been updated. This is important to know because a participant may have received their flu vaccination today but the report may show them as non-compliant because the data hasn’t been refreshed.
    • Compliance Results – displays the program, compliance, due date and notes, all important information.

Compliance Status Definitions

  • COMPLIANT: Next Due Date is farther out than “Due – Next Month”, or for Seasonal Flu, the person has complied to the requirements of the program before the Seasonal Flu program end date.
  • DUE-CURRENT MONTH: Next Due Date is in the current month
  • DUE-NEXT MONTH: Next Due Date is in the month following current month.
  • NON-COMPLIANT: Next Due Date is in the next month or in the past, depending on the program rules. For example, if someone’s due date is 3/14 and the date is 3/16, they will remain “Due – Current Month” unless it’s for Seasonal Flu. Flu uses the Program End Date as a “firm” date for compliance.
  • DUE: Used in a program where a single Next Due Date has been set for all participants (e.g. the Seasonal Flu program) and an employee has not yet been vaccinated (or in some programs, examined or tested).
  • NOT IN PROGRAM: The participant does not have charting form for the specific program or the charting form doesn’t have a Next Due Date entered.
  • ERROR IN RESULTS: The participant has multiple program documents with different Next Due Dates present. The system is not sure which date to adhere to. You may have to use Edit Appointments either Void or correct the form.
