Event Setup  

To set up an event: 

  1. If an email will be sent, determine the Email Launch Date.
  2. Determine the Event Start Date.
  3. Determine if the event will be using Event Users to assist and if so, which users (restricted access User-not EHS manager access).
  4. Review the Survey and charting form wording.
    Submit a Cority Helpdesk configuration ticket (at least 4 weeks before launch date) to request any wording edits needed. 
  5. Ensure there is an event and calendar set up.
    1. In Client Admin > Provider Locations, identify if you have a prior or default Event Location you can use or update.
    2. If no prior or default event, create a new provider location – type: Event.
      This is the provider location you will assign to the Event users when you create them.
    3. The provider location should have the Event charting form assigned to it (under Provider Tests). 

      Note:  Any given charting form must only be assigned to a single Event location. For example, you cannot have multiple Event locations with the Seasonal Flu Immunization Record but you can have one Event location with Seasonal Flu Immunization Record and another Event location with Respirator Fit Testing. If you create a new Event location and intend to use it for auto-ordering charting forms from surveys, please contact Support as there is additional configuration required. 

  6. Create an Email Template.
    1. Add the Event Survey to the email template.
    2. Work with Cority Customer Support to set up any auto-order of the charting forms to the Event Calendar.
    3. Include instructions on how people should schedule for the event. If self-scheduling, check if relevant calendar is set-up with availability.
  7. If using an Event User crew, create a username and password for each user.
    1. Click Client Admin 
    2. Check if the User already exists from a previous Event like Flu Access.
    3. In User Maintenance, click New User and configure the following:
      1. For Active, select Yes.
      2. Create a Username. 
         The suggested format is Event + Org Code + first initial + last name. For example, Flu1287JSmith.
      3. Click the Provider Location drop-down and select the Event Location.
      4. Click the Provider Contact drop-down and choose a contact, or click New to create a new one. For example, for a Flu Event, the following configuration is used:
        1. Active - Yes 
        2. First Name - Flu 
        3. Last Name - Event 
        4. Address - your clinic address 
        5. City, State, Zip 
        6. Generic email 
        7. Start Time - 7:00AM 
        8. End Time - 7:00PM 
        9. Appointment Duration - 10 
      5. Enter the user's email.
      6. Configure a password.
        Use the same password for all event users 
      7. Enter First Name a  nd Last Name. 
      8. Choose to Allow Assignment for Correspondence.
        By default, this is set to No. 
      9. Under User Roles, select Event Reviewer.
      10. Click Save.
        The user will receive an email stating they have created a login and will give them their username. The password will not be given. You will need to provide the password to all Event users.
  8. For vaccination events, add Vaccine Lot Number and Expiration Date.
    1. Click the C3 tab and click Product Control.
    2. Find and select the Product and Presentation that matches your product.
    3. Click Add New.
      1. Enter the Lot number from vaccine packaging.
      2. Enter the quantity received.
      3. Enter the Expiry Date from vaccine packaging
      4. System Default - Choose whether this lot will be the default across all locations
      5. Check all the locations that will be using this lot.
        Always select the event location.
      6. Click Save.
  9. Launch the Event campaign with or without an email to everyone enrolled.
    For more information, see Using the C3/Mass Email and Initialize Programs.
