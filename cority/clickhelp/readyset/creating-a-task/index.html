Creating a Task

  1. Select desired participant.
  2. Click bin the left menu.
  3. Click New.
  4. Enter all known information. Required fields are marked by an “*”.
    • Description - Enter short description of the task.
    • Task* – select a task.
    • Status* – select Open, Closed or Complete.
    • Follow-up Required*– select Yes or No.
    • Follow-up Date - select the date for follow-up or type in the date, mm/dd/yyyy.
    • Correspondence Method – select Phone, Mail or Email.
    • Department – select the correct item, if needed.
    • Assign To – select the person that you are assigning this task.
    • Notes – Enter free form information. The first 4000 characters will print on the CSV report.
  5. Click Save.
