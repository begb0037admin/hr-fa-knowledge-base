Charting a Documentation Entry

EHS Managers can chart the entire history of an immunization on one charting form. This is useful if you also need to administer an immunization, order a new immunization record, and use that form for an actual immunization. Since you are creating a historical record, chart the oldest information first.

To chart a documentation entry:

  1. When a participant arrives for their appointment, select the participant from the Calendar or using the Participant Management tab, use the Search option to find the participant.
  2. Select Open Orders from either region.
    This will display the charting/test forms listed by date.
  3. Open the Charting form.

Example: Hepatitis B Immunization charting form.

This is a “Smart Form”, so by answering certain questions the form will open the corresponding fields that relate to that process:

  1. Reason for this visit [New to this organization]
  2. Hepatitis B Vaccination Performed By [Received Elsewhere]
  3. Prior Hepatitis B vaccination documents received? Select the appropriate option:
    • Yes – Provided Acceptable Documentation
    • No Documentation Available
  4. Provider of clinic name where vaccination received
    • Date of Prior First Dose
    • Date of Prior Second Dose
    • Date of Prior Third Dose
  5. Prior Vaccine Details:
    • Dose Administered- Select the latest dose date, e.g. if they have had two doses then select Second Dose date (this displays in Record Summary).
    • Date Vaccine Administered: Enter the latest dose date (this displays in Record Summary).
  6. Date of Next Vaccination (if required): This is very important for running reports.
  7. Immunity Status: Answer per your policy.

Each Immunization charting form may be constructed a little differently, but only answer questions like the ones above when charting documentation.
