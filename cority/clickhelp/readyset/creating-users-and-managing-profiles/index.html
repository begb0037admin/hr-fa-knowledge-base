Creating Users and Managing Profiles

This method allows a user with Client Admin rights to set up usernames, locations and assign the correct roles for the user. Note each column denotes the type of user and the fields that are required to complete the process.

Inactivating Users (Providers, Clinicians or Event/Flu Crew)

The following steps show how to inactivate selected Provider, Clinician or Event/Flu Crew user.

  1. Click User Maintenance in the left menu.
  2. Search for the user by entering the Last and First name and click Search.
  3. Select the user.
  4. In the Active field, select No.
  5. In the Allow Assignment for Correspondence field, select No.
  6. Remove all User Role check marks.
  7. Click Save Changes.

Inactivating a Group of Users

To inactivating Event users:

  1. Click User Maintenance in the left menu.
  2. In the Roles field, search for the group to be inactivated.
  3. Select all check the boxes next to the users to inactivate.
  4. Click Inactivate Selected.
  5. Click Yes to confirmation question.
