Viewing Population Types

To View Populations Types

  1. Click the Recruiter tab on the horizontal navigation panel.  
  2. In the Participants section, you can view a list of population types included by the administrator.

    There are different ways that population types can be made visible to recruiters outside configuration:

    1.  Java feed Recruiters can change a configured population type directly in a participant record. 
    2. Recruiters can change a configured population type directly in a participant record.
