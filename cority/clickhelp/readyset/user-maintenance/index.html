User Maintenance

Allows you to set up the username, location and assign the correct roles for the user.

Creating a New User Profile for a Provider, Clinician or Event/Flu Crew User

  1. Choose Client Admin > User Maintenance.
  2. Click New User.
  3. Complete the required fields:
    4. Field Information
    Active Select "Yes".
    Username Username must be 5–60 alphanumeric characters and can contain these special characters:  @ - _ 
    The clinician/provider name will display on the charting and test forms in the Reviewed By or Administered By fields.
    Client Site Displays your information.
    Provider Location

    Select the correct site for the user’s position.

    EHS clinician/provider: select the site where they will be working.

    Event/Flu Crew: select the event site only.

    Provider Contact Select the clinician’s name or select “New” to add them.
  4. In the Provider Contact field, select New.
  5. Complete the required fields.
  6. Click Save.
  7. Complete the remaining fields in the Edit User screen.
    8. Email Enter user’s work email address
    Password Password must be 8–30 characters and must include 1 upper case letter, 1 lower case letter, 1 numeric and 1 of these special characters:   ! @ # $ % ^ &* ( )
    Confirm Password Must match the password entered in the field above.
    SSO Username Leave blank unless directed to enter
    Description Leave blank
    First Name Required
    Last Name Required
    Suffix/Credentials Use for Credentials, MD, RN etc.
    Phone Phone number
    Second Factor Phone Leave blank
    Date of Birth Date of birth
    Allow Assignment for Correspondence

    Yes – For Provider/EHS Manager/Clinicians – To allow the user to assign Tasks and/or Correspondence to themselves or other users
    No – All other users

    Event Leave blank.
  8. User Regions/Markets – will display if required. If present, select the appropriate location.
  9. User Roles – select the user roles/access permissions that correspond with the position of the user and display as tabs when the user logs into ReadySet.
    Make sure you are familiar with the functions for each role so that you assign permissions correctly per your policy.
    10. C3 Role Tab for Product Control, Mass Email and Initialize Programs
    Case ManagementTab for Case Management/WC
    Client AdminTab for EHS Super User only - ReadySet can only give this function
    EHS ManagerTab for EHS Managers/Clinicians daily processes
    Event ReviewerTab for Event/Flu Crew with limited access to program(s) they are providing services for (e.g. flu vaccinations)
    Help DeskTab for Help Desk password assistance
    IncidentTab for Incident Mgmt. – Contracted module
    Lab ResultsTab for Lab Results review
    ParticipantTab for My Health
    RecruiterTab for Recruiters/HR
    Report RunnerTab for Reports (contains PHI information)
    Reports Only – AdminDo not use – available upon request
    Reports Only – BillingDo not use – available upon request
    Reports Only – ClinicalDo not use – available upon request
    Reports Only - ManagementDo not use – available upon request
    SupervisorTab for Supervisors
    WellnessUsed for Wellness module
  10. User Clients – defaults to your client site.
  11. Click Save Changes.

Adding Help Desk Staff, Recruiter/HR

Help Desk and Recruiters have specifics roles with no access to participant’s medical records.

  1. Choose Client Admin > User Maintenance.
  2. Click New User.
  3. Complete the required fields:
    FieldInformation
    ActiveSelect "Yes"
    UsernameUsername must be 5–60 alphanumeric characters and can contain these special characters:  @ - _ 
    Username suggestion: role + first initial + last name (e.g. HDJSmith or HRJSmith). This will aid in finding users.
    Client SiteDisplays your information
    Provider LocationLeave blank
    Provider ContactLeave blank
    EmailEnter user’s work email address
    PasswordPassword must be 8–30 characters and must include 1 upper case letter, 1 lower case letter, 1 numeric and 1 of these special characters:  ! @ # $ % ^ &* ( ).
    Confirm PasswordMust match the password entered in the field above
    SSO UsernameLeave blank unless directed to enter
    DescriptionLeave blank
    First NameRequired
    Last NameRequired
    Suffix/CredentialsUse for Credentials, MD, RN etc.
    PhonePhone number
    Second Factor PhoneLeave blank
    Date of BirthDate of birth
    Allow Assignment for Correspondence"No" for Help Desk and Recruiters
    EventLeave blank
  4. User Roles – select Help Desk or Recruiter.
  5. Click Save Changes.
