Provider Locations

Displays all provider location/clinic details. Use to add new or edit provider locations/clinics, defined as EHS Clinics, Lab, Radiology and Event.

The following options are available within a location:

  • Provider Location Details – edit current location/clinic details.
  • Providers assigned to Location – add New, Activate or Inactivate Providers assigned to this location/clinic. Users are defined as Providers, Clinicians and Event/Flu Crew.
  • Provider Tests – displays the charting/testing forms assigned to a location/clinic; add New, Activate or Inactivate charting/testing forms to a location/clinic.

Add New Provider/Clinic Location

  1. Choose Client Admin > Provider Locations.
  2. Click New Provider Location.
  3. Complete the required fields.
  4. Click Save.

Provider Location Details

  1. Choose Client Admin > Provider Locations.
  2. Select the location that you want to view or edit by clicking the Edit icon.
    This will open a Provider Location dialog box displaying Provider Location Details that you can edit for the location.
  3. Click Save.
