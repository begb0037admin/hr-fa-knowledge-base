Enhanced Notifications

EHS managers, recruiters, and supervisors, and employees use different systems throughout the day. Enhanced Notifications allow users to know if there are appointments or tasks that require their attention.  Users can opt-in to notifications sent through email, text, or both.   

For text messaging to be enabled in the dropdown menu for notifications, your organization must have a Twilio account.   

When Enhanced Notifications is available, a new menu option will appear in User Settings.

If you choose to enable Enhanced Notifications, all notification options will be available to all users with the appropriate roles. It is not possible to only enable certain notifications for your organization, however each individual user must opt-in to receive them.
