Scheduling to Run a My Report

To Schedule to Run a My Report

  1. Once a My Report is accessed (see Accessing My Report), the Parameter window displays by default to the right.
  2. Click the Schedule tabs. 
  3. You can schedule reports to run either by a fixed frequency or by specifically inputting a date and time for the report to run.
    1. If you want to schedule running a report on a fixed frequency, click the Common Settings dropdown menu and select a frequency.
    2. If you want to schedule running a report on a specific date and time, click the dropdown textboxes for Hour, Day, Month, and Weekday as needed. 
  4. Click Save.
