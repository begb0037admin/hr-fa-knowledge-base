Seasonal Flu Immunization Survey and Compliance

Mandatory

  • Compliance based solely on data from the Seasonal Flu Vaccination Record charting form
  • Seasonal Flu Immunization Survey data not used to measure compliance
  • Declinations not accepted
  • Exemptions can be accepted / approved

Non-Mandatory

  • Compliance based on data from either the Seasonal Flu Vaccination Record charting form OR the Seasonal Flu Immunization survey
  • Seasonal Flu Immunization survey data used to measure compliance when no Seasonal Flu Vaccination Record charting form is present
  • Declinations accepted
  • Exemptions can be accepted / approved

If an answer with exact text beginning with “I DO NOT WANT” is added to the question with the question code “SFLUFLU11” in the Seasonal Flu Immunization survey, the Flu program will become non-mandatory. If an answer with that text is not present, the flu program will be mandatory.  Select the appropriate option when running Flu Compliance reports.

Changes That Impact Compliance

What does this mean for changes to the Flu Immunization survey?

Any changes to the question or answers within the question code “SFLUFLU11” (typically the 1st question on the survey) should be made with extreme caution.

  • If an answer is added with text starting with “I DO NOT WANT” (case sensitive), it will make your Flu Program non-mandatory and a charting form will not be required to count this as non-compliant
  • If an answer starting with the text “I DO NOT WANT” (case sensitive) is removed, you may be changing your program from non-mandatory to mandatory
  • If an answer starting with the text “I ALREADY RECEIVED” (case sensitive) is removed, a charting form will be required to count the participant as compliant
  • Any of the following changes to the answers beginning with text “I DO NOT WANT” or “I ALREADY RECEIVED” may change your program from mandatory to non-mandatory (or vice versa) and will impact compliance reporting:
    • Changing the case on any letter from upper case to lower case
    • Adding any text in front of those statements
    • Adding an answer option beginning with those statements (if you do not currently have them)
    • Removing an answer option beginning with those statements

Compliance Impacting Edits

  • Typical first question within the Seasonal Flu Immunization survey.
  • Question code “SFLUFLU11” confirms that the answers available in this Question impact Flu Compliance.
  • Any answer beginning with the case sensitive text “I ALREADY RECEIVED” or “I DO NOT WANT” affects compliance.
  • If an answer with leading text of “I DO NOT WANT” or “I ALREADY RECEIVED” is removed, edited, or added to the question with the question code “SFLUFLU11”, a warning message will appear.
  • Typically the Seasonal Flu Vaccination record charting form is configured to be auto-scheduled based on any answer being selected in the first question so that a form is present and will be used for compliance. 

Best Practices

  • Use caution editing anything related to the question with the code “SFLUFLU11” because it might impact your compliance reporting.
  • Ensure an answer beginning with the case-sensitive text “I DO NOT WANT” is only added or available if your program is non-mandatory, and you would like this response to count as non-compliant if no charting form is completed.
  • If your program is non-mandatory, be aware that any answer beginning with the case-sensitive text “I ALREADY RECEIVED” will count as compliant if no charting form is completed.
  • Case and order matter. Only answers with the exact text at the beginning of the answer and, all in upper case will affect compliance.
  • Make sure answers are properly configured to auto-schedule the Seasonal Flu Vaccination Record charting form when needed.
  • Consistently check and monitor the Medical Considerations. Any changes to product inserts / Vaccination Information Sheets, recommendations from the CDC, and products approved by the FDA for that particular season should be monitored and reflected in the Medical Considerations tab within Answer Properties for the appropriate answers.
