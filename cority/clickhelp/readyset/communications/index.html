Communications

Communications is used to create email templates and to set up automated email reminders.

Template

  • Used to set up email templates for mass emails and initializing program emails.
  • See Communication Setup for detailed documentation.

Adding an Email Template

  1. Choose Client Admin > Communication > Template.
  2. Click New.
  3. Enter a Description.
  4. Select the Email Template checkbox.
  5. If setting up a program launch template, select the Include Survey(s) checkbox.
  6. If adding a survey:
    1. Click Save.
    2. Add the appropriate survey(s) on the Survey(s) tab.
  7. If setting up Mass email template, click Save and Close.

Activating or Inactivating Templates

  1. Select the Template(s) checkbox.
  2. Click Activate Selected or Inactivate Selected as appropriate.
