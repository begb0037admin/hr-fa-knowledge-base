Adding the Charting Form to a Provider Location

To Add the Charting Form to a Provider Location

  1. On the horizontal navigation panel, click the Client Admin tab.
  2. On the left navigation panel, click Provider Locations.
  3. In the Search Results window, click an existing provider location.
    The provider location window opens.
  4. Click the Provider Tests tab.

  1. Click Add New to add a new charting form to a provider.
  2. Select the new form that was created, by clicking the checkbox in front of the form.
  3. Click Add Tests.
    The form is displayed in the list of providers under the Provider Tests tab. 
  4. Click Save.
