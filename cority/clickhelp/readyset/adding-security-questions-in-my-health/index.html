Adding and Updating Security Questions in My Health

You can add security questions in My Health for added security. To add or update security questions, do the following: 

  1. Log in to ReadySet with your credentials.

  2. Click the User Settings tab.
  3. Under My Account, click Security Questions.
  4. Use the drop-down to select a question and enter an answer.
  5. Repeat for the other questions. 
  6. Click Update.
