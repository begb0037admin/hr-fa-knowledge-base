Running a My Report Now

To Run a My Report Now

  1. Once a My Report is accessed (see Accessing My Report), do one of the following:
    1. On the Parameter window displayed by default, click Run Now. 
    2. On the Schedule window, displayed when the Schedule tab is clicked, click Run Now.
