Adding an Appointment Status and Appointment Status Indicator Icon

To Add an Appointment Status and Appointment Status Indicator icon:

  1. Click the Client Admin tab.
  2. On the left Navigational panel, click Appointment Status Indicator. The Appointment Status window appears to the right.  
  3. On the Appointment Status window, click the Add icon.
    The Add Appointment Status window appears.

  4. On the Appointment Status window, fill in the Appointment Status Name.
    The Appointment Status Name must be unique.
  5. In the Status Type dropdown textbox, select Scheduling for the appointment status to display on the calendar.
  6. In the Status Order textbox, select an order value.
  7. In the Icon dropdown textbox, select one of five icon options available.
  8. In the Icon Color dropdown textbox, select one of seven color options available for the icon.
    If an Icon Color is not selected, a warning icon displays to the left of the Icon Color dropdown textbox indicating information is missing.
  9. Fill in all other fields as needed.
  10. Click Save.
