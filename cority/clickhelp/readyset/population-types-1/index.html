Population Types

Population Types can help recruiters streamline some of their processes by categorizing populations, for example as new hires (pre-placement), rehires, or transfers.  

Recruiters should use existing Population Types when possible. Recruiters should be restrictive of configuring or creating new population types. Creating new population types specifically related to compliance reporting can impact other workflows.
