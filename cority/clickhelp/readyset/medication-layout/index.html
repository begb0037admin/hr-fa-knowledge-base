Medication Layout

The Medication layout is used to record and report medication within the problem list for an employee. The fields displayed in the layout are those required for a medication or prescription.

It is not mandatory to fill all fields, they are available for additional documentation if needed.

The medication layout has an “Active” status which automatically updates to “No” based on the medication end date.

If the end date is not entered the medication “Active” status will remain as “Yes”.

Both the 'Problem List Details Report' and the Medication printout will include all the fields present in the Medication layout.
