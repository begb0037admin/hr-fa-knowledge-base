Adding New Populations Types

To Add New Population Types

  1. Log into the client site as an Administrator user. 
    1. Click the Administrator tab on the horizontal navigation panel.   
    2. Click Client on the left navigational panel.
    3. Click Client Reference.
      The Reference panel appears. 
    4. In the Reference window, in the Filter textbox type in Population Types. 

      As you type in Population types the list below is filtered to match the values being typed in.  

    5. Click Population Types.
      The Population Types window displays to the right with a list of Population Types. Population types can differ based on clients’ needs, and company organization needs.  
    6. On the Population Types window click the New icon.
      A new line displays in the list of Population types


    7. Fill in all the fields as needed.
    8. Click Save.
