Best Practices

Tasks

  • The Tasks menu option (in the left menu) is used to create follow-up reminders.
  • Suggest using Task – Follow Up Required.
  • Assign to yourself or the clinician/provider who will be following the participant.
  • Use the Task Search (on the EHS Manager tab) to see all your open tasks:

Correspondence

  • The Correspondence menu option is located in the participant record in the left menu.
  • Use the Create Email option to send specific emails to the participant.
  • Use Client Admin/Communication to create an email template.
