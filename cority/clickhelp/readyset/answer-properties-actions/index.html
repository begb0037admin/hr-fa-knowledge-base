Actions and Survey Planning

On the Actions tab in Answer Properties, you can configure a group of questions to open based on a specific answer selected by the participant. Answers for radio button questions are the only ones you can configure to open a group.

Survey planning is very important.

Before adding actions, plan your entire survey. This includes:

  • A starting question to introduce the purpose of the survey or direct participants to a specific group of questions based on the data you aim to collect.
    For example, is the survey intended to obtain consent or record that a participant is not consenting? Do you need it to gather certain data from the participants? Are the questions only relevant to a specific segment/demographic?
  • Where applicable, a list of all questions that pertain to a specific answer. Group those questions together based on the answer.
  • A list of questions relevant to all participants, regardless of how they answer any particular question. These need to be put into a group every participant will see.
  • A list of questions that are mandatory. Questions must be configured as mandatory on the Actions tab, if they are in a group that is configured to open.
  • The order of your groups and questions. Make sure, for example, any answer that opens a group is not located below the group it will open.

Best Practices for Survey Structure and Actions

  1. Start by looking for existing, similar surveys. It is easiest to structure a new survey similar to an existing, successful survey.
  2. The first question should be used to help participants understand what type of data/information is being collected, with groups that will potentially expand left hidden.
  3. Each answer in the first question opens one or multiple question groups.
  4. Each subsequent group is configured to be hidden, so will only open if a particular answer above it is selected.
  5. Groups below the first question will be for the bulk of data you are aiming to collect.
  6. Where appropriate, the first question in a group can have an answer within it that will open the rest of the group if that answer is selected.
  7. Answers should not be configured to open a group above the current group.
  8. Most actions should occur near the top of the survey.
  9. If required, add a text field to capture a signature at the end of each group.

Adding an Action

To add an action:

  1. Ensure the group you want to open is configured to be hidden.
  2. Right-click the radio button answer you want configured to open the group and select Properties.
  3. Navigate to the Actions tab.
  4. Select the check box next to the group or groups you want to open when that answer is chosen.
  5. Click within the Mandatory Questions column to specify any questions you want mandatory when the group is open.
  6. Click Save.
    The radio button answer will now have green text next to it indicating the group or groups that are configured to open. If multiple groups are configured to open, it will indicate "Multiple" along with the number of groups that will open.

Adding an Action to Re-open the Same Group

An action can also be configured to re-open the group that contains the answer. This can be useful when you want the participant to answer a single question first and then have all the additional questions open based on the answer selected.

  1. This can only be configured for the first radio button question in the group.
  2. The group must be configured as a QT (Question in Title).
  3. A group marked with an asterisk and bolded is the group to which the answer you are configuring belongs, indicating this action will re-open the same group to display all questions, not just the first question in a group configured as QT.

Use caution with mandatory questions. If you add an action to open a group and want certain or all questions to be mandatory when the group is opened, you must specify the mandatory questions in the Mandatory Questions column on the Actions tab.
