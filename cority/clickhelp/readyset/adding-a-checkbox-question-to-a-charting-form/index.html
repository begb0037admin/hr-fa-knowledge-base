Adding a Checkbox Question to a Charting Form

To Add a Checkbox Question to a Charting From

  1. Right click the Group created under the charting form.
    A Menu appears.
  2. Click New Question.
    Another menu to the left appears.
  3. Click Header.
    The New Question window appears. The Type field is automatically filled in as Header.

  1. Click the Text textbox and type in a question.
  2. Click Save.
    The header for the checkbox response has been created.

  1. Right click the Group where the Header for the checkbox was created in.

  1. Click New Question.
    Another menu to the left appears.
  2. Click Checkbox.
     The New Question window appears.

The Type field is automatically filled in as Checkbox. Instructions at the top of the window are provided as a guideline that the header created before a checkbox for a checkbox question.

  1. Click the Text textbox and type in an answer.
  2. In the Header textbox, type in instructions that you want to show prior to a question.
  1. In the Footer textbox, type in what you want to show after a question.
  1. Click Save.

  1. To add another checkbox to the header, right click the Group where the Header for the checkbox was created in.
  2. Click New Question.
    Another menu to the left appears.
  3. Click Checkbox.
    The New Question window appears. The Type field is automatically filled in as Checkbox. Instructions at the top are provided as a guideline for having a header created before a checkbox for a checkbox question.

  1. Click the Text textbox and type in an answer.
    The Answer dropdown text box should have the same answer as the answer inputted in the Text: textbox.
  2. In the Header textbox, type in instructions that you want to show prior to a question.
  1. Click Save.
    The second answer is added.

  1. You can repeat the process to add more responses to the question.
