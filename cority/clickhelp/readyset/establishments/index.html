Establishments

Establishments option is used to add all locations used for keeping OSHA logs or reporting. The Establishments entered are available to select in the Injury, Illness or Exposure charting form. This option is only available if the Injury, Illness or Exposure module has been purchased.

Adding Establishments

  1. Choose Client Admin > Establishments.
  2. Click New.
  3. Complete the appropriate fields.
  4. Click Save to activate the OSHA Hours tab.
  5. Complete the appropriate fields.
  6. Click Save or Save and Close.

Activate, Inactivate and Show Inactive

  1. Select the checkbox beside the Establishment to activate/inactivate.
  2. If necessary, select the Show Inactive checkbox to display any inactivated establishments.
  3. Click the appropriate button to Activate or Inactivate.
