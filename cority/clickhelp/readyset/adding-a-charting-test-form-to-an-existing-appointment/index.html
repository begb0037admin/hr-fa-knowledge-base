Adding a Charting/Test Form to an Existing Appointment

Charting and Test forms can be added to existing appointments. 

To add a charting/test form to an existing appointment:

  1. Click on the EHS Manager tab.
    You will be at the Home screen.
  2. On the Participant Management tab, search by Last and First name or by Employee ID.
  3. Click Search.
    This will provide a results list on the right side of the screen. Confirm your search has found your employee.
  4. Click on the employee to highlight it, or double-click to open that employee record, or click the Edit icon.
    The screen will open to the Medical Chart.
  5. In the left side menu, select Edit Appointments.
  6. Select the correct appointment time in the Exams Groups dialog box.
    This will display the list of charting forms for this appointment.
  7. Click Add Exams.
    This opens the Add Exams dialog box.
  8. Click Visit Type (gives the different program types, e.g. Pre-Placement or the Protocol dropdown displays the charting forms by grouping, e.g. all charting forms associated with Hepatitis A).
  9. Select the checkbox for each desired test or select the checkbox at the top of the list to select all tests.
  10. Click Add Selected Exams. 
    This adds the charting form to this appointment time.
