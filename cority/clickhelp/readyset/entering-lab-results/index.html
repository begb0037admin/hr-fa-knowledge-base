Lab Results Overview

The Lab Results interface allows Employee Health departments to review employee lab results and enter them in the employee’s medical chart. To review lab results, the employee health staff simply clicks on the results they want to review. If acceptable, the employee health staff can side by side enter the lab results on the appropriate charting form. 

The table below shows the overall process of tasks/activities related to lab integration. The task/activity is listed in the first column, the user performing those tasks/activities in the middle column, and the specific portal to use in the last column.

Order Lab Charting Forms

Order the lab charting forms prior to the participant’s specimen collection. To order lab charting forms, do the following: 

  1. Select the EHS Manager tab.
  2. Select Participant Management.
  3. Search and open the employee record.
  4. Select Order Tests.
  5. Use either Visit Type or Protocol to select the lab charting forms.  


Once ordered, lab tests will be in ‘Ready’ Status in the Open Orders tab under the Medical Chart menu.   

Lab Results Tab

The lab analyzes the specimens collected and sends results in an HL7 file that is viewable in your Labs Results tab. The file is automatically uploaded into your system. The Lab Results tab has two menu options; Import Errors and Review. Lab results with no errors are in the Review tab. Lab test results that have errors will be in the Import Errors tab.

The following options are available when you open each entry.

  • Close - This option will take you back to the Import Errors list of lab tests.
  • Reject - You will use this option to remove the result from Import Errors list.

To review an entry in the Import Errors list, do the following:

  1. Select the Edit icon to view the Lab Test Result.
    The information under the HL7 Overview tab will display the actual value, lab interpretations, and normal ranges sent from the lab.
  2. The HL7 Order 1 tab contains the order information and the lab results

Correcting Import Status Error

Use the following steps to correct the Employee Not Matched import status error:

  1. Select the Lab Results tab.
    The tab defaults to Import Errors option.
  2. Select the lab order to correct.
  3. Select the Match to Employee option.
  4. Search for and select the correct match.
  5. Select Process Selected.
    The item will drop off the Import Error list and move to the Review list.

Review Menu Overview

When the HL7 file has been uploaded, the successful lab test results are found under the Review tab. The options below are available when you open each entry:

  1. Select the Review option.
  2. Use the Search option to find by Name, Result Status, Location, Facility etc. 
  3. Result Status options: 
    • Some Results Available
    • Corrected Results – Default
    • Deleted OBX Record
    • Final Results – Default
    • Pending Results
    • Not Asked
    • Description Only
    • Preliminary Results
    • Partial Results
    • Preliminary to Final
    • Results Not Obtained
    • Post Original as Wrong
    • Results Entered – Not Verified
  4. Select the Edit  icon to view the Lab Test Result.
    The following options are available:
    • Close - This option will take you back to the Review list of lab tests 
    • Reject - Use this option if there is a mistake in the data from the lab. For example, if a value has been incorrectly entered by the lab. The lab will need to be contacted to send a corrected file. Multiple lines can be selected for rejection.
    • Void - Use this option if a lab test needs to be re-ordered due to the specimen sample being compromised. A new lab test will need to be ordered using the Order Tests tab. Multiple lines can be selected to be void.
    • Remove - This option will remove the lab result from the Review list of lab tests. Multiple lines can be selected for removal.
  5. Use the Jump to Chart  icon to open the participant’s medical record.

Entering Lab Results

Once Lab Results are available and verified, they will need to be added to the participant's chart. To enter lab results, do the following:

  1. Select the Lab Results tab.
  2. Select the Edit icon to open the lab result.
    The left panel displays the lab result and the right panel displays the corresponding appointment charting forms.
  1. Open the Lab Result Charting form.


  2. Enter the lab results on the charting form.
  3. Select Submit Final.

  4. If the charting form is not available, use the Order Missing Test button to add the needed charting form.

  5. If there are no appointments displaying in the panel, select Close.

Enter Lab Results from the Medical Chart

  1. From the Review tab, select the Jump to Chart icon.  
  2. Select Order Tests.
  3. Select Medical Chart.
  4. In one window, select the Labs tab.
  5. In the other window, select Open Orders and the Charting Form tab.

  6. Enter the lab results on the charting form.
  7. Select Submit Final.
  8. Select Yes, Attach Lab Result button.

Printing a Lab Result

Lab results can be printed from both Import Errors and Review tabs.

  1. Select the Edit icon.
  2. Click Print.
