Tabs and Notifications

The answer properties has multiple tabs.

Tabs

After a new answer is saved, to view and edit additional properties, right-click the answer and select Properties.

You will see the following tabs:

Tab
Use
Details

View and change the answer, notification text, and whether or not a medical consideration is displayed.

Action

Configure groups to open based on the answer selected.

Considerations

Configure a medical consideration to display.

Tests

Configure charting forms to be automatically ordered based on the answer selected.

Meta

View the time, date, and user ID.

Notifications

Notifications only apply to the Health Risk Assessment (HRA) survey. This field should be left blank (empty) unless you are working with the HRA survey. Text in this field will only be visible in the HRA Report Letter.

Watch the Cority Academy training module about the HRA survey if you would like to learn about configuring notifications for it. Learn More
