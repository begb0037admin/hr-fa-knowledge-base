Creating a Visit Type

To create a visit type:

  1. Click the Recruiter tab on the horizontal navigation panel.   
  2. In the Participants section, click the Edit icon of a participant that has a population type that is either transfer or rehire.
    The Visit Type window opens.
  3.  The Visit Type window by default will open on the Details tab, which displays the participants information. 
  4. Click the Appointments tab.
    The Appointments window appears.

  5. On the Appointments window click  New Appointment.
    The Schedule Exams window appears. 

  6. On the Schedule Exams window, click the Visit Type dropdown textbox and select one of the following:
    1. Appt Reminder Visit Type
    2. New Hire
    3. Transfer Visit Type


  7. Once a Visit Type is selected a list of visit types specific to that selection will appear.
  8. Select a Visit Type. 
  9. Click the Location dropdown textbox and select a location. 
  10. Click the Contact dropdown textbox and select a contact. 
  11. Click the Date dropdown textbox and select a date.
  12. Click the Time dropdown textbox and select a time. 
  13. Click Submit.
    The Visit type window will redisplay on the Appointment Tab. 
    1. On the Appointment tab, the appointment appears under the Appointment section.
    2. Click Close.
