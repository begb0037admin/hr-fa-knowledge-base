Adding an Answer to an Existing Form

To Add an Answer to an Existing Form

  1. Right click on the question. A menu appears.
  2. Click + New Answer.

The New Answer window opens.

  1. In the Text textbox type in an answer.
  2. In the Value textbox  type in an answer that is the same as answer typed in in the Text textbox.
  3. Click Save.
