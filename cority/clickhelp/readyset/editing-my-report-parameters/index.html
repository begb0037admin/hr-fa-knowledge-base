Editing My Reports Parameters

To Edit My Report Parameters

  1. Once My Report is accessed (see Accessing My Report), the Parameter section displays to the right.
    In the Selection Criteria section, the filtered criteria of the report are listed. These parameters can be edited. 

  2. To edit a parameter, click the Edit   icon for that parameter.
    The Add Criteria window appears. Each parameter has its own Edit icon. You may have to scroll through each parameters to find the Edit icon. 

  3. On the Add Criteria window, make changes as needed. 
  4. Click Apply Search Criteria.
    The changes made to parameters are updated. 
    1. In the Column section, you can select the columns that displays when the reports is exported.
