Question Groups

A Question Group is a grouping of one or more questions.

Adding a Question Group

Before you can create questions, you need a group to place them in. Right-click the survey name, select New Group and fill out the Group Properties.

Field
Use
Name

Title of the group. Visible to Participants.

Sort On

Positioning in the survey. Does not override manual re-arranging done by drag & drop.

Question in Title

Only check if the first question will be a radio button question type used to make other questions appear based on a selection. This will make the first question in the group visible without expanding the full group.

Hidden

Check if you would like the group of questions to be hidden and only be displayed if a particular radio button answer is selected.

Hiding and Collapsing Groups

By default, all groups but the first will be collapsed when a participant opens a survey.

Consider including all questions within a single group so the participant does not need to expand subsequent groups OR ensure subsequent groups are configured to open based on a selected answer.

Hidden Group

Prevents the participant from seeing it unless they select a specific radio button answer that is configured to open the group.

Collapsed Group

All questions within groups (other than the 1st group) are collapsed until the participant clicks on the arrow next to the group title to expand it.

Question in Title

Hides all questions in the group (including the first group) other than the first question. Only check if the first question is a radio button question type with answers configured to open subsequent questions.

Configuration

  • The first group is expanded by default unless “Question in Title” is checked, then only the 1st question is expanded.
  • The second group is configured as a Question in Title, so only the first question in the group is opened by default.
  • The third group is configured to be hidden so does not appear at all unless a specific answer is configured to open it.
  • The fourth and fifth groups are collapsed by default since they are not the first group and do not have a Question in Title configuration.

Inserting and Re-positioning Groups

To add another group of questions:

  1. Right-click the name of the group you would like to insert a new group above
  2. Select Insert Group and fill out the group details.
  3. If you would like to place the group in a different position from where it was inserted, simply drag and drop it to the desired location.
    Drag and drop movement overrides the Sort On value.

Removing a Question Group

If you remove a question group, you will also remove all questions within that group.

To remove a group:

  1. Review all questions within the group and confirm you would like to remove them all before proceeding.
  2. Right-click the name of the group you would like to remove.
  3. Select Remove.
  4. Click Ok on the warning message if you would like to proceed, or cancel to exist without removing the group.
  5. Open the Unused Questions box at the bottom of the survey to view the removed questions.

Additional Open/Close Logic

Logic to open specific groups also exists within Answer Properties. This will be covered in detail in an upcoming module on adding, editing and removing Answers. For now, be aware that a group can be configured to open only if a specific answer is selected by a participant. For example, if you would like a group of questions about an Injury to appear, you may configure an answer to only open that group when an answer of “Yes I was injured” is selected.

Best Practices

  • Keep all questions in one group unless you are specifically configuring subsequent groups of questions to open based on a specific answer selection. Otherwise, participants will have to manually open each group themselves.
  • Only set the Group Property “Question in Title” if the first question in the group is a radio button question type that is intended to open additional questions or keep additional questions hidden based on the answer.
  • Re-arrange groups using the drag and drop functionality instead of the Sort On field.
  • Only remove a group after reviewing all questions within the group to ensure none of them are needed.
