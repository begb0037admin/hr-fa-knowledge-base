Configuring Tests / Charting Forms to be Ordered Automatically

Before configuring tests/charting forms to be ordered automatically, the following are best practices to consider:

  • Remember to ensure your charting forms or tests are configured in Client Admin under Provider Locations in order for them to be ordered.
  • Always ensure that a Test / Charting Form is only associated with one Provider Location for the auto-ordering logic to work. If you have a Test / Charting Form that is associated with more than one Provider Location, when it is auto scheduled it may be auto scheduled for a location you are not intending which means it may not be accessible.
  • If you’ve created a custom charting form, ensure it is part of the desired Exposure Protocol within the form properties.

Just like Actions, planning is important when configuring Tests / Charting Forms to be automatically scheduled and ordered! Using your flow chart survey design that was used to build actions, now, identify answers that if selected, should cause any of the charting forms to not be scheduled.

Map out your process in a flow chart:

  1. Some charting forms may exist within the selected protocol that you do not want scheduled when this survey is submitted at all. Identify these Tests/Forms: These charting forms/tests should be unchecked (removed) from all answers associated with the first question that ALL participants will be required to answer.
  2. Some charting forms should not be scheduled when one answer is selected: This answer should be at the very end of the answer flow (the last question the participant is responding to) which will determine if that test/ form is needed or not.
  3. Some charting forms should not be scheduled when multiple answers are selected: The final answer that determines that the charting form / test should not be ordered, should be configured uncheck the test/ charting form.

Just like actions, the order you apply these configurations in matters greatly. As soon as a test / charting form is unchecked and configured to not be auto-scheduled for an answer, that test/form cannot be auto-ordered for any subsequent answers.

All answers that trigger the auto-ordering should be above any answer for which you cancel the auto-ordering.

Auto-ordering Tests / Charting Forms

When a Test or Charting Form is configured to be automatically ordered, after the participant submits their survey, it will be ordered at 12:00AM that night, for the Provider Location that is assigned to the Test or Form.

  1. Within Survey Properties, select the protocol the charting form or test is a part of within the “Auto-Order Charting Forms” dropdown.
  2. Right-click any answer in your survey and select the “Tests” tab.
    All Charting Forms / Tests that belong to that exposure protocol will be visible and checked by default.
  3. Reference your survey design flow chart and ensure all answers you want the test/ charting form(s) to be automatically ordered and scheduled for are above and will be answered before any answer you want to configure to not auto-schedule the test/form. As soon as a test/form is unchecked for an answer, it will no longer be available to have checked in subsequent answers.
  4. Open the Answer Properties for an answer that should cause a test / form to NOT be ordered. Navigate to the Tests tab and uncheck the form/test.

Once an answer has been configured to remove a Test or Charting Form from being auto-scheduled, the answer will have a red “I” icon next to it so you can easily locate answers that are causing forms to not be ordered.

Hover over the icon to view the charting forms that are not being ordered as a result of that answer being selected.

Once a form is removed from being auto-scheduled, it will still appear like it is being auto-ordered in subsequent answers, so it is important to reference the red “I” icon to be aware of forms that are no longer available to order.

Editing Surveys with Auto-scheduling

Anytime an existing survey is edited, it’s very important to check if the changes will impact the tests or forms that are configured to be auto-scheduled. Changes to watch for include:

  • Removing an answer that is configured to de-select forms from being ordered.
  • Changing the exposure protocol selected in the Auto-Order charting forms drop down OR adding a new one.
  • Re-arranging the order of groups, questions and answers.
  • Adding or changing an action.
  • Adding an answer.
