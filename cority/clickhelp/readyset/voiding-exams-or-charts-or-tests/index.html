Voiding Exams or Charts or Tests

  1. Select the participant from Participant Management on the primary navigation menu.
  2. Choose Edit Appointments from left menu.
    The screen opens to Exam Groups by Appointment dates.
  3. Click on the correct date to view the forms listed.
    This displays all tests attached to that date.
  4. Select the checkbox beside the charting form(s) that you want to void.

    Only Exams/Charts/Tests that are in Ready status should be voided. If the Status is Complete, do not void the test, as it contains data entered by a provider.

  5. Click the Modify Status icon located above the Test Description.
    This opens a Modify Selected Records dialog box.
  6. In the Status dropdown, select Void.
  7. Select a Reason, if needed.
  8. Click Update.
    The test will still be there but the status is now Void.
