Flu Event Setup and Workflow

To set up an event: 

  1. Determine the Email Launch Date.
  2. Determine the Event Start Date.
  3. Determine if the event will be using Flu Crew Event Users to assist with giving Flu Shots (restricted access User-not EHS manager access).
  4. Review the Flu Survey and Flu Charting Form wording.
  5. Submit a Cority Support configuration ticket (at least 4 weeks before launch date) to request any wording edits. Additionally, check with Support if you have already set up the automation where a completed survey triggers the system to automatically order a charting form for the participant. If you do not have this set up, you need to either batch order the charting forms for the participants or order them one-by-one as needed to chart. Do not manually batch order the charting forms. If the automated feature is activated, the system will order the charting form once the participant clicks submit on their completed survey.
  6. Ensure there is an event and calendar set up.
    1. In Client Admin > Provider Locations, identify if you have a prior or default Event Location you can use or update.
    2. If no prior or default event, create a new provider location – type: Event.
      This is the provider location you will assign to the Flu crew users when you create them.
    3. The provider location should have the Flu charting form assigned to it (under Provider Tests). 

      Note: There should only be one Event Provider Location with the Flu charting form assigned. Verify that you do not have one already.

  7. Create an Email Template.
    1. Add the Flu Survey to the email template.
    2. Work with Cority Customer Support to set up any auto-order of the Flu charting forms to the Event Calendar.
    3. Include instructions on how people should schedule for the event. If self-scheduling, check if relevant calendar is set-up with availability.
  8. If using an external Flu Crew, create a username and password for each user.
    1. Click Client Admin.
    2. In User Maintenance, click New User and configure the following:
      1. For Active, select Yes.
      2. Create a Username. 
         The suggested format is Flu + Org Code + first initial + last name. For example, Flu1287JSmith.
      3. Click the Provider Location drop-down and s elect the Event Location.
      4. Click the Provider Contact drop-down and choose a contact, or click New to create a new one. For example, for a Flu Event, the following configuration is used:
        1. Active - Yes 
        2. First Name - Flu 
        3. Last Name - Event 
        4. Address - your clinic address 
        5. City, State, Zip 
        6. Generic email 
        7. Start Time - 7:00AM 
        8. End Time - 7:00PM 
        9. Appointment Duration - 10 
      5. Enter the user's email.
      6. Configure a password.
        Use the same password for all event users 
      7. Enter First Name and Last Name.   
      8. Choose to Allow Assignment for Correspondence.
        By default, this is set to No. 
      9. Under User Roles, select Event Reviewer.
      10. Click Save.
        The user will receive an email stating they have created a login and will give them their username. The password will not be given. You will need to provide the password to all Event users.
  9. Add Flu Vaccine Lot Number and Expiration Date.
    1. Click the C3 tab and click Product Control.
    2. Find and select the Product and Presentation that matches your product.
    3. Click Add New.
      1. Enter the Lot number from vaccine packaging.
      2. Enter the quantity received.
      3. Enter the Expiry Date from vaccine packaging
      4. System Default - Choose whether this lot will be the default across all locations
      5. Check all the locations that will be using this lot.
        Always select the event location.
      6. Click Save.
  10. Launch the Annual Flu campaign communication and surveys to everyone enrolled.
    For more information, see Using the C3/Mass Email and Initialize Programs.
