Creating, Editing, and Removing Questions

You can create a question by doing one of the following:

  • Right-click the name of the group you want the question in and select New Question.
  • Right-click a question that already exists in the group and select Insert Question to insert above it.

If you right-click the first question in a group designated as QT, you will not have the option to insert a new question above it. You must insert above the question below that one or remove the QT designation.

Once created, you can edit a question by right-clicking the question text and select Properties.

Selecting an Answer

Each question must have an answer associated with it. If you have chosen a radio button question, it can have multiple answer options associated with it. When you add or change an answer, you will be able to select from an answer bank that contains Global Answers or Custom Answers.

  • Global Answers: An answer bank of over 1,500 common answer options available to all clients. These answers can be used but not edited. They appear greyed out and have “Global” in the permission column.
  • Custom Answers: Answers created by users. They are available to the current user and other users within the organization. They appear black and have “Custom” in the permission column.
  • Click the Permission field in the left search panel to filter the answers you are seeing to either global or custom answers.
  • Search for an existing answer using the search panel and click Search.
  • Double-click an answer, or left-click the answer and click Choose Selected, to associate the answer to your question.

Headers and Footers

  • A header will display in blue text above the question for which it has been configured. When a question has a header configured, an [H] indicator will display to the left of the question text within the configuration view.
  • A footer will display in black text below the question and above its answer(s). When a question has a footer configured, an [F] indicator will display to the right of the question text within the configuration view.

Question Properties

Mandatory

  • Select this box to ensure the participant responds to the question.
  • This is not recommended for a question within a hidden group, unless the hidden group is properly configured to be displayed when the question is necessary.
  • This is recommended for radio button questions that have an answer configured to open another group or groups.

Copy on Reinitialize

  • Select this if participants will be asked to complete the survey frequently, and the answer to the question is unlikely to change. For example: What is your height?

Date Settings

In addition to the Details fields listed above, date questions have two fields for restricting the values that can be entered:

  • Min Date: If used, no date preceding the date entered here will be accepted.
  • Today Minus: If used, no date further in the past than today minus the specified number of days will be accepted.

Removing a Question

To remove a question:

  1. Right-click the question.
  2. Select Remove.

The question removed will display in the Unused Questions list at the bottom of the survey. This will not impact surveys that have already been ordered/initialized for participants, only newly ordered ones.
