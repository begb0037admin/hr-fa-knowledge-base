Setting Up Help Desk Users

To create the Username and Assign Permissions, 

  1. Login to your client-specific URL with your Super User username and password (https://clientURL.readysetsecure.com).
  2. On the Client Admin tab, click New User.
  3. Enter the following criteria for the Help Desk User:
    • Username– suggest to use first initial, last name and HD (for HelpDesk) e.g. jsmithhd
    • Select the Client (your company name)
    • Do not select an Employee
    • Leave Provider Location blank
    • Leave Provider Contact blank
    • Enter the person’s work Email Address
    • Enter a default Password meeting the following password criteria
      • minimum 8 characters in length
      • 1 capital letter
      • 1 number and 1 special character
    • In the Type field, select "EHS Manager/C3/Client Support".
    • Code – leave blank
    • Description – leave blank
    • First Name – Enter Help Desk first name
    • Last Name – Enter Help Desk last name
    • Phone Number – leave blank
    • Date of Birth – leave blank
    • Allow for Assignment = NO
    • Event – leave blank
    • User Roles – for Help Desk tab access – lookup usernames and change passwords, select the HELP DESK checkbox 
    • User Groups – do not check any boxes.
  4. Click Save Changes.
