Coronavirus Module FAQ

Below you will find the answers to some frequently asked questions about the ReadySet Coronavirus module.

Can I setup additional symptoms to display in the 21-day tracker – YES

Adding COVID-19 Symptoms to the 21-Day Symptom Tracker

  1. Select Client Admin.
  2. Select List Configuration.
  3. Select Surveys Folder, Ebola Daily Symptoms, Symptoms.
  4. Select New and add symptoms that will show on the 21-day symptom tracker.
    There is a default list of symptoms.
  5. Select Save Changes.

Can I get a notification email when a worker indicates they have a fever or a symptom -YES

Contact your account representative to setup an email notification to key personnel when a worker indicates fever or symptoms.

Where do we send feedback?
