Attaching a Scanned Document

Documents can be scanned and attached to a specific charting form, supporting documentation chart, or to the documents option. 

Attach a document to a specific charting form

The employee can see any documents that are attached to specific forms.

  1. Scan document and save it to your pre-determined location.
    It is recommended that you use the same naming convention for all scans. For example, last name, first initial, test name, and appointment date.
  2. Click the EHS Manager tab
  3. Click Attach Documents on the primary navigation menu to search for the employee to attach document to.
  4. Double click on the correct test/chart in which you want to attach the document.
    This opens a Manage Exam Attachments dialog box.
  5. Click on New.
  6. Click Select a File to find the document in your pre-determined location and open.
    This brings you back to the ReadySet screen.
  7. Click Upload.
    This will display the file under File Name.

The Delete Selected icon is located at the top of the dialog box. If you need to remove the document, click on the icon.

To view the attached document:

  1. Search for and select the participant.
  2. Click Medical Chart on the menu on the left.
  3. On the Results tab, select the same test as above.
    The attached document icon displays at the top of that test/charting entry.
  4. Click on the Attachments icon to display the attachment.

Attached a document to supporting documentation chart

Note: The participant can see any documents that are attached to their file when selecting SUPPORTING DOCUMENTATION VIEWABLE

  1. Scan document and save it to your pre-determined location.
    It is recommended that you use the same naming convention for all scans. For example, last name, first initial, test name, and appointment date.
  2. On the EHS Manager tab, click the Participant Management tab.
  3. Search by Last name, First name or by employee ID.
  4. Select the participant that you have a document to attach.
  5. From the menu on the left, select Edit Appointments. 
  6. Select the correct appointment time located in the Exams Groups dialog box.
    This will open to the right the list of charting forms for this appointment.
  7. In the Protocol drop down, select Supporting Document.
    This will display:
    • SUPPORTING DOCUMENTATION EMP VIEWABLE
    • SUPPORTING DOCUMENTATION EMP NON-VIEWABLE
  8. Click the Add Selected Exams button.
    This adds the charting form to this appointment time.
  9. Navigate to the medical chart for the participant.
  10. Click on the Open Orders drop down.
  11. Click on the Supporting Documentation form that is displayed.
  12. Enter the information for the scanned document and submit.
  13. Either click on the attachment icon in the lower left corner of the charting form or click on Attach Documents on the top menu.
  14. Enter the participant Last Name and First Name, then click Search.
    The search results will display the participant.
  15. Select the correct employee by double clicking on the line.
    The screen will display the list of charting forms.
  16. Double click on Supporting Documentation Form to attach a document.
  17. Click New.
  18. Click Select a File to find the document in your pre-determined location and open.
    This brings you back to the ReadySet screen.
  19. Click Upload.
    The screen will display the file under File Name.
  20. To view the attached document, search for and select the participant.
  21. Click Medical Chart on the menu on the left.
  22. On the Results tab, select the same test as above. 
    The attached document icon displays at the top of that test/charting entry.
  23. Click to display the attachment.

Attach documents to the Documents option 

The participant cannot see any documents that are attached under the Documents option.

  1. Scan document and save it to your pre-determined location.
    It is recommended that you use the same naming convention for all scans. For example, last name, first initial, test name, and appointment date. 
  2. Click the EHS Manager tab. 
  3. Click the Participant Management tab.
  4. Search by Last name, First name or by Employee ID.
  5. Select the participant for which you have a document to attach. 
  6. Click the Documents option on the left side menu.
  7. Optional: You can create customized folders by clicking New Folder and entering a name of the folder. For example, Summary Immunizations.
  8. Select the folder and click Attach New File.
  9. Click Select a File to find the document in your pre-determined location and open.
    This brings you back to the ReadySet screen.
  10. Click Upload.
    Screen will display the file under Folder Name.

The Delete Selected icon is located at the top of the dialog box. If you need to remove the document, click on the icon.
