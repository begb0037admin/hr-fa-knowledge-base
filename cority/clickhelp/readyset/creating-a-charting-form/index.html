Creating a Charting Form

To Create a Charting Form

  1. On the horizontal menu at the top, click the Form Config tab.
  2. On the left navigation panel, click + Create New Charting Form.
    The Dynamic Test Properties window opens.

  1. Fill in Name textbox. This will be the title of the form.
  2. Fill in the Description textbox.
    Usually this is the same as what is filled in the Name textbox. This description is what shows up and displays when ordering the test in Order Test.
  3. Click the Exposure Protocol dropdown textbox and select the closest Exposure Protocol that fits your form.
  4. Click the Test Type dropdown textbox to select whether you want to add this form to an event manager.
    If they are having an event program (ReviewVacc- Display in Event) or not (Review – Do not display in event). By choosing to display in event, the form will show in the events tab.
  5. Viewable has three options to select Employee, Record Summary, and Compliance:
    1. Employee – By selecting this option, the form information is viewable by the Employee
    2. Record Summary – By selecting this option, the form information is recorded, this should be unchecked if you do not want personal information to be printed out.
    3. Compliance – is to tie the form to a compliance program.
  6. Click Save.
    The Dynamic Test Properties window closes.
  7. To confirm that the newly created charting form was created, look for the form in the Tests Window (left navigational panel) on the Client Config page.
