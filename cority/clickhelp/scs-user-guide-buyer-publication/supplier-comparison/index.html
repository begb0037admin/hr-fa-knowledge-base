Supplier Comparison

In the Supplier Comparison section, you can run comparisons across the Supplier groups that you can create and manage in Settings.

A list of all your groups will be displayed on the page. Click ‘Run Comparison’ to compare the performance of Suppliers within the group.

A comparison screen will be displayed with the Suppliers’ names across the top and performance metrics, from all available questionnaires, in expandable sections below. You can export all information to Excel for further analysis if required.
