Audits > Groups

Users with Auditor access rights will only be able to upload or carry out automated audits against the Suppliers in their assigned audit groups.

Create an audit group by clicking on ‘New Audit Group’, name the group and then select the users you wish to access it from the list of users with Auditor roles.

Once the group is created you can add Suppliers to it.
