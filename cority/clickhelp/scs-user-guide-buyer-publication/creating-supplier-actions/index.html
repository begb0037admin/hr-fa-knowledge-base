Creating Supplier Actions

Do not create actions using the risk management function unless you have populated the ‘Required Action’ text for each risk flag (see Admin Settings > Flagged Questions).

In order to create actions for a supplier, or multiple suppliers, use the check boxes to select the desired suppliers, and then click ‘Create Action’. This will display a pop up which will tell you how many suppliers you are about to contact. You will need to set a deadline for these actions and assign notifications to users before you are able to proceed.

Users selected for notifications will receive three types of notifications relating to the action(s) – action(s) assigned, action deadlines, action responses. Users should ensure they have the relevant notifications activated (see Admin Settings > User Management).

Once you click ‘Confirm’, suppliers will also be sent a notification email detailing the required actions.
