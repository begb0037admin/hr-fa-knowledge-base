Supplier Search Results

Once you have returned results using either of these search functions, users can view and write notes for a Supplier by clicking on ‘Comments’ link next to the Supplier name in the search results. Supporting files can also be uploaded in the Comments section.

The link symbol next to a Supplier’s name indicates that the Supplier is a member of a group created by a user in your organisation. The label symbol indicates that a user within your organisation has created a label for that Supplier.
