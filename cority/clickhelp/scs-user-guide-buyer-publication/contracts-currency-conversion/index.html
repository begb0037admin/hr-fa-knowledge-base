Contracts > Currency Conversion

In order to access contracts they will need to be turned on for your organisation by Cority. Those users with contract admin access can access the Admin settings > contracts menu.

Use the Contracts > Currency Conversion section to manage currency conversions in association with contract information uploaded against suppliers. Click on ‘Add Currency’ to add a new currency and use the expander icon (>) to add specific exchange rates with dates.

The default currency rate will be used should there be no currency rate set with a date range that includes the contract start date.
