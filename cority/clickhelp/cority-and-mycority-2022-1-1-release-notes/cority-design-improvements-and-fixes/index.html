Cority Design Improvements and Fixes

The table below lists the design improvements and fixes we have made in the Cority 2022.1.1 release. The items are organized by component and the components are arranged in alphabetical order.

Item #Component(s)ReportedDescription
CCC-3110Business IntelligenceN/A

Dashboard indicators displaying environmental actions with associated objectives now function properly and without generating unexpected errors.

 

CCC-7040Chemical ManagementN/A

On the 'Public Chemical Product' layout (ML-001139), the 'Print Form' action is now enabled.

 

CCC-7036Chemical ManagementN/A

When applicable, and if the view is configured properly, on the Related Chemicals tab (sublist) of an Asset Management record, the user can now see whether or not each chemical product is active or inactive.

 

CCC-7034Chemical ManagementN/A

On a Chemical Product look-up table record, on the Product Group tab, a user with the required security configuration can now inline-add a record without generating an unexpected error.

 

CCC-7751Emissions Inventory2021.3.2

In Emissions Inventory, the calculation engine will now calculate emissions for an asset sequence that has data sources of different types.

 

CCC-3274Emissions InventoryN/A

The following improvements have been made to Emissions Inventory module:

  • The performance of the emissions calculation engine has been improved.
  • When generating the Emission Calculation Report with reporting periods specified, the system will now only re-calculate intermediate and final results for the selected source profiles and reporting periods.
  • Calculated emissions values can now be used in subsequent emissions calculations. To support this, the new Secondary Sequence field (a check box that is not selected by default) can now be added to custom versions of the Source Profile 'Related Asset' layout (ML-000338).
  • From a Source Profiles list view, emissions can now be calculated for multiple source profiles at one time.
  • When calculating emissions, the system will now only aggregate emissions that have the same related-asset relationships.
  • The new 'Maximum Hourly Result' and 'Maximum Ozone Result' fields (check boxes that are not selected by default) can now be added to custom versions of the Source Profile 'Related Asset' layout (ML-000338).

For information on working with the Emissions Inventory module, see the Cority User Guide.

 

CCC-7386Industrial HygieneN/A

On 'IH Noise Sample' layouts, both the 'dB Lower Limit' and 'dB Upper Limit' drop-down menus now provide 5 dB increments.

 

CCC-6009Industrial HygieneN/A

On a Lab Requisition record, when applicable, the 'Location (Site)' field will now populate automatically with the location the sample(s) were taken, instead of populating with the lab name.

 

CCC-6978Occupational Health – Employee CareN/A

In the Clinic Visit module, the performance of the Vital Signs functionality has been improved and that feature set now works without generating any unexpected errors.

 

CCC-6808Occupational Health – Employee CareN/A

When sending a medical letter, all applicable fields are now editable.

 

CCC-6172Occupational Health – Employee CareN/A

When a medical letter is sent, the fonts in the letter will now remain the same as those in the letter template being used.

 

CCC-6503Occupational Health – Employee Care2021.3.0

When configured to do so, the user's signature will now display as an image on an immunization letter.

 

CCC-5958Occupational Health – Employee Care2021.2.2

When a user has reassigned multiple appointments, site security for all appointments now continues to be respected (that is, it is unaffected).

 

CCC-5386Occupational Health – Employee CareN/A

From Clinic Visit records, a new version of the DOT Medical Examination Report (MCSA-5875) is now available.

 

CCC-7663Platform – Administrator2021.3.0

BR-100551 and all related Cority-created business rule actions are now marked Cority-created with no other conditions.

 

CCC-7410Platform – Administrator2022.1.0

On an Equipment record that has the EMS Requirements tab populated, if the user clicks Graph and the EMS session expires or is lost, the EMS login screen will now display. When the user logs in, the calculation graph will display again with the appropriate data.

 

CCC-7297Platform – Administrator2022.1.0

A display rule with the Layout action created for the CaseMaster entity will no longer be overridden by the case layout logic that matches the layout to the default case type.

 

CCC-7007Platform – AdministratorN/A

If a record is locked and the user switches from one layout to another, the record will now remain locked.

 

CCC-2641Platform – AdministratorN/A

When the Employee Number field is prohibited from the user's role, the following Safety Incident columns/fields will now mask the employee number:

  • Employee
  • Inv Supervisor / Approver 1
  • Supervisor

 

CCC-2626Platform – Administrator2020.1.0

For a business rule email action with a URL link that contains a merge field, a translation will no longer discard the link.

 

CCC-7037Platform – End-UserN/A

When the Questionnaire Inbox has a questionnaire that is not yet posted and the user attempts to post results for the questionnaire, that post will now succeed, updating the existing header and response on the questionnaire, the same as when posting for the first time to a new record. Also, the update will be recorded in the Event Log.

 

CCC-6044Platform – End-User2021.3.0

The functionality for configuring and sending two different emails, each in its own window, now works as expected.

 

CCC-5464Platform – End-UserN/A

On a locked questionnaire with questions that have child questions, the user can now expand such parent questions without generating an unexpected error.

 

CCC-3838Platform – End-UserN/A

When configuring the behavior of number fields on layouts:

  • If the field is set to read-only/disabled and no number of decimal places is specified, the value will display all decimal places (instead of up to three only).
  • If the field is not set to read-only/disabled and no number of decimal places is specified, the value will display all decimal places (as before).

 

CCC-3330Platform – End-User2020.1.0

On a questionnaire with one or more nested/child questions that are of the subquery type, for each both the parent question and the nested/child question will now display and function correctly.

 

CCC-7799Platform – InfrastructureN/A

For Form Mapper, when PDF generation fails because of an error, more information is now recorded in the Event Log.

 

CCC-7603Platform – InfrastructureN/A

When an invalid JSON array is sent in the HTTP request body to an API endpoint, the server will now return a 400 bad request HTTP status code and a generic response body that indicates why the request is bad.

 

CCC-6057 and 6709Platform – Infrastructure2021.3.1

All login screens now have a link to the Cority privacy policy.

 

CCC-4631Platform – InfrastructureN/A

After providing values for tree fields on a record (for example, a Safety Audit record) and then saving the record, you can now tab through those tree fields and save the record again without generating any unexpected required-field errors.

 

CCC-7130Platform – Interfaces 2021.3.1

The Create Record business rule action now verifies whether or not the user's role is granted the Create Record entity module.save action. If not, a security violation error will be generated.

 

CCC-5007Platform – InterfacesN/A

In RESTful API calls, the property.ID parameter can now be used for filtering with advanced conditions.

 

CCC-5463Safety – Event Reporting N/A

When applicable, a user with the appropriate security configuration will now be able to delete a Safety 'Event Report' record.

 

CCC-7574Safety – IncidentN/A

The following FRA forms have been updated:

  • 54
  • 55
  • 55a
  • 57
  • 97
  • 98

Also, the following two fields have been added to the FRA Incident and FRA Incident  A data tables (and applicable layouts):

  • OMB Approved
  • Approval Expires

The new fields can be used in business rules, business rule actions, and Query Builder, and can be updated using the Import Utility.

 

CCC-7068Safety – Incident 2021.1.1

When creating or editing a Safety 'FRA Incident' using a layout that has the 'Type of Accident/Incident' field, the field's drop-down list now provides the Other Impacts option.

 

CCC-5944Safety – IncidentN/A

When a user clones an 'Event Reporting Inbox' list view that has the 'On Premise' column, the new clone list view will also have that column.

 

CCC-5321Safety – Incident N/A

For an Action record configured to have recurrence and assigned to a group/team with the complete as team option enabled, the recurrence can now be removed or reconfigured.

 

CCC-7197Safety – Inspections & SurveysN/A

The 'Safety Inspections & Surveys Report' will now provide all of the expected data (including, when applicable, due inspections).

 

CCC-7087Waste Management2021.3.1

On a Waste Management record, the user can now navigate to the Manifest tab (sublist) without generating an unexpected error.

 

CCC-6998Waste ManagementN/A

From the Manifest tab (sublist) on a Waste Management record, manifests can now be opened and viewed by a user with the required security configuration without generating an unexpected license key error.

 

CCC-6189Waste Management2021.3.0

For Waste Profiles, you can now successfully pin custom list views.

 

CCC-4489Waste Management2021.1.2

On Waste Profile look-up table list views, the Waste Code column now displays the waste code/description instead of just the waste code.

 

CCC-3001Waste ManagementN/A

In the Waste Profile look-up table, for each of the Transporter and TSDF fields, the values in the field's drop-down are now correct. That is, they now match the values in the corresponding picklist.
