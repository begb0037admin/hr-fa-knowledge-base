myCority Design Improvements and Fixes

The table below lists the design improvements and fixes we have made in the myCority 2022.1.1 release. The items are organized by component and the components are arranged in alphabetical order.

Item #Component(s)ReportedDescription
CCC-6884Business RulesN/A

When a business rule email that has HTML formatting is sent in the foreground through myCority, the HTML formatting will now be retained.

 

CCC-7446Event ReportingN/A

When applicable, the user can now edit an auto-created questionnaire on an Event Report record.

 

CCC-4666Inspections – Findings & ActionsN/A

If the user attempts to submit without first saving an assigned Inspection that has incomplete auto-created actions on it, the user will now be prompted to complete the auto-created actions first.

 

CCC-6660 and 6659Occupational Health – Employee CareN/A

To make it easier for a supervisor submitting a referral questionnaire to select the Employee record with the correct job position, on the Employee picklist in the Questionnaire Header layout in myCority, when applicable the following three standard views will now display the Additional Jobs, Position Start Date, and Position End Date values:

  • Active Multi Job Employees
  • Inactive Multi Job Employees
  • All Multi Job Employees

 

CCC-6800Occupational Health – Medical MonitoringN/A

When a business rules action email is triggered from myCority, barcode and QR code merge fields now function as expected.

 

CCC-7581Platform – End-UserN/A

Where applicable, the Employee picklist now provides each employee's first and last name.

 

CCC-7008Platform – End-UserN/A

A questionnaire created by a user on behalf of someone else will now be visible to and accessible by that 'Created By' user on his or her 'My Tasks' Incomplete or Complete tab. Examples:

  • A supervisor who needs to create a questionnaire for an employee who reports to someone else
  • A recruiter who needs to create a questionnaire for an applicant

 

CCC-6710Platform – End-UserN/A

The Help button is now mapped to the appropriate content on our new end-user documentation platform.

 

CCC-6080Platform – End User N/A

When a questionnaire with default answers is saved, the default answers will now be retained.

 

CCC-7240Platform – Infrastructure N/A

myCority now supports SP-initiated SSO for organizations with multiple IDPs.

 

CCC-6346Safety – Incident 2021.3.1

A user with the required security configuration can now successfully submit an Event Report that has an embedded questionnaire.

 

CCC-2427Safety – Incident2020.3.0

A user assigned an Incident record that has FRA (V2) forms can now successfully open those forms.
