myCority Design Improvements and Fixes

The table below lists the design improvements and fixes we have made in the myCority 2024.3.1 release. The items are organized by component and the components are arranged in alphabetical order.

Item #Component(s)ReportedDescription
CCC-19817Business Intelligence2024.3.0.4

On a dashboard, a Table indicator will no longer show duplicate records.

 

CCC-19747Business IntelligenceN/A

When a published Query Builder query (entity Schedules, for example) is used in a business rule (BR), hard enforce or not, that has an 'Is Contained' condition, if a user in myCority with only the Portal role (No All Modules and All Sites) performs the action(s) that should trigger the BR, that BR will now function as expected. This is the case regardless of the DisableRWSOA flag setting.

 

CCC-18432Business IntelligenceN/A

When applicable, if a user downloads 'My Records', all headers in the 'Medical Records' report (for example, 'Case Notes') will translate properly.

 

CCC-15082Business IntelligenceN/A

If a business rule (BR) for emailing employees when a 'Finding & Action' is created references a subquery that is a distribution list filtered by location, that BR will now function properly when the 'Finding & Action' is created using myCority.

 

CCC-19431ErgonomicsN/A

When one of the risk types for a user is marked 'Does not contribute to overall risk' and set to 'Expose on My Ergo Dashboard', that risk type will still remain visible for the user where applicable in myCority.

 

CCC-19505Platform N/A

For a Safety 'Incident' record with the user's employee assigned as Supervisor that has an MVA tab with record on it assigned to the same employee, when opened to the MVA record in myCority, the MVA record's related assets features will now function properly.

 

CCC-19264Platform N/A

On applicable layouts, the 'Date Consent Provided' default option now functions properly.

 

CCC-19212PlatformN/A

When properly configured, in myCority a user whose role has valid security permissions can now successfully create a new Work Permit, fill in all the required fields, set the 'Workflow Status' to Draft, click save, click the 'Active' workflow button, then click the 'Close Permit' workflow button without generating an unexpected error.

 

CCC-18785Platform 2024.3.0.0

The 'Every Number of Days' recurrence frequency now displays next to the Inspection Summary icon.

 

CCC-12391Platform N/A

The MG-000344 exception can be successfully translated in Phrase Translations, and when applicable, will now translate into the expected language in myCority.

 

CCC-12164Platform N/A

When applicable, phrase translations imported using the Import Utility will now display as expected in myCority.

 

CCC-4046Platform N/A

Form tooltip translations now function as expected.

 

CCC-3160Platform N/A

The Language drop-down list no longer shows inactive languages.

 

CCC-19039Safety - Audits & Inspections2024.3.1.0

When applicable, from 'My Tasks', on an Inspection with 'Every Number of Days' recurrence, the 'Every Number of Days' phrase will now translate properly in the Inspection summary.

 

CCC-19804Safety – Contractor ManagementN/A

From the Safey ‘Event Reporting Inbox’, if a user creates a record and specifies both a Contractor Project and a Contractor, when that record is opened in myCority, the Contractor Project and Contractor will be correct.

 

CCC-19481 and 18826Safety - Incident2024.2.2.0

For an 'Incident' Event Report created in myCority that has the user's employee assigned as Supervisor and an MVA record added using myCority, all of the MVA record's related assets features will now function properly in myCority.

 

CCC-14507Platform - Safety - IncidentN/A

When configured properly, a user can now successfully save and submit an Event Report with multiple attached documents within the total supported file size limit without generating any unexpected errors.
