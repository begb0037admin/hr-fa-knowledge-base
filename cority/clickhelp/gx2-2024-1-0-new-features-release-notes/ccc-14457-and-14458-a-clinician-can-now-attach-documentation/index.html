CCC-14457 and 14458: A clinician can now attach documentation to a specific job position

  • A clinician can now attach documentation (for example, an employee's/applicant's Medical Clearance Certificate) to a specific job position so that the posts for which the employee is medically cleared are readily evident.
  • To support this, a Letters sublist (tab) can now be added to custom versions of the 'Employee Job Position' layout.
  • The name of the sublist's default view is 'Letters for this Job Position'.
  • The view has the following columns: Letter Code, Created Date, Draft.
  • The list is ordered by the 'Created Date' column.
  • Other typical columns for a Letters view can be added to custom versions of this new view.
  • The sublist has a new 'Job Position Letters' layout (ML-003831).
  • The layout looks and functions similarly (buttons, actions, etc.) to the existing 'Medical Letters' layout (ML-000187).
  • Any letters on the new sublist are hidden by default from the rest of the system (for example, Safety, Medical, IH, etc. main letters lists) and are only accessible if the user has access to Demographics module.
  • These Letter records are also secured in Query Builder and Report Writer by the Demographics security module.
  • The GDDLOFB on each letter will be populated automatically with the GDDLOFB from the parent 'Employee Job Position' record and will be disabled.
  • If the GDDLOFB is updated on the 'Employee Job Position' record, it will be updated automatically on all linked letters.
  • The letters Email action, with password protected feature, functions as expected with 'Employee Job Position' letters.
  • Also, a Letters tab (or sublist) can now be added to custom versions of the myCority ‘My Applicants’ layout. Therefore, for the same employee and same job associated with the same recruiter, the letters the clinicians add using the feature described above will be available in My Applicants. That means the recruiter will also have access to a read-only clearance certificate.
  • For information on working with letters and functionality related to letters, see the GX2 User Guide.
