Summary of Platform Enhancements

The table below lists smaller design improvements we have made within the GX2 Platform. The items are organized by component and the components are arranged in alphabetical order. Descriptions of larger features follow the table.

ItemComponent(s)Description
CCC-11755Administrator, End-User

For working with notes, business rules, emails, and clinical testing results, the text editor has been replaced.

This eliminates the potential security vulnerabilities of the previous editor.

The new editor is more intuitive, user-friendly, and makes much better use of space.

Its output (when exporting, printing, or emailing) is formatted with a more modern, professional look.

Also, for notes, the usability and format of the task list (of check boxes) is greatly improved.

Note: For an email body template created using the improved editor, there might be formatting/styling discrepancies if it is used in a front-end business rule email. This will be addressed in an upcoming release.

For information on working with notes, business rules, emails, and clinical testing results, see the Cority GX2 User Guide.

 

CCC-13423End-User

The email functionality now supports domain extensions of up to 15 characters in length.

 

CCC-12321End-User
In the GX2 platform, the following record types can now be accessed using bookmark links:
  • Finding & Actions
  • Corrective Actions
  • Compliance Actions
  • Safety Incidents
A bookmark link is a direct link to the record.
These bookmark links can be shared ad hoc with others through email, messaging, etc.

Previously, this was only possible in myCority, not in GX2.

     

    CCC-12407Infrastructure

    The following Apple file types can now be uploaded:

    • Pages (.pages)
    • Numbers (.numbers)
    • Keynote (.key)
    • Images (.heic)
    • Videos (.hevc)

     

    CCC-15334Interfaces

    For applicable ‘Employee’ endpoint RESTful API calls, the 'SSN Value' will now be returned unmasked.

    This enables the 'SSN Value' to be used as a unique identifier for government system integrations.

    Note: For such calls, 'SSN' will still be masked, and if 'SSN Value' is a prohibited field, the 'SSN Value' will not be returned.

     

    CCC-14911 and 14293Questionnaires

    Questionnaire Response data cannot be moved outside of its current area through import for potential security concerns.

    For all Questionnaire Response Header entities (Environmental/Ergonomics/IH/OH/Quality/Safety/Training QRH (Questionnaires)) available through the RESTful API, the GX2 Import Utility, or the Cority Data Import Utility, if the user is attempting to import a CSV file to one of them and the file includes a QRH ID that already exists, QRH has Medical = True, and the user has Update Existing Records = True on the Import Screen, then the user can no longer set one or more of the following using an import file:

    • Medical = False
    • Environmental, Ergonomics, IH, Quality, Safety, or Training = True
    • FK related to non-OH parent not set

     

    Also, for business rule (BR) change actions on Public QRH entities (Environmental/Ergonomics/IH/OH/Quality/Safety/Training Public QRH (Questionnaire Inbox), Training QRH (Questionnaires)), if the user is attempting to change a QRH ID for which QRH has Medical = True, then the user can no longer set one or more of the following through the change action:

    • Medical = False
    • Environmental, Ergonomics, IH, Quality, Safety, or Training = True
    • FK related to non-OH parent not set

     

    If so, the record/save will be rejected, an error thrown, and the event will be recorded in the Process and Status Log.
