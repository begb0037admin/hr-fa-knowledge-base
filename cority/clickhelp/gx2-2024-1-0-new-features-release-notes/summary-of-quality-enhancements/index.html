Summary of Quality Enhancements

The table below lists smaller design improvements we have made in the Quality cloud. The items are organized by component and the components are arranged in alphabetical order.

ItemComponent(s)Description
CCC-15037Customer Complaints

The 'Quality Customer Complaints' data table can now be updated using the Import Utility.

Note: The 'Quality Event ID' field serves as the unique key for the import. When updating entries for the table using the Import Utility, an alpha-numeric value for that field must be provided for each entry.

 

CCC-15265Nonconformances

The 'Quality Nonconformances' data table can now be updated using the Import Utility.

Note: The 'Quality Event ID' field serves as the unique key for the import. When updating entries for the table using the Import Utility, an alpha-numeric value for that field must be provided for each entry.
