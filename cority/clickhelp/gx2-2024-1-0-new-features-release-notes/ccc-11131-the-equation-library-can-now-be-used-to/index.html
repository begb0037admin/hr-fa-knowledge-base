CCC-12020: The Equation Library can now be used to create and store IH equations and make calculations for IH monitoring samples

  • You will not have to visit the library often. It simply serves as an equation database or centralized hub where you can create and store equations common to your industry or workflows.
  • You build your equations to pull information from your monitoring sample records and configure them to be used on and display the data on those records.
  • The Equation Library is accessible from the IH menu bar. Within the library, you create your equations.
  • Note: The entity you specify when creating an equation dictates where on records it can be configured to appear and display the calculated result.
  • For example, if you want your equation to be viewed on the parent tab of the IH sample record, then you would select the IHSample entity.
  • There are four new Calculated Fields (1 -4) that can be added to custom Monitoring Sample layouts. Each can be used to display the data for a particular equation. For example, if you want a radon gas equation to display on the Sample Results tab, you can configure it to appear in Calculated Field 1.
  • When using the layout editor to add the calculated field, you can change its name to better represent the data it will display. For example, you could rename the field ‘Radon Gas Exposure’.
  • When creating an equation, you select fields, constants, etc. as inputs, and specify operators. Any existing applicable IH fields, UDF fields, Flex Fields can be used in your equation. Equations are very flexible.
  • Once you have created one or more equations, you then group it/them into an Equation Set, and it is the Equation Set you display on the custom Monitoring Sample layout. You can include up to four individual equations within an equation set, therefore up to four on a single layout to be used and displayed on individual Monitoring Sample records. For example, you might have three separate calculations using different variations of the similar inputs for radon. You could then call your equation set ‘Radon Gas Equations’. That will allow you to run all three on individual Monitoring Sample records.
  • Note: Even if you have just one equation, it still must be added to an equation set to be displayed and used, and the resulting data viewed, on records.
  • Equations can also be removed from equation sets.
  • Up to four calculations can be run simultaneously under one equation set, therefore for any single Monitoring Sample record.
  • For ease of analysis, you can add any of your equation inputs (existing IH fields, UDFs, etc.) to your custom layouts as well.
  • Also, to make it easy to edit equations, from your custom layout you can access an equation within the Equation Library directly.
  • For information on working within the Equation Library or working with the layout editor, see the GX2 User Guide.
