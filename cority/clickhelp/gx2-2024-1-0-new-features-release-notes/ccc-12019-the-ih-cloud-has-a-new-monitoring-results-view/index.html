CCC-14344: The IH cloud has a new Monitoring Results view

  • The view must be added to the user's menu configuration. For information on how to do this, see the GX2 User Guide.
  • Once added, the view will be accessible from the IH navigation menu.
  • It is a list view that enables users to analyze the more important information for each sample without having to click into each Sample record.
  • Also, using the Edit action and inline edit feature on the view, a user can quickly edit certain details for any survey, any sampling strategy, or any set of samples.
  • The view provides the create/clone view functionality, so that users can create custom versions of it.
  • For organizations performing calculations, the Calculated Field 1 through 4 columns and Sample UDF Num 1 through 20 columns can be added to custom versions of the view. The equivalent fields can be added to and used on custom IH Sample layouts.
  • For information specific to working with IH monitoring, IH equations, or custom list views, see the GX2 User Guide.
