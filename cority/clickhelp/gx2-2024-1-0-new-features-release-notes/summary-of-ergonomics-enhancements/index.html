Summary of Ergonomics Enhancements

The table below lists smaller design improvements we have made in the Ergonomics cloud. The items are organized by component and the components are arranged in alphabetical order.

ItemComponent(s)Description
CCC-15022 and 14921Reporting – Email

In Advanced Dashboard, an Ergonomics report that meets the criteria to be sent in an email will now have a new column of checkboxes at the left. The user can select the checkbox for each employee recipient and then click the Email button to send the report to those recipients.

There is also a checkbox at the top of the new column for selecting all recipients.

 

Also in Advanced Dashboard, for a table indicator, a user can now click the new Email icon on the indicator's hover-over to email the report for the indicator to the employees included in its data.

Note: The icon only appears if the indicator has data for employees with email addresses stored in the system.

When a user clicks the icon, an Email modal box will open. The box has the following fields:

  • From - The email address for the user who is sending the email
  • To - The email addresses for the employees included in the report
  • CC - A picklist to the employees with email addresses list
  • Subject - The name of the indicator, which can be edited
  • Body - The body of the email, which can be edited

The modal box also has Cancel, Send, and Actions buttons. The 'Save Layout' and 'Edit Layout' actions can be added to custom versions of the Email modal box's layout.

Employees not included in the report data will not be sent the email.

Note: The templates option is only provided on the Email modal box for reports that do not have aggregation.

An email cannot be sent if the report includes data for more than 250 employees. That is, this feature can only send the report to a maximum of 250 employees.
