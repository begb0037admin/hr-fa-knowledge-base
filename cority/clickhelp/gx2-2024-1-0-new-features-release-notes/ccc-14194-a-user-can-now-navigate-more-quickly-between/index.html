CCC-14194: A user can now navigate more quickly between GX2 and myCority

  • In myCority, the Profile drop-down menu at the top right now has the new 'Cority Platform (GX2)' option. The option is provided only if:
    • The user's role does not have the 'Portal/myCority Only' option
    • The user is not impersonating another myCority user
  • A user who selects the new menu option will be taken to the GX2 landing page, and a GX2 'Login Log' entry will be added.
  • This enables a user in myCority to move quickly to the GX2 platform, to verify, for example, records created while in a myCority workflow (such as a myCority ‘Risk Assessment’).
  • In GX2, 'My Favorites' has a new 'myCority' menu item. This option must be added using 'My Menu', and can also be removed.
  • If the user clicks the new 'myCority' menu item, the system will verify that:
    • One of the user's roles has the Portal security module
    • One of the user's roles has the General security module
    • The user's profile has a linked employee
    • The user is not impersonating another GX2 user
  • If those things verify, the user will be taken from GX2 to myCority, and a 'Login Log' entry for myCority will be added.
  • If those things do not verify, an error message will display.
  • This enables a user in GX2 to move quickly to the myCority application, for example to complete a myCority workflow (such as a myCority ‘Risk Assessment’).
  • Note: Logging out of myCority will not log the user out of GX2, and logging out of GX2 will not log the user out of myCority.
  • Self-hosted clients will need to work with Cority Support (helpdesk@cority.com) to ensure proper setup.
  • For more information on security roles, GX2 'My Menu', GX2 'My Favorites', impersonating users, or the Login Log, see the GX2 User Guide.
