CCC-12705 and 14752: The Permit to Work functionality has been enhanced

This includes the following changes:

  • A new Work Permit checkbox in each of the Probabilities, Control Type, Hazard Severity Rating, and Agent Hazard tables, so that the appropriate lists will filter by that checkbox
  • A new Risk Matrix X-Axis (for Record Related Risk) system setting with severity and probability options, to support the calculation of permit to work risk
  • A new Linked Records tab (sublist), with default list view, so that associated records can be linked to a work permit
  • A new Work Permit Risk tab (sublist), with default list view and layout, so that risk for a work permit can be tracked, monitored, and assessed
  • Support for attached documents on the Work Permit layout

It also includes the following myCority enhancements:

  • My Tasks now shows and filters Work Permits for the user by Groups and Teams
  • The My Tasks information for each Work Permit has been updated and now includes the Workflow Status when applicable
  • The Permit Type field now supports multiple values
  • On the Permit to Work sublist, the Control Type field now supports multiple values

  • A Work Permit can now be cloned
  • The new Linked Records and Work Permit Risk sublists have been added

For information on working with the Permit to Work module, sublists, and/or associated GX2 or myCority workflows, see the GX2 and myCority User Guides.
