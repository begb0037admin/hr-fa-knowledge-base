CCC-12438: The PFT module now supports the Quanjer GLI-2012 pulmonary predicted values standard

The following changes have been made:

  • The standard has been added to the ‘Pulmonary Predicted Values Standard’ system setting.
  • New options (values) have been added to the PFT ‘Race’ drop-down menu.
  • The associated M-spline, S-spline, and L-spline equations have been updated to function with the Quanjer GLI-2012 standard and each race option.
  • For the standard, new predicted values calculations have been added.
  • The following new calculated fields (for each calculation measure) are available to be added to custom versions of the PFT layout:
    • S
    • L
    • LLN
    • Z-score

For information on working with the PFT module, custom layouts, or custom list views, see the GX2 User Guide.
