Overview

At Cority we are committed to continually enhancing our products. The 2024.1.0 GX2 release contains new and improved functionality in several areas—including enhancements to the overall user experience, improvements to the OH pre-employment process, support for the Quanjer GLI-2012 pulmonary predicted values standard, the ability to create and store IH monitory sample equations, and updates to the safety Permit to Work module.

Tips:

  • We use the number(s) assigned to each enhancement to identify it internally. If you have a question about a feature, its number(s) will help the Cority technical contact quickly access all of the relevant information.
  • For the larger items after the tables, we have categorized each as either:
    • Opt-In – The feature is available, but its use is optional.
    • Mandatory – An element of the feature is likely to affect one or more of your current workflows or changes the way data is grouped and/or displayed.
    • N/A – The feature cannot easily be categorized as either opt-in or mandatory.
  • Due to the large feature set and extensive configurability of the Cority platform and its modules, the Cority New Features Release Notes document is published the week prior to the Test environment release. The myCority Release Notes document is published on or shortly after the Test release.
  • Until Cority is released to Production environments, please check this document for updates.
  • For previous versions of the Release Notes, see the Documents section of the User Community.
  • The version number on the cover (landing) page is the document version. A number greater than 1.0 indicates one or more updates have been made.
