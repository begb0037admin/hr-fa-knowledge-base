Workflow Scanning and Workflow Image Analysis for Advanced Workflows

This feature is currently in Early Access. The content in this topic is subject to change as the feature continues to improve.

The Workflow Scanning and Workflow Image Analysis agents can automatically fill out forms by analyzing photos or scanned documents. 

The two agents can work together to help streamline workflow data entry:

  • Workflow Scanning Agent — Take a photo of a completed paper form, and the AI agent will read it and populate the corresponding digital form fields automatically.
  • Workflow Image Analysis Agent — Take a photo of a real-world area or piece of equipment, and the AI agent will analyze it and fill in the relevant inspection fields.

An internet connection is required to use the AI agents. Photos can be taken offline, but processing requires network access.

Configure the AI Agents in Advanced Workflows (WAB) 

The Workflow Scanning and Workflow Image Analysis agents must be enabled in the Cortex Control Center. Once enabled in the control center, you can configure the agents. 

  1. Navigate to the AI Settings tab within any Workflow.
  2. Under the AI Settings tab, toggle on the agent(s) you want to enable for that Advanced Workflows (WAB) solution.
  3. For each form in the Workflow, expand the Actions section.
  4. In the AI Settings section, you can do any of the following:
    • Select which agent to apply (if multiple agents are enabled).
    • Configure a button name, which is the label users will see on the AI button in the form.
    • Configure a prompt to guide the AI's behavior for this specific use case. This is submitted as a user prompt and cannot override system-level prompts.

Using Workflow Scanning and Workflow Image Analysis in Workflows

When you open a form that has an AI agent enabled, users see a button with the label configured for the form. 

  1. Click the AI button.
  2. Either take a photo using your device's camera or import an existing file from your device. Depending on the workflow, the image should be one of the following:
    • Workflow Scanning Agent - A completed paper version of the form you're filling out.
    • Workflow Image Analysis Agent - The physical area, equipment, or subject of the inspection.
  3. The AI agent will begin processing the image. If you cancel, no changes will be made to the form.

If the AI call has been sent before canceling, any token usage may still be counted toward your credit balance.

Reviewing AI-Populated Fields

Once the analysis is complete, fields populated by the AI are marked with an AI icon so you can easily identify them. Users can edit any field before saving. 

After saving, the AI icons and disclaimer banner are cleared.

If the AI finds nothing to apply, a message appears and no fields will be marked or populated. If you run the AI again on the same unsaved form, any previously AI-populated fields will be cleared and replaced with the new results.

Supported Field Types

The AI can populate the following field types:

  • Drop-down lists
  • Multi-select fields
  • Numeric fields
  • Text boxes (all sizes)
  • Boolean (yes/no) fields
  • Labels
  • Linked lists

Fields of unsupported types will be skipped.
