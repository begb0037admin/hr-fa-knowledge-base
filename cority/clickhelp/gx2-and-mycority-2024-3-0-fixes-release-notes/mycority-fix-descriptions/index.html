myCority Fix Descriptions

The table below lists the fixes we have made for myCority in the 2024.3.0 release. The fixes are organized by module and the modules are arranged in alphabetical order.

Item #Component(s)ReportedDescription
CCC-15208Business Intelligence – Data CubeN/A

Indicators created using the Data Cube that should display data now do display that data.

 

CCC-18930
Ergonomics
2024.2.2

An applicable Employee entity BRA will now create the appropriate log point in Employee Summary Key Activities when its business rule is triggered.


CCC-18426
Platform Administrator - Display Rules
N/A

The Layout display rule action now functions as expected for new records.


CCC-6501Platform
End-User - Demographics		N/A

The Driver’s License field name is now spelled correctly.

 

CCC-1735Platform
End-User - Questionnaires, OH		N/A

When applicable, the signature(s) for an unposted questionnaire are now visible prior to posting.

 

CCC-18647
Safety - Audits
& Inspections
N/A

If the ‘Create separate findings for questionnaire responses with the same finding type’ system setting is not selected and a user attempts to add an action to any Inspection questionnaire, an informative error message is now displayed.

If the system setting is selected, the user can now successfully add an action to any Inspection questionnaire.


CCC-17935 and 6548
Safety - Audits & Inspections
2021.3.0

For an Inspection questionnaire, the In Progress and Completed fields now interact and function properly no matter where or how the questionnaire was worked on or completed.
