GX2 Fix Descriptions

The table below lists the fixes we have made for GX2 in the 2024.3.0 release. The fixes are organized by module and the modules are arranged in alphabetical order.

Item #Component(s)ReportedDescription

For a report created in Query Builder with formatting added (for example, colors to columns), that formatting will now carry over as expected to a Microsoft Excel export of the report.

Under BI > Reports, a user can now open the Reports Queue without encountering any unexpected errors.

Administrator > Reports > Reports List Translations can now be used to successfully translate the titles of user-created reports, even if the reports themselves do not have a description included.

After running the Issue Frequency Report and using one of the available options to navigate to the Employee Risk Report, the number of records displayed will now be accurate.
