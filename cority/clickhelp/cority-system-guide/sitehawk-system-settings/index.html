SiteHawk System Settings

Cority uses the following system settings in order to successfully connect to SiteHawk’s Server.

  • SiteHawk FTP Address ‒ ftp://ftp.sitehawk.com
  • SiteHawk FTP Username ‒Username provided by SiteHawk
  • SiteHawk FTP Password ‒ Password provided by SiteHawk

Make sure that you have acquired valid credentials from SiteHawk and populated the system settings before scheduling SiteHawk Import.

For Self-hosted clients, make sure that the firewall rules allow to connect to FTP over port 21. Please provide the host / server’s external IP Address to SiteHawk so that it can be whitelisted by them.
