5.10 Enabling the Time-driven Business Rules (TDBR) Functionality

This functionality provides the ability to set up business rules that are time-driven.

To enable time-driven business rules:

  1. Obtain the source files from the TDBR directory of the installation package.
  2. Copy those files into a folder on the server.
  3. Inside the Sites folder provided, there is a site file (with .site extension). In the site file, provide the following nodes from your properties.config file (actual values in brackets): connection.connection_string (nhConnectionString), default_schema (nhDefaultSchema), olapdatasource (nhOlapDataSource), olapdatabase (nhOlapDatabase)
  4. Open the Windows Command Prompt application in Administrator mode.
  5. Execute: cd C:\Windows\Microsoft.NET\Framework\v4.0.30319 (or other version, if applicable)
    Optional: If you are installing multiple instances or changing the frequency, open the config file Medgate.NMedgate.TDBRS.exe.config, and make changes to respective nodes.
  6. Execute: InstallUtil.exe [folder location on the server]\Medgate.NMedgate.TDBRS.exe
  7. Open Local Services in Windows. Locate the TDBR Service. Right-click TDBR Service and select Start Service.
    If you want the site file to be encrypted, change EncryptSiteFiles to true in Medgate.NMedgate.TDBRS.exe.config. Then right-click the TDBR service, select Properties, select Log On, and specify Local System account.
  8. Open the TDBRLog.evtx log file under C:\Windows\System32\winevt\Logs\ to check the process log and ensure the service is running successfully.

If you have trouble with any of these steps, contact Cority Support.
