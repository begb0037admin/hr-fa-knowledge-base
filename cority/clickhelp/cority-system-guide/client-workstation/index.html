Client Workstation

The following are requirements for the client workstation:

  • Google Chrome 34 or later
    Apple Safari 5.1.7 or later
    Mozilla Firefox 3 or later
    Microsoft Edge
  • Microsoft .NET Framework v6.0

.NET framework is not required on all client workstations. It is only required when the workstation is running a Windows client for a web service, such as the Cority HR Integration Utility (formerly MEIP).

  • Acrobat Reader 7 or later
