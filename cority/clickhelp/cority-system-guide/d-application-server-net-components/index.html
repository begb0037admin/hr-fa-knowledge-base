Application Server (.Net Components)

The middle tier of the application, the business layer, uses objects based on Microsoft .Net framework. These objects encapsulate application logic and provide a simple interface to the upper tier.

Cority also provides a collection of web services, for major modules of the system.

Clients or third parties that wish to develop their own programs that work against the Cority database, may utilize those services, and do so safely without corrupting the database, as could be the case, if the updates were done directly.

The Application Server must be a Microsoft Windows Server with Microsoft .Net framework.
