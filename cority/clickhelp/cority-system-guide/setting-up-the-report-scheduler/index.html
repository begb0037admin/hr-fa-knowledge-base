Setting up the Report Scheduler

The Report Scheduler requires the creation of a scheduled task.

To set up a scheduled task to generate the report nightly:

  1. Go to Start > Administrative Tools > Task Scheduler.
  2. On the Task Scheduler window, click Create Basic Task.

  1. Name the task (for example, Report Scheduler), and then click Next.

  1. Choose the Daily update frequency, and then click Next.

  1. Set the start date and time for when you want the task first performed. Set the start date to be the current date. Since this process may be long and resource-intensive if many reports are scheduled to be sent, it is advised that you set the time to be during off hours. Click Next to continue.

  1. For Action, select ‘Start a program’, and then click Next.

  1. Click Browse and navigate to the Internet Explorer program (for example, C:\Program Files (x86)\Internet Explorer\iexplore.exe).

You also need the report scheduler URL for your Cority installation. For example, if your Cority application URL is: Cority.com/pr" style="text-decoration: none;;color: #0000FF; text-decoration: underline;">http://dev.Cority.com/pr then your report scheduler URL is: Cority.com/pr/reportscheduler/send.rails" style="text-decoration: none;;color: #0000FF; text-decoration: underline;">http://dev.Cority.com/pr/reportscheduler/send.rails

  1. Enter the report scheduler URL into the ‘Add arguments (optional)’ field.

  1. Ensure that ‘Open the Properties dialog for this task when I click Finish’ is checked, and then click Finish.

  1. Click Change User or Group, select the credentials you want the task to use, and then click OK.

  1.  Select Run whether user is logged on or not and then click OK.

The Report Scheduler will now be configured to send scheduled report emails every day, starting at the start time you configured.
