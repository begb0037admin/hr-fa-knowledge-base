Install the License Key

The application is pre-licensed for access to the administrator module only. This allows you to login and verify that your installation is successful.

By default this will not allow you access to any of your licensed modules, you must update the license key. To do this open SQL Server Management Studio and start a new query to update the table DT_LicenseKey with the license key provided to you by Cority.

Once the license key has been updated you will then have access to all your licensed modules in the application.

The license key is cached in the application. To have it refresh with the new license key in the database, go to Administrator – System Settings and click on the ‘Refresh License Key from the Database’ action.

If the license key in the database is not a valid, it will not be refreshed in the application but the old license key will still be used until IIS is reset. If an invalid license key is entered, the message ‘License key on the database was invalid and application still using old key. (MG-000644)’ will appear. If the license key is valid, the message ‘Refreshed License Key’ will appear.
