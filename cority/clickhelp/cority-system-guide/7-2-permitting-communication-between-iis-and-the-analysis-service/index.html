7.2 Permitting communication between IIS and the Analysis Service

  1. After installing SSAS on the server, with the same administrator account on the same server, open SSMS. In the Object Explorer, select Connect > Analysis Services.

  1. Enter “localhost” for the server name, and then press connect.
    You should now be connected to the Analysis Service. Now right-click localhost and select     Properties.

  1. Click Security at the left, and then click Add.
  2. Enter the anonymous internet user account that you wrote down earlier. It should be IUSR_<computername>, by default.
    You have now permitted IIS to communicate with the Analysis Service.
