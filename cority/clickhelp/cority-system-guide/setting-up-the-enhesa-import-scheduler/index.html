Setting up the ENHESA Import Scheduler

The ENHESA Import Scheduler requires the creation of a scheduled task.

To set up a scheduled task to import from SiteHawk:

  1. Select Start > Administrative Tools > Task Scheduler.
  2. On the Task Scheduler window, click Create Basic Task.

  1. Name the task (for example, ENHESA Import), and then click Next

  1. Choose the Monthly update frequency, and then click Next.

  1. Set the start date and time for when you want the task first performed. Set the start date to be the today’s date and time as 4 am. For Months, select ‘<Select All Months>’; and for Days, select the date when you want the task to be executed. It is recommended to select ‘1’ for this.

  1. Click Next to continue.

  1. For Action, select ‘Start a program’, and then click Next.

  1. Click Browse and navigate to a browser program.
    (for example, if you are using Internet Explorer program then C:\Program Files (x86)\Internet Explorer\iexplore.exe, or if you are using Chrome then C:\Program Files (x86)\Google\Chrome\Application\chrome.exe).

You also need the ENHESA Import URL for your Cority installation.

For example, if your Cority application URL is Cority.com/pr" style="text-decoration: none;;color: #0000FF; text-decoration: underline;">http://dev.Cority.com/pr
then your report scheduler URL is Cority.com/pr/ehnesa/refreshtrigger.rails" style="text-decoration: none;;color: #0000FF; text-decoration: underline;">http://dev.Cority.com/pr/ehnesa/refreshtrigger.rails

  1. Enter the report scheduler URL into the ‘Add arguments (optional)’ field.

  1. Ensure that ‘Open the Properties dialog for this task when I click Finish’ is checked and then click Finish.

  1. Click ‘Change User or Group’ and select the credentials you want the task to use, and click OK.

 

  1. Select ‘Run whether user is logged on or not’ and click OK.

The ENHESA Import is now configured to run on 1st of every month at 4am starting on the start time you configured.
