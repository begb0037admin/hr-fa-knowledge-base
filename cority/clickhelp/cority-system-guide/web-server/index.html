Web Server

The following are requirements for the web server:

  • Windows Server 2008 R2 / 2012 / 2016
  • 2 GHz+ x64 Processor
  • 8 GB RAM
  • Microsoft Internet Information Server v7.5+
  • World Wide Web Publishing service
  • Simple Mail Transfer Protocol (SMTP) service
  • Microsoft .NET Framework v4.8

SQL Server database connectors

  • Microsoft SQL Server ODBC driver

Roles and Features (for self-hosted clients only)

  • Roles:
  • File Services
  • Web Server (IIS)
  • Features:
  • Remote Server Administration Tools
  • SMTP Server
  • Windows Process Activation Service
  • .NET Framework 4.8 Features
