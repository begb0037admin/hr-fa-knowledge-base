Installing the Session Start Database Using the Aspnet_regsql.exe Tool

The session state database is needed for storing the session variables in the database instead of storing in memory.

To install the session state database on SQL Server, run the Aspnet_regsql.exe tool located in the systemroot\Microsoft.NET\Framework\versionNumber folder on your database server (e.g. C:\WINDOWS\Microsoft.NET\Framework\v4.0.30319).

From the command prompt (Start, Run, cmd), go to the folder where the aspnet_regsql.exe is located and execute aspnet_regsql.exe -S SampleSqlServer -E -ssadd -sstype p. Replace ‘SampleSqlServer’ with the name of the SQL Server.

The user running this command must have administrative privileges on the SQL Server.

The user created in the previous step (“gxuser”) needs to have “db_owner” privileges assigned to the ASPState database.
