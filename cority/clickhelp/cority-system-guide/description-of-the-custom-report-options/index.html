Description of the custom report options

Report Details

  • Report Name – The file name of the report, without the extension
  • Module – The module to which the report belongs
  • Description – The title or a brief description of the report
  • Inactive – If the report is active (that is, available in the Reports list)

Look-up Field Filters

  • Employee – Allows you to filter by employee. Note: The custom view must have the field
  • EmployeeId
  • Health Center – Allows you to filter by health center. Note: The custom view must have the field
  • HealthCenterId
  • Geographic Location – Allows you to filter by geographic location. Note: The custom view must have the field
  • GeographicLocationId
  • Department – Allows you to filter by department. Note: the custom view must have the field
  • DepartmentId
  • Division – Allows you to filter by division. Note: The custom view must have the field
  • DivisionId
  • Location – Allows you to filter by location. Note: The custom view must have the field
  • LocationId
  • Organization – Allows you to filter by organization. Note: The custom view must have the field
  • OrganizationId
  • Floor Area – Allows you to filter by floor area. Note: The custom view must have the field
  • FloorAreaId
  • Building – Allows you to filter by building. Note: The custom view must have the field
  • BuildingId
  • Job Position – Allows you to filter by job position. Note: The custom view must have the field
  • JobPositionId
  • Facility – Allows you to filter by facility. Note: The custom view must have the field
  • FacilityId
  • Supervisor – Allows you to filter by supervisor. Note: The custom view must have the field
  • SupervisorId
  • ShiftCode – Allows you to filter by shift code. Note: The custom view must have the field
  • ShiftCodeId
  • User – Allows you to filter by user. Note: The custom view must have the field
  • UserId
  • Multiple Job Position Supervisor – Limits the custom report query to only the data that pertains to the supervisor specified and those employees who report to that supervisor

If this field is present on the form, a value must be provided for it.

  • Multiple Job Position Filter – Allows you to filter by job position status for the employee. Note: The custom view must have the field

Date Field Filters

  • Date Field – The database field name in the custom view that will be used as the Date Range criterion
  • Date Label – The label of the date range selection

Custom Look-up Field Filters

  • Lookup Table – An additional field on which you can filter
  • Lookup Field – The look-up field name in the custom view
  • Lookup Label – The label of the custom look-up parameter

Additional Criteria

  • Sort By – Allows you to sort by a field in the custom view
  • Signed Records – Allows you to filter by signed records

The custom view must have the associated field.
