Database Server

The following are requirements for the database server:

  • Microsoft SQL Server 2016 / 2019, with the latest service pack
  • SQL Server Analysis Services (hosted on a separate server)
  • 2 GHz+ x64 Processor
  • 8 GB RAM (16 GB recommended)
  • SAS Hard Drive, with RAID 10 (recommended)
  • Approx. 50 KB per employee per year of disk space (for example, for a company with 6000 employees: 6000 * 50 KB = 300 MB / year)
