Web Server (Crystal Reports)

All reports in Cority are generated on the server using Crystal Reports runtime components. This product installs on the Web Server and generates reports which are then downloaded to the client web browser. There is no report processing on the client.

Crystal Reports runtime components must be installed on the same web server where Cority’s application is installed.
