Cube Database

  • Microsoft SQL Server Analysis Service (SSAS),
  • Microsoft SQL Server Management Studio (SSMS)
    • SSAS and SSMS are components of Microsoft SQL Server. Refer to the Microsoft SQL Server documentation for information on how to install these components.
  • 15 GB HDD, 4 GB RAM
      • The requirement for hard drive space depends on the size of the data tables in the Cority relational database. The larger the relational database grows, the larger the cube database grows. 15 GB of hard drive space is enough storage for the cube server to generate cubes for a relational database of moderate size.
  • Fast disk access
      • To ensure a timely response from the cubes, use hard drives in RAID arrays.
  • Optional dedicated Analysis Service server
      • The Analysis Service does not have to be installed on the same machine as SQL Server. Ideally, the Analysis Service should be installed on a dedicated machine because the Analysis Service requires a lot of hard drive activity for queries and data processing.
  • A user, either locally on the SQL Server machine or in the active directory domain, that has read access to the relational database.
