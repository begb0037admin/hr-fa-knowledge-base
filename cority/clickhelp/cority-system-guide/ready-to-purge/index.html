Ready to Purge

This process moves audit records linked to Archived employees to the Ready to Purge state (from History Reason 4 to History Reason 5).

To have records moved from Archived to Ready to Purge:

  1. Create a business rule with Ready to Purge conditions.
      

    For specific information on working with business rules, see the     Cority User Guide.
  2. Using the Action List tab, add the BRA-ReadytoPurge action to the business rule.

  3. From the Actions menu, select Preview Records to Purge.

  1. Run the Start Trigger Thread (<your Cority domain>/businessrules/starttriggerthread.rails) script to move any records in the Archived state to the Ready to Purge state.

To report on Employee records that are in the Ready to Purge state:

  1. Create a Report Writer report with the Employee Record History entity, and add the criteria you require.
    To report on the records that are ready to purge, you will need to add the Employee Record History Reason and make it greater than 4 (for ReadyToPurge).



    For more specific information on creating Report Writer reports, see the     Cority User Guide.

  2. Run your report.
    The report will list the records that are in the Ready to Purge state.
