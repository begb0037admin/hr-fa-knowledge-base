5.6 Configuring the Nightly Exposure Group Compliance Report

The nightly Exposure Group Compliance report is similar to the regular Exposure Group Compliance report. The difference is that the former can be scheduled to run nightly, during off hours. This is useful when you want to run the report in a large corporation and the report will take a long time to generate.

To set up a scheduled task to generate the report nightly:

  1. Select Start > Administrative Tools > Task Scheduler.
  2. On the Task Scheduler window, click Create Basic Task.

  1. Name the task (for example, Reports Nightly Update), and then click Next.

  1. Choose the update frequency you want, and then click Next.

  1. Set the start date and time for when you want the task first performed, and then click Next.

  1. For Action, select Start a program, and then click Next.

  1.  Click Browse and navigate to the Internet Explorer program (for example, C:\Program Files (x86)\Internet Explorer\iexplore.exe).You also need the report update URL for your Cority installation.
    For example, if your Cority application URL is: Cority.com/pr" style="font-size: 11pt; color: #0000ff;">http://dev.Cority.com/pr then your report update URL is:  Cority.com/pr/report/nightlyupdate.rails" style="font-size: 11pt; color: #0000ff;">http://dev.Cority.com/pr/report/nightlyupdate.rails
  1. Enter the report update URL into the ‘Add arguments (optional)’ field.

  1. Ensure that ‘Open the Properties dialog for this task when I click Finish’ is checked, and then click Finish.

  1. Click Change User or Group, select the credentials you want the task to use, and then click OK.

  1.  Select Run whether user is logged on or not, and then click OK.

The nightly Exposure Group Compliance report will now update at the start time and then with the frequency you configured.
