5.7 Configuring Report Scheduler

The Report Scheduler can be used to send a recurring e-mail to a list of recipients that contains a Cority report attachment, a Report Writer report attachment, or a Dashboard view.

Report scheduling can be a long and resource-intensive process, depending on the items scheduled to be sent. Therefore, it is recommended you run the Report Scheduler during off hours.
