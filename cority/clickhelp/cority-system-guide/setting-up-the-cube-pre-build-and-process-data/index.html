Setting up the cube pre-build and process data

The cube pre-build and process data requires the creation of a scheduled task.

To set up a scheduled task to pre-build and process cube data nightly:

  1. Select Start > Administrative Tools > Task Scheduler.

  1. In the Task Scheduler window, click Create Basic Task.

  1. Name the task (for example, Cube Scheduler), and then click Next.

  1. Choose the Daily update frequency, and then click Next.

  1. Set the start date and time for when you want the task first performed.
    Set the start date to be the current date. Since this process may be long and resource-intensive, it is advised that you set the time to be during off hours.

  1. Click Next.

  1. For Action, select ‘Start a program’, and then click Next.

  1. Click Browse and navigate to the Internet Explorer program (for example, C:\Program Files (x86)\Internet Explorer\iexplore.exe).

You also need the Cube Scheduler URL for your Cority installation.

For example, if your Cority application URL is Cority.com/pr" style="text-decoration: none;;color: #0000FF; text-decoration: underline;">http://dev.Cority.com/pr then your Cube Scheduler URL is Cority.com/pr/cube/prebuildandprocessdata.rails?analysisServiceName=http://cubeservername/olap/msmdpump.dll" style="text-decoration: none;;color: #0000FF; text-decoration: underline;">http://dev.Cority.com/pr/cube/prebuildandprocessdata.rails?analysisServiceName=http://cubeservername/olap/msmdpump.dll

AnalysisServiceName value must be the same <nhOlapDataSource> value inside properties.config. Also, properties.config should point to the server where msmdpump.dll was installed.

  1. Enter the Cube Scheduler URL into the ‘Add arguments (optional)’ field.

  1. Ensure that ‘Open the Properties dialog for this task when I click Finish’ is checked, and then click Finish.

  1. Click ‘Change User or Group’, select the credentials you want the task to use, and then click OK.

  1. Select ‘Run whether user is logged on or not’ and then click OK.

The Cube Scheduler will now be configured to process data every day, starting at the start time you configured.
