Install Crystal Report 2011 Runtime

The Crystal Report 2011 runtime installation files in the Cority package in the “Crystal” folder. Depending on if you webserver is 32-bit or 64-bit, run corresponding “CRRuntime_NNbit_13_0_3.msi”
