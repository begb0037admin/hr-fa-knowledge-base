Database Server

Cority is compatible with SQL Server 2016 / 2019.

There is no operating system dependence for the database. Any operating system (such as Unix of NT), or machine may be used, if it is compatible with the underlying database version.

Oracle Assistance for Self-hosted Clients

If you are using an Oracle database and you are sending it to Cority for assistance, you must create a backup of your database first. This is required.

For Oracle 10, create a backup of the database using the Data Pump utility. For Oracle 9, create a backup of the database using the Export (exp) utility.

Also, we recommend you provide the following:

  • export log file
  • export parameter file
  • table space name
  • schema name
  • database/schema dump file
