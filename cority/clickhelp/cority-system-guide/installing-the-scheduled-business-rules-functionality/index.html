5.12 Installing the Scheduled Business Rules Functionality

This will provide the ability to configure and use Scheduled Business Rules (TDBRWorker).

To enable Scheduled Business Rules:

  1. Obtain the source files from the TDBRWorker directory of the installation package.

  2. Run the TDBRWorker.sql script on your database.

  3. Copy the files into a folder on the server and copy the utils.config from your Web folder.

  1. In the Sites folder provided, there is a site file (with .site extension). Within that site file, provide the following nodes from your properties.config file (the required values are in parentheses): connection.connection_string (nhConnectionString), default_schema (nhDefaultSchema), olapdatasource (nhOlapDataSource), olapdatabase (nhOlapDatabase)

  2. In the config file (Medgate.NMedgate.TDBRWorker.exe.config):

a. Set the CentralDbConnectionString parameter to the nhConnectionString from your properties.config file.
You can provide a UTF-8 encryption based on the key within the utils.config.

b. Set the TDBRWorkerId parameter to TDBRWorker_1.

c. Set the ServerId parameter to Release.

d. Set the MaxActiveThreads parameter to 1.

e. Set the EOPdfLicense parameter to the EOPdfLicense from your Web folder’s server.config.

  1. Open the Windows Command Prompt application in Administrator mode.

1. Execute the following command: cd C:\Windows\Microsoft.NET\Framework\v4.0.30319 (or your installed version, if applicable)

2. If you are installing multiple instances or changing the frequency, open the config file (Medgate.NMedgate.TDBRWorker.exe.config), and make the changes to the appropriate nodes.

3. Execute: InstallUtil.exe [folder location on the server]\Medgate.NMedgate.TDBRWorker.exe

  1. Open Local Services in Windows. Locate the TDBR Service. Right-click TDBR Service and select Start Service.

  2. If you want the site file to be encrypted:

1. Change EncryptSiteFiles to true within Medgate.NMedgate.TDBRWorker.exe.config.

2. Right-click the TDBR service, select Properties, select Log On, and specify Local System account.

3. Open the TDBRWLog.evtx log file under C:\Windows\System32\winevt\Logs\ to check the process log and ensure the service is running successfully.

If you have trouble with any of these steps, contact Cority Support.
