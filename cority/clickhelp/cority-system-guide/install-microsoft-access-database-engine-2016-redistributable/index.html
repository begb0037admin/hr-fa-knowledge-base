Install Microsoft Access Database Engine 2016 Redistributable

This is an optional step and you only need to install it if you use the AIHA Spreadsheet in Cority.

  1. Download Microsoft Access Database Engine 2016 Redistributable from http://www.microsoft.com/en-us/download/details.aspx?id=13255.
  2. Install by following the provided instructions.
