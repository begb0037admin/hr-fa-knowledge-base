Using Multiple SSO Providers

SSO users can now acquire valid authentication from one of several IDPs when logging into Cority.

To support this, there is a new ‘SamlKey’ look-up table for configuring all available single sign-on (SSO) providers. The new look-up table provides a default list view and a new ‘Saml Key’ layout.

To create or edit values in the ‘SamlKey’ look-up table, the Admin security module must be granted to one of the user’s roles. For information on working with look-up tables or role security, see the Cority User Guide.

Once an SSO provider record is configured for an IDP (identity provider) in the ‘SamlKey’ look-up table, an SSO user can log in through the IDP by simply logging into Cority, and then on another tab of the same web browser, providing the following URL and pressing the Enter key: http://<your Cority domain>/security/login.rails?idp=<IDP Name>

One of the records in the 'SAML Key' look-up table should be marked as default. If the URL above is provided without any IDP name, the default IDP will be used.

If a client has SAML SSO set up using system settings in GX2u Patch B or earlier and upgrades to 2018.1 or later, a 'SAML Key' look-up table record with the following must be created:

  • IDPName
  • Login Link (from System Settings)
  • Certificate (from System Settings)
  • Marked as Default
