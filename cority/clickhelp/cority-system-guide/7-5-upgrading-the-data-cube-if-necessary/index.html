7.5 Upgrading the Data Cube (If Necessary)

The Data Cube must be upgraded whenever there is a creation script included in the release package (e.g., Cube_Create_2018.2.xmla). To upgrade the Data Cube, you must delete the existing Data Cube and re-create it using the latest creation script.

  1. Open SSMS.
  2. In the Object Explorer, select Connect > Analysis Services, connect to the Analysis Service instance that hosts your Data Cube.
  3. Right-click the Data Cube and click Delete.

  1. Click OK on the Delete Objects dialog box.

  1. Follow the steps in subsection 7.3 to re-create the Data Cube.
