GX2 Descriptions

The table below lists the fixes and minor improvements we have made in GX2 2026.1.0. They are organized by module, and the modules are in alphabetical order.

Item #Component(s)Description
CCC-24639BI - Dashboards

For Advanced Dashboards, the ‘Add Indicator(s)’ feature now functions as expected.

 

CCC-23401BI - Query Builder

In Query Builder, the ‘Business Rule Actions’ query now functions properly and without generating any unexpected errors.

 

CCC-22115Clinical Monitoring - Smart Notes

The smart notes row span issues have been fixed.

 

CCC-24890Demographics

On the Employees list, when selecting a value from a Tree Selector (for example, Geographic Location) or for a Date field, the cursor will now remain in that field instead of unexpectedly jumping over to the first column (Full Name).

 

CCC-24053Environmental - Audits

A user can now successfully create an Environmental ‘Audit’ record with required fields and ‘Equipment Group’ populated and save without generating any unexpected errors.

 

CCC-7939Environmental - Chemical Management

In Environmental ‘Chemical Inventory’, the ‘Add Chemical to Waste Container’ action now functions properly.

 

CCC-25554Environmental - Imports

Into the ‘Investigation EHS’ look-up table, a user can now successfully import a supported value for the ‘Environmental’ check box field without generating any unexpected errors.

 

CCC-24963Environmental, Import Utility

For importing recurring actions using the Import Utility, the validation has been enhanced to help ensure the recurrences function as expected after import.

 

CCC-22698Environmental

In the Environmental cloud, when clicking modules on the left navigational menu, the Environmental icon will now remain selected.

 

CCC-25702Ergonomics - Case Manager

For a Case Manager worksheet, if a user clears the issue ID from linked issues, that will no longer break Risk Inventory Value updates back to GX2 for all linked issues.

 

CCC-25530Ergonomics - Case Manager

For Case Manager, there is a new Personal Risk Preference with code “case_manager_display_history_logs_in_user_time”. By default, it is not selected. When it is not selected (or is inactive), at the bottom of a Case Summary the History list will report dates and times according to the server time (UTC). If it is selected (active), those times will be reported according to the user’s local time.

 

CCC-25513Ergonomics - Case Manager

When applicable, the Attribute Data Type drop-down field with appropriate options will now be available.

 

CCC-25016Ergonomics - Case Manager

PDF versions of Case Manager ‘Evaluation’ reports now format correctly. For example, sections and subsections without any data are no longer shown and pictures are now paginating correctly.

 

CCC-24774Ergonomics - Case Manager

For Case Manager, where applicable, when demographics are set to be visible (for example, the Location field), the description will now be displayed, as expected, instead of the code.

 

CCC-24205Ergonomics - Case Manager

When applicable, within Case Manager ‘Setup Management’, security groups can now be deleted.

 

CCC-24576IH - Compliance

On Compliance Actions, when applicable, the ‘Is Recurrent’ check box is now available for use and functions properly.

 

CCC-24899IH - Findings & Actions

In Findings & Actions, for a daily recurring series that has no end date, when the last action in the series is completed, the next one that is created automatically will now have an incremented due date, as expected, instead of the same due date.

 

CCC-20558IH - Noise Monitoring

In IH Noise Monitoring, for emailed letters, time stamps will now match.

 

CCC-25133IH - Risk Assessment

You can now import data into RAS.RAInterviewedEmployee using all supported import methods.

 

CCC-23671IH - Risk Assessment

On completed IH ‘Risk Assessment’ records, any records on sublists will now be locked (not editable) on the sublist itself and in the form view.

 

CCC-24494OH / IH - Questionnaires

An issue that was preventing the 'Show/Hide Related Question(s)' functionality on an RFT questionnaire from working properly has been fixed.

 

CCC-23805OH / IH - Questionnaires

When applicable, on a standalone Respirator questionnaire, the Location look-up selector now functions as expected (and without generating any errors).

 

CCC-25166OH - Appointments

For the Microsoft Outlook integration with the Appointments module, the Scheduling Assistant now remains available regardless of the duration of the event.

 

CCC-23988OH - Appointments

For appointments, Brazilian Portuguese translations will now apply properly (for example, for day and month names).

 

CCC-24067OH - Immunization

An Immunization Recall Report letter saved as a standard query that retrieves data for an employee with long First Name / Last Name and is configured to be delivered by email with recurrence pattern of ‘Every 1 Day’ ending after one occurrence will now function properly.

 

CCC-23022
OH - Reporting

The performance and error messaging (when necessary) of the Medical Records Report has been improved.


CCC-23319
Platform Administrator - Impersonate User
When using the impersonate user feature, the CorityOne Waffle functionality is no longer available.
CCC-15232
Platform Administrator - Roles

The '<<TableName>>/Import' REST API endpoint now has the new removeRole option. That option can be used to remove roles from the user.


CCC-25633
Platform Administrator - System Settings

The 'Open Default Document for Chemical Product SDS Hyperlink' system setting is now Global and locked.


CCC-23388Platform - Business Rules

A business rule configuration that contains a date range filter with dates relative to today will now import successfully, without generating any unexpected errors, and the date range filter will function correctly.

 

CCC-15066Platform - Business Rules

The Business Rule Conditions functionality now supports round bracket parentheses characters in flex field questions. That resolves an issue that was preventing multiple flex fields being selected.

 

CCC-21311Platform - Business Rules

In the Business Rule Actions queue, when the user selects Actions > SBRA Queue (Recently Processed) and filters on a status of Failure, that now functions properly and without generating any error messages.

 

CCC-21047Platform - Business Rules

With time in System Settings set to Pacific, a business rule that has an Email BRA and scheduled recurrence set to every weekday with no end date will now run as expected on Monday, Tuesday, Wednesday, Thursday, and Friday, and only on those days.

 

CCC-24739Platform - Display Rules

When a display rule limit for an entity is configured and has been reached, if the user attempts to activate and save a display rule for the same entity, an appropriate notification will now display and the save will be prevented.

 

CCC-24641Platform - End-User

When changing list views, the focus now returns to the first editable input field (column), as expected.

 

CCC-20130Platform - End-User

An issue that was creating TreeMasterCode duplicates has been fixed.

 

CCC-25229Platform - Infrastructure

TDBRService and TDBRWorker logging can now be turned on and off.

 

CCC-24328Platform - Interfaces

When the constraint check of a REST API call for inserting or updating a record of a particular entity fails, the correct error message now displays.

 

CCC-22197Quality - Management of Change

For an applicable MoC business rule that does not have a prompt, when appropriate, the BRA merge field for the Approver will now populate.

 

CCC-25440Quality - Nonconformance and Complaints

For the Quality ‘Nonconformance’ (ML-003208) and ‘Complaint’ (ML-003235) layouts, the UDF LU 1 through 6 fields are now available again and can be added to custom versions of those layouts. *Note:* If they had been added previously to a custom layout, they will have remained on that layout.

 

CCC-24206
Questionnaires, Reporting

When a Questionnaire Crosstab Report saved as a standard query is brought into Report Scheduler, the CSV export option is now available in Advanced Details.


CCC-15217
Questionnaires

For a question on a Flex Field questionnaire that will accommodate an attachment, the attachment can now successfully be deleted.


CCC-2198
Questionnaires

For questionnaire building, the following Single Question ’Valid Choices’ layout fields can now be added as columns to applicable custom list views:

  • Finding Type
  • Unacceptable Response
  • Response No
  • TimeStamp

CCC-24585Safety - Compliance

For a Safety ‘Legal & Other Requirements’ Corrective Plan, on created Compliance Actions, when applicable, the ‘End After # Recurrences’ and ‘Recurrence End Date’ values will now be correct.

 

CCC-7643Safety - Findings & Actions

For assigning business rules to a Safety ‘Finding’ layout, when the user clicks the Business Rules tab, the tab will now filter and sort any rules on it appropriately.

 

CCC-23333Safety - Management of Change

In Safety ‘Management of Change’, for a properly configured workflow, any required fields at a workflow step will now function as expected.

 

CCC-24441Safety - Permits

For a Safety ‘Permit’ with GDDLOFB and a Corrective Plan that has two Corrective Action Plans, when applicable, the correct number of Compliance Actions will now be created for both Action Plans.

 

CCC-25622Safety/Environmental/Quality

Where applicable, 5 Whys Analysis now functions as expected.

 

CCC-23671Safety - Risk Assessment

On completed Safety ‘Risk Assessment’ records, any records on sublists will now be locked (not editable) on the sublist itself and in the form view.

 

CCC-14321Safety - Risk Assessment

In Safety ‘Risk Assessment’, for a Task-Hazards-Control record with multiple ‘Legal Requirements’ records, the ‘Copy Process/Task’ action now functions as expected, without generating any errors.
