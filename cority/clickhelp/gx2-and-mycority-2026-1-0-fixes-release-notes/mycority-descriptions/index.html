myCority Descriptions

The table below lists the fixes and minor improvements we have made in myCority 2026.1.0. They are organized by module, and the modules are in alphabetical order.

Item #Component(s)Description
CCC-6807
Business Rules

Scheduled BR API actions can now be configured to trigger successfully in myCority as long as the entity is not Questionnaires, Campaigns, Metrics, or Inspections.


CCC-20196Display Rules

A display rule properly configured with Action as the entity, the ‘Safety Action’ and ‘Safety Action Assignor’ layouts selected, and a display rule action that requires one or more fields will now function as expected in myCority.

 

CCC-24230Organizational Trees

In myCority, the default maximum nodes for Organizational Trees is now reset to 1000. Where applicable, that also resolves an issue that was preventing GDDLOFB fields from accepting data.

 

CCC-14448Platform End-User

When guest users are being redirected to a specific link on login (for example, an Event Report), if the guest selects a language from the Login screen before clicking ‘Guest Login’ then logging in, the selected language will now be maintained after login.

 

CCC-13077Platform End-User

Where applicable, Employee picklists (including custom Employee picklists) are now searchable.

 

CCC-23232Safety & Quality

When the same employee is assigned to multiple investigation levels, questionnaires created by that employee will no longer become read-only in myCority.
