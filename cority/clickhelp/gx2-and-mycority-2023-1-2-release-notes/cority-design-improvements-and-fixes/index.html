GX2 Design Improvements and Fixes

The table below lists the design improvements and fixes we have made in the GX2 2023.1.2 release. The items are organized by component and the components are arranged in alphabetical order.

Item #Component(s)ReportedDescription
CCC-12233Business IntelligenceN/A

The 'Export to Excel' action now executes successfully on Query Builder reports that have average sick leave data.

CCC-11766

Chemical Management

When a new 'Agent Hazard' record is created and the following fields are not on the layout, null (not invalid '0') values are now saved for them in the database.

  • Criteria Pollutant
  • DRE
CCC-10930

Environmental –

Chemical Management

N/A

Two or more 'Chemical Product' records can now have a 'Related SDS' record with the same code.

CCC-12436

Environmental / Safety –

Compliance Management

N/A

Regardless of how recurring compliance actions are configured and generated, the correct number of recurrences will now be created.

CCC-9914

Environmental –

Chemical Management

N/A

The following new text UDFs can now be added to custom versions of the 'Agent Hazard' and 'Chemical Product' look-up table layouts: UDFText5 through UDFText23

Each field can accommodate a maximum of 1000 characters.

The fields are available in Query Builder and Report Writer, and for use in business rules and display rules.

The fields' values can be populated or edited using the Import Utility or the Cority Data Integration Utility.

CCC-12436
Environmental – Compliance
N/A
The timeout for the creation of recurring actions has been increased so that regardless of the configuration creations now allow up to the following number of recurrences:
• No End Date - hard-coded to 52
• End after [X] occurrences or End by [Date] - strongly recommend no more than 400 because more than that is likely to impact performance.
The user should not navigate away from the screen or save or refresh the record while the system is creating the recurrences.
Note: This does not apply to those created from Corrective Plans.
CCC-12414ErgonomicsN/A

For a personal 'Risk Inventory', on the 'Issue Resolution Config' tab, a user can now successfully add an image to the text box for a step and save the record.

CCC-12400ErgonomicsN/A

In the Office Ergonomics cloud, the arrow for the 'Desktop Usage Risk' gauge on the 'Desktop Summary' tab is now present by default.

CCC-12390ErgonomicsN/A

In Office Ergonomics, the Translations tab has been added to the default Risk Type (ML-003659) layout.

CCC-12245ErgonomicsN/A

In Office Ergonomics, the following two new views have been added to the 'Manage Employee Risk' list view:

  • Active Employees - filtered to only active employees
  • Inactive Employees - filtered to only inactive employees

'Active Employees' is now the default view.

CCC-12201ErgonomicsN/A

The following new functionality will enable an ergonomics professional to look at only those risk factors currently affecting the employee's risk levels.

A new 'Show Inventories Affecting Risk' checkbox has been added to the 'Manage Employee Risk' screen. It is located to the left of the 'Show History' button.

When the checkbox is selected, all Risk Inventories (RIs) with a current 'Risk Inventory Value' (RIV) for which the 'Risk Equation Value' is 0 are hidden from the screen.

A new 'Show Facts' checkbox has been added to the 'Manage Employee Risk' screen. It is located to the left of the 'Show Inventories Affecting Risk' checkbox.

When the checkbox is selected, the RIVs on the 'Manage Employee Risk' screen are filtered to RIs for which 'Count as Fact' is true.

'Show Facts' and 'Show Inventories Affecting Risk' cannot be selected simultaneously. Selecting one will deselect the other. 

'Show History' can be selected at the same time as either 'Show Facts' or 'Show Inventories Affecting Risk'.

The 'Show History' button has been converted to a checkbox in the style of the two new checkboxes.

CCC-11882ErgonomicsN/A

In Office Ergonomics, Case 'Criteria Sets' can no longer be deleted.

CCC-11668ErgonomicsN/A

The Desktop Summary from Personal Risk in myCority has been added as a tab to the 'Manage Employee Risk' screen in GX2.

This will help provide an Ergonomics Administrator with a complete picture of a user's status from one screen.

Note: The new tab is only available if the 'Enable RSIGuard Risk' system setting is selected.

CCC-10339ErgonomicsN/A

For Office Ergonomics, the Desktop Actions data table is now available for use in business rules.

CCC-5295Industrial HygieneN/A

A user with the appropriate role and site security configured can now successfully generate a notification letter from the Sample tab of an IH Survey record.

Occupational Health –

Audiometric

CCC-12749Platform – AdministratorN/A

When the Questionnaire Crosstab report is run by Report Scheduler, the questionnaire questions no longer translate to the language of the user who scheduled the report.

CCC-12222Platform – AdministratorN/A

When creating or editing a custom layout, if you add a field with a tooltip that has a URL-referenced image, the entire tooltip with image will now appear on the layout as expected.

CCC-12082TrainingN/A
