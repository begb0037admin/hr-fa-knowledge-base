CCC-15765: Permits associated with Corrective Plans can now automatically generate recurring actions

Opt-In

When creating a Corrective Plan Action, users can now check the 'Is recurrent' checkbox to set a recurrence plan for a Corrective Action. The checkbox becomes available once the Effective Date of the Action is set and the Corrective Plan Action is saved.

When selected, the 'Recurrence Settings' window will open to configure the frequency at which to generate tasks for the Corrective Plan.

A Safety Permit associated with the Corrective Plan will list all the recurring Compliance Action tasks generated from the Corrective Plan Action.

The number of tasks generated is based on the recurrence frequency as follows:

  • Daily Recurrence – generates a daily task for the next year.
  • Weekly Recurrence – generates a weekly task for the next year.
  • Monthly Recurrence – generates a monthly task for the next five years.
  • Yearly Recurrence – generates a yearly task for the next five years.

After the task due date, the next task will be automatically created. For example, for yearly recurring tasks, when the due date passes for the current year's task, a new task will be created for five years from the current year.

If the recurrence frequency of the action is updated, all uncompleted tasks are deleted and new tasks are generated based on the new recurrence.
