Summary of Platform Enhancements

The table below contains design improvements we have made to the platform. The items are organized by component, and the components are arranged in alphabetical order. Descriptions of any larger features follow the table.

ItemComponent(s)Description
CCC-21820End-User

The Kendo UI being used has been upgraded to version 2025.1.227.

 

CCC-16479Health, Risk

In all clouds with the Risk solution, the character limit for the Risk ‘Job Description’ field has been increased from 500 to 2500.

 

CCC-22440myCority – Employee Picklists

Where applicable, for Employee picklists, Boolean fields, hard-coded system lists, look-up fields, organizational trees, and all text field column headers are now searchable.


There is a helpful training video for this on the Cority Academy.

 

CCC-24905myCority - Platform

For myCority, the Angular web application framework has been upgraded to version 20.1.
