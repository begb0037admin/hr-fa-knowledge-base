CCC-19786Nonconformance, Complaints

The following new fields can now be added to custom versions of Quality ‘Nonconformance' and 'Complaints’ layouts:

  • 15 new look-up table UDFs, numbered 22 through 36
  • 10 new numeric (integer) UDFs, numbered 7 through 16
  • 10 new Flag (check box) UDFs, numbered 7 through 16

Each of the look-up table fields has a corresponding new look-up table. Each look-up table has a default list view and layout with appropriate columns/fields, and each functions as a typical GX2 look-up table.

For each new field, the equivalent column can be added to applicable custom list views.

The fields can be used in business rules, display rules, and workflows, and can be reported on using Query Builder and Report Writer.

Each of the new fields can be prohibited from user roles.

Values for the fields can be added or updated through import (Import Utility or REST API).
