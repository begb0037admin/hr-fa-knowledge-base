Summary of Industrial Hygiene Enhancements

The table below contains design improvements we have made in the Industrial Hygiene cloud. The items are organized by component, and the components are arranged in alphabetical order.

ItemComponent(s)Description
CCC-23109Monitoring, Surveys

When an IH Monitoring Survey is copied using the Actions > Copy function on the IH Survey form, the Job Name, Task, and Process values now all get copied into the new Survey. Those values are important for understanding the monitoring plan.

 

CCC-16505Risk Assessment, myCority

myCority users can now add individuals to exposure groups associated with a job.

 

In myCority, when creating a new IH Risk Assessment, there is a new Exposure Group sublist which lists the SEGs associated with the job. The SEGs are added to the job in GX2.

 

In the Exposure Group sublist for the job, you can select a SEG to add or inactivate employees. In the 'Employee' tab of the SEG, click the 'Add' button and select employees to add. When adding an employee to a SEG, you can specify a start date, and to inactivate an employee enter an end date.

 

Note: Employees can only be added to SEGs that are flagged as Industrial Hygiene Use.
