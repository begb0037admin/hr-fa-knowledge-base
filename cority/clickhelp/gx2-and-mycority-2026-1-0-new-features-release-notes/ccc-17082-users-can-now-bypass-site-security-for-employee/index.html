CCC-17082: Users can now bypass Site Security for Employee picklists to assign records to people outside of their site

Opt-In

In GX2 System Settings, a new global setting, 'Provide Admins with Bypass Site Security option on customer configured Employee picklists', is now available. When selected, a new 'Bypass Site Security' check box will be available to administrators for new and existing custom Employee Picklist layouts. By default, the check box will be unchecked when creating or cloning a new Employee picklist.

When the 'Bypass Site Security' option is enabled for an Employee picklist, users will be able to select employees outside of their site security when creating and assigning a record.

Note: Site Security will always honor Employee Demographics and record types that inherit Organizational Trees from demographic records.

Disabling the 'Provide Admins with Bypass Site Security option on customer configured Employee picklists' system automatically removes the 'Bypass Site Security' from all Employee picklists that have it active.

This functionality has the following limitations:

  • In myCority Offline, only the All Active Employees picklist is available and Site Security will always apply.
  • In myCority, the Permit to Work Authorized Employees sublist does not reflect the Bypass Site Security when turned on. This will be addressed in a future release.
  • Employee Sublists with Multiple Select configured will not have the 'Select' button. This will be addressed in a future release.

  • GX2 users with Limited Site Security will not be able to save when creating a new record that inherits Employee organizational tree information and selecting an Employee outside of their Site Security without first modifying the trees that are associated to the new record.
  • Users with limited Site Security will not be able to see and complete records assigned to them in GX2. Instead, they will need to complete or make any edits from myCority.
