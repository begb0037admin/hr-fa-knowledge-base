CCC-18038: In myCority, the workflow for inspection responses and actions has been streamlined

N/A

When a response on an inspection with a manually triggered action is changed, or when a comment or attachment is added or modified, the Finding Details will now automatically update with the new response, comments, and attachments.

A new 'Delete Actions' button is also now available to allow users to delete a manually triggered Finding and Action. The option to delete is only available until the inspection is submitted. 

Auto-created Findings and Actions from a question are still deleted when a response or comment is changed. Adding attachments to a question no longer deletes the Findings and Actions.

Creating and deleting Findings and Actions is not supported in Offline.

Note: For Numeric question types, there are inconsistencies in the behavior of how Actions are updated with changes to the question response, comments, and attachments. This will be addressed in a future release.

There is a helpful training video for this on the Cority Academy.
