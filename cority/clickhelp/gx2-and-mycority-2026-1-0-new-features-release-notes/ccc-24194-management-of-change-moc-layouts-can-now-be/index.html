CCC-24194: Management of Change (MOC) layouts can now be configured to auto-populate the GDDLOFB fields

Opt-In

To support this, for custom Environmental, Quality, and Safety MOC layouts, there is a new ‘Organizational Trees Use Employee Demographics’ check box. It can be added to custom layouts, and the equivalent column can be added to applicable custom list views. By default, the check box is not selected.

To use the check box, the user’s role must be granted the corresponding security action:

  • Environmental - environmentalmanagementofchangetype.orgtreeemployeedemographics
  • Quality - qualitymanagementofchangetype.orgtreeemployeedemographics
  • Safety - safetymanagementofchangetype.orgtreeemployeedemographics

For users whose role do not have the action, the check box will be de-selected and read-only.

When the check box is selected, the GDDLOFB fields present on the layout for the new record will auto-populate with the corresponding Demographics values of the employee in the ‘Requested By’ field.

Note: When you click ‘New Change Request’ and select the ‘Management of Change Type’, the ‘Requested By’ field auto-populates with the employee associated to the user.

If the employee name in the ‘Requested By’ field gets changed after the GDDLOFB fields have been auto-populated, the GDDLOFB field values will update accordingly.

If a user changes a GDDLOFB value manually after the values were auto-populated and saves the record, the updated value will be retained.

If the user de-selects the check box, the values already populated will be retained.

When the setting is not selected, on new Change Request records the GDDLOFB fields will remain empty until manually populated.
