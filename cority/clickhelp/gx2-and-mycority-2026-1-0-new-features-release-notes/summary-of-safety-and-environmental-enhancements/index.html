Summary of Safety and Environmental Enhancements

The table below contains design improvements we have made in the Safety and Environmental clouds. The items are organized by component, and the components are arranged in alphabetical order. Descriptions of any larger features follow the table.

ItemComponent(s)Description
CCC-21315Safety - Incident

The following two forms have been updated:

  • The Texas 'Employer’s First Report of Injury or Illness'
  • The New Brunswick ‘Employer Report of Injury or Illness’

This includes the field mappings required for your organization to remain in compliance.

 

CCC-1483Incident Management

When configuring a business rule email action for the Safety Incident entity:

  • Both ‘Incident Categories’ and ‘Injured Employees’ are now available in the Merge Fields list.
  • ‘Investigation Email Addresses’ are now available in Email Merge Fields and can be added to the To and Cc fields.

When configuring a business rule email action for the Environmental Incident entity:

  • ‘Incident Categories’ is now available in the Merge Fields list.
  • ‘Investigation Email Addresses’ are now available in Email Merge Fields and can be added to the To and Cc fields.

 

CCC-25443Chemical Management

In Environmental ‘Label Management’, on the Label Setup tab of a Label Template, the following fonts have been added to the font drop-down menu in the Preview:

  • Noto Sans SC
  • Noto Serif Thai
  • Noto Sans KR

These fonts support non-roman alphabet systems.

Also, the following smaller font sizes have been added to the font size drop-down menu in the Preview: 11, 10, 9, 8, 7, 6, 5, 4

These fonts and font sizes can be applied and will be accurately reflected on screen and when printed.

 

CCC-18330Chemical Management

For the 3E integration, there is a new ‘Open Default Document for Chemical Product SDS Hyperlink’ system setting. It is a check box. It is categorized under Chemical, and by default it is selected.

When selected, the document marked as default will be displayed when clicking the Chemical Product SDS hyperlink. The default document must be marked as active. If no default document is defined, the record with the most recent revision date will be displayed.

 

CCC-23400Waste Management

In the Waste Container module, the ‘Update container inventory’ modal box screen is now a layout. The default version of the new layout has applicable options and fields, and functions similarly to other typical GX2 layouts. The layout is also accessible in Administrator > Layouts.

From the modal box, custom versions of the layout can be created and optional fields from the Waste Container table (including UDFs) can be added to them. For information on creating custom versions of layouts, see the GX2 User Guide.

When applicable, a new drop-down selector on the ‘Update container inventory’ modal box allows the user to select from any custom versions of the layout that have been created. Also, the modal box allows the user to pin a layout.
