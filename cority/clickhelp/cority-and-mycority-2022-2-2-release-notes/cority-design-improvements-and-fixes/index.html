Cority Design Improvements and Fixes

The table below lists the design improvements and fixes we have made in the Cority 2022.2.2 release. The items are organized by component and the components are arranged in alphabetical order.

ItemComponent(s)ReportedDescription
CCC-7173Environmental - IncidentN/A

For an Environmental dashboard with links to Incident records, the user can now click a link to an Incident record without generating an unexpected error.

 

CCC-9137Environmental - Emission InventoryN/A

When creating and populating an Emissions Inventory 'Asset Management' record on a layout that has both an Equipment Attributes and an Equipment UDFs subsection, an unexpected error regarding a formula will no longer be generated.

 

CCC-9358ErgonomicsN/A

In the SCOFileData look-up table, on the 'SCORM Variable Substitution' look-up table, the maximum number of characters for the Description field has been increased to 500.

 

CCC-8706ErgonomicsN/A

When creating a new Ergonomics 'Risk Inventory Value', the Save button now functions as expected.

 

CCC-8639Platform - AdministratorN/A

If the date format used in a saved Create Record BRA is not the same as the one specified for the user's Date Format system setting, the BRA will now function properly.

 

CCC-8229Platform - AdministratorN/A

When creating or editing a business rule for the FRA Incident entity and setting criteria, if the administrator selects an FRA form, the screen will no longer freeze.

 

CCC-8204Platform - AdministratorN/A

For Form Mapper, when a PDF is generated, translations now work as expected whether or not special characters have been used.

 

CCC-7796Platform - AdministratorN/A

In the Record History for a Safety Inspection/Survey record, the 'Modified By' and 'Created By' values are now first and last names, as expected.

 

CCC-7729Platform - AdministratorN/A

When a Create Record BRA that has a new record time field mapped to a time field from the main record entity is triggered, the corresponding time field on the new record will now get populated correctly.

 

CCC-6796Platform - AdministratorN/A

When configuring a Create Record BRA for Environmental 'Finding' records, the BRA will now save with an integer value set for one or more of the following fields:

  • Due Send Notification Days
  • Due Send Reminder Days
  • Overdue Send Notification Days
  • Overdue Send Reminder Days

 

CCC-4502Platform - Administrator2021.1.0

In Business Rules, where applicable, the ‘Add Actions to queue for record matching conditions’ feature now functions properly for all supported date formats.

 

CCC-4370Platform - AdministratorN/A

When applicable, Form Mapper will now properly map concatenated fields from Query Builder.

 

CCC-3233Platform - AdministratorN/A

For single questions with 'new line' spacing, translations will now function as expected.

 

CCC-2724Platform - AdministratorN/A

The user can now open form translations without generating any unexpected errors.

 

CCC-9050Platform - End UserN/A

With an imported JSON 'User' layout in GX2, if the user opens an Employee record, clicks New, selects the imported layout, and then clicks Save without adding any data, a notification about required field values will now be displayed, and an unexpected error message will no longer be generated.

 

CCC-8748Platform - End User2022.2.0

On a custom Environmental 'Incident' split-screen layout that has the Documents sublist in the right panel, when the user clicks New on the sublist, the new Document record will now open independently, instead of under the Documents sublist.


CCC-7866Platform - End UserN/A

For a date field that is located at the bottom of a layout or dialog box, the date-picker (when required) will no longer be truncated.

 

CCC-2817Platform - End UserN/A

When using the Save button or navigating from one screen to another, the Back button no longer reverts to an older style.

 

CCC-7379Platform - InfrastructureN/A

An email generated by a business rule will now be sent from the email address specified in the business rule, not the user who created the business rule (unless they are the same).

 

CCC-7296Platform - InfrastructureN/A

When using import, through GX2 or Cority web interface, to inactivate one or more parent or child tree nodes, this will now achieve the expected results.

 

CCC-7120Platform - InfrastructureN/A

For Safety 'Incident' records, translations now function as expected in both the Actions menu and on associated dialog boxes and picklists.

 

CCC-9688Platform - InterfacesN/A

When applicable, you can now connect to SOAP API as expected, without generating an unexpected error.

 

CCC-8718Platform - InterfacesN/A

When applicable, if integrating with an application that returns an API token containing a colon, the token will no longer become truncated, therefore the required BRA will now function properly.

 

CCC-8199Platform - InterfacesN/A

When applicable, a RESTful API PUT call can now update multiple records, as expected.

 

CCC-7829Platform - Interfaces2022.1.0

Using a RESTful API POST call, you can now successfully import multiple documents at once.

 

CCC-9288Safety - Audits & Inspections2022.2.0

For an Ergonomics or Quality Inspection with a questionnaire, the questionnaire will now display the correct Source and Source ID values.

 

CCC-7580Safety - Audits & InspectionsN/A

A user can now delete an in-progress or completed Safety, Ergonomics, Environmental, or Quality 'Inspection' questionnaire.

To do this, the user's role must be granted the new questionnaireresponseheader.deletestartedinspections security action. The action will be categorized under the appropriate (Safety/Ergonomics/Environmental/Quality) 'Inspection Admin' module.
