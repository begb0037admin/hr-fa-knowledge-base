myCority Design Improvements and Fixes

The table below lists the design improvements and fixes we have made in the myCority 2022.2.2 release. The items are organized by component and the components are arranged in alphabetical order.

Item #Component(s)ReportedDescription
CCC-8998ErgonomicsN/A

On an Ergonomics dashboard, when a risk color is not defined for an overall risk type, the resulting error message now indicates that.

 

CCC-8898Occupational Health – Employee Care N/A

When an appointment is created using myCority, the resulting email now provides the option to accept / accept tentative / decline without having to first open an ICS file.

 

CCC-9097PlatformN/A

When a business rule action (BRA) that uses the plus/minus date calculation is triggered, it will now produce the expected results in both myCority and GX2.

 

CCC-9395Platform2022.2.1

A submitted questionnaire that has been marked as a referral questionnaire will no longer be listed more than once in My Tasks.

 

CCC-9091PlatformN/A

For a myCority user, the Supervisor picklist now provides the expected view(s).

 

CCC-7905PlatformN/A

In 'My Records', for a 'Respirator Fit Test' record on a layout configured to include the Documents tab, the user can now open a document  without generating an unexpected error.

 

CCC-9402TrainingN/A

A training session with an inactive SCORM package will no longer be available in myCority.

 

CCC-8904TrainingN/A

When using training in myCority, the Exit button now works as expected without generating any unexpected errors.
