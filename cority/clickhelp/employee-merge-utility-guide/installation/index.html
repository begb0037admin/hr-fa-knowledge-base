Installation

If you have installed a previous version of the Employee Merge Utility, uninstall the old version before proceeding to this new installation.

  1. Install Microsoft .NET Framework 4.5.2. The download is available from the Microsoft website.
  2. Insert the Cority application CD and open the Employee Merge Utility folder.
  3. Double-click Employee Merge Utility Setup.msi to run the setup file. The Employee Merge Utility - InstallShield Wizard will open.

  1. Click Next.

  1. Click Change to select a destination folder for the Employee Merge Utility, or click Next to use the default folder.

  1. Click Install to begin the installation, or Back to review or change your installation settings.

  1. The InstallShield Wizard will begin installing the Employee Merge Utility. This process may take several minutes.

  1. When the installation is complete, click Finish to exit the InstallShield Wizard.

  1. After the program has finished installing, you will need to restart your computer. Once you have restarted your computer, the program will appear in your Windows > Start Menu > Cority folder.

  1. Read/write permissions are required so when Employee Merge Utility is running, the log file is written correctly. To grant read/write permissions to the user(s) who will be running Employee Merge Utility, right-click the Employee Merge Utility program file and select Properties. The Employee Merge Utility Properties form will open.
  2. Navigate to the Security tab and click Edit. The Permissions for Employee Merge Utility form will open.
  3.  Assign the appropriate permissions to the selected user(s). Click Add to insert a new user.

  1. Click OK to close the Permissions for Employee Merge Utility form.
  2. Click OK to close the Employee Merge Utility Properties screen.
