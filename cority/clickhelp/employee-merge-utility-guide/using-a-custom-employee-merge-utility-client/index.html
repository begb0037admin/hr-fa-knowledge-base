Using a Custom Employee Merge Utility Client

You also have the option to write your own client instead of using the client provided by Cority.

The provided Employee Merge Utility client merges employee records in Cority via the Employee Merge Utility Web Service, which can be used in your own custom clients. See the Employee Merge Utility Web Service API section for more details.
