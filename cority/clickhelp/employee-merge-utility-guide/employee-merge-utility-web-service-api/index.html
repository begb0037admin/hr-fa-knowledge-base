Employee Merge Utility Web Service API

Methods

IList<string>

 

Merge(byte[] rawData, string username, string password, string url)

This is the only method exposed for the employee global merge Web service. Calling this method will begin the merge process. This is a synchronous call, meaning it will block until the merge process is complete.

Parameters:

  • byte[] rawData – This is the list of pairs of employee numbers to be merged. The import file should contain two employee numbers per line, separate by a comma. The file should be read into a byte array and then compressed into a gzip stream for upload.
  • string username – the username to login as for the merge
  • string password – the password to login with for the merge
  • string url – the URL of the Web service being used
