GX2 Design Improvements and Fixes

The table below lists the design improvements and fixes we have made in the GX2 2025.3.1 release. The items are organized by component, and the components are arranged in alphabetical order.

Item #Component(s)ReportedDescription
CCC-23033AuditsN/A

There is  a new Audit Report in the Audits module of the following clouds: Safety, Environmental, Quality, and Ergonomics.

To support this, a new ‘Generate Audit Report’ action can now be added to custom versions of applicable Audit layouts.

When the ‘Generate Audit Report’ action is executed, from the modal box that opens, the user will be able to select the sections that will be included in the report and then generate the report.

Anyone who can edit the Audit layout that will be used can grant the roles that will be able to use that layout. Anyone with a role that can access that layout can use the new action.

 

CCC-12863BI - MetricsN/A

In Business Intelligence > Campaigns, from the ‘All Active Campaigns’ view, when the user double-clicks the status bar showing YTD Completion Status for an incomplete Campaign, the associated Missing Data report will now show the correct results.

 

CCC-23081BI – Query Builder2025.2.0In Query Builder, for a report that has more than one row of data, after the 'Set row limit' action is executed, any next action executed (for example, Export to Excel) will now function properly and without generating a warning message.
CCC-22193BI – Report SchedulerN/A

Reports emailed from Report Scheduler in either the PDF or Microsoft Excel format can now be password protected.
When scheduling such a report, the new ‘Password Protected’ option is now available. If that option is selected, a ‘Send without zip’ option appears. A password-protected report can be emailed with or without being zipped.
When applicable, the password to access the report will be sent in a separate email.

 

CCC-23893Business Rules – Documents N/A

For a business rule action in a ‘Document Control entity business rule, a properly configured 'Document Control’ subquery can now be selected.

 

CCC-16720Business RulesN/A

When editing a custom layout (for example, Safety ‘Nonconformance’) and cloning its Business Rules or Display Rules view, the pin functionality for the new view will now function properly.

 

CCC-23945Chemical ManagementN/A

A new business rule (BR-100670) with entity Chemical Product now ensures that a user cannot modify a Chemical Product record between the time the user submits the product to the Master Library and when the Master Library ID for the product is generated on the client site.

 

CCC-22550Chemical ManagementN/A

The following new user-defined fields (UDFs) are now available to be added to custom versions of the Chemical Symbol look-up table (LU_CHM_Symbol) layout (ML-000147):

  • Five new text fields, numbered 1 through 5
  • Five new flag (check box) fields, numbered 1 through 5

 

CCC-22387Chemical ManagementN/A

For data transfer from the Chemical Products Library to client sites, the performance has been improved. This reduces processing time and reduces the risk of timeouts.

 

CCC-16921Display RulesN/A

For a display rule configured to make a number of fields for a record type (for example, Safety Equipment MOC) read-only, after the rule triggered, saving an applicable record was generating an unexpected error. This has been fixed.

 

CCC-19752Environmental – Emissions InventoryN/A

The following new user-defined fields (UDFs) are now available to be added to custom versions of the Environmental EI Source Test Data layouts (ML-003472 and ML-3473):

  • Six new text fields, numbered 1 through 6
  • Six new flag (check box) fields, numbered 1 and 6
  • Six new numeric fields, numbered 1 through 6
  • Six new date/time fields, numbered 1 through 6
  • Six new look-up selector fields, numbered 1 through 6

For the look-up selector fields, the corresponding five look-up tables have also been added.

 

CCC-23807Environmental – Waste ManagementN/A

In Environmental > Waste Shipment, the ‘Waste Transporter’ look-up selector will now function as expected (and without any unexpected errors) when a filter has been applied to the picklist view for either ‘Facility State’ or ‘Shipping State/Province’.

 

CCC-23176Environmental – Waste ManagementN/A

Waste Container forms can now be printed in bulk from the Waste Container list view. To support this, the new ‘Bulk Print’ action can now be added to custom versions of the Waste Container list view.

The user selects any records with at least one PDF Waste Container form and then initiates the action. One PDF with the forms concatenated will be generated.

 

CCC-16463Environmental – Waste ManagementN/A

The following new user-defined fields (UDFs) are now available to be added to custom versions of the Waste layout (ML-000166):

  • Ten new text fields, numbered 21 through 30
  • Five new flag (check box) fields, numbered 11 through 15
  • Five new number fields, numbered 16 through 20
  • Five new look-up selector fields, numbered 1 through 5

For the look-up selector fields, the corresponding five look-up tables have also been added.

 

CCC-24054Event Reporting – Safety and EnvironmentalN/A

A new feature will enable users to submit Event Reports without having to save them first.
To support this, there is a new ‘Require Save before Submit’ check box that can be added to custom versions of ‘Event Report Type’ look-up table layouts. By default, the check box is selected, which retains the existing behavior. If added and deselected for a particular Event Report type, the saving of that type of Event Report prior to submitting will no longer be enforced.

 

CCC-19493EquipmentN/A

The following new user-defined fields (UDFs) are now available to be added to custom versions of Equipment UDF layouts:

  • Five new text fields, numbered 41 through 45
  • Five new look-up selector fields, numbered 1 through 5

For the look-up selector fields, the corresponding five look-up tables have also been added.

 

CCC-19490EquipmentN/A

The following new user-defined fields (UDFs) are now available to be added to custom versions of Environmental, Ergonomic, IH, OH, Quality, and Safety Equipment layouts:

  • Two new flag (check box) fields, numbered 4 and 5
  • Five new real number fields, numbered 1 through 5
  • Five new look-up selector fields, numbered 1 through 5

For the look-up selector fields, the corresponding five look-up tables have also been added.

The equivalent column can also be added to custom versions of the myCority Asset view.

 

CCC-3306Industrial HygieneN/A

When the user creates a new IH Monitoring or Noise Monitoring sample before midday, the sample Date will now be correct. It will no longer default to the day before, regardless of where the database for the environment is located.

 

CCC-9693Inspections / Surveys / ObservationsN/A

When applicable, for Inspections/Surveys/Observations with Recurrence = None, regardless of Start Date value, the Inspection Questionnaire will now be added (and accessible where expected) upon assignment.

 

CCC-23083Management of ChangeN/A

For a custom ‘Change Request’ list view with any of the approver fields used in the filtering criteria (for example, Safety Local Approval = <a valid employee name>), if the user selects ‘Edit View’, on the View Editor the view will remain filtered by the defined criteria and the criteria will be displayed and editable.

 

CCC-16921Management of Change – Display RulesN/A

For a display rule configured to make a number of fields for an MOC record type (for example, Safety Equipment MOC) read-only, after the rule triggered, saving an applicable record was generating an unexpected error. This has been fixed.

 

CCC-23787Occupational Health - Appointments2025.3.0

In the Appointments module, when applicable, the Notification Bell views can now all be pinned.

 

CCC-23558Occupational Health - AppointmentsN/A

In the Appointments module, for the Schedule Entry functionality, the Pin icon now changes shape as well as color to indicate pinned or not pinned.

 

CCC-18747Occupational Health – ImmunizationN/A

Six time user-defined fields (UDFs) are now available to be added to custom versions of Immunization layouts (ML-000311 and MLs-000311).

 

CCC-19414Occupational Health – Medical Records ReportN/A

For the Medical Records Report, where applicable (for example, in the body of the email sending the report) and when necessary, wider images are now scaled to fit.

 

CCC-23721Occupational Health – Scheduling N/A

In Occupational Health ‘Scheduling’, when scrolling, items that should remain static at the topic of the screen now do that.

 

CCC-23676Organizational TreesN/A

On the Organizational Tree, if a user inactivates a node, it will now still be accessible (as expected), therefore can be reactivated.

 

CCC-18010Platform Administrator – Interfaces N/A

For creating more complex RESTful API calls, advanced conditions are no longer required.

 

CCC-24224Platform End-User – Recurring ActionsN/A

For a recurring Action, if a user updates the value of one or more fields and saves the Action, regardless of the Due Date (for example, a Due Date older than one year or a Due Date in the future), ‘Is Recurrent’ will remain selected.

 

CCC-20713Platform End-User – ActionsN/A

Actions, recurring or otherwise, created and assigned prior to release 2024.3 that have a Due Date older than one year can now be completed in GX2 and myCority.

 

CCC-10603QuestionnairesN/A

When a user is navigating on a questionnaire (in Clinic Visit, for example), after the user populates required fields and clicks either Save or Actions, the cursor no longer moves to unexpected locations. Both the Save button and the Actions menu now function as expected.

 

CCC-24387Safety – Findings & Actions2025.2.1

In Safety ‘Finding and Actions’, for an Action that is part of a series, if the user clicks ‘View Recurrence Setting' the Save button on the 'Recurrence Setting’ window is read-only, now when the use closes that window, the Save button on the Action remains active.
