myCority Design Improvements and Fixes

The table below lists the design improvements and fixes we have made in the myCority 2025.3.1 release. The items are organized by component, and the components are arranged in alphabetical order.

Item #Component(s)ReportedDescription
CCC-22900BI - MetricsN/A

When working on Campaigns in myCority, the system will no longer accept a number entered with a comma and remove the comma (for example, an entered 7,4 would be accepted and changed to 74). Now if a user enters a number with a comma, an error message lets the user know the number is invalid and will not be accepted.

 

CCC-23586Event Reporting – QuestionnairesN/A

For an Event Report with a questionnaire that has a parent question with one or more required child questions for one of the question’s responses, if another response is selected (not triggering the required child questions) and the questionnaire saved, the Event Report can now be successfully submitted from an applicable record on an associated list.

 

CCC-20713Platform End-User – Recurring ActionsN/A

Actions created and assigned prior to release 2024.3 that have a Due Date older than one year can now be completed in GX2 and myCority.

 

CCC-20864QuestionnairesN/A

The PDF exporting/printing of questionnaires has been enhanced. This includes:

  • Images in the questionnaire are now exported/printed
  • For questions with sections or multiple pages, the user can now select the section or page that gets exported/printed
  • Print and export behave the same way, printing/exporting all that is expected
  • The layout of exports and printed versions has been optimized so that the output is both more compact and easier to read
