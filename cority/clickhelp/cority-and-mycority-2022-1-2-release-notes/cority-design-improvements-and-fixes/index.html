Cority Design Improvements and Fixes

The table below lists the design improvements and fixes we have made in the Cority 2022.1.2 release. The items are organized by component and the components are arranged in alphabetical order.

Item #Component(s)ReportedDescription
CCC-7500Business Intelligence2021.3.0

In Query Builder, when importing, the screen no longer refreshes each time the user selects an expandable field.

 

CCC-7039Business IntelligenceN/A

In Query Builder, the 'Combine with other subqueries' option now functions as expected in all supported environments.

 

CCC-7282Custom MetricsN/A

On an Objective record, for assigned custom metrics, the Completion/History data is now accurate and the 'Is Target' check box now functions as expected.

 

CCC-7040Custom MetricsN/A

For a metrics campaign, you can now select assignees without encountering any screen freezing or display issues.

 

CCC-7915Findings & ActionsN/A

For an environmental action or compliance action that is assigned to a group, when the 'Complete as a Team' check box is selected, any associated MAEN configuration now functions as expected.

 

CCC-6762Emissions Inventory2021.3.0

In the Emissions Inventory module, on a Source Profile record, when the user attempts to create a new Related Asset record, the new record's Source ID field will now auto-populate, as expected.

 

CCC-7822Environmental – ComplianceN/A

When applicable, for ENHESA legal requirements, translated values will now appear on applicable list views as well as the records.

 

CCC-7955Inspections and Surveys2021.1.1

On a Safety, Environmental, or Ergonomics Inspections and Surveys Report, assigned group and/or teams are now shown.

 

CCC-7454Platform – AdministratorN/A

When using any of the import tools to move a parent and its children from one node to another, all associated lineages now update as expected.

 

CCC-5640Platform – AdministratorN/A

The 'View Application as User' action now works as expected and no longer generates any unexpected errors.

 

CCC-5393Platform – Administrator2021.2.2

On a business rule, the 'Business Rule Action' subsection heading now has spaces between the words.

 

CCC-2205Platform – Administrator2021.2.0

When GX2 is configured to be using IDP-initiated SAML 2.0 SSO authentication, the GX2 user can now successfully log into the Cority User Community.

 

CCC-2057Platform – Administrator2020.3.1

In the Objective Types look-up table, the user can now enter a description of up to 2000 characters without encountering an unexpected error.

 

CCC-7289Platform – InfrastructureN/A

Prototype JavaScript Framework has been upgraded to version 1.7.3.

 

CCC-7020Platform – InfrastructureN/A

After a SQL failover, a time-driven business rule (TDBR) that was running will now continue to run.

 

CCC-6845Platform – InfrastructureN/A

In GX2, jQuery has been upgraded to version 3.6.0.

 

CCC-6676Platform – InfrastructureN/A

In GX2, Scriptaculous (script.aculo.us) has been upgraded to version 1.9.0.

 

CCC-7817Platform – Interfaces N/A

Each 'Cority Employee Merge' SOAP web service request now requires valid username and password authentication.

 

CCC-7727Safety – Contractor N/A

In the Safety cloud, on a Contractor 'Project' record, Flex Fields now function as expected.

 

CCC-7749Safety – IncidentN/A

The Ontario WSIB Form 7 (Employer's Report of Injury/Disease) can now be submitted successfully, when data that can be missing is missing, without any unexpected XML validation error.

 

CCC-7035Safety – Incident N/A

In the Safety cloud, Incident Investigation records that are read-only now remain read-only where applicable.

 

CCC-6186Waste ManagementN/A

In the Waste Container Management module, when executing the 'Inventory Waste Containers in Bulk' action, the Waste Profile views now display the expected records.

 

CCC-5405Waste ManagementN/A

In the Waste Management module, on the main list view, the Disposal Method picklist now provides all of the expected values.
