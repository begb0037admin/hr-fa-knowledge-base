GSE-975: UI enhancements and quick document access streamline the approvals workflow for environmental data.

  •  Now, users can easily download supporting attachments, such as invoices, directly from the Approvals page, which will provide additional insight and context for approving specific sustainability metrics.
  • Users will be notified where specific data might be missing, based on historical data uploads, enabling faster error resolution and increasing the accuracy of metrics data. 
    Note: This functionality is optional. If you would like to use it, an Administrator can enable it through Admin > Environment > Data Approval.
  • Also, user interface enhancements have been made throughout the workflow, such as variance calculations shown in a sub-grid that provide a breakdown of the data for easier approvals, along with icons for easily accessing supporting attachments and comments.
