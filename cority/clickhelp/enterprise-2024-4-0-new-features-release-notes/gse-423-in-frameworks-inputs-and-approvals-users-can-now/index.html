GSE-1348: Data interconnectivity to external systems is enhanced through new outbound API endpoints.

  • Now new outbound API endpoints are available for all consumption and emissions types.
  • They enable users to export their carbon management data seamlessly from CorityOne through API into all third-party external systems (for example, into business intelligence, reporting platforms, Power BI) for further data visualizations. 
  • Users can also automate API calls and requests for specific data points at regular intervals, which will reduce administrative time and make it easier to monitor changes in data.
