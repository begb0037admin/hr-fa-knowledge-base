Fix Descriptions

The table below describes the fixes we have made for 2024.2.0.

Item #Component(s)Reported VersionDescription
CCC-7836Business Intelligence – Query BuilderN/A

Query Builder can now be used to successfully report on documents, uploaded using myCority, for questionnaire question responses.

 

CCC-17775MetricsN/A

A user with the required security configuration can now successfully (without generating an unexpected error) open a Campaign with a measure that has an associated unit of measure with a factor value.

 

CCC-14634Occupational Health – Audiometric TestingN/AAudiometric questionnaires now display in full.
CCC-8959Platform – End-UserN/A

If the 'Display as Radio Button' option is specified, any related field property selections will now be applied properly in myCority.

 

CCC-17229Permit to WorkN/A

For a saved Work Permit with a questionnaire (created manually or using a business rule), the questionnaire can now successfully be worked on and saved, and completed and saved, in myCority.

 

CCC-15702Questionnaires, Findings & ActionsN/A

For a questionnaire configured to auto-create Findings & Actions, the first question response that triggers the creation of a Finding & Action (Finding type with an associated Action type) will now also create the Action portion of the record. Therefore, the Organizational Tree will populate accordingly. 

 

CCC-7940QuestionnairesN/A

If a user attempts to submit without first saving a questionnaire that has assigned actions, the appropriate error message will now display.
