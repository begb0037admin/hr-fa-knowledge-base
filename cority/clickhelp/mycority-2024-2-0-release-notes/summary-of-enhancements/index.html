CCC-16177 and 17083Platform Administrator

myCority users (or users of the older Portal application) can now be created using the GX2 'Import Utility'.

Note: This can already be accomplished using the Cority HR Integration Utility.

To support this, a new check box has been added to Import Utility > Data Tables > Employee. The check box is labelled 'Auto-Create Portal-Only User for Login ID'.

By default, the check box is not selected.

If selected and a login ID is provided correctly in the import file, a new user will be auto-created with the login ID as the username.

The user will be assigned the Portal role, and the associated new User record will be populated with any other acceptable details that were provided (for example, a linked Employee record).

The following requirements must be met for the user to be created successfully:

  • The login ID must not yet exist.
  • The termination date on an associated Employee record must either be null or after the current date.
  • The Portal license 'User Count Limit' must not currently be reached.

Note: To reset the password and log into myCority or Portal, the 'Forgot Password' feature must be used. If the user is configured for SSO/LDAP, this step is not necessary.

CCC-15369Safety – Permit to Work

In GX2 and myCority, the Work Permit (Permit to Work Risk) sublist provides two new views:

  • Isolations Details for this Permit, which by default has the following columns:
    • Job Step, Equipment Description & Asset Tag, Equipment Lock & Tag No., Applied By, Isolation Integrity Checked By, Integrity Checked Date, Removed By, Removed Date
      • Integrity Checked Date and Removed Date are read-only.
  • Detailed Risk for this Permit, which by default has the following columns:
    • Step #, Job Step, Area / Job Hazard, Free Text Hazard, Initial Severity, Initial Likelihood, Initial Risk, Control Type, Free Text Control, Residual Severity, Residual Likelihood, Residual Risk
      • Initial Risk and Residual Risk are read-only.

Also, for the Work Risk sublist, the following columns have been added to the 'Isolations for this Permit' view: Job Step # and Job Step

A user can inline-edit on applicable columns.
