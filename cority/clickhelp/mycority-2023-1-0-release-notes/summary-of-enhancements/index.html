Summary of Enhancements

The table below describes the enhancements we have made in 2023.1.0.

Item #Component(s)Description
CCC-9102Ergonomics

The Ergonomics cloud now provides a summary of an employee's personal risk. This will help ergonomists attend to people who are at risk. See CCC-9102 in the GX2 2023.1.0 New Features Release Notes document for more information.

 

CCC-6474Ergonomics

In Ergonomics 'Personal Risk', a new 'RSIGuard - Desktop Summary' tab is now provided. Note: This is only available to users who have an active installation of RSIGuard and when the 'Enable RSIGuard Risk' system setting is selected.

 

CCC-9131Findings & Actions

If one or more questions on an Environmental, Ergonomics, Quality, or Safety Inspection questionnaire has attachments, those will now be accessible to the Assignee from the Documents sublist of any corresponding auto-created 'Action' records.  This will also be available for other solutions that support auto-creation of Findings & Actions from a questionnaire (Incident, Audits, Management of Change, etc.).

 

CCC-8862Findings & Actions

On Environmental, Ergonomics, Quality, and Safety 'Action' records auto-created from an Inspection (Surveys or Observations), the Info icon is now provided. If you click the icon, any relevant (if available) details for the originating Finding will display.

 

CCC-10372Platform – Administrator

.NET has been upgraded to version 6.0.

 

CCC-1371Questionnaires

When creating subquery type questions and selecting options for the answers, myCority will now allow users to filter for those options. Also, the options will be translated if applicable.

 

Note: When creating a subquery report for the Subquery question type, a sort order should be stipulated for one (or more) of the columns. If it is not, myCority will simply sort by the first column and the Record ID value.  The column header sort functionality available in the GX2 platform is not possible in myCority.  

 

In addition, for subquery questions it is no longer necessary to grant the corresponding security actions to the user's role. That is still required though to create/update business rules that use subqueries.
