Fix Descriptions

The table below describes the fixes we have made for 2023.1.0.

Item #Component(s)Reported VersionDescription
CCC-10747Occupational Health – Medical RecordsN/A

When running the 'Medical Records' report for an employee, if site security prevents the report from containing any data, the report will no longer run. An error message will instead be displayed.

 

CCC-7569 and 6683Platform – Administrator2022.1.0

A number of potential security vulnerabilities have been addressed.

 

CCC-10869Platform – End-UserN/A

On a foreground email for a business rule email action and Map indicators in My Dashboards, all of the expected icons now display and function properly.

 

CCC-11315Questionnaires2022.3.0

A myCority user can now open and save/submit a questionnaire that has no question responses, has no GDDLOFB section, and is to be submitted to the Quality 'Questionnaire Inbox', without encountering an unexpected error.

 

CCC-8669QuestionnairesN/A

If the Employees picklist is used to select a different employee, the personal information in the questionnaire header will now change to reflect that. This ensures that when the questionnaire is submitted, it arrives in the Inbox with the correct employee information.

 

CCC-6124QuestionnairesN/A

On questionnaires in myCority, for subquery question types, translations will now function as expected.
