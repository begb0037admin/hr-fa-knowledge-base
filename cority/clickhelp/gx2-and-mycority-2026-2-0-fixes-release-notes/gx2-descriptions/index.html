GX2 Descriptions

The table below lists the fixes and minor improvements we have made in GX2 2026.2.0. They are organized by module, and the modules are in alphabetical order.

Item #Component(s)Description
CCC-27566Environmental - Inspections, Questionnaires

An issue that was generating an error and preventing the completing and saving of an Environmental Inspection questionnaire (with a valid choice value selected that has a Finding Type value) has been resolved.

 

CCC-23970Environmental - Inspections

When applicable, for a completed Environmental ‘Inspection’ that is then printed, the Signature field will now properly display the signature.

 

CCC-28111Environmental - Permits

The ‘Permit Condition’ entity is now available for use in business rules.

 

CCC-27931Ergonomics - License Key, Motion Capture

After a license key is added or updated, the fields Ergonomics - Motion Capture Users, Ergonomics - Motion Capture Class 2 Users, Office Ergonomics Users, and Office Ergonomics Class 2 Users no longer get cleared. They retain any previously saved values.

 

CCC-27721Ergonomics - Reporting

The Overall Break Compliance Report will no longer be able to find, therefore list employee records with totals of over 100%.

 

CCC-28309
Ergonomics - Risk Assessment

The Personal Risk microservice will now delete older log files when the maximum number of archived log files has been reached.


CCC-27285Ergonomics - Risk Assessment

For an employee who is in a ‘Group and Team’ that is assigned multiple Risk profiles, those profiles will now be assigned successfully to that employee within Demographics. That will enable the employee to open any assigned assessments.

 

CCC-27964IH - Monitoring

The user can now successfully create a new IH > Monitoring record using a custom Personal Sample layout that does not have the Sample Status field added without generating any unexpected errors.

 

CCC-21207IH - Monitoring

The Monitoring Results list view now has the same site security applied as the Monitoring module.

 

CCC-20101IH - Monitoring

For standard ‘Batch Letter Monitoring Report’ queries scheduled using Report Scheduler, and with both ‘Back-Up Delivery Email Address’ and ‘Send Email only to Back-Up Delivery Email Address’ configured for those queries, the reports will now be sent only to the correct person (or people, if applicable).

 

CCC-27334IH - Noise Monitoring

An issue that was causing the calculation of the Leq from a dose entry in personal noise dosimetry to produce incorrect values has been resolved. They are now correct regardless of the option selected for the ‘Dose/Lav Calculation Based On’ system setting.

 

CCC-20452IH - Risk

On an IH Risk Assessment with a ‘Task/Hazard/Controls’ record that has Agent ‘Noise’, if you run statistical analysis, the results will now match the equivalent results in the ‘Detailed Noise Monitoring Results’ report.

 

CCC-24803OH - Appointments

For the Appointments module, an issue that was causing available time slots to display where time had been booked has been resolved.

 

CCC-28049OH - Clinic Visit, Documents

An issue that was incorrectly generating a ‘Row Level Security’ error when trying to access or upload documents to a Clinic Visit record has been resolved.

 

CCC-24584OH - Drug Testing

In the Drug Testing module, when using the ‘Import Results’ action and the HL723_v2 standard, both the import and ‘Result Date’ will now function as expected.

 

CCC-17486OH - Drug Testing - REST API

For the REST API Drug Testing Import endpoint, when invalid Laboratory/Standard values are passed, the appropriate error message will now be displayed.

 

CCC-27667OH - ePrescribing

With the proper security configuration, you can now successfully register users for EPCS Gold without encountering any issues.

 

CCC-25416OH - Immunization

On an Immunization record, when the Dose Date gets updated, the Recall Dose Date will now update automatically.

 

CCC-27947OH - Layouts, Actions

On a layout (particularly split-screen, multi-panel) with a large number of actions configured, the user can now successfully scroll to access all actions in the Actions menu.

 

CCC-27756OH - Layouts, Lists

On a layout, for a list, after editing it using the ‘Pencil’ icon on the Configuration popup and clicking ‘Done’, the ‘Pencil’ and 'X' icons no longer disappear from that popup.

 

CCC-20853OH - Management Referral

If a user opens a signed (therefore locked) Management Referral Response questionnaire, changes nothing, then clicks ‘Save and Close’, existing content within the questionnaire will no longer be deleted.

 

CCC-19417OH - Medical Records

For the Medical Records report, TIFF files now export and print as expected.

 

CCC-18833OH - Medical Records

When exporting a Medical Records Report questionnaire to Microsoft Excel, if the questionnaire has a multi-select check box question, the choice description will now be shown, as expected.

 

CCC-27624OH - MoC and Billing

For Management of Change Approver/Approval fields, the Billing ‘Fee’ field, and the OH ‘Additional Jobs’ field, smart search now functions properly.

 

CCC-27301OH - Patient Engagement, ESR Exports

Updates have been made to the ESR export functionality to help ensure successful exports. These include changes to how Person Id is handled, improved Export7CompleteFunction timeout handling, an increased cron job interval to help avoid overlapping jobs, and additional logging.

 

CCC-27757OH - Scheduling and Roles

Custom ‘Schedule Entry’ layouts with ‘Granted Roles’ now function properly without generating unexpected errors.

 

CCC-27420OH/IH - Risk Assessment

You can now import data into RAS.RAInterviewedEmployee using all supported import methods.

 

CCC-27175Platform Administrator - Authentication

An issue that was preventing the correct setup for SP-initiated SSO to an IDP and generating an XML signature error has been resolved.

 

CCC-27222Platform Administrator - Business Rules, Letters

An issue that was preventing a properly configured business rule, for sending an email with a letter that uses a subquery, from extracting and displaying the subquery results has been resolved.

 

CCC-27902Platform Administrator - Identity & Role Management

On a User record, the ‘View System Settings’ action can now successfully be executed without generating any unexpected errors.

 

CCC-27898Platform Administrator - Roles, Documents

The security action questionnaireresponsedocument.removemainformdocument is now available in Security Actions and can be granted or removed from roles. A user whose role is granted the security action can add or remove attachments from regular and Flex Field questionnaires. A user whose role is not granted the security action cannot.

 

CCC-24749Platform Administrator - TDBRs

An issue that froze the time-driven business rules service (action queue) for three days in October 2025 has been fixed.

 

CCC-28033Platform User - Business Rules

An issue that was causing business rule actions to fail incorrectly with ‘error during processing of TDBR’ has been resolved.

 

CCC-25643Platform User - Business Rules, Actions

An issue that was causing a business rule that is properly configured to unlock Action records from doing so has been resolved.

 

CCC-27765Platform User - Demographics

An issue that was intermittently preventing the Demographics list from opening and Employee records from opening has been resolved.

 

CCC-24851Platform User - Email Notifications

Any emails sent using MAEN (the platform’s email notifications utility) will now be recorded only once in the Email Log.

 

CCC-23832Platform User - Emails, Letters

User-created ad-hoc Clinic Visit ‘Medical Letter’ emails now function as expected, including logging.

 

CCC-27693Platform User - EMS Integration

From within GX2, when applicable, the user can now rename, edit, and delete EMS-integrated assets. When deleting such an asset, the user can choose to have the integration delete the equivalent object in EMS, leave the object in EMS intact, or manually delete the object from EMS afterward.

 

CCC-27221Platform User - EMS Integration

When applicable, if the user opens GX2 from within EMS, the proper menu item and screen will now both display.

 

CCC-28158Platform User - Incident Management

For Incident Management, an issue that was causing the CAPA AI agent to intermittently generate an incorrect error has been resolved.

 

CCC-28581Platform User - Letter Templates

A user whose role has the correct security configuration can now successfully create letter templates with merge fields, and those templates can now be used without generating any unexpected errors.

 

CCC-27926Platform User - Logging In

An attempt to log into the platform with the Username field left empty will now generate the appropriate error message and be recorded properly in the Login Log.

 

CCC-27628Platform User - Navigation

Where applicable, if a user attempts to navigate away from a page that has unsaved changes, the appropriate notification message will now be displayed.

 

CCC-26316Platform User - Questionnaires

With or without branching enabled, when applicable, questionnaires that are submitted without being saved first will now retain all expected data.

 

CCC-14017Platform User - Questionnaires

For a questionnaire with any or all question types, when the ‘Print HTML’ action is executed with ‘Include Valid Choices and Include All Responses’ selected, the results will now more clearly indicate each question response.

 

CCC-28236Platform User - Questionnaires, Translations

When applicable, a standalone questionnaire for which the URL is embedded with questionnaire code and a language other than English will now display in that language.

 

CCC-25220Platform User - Report Scheduler

If an HTML page break <br> is added to the email content sent by a Report Scheduler report, that break will now be applied properly.

 

CCC-27876Platform User - REST API

An issue that was preventing a correct REST API PUT request from successfully updating GUID fields in /api/treemastercode has been resolved.

 

CCC-20538Platform User - Translations

When the language is French, the ‘Current Date’ merge field used in letters will now respect the ‘Long Date Style’ specified in System Settings.

 

CCC-27960Safety  - Findings & Actions

For a Safety ‘Findings & Actions (Audit)’, when applicable, the ‘Rating (Reason)’ field can now be edited without generating the ‘Changing this answer will clear any related responses.’ message.

 

CCC-27181Safety - Incident

In Safety Incident ‘Root Cause’, when the user clicks within the Cause look-up field, an unknown error message no longer appears immediately or periodically.

 

CCC-21809Safety - Incident

For the Safety Incident list, any configured color coding will now function properly.

 

CCC-27466Safety - MoC, Findings & Actions

On a Safety ‘Change Request’, in ‘Findings & Actions’, after creating and saving a new ‘Finding & Action’ with Finding Type ‘MOC Effectivity Action’ and mandatory fields populated then clicking ‘Make Active’, the Finding status will now become Active and the action details will no longer get cleared.

 

CCC-25815Safety - Projects

When using the ‘Save and Close’ button to save a Safety Project ‘Qualified Work’ record with Flex Field data, the Flex Field data will now save, as expected.

 

CCC-26436Safety/Quality - Business Rules, Workflow

When applicable, a business rule configured to update the workflow status when its conditions are met will now successfully do that.
