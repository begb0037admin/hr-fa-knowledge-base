myCority Descriptions

The table below lists the fixes and minor improvements we have made in myCority 2026.2.0. They are organized by module, and the modules are in alphabetical order.

Item #Component(s)Description
CCC-26392Business Intelligence - Dashboards

On a myCority dashboard, an indicator with no records or data will now properly finish rendering in a timely manner so that the end user can see there are no records or data.

 

CCC-23094Case Management - Questionnaires

When managers export Case response questionnaires using myCority, the formatting for the answers provided is now retained.

 

CCC-28056Ergonomics - Risk Assessment

When applicable, the office ergonomics assessment SCORM will now load successfully in myCority.

 

CCC-27477Ergonomics - Risk Assessment

When applicable, the office ergonomics assessment SCORM will now load successfully in myCority.

 

CCC-20651Event Reporting

For myCority in offline mode, when applicable, an Event Report with a questionnaire will now display and function as expected.

 

CCC-28070OH - Clinical Testing

In myCority, an issue that was preventing migrated Clinical Test Results from displaying and therefore being accessible in My Records has been resolved.

 

CCC-27475OH - Management Referral

When applicable, a Management Referral completed in and submitted from myCority will now be both retained as is in myCority and reflected as expected in GX2.

 

CCC-27240OH - Recruiting

In the Recruiter workflow, after the new applicant logs into myCority and creates a new password, that applicant will then be able to successfully log in with the correct username and that new password.

 

CCC-27548Platform User - Accessibility

In myCority, where applicable, the ‘Enter a code’ field can now be accessed using just the keyboard, and its character count is now both visually and with voice-over connected to the field.

 

CCC-25049Platform User - Inspection Questionnaires, Translations

For translated (into any language) Inspection questionnaires with look-up table selections, when using ‘Print or Export’ to PDF, the translations will now be rendered correctly.

 

CCC-27974Platform User - Keyboard

In myCority, when using the keyboard, the Shift and Ctrl keys now function properly. They no longer function interchangeably on occasion.

 

CCC-26152Platform User - Metrics

When applicable, for a campaign approval workflow, after the campaign is created and a metric completed in myCority, the workflow will now assign the current active approver instead of a previous approver who has been made inactive.

 

CCC-21894Platform User - Offline

In myCority, when working on a questionnaire offline (adding comments, pictures, etc.) using an iPhone and Microsoft Edge, the user no longer gets logged out unexpectedly and loses the changes.

 

CCC-25791Platform User - Organizational Trees

An issue that was preventing organizational trees from loading and rendering properly in myCority has been addressed.

 

CCC-4549Platform User - Questionnaires

In myCority, when offline, the Create New search for questionnaires is no longer available.

 

CCC-24375Platform User - Questionnaires

Where applicable, myCority is now consistent with GX2 in the way it renders markup in questionnaires.

 

CCC-28124Platform User - Translations

In myCority, when the language set is not English (for example, Spanish), the search functionality for the UDF 24 look-up table field will now function properly.

 

CCC-22504Platform User - Translations

In myCority, for exporting and printing, non-Latin translations will now display properly.
