The Reference Library includes this User Guide, a Data Checklist, Terms and Conditions for using Supply-Chain Sustainability (SCS) and a FAQs document. If you have any issues there is also an option to contact the support desk.

In Admin Settings you can access and edit your company details, set up and manage multiple users, set up your public profile, renew your Supply-Chain Sustainability (SCS) subscription and see which buyers have been viewing your profile.

My Account enables you to change your password, edit your user details and successfully log out of the system.
