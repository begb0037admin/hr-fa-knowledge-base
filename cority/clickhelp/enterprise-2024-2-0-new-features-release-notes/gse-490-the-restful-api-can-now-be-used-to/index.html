GSE-490: The RESTful API can now be used to export consumption and emissions data.

  • For this purpose, the following endpoints are now available:
    • Electricity (Grid) - exportconsumptiondata/electricitygrid and exportemissiondata/electricitygrid
    • Electricity (Non-Grid) - exportconsumptiondata/electricitynongrid and exportemissiondata/electricitynongrid
    • Fuel - exportconsumptiondata/fuel and exportemissiondata/fuel
    • Waste - exportconsumptiondata/waste and exportemissiondata/waste
    • Heat (Grid) - exportconsumptiondata/heatgrid and exportemissiondata/heatgrid
    • Heat (Non-Grid) - exportconsumptiondata/heatnongrid and exportemissiondata/heatnongrid
    • Road Business - exportconsumptiondata/roadbusiness and exportemissiondata/roadbusiness
    • Air Business - exportconsumptiondata/airbusiness and exportemissiondata/airbusiness
  • If you have any questions about using the RESTful API, contact your Cority representative.
