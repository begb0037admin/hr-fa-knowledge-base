Watch a video tutorial on setting up the BreakTimer.

Adjusting BreakTimer Settings:

To adjust BreakTimer settings, click the   Tools menu of the main RSIGuard window (pictured below), and select Settings.

Then, select the BreakTimer tab.

:

Review Current BreakTimer Settings. If you wish to adjust your settings, click Adjust Settings (or press Alt+A).

For more information on BreakTimer Settings Sections, click:

  • Break Timing
  • Interaction Style
  • Stretch & Online Videos
  • Work Restrictions
  • Scheduled Breaks
  • BreakTimer Filters
