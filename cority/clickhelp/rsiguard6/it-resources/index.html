IT Resources

RSIGuard is designed to be very easy to implement from an IT perspective. Some organizations need no IT involvement to deploy RSIGuard. However, IT will likely need to be involved if:

  • Your organization will use RSIGuard in conjunction with Cority's MyCority/GX2 solution.
  • Your organization desires changes to default RSIGuard settings.
  • RSIGuard will be deployed via a push or made available in a software store.
  • Your organization wants to use RSIGuard reporting tools, or centralized management of user configuration.

Additional IT Resources

  • RSIGuard Settings Clearing Tool - This small application can be run to clear all RSIGuard settings/registry to pre-installation state. Note that uninstalling RSIGuard and reinstalling it doesn't affect settings, and typically has no impact unless installation files were actually modified. This is equivalent to using the Factory Reset option in the Toolgear menu of RSIGuard (hold CTRL key and click Toolgear). But this tool can be used even if RSIGuard isn't running.
  • RSIScript Documentation - RSIScript is a core technology of RSIGuard that enables complex customization based on programmatic logic.
  • Client-Server Architecture Diagram
  • RSIGuard Pilot Information - This documentation may be useful to help you conduct an RSIGuard pilot.
