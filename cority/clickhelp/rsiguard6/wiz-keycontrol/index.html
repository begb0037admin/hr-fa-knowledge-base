The Setup Wizard - KeyControl

The KeyControl feature lets you define hotkeys to assign a wide variety of functions to your keyboard.

Hotkeys can perform tasks like:

  • Typing frequently used text
  • Mouse functions, such as drag-and-drop and double click
  • Opening applications, web pages, documents, and templated emails
  • Controlling features of RSIGuard, such as starting breaks, toggling AutoClick, and text-to-speech
  • Complex scripted operations, such as copying text from one application and pasting it into another

In addition, this screen lets you select KeyControl to set up some basic hotkeys. You can always set up hotkeys one-at-a-time from the KeyControl settings. See the table below to learn what each option configures. 

To start without preset hotkeys, select Don't create mouse-related hotkeys now.
