Getting RSIGuard

RSIGuard is desktop software and should be installed on each computer that you use. If your organization provides RSIGuard, the organization may install RSIGuard for you or may provide RSIGuard through your organization's software distribution tool.

To install RSIGuard yourself:

  1. Download RSIGuard - Click the link to visit our download page.
  2. Select the RSIGuard version you want to install from the Download page.
    • Stretch Edition (Windows, 27 languages*) - This is the fully-featured edition of RSIGuard. It includes BreakTimer, ErgoCoach, AutoClick, KeyControl, ForgetMeNots, ErgoAnswers, Work-Restriction Manager and DataLogger. Recommended for most RSIGuard users using Microsoft Windows and Mac.
    • Call Center Edition (Windows, 27 languages*) - This edition is optimized for the call center or other customer-facing environments. RSIGuard defaults to minimize work interruption by BreakTimer and ForgetMeNots. Adds user-warnings if a feature might interfere with a call or customer interaction. Fewer setup options are provided. Microsoft Windows only.
  3. Install RSIGuard - The download page provides instructions to guide you through the process of installing.
  4. The first time RSIGuard starts, it guides you through an Introductory Setup/Tutorial Wizard. Take some time to get things set up!

RSIGuard will launch every time you start your computer and remain active to help keep you working more safely every day.
