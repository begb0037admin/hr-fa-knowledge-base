Configuring RSIGuard for Organizations

Overview

Thank you for selecting RSIGuard for your organization. This document will help guide you in configuring RSIGuard to meet the needs of your organization. It is intended for organization's whose license includes a customized installation package (MSI for Windows and/or DMG for Mac).

Since different organizations have different needs, we will build your installation package(s) with default settings (that you specify) to match your specific needs. RSIGuard has customizations related to:

  • user settings (e.g., BreakTimer timing, ForgetMeNot messages)
  • user interface adjustments (e.g., branding RSIGuard with your logo, custom menu item to link to your organization's ergonomic resources)
  • technical configuration (e.g., server setup and registration)
  • organization details (e.g., contact information of people who will receive links to your RSIGuard installation package(s).

We provide suggested default settings, but you may request alternate defaults if they make more sense for your situation. For example, by default, ForgetMeNots are configured to appear every 15 minutes, but you could change this to a different default interval such as 10 or 20 minutes. If necessary, defaults can be specified for different subsets of users in your organization. And you can specify, for each setting, if users can adjust the setting (by default users can adjust all settings), or if a setting is locked or restricted to a range. For example, you could say that ForgetMeNots appear every 15 minutes, and users can adjust this to a value between 10 and 30 minutes.


The Configuration Spreadsheet

To prepare your custom installation, you will complete a Configuration Spreadsheet (Excel format). There are 2 spreadsheets to choose from.

  • RSIGuard Essentials Spreadsheet - This is a streamlined spreadsheet with just a few key customization options. It is appropriate for Office Essentials customers, smaller licenses, or customers who generally wish to go with our default configuration. Completing it is easy and fast.
  • RSIGuard Extended Spreadsheet - This spreadsheet includes a large range of options. It is appropriate for customers who wish to more finely customize RSIGuard to their organization. This option is great for many organizations because it helps you see all the possible options for RSIGuard - even if you end up leaving most options unchanged (i.e., you choose the Cority-specified default).

Please select the spreadsheet that matches your organization's needs, and return the spreadsheet to your Cority contact.


Configuring RSIGuard for Subsets of Users (Advanced)

Most organization configure RSIGuard the same for all of their users. But, if you need customizations for subsets of users, this section provides details on how to achieve this.

In the notes column you can specify customizations that apply to subsets of users. For example, you might write "breaks default to Polite Mode for phone agents, and popup mode for other users."

However, for RSIGuard to be able to have different settings for different user groups, it needs a way to differentiate which group a user is in. There are a few standard ways this can occur:

  • Domain/computer info - RSIGuard can query the operating system (Windows only) to determine computer name, network name, etc. to help determine user group. You can download and use the Computer name/domain info tool (Windows executable) to help determine the values you can use. RSIGuard can test strings (e.g., apply a setting to all machines that start with "contractor_").
  • IP Address, WiFi network
  • Username - Some organizations use a username pattern to identify a group. For example, customer-facing agents might have usernames starting with 1 or 2 special characters, and then RSIGuard can apply settings based on this. It can also use a text database to look up users by username to assign users to various organization-specified groups.
  • Peripherals - RSIGuard can see how many keyboards, pointers, monitors there are, and in most cases, what kind of devices. It can see if the computer is a laptop or other device. It can adjust settings based on this.
  • User query - RSIGuard can ask users a question to determine their group. This isn't optimal if the answer must be correct since users sometimes answer questions incorrectly. But, for example, if the question is a user preference, e.g., "Do you want a stricter break schedule?", then the user gets to make this choice.
  • More options are possible using RSIScript. See the RSIScript reference for more detail.
