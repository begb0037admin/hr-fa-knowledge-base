Automatically Generated Tasks

Tasks can be automatically generated by the system in the following circumstances:

  • When a numeric requirement exceeds its regulatory or internal limit, a task may be triggered in conjunction with a data warning. The task may be used alone when some action is required but no further documentation is necessary. Or the task may be used to trigger a workflow, if the task has an associated workflow. See Task Triggered Workflows.
  • When an event is triggered as the result of a limit exceedance on a numeric requirement. In this case, the event is associated with the numeric requirement and the task is associated with the event. The custom fields for the event log are included in the task completion form.
  • When an event is triggered as the result of a task for a non-numeric requirement being completed with the compliance status of "Not Determined." The custom fields for the event log are included in the task completion form.
  • When an event is created for a manual event log. For example, when a record is created in an incident log, an task is created for following up and documenting the incident. The custom fields for the event log are included in the task completion form.

Task templates are used to generate automatic tasks. See Task Templates.
