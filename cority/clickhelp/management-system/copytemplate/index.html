Copy or Rename Template

You copy an existing template to make a new template to save time when setting up templates for similar requirements which may have slightly different information, such as different requirement drivers or effective dates.

To copy a template:

  1. Right click the template and select Copy.

  2. Enter a new name for the copy, then select Save.

You can then edit the new template as desired and add or remove fields.

To rename a template or field:

  1. In the corresponding templates library, right click the template or field name and select Rename.
  2. Edit the name for the template, then select Save.

A renamed template or field retains all its object associations, and the new name will be reflected everywhere it is referenced.
