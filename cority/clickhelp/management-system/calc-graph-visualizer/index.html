Calc Graph Visualizer

The Calc Graph Visualizer takes your complex calculation structures and displays them in an interactive visual map. This tool helps you better understand your current calculation configurations, diagnose problems, and plan changes in an informed manner.

The Calc Graph Visualizer can map existing calculation connections between system variables, parameters, auto parameters, calculated requirements, time-based calculations, and material and activity calculations. 

Users can:

  • Quickly view all calculations that use a selected requirement.
  • Expand the graph to view related calculations.
  • View calculation and limit histories of a selected requirement.
  • Edit the properties of a selected requirement (with appropriate permissions).

Browser Support & License Information

Calc Graph Visualizer is best viewed on an HTML5 compliant browser. Supported browsers are:

  • Chrome (desktop)
  • Safari (Mac)
  • Edge (desktop)
