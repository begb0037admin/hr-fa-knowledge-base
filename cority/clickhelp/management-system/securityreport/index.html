Security Report

Security Reports are used to obtain an overview of the rights and permissions assigned to system users and groups.

Two types of security reports may be created:

  • Security Report by Rights: Reports on users and groups assigned certain system-wide user rights.
  • Security Report by Permissions: Reports on users and groups assigned permissions to view and/or modify certain parts of the system model.

Security Report by Rights

This type of report will show all users or groups with a list of their rights. The report may be grouped and filtered by rights.

Rights define which parts of the application are available to a user. Rights give access to system-wide functions. For example, to create or edit task templates, you must have the Manage Task Templates right.

Examples of a Security Report by Rights are:

  • Report on what rights are assigned to specific users (for example, which users have the rights to Manage Task Templates).
  • Report on which users or groups have which system rights.

To create or run a Security Report by Rights, users must have the following user rights and permissions:

  • User rights: Manage Users and/or Manage Groups
  • Report permissions: Unrestricted (plus View or Edit)

Security Report by Permissions

This type of report creates a record for each system object with a list of the users who have access to the objects and their permissions.

Permissions define the read/write privileges users have with system objects. For example, to enter data on a Requirement, you must have View/Enter Data permission on the Requirement (or its parent object).

Example of a Security Report by Permissions are:

  • Report on which users have access to which objects, and the type of access (for example, who has View/Enter Data permission for a specific Facility, Unit, POI or Requirement)
  • Report on the list of permissions assigned to specific users or groups.

To create or run a Security Report by Permissions, users must have Full Control permission for the objects included in the report.
