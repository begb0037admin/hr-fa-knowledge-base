Custom Field Templates

Custom Field Templates are used to apply a group of custom fields to be used as additional properties of one or more system model objects.

A single Custom Field Template can be applied to any object at creation. A template may also be applied to one or more existing objects. The fields are then available for entry in the Edit Properties page.

If a Custom Field Template is modified by adding or deleting a custom field, the change is reflected in all objects with which the template is associated.

To create or modify Custom Field Templates, you must have the Manage Custom Fields right. This right gives users the ability to both create/edit custom fields and Custom Field Templates.

To view Custom Field Templates:

  1. From the menu, select Setup > Custom Field under Templates.

    The Custom Field Templates are displayed. The # Ref column indicates the number of objects that use that template.

  2. Click the icon to expand the Search pane and use the search function to find a specific template. You can search for Custom Field Templates by:
    1. Name (full or partial string)
    2. Date created: Search for an exact date, or to include templates created before or after a selected date.
  3. To view the fields on a Custom Field Template, right click the template and select View.
