Event Fields

Event fields are the fields that may be used to document an event. Event fields typically represent the columns required in a report, such as a Title V Deviations report or an OSHA 300 or 301 report.

Event fields are grouped together to form Event Templates (similar to Custom Field Templates). Any number of custom fields, created in the Custom Fields Library, may be included on an Event Template.

In addition to the user-defined custom fields, eleven pre-configured event fields are provided for use in calculating data related to events. These are primarily used for Event Logs that monitor numeric requirements. You may add any of these predefined fields you need for your reporting purposes to an Event Template. The values are automatically calculated for each event.

To view the pre-configured event fields:

  1. From the menu, select Setup > Custom Fields.
  2. In the Custom Field Library expand the Search pane.
  3. Select the checkbox Show only Predefined Fields.

  4. Click Search.

    The eleven pre-configured, calculated fields for Event Templates are described in the following table.

    Event Fields

    Definition

    Average Data Value

    Statistical average of all the data points represented

    Maximum Data Value

    Statistical maximum value of all the data points represented

    Minimum Data Value

    Statistical minimum value of all the data points represented

    Count Data Value

    Number of all data points represented

    Duration

    Duration of the event (days, hours, minutes) calculated as the time from the first data point out of compliance to the next data point within compliance

    Regulatory Limit High

    Regulatory Limit Low

    The high and low or the regulatory limits of the monitored requirement, as dictated by the permit and specified on the requirement properties.

     

    If the regulatory limit is x=<5 and x=>2, the regulatory limit high will be 5 and the regulatory limit low will be 2.

    Internal Limit High

    Internal Limit Low

    The high and low of the internal limits of the monitored requirement, as specified on the requirement properties.

     

    If the internal limit is x=<5 and x=>2, the internal limit high will be 5 and the internal limit low will be 2.

    Selected Limit High

    Selected Limit Low

    The high and low limits of the monitored requirement, according to which limit (regulatory or internal) triggers the event.

     

    This is useful if the event log is monitoring both regulatory and internal limits. If the data value exceeds both limits, two events will be created in the log, one for the regulatory exceedance and one for the internal exceedance. Using the Selected Limit High and Low properties gives you the values for the limit related to the exceedance.

The Accept as Deviation field is an additional field that may be included in an Event Template. This is a Boolean field (true/false) which allows users to decide whether, on any given event, a requirement should be treated as out of compliance or not. The Accept as Deviation field is included only if you check the option on the event template form Include Compliance Certification Status.
