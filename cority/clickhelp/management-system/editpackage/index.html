Edit Apps

You may edit an App to:

  • Change the initial display page.
  • Edit Role memberships.
  • Select or change an icon to associate with the App.

Permissions and Security Policies are defined in the App; they may be viewed but not edited from the interface.

To update package contents, see Update App.

 Once configured, a package may be locked in the database so that no further editing is allowed. For security reasons (to prevent the introduction of malicious code), locking or unlocking an App may not be done from the interface. Contact your Cority representative to lock or unlock a package. You may also disable Apps Manager, if you do not want package editing to be available from the interface. Disabling Apps Manager will not disable Apps that are already configured for your system.

To edit an App:

  1. From the menu, select Setup > Cority Apps.

  2. Right click a package and choose Edit.

    To change the default page, select a new page from the drop-down list. 

    To view or change Role memberships, select the Role Membership tab. See Roles for Apps.

Delete an App

Providing an App has not been locked, it can be deleted. Locked Apps cannot be deleted. Deleting the App package also deletes any page associated with the App.

Deleting an App will remove all files from the system and cannot be undone. Before deleting, be sure you have backup files if you should need them. You can download the package first to retain a copy. See Download App .

To delete an App package:

  1. In Apps Manager, right click the package and select Delete.
  2. Click Delete again to confirm.
