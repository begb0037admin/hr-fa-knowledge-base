Version 9.4.4 Released 12/17/2018

Improved Scalability and Performance: For organizations with a large number of facilities and users, some operations will be substantially faster (such as adding a user to a user group). Other querying scenarios will see some improvements as well.

General Improvements and Bug Fixes

  • MAIN-9240 Deep Links on Mobile Devices will now work for SSO users not previously authenticated
  • MAIN-9086 EQL Added support for the setting “Inherit Permissions from Parent Object”
  • MAIN-8581 Further restricted task creation and editing to ensure invalid characters are not included in the task name (“/”, “\”, “[“, and “]”).
  • MAIN-8454 Tasks with a “Time after Last Completion” schedule will receive a new version of their logic for calculating the next instance’s due time. Task Schedules created after the release will recur with the originally scheduled time of the day irrespective of the time each previous task is completed.
