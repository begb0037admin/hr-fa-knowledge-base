Manage User Groups

Rights and permissions in the system can be managed most efficiently through user groups. Using groups to control rights and permissions gives you the ability to apply the same system rights to multiple users. User groups can also be used to grant permissions to system objects, documents and reports.

The following types of users may view, create, and edit user groups:

  • Users who have been granted the Manage Groups right, or belong to a user group that has this right. To create new users to add to a group, the Manage Users right will also required.
  • Members of the Administrators group or the System Owner.

View User Groups

  1. From the menu, select Setup > User Groups (in the Security group).

    The list of existing user groups is displayed.

  2. Select the name of the group to see the users assigned to the group and the rights assigned to the group.

Create a new user group

  1. From the menu, select Setup > User Groups (in the Security group).

  2. Select New User Group or, right click the user group list and select New.

  3. Enter a Group Name.

  4. Click Add to add users to the group.

  5. From the selection window, select user(s) to assign to the group by checking the selection box, then click Select. 
    You can create a user group with no members assigned to the group.

  6. To search for users, click the plus sign (+) in the Search bar to expand the search pane.

  7. Select the rights to assign to the group by checking the boxes in the Security Options section. 
    For a description of user rights, see User Rights.

     It is not necessary to assign user rights to a group. User rights grant high-level functional control over the system and are usually required only by those with administrative responsibilities for the system. User groups are also used to assign permissions to the system model, and to documents and reports. Many groups may be used only for the purpose of granting permissions and do not need to have user rights.

  8. Select Save.

Copy a user group

Copying a user group copies the group's members and rights. It does not copy any permissions assigned to the group.

  1. From the menu, select Setup >Groups (in the Security group).
  2. Right click the group and select Copy.
  3. Rename the group as desired and click Save.
