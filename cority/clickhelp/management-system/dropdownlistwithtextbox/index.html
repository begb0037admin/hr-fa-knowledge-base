Dropdown List with Text Box

A dropdown list with text box allows users to select from a list of previous values or enter their own value, if desired. Users are not limited to the options available, but may enter a new value as needed. Values entered by users are saved as list options so they can be easily reused.

The dropdown list with text box type is available for both text and number fields. Entries on number fields will be checked for numeric content.

To create a list with text box:

  1. For the Data Type, choose Text or Number, depending on the data type desired.

  2. For the Value Entry Method, choose Dropdown List with Text Box.

    List only values of objects with same Custom Field Template: If checked, then values entered using the text box are shown in the list box for selection only if they are entered on objects that use the same template.

  3. Select Save then Confirm.

Initial values for the list must be created from the object’s property form. The order of display is ascending (for either text or number data types).

 For mobile applications, it is recommended that you use a standard dropdown list, since the dropdown list with text box may not work as expected. Access to historical list entries is limited to the data range selected and due to the need to prevent duplicate entries, a text box is not presented in the mobile view.

Localization

The Name, Caption and Description may be localized in any of the available languages in the system.

To enter translated values for different languages:

  1. Click the language symbol next to the field.

    In the pop-up dialog the currently active languages for users in the system are shown, as determined by the values selected in the Culture field in users' profiles. Check "Show All EMS Languages" if you want to add translations for languages not currently selected by users.

  2. Enter the value to use for each language for which you want to provide a localized translation.

  3. Click Save.
