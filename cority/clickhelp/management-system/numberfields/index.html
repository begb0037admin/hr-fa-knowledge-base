Number Fields

Number fields are for entering numeric values. Entries on number fields are checked for numeric content.

Number fields can be of four data entry types:

Text Box

Dropdown List

Dropdown List with Text Box

Numeric ID Control Field (used in Event Templates only)

Numeric Lookup

When creating a new field, choose the Value Entry Method to specify the entry type.
