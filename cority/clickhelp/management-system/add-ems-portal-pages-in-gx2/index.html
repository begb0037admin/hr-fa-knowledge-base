Add Portal Pages in Core (GX2) 

When your organization uses both Advanced Calculations (EMS) and Core (GX2), you can create an Advanced Dashboard in Core (GX2)to embed a portal page from Advanced Calculations (EMS).  

To embed a Portal page as a dashboard: 

  1. In the Business Intelligence module, under Advanced Dashboard, click New Dashboard.  

  1. In the Add Indicators window, choose the Other category, and choose the Webpage indicator.  

  1. Click the indicator to add a web page.  

  1. Enter the URL for your Portal page as follows:
    [Environment]/security/UUIDRedirect.rails?target=[EMS AppName]&deeplink=%2Fgoto%2F[SystemID]%2FPortal%2Fembedded.html%3Fhash%3D%2Fpage%2F[Portal pageID] 

    • Environment - Your Core (GX2) system URL. For example, https://company.cority.com

    • EMS AppName – The App name from the UUID setup.

    • System ID – The system ID for your Advanced Calculations (EMS) system. You can find the System ID by calling the System Object in the Data Preparation Tool.

    • Portal pageID – The ID of the Portal page to be embedded. You can find the Portal page ID by opening the page settings and selecting Copy page URL. 

You must add cority.com and enviance.com to the list of URLs that are allowed to be used for embedding. For more information, see Whitelist URLs. 

The Portal page has all the functionality as it does in Advanced Calculations (EMS). For example, you can enter data into panels and view tables and charts.
