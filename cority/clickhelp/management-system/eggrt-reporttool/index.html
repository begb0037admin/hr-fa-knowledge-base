Electronic Greenhouse Gas Reporting Tool

The e-GGRT reporting tool is designed to work with a pre-defined, custom Greenhouse Gas report run from the Management System. The tool takes the Excel file and converts it to the xml format required for electronic reporting on the EPA site.

 The electronic Greenhouse Gas Reporting Tool currently is supported only in the Internet Explorer browser.

Procedure for generating e-GGRT file:

  1. In the Management System, run the report, using the Excel template format output and save to your computer.
  2. Open the Excel file and allow the macros to run. Review the data, then save the file.
  3. Log into the xml transformer tool.
    Login is not necessary if you are already logged in.

  4. Select the reporting year. Select the Excel report file. Upon selection, the file is automatically uploaded.
    Make sure you have selected the correct reporting year, as the report is validated against the xml schema for that reporting year.

  5. Click Next to begin conversion.
    The Convert tab is displayed and shows the status and progress of the transformation.

  6. If conversion is successful, click the file link to download the file.

    If conversion fails, note the error message displayed. For further information, click the Log File link to download the log.

    If conversion succeeds, but there are validation errors, review any validation errors and correct as necessary.

Frequently Asked Questions

What do I do if the system reports validation errors?

The error message displayed should give you the location of the error in the Excel report and an indication of the problem. Find the referenced cell in the Excel file and correct it. Then run the report conversion tool again.

What do I do if the conversion process fails?

Note the error message, which should give you the reason for the failure. Correct the problem as indicated. Also, make sure you have selected the correct reporting year, as the xml schema used for validation may change from year to year.

How do I correct information such as names, addresses, etc., in the report?

Correct the information, then re-run the report. Save to your computer, open the report and allow the macros to run, then save again.

What do I do if there is missing data in the report?

Review the data in the Management System. Make sure all values are present and the dates are correct. Enter or edit data as required. Then re-run the report from EMS and save. Re-run the report conversion tool.

What if the EPA site rejects the report when I upload it?

Make sure you have selected the correct reporting year, and that the correct year was used in the xml transformer too. If you are not sure, run the xml transformer tool again and make sure that all validation errors are corrected. If you still have problems, contact your Cority representative.

When I upload my file I get errors that refer to cells in the format, D6, D7, etc. But when I open the file the columns have numbers instead of letters. How can I find the cells that are referenced with errors?

You need to modify your Excel options to turn off the R1C1 format (numbers for both rows and columns). The method depends on your Excel version. For Excel 2007 or 2010, click on the Office button, or select the File tab. Select Options (or Excel Options), then Formulas. Uncheck the R1C1 reference style. For other Excel versions, see http://kb.wisc.edu/page.php?id=781.
