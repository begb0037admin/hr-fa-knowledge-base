Output Report to Custom Excel Template

If a custom Excel Template is associated with a report, you will most likely want to make this the default output format.

To make Excel Template the default output format:

  1. Right click the report and choose Update.

  2. For the output format (at the bottom of the page), choose Excel Template.

  3. Save the report.

Any report may be output to the Excel Template format. If a formatted template is associated with the report, the output will reflect the formatted design. If no Excel template is associated with the report, the output will be raw data only, with one worksheet per report.

To output a report to an Excel template:

  1. For the output format, choose Excel Template and click Run Report.

  1. In the File Download dialog, click Save and save the file to your system.

    It is recommended that you save the report, rather than open it directly. After downloading the file, you may then open the report in Excel. If you choose to view the file directly, it will open in the browser, where only limited Excel functions are available.

  2. Open the file in Excel to view the report.
