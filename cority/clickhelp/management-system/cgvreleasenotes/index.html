Calc Graph Visualizer Release Notes

Version 1.0 Release date: 

The EMS Calc Graph Visualizer takes your complex calculation structures and displays them in an interactive visual map.  This tool helps you better understand your current calculation configurations, diagnose problems, and plan changes in an informed manner.

v1.0 Features: 

  • Interactive Calculation Graph

Allows users to quickly view all calculations in a selected requirement.  The graph can be expanded to see related calculations.

  • Information Side Panel

Allows users to view calculations and limit histories of a selected requirement. 

  • Direct Link to Management System (appropriate permissions required)

Allows users to quickly make changes to a calculation by clicking a direct link to a requirement properties page.
