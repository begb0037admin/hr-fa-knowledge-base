Editing Regulatory Limits

Requirement limits may not be edited while an event is open.

Caution:  If any Event Logs are associated with the requirement, existing limits should only be edited with great care. When events are associated with a parameter or calculated requirement, the following actions may cause loss of existing event data:

  • Adding and removing limits history (internal or regulatory, depending on which event data exists)
  • Editing limits (changing the comparison, limit values, limit begin date and end date)
  • For calculated requirements, adding and removing formula history, or changing begin and end date of the calculation
  • Changing calculation settings (formula, aggregation type, fixed period, rolling period)
  • Editing settings of a system variable used in a calculated requirement (value, begin date, end date)
  • Editing custom fields that are on the calculation template and are included in calculations (may affect output data of a requirement, and so the event data as well)
