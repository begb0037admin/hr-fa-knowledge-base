Copy/Move/Delete Documents

You can create a copy of an existing document and save it under a different name or in another document folder. When you copy a document, links to the document are not copied. You can create new links to the new document.

To create a copy of a document:

  1. Right click the document in the documents list and select Copy.

  2. Right click the folder to which you want to copy the document and choose Paste.
    You may select the folder location either from the Documents tree or in the Documents library.

  3. Enter a new name for the document.
    By default, "(copy)" is appended to the document name. If the document is copied to a different folder, it may have the same name.

  4. Select Save.
    A confirmation message appears, informing you that the file has been copied.

Permissions on the original document are not copied. A copied document inherits the permissions set on the parent folder.

To move a document to another folder:

  1. Right click the document in the documents list and select Cut.

  2. Right click the folder to which you want to copy the document and choose Paste.

    Optionally, you may rename the document before saving in the new location.

  3. Select Save.

To delete a document:

  1. Select one or more documents in the documents list, then right click and choose Delete.

  2. In the confirmation dialog, click OK to confirm.

When you delete a document, all links to the document are also removed.
