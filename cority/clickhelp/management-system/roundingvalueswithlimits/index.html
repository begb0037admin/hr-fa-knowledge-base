Rounding Values with Limits

Advanced Calculations (EMS) does not round values to evaluate compliance status. To enable rounding, the limit can be set artificially higher than the actual limit. If the limit is a whole number:

  • Set the regulatory limit to the emission limit plus 0.5
  • Set the comparison to < High
  • In data entry, do not enter more than 13 digits after the decimal point.

The system will then behave as if rounding, relative to the standard.

If the limit is not a whole number, the amount added to the limit should be relative to the precision of the limit itself. For example, if a limit is set to 15.5, add 0.05 to the limit to effect rounding.
