Activity Value Based Properties

Activity Value Based Properties are constants that are specific to an Activity that may be needed for Material Activity calculations. They are created and managed from the Material/Activity Field Library.

To create a value based property for an Activity:

  1. From the menu, select Setup > Material Activity Field Library under Materials/Activities.

  2. Select New Material/Activity Field.

  3. For the type of property, select Value Based Activity.

  4. Enter a name for the property. Provide an optional description.
    The description is only seen in the Material Activity property list, but may be useful when selecting properties to add to a material.
  5. Choose the property type: Numeric or Boolean.

  6. Click Save.

    The property must next be added to an Activity in order to be used in a Material Activity calculation. The value for the property is defined on the Activity.

    After adding the property to the Activity, click Add and enter a value and a Begin Date. Click Apply to save the value.
