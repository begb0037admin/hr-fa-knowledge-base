Toxic Release Inventory Report (Form R)

The Toxic Release Inventory (TRI) Form R report is an additional module that can be accessed from the Management System to help in completing and filing Form R. to meet your TRI reporting requirements.

If you have subscribed to this module, the Form R reporting tool can be accessed from the right click menu for Reports.

The TRI Report module appears in a new browser window. Select a year and a facility from the drop-down lists at the top.

The TRI Help can be accessed from the Help link at the top of the page. Line item help can be access from the help icon on each line.

Once you have completed the information on the form, you can generate electronic files for filing. See TRI Help for more information.
