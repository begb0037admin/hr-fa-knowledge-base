Search Tasks

From Task Manager, you can use the task search function to find tasks by specific criteria.

To search tasks:

  1. Click the plus sign (+) in the Search bar to open the search pane.

    The search criteria is shown. The initial default filter is My Tasks beginning with today’s date. The search criteria will default to the last search criteria you used.

  2. Select the task search criteria. Most important are the Start Date and Show options. See below explanation of all search criteria.
  3. Click Search.

Task search criteria

Due Date: Select a time period, relative to the current date, from one week in the past to four weeks in the future.

Task Category: Search by task status: Complete, Not Complete, Past Due, Dismissed, or All Tasks

Task Name: Search for tasks by text string in task name. Search results will include tasks where the text occurs anywhere in the task name.

Start Date: Search for tasks whose start date is on or after a specified date. The start date defaults to today’s date. If no End date is specified, search is for tasks due from today forward.

End Date: Search for tasks whose end date is on or before a specified date. You can combine Start and End dates to create a date range. 

You must specify both Start and End dates to see multiple occurrences of a recurring task. Unless an end date is specified, only the most current instance of a recurring task is shown.

Assignor: Search by task assignor by clicking Select User and choosing a user.

Assignee: Search by task assignee by clicking Select User or Select Group and choosing a user or group.

Type (of related object): Choose the type of system object associated with the task

Requirement Template: If the related object is a requirement, you may further filter by the Requirement Template associated with the object.

Custom Field Template: Select the Custom Field Template that is applied to the related object. If you select a custom field template, you may further filter for specific field values by checking the Selection Criteria box. Custom fields on the template are then available for creating a filter.

Show: Choose to show tasks assigned to you, tasks you’ve assigned, or all tasks you have permission to view.

My Tasks: Tasks for which you are the Assignee.

Tasks I Assigned: Tasks for which you are the Assignor.

Tasks I May View: All tasks you have permission to view (regardless of assignee or assignor).

Permissions may be granted to individual users or groups to View Tasks or Create and Complete Tasks for specific parts of the system model.
