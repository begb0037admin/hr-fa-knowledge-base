Editing Workflow Instances

Workflow instances that are still open may be edited in the following ways, if you have the appropriate permissions:

  • Edit workflow properties
  • Edit step forms to change field values
  • Change the assignee for the current workflow step
  • Add comments
  • Attach documents
  • End the workflow
  • Re-open the workflow
  • Delete the workflow

Workflows that are already closed may not be edited, except to add comments. However a closed workflow may be re-opened and then edited.
