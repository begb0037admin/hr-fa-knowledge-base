Copy/Move System Objects

You can copy an existing system object using the Copy and Paste options, or move an object’s location using the Cut and Paste options. When you copy an object, tasks, documents, and citations associated with the object are also copied. Data is not copied.

When using the Copy and Paste options, you can choose whether to include child objects. When using the Cut and Paste option with an object, all child objects are automatically included. You can also use a Bulk Tools to copy objects for large operations.

Special considerations apply to copying or moving calculated requirements and any associated variables. See Copying Calculated Requirements.

You can copy an existing system object to create a new object with the same properties. When you copy an object, tasks, documents, and citations associated with the object are also copied. Data is not copied.

When copying a parent object, you may choose whether to include children. A containment rule is applied when copying calculated requirements, as follows:

  • If all requirements referenced in the calc are included in the copy, then relative reference integrity is maintained. That is, the calculation formula will reference the new requirements copied along with it.
  • If requirements referenced in the calc are not part of the copy operation, then references to the original requirements are maintained.

 You can copy an object in the system model tree, along with all its children, to another location on the tree by dragging and dropping the object with the cursor. To move an object (delete it from one location and add it to another), use hold down the Ctrl key as you drag and drop. (These drag and drop actions only work within the System Model pane.)

To copy a system object:

  1. Right click the object you want to copy and select Copy.

    The hierarchical rules of the tree structure apply in copying:

    • A Facility/Program may only be copied to a Division or to the top level (Locations & Programs).
    • A Unit/Element may be only be copied to a Facility/Program.
    • POIs may be copied to a Unit/Element or a Facility/Program.
    • Requirements and Event Logs may be copied to a POI, Unit/Element or Facility/Program.

  2. Select the parent object under which you want to make a copy.

  3. Right click and select Paste.

    The Copy Object screen appears. The item to copy is shown, along with the object to which you are copying.

  4. Rename the object, if desired. If you are copying to the same parent object, you must provide a different name. You can keep the same name if copying to a different parent.

  5. To include children of the object, leave the Include Children box selected.

    If you only want to copy the parent object, de-select Include Children.

  6. Click Copy.

    The object is copied and appears in the system model tree in the location designated. The object may initially appear in blue, indicating that the transaction is in process. (It may remain in blue until the view is refreshed.)

After copying an object, you should make sure that any calculations that were copied with it are valid in their new environment. See Copying Calculated Requirements.

Moving Objects

You can move an object from one location to another using the Cut and Paste function. You can also use Bulk Tools for large operations.

If you move an object that is a part of a calculation setup, all references will point to the object in the new location. Alternately, you can collect all requirements used in the calculation setup under one parent object, then move the parent object with all of its children, in order to maintain the relative referential integrity.

You can research all requirement dependencies before moving an object using View Dependencies.

 You can move an object in the system model tree, along with its children, by holding down the Ctrl key as you drag and drop it to a new location in the tree. To make a copy of an object, drag and drop it without holding down Ctrl key. (These drag and drop actions only work within the System Model pane.)

To move an object:

  1. Right click the object in the System Model tree and select Cut.

  2. Select the parent object to which you want to move the object. Right click and choose Paste.

    The Move Object screen appears, showing the current path of the object and the new path. You can rename the object if desired.

  3. Select Move.

    If the move was successful, a confirmation message displays.

 Moving numeric and calculated requirements to a facility in a different time zone can affect the effective dates for calculations. For more information, see Copy/Move Objects Across Time Zones.
