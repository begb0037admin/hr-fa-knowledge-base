Exporting Breakdown of Data for a Requirement

In the Calc Graph Visualizer, users can export data for a requirement into an excel document.

To Export Data for a Requirement:

  1. On the Calc Graph Visualizer window, click the Build Graph tab.

  2. Under View Settings, click the View Data Checkbox.

    Once the checkmark in front of View data displays, the Breakdown of Data section appears.

     This section will be blank before any requirement is selected.

  3. On the header of the Calc Graph Visualizer window, click the Date Range icon.
    The Data Range selector allows users to observe the history of calculations, and any changes in formulas within the selected date range. 

  4. On the Data Range window click the Date From, and Date To dropdown list, and select dates. 

  5. Click Apply.
    The date range updates, and the Date Range window closes.

  6. Click the requirement of interest.
    The Breakdown of Data section displays with data points.


     Data in the Breakdown of Data section by default is displayed in descending date order, you can click the date column for the order to be changed to ascending order. 

  7. To export the Data for a requirement, click the Export Data icon in the Breakdown of Data section.

The data will be exported into an excel document.
