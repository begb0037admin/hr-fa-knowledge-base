Edit Materials

You can edit a material in order to:

  • Modify the name or description
  • Edit chemical concentrations (add new history for concentration)
  • Edit values for value based properties
  • Disable a material for data entry.

The calculation formula for a formula based property may not be edited on a material. The calculations for all formula based properties are the same for all materials to which they are applied.

To edit a Material:

  1. Right click the material in the Materials list and choose Edit. 
    The Material properties form appears.

  2. To disable a material for data entry, uncheck the Available for data entry box.
    If this option is disabled, the material will not display in the select list when entering Material Activity data.

  3. To modify chemicals or value based properties, click Add to add a new value history. Set the new value and the Begin Date for using the new value.

  4. Alternatively, you can edit the existing history by clicking Edit. Verify that this will not adversely affect existing data in the system, or cause large re-calculations of existing data.

  5. To add properties, click Add in the appropriate property type section.

  6. To delete a property, select the checkbox for the property and click Delete.
    Properties can not be deleted if they are used in calculations for existing data.
