System Requirements

The following browsers are supported:

  • Chrome for Windows Desktop (latest)
  • Edge for Windows Desktop (latest)
  • Safari for iOS/iPadOS (latest)
    • Applicable only to interfaces that support mobility such as the Portal, the Advanced Workflows, and the TaskApp.
  • Chrome for Android (latest)
    • Applicable only to interfaces that support mobility such as the Portal, the Advanced Workflows, and the TaskApp.

Some customer apps might be designed to function across additional platforms and browsers. See Advanced Calculations (EMS) Apps for more information.

Recommended minimum screen resolution: 1024x768
