Calculated Numeric

Calculated numeric fields are used to store calculated values. Calculated numeric fields may be used on Event Templates, Calculation Templates, Data Quality Templates and Form Templates.

The formula for a calculated numeric field is defined on the template, and is the same over all uses of the template. The formula may use numeric, Boolean and other calculated numeric fields applied to the same template. The value history is tracked on the template.

For convenience in creating new templates, an optional default formula may be assigned to the field on creation. The default formula may be accepted as is, or edited when applied to a template.

To create a calculated numeric field:

  1. For the Data Type, choose Calculated Numeric.

    Assign the following optional attributes, as desired:

    Description: Optional text description.

    Default Value: Default formula to use for the field. Default value is optional. The formula may be edited on the template it is applied to.

    Precision: Number of decimal places to show for field value.

  2. Select Save and Confirm.

Localization

The Name, Caption and Description may be localized in any of the available languages in the system.

To enter translated values for different languages:

  1. Click the language symbol next to the field.

    In the pop-up dialog the currently active languages for users in the system are shown, as determined by the values selected in the Culture field in users' profiles. Check "Show All EMS Languages" if you want to add translations for languages not currently selected by users.

  2. Enter the value to use for each language for which you want to provide a localized version.

  3. Click Save.
