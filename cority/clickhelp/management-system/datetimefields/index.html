Date/Time Fields

Custom Date/Time fields can be created to store date, time or both. The format of the time display depends on the user settings (as determined by the "Culture" setting in the user profile. In addition, you can localize the caption according to the user's culture.

Examples of Date/Time fields:

To create a date/time field:

  1. For the Data Type, choose Date/Time.

  2. Choose the Value Entry Method:

    Date: Allows date entry or selection of date from popup calendar.

    Time: Allows selection of time in 30 min. intervals, from 12:00 AM to 11:30 PM.

    Date and Time: Includes both Date and Time entry fields, as above.

  3. Select Save.

  4. Select Confirm to save the field as configured, or Back to edit it.

Localization

The Name, Caption and Description may be localized in any of the available languages in the system.

To enter translated values for different languages:

  1. Click the language symbol next to the field.

    In the pop-up dialog the currently active languages for users in the system are shown, as determined by the values selected in the Culture field in users' profiles. Check "Show All Cority EMS Languages" if you want to add translations for languages not currently selected by users.

  2. Enter the value to use for each language for which you want to provide a localized translation.

  3. Click Save.
