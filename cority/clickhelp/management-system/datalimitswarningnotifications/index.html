Data Warning Notifications for Limits

You may select users to receive data warnings when a limit is exceeded via Email or Inbox. Users selected for data warning notifications do not need to have View Data permission on the object.

 Users can see data warnings at any time for all the objects in the system for which they have View Data permission from the Messages page > Data Warnings.

To add users for data warning notifications:

  1. After setting the limits, in the Data Warning Notifications section, select Add for either Users or Groups, then select the user(s)/group(s) from the selection window.

  2. Check Inbox or Email for the notification method.
