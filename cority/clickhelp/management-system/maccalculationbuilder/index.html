Using the Calculation Builder for MACs

The Calculation Builder helps you to create calculation formulas for Material Activity Calculated Requirements. The calculator automatically filters for all the properties that are available for the MAC, using the fields on the associated materials, activity, and calculation template, if any.

The tabs available in the Calculation Builder and their uses are:

  • Formulas: This tab contains pre-defined formulas from a library which may be copied and edited.
  • Functions: This tab contains the functions that can be used in the formula. It can be used like a calculator to add a function in the correct format.

  • Chemicals: Chemicals may be referenced in two ways:

    Chemical explicit properties: Properties of the chemicals that make up the material chemical composition. To use a chemical explicit property, select the chemical, then select the property, then click Select.

    Chemical logical properties: Aggregate properties of all chemicals that make up the material chemical composition. To use chemical properties as aggregates, select "Chem," then select the property, then click Select.

  • UDFs: numeric custom fields on the Calculation Template applied to the direct parent object
  • Met fields, from a Location specified on a parent object
  • Material Value Based Properties: Constant values specified on the material.
  • Material Formula Based Properties: Intermediate formulas that are calculated as properties of the material.
  • Logical Properties: Chemical Logical formulas which produce values for each chemical used in the material.
  • Activity Value Based Properties: Constant values that are properties of the Activity, whose values are defined on the Activity.
  • Activity Specific Use Variables: The specific use variables used for entering data
  • Requirements (via Tags): Standard numeric and calculated requirements referenced via tags, which maintain relative reference per location. See Referencing Requirements in Material Scripts.
  • Requirements: Standard numeric and calculated requirements referenced absolutely by path.

In order to maintain relative references to standard requirements used in a MAC formula you must use Tags. This will allow you to maintain calculation integrity when you copy and paste a location from the tree. Requirements referenced from the "Requirements" tab are absolute references by path only and do not adjust accordingly when copied.

To build the calculation:

  1. Select a property from one of the dropdown lists and click Select to add it to the formula.
  2. Add operators, functions and other factors as needed, using the calculator.

  3. When finished building the calculation, click Save.

  4. Select a Begin Date for the formula.

    Optionally, you may define Calculation Errors Handling. See Calculation Errors Handling.

  5. Click Update.

    All formulas that are required in the MAC calculation must be valid in order to save the requirement.
