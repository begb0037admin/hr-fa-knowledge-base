Create/Edit Material/Activity Template

To create a new Material/Activity Template:

  1. First create the custom fields that you want to use on the template. See Create/Edit Custom Fields.
  2. From the menu, select Setup > Material/Activity under Templates.

  3. Select New Material/Activity Template.

  4. Enter a Name for the template and a Description.

    The Name appears on the properties form for the Materials and Activities using the template, as a section label for the custom fields. The description is only seen in the Material/Activity Templates list, and may help users identify the purpose of the template.

  5. Select Add to add fields to the template.

    In the selection window, browse or use the search to find and select the fields to add to the template. Check the checkbox for the fields you want and click Select Fields.

    The order in which the fields appear will be the display order on the properties form for the objects to which the template is applied. To re-order the fields, select a field and click the Up or Down button.

  6. Select Save, then Confirm to save the template.

To apply a Material/Activity Template:

  • On a new material or activity, select the Material/Activity Template on the first screen during creation.
  • Add or change a Material/Activity Template on an existing material or activity from the right click context menu in the Materials list or Activities list.

You can edit an existing Material/Activity Template in order to add or remove fields. When you edit a Material/Activity Template, the changes will be applied to all materials to which that template is applied, as follows:

  • New fields will be added to each material that uses the template. You will need to edit the material properties to assign values for these fields.
  • Deleted fields will be deleted from all materials that use the template. Any existing data in these fields will be lost.

To modify a Material/Activity Template:

  1. Right click the template in the Material/Activity Templates list and select Edit.

  2. On the template form, make the desired changes.

    To add a field, select Add. In the selection window, browse or use the search to find and select the fields to add to the template. Check the checkbox for the fields you want and click Select Fields.

    To create a new custom field to add to the template, click Create New Custom Field. (See Create/Edit Custom Fields.) After the new field is created, you will be returned to the template edit screen. The new field will appear in the Selected Fields list.

    To remove a field, select the field in the list and click Remove.

    To change the field order, select a field and click the Up or Down button to change its position.

  3. Select Save, then Confirm to save the template.
