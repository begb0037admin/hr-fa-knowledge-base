Managing Access to Reports

Access to reports is controlled through a combination of report permissions and system object permissions.

  • Report permissions (granted on a report folder or report) include View, Edit and Unrestricted. View and Edit permissions work in combination with the permissions granted to the system objects. Unrestricted may be granted in lieu of system object permissions and allows users to view any data in the report, regardless of their object permissions.
  • System object permissions (granted on the system model tree) allow users to see the data in a report. The Report permission for objects grants users the ability to view data, view properties and view tasks (the three types of data most commonly used in reports).

Users with Manage Reports right have unrestricted permission to all objects, meaning they can create and run reports for all objects, regardless of permissions.
