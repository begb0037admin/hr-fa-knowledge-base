Version: 9.4.8 Released: 9/3/2019

New Feature

  • Parameter Data Value History: When enabled, this option allows managers to view the history trail of parameter data, such as:
    • Current value and the user who entered the data point and timestamp
    • Previous values (up to pre-set time limit) along with the user who entered the values and timestamp

General Improvements and Bug Fixes

  • MAIN-10047: Performance of adding/removing Users from User Groups in large systems was improved.
  • MAIN-10330: Logic in circular reference check validations was improved. This allows changes to calculations in large systems to occur without error.
  • MAIN-10235: Workflow Creation and Closure Date/Time can be set now via REST API, enabling important cases in historical data loading and offline scenarios.
  • MAIN-10343: Culture support, including language and numeric/date format settings for Costa Rica, El Salvador, Guatemala, Honduras, and Nicaragua was added.
  • MAIN-10150: An error that caused workflows not to be generated under certain large-scale batch triggering cases was fixed.
  • MAIN-9792: Step Roles now can be empty (no members) upon workflow creation.
  • MAIN-3960: Workflow can be created now when the Assignee is a User Group that does not have members.
