Dropdown List

A dropdown list field allows users to choose options from a pre-defined list. The dropdown list field type is available for both text and number fields. Entry on number fields will be checked for numeric content.

To create a list:

  1. For the Data Type, choose Text or Number, depending on the data type desired.
  2. For the Value Entry Method, choose Dropdown List.

  3. In the Value box, enter the text for the first list option. Click Add to add successive items.

    The order of display in the list box will be the same as the order shown on the form. To move items up or down in the list order, click the up or down arrow next to the list item.

    To link this list to another list, select Link List. When the list is linked to another list, selecting an option on this list enables selection of an item from the related list. The list field you want to link to must already exist. See Linked Lists.

  4. Select Save and Confirm.

Localization

The list Caption, Description and List Item values may be localized in any of the available languages in the system.

To enter translated values for different languages:

  1. Click the language symbol next to the field.

    In the pop-up dialog the currently active languages for users in the system are shown, as determined by the values selected in the Culture field in users' profiles. Check Show All EMS Languages if you want to add translations for languages not currently selected by users.

  2. Enter the value to use for each language for which you want to provide a localized translation.

  3. Click Save.
