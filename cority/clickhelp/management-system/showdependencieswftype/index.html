Show Dependencies for Workflow Type

Dependencies for a Workflow Type include:

  • Policies applied to the workflow
  • Form templates used on steps
  • Roles associated with the workflow
  • Default Users and Groups associated with the Roles
  • Allowed child workflows

To view all dependencies for a workflow type, from the Workflow Types page (Setup > Types>Workflows), right click the workflow and choose Show Dependencies.

You may also view dependencies for a specific workflow instance. A workflow instance is created as a copy of the workflow type as defined at the time of creation, so dependencies will reflect the version of the workflow at the time the instance was created. The user/group role associations will reflect the actual assignees to the workflow, in addition to the default role members, if these are different.
