Managing Tasks

You can use tasks to prompt and monitor compliance with regulatory requirements. Task-related data can be used in various types of reports, such as Title V reports that call for a combination of numeric data and task-related monitoring details for specific events.

Tasks may be associated with one or more system objects.

  • Non-numeric Requirements: Tasks are used to monitor compliance with a particular citation or condition.
  • Numeric Requirements: Tasks may be used to monitor regulatory or internal limits and trigger action.
  • Event logs: Tasks may be used to prompt and record action related to an event occurrence.
  • System Model tree objects (Facilities, Units, POIs): Tasks related to tree objects may be related to a general type of object or program area.

Tasks may be one-time tasks or recurrent tasks. Tasks may also be used to schedule workflows or trigger an associated workflow when an event occurs.

Once you decide on the types of tasks you need, you can use the Task bulk tool is available for building to create and edit tasks in the system.
