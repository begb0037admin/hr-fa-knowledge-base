Calculating Usage from Meter Readings

Frequently, when data is input as a meter reading, it is necessary to compute usage based on the meter readings. This can be done via a simple calculated requirement that uses the PREV(SELF) function. If it is necessary to account for (or potentially edit) the meter rollover value, the rollover value can be stored in a custom field with tracked value history on a calculation template or in a System Variable.

To set up a calculation for usage based on meter readings:

  1. Create a custom field to hold the Meter Rollover value.

    The field should be of the type "number" and input method "text."

  2. Create a Calculation Template and add the Meter Rollover field to the template.

  3. Apply the calculation template to the POI (or other parent object).

    On the properties page, enter the value for the meter rollover.For example, if the meter rolls over at 1000000, input this value in the field.

  4. Create a parameter to hold Meter Reading values.
  5. Create a Calculated Requirement to compute the usage from the meter reading, using the following formula:

IF (([Meter Reading]-PREV([Meter Reading]))<0) THEN

[Udf_Meter Rollover Value]+[Meter Reading] - PREV([Meter Reading])

ELSE [Meter Reading]-PREV([Meter Reading])

END IF
