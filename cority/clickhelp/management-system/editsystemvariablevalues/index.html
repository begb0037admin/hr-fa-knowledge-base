Edit System Variable Values

System variables have tracked historical values, like calculated requirements. If the variable value needs to change, you can create a new value history to be used going forward from a specific date. You can also edit the existing value, but before doing so you should review any dependencies to avoid excess re-calculations.

When a system variable is used by a calculated requirement that is monitored by an event, where event instances have been triggered as a result, editing the value of a system variable may cause the loss of existing event data.

To edit a system variable value:

  1. Right click the system variable and choose Properties > Edit.

  2. Click the plus sign (+) in the System Variable Value bar to expand the value history. Click Edit to edit the current value.

  3. Enter an End Date for the current value and click Update.

  4. Click New to add a new value.

  5. Enter a value and specify the Begin Date for the new value.

    The new value will be used in calculations beginning with the date specified. 12:00 AM is default time, unless a time is specified.

  6. Click Save to save your changes.
