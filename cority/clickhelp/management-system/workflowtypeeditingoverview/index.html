Workflow Type Editing Overview

What do you want to edit?

  • The step forms and fields. Form Templates
  • The step assignees. Role Memberships
  • The permissions for the workflow. Workflow Permissions
  • The workflow process (steps, flow, actions). Edit Workflow Process
  • ID Generating scheme. Workflow ID Generating Scheme
  • General attributes (name, description, version comments). Edit Workflow Type

What rights are required to edit workflow types?

  • The Manage Workflows right is required to edit a workflow type.
  • Limited editing is available with Workflow Overrides, which allow you to change role memberships and policies for associated System Model objects (and children). Applying Workflow Overrides requires Full Control permission on the object.

What can I change when editing a workflow?

Workflow Types may be edited in the following ways:

  • Edit description and version comments. See Edit Workflow Type.
  • Edit automatic ID generating scheme for workflow instances. See Workflow ID Generating Scheme.
  • Edit the process flow, including steps, step actions and associated roles and forms. See Edit Workflow Process.
  • Create or edit forms used in the workflow steps. See Form Templates.
  • Map Workflow Roles to User(s) and/or Group(s). See Role Memberships .
  • Select fields to designate as global fields. See Fields Scope.
  • Assign Permissions to Roles. See Workflow Permissions.
  • Associate Policies with the workflow type. See Policies.
  • Create a new version of a workflow. See Workflow Versions.
  • Apply Workflow Overrides to change default role members and policies for a facility. See Workflow Overrides.
