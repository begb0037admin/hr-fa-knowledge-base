Numeric ID Control Field

Numeric ID Control fields can be created for use on Event Templates. This type of field is most commonly used to number findings for an Event Log which is used for audits and assessments.

When you apply a numeric ID field to an event template, an ID number can then be assigned to each event.

 Numeric ID Control fields can only be used on Event Templates.

You can choose whether the field value is auto-incrementing or is to be entered manually. If auto-increment is chosen, the number will be automatically assigned; users will not see this field for entry when creating an instance. However, after the record has been saved, the value may be edited.

To create a numeric ID control field:

  1. Create a Custom Field. For the Data Type, choose Number.

  2. For the Value Entry Method, choose ID Control.

    If you want numbers to automatically increment, check Auto Increment and enter a Start Value for the first item.

    To allow users to enter their own numbers, leave Auto Increment unchecked.

  3. Select Save, then Confirm to save the field.
