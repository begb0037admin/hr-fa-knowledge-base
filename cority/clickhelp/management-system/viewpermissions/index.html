Task Viewing Permissions

The tasks a user sees and the functions available to the user depend on permissions.

Users always see tasks in which they are either the assignee or assignor. They will only see tasks assigned to or created by others if they have specific permissions to do so.

If you have permission to view, create and complete tasks for a specific facility/program, or other system model object, you will be able to view or edit tasks for that object regardless of assignee/assignor. See View Tasks For Object.

Administrators can view all tasks in the system. However, be sure to select the appropriate search filters or search criteria to view tasks for different system users.

Permissions may be granted to individual users or groups to View Tasks or Create/Modify Tasks for specific parts of the system model.
