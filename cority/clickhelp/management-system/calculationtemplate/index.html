Calculation Templates

A Calculation Template is a special type of custom field template that contains numeric fields that may be used in calculations. A calculation template may be applied to any System Model object on the tree. A Calculation Template may include only numeric, Boolean, and calculated fields.

The user-defined fields on the calculation template are available as input to immediate child calculated requirements and to Material Activity Calculated requirements.

To view Calculation Templates:

  1. From the menu, select Setup > Calculation under Templates.

    Existing Calculation Templates are displayed.
