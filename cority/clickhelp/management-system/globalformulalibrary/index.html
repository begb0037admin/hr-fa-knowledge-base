Global Formula Library

A Global Formula Library is available from the calculator window for accessing frequently used formulas. You may select a formula from the list of available formulas, use the copy formula link to copy it to the calc definition window, then edit the formula as necessary, substituting variables from your own system.

Formulas in the formula library are not system-specific, but apply to all systems. They can be accessed only through development tools (not accessible to end users), but requests for additions may be submitted.
