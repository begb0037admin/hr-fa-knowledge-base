Update Reports (Create New Version)

If you have Modify permission on a report or report folder, you may update the report by editing the report criteria and saving it.

When you edit the report criteria and save it, a new version of the report is created. All versions are archived and a version history is maintained.

To update a report (create a new version):

  1. In the Reports library, right click the report and select Update.

  2. Edit the report criteria as desired.

    For information on the different options in the report form see:

    Select Objects to Report On

    Select Properties to Report On

    Refine Results by Filtering

    Select Users or Groups to Report On

    Select Aggregates to Report

    Data Grouping Options

    Data Report Display Options

  3. Select Save.

    The report is saved as a new version, and becomes the active version of the report. The original report is archived as the previous version.
