Chemical Calculations

Chemical properties have two modes when used in calculations:

  • Explicit Property: The property value for a specific chemical. Syntax: ChemExp_Property
  • Logical Property: The value for the combination of chemicals that are used in a material. Syntax: Chem_Property

Property is the chemical property abbreviation (MW, AvgConc, AntA, etc., as seen in the Calculation Editor).

There are three ways of using these properties in material calculations, depending on what results you want to achieve:

  • ChemExp_Alias_Property: This is a chemical explicit property use.
  • Aggregate(Chem_Property): This is a chemical logical aggregation.
  • Chem_Property: This a chemical logical linear usage.

Alias is the chemical alias. Aggregate is an aggregation type (SUM, AVG, etc.)

Chemical explicit property

When a chemical explicit property is used in a material calculation, it refers to the explicit value for a specific chemical.

For example, [ChemExp_BZ_MW]) results in the molecular weight of benzene, which is a property of the chemical.

Chemical logical aggregations

When a chemical logical property is used in a calculation, surrounded by an aggregation, it refers to the aggregate value for all chemicals in the material. For example, SUM(Chem_MW) results in the sum of the molecular weights for all chemicals in the material.

For example, for a given material that contains benzene (MW=78.11), toluene (MW=92.13) and cyclohexane (MW=84.16), SUM([Chem_MW]) results in the sum of the molecular weights of all three chemicals, or SUM(78.11, 92.13, 84.16) = 254.4.

Chemical logical linear usage

When a chemical logical property is used without an aggregation in a Chemical Logical Formula Based Property script, it results in a calculation for each chemical component for the material.

For the above material, a property named Chemical Molecular Wt, having this formula:

[Chem_MW] results in three linear calculated values which may each be accessed individually by other calculations, using the property name including a suffix with the chemical alias, in this case:

  • [PropExp_Chemical Molecular Wt:BZ]
  • [PropExp_Chemical Molecular Wt:TOL]
  • [PropExp_Chemical Molecular Wt:CYC]

These calculation modes may be combined in a formula to automatically produce values for each chemical in a material (without having to name the specific chemicals).

Example: The following Chemical Formula Based Primary Property is used to get the liquid mole fractions of each chemical in the material:

([Chem_AvgConc]/[Chem_MW])/SUM([Chem_AvgConc]/[Chem_MW])

 The liquid mole fraction of a component in a mixture is derived by 1) dividing the average concentration of a component by its molecular weight, then 2) dividing the result by the sum of the first calc for all components.

For the above material, this results in three calculated values (one for each component), which can be accessed with the following syntax:

[PropExp_LiqMoleFraction:BZ]

[PropExp_LiqMoleFraction:TOL]

[PropExp_LiqMoleFraction:CYC]

The following table shows the calculation results:

Benzene

Toluene 92.13 8 0.086833822 0.068812023

SUM   100 1.261898978 1

To get these values in a Material Activity Calculation, you would use AVG for the aggregation (since the calc will produce the same result for each data line and you only want the discrete value). So:

AVG([[PropExp_LiqMoleFraction:BZ]) gives the value of the calc for Benzene.

AVG([Prop_LiqMoleFraction] gives the value for all components, which is 1 (a not very useful value in this case, except as a check).

Further, since this is a Primary formula, you can use it in a Secondary or Tertiary CLFBP and it will produce similar linear results for each component. Each linear calculation for a single chemical will use the value for the same chemical from any other CLFBP referenced in its formula.

Example:

A Tertiary CLFBP for total vapor pressure for a material looks like this:

(10^([AntA]-([AntB]/ ([Tla C]+[AntC])))*0.01933677) * [LiqMoleFraction]

where:

AntA, AntB and Ant C are chemical properties

Tla C is a calculated value based on temperature

LiqMoleFraction is the Primary CL FBP given above

The calculation will give three values for the same material, one for each chemical component. Each linear calculation for a single chemical will use the previous Primary CL FBP value for the same chemical.

The total vapor pressure of the material is the sum of the partial vapor pressures for each component. So we can get the value in a MAC or for use in another calc by asking for the aggregate value, shown in the last row:

SUM([Pva])
