Label

The custom field type Label can be used:

  • To embed instructions or other explanatory text in a template.
  • To create System Quick Links which can be embedded in workflows, events and custom field properties of other objects.

The label field is displayed as a non-editable field.

To create a Label field for instructional text:

  1. Select the type Label. Enter a name and a caption for the field.

    Both fields are required. The Caption field, although required, does not display for this field type.

  2. In the Label box, enter the text you want to appear for this field (the instructions or explanatory text).

    The Label is the text that displays on the form. You can add translated values for localization by clicking on the language symbol . (The Caption and description may also be localized, but these fields are not displayed.)

  3. Click Save.

To use a Label field to display one or more links on a template:

  1. Select the type Label. Enter a name and a caption for the field.

    Both fields are required. The Caption field, although required, does not display for this field type.

  2. In the System Quick Links box, click Add. Select the Quick Links that you want to display.

    The Label is optional if you are using the field to display links. Each link is displayed on a separate line. Label text, if any, displays on a line above.

  3. Click Save.

    Once the field is added to the appropriate template, the links will be displayed by name (not URL), and will be selectable in either view or edit mode. When clicked, links will open in a new browser window.
