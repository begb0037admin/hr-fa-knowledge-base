Quick Data Reports Configuration

The Quick Data Reports tab allows users to access reports stored in the Management System quickly and easily from Quick Data without the need to log into the main application and navigate the Reports library.

To make reports available from Quick Data:

  1. Create a Reports folder with the following name: QuickData Reports

  2. Create your Quick Data reports in this folder, or copy/move reports from elsewhere in the Reports library.
  3. Grant the appropriate report permissions to the users who will be running the reports.

Only those reports for which the user has been granted permissions will be shown in the Reports tab in Quick Data.
