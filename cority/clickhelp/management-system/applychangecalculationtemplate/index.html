Apply or Change Calculation Template

A Calculation Template may be applied to any System Model (tree) object at creation. It may also be applied to existing objects, either singly or in bulk.

Changing the existing Calculation Template applied to an object will only be allowed if no data exists that uses the fields.

After adding or changing a the template, you may also use the bulk edit feature to edit the field values for the objects, if you want to apply the same field values to all.

To apply a Calculation Template when creating an object:

  1. Select the Calculation Template from the list, presented on the first page when creating an object.

    You can also create a new Calculation Template from this screen by selecting the New Calculation Template link. After creating the Calculation Template, you will be returned to the selection screen where you can select the new template from the list.

    On the properties page, the calculation templates are displayed for entering values. The calculated fields show the calculation formula.

To apply a Calculation Template to existing objects:

  1. Select an object in the System Model tree, right click and choose Change > Calculation Template.

    Or, select one or more objects from the Requirements view. Right click and choose Change > Calculation Template.

  2. Select the Calculation Template to apply from the list.

    You can also create a new Calculation Template from this screen by selecting the New Calculation Template link. After creating the Custom Field Template, you will be returned to the selection screen where you can select the new template from the list.

    If calculated data already exists using the fields on the template, or the fields are referenced by calculations, the operation will not be allowed.

  3. Select Save and Continue for a single object, or Change for multiple objects.

    If you are replacing an existing Calculation Template, a message appears informing you that all data currently saved in the existing fields will be lost. Consider whether you want to lose this data before continuing. If this is not what you want to do, select Cancel.

     Field values for fields that are on the same on both the original and new templates will be preserved.

    If you are editing a single object, the properties of that object will appear and you can enter values for the fields now and save the object. If you are editing multiple objects, you will have to edit the objects, either singly or in bulk, next to enter field values.
