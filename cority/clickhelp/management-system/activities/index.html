Activities

An Activity defines how materials will be used in Material Activity calculations. The Activity contains the fields that are used for data entry for the calculations, or Specific Use Variables. An Activity may also include one or more value-based properties.

A Material Activity Calculated Requirement is associated with one Activity and one or more Materials.

 To view Activities, users must have the Manage Materials and Activities user right.
