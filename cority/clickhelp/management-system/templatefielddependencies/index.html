View Template and Field Dependencies

To see what templates and custom fields are associated with an object, you can choose the menu option to Show Dependencies for an object.

Object dependencies listed include:

  • Custom Field Template
  • Custom Fields
  • Event Template
  • Monitored Requirements
  • Task Template
  • Tasks
  • Tags

You can view templates, fields and tasks associated with an object. Select the object in the system model tree, right click and choose Show Dependencies. All the associations for the selected object are displayed.
