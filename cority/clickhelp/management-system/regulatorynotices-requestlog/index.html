Regulatory Notice Request Log

The Regulatory Notice Request Log shows the status of each regulatory notice subscription request.

To view the Regulatory Notice Request Log, navigate to Messages > Regulatory Notice Request Log.

The regulatory notice subscription requests you have made are listed with the status of each. Use Search to search for a specific citation by status or the date requested.

The Status column shows the status of the request. Requests to add or delete a regulatory notice are initially Queued. Pending means the request has been logged. Successful means the request was confirmed. If the request was not successful, the status is Failed; see the Error Message column for further information.

To view details/history of a specific notice, click the link in the Regulatory Notice column.
