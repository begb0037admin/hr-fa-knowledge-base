View Dependencies

When you need to know what other items are associated with or dependent on a system object, you can Show Dependencies for an object.

This function reveals:

  • Custom Field Template associated with object
  • List of Custom Fields used on the object (from the Custom Field Template)
  • Event Template or Requirement Template associated with object
  • Monitored Requirements (for an Event Log)
  • Task Template used (for numeric requirements)
  • Calculated requirements in which the parameter is used (for numeric requirements)
  • Tasks associated with the object

To view object dependencies, select the object (either from the right or left pane), right click and select Show Dependencies.

All the associations for the selected object are displayed.
