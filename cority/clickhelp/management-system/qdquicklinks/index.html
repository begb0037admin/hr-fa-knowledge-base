Quick Links for Quick Data

You can create Quick Links to Quick Data pages which include pre-configured filter criteria. These links can then be used on dashboards to allow easy access from the main application.

To create Quick Links to Quick Data, users must have the Manage Quick Links right. Quick Links created from Quick Data are saved as Shared Quick Links. To be available to users, they must then be published to users or used on a Shared Quick Links panel on a distributed dashboard.

To create a Quick Link to Quick Data:

  1. Make your filter selections for the page.
    For example, on the Data Forms tab, choose the facility for which you want to enter data.
  2. Click Add Quick Link.
  3. Enter a name for the Quick Link (the link name as it will appear on your dashboard). Then click OK.
