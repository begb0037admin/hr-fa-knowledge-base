Material Groups

Material Groups can be used to:

  • Add materials in bulk to Material Activity Calculated Requirements.
  • Update the materials used at one or more locations.
  • Select materials for a Report.
  • Export materials to an Excel template for editing.

Create a new Material Group

You may create your own material groups as needed. When editing a Material Group, you may choose whether or not to apply the changes to existing dependent MACs.

 To view or edit Material Groups, users must have the Manage Materials and Activities user right.

  1. From the menu, select Setup > Material Groups under Materials/Activities. 
    Existing Material Groups are displayed. Expand the search pane to search for a group by name.

  2. Select New Material Group or, right click the Material Groups list and select New.

  3. Enter a Name for the group and an optional Description.
  4. Click Add.
  5. In the selection window, browse or use the search to find the materials to add to the group.
  6. Select checkboxes for the materials, then click Select Materials.
  7. Click Save, then Confirm.
    You will have the option to Update Associated MACs. If this is a new group the option is not relevant, click Back to Manager.

Edit Materials in a Material Group

To edit materials in a material group:

  1. Right click the material group and select Edit.

  2. Click Add to add materials to the group, then select the materials from the selection window.

     Materials will not be deleted from any dependent MACs with existing data (even if the material is not used in existing data).

  3. To delete materials from the group, check the box for the materials you want to delete, then click Delete.
  4. Click Update Associated MACs.
  5. Choose one of the following options: 
    • All: Apply the changes to all dependent MACs. You will be able to view the list of dependent MACs before proceeding.
    • Some: Select the MACs for applying the changes. You will be able to view and select the dependent MACs to proceed.
    • None: Save the changes to the group but do not apply the changes to existing MACs.
  6. Click Next.
  7. If you chose All you will be shown the MACs with which the material is associated, along with the requirement path, in View mode.
  8. If you chose Some, you will be shown the MAC dependencies with a checkbox to select the MACs to update.
  9. To proceed, click Apply Changes, then click Yes to confirm changes.
  10. Click Cancel to cancel all changes.
  11. Click Back to return to the previous screen if you want to change the option.
