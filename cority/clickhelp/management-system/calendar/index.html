Task and Workflow Calendars

The Calendar page gives you a convenient calendar format in which to view your tasks and workflows. The calendar can be customized to show tasks for which you are assignee or assignor, and workflows in which you are a participant or those you created. You may also view tasks and workflows for others if you have the appropriate permissions.

To access the Calendar page, select Calendar from the menu.

An abbreviated calendar may be displayed on your default dashboard. The Calendar panel on the dashboard shows this month’s tasks and workflows. You can access the full version with configurable options by clicking the Calendar header.

In addition to your default personal calendar, an Object Calendar and a System are available.

  • Object Calendar: Shows tasks and workflows related to selected system model objects. Access this calendar from the System Model by right-clicking an object in the tree.
  • System Calendar: Shows tasks and workflows related to the system as a whole. Access this calendar from the System Model by right-clicking the System object (the top level object of the System Model, which is usually the company name).

The Calendar presents an overview of tasks by due date and time. Items displayed in your personal calendar include both:

  • Tasks assigned to you
  • Workflows assigned to you or that you participate in
  • Tasks and Workflows you assigned and flagged to show in your calendar

The initial default view of the calendar is the daily format. You can change the default view simply by choosing another view. The last view used is retained the next time you view the calendar. You can change your view as follows:

  • Click the "W" link in the left column for the week you want to view.

  • Select the "MO" link in the top row of the calendar. Use the navigation controls at the top of the calendar to change the month.

To view tasks and workflows for a specific date, select the desired date in the calendar.

To view a quick summary for a task or workflow item, hold the cursor over the task or workflow link or the task icon.

Dates with a colored border in the calendar have scheduled task or workflow assignments. Blue indicates current items, red indicates overdue items. Click on the task icon to go directly to the task or workflow.

Calendar display and notifications are dependent on the time zone specified in your profile. To receive timely notifications, be sure the correct time zone is selected in your profile.

The calendar includes tasks and workflows for the logged in user, those assigned to the user and those assigned by the user if flagged to "Show in My Calendar" by default. Additional filter options are available depending upon the user’s rights and permissions.

Other operations you can perform from the calendar:

  • Select a task link to complete the task (if you are the assignee). If you are not the assignee, selecting the task link will take you to the task properties.
  • Select a workflow link to view its properties, or navigate to the step completion page, if you are an assignee.
  • Right click a task link to access a popup menu, where you can choose Search Tasks, Complete/Dismiss, or Properties (view).
  • Right click a workflow link to access a popup menu where you can choose View (to view workflow properties) or Complete (navigate to step completion page for current step, if you are an assignee).

Object Calendar

The Object Calendar shows all tasks and workflows associated with a specific system model object (regardless of assignee), or the object and its children if this option is selected. The Object Calendar can be displayed for any system model tree object (Facility, Unit or Point of Interest). It can be displayed in daily, weekly or monthly view.

To view the object calendar for an object:

  1. In the System Model tab, right click the desired object in the system tree and select Object Calendar.
  2. Choose the desired filter options under the mini-calendar on the left:
    • My Tasks: Tasks assigned to you. Checked by default.
    • Tasks I Assigned: Check to include tasks for which you are Assignor.
    • Tasks I May View: Check to include all tasks you have permission to view for this object. This may include tasks for which you are not Assignee or Assignor.
    • Workflows Assigned to Me: Filters for workflows in which you are an assignee.
    • Workflows I Created: Filters for workflows you created.
    • Workflows I Participate In: Filters for workflows where you are a member of any workflow role associated with the workflow.
    • Object’s Children: Check to include tasks associated with child requirements. The default mode is to show only tasks directly associated with the selected object.
    • Tasks not selected to show on calendar during set up: Check to include tasks that were not configured for object calendar display when created.
  1. Click Apply to apply the filter options selected.

To view tasks on the Object Calendar users must have View Tasks permission for that object. To see workflows, the user must have Full Control on the object.
