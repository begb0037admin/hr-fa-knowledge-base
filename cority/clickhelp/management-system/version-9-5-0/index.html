Version: 9.5.0 Released: 5/4/2020

New Features & Improvements

  • Tag Aggregation Calculations
    • Allow aggregation calculations to be created that are updated automatically as new sources are added to the system
  • Calculation Graph Visualizer
    • Allows users to visualize the flow of inputs and calculations throughout the calculation configuration

General Improvements and Bug Fixes

  • MAIN-3481: A new table, WfAggregationSettings, was added to allow workflow aggregation properties of requirements to be retrieved in bulk using a query
