Release Date: July 10, 2026

New Features

  • The user interface for the management system and associated apps has been enhanced. Enhancements include:
    • Updated fonts and colors throughout the platform for consistency and visual clarity.
    • Updated login page for a seamless experience.
    • Updated navigation menu with the following:
      • The menu has been redesigned with a more modern look.
      • The menu now preserves the structure the way the user viewed it last.
      • Icons have been updated to a more modern design.
      • The System Switcher, Profile menu, and Solutions Navigator have been moved to the left navigation menu.
      • The default CorityOne logo can be configured to a custom logo.

      The new user interface and user experience will be made available in customer test environments July 20th and production environments August 24th.
