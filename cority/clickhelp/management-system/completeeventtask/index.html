Completing an Event-Triggered Task

When a task template is associated with an event log, a task is automatically generated whenever an event is created. The task completion form includes the fields necessary to document the instance. The event may be documented by completing the fields on the task completion form.

For an automatic event, the monitored requirement that triggered the task is appended to the task name. The full path can be seen in the task completion form as the monitored requirement.

For a manual event, the name of the event (entered by the user who created the event log entry) is appended to the task name.

To complete a task generated by an event:

  1. Access the task from the task assignment email or from the Management System.

    See How to Access Tasks.

  2. Complete the fields for the event, shown at the bottom of the form. Data can be entered or edited directly on the form.

    If the Accept as Deviation field appears for this event, decide whether this event should be treated as a deviation:

    Yes means that the requirement will be treated as out of compliance for the event period.

    No means that the event will not be treated as a deviation. The not-determined compliance status during the event period does not count towards compliance certification. If a compliance report is created, it will show the requirement as in full compliance for this period.

    For more information, see Compliance Status Report.

  3. To complete the task and save the data:

    Select the Completion Date.

    Set the Completion Status to 100%.

    To keep the task open, set the Completion Status to any amount less than 100%. The task will not be closed until the completion status is set to 100%.

    If the event is associated with a non-numeric task, select the Compliance Period Start and End dates and answer the question "In compliance with requirement?" by choosing the appropriate option.

     These fields appear only when the completion status is set to 100% for a non-numeric requirement.

    Optionally, you can complete the Time to Complete, Cost to Complete and Comment fields, if applicable. These fields are not required.

  4. Select Save.
