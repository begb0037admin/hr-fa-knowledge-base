Version 2025.2

Release Date: June 27th 

New Features

  • Improvements have been made to importing and exporting data from Excel sheets which include:
    • Users can now apply conditional formatting to reports and retain the formatting in the exported file.
    • Additional formulas are now supported in the exported file.
    • For Bulk Imports, the resulting file can now be returned in .xlsx or .xlsm formats.
  • Workflow data can now be imported using the bulk import tool or the REST API.
