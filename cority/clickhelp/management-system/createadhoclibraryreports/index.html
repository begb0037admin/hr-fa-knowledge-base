Creating Ad Hoc and Library Reports

Users with the appropriate permissions may create reports from a variety of standard type on an ad hoc basis, or to save in the report library to be run as needed.

When you save a report in the Reports library, the report is then available to be run with the criteria you selected by any user who has View permissions on the folder or report.

To edit a report or create a new report, Edit permission for reports is required. Edit permission allows you to create and edit reports that include objects to which you also have permission. To create and edit reports that include objects to which you do not have permission, you will need the additional Unrestricted permission.

When you create or edit a report you can define:

  • The objects to report on
  • Properties of objects to display
  • Filtering criteria
  • Grouping and sorting criteria
  • Data processing options
  • Default dates for the report (may be changed by user when run)
  • Default output format (may be changed by user when run)
