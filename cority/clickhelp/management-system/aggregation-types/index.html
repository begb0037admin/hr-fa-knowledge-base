Aggregation Types

The following types of aggregate functions may be used with Time Based requirements. The active time period is defined by the Active Time Begin/End dates, inclusive of the Begin Date and exclusive of the End Date.

For expanded definitions, syntax and examples of these functions, see Mathematical Functions and Notations.

Aggregation Type

Calculated Output

SUM

Sum of all data points within active time period

AVERAGE

Average of all data points within active time period

COUNT

Number of data points generated within active time period

MIN

Minimum value recorded in active time period

MAX

Maximum value recorded in active time period

STDEV

Standard deviation of all data points within the active time period (computed as the square root of the variance)

VAR

Variance in data points within active time period (computed as the average squared deviation of each number from its mean)

GM

Geometric mean

HM

Harmonic mean

QM

Quadratic mean

FIRST

First data point in period

LAST

Last data point in period

Workflow Aggregations (Time Based Fixed Calculations only)
COUNTWF Count of workflows of identified type within time period
SUMWF Sum of values for a workflow field within time period
AVGWF Average of values for a workflow field within time period
MINWF Minimum value of a workflow field within time period
MAXWF Maximum value of a workflow field within time period
