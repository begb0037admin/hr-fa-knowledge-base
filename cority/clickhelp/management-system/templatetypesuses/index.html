Template Types & Use

The following types of templates are used in the system.

Template Type

Applied to

 Description

Requirement Templates

Requirement

Defines the authority and drivers for requirements. Each requirement has a requirement template assigned on creation.

Custom Field Templates

Facility, Unit, POI, Requirement (all types), Event Log

Defines a set of optional custom fields to apply to various system objects. Template can also be used to store a Unique Tag field to be used in data integration.

Task Templates

Event Log; Numeric Requirement with Regulatory or Internal Limits

Defines the parameters for tasks created automatically when a limit is exceeded or when an event is created. Optionally, may specify the automatic creation of a workflow.

Event Templates

Event Log

Defines the properties to be used to document events. The Event Template is assigned to the Event Log on creation.

Calculation Templates

Facility, Unit, POI

Defines numeric fields that may be used in calculations made on child requirements. Field types allowed are numeric, Boolean and calculated fields.

Data Quality Templates

Requirement

Defines fields that may be used to provide further analytic information for a data point, or to provide an optional data substitution script. Field types allowed are numeric, Boolean and calculated fields.

Material/Activity Templates

Facility, Unit, POI, Requirement (all types), Event Log

Defines custom fields that may be used on Materials or Activities. Fields are for informational purposes only and are not used in calculations. Template can also be used to store a Unique Tag field to be used in data integration.
Form Templates Workflow Type Step Defines custom fields that are used on workflow steps.
Notification Templates Workflow Type Defines the content of email notifications for workflows (subject, text body, HTML body).
