Using TimeSpan in Material Activity Calculations

The TimeSpan variable is available for use in Materials Activity calculations. The TimeSpan variable calculates the number of minutes between the Start Time and End Time in each material data line.

The TimeSpan variable may be used in both Material Activity Calculated Requirements and in Tertiary Formula Based properties. For example, if you need to calculate emissions from two or more fuel types, you can define two formula-based properties, Duration of Fuel Use X and Duration of Fuel Use Y, and set the value of each to [TimeSpan].

Data may be entered for a timespan as low as one minute. This data point will be stored at the hour prior to the time entered, rounded down (to avoid storing the data point on the next day when the end time is after 11:00 pm).

Data entered with a start time of 10:29 and end time of 10:30 will be stored at 10:00 and is available to be used in other calculations that have data points available at 10:00. If the data is used with the TimeSpan function the actual timespan of "1" (minute) is used as the calculated value.
