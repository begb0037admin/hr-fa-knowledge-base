Activity Specific Use Variables

An Activity must have at least one Specific Use Variable (SUV). Data entry for at least one SUV is the event that triggers a Material Activity calculation. Although you may have calculation inputs from parameters and standard calculations in your material formulas, an SUV value is still required to trigger a MAC calculation.

Activity Specific Use Variables are created and managed from the Material/Activity Field Library.

To create a Specific Use Variable for an Activity:

  1. From the menu, select Setup >  Material/Activity Field Library.

  2. Select New Material/Activity Field.

  3. For the type of property, select Specific Use Variable.

  4. Enter a name for the property.
    This is the name that is seen at data entry.

  5. If a unique tag is required for data integration purposes, enter the Unique Tag ID (optional).

    Provide an optional description. The description is only seen in the Material Activity property list, but may be useful when selecting properties to add to a material.

  6. Click Save.

The Specific Use Variable must next be added to an Activity in order to be used in a Material Activity calculation.
