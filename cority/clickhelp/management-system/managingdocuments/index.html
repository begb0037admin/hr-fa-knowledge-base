Managing Documents

Document permissions are most commonly set on document folders to control which users have access to document functions. However, permissions may also be set on single documents if necessary.

In order to manage documents, you must have Edit permission on the relevant documents or folders. Users with Edit permission on a folder may:

  • Add new documents.
  • Update a document by creating a new version
  • Set the current version of a document
  • Edit document properties, rename or delete a document
  • Create and manage folders within permitted areas

Users with the Manage Documents user right have global rights to documents. The Manage Documents user right allows all of the above actions on all folders, plus the ability to set document permissions.
