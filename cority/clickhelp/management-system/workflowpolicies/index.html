Workflow Policies

Workflow Policies define business rules that can be used across many Workflow Types. Currently only Notification Policies are supported. (Future versions may include other types of policies, such as Escalation Policies, Validation Policies, and Security Policies.)

Policies may be applied to one or more workflow types. Policies associated with a workflow type serve as the default policies for any workflow instance using that workflow type. Policy overrides may be applied to system model objects, allowing different facilities to specify their own policies for a particular workflow type. See Workflow Overrides.
