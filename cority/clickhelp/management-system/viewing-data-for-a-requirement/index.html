Viewing Data for a Requirement

With the View data function, users can view data calculations for a requirement, and the changes in calculation definitions over time. By clicking on a requirement in the Breakdown of Data section, users can further look at the properties of a requirement.

To View Data for a Requirement

  1. On the Calc Graph Visualizer window, click the Build Graph tab.

  2. Under the View Settings, click the View Data checkbox. 

    Once the checkmark in front of View data displays, the Breakdown of Data section appears.

     This section will be blank before any requirement is selected.

  3. On the header of the Calc Graph Visualizer window, click the Date Range icon.

    The Date Range selector allows users to observe the history of calculations, and any changes in formulas within the selected date range.


    1. On the Data Range window click the Date From, and Date To drop down list, and select dates.
    2. Click Apply.
      The date range is updated, and the Date Range window closes.
    3. Click the requirement of interest.
      The Breakdown of Data section display with data points.

      Data in the Breakdown of Data section by default is displayed in descending date order, you can click the date column for the order to be changed to ascending order. 

    4. To view the Properties panel of a requirement, click the respective column header hyperlink in the Breakdown of Data section.

      The Properties panel will open on the right side of the Calc Graph Visualizer window.

         If the View Data checkbox is not selected, the Properties panel will automatically display on the right of the Calc Graph Visualizer window when a requirement is selected on the graph. 

      1. In the Properties panel, you can select how you would like to view the properties subsections and the information of those sections of a requirement.
        1. Click Expand All to view all property sections and their information of a requirement.


        2. Click Collapse All to collapse all property sections so that only the Property heading sections appears.


        3. Manually select which Property sections should be expanded and collapsed by manually clicking the arrows to the left of each property section.
