Mathematical Functions and Notations

The following table includes definitions, syntax and examples for the major functions that may be used in formulas. Note that buttons are not available for all functions. In all cases, you may enter syntax directly in the formula window.

ABS

Returns the absolute value of a decimal number. The absolute value of a number is the number without its sign.

Syntax: ABS(n)

Example: ABS([Prop1])

If Prop1=-3, ABS([Prop1]) equals 3

ACOS

Returns the arccosine, or inverse cosine, of a number, in radians. The arcosine is the angle whose cosine is the given number.

The returned angle is given in radians in the range 0 (zero) to pi.

Syntax: ACOS(n)

Example: ACOS(-0.5) equals 2*Pi/3 or 2.094395

To convert from radians to degrees, multiply by 180/Pi():

ACOS(-0.5)*180/Pi() equals 120 degrees

ASIN

Returns the arcsine, or inverse sine, of a number. The arcsine is the angle whose sine is number. The returned angle is given in radians in the range -pi/2 to pi/2.

A positive value represents a counterclockwise angle from the x-axis; a negative return value represents a clockwise angle.

Syntax: ASIN(n)

Example: ASIN(-0.5) equals -pi/6 or -0.5236

To convert from radians to degrees, multiply by 180/Pi.

Example: ASIN(-0.5)*180/Pi() equals -30 degrees

ATAN

Returns the arctangent, or inverse tangent, or a number. The arctangent is the angle whose tangent is the specified number.

The returned angle is given in radians in the range
-pi/2 to pi/2.

Syntax: ATAN(n)

Example: ATAN(1) equals Pi/4 or 0.785398

To convert from radians to degrees, multiply by 180/Pi.

Example: ATAN(1)*180/Pi() equals 45 degrees

ATAN2

Returns the angle whose tangent is the quotient of two specified numbers.

Returns the arctangent, or inverse tangent, of the specified x- and y-coordinates. The arctangent is the angle from the x-axis to a line containing the origin (0, 0) and a point with coordinates (x_num, y_num). The angle is given in radians between -pi and pi, excluding -pi.

A positive result represents a counterclockwise angle from the x-axis; a negative result represents a clockwise angle.

Syntax: ATAN2(x,y)

Example: ATAN2(10,5)

To convert from radians to degrees, multiply by 180/Pi.

AND

Combines two Boolean expressions and returns TRUE when both expressions are TRUE. When more than one logical operator is used in a statement, AND operators are evaluated first. You can change the order of evaluation by using parentheses.

ANTILOG

Returns the number of which a given number is the logarithm (or inverse of a logarithm)

Syntax: Antilog(10,n) or POW(10,n)

Example: Log P=6, so P=Antilog(10,6) or 610

Antilog (10,6) is the same as POW(6,10)

AVG

Example:

GM

Returns the geometric mean of an array or range of positive data for a single variable.

The function takes sum of the natural log of all values, then divides that by the count of all values, then returns the Exp of that result. The formula can be expressed as:

EXP(LN(n1)+LN(n2)+…)

Syntax:

GM(n1,n2, ...)

n1,n2, ... is the set of numbers used to calculate the mean. May also be a single array or a reference to an array instead of arguments separated by commas.

Examples:

GM(4,5,8,7,11,4,3)

resolves to 5.476987

GM([Param])

for a TB Calc returns the geometric mean of all values of Param within the period of the time-based calc.

GMOF

Returns the geometric mean for the values of all non-null expressions at the time of calculation.

GMOF(expression1, expression2, ...expressionN)

HM

Returns the harmonic mean of an array of numbers for a single variable.

The harmonic mean is the reciprocal of the arithmetic mean of reciprocals. The harmonic mean is always less than the geometric mean, which is always less than the arithmetic mean.

The function takes the sum of 1/value for all values in an array, then divides the count of values by that result. It can be expressed as:

COUNT(n)/(1/n1+1/n2...)

Syntax:

HM(n1,n2, ...)

n1,n2, ... is the set of numbers used to calculate the mean. May also be a single array or a reference to an array instead of arguments separated by commas.

Examples:

HM(4,5,8,7,11,4,3)

resolves to 5.028376

HM([Param])

for a TB Calc returns the harmonic mean of all values of Param within the period of the time-based calc.

IEEERemainder, REM

Returns the remainder resulting from the division of one number by another number.

Result is a number equal to x- (y Q), where Q is the quotient of x/y rounded to the nearest integer (if x/y falls halfway between two integers, the even integer is returned). Note that two positive numbers can yield a negative remainder.

If x- (y Q) is zero, the value +0 is returned if x is positive, or -0 if x is negative.

If y = 0, NaN (Not-A-Number) is returned.

Syntax: IEEERemainder(x,y)

Calculator button is REM.

IF-THEN

Imposes a condition on the execution of a statement. The statement following an IF keyword and its condition is executed if the condition is satisfied (when the Boolean expression returns TRUE). The optional ELSE keyword introduces an alternate statement that is executed when the IF condition is not satisfied (when the Boolean expression returns FALSE).

Example:

IF ([P1]>1) THEN

[P1]

ELSE

[P2]

END IF

ISNULL

Evaluates for absent or empty value (no data point). The IsNull function has two uses:

1) Evaluates for the existence of a data value and returns a Boolean value.

Example: IsNull([param])

This the same logically as [param] = NULL

2) Can be used to return values instead of NULL, as:

IsNull([param], 2.3)

This is same logically as:

IF ([param] = NULL) then 2.3

ELSE [param]

END IF

LAST

Get the last value for a parameter stored in the system.

In the context of a time-based calc, this will be the last value within the specified period.

LAST()

For a regular parameter, the LAST value is simply the last value stored, relative to the date/time of the calculation that references it (which is set by at least one other requirement which must not be wrapped in LAST or PREV).

Example:

P1 has data value=2 on 1/1/2010

P2 gets monthly data on the last day of each month.

Calc1 formula is [P2]*LAST[[P1]

Calc 1 calculates monthly at same date time as P2, using last value of P1=2 through 2010.

P1 gets new value=3 on 1/1/2011.

Calc1 uses new value of 3 for P1 from 1/1/2011, until a new value is entered for P1.

In essence, this allows parameters to be used like system variables, but in a more flexible manner.

NEXT

Returns the next value of a referenced factor (parameter, system variable or other calculated requirement). The next value that exists for the factor at the appropriate date and time is returned for use in the calculation.


NEXT cannot be used in a top-level aggregate in time-based calculations, but may be used within the aggregation.


NEXTDATEDIFF

Returns the number of minutes between the current date/time and the next date/time for which the referenced requirement has a value.

NOT

Negates a Boolean input.

Example:

0

ELSE

NULL

Evaluates for absent or empty value (no data point). NULL allows comparison to as well as return of NULL (missing value).

Example:

IF ([param] = NULL)

return NULL

ELSE

[...]

END IF

Also see ISNULL for alternate syntax for substituting values.

OR

Combines two conditions. When more than one logical operator is used in a statement, OR operators are evaluated after AND operators. However, you can change the order of evaluation by using parentheses.

PI

Returns the value of pi (3.14159...)

Syntax: Pi()

Example: "Pi times radius squared" is expressed: Pi()*POW(r,2)

POW

Returns a specified number raised to the specified power.

Syntax: (x^y)

Example:

(3^2) calculates 3 squared

The "^" operator indicates the power (y) to which the base number (x) is to be raised.

PREV

Returns the previous value of a referenced factor (parameter, system variable or other calculated requirement). The previous value that exists for the factor at the appropriate date and time is returned for use in the calc.

 

PREV cannot be used in a top-level aggregate in time-based calcs, but may be used within the aggregation.

 

A special use of PREV is when a calc needs to reference the previous value of itself. The syntax for this is PREV ([SELF]). See Self-Referencing Calculations.

PREVDATEDIFF

Returns the number of minutes between the current date/time and the previous date/time for which the referenced requirement has a value.

QM

Returns the quadratic mean of an array of numbers. Also known as the root-mean-square (RMS), the quadratic mean is the square root of the mean squared values.

The function takes the sum of value squared for all values in an array, then divides that number by the count of values and returns the square root of the result. It can be expressed as:

SQRT((n1^2+n2^2...)/COUNT(n))

Syntax:

QM(n1,n2, ...)

n1,n2, ... is the set of numbers used to calculate the mean. May also be a single array or a reference to an array instead of arguments separated by commas.

Examples:

QM(4,5,8,7,11,4,3)

SELF

Allows a calc to reference a previous value of itself, as PREV([SELF]). When a calc is evaluated via the SELF keyword, its formula is not executed, but rather any value that exists for the calc at the appropriate date and time is returned. Can only be used with the time-shift function PREV.

Example: PREV([SELF])+[PRM1]

See Self-Referencing Calculations.

SIGN

Example: SIN(30*Pi()/180) = sine of 30 degrees (0.5)

TIMESPAN

Gives the duration for a MAC data entry, computed in minutes, using the start time and end time of each material data line.

Example:

The MAC aggregation type is AVG and the MAC formula is:

([Thruput (Liters)]/[Timespan])*60

The calculated result is the average thruput in liters per hour.

Timespan is calculated per data line, using the Start Time and End Time, then aggregated.
