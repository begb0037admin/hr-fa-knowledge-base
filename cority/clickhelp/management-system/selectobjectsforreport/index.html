Select Objects to Report On

Select the system objects to include in the report. You may select parent objects to include all children, or narrow your selection to specific objects. If no object is selected, all system objects will be included.

To select objects to include in the report:

  1. Click Add.

  2. From the selection window, browse or search the system model to find the objects to include.

  3. Check the desired objects, then click Associate.

    If you selecting a parent object, you will have an opportunity to specify that you want to include all its children afterwards, if the report type supports it.

    The selected objects will appear in the objects box on the report creation form.

  4. To include all child objects as well (when available), check the Include children box and click Apply.

    To delete objects: Click the Select box and click Delete.

    Optionally, you may allow users to select different objects to include when they run the report. For instance, the same data report, with identical criteria, may need to be run for different pieces of equipment. The object you select in the report creation form will be the default object for the report, but may be changed by users when they run the report.

    To give the ability to select different objects to report on: Check the box to Include Object Selector on Report Run page.
