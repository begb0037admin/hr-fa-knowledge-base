Bulk Creation and Editing

A number of bulk edit operations are available for creating and editing multiple system model objects and requirements.

 In addition to bulk creation functions within the application, bulk tools are available for building components by upload from Excel templates. See your Cority representative for more information on this option.

Bulk creation options available from the application are:

  • Facility/Program
  • Unit/Elements and POIs
  • Create Requirements in Bulk
  • Create an Event Log

Bulk editing operations available are:

  • Edit Objects in Bulk (edit properties of similar object types)
  • Add or change the Custom Field Template (see Apply or Change Custom Field Template)
  • Add or change the Calculation Template (see Apply or Change Calculation Template)
  • Change Requirement Template in Bulk
  • Change Document associations (see Associating Documents)
  • Change Citation associations (see Citation Associations)
  • Change Tags (see Managing Object ID Tags)
