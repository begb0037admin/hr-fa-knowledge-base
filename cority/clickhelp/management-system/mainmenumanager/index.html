Main Menu Management

You can customize the main menu to control which pages are visible to users on a user/group basis.

To set main menu options, users must have the Manage Main Menu permission.

To customize the menu display for users:

  1. From the menu, select Setup > Apps > Main Menu.

    The default system pages are listed, along with any custom pages for Apps that have been configured for the system. The Visibility column shows the users for whom the page display is enabled.

    The native pages (Home, Messages, Calendar, Tasks and Workflows, and System Model) are visible to all users by default. You can change the visibility of these tabs, as well as any custom pages for all users, or specify visibility by user groups.

  2. To change visibility settings, click Edit.

    To display the page for all users, check Visible to All.

    To display the page only for specific users and groups, uncheck Visible to All. Then click Add in the Visible to Users/Groups boxes and select the users/groups to whom the page should be accessible.

    To hide the page for all users, check Invisible to All.

    To hide the page only for select users or groups, uncheck Invisible to All. Then click Add in the Invisible to Users/Groups boxes and select the users/groups for whom the page should be hidden.

  3. Click Update.
  4. When you have finished editing page visibility, click Save and Confirm to save your menu changes.

To delete a page:

  1. Click the Delete link.

  2. Click OK.

    Deleting a page removes all visibility settings and hides the display for all users. However, page visibility can be restored if desired.

To restore page visibility:

  1. Click Add.

    A dialog displays with a list of pages available, including any Apps not currently displayed and any native pages currently hidden.

  2. Select the page you want to restore.
  3. Set the visibility per users or groups as desired. Then click Update.
  4. Click Save and Confirm to save menu changes.

 Disabling display of a native page does not disable access to the features on that page. For example, if the Tasks and Workflow page is not displayed, users will still be able to view tasks and workflows through quick links, dashboard panels, and right-click menu options. Deleting a custom page does not delete the App associated with it; it only disables the page display.

To change page display order:

  1. Click and hold on the arrows in the Drag to Order column and drag the item to the position you want.
  2. Click Save and Confirm to save menu changes.
