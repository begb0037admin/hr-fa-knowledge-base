Edit Citations

You can edit a citation in these ways:

  • Create a new version of the citation. When you edit the properties of the citation, a new version is created. All links to the current version will go to the new version.
  • Edit a specific version of the citation. When you edit a specific version of a citation, a new version is not created. Any existing links to this version are unchanged.
  • Edit citations in bulk, creating a new version of each citation in the process.

To create a new version of a citation:

  1. Right click the citation in the Citations library and choose Properties > Edit.

    The citation form appears, with the current information for the citation.

  2. Edit the form fields as necessary, then click Save.

    All links to "Latest" version will automatically point to the updated version. However, links that were made to a specific citation version will not be changed.

To edit a specific version of a citation:

  1. Right click the citation in the Citations library and choose Versions.

    The existing versions of the citation are shown.

  2. Edit the form fields as desired, then click Save.

  3. Click Confirm.

    The changes will be saved to this version of the citation only. All links to this version will be unchanged.

To copy a Citation:

  1. Right click the Citation choose Copy.
  2. Right click the folder to which you want to copy the Citation and choose Paste.
  3. Enter a new name for the Citation, if desired.
  4. Select Save.

 Permissions on the original Citation are not copied. A copied Citation inherits the permissions set on the parent folder. If you want to set specific permissions, you must edit the permissions individually.

To move a Citation:

  1. Right click the Citation and choose Cut.
  2. Right click the folder to which you want to copy the Citation and choose Paste. Optionally, you may rename the document before saving in the new location.
  3. Select Save.

To rename a Citation:

  1. Right click the Citation and select Rename.
  2. Enter the new name and click Save.

To edit citation properties in bulk:

  1. Check the Select box for all the citations you want to edit.

  2. Right click and choose Properties > Edit.

  3. Check the boxes for the properties in common that you want to edit, then enter the new values.

    A new version will be created for each citation, with the selected properties changed.

  4. Click Save, then Confirm.
