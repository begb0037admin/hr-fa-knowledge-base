Role Memberships

The Roles tab in the Workflow Type Editor shows the Roles used in the workflow and the default users or groups associated with them.

The default role members will be used for step assignments for all workflow instances, with the following exceptions:

  • Workflow is associated with an object that has workflow overrides.
  • A user who has Assign permission (granted to a Role of which they are a member) selects another system user for a step assignment.

Roles and permissions work together to determine what users may do at any step in the workflow, or in general workflow operations. See Workflow Permissions.

Roles do not require default members to be set. It is a best practice in most cases, however, to ensure that roles used in steps have default members assigned. Default members can be assigned either through the workflow type or through overrides on the objects associated with the workflows. The creator of the workflow instance may choose to assign the step to someone else after initiating it, and the same role may be used on other steps. The first step Role may also be used to define who is allowed to create workflow instances from this type by giving the Create permission to the role (although that permission may be given to any role).

Workflow Manager: Members are dynamically assigned to the Workflow Manager role, but you may add other members to whom you want to grant permission to manage all workflow instances.

Other Roles: Other Roles include Roles not used in the process but additional Roles that are associated with the Workflow Type. These are usually added in order to grant special permissions. For instance, a Workflow Reports role can be created and granted permission to run reports on the workflow.

To add or edit default role memberships for a workflow type:

  1. On the Workflow Type properties, click the Roles tab.

    The roles used in the process are shown in the Roles used in Steps section, with existing member associations. For a new workflow where default members were not specified on the workflow Roles creation, the memberships will be empty.

  2. Select Edit for the role you want to edit.

  3. Click Add User or Add Group.

  4. Select the user or group you want to add from the selection window.

    To remove a user or group, select it and click Delete.

    You may add as many default members as needed to the role. Users will be able to select from the list of default members when assigning the step.

  5. Click Update.
  6. Click Save to save the changes to the workflow type when you are finished, or select another tab to continue editing the workflow type.
