Version: 9.5.1 Released: 6/29/2020

This release focuses on modifying the user interface colors and styles to ensure consistency among Cority products. 

General Improvements and Bug Fixes: 

  • Users without the Manage Workflow and Manage Users/Group rights are now allowed to query the workflow type table.
  • MAIN-3260: The Case expression is now supported by EQL. 
  • MAIN-11495: The String_Agg function is now supported by EQL.
  • MAIN-11557: The DateFromParts function is now supported by EQL.
  • MAIN-11558: The EoMonth function is now supported by EQL.
  • MAIN-9878: A logout page may now be specified per system. This allows SSO users to log out of the application without being redirected to the login page.
  • MAIN-11008: When using SSO, the Main Menu icon now displays correctly (no double images).
  • MAIN-11654: Using a colon in the object names no longer creates a problem for updating calculations.
  • MAIN-11610: Using long custom field names no longer causes the EQL update service to fail and new fields not to be made available.
  • MAIN-11516: New REST API is added for updating custom field captions and picklist items, including language localizations.
  • MAIN-11474: An issue of occasionally creating multiple workflow instances for the same task has been resolved.
  • MAIN-11498:Performance of creating workflows with large numbers of custom fields has been improved.
  • MAIN-11500: A slight performance improvement when loading Workflow Solutions has been made.
