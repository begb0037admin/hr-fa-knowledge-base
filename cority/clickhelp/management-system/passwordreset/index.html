Password Reset

Users who forget their passwords can use the "Forgot your password?" link on the login page to have a temporary password sent to them by email. They can then use the temporary password to log in and change their password. In order to obtain a temporary password, users will have to successfully answer one of their security questions.

If the security questions have not yet been set up, or the user cannot answer the security question successfully, they will be directed to contact their administrator. The administrator can reset the password and check the option that "User must change password at next logon" to allow the user to reset the password. If security questions have not yet been set up, the user will also have an opportunity to do so on logging in. Users who are unsure of their security questions should be instructed to review and edit the security questions in the profile.

Administrators do not have access to the security questions. They can only be accessed by logging in with the user id and editing the personal profile.
