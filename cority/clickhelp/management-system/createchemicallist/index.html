Create Chemical List

You can create your own Chemical Lists to reflect the chemical regulatory obligations that apply to your Material Activity requirements.

To create a Chemical List:

  1. Select Setup > Chemical Lists under Materials/Activities.
  2. Select New Chemical List.
  3. Enter a Name for the group and an optional Description.
  4. Click the plus sign (+) to expand the Chemical List Limits History.

  5. Click Add to add a new value history.

    An initial value history is available for editing.

  6. Click Edit.

  7. Click Add to add chemicals singly, or Add Group to add chemicals in bulk from a Chemical Group.
  8. In the selection window, browse or use the search to find the chemicals to add to the group. Select the checkboxes for the desired chemicals and click Select Chemicals.

  9. After adding the chemicals to the list, enter the limits for each chemical in the list. Set the Begin Date, then click Update.

    The Begin Date defaults to today’s date. It must be set early enough to include the earliest date for which data will be entered.

  10. Click Save, then Confirm to save the Chemical List.
