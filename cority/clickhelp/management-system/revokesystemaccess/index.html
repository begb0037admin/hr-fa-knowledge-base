Revoke System Access

You can revoke access to the system for any user granted access from another system. When you revoke access, the user is deleted from the system and no longer appears in the user list (even if you choose to show deleted/expired users). All user group assignments, rights and permissions in the system are removed.

 To retain the user’s information for reactivation at a later time, mark the user account as expired instead. When the account is expired, the user’s account is locked. All group memberships, rights and permissions in the system are retained and will be reinstated if the expiration date is reset to active. The user appears in the user list if you choose to show deleted/expired users.

To revoke access to the system for an external user:

  1. Right click the name of the access user whose access you want to revoke and select Revoke Access.

    To see access users, Access users must be checked in the Show options in the search pane. In the user list display, the Home System for the user is shown in the last column.

  2. Confirm by clicking Revoke again.
