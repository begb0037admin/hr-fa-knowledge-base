Add/Remove Associated Objects for Multiple Tasks

To add or remove object associations for multiple tasks:

  1. First, search for the tasks you want to edit using the search criteria in the Tasks search pane.
  2. Select the checkboxes for the tasks you want to edit.

  3. Right click and choose Edit Task Properties in Bulk.

    A task form appears with the selected tasks listed on top of the form.

  4. Check Selected object(s) to enable editing.

    Any objects that the tasks already have in common are shown.

    To remove an object association, select the object and click Remove.

  5. To add objects, click Add.

    In the selection window, search for the requirements to associate. Select the checkboxes for each requirement, then click Select Requirements.

  6. Click Save. The changes to the tasks are shown for your review. Click Save again or Back to edit.
