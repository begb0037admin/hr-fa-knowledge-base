About Admin Tools

Tools to help administrators monitor activities in the system include:

Setup 

The Setup functions allow you to create and manage various system components. The Setup link (next to Help & Training at the top of the page) is only displayed for those users with the appropriate rights and permissions to the functions it contains.

Command Log

The Command Log allows you to monitor activity in the system by tracking transactions. You can check for failed or partially completed commands and monitor processing speed. While all users have access to the Command Log to view their own transactions, administrators may monitor activity throughout the system.

Data Integration with Web Services

For database integration projects, the Web Services APIs can be accessed by any application that can send data to Web Services. Existing third-party applications can be used to send date, or, for those without an existing data service, Cority provides the EIFL software.

Bulk Upload and Editing Tools

A collection of bulk upload and editing tools may be utilized for more rapid system implementation. These tools require coordination with the Cority Support team.
