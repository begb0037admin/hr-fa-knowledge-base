System Properties Report

A System Properties Report can be used to report on system model objects and properties. The report can include a combination of any of the generic and custom properties of the system model objects.

Some examples of System Properties Reports are:

  • List of requirements by regulatory program
  • Equipment list and associated characteristics
  • Emission sources and associated information

You can select the objects for reporting, the properties to include, add a filter based on property values, and specify sorting.

The rows of the report are created by the system objects selected. The columns are the object properties.
