View Report Execution History

When any report in the Reports library is run, the execution history is retained and the results are cached, up to a limit. The previous execution history of any report in the Reports library may be viewed up to the limit of the cache size, and cached reports may be retrieved.

 The number of reports of each type that are cached depends on the cache size that is set for the system. Default number of cached reports is 10.

To view the report execution history:

  • Right click a report and select View Execution History from the context menu.

To view a cached report:

  1. Click the View link in the Action column.

    You have the option of changing the default output format shown.

  2. Click View Report.

 Users will see only those cached reports executed by themselves, unless they have Unrestricted permission on the report or the Manage Reports right.
