View/Edit Event-Related Tasks

You can view a list of tasks associated with an event log and gain a summary of task status. From the filtered task list, you can choose to view or edit the tasks.

To view tasks associated with an event log:

  • From the Applicable Requirements view, select the event log, right click and choose Tasks from the popup menu.

    Tasks are displayed, filtered for the selected Event Log.

Use the search criteria to change the filter, specifying a date range if desired. To see all tasks regardless of assignor or assignee, select Tasks I May View.
