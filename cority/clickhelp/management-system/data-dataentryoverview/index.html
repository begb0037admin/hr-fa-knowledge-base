Data Entry Overview

Numeric data may be entered into the system by various methods:

Quick Data: With this method users access a separate interface with limited functionality. Data is entered into a form that has been pre-configured for data entry for specific sets of data. Quick Add is designed for easy data entry for users who have no need to access the main application.

Quick Add: Use this method to enter or edit periodic data in the main application. A form is generated with specified dates. Quick Add can also be use to set up a Quick Link on the dashboard, so that users can access the requirements for which they need to enter data directly.

Data Enter/Edit (standard data entry): This method offers full functionality for entering and editing data of any kind. You will need to use this method for random or discrete data that does not occur at regular intervals (daily, monthly, quarterly, yearly) or to enter any data that needs a precise time stamp.

Excel Data Upload: You may upload data from an Excel file.

In addition, data may be uploaded directly to the system via backend data integration systems with existing legacy databases. This process may be automatic or manually induced, according to the design. For information on data integration systems, see your organization’s data administrator, or contact your Cority representative.
