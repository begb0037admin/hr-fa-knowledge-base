Export/Import Materials

You can export one or more material definitions to an Excel file for editing. The following properties may be edited from Excel:

  • Material Description
  • Value Based Properties
  • Chemical concentrations
  • User defined fields (custom fields on Material/Activity Template)

Edited materials may be uploaded to the same system, or to a different system model. If uploaded to a different system model, any formula based properties associated with the materials will not be copied. However, if the same formula-based properties exist in the target system, the associations will be retained.

Export a material

To export a single material to Excel:

  1. Right click the material in the Materials list and choose Export to Excel.

  2. Choose a file name and a location and Save.

    Open the file in Excel to edit it. Separate tabs in the file show the material definition, chemicals, value-based properties, and custom fields from a Material Template, if any.

Export multiple materials

To export multiple materials to an Excel file:

  1. In the Materials library, select Import Materials.

  2. Click Add in the Create Template section. In the selection window, select the materials to download.

  3. If a Material/Activity Template is applied to the materials, select the template from the template list.
  4. Click Get Template.
  5. Choose a filename and a location to save the file.
    Open the file in Excel and edit the material property values as needed.

Import materials

To import materials from an Excel file:

  1. On the Materials tab, select Import Materials.
  2. In the Load Template section, click Browse.
  3. Find and select the Excel file.
  4. Click Upload.

You can create new materials by copying the rows for an existing material, then rename it and edit the fields as necessary. Formula based properties will not be copied for new materials created in Excel and uploaded to the system.

If formula-based properties are required, copy a material in the system, rename it, then download it to Excel for editing. As long as the name remains the same, the formula-based property association will be retained.
