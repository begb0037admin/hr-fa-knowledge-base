Editing Calculations in Bulk

If you have multiple requirements that use the same calculation formula and that formula needs to be changed throughout, you can use bulk edit. When editing calculation formulas in bulk, certain restrictions apply:

  • Requirements must be of the same type (Calculated Requirement, Time Based Fixed, Time Based Rolling, etc.) to be edited in bulk.
  • In order to prevent an unknown number of re-calculations in the system, when you edit formulas in bulk, the Start Date for the formula cannot be earlier than the current date/time.

When bulk editing calculations, objects with the same name under the same parent object will be available for inclusion in the calc, and each calc included in the bulk operation will reference the value in its own location. Objects located elsewhere in the model can be referenced by path and all calcs will reference the same object.

Example: Facility A and Facility B have the following objects: Param1, Calc1. The Calc 1 formula is:

Param1* Calc1* AP-42 Factor1

The AP-42 Factor is located in a library of AP-42 table values, located elsewhere in the model. The calculation needs to be edited to reference a different AP-42 Factor, from this date forward.

When you edit Calc 1, Param1 will be available as one of the Calculation Requirements that may be used in the formula. The AP-42 Factor will need to be added. The result of the bulk edit on the calculation formulas to replace AP-42 Factor1 with AP-42 Factor 2 will be:

[MySystem/Division A/Facility A/Param1] * [MySystem/Division A/Facility A/Calc1] * [MySystem/ReferenceLibrary/Table 1/AP-42Factor2]

[MySystem/Division B/Facility B/Param1] * [MySystem/Division B/Facility B/Calc1] * [MySystem/ReferenceLibrary/Table 1/AP-42Factor2]

To edit calculations in bulk:

  1. In the Applicable Requirements view, use the search function to find the calculated requirement you want to edit.

    Since you can only edit objects of the same type in bulk, you can set the search to the object type and add any other desired search criteria.

  2. Select the checkboxes for the requirements to edit. Right click and choose Properties > Edit.

    A bulk edit properties form is displayed. The objects selected to edit are listed at the top of the form. All the properties that may be edited are shown.

  3. Select the checkbox next to the Calculation Requirements box.

    This will enable editing for both Calculation Requirements (so you may add new factors if necessary) and the Calculation Definition.

    The Calculation Requirements will show the names of all requirements that the requirements being edited have in common in their respective locations (followed by "- common requirement").

    If you need to add one or more factors to be used in the calculation, click Add and browse to select the requirements you need. Added requirements will be shown with the full path.

  4. Expand the Calculation Definition (click the plus sign). Click Add to add a new value history.

    You will not see existing histories for the requirements being edited. However, all existing histories will be automatically end dated with the Begin Date for the new formula history.

  5. Click Add to create a new value history.

  6. Set the Begin Date. Date must be later than the current date/time.

    Existing value histories for all requirements being edited will be automatically end-dated with this date.

  7. Use the calculation builder to create the new formula and Save.
  8. Click Save, then Confirm.
