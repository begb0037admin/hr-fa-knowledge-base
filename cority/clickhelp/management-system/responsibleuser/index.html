Default Task Assignee (Responsible User)

You can set a default assignee for a task related to any requirement or System Model object by designating the Responsible User on the object properties.

When a Responsible User is set for an object, any tasks created for that object will automatically have that user as the default task assignee. However, the assignee may be changed on the task form as desired.
