Management System - 2023.2 Release Notes

Release Date: June 30th

New Features

  • The EMS user interface has been modernized:
    • On the left navigational panel, the first level and second level menu has been updated; and
    • The font and background color of the user interface has been updated.
  • When creating a new custom field in the Management System, depending on the data type, a "Track Value History" option is now available.

The Track Value History option should only be selected for custom fields that need or require to be tracked. If this option is selected for every custom field, the system will slow down.

  • Users with appropriate permissions will now be able to launch Bulk Tools as an app in their sandbox environment.
