Data Integration for Material/Activities

To integrate external databases with the Management System when Material Activity calculations are used, it is necessary to assign unique tags the following object types:

  • Specific Use Variable(s) used for data entry: Define the unique id value on the field properties.
  • Parent object of the MAC calculations: Apply a Custom Field Template with a Unique Tag custom field, or add the field to an existing template on the object. Define the tag value on the object properties.
  • Materials used in the MAC calculations: Apply a Material Activity Template with a Unique Tag custom field to the Material. Define the tag value on the Material properties.

  • Activity used by the MAC calculations: Apply a Material Activity Template with a Unique Tag custom field to the Activity. Define the tag value on the Activity properties.

     If the concept of an Activity is not part of the source database, a generic activity ID may be created through the configuration file for data integration purposes.

  • Standard Requirements used in material calculations

    Standard requirements (parameters, calculated requirements and system variables) that are used in material formula-based property scripts require a Tag Scheme: Tag if they are to be relative to the location. See Tag Schemes and Tags. System-wide variables referenced explicitly will require a Unique Tag custom field.
