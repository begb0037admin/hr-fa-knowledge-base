Workflow Field Value Inheritance

A workflow instance can inherit the value of a field from:

  • An object or objects associated with the workflow
  • A parent workflow to child workflow at the time of creation only, if the field is a global field on both workflow types.

Associated Object Inheritance

In order to inherit the value, the same custom field must be applied to the associated object or parent object, and on the form for the first step in the workflow. If the field is used on a form for a step other than the first step, then it can inherit the value if the field is global in scope.

"Facility Name" is a custom field applied to the Facility. "Facility Name" is also on the form template for the first step on the workflow type. A workflow instance is created and associated with the Facility. The value of the field will automatically be transferred to the workflow form. If a workflow is created for a child POI which does not have the field itself, the value will be inherited from the parent Facility.

In the case of multiple objects associated with the workflow, the value is inherited if the value is the same across all associated objects (disregarding null values). The same rules regarding inheritance from parent objects apply.

Parent to Child Workflow Inheritance

The value of a global field on a parent workflow will be inherited by a child workflow if the same global field exists on the first step in the child workflow. This inheritance is one-time only, at the time of creation. If the value of the field subsequently changes in the parent workflow, it will not be changed in the child workflow.
