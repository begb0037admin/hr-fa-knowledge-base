Numeric Data

Numeric data includes both data directly entered in or uploaded to the system and the calculated data that results from data entry. Numeric requirements include the following types:

Parameters: Used for direct data input.

Calculated Requirements: Data calculated by the system based on parameter input and other variables. Different types of calculated requirements include standard calculated requirements along with time-based calculations (roll ups and aggregations).

Material Activity Calculated Requirements: Data calculated by the system as a result of the use of specific materials in an activity. Data includes both the data input on the specific use variables, and the data calculated as a result of the input.

System Variables: Constants used for calculation purposes.

Auto Parameters: Used to generate a specific value at a specified frequency; often used to trigger calculations at a specific point in time.
