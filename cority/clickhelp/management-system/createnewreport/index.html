Create New Report

You can create a new report from the Reports tree. 

To create a new report:

  1. Right click the report folder in the Reports tree and select New, then select the type of report you want to create.
  2. Alternatively, open the folder in which you want to save the report and select Add Report.
  3. Select the type of report to create, then select Continue.
  4. See Types of Reports.
  5. In the New Report form, select the report options and criteria for the information to include in the report.
  6. To filter report output by dates, select the Date From and Date To.
    The selected dates will become the default dates for users when running the report. However, users may edit the dates when they run the report.

    The report type determines which fields are filtered by the date range. For example, System Properties Reports filter on Active and Inactive dates of system objects. Task Reports filter on Task Due Date. Data Reports filter on the dates associated with data points. See the sections for each report type for more information.
  7. The report options depend on the report type selected. The following common selection criteria are available:
    • Select Objects to Report On
    • Select Properties to Report On
    • Refine Results by Filtering
    • Select Users or Groups to Report On
    • Select Aggregates to Report
    • Data Grouping Options
    • Data Report Display Options
  8. After selecting report criteria, in the General Report Description section, enter a Report Name and optional Description.
  9. Both the Name and the Description will appear in the list of reports in the Reports library. The description can help users identify the purpose of the report.
  10. To save the report to a different folder, you can select the folder from the list.
  11. A Header and Footer for the report output may also be specified.
  12. Select the Output Format for the report.
    • HTML: View the output directly in the Web browser.
    • Excel: Export the data to an Excel file, in a basic formatted view.
    • Excel Template: Exports the raw data to an Excel file. You can then use other worksheets and macros to format the data as you wish. See Excel Template Reports (Custom Reports).
      The default format will be pre-selected for users when they run the report. However, users will be able to choose either format.
  13. Select Preview to preview the output if you wish.
    If you choose HTML output, the report preview will appear in a new browser window. Or, if you chose Excel format, you will have a choice of opening or saving the report to a file. After previewing, if you want to edit the report further, you can return to the report definition and refine the output before saving.
  14. To preview the report, you may need to select sample dates to include in the report. If you do not want to have the same dates selected by default when users run the report, reset the date fields to the desired default dates for the report before saving the report.
  15. Select Save to save the report when you are satisfied with the output.
