About the Document Library

The Document library allows you to associate relevant documents with activities such as tasks, workflows and event logs, or with requirements and system model objects.

You may store documents either as files, which are uploaded to the system and maintained in the Documents library, or as links to documents accessed via the Web. By creating documents as links rather than files, you can integrate with an external document management system, documents in your company intranet, or documents maintained by another agency. For each document you want to use in the system, you will need to create an item (file or a link) in the Documents library.

To access Documents, you must have View or Edit permissions on one or more documents or document folders.

The Manage Documents user right grants global access and permissions to documents. This right is customarily given only to an individual with librarian responsibility in the system.
