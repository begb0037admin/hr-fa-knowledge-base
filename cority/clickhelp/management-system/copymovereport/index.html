Copy/Move Report

You can create a copy of an existing report and save it to another report folder, or rename the copy and save it to the same folder. When you copy a report, all criteria set in the original report are identical. You can then edit it, if you wish, to change criteria. This may be useful for creating an identical report for a different part of the system model.

To create a copy of a report:

  1. Right click the report in the Reports library and choose Copy.

  2. Right click the report folder into which you want to copy the report and click Paste.

  3. Rename the report as desired.

    You may delete this and use the same name if you are saving to a different folder.

    To copy the report to a different folder than that selected, you may choose a new folder from the list.

  4. Select Save.

    Permissions on the original report are not copied. A copied report, just like a new report, inherits all the permissions set on the parent folder.

To move a report to a new folder:

  1. Right click the report name in the list in the Reports library and choose Cut.
  2. Right click the folder into which you want to copy the report and click Paste.

  3. Rename the report if desired, and select Save.

    When you move a report, the report inherits the permission on the new parent folder.
