Version 2025.1

Release Date: March 7th 

New Features

  • The cross-platform user experience has been improved to provide more seamless navigation between the EMS and GX2 using a consolidated menu. In GX2, when EMS integration is configured, users can now navigate to the Air, Water, and Metrics clouds from the menu and access all functions and configuration of the EMS. Similarly, from the menu in the EMS, users can navigate to the clouds and options available to them in GX2.
