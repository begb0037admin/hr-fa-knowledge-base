Edit General Task Attributes for Multiple Tasks

To edit task attributes for multiple tasks at once:

  1. Search for the tasks you want to edit using the search criteria in the Tasks search pane.
  2. Select the check boxes for the tasks you want to edit.
  3. Right click and choose Edit Task Properties in Bulk.
    A task form appears with the selected tasks listed on top of the form. Properties available for editing are shown on the form; when the values are the same for all tasks, the value is also shown.
  4. Select the checkbox for a property to enable editing.
  5. To change the assignee(s) for all tasks, add the new assignee(s) by selecting from the list, and remove old assignee(s).
  6. After making all desired changes, click Save.
    The changes are shown for your review.
  7. Review your changes and click Save again, or Back to edit.
    Identical changes will be made for all the selected tasks. Only those properties specifically selected for editing will be changed.
