Calculated Requirements

Calculated Requirements can be defined using arithmetic, algebraic, and statistical functions. Calculations can be set for rolling periods or fixed periods.

Calculations are defined through an expression builder similar to the calculator on a standard personal computer. Numeric parameters, variables, and previously defined calculated parameters are available to include in the calculation definition. This menu-driven approach simplifies the calculation setup process. For example, it is very simple to set up a rolling average of the sum of other calculated parameters.

If it is necessary to change the expression by which a parameter is calculated, the calculation may be edited. The system automatically keeps and displays a record of the versions of the calculation and the time periods for which each version is used. This is particularly useful if emission factors change or there is a change in the input parameters to a calculation.
