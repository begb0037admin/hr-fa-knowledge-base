Activity Fields

An Activity must contain at least one Specific Use Variable. Data entry on the specific use variable is the event that triggers the Material Activity calculation, along with any dependent calculations.

One or more value based properties may also be associated with an Activity. An example of a value based property for an Activity might be an equipment setting (such as a flow meter setting).

The two types of Activity fields are:

  • Activity Specific Use Variable (SUV): The property that is used for data entry on a Material Activity calculation, such as the amount of material used.
  • Activity Value Based Properties: Constants (numeric or Boolean) that are specific to the activity.

Activity fields are created and managed from the Material/Activity Field Library.
