Multi-Selection List Box

A multi-selection list allows users to choose one or more pre-defined values using checkboxes.

To create a multi-selection list:

  1. For the Data Type, choose Text.
  2. For the Value Entry Method, choose Multi-Selection List Box.
  3. In the Value box, enter the text for the first list option.

  4. Select Add to add another list item.

    Sort Options by Value: Selecting this option order the items alphanumerically. If you do not select this, the options will display in the order entered.

  5. Select Save and Confirm.

Localization

The Name, Caption and Description may be localized in any of the available languages in the system.

To enter translated values for different languages:

  1. Click the language symbol next to the field.

    In the pop-up dialog the currently active languages for users in the system are shown, as determined by the values selected in the Culture field in users' profiles. Check "Show All Cority EMS Languages" if you want to add translations for languages not currently selected by users.

  2. Enter the value to use for each language for which you want to provide a localized translation.

  3. Click Save.
