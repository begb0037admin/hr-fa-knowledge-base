Quick Data Reports

Select the Reports tab to view the reports that are available from Quick Data.

To run a report:

  1. Click to open a report folder and find the report you want to run. Then click the report link.

    A new browser window opens to select the report dates and output format.

  2. Click Run Report.

  3. For Excel report output, in the File Download dialog, choose Save to save the report to your computer and choose a location to save it on your computer. Close the browser window after downloading.

    For output to HTML, the report will open for view in the same window.

     Reports must be stored in a folder named QuickData Reports or one of its sub-folders in the Reports library in order to be run from the Quick Data interface.

  4. Enter a name for the Quick Link (the link name as it will appear on your dashboard). Then click OK.
