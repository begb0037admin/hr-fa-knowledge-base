Setting Up the System Model

The System Model is established by creating the various model components that reflect the company’s operations and configuring the properties necessary for informational and reporting purposes. These components may be created and edited as needed by several methods:

  • HTML input onto menu-driven set-up pages.

    Companies that have a relatively small number of facilities, permits, and compliance obligations typically set up their System Model in this manner.

  • Bulk upload via Excel templates.

    Bulk upload templates are available that allow creating and editing components of the System Model in bulk. See your Cority representative for an explanation of these tools and to get access. See Bulk Upload and Editing Tools.

  • Direct transfer of information via electronic means.

    This approach may be preferred when the information has already been compiled into a database format.

The System Model can be modified at any time to reflect new or modified facilities, programs or requirements.
