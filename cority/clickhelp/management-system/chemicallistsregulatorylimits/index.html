Set MAC Regulatory Limits Using a Chemical List

Regulatory limits on a Material Activity Calculated Requirement may reference values stored on a chemical regulatory list.

To set the regulatory limit to reference a Chemical List:

  1. Select the Calculation tab of the Material Activity Calculated Requirement properties.

  2. Click the plus sign (+) to expand the Limits section, then click New to define a new limit.

  3. Click Chemical to select the chemical to monitored. Select the chemical from the selection window.

  4. Select the Comparison, then enter the percentage of the regulatory list value to use for the limit.

    You may set both Regulatory and Internal limits, as desired.

  5. Click Update to save the limit history value.
