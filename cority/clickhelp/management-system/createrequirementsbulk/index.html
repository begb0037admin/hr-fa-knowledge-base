Create Requirements in Bulk

To create Requirements in bulk:

  1. In the Applicable Requirements view, use the search to find the parent objects under which you want to create the new Requirements.

  2. Select the checkboxes for the parent objects under which the new Requirements will be created.

  3. Right click and choose New > Requirement.
  4. Select the Requirement Template.

  5. Choose the requirement type.

    Optionally, select a Custom Field Template, if desired.

  6. Click Continue.

  7. Complete the properties as appropriate.

    The same property values will apply to all the requirements created.

  8. Click Save.

    The list of objects to be created and the property values are displayed for review. You may click Back to edit if necessary.

  9. Click Confirm.
