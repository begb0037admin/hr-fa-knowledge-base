Resetting Password in User Profile

To Reset Password in User Profile

  1. On the Main menu, click Setup.
  2. Under Security, click Users. The Users window appears.
  3. In the Search section input information of the user you are looking for, and then click Search.

The user list below will filter, showing user options that fit search criteria.

  1. Click the user. The Users profile appears.
  2. Under the Edit User section, to the right of the Password textbox, click the Reset Password link.

A prompt displays “Would you like to reset the user’s password?

  1. Click OK. The time sensitive link will be sent to the user’s email.

For users that do not require a password and are expected to access the user interface through SSO, No Password can be selected instead of resetting the password.

  1. Click Save.
