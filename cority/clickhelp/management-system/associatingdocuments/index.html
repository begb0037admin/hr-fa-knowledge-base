Associating Documents

Documents may be associated with System Model objects, Requirements, and Tasks via document links. In order to associate a document with any object, the document must first be stored in the Documents library.

 In order for users to view an associated document, they must have View permission to the document. Document permissions are granted separately from object permissions. Users must have permission both to the object and to the associated document or document folder to access a document associated with an object.

You can add or edit links from one or more documents to one or more System Model objects or requirements:

  • From the Documents library
  • From the object properties page

If you select multiple objects, you can associate documents to all documents or bulk edit all associations that the objects have in common.

Permissions:  View or Edit permission on the document and Modify permissions on the object are required to edit document associations. To associate documents with tasks, a user must also have Create and Complete Tasks permission on the parent object.

To link one or more documents to one or more objects:

  1. From the Documents library, select the document(s) you want, then right click and select Associate.
    If any links to the document already exist, the objects currently linked are shown. In the case of multiple documents, any objects they have in common are shown.

  2. Click Add Association.

  3. Click Add in the "Objects to associate" section to find the objects to associate.

  4. In the selection window, browse the system model or use the Search to find the objects to which you want to create links.

  5. Select the object(s), then click Select Objects. 

  6. Click Save to save associations.

Link one or more objects to one or more documents

You can link one or more objects to one or more documents by setting their relations. 

  1. From the Applicable Requirements view, select the object(s) to be linked, right click and choose Properties > Edit.

  2. Scroll to the bottom of the object properties page to the Relations section. Check the Documents box, then select Add.

    The Document selection window appears.

  3. Browse the document folders, or expand the search pane and use the search function to find the document(s) you want.

  4. Select the document(s) to associate, then click Select documents.

  5. Click Save, then Confirm to save changes to the object properties.

Edit document links from the Documents library

  1. In the Documents library, select the document(s), right click and select Associate. 
    All objects to which the document is currently linked are shown. 
  2. To add a document link, click Add, then find and select the documents you want to link.
  3. To remove a document link, select the object(s), then right click and select Delete Associations.
  4. Click Save.

Edit document links from one or more objects

  1. In the Applicable Requirements view, find the object(s) select the object(s).

  2. Right click and select Properties > Edit.

  3. Check the Documents box.

  4. Scroll to the bottom of the properties page in the Relations section.
    Documents linked to the object are shown. If you selected multiple objects, only those documents that the objects have in common are shown.

  5. To add a document link, click Add, and find and select the documents you want to link.

  6. To remove a document link, select the document and click Remove.

  7. Click Save, then Confirm to save the changes to the object.
