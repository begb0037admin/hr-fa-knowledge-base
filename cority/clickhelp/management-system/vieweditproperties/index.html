View/Edit Properties

The properties of objects include the standard fields for the object type, as well as any custom fields that have been applied to an object.

Users with View permissions on an object can view properties. To edit properties, Modify permission on the object is required.

To view the properties of an object, right click the object, either in the System Model tree on the left, or from the Applicable Requirements view on the right, and choose Properties > View.

You can use a System Properties Report to filter system objects by custom criteria and get a more detailed view of the objects in the system.

To edit object properties:

  1. Right click the object, either in the System Model tree on the left, or from the Applicable Requirements view on the right, and choose Properties > Edit.

    The property form is displayed in edit mode. Fields that may be edited are enabled for editing.

     Some fields, such as certain requirement definition fields on a requirement template or calculated fields on a calculation template, cannot be edited from the properties form.

  2. Edit the properties as desired.

Required fields will have an asterisk to the right of the Field Name. When saving changes, each required fields without a value inputted will result in a message that display to the right of the field “*Value required".

  1. Click Save and Confirm.

 You can edit several similar objects at once to apply the same changes to all. See Edit Objects in Bulk.
