Web Services Partial Command Processing

WebServices allows for partial processing of data batches uploaded via data integration. This means that processing will not completely fail when a batch contains bad data, but will continue to process any valid data in the batch.

A filtering option in the Command Log search pane allows filtering for Command Log batches that have been partially processed. The purpose is for monitoring these webservices transactions.

You can view the details of a transaction that has partially processed or failed to get more information. Right click the transaction in the Command Log list and choose View Details.

When a transaction has failed, the option to Resubmit is also available.
