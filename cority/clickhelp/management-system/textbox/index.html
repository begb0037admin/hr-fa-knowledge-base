Text Box

A simple text box allows manual entry of values when it is applied to an object. The text box data entry type is available for both text and number fields. Any character string is allowed for a field of the data type text. Numeric values are required for a field of the data type number; values are checked for numeric content upon entry.

The size of the text box (small, medium or large) sets the maximum number of characters that may be stored in the field for data entry.

Small allows up to 20 characters.

Medium allows up to 250 characters.

Large allows up to 7900 characters.

The physical size of the small and medium text box is the same, although the maximum number of characters allowed is different.

To create a text box:

  1. For the Data Type, choose Text or Number, depending on the data type desired.
  2. For the Value Entry Method, choose Text Box. This is the first option and is selected by default.

  3. Select the desired Size (small, medium or large) depending on the number of characters required for data entry.


  4. Select Save and Confirm.

Localization

The Name, Caption and Description may be localized in any of the available languages in the system.

To enter translated values for different languages:

  1. Click the language symbol next to the field.

    In the pop-up dialog the currently active languages for users in the system are shown, as determined by the values selected in the Culture field in users' profiles. Check Show All EMS Languages if you want to add translations for languages not currently selected by users.

  2. Enter the value to use for each language for which you want to provide a localized translation.

  3. Click Save.
