Version 9.4.2 Release 7/9/2018

  • MAIN-7232 Localization of Task and Workflow Notifications: Notification templates may now be specified for each language supported by EMS. Users will receive notifications in the appropriate language according to the Culture setting in the user profile.
  • MAIN-7134 REST APIs: Custom field localized values are now supported in REST APIs for system model objects, workflow steps, events, and data quality templates.
  • MAIN-7413 REST APIs: System model object name localized values are now supported in REST APIs.
  • MAIN-7412 EQL: System model object name localized values are now supported in EQL.
  • MAIN-8475 System Model: Added Provinces as selectable option when Mexico is selected as the country on Facility/Programs.
  • MAIN-8569 Tasks/WFs: Single-instance tasks with triggered workflows of the same due date will keep their due dates synchronized whenever an edit is made to either due date (task or workflow).
