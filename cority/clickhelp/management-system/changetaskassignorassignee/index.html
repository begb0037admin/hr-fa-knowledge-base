Change Task Assignor/Assignee

Both the Assignee and the Assignor of a task may be changed for a task. For recurring tasks, changing the assignee or assignor will affect all tasks whose due date is today or later. Saved instances of the task will not be affected.

For automatically triggered tasks, the task assignor and assignee are set on the properties of the event log or the monitored requirement with which the task is associated.

For all recurring tasks or automatically generated tasks, changing the assignor or assignee will affect the tasks generated after the changes are made, but will not affect existing tasks.

 In the case of recurring tasks, any incomplete, overdue tasks will still be assigned to the original task assignee, so it is best to make sure that the task completion schedule is up to date before changing the assignee.

To change the assignee or assignor of a recurring or simple task:

  1. Right the task and select Edit Task Properties.

    For recurrent tasks, you may select any instance of the task.

  2. Scroll down to the Assignee and Assignor section on the task form.

    To change the Assignor, click Assignor. In the Users selection window, find the user you want to be the new task assignor and click Select.

    To remove an Assignee, select the assignee from the Users or Groups box and click Remove.

    To add an Assignee, click Add in either the Users or Groups section, choose the new Assignor from the user or group selection window.

  3. Click Save to save the changes to the task.

To change assignee or assignor for an Event Log task:

  1. Select the Event Log with which the task is associated, right click and choose Properties > Edit.

  2. On the Event properties form, in the Task Template section, change the Assignee/Assignor, as above.

  3. Select Save, then Confirm to save the changes.

To change assignee or assignor for a task associated with an exceedance:

  1. Select the Requirement with which the task is associated, right click and choose Properties > Edit.

    In the Limits section of the properties form, the Task Template and Assignor/Assignees for each limit is shown.

  2. Change the Assignor/Assignee, as desired:

    To change the Assignor, click Assignor and select a user from the Users selection window.

    To remove an Assignee, select the user or group name and click Remove.

    To add an Assignee, click Add in the User or Group box. Select the new assignees from the selection window.

  3. Select Save, then Confirm to save the changes.
