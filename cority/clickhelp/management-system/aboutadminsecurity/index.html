About Admin and Security

Admin and Security features include two components: User Rights and System Permissions.

  • User Rights control which parts of the application a user has access to. The tabs and menu options available to the user are dependent on the user rights assigned to the user or the groups to which the user belongs.
  • Permissions control which system model objects users can access in the system model and the set of functions available to them on those objects. This allows a user to be assigned very specific permissions to relevant parts of the system model, such as data viewing, data entry, task management, etc. Permissions on documents stored in the system and reports are in addition to system object permissions.

Both User Rights and Permissions may be assigned to individual users or to user groups.
