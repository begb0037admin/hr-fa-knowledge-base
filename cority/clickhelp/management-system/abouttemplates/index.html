About Templates

Templates are used to define the custom properties you want to use on system objects, define requirements, and define the model to use when instantiating automatic tasks and events.

Objects that use the same template can be easily updated from a central location when, for instance, calculations must change, permit numbers or effective dates change, or other information must be edited or added.

Templates include the following types:

Custom Field Templates

Group custom fields that can then be applied to various system objects.

Event Templates

Group the property fields used to document an event.

Requirement Templates

Define the general information concerning the authority and drivers for requirements.

Task Templates

Define global settings for associated tasks. Also used for automatically created tasks triggered by event log instances or limit exceedances.

Calculation Templates

Define fields that may be used in calculations related to a specific parent object (such as equipment specs associated with an equipment POI.

Data Quality Templates

Define fields that can be used to provide analytical information for data points, or to define a data substitution script.

Material/Activity Templates

Group custom fields (for information purposes only) for Materials and Activities.

Form Templates

Define the forms that are used for completing workflow steps.

Notification Templates

Define the content of the messages sent for workflow notifications.

To create or modify templates, you must have the appropriate user rights. The following user rights apply to templates:

Manage Requirement Templates

Manage Task Templates

Manage Custom Fields

Manage Events

Manage Data Quality Templates

Manage Calculation Templates

Manage Material Templates

Manage Workflows (for both Form and Notification Templates, as well as workflows)
