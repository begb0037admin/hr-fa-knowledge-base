Version 9.3.1 Released 1/8/2018

Release focused on small architectural and security improvements as well as minor enhancements.

  • MAIN-7818 Fixed concurrency issue resulting in errors when requests across many users collide (usually from many users in the same App)
  • MAIN-7858 Added Canadian provinces Facility objects when specifying address fields
  • MAIN-8103 Added Spanish language as option in "Culture" dropdown list for users, allowing Administrators to begin specifying UDF and Object localized values. (Translation of standard system fields to Spanish will come in a future release and is not include.)
  • MAIN-9031 EQL enhancements allowing for careful tracking of changes to permissions and overrides. This allows for critical performance enhancements for Apps operating offline.
  • MAIN-7788 New optional relationship added for child workflows allowing for the relationship to identify not only a parent workflow, but also a parent workflow field. Only available via REST and EQL.
