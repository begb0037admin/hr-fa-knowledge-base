Material Activity Calculated Requirements

Material Activity Calculated Requirements differ from regular calculated requirements in several significant ways:

  • When setting up a Material Activity Calculated Requirement, you must specify one Activity and one or more Materials to be used in the calculation.
  • Data entry for Material Activity Calculated Requirements is not done via parameters, but by entering values for Specific Use Variables. Data is not done directly on a requirement, but is entered from the parent object of one or more Material Activity Calculated Requirements.
  • Data is entered in material data batches. Multiple data lines may be entered to produce a single aggregated data point. For example, a month’s worth of data entries referencing different materials may be used to produce an aggregate data point, such as total VOCs emitted.
  • MACs may use a wide variety of variables which are not available to regular calculations. The variety of logical ways that variables may be stored in the system contributes to the flexibility of the calculations. However, it also requires that serious forethought be used in planning how to set up your calculations.

Required components for a Material Activity Requirement are:

  • One Activity, which includes at least one Specific Use Variable.
  • One or more Materials, comprised of one or more Chemicals.

Optional variables that may be used in MAC formulas are:

  • Material Value Based Properties
  • Material Formula Based Properties
  • Activity Value Based Properties
  • Calculation UDFs (user-defined fields) stored on a Calculation Template applied to the parent object
  • Chemical properties
  • Meteorological data
