Sensitive Data Fields

Custom fields that contain sensitive data can be indicated with a flag for security or privacy purposes. The flag "May contain sensitive data" may be applied to custom fields which store any kind of sensitive data (such as employee identifiers or personal information).

The true/false field "Name may contain sensitive data" is also available for object names (Division, Facility, Unit, POI and all Requirements).

Fields marked as containing sensitive data will be irreversibly scrubbed before leaving the customer environments, which means that Cority staff will not have access to these values in non-production environments such as staging and QA.
