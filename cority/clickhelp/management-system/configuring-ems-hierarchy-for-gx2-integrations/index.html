Configuring Advanced Calculations (EMS)  hierarchy for Core (GX2) Integrations 

When your organization uses both Advanced Calculations (EMS) and Core (GX2), both systems work together to create a seamless experience managing environmental data, assets, and more.  

To initiate the integration of your Advanced Calculations (EMS) and Core (GX2) systems, please contact Cority Customer Support.  

Designating the Advanced Calculations (EMS) Tree in Core (GX2) 

Once both systems are connect, you will need to designate one of the organizational trees in GX2 as the EMS tree. This tree will represent the Advanced Calculations (EMS) hierarchy, similar to the System Model. Unlike the Core (GX2) organizational tree, the Advanced Calculations (EMS) designated tree will only have three levels; Division, Facility, and Unit/POI. For more information about Organizational Trees in Core (GX2), see Organizational Trees in the Cority User Guide. 

To designate the Advanced Calculations (EMS) tree, in Core (GX2), navigate to Administrator > System Settings, search for the EMS – Controlling Org Tree setting, and choose the tree to designate.  

When possible, it is recommended to use an open or unused tree. The selected tree will automatically get the Advanced Calculations (EMS) hierarchy restrictions (three levels), and all other levels will be removed.  

Building the Advanced Calculations (EMS) Hierarchy 

Once you have designated a tree, you can build the hierarchy from Core (GX2). When you create a new node in the Advanced Calculations (EMS) designated tree in Core (GX2), a new unit will be created in the System Model.  

For facilities, the Time Zone field is required when creating a new facility in the designated tree. The Time Zone field must be added to a custom version of the Tree Master with Attributes layout.  

In Core (GX2), each asset is equivalent to a Unit/POI. In the Equipment Types lookup table, you can search for assets and use the Advanced Calculations (EMS) fields, EMS Template Compliance Object ID and EMS Template Compliance Type, to relate the asset in Core (GX2) to a POI or Unit template in Advanced Calculations (EMS). For more information on requirement templates, see Requirement Templates.  

The Advanced Calculations (EMS) fields must be added to a custom version of the Equipment Type layout.
