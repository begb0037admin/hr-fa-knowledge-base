Requirement Templates

A Requirement Template contains general information about the authority and driver for Requirements created within the system. Requirement Templates save time when developing the System Model as you only need to reference the appropriate template, rather than entering the Requirement driver information each time a Requirement is created. Any changes made to the Requirement Template will be reflected automatically in all Requirements that were created using that Template.

Requirement Templates may be set up for each permit, internal program, enforcement action, and major regulation to which facilities are subject. Standard fields are provided to track the Driver/Authority Type and details relevant to each type. The pre-configured Authority Types include federal or state regulations, permits, enforcement actions or other (such as a company’s internal requirement).

In some cases, for a more flexible model, you may prefer to create a generic template for requirements of a certain type, then use custom fields to track specific information, which can be applied either to the Requirement or to a parent object via a Custom Field Template.

To view, create or modify Requirement Templates, you must have the Manage Requirement Templates right.

To view Requirement Templates:

  1. From the menu, select Setup > Requirement under Templates.

    Existing Requirement Templates are shown. Browse the list by selecting consecutive pages.

 The # Ref column indicates the number of Requirements which which the template is associated.

You can search for Requirement Templates based on an applicable dates, in order to find out which Requirements were in force on that date. This search is only effective if the Active Date fields are completed on the Requirement Templates. The Active Date and Inactive Date are not required fields.

To search Requirement Templates by applicable date:

  1. In the Applicable On search field in the Requirement Templates search pane, enter a date in the format MM/DD/YYYY, or choose a date from the popup calendar.

  2. Select Search.

    All Requirement Templates whose applicable dates include the selected date are displayed. The number of actual Requirements that use each template are shown in the #Ref column.
