Chemical Formula Based Tertiary Properties

Chemical Material Formula Based Tertiary Properties (Tertiary CL FBPs) are calculated properties that are used for calculations using chemical properties, which will automatically produce a calculation for each chemical in the material. As Tertiary material calcs, they are dependent on both where and when the material is used. They can only be calculated when a data point is entered. The calculation may depend on inputs such as how much material was used, how long a piece of equipment was run, or monthly temperature data (where it is necessary to know the month to run the calculation).

The formula may use:

  • Chemical Properties, both explicit and logical
  • Material Value Based Properties
  • Activity Value Based Properties
  • Calculation Template fields applied to the immediate parent object of the MAC(s) using the material
  • Annual meteorological data, from the location specified on the parent of the MAC(s)
  • Primary FBPs
  • Primary CL FBPs in chemical-explicit form, chemical-logical aggregation, or chemical linear usage (see Chemical Calculations for an explanation of usage)
  • Secondary FBPs
  • Secondary CL FBPs in chemical-explicit form, chemical-logical aggregation, or chemical linear usage (see Chemical Calculations for an explanation of usage)
  • Tertiary FBPs
  • Other Tertiary CL FBPs in chemical-explicit form, chemical-logical aggregation, or chemical linear usage (see Chemical Calculations for an explanation of usage)
  • Activity Specific Use Variables
  • Requirement data (Parameters, System Variables and Calculated Requirements). See Referencing Requirements in Material Scripts.
  • TimeSpan

The TimeSpan variable calculates the number of minutes between the Start Date and End Date for each data line. It is available for use in Tertiary FBPs and CLFBPs, as well as Material Activity Calculated Requirements.

The formula for the property is the same for all materials to which it is applied, although the value may depend on variables that cannot be known until it is associated with a Material Activity calculation and data is entered.

The formula is validated when a Material Activity Calculated Requirement that uses the material is created. However, it may only be calculated when data is entered.

To check the validation of the property:

  1. In Properties Edit mode for a Material Activity Calculated Requirement that uses the material, click the Validation tab.

  2. If there is more than one material, select the material to validate.

    The Secondary and Tertiary Formula Based Properties are shown. The Valid column shows TRUE if all factors necessary for its calculation are found and the calculation can be performed. If the validation is FALSE, the missing factors are shown in red.

    The calculation must be valid for at least one associated material if the property is required in the MAC calculation.

The Calculation Visualizer can be used to view the calculated value of a Tertiary FBP using hypothetical input values for a Material Activity calculation. See Calculation Visualizer for MACs.
