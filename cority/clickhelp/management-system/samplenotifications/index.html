Sample Email Notifications for Apps and Tasks

Sample notification template formats are provided for your use in setting up notifications for Apps in your system. The notification templates are shown in the table below. The text of the message can be edited as you wish.

Right click the links and download the text files to your system, then follow these instructions for setting up the Notification Templates.

To create the Notification Templates:

  1. From the main menu button, select Setup > Notifications > Templates.
  2. Select New Notification Template.

  3. For the Type:

    For App notifications, select Workflow Notification.

    For the Standard Task Notifications and the Portal Form for Tasks Only (used for tasks not associated with a workflow), select Task Notification.

  4. Enter a name for the template.

  5. Enter a Subject line. Suggested Subject lines are given in the table below.

  6. For the HTML message body, click Source.
  7. Open the notification text file in a text editor (i.e., Notepad or Notepad++). Select and copy the contents, then paste it into the Source window.

  8. Click Save. A preview of the message will be displayed. Click Confirm to save the template.

    A notification template to be used for an App must then be associated with a Workflow Policy, which is then associated with the workflow type for the App. The default policies for the global apps and their associations are shown in the second table below.

    A notification template for a task must be associated with a Task Template used to create the task.
