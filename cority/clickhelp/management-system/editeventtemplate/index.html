Edit an Event Template

If you have the appropriate rights, you can edit an Event Template in order to modify properties, such as adding or remove fields.

Modifications to an Event Template are automatically applied to all events for the Event Logs associated with the template.

Calculated fields added to the template will be automatically populated. However, to add values for manual entry fields it is necessary to edit existing instances.

To edit an Event Template:

  1. Right click the event template and choose Edit.

    The properties form is displayed for editing.

  2. Modify the properties of the template as desired.
  3. Select Save, then Confirm.
