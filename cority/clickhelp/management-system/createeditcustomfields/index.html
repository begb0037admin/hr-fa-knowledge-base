Create/Edit Custom Fields

The following basic instructions apply to creating custom fields of all types. For specific instructions on different data types and different value entry fields, see the referenced sections.

To create a new custom field:

  1. In the Custom Field Library (Setup > Custom Fields), select New Custom Field.

    Or, from the Custom Field Library, right click anywhere in the table and select New.

  2. Enter a Name for the field.

    The Name is the field identifier. You may want to use a naming convention that will help you find the fields you want to group together on a template. The name will not appear on forms.

    If the field may be used to store sensitive data that should be protected for security or privacy reasons (such as personal identifiers or information), you can indicate it by checking "May contain sensitive data".

     Fields marked as possibly containing sensitive data will be irreversibly scrubbed before leaving the customer environments, which means that Cority staff will not have access to these values in non-production environments such as staging and QA. See Sensitive Data Fields.

  3. Enter a Caption for the field.

    The caption is the field label that will appear on the forms in which the field is used. The caption may be different than the name, and may contain up to 1000 characters.

  4. Add a Description if desired.

    The description may be viewed as a property of the field in the Custom Fields Library and selection windows and may help users identify its purpose. It will not appear on forms.

  5. Select the Data Type from the dropdown list.

    Additional properties appear for defining the specific field type. See the specific instructions for each data type.

    Localization

    The Name, Caption and Description may be localized in any of the available languages in the system. Value options for dropdown lists, numeric aliases and labels can also be localized.

    To enter translated values for different languages:

    1. Click the language symbol next to the field.

      In the pop-up dialog the currently active languages for users in the system are shown, as determined by the values selected in the Culture field in users' profiles. Check Show All EMS Languages if you want to add translations for languages not currently selected by users.

    2. Enter the value to use for each language for which you want to provide a localized translation.

    3. Click Save.
