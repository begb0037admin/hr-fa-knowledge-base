Troubleshoot Material Activity Data

The most common reason that a Material Activity calculation will fail is that data has been entered for a invalid period—that is, a period for which one or more components of the calculation is not valid. Recheck the input dates for the data entry to be sure they are correct first. Correct the dates for the data entry and re-submit, if necessary.

The following date fields should also be checked for validity. All of these date fields must be valid for the data entry period for the calculation to succeed:

  • The Calculation Begin/End dates for the Material Activity Calculated Requirement
  • The Begin/End Dates for all of the property values for the Materials/Activities
  • The Begin/End Dates for chemicals used in the calculation. Both the Begin Date of the chemical stored in the Chemicals library and the Begin/End Date of the chemical composition on the material are relevant. The earliest allowable Begin Date for a chemical is 1/1/2005. No calculations that use chemical properties will be valid before this date.
  • The Begin/End Dates for formulas in calculated UDFs (custom fields) on the calculation template used.
  • The Begin Date for a Location specified on a parent object, if Met fields are used.

To help diagnose the problem, you can use the Calculation Visualizer to see which properties failed to calculate. See Calculation Visualizer for MACs.

To check the valid dates for the Requirement:

  1. Right click the Material Activity Calculated Requirement and choose Properties > View.
  2. On the General tab, check the Active Date for the Requirement.
  3. On the Calculation tab, check the Calculation Begin Date and the Calculation History.
    The data entry dates must be within the valid dates for the calculation.

To check the valid dates for the Material properties:

  1. Select Materials from the Materials/Activities tab. From the Materials list, find the materials used in the calculation.

    If you don’t know which materials are involved, you can see the list of materials in the initial steps of the data entry process. Select the parent object, right click and choose Data > Enter/Edit. The Materials list shows the related materials.

  2. In the Materials tab, right click a material and choose View.

    The properties used on the material are shown, with their value histories. Review the Begin Dates to ensure that all properties are valid for the period of the data entry.

    Value based properties may be edited on the material, if they are not correct. Formula based properties must be edited from Material/Activity Fields Library, as the formulas and begin dates are applicable to all materials that use the formula.

To check calculation template values:

  1. Right click the immediate parent object and choose Properties > View.

  2. Check the Begin dates for all calculated properties on the calculation template.

    If the calculation begin dates are not correct, you must edit them on the Calculation Template. They cannot be edited from the object properties.

To check valid dates for chemicals, view the Begin Dates for the chemicals on the material from the material properties (as above).

The standard chemicals in the system have chemical history dates beginning with 1/1/2005. Data cannot be entered earlier than this date if chemical properties are used in the calculation.

Custom chemicals may have earlier dates. Check the History From field for the chemical in Chemicals to determine the earliest possible date for using custom chemicals.

If some MAC requirements are calculating and others are not

Check to be sure all MAC requirements are associated with the materials you are using for data entry. During data entry, all materials that are valid for any of the MACs under the POI are presented for data entry. However, individual MAC requirements will only calculate data for the materials that are valid for that requirement.

Generally, as best practice, all MACs under a POI should be associated with the same set of materials. If material groups are used for association, when new materials are added to the group, it is necessary to choose the option to "update associated MACs" in order to use the new materials in existing setups. If this is not done, some newer materials may not be associated with all the necessary MACs.

To check for the validity of the material on a MAC:

  1. Right click the MAC requirement and choose Properties > View.

    The General tab will show the individual materials and/or Material Group associated with the MAC.

  2. If the associated MACs are a material group, select the Validation tab.

  3. Select the Material drop-down and check to see which materials are available.

    If the materials list in the Validation tab does not include the material used for data entry, then it is not associated with the MAC requirement. To fix this, you will need to edit the material group and choose the option to "update associate MACs". See Material Groups.
