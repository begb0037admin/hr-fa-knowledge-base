Bulk Upload and Editing Tools

Cority has several bulk upload and editing tools for facilitating faster system build and implementation. Customers or partners can arrange with the  Cority Customer Support for use of these system administration tools.

Help is available for bulk tools, including instructions on preparing upload files and template files for download here:

Bulk Tools Help

The bulk tools that are currently available include:

Citation Management Tool

Creates folders for Citations management

Creates parent Citation and sets the path, identifier and active date

Edits Citation property values

Associates Citation to an object

Object Copy Tool

Creates objects (Divisions, Facilities, Units, POIs and Requirements) from existing objects

Copies and changes the name of the object and the path

Creates child objects in the copy process

Object Properties Edit Tool

Edits custom field property values for existing objects (Divisions, Facilities, Units, POIs, and Requirements)

Object Move

Move objects from one location to another in the system.

Object Delete

Delete objects from the system in bulk.

Permissions Editing Tool

Create and edit users and user groups, set object permissions for users and user groups, set citation, document and report permissions for users and user groups.

Search Tags Under Settings Tool

Allows users to specify system levels or specific objects under which Calculated Requirement will search other requirements to resolve them in Tag Aggregation Calculation.

Tag Schemes and Tags Tool

Create, Edit, Copy and Delete Tag Schemes and Tags.

Task Edit Tool

Create and edit tasks, task schedules, assignees, notifications and task exceptions.

Template Edit

Apply or change Custom Field Templates, Requirement Templates, Event Templates and Task Templates.

Calculation Edit

Edit calculation formulas (edit existing or add new history)

Edit limits (regulatory and internal)

Edit values for numeric fields on a calculation template applied to a tree object.

Document Edit

Move documents

Move document folders

Edit document properties and values

Associate documents

Delete documents

Workflow Overrides Edit

Add / Replace/ Delete Workflow Role Overrides

Add / Replace / Delete Workflow Policy Overrides
