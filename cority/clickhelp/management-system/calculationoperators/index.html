Calculation Operators

Operators specify the type of calculation that you want to perform on the elements of a formula. The calculator handles the following types of calculation operators: arithmetic, comparison, Boolean, and reference. In addition, three editing buttons are available in the calculator.

Arithmetic operators: The following arithmetical operators are supported.

Arithmetic operator

Example = Result

+ (addition)

3+3=6

– (subtraction)

3–1=2

* (multiplication)

3*3=9

/ (division)

3/3=1

^ (power)

3^2=9

This is the same as POW(3,2)

Comparison operators: You can compare two values with the following operators. When two values are compared by using these operators, the result is a logical value either TRUE or FALSE.

Comparison operator

Meaning (Example)

=

Equal to
[Param1]=[Param2]

>

Greater than

[Param1]>[Param2]

<

Less than
[Param1]<[Param2]

>=

Greater than or equal to ([Param1]>=[Param2])

<=

Less than or equal to
[Param1]<=[Param2]

!=

Not equal to
[Param1]<![Param2]

When using more than one comparison in an expression, a Boolean operator is usually required. See the clarification below.

Boolean operators: Formulas may use any of the following Boolean operators.

Boolean operator

Meaning (Example)

AND

Both expressions must be true:

(2 < 3) AND (2 < 4) (true)

OR

One expression must be true

(2 < 3) OR (3 < 2) (true)

NOT

Expression must be false

NOT (2 < 1) (true)

Note that the following two expressions are NOT the same and can produce different results:

1 < [Prm] AND [Prm] < 3

1 < [Prm] < 3

1 < [Prm] AND [Prm] < 3 denotes TWO comparison operations joined by a Boolean AND operation. Therefore, for the whole statement to be TRUE (1), BOTH comparisons must be TRUE (1).

1 < [Prm] < 3 denotes TWO comparison operations NOT joined by a Boolean AND operation. In this case, the system first determines if 1 < [Prm], returns TRUE (1) or FALSE (0). Next, the result of that operation is simply fed into the next, checking to see if it is < 3.

For example, if [Prm] value == 4, the system would evaluate the second expression thus:

(1 < 4) < 3

(TRUE) < 3

(1) < 3 == TRUE (1)

Reference operators: Combine ranges of cells for calculations with the following operators.

Reference operator

Meaning (Example)

. (period)

Decimal point

, (comma)

Used as a separator for the arguments for a function. For example:

POW(2,3)

where 2 is the specified base number and 3 is the power to which it is to be raised
