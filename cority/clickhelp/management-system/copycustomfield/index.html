Copy Custom Field

You can create a new custom field by making a copy of an existing field. You may then modify the field as you wish.

To copy a custom field:

  1. In the Custom Field Library, find the custom field you want to copy. Right click and select Copy.

  2. Enter a new name for the field, then select Copy.

A confirmation message is displayed. You may then search for the field in the Custom Field Library and edit it. Note that the caption is a separate field from the field name. You will need to edit the field to change the caption as well.
