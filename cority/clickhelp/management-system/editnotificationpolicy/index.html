Edit Notification Policy

You can edit a notification policy for workflows. 

Before editing a policy, make sure that the edits are appropriate for all workflow types associated with it.

To edit a notification policy:

  1. From the menu, select Setup > Policies under Workflows.
    The existing policies defined in the system are listed. The Roles referenced by the policy and associated workflow types are shown.
  2. Right click the policy you want to edit and choose Edit.
    Existing notification schedules are listed, with the recipient Roles. Any existing workflow types with which a policy is associated are also shown.
  3. To edit an existing notification schedule, click the row for the notification schedule you want to change.
    The schedule criteria are shown.
  4. Edit the schedule as desired.
  5. Select another schedule to edit that schedule.
    You do not need to save before editing another schedule.
  6. To add a notification schedule, click Add New Notification.
    The schedule criteria is displayed for creating your new notification. For a description of criteria, see Create Workflow Notification Policy.
  7. To delete a notification, select the notification, then click Delete Notification.
  8. When you have edited all the notifications you want, click Save, then click Confirm.

When a notification policy is associated with a specific step in a selected workflow type, the association is made with the current version of the workflow type. If a new version of the workflow type is created, the policy must be edited to re-select the workflow type and step in order to continue to be valid.
