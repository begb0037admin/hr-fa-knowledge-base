Create New Form Template

To create a new form template:

  1. Do one of the following:
    1. From the menu, select Setup > Form under Templates, and select New Form Template.
    2. In the Process tab of the Workflow Type Editor, create a new step or select an existing step to edit it. Next to the Associated Form Template field, select Create.
  2. Enter a Name for the template and a Description.
  3. Select Add to add fields to the template.
  4. In the selection window, browse or use the search to find and select the fields to add to the template.
  5. Check the checkbox for the fields you want and click Select Fields.
  6. To create a new custom field to add to the template, click Create New Custom Field.
    See Create/Edit Custom Fields. After the new field is created, you will be returned to the template edit screen. The new field will appear in the Selected Fields list.
  7. To change the display order of the fields, select a field and click the Up or Down button.
  8. To apply a validation type to a field, select the field in the list box. The possible validation types are shown below the fields list box. Select the validations to apply and enter any required values.
    Fields with validations will be shown in blue. See Form Field Validations for a list of validations per field type.
  9. Select Save and Confirm.
    If any calculated fields are included on the templates, after clicking Save, enter the formula with a begin date and click Update for each calculated field.
  10. Click Save, then Confirm when done.

If you started from the Workflow Type description, the new form template will be selected as the Associated Form Template for the step. You can continue to set up the workflow step.

If you started from Form Template Manager, you can continue to set up any other forms you need for your workflow. Go to the Workflow Type Editor to create or edit the workflow in which you want to use the Form Template. See Edit Workflow Process.
