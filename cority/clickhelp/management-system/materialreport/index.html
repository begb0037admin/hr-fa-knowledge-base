Material Report

A Material Report is used to report on the properties of Materials used in the system.

A Material Report may include

  • Chemical concentrations in materials
  • Chemical properties
  • Material Value Based Properties (values)
  • Calculated values for Primary FBPs
  • Definitions for all formula-based properties

To create and run a Material Report, users must have the following user rights and permissions:

  • User rights: Manager Materials and Activities; Manager Reports
  • Report permissions: Unrestricted (plus View or Edit)

To create a Material Report:

  1. Select the Materials or Material Groups to include. Materials are filtered for those used in the selected objects above.

  2. Select the Chemicals to include. Chemicals are filtered by the Materials selected.

  3. Select the properties to include in the report.

    Calculated values for material value-based properties and primary formula-based properties may be included. For secondary and tertiary FBPs only the definitions may be included as the values are calculated based on use and data input.
