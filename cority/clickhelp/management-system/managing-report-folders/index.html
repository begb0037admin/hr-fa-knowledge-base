Managing Report Folders

The library of reports for your system can be organized in any number of folders and subfolders. When you create your report folders, you should consider both your organization and security needs.

Folders should be set up in the Reports library in a manner that facilitates granting permissions to specific users and groups to the reports they need. Permissions and may then be set on an entire folder, and inherited through subfolders.

Any user with Edit permission on a folder may create and manage subfolders and reports in that folder. Additionally:

  • Users with Edit permission (which includes View) may create reports for objects to which they also have permissions.
  • Users with Unrestricted permission may create reports for any system objects, regardless of their permissions for the objects included.

User with Edit permissions on a folder may create and edit subfolders within that folder.

 You can create subfolders in any folder for which you have Edit permissions. However, to set permissions to the folders you create, you must have the Manage Reports user right.

Create a new report folder

  1. Select Reports or select the report folder in which you want to create a new subfolder.
  2. Right click and choose New > Folder.
  3. Alternatively,  from the Reports display, select Add Folder.
    If the Add Folder link is not enabled, you only have View permission for the current folder.
  4. Enter a Name for the new folder and a Description.
  5. To create the folder in a different location than selected, choose a parent folder from the Create In list.
  6. Select Save.

Edit folder properties

  1. Right click the folder from the system model tree or the content pane and choose Properties > Edit.

  2. Edit the properties as desired, then click Save.

  3. Select Confirm to confirm your changes.

Rename a folder

  1. Right click the folder name from the system model tree or the content pane and choose Rename.

  2. Enter the new name of the folder, then click Rename.

You can make a copy of a folder along with all its contents and save it as a new folder. When you copy a report folder, all subfolders and reports within the folders are copied. Permissions are not copied. The permissions on the new folder will be inherited from the new parent folder.

Copy a folder

  1. Right click the folder name from the system model tree or the content pane and choose Copy.

  2. Right click the folder in the Reports tree into which you want to copy the report and click Paste.

  3. Rename the report as desired.

    You may choose a different folder to copy to from the list, if desired.

  4. Click Save.

Move a folder

  1. Right click the report name in from the system model tree or the content pane and choose Cut.
  2. Right click the folder in the Reports tree into which you want to copy the report and click Paste.
  3. Rename the report if desired, and select Save.
