Edit Non-Numeric Data

If you have the appropriate permissions, you may edit data records for a non-numeric requirement from Data Manager.

When a task is associated with a non-numeric requirement, completing a task creates a data record for the requirement. Since a completed task cannot be edited, in order to modify the data created by the task for the associated requirement, you must edit the data for non-numeric requirement, with the following exceptions:

  • Task Comments may be edited either by editing the task instance or by editing the non-numeric requirement data.
  • The fields for time and cost to complete found on the task form can only be edited by editing the task instance, as the data belongs to the task instance, not to the related non-numeric requirement.

See Editing Completed Tasks.

To edit data records for a non-numeric requirement:

  1. Right click the requirement and choose Data > Enter/Edit from the popup menu.

    The data records for this requirement are displayed, beginning with the most recent. Increase the Results per Page or expand the search section and use the search function to find the data record you want to edit, if it is not shown.

  2. Select the Edit link for the data record.

  3. Edit the fields as desired.

  4. Select Update to save the changes.
