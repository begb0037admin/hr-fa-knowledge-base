External Quick Links

External Quick Links allow you to integrate your system with other resources, such as a company intranet, other management systems, regulatory agencies, or reference material. External links are simply URL links to another site. External Quick Links can only be created as System Quick Links.

External links to Quick Data with pre-set filter criteria can also be created automatically from Quick Data.

To create an external Quick Link:

  1. From the menu, select Setup > QuickLinks.
  2. Select New Quick Link, or right click on the page and choose New.
  3. For the Link Destination select "To another Web Site".
  4. Click Continue.
  5. Enter a Name for the Quick Link.

  6. Enter the URL in the Address box.

    A full URL is required. Supported types are http://, https://, ftp://, mailto:// and file://

    You may use macro tokens to create a search string. See Quick Links Macro Tokens.

    Special characters, such as spaces, must be encoded.

  7. Click Save.
