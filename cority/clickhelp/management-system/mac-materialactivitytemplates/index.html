Material/Activity Templates

Material/Activity Templates are custom field templates that may be applied to Materials or Activities. The fields on a Material/Activity Template are generally for informational purposes only and cannot be used in calculations. An example is a template that contains information such as supplier, batch numbers, or ordering information, etc. for a material.

Another important use of Material Template is for tagging Materials and Activities to be used in backend data integration. To provide a unique tag for data integration purposes, you must add a custom field of the type Unique Tag to a Material/Activity Template, then apply the template to both the Material and the Activity. The value is defined on the properties for the Material or Activity.

To view, create or edit Material/Activity Templates, you must have the Manager Material/Activity Templates user right.

To view Material/Activity Templates:

  1. From the menu, select Setup > Material/Activity under Templates.
    The list of Material/Activity Templates is displayed.
  2. Use the search to filter for the materials you want.
