Associate One or More Documents to Multiple Tasks

You can associate one or more documents to multiple tasks using bulk edit of tasks.

To associate one or more documents to multiple tasks:

  1. First, search for the tasks you want to edit in the using the search criteria in the Tasks search pane.
  2. Select the checkboxes for the tasks you want to edit.
  3. Right click and choose Edit Task Properties in Bulk.A task form appears with the selected tasks listed on top of the form. Properties available for editing are shown on the form; when the values are the same for all tasks, the value is also shown.
    All associated documents that the tasks have in common are listed in the Associated box in the Documents section at the bottom of the General tab.
  4. To add a document, click Add.
  5. In the Documents selection window, browse or use the search to find the document(s) to associate.
  6. Check the document(s) and click Select documents.
  7. To remove a document, select it in the Associated box and click the > button to remove it.
  8. Click Save.
    The changes to the tasks are shown for your review.
  9. Click Save again or Back to edit.
