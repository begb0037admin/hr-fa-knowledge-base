Create Citations

Modify permissions on the Citation Folder are required to create or edit citations in that folder.

To create a new citation:

  1. In the Citations library, open the folder to which you want to add the citation.

  2. Select Add Citation.

    Or, right click the citation folder on the tree and choose New > Citation.

    The new citation form appears.

  3. Complete the information fields for the citation as applicable.

    Required fields are Name, Identifier and Active Date. Identifier must be unique.

    Various date fields are available to track issue, approval, effective and enforceable dates, as applicable.

    In the Text field, you can copy the exact text of the citation.

    Identify the Issue Agency by choosing from the dropdown lists. (To create new Issue Agencies, see Issue Agencies.)

    In the User Data section, you can enter specific questions relevant to compliance that need to be addressed. Three custom question fields are available, each with its own a relevant date for each.

    Version Comments can be used to track versions, to note reasons for changes, or other identifying information.

  4. Click Save.
