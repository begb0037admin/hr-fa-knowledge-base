Form Field Object Value Inheritance

A workflow form field may inherit its value from an object associated with the workflow. Any type of custom field except calculated fields may be used.

To use this feature:

  • Apply the same custom field to the Form Template used in the workflow and to a Custom Field Template applied to a System Model object.
  • The field may be applied to the System Model object directly associated with the workflow or to its parent or another ancestor. In the case where the field appears on more than one ancestor, the value on the closest ancestor is used.
  • The custom field on the object must have an active (current) value at the time of the workflow instance creation.
  • The field on the workflow must be used in the initial workflow step or be a global field.

The field value on the associated object will be transferred to the workflow instance upon creation of the workflow instance.

If the workflow being created is a child workflow, the value will not be transferred if the field already has a value which is inherited from the parent workflow. In this case, the parent workflow value has precedence over the associated object value.

If there are multiple objects associated with a workflow, only values that are the same across all objects will be applied.

If you do not want the value to be editable, apply read-only permissions to the field.
