Calculating Time Duration

The NEXTDATEDIFF and PREVDATEDIFF functions will allow you to calculate the number of minutes between the current date/time and the next or previous date/time, respectively. 

Example:

Date/TimeParam1PREVDATEDIFF([Param1]) * [Param1]/[Param1]NEXTDATEDIFF([Param1])* [Param1]/[Param1]
1/1/2020 0:001 126
1/1/2020 2:0621261104
1/1/2020 16:18111042688
1/2/2020 4:30226881261
1/2/2020 16:31112612680
1/3/2020 4:09226801699
1/4/2020 0:10116991062
1/4/2020 17:3221062

These functions cannot be used in a top-level aggregate in time-based calculations, but may be used within the aggregation.
