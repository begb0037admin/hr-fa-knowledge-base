Excel Data Upload

You can enter or edit data for single requirements or multiple requirements of a parent object by uploading data from an Excel file, using a system-generated Excel template. This option allows you to upload large quantities of data at once.

Either standard Data Enter/Edit or Quick Add can be used to generate the Excel template to use for data entry. Both methods will produce a template with data rows pre-stamped with the date/time.

To add or edit data in Excel format:

  1. From the data entry selection page (Quick Add or Standard Data Entry), after selecting the filter criteria, select Excel for the data entry format.

    If you have selected multiple parameters with the same name, also click Display full path so that you will be able to distinguish the parameters in the Excel file.

  2. Click Next.

    A dialog asks whether you want to open or save the document.

  3. Choose Save to save the template to your computer. Choose a location to save it and rename the file if desired.

  4. Open the file in Excel and enter the data as needed. Save the file.

    Any existing data for the date range and requirements you selected will appear in the template. You may edit and overwrite this data as needed. When you upload the file, all data for the same date/times shown in the spreadsheet will be overwritten.

     Blank cells will be ignored. Existing data for the same date/time will not be overwritten with a null value. In order to delete data, you must edit the data points in the main application.

To upload data from an Excel template:

  1. When you are ready to upload data from an Excel file, return to the Data Entry screen.

    If the page from which you generated the template is no longer up, you can right click any container and choose Data > Enter/Edit or Quick Add. Since the ID of the requirements for which you are entering data is stored in the Excel template, it does not matter what object you select or what mode you choose.

  2. Select the Upload Data button, then select Next.

     When uploading data, you can ignore the rest of the fields in the page. The dates and parameter selections will be imported from the Excel spreadsheet.

  3. Select Browse and browse to find the Excel data file from your local folders.

  4. Select Upload.

    When upload is complete, a message confirms that the data has been uploaded and queued for entry.

    Note that data changes may not be immediately visible in the system. The process time will depend on the amount of calculation or re-calculation required and the system load. You can check the status of a command immediately by clicking View Commands. Completed transactions have the status Succeeded. Transactions still in process may be Processing or Waiting. Failed commands should be reported to your administrator. Data from a failed transaction is not saved and will need to be resubmitted once the problem is resolved.

  5. Click Back to Manager to return to the previous view mode.
