Quick Data Documents

Select the Documents tab to view the documents that are available from Quick Data.

To access a document:

  1. Select the link to the document.
  2. In the File Download dialog, choose Save to save the document to your computer, or Open to open the document directly.

 The name of the document folder in which Quick Data support documents are stored is shown at the top. All documents that you want to be available through Quick Data must be stored in this document folder. The path given is the path to the document including subfolders in the main application.
