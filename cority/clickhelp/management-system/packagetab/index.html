Add App Page

After an App has been created for the system, you can add a page to display its contents to selected users. You may also restore any system default (native) pages that have been previously hidden.

To add an App page:

  1. From the menu, select Setup > Main Menu.

  2. Click Add. In the dialog, select the App you want to associate with the page.

    You may also restore a native page that has been deleted by selecting it.

  3. Edit the page name for display purposes, if desired.

    You may add a description, if desired. The description is not displayed to users, but is for management reference only.

  4. If you want the page to be visible to all users, leave the Visible to All box checked.

    To edit visibility by users or groups, uncheck Visible to All. Click Add in the Users or Groups boxes and select the users/groups to whom the page should be accessible.

  5. Click Update.
  6. Click Save and Confirm.

 Users must also have permission to the App contents, granted through Role Membership, as configured in the App Manager. If a user does not have permission to at least the default display page associated with the App, a permissions error will be displayed when the user selects the page.
