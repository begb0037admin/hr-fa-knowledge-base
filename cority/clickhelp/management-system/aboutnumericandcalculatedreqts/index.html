About Numeric and Calculated Requirements

Numeric data encompass several different types of numeric values that may be tracked in the system. For example, emissions data tracked in the system may include meter readings, fuel consumption data, emission calculations for various criteria pollutants based on fuel consumption and other variables, and various time-based calculations for rolling or fixed periods.

Numeric compliance data can be compared to external (regulatory) limits and/or internal limits (which may be set lower than the external limits). If data exceed either limit, a data warning is automatically generated by the system. This automatic recognition of potential deviations facilitates response to the situation and accurate reporting, if appropriate. This feature, combined with the ability to track task completion status and dates, provides the basis for isolating deviations as part of Title V reporting.

The following table defines the numeric requirement types and their uses in the system:

Requirement Type Description

Parameter

Used for data input. Typically used for a requirement associated with a regulated value, upon which calculations may be based. For example, fuel usage.

See Parameters .

Auto Parameter

Used to trigger a pre-determined value at a set interval, for the purposes of triggering a calc, generating a task or an event, or other purpose.

See Auto Parameters.

Calculated

Defines formulas for calculations, based on data input for parameters.

See Calculated Requirements.

Time Based Fixed

Enables statistical functions over a specified calendar time frame. For example, monthly or annual rollups based on calendar months/years.

May also be used for workflow aggregations,

See Time-Based Calculated (Fixed Period).

Time Based Rolling

Enables statistical functions over a rolling period. For example, 12-month rolling sum or average (calculates over any given 12 months rather than calendar year).

See Time-Based Calculated (Rolling Period).

Count-Based Calculated

Enables statistical functions over a specified number of data points (similar to a time-based rolling calculation, but without regard to time frame over which data points occur).

Count Based Calculated

Time Based Aggregation

Enables calculations over a specified time interval (without necessitating data entry). For example, year-to-date calculations.

See Time-Based Aggregation.

Time Based Subtraction

Derives a value based on subtraction of previous value from current value. Principally used for calculating values based upon meter readings. The addition of the PREV() function replaced this functionality, so the time-based subtraction requirement is now deprecated.)

See Time-Based Subtraction.

Standard Material Activity Calc

Used to calculate values based on the use of specific materials in defined activities or situations

See Material Activity Calculations.

Single Material Activity Calc

Used to calculate values based on the use of a single material in a defined activity or situation.

See Material Activity Calculations.

System Variables

Used to store constants required for calculation, such as emission factors, location specific variables, or properties of equipment.

See System Variables.
