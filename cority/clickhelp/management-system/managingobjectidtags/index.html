Managing Object ID Tags

Unique ID tags may be assigned to system model objects for the purpose of integration with backend systems.

The custom field type Unique Tag is available for this purpose. To assign ID tags to objects, a custom field of the Unique Tag type is applied to the required objects. A unique ID (alpha-numeric) may then be entered for each object on the object properties.

 Only one Custom Field with the Data Type "Unique Tag" may be used in each System.

To assign object ID tags:

  1. Create a custom field of the type Unique Tag.

  2. Apply the field to a Custom Field Template.

    You may use an existing Custom Field Template applied to the objects, or create a template specifically for this use.

  3. Apply the Custom Field Template to the objects that need to have ID tags.
  4. On the object properties, assign the ID tag value for each object. The values must be unique.

To assign or edit ID tags in bulk:

  1. Search for the objects to be edited.

    You can search by Custom Field Template or by Tag values, if desired.

  2. Select the objects whose tags you want to edit using the checkboxes.

  3. Right click and choose Change > Tags.

    Objects and their existing tags, if any, are shown in edit mode.

  4. Enter or edit tag values for each object.
  5. Click Save.

To search for objects by ID tag:

  1. Select the appropriate parent object for your search and expand the Search section on the Applicable Requirements page.

  2. Enter the search criteria to use.

    In the Tag search box, enter the value to search for. You can search for all tags that contain a particular string, if desired.

    If the objects with unique tags share the same Custom Field Template, you can also search by Custom Field Template.

    Check "Include all children" to find all objects in the hierarchy path.

  3. Click Search.

    The results list shows the objects matching the criteria. You may select the checkboxes for the objects to perform bulk operations, including bulk edit of tags.
