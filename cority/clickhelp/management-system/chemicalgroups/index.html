Chemical Groups

Chemical groups are optional groupings of chemicals for convenience in system operations. They can be used to:

  • Add chemicals in bulk to a material
  • Select chemicals for a Chemical Report
  • Add chemicals in bulk to a Chemical List (regulatory list)

The difference between Chemical Groups and Chemical Lists is that Chemical Lists are regulatory lists of chemicals with associated limits. Chemical Groups are simply groupings for convenience only.

You may create your own chemical groups as needed.

 To view Chemical Groups, users must have the Manage Materials and Activities user right.

To create a chemical group:

  1. From the menu, select Setup > Chemical Groups under Materials/Activities.

    The existing Chemical Groups are listed. The Count column indicates the number of chemicals in the group.

  2. Select New Chemical Group.

  3. Enter a Name for the group and an optional Description.
  4. Click Add.

  5. In the selection window, browse or use the search to find the chemicals to add to the group. Select the checkboxes for the desired chemicals and click Select Chemicals.

  6. Click Save, then Confirm.
