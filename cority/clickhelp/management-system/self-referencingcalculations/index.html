Self-Referencing Calculations

A calculations may reference a previous values of itself using the SELF function. This function is available for uses such as inventory management.

The SELF function can be used with the following calculations:

  • PREV - syntax: PREV ([SELF])
  • PREVDATEDIFF - syntax: PREVDATEDIFF ([SELF])

In addition, in order to initialize the first instance, it is usually necessary to use ISNULL, as follows:

  • ISNULL (PREV([SELF]),0)

Total Inventory Weight may be calculated using the following formula in a calculated requirement:

  • ISNULL(PREV([SELF]),0)+[Weight of New Inventory]-[Transported out Weight]

These functions cannot be used in a top-level aggregate in time-based calculations, but may be used within the aggregation. Within a time-based calculation, the first value within a given period will always be null, so ISNULL is required to initialize the first instance.
