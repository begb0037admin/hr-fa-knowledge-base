Change Task Recurrence Schedule for Multiple Tasks

You can change task recurrence schedules in bulk by creating a new task schedule to apply to all tasks in a bulk edit operation. When you add a new recurrence schedule, you can choose whether to replace the old recurrence schedules, and whether or not to preserve the data associated with any completed tasks for those schedules.

 Task recurrence schedules may not be edited if any of the tasks selected for bulk edit is an automatically generated task.

To edit task schedules for multiple tasks at once:

  1. First, search for the tasks you want to edit using the search criteria in the Tasks search pane.
  2. Select the checkboxes for the tasks you want to edit.
  3. Right click and choose Edit Task Properties in Bulk.
    A task form appears with the selected tasks listed on top of the form.
  4. Select the Recurrence tab.
  5. To create a new schedule, click Add New Schedule.
  6. Complete the information for the new recurrence schedule. You can choose whether to preserve existing task recurrence schedules and data:
    • Preserve all old task recurrence data: Current task schedule(s) will remain in effect, in addition to the new schedule. (See Note below.)
    • Preserve old task recurrence data and finish them [date]: Current task schedule will end on the date given. Old task data will be preserved.
    • Delete old task recurrence data: All data associated with the previous task schedules will be deleted and the new schedule will begin as specified.
  7. The Save Changes box is checked when you add a new schedule. If you decide you do not want to save a schedule you created, uncheck this box before going to another tab or clicking Save to save task. Otherwise, you risk losing old task data.
  8. Click Save. The changes are shown for your review.
  9. Click Save again, or Back to edit.

 When you add a new recurrence schedule and choose to "Preserve all old task recurrence data," the new task schedule will be added only if it does not fall within the range of the old schedule. If the new task schedule overlaps the new one, no changes will be made to the task schedule.
