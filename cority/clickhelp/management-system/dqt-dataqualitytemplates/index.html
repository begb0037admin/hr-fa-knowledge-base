Data Quality Templates

A Data Quality Template is a type of custom field template that allows you to provide supplemental information for data points. For example, if a data point exceeds the limit or is an anomaly, you can use the data quality fields to document the reasons on the data point.

The custom field types allowed on a Data Quality Template are:

  • Numeric (including numeric lookup)
  • Boolean
  • Small text
  • Calculated

Calculated fields may use numeric and Boolean fields on the same template in their formulas.

The data quality fields are available only when using Excel data entry, or by standard data entry in HTML (not Quick Add) on a single parameter which has a data quality template. Data quality fields are not available when doing data entry from the parent object, or when you select more than one parameter.

When viewing/editing data on a parameter with a Data Quality Template, the Data Quality fields may be seen by clicking on View, Add or Edit.

Data Quality fields may be used for two purposes:

  • Purely for information and analysis
  • To provide fields that can be used in a data substitution scripts.

To view Data Quality Templates, from the menu, select Setup > Data Quality under Templates. The list of existing Data Quality Templates is displayed.
