Task Default Notifications

Custom notifications may be created to use for email notifications for tasks. See Notification Template for instructions on creating your own notifications.

A Standard Task Notification is available for your use in the following text file: Standard Task Notification.txt

Open the file in a text editor (Notepad). Edit the text if needed, then copy and paste it into the Notification Template body source as code.

In the Notifications HTML editor, click the Source button. Copy the text into the source window and click Save. You will see a preview of the email text before confirming.
