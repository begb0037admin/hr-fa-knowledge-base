Supervisor and Manager Functions

Setting the Supervisor for users allows filtering users in workflows by their supervisor.

EQL queries can be used to query workflows for a particular set of roles where one of the members lists the querying user as their Supervisor or is “down the Supervisor chain” from the querying user. The Supervisor field is also accessible through the REST APIs.

The Supervisor for a user is set through the User Profile. You can edit the user profile manually in the system UI, or use bulk tools to edit multiple user profiles.

The following EQL functions can be used:

  • IsMember("RoleName1", "RoleName2") - This function will return TRUE for any given workflow instance IF the calling user resolves to any of the supplied Roles for the workflow instance
  • IsSupervisor("RoleName1", "RoleName2") - This function will return TRUE for any given workflow instance IF the calling user is listed as the direct Supervisor on the user profile of any user that resolves to any of the supplied Roles for the workflow instance.
  • IsManagement("RoleName1", "RoleName2") - This function will return TRUE for any given workflow instance IF the calling user is UP the "chain of command" based on the user profile of any user that resolves to any of the supplied Roles for the workflow instance.

Chain of command simply means if user 5 is the supervisor of user 4, and user 4 is the supervisor of user 3, and user 3 is the supervisor of user 2, and user 2 is the supervisor of user. If user 4, user 3, user 2, or user 1 is a Role Member of any of the Roles supplied in the arguments for a given workflow instance, then if user 5 uses this function, the results should be true for that workflow instance.

See EQL Help for more information.
