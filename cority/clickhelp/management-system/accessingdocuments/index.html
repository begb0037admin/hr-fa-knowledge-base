Accessing Documents

In the Documents library, you can view all the documents to which you have been given permissions. If you do not have permissions for any documents or document folders, Documents will not be visible on the tree. The following instructions assume that you have permissions to at least one document or document folder.

To access the Document library:

  1. On the System Model page, select Documents from the tree.

    The document folders are displayed.

  2. Browse document folders by selecting them to display the contents.

    You may sort documents by Date Created or Last Modified by clicking on the column labels.

    The path to the current folder is shown in the title bar below the Documents head. The path is hyperlinked and may be used for navigating back up the folder structure.
