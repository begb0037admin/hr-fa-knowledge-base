Combined Report

Output from multiple saved reports can be combined into a single report output file using the Combined Report. Before you can create a Combined Report, you must create the separate reports that you want to combine.

Combined Reports can be output to HTML or standard Excel report format. However, it is primarily designed for use with the Excel template format, where raw data is output from multiple reports to an Excel file with multiple worksheets, on which macros can be run to format and combine data.

Results of different output formats are:

  • Excel Template: Raw data for each report will output to a separate worksheet, with the worksheet name and order defined in the Combined Report definition. The Excel Template needs to be associated with the Combined Report. Child reports do not need to have Excel Templates associated with them.
  • Excel output: Each report will output to a separate worksheet, with the worksheet name and order defined in the Combined Report definition. Formatting will be the standard Excel formatting for the report type.
  • HTML output: Child reports are output to HTML one after the other, in the order defined in the Combined Report.

To create a Combined Report:

  1. First, create the separate reports that you want to combine.
  2. In the Reports tab, click Add Report.
  3. For the type, select Combined Report. Click Continue.

  4. Under Subreports, click Add Report. In the selection window, select the reports you want to include in the combined report, then click Associate.

    If you want the reports in a particular order, select them one at a time in the desired order.

  5. For each report, enter the default date range to include in the report, if any. Or, under All Subreports, enter the date range to use for all reports and click Apply to All Reports.

    If the report output will be Excel or Excel Tmplate, you can specify the worksheet name in Excel for each report. (For HTML reports, the name is ignored.)

    If the object selector is included on the sub-reports, it will also be available for the combined report. You must specify the object selector on the sub-reports, if you want the ability to run the report on different objects. However, you can change the default objects for the combined report.

  6. Name the report and select an output format.

    If you want to use a custom Excel Template format, save the report first, then select Manage Templates from the right click menu and associate a template with the report. You can then update the report and choose the Excel template option. See Excel Template Reports (Custom Reports).

  7. Save the report.

You may also set up a schedule for automatic report execution, if desired.

If you do not want to include a subreport in the output at any time, you can uncheck the Active box next to the report. Only subreports that have the Active box checked on the report setup will be included when the report is run.

The worksheet names specified in the report setup must match the worksheet names in the Excel Template file attached to the report in order to output to the correct worksheet. If no worksheet by the same name is found in the Excel template file, a new worksheet will be created with the name specified in the report setup. Macros that reference worksheet names can consequently be broken.
