Create Custom Chemicals

Custom chemicals can be created as needed for your system. Custom chemicals allow you to:

  • Create chemicals not included in the standard chemicals provided.
  • Change numeric property values for slight variations or greater precision.
  • Tag chemicals for various chemical lists using the Boolean properties.

Chemicals are identified by their name and CAS number. A mathematical alias is also required, which is used for reference in calculations.

When speciation is not required for Material Activity calculations, a generic "chemical" may be created in the system to represent the material as a whole.

Chemicals may be created manually in the system or imported via an Excel file. See Export/Import Custom Chemicals.

To create a custom chemical:

  1. From the menu, select Setup > Chemicals under Materials/Activities.

  2. Select New Chemical.

    Or, right click anywhere in the table in the chemicals list and choose New.

  3. Enter a Name and CAS Number.

    The combination of Name and CAS Number must be unique.

  4. Choose a Mathematical Alias for the chemical, to be used as shorthand when creating calculations.

    Optionally, enter a Description.

  5. To define property values, click the plus sign (+) to expand the Chemical Property History.

    An initial value history is provided which can be edited to set the necessary values.

    Even if you do not want to define properties, you will need to set the Begin Date in the Chemical Property History section. The Begin Date defaults to the current date so calculations will not valid before this date unless you backdate it appropriately.

  6. Click Edit.

  7. Enter property values where known and as needed. Check the Boolean (non-numeric) properties that apply. Set the Begin Date, then click Update.

    Set the Begin Date to include the earliest date for which data will be entered, even if no properties are defined. Calculations will not be valid and will not run before this date.

  8. Click Save to save the chemical.

 Editing of chemicals after they have been used in the system is not recommended, and some changes may be restricted. Operations that cause re-calculation of existing data is subject to calculation limits.

Edit a Custom Chemical

Once created, you can edit a custom chemical's properties.

  1. From the menu, select Setup > Chemicals under Materials/Activities.
  2. In the Chemicals library, expand the Search pane.

  3. Select the Search criteria to find the chemical to edit.

    Select Show Only Custom Chemicals to filter for custom chemicals only.

  4. Select the chemical, right click and choose Edit.
  5. To edit chemical property values, click the plus sign (+) to expand the Chemical Property History.

  6. Click New to add a new chemical history or click Edit to edit the existing value history.

    You cannot edit or delete a chemical history if it is currently used in a material.

  7. Enter property values where known and as needed. Check the Boolean (non-numeric) properties that apply. Set the Begin Date, then click Update.

  8. Select Save.
