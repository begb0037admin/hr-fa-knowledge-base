Removing Users (Expiring, Deleting and Locking Accounts)

Options for removing a user’s access in the system are:

  • Mark as Deleted: User accounts set up as home users for the system may be "Marked as Deleted." When this option is chosen, the user’s access is revoked. The user will no longer be visible as a member of any groups and all system mail is blocked to the user. The user will no longer be available for task assignment. However, marking a user as deleted does not remove any existing task assignments or other associations (including permissions). This allows reports to show historical information associated with the user. If the user is later restored, all associations will be restored intact.
  • Mark as Expired: An expiration date may be set on any user account in the user profile. Access is denied as of the expiration date. Expired accounts also retain their group memberships, rights and permissions for historical purposes. The user can be restored, with all previous associations intact, by simply removing or resetting the expiration date.

  • Set an expiration date on the account, then click Save.

    For an Access user, you can set an immediate expiration data using the right click menu option Mark as Expired. The expiration date will be set to today’s date.

    To see the user in the user profile list, you must check Show deleted/expired users. The user account status shows Expired in the user list.

  • Lock Account: A locked account simply has the lock flag set on the profile. An account may be locked automatically from failed login attempts, or it may be set manually by an administrator from the user profile. All group memberships, rights and permissions are retained, but access will be denied until the flag is removed.

For users who have been granted access from another system, the option to "Mark as Expired" appears. When this option is chosen, an expiration date with today’s date is set on the account. Alternatively, you have the option to "Revoke Access." This option removes the user account form the system and deletes all group associations, rights and permissions. See Revoke System Access.

To mark an account expired:

  1. Right click the user name and choose Edit.

To view expired users:

  1. In the Users search pane, check Deleted/expired users and click Search. If you only want to see deleted or expired users, you can de-select the other options.

    The Status column shows Expired for expired users.

To reset an expired user account to active:

  1. Select the user name, or right click in the row for the account and select Edit.
  2. In the User Profile editor, remove or reset the Expires date.
  3. Click Save.
