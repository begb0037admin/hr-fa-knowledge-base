Navigating to the Calc Graph Visualizer

You can navigate to the Calc Graph Visualizer window (Build Graph screen) from the:

  • Advanced Calculations (EMS) Main Menu; or
  • System Model through the Context Menu.

Launch the Calc Graph Visualizer from the Management System Main Menu

  1. Open the main menu.
  2. Hover over Calc Graph Visualizer, a window expands to the right of the navigation panel, click Calc Graph Visualizer or select the Launch button from the sliding menu.
    The Calc Graph Visualizer main page will open.

  1. To bring up the search sidebar, click the Search icon on the left navigation panel.
  2. Enter values in the textbox; search results are returned as you type.
    Wildcard searches are supported.
  3. Click one of the requirements from the list to view.
    The Calc Graph Visualizer window (Build Graph) will open for the selected requirement. 


    Launch the Calc Graph Visualizer from System model (Context Menu)

    1. From the main menu, navigate to System Model. 
    2. Navigate to and click on a specific compliance object.
      The Applicable Requirements window will display for that selection. 
    3. To Perform a search for your desired requirement, right-click a requirement to bring up the context menu, and then click Show Calc-Graph. 

    The Calc Graph Visualizer window will open, displaying the Build Graph screen for the selected requirement.

    Build Graph 

    The Calc Graph Visualizer window (Build Graph screen) is made up of different areas to allow you to build calculations. 


    The Calc Graph Visualizer window (Build Graph screen) has the following controls:

    • When Show UOM is selected, the requirement's unit of measurement is displayed next to its name.
    • Changing the number in Display Levels expands or contracts the graph to that number of levels upstream and downstream from the nodes in the Connection History.
    • Changing the number in Display Nodes limits the number of requirements that will appear in the graph.

       If a calculation has more dependencies than the set number of nodes, a warning will appear. A full list of dependencies can be exported in .xlsx format.

    • After making changes to Display Levels or Display Nodes, click the Update button to implement those changes.
    • When Pan while zooming is active, the graph will maintain its current center while zooming in and out.
    • Activating Auto Zoom zooms the graph in or out to its current full width. Keeping it active zooms the graph automatically when nodes are expanded or contracted.
    • Activating Auto Center places the graph at the center of the screen. Keeping it active automatically adjusts the center when nodes are expanded or contracted.
    • Change the Node Width by entering a number (in pixels) in the textbox, or adjusting the slider.
    • When Object Legend is selected, a legend of the icons used in the graph are displayed at the top of the screen providing information on the types of requirements that are in the graph.
    • When Object Location is selected, the source location of a requirement is provided at the top of the screen.
      The Current Object Location will provide the source location of the selected requirement in the graph, which will have a blue outline around it. The Other Location will provide information on a requirement that you hover over and is not selected.  
    • Selecting a date range in the Date Range selector allows users to observe the history of calculations, and any changes in formulas within the selected date range.
      On the Data Range window click the Date From, and Date To drop down list, select dates, and click Apply. The date range is updated, and the Date Range window closes.
    • When View Data is selected, the Breakdown of Data section displays.
      This section will be blank before any requirement is selected. Multiple requirements may be selected.

      Data in the Breakdown of Data section by default is displayed in descending data order. You can click the data column for the order to be changed to ascending order. 

    • To view the Properties panel of a requirement, click the respective column header hyperlink in the Break of Data section.
      The Properties panel will open on the right side of the Calc Graph Visualizer window.

         If the View Data checkbox is not selected, the Properties panel will automatically display on the right of the Calc Graph Visualizer window when a requirement is selected on the graph. 

      • You can zoom manually using your mouse wheel, or by clicking the  or  buttons.
      • Clicking Zoom to Fit, centers the graph and resizes it so that it fits completely on the screen.
      • Click and drag anywhere in the graph area to move the graph manually.
