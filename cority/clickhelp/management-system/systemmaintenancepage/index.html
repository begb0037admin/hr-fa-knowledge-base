System Maintenance Page & System Alerts

A system maintenance alert page is available for displaying important system messages to users. The System Maintenance message page can be turned on and off as needed. When turned on, users will see the alert page first after login. They will then need to click a button to continue to the application.

The creation of the System Maintenance page is controlled through the Admin Tools and may be applied to selected environments and systems as needed, by request to Customer Service. The system maintenance page may be used:

  • By Cority, to notify all customers of changes, updates and scheduled system maintenance.
  • By customers to notify their own users of system changes and additions, special instructions, or any system-related issues.
