Workflow Roles

Workflow Roles are used to assign responsibilities in a workflow type.

There are four pre-defined roles that apply to all workflow types,. The pre-defined roles cannot be edited or deleted. Pre-defined roles include:

  • Creator: The user who initially created the workflow.
  • Assignee: The user or group assigned the current step in the workflow
  • Previous Assignee: The user who completed the previous step in the workflow.
  • Workflow Manager: Any user who successfully invokes an operation on a Workflow based on the Manage Workflow right or the permission to Manage Workflows for an object. Additional users may be added to this role through the Roles tab of the workflow type, giving them management rights solely for this type.

Custom roles are any roles created by users for their workflow types. Default role memberships for custom Roles are set up on the workflow type. However, Role Overrides may be applied to system model objects. Workflow instances associated with a facility (or other object) with a Role Override will use the default memberships specified for that object. Thus different facilities may specify their own role members for a particular workflow type. See Workflow Overrides.

 The same Role may be used in different Workflow Types and be mapped to different role members. The Role may also have different overrides per workflow type.

To view the existing roles in Role Manager:

  1. From the menu, select Setup > Roles under Workflows.
    The last column shows all workflow types that use this Role.
  2. To view properties of a Role, right click the Role and choose View.
  3. To see dependencies for a Role, right click the Role and choose Show Dependencies.
    Dependencies include the Workflow Types, Workflow Policies and Workflow Overrides that reference this Role.
