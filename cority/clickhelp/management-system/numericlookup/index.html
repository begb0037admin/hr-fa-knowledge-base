Numeric Lookup

A numeric lookup field allows you to create a list of text options that have corresponding numeric values. The field has the type number, so it may be used on a Calculation Template, Data Quality Template or Event Template, where the value may then be used in calculations.

To create a numeric lookup list field:

  1. For the Data Type, choose Number.

  2. For the Value Entry Method, choose Numeric Lookup.

    An entry box appears so you may enter list values.

  3. Enter the Numeric Value and the Text Alias for each list item. Select Add to add another list item.

    You can add translated values for localization by clicking on the language symbol .

    The order of display in the list box will be the same as the order shown on the form. To move items up or down in the list order, click the up or down arrow next to the list item.

    Select Link List if you want to link this list to another list, so that selecting an option on this list enables selection of an item from a related list. The list field you want to link to must already exist. See Linked Lists.

  4. Select Save and Confirm.

Localization

The list Name, Caption, Description and Text Alias values may be localized in any of the available languages in the system.

To enter translated values for different languages:

  1. Click the language symbol next to the field.

    In the pop-up dialog the currently active languages for users in the system are shown, as determined by the values selected in the Culture field in users' profiles. Check "Show All EMS Languages" if you want to add translations for languages not currently selected by users.

  2. Enter the value to use for each language for which you want to provide a localized translation.

  3. Click Save.
