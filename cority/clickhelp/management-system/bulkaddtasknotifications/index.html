Add Task Notifications for Multiple Tasks

You can change notifications for all tasks in a bulk edit operation.

New notifications you add in a bulk operation will overwrite all existing notifications. Existing task notifications will be deleted. To preserve existing notifications, recreate them in addition to the new ones.

To add task notifications for multiple tasks:

  1. First, search for the tasks you want to edit using the search criteria in the Tasks search pane.
  2. Select the checkboxes for the tasks you want to edit.

  3. Right click and choose Edit Task Properties in Bulk.

    A task form appears with the selected tasks listed on top of the form.

  4. Select the Notifications tab.

    To create a new notification, click Add New Notification, then complete the notification fields.

    The Save Changes box is checked when you add new notifications. If you decide you do not want to save the new notifications, uncheck this box before clicking another tab or clicking Save.

  5. Click Save. The changes to the tasks are shown for your review. Click Save again or Back to edit.
