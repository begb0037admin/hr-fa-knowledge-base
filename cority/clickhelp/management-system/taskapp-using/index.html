Task Completion App

With the Task Completion App you can complete tasks on mobile devices, tablets and multiple browsers. The Task Completion App can be accessed from the main menu or accessed directly through email or local links which have been properly configured by your system administrator.

    The Task Completion App only shows tasks assigned to the current user.

      Access the Task Completion App from an email notification

      1. Click the link in the email.
        Must be a custom notification with the correctly configured link; standard task emails will go only to the main application.

      2. Log into Cority on the login screen.

        The Task Completion App is displayed with a list of your assigned tasks.

        Tasks may be displayed for This Week (default), Today, Last Week, This Month or Last Month by making a selection from the dropdown.

        Choose whether to Show Complete Tasks or not with the On/Off toggle.

      Complete a task

      1. Select the task from the task list.

        Optionally, to see task information (objects, assignor and assignees), select Description. Click Back to return.

      2. Complete the task fields provided.

        Status defaults to 100% (complete) with current date and time for completion. Edit these fields if necessary.

        Other task fields (Time and Cost to Complete, Comments) may also be available for entry, depending on the administrative configuration.

      3. Select Save.

        You may click Cancel to undo changes before saving. However, you cannot undo changes once you have clicked Save.
