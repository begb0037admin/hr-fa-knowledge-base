View Citations

Citations are organized in folders accessed from the System Model tree, in the same manner as Documents.

To view Citations:

  1. Select Citations from the tree.

    The citation folders to which you have permission are displayed in the Citations library.

  2. Browse the folders by selecting them to display the contents.

    Citation folders may be browsed from the tree, or in the content pane. Citations are displayed only in the content pane on the right.

    The path to the current folder is shown in the title bar below the Citations head. The path is hyperlinked and may be used for navigating back up the folder structure.

To view Citation properties:

  • Right click the citation and choose Properties > View.

To view properties for multiple Citations:

  1. Check the Select box for all the citations you want to edit.

  2. Right click and choose Properties > View.

    Properties will show all values that the selected Citations have in common.

Search Citations

Use the search function to find specific citations by text and/or active dates. Before searching you can browse to a specific folder to begin your search.

To search Citations:

  1. Click the plus sign (+) to expand the search pane.

  2. Select the search criteria.

    Search For: Text string to search for.

    Search In: Folders to search:
    Current Folder searches only the current folder.
    Current Branch searches the current folder and all subfolders.
    All Folders searches all reports and report folders.

    Scope: Choose which fields to search for the text (Name, Text, Identifier, Questions, Userfields, Descriptions, or All).

    Active Date From/To: Filter by active dates of citations.

  3. Select Search.

    All citations matching the criteria are displayed.
