Version 9.3.2 Release 2/12/2018

This release adds Spanish language translations to the Management System. Users may be configured with Spanish as their culture, allowing them to view the system in Spanish.

  • MAIN-5092 Fixed an issue where the path for an object in the tree could become corrupted in certain cases where the parent object was renamed.
  • MAIN-8101 Fixed an issue where the grid in QuickData forms did not work if it included calculated requirements.
