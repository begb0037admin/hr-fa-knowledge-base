Calendar Icons

The calendar icons indicate the status of tasks and workflows.

The task icons indicate the type of task and task status. The general symbols used in the task icons are shown in the following table.

  

Single task occurrence (square)

  

Recurring task (pointed)

 

Tasks for single object (one bar)

 

Task for multiple objects (two bars)

 

Completed (checkmark)

 

Dismissed (x)
 

Overdue (red)

 

Tasks you assigned (yellow)

These general symbols are combined to indicate both task type and status. For more examples and explanations of the various combinations, see Task Icons.

The workflow icons indicate the status of a workflow, as follows:

  

Open: Workflow is still in progress

  

Open Overdue: Workflow is in progress and overdue

  

Closed: Workflow is completed
