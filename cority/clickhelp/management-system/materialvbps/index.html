Material Value Based Properties

Material Value Based Properties (VBPs) are constants (numeric or Boolean) that are properties of the material and which may be used in calculations related to a material.

Material VBPs are created in the Material/Activity Field Library. They may then be added to one or more materials. The value is defined on the material.

To create a value based property for a material:

  1. From the menu, select Setup > Material/Activity Field Library under Materials/Activities.
  2. Select New Material/Activity Field.
  3. For the type of property, select Value Based Material.

  4. Enter a name for the property and an optional description.

    The description is only seen in the property manager, but may be useful when selecting properties to add to a material.

  5. Choose the property type: numeric or Boolean.

  6. Click Save.

    The value for the property is defined when it is added to a material. After adding the property to the material, expand the history, click New, enter a value and Begin Date, and click Update.
