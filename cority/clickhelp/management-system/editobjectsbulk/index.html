Edit Objects in Bulk

You can edit the properties of multiple objects of the same type at once to apply the same property values to all objects. When editing properties in bulk, you can choose the properties you want to edit. Only the values for the properties you select will be modified. Other properties will retain their original (and different) values.

To edit properties in bulk:

  1. In the Applicable Requirements view, use the search function to find the objects you want to edit.

    Since you can only edit objects of the same type in bulk, you can set the search to the object type and add any other desired search criteria.

  2. Select the checkboxes for the objects to edit.

  3. Right click and choose Properties > Edit.

    A bulk edit properties form is displayed. The objects selected to edit are listed at the top of the form. All the properties the objects have in common that may be edited are shown. Existing values are shown if they are identical.

  4. Select the checkboxes for the properties you want to edit to enable editing, then modify the values as desired.

     Telephone number fields for Facilities cannot be edited in bulk in this manner. However you can edit these fields using the Bulk Upload and Editing Tools.

  5. Click Save and Confirm.
