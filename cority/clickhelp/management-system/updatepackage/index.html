Update an App

You can update the contents of an App by uploading a new revised package.

 The system does not retain package versions. If you want to retain versions for archive purposes, you can download the current App package. See Download App .

To update an App package:

  1. In Apps Manager, right click the package and choose Update.
  2. Select Browse and select the zip file from your computer or network.

  3. Select Upload.
    After the file is uploaded, the form for editing App properties is displayed for editing. (See Create Apps.)

  4. When you are done, click Save and Confirm.

Download App

You can download an existing App package from the system to use for updates or for archive purposes.

To download an App package:

  1. In Apps Manager, right click the package and select Download.
  2. In the Windows download dialog, click Save.

  3. Choose the location to which you want to save the file and click Save.

    The App package is saved to your selected location as a zip file. Unzip the contents to edit it.
