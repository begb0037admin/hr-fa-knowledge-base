Command Failure Notifications

Automatic notifications of command failures are automatically sent to the user who submitted the command.

You can set up additional notifications as follows:

  • Set Command Failure Notifications on a system-wide basis for default users/groups from Setup > Command Failure Notifications.
  • Set location-related Command Failure Notifications on the System Model tree using Notification Overrides. These are set via the right-click context menu on the System Model tree.

Location-related Notifications are only sent out if a definable location is associated with the command. The Notification Overrides are in place of the system-wide Command Failure Notifications. For example, when data entry fails for objects under a specific Facility/Unit/POI, a failure notification will be sent out according to the failure notifications set on the immediate parent or nearest ancestor, if any. When data entry fails for multiple objects in different locations, Notification Overrides do not apply and only the default Command Failure Notifications for the system, as specified in Setup, are sent. If no failure notifications are set on the tree, the system-wide failure notifications apply.

User profiles have an additional setting to specify where Command Log failure notifications are sent, to Inbox only, or to both Inbox and Email. The default is Inbox only. Settings in the Notifications setup page that apply to the user, if any, will override user profile selection.

In addition, if a user has multiple applicable overrides (for example, he is explicitly selected in the override and is also a member of a group that is selected), only one notification will be sent. If the user has Inbox and Email selected for any of the override memberships he will receive both Inbox and Email notifications.

To set system-wide command failure notifications:

  1. From the menu, select Setup > Command Failure Notifications under Notifications.
  2. Select Add under Users or Groups and select the users/groups to add from the selection window.
  3. For each user or group select the Notification Method: Inbox only or Inbox and Email.
  4. Click Save.

To set Notification Overrides for location-specific command failure notifications:

  1. Right click the parent object on the tree and choose Change > Notification Overrides.
  2. Select Add under Users or Groups and select the users/groups to add from the selection window.
  3. For each user or group select the Notification Method: Inbox only or Inbox and Email.
  4. Click Save.

Notifications set on the System Model tree are inherited by all child objects. Upon command failure, if a specific location is identified, the system will look for notifications first on the parent object, then each ancestor. If no notifications are found to be set on the tree, then the default notifications as specified in Setup will apply.

 You must be a member of the Administrators group to view or set Notification Overrides.
