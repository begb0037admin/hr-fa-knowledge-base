Object Naming Rules

When naming objects in the system you should carefully choose a naming syntax that takes into account their use in data entry, reports, Apps, etc. Certain characters are invalid and others strongly discouraged due to problems they create with build and maintain tools, EQL queries, Excel reports, VBA code (used in Excel macros for reports), and other integration tools.

Illegal or strongly discouraged characters include (but are not limited to) the following.

/ \ Slashes (forward or back), as they are in object location paths and urls
[ ] Square brackets are used in calculation syntax.
|| Used as delimiters
& May be encoded as html when copied
* Asterisk is used as a wild card so searches will be difficult if it is used in a name. Other mathematical symbols are also discouraged.
< > = Relative comparison symbols.
, Commas cause issues when dealing with comma delimited files (i.e. EQL queries)
; Semi-colon is used to differentiate link listed items
: Colon is used to give field name followed by value inside link list
- – — hyphen, n-dash, m-dash can all be hard to find and correct and cause issues with searches. If it is necessary to include a dash for reporting purposes, create a custom field on the object that has the official name for the reporting agency and use the dash there.
white spaces White spaces or [Alt]+[Enter] in a cell in Excel when using a build tool are hard to find and eradicate
multiple spaces Multiple spaces in a row make searching very difficult.
accents Accent marks are hard to replicate for bulk tools. Better not used.
μ or UOM UOM symbols like the micro μ can cause issues with queries.
©® Copyright and other symbols may be encoded as html and will cause problems with searches and queries.

 In general, any special character can cause trouble when setting up the bulk tools. EQL query results can also be thwarted. If a special character field is required, then create a custom field and place it on the object. Make that field hold the “true” name of the object (for searching/reporting/etc.)
