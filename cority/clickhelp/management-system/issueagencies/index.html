Issue Agencies

The regulatory agencies that are the issuing agencies for your citations can be created in Issue Agency Manager. You need to create the agencies with which you want to associate your citations in order to make them available for selection in the dropdown list in the Citation properties form.

To create Issue Agencies:

  1. Right click Citations in the tree and choose Issue Agency Manager.

    You can create two level selection lists for agencies. Each agency may have sub-agencies that will be available in the sublist when that agency is selected in the first list.

  2. Enter a name in the Level 1 Agency Name box and click Add/Save.

  3. To create a sub-agency (Level 2), select the Level 1 agency with which it is to be associated. Then enter a name in the Level 2 Agency Name box and click Add/Save.

    Repeat to add more items to the sub list.
