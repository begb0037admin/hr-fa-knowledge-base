Completing or Updating Tasks

Whenever a task-related activity occurs, the task should be updated to show its completion status. When a task is fully complete, the completion status is set to 100%.

When updating tasks, you may:

  • Change the completion status of a task to indicate it is either fully or partially complete (expressed as a percent):

    Completing a Task or Updating Task Status

  • Dismiss a task that cannot be completed:

    Dismissing a Task

  • Create a task exception for a recurrent task that must be rescheduled:

    Task Exceptions

  • Complete multiple tasks at once using the Global Completion/Dismissal options:

    Global Task Completion or Dismissal

  • Complete a task for multiple objects, with identical or different completion information:

    Completing Multi-object Tasks

  • Complete subtasks and parent tasks:

    Completing Subtasks and Parent Tasks

  • Complete event log information for a task that is associated with an event:

    Completing an Event-Triggered Task
