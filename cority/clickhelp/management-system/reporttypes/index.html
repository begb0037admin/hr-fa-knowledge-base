Types of Reports

A variety of standard report types are available to be configured specifically for your reporting needs.

The following table shows the standard report types available and their common uses and examples.

Report Type

Use and Examples

System Properties Report

Used to report on system model objects and properties. Examples are:

  • List of requirements by regulatory program
  • Equipment list and associated characteristics
  • Emission sources and associated information

Data Report

Used to report on compliance data for a selected time frame. Examples are:

  • Waste Water Reporting
  • Emissions Inventory Report
  • Inspection dates and results

Non-Numeric Data Status Summary Report

Used to produce an overview of the compliance status for non-numeric requirements. May be used to track and follow up on possible deviations for compliance-related tasks.

Example: Number of equipment inspections for which the compliance status was "Not Determined."

Task Report

May be used to produce information about individual task instances. Examples are:

  • Assignee, assignor, due date, complete date
  • Inspection Logs
  • Maintenance Logs

Task Status Summary Report

Used to obtain an overview of the status of all system tasks (number and percentage of tasks completed on time, completed overdue, pending, overdue, etc.).

Task Closing Time Summary Report

Used to obtain an overview of time required to complete system tasks.

Event Report

Used to view summary information for selected events. Examples are:

  • Safety Incident Tracking and Reporting
  • Title V Deviation Reporting
  • Audit Findings

Event Instance Count Summary Report

Used to obtain a statistical count of the number of events per location, by week, month, quarter or year. Examples are:

Recurring Findings Rate

Root Cause Evaluation

Workflow Report

Used to report on workflow instances by workflow type.

Security Report

Used to obtain an overview of the rights and permissions assigned to system users and groups.

Compliance Status Report

Used to report on the compliance status of tracked requirements over a period of time.

Main use is: Generate Title V Compliance Certification Reports.

Citation Report

Used to report on requirements related to specific citations. Requirements can be grouped by citation.

Issues/Findings per Assessment Aggregate Report

Used to provide a statistical view of findings for assessments in conjunction with an assessment log.

Toxic Release Inventory Report (Form R)

Used to complete Form R for TRI reporting requirements. This is an additional module that may be added to your customer system on request.

Material Activities Report

Used to report on Material Activity calculations

Material Report

Report on Materials and their properties used in Material/Activity calculations

Chemical Report

Report on chemicals and chemical properties from the Chemicals list

Combined Report

Combines two or more reports of any type into one output file. Output may be in any format, but most commonly used with Excel Template Reports to produce a custom report.
