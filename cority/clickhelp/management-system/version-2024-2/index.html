Version 2024.2

Release Date: June 28th 

New Features

  • Users are now able to make specific fields required on Custom Field templates. When these Custom Field templates are applied to objects/requirements, users will be required to fill in these fields to create or save the objects/requirements.

 Making fields required on an existing Custom Field templates will not affect existing objects/requirements with that custom field template. However, the next time a user edits that object/requirement those fields will then be required. This effects edits made in the user interface as well as to the API.

  • Users can now enter comments to deleted data points in the Data Quality Template (DQT) field, and follow the history of that data point even after its deletion.
