Create/Edit Calculation Template

To create a Calculation Template:

  1. From the menu, select Setup > Calculation under Templates.

  2. Select New Calculation Template.

    Or right click anywhere in the Calculation Templates list and select New.

  3. Enter a Name for the template and a Description.

    The Name appears on the properties form for objects using the template, as the section label for calculation fields. The description is only seen in the Calculation Templates list, and may help users identify the purpose of the template.

  4. Select Add to add fields to the template.

    In the selection window, browse or use the search to find and select the fields to add to the template. Check the checkbox for the fields you want and click Select Fields.

    Field selections are limited to the following allowed types:

    • Numeric
    • Boolean
    • Calculated: Calculated fields may use numeric and Boolean fields on the same template in their formulas

    The order in which the fields appear will be the display order on the properties form for the objects to which the template is applied. To re-order the fields, select a field and click the Up or Down button.

  5. Select Save.

    If any calculated fields are included on the template, you must then define the calculation and specify a Start date for the calculation. (See Calculated Numeric.)

    Click the Calculator button to use the calculation builder. The other fields on the Calculation Template are available to use for input. After defining the formula, click Save.

    Select a Start Date for the formula and click Update to save the value.

    The calculation Start Date defaults to the current date. Be sure to edit the Start Date to include the earliest date for which data will be entered in the system. Calculations will not be made before the Calculation Start Date.

  6. After defining all calculated field formulas, click Save.

    The Calculation Template fields are displayed for review, with the formulas.

  7. Select Confirm to save the template.

 Calculation formula definitions apply only to applications of this template and do not affect other templates in which the same field may be used.

After the template is applied to an object, you can enter field values on the properties form for the object (in create or edit mode).

Editing a Calculation Template

An existing calculation template may be edited in order to:

  • Edit the formulas for calculated fields.
  • Add or remove properties.
  • Modify the template description.

Properties may not be removed from the template if they are either being used in calculations or have associated data.

To edit a calculation template:

  1. Right click the Calculation Template in the Calculation Templates list and choose Edit.

    To add a field, select Add. In the selection window, browse or use the search to find and select the fields to add to the template. Check the checkbox for the fields you want and click Select Fields.

    To create a new custom field to add to the template, click Create New Custom Field. (See Create/Edit Custom Fields.) After the new field is created, you will be returned to the template edit screen. The new field will appear in the Selected Fields list.

    To remove a field, select the field in the list and click Remove.

    To change the field order, select a field and click the Up or Down button to change its position.

    To edit the formula for calculated field, select the Edit link from the formula-based property table (bottom of page).

    If you edit a calculation definition and want to preserve previously calculated data, set a new Begin Date for the edited formula. The calculation history will then be preserved for old data and the new formula used only for new data.

  2. Select Save then Confirm to save the template changes.
