Canceling or Deleting Tasks

Tasks may be canceled if they are no longer required, or are to be replaced by other task requirements. You can cancel a currently active task by setting an end date for the task.

  • To cancel a single-occurrence task which has not yet been completed, simply delete the task. The task assignee will be notified that the task has been deleted.
  • To cancel a recurrent task, which has completed instances, edit the recurrence schedule to set an end date for the schedule. See Editing Task Recurrence Schedules.
  • To cancel a recurrent task that has no completed instances, delete the schedule.

To delete a recurrent task that has completed task instances you must have Admin rights, or have Full Control and be the Assignor for all task instances.

To delete a recurrent task series:

  1. Right-click a task instance and select Delete Task Series from the popup menu.

  2. In the confirmation dialog, click OK to confirm that you want to delete the task series.

    If you delete a task series, all data for that task is deleted. Use this option only if you do not want to preserve the data.

     When a task is deleted which has associated workflow instances, the workflows will not be deleted. A history record will be added to the workflow history indicating that the underlying task was deleted. Conversely, if a workflow is deleted, no change is made to the associated task.
