Task App Settings and Configuration

To manage the settings for the Task Completion App you must be a member of the ETA-TaskAppAdministrator group. Users in this group will see the Settings button in the top right corner of the Task Completion App.

Display settings apply to all tasks. Users will only see those tasks to which they are assigned. There is no search capability other than the filter for the task time period and the option to toggle on/off display of completed tasks.

To view/edit settings:

  1. Select the Settings button on the Task Completion App.
  2. Click the button to turn on or off display of the following optional fields:
    • Dismiss: Users will not be able to dismiss a task if this setting is Off.
    • Date: Completion date defaults to current date, but may be edited if displayed (On).
    • Time: Time of completion defaults to current time, but may be edited if displayed (On).
    • Time to Complete: Optional
    • Cost to Complete: Optional
    • Comments: Optional
  3. Click Save to save the settings.
  4. Select Back to return to the task display.

Supported browsers for the Task App:

  • iPhone iOS 7 Safari
  • Android with native browser
  • Windows Mobile with native IE
