Tag Associations

Tags may be associated with any System Model Object or be inherited. See Tag Inheritance for information on how to associate tags with Divisions, Facilities, Units, and POIs.

Tags should be applied at the highest system model object level with which they associate.  For example, if a tag is a property of the Facility, it should be applied at the Facility level rather than to each Unit underneath that Facility.

See Tag Schemes and Tags for information on how to create tag schemes and tags. 

Associate tags with requirements

  1. In the Applicable Requirements screen, find the requirement(s) you want to associate with a tag.

    Use the Requirements Search, if necessary, to find objects under different parent objects.

  2. Select the checkboxes for the requirement(s), right-click, and choose Properties > Edit.


  1. On the Edit page, scroll to the bottom of the form to the Relations section.

  2. Click Add in the Tags box.


The Tag Association window opens.
  1. In the Tag Association window, search for the Tag Scheme and select the tag you want to associate with the requirement.

  1. Click Select Tag. 
    The selected tag appears in the Tags box of the Edit Parameter Requirement screen.

 

If tags belong to the Tag Scheme with Track Value History property enabled, you need to enter Begin Date and, optionally, End Date. Click Update to save the formula value. The calculation value can only be used in other calculations from the Begin Date. 

  1. Click Save, then Confirm. 
    On the View/Edit Properties screen, see tags assigned to an object.

The syntax for requirement association via tags is {TagSchemeName}:{TagName}].

Remove a tag association from an object 

  1. From the Edit Properties screen, select the tag and click Delete.

  1. Click Save, then Confirm.
