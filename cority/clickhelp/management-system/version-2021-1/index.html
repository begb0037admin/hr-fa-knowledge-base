Version 2020.1.1, Released 04/09/2021 

New Features

  • The performance of creating and updating workflows has been improved.
  • The following new calculation functions have been added:
    • NEXT: Returns the next value for a parameter stored in the system.
    • PREVDATEDIFF: Returns the difference between a previous and current date. 
    • NEXTDATEDIFF: Returns the difference between the current and next date.
