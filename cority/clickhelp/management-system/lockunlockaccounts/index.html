Lock/Unlock Accounts

User accounts may be locked and unlocked automatically as a consequence of failed login attempts. The criteria for account lockout is configured in the Security Policies settings for the system. See Manage Security Policies.

A user account may also be locked or unlocked manually by editing the user profile.

To lock/unlock a user account:

  1. Open the user profile.
  2. In the Security Options section of the profile (below supplementary information), check/uncheck User’s account is locked.
  3. Click Save.

 You cannot lock an account for an access user (user granted access from another system). Instead, you may either revoke access or set the account to expire.
