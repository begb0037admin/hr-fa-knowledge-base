Version 2022.3  Release Date: November 22nd

New Features

  • On the Calculation Graph Visualizer, in Data view mode, once users have selected multiple requirements on a graph and clicked “Expand” to see a list of requirements with its locations, they can now export this list to an Excel sheet by clicking the Export button.

  • On the Calculation Graph Visualizer, when a requirement is selected, the property panel displays on the right and now provides requirement properties based on the system model
