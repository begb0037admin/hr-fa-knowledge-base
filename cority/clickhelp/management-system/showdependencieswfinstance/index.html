Show Dependencies for Workflow Instance

Dependencies for a workflow instance include:

  • Policies applied to the workflow (notifications)
  • Form templates used (to complete each step)
  • Roles associated with the workflow
  • Users and Groups associated with the Roles for this workflow instance

View dependencies for a workflow instance

In the Workflows page (Tasks and Workflows page), right click the workflow and choose Show Dependencies.

The workflow dependencies depend on the workflow type version in effect at the time the workflow instance was created. The role members for the workflow instance include the actual assignees to the workflow, in addition to the default role members.
