Version: 9.5.3 Released: 11/16/2020


This release focuses performance enhancements and bug fixes.


New Features and Improvements

  • On a workflow type, custom fields must now share the same value for each step. This will improve the process and performance for querying workflow data (including Portal panels), and reduces the overall effort required to build a workflow.
  • For a workflow type, you can now optimize up to three custom fields. This will allow for faster filtering and sorting.

General Improvements and Bug Fixes

  • MAIN-11673: On a workflow instance, users can now query a custom field using EQL directly from the 'WorkflowInstance' table. This eliminates the need for the additional JOIN to the 'WorkflowStep' table, and results in a significant improvement in performance.
  • MAIN-11780: For the UNION function, all queries will now complete as expected.
  • MAIN-12256: The performance of the 'Current Status' and 'Current Step' fields has been enhanced.
  • MAIN-12119: When using workflow aggregations in a requirement script, an alias will now display instead of a GUID.
  • MAIN-12118: The duplicate 'WorkflowInstanceValue' table has been removed.
  • MAIN-12342: Now when a custom field formula script is validated, the calculation can now be applied to multiple steps and form templates. To do this, the properties on each of the steps/templates must be the same.
