Management System - 2023.1 Release Notes

Release Date: March 17th

New Features

  • To ensure “/” or “%” is not used when naming a Workflow Step (as this is breaking the WAB), a warning message now displays "If you intend to use this WF type with the Workflow Application Builder (WAB) do not use these characters in the WF step name”.


Calc Graph Visualizer 2023.1

Release Date: March 24th (Tentative)

New Features

  • In the View Data Mode of the Calc Graph Visualizer, users can hover over a requirement for a lineage Tree option to appear. When the Lineage Tree option is clicked, users can view and trace a particular calculated value back to its source in combination with important metadata in the form of an excel document.

  • In the View Data Mode of the Calc Graph Visualizer, users can now export data directly into an excel format.
  • In the Calc Graph Visualizer, the Collapse ALL button and Expand ALL button have been add to the properties panel.
