Associate an Advanced Calculations (EMS) Data View to a Core (GX2) Layout 

You can associate a data view from Advanced Calculations (EMS) to a layout in Core (GX2). 

To associate a data view: 

  1. In Core (GX2), navigate to Administrator > Look-up Tables and search for the EMSRequirementsDataViewPerLayout table. 

  1. Choose a layout to associate the data view with.  

  1. Use the Data View Name field to select a data view from Advanced Calculations (EMS). 

  2. The selected Data View can then be added to the layout as a sublist.
