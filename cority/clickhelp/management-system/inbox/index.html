Inbox

The Message Inbox is used to display notifications sent to you concerning system activities, including task notifications and additional data warnings.

Notifications are commonly set up to be sent by email. However, in the event that you do not want to use email for notification, or when email is not available, notifications can be sent to your inbox. This must be configured on the task creation form for task notifications, or on the properties form for numeric requirements.

The Data Warnings section on the Messages page shows all data warnings for all objects for which you have data viewing permissions. The Inbox shows data warning messages for only specific Requirements where you have been chosen to receive notification.

To view messages in your Inbox:

  1. Select Inbox from the Messages tab.

    Your messages are displayed. The message summary shows the subject, date, sender and the objects with which the message is associated. You can sort by a column by selecting the column head.

    Use the Search pane to search for messages by specific criteria, including message type, subject, related object, sent by, and date sent.

    The envelope icon for each message indicates whether a message has been read or not. You can filter the messages by status using the status links (All | Unread | Read | Archived) at the top of the page.

  2. Select the link in the Subject column to read a message. Once you view a message, its status changes to Read. From the reading pane you may select Archive or Delete. Archived messages may be retrieved again later; deleted messages are deleted from the system.

    To archive or delete messages from the Inbox, select one or more messages, right click and choose Archive or Delete.

    To change the Read/Unread status of messages, right-click the message in the Inbox list and choose Change Read Status.
