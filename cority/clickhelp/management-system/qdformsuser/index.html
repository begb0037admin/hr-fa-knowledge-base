Data Forms

The Data Forms tab displays data entry forms that can be used to enter data and/or document events.

Depending on the configuration of the form, numeric data may be displayed in a numeric grid or line-by-line.

To enter data in the data grid and form:

  1. Select the Facility, then the Source from the dropdown lists.

    Enter a few characters to search and narrow the list. The full path is searched and a matching list is presented, with a maximum of 20 items at a time. Click More on the bottom to see additional items. To clear the search, click the X at the right.

  2. Select the date from the date selection field(s).

    Depending on the type of data and the setup, you may need to select month/year, year only, or a day/month/year. For an event log with the day/month/year selection, you have the option of setting the end date as well. Check the box next to the Instance End Date fields first to enable the fields.

    A form is displayed for data entry. If there is existing data for the selected date, it will be shown.

     You may expand or reduce the width of any column by drag-and-drop.

  3. For numeric data in the data grid, select a cell to enter data directly.

    You may also copy one or more cells from Excel and paste into the data grid. See To copy and paste data from Excel.

    Use the arrow or tab keys to move from one cell to the next in the data grid.

    When you select a cell for data entry, additional notes and validation messages may appear in the Column Settings section of the box to the right of the grid.

    If data quality fields are associated with a parameter, a Data Quality fields section will also appear in the box to the right of the grid. Click View to enter or edit data quality fields. See To add data quality information.

  4. Additional text information fields appear in a form below the grid. Complete these fields as appropriate.

  5. When you have completed the form, click Save.

    Quick Data will validate the data and inform you if any required fields are missing or entries are invalid. This may include adding required information for data quality fields. Invalid cells will be highlighted in yellow. An error message appears when the cursor is hovered over the cell. See To validate data.

    If save is successful, the status bar will show Successful in green. If the status is Failed, select the status message to show an error message. (The text in the Sent Data box is available to aid in debugging, if necessary.)

    To view any calculated data resulting from your data entry click Refresh once data has been saved successfully.

To copy and paste data from Excel:

  1. Select the data cells to copy in Excel and press Ctrl+C.

  2. Select the top, leftmost field in the data grid into which you want to copy data and press Ctrl+V.

    If you need to enter data quality information for any of the fields, select the cell for the data you need to document and click View. See To add data quality information.

  3. When you have completed the rest of the data form, click Save to validate the data.

To validate data:

Data that has been previously uploaded to the system (i.e., through web services data integration), can be reviewed, validated for completeness, then marked Complete in Quick Data Forms.

  1. Select the Facility and the Source from the dropdown lists.

  2. Select the Date from the date selection field(s).

    Data already in the system will be presented for review.

  3. Review and complete any additional form fields that are required.

  4. Click Save.

    Before saving, Quick Data validates the data. Cells that contain invalid or incomplete data will be highlighted in yellow. An error message appears when the cursor is hovered over the cell.

  5. Select a highlighted cell to edit it.

    If data quality fields are associated with the field, the View and Update buttons appear on the right. Click View to view and edit data quality fields.

  6. Enter data quality field values for the data point as needed. Click Update.

     Update validates and saves only the selected data point value and its corresponding data quality fields. The Save button validates and submits the values in the data grid and text form fields, but not data quality fields.

  7. After fixing any errors or missing data, click Save to validate and submit the rest of the data on the page.

    If save succeeds, the status bar will show Successful in green. If the status is Failed, select the status message to show an error message.

    After data is saved successfully, click Refresh to refresh the values from the database in order to show any calculated data values.

To add data quality information:

  1. Select the cell for the data point you want to document in the grid.

    The View and Update buttons appear in the box on the right if data quality fields are associated with the parameter.

  2. Click View.
  3. Enter the data quality field values for the data point as needed.
  4. Click Update.

 Update validates and saves only the selected data point value and its corresponding data quality fields. The Save button validates and submits the values in the data grid and text form fields, but not data quality fields.

To mark data complete:

Once all data has been validated by the system and reviewed appropriately, the data may be marked Complete. This action "locks" the data, so that no further editing may be done by end users from the Quick Data interface.

  1. Check that all data has been validated and saved.
  2. Select the Complete button.

  3. Click Save.

    If any data required to mark the source complete is missing, an error message will give the details. Fix any incomplete data and re-save.

 Users with View, Enter and Edit Data permission may change the Complete status to Yes and lock the data. An Admin user (one with full control over the facility and source or a member of the Administrators group), may revert the Complete status to No to re-enable editing from Quick Data. Data may be edited from the main app by any user with Enter/Edit Data permission, regardless of Complete status.
