Version 9.0 Released 3/13/2017

The Management System has been upgraded to HTML5 technology and now officially supports the following modern and secure browsers (with some minor exceptions in secondary extensions noted below):

  • Google Chrome
  • Apple Safari
  • Microsoft Edge
  • Microsoft Internet Explorer 11

Companies may now standardize on any of the browsers above or allow their users to choose their preferred browser. The re-designed UI allows easier navigation between EMS products, including navigating from Apps to the Management System using the same browser.

Exceptions:

A few Management System Extensions will only support IE11:

  • Bulk Tools (used by customers in Sandbox)
  • GHG Electronic Reporting
  • QuickData
  • TRI
  • Waste

Additionally, the color palette for the Management System has been modified to further standardize and simplify the user experience when working with any EMS product.

This release also includes EQL version 1.9.8, with features to support Portal updates.
