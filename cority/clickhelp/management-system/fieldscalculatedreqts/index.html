Field Definitions for Calculated Requirements

Periodicity in Calculated Requirements

Periodicity defines how often the requirement should be monitored or is applicable. The periodicity field for a calculated Requirement is similar to a Time-Based Calculated requirement (rather than Parameter or Variable). The periodicity is "every ___ interval," such as every 3 days, or every 1 month. This field is descriptive only and has no effect on the calculation.

The start time for Periodicity is based on the Calculation Begin Date.

Description

Description of the Calculated Requirement (what it measures or other information).

Unit of Measure (UOM)

The unit of measure for data entered for the requirement. Standard units of measure already in use in the system are available in the selection list. A new UOM may be entered in the text box provided.

Precision

Determines the number of places to the right of the decimal point that will be displayed when displaying data, both online and in reports when HTML or standard Excel is the output format. The values are rounded. However, the raw data is stored in the system and is used for all calculations, including the aggregate functions of a report. The raw data is also exported in an Excel template report.

Calculation Purpose

Description of the purpose of the calculation. Describe what you want to accomplish with this calculation.

Calculation Requirements 

The Requirements that are used in the calculation. Requirements under the same parent object automatically appear in the Calculation Requirements box and are available to use in the calculation. Numeric data located elsewhere in the system must be added to be used in the calculation definition.

Calculation UDF Parameters

The custom numeric and calculated fields available to be used in the calculation, derived from a calculation template applied to the immediate parent of the requirement. See Calculation Templates.

Tag Aggragation Settings

Determines where in the system the calculation searches hierarchy for applicable requirements to do the aggregation. See Tag Aggreration Settings, Search Tags Under.

Calculation Definition

The mathematical calculation, which can be defined through the expression builder. Numeric parameters, variables, and previously defined calculated parameters are available for reference in a calculation definition.

Calculation Begin/End Dates

The applicable dates for the calculation. These dates are used to track the history of the calculation if the calculation changes over time. Only the Calculation Begin Date is required when initially defining a new formula value. To create a new formula history, you must first edit the current formula history to add an End Date.

Calculation Errors Handling 

Can be used to define a value to be returned if the calculation produces an error.

Expected Frequency

Can be used to produce a data warning if expected data is missing. Most frequently used in conjunction with a continuous emission monitoring system or other backend integration, to warn of possible failures. The expected frequency is defined as the number of data points expected per day. A Begin Date must be set.

Limits

The Regulatory or Internal limits against which values can be compared. Data warnings are generated when limits of either kind are exceeded. The incidents and values can be used in deviation reports. See Setting Regulatory Limits.

Limit Begin/End Dates

Applicable dates for the limits. Limit history may be tracked historically if limits change. Setting Regulatory Limits.

Task Template

The Task Template to use to trigger a task when limits are exceeded (optional). See Task Template for Limit Exceedance.

Data Warning Notifications

Recipients for additional data warnings when limits are exceeded (in addition to default recipients who are all users with permissions on object). See Setting Regulatory Limits.

Documents

Links to documents stored in the Documents library that are associated with the requirement. For example, specifications or instructions. See Associating Documents.

Citations

Links to Citations associated with the requirement. See About Citations.

Tags

Tag Schemes and Tags associated with the requirement. See Tag Schemes and Tags.
