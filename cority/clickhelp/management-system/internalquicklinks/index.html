Internal Quick Links

The following steps to create an internal Quick Link apply to all types of links. The exact steps will vary according to the type of action involved in the link (i.e., data entry, workflow creation, etc.). Each type of action has its own filter criteria which may be pre-configured for the link. See table below the steps for the filter criteria that can be pre-configured for each action type.

The "Save as Quick Link" option is available on the Search bar while performing any of the related actions, such as when selecting criteria to enter data, creating a workflow type, etc. Clicking Save as Quick Link will lead to the Quick Link setup menu with the selected objects and filter criteria already selected. If you have the Manage Quick Links right, you will then be able to choose whether to save it as a personal or system Quick Link.

To create an internal Quick Link:

  1. From the menu, select Setup > QuickLinks.
  2. Select New Quick Link, or right click on the page and choose New.
  3. For the Link Destination, select "Within this Site".
  4. Select an Action from the dropdown menu.
  5. Click Continue.

  6. Enter a Name for the Quick Link.

    Since you are creating a shared link, the Create for Other Users option is selected.

  7. Steps are presented where you can pre-select the criteria, depending on the type of action. (See table below.)

    To select a filter criteria, uncheck the "Ask for this later" box, then select the criteria you want.

    To ignore a filter criteria, uncheck the "Ask for this later" box, and leave the filter blank.

    Leave the box checked if you want users to be able to select this filter criteria when executing the link.

  8. When you have finished configuring the Quick Link, click Save.

After creating a Quick Link, you must publish it in order to make it available to users. See Publish Quick Links.
