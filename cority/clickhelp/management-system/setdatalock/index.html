Set Data Lock

The Data Lock features allows administrators to limit the data entry window relative to the current date, thereby preventing data from being edited by users after a specified period of time.

For example, if you set the data lock to 30 days, users will be unable to enter or edit data with a date/time more than 30 days previous to the current date. This can be useful to prevent data changes after reports have been filed, for instance.

Data locks may be set on parent objects in the System Model, which then apply to all associated data entry objects. A Data Lock may also be applied to specific parameters and event logs.

To set a data lock on an object:

  1. Right click the object and choose Data > Lock.

  2. Click Add User or Add Group to choose users to add to the lock.

  3. From the selection window, select the users or groups to add by checking the boxes and click Select.

  4. Set the data lock options for the group:

    Enter the number of days previous to the current date to apply the lock.

    Check Apply to Children to apply the lock to all child objects.

  5. Click Save.
