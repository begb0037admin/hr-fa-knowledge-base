Version 2024.3

Release Date: Nov 1st

New Features

  • In the Setup menu, under the Libraries section, users can now add units of measures and associated conversion factors.
  • On the parameter’s settings, users can now turn on auto UOM conversion and define UOM parameters.

The current automated unit of measure conversion only supports simple conversion factors.
