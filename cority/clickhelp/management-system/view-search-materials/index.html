View and Search Materials

 To view Materials, users must have the Manage Materials and Activities user right.

To view existing Materials:

  1. From the menu, select Setup > Materials under Materials/Activities.

  2. Expand the search pane.

  3. To search for one or more materials by name, enter all or part of the name.

  4. To search for materials in a specific Material Group, select the group from the drop-down list.

  5. Click Search.
