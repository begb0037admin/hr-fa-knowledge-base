Version 2025.3

Release Date: November 7, 2025

New Features

  • In the Data Preparation tool, users can now connect large data sets to their own data lakes. In the Data View Library, the new 'Cloud Publish' status indicates that the data view is connected to cloud storage. The connection can be configured to transfer on a schedule.
  • For GX2 integrations, when a regulatory or internal limit is exceeded, you can now choose to automatically create an event in GX2 instead of an EMS task. A new ‘Data Sync’ log is available to view each event created from limit exceedance.
