View Task Documents

Documents may be associated with a task in order to be readily available to task assignees. The related documents box on the bottom of the Task Properties or Task Completion/Dismissal page shows any associated documents.

In order to view an associated document, you must have view permission for that document in the Documents library.

View a document associated with a task

Select the document in the Documents box and select Open.

A dialog appears asking whether you want to open or save the file.

How you view documents depends on the type of file and the file associations on your computer. Microsoft Word or Excel files can be opened directly with Word or Excel. Other types of files (such as drawings) may require you to launch the appropriate application. You can save a copy of a file to your computer, then open it with the appropriate application.

View a document directly

When you receive the message asking whether you want to open the file or save it to your computer, choose Open.

A temporary copy will open for viewing.

Save a copy to your computer

When you receive the message asking whether you want to open the file or save it to your computer, choose Save.

Choose a location to save it on your computer. You may then open the file from this location using the appropriate application.
