Material Data Lines and Data Batches

A data batch is a group of material data lines that share the same Complete Date. The Complete Date is the date/time at which the data is stored.

Each material data line has a Start Date and End Date. The End Time of each MDL will be used to determine the value to use for any script references (i.e., in formula-based properties of the materials). This includes parameters, standard calculations, system variables, value-based properties, and calculation UDFs . The End Date must be equal to or later than the Start Date.

The Completion Date may be before, after or within the time range of the MDLs.

For example, a month’s worth of data with daily values may have 30 material data lines. The material data lines have individual Start-End Dates at 12:00AM on each day of the month. The Complete Date may be on the last day of the month, the first day of the month, or at some date in the middle of the month for computational purposes. The Complete Date, which is the single aggregate value for the MAC, is the time at which any calcs dependent on the MAC will run.

If data will be entered by batch, it is important to understand how the aggregation is performed across the data lines. See MAC Aggregations in Formulas.

It is also important to understand the timing of data that may be required for calculation. Material formula-based properties that reference any external factors (system variables, parameters and standard calculation outputs) will need to find a value to use that matches the end date of the material data line (MDL). If all material data lines have the same end date, this does not present a problem. But in cases that require material data lines with separate date/time signatures, care needs to be taken to line up the data points required for calculation. The following graph shows a time scale with the essential points in time noted.

|____E1_______________________________| End Date of MDL 1

|_______________E2____________________| End Date of MDL 2

|___________________________E3________| End Date of MDL 3

|___________________________________C_| Complete Date of Batch

The Complete Date is the date/time of the MAC data point.

 The use of LAST should be avoided in MAC calculations, to avoid slowing down the calculation time. If the use of LAST cannot be avoided to ensure a datapoint at a specific time, it should be pre-calculated before the value is made available to the MAC.

A special variable, TimeSpan, is available for use in Material Activity calculations and Tertiary FBPs. The TimeSpan variable calculates the number of minutes between the Start Date and End Date for a data line. See Using TimeSpan in Material Activity Calculations.
