Version 2022.2  Release Date: July 15th

New Features

  • In the Management System, when editing form templates, administrators can now configure custom parent-child field relationships.
  • View Data mode has been added to the Calc Graph Visualizer. This will enable users to view data points for calculation parameters over a specified date range.
  • A date range selector is now provided. This enables users to trace the history of calculation definitions and examine data points.
