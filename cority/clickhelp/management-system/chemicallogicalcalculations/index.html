Chemical Logical Material Calculations

Chemical Logical Material Calculations are calculated properties of materials that are used for calculations involving chemicals, where it is desired to do the same calculation for each chemical component of a material. They enable doing automatic calculations for speciation, without having to create separate calculations for each component. The calculation "knows" what chemicals are in the material and automatically creates a version of itself for each.

Chemical Logical formulas can use both the specific and logical properties of chemicals, allowing you to produce logical aggregations of the chemicals in a material as well as chemical specific values. For an explanation of syntax and examples of usage in formulas, see Chemical Calculations.

Chemical Logical Material Calculations can be Primary, Secondary and Tertiary, just like regular material calcs, depending on what values they need in order to calculate. See these topics for a description of each type:
