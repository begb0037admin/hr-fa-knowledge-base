Version 2024.1

Release Date: March 18th 

 New Features

  • In the Management System, geographic coordinate fields have been added to the division level, and decimal degrees can now be inputted as a value in these fields.

The available coordinate input types are now decimal degrees, degrees/minutes/seconds, and UTM. Coordinates entered in any format will be converted and available in the other two formats.

  • When administrators are creating new user accounts on the user interface, a new option will be available to send the user a time-sensitive link through email instead of needing to set a password.
