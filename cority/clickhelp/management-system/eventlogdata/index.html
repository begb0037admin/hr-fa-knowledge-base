Event Log Data

Event Logs store data related to events that may be required for compliance reporting or for internal records. The types of data stored in Event Logs include:

  • Deviations caused by the exceedance of limits on numeric requirements. The event log is used to decide whether the exceedance is a true deviation or not and to record details that may be required for reporting or internal records.
  • Deviations caused by tasks completed with a compliance status of "Not determined." The event log is used to decide whether this is a valid deviation and to record details that may be required for reporting or internal records.
  • Information related to other reportable incidents, such as tracking of health and safety incidents.

Event Logs may be either Automatic or Manual.

Automatic Event Logs store data and supplementary information for deviations associated with one or more requirements. Events are automatically generated when data has a Not Determined compliance status. This can occur because:

  • The numeric limit set for a monitored requirement is exceeded.
  • A task associated with a requirement has compliance status of Not Determined.

Custom event fields allow you to enter supplemental information to document the event. Usually this is done via a task, where the fields needed to document the event are available in the task form. Event log records may also be edited manually if needed.

Manual Event Logs store non-deviation information about a requirement, such as a log of health and safety incidents or a required activity log.

New log entries for a manual event log can be created as needed. If followup is required, a task may be associated with the creation of a new log entry. The fields needed to document the event will then be available in the task form.
