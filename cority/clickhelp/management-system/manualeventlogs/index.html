Manual Event Logs

Manual event logs are typically associated with non-numeric requirements and are used for purposes such as documenting health and safety incidents, or maintaining an activity log.

The event log may have an automated task associated with it, so that when an event is created, the task assignee is responsible for completing the data required to document the event (such as a safety incident). In other cases, where no follow-up is necessary, the creation of the event itself may be sufficient to fulfill the requirement and no task is necessary (such as indicating that a required inspection was performed).

Example 1: Manual Event with No Task

The requirement to perform a weekly or monthly inspection and maintain an inspection log is represented in the system by a non-numeric requirement. An event log called the Inspection Log is associated with this requirement. When an inspection occurs, the user creates an instance in the Inspection Log and enters the relevant information pertaining to the inspection directly in the log.

Example 2: Manual Event with Automated Task

The requirement to log all health and safety incidents is represented in the system by a non-numeric requirement. An event log called the Incident Log is associated with this requirement. The Incident Log has an associated task, called Incident Resolution. When a real-life incident occurs, the supervisor or other responsible person enters the event in the system with the initial details of the incident. The system then automatically generates the Incident Resolution task, and sends it to a task assignee, who is responsible for completing the documentation of the incident by providing the resolution details for the Incident Log.
