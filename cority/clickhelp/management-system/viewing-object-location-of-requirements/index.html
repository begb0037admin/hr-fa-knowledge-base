Viewing Object Location of Requirements

The Object Location function provides users information of the source location of a requirement.

The “Current Object Location” will provide information on the requirement a user has selected, this will have a blue outline around it. The “Other location” will provide information on a requirement that the user hovers over that is not selected.

To view Object location of a Requirement

  1. On the Calc Graph Visualizer window, under View Settings, click the Object Location checkbox. A checkmark will display in the checkbox.
  2. To view location details of a requirement in the Current Object Location section, click a requirement, and ensure a blue outline is around the requirement in the graph.
  3. To view location details of a requirement in the Other Location section, hover over a requirement in the graph.


  4. To view the object locations of multiple requirements, ensure that the “Data View” mode is turned on, and then click the Expand icon.


    1. To export the List of multiple selected requirements to an Excel sheet, click on the checkbox beside each requirement, and click the Export button.

    2. To hide the list of multiple selected requirements in the Current Object Location section, click the Hide icon.
