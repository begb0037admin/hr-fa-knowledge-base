Workflow Versions

When you edit a workflow type you can choose to update the current version or create a new version of the workflow. However, if there are existing instances for the workflow, you will be required to create a new version.

Editing a workflow type does not affect existing instances of a workflow, which use the version in effect at the time the instance was created.

To view different versions of a Workflow Type:

  1. In Workflow Type Manager, right click the workflow and choose Versions.
  2. Select the version you want to view, right click and choose Open.

To revert to a previous version of a Workflow Type.

  1. In Workflow Type Manager, right click the workflow and choose Versions.
  2. Select the version you want to view, right click and choose Revert to Version.
