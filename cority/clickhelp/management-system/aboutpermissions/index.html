About Permissions

Permissions are used to control access to system model objects and to the documents, reports and citations that are associated with them.

The difference between user rights and permissions can be summed as follows:

User Rights grant global control over certain parts of the application, such as Documents or Reports. A user with the Manage Documents user right has full control over all documents stored in the system.

Permissions grant specific access to objects in the system. Thus users may be granted permissions to view or modify only the requirements in the Requirements tree that they need to work with. Additionally, users may be granted permissions to view or modify associated documents and citations, and to run related reports.

The following types of permissions may be assigned to users in the system:

System Model Object Permissions

Document Permissions

Report Permissions

Citation Permissions

Dashboard Permissions

System Model Object permissions should be coordinated with the permissions granted to documents, reports, and citations, so that users have access to the items associated with the objects, as necessary.

In general, permissions are best managed utilizing parent-child relationships in the tree and user groups. However, it is also possible to grant individual user permissions to specific items.

 All rights and permissions are additive. Users who belong to different groups with different sets of rights and permission will get the combination of all rights and permissions associated with those groups. The exception is the No Access permission, which overrides any other permissions granted.
