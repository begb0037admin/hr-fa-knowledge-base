Edit User Profiles

From the user profile you can edit a user name or password, user's time zone, email, or any of the supplementary information. You can also edit user group membership and grant rights individually to the user.

To edit a user profile:

  1. From the menu, select Setup > Users (in the Security group).

  2. Browse or search to find the user if necessary, then select the user by clicking the user name.

    Or, right click the user name and select Edit.

    In the user profile edit the fields in the profile as desired.

    The groups to which the user belongs are shown in the User Groups section at the bottom of the profile page.

    To add the user to a user group: Click Add and select the user group from the selection window.

    To remove the user from a group: Select the group in the box and click Remove.

    To grant individual rights to the individual: Check the boxes for the rights to assign. However, it is preferable to manage user rights through an appropriate user group. Any rights granted in the user profile will be in addition to the rights granted to the groups to which the user belongs.

  3. Click Save to save changes.
