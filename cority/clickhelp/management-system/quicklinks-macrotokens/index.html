Quick Links Macro Tokens

The following replaceable macro tokens may be used in an external Quick Link URL:

{login}

Is replaced with the login of the user. Example: http://sap.mycompany.com/tasklist.aspx?user={login}

{sessionid}

Is replaced with the current session id. Example: https://my.enviance.com/authentication/passthrough.aspx?sessionid={sessionid}

{systemid}

Is replaced with the current session’s active system id. Example: https://www.enviance.com/usergroup/loginpage.aspx?systemid={systemid}

{homesystemid}

Is replaced with the current session’s home system id. Example: https://www.enviance.com/usergroup/loginpage.aspx?systemid={homesystemid}
