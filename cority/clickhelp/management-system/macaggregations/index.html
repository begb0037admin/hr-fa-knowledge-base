MAC Aggregations in Formulas

When creating the formula for a Material Activity calculation, you must choose an aggregation type. Aggregation types include SUM, AVG, VAR, and STDEV.

It is important to understand how the aggregation works across multiple data lines in a data batch to ensure that the result is as expected. The following example illustrates the aggregation:

A MAC uses 3 variables in its calculation: A, B and C.

The MAC calculation script is (A*B*C) and the selected aggregation is SUM, so the actual MAC calculation is:

SUM(A*B*C)

If there are two data lines in the batch, the result of this calculation will be:

(A*B*C) + (A*B*C)

  A B C

(A*B*C)
MDL1 2 3 4 24
MDL2 2 4 5 40
SUM(A*B*C)       64

The MAC formula runs first across for each material data line (left to right as shown in the grid), then the aggregation is run over all data lines (top to bottom). If the selected aggregation is AVG, the result is AVG(A*B*C) or 32.

In cases where there are multiple data lines and each data line produces the same value, and you only want one of those values, use AVG. For example, if you want to get a temperature value where the temperature is constant for all data lines.
