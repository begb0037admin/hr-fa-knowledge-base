Form Field Validations

Form Templates allow for optional validations for each custom field. For example, required fields may be specified, or numeric fields may be given a valid range.

The validation types available depend on the type of custom field:

 The Regular Expression validation is available only for text fields and can be used for complex validations such as email or phone formats. For guidance on syntax, see reference material for the .NET framework implementation of regular expressions (available in the MSDN online library).

You can choose whether to apply the validation when a user attempts to saves a workflow step, or when a user attempts to transition the workflow.

To apply a validation type to a field:

  1. In edit mode on the form template, select the field in the list box.

    The possible validation types are shown below the fields list box.

  2. Select the validations to apply, and check when the validation should be applied: when saving, when transitioning, or both.

    Enter a value if the validation type requires it.
