Refine Results by Filtering

You can further refine results by filtering on property values for selected objects.

To refine results by filtering on property values:

  1. Click Add to choose a property the filter on.

  2. From the selection window, select one or more properties and click Associate.
  3. Choose an operator (>, <, =, etc.) for each and the value to filter by for each property selected

  4. Select the logical operator AND or OR.

    Only one logical operator may be used in the report criteria. You cannot combine AND and OR filters.

    Boolean Fields: To filter on a Boolean value (true/false checkbox), use "1" for true (checked), and "0" for false (unchecked).

    Text Fields: Use asterisk(s) as a wildcard for matches on text fields, as follows:

    word* = begins with "word"

    *word = ends with "word"

    *word* = includes "word"

    Do not use quotes around search text. Text search is not case-sensitive.

To delete a property filter, check the Select box and click Delete.

Change a selected property

  1. Click on the property name.

    The selection window will appear.

  2. Select the property to substitue and click Associate.

    The selected property replaces the old one in the list.
