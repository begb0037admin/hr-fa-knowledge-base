Create Apps

An App is a collection of files that define a custom interface. Files may include HTML, CSS, scripts, images, etc. The files that will be used in the custom UI are developed outside of the application and are then zipped and uploaded. Once uploaded, the App is configured for display in Advanced Calculations (EMS).

 To upload or edit an App package you must have the Manage Apps right. Additionally, Apps management must be enabled for your System. It is possible to have Apps configured for your system, but not managed from the system. To enable display of custom tabs and set permissions by users or groups, you must have the Manage Main Menu right.

You can also create an empty App to generate an app ID to use in the development phase, if necessary. If you are developing an App to be hosted on another server, you will need an app ID to call the Cority APIs.

To upload a new App:

  1. Create a zip file containing all the files that define your App. (You may use any folder structure for the files.)
  2. In the platform, from the menu, select Setup > Cority Apps.
  3. Select Upload New Cority EMS App.
  4. Click Browse and select the zip file from your computer or network.
  5. Select Upload.  
  6. After the file is uploaded, the New App page is displayed. The General tab shows the following options:
    • Name: Required.
    • Icon: Optional. The icon will be used in the main menu overflow (a menu that is shown when there are more tabs than fit across the screen).
    • Description: Optional. Shown only in the Apps Manager.
    • Display Page: Required. The display page is the page that displays when the App is opened by users.
  7. Select the Role Membership tab to view Roles used in the App.
    You can associate users or groups with the Roles when it is ready to test or release
  8. The Permissions and Security Policies tabs are primarily for developer use.
    Permissions and Security Policies are defined in the App and are not editable from the interface. For more information, see the Apps SDK documentation.
  9. Click Save and Confirm to save the App.

To make the App available to users it must be mapped to a page and enabled for display to selected users or groups in Main Menu Manager.

You can preview the App in the App Manager. Right click the App and select Run.

You can also run the App in App View mode by clicking the Run button.

 An App package usually contains a manifest.xml file (not required but recommended), which may be used to define default settings, roles, various permissions, and content security options.

Copy App

You can copy an App package to create a new App with the same content and configuration. After copying (provided the App is not locked), you can edit it to change settings.

Advanced Workflows packages should be locked and unable to copy. If you would like to copy an Advanced Workflows App, please contact Cority Support. 

To copy a package:

  1. In the Apps Manager, right click the package and choose Copy.
  2. Enter a new name and click Save.

 If the App copied is locked in the database, the new App will also be locked. It must be unlocked to edit it. For security reasons, locking or unlocking an App may not be done from the interface. Contact your Cority representative to lock or unlock Apps.

To create an empty App:

  1. Select Create Empty Cority EMS App.

  2. Enter a name and optional description.

    The app ID is shown as part of the Link URL on the General tab. You can copy this ID to use in App development. One index file is created as an empty .htm file, which may be edited or replaced in development.

  3. Click Save and Confirm.

For documentation on the SDK, JavaScript SDK and REST APIs, see App SDK Help.
