Form Templates

Form Templates define the forms that are used for completing workflow steps. Before creating the steps for a workflow type, you will need to create the forms to associate with each step.

Creating Form Templates is similar to creating other types of custom field templates. Form Templates may use most custom field types, including calculated fields. (Exceptions are Predefined fields, Number - ID Control, and Unique Tag.)

Form Templates also allow for optional validations for each custom field. For example, fields may be designated as Required, or a numeric field may have a specified valid range.

To view Form Templates:

  1. From the menu, select Setup > Form under Templates.
    The Form Templates are displayed. The # Ref column indicates the number of workflow types that use that template. You can search for template in the Search pane by name (full or partial string) and date created.
  2. To view the fields on a Form Template, right click the template and select View.
    The custom fields applied to the form template are listed. The Validation column shows any validations that have been applied to a field.
  3. To view the formula for a calculated field, click the View link for the field.
  4. Right click the template in the list and choose Show Dependencies.
  5. Dependencies include:
    1. The workflow types that use the template.
    2. The custom fields included on the template.
