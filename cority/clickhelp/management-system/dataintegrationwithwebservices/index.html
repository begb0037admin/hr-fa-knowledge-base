Data Integration with Web Services

The APIs can be accessed by any application that can send data to Web Services (APIs). If your company already uses another third-party application to send data to Web Services, you can leverage the same infrastructure to send data to Advanced Calculations (EMS).

If your company does not have an infrastructure or the IT staff does not have the resources to work on the project, then Cority provides an easy-to-install application called EIFL for sending data to Advanced Calculations (EMS).

Web Services are the key to the integration solution, whether you use EIFL or a custom solution. The Advanced Calculations (EMS) Web Services are a programming interface (API) to the Management System. They provide a very robust, scalable, and secure (SSL) way to interact with the Management System from another program. With these APIs you can:

  • Integrate to your internal data systems with Advanced Calculations (EMS).
  • Extract data for use with external reporting tools.
  • Integrate data into your organization’s portal.

Integration with Advanced Calculations (EMS) can be accomplished at varying levels of customization, as needed.

Low: In this scenario, the customer uses the standard EIFL Connector package, with supported file types and column structure. Existing web services are used.

Medium: In this scenario, the customer works with the system to leverage existing EIFL Connector capabilities but requires custom input file formats, such as non-standard file types, transformation of columns, rows or generating tags. Existing web services are used.

High: In this scenario, the customer requires custom enhancements such as:

  • Custom rules for interpreting and manipulating the input file
  • New input file type or format
  • New web services (APIs)

If you are already using Web Services to integrate with other systems, you can request a technical description of the Advanced Calculations (EMS) Web Services APIs. If you are not already sending Web Service data to other locations, Cority strongly recommends you use EIFL.
