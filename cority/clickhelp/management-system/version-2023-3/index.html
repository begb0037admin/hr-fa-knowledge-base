Version 2023.3 Release Date: Nov 3rd

New Features

  • Now EMS will be able to utilize time-sensitive links to reset the users' forgotten passwords or create new user login through Bulk Tools.
  • Users can now launch Bulk Tools as an app in EMS, instead of a separate URL. This will first be available only in the sandbox environment but will eventually be available to customers in production.

  • Users will now be able to push aggregated data from EMS Requirements to GX2 metrics.
