Add New Documents

Users who have Edit permissions on a document folder may add new documents to that folder from the System Model page.

 Uploaded documents are limited to 200 MB.

To add new documents:

  1. Select the Documents folder to which you want to add the document.

  2. Select Add Document.

    Or, right click the document folder on the tree and choose New > Document.

     If you do not have Edit permissions on the folder, the Add Document link will not be enabled. If the menu option is not enabled, you only have View permissions on the current folder.

    The new document form is displayed.

  3. Choose whether you want to upload a file or link to a file or web page.

    Upload a file:

    Select Browse. Find and select the document on your computer or local network. Maximum allowed file size is 200 MB.

    The file name and extension will by displayed by default as the Name. You may change the name if you wish. Document name limit is 255 characters.

     The file extension is optional. Usually the content type or mime type is sufficient to identify it for opening with the appropriate application, but you may need to include the extension for rare types.

    Link to a file or web page:

    Enter or copy and paste the URL in the web address box. Then enter a name for the file or page.

    Optional information includes:

    Document Description: The field appears in the Documents list, so it may help identify the contents for users when browsing or searching. This is also a searchable field, so you may use key words for search purposes in the description. The field applies to all versions of the document.

    Version Comments: Applies only to a specific document version. This field can be used to help identify different versions or to note changes when you update documents in the system.

  4. Select Save.

 Uploaded documents are scanned for viruses when they are uploaded. If a virus is detected, the document will be automatically deleted from the system.
