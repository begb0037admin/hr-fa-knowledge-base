Grant System Access to External Users

You can grant access to the system for users from other Advanced Calculations (EMS) customer systems. The user profile must already exist in another customer system, and you must know the user name assigned in the home system to grant access.

After granting access, you can assign the user to a user group or grant individual user rights and permissions.

If desired, you can set an expiration date for system access for an external user in the user profile.

 External users granted access to the system are licensed through their home system and do not count as licenses in your system.

To see access users in the user list, check the "Access users" option in the search pane and click Search. The Home System for the user is shown in the last column.

To grant access to external users, you must have the Manage Access right, or be a member of the Administrators group.

To grant access to the system to a user from another system:

  1. From the menu, select Setup > Users (in the Security group).

  2. Select New User Access or right-click anywhere in the user table and select New Access.

  3. In the Add User page, enter the username of the person you want to grant access to. This must be the same username used in the user’s home system.

  4. Click Grant Access.

  5. Confirm by clicking Grant Access again.

    Optionally, you can set an Expiration date and add Comments.

    The user profile page appears. The user information is initially the same as that in the user’s home system. However, user profile details may be edited for this system.

    To grant individual user rights to this user, select the user rights to assign. Or, after saving, add the user to a user group that has the appropriate user rights and object permissions. See Manage User Groups.

    For a description of user rights, see User Rights.

     User rights assigned individually are in addition to any rights granted to the user through their assigned user groups.

  6. Click Save to save the new access user in the system.
