Material Formula Based Properties

Material Formula Based properties (Material FBPs) are calculated properties of materials. There are Primary, Secondary and Tertiary formula-based properties, defined by when they can be calculated and the types of values they can use in their formulas.

  • Primary FBPs and CLFBPs can be calculated based solely on the material’s composition and its basic properties, without reference to its usage. The values are calculated in the system when the material is created and the value is stored with the material.
  • Secondary FBPs and CLFBPs can be calculated when it is known where the material is used. The calculation may be dependent on such factors as annual temperature data for the location, or equipment specifications that are stored on a calculation template associated with the system object that represents the equipment.
  • Tertiary FBPs and CLFBPs can only be calculated when a data point is entered. The calculation may depend on inputs such as how much material was used, how long a piece of equipment was run, or monthly temperature data. They may also need to find a value for a local variable for which a data timestamp is required.

The "simple calc versions" (FBPs) create a single value, which is an aggregate of all the chemicals in the material. The "chemical logical" versions of these property (CLFBPs) can create separate calculated values for each chemical in the material, each of which can be accessed in other calculations.

Example of Material FBP

A standard Formula Based Primary property may be expressed as:

[ChemExp_Bz_MW]*[ChemExp_BZ_AvgConc]

which yields a calculated result for one specific named chemical using the chemical specific property reference.

Or, it may have an aggregate formula, expressed as:

SUM([Chem_MW]*[Chem_AvgConc])

which results in a single calculated result that is an aggregate of all the chemicals in the material.

With either formula, only one value is returned.

A Chemical Logical Formula Based Primary property may be expressed in a third manner, without an aggregation:

[Chem_MW]*[Chem_AvgConc]

which results in multiple calculated results, one for each chemical in the material. So if the material has 3 chemicals there will be 3 values; if it has 10 chemicals, there will be 10 values. Each of these may be retrieved individually using the syntax:

[PropExp_<PropertyName>:<ChemicalName>]

See Chemical Calculations for a more complete example.

Material formula based properties are created and managed from Material/Activity Field Library. The calculation for a formula based property is defined when it is created, and the formula is the same for all materials to which the property is applied. New historical values may be created by editing the property.
