Version 9.2 Released 7/24/2017

New Features & Improvements

  • Workflow Query Performance

    The performance speed when querying for workflows has been improved substantially. As a result, Apps and the tables and charts in the Portal will load much faster. The workflows list in the Management System will also load faster.

  • Hierarchy Permissions Performance

    The process of evaluating of user permissions for Locations & Programs in the system model has been made faster. As a result, users with limited permissions (i.e. non-administrators) will see performance gains across the system, including when using the Portal and Apps.

  • Updated Task Email Notifications:

    The default email format for task notifications has a new, modernized look and feel. The task name is visually emphasized within the message, the View Task link has been change to a button, and a hyperlink lets users add the task to their local calendar (i.e., Outlook Calendar).

  • New REST APIs:

    Workflow Type Management

    Workflow Role Management

    Bulk Workflow Creation

    Support for Workflow Tab added to Task REST API

General Improvements and Bug Fixes:

  • MAIN-65 – Improved visibility of inactive indicators in Locations and Programs hierarchy
  • MAIN-66 – Improved clarity of messages for deleted tasks, with new subject line and message
