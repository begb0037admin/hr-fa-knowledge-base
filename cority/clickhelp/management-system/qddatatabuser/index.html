Data Tab

On the Data tab, you can enter monthly, quarterly or yearly data. Once data entry is complete or has been validated, it can be locked so that further editing from the Quick Data interface is disabled.

The facilities and data sources to which you have access are listed in the Facility and Source dropdown lists. The Previous column (read only) shows prior data for each parameter. You can choose whether to show comparison data for the Previous Period or Previous Year's Month. Previous data values are shown for information only.

  • Previous Period shows the last data entry for the parameter (previous month, quarter or year, depending on the frequency of data entry).
  • Previous Year's Month shows the data for the same month last year. In the case of yearly data entry, this is the same as the Previous Period.

To enter data:

  1. Select the Facility, then the Source from the dropdown lists.

    To search and narrow the list, enter a few characters. A list of matches will be displayed, with a maximum of 20 items at a time. Click "More" on the bottom to see additional items if necessary. To clear the search, click the X at the right.

    The parameters for data entry are displayed.

  2. Select the year for data entry.

  3. Select the month (for monthly data entry) or the quarter (for quarterly data entry).

    For annual data entry, the month will correspond with the end of the fiscal year, as configured.

    For quarterly data entry, the quarter selection will display the appropriate month for data entry, depending on the fiscal year and first quarter selected in the configuration.

    To change the fiscal year, see Fiscal Year and Quarter Configuration.

  4. Enter data in the available entry boxes.
  5. Click Save.

To view any calculated data resulting from the data entry, click Refresh.

 Null values are ignored. Therefore, if you delete a data value in Quick Data and save, existing data will not be deleted from the database. Existing data can only be deleted from the main application.

You can use the Conversion Calculator to convert values to a different unit of measure. See To use the conversion calculator.

Optionally, you may:

  • Enter comments in the Comments box.
  • Lock data by checking the lock checkbox.

 After the lock box is checked and data is saved, no further editing will be possible from the Quick Data interface. For more information, see To lock data.

To use the conversion calculator:

  1. First, place the cursor in the box in which you want to enter data.
  2. Click the Conversion Calculator link.

  3. In the popup box, enter the input value.

    Select the Unit From and Unit To values from the dropdown lists.

    The Result shows the converted value. The field to which the value will be applied is highlighted in yellow.

  4. Click Update Data Field.

    The result of the conversion is applied to the data entry field and the conversion calculator closes.

Lock data

The lock checkbox on the data entry page may be used to lock data once data entry is complete, or after it has been validated.

  1. Select the month and year to display the data for the selected period.
  2. Check that the displayed data as entered is correct.
  3. Check the "lock" box at the bottom.
  4. Click Save.

Once the data set has been locked, it may not be edited from the Quick Data interface. If necessary, the data may be unlocked and edited from the Management System.
