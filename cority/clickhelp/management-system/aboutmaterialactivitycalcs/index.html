About Material Activity Calculations

Material Activity Calculations are used for many purposes where values must be calculated based on the properties of different materials that are used in a common activity. Some common examples of Material Activity Calculations are:

  • Determining the emissions from a process that uses one or more materials, such as a coating process.
  • Evaluating emissions resulting from changing conditions and activities (such as temperature, flow, duration of activity, etc.).
  • Creating multimedia calculations for routine operation and maintenance activities.
  • Monitoring emissions from flares (intermittent operations and multiple sources).
  • Calculating emissions from storage tanks.

A Material Activity Calculation is the result of one or more materials used in a single Activity (or process). Before creating Material Activity Calculations you will need to create several components. At a minimum, you will need:

  • One or more chemicals. At least one is required for each material.
  • One or more materials, with associated chemicals.
  • One or more Specific Use Variables for data entry.
  • An Activity, with at least one associated Specific Use Variable.

Optional components include various types of material properties (value-based and formula-based) which can be used to perform intermediary material calculations.
