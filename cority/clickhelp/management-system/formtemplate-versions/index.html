Versioning of Form Templates

When editing a form template, you may choose whether to create a new version or update the existing version.

If you choose to update the current version, the changes will automatically be applied to new workflow instances.

If you choose to create a new version, you will need to apply the new form template version to the associated workflow type(s) in order to apply the changes to new workflow instances. Edit the workflow type(s) using the form template and re-select the template for each step in which it is used.

If you have used the App Form Designer to design custom forms for an App that uses the workflow, you will need to copy the previous version of the form in Forms Designer to avoid losing any customizations you may have done for the form user interface.

To view current version of a form template:

  1. Right click the template in the list and choose Versions.

    The versions of the template are listed, with the most current first (marked with an asterisk).

    To view a previous version, right click the version and choose Open.

    To revert to a previous version, right click the version and choose Revert. A new version will be created as a copy.
