Delete and Restore Users

To prevent further access to the system, you may mark a user deleted from the system. When users are marked deleted, the account is locked and access is denied.

The user will no longer be visible as a member of any groups and all system mail is blocked to the user. The user will no longer be available for task assignment. However, marking a user as deleted does not remove any existing task assignments or other associations (including permissions). This allows reports to show historical information associated with the user.

A user who has been "Marked as Deleted" may be restored later. If you restore a deleted user, all group memberships, rights and permissions, and task assignments are restored.

To delete a user from the system:

  1. From the menu, select Setup >Users (in the Security group).

  2. Right click the user name in the user list and select Mark as Deleted.

    The user’s access is immediately frozen.

To see deleted users in the user list, Deleted/expired users must be checked in the Show options in the search pane. In the user list display, the Status column shows Deleted and information is in red.

To restore a deleted user:

  1. To display the user for editing, check the "Deleted/expired users" option in the Search pane and click Search. (Uncheck the other boxes to filter for only deleted/expired users.)

  2. Right click the user name and select Restore.
