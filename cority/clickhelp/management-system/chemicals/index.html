Chemicals

The chemicals stored in the system are used to define the properties of the materials that will be used in Material Activity Calculations. A list of standard chemicals are supplied in the system. Standard chemicals may not be edited. You copy standard chemicals to make custom chemicals you can edit, and can create new custom chemicals, directly in the system or by import.

 To view Chemicals, users must have the Manage Materials and Activities user right.

To view chemicals:

  1. From the menu, select Setup > Chemicals under Materials/Activities.
    The Type column indicates whether the chemical is standard or custom.
  2. Expand the search pane.
  3. To filter for custom chemicals, check Show Only Custom Chemicals and click Search.
  4. Enter either CAS number, name or alias and click Search.
    You can search by partial string value in any field.
