Citation Permissions

Citation permissions control read and write permissions granted to users for the citations in the Citations library. Citation permissions are in addition to the permissions granted to users for system objects.

In addition to Administrators, users with the Manage Citations right may set permissions on citations. (See User Rights.)

Within the Citations library, permissions can be assigned in the most efficient manner by applying them to folders. However, you can also assign permissions to individual citations if necessary.

Citation permissions include both View and Modify permissions.

Users with View permissions on a folder and the citations it contains can:

  • View citation properties.
  • View requirements associated with citations (Show Dependencies).

In addition to the above, users with Modify permissions on a folder and the citations it contains can:

  • Edit a citation, thereby creating a new version.
  • Create new citations.
  • Create subfolders.
  • Copy or delete a citation or subfolder.
  • Associate citations with requirements.

You can add, delete or modify permissions on any citation folder. When you add a new user/group, you may choose whether to apply folder permissions to all reports and subfolders or not.

View and Modify permissions on reports are best granted through folders. However, you can also assign permissions to individual citations. By default, new or copied citations inherit the permissions set on the parent folder.

 Permissions can be applied or reapplied at the folder level. However the permission settings are saved with each citation. Therefore, when new users/groups are added to the permissions on a folder, you must use Apply to Children to grant access to the existing citations.

The Manage Citations user right is required to view citation permissions.

View permissions on a citation folder or citation

You can open the Permissions Editor by one of the following means:

  • In the Citations library, select Current Folder Permissions (to view permissions for the currently selected folder.

  • Right click a folder or citation and choose Permissions.

The Permissions Editor shows groups and users with permissions on the folder or citation and the permissions granted to each.

Set permissions on a citation folder or citation

  1. Click Add User or Add Group.

  2. From the selection window, select the users or groups to add by checking the boxes and click Select.

    The users/groups are added to the permissions list. Next, select the permissions to grant.

  3. With the Select box checked for the new users/groups, click Edit.

  4. From the popup box, select the permissions you want to grant, then click OK:

    View: Users may view folder contents, view properties of citations, and view associated requirements.

    Modify: Users may add new citations, create subfolders, and copy subfolders and citations within the folder. Users may also modify citations in the folder, manage versions, and associate citations with requirements.

  5. To extend the same permissions to all child folders and citations, check Apply to Children.

    Permissions are inherited by default only when a folder or citation is created. To grant new users permission to existing citations and folders, the change must be applied to children.

  6. Click Save.

Delete permissions for a user or group

  1. Check the Select box for the user or group.

  2. Click Delete.

    The permissions are removed and the Permissions column is now blank for the user. However, you must also save the changes.

  3. Check Apply to Children to delete user permissions to all existing citations and subfolders.

    If you do not check Apply to Children, the user’s permissions on all existing citations and subfolders will be retained. The changes will only apply to new citations that will inherit the new permissions.

  4. Click Save.
