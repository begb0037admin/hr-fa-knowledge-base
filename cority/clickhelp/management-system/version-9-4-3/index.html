Version 9.4.3 Released: 9/17/2018

New expanded permissions for better management of objects and documents:

  • Locations and Programs: Create and Edit Objects permission allows users to modify objects in the hierarchy while preventing the user from deleting those objects.
  • Documents: Add and Edit permission allows users to add and edit documents and document versions while preventing the ability to delete those documents. Delete permission can be assigned independently.
  • Documents: Permissions inheritance simplifies document permissions by allowing document folders to inherit their permissions from parent folders.

Bug Fixes

  • MAIN-8173 Documents: Increased max single document file size to 200 MB
  • MAIN-5077 Documents: Increased document name character limit to 255 characters
  • MAIN-8958 Task-Workflows: Allow users to reschedule tasks without delete permissions on the workflow type.
  • MAIN-9021 Task-Workflows: Allow triggering for a TAL (Time After Last Completion) scheduled task-workflow without create permissions on the workflow type
  • MAIN-3646 Task-Workflows: Automatically delete associated workflows when the triggering task is deleted
  • MAIN-8936 Task-Workflows: Workflows will now re-trigger when the Time to Create value is modified for By Due Date schedules
  • MAIN-8534 Workflows: Allow parent workflows to be closed and child workflows to remain open. Allow child workflows to be due after the due date of the parent workflow.
  • MAIN-8790 Workflow Notifications: Addressed issue where notifications would not be sent if certain fields were not populated
  • MAIN-8582 EQL: Added support for fields found on calculation templates
  • MAIN-8096 Materials: Clarified boundaries of support for some functions inside Calculation Visualizer
  • MAIN-8932 Materials: Addressed issue where show/hide of calculation sub-tree did not work properly in UI
  • MAIN-5067 Materials: Dropdown lists in Materials Calculation Visualizer page are now sorted alphabetically.
