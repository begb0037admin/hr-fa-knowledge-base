Manage Users

The following types of users may view, create, and edit users and manage user rights:

  • Users who have been granted the Manage Users right, or belong to a user group that has this right.
  • Members of the Administrators group or the System Owner.

To view users in the system:

  • From the menu, select Setup > Users (in the Security group).

    Sort the user list by any column by clicking the column head. Click again to change from ascending to descending.

    Select a page number to go directly to a page, or increase the number of results per page to view more results.

    Click the plus sign (+) in the Search bar to search for users.

Show options can be used to show or hide the following types of users:

Deleted/expired users are users or users whose access has expired. See Delete/Restore Users.

Access users are users whose accounts were created in other systems, and who have been granted access to this system. See Grant System Access to External Users.

Home users are users whose accounts were created in this system.
