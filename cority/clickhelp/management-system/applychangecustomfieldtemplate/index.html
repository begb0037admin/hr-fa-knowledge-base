Apply or Change Custom Field Template

A Custom Field Template may be applied to any System Model (tree) object or to any Requirement. The template may be applied at creation. It may also be applied to existing objects, either singly or in bulk.

 To add new fields to the existing Custom Template, edit the existing template instead of applying a new template. When new fields are added to an existing Custom Field Template, those fields will appear on all objects to which the template applies.

After adding or changing a the template, you may also use the bulk edit feature to edit the field values for the objects, if you want to apply the same value to all.

To apply a Custom Field Template when creating an object:

  1. Select the Custom Field Template from the list which is presented as the first step when creating an object.

    You can also create a new Custom Field Template from this screen by selecting the New Custom Field Template link. After creating the Custom Field Template, you will be returned to the selection screen where you can select the new template from the list.

To apply a Custom Field Template to existing objects:

  1. Select an object in the System Model tree, right click and choose Change > Custom Field Template.

    Or, select one or more objects from the Requirements view. Right click and choose Change > Custom Field Template.

  2. Select the Custom Field Template to apply from the list.

    You can also create a new Custom Field Template from this screen by selecting the New Custom Field Template link. After creating the Custom Field Template, you will be returned to the selection screen where you can select the new template from the list.

  3. Select Save and Continue for a single object, or Change for multiple objects.

If you are replacing an existing Custom Field Template, a message appears informing you that all data currently saved in the existing custom fields will be lost. Consider whether you want to lose this data before continuing. If this is not what you want to do, select Cancel.

 Field values for fields that are on the same on both the original and new templates will be preserved.

If you are editing a single object, the properties of that object will appear and you can enter values for the fields now and save the object. If you are editing multiple objects, you will have to edit the objects, either singly or in bulk, next to enter field values.
