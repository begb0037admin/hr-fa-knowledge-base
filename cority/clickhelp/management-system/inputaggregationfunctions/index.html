Input Aggregation Functions

Input aggregation functions (AggOf) aggregate across the expressions specified, each with a possible single value for the calculation date context.

 These aggregate functions are not to be confused with their counterparts (without the "OF" suffix) that aggregate a single expression across a time range, as used in Time-Based Calculation formulas.

Input aggregation functions, evaluated against a set of values where some, but not all, values are NULL will ignore the NULL values.

Input aggregation functions, evaluated against a set of values where all values are NULL returns NULL.

Exception: The COUNTOF function will return 0 when evaluated against a set of all NULL values.

The input aggregate functions include:

SUMOF

AVGOF

MAXOF

MINOF

FIRSTOF

LASTOF

VAROF

STDEVOF

QMOF

GMOF

HMOF

COUNTOF
