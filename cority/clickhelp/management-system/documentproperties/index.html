View/Edit Document Properties

The properties of a document include its name, the creator, and description. In addition, the document history records each document version with the version number, creation date, file size and version comments.

To view document properties:

  1. Right click the document in the Documents list and select Properties > View.

    The document properties are displayed. The properties that apply to all versions of the document are the name, creator, and description.

  2. To view the document history and details of each version, click the link ("Click here to see version history").

    All versions of the document are displayed. The properties specific to each version are the version number, creation date, file size, and version comments.

    To view a previous version of the document, right click the version and choose Open.

 With View permission you may open and view any previous document version. To delete or revert a version, you must have Edit permission.

Users with Edit permission on a document may edit the document name or description by editing the document properties. Other properties, such as creator, creation date, and version are automatically updated.

To edit the document description:

  1. Right click the document in the documents list and select Properties > Edit.

  2. Edit the name or description as desired.

  3. Select Save to save the new document properties.

Users with Edit permission on a document may rename a document. When you rename a document, the name applies to all versions of the document. The new name will be displayed anywhere the document is linked.

To rename a document:

  1. Right click the document in the documents list and select Rename.

  2. Enter the new name for the document and select Save.

A confirmation message appears informing you that the document has been renamed.
