Scheduling Workflows

Workflows can be scheduled by associating the workflow with a recurring task. Workflows are triggered relative to each task instance, according to the task schedule. Workflows are triggered in the same manner as notifications.

Configure the workflow schedule through either the task properties, or from a Task Template applied to a task. The Time to Create field specifies when the workflow is to be created.

To set up a regularly recurring workflow:

  1. For Time to Create, select the By Due Date option.

  2. Set the time relative to the due date of each task instance.

    If you want the workflows to show on the schedule in advance, use before due date. The system will look at the due date of each task instance and trigger the creation of the associated workflows in advance of the task due date by the period set (the same as it does for task notifications). For example, 1 year before due date would cause a year's worth of workflows to be triggered immediately and placed on the calendar. Workflow creation would continue to be triggered one at a time at the designated time for each task instance. For a more complete compliance calendar solution, use a greater time period, such as 20 years before.

Editing Task-Workflow Recurrence Schedule

  • If you edit the recurrence schedule for the task, all tasks and workflows that have not yet been edited by a user will be re-generated. Existing tasks and workflows will be deleted and new ones created.
  • If any tasks or workflows have already been edited, only changes to the end date will be allowed. You can end the current schedule and add a new recurrence schedule to make the change to the schedule.
