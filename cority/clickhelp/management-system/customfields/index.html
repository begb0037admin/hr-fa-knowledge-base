Custom Fields

To access the Custom Field Library to view, create or modify custom fields, you must have the Manage Custom Fields right.

To view existing custom fields:

  1. From the menu, select Setup > Custom Fields.
      The existing Custom Fields are shown.
    1. Click the  icon to expand the Search pane and use the search to find a specific field.
      Search for custom fields by name, by date created, by data type, and by value entry method.

    A limited number of pre-defined system fields of the calculated numeric data type are available in the system. Check Show Only Predefined Fields if you want to filter for these fields.

    The # Ref column indicates the number of Custom Field Templates that use the field.
