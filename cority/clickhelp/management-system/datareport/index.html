Data Report

A Data Report is used to report on compliance data for a selected time frame.

Some examples of Data Reports are:

  • Waste Water Reporting
  • Emissions Inventory Report
  • Inspection dates and results

A Data Report can be based on Location, Date or Parameter. The Type column in the report table in the Reports library shows whether the report is Location Based, Date Based or Parameter Based.

 The maximum report size is 70,000 cells. If too many columns are selected and the data exceeds this limit, a message will inform you that the limit has been exceeded. Use the selection criteria to reduce the number of records.
