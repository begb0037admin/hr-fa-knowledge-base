Version 9.1 Released 6/5/2017

New Features: 

  • Workflow Aggregations: Aggregations of data collected in workflows that meet particular user-defined criteria may now be captured in a Time-Based Fixed Period Calculated Requirement. Users may create calculations based on one or more workflow types and count instances or perform other aggregations (SUM, MIN, MAX, AVG) based on custom fields (UDFs) found on the workflow forms. Users may also define criteria based on workflow form UDFs or a particular Step that has been reached in the workflow process. Workflow Aggregations allow the data in workflows to be aggregated for a time period and the results made available as a numeric requirement that can be referenced in calculations, evaluated against a limit, and used like parameters and calculations.

  • Favicons: Favicon support across multiple browsers and platforms allow bookmarks and shortcuts to Management System products (such as the Portal or Management System) to be displayed on a device with the Cority Logo rather than a generic bookmark symbol. As a result, the user experience is closer to that of a Native App.

General Improvements and Bug Fixes:

  • AJ-2027 – Added REST API for reopening workflows
  • AJ-1674 – Added REST API for bulk retrieval of workflow steps and their forms
  • AJ-2021 – Material/Activity Calculations with references to numeric requirements are not properly localized upon copy operation
  • AJ-1672 – Added REST API for non-numeric data points
  • AJ-3006 – Credentials disappear after user clicks Sign In, but system is not loaded and no error message appears
