Defining Fields for an Event Log

The fields that are available for recording Events in an Event Log are configured with an Event Template. Any number of custom fields may be used in the Event Template. Typical fields for an Event Log are such things as the cause of the event and corrective action. Or, for a manual log, details of the incident, date/time of occurrence, description of the event, and other required details.

Eleven pre-configured calculated fields are also available for use in an Event Template. These fields allow you to automatically record such details as the duration of the event, or the highest amount of a limit exceedance. These are primarily used for Event Logs that monitor numeric requirements. For a full description of these fields, see Event Fields.
