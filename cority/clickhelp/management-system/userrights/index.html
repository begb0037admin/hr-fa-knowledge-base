User Rights

User Rights are authorizations given to users and groups that deal with system-wide functions, such as managing documents or creating templates. The user rights assigned to users control which parts of the application and which managerial functions are available to them.

 All rights and permissions are additive. Users who belong to multiple groups with different sets of rights and permission will get the combination of all rights and permissions associated with those groups.

User rights are described in the following table.

User Right

Actions Allowed

Security

Manage Users

Create/edit user profiles.

Grant access to a user from another system model.

Manage Groups

Create/edit user groups.

Manage Access

Grant or revoke system access for external users (from other systems).

Manage Security Policy

Set password requirements.

Enable automatic lockout.

Set session timeout factor.

Manage Command Log

View all commands sent to the system in Command Log. (Users without this permission see only commands they issued themselves.)

Manage System Messages

Can view all system messages (i.e., data warnings) in Message Center. (Users without this right see only system messages on objects to which they have permissions. Users with this permission see all system messages regardless of their permissions.)

Manage Quick Links

Configure links for the Quick Links menu for the system.

Tasks, Events, Workflows

Manage Task Templates and Notifications

Create/edit Task Templates and Task Notifications.

Manage Event Templates

Create/edit Event Templates.

Manage Workflows

Edit Workflow Types. Associate users and groups to Roles. Set workflow permissions.

Create/edit Roles, and set default members for workflow Roles.

Create/edit Form Templates.

Create/edit/associate Notification Templates.

Create/edit/associate Notification Policies.

Data

Manage Calculation Templates

Create/edit Calculation Templates

Manage Data Quality Templates

Create/edit Data Quality Templates

Manage Materials and Activities

Create/edit all components of Material Activity calculations, including materials , material groups, activities, chemicals, chemical groups, chemical lists, and Material Activity fields.

Manage TRI

View/run/edit Toxic Release Inventory (TRI) reports (Form R). Requires installation of the TRI product.

Configuration

Manage Requirement Templates

Create/edit Requirement Templates.

Manage Custom Fields

Create/edit custom fields and Custom Field Templates.

Manage Material Templates

Create/edit Material Templates

Manage Citations

Create/edit Citations.

Manage Dashboards

Create/edit/delete all System Dashboards and dashboard folders in the tree. Manage permissions for dashboards. Publish/Share dashboards.
Manage Main Menu

Enable or disable display of menu tabs (both native and custom tabs).
Add custom tabs for EIFL Apps and set permissions for tabs by users/groups.
Order menu tabs, delete menu tabs.

Documents, Reports

Manage Documents

Create/edit document folders

Add and edit documents.

Set document permissions.

Manage Reports

Create/run/edit all reports, with unrestricted access to object data regardless of object permissions.

Set permissions on reports.
Advanced Calculations (EMS) Apps
Manage Apps

Perform all operations for Apps, including:

Create/edit Apps (upload packages, edit existing packages).

Copy, delete, and download packages.

Create/edit Role associations with users and groups.

Set access permissions for content files in an App package.
Manage Portal Add/edit/remove portal pages and panels. This right is required in order to save page edits, if the user is not in Administrators group. Users who are members of the app role Portal Administrators and not in the Administrators group will also need this right in order to save page edits.
Tag Schemes
Manage Tag Schemes Create/edit tag schemes and tags.
