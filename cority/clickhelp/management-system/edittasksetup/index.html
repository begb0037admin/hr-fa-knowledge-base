Edit Task Setup

You can edit properties of a task or task series in the following ways:

  • Change the assignee or assignor. See Change Task Assignor/Assignee.
  • Add or edit schedules and due dates. See Editing Task Recurrence Schedules.
  • Add or edit notifications. See Add/Edit Task Notifications.
  • Edit general properties, such as task name and description.
  • Add an associated workflow. See Task Triggered Workflows

If a Task Template is associated with the task, you can edit the task template to apply changes such as notifications and workflow triggers to all associated tasks. See Task Templates.

You must have the appropriate permissions to edit tasks.

 Edits to task properties will be applied only to tasks with due dates in the future and those whose task status is 0%. Overdue tasks will not be edited, nor will any tasks with completion status >0%. Therefore it is advisable to complete all overdue tasks and partially completed tasks before editing the task properties. If you want to change the properties for an overdue or partially complete task, or apply changes to tasks that have already been completed, you can dismiss the original task instances and create exceptions. See Task Exceptions.

To edit a task:

  1. Right click any instance of the task and select Edit Task Properties.

  2. Edit the task properties as desired:

    Editing Task Recurrence Schedules

    Add/Edit Task Notifications

    Associate Documents with a Task

  3. Click Save.

 For automatically triggered tasks, the task schedule and notifications are set on the task template, rather than the task itself. See Task Templates.
