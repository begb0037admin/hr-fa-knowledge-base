Create Workflow Roles

You may create a new workflow role that you need for a workflow either from Workflow Role Manager or from the Process tab of the Workflow Type Editor as you set up the workflow steps.

To create a new workflow role:

  1. Do one of the following to create a new workflow role:
    1. From the menu, select Setup > Roles under Workflows and select New Workflow Role.
    2. In the Process tab of the Workflow Type Editor, create a new step or select an existing step to edit it, and next to the Assigned Role field, select Create.
  2. Enter a Name for the role and an optional description.
    You may also add default members, if desired. Default members are for setup convenience only and will not be used for role resolution in workflow assignments. When the role is added to a step on a Workflow Type, you may accept or change the default memberships as you wish.
  3. To set up default users or groups, click Add and select the users or groups from the selection window.
    You can create a role with no members assigned to the role.
  4. Click Save and Confirm.

If you started from the Workflow Type description, the new Role will be selected as the Assigned Role for the step. You can continue to set up the workflow step.

If you started from Workflow Role Manager, you can continue to set up the Roles you need for your workflow. Go to the Workflow Type Editor to create or edit the workflow in which you want to use the Roles. See Edit Workflow Process.
