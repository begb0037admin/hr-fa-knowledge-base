Version 9.3 Released 12/4/2017

Release focused on expanding support for localization to allow different languages inside the Management System user interface.

General Improvements and Bug Fixes:

  • MAIN-4070 Custom field captions and list values can now be defined with with values in each supported age.
  • MAIN-4071 System model objects can now be configured with names in multiple 3645 Workflow assignees now more clearly defaulted to the task assignee for new triggered workflows.
  • MAIN-84 New REST API for Form Template management.
  • MAIN-5613 Workflow bug fix: Overview page shows past due symbol when workflow is complete.
  • MAIN-7782 Workflow bug fix: Calendar shows past due symbol when workflow is complete
  • MAIN-7265 EQL support for all SCIM user properties.
