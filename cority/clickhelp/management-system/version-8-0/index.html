EMS System 8.0 Release Notes

Release Date: 10/31/2015

New Features and Improvements

Tag Schemes and Tags

A classification scheme is introduced to allow for tagging system model objects and requirements as properties of the objects. The major application for tag schemes in this release is to allow tagged requirements to be used in Material Activities. However, the classification scheme will allow in the future for more robust object identification than simple naming schemes.

Tags were also added to the following report types:

  • System Property Report
  • Data Report
  • Task Report
  • Event Report
  • Compliance Status Report
  • Event Instance Account Summary Report 
  • Task Status Summary Report
  • Non-Numeric Data Status Summary Report
  • Task Closing Time Summary Report
  • Citation Report

Support for tags has also been added to Bulk Tools.

New Material Activity Features and Improvements

This release features the first major upgrade to the Material Activity functionality, including the following new features:

Chemical Logical Formula-Based Properties

A new type of Formula-Based Property is introduced, which allows to build a single formula that will automatically create values for each chemical component within the material. Chemical Logical Properties can be Primary, Secondary or Tertiary. Chemical Logical Properties can be referenced by other Material Calcs as an aggregate or as a chemical-explicit version, and additionally by other Chemical Logical Properties in a linear version. Chemical Logical calculations have the potential to replace large numbers of discrete calculations in current and future system models.

Dynamic Material Groups

When a Material Group is edited, the user has the option of applying the changes to all Material Activity Calcs to which the group is associated. A new material will be added to all associated MACs. When a material is deleted from a group, it will only be deleted from associated MACs if there is no data for that material.

Ability To Disable Materials

Material can be disabled from use in data entry. When a material is disabled, it will not appear for material data entry.

Material Data Quick Add

A new interface is available for adding material data via Quick Add (similar to Quick Add for parameters). Users can select a period and start and end date, and a table for data entry will be generated with start and end dates for material data lines and a completion date. Data may be copied and pasted from spreadsheets into the data grid.

Integration of Standard Requirements in Material Formulas

Standard numeric requirements can be used in calculation scripts for Tertiary Formula-Based Properties and Material Activity Calculated Requirements. Tag Schemes and Tags are used to tag requirements for Material Activity use, relative to the data location. Requirements without tags can also be referenced by absolute path (useful for common library components).

New User Interface for Materials, Material Properties, and Material Activity Calculated Requirements

A new tabbed UI for finding components and functions by categories is enabled for:

  • Material Activity Calculated Requirements calculation builder (Create/Edit/View)
  • Material Formula-Based Properties calculation builder (Create/Edit/View)
  • Materials (Create/Edit/View)

New Chemical Properties

New chemical properties have been added to include DIPPR variables for extended Antoine equations and some additional Boolean properties.

Material Report Changes

Material Reports will include outputs for Chemical Logical Properties per chemical component.

Performance Improvements

Major performance improvements have been made for the Material Activity calculation engine.

EMS SDK Additions

New REST APIs have been added to support Material/Activity functions, as well as support for managing Requirements and Tags. See AppSDK Help for more information.
