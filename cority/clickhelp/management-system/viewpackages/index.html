View Apps

Each App is a separate package, or collection of files, which defines the custom interface to be displayed in a custom page. 

To view the Apps in the system:

  1. From the menu, select Setup > Apps.

    The Apps available in the system are listed.

  2. To view the content and configuration of an App package, right click the package and choose View.

    The General tab shows the files included in the package and the display page (the page that displays initially when the tab is opened).

    The Role Membership tab shows the Roles used in the App, and the users or groups mapped to each Role.

    The Permissions tab shows the access permissions for the App contents by Role (default Role, if none is defined in the package, is Everyone). This tab is view only, for development use. Permissions are defined by Role.

    The Security Policy tab shows the content security policies, which limits the sources of files served by the App. The tab is view only, for development use; Security Policy is defined in the App manifest.

You may run the App to preview it from the view page.

To preview the display of the App, click the Run button on the View page. You can also right-click the package in Apps Manager and select Run.

The menu tab associated with an App, if a menu tab has been configured, can be seen by showing the dependencies for the App. To view dependencies,  in Apps Manager, right click the package and choose Show Dependencies.
