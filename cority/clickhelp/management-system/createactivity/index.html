Create Activity

Activities are created and managed in the Activities page, accessed from the Materials/Activities page.

When creating an Activity, you must add at least one Specific Use Variable. You may also apply one or more Activity Value Based Properties, whose values are defined on the activity.

An Activity may also have a Material/Activity Template. This template may be used to store a Unique Tag id that is required for database integration purposes. It might also be used to store information needed for reporting purposes but which is not relevant to the calculations.

To create an Activity:

  1. From the menu, select Setup > Activities under Materials/Activities.

  2. Select New Activity.

    Optionally, select a Material/Activity Template to apply. The Material/Activity Template stores custom fields for information purposes only. It may also be used to store a unique ID tag for data integration purposes. See Material/Activity Templates.

  3. Click Continue.
  4. Enter a Name and an optional Description.

  5. In the Specific Use Variable section, click Add to add a Specific Use Variable, and select the property from the selection window.

    At least one Specific Use Variable is required.

  6. If any Value Based Properties are required, click Add in the Value based Properties section and select the properties from the selection window.

    After adding a property, click the plus sign (+) to expand the value history section. Click New to define a value for the property.

    Enter a value and a Begin Date, then click Update.

    If a Material/Activity Template is applied, enter the values for the template fields. For data integration, a unique tag ID is required.

  7. Click Save.
