Compliance Permit Analysis 

With the Permit Analysis Agent, you can upload permit documents to generate a summary of requirements, refine results, and perform further analysis using the AI. The Permit Analysis Agent can be accessed from the Environmental Cloud of Core (GX2) and from Advanced Calculations (EMS).

Enable Permit Analysis 

To enable Permit Analysis:

  1. In Permits, Policies, & Procedures, create a new view or edit an existing one. 
  2. In the AI Settings section, choose Compliance Permit Analysis Agent. 

    The Compliance Permit Analysis Agent will only appear if it has been activated in the Cortex AI Control Center.

  3. Check the Enabled checkbox. 
  4. Optionally, enter a name for the button used to analyze a permit. 
  5. Click Save.

Analyze a Permit

From the Environmental Permits, Policies, and Procedures list view, do the following:

  1. Click Permit Analysis (button name may vary) to open the Permit Analyzer.

  2. Click New Permit.    

  1. Drag and drop a file or click Browse Files to search for a file on your device.  

  1. Optional: As your file is being analyzed, click the Notify icon to receive an email when the analysis is complete. 
    You can cancel the analysis at any time.  


Once the analysis is complete, a table is generated, summarizing actions required to maintain compliance with the permit. You interact with the summary using the AI to refine the results and ask additional questions about the permit. For example, you can ask "Can you add a column to the table for regulatory references?".

View history

You can search for and view previous permits analyzed from the side menu. For each analysis, you can click the Options icon and do any of the following:

  • Click Rename to rename the analysis in the side bar.
  • Click Delete to delete the analysis. 
  • Click Pin to keep the analysis at the top of the list. 
  • Click Make Public or Make Private to allow other users to view the analysis or keep it private.
