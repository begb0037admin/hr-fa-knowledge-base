Parametric Report for Vault

The Parametric report searches for products by virtually any chemical characteristic, including product information, composition or ingredients, emergency overview text, physical and chemical properties, hazard ratings, CLP class, DSD/DPD class (risk or safety phrases), or transportation class.

Note:  The Parametric Report in Vault is identical to the Parametric Report in Regulator, except that the Regulator version includes inventory information fields in the Product Information Section.

To create a Parametric Report:

  1. Click Vault Main Menu (). The Vault navigation pane displays. Select Parametric from the Reports list.

    The Parametric Report setup is displayed.

  2. Check the fields you want displayed in the report and enter filter information.

    Expand a section by clicking on the section head to view available fields.

  3. At the top of the page, select the Location to search. You can search Current Location or Current Location and Children.

    To save the report as a custom report, click Save As and enter a report name.

  4. Click Run Report.

    The report displays. Click Download XLS to download the report in Excel format.
