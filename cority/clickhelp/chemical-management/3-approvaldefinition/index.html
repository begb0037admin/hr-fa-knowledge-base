Approval Definition

The Approval Definition maps Gatekeeper requestors to the request forms and approval forms, and specifies who gets notified of the request.

Your Enviance Customer Service Manager can configure the approval workflow in one of two ways:

Requestor-Choice—The approval workflow follows the flow configured in the Approval Definition. You can configure multiple stages of approval. When the approver for the first stage approves the request, Gatekeeper initiates the second stage approval using the same, or a different approval form and sending it to another approver.

Question-Response—The approval workflow varies depending on the answers provided by the requestor.  For  questions in the request form, you specify the answer value that triggers an approval form.  You can configure different approval paths for different requestor answers.

See the linked sections for information on creating an approval definition for either workflow.  For more information about these choices, call your Enviance Customer Service Manager.

Before creating an Approval Definition, you must

  1. Create a request form
  2. Create an approval form
  3. Add users to the locations where the Approval Definition will be used.
