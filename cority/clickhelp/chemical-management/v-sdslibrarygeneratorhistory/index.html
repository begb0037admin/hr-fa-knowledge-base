SDS Library Generator History Report

The SDS Library Generator History Report gives a history of SDS Library backups made using the SDS Library Generator. It includes the person who generated it, the location for which the library backup was made and the date created.

To run a SDS Library Generator History Report:

  1. Click Vault Main Menu (). The Vault navigation pane displays. Select SDS Library Generator History from the Reports list.

  2. Enter the start and end dates.

  3. Click Run Report.

    The report displays. Click Download XLS to download the report in Excel format.
