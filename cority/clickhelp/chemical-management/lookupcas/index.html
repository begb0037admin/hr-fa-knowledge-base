Chemical Lookup

You can look up a chemical by name, CAS number or EC Number using the Chemical Lookup tool.

To look up a chemical:

  1. Click Tools and select Chemical Lookup.

  2. Choose whether you want to look up the chemical by Ingredient Name or CAS number.

    Enter the name or CAS. As you type a list of matches are displayed for you to select from.

    The CAS Lookup window displays the information for the chemical.
