Regulatory Analysis Report

The Regulatory Analysis report indicates whether any of the chemicals in inventory at the location appear on a specific regulatory list.

Many Regulatory Analysis lists, both regional and global, are maintained in the system and are available. You can select a regulatory list from the system, or you can add your own list in .xls format. For more information about doing this, see the Vault Quick Start Guide.

To run the Regulatory Analysis Report:

  1. Click Regulator Main Menu (). The Regulator navigation pane displays. Select Regulatory Analysis from the Reports list.

  2. Select a Regulatory List Type from the list.

  3. Enter the details for the report in the report form.

  4. Click Run Report.

    The report displays. Click Download XLS to download the report in Excel format. Click the document icon to download the report in the pdf format.
