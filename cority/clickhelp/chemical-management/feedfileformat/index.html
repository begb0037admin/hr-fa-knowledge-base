Feed File Format

The information in this section will help your IT department understand the requirements for the feed file that supplies the Distribution information to the application:

Formatting the Feed File

Naming the Feed File

Formatting the feed file:

The feed file you post to the FTP site must include the following header row, formatted as a single line, followed by rows of actual transaction data:

CustomerNumber|CustomerName|ContactName|ContactEmail|Address1|
Address2|City|State|Zip|Country|ProductName|PurchaseDate|ClientCode1|ClientCode2

Note:  Not all fields are required. When omitting a field, you must still include the delimiter
character (|).

The following example shows a row with only the required fields:

CustomerNumber|||ContactEmail||Country||PurchaseDate|ClientCode1

The filename of the feed file must include the name of a location in your Vault, and the location name must be unique. For example, if you want to distribute SDSs in your location named Dallas warehouse, but you also have the location Dallas factory, name the feed file warehouse.

Naming the Feed File

The filename of the feed file must include the name of a location in your Vault. Thehe location name must be unique. The feed file should also include the date.

For example, if you want to distribute SDSs in your location named Dallas Warehouse, name the feed file Dallas Warehouse_10042017.txt.
