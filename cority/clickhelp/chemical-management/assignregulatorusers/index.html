Assign Regulator Users to your Locations

For each Location, you can authorize users to add inventory.

To assign Regulator users for your locations:

  1. Click Regulator Main Menu (). The Regulator navigation pane displays. Select Add Users to Locations from the Configurations list.

  2. Click a location name in the hierarchy.

    The pop-up window displays the available users.

  3. Select a user from the available users on the left. Use CRTL+click to select multiple users. Click the right arrow to move the user to the list of Regulator Users. Use the double-right arrow to move all the users.

  4. Click Save.

Note:  Available users must be Vault users and be assigned a Regulator role in their user profile.
