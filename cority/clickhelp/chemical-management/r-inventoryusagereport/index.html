Inventory or Usage Report

The Inventory Report shows you the inventory for the location. You can view the inventory by product, container, ingredient, or threshold. The Usage Report shows the inventory used, including the amounts and units.

To run the Inventory or Usage Report:

  1. Click Regulator Main Menu (). The Regulator navigation pane displays. Select Inventory or Usage from the Reports list.

  2. Select the type of report from the list.

  3. Enter the details in the report fields.

  4. Click Run Report.

    The report displays. Click Download XLS to download the report in Excel format. Click the document icon to download the report in the pdf format.
