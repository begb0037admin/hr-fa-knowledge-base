Searching Current Inventory

You can search for Regulator inventory by entering inventory information in the Search Inventory form.

To search inventory:

  1. Click Regulator Main Menu. The navigation pane displays. Select Search Current Inventory from the Actions list.

    The search page displays:

  2. Enter a specific product to search for, or click Search to show all products currently in inventory for the location.

    The results page displays.

  3. From the resulting product list, click the gear icon in the Action column for the product you want and select the icon from list.

    The results page displays. You can view the SDS, print labels and scan barcode labels, add and edit inventory, and see chemical characteristics.

  1. Click Advanced Search to search for specific text in a SDS, or for text within custom fields or within industry-standard fields.

To scan inventory:

  • Navigate to the Use Inventory page by clicking the gear icon in the Action column for the product you want and select Labels. See Using Inventory.
  • Use a barcode scan tool to scan the Regulator barcode label on the product. Regulator displays the inventory search results page showing the product you scanned.

See also Print Barcode Labels.

To Use Inventory:

  • Navigate to the Use Inventory page by clicking the gear icon in the Action column for the product you want and select Use Inventory. See Using Inventory.
