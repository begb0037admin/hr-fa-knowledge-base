Configuring Distribution

As a Distribution administrator, you can accomplish most tasks from the Configurations menu on the Distribution tab. The following steps provide guidelines to get you started. Click the links in the steps for more detailed information about each step:

  1. First, specify Distribution users for a location from among your existing Vault users.
  2. Next, set the Distribution rules. This includes the actions to take when problems occur.
  3. Specify the documents and languages for countries.
  4. Manage Information about your entities (or locations)
  5. Finally, drop the RSS feed file in the FTP folder.

For information about formatting the Feed File for your IT Department, see Feed File Format.
