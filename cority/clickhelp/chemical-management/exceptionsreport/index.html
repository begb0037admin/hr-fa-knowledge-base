Exceptions Report

The Distribution Exceptions Report show information about the Distribution exceptions (errors).

To view the Distribution Exceptions Report:

  1. Select the folder icon in the Distribution header and select Exceptions from the Reports menu.

  2. Enter filter information as desired, or leave filters blank to see all.

  3. Click Download Transaction History to download a spreadsheet listing the exceptions.

    Information includes: Document Name, Customer Code, Exception, Sent From, Customer Number, Customer Name, Email, Date Purchased, File Name

Click in the Edit column to edit information.
