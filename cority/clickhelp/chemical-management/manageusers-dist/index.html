Manage Users for Distribution

You can specify Distribution users for a location from among the existing Vault users.

To specify Distribution users:

  1. Select the folder icon in the Distribution header and select Manage Users from the Configurations menu.

    The Manage Users by Location page displays.

  2. Click a location name.  A window displays for the location, listing the available Vault users:

    Highlight users from the Available Users list and click the right arrow to move the user to the Regulator Users list.

  3. Click Save.

Note:  Available users are Vault users who have been assigned a role for Distribution in their user profile.
