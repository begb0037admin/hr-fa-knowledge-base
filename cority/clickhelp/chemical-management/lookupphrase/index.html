Phrase Lookup

You can look up hazard and precautionary statements, risk and safety phrases, and signal words using the Phrase Lookup tool.

To find phrases:

  1. Click Tools and select Phrase Lookup.

  2. Click Phrase Lookup.

    The Phrases window opens.

  3. Choose a type of statement or phrase from the Type list. Select a language if necessary. Click Go.

    All statements of the selected type are listed.

  4. Enter the phrase to search for in the Find box at the bottom. The list is instantly filtered as you type. The number of matches is noted in parentheses.

    If you want to show all with matches highlighted instead of filtered, select the Highlight button and click Go.

  5. Click Go.
