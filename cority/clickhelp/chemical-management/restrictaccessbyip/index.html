Restrict Access By IP Address

IP Address Restriction provides an additional layer of security by requiring users to access the system from computers having IP addresses that are on a list of allowed IP addresses. After a user enters their username and password, the system checks the IP address of the user and verifies the address is on the list of allowed IP addresses. If it is on the list, the user is allowed access. If the address is not on the list, the user receives an alert that the IP address they are originating from is not on the list of allowed IP addresses.

Important:  If you delete your own IP address from the list of allowed addresses, you will disable your own administrative access to the system. If this occurs, access the system from another computer whose IP Address is on the list.

To restrict access by an IP address:

  1. Click the dropdown arrow next to your name top right. Select Administration from the menu.

    In the Administration menu, select IP Address Restriction.

  2. To restrict access to the computer from which you are currently logged in, click Add Current.

    The IP address of the current computer is displayed and added to the allowed list. Any users logging in from this IP address will be allowed access; users from other IP addresses will not be allowed. For example, you can limit access to a work environment. Users who log in from home would need to have their IP addresses added separately by an administrator.

  3. To add an address other than the current computer, enter the address in the IP Address field and click Go.

    The address is added to the list displayed on the page.

  4. To delete an address, click the Delete button next to the address.

Important:  When you enter an IP address or click the Add Current button, future logins are immediately restricted to those addresses on the IP Address Restriction List.
