Transaction History Report

The Transaction History report shows inventory transactions for a specific time period, including the location, the product, the type of transaction (added, used, waste), transaction date and amount.

To run the Transaction History report:

  1. Click Regulator Main Menu (). The Regulator navigation pane displays. Select Transaction History from the Reports list.

  2. Enter the date range and unit of measure. Adjust the decimal length if necessary.

  3. Click Run Report.

    The report displays. Click Download XLS to download the report in Excel format. Click the document icon to download the report in the pdf format.
