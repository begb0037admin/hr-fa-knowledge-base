Manage Entity Information

You can specify Entity information including the address and country of the entity (or location).

To manage Entity information:

  1. Select the folder icon in the Distribution header and select Manage Entity Information from the Configurations menu.

    The Manage Distribution Entities page displays.

  2. Click the name of an entity (or location). A window displays with address and country information:

  3. Complete the information as required.
  4. Click Save.
