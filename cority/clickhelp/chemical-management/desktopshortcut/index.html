Instant Access Shortcuts

Instant Access shortcuts can be created for use as a desktop shortcut that may be deployed for users on a personal or shared computer. Shortcuts can be created for Search Only and General users.

To create an instant access shortcut:

  1. In the user table, click the green Reset button in the Reset column.

    The Reset button is displayed only for Search Only and General users.

    The shortcut will be created and the icon displayed in the Shortcut column. The name on the shortcut is the user last name; it can be renamed once it is deployed.

  2. Select the shortcut icon it and drag it onto the desktop.

To disable a shortcut:

  1. Click the icon in the Disable column. This will disable the shortcut anywhere it has been deployed (such as multiple kiosks with the same user access).

To re-enable the shortcut:

  1. Click the green Reset button in the Reset column.

You can change the shortcut icon from the browser default icon to an Actio system icon. In the Change Icon window, click Browse. Find the location where you saved the Actio icon and select it, then click Open.
