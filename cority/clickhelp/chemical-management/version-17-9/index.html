Version: 17.9 Released: 11/12/2018

New Features and Improvements

  • Proprietary SDS Vault Location: Administrators now have the ability to make an SDS Vault location proprietary and limit access only to specified users. Only authorized users will be able to view and run reports for a proprietary location.
  • Regulator Expiration Date Notifications: Administrators can now configure location-specific chemical expiration notifications. This includes advance notice of expiration and actual expiration date notices to specified users.

General Improvement and Bug Fixes

  • Data Entry: CHEM-234 Doc ID not visible in Data Input Grid.
  • Data Entry: CHEM-756 Prevent refresh of results after executing a function.
  • SDS Vault: CHEM-1137 Clients cannot log into Vault on the first login.
  • API: CHEM-1378 Sort Search Results Grid in alphabetical order.
