Version: 18.2.0 Released: 2/10/2021 

New Features

  • Regulator Inventory Thresholds
    • The feature allows users to automate their physical container inventory audits. Users can also set inventory compliance thresholds, and monitor product ordering. 
    • Existing minimum/maximum thresholds by CAS/Ingredient can now be tracked by location.
    • Now when the minimum/maximum inventory count or CAS/ingredient threshold is reached, system notifications will be sent. 
    • The new and improved Thresholds Flag Grid will display any chemicals or product containers at a location that have reached their minimum/maximum threshold.  Users can also flag a chemical whose threshold level requires attention.
  • Physical Inventory Report
    • This report will be available to facilities that track minimum/maximum thresholds by physical container inventory.  The report will automatically aggregate containers and compare them to the minimum/maximum values stored, and allow users to quickly either add or subtract the container inventory to satisfy the minimum/maximum values.
  • Adding Inventory on-demand
    • This feature further integrates the Chemical Approvals module with inventory tracking. Chemical Approvers can enable certain products and chemicals during the Gatekeeper approval process to be added to inventory on-demand list, allowing users to bypass the new approval process and directly add containers to inventory, as long as the original request is in the 'Approved' state.

  • Gatekeeper Pre-approval list by Custom Field
    • The Gatekeeper module now supports pre-approvals based on CAS number and SDS information. This new feature will enable users to also utilize one of their Custom Field names and add its values to pre-approval list.
