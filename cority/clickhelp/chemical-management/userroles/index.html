User Roles

The following types of users are supported, from lowest to highest. Each level includes the privileges of the lower level(s).

Account Type Account Privileges
Vault Gatekeeper Regulator
Search Only Search for, view, and print SDS and related documents, view document revision history, print labels No access No access
General User Run reports about the documents in Vault, use ingredient lookup tools, pre-screen ingredients, email SDSs. May also be enabled to request products for library.

Run reports, use ingredient lookup tools, and pre-screen ingredients.

General Users can be assigned as Requestors and/or Approvers.

 Search for and view inventory, manage container inventory (add/edit containers, use chemicals, transfer containers to other locations, etc.), run reports, use ingredient lookup tools, and pre-screen ingredients.
Application Administrator Add new documents, create and manage labels (and automatically generate labels), add custom search fields, create summary sheets, archive SDSs, create an SDS Library In addition General User privileges, can access the Configurations menu to manage the Gatekeeper approval process, create request and approval forms and map them to Gatekeeper users using approval definitions, manage emails. In addition General User privileges, can access the Configurations menu to add users to locations, add customers, customize the Regulator inventory grids, configure thresholds for inventory, and add, use, or transfer inventory to other locations.
Account Administrator All Application Administrator privileges, plus add account users, manage locations, manage regulatory lists, and run administrative reports. User must have Application Administrator role to be enabled as Account Administrator. All Application Administrator privileges, plus add account users, manage locations, manage regulatory lists, and run administrative reports. All Application Administrator privileges, plus add account users, manage locations, manage regulatory lists, and run administrative reports.
