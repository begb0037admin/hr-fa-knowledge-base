Requestor-Choice Approval Flow

The Requestor-Choice Approval flow is configured as you want in the Approval Definition. You can configure multiple stages of approval. When the approver for the first stage approves the request, Gatekeeper initiates the second stage approval using either the same approval form or a different approval form and sends it to the designated approver.

To create an Approval Definition for Requestor-Choice flow:

  1. Click Gatekeeper Main Menu (). The Gatekeeper navigation pane displays. Select Approval Definition Builder from the Configurations list.

    The Approval Definition List displays.

  2. Click the Add Definition button.

    The Approval Definition Builder page displays.

  3. In the Location list select a location for which the definition applies. Use CRTL+click to select multiple locations.
  4. Enter an Approval Definition Name.

  5. Select the Request Form this definition will use from the dropdown list.

  6. Then select the Approval Form that will display to approvers.

    7. Both the request and approval forms must be active to be available in the lists. If a form you created is not listed, go to the request or approval form list and ensure the form is active.

  7. Enter a Stage number. Click the Add Stage button to add another Stage.

  8. Choose an Approver for the stage.

  9. Choose the Notifications.

    This field specifies when to notify the selected Approver. Options are: Always, Never, On Request, On Final Approval, On Previous Approval, On Decline

    To additional Notifications to other approvers, click the + button to the right. Another set of fields (for Approver, Notifications, Storage Location(s) and Backup Approver) will appear below, which will apply to the same approval form and stage. You can set up different Approvers and applicable Notifications for the same location or different locations.

  10. (Optional) Select one or more Storage Location(s) to which the Approver and Notifications apply. Use CRTL+click to select multiple locations.

  11. (Optional) Choose a Backup Approver (one or more).

  12. (Optional) Select users to "notify only" by clicking the + button below Notify Only and select when to notify. These users receive email notifications, but are not required to log in to Gatekeeper or approve the request.

  13. Click Save.

    Or click Update if you are editing an existing Approval Definition.

Select the Approval Definition List link at the bottom to return to the definition list.
