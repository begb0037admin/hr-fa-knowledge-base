Configure Regulator Grid Display

Administrators can customize the grid displayed when searching or adding inventory.

To customize the grid display:

  1. Click Regulator Main Menu (). The Regulator navigation pane displays. Select Grid Display from the Configurations list.

    The Regulator Grid Display shows the available fields. If custom fields are configured, the custom fields may also be enabled in the grid.

  2. Check the fields you want to be displayed.
  3. Drag and drop column names to adjust the order of the columns as they appear in the grids.
  4. Click Go to save your settings.
