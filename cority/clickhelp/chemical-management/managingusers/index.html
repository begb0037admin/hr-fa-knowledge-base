Managing Users

Add Vault users from this page. In the User Roles section, the drop-lists displayed vary depending on which modules are enabled for your company.

Check the Account Administrator checkbox to give this user the highest level privileges across all modules. In addition to the privileges of Application Administrators, Account Administrators can add account users, manage locations, manage regulatory lists, and run administrative reports such as user login reports.

Vault supports the following types of users listed from highest to lowest privilege level. Each level includes the privileges of the lower level(s):

Search-only User: Search for, view, and print SDS and related documents, view document revision history, print labels.

General User: Run reports about the documents in your Vault, use ingredient lookup tools, pre-screen ingredients, email SDSs.

Application Administrator: Add new documents, create and manage labels (and automatically generate labels), add custom search fields, create summary sheets, archive SDSs, create an SDS Library you can copy to a CD or flash drive.

Account Administrator: Add account users, manage locations, manage regulatory lists, and run administrative reports such as document count and user login reports.

To add a user:

  1. Click Administration in the lower Vault toolbar. The Administration drop-list opens.
  2. Choose User Management. The User Management list displays.
  3. Click Add a Person. The Add a Person window displays.
  4. Specify user information in the fields and choose the user role(s).
  5. Click Save.

You can create a shortcut to Vault on the desktop for General and Search-only users to have immediate access to Vault.

To add a Vault desktop shortcut:

  1. In the user list, click the green Reset button for the user. Vault creates the shortcut and lists it in the Shortcut column.
  2. Click and drag the shortcut from the Shortcut column onto the desktop. Vault creates the shortcut on the desktop.

Note:  If you click the green Reset button for a user shortcut, Vault resets the shortcut URL for that user.
