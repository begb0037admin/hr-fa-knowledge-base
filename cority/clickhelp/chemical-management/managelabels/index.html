Manage Labels

Managing your labels involves creating label templates that specify which label fields and graphics appear to users in the label editor. Vault supports a standard template and a free-form template. In the standard template, you enable discrete fields and graphics that appear in the label editor to users creating labels. Your control over the positioning of fields in the label area is limited.

With the free-form template, you enable label fields and graphics as objects that you drag and position into a graphical representation of the label. Each object has its own editor for adjusting the text format. You have unlimited control over the position of each object in the label area.

Once you create a template, you can create labels instantly for all your products in Vault using the Auto-Generate feature. When doing this, you have the option to create labels for all products, for specific products, or for products in specific locations. You can also reverse the label auto-generation if necessary.

To create a standard label template:

  1. Click the dropdown arrow next to your name top right. Select Administration from the menu.

    From the Administration menu, select Label Management.

  2. Click Create New Label Template.

    The page refreshes and displays the template options.

  3. Choose the Label Type Standard from the list and click Start Creating Template.

    Vault expands the page and displays the template format options:

  4. Enter a template name and choose Published, Yes or No.

    Publishing a template makes it available to users when they create a new label.

  5. Choose the Label Stock from the list. Each template you create only supports one label stock.

  6. In the Label Layout Right Column table, check the pictograms to include in the right-hand side of the label.

    We recommend you choose the pictograms first because the pictograms enabled for printing affect how the fields are arranged in the remaining space on the label.

  7. In the Label Layout Left Column table, check the fields to include in the label.
  8. Check the Print Left or Print Below options to make the fields appear in the label—either to the left or under any enabled pictograms.
  9. Reorder the fields as necessary by dragging and dropping rows up or down in the table.

  10. Click Save New Label Template. Vault saves the template and the template becomes available to users when they create labels.

To create a free-form label template:

  1. From the Create New Label Template page, choose the Label Type Free Form in the drop-list and click Start Creating Template. The page refreshes and displays template options.

  2. Enter a template name and choose Published, Yes or No. Publishing a template makes it available to users when they create a new label.
  3. Choose the Label Stock from the drop-list. Each template you create only supports one label stock.

  4. In the List of Available Data Fields table, check fields and pictograms to include in the label. As you enable the fields, the editor adds them as objects to the Label Preview, stacking them on top of each other:

  5. For each object, click inside the frame and drag the object to position it within the label area.

  6. To customize the object text, click the Edit button within the frame. A control panel displays with text and editing options. You can expand the box to see the options by grabbing and dragging the lower left corner.

    The controls allow you to form text in the object, control the stack order, show or hide the object header, and upload images such as logos.

    Show/Hide Object Header controls the display of the object header. For example, the name of the product could be sufficient to display in the label. In this case you can hide the object header for Product Name.

    Show Text displays a text box where you can type in additional text to display in the header.

    Hide Text hides the text you added using the text box.

    Move Front (object stack order) moves the current object to the top, and Move Back moves the object behind other overlapping objects.

    Border Width defines the border settings for the object, if desired. By default, objects do not have borders.

  7. When you are done adjusting the objects, click Save New Label Template. Vault saves the template and the template becomes available to users when they create labels.

To create new labels using Auto-Generation:

  1. In the Label Template page, click Show List.

    Click Auto-Generate Labels/History for a template. The Auto-Generate Labels page displays:

  2. Fill in a title for the Auto-Generate instance.
  3. (Optional) Choose whether to add text to the beginning or end of the label name. Vault displays label names created through Auto-Generation with the prefix or suffix you specify.
  4. Choose which documents in Vault for which to create auto-generated labels—by choosing specific documents, by specifying locations, or all documents. In our example, we choose all documents.
  5. Click Start Label Generation. Vault creates the labels.

To reverse your label Auto-Generation:

  1. To undo the label creation, in the Label Template List, choose Auto Generation Labels/History. The Auto-Generate Labels page displays and includes a Label Generation History table:

  2. Click Remove auto-generation and associated labels.
  3. If you are sure, click Confirm. Vault removes the labels created by the Auto-Generation.

To refresh your Auto-Generated labels:

Sometimes the IntelligenTEXT information for a product's SDS document is more recent than the information used when you created a label for that product. In that case, you can update your labels with the more recent IntelligenTEXT information using these options:

  • Refresh all data fields for this label generation—Vault replaces all manually entered label data with the more recent information stored in the IntelligenTEXT database.
  • Refresh for blank fields for this label generation if possible—Vault attempts to fill in empty fields with information in the IntelligenTEXT database but does not update any field that already has data.
