Security Policies

The Account  Administrators may specify security policy criteria for users in the Administration > User Management page.


Security policies include the ability to specify password complexity and length, to reset password by user, and to force password reset by administrator. Security policy also includes session timeout.

Password options include Password Complexity and Password Length.

Enable Password Complexity Policy

A complex password must include two of the following:

    • At least one upper-case letter
    • At least one number

    • At least one special character of the following: exclamation mark (!), at (@), number (#), dollar ($), and (&), asterisk (*), underscore ( _ ), or hyphen ( - )

    Enable Minimum Password Length Policy

    • Password must be at least 12 characters long

    Session Timeout Policy

    Session Timeout: Period of inactivity allowed before session times out and the user must sign in again.

    • Timeout is 24 hours

    Password Reset

    Depending on the User Roles, passwords can be reset for security reasons.

    The following table shows available reset password actions for different user roles.

    User Role Actions Allowed 
    Vault Search OnlyCan't reset password. The password must be reset by an Account Administrator.
    General UserCan reset password through Forgot Password link on the Sign-in page. 
    Application Administrator

    Can reset password through Forgot Password link on the Sign-in page and Reset Password link on My Account page.  

    Account Administrator

    Can set or reset user password for Vault Search Only User and Vault General User on the User Management page.

    Can force to reset password for all user types other than Vault Search Only User and Vault General User on the User Management page.
