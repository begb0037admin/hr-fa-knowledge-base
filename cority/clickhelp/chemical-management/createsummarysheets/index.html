Create Summary Sheets

You can create a summary sheet for a product from a generic template or a GHS template. After you choose a template, Vault launches the summary sheet form with IntelligenText data pre-filled in the form. Once created, Vault displays the summary sheet in the search results grid as a separate line with the document type summary sheet.

To create a summary sheet:

  1. In the search results grid, click the gear icon in the Action column for the document on which the summary sheet is based.

  2. From the Action palette, select Summary Sheet.

    The Summary Sheet window displays.

  3. Choose a template from the list and click Choose Template.

    The Summary Sheet editor displays.

  4. Fill in the form fields and add pictograms as desired.

    Scroll down the page to reveal more fields.

  5. Click Save at the bottom of the form when you are done entering the information.

    Vault saves the summary sheet in the location.
