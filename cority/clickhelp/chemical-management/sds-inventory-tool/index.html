SDS Inventory Tool

The SDS Inventory Tool allows users to manage Safety Data Sheets location inventory by creating a report which: 

  • Enables users to perform an audit of their chemical inventory per facility
  • Verifies that their physical inventory matches SDS Vault inventory
  • Stamps current inventory with an audit date
  • Allows users to archive inventory that is no longer on the shelf

To create a report: 

Note: To create and manage an inventory report,  you must be an Account  Administrator. 

  1. Click the drop-down arrow next to your name at the top right. Select Administration from the menu.

  2. From the Administration menu, select SDS Inventory Tool. The SDS Inventory Tool window opens.

      
  3. In the SDS Inventory Tool window, choose locations for which you want to run a report. You can choose one or multiple locations.
  4. To include custom codes, click Show. From the Custom Codes list, check the codes  you wish to include. New columns will be added to the report.

  1. Click Run Report to generate a report with active Safety Data Sheets.


In the report:

  • Click Download XLS to download the report in an Excel format
  • Click the document icon to download the report in a pdf format
  • Click Email to email the report

Verify: To verify that your location inventory matches the SDS Vault inventory, select the product and then click Verify. The Verified window opens. Click OK. The verified date is added to the Inventory Tool report and to the Product List Vault report. 

Archive: To archive a product that is not in the SDS Vault inventory, click Archive. You can select multiple products to archive at the same time.
