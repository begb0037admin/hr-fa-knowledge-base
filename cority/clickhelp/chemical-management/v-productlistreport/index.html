Product List Report

The Product List report displays the list of chemicals for your location. This report can be used to comply with the requirement in the OSHA Hazardous Communication Standard for a comprehensive chemical list by location.

To create a Product List report

  1. Click Vault Main Menu (). The Vault navigation pane displays. Select Product List from the Reports list.

  2. Select a Type from the list.

  3. To include Custom Codes, click show then check the codes to include.

  4. Click Run Report.

    The report is displayed. Click Download XLS to download the report in Excel format. Click the document icon to download the report in the pdf format.
