Transactions Report

The Transactions Report shows information about the Distribution transactions. , including

To view the Transactions Report:

  1. Select the folder icon in the Distribution header and select Transactions from the Reports menu.

  2. Enter filter information as desired, or leave filters blank to see all.

  3. Click Download Transaction History to download a spreadsheet listing the transactions.

    Information includes: Document Name, Customer Code, Sent From, Customer Number, Customer Name, Email, Country, Distributed On, File Name

Click in the Resend column to resend a SDS document.
