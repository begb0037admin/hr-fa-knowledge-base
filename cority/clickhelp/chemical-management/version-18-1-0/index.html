Version: 18.1.0 Released: 10/16/2019

New Features and Improvements

  • The SDS Inventory Tool: Administrators now have a better way to manage their chemical inventory by creating an audit report per facility and archiving inventory by multiple items.
  • Form Response Report Enhancement: The Form Response Report can now provide the data for a specific time period and a specific user.
  • Security Policies: Administrators can now enforce security policies by enabling or disabling Password Complexity and Password Length and by forcing a password reset.
  • SDS Vault User Interface Enhancement: The Vault UI is now available in the Vietnamese language.

General Improvement and Bug Fixes

  • Regulator: CHEM-816 The Expiration Date column has been added to the Regulator Parametric Report.
  • Data Entry: CHEM-766 More data can now be stored in "Other" phrases field.
  • SDS Vault: CHEM-2115 When an ID number is de-duped, the custom code now is transferred to the active ID number.
  • Gatekeeper: CHEM-1532 The Gatekeeper non-approved requested products are no longer showing in the drop-down menu on the Vault search page.
  • Data Entry: CHEM-2158 After adding, deleting or updating an ingredient, the Data Entry tool no longer refreshes.
  • Gatekeeper: CHEM-1968 Approved products now are assigned to the STM Vault.
  • SDS Vault: CHEM-1170 The issue of 404 error when viewing SDS in the archive manager is resolved.
