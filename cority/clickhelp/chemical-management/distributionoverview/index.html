Distribution

The Distribution module receives RSS feed files with product transaction information and sends SDS documents to email addresses specified in the feed file.

The RSS feed file with product SDS information is uploaded to the secure FTP site. The servers search for new files daily, processing the data and instantly sending SDS documents to the email addresses specified in the Distribution settings.

The feed file can be processed immediately from the Feed Files report page by clicking the Get Feed File button.

The Distribution module also provides detailed reports about transactions, exceptions (problems), the feed files, and the emails.

The Distribution Transactions report displays by default when you open the Distributions module. For help about this report, see Viewing the Distribution Transactions Report.

Note:  The document to distribute must reside in the location specified by the filename of the feed file. If it does not, an exception is reported as "no document found".
