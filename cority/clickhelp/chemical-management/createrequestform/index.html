Creating a Request Form

To create a Request Form

  1. Click the Gatekeeper Main menu. In the Gatekeeper Navigation panel, under Configurations, select Request Form Builder.

    The Request Form Builder List displays forms including any forms you created previously.

  2. To create a new form, click Add Form.

  3. Enter a Name and Description.

  4. (Optional) To display a message to Gatekeeper requestors at the end of the request form, enter text in the Message Displayed at End field.

  5. Click Save. 

    Your new form displays in the form list.

Note:  By default, when you save the form, the form is inactive.  When you edit the form and create the first question, the form is available for activation.
