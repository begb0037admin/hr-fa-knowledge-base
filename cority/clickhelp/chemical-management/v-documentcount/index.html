Document Count Report

The Document Count Report provides a total count of the documents assigned to your vault. It includes breakdowns of how many documents are assigned to each child location. Clicking on the Details links provides more detailed information about the documents in a location.

To run a Document Count Report:

  1. Click Vault Main Menu (). The Vault navigation pane displays. Select Document Count from the Reports list.

  2. The report summary is displayed, with total document count per location. Select Details for a location to view more details.
