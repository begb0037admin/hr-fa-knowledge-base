Supported Question Types

The question field may contain up to 255 characters for all question types. The character limit for answers that requestors enter varies depending on the question type as noted below.

Gatekeeper supports the following question types for both request and approval forms, unless otherwise noted:

CAS #—Displays a field for the requestor to enter a CAS number and provides a button to pre-screen the CAS number entered.

Custom Fields—Displays a custom field (enabled in Vault) with a text box for the requestor to respond. If you check Enable Mapping, Gatekeeper displays any custom field values for the field as choices in a drop-list for the requestor to select.

Date—Displays a date field and a popup calendar for selecting a date with the mouse.

Grid—Displays questions in a table format to requestors. Within this grid, supported questions include true/false, yes/no, multiple choice with options for single or multiple correct answers, text box, and file upload.

File Upload—Provides an opportunity for the requestor to upload a document that supports the request.

Header—Displays header text.

Length of Use Notification—Displays a drop-list with the values Permanent and Temporary. If the requestor chooses Temporary, the popup calendar displays for date picking. When the date is reached, the requestor receives a notification email prompting them to resubmit a new request.

Material Disclosure Outreach (approval form only)—If your Gatekeeper account is connected to your MD account, Gatekeeper accesses your MD supplier information and makes the information available in the MD Outreach question in the approval form. Gatekeeper asks the approver for the supplier name, supplier item, and supplier contact information in the approval form. The approver can also launch a campaign and view the results before approving.

Multiple Choice (Multi Selection)—Displays a question and multiple answers. Requestors can choose more than one answer by clicking option buttons.

Multiple Choice (Multi Selection) with Other—Displays a question and multiple answers, and includes Other, with a text box to enter a value. Requestors can choose more than one answer by clicking option buttons. If they choose Other, they can enter up to 250 characters.

Multiple Choice (Single Selection)—Displays a question and a drop-list with multiple answers. Requestors can choose only one answer.

Multiple Choice (Single Selection) with Other—Displays a question and a drop-list of multiple answers, and includes Other with a text box to enter a value. If requestors choose Other, they can enter up to 250 characters.

Section—Groups questions in sections until the next section or the end of the form is reached.

Text Box (Multi)—Displays a question and a large text box for the requestor to provide information. The requestor can enter an unlimited number of characters.

Text Box (Single)—Displays a question and a small text box for the requestor to provide information. The requestor can enter up to 255 characters.

True/False—Displays a question with a True and a False answer. The requestor clicks an option button.

Yes/No—Displays a question with a Yes and a No answer. The requestor clicks an option button.
