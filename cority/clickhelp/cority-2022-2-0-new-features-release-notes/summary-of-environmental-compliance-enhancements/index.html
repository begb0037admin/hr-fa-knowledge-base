Summary of Environmental Compliance Enhancements

The table below lists the smaller design improvements we have made in Environmental Compliance. The items are organized by component and the components are arranged in alphabetical order. Descriptions of larger features follow the table.

Item Description
CCC-5178

For working with environmental equipment, the new ‘Sample Data’ tab (sublist) can now be added to custom versions of the ML-001267 and ML-000392 layouts.

The sublist has the Environmental-only ‘All Active’ and ‘All Inactive’ list views.

 

 

By default, each of the list views has New and Delete buttons, an Actions menu with the ‘Export List to Excel’ option, and the following columns:

  • Sample Number
  • Sample Description
  • Sample Source
  • Sample Source Type
  • Sample Date
  • Location

The views have multi/add and create/clone functionality.

When the user clicks ‘New’ or opens a record from the sublist, the Sample (ML-003473) layout will be used.

If the user attempts to delete a record from the Sample Data sublist that is also populated on the main Equipment record, the following message will display: The selected Sample Data record(s) are auto-populated and cannot be deleted. (MG-001588)

When a record gets added to the new Sample Data sublist, the corresponding Equipment record will be added to the ‘Related Assets’ tab on the Sample record.

If the Sample Data field on any existing Equipment record is populated, this new Sample Data sublist will be populated accordingly. That is, existing data will be migrated to the new DT_EquipmentSampleData data table.

The Import Utility can be used to import into that new data table.

The relationship between Equipment and the Sample Data records on this new sublist can be reported on using Query Builder and/or Report Writer.

 

CCC-4874

With the ENHESA system settings configured, after executing the 'Update Applicability Data' action in the Publications look-up table, on any questionnaires that are imported, for questions with an Advice Popup Message (additional info), that message will now translate into the user's (a Compliance Manager, for example) native language.

Note: The user's native language must be specified for his or her Language system setting.

 

CCC-4788

A Related Assets tab (sublist) can now be added to custom versions of the Permit Conditions layout (ML-003369).

By default, the tab's list view has the following columns:

  • Asset Code
  • Description
  • Asset Type
  • Location

 

 

These columns can be added to custom versions of the list view:

  • Accuracy Score
  • Address
  • Air Noise
  • Approval No

 

 

The list view has New, Edit, and Delete buttons, and an Actions menu with the following options:

  • Generate Asset Barcodes
  • Print Barcodes
  • Export List to Excel

 

CCC-3743

For ENHESA requlatory content within GX2, some mappings have changed and additional information is now provided.

The ENHESA <lg:RegLevel> field is now mapped to and populates the 'Level' field for Legal Requirements on ML-000061 (Environmental) and ML-000062 (Safety) layouts.

There is a new 'Research Date' field for Legal Requirements on ML-000061 (Environmental) and ML-000062 (Safety) layouts.

The ENHESA <lg:EnhesaResearchDate> field is now mapped to and populates the new field.  

 

An import of ENHESA regulatory content will now examine the ENHESA <lg:ChangeType> field value.

If the <lg:ChangeType> field value for a regulation is 4, the regulation will become inactive (Inactive = True).

For regulations, the 'Publication Date' field and its mapping from ENHESA have been removed.

In the 'Process Status and Log', the 'Revision Date' field is no longer mapped.

 

CCC-3608

RegScan regulations can now be mapped to the user's configured location(s).

For RegScan regulations, when the user selects the 'Refresh Requirements' action, after the processing is finished all new regulations will now be mapped to the proper GDDLOFB node based on the value of the 'Map RegScan Profile To' system setting.

Also, when new (additional) profiles that have been added to RegScan are imported into the system, if the same regulation exists for two or more profiles, that regulation will be mapped to the proper location for each profile based on the corresponding 'Map RegScan Profile To' system setting value.

 

CCC-3475

The new ‘Regulations’ tab (sublist) can now be added to custom versions of the
following layouts:

  • Environmental Compliance Finding (w/Notification) - ML-003116
  • Environmental Compliance Finding (w/Risk) - ML-001319
  • Environmental Compliance Obligation - ML-001318
  • Environmental Corrective Actions layouts – ML-001216, ML-003114, and ML-001245

 

The new ‘Legal Requirements’ tab (sublist) can now be added to custom versions of the following layouts:

  • Safety Compliance Finding (w/Notification) - ML-003126
  • Safety Compliance Finding (w/Risk) - ML-001309
  • Safety Compliance - ML-001310
  • Safety Findings and Actions layouts – ML-001243, ML-001215, and ML-003124

 

Each of these two new tabs has:

  • A default view with Code and Description columns and Create/Clone functionality
  • A Delete button
  • An ‘Export List to Excel’ action
  • Multi-add functionality, which opens the appropriate look-up table picklist

Each can be imported into, and reported on using Query Builder or Report Writer.

 

When a user is completing an audit questionnaire, if a non-conformance was identified and a finding is auto-generated, then its Regulations tab will become populated with the regulations that are linked to the audit question.

When a user is completing an inspection questionnaire, if a non-conformance was identified and a finding is auto-generated, then its Regulations tab will become populated with the regulations that are linked to the inspection question.

 

CCC-1338

An Environmental Manager can now add corrective actions to Sample Data records. which will help his or her organization maintain regulatory compliance.

To support this, the 'Environmental Corrective Actions' tab (sublist) has been added to the following default layouts:

  • Sample Data Water (ML-003473)
  • Sample Data Waste (ML-003472)

 

This new feature ensures that Environmental cloud users no longer require the Emissions Inventory license key to use the full functionality of the Environmental 'Sample Data' module.

All of the expected functionality has been built into the new sublist, and when creating a new Corrective Action record from the sublist:

-The GDDLOFB of the parent Sample Data record will populate on the new record automatically and be read-only.

  • The Source ID of the Sample Data record will also populate automatically.
  • The Source for the new record will be set to Sample Data.

 

CCC-1332

When a document is added to the Documents tab (sublist) on either of the following layouts, or any cloned versions of the layouts, the document is now marked Environmental instead of Emissions Inventory.

  • Sample Data Water (ML-003473)
  • Sample Data Waste (ML-003472)

 

Also, all documents added to that sublist are now provided in the Documents module within the Environmental Cloud.

 

On that same Documents sublist, when the user clicks New to create a new record, the Source field value now defaults to 'Sample Data' instead of 'Emission Source Test Data'.

 

CCC-333

A legal requirement/regulation or permit will now automatically display any newly added corrective actions

In the Safety 'Legal & Other Requirements' and 'Permits' and Environmental 'Regulations' and 'Permits, Policies, & Procedures' modules, the 'Compliance Actions' tab will now display all records associated with the linked corrective plan.

This will ensure your legal requirement/regulation and permit records are accurate and complete.
