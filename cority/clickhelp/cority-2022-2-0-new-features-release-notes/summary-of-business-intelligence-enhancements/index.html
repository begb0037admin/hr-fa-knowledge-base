Summary of Business Intelligence Enhancements

The table below lists the smaller design improvements we have made in Business Intelligence. The items are organized by component and the components are arranged in alphabetical order.

ItemComponent(s)Description
CCC-138
Custom Metrics

You can now attach documents to a metric.

To support this, an 'Attach Document' field and a 'Documents' tab can now be added to custom versions of the 'Custom Metric Entry' (ML-001276) and 'Metric Entry' (ML-000122) layouts.

The 'Attach Document' field provides a 'Select files…' button that will allow you to upload a document.

  • When you attach a document to a metric, it will also display on the new 'Documents' tab (if added to the layout).

 The 'Documents' tab provides a 'Documents for This Metric Entry' view with the following columns: Description, Document Type, Document Date, and Received From.

  • The tab has the New and Delete buttons, and an Actions menu with the Open Document, Print, Sign, Export List to Excel, and Show Record History options.
  • When you open a record from the tab, it will open in its pinned layout.

This will enable users to create more comprehensive Metrics entries by attaching any relevant documents.

CCC-6066
Dashboards
The total number of indicators a user can add to a single advanced dashboard is now limited to twenty.
A dashboard that existed prior to this release and has more than twenty indicators will not be changed, though no new indicators can be added to it. Also, if an indicator is removed from that dashboard, a new indicator cannot be added unless the dashboard's total number of indicators is less than twenty.
CCC-6938
Emissions Inventory
For the emission factor value, to reduce the amount of data and its load time, your Administrator can now submit a support ticket using the Cority Community to request that the following parameter be added to the site file:
  • (<olapemissionfactorvalueyears>X</olapemissionfactorvalueyears>)
When the X is replaced with a numeric value, the DT_EmissionFactorValue table will only maintain X years of data.
  • If set to 7, when the data is loaded, only the last 7 years of data will be provided for each node.
  • For reporting, after dragging the year/month time dimension to its limit, only X years of data will be shown.
If the variable is not set, all values from the specified effective date till now will be shown.
CCC-6382
Reporting
The new 'Password Protected' check box can now be added to Report Scheduler.

When the check box is selected:
  • The 'Encryption Key File' field will be cleared.
  • The new 'Email(s) To Send Password' text field (with limit of 250 characters) will appear and be required.
    • This will enable the user to add multiple email addresses, separated by semi-colons, to which the encrypted password will be sent.
  • Each recipient will receive an initial email titled '[Report Name] Password Protected' and a second email with the zipped report, which will open with use of the encrypted password.
CCC-3070Reporting

There is a new 'Wrap report columns with high character count' Global/User system setting, categorized under the Reports module. The setting is a check box, and by default it is not selected. When not selected, the columns in reports will wrap appropriately where spacing allows. If a column title or field in a report has a high character count and limited or no word spacing, and this setting is selected, the text in the column will now be forced to wrap instead of the column expanding in width.
