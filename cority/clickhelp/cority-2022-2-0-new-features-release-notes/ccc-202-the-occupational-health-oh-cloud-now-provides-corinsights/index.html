CCC-202: The Occupational Health (OH) cloud now provides CorInsights

  • CorInsights for OH will use existing data to generate key health insights.
  • If the CorInsights feature is added to a layout, a lightbulb icon will display on the layout next to the Actions menu. If insights are available for a particular record, the icon will be blue.
  • CorInsights can now be added to custom versions of the following layout types:
    • Audiometric
    • Case Management
    • Clinic Visit
    • Pulmonary Fit Testing (PFT)
  • For example:
    • On a Case Management record, a CorInsight could be: “This worker has current restrictions. More Info”
    • On a Clinic Visit record, a CorInsight could be: “BMI results are available for this worker. More Info”
  • The More Info link will take the user to the corresponding record or records.

Impact to Existing Users:

  • These CorInsights will help users:
    • Save time when aggregating and analyzing data.
    • Quickly and efficiently address the most critical issues.

Additional Configuration Considerations:

  • Beyond what is described above, no additional configuration is required.
  • For information on how to configure custom layouts, see the GX2 User Guide.
