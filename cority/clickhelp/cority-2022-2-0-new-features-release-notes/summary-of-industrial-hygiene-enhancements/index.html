Summary of Industrial Hygiene Enhancements

The table below lists the smaller design improvements we have made in the Industrial Hygiene Cloud. The items are organized by component and the components are arranged in alphabetical order.

ItemDescription
CCC-7523

For importing IH Fit Test results, the maximum character limit for both the Equipment Code and Equipment Description fields is now 100.

 

CCC-7105

Whether creating or copying an IH Survey record, the character limit for the Survey ID field is now always 20.

 

CCC-6891

It is now easier for an Industrial Hygienist to analyze his or her exposure datasets for lognormality utilizing the MVUE parametric data analysis calculations from the AIHA IH Stat worksheet. This will make it easier for the Industrial Hygienist to better understand his or her workers' exposure profiles.

To support this, the following labels in the Lognormal Statistics section have been changed:

  • 'Estimated Arithmetic Mean' is now 'Estimated Arithmetic Mean - MVUE'
  • 'Confidence Limits' (with the two fields representing the LCL and UCL) is now 'Land's "Exact" Lower and Upper Confidence Limits for the MVUE'
  • '(95% certain the mean is between these two values)' is now '(95% certain the MVUE is between these two values)'
  • 'UTL' is now 'UTL 95,95'

 

The calculation for the MVUE from the mean calculation currently in the 'Estimated Arithmetic Mean' field has been optimized.

 

CCC-6366

For updating 'IH Agent Standard' records using the Import Utility, the composite key now includes the Source.Code parameter. That is, the composite key now consists of Agent.Code, Type.Code, Effective.Date and Source.Code.

 

CCC-6252

For an Industrial Hygienist creating a batch notification letter to be sent to workers that will include primary and/or secondary exposure assessment results, there is a new 'Send Only If the Results Are Populated' check box next to the existing 'Primary/Secondary Results' radio buttons. If the new check box is selected, the letter will now only be sent if data exists for the type of results specified.

 

CCC-5975

The Hearing Fit module in the Industrial Hygiene cloud now supports the importing of hearing fit test records (.csv format) in the new Earfit Dual 2.0 standard (for the 3M E-A-Rfit program). The results will populate on the Hearing Fit record. Any failed import can be re-processed from within the Process Status & Log. For information on importing Hearing Fit test data into the Hearing Fit module, see the GX2 User Guide.
