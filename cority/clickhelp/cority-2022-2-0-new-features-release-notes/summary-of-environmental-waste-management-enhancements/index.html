Summary of Environmental Waste Management Enhancements

The table below lists the smaller design improvements we have made in Waste Management. The items are organized by component and the components are arranged in alphabetical order.

ItemDescription
CCC-8123 and 2675

In the Waste Container Management module, the 'Accumulation Start Date' field (for layout ML-000228 and any of its clones) is now only mandatory (a value must be provided) when the 'Disposed Amount' value is greater than 0. This will enable users to inventory empty waste containers in advance, without having to start the count on accumulation days.

 

CCC-3530

To help ensure that waste is transported to the proper treatment, storage and disposal Facility (TSDF), when a user generates a waste manifest (Environmental > Waste Management > Actions > Generate Waste Manifest for Selected Records) from a single Waste Management record or from multiple Waste Management records containing waste streams with matching Generator and TSDF values:

  • The 'Generator' field on the 'Generate Waste Manifest' dialog box will now auto-populate with the generator that corresponds to the record's waste stream (waste profile).
  • The 'Disposal Facility (TSDF)' field on the dialog box will now auto-populate with the TSDF that corresponds to the record's waste stream.

 

When the user generates a waste manifest from multiple Waste Management records containing waste streams that do not have matching Generator and TSDF values:

  • The 'Generator' or 'Disposal Facility (TSDF)' fields on the 'Generate Waste Manifest' dialog box will not auto-populate.

 

As well, a new 'Date of Disposal' timestamp field is now provided on the 'Generate Waste Manifest' dialog box. The 'Date of Disposal' value entered in that field will be automatically transferred to the 'Date of Disposal' field on the newly created Waste Shipment record.

Also, the 'Disposal Notes', 'Manifest Sent to Regulator' and 'Manifest Returned from Regulator' fields on the 'Generate Waste Manifest' dialog box have been re-positioned.  

 

CCC-2898

In the Waste Profiles look-up table, the following columns can now be added to custom versions of Waste Codes list views:

  • Federal
  • State/Province
  • Waste Disposition
  • Other
  • Inactive
  • Country
  • Form Code
  • Management Method Code
  • Region
  • Source Code
  • Waste Minimization Code

Each corresponds to the equivalent Waste Code check box field on the Waste Profile layout (ML-003326).
