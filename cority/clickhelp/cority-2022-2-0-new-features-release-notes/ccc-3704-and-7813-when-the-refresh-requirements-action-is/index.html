CCC-3704 and 7813: When the 'Refresh Requirements' action is used for RegScan content, the required Applicability Assessments now get created

  • In the Environmental or Safety 'Regulations' module, when a user clicks 'Refresh Requirements' and the content provider is RegScan (specified by populating the 'RegScan Feed Name' and 'RegScan End-User License' system settings):
    • The applicable regulations are imported.
    • The RegScan 'Audit Questionnaire' content is refreshed (the same result as the user selecting the 'Refresh Compliance Questionnaire' action in the Questionnaires look-up table).
    • One Applicability Assessment is created for each RegScan profile.
  • This results in the following:
    • All regulations associated with each RegScan profile get updated or added.
    • For each regulation, the required Audit Questionnaires with associated legal requirements get created and are listed in the 'Related Audits and Inspections' sublist of the regulation.
  • Each Applicability Assessment record will have:
    • The same location as the associated profile.
    • A status of Completed.
    • The set of applicable regulations, and one or more associated audits.
  • Each Audit record will have:
    • The same location as the associated profile.
    • A set of legal requirements identical to the ones associated with the Applicability Assessment record.
    • A set of questionnaires related to all of those legal requirements.

Impact to Existing Users:

  • This will make it much easier for a Compliance Manager to complete regulatory audits based on his or her applicable RegScan regulations, therefore help to ensure sites are in compliance.

Additional Configuration Considerations:

  • Beyond what is described above, no additional configuration is required. For information on working with Environmental and Safety regulatory content, see the GX2 User Guide.
