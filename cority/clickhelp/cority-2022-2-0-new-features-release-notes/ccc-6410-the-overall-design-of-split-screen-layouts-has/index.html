CCC-6410: The overall design of split-screen layouts has been enhanced

  • The following changes have been made:
    • Shading has been added to improve readability.
    • The horizontal scroll bar for the entire split-screen is no longer required, so has been removed.
    • The height of the panels no longer exceeds the height of the split-screen, so vertical panel scroll bars have been removed.
    • For a panel of the default size, a horizontal scroll bar is no longer required, so horizontal panel scroll bars have also been removed.
    • For each panel, the panel width is now adjustable. Note: When adjusting the width, a horizontal panel scroll bar will be added if necessary.
    • The two panels are now collapsible/expandible.
    • When adjusting panel width and/or resizing the browser window, the content on the split-screen is responsive.
    • On a split-screen layout in the OH cloud:
      • When a questionnaire is selected from a sublist in the right panel, the questionnaire will now open beneath the sublist so that it can be viewed and updated/completed within that right panel (for example, in the same way that a Vital Signs record can).
      • When a Medication, Absence, Document, or Letter-(including Case Documents and Letters) record is selected from a sublist in the right panel, the record will now open beneath the sublist so that it can be viewed and updated within that right panel (which is the same behavior currently for Vital Signs and Allergies).
      • When the ‘New’ button is selected from a sublist in the right panel, the corresponding layout will open beneath the sublist in the right panel, so that a record of that type can be created.
    • Note: One or more of the supported sublists displayed in the right panel of a split-screen layout can be opened simultaneously.

Impact to Existing Users:

  • These enhancements reduce clicks and greatly improve the overall user experience of workflows that utilize split-screen layouts.

Additional Configuration Considerations:

  • Beyond what is described above, no additional configuration is required.
