Changes Since Version 1.0

The following release notes have been added: CCC-6066, CCC-6938, and CCC-6382

The following release notes have been updated: CCC-6383, CCC-5113, CCC-2969, CCC-6374, and CCC-202

CCC-2587 has been removed.
The functionality is complete and has been validated, but it is awaiting deployment by our IT department. Its deployment will align with the ESR export functionality scheduled for release 2022.3.0. Currently you will still see front-end components, an ESR Config module and ESR Import Log in the GX2 Administrator tools for examples, but until deployment they will not be fully functional.

Release notes for CCC-7641 and CCC-6540 have been added. Each was part of the removed CCC-2587 (see above). They are complete, and can be utilized by any client—even those who do not use NHS’s ESR service.
