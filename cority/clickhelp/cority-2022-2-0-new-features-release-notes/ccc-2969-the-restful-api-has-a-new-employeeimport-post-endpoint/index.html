CCC-2969: The RESTful API has a new 'employeeimport' POST endpoint

  • This new endpoint will accept all Cority HR Integration Utility (formerly MEIP) options and parameters. Note: These are only supported for this POST endpoint (not with GET, PUT, etc.).
  • The parameters will be provided in an options envelope, and the data returned will be provided in a records envelope.
  • For the following parameters, specifically:
    • updateExistingRecords - This is only applicable in the POST request. If an employee number already exists, the corresponding employee record will be overwritten with the corresponding data returned.
    • insertBaseTables - If a look-up table code does not exist, one will be created and then assigned to the specified employee.
    • forceLookupTableUpdate - If a look-up table description is specified and it is different from the one in the GX2 database, the one in the database will get updated and then its code will be assigned to the employee.
    • disableSegUpdate - This will ensure that exposure groups do not get updated for imported/updated employees.
    • autoCreatePortalUser - If a login ID exists for the employee and his or her email address is not null in the body of the POST request, a Portal user will be created for the specified employee. If an employee is terminated, his or her Portal user will be deactivated (either scheduled for the future date of termination or immediate for the current or a past date of termination).
    • mergeRecordsWithMatchingSsn - If a historical employee with SSN already exists in the GX2 database for a new employee within the request, this will merge the historical employee (data) with the new employee. If an employee is reinstated, his or her corresponding Portal user will become reactivated.
  • The import format will be obtained from the format of the first record imported.
  • The standard HR Integration Utility batching will occur when sending the data to GX2.
  • We recommend importing only 100 employee records at a time (per call).
    • To import more than 100, make multiple calls of 100, batching the larger file manually before importing.
  • Note: This endpoint will be excluded from the RESTful API 'Daily Threshold Limit'.
  • The response body for the call will match that of standard HR Integration Utility responses.
  • To use this POST call:
    • The user's User layout must have the 'MEIP User' check box selected.
    • The user's role must be granted the new employeeimport.apiwrite security action.
