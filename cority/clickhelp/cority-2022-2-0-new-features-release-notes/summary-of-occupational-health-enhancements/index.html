Summary of Occupational Health Enhancements

The table below lists the smaller design improvements we have made in the Occupational Health Cloud. The items are organized by component and the components are arranged in alphabetical order. Descriptions of larger features follow the table.

ItemComponent(s)Description
CCC-6374Case Management

On Case layouts, the 'Display WC Forms' action can now be made available instead as a tab. To support this, the new 'Forms' tab can be added to custom versions of Case layouts.

 

By default, the tab has the following two list views:

  • Available Forms for this Injury/Case Record
  • Not-selected Forms for this Injury/Case Record

 

The forms available on the tab will change based on the Jurisdiction value specified on the Case record.

The new tab has a Delete button and an Actions menu with the 'Print' and 'Export List to Excel' actions.

 

CCC-7641Employee Care

The new Results tab (sublist) can be added to custom versions of the Immunization Code layout.

This tab can be used to link/associate specific result options (the applicable ones only) to each immunization code. When this is configured and on an Immunization record, the user specifies an immunization code in the ‘Immunization Test’ field, only the applicable result options will be available in the ‘Immunization Result’ field picklist.

If this new Results tab is not used, then the ‘Immunization Result’ field picklist will continue to display every option from the Results look-up table.

 

CCC-6119Employee Care

A column for the Problem List check box can now be added to custom versions of the following Dx list views:

  • Diagnoses Related to This Case and Pre-existing Medical Conditions
  • Diagnoses Related to Cases
  • Pre-existing Medical Conditions or Not Case Related
  • All Diagnoses by Medical Description
  • All Diagnoses by Diagnosis Date

 

Such views can be configured to use the column for sorting and/or filtering.

 

CCC-3221Employee Care

The Employee column has been added to the Clinic Visit Risk Assessment Entry tab (sublist), so that a user with the required security configuration can now view the Employee Risks records for an employee on the Employee Risks tab (of a Medical Chart record, for example).

 

 

CCC-6601Medical Monitoring

An 'All [module] Questionnaires' list view has been added to the Questionnaire tab (sublist) in the following modules:

  • Audiometric
  • Immunization
  • PFT
  • Respirator Fit
  • Travel

By default, the view has the Date and Questionnaire columns, New and Delete buttons, and an Actions menu with the associated actions.

A questionnaire opened from the view will open in the ‘Medical Questionnaire Response Header’ layout.

The view can be granted to or prohibited from a role, site security is respected by the view, and only medical questionnaires accessible to the logged in user and for the selected global employee will be listed.

 

An ‘All [module] Notes' list view has been added to the Notes tab (sublist) in the following modules:

  • Audiometric
  • Clinical Testing
  • Drug Testing
  • Immunization
  • PFT
  • Travel
  • Vision Testing

By default, the view has the Date, Time, Author, Signed?, and Notes columns, New and Delete buttons, and an Actions menu with the associated actions.

A Note record opened from the view will open in the ‘Medical Note’ layout.

The view can be granted to or prohibited from a role, site security is respected by the view, and only medical notes accessible to the logged in user and for the selected global employee will be listed.

 

An ‘All [module] Letters' list view has been added to the Letters tab (sublist) in the following modules:

  • Audiometric
  • Chest X-Ray
  • Clinical Testing
  • Drug Testing
  • Immunization
  • PFT
  • Travel
  • Vision Testing

By default, the view has the Letter Code, Created Date, and Draft columns, New and Delete buttons, and an Actions menu with the associated actions.

A Letter record opened from the view will open in the ‘Medical Letter’ layout.

The view can be granted to or prohibited from a role, site security is respected by the view, and only medical letters accessible to the logged in user and for the selected global employee will be listed.
