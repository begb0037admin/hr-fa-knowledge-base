CCC-3917: A Cority Administrator can now update the Cority private/public key pair

  • This no longer has to be done by Cority Customer Support or DevOps.
  • There is a new DT_CoritySAMLKey data table. Note: The table is not available in Query Builder or Report Writer, nor is it accessible through the RESTful API.
  • DT_CoritySAMLKey records have the following parameters:
    • Config File - for storing a config file
    • Private - the key
    • Passphrase
    • Start Date
    • End Date
  • In System Settings, there is a new 'Download Cority Public Key' action.
  • The action will check if there is a record in DT_CoritySAMLKey with a Private value of False and a current date and time between the Start Date and End Date.
    • If so, that key will be downloaded to the client's system.
    • If not, the following message will display: There is no Cority Public Key currently available.
  • In System Settings, there is also a new 'Update Cority Private Key' action.
  • When selected, the following message will display: Please click ‘Yes’ to confirm you have installed the updated Cority Public Key. Otherwise, click ‘No’ and run the 'Download Cority Public Key' action first.
    • If the user clicks No, the Cority Private Key will remain the same. It will not be overwritten/updated.
    • If the user clicks Yes, the action will check if there is a record in DT_CoritySAMLKey with a Private value of True, a Passphrase value (not null), and a current date and time between the Start Date and End Date.
      • If not, the following message will display: There is no Cority Private Key currently available.
      • If so (a key is available), that key will be applied automatically to the 'SSO SAML 2.0 Private Key' system setting, overwriting the existing key.
        • The following message will then display: Please test logging in from a different tab or browser while keeping this current tab and dialog box open. Once you do and login is successful, click ‘Yes’. If you click ‘No’, Cority will revert to the previous Private Key. If you click neither within 60 seconds, Cority will revert to the previous Private Key.
