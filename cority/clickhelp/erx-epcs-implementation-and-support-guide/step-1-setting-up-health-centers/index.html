Step 1: Setting up Health Centers

Repeat the below steps for each health center that will be prescribing eRx medications.

  1. Select Administrator > Look-up Tables.
  2. Search for and select the Health Center look-up table.
  3. Select a health center record, or click New to create a new record.
  4. Complete the following required fields and click Save:
    • Description
    • Address
    • City
    • State
    • Zip
    • Phone Number
    • Fax Number

Note: Ensure the description includes the organization’s name to ensure the it can be identified in the eRx transaction and also ensure the description is less than 35 characters.
