Step 1: Registering EPCS Users

  1. Instruct each EPCS user to access Symantec VIP on their smartphone and download a soft token. Note: The soft token will be activated in a subsequent step.
    1. Although Soft Tokens are recommended, the client can also if they would like, request a Hard Token from Dr. First.
      1. Hard tokens are requested by email.  These requests should be sent to registerEPCS@drfirst.com using the template below.  If you are ordering tokens that need to go to multiple locations/addresses we ask that you clearly separate and bundle your requests by location in a single email or submit a separate email request for each location (preferred).
        1. Name of the organization
        2. Full valid address, including suite #:
        3. Organization ID (optional):
        4. Number of Tokens: 
        5. Providers Name(s):
        6. Point of Contact (first & last name):
        7. E-mail address for shipping/tracking info:
  2. Log in as a user with the eRx Admin functional role assigned and select a user record that will be registering with Dr. First.
  3. Select Action > Register User with EPCS Gold. When the ‘EPCS Gold Registration’ prompt appears, enter the user’s full name in Last Name, First Name format. In the user record, ensure the ‘First Name’, ‘Last Name’, and ‘Email Address’ fields do not contain extra spaces.

  1. Click Register. This will initiate a call with the Dr. First API. Dr. First will email the user to initiate the EPCS registration process.
  2. Instruct each EPCS user to click the link in the Dr. First registration email. Users must then complete the Dr. First Identity Proofing Process (IDP), during which they will activate the soft token that was downloaded in step 1.

During the registration process, users can specify if they want to receive their EPCS code in the mail or in a text message sent to their smartphone; encourage users to select the text message option.

Note: Cority cannot perform this process on the customer’s behalf.

  1. Once the IDP process is complete users will be issued a code either by mail or text message, depending on the preference selected in the previous step. Instruct users to do the following:
  1. Log into Cority and select Occupational Health > Inbox.
  2. Select the eRx Transactions tab at the top of the screen.
  3. Select Actions > Launch EPCS Gold Prescriber Dashboard. The user will be directed to the Dr. First website.
  4. Enter the user name and password that were created during the Dr. First registration process.
  5. Enter the soft token that was obtained in step 1.
  6. Enter the code that was received by mail or text message.

Once complete, the user’s status will change to ‘Enrolled’.
