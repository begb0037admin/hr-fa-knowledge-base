Step 2: Verifying Users’ Status

  1. To verify users’ EPCS status, select a user and go to Actions > Get EPCS Gold Registration Status.

Note: If you want to view users’ EPCS registration status directly from the user record, you must add the ‘EPCS Status’ and ‘EPCS Invite from Cority’ fields to the layout.

  1. Once registration has been successfully initiated by the eRx Admin, users will show a status of ‘Invited’ and the ‘EPCS Invite from Cority’ checkbox will be selected in the user record.

Note: You must refresh the user profile to see the ‘EPCS Invite from Cority’ checkbox.
