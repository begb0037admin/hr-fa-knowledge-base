EPCS Customers

Ensure the following prerequisites are met for all EPCS customers.

Test Site Setup

  • Customer Support must log into the EPCS Admin Console test site and complete the following forms:
    • Manage Organization
    • Add New Organization
      • Source Organization ID: Salesforce ASP client ID
      • Organization Name/Label: Salesforce account name
      • Address: Salesforce billing address
    • Customer Support must create an IT Support ticket that contains the following:

      • Please add the following XML to the test site file:

      [Salesforce Account Name]

      Organization ID: [Salesforce ASP Client ID]

      URL: [Client Test Hosted URL]

      XML:

      <EPCSGold>

      <SourceOrganizationId>Salesforce ASP Client ID</SourceOrganizationId>

      </EPCSGold>

    • IT Support must create an RFC. Once complete, IT Support must notify Customer Support.
    • Customer Support must request Professional Services to test the EPCS connection in the test site as follows:
  1. Log into the test site as an eRx Admin user.
  2. Select the eRx Admin user profile.
  3. Select Actions > Launch EPCS Gold Logistical Access Dashboard.
  • If the EPCS connection is successful, Professional Services must notify Customer Support.

Production Site Setup

    • Customer Support must log into the EPCS Admin Console production site and complete the following forms:
    • Manage Organization
    • Add New Organization
    • Source Organization ID: Salesforce ASP client ID
    • Organization Name/Label: Salesforce account name
    • Address: Salesforce billing address
  • Customer Support must create an IT Support ticket that contains the following:

    • Please add the following XML to the production site file:

    [Salesforce Account Name]

    Organization ID: [Salesforce ASP Client ID]

    URL: [Client Production Hosted URL]

    XML:

    <EPCSGold>

    <SourceOrganizationId>Salesforce ASP Client ID</SourceOrganizationId>

    </EPCSGold>

  • IT Support must create an RFC.
    • Changes to production servers must receive CAB approval. CAB approval occurs each Tuesday.
    • Once CAB approval is obtained, IT Support will schedule database changes for the customer. Customer Support and Professional Services will be notified when this is complete.
    • If the customer is already live, the customer must complete an SR. The SR must then be attached to the RFC.
  • Customer Support must request Professional Services to test the EPCS connection in the production site as follows:
  1. Log into the Production site as an eRx Admin user.
  2. Select the eRx Admin user profile.
  3. Select Actions > Launch EPCS Gold Logistical Access Dashboard.
  • If the EPCS connection is successful, Professional Services must notify Customer Support.
