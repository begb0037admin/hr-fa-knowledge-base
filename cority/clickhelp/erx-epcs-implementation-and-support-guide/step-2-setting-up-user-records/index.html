Step 2: Setting up User Records

Repeat the below steps for each user who will be using the eRx service.

  1. Select Administrator > Users.
  2. Select a user record, or click New to create a new record.
  3. Complete the following required fields and click Save:
    • First Name
    • Last Name
    • Gender
    • Email Address
    • Address
    • City
    • State
    • Zip
    • Phone Number
    • NPI Number
    • DEA Number

Note: A DEA number is required for the Controlled Substance Service Level only; however, it is recommended that you include a DEA number for all eRx users in the event of service level changes.

Assigning Granted Roles

  1. Click the ‘Granted Roles’ tab at the top of the user record and click New.
  2. Click the ‘+’ icon. The Roles form will open.
  3. Place a checkmark next to ‘eRx Prescriber’ and click Select.

Assigning Linked Health Centers

  1. Click the ‘Linked Health Centers’ tab at the top of the user record and click New.
  2. Type the name of a health center in the Health Center field. If a matching record exists, it will appear below the Health Center field. Select the record.
  3. Click Save and Close.
  4. Repeat steps 2-3 for each health center you want to link to the user.
  5. Ensure each eRx Admin has access to the User and Health Center tables so they can access user records, link health centers, and access the various actions required during the eRx/EPCS user registration process.

Ensure all other eRx users (non-Admins) have the following roles:

  • a functional role that includes access to the Clinic Visit component
  • a site role that grants access to the appropriate user data
  • the ‘eRx Prescriber’ role that has permission to perform eRx/EPCS user registration
