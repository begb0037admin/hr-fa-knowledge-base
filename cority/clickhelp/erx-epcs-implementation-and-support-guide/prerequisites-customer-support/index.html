Prerequisites (Customer Support)

Before you proceed with the eRx/EPCS setup instructions, ensure the following prerequisites are met:

  • The client has purchased Lexicomp/Surescripts and/or EPCS from Cority Sales
  • Cority Sales has sent the CRO to Customer Support
  • Customer Support has created a license key
  • Customer Support has created an RFC to create Client Test and Production sites with the license key
