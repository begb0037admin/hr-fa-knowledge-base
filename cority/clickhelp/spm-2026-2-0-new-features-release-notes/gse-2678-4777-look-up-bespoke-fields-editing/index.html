GSE-2678 and 4777: Look-up values for bespoke fields can now be edited.

In Bespoke Field Management, each look-up value for a look-up bespoke field has the new Edit option. If selected, the value’s name and display order can be changed.
Note: Any such changes will be made for both future and all applicable historical data. A warning message will notify the user of that before allowing the changes to be applied.
