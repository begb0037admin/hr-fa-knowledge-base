GSE-2671: Bespoke fields can now be archived.

If you are no longer using a particular bespoke field, in Customisation > Bespoke Fields each bespoke field now has an Archive button that can be used to effectively delete that field. A completely archived bespoke field will no longer appear in Inputs and will be hidden from reports. Also, the Bespoke Field Management list has a new ‘Show archived records’ check box at the top right. If selected, all archived bespoke fields will be included in the list, and each will have a Restore button beside it. If you click a Restore button, that bespoke field will be restored as it was before being archived. That will bring back its data as well.

Also in Bespoke Field Management, for look-up bespoke fields, each look-up value has an Archive button, Those buttons can be used to archive one or more of the look-up options. If you do that for any look-up option, that will prevent it from being available for any new Inputs, but it will remain selected where applicable for any historical data and remain available in reports if used in the past. If the ‘Show archived records’ check box is selected at the top right of the screen, such archived look-up options will be visible in Bespoke Field Management with Restore button for restoring.
