GSE-4390: Consumption labels are now shown on the Audit Dashboard and through the outbound API.

Consumption labels are used to add custom names for our standard categories. They are configured in Customisation > Consumption Labels. For example, the Emission Sub-Type might be named Standard Grid (General), but a client might want to add the label Average Electricity to be used instead. That label will then appear on applicable Input forms. Now when added, such labels will appear where applicable on the Audit Dashboard (in the new Consumption Label column) and through the outbound API. Therefore, data can now be analyzed under those categories when the Audit Dashboard and outbound API are used.
