Overview

At Cority we are committed to continually improving our products. The 2026.2.0 SPM release contains new and improved functionality in several areas—including consumption label enhancements, new inbound APIs and tabular data entry functionality for the rest of the consumption types, an enhancement to the Invoice Processing AI Agent, and archiving and editing features for bespoke fields.

Tips:

  • We use the number that prefixes each enhancement (for example, GSE-4200) to identify it internally. If you have a question about a feature, its number(s) will help the Cority technical contact quickly access all of the relevant information.
  • Until the software is released to Production environments, please check this document for updates.
  • The version number below is the document version, not the software release version. A number greater than 1.0 indicates that one or more updates have been made.
