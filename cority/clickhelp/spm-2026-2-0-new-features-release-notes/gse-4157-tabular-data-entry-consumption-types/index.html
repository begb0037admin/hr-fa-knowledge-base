GSE-4157: Tabular data entry is now available for all consumption types.

Previously, the tabular data entry functionality was available for consumption types Electricity, Fuel, Water, and Heat. It is now available for all of your consumption types. For more information on the tabular data entry functionality, see the initial release note for it here.
