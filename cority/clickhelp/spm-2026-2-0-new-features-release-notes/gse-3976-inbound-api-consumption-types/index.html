GSE-3976: The inbound API is now available for all consumption types.

Previously, the inbound API was available for consumption types Electricity, Fuel, Water, and Heat. It is now available for all of your consumption types.

These API enable the automated collection, submission, and updating of consumption data from external systems to the SPM solution.

API-based data uploads will allow clients to streamline data entry, reducing manual effort and risk of errors, and tailor data templates to fit their needs, which will result in faster, more reliable data ingestion.
