Other Feature Updates

GSE-3359     New airports have been added to the airports list.

GSE-4356     New currency codes with their associated conversions have been added to applicable Input form drop-down menus and are supported in Microsoft Excel uploads.

GSE-4712      The following two node types (or entity types) can now be added through Admin Settings > Organisation > Nodes & Data Sources > Create node: Retail Pod and Research & Development. Node types can be modeled with different intensity factors in Environment > Settings > Modelling > Intensity Factors, and are available in a number of reports/exports.
