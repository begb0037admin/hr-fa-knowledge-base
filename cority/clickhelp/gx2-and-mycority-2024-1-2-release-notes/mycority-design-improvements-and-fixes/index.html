myCority Design Improvements and Fixes

The table below lists the design improvements and fixes we have made in the myCority 2024.1.2 release. The items are organized by component and the components are arranged in alphabetical order.

Item #Component(s)ReportedDescription
CCC-16903Dashboards2024.1.1

When an Advanced Dashboard name has been translated into a language other than English and the myCority user's language is configured to be that language, in My Dashboards the user can now successfully search for the dashboard using its translated name.

 

CCC-16656Environmental – Waste ManagementN/A

When a field on a Waste record (for example, Disposal Cost) has no value (is empty), the Waste list view in myCority will no longer fail to load and generate an unexpected error.

When a field on a Waste Container record (for example, Container Rental Cost) has no value (is empty), the Waste Container list view in myCority will no longer fail to load and generate an unexpected error.

 

CCC-15642Ergonomics – Enhancements N/A

A number of enhancements have been made to the office ergonomics solution. These include:

  • A new To-Do list on the ‘Personal Risk’ dashboard
  • The availability of configurable help text
  • The ability to configure the frequency at which the data privacy disclaimer appears, using the ‘Display the privacy agreement for Portal/myCoirty users on login’ system setting

 

CCC-12234Event ReportingN/A

When the myCority 'Event Report Selection' look-up table is not used, the order in which the Safety and Environmental event reports are displayed now respects the order specified in the corresponding (Safety or Environmental) 'Event Report Selection' look-up table.

 

CCC-16785MetricsN/A

When a metric entry related to a campaign is due or overdue, the applicable user can now open the record and enter the required data without encountering any unexpected issues.

 

CCC-5813 and 2844Metrics2020.3.0When a Campaign record contains a custom metric without a unit of measure (UOM) and one or more with a unit of measure (UOM) that is linked to a UOM category and the record is opened in myCority, the UOM field for the metric(s) with the UOM will now be enabled, as expected.
CCC-15631Organizational TreesN/A

For the Tree Selector, the user’s site security configuration is now applied to the tree nodes.

 

CCC-8198Organizational TreesN/A

For organizational trees, the 'Restrict Leaf Member Selection' field property on layouts now functions properly.

 

CCC-16907Safety – Permit to Work2024.1.1

In both GX2 and myCority, for a custom version of the Safety 'Work Permit' list view that has the 'Permit Type' column, 'Permit Type' now provides the permit type code. The new 'Permit Type Description' column provides the description.
