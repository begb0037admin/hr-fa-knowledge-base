GX2 Design Improvements and Fixes

The table below lists the design improvements and fixes we have made in the GX2 2024.1.2 release. The items are organized by component and the components are arranged in alphabetical order.

Item #Component(s)ReportedDescription
CCC-16938Business Intelligence – Dashboards2024.1.1

Advanced Dashboards will now successfully export to PDF and Microsoft Excel.

 

CCC-15154Business Intelligence – Dashboards, Query BuilderN/A

When Flex Fields are used in a Query Builder report, the data retrieved will now successfully display in the report and on an Advanced Dashboard indicator. Also, both the report and the dashboard can now successfully be exported with the correct data to CSV, Microsoft Excel, or PDF.

 

CCC-6837Business Intelligence – Query BuilderN/A

For a Query Builder report, if a filter or conditional formatting has been applied to a column and then the aggregation type for that column is changed, an unexpected error will no longer be generated when the report is run.

 

CCC-16998Chemical ManagementN/A

To facilitate the 3E Master Library integration, which will be made available in an upcoming release, new fields have been added to the following :

  • Agent Hazard SDS look-up table
  • Agent Hazards / Chemical Products look-up table
  • Chemical Phrases look-up table
  • Chemical Handling data table
  • SDS Request Alert data table

The new fields are to be used with the Master Library, when it is available.

 

CCC-16759Environmental – Emissions InventoryN/A

The Import Utility can now be used to successfully update the STARS data tables.

 

CCC-10697Environmental – Waste ManagementN/A

For a waste shipment with multiple containers, a workflow status update will now apply to all of the containers, not just the first one.

 

CCC-16949ErgonomicsN/A

When attempting to email an Advanced Dashboard, if a user added in the To field does not have a valid email address configured, the email will no longer be sent to any user (for example, a user added in the CC field). Instead, the email will fail to send and an error message will display.

 

CCC-15642Ergonomics – Employee RiskN/A

You can now send emails, email templates, and view global notes form the ‘Manage Employee Risk’ screen.

 

CCC-15819Ergonomics – ReportingN/A

The Ergonomics cloud now provides the ‘Employee List Report’.

You can access the report from Ergonomics > Ergo Reports. It will also be available in Business Intelligence > Reports.

The report respects the user’s site security configuration.

The report provides office ergonomics information (risk types, overall risk, unresolved issues, etc.), desktop information, and discomfort information for the employees included.

The report can be exported to PDF or Microsoft Excel.

For information on working with GX2 reports, see the GX2 User Guide.

 

CCC-15662
Ergonomics - Reporting
N/A

A user can now email any Ergonomics report to a single employee or to several employees at once.
To support this, a Send Email button is now provided at the top of each report.
If the user selects one or more employees and clicks that button, an email dialog box will open from which the user can send the email.


CCC-16250Ergonomics – Training 2024.1.0

In Ergonomics 'Online Training Sessions', when executing the 'Email Selected Employees' action with all required fields populated and only one email address in the 'To' field, after the email is sent successfully, the confirmation message is now correct.

 

CCC-16247Ergonomics – Training2024.1.0

In Ergonomics 'Online Training Sessions', when executing the 'Email Selected Employees' action, the 'Go To Top' button now functions as unexpected.

 

CCC-6256Business Intelligence – MetricsN/A

In My Metrics, the user can now access due metrics without encountering a load issue.

 

CCC-16728Occupational Health – AppointmentsN/A

When booking an appointment (schedule entry) with or without activities, the available time slots are now calculated and presented as expected.

 

CCC-16491Occupational Health – AppointmentsN/A

The Appointments module now loads efficiently, filters properly, and displays the expected appointments.

 

CCC-16957Occupational Health – Clinic Visit2024.1.1

In the Clinic Visit module, on the HCFA-1500 form, the Delete button now functions as expected.

 

CCC-16770Occupational Health – Clinic VisitN/A

In OH 'Clinic Visit', the space for creating a smart note now remains the expected size and the user can now successfully adjust the font type and size without encountering any issues.

 

CCC-16923Incidents2024.1.1

With the correct license key applied, a user with proper security configuration can now successfully email a questionnaire from within the 'Incident' module.

 

CCC-15338IncidentsN/A

When a module is included in the license key, a user can now successfully email a questionnaire from a record within that module without encountering an unexpected error.

 

CCC-12830Industrial Hygiene – Findings & ActionsN/A

In IH 'Findings & Actions', for a new or existing record with more than one action associated, when scrolling, both the New and Save buttons will now continue to display in the header bar.

 

CCC-16586Platform – Administrator, DemographicsN/A

When a display rule configured to change the Demographics layout based on 'Employee Type' does so, the user can now switch (toggle between) layouts afterward.

 

CCC-16240Platform – Administrator, TranslationsN/A

Specifying only certain HTTP referrers for the Google Translate API now functions properly.

 

CCC-14856Platform – End-User, WorkflowsN/A

On a 'Workflow History' sublist (for example, in the Quality cloud), the 'Export List to Excel' action will now filter the data as expected.

 

CCC-15624Quality – Suppliers N/A

Both the Import Utility and the Cority Data Integration Utility will now import successfully into the External Entity data table when providing the ParentOrganisation.SupplierID. An unexpected error will no longer be generated.

 

CCC-13420Quality – SuppliersN/A

In Quality 'Products', when adding a supplier to a product using the '+' button, the user can now successfully filter the Suppliers list by 'Supplier ID' or 'Supplier Name'.

 

CCC-16907Safety – Permit to Work2024.1.1

In both GX2 and myCority, for a custom version of the Safety 'Work Permit' list view that has the 'Permit Type' column, 'Permit Type' now provides the permit type code. The new 'Permit Type Description' column provides the description.

 

CCC-16657Safety N/A

When and where applicable, the 'Refresh Last Call Date' action now functions as expected and does not generate a license key error.

 

CCC-15715Safety – Event ReportingN/A

A user can now successfully delete a document from a Safety 'Event Report' without encountering an unexpected error.

 

CCC-15302Safety – DocumentsN/A

In Safety Documents, when the Document Type is 'Web Hyperlink', the user can now successfully enter a URL into 'Doc. Http Link' and save. An unexpected error will no longer be generated.
