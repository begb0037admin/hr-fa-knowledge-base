ReadySet Release – October 19, 2022

Deployment for clients to Test (Oct. 5th):

EHS-9251  A multi-select dropdown list will display when a Provider location is selected and show all calendars available for the location. Clients with more than 36 calendars will be able to select and de-select calendar options using a free text search box. A warning message will display if more than 36 calendars are selected for a view, because 36 is the maximum. Once 36 calendars are selected, the other calendar options not be selectable (will be greyed out) until others are de-selected. The default functionality will display up to 36 calendars alphabetically in the view window.

RPTS-657 The enhanced NHSN COVID-19 Summary Report will accommodate new vaccine products. When the initial report was released, the CDC requirements were Pfizer, Moderna, and Janssen only. The new requirements from May, 2022 (Rev 7) no longer need vaccines to be categorized by manufacturer. The new enhancements include other new vaccines such as Novavax and Pfizer Bivalent in the up-to-date count. With these changes, the report will no longer hard-code every available product into the report logic. The enhanced report logic/architecture will allow for any product to be counted when charted as "part of this encounter". The "received elsewhere" vaccines already allow for "other" and "unknown", so barring any potential edge-case scenarios, that will already be covered.

The NHSN COVID-19 Summary Report is already available for clients, however these enhancements will make the report more accurate if charting the new vaccines that have recently been added in the Product Formulary.
