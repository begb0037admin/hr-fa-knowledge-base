ReadySet Release – January 18, 2023

Deployment for clients to Test (Jan. 4th):

EHS-9153   When an employee has more than one job in the system, for each job the Demographics section of the UI will now display values in every populated field (Occupation, Job Title, Location, etc.).

EHS-9360   On the Lab Result PDF, the first and middle name of the patient are no longer reversed.

EHS-9450   For Respiratory Compliance clients, whenever charting forms are updated or voided, the Supervisor Compliance view will now get updated to reflect the appropriate flags (Compliant, Non-Compliant, Due- Next Month, Due Current Month, No Next Due Date, or Not in Program) . Also, statuses on the Supervisor Compliance view related to the charting form and test date completed are now correct.

EHS-9507   For Occupational Medicine clients, the CMS1500 form no longer defaults to Medicare for question 1 when the user selects Other. The form no longer defaults to Self for question 6 when the user selects Other. The form no longer defaults to SSN for question 25 when the user selects EIN. The CMS1500 form will now be accurate for billing.

EHS-9469   The NHSN COVID-19 status now updates correctly, if applicable, when the user edits the existing charting form.

EHS-9489   For Occupational Medicine clients, in Admin/Client Admin > Visit Types, the Visit Code field now displays under Employer in Visit Type Properties.

EHS-9461      In the OMS (Occupational Medicine Services) module, when the fee/billing code is inactivated within the fee schedule, it is no longer a coding option. An inactive code will no longer be a listed available coding option for billing purposes if either the effective date is in the future or the end date is in the past, regardless of whether or not the Active option is selected.

EHS-9488   The Medical Examiners Certification DOT has been updated to the new version.
