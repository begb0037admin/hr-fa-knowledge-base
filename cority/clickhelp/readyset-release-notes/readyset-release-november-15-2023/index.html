ReadySet Release – November 15, 2023

Deployment for clients to Test (November 4th):

EHS-10143   The NHSN COVID-19 Summary Report has been updated to September 2023 guidelines for Q4 reporting. Also, for back-end purposes, seasons tracking has been added to completed forms.

EHS-10100   When a supervisor for multi-job employees becomes inactive, that supervisor is no longer included in any communications or reports for those employees.

EHS-10015   Inactive templates now get removed from the supervisor notification drop-down list.

EHS-9759   For custom reports, users can now use the ‘Save as My Report’ option and schedule reports from ‘My Reports’.

EHS-9392   A cross-site scripting (XSS) security vulnerability has been fixed.
