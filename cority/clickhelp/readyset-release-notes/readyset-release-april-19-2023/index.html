ReadySet Release – April 19, 2023

Deployment for clients to Test (April 5th):

EHS-9180 (Bug)   Manually entered email addresses now support apostrophes.

EHS-9377   Older Flu reports will no longer be cleared automatically.

EHS-9579 (Bug)   On the Overall Programs dashboard, all compliant employees are now correctly showing the Compliant status.

EHS-9585 (Bug)   The ‘Duplication of Employee’ error message has been change to: “Participant creation failed. Duplicate record found. Please contact Employee Health to verify existing information in ReadySet.”

EHS-9586   For Custom Reports, there is a new ‘Add Column Count’ option. The count will display within the ‘Select Column’ window at the bottom left of the screen. This will help users decide how many columns to select or deselect.

EHS-9603 (Bug)   A search performed for a ’Product Name’ question in the Custom Report charting form will now generate and display the appropriate results.

EHS-9683 (Bug)   In CorAnalytics, a user can now successfully filter billing on the Billing dashboard.

EHS-9699 (Bug)   The First Report of Injury (FROI) custom form now includes the Gender field when printed.

EHS-9751 (Bug)   In CorAnalytics, the TB Program Compliance dashboard now displays all employees by supervisor.
