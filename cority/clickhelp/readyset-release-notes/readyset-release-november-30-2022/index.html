ReadySet Release – November 30, 2022

Deployment for clients to Test (Nov. 30th):

RPTS-654   (Issue for One Client Only) The Industry description under Client > Establishment is now provided on the OSHA 300A report.

RPTS-667      The logic of the 'NHSN COVID-19 Summary Report' has been enhanced so that up-to-date HCP are now included in Box 5.

EHS-9292   If the Visit Type description gets changed, Recruiter > Appointments will no longer disappear.

EHS-9343   In MyHealth > Demographics, the Work Information panel now displays when the 'Enable MultiJob' client ref = YES.

EHS-9344   In MyHealth > Demographics, when the user selects the drop-down field on the Work Information panel, an unexpected “No [partition] selected” error no longer occurs.

EHS-9345   In MyHealth > Demographics, if the client does not have any row in the ohl_client_ref table, the MultiJobs panel no longer displays.

EHS-9420   On initial loading, an unexpected Recruiter 504 error no longer occurs.

EHS-9421   In Administrator > Client Setup > Locations, when the user updates Address 1 or Address 2 for the client location, an unexpected “update of client location” error no longer occurs.

EHS-9449   The Flex_10 codes for the 'Asbestos Symptom Review Charting Form' have been updated.

EHS-9471   The 'HR Feed Match Report Dashboard' now loads successfully, and without generating a partition ID error.
