Deployment for clients to Test - May 27, 2026

EHS-11360 For C3 Order Forms and Initialize Programs, users can now void completed notifications. This allows you to mass delete surveys or void charting forms ordered in error. 
Watch the Bulk Voiding training video on Cority Academy for additional information. 

EHS-11366 For scheduled API calls, when 'Run now' is selected for the request, the log now correctly displays the request's status as 'Queued'. 

EHS-11258 For Seasonal Flu Vaccination records, an error when batch charting has been resolved. 

EHS-11387 For custom reports, when filtering based on criteria with multiple pages of results, selections made on previous pages now correctly remain selected when changing pages. 

EHS-11017 For reports, there is a new warning message to prevent reports from being saved with special characters in their name that could prevent the resulting file from being downloaded.

EHS-11396 In EHS Manager, an issue causing the Facility field selection to be cleared has been resolved.
