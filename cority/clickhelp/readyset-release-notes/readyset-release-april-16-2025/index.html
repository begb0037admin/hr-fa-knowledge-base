ReadySet Release – April 16, 2025

Deployment for clients to Test - April 2nd

EHS-10650 In Participant Management, in the search panel, you now see a list of the five most recently accessed records. The list is unique to each user and will be updated each time a new record is accessed. You can hover each name in the list to view the participant's Corporate HR ID and Date of Birth. When you open a record from the list, it will open in the view that you are accessing it from. For example, if you open the record from the list when in the Document View, it will open the document view of that record.

EHS-10730 For custom reports, you can now create dynamic date ranges and save them to scheduled reports to automatically get results for the specified time. For any date filter option in charting forms and survey criteria, there is a new "Last" option, and you can specify a numeric value and either days, weeks, months, or years. 

EHS-10632 In the C3 tab, the Order Forms modal has been enhanced so that charting forms, surveys, and notifications can now be automatically ordered for a customized group of participants based on a custom schedule. From the modal, you can now run a program on demand or schedule it based on a custom frequency, re-initialize surveys, and bulk order new surveys along with forms or separately, and send email or text notifications to recipients. You can also now build a list of recipients using a custom report.  

EHS-10949 For custom reports, date filters with an OR condition now return the expected search results.
