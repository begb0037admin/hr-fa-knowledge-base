ReadySet Release – April 15, 2026

EHS-10926 A new API component is now available and allows users to configure outbound API calls for their ReadySet system. On the new APIs tab, users with the new API User role are able to configure and manage API calls, and view a log of all calls

Please reach out to the support team to enable this feature for your ReadySet environment.

EHS-9151 Recruiter tab can be configured to display additional appointments that were not placed by Recruiters.

EHS-10875 For C3 Programs, using the Add all recipients option now correctly adds all employees to the recipient list.

EHS-11173 For C3 Programs, an issue causing Respirator Program order forms to be duplicated has been resolved.

EHS-11350 For OSHA 300/301 reports, there is a limit of 255 characters for the incident description, aligning with ITA file specifications. 

EHS-11346 For OSHA 300/301 reports, the report output now uses 'Sex' instead of 'Gender'.
