ReadySet Release – February 15, 2023

Deployment for clients to Test (Feb. 1st):

EHS-9568   When applicable, new lab results will post to Medical Chart with the PDF attachment.

EHS-9552   MMR, Varicella, and Hep B immunity reports – When there are multiple charting forms with the same flex_10 value, the report now functions as expected.

EHS-9551   If a job is inactivated, reports that include those jobs will no longer display the name of the former supervisor for the employee who was working that job.

EHS-9531   For DYMO LabelWriter printers, the parameters now support both the 450 and 550 models.

EHS-9234   When a user without a role logs in, that user is now routed to the User Settings screen, as expected.

EHS-9179   In the HR Feed, employees no longer get added without the ohl_emp_client_sites record.

EHS-8853   In Admin > Client Setup > Exp Prots, Sort by Partition is now based on description, not ID.
