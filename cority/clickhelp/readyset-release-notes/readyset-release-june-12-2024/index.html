ReadySet Release – June 12, 2024

Deployment for clients to Test - May 29th

EHS-9275  Client admin users can now add appointment status indicators to appointment statuses using five different icons and seven different colors (red, orange, yellow, green, blue, white, and black). The status indicators can be edited. This functionality can be made available through a request to our Support team.

After an appointment status has been updated, the user will have to reload the page so that the associated appointment status indicator is reflected.

EHS-9989, 9594, 9569, 9536, and 9535  In the Problem List on a record, the Medication Layout now has additional functionality that will improve recording and reporting.
It now provides all fields included on a standard prescription, and the the Active status now updates based on the medication end date. Both the 'Problem List Details Report' and the Medication printout will include the new fields.
From the end of June 2024, the new Medication Layout will be made available to users who have access to the Problem List tab.
