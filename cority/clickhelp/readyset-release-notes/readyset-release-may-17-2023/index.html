ReadySet Release – May 17, 2023

Deployment for clients to Test (May 3rd):

RPTS-670   For the OSHA 300A report, the Industry Description now prints as expected.

EHS-9778   In ‘Visit Type Properties’, you can now select or deselect the Recruiter checkbox and save without any issues.

EHS-9774   In Custom Reports, a user now requires the proper role configuration to view reports on the Download Reports tab and to export reports to CSV.

EHS-9750   In Custom Reports > Seasonal Flu Immunization Survey, HTML tags no longer appear when using ‘Select Columns’.

EHS-9749   In Custom Reports, a search performed when compliance columns are not selected will no longer generate an unexpected error.

EHS-9745   In Custom Reports, when expanding the criteria selection in the Select Columns section or unchecking the column sections one at a time, unexpected errors are no longer generated.

EHS-9741   When the Charting Form is saved as Draft with compliance fields and then later is submitted as Final with the ‘No compliance order required’ checkbox selected, the compliance fields will no longer display. 

EHS-9737    When viewing and using Compliance V2 filter criteria, the page view now renders properly and all page view elements retain their proper positions.

EHS-9736    In Custom Reports, compliance order and noncompliance order records with no Compliance V2 answered and Charting Form columns selected are now displayed on the Result grid when queried.

EHS-9735    In Custom Reports, "Multiple compliance orders" is now available for the Search button.

EHS-9733    In Custom Reports, the drop-down items in the Charting Form and Survey sections are now in alphabetical order.

EHS-9732    On the ‘Download Reports’ tab, an export to CSV for Compliance V2 columns now functions as expected without error.

EHS-9731    When Compliance V2 fields are selected for ‘Custom Search’, the criteria is now editable.

EHS-9730    In Compliance V2 filter criteria, the ‘Completed Date’ field is now available.

EHS-9723    In Custom Reports, the correct error message now displays when the user does not have the required role configured.

EHS-9696    If the user is assigned to a Provider Location that allows outbound lab orders, outbound lab orders now only get generated when applicable. Messages with null values will no longer be sent to the lab.

EHS-9606    In Custom Reports, when ‘Export to CSV’ is selected, a text field is now provided for adding a name for the report.

EHS-9492    In Custom Reports, the compliance fields have been added to the Filter Panel.

EHS-9485    When the search criteria for text and drop-down fields is selected, a responsive horizontal scrollbar is now provided.

EHS-9245    In the ‘Appointments by Calendar’ report drop-down menu, calendars are no longer missing.
