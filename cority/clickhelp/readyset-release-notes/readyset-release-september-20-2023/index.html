ReadySet Release – September 20, 2023

Deployment for clients to Test (September 6th):

EHS-9951   (Bug) - When configured to do so, the client logo will now display on the Login screen.

EHS-9881   (Bug) - For custom reports, when the Parent checkbox in ‘Select Columns’ is used instead of individual parameters and the report result contains a lot of data, instead of the report timing out, a message now displays to inform the user the report is too long to run and to suggest downloading a CSV file instead. The user can choose to export the report as a CSV file or cancel the operation.

EHS-9416   (Bug) - In ‘Void Surveys’, all surveys are now available in the list for deletion.

EHS-9987   (Bug) - Occupational Medicine users searching for a specific invoice number during their billing activities will now only see the proper invoice in the search result.
