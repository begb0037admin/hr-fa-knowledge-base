ReadySet Release – October 15, 2025

Deployment for clients to Test - October 1st 2025

EHS-9928 An issue causing some lab results to not open has been resolved.

EHS-10481 For Custom Reports, when selecting Filter Criteria, charting forms and surveys can now both be ordered by date.

EHS-10548 For Incidents, when a participant is assigned as a witness to a new incident before completing the Witness Survey for the first incident, the initial Witness Survey now shows the 'CANCELED' status. The 'CANCELED' status indicates the survey is inactive and incomplete. When the participant completes the Witness Survey for the second incident, the survey for the first incident can be reinitialized.

EHS-10862 The Billing Dashboard now displays the correct data when a date filter is applied.

EHS-11011 For MMR Immunity Reports, results now correctly consider the 'Vaccination Measles Prior Dose Date if before 1963 or after 1967' requirement.

EHS-11024 For Demographics, closing the employee record no longer displays the 'Save changes to participant?' message when no changes were made.
