ReadySet Release – January 21, 2026

Deployment for clients to Test - January 7, 2026

EHS-11073 In EHS Manager, new optional demographic fields have been added to allow users to capture additional participant information. When creating or editing a participant, you can now capture Race and Ethnicity information, which can be used in reports. A new 'Previous Last Name' field has been added to record any previous last names for a participant. Additionally, the 'Gender' field has been renamed to 'Sex' and a new 'Gender Identity' field has been added. 

EHS-11107 For Lab Results, clearing the search criteria now correctly reloads the main list of participants.

EHS-11171 For Compliance, when adding a new question to a charting form that has been added to multiple compliance programs, the charting form now correctly loads when opened from any of the compliance programs.
