ReadySet Release – March 19, 2025

Deployment for clients to Test - March 5th 

EHS-10656 The Whiteboard view that is currently available to Occupational Medicine clients is now also available to all Employee Health clients. It is a list view of appointments. It defaults to today's date and provides a view of appointment statuses. The new Appointment Status icons are used. You can also access the Participant record directly from this list.

EHS-10876  With the new HR Feed, clients can now send a primary job flag within their HR file. 

EHS-10872  With the new HR Feed, clients can now specify the population types for which they would like updates skipped. 

EHS-10894  On the ‘Supervisor Compliance V2’ tab (for Medical Surveillance programs), employees whose status should be Compliant no longer have a status of either Pending or Non-Compliant.

EHS-10960  The fields that were missing from the Accounting Dashboard have been added to it.

EHS-10776  In EHS Mgr 'Demographics', on a Participant record, when a user specifies values for the Supervisor2 and Supervisor3 fields and then saves the record, those values will be retained, even after a screen refresh.
