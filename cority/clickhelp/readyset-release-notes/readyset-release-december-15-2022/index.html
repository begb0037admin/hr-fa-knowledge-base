ReadySet Release – December 15, 2022

Deployment for clients to Test (Nov. 30th):

EHS-9167   (Required for Ascension) CorAnalytics - For dashboard customization, professional license user access has been added.  Professional license users, with access to their own data, will be able to create new or edit copies of existing dashboard visualizations and securely publish their own dashboards to be seen only by their organization.

EHS-9186   CorAnalytics - The new COVID-19 compliance and vaccination dashboard shows the number of employees who have received each type of vaccination, where the type was received, which date it was received, when employees are due for a booster, and much more. It provides the information required to accurately report this data to internal stakeholders and external regulatory agencies.

EHS-9129   CorAnalytics - The new Appointments dashboard shows the total number of appointments booked based on provider, visit type, location, and much more. It will help users better analyze the employee appointments booked in health clinics, which in turn will better inform future resource planning.

EHS-9213   (Bug fix) On the Flu Compliance dashboard, the flu details reported now match the flu compliance data.

EHS-9418   The Professional License User > Home, Access Allocation enables users to create new or edit (customize) copies of existing dashboard visualizations and securely publish them to be seen and used only by their organization. This is an extra enhancement with a separate price package. (Also required for the Ascension contract, mentioned in EHS-9167.)

RPTS-654      (Bug) (One Client Only) The Industry description under Client > Establishment is now provided on the OSHA 300A report.
