ReadySet Release – October 18, 2023

Deployment for clients to Test (October 4th):

EHS-9155   Enhanced Notifications - This new functionality provides participants, EHS Managers, Incident Managers, Supervisors, and Recruiters the ability to receive alerts related to specific tasks or activities that require action. 

EHS-9929   (Bug)  Charting Form – A “Please wait” warning message is no longer displayed after ‘Submit Final’ is clicked when completing charting forms. This only affects clients with multi-job enabled. 

EHS-9977   (Bug) Custom Reports - Voided charting forms are no longer being included in the output results for the last charting form completed on the record. 

EHS-10004   New 'Improve ReadySet' Link - A link to the Cority User Community is now provided for submitting, tracking, and voting on product improvement ideas.
