ReadySet Release – February 19, 2025

Deployment for clients to Test - February 5th

EHS-10816 For the new HR feed, SSN values with or without dashes will now be accepted and matched.

EHS-10761 For 1500 forms, check box values will now save. 

EHS-10723 For the 'Respirator FIT Details' report, performance has been improved.

EHS-10554 For custom reports, there is a new warning message to prevent them from being saved with special characters that would prevent the resulting file from being downloaded.

EHS-10402 For 'TB Compliance' reporting, the latest charting form is now referenced consistently.

EHS-9971 The following improvements have been made to the Accounting Dashboard: A new data set has been added for improved accuracy. Chart labels have been updated for clarity. The dashboard now provides the ability to view both the current and previous billing period data, and optionally, the maximum number of employees included in the contract.

EHS-9787 Updates have been made to backend file storage that improve database usage. 

EHS-10775 For the OSHA 300/301 CSV report, if "Choose one of the following that best describes this incident:" is left blank and the type_of_incident column is selected, the report will now run successfully and without generating any unexpected errors.
