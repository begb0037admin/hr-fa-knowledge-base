Configuring http and https (SSL)

To use https with the Report Writer Utility web service, web.config must be configured as follows:

  • The end point binding must contain a base address beginning with https.
  • The mex end point must use mexHttpsBinding.
  • The wsHttpsBinding security mode must be set to Transport.

Examples:  

  • <security mode="Transport"><!--change to "None" for http-->
  • <endpoint address="https://myserver/gx_pr/webservice/Report Writer Utilityservice.svc" binding="wsHttpBinding"…
  • <endpoint address="mex" binding="mexHttpsBinding" contract="IMetadataExchange"/>

If you are not using https (SSL), the base address should begin with http, the mex binding should be mexHttpBinding, and the security mode should be set to None.
