Methods

bool

 

 

 

ValidateUserLogin (string username, string password). This method validates the user by verifying the user has valid login credentials.

Parameters:

  • string username - the username to log in for imports
  • string password - the password to log in for imports

Return Value: Returns ‘true’ or ‘false’, depending on if the user has valid login credentials

bool

ValidateUserToken (string key). This method validates the key. If validated, the life of the key will be extended by 30 minutes.

Parameters:

  • string key - a generated key required to authenticate the user

string

ValidateUser (string username, string password). This method creates a token when a valid username and password are entered. When called, it will also renew the timer for which the token is valid. A valid token expires after 30 minutes. The token created is up to 500 characters in length.

Parameters:

  • string username - the username used to check for Report Writer Utility permission
  • string password - the password used to check for Report Writer Utility permission

bool

ValidateuserReportWriterUtilityPermission (string username, string key). This method verifies that the user has permission to run imports by checking if the user has an admin role or is has the “reportwriter.display” permission.

Parameters:

  • string username - the username used to check for Report Writer Utility permission
  • string key - a generated key required to authenticate the user

Return Value: Returns ‘true’ or ‘false’, depending on if the user has the Report Writer Utility permission.
