Scheduling the Report Writer Utility

To schedule the Report Writer Utility, you must first run the client manually and save the configuration by clicking Save Configuration (see the Configuring and Running the Report Writer Utility section for instructions). Once is complete you can schedule the Report Writer Utility to run automatically using your saved configuration. Note: The file that was selected when the configuration was saved will be used for exporting reports.

Important: If you have updated the Report Writer Utility web client from GX2t or earlier to GX2u or later, you must update the Program/Script field of your scheduled task to reference the new executable filename (.exe), because that filename has changed.

  1. Select Start > Programs > Accessories > System Tools > Task Scheduler.
  2. Select Create Basic Task. The Create Basic Task Wizard will open.
  3. Enter a name and description (optional) for the task.

  1. Click Next.

  1. Select when you want the task to start.

  1. If you selected Daily, Weekly, Monthly, or One time in the Trigger step, select a start date and time and specify when you want future tasks to run, if applicable. Click Next.

If you selected When a specific event is logged in the Trigger step, select a Log and Source and enter an Event ID. Click Next.

  1. In the Action step, select Start a program.

  1. Click Next.
  2. Click Browse.
  3.  Select ‘Report Writer Utility.exe’ and click Open.

  1. In the ‘Add arguments (optional)’ field, enter “/s”. This denotes silent or automated execution of the command.

 

  1. Click Next. Review your settings and click Finish to create your Report Writer Utility task. The Windows Task Scheduler will automatically start Report Writer Utility per your specifications.
