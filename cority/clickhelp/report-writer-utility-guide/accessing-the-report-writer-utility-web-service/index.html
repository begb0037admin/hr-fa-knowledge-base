Accessing the Report Writer Utility Web Service

You can determine the URL of the Report Writer Utility web service by looking at your login URL. For example, if your login URL is https://dev.cority.com/gx/security/login.rails, your Report Writer Utility web service URL is https://dev.cority.com/gx/WebService/ReportWriterUtilityService.svc.
