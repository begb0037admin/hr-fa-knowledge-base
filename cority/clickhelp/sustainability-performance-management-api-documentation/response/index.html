Response 

Most endpoints follow a standard set of response fields. These follow a similar format to the data audit dashboard. Different fields are available depending on if an emissions or consumption endpoint is queried. The standard fields and their relevant to either consumption or emissions are outlined below.

Also, each consumption type has different fields available during the data input process. For example, waste uploads require the user to input data on “treatment type of purchased materials” and “treatment type”, which are fields only relevant to waste uploads. Fields which are unique to each consumption type are the only exceptions to the standard response shown below. They are included in the API response but are not outlined below. Bespoke fields are also displayed through the API. These are user defined fields and are therefore not outlined below. 

The response is split into three distinct sections: 

  • Success messages 
  • Actual data 
  • Modelled data

Actual Data 

The actual data contains different fields depending on if a consumption or emissions endpoint is queried. A number of market-based emissions fields are included within the actual data. To replicate the market-based emissions of the dashboards and reports of SPM users should aggregate market-based emissions according to the priority order outlined below. If emissions are not available for one step, the next priority should be used. 

  1. totalMarketbasedtCO2e 
  2. residualMixtCO2e 
  3. Location-based emissions
