Getting Started

API Permissions 

Permissions to the Sustainability Performance Management (SPM) API are user specific. This means one token can be generated per user and that this token will only allow you to view the data which you should have access to. 

Managing API tokens 

To manage your API tokens navigate to Admin Settings > General > API tokens.

 

To generate a new token:  

  • Click the ‘Add Token’ button. 
  • Enter the username for whom the token should be generated. 
  • Specify token duration using the numeric field and dropdown. 
  • Select ‘Insert’ to generate the token. 

The maximum token duration is 5 years. Tokens can be copied using the copy icon to the right of the token. Tokens can also be renewed or revoked using the associated buttons on the right of the table.
