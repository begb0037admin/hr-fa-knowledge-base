Introduction 

The SPM API allows clients to extract consumption and emissions data without the need to log into the SPM platform. Users can generate tokens in the SPM platform. Tokens can be used to authorize requests for data made through an external API client.

The data returned is formatted in a comparable way to the data audit dashboard. This provides users with a high degree of data granularity, allowing them a great degree of flexibility in how the data is pivoted when used in partnership with analytical tools.
