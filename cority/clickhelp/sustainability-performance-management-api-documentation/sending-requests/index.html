Sending Requests 

Standard Requests 

All consumption endpoints share a common set of filters. An example of this, and an explanation of each filter is provided below. Some endpoints have additional filters available. These are outlined in the next section. The formatting of requests for each endpoint is also demonstrated in the Swagger.

{
  "viewName": "Example View", 
  "nodeReference": "Root", 
  "fromDate": "2020-01-01", 
  "toDate": "2023-12-31", 
  "scope": ["Scope 1", "Scope 2", "Scope 3"],
"scope3": [1,2], 
  "consumptionType": ["Standard Grid (General)"], 
  "includeHierarchy": true, 
  "consumptionUnit": "kWh", 
  "displayEstimationCategories": ["Actual", "Estimated"]
} 

Property Description Type Required? 
viewName Filters by view name, as listed in "Admin Settings > General > Organisation > Views". string Yes 
nodeReference Filters by node reference code, as described in "Admin Settings > General > Organisations > Nodes & Data Sources". To use the top-level node, please specify the reference as “Root”. string Yes 
fromDate Filters by initial date for the consumption the user is searching for. date Yes 
toDate Final date for the consumption the user is searching for. date Yes 
scope Filters by consumption related to one or more scopes. 
Options: "Scope 1", "Scope 2" and "Scope 3". 		array of string Yes 
scope3 Filters by one or more of the scope 3 reporting categories related to Scope 3. 
Options:  
1 - "Category 1 - Purchased goods and services" 
2 - "Category 2 - Capital goods" 
3 - "Category 3 - Fuel- and energy-related activities" 
4 - "Category 4 - Upstream transportation and distribution" 
5 - "Category 5 - Waste generated in operations" 
6 - "Category 6 - Business travel" 
7 - "Category 7 - Employee commuting" 
8 - "Category 8 - Upstream leased assets" 
9 - "Category 9 - Downstream transportation and distribution" 
10 - "Category 10 - Processing of sold products" 
11 - "Category 11 - Use of sold products" 
12 - "Category 12 - End-of-life treatment of sold products" 
13 - "Category 13 - Downstream leased assets" 
14 - "Category 14 - Franchises" 
15 - "Category 15 - Investments" 		array of int No 
consumptionType Filters by consumption sub-type. For example, this allows the user to filter by electricity type or fuel type. The sub-types available here are also shown in the data audit report. Array of strings No 
includeHierarchy 

If the node described in property "nodeReference" has child nodes associated to it in the informed view, it's possible to include their consumption data in the result as well. 
 

Options: 
"true" - Adds consumption data for child nodes. 
"false" - Displays only consumption data for the node described in property "nodeReference", not considering the data added to its child nodes, if there is any. 
 
To check if a node has any child nodes, go to "Admin Settings > General > Organisation > Views" and click on the desired view to see the corresponding node hierarchy. 

bool No 
consumptionUnit 

Filters by consumption unit type. 
Options: 
"kWh" 
“litre” 

“tonne” 

“km” 

Array of strings No 
displayEstimationCategories Filters by the consumption data's Estimation Category. Options can be "Actual" (actual consumption amounts), "Estimated" (estimated consumption amounts), or the methodologies used to calculate the consumption, as listed in "Admin Settings > General > Category Management > Estimation". array of strings No 

Exceptions to the Standard Filters 

A collection of endpoints have additional filters available. These are outlined below. 

Heat (Grid) 

Property Description Type Required? 
heatTypes Heat data can be entered as either fuel consumption, or the amount of heat and steam produced. The consumptionTypes filter allows the user to filter by fuel type, while the heatType filter allows the user to filter by the heat type entered. Array of stringsNo

Travel data (Business, Commuter and Freight data)

Property Description Type Required? 
distanceUnits Road Business data can be uploaded using fuel consumption or distance travelled. While the consumptionUnits filter allows the user to filter by units of fuel consumption, the distance units allow the user to filter by distance units. Array of stringsNo
