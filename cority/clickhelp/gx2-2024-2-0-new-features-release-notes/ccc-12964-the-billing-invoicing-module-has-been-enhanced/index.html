CCC-12964: The Billing/Invoicing module has been enhanced

Opt-In

This includes the following improvements:

  • For use on custom versions of the Invoice layout (ML-003780): six new alphanumeric UDFs, six new date/time UDFs, six new check box UDFs, and six new look-up table UDFs (with accompanying look-up tables).
  • A new ‘Insurance EDI Payer Code’ field on the default Payer look-up table layout (ML-003774). The new field can be prohibited from a user’s role, reported on using Query Builder, and populated or edited by import.
  • The ability to track all payments applied to an invoice (therefore, any outstanding amounts as well), which includes:
    • A new ‘Payment Type’ look-up table, categorized under the Billing module. The look-up table has the All Active, All Inactive, and All views. To use the table, the ‘Lookup Tables for Billing’ security module must be granted to the user’s role. The table has the ‘Export List to Excel’ and ‘Show Record History’ actions. The table (its fields) can be reported on using Query Builder and populated / updated through import.
    • A new ‘Payment Tracker’ tab (data table) on the default Invoice layout (ML-003780). The tab has an ‘All Payments’ view with the following columns: Received Amount (as of this payment, not invoice outstanding), Received Date, Payment Type, Written Off Amount (as of this payment, not invoice outstanding), Notes (with character limit of 250), Posted By, and Invoice Number (not provided by default).
      The view has the ‘Print’ and ‘Export to Excel’ actions, and New, Edit, Save, and Delete buttons:
      • New – Payments are applied to the invoice until nothing owing is left.
      • Edit – The payment of only the edited/updated amount is applied.
      • Delete – The payment deleted will be subtracted from the invoice.

The tab (its fields) can be reported on using Query Builder.
The records will open in the new ‘Payment Tracker’ layout, which has the following fields: Invoice, Posted By, Payment Type, Date, Received, Written Off, Billing Item, and Notes. The ‘Billing Item’ field is a picklist to the ‘Invoiced Billing Item’ look-up table. Where applicable, the fields correspond to the equivalent columns on the ‘Payment Tracker’ tab.

  • The ability to configure the auto-creation of billing for scheduled exam activities, which includes:
    • A new Fee Schedule tab (sublist) that can be added to custom versions of the ‘Schedule Activity’ look-up table layout (ML-000455). The new tab has an ‘All Fee Schedules’ list view, in-line add functionality, New, Edit, and Delete buttons, and an ‘Export List to Excel’ action. The ‘Fee Schedule’ records open in the new ‘Schedule Activity Fee Schedule’ layout (ML-003843).
    • A new action on the ‘Exam Activity’ tab labelled ‘Add Selected Exam Activities to Billing’. To use the action , you must have the Billing license key and the user’s role must be granted the Billing module. The exam activities will be added to the ‘Billing Items’ tab. If an activity has more than one fee schedule, a billing item will be created for each activity / fee schedule combination.
      Note: A billing item cannot be marked ‘Code Completed’ if the ‘Fee Schedule Cost’ field is empty, and a new billing item will not be created if the exact one already exists.
    • A new ‘Fee Schedule’ field on the default ML-003804 layout. A value for this field is required. The field is a picklist to the ‘Fee Schedule’ look-up table. The picklist will be filtered by the parent ‘Clinic Visit’ GDDLOFB and any ‘Fee Schedule’ for which the GDDLOFB is null. The equivalent column will be provided on applicable list views.
      Note: The existing ‘Fee Schedule Cost’ field will no longer require a value and will be filtered based on the selected Fee Schedule.
