Summary of Platform Enhancements

The table below lists smaller design improvements we have made within the GX2 Platform. The items are organized by component and the components are arranged in alphabetical order. Descriptions of larger features follow the table.

ItemComponent(s)Description
CCC-16690Administrator, End-User

Measures have been taken to guard against the potential for Cross-Site Scripting (XSS) when using the 'Enable translation mode' and 'Enable translatable free-text fields' system settings, as well as when using look-up table descriptions on list views.

 

CCC-14270Infrastructure

To guard against potential security vulnerabilities:

  • Kendo has been upgraded to the latest version.
  • For exporting Why Trees to PDF or an image, Kendo PDF Export has been implemented.
  • In Advanced Dashboard, PhantomJS has been replaced with Puppeteer Sharp.

 

CCC-9233Infrastructure

To protect against a potential security vulnerability, the Newtonsoft.Json.dll library has been upgraded.
