Summary of Occupational Health Enhancements

The table below lists smaller design improvements we have made in the Occupational Health cloud. The items are organized by component and the components are arranged in alphabetical order. Descriptions of any larger features follow the table.

ItemComponent(s)Description
CCC-16190Appointments

In the OH Appointments module, a user can now filter the list of practitioners by specialty.

To support this, a new 'Practitioner Specialty' filter has been added to the menu at the right.

The new filter is a picklist that opens the 'Practitioner Specialty' look-up table. From the picklist, the user can select multiple values (for example, both Cardiologist and Oncologist).

The picklist opens to the 'All Active' view by default, but the user can switch to the 'Inactive' or 'All' view.

The new filter works in conjunction with the other available filters (Health Center, Active/Inactive toggle, etc.).

If used, the new filter's value(s) will be saved for the next time the module is opened.

Note: For this filter to function, a 'Practitioner Specialty' value must be added to each applicable User record.

 

CCC-16348Display Rules, Scheduling

For a Display Rule using the 'Schedule Entry' entity, the Filter action now provides the 'Scheduling User' option.

 

CCC-6272Pre-Employment

It is now easier for a nurse practitioner to generate a certificate of clearance that will inform the recruiter the applicant is cleared (fit) for duty.  

In the 'Letter Templates' look-up table, 'Employee' is now available as an entity (merge table).

All fields within the 'Employee Job Position' data table are available within the entity to be used as merge fields.

Letters created using the Employee entity (merge table) will be stored on the 'Employee Job Position' Letters tab only (will not be accessible anywhere else in the product). This will ensure that letters of clearance remain associated with the job itself.

For information on working with Letters, see the GX2 User Guide.
