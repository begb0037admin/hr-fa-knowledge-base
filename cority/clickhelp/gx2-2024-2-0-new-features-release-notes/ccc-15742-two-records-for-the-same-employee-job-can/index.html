CCC-15742: Two records for the same employee job can now be merged

Opt-In

If an ESR import adds an ‘Employee Job Position’ record and a recruiter creates another record for the same job with a different start date, for example, this feature enables the user to merge the two into a single record.

To support this, the ‘Employee Job Position’ data table has a new ‘Job Position Merge’ action.

The user’s role must be granted this action. Otherwise, it will not be available.

The action will open a dialog box that requires input from the user.

After the dialog box is populated, clicking ‘Merge’ will merge the data of the two ‘Employee Job Position’ records into one. Clicking ‘Cancel’ will clear and close the dialog box.

If there are more than two records for the same employee job, to merge all of them the user will have to execute the new action again for each additional record.

The letters from each of the records will be retained and made available on the single ‘Job Position’ record.
