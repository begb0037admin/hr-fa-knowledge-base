CCC-15911: The Cority Data Integration Utility can now be used to import multiple SDS documents with multiple attachments

Opt-In

The AgentHazardSDS entity in the utility now provides the 'Document Path' field within 'Available Fields'.

On an import file, for the AgentHazardSDS entity, the 'Document Path' field (which corresponds to and will populate the existing 'Document Data Format' and 'Document Data' fields) can now be used to attach documents to 'Agent Hazard' records.

During such an import:

  • If 'update existing records' is enabled, values for the required fields for a record are provided, and a matching record is found, the record will get updated with the document(s) attached, and all the applicable tables will get populated accordingly.
  • If 'update existing records' is not enabled and values for the required fields for a record are provided, a new record will get created with the document(s) attached, and all the applicable tables will get populated accordingly.

Note: The expected document upload checks (such as file size and supported document type) will be respected. If document(s) cannot be imported, the parent record will still be updated/created and a corresponding error logged.

For information on working with the Cority Data Integration Utility, see its user guide.
