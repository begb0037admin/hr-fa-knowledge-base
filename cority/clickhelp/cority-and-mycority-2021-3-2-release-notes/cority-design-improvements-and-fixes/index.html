Cority Design Improvements and Fixes

The table below lists the design improvements and fixes we have made in the Cority 2021.3.2 release. The items are organized by module and the modules are arranged in alphabetical order.

Item #Component(s)ReportedDescription
CCC-6391Chemical ManagementN/A

When the user creates a new Chemical Inventory record adding to it a Chemical Product that has a linked Chemical Handling record, the new Chemical Inventory record can now be saved, closed, and reopened without generating an unexpected error.

 

CCC-6295Chemical ManagementN/A

In the 'Vapor Pressure Coefficients' section on 'Chemical' records in the Emissions Inventory module (so, in the 'Chemical Vapor Pressure' data table), the 'Temperature 1' through 'Temperature 7' fields now support values with decimal places.

 

CCC-6750Emissions InventoryN/A

When importing into the Texas STARS emissions table, only emissions that have linked emission sources, emission points, and control devices for the Texas STARS account used will now be imported.

 

CCC-6703Emissions InventoryN/A

When calculating emissions for assets (emission sources) that have more than one emission parameter record and more than one related equipment attributes, all of the associated emission parameter results (for all selected reporting periods) will now be calculated and provided.

 

CCC-6420Emissions Inventory2021.1.1

In Emissions Inventory, from the Emissions tab of a Texas STARS record, when the user selects the 'Export Excel Emission Template' and uses a previously saved template file, CIN (Control Device) values will now import correctly and applicable records will all now have the correct CIN values.

 

CCC-6409Emissions InventoryN/A

In Emissions Inventory, for a chemical, Vapor Pressure vs. Temperature interpolation now only requires two data points.

 

CCC-6303Emissions InventoryN/A

The functionality and workflow for importing source profile emission results into the Texas STARS emissions table have been reworked and enhanced.

 

CCC-6301Emissions InventoryN/A

In 'Emissions Inventory', when a user executes the 'Generate Emission Calculation Report' action for a Source Profile, that process is now handled by several business rule actions, which all get added to the business rule action queue. This improves its overall performance.

 

CCC-6007Occupational Health – ePrescription2021.3.0

If a user attempts to dispense a medication for an employee a second time, when applicable the "no refills remaining" dialog box will now function as expected.

 

CCC-6558Occupational Health – Medical MonitoringN/A

A time-driven business rule (TDBR) configured properly to email a large questionnaire distribution batch will now run without any timeout issue(s) and process all expected items successfully.

 

CCC-6556Occupational Health – SEG ManagementN/A

In the Occupational Health 'SEG Management' module, a SEG can now be cloned as expected.

 

CCC-3397Platform – AdministratorN/A

The archive and purge (data retention) business rule functionality now work as expected. Also, the starttriggerthread execution timeout for archive and purge has been extended.

 

CCC-3315Platform – AdministratorN/A

Security for the Disclaimer Message has been improved so that it is no longer vulnerable to Cross-Site Scripting (XSS).

 

CCC-2128Platform – Administrator2020.1.0

The Employee Banner now displays renamed field labels, as expected.

 

CCC-6484Platform – End UserN/A

For all text area fields (for examples, Note and Smart Note), the font size has been increased.

 

CCC-2820Platform – End UserN/A

For configured workflows, all check box fields are now positioned properly and all read-only fields are now greyed out.

 

CCC-6455Platform – Interfaces2021.3.1

A business rule with business rule action, which is configured to trigger on a particular change to a parent record with sublist records and create one or more new records, will now fire as expected and create any records that should be created with proper fields populated. Also, both the API Log and Event Log will now function properly under such circumstances.

 

CCC-4682Platform – Interfaces N/A

A number of UX enhancements have been made so that the importing of TreeMaster records and data with the RESTful API is now more user-friendly.

 

CCC-6830Quality – Equipment2021.1.0

When creating an 'Equipment Group' look-up table record and adding equipment, 'Quality' cloud equipment is now available for selection.

 

CCC-217Safety – Audits and InspectionsN/A

For inspections and surveys, the asset assignment functionality has been enhanced.

To custom versions of the 'Assignees/Recipients' (ML-001247, ML-001258, ML-003386, and ML-001251) layouts, you can now add the following new fields:

  • Individual Asset - A check box
  • Asset Group Equals and Below - A check box

When the 'Individual Asset' check box is selected, an inspection/survey will be created for each asset linked to the selected 'Related Asset Group'. The assignment will also display on the 'Assigned To Me' Advanced Dashboard gadget and in myCority.

  • You cannot select both an 'Asset Association' and the new 'Individual Asset' check box.

When the 'Asset Group Equals and Below' check box is selected, the assets linked to the selected 'Related Asset Group' will only be assigned to a group member when there is an exact match between the GDDLOFB field values and the ones specified on the asset, or when the value specified on the asset is the parent or higher of the one specified on the 'Assignees/Recipients' layout.

  • If 'Asset Group Equals and Below' is selected but no GDDLOFB values are specified, an inspection/survey will be created for each asset in the selected group.

The new fields can be populated/updated using the Import Utility and are available for use in Query Builder and Report Writer.

The new fields can also be used in business rules and business rule actions.

The equivalent columns, along with the 'Equipment Group' column, can be added to custom versions of applicable list views.

Also, the 'Assignees' tab (sublist) can now be added to custom versions of the following:

  • The 'Completion/History' tab of Inspection/Survey records for due inspections, in-progress inspections, and completed inspections (for Safety, Environmental, Ergonomics and Quality inspections)
  • The 'Completion/History' tab of 'My Inspections & Surveys' records for due inspections and completed inspections (for Safety, Environmental, Ergonomics and Quality inspections)

In Addition, on 'Assignees/Recipients' layouts, when you click the 'Magnifying Glass' icon next to the 'Asset Association' field, the resulting 'Equipment' dialog box will now provide the 'All Active Equipment' and 'All Inactive Equipment' list views.

  • If GDDLOFB values and/or a 'Related Asset Group' are selected on the layout, the 'Equipment' dialog box will filter accordingly.

 

CCC-65Safety – Audits and InspectionsN/AThe Inspections/Surveys module is now stored and functions as a data table entity, instead of as a virtual list. This provides more flexibility and power for reporting on Inspections/Surveys using Query Builder and Report Writer. It also makes future enhancements (offline capability for team inspections, advanced frequency assignments, support for time-driven business rules, etc.) easier to implement. For this release, other than more robust reporting options, end users will not see any changes in Inspections/Surveys functionality.
