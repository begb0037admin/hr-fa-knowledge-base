GSE-2938: It is now possible to calculate waste emissions using volume-based units.

This is only applicable to waste data sources that have the EPA emission factor methodology and the United States country / region. Others will continue to use weight-based units only.

To support this, for Input forms, in the Units drop-down field the appropriate volume-based units will now be available where applicable. Volume-based waste data can also be uploaded using Excel or SFTP.

Where applicable, the units have also been added to dashboards, reports, and in administrative sections. For example, for the Waste Report, new tables and plots have been added that will handle volume-based waste data.
