GSE-2668: Reports from Environment > Reporting > Reports will now run in the background.

Reports from Environment > Reporting > Reports will now run in the background so the user can continue working while the report is in the queue or being generated. Previously, the user could not continue working until the report had run.

The workflow for running a report remains the same, but now when the report starts to run, after the toast notification message is displayed the user can continue to work.

The user can even set up multiple reports to run, then continue working while each waits its turn in the queue and then generates.

In support of this, on the Environment Reports view, there is a new Status column with Pending, In Progress, and Completed statuses. Pending indicates that the report is in the queue awaiting its turn to run. Only reports with either the Pending or Completed status can be deleted. For reports In Progress, the Delete icon is not available.

There are two additional statuses for reports that you might see in that column: Timeout and Failed. If the report runs for 30 minutes without being completed, the report will be given the Timeout status. The system will attempt to run a report three times before giving it the Failed status. If the report fails, you should revisit its settings (for example, if there is a very large amount of data being used).

Once the report is completed or has failed, the user will receive a notification email.

In addition, on the Environment Reports view, for each report the Rerun action has been renamed Clone. Note: When using the Clone action, the user must alter some aspect of the report’s configuration or a validation error will prevent the clone from running.
