Overview

At Cority we are committed to continually enhancing our products. The 2025.3.0 SPM Enterprise release contains new and improved functionality in several areas—including improved UI responsiveness for the homepage, save configuration features in Frameworks > Aggregated Reports, the ability to continue working while reports in Environment > Reports are queued and running, and volume-based recording and calculations for waste emissions data.

Tips:

  • We use the number that prefixes each enhancement (for example, GSE-3061) to identify it internally. If you have a question about a feature, its number(s) will help the Cority technical contact quickly access all of the relevant information.
  • Until the software is released to Production environments, please check this document for updates.
  • The version number below is the document version, not the software release version. A number greater than 1.0 indicates that one or more updates have been made.
