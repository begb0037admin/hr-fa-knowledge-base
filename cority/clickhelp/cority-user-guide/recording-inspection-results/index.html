Recording Inspection Results

  1. In the Quality menu click Data Collection.

  2. Retrieve the Inspection Plan you are recording data for.

  3. On the Data Collection tab, record information about the collection activity itself, e.g. who did it, when, where, details about the lot inspected, etc.

  4. On the Sample Results tab, either select the checkbox beside one or more records and click Edit (to edit inline), or click a record number to open it for more detailed data capture.
