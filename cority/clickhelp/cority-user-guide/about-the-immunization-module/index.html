About the Immunization Module

Use the Immunization module to record immunizations and to print immunization recall letters. The module includes features for automatic generation of recall letters and specific fields for recording TB test results. Other fields include known allergies, injection site, immune status, date of recent serology and indicators for employees who decline an immunization series. Batch immunization recall letters can be printed or emailed directly through the system.

The Inventory module allows you to record inventory levels by health center. Inventory is updated as vaccines are used in immunization records. See Inventory.

Cority provides functionality for New York City and Massachusetts users to submit immunizations to the appropriate municipal oversight body. This requires the following:
- define supporting information in several look-up tables and system settings
- either set up the Submit to Jurisdiction business rule action to automatically submit the record to the appropriate jurisdiction when the record is saved, or add the Submit to Jurisdiction action to a custom form layout.
Please contact your system administrator for further information.
