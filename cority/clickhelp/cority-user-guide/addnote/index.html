AddNote

This table lists templates of notes that can be added to a record.

  1. To filter the list of records, enter a few characters in one or more of the fields at the top followed by an asterisk, then press enter.

  2. Click a link to edit, or click New.

  3. Enter a Code and Description for the note.

  4. Select a Category so the system will filter in which module the note template appears. To have the note appear in all Notes sub-lists, link to the “General” category.

  5. Select the Geographic Location and Health Center.

    6. To have picklists for this table only show values corresponding to the user’s geographic location, ensure the "Filter Look-up Tables by Geographic Location" system setting is enabled.

  6. Click Save.
