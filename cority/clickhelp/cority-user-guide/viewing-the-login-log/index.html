Viewing the Login Log

In the Administrator menu, click Login Log to view a list of all login attempts, showing the login name, status and time, and if the login was to the Portal or mobile Portal. Login status can be one of the following:

  • Decline Privacy Agreement Logout

  • Inactive

  • Incorrect Password

  • Incorrect User Name

  • Locked Out

  • Logout

  • Portal User

  • Success 

The "Login Log" entity can be used in business rules to archive login log records, mark them for purge, or purge them; there are also related business rule actions.
The Show Record History action in the list view only displays any archived login log records (that have not been purged).
