About the Monitoring Module

This module records and tracks a wide variety of user-defined sample types, including personal, area, bulk, wipe and direct reading samples. Cority can store data related to chemical stressors, biological stressors and physical stressors such as radiation, heat stress and vibration.

The module includes numerous fields to capture sample details, including employee sampled, process, tasks, controls, job position, location and PPE worn. The system also provides fields to store data related to sampling equipment, collection media used, calibration data, sample time, volume and environmental conditions. The agent section stores and calculates all sample data entered in the system.

Cority has robust calculation tools which can calculate concentration and time weighted average (TWA) including the ability to calculate integrated TWAs for a sample set. The system allows for the definition of unlimited standards related to any agent to accommodate multiple jurisdictions. An effective start and end date system allows the user to store historical standards and terminate standards that have been withdrawn. Based on the jurisdiction and sample date on a sample record the appropriate standard for that time is compared automatically with entered results. A Brief and Scala OEL reduction tool is also available to reduce occupational exposure limits for extended shifts.

A laboratory interface is available to allow secured electronic loading of analytical results by laboratories. A secured login can be provided to a laboratory. When a laboratory enters Cority they can only access the Requisition module and can only see and manage samples sent to their laboratory.

A corrective actions tracking feature is included. Any actions can be assigned through Cority and automatic reminders and notifications can be set up to run through the Cority Email Notification Utility.

Notification letters and reports are available to report data to both management and staff. Robust report queries allow for the reporting by numerous factors, including employee, location, process, task, job position and exposure group. Queries are also available to search the database by percent of OEL (e.g. search for all results exceeding 50% of the OEL).

There are three tools available to statistically evaluate data stored in the Monitoring module: LogNorm, LOGAN and the AIHA Spreadsheet.
