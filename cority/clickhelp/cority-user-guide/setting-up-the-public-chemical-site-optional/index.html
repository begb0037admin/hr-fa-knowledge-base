Setting Up the Public Chemical Site (Optional)

The Public Chemical site uses the PublicChemProduct user, which is preloaded into the User table, to login into the application in the background. The site address is <Site Root>/publicchemproduct/publiclogin.rails.

You can append a view ID to the URL so that it takes the user directly to a specific GX2 Chemical Product list view. To set this up:

  1. Create the desired view of the Chemical Product layout. The view must be saved as a Standard View. See Creating a New View.
  2. With the desired Chemical Product view open, look at the URL and make note of the view ID at the end; for example:
    <Site Root>/chemproduct/list.rails?page=0&navigationIndex=2
  3. Go to the public site, and in the URL append "?view=<ID>" at the end. Using the example above:
    <Site Root>/publicchemproduct/publiclogin.rails?view=2
  4. Copy the new URL to provide to users. When they click that link it will open directly to the desired view.

The public site will display a client logo if provided in the "Logo - Login Page and Main Application" system setting; if no logo is provided for that system setting, the Cority logo will display.
Any chemical product records that have the Exclude from Public Links checkbox selected will be excluded from public list views.

There are several actions available on the public site:

  • To open the SDS for a product, select the chemical product and choose Actions»Open SDS.

  • To access an SDS linked from a manufacturer’s website, click the SDS link to the left of the desired product.

  • To search the Chemical Product List for chemical products with a given  Trade or Chemical Name, choose Actions»Search Trade and Chemical Name.

  • Click a Reference Number to view a simplified read-only form of the Chemical Product.

Public users may also view and print any chemical product labels that are identified as a Public Label (this checkbox must be added to a custom version of the Chemical Product Label layout). When they select a record and choose Actions»View/Print Labels, the corresponding label will download as a printable PDF file.
