Viewing Published Controlled Documents

The Published Documents module displays a read-only list of the most current controlled documents that have been published from the Document Control module (see Managing Controlled Documents). Word, Excel, txt, and rtf documents are published as PDFs.

To view the list of all published controlled documents, click Published Documents in the My Favorites menu.

To view a document, select the checkbox beside the document and choose Actions»Open Document.

If you want to include a link to a published document in an email, document or web page, open the document and then right-click and choose Copy link address. The URL for the document will be copied to your clipboard.

An archive action may be added to a custom layout. When a document is archived, all versions of the published document will be unpublished from My Favourites > Published Documents, and no user will be able to access the published documents associated with that record on either GX2 or myCority.
