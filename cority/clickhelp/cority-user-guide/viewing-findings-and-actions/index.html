Viewing Findings and Actions

When you click Findings & Actions in a Cloud’s menu (“Corrective Actions” in the Environmental menu), you will only see the findings for modules that you have security access to. For example, if you do not have access to the Incident module, the Findings and Actions list via the Safety menu will not show any Incident findings.

For medical findings, security is determined by its parent (e.g. the body fluid exposure record it is attached to) OR the employee it is related to. Only users with security to see that parent record (or that employee) can view the attached findings.

For findings/actions that were automatically generated, click on the Source ID in the finding/action record to go to the record that created the finding/action.

Employees can view their complete and incomplete assigned actions in their task list in the Portal/myCority.

Set the assignee and/or due date for multiple records at the same time: on the Findings list, select the records and choose Actions»Set Assignee/Due Date, then select the assignee and/or due date that will apply to all the selected records.
