Viewing Compliance Actions

In the Safety menu, click Compliance Calendar
or
in the Environmental menu, click Compliance Obligations,
then use the provided fields and views to filter the list.

The list consolidates all entries on the Compliance Actions tab for all legal requirements and permits.

You can edit multiple actions inline on the list view without opening each action record: select the records and click Edit.

All actions will appear in the Findings & Actions module; for more information, see Findings and Actions.
