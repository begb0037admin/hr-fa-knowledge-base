TrainingCourse

This table contains information about mandatory and optional courses for your employees.

  1. To filter the list of records, enter a few characters in one or more of the fields at the top followed by an asterisk, then press Enter.

  2. Click a link to edit, or click New.

  3. Enter a Code and Description for the course.

  4. Select the Course Type, Course Owner, and any Reference.

  5. Enter the Duration of the course in minutes.

  6. Click Save.
