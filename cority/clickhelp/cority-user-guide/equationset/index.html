EquationSet

This table allows you to create a set of equations that will apply to a record. For example this may apply to fields in an asset table that are specific to an asset which will be used in a source profile; alternatively they may apply to an IH monitoring record.

Create an equation set via the EquationSet look-up table, and link the equations to it. Alternatively you may add a Related Equation Set tab on a custom layout of the IH Equation table.

Even if you only have one equation, it must be tied to an equation set in order to be viewed in a record.

  1. Enter a Code and Description, and select the Entity.

  2. On the Related Equations tab:

  • Click New.

  • Select the Field (from the selected entity) and the Associated Calculation to be applied to that field.

  • Indicate if you want to allow users to manually Overwrite the calculated value for this field. These fields will include an icon to restore the calculated value:

The Overwrite Calculation checkbox is not available if Entity is a risk assessment.
