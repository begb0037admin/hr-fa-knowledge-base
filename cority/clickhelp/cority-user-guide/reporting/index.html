Reporting

There are no canned reports related to waste management records. Use Report Writer subqueries to create metrics that can be analyzed in the Data Cube, as follows:

  1. Create the subquery - use the provided Waste Metrics Subquery or clone it to create your own.
    If you are creating a subquery for use in a custom measure:
    - the first column must be a number field (e.g. Amount)
    - the second column must be a date/time field
    - subsequent columns must be the GDDLOFB ID fields, in that order)
    Note that the Subquery field is not available on default custom measure layouts.
    For more information about creating Report Writer queries, see Editing or Creating an Ad Hoc Report in Report Writer.

  2. Create a custom layout for custom measures to add the Subquery field. For more information, see Defining Form Layouts.

  3. Associate the subquery to a new or existing custom measure. For more information, see Setting Up Custom Metrics.

  4. When the custom measure is linked to the subquery and saved, individual metrics records are created from the waste management record and listed on the Completion/History tab.

  5. The custom measure is available for use in the Data Cube as usual. For more information, see Using the Data Cube.

Biennial RCRA Reporting

Waste Generators can accurately report biennially (every other year) on the amount of waste generated onsite, received onsite, managed onsite, and/or shipped offsite. This includes the following files:

  • Waste Generation and Management (GM)
  • Waste Received Offsite (WR)
  • Site Identification Information (SI ID)
  • Offsite Identification (OI)

Only manifested waste will be considered for either on-site or off-site treatment. That is, waste records must have a relationship to a waste manifest whether the waste is shipped off-site or treated on-site.
When there is no entered data to pull into the file, the file will still be generated but empty.
For the GM1 file to be created properly, the following value must be added to the Units of Measure look-up table in order to map the Density Unit of Measure information for the file:
Code=lbs/gal, Description=Pounds per Gallon.

To populate, generate, and download the biennial waste forms:

  1. In the Environmental menu, click Location Details.
  2. Choose Actions»Generate Biennial Report.
  3. Select the Form Type (as listed above) and Reporting Period. If you select the Include in National Report checkbox, the EPA will include the generated data in the national report.
  4. Click Select. A file will be generated and downloaded in the appropriate file format (for example, ZIP). The files conform to the specifications outlined by the RCRA, and named in the format: SSFFFNNN.FIL where:
    • SS – the state postal code
    • FFF – the file identifier (e.g. SI2 for Site Identification Information Form 2)
    • NNN – the date the file was created
    • For example, the name for the SI2 file containing KS data, produced on February 4th, would be KSSI3035.FIL.
