Applying Desktop Actions

Desktop Actions are programmed actions that perform tasks with RSIGuard. Desktop actions are executed using RSIScripts; a scripting language that lets you write "programs" to perform complex tasks with RSIGuard. Tasks can include:

  • Performing repetitive tasks such as creating a standard email, addressing it, filling in the fields, and sending it.
  • Asking a user questions and doing various actions based on their responses.


To set up desktop actions:

  1. In the Ergonomics cloud menu, choose Desktop Actions.
  2. Click New, or select an existing desktop action to modify (and skip to step 6).
  3. Enter a Code and Description.
  4. Enter the desired RSIScript.
  5. Click Save.
  6. Use the Groups and Teams or Employees tabs to select the users that this desktop action will apply to.
