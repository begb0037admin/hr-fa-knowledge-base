Working with the Medical Correspondence Module

The Medical Correspondence module provides a central location to view all of an employee's medical correspondence, and for a practitioner to easily email one or more of the medical correspondence items. These may include medical or case notes, medical or case documents, medical questionnaires, saved PDF forms, non-draft medical or case letters, or email logs.

The Medical Correspondence module is not available in the OH menu by default; it must be made available to each user through their menu configuration. A user will only be able to see correspondence for sources that they have security permissions to access.

  1. In the Occupational Health menu, click Medical Correspondence.
  2. Select an Employee and optionally filter by Created Date and/or Source.
  3. To view a record, click on the employee name. The record will open in the appropriate related layout; for a Form record, the PDF will open in a new tab or be downloaded, depending on the browser’s configuration.
  4. To send one or more records by email, select the record(s) and choose Actions»Email. You are prompted to provide the To and CC recipients, subject and body content. For security, two emails are generated and sent:

The first email will have the subject and body content you provided, and a password-protected zip file containing all of the selected medical correspondence items in the following format:

  • Notes: a Clinic Visit/Case Progress report for the selected notes in a single file named MedicalNotes/CaseNotes
  • Questionnaires: a single PDF that includes all of the questionnaire responses separated by a report header
  • Forms: a PDF for each form, named the same as the form
  • Letters: a PDF for each letter, named using the letter code
  • Documents: a file for each selected document in its original format. If a document is a hyperlink (not an import file), it will not be included in the zip file
  • Email Logs: a PDF for each log with file name EmailMessageId.PDF
  • Attachments in the Email Log: a separate file for each email attachment with part of the file name EmailAttachmentMessageId.pdf so that the Message ID field can be used to identify the email that goes with the attachment

The second email will provide each recipient with a system-generated password for accessing the content in the zip file sent in the first email. It will have have a subject of “Password”. For medical correspondence Emails (“Email Log” records), the list is restricted to only those from the logged in user's email log.
