Managing Online Training Courses

Cority’s LMS is made up of three look-up tables:

  • Online Training SCORM Files – This table holds the SCORM package for a training course. This is hidden and managed by Cority.
  • Online Training Library – This is a list of available courses. SCORM files from the Online Training SCORM Files table are attached to the courses here.
  • Online Training Series – This is the scheduling tool for online training. Administrators add courses to an Online Training Series and can schedule ad hoc training sessions or create recurring training.

The series creates a session with the correct SCORM package attached. When a user logs into myCority and clicks on Training, they are given a list of training sessions that are available to them. Clicking on one will launch the training for the user.

Assigning a Single Ad Hoc Training Session to a User

Note  Any training assigned like this will not be scheduled on a recurring basis; this will be the only session that the user receives.

  1. In the Training menu, click Online Sessions, then click New.
  2. Populate the Employee, Course, and Date, then click Save.

The new session will be added to the Online Training Sessions list view. 

Assigning Scheduled Training to a Group of Users

Set up the group:

  1. In the Training menu, click Online Training Groups, then select an existing group or click New to create a new group. If you are creating a new group, ensure that the "Training" flag is selected.
  2. If you want to manually add team members:

Manage Recurrence (Training Series):

  1. In the Training menu, click Online Training Series, then select an existing series or click New to create a new series.
  2. If you selected an existing series, skip to step 3.
    If you are creating a new series:
    1. Enter a Description. This will be the label for this series, i.e. how it will appear in training sessions.
    2. Enter the Start Date. This is the date the series will become active and start scheduling sessions. Optionally enter an End Date when you want to stop scheduling sessions.
    3. Set the Recurrence that you want to generate the sessions, and the Gap. For example, a recurrence of “weekly” with a recurrence gap of “4” would schedule sessions every 4 weeks.
    4. Set the Recurrence Start Method that will trigger a recurrence:
      • Series Start Date: All sessions will always recur based on the original start date for this training series. So even if courses are added after the fact, they would still recur based on the date the series started.
      • Course Assigned Date: This is the same as the Series Start Date with one difference: If courses are added after the fact, those courses will recur based on the date they were added to the series.
      • Completed Date: Recurrence will be based on the date the user completes the training.
    5. Optionally, set the Days to Complete. This determines the due date. If left blank, sessions associated with this series will not have a due date. This cannot be changed after the series is saved.
    6. Click Save.
  3. Click Group and Teams, then click .
  4. Select the group(s) you want to add, then click Select.


When an employee is removed from or leaves a group/team, select the Inactive check box in the Details section of any incomplete online training sessions. This prevents duplicate sessions being created if the employee is added to another group/team that uses the same course(s). 
Any risk data recorded from a self-assessment is retained, even if the session is inactivated prior to completion because the user has been removed from the group/team.
