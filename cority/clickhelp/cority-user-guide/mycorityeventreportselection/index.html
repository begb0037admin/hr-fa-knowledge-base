myCorityEventReportSelection

This optional table can be used to identify consolidated lists of Event Report Types that are available to myCority users across the different solution areas (Environmental, Ergonomic, Quality, and Safety Event Report Types). This table only controls the Event Report Types available in myCority by one of the Organizational Trees; e.g. allowing for different Event Report Types to be seen by users in different countries, regions, departments, etc. It also allows for creating the desired order of Event Report Types across the solution areas, so that the most frequently used are higher in the selection screen.

 If this table is not populated and Event Report Types are configured for more than one solution area, then the Event Report Types for the different solution areas will appear in the following order:  Safety, Environmental, Ergonomic, and Quality.

 Population of the Event Report Selection look-up tables for the solution areas used will still need to be completed if users create Event Reports via Cority GX2 and/or via standalone access. When there is one or more active records in the myCority Event Report Selection, then it will be displayed for myCority users.

For each Event Report Selection record:

  1. Enter a Code and Description for the Event Report Selection screen.
  2. Optionally populate a Start Date.
  3. Populate one of the Organizational Tree(s) to identify the myCority users that will see the associated Event Report Types.
    1. The first record created will determine the tree that can be used for all the additional records created in this look-up table.
    2. The tree selected should be one that is populated for all Employee demographic records, so that myCority knows which selection screen to provide.
  4. Optionally provide general Instructions that will be provided to myCority users when they select New Event Report.
  5. Optionally select Default Selection checkbox on one of these records:
    • This will be used by Guest User, if this generic user is allowed in your myCority instance.
    • This will also be used for a user that has an Employee where the tree selected in #3 above is not populated.
  6. Select the Event Report Types in the Event Report Type sublist and adjust the order.
