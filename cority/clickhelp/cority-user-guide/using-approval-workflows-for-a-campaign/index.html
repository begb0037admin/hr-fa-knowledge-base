Using Approval Workflows for a Campaign

You can route all metrics associated with a campaign through an automated approval workflow to ensure that the company is using only approved data for internal reporting and external messaging, and to create an audit trail for third-party sustainability auditing.

An approval workflow record for a campaign displays all recorded campaign data (read-only), as well as any associated findings and actions. A user with appropriate permission can delete any record that they do not want taken through the approval process.

When an approver approves a metric, the campaign is then routed to the next level of approver, who receives an email notification that a campaign record is awaiting their review and approval. Upon final approval, the person who initiated the request is notified.

You can configure the notification email message in the LettersTemplate look-up table. If enabled in the Cority Email Notification Utility settings, an email may be sent to alert approvers (or initiators, or both) that an approval is due or overdue. For more information, see Working with MAEN Settings).

Setting Up an Approval Workflow

In order to use the approval workflow process for campaign data, the following must be established:

  • Set up the supporting look-up tables: the BIWorkflowApprovalType table contains approval types related to different approval layouts.

  • Optionally, set up a swimlane view to view and manage the approval workflows (see Working with Swimlane Views).

  • Set up a campaign that is defined to automatically create approval records and indicates which Approval Workflow type should be used (see Grouping Metrics into a Campaign).

Approving a Campaign’s Data

An approval record is automatically created for each metric instance recorded by each assignee in the campaign. The workflow process is not triggered until the assignment is 100% complete (that is, all metric values have been recorded).

Designated approvers review the campaign’s approval records and approve them to move them to the next approval stage.

  1. In the Business Intelligence menu, click Approval Workflows. All campaigns that have some data recorded are listed.

  2. Open an approval workflow record and review the metric data.

  3. When you are ready to approve the change request, select the date beside your name in the Approvals list. The next approver is notified. If you were the final approver, the person who initiated the request is notified.

The status of an approval workflow record will revert to “In Progress” if an associated measure or campaign metric is deleted.

If a swimlane view has been set up, you can switch to that view. Drag and drop the record into another approval role swimlane. Click an entry to view the approval record.

Making Changes to the Campaign

Approval records are separate from the campaign they were created for. For this reason:

  • If you clear the Auto-Create Approval Workflow for This Campaign checkbox, no further approval records will be created but you must manually delete any that have already been created.

  • If you want to change the Approval Workflow type selected for a campaign:

    • Clear the Auto-Create Approval Workflow for This Campaign checkbox.

    • Delete all approval records that were created for the campaign.

    • Select the Auto-Create Approval Workflow for This Campaign checkbox again and select the appropriate Workflow Approval type.

If a metric is added to the campaign, or if a metric value is added or modified, the workflow status will change depending on the new completion status. If an associated measure or campaign metric is deleted, the status of the approval workflow record will revert to “In Progress”.
