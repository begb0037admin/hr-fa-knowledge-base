Viewing Location Details (Emissions Inventory)

The Location Details displays a map of the site and tabs for data linked to the selected site.

In the Emissions Inventory menu, ensure a site is selected and then click Location Details.

If you do not have a Default Location defined in your user settings, use the Site Selector at the top of the Emissions Inventory menu to select a site in your organization tree.

Use any of the tabs to view or enter information connected to the selected site: assets, source profiles, chemicals, and emission source test data.

    The tabs may include information for the site's child locations as well, depending on the "Display Child Locations for Location Details Landing Page" system setting.
