IncidentCostType

This table contains the various types of costs used to complete employers’ reports and other compensation forms related to an incident claim.

  1. Click a link to edit, or click New.

  2. Enter a Code and Description.

    3. If you are an experience-rated organization, be sure to use the same cost type codes as those used by the workers’ compensation board within your jurisdiction.

  3. If the cost is to be included in the reserve fund, select the Reserve checkbox. Leave this checkbox clear if it is considered a payment description (e.g. physician payment).

  4. Click Save.
