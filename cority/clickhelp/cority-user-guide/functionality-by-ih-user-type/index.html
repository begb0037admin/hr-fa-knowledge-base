Functionality by IH User Type

The functions available depend on your user type, which is defined in the Users table (an Administrator function; see Setting Up Users). Each user type has a different role in the IH modules:

  • Laboratory Users only have access to the Lab Requisition module. They may only view requisitions that have been assigned to their laboratory.

  • Chemical Designates are only able to access the Chemical Product, Chemical Inventory, and Chemical Request modules. They can only see and manipulate their own chemical inventories.

  • Technician/Consultants have only limited access to the Industrial Hygiene modules. Among other limitations, they can enter sample and survey records, but can not change the sample status (i.e. Approve, Void, Reject, Hold), nor can they view records created by other users. If Technician/Consultant users are allowed to run reports, they are only able to see approved samples that they have entered into the database.

  • Hygienists can enter, view, update, or delete records, approve samples, and run reports as needed. They are generally able to work freely in any of the Industrial Hygiene modules to which they have been granted access.

  • Managing Hygienists have similar access as Hygienists, with the exception that only Managing Hygienists may approve an Exposure Assessment record.
