TaskEscalation

This table is used to defined escalation profiles that may be associated with a compliance action.

Each profile can have multiple scenarios, which dictate which notification is sent to whom and when (in relation to the task due date).

For each scenario, you must select either the Escalation Group (from the GroupandTeamlook-up table) or the Employee to Notify.
