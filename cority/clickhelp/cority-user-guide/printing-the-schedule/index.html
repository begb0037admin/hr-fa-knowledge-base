Printing the Schedule

You can print your schedule from any of the schedule views. The printout is a screenshot of the calendar as you are viewing it, so you can select the desired view and any sidebar options (such as a particular schedule status for a single user) to set up what will be included on the printout.

Select the appropriate view and apply any filters as required, then click . If the view displays To-Dos, they will also be included on the printout.

If information is being cut off in the appointment blocks, you can set the Slot Duration to a smaller time, e.g. 10 min, so that the appointment blocks appear larger. See Setting Up the Calendar. Note that this will also require more space for the full schedule to fit in.
