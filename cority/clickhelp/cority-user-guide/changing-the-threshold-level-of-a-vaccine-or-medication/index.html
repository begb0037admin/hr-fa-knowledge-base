Changing the Threshold Level of a Vaccine or Medication

Threshold levels can be set in the Inventory module or in the related Vaccine or Medication look-up tables.

To update thresholds in the Inventory module:

  1. In the Occupational Health menu, click Inventory.

  2. The thresholds will be changed for your default Health Center only. If necessary (and according to your security access), select a different health center to update their thresholds.

  3. In the appropriate list select the immunization or medication, then choose Actions»Update Inventory Threshold and enter the new threshold value. If multiple items (within the same list) require the same threshold number, you can select and update them at the same time.
