Pharmacy

This table lists contact information for pharmacies that might be sent prescriptions.

If you are an eRx user, your prescriptions will not use this list of pharmacies. The eRx Employee Medication form accesses a separate list of pharmacies that is maintained by Surescripts. Each pharmacy in that list has been certified by Surescripts and is displayed with the services it provides (New Rx, Refill, Change, Cancel, and Controlled Substance).
