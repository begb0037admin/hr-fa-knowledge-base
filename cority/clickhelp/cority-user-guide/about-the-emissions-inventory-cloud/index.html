About the Emissions Inventory Cloud

The Emissions Inventory Cloud simplifies organizational efforts for gathering data, calculating air emissions of hazardous chemicals, and conducting agency reporting to ensure compliance with global regulations and legislation. Reporting can be done for different levels and agencies, by asset, facility, etc.

This chapter explains how to:

  • set up the supporting data that may be used by multiple source profiles (see Setting Up Supporting Data)

  • group chemicals into process streams in order to track the stream composition for materials over time (see Creating Streams)

  • define the assets that you want to monitor, along with their emission parameters including the stream they are associated with (see Recording Assets)

  • set up a source profile that dictates the assets and sequence for analysis (see Setting Up a Source Profile)

  • monitor and review reports (see Emissions Inventory Reporting)

For a visual and/or site-specific view of all emissions data related to a particular location, use the Site Diagram (see Viewing and Managing Data for a Site).
