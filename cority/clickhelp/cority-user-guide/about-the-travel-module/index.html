About the Travel Module

Use the travel module to record travel plans and ensure employees receive the required immunizations for their destinations.

 

This chapter explains how to:

  • enter a travel clearance request (see Entering a Travel Clearance Request for an Employee)

  • view an employee’s immunization plan (see Viewing an Immunization Plan)

  • clear an employee for travel (see Clearing an Employee for Travel).

To see the look-up tables used by this module, see Look-up Tables Used by This Module. There may also be system settings that affect your use of this module; for more information, see Changing Your System Settings.
