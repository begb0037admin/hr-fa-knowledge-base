Viewing and Managing Emissions Data for a Site

There are two ways to view and manage emissions data for a specific site:

  • The Location Details displays a map of the site and tabs for the assets, source profiles, chemicals, and emission source test data linked to the site.

  • A Site Process Flow Diagram allows you to view and move your emissions data in a flow diagram.

These functions display the same data recorded directly in the separate modules, and conversely any data entered in the Location Details or Site Diagram are reflected in the modules.

If you do not have a Default Location defined in your user settings, use the Site Selector at the top of the Emissions Inventory menu to select a site in your organization tree.
