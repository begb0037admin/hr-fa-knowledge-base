Recording Work Restrictions

An employee’s work restrictions can be recorded in the Demographic, Medical Chart, Clinic Visits, Case Management, Pulmonary, and Respirator Fit modules. The Restrictions tab in each of these modules displays all of the employee’s work restrictions regardless of where they were entered.

  1. On the Restrictions tab, click a link to edit an existing restriction, or click New.

    2. To quickly add a new record with minimum fields, click  and complete the fields as required, then click Save. To add multiple restrictions with the same start date, click , select all restrictions that apply, then enter the start date. If necessary, you can later open the new records to capture additional information.

  2. Select the Restriction, and enter the Start Date (mandatory).

    3. The Restriction list in the Respirator Fit module will not include any restrictions considered solely medical-related (i.e. they are set to “Hide Restriction in Respirator Fit module” in the Restriction look-up table).

  3. Indicate if the restriction is Permanent (restrictions are temporary unless indicated otherwise).

  4. Indicate if the restriction is Occupation-related, and enter the Case Number if not displayed automatically.

  5. Optionally, enter Accepted, Review, and End Dates, and any Notes about the restriction.

    6. To quickly apply the same end date for multiple restrictions, choose Actions»End All Active Restrictions. Enter the Actual End Date and click OK. You can only use this action on restrictions that have the same case number, if applicable, and which do not already have an End Date entered.
    If you have linked the restriction to one of an employee's case records and there is an active RWD or LWD absence for the same case number, you are asked if you want to update the absence status as well.

  6. Indicate if the restriction should be included on the Problem List (see Working with the Problem List).

  7. Click Save. Cority checks the Holiday look-up table to see if there are any holidays in this period that apply to this employee.

If you enter a restriction in the Clinic Visit or Case modules, you are asked if you want Cority to begin counting the number of restricted days. If you choose Yes, Cority creates an RWD absence with the same start date as the restriction entered, using the status defined in the appropriate system setting.
