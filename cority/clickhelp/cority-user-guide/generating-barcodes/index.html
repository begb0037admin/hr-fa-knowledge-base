Generating Barcodes

Environmental Cloud

You can generate barcodes for environmental assets that will allow myCority users to scan and retrieve information about an asset.

Generating Barcode(s) to be Included on the Asset Record

  1. On the Asset Management list view, select the assets that you want to create barcodes for.

  2. Choose Actions»Generate Asset Barcodes.

  3. Select the barcode type:

    • If you just want to generate the barcodes to be included on the records, select “Do not print barcode”.

    • If you want to generate the barcodes to be included on the records AND to print the barcodes, select the barcode type.

  4. Click Generate.
    If you selected a barcode type, the barcode(s) open in a separate tab in PDF format.
    Regardless of your selection (barcode type or “Do not print barcode”), the barcode will be found in the Container Barcode field of each record. The format shown depends on the Field Properties of that field:

  • If the View Type is “Text”, a nine-digit numeric code will be provided in the field:

    • The first six digits will be today’s date in YY/MM/DD format.

    • The last three digits will be a sequential, system-generated number that ranges from 001 to 999. The sequence will restart at 001 each day.

  • If the View Type is “Barcode”, a barcode will be displayed and a nine-digit numeric code (in the default CODE128 format) will display below it.

  • If the View Type is “QR Code”, a QR code will be displayed.

For information about field properties, see Defining Form Layouts.

Printing Barcodes (Without Generating)

You can print barcodes while generating them for records as described above, but if you only want to print the barcode to apply to the asset, select one or more records on the Asset Management list view, then choose Actions»Print Barcodes. Select the barcode type and click Print. The barcode(s) will open in a separate tab in PDF format.
