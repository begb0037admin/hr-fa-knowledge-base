Managing Absence Reports from myCority

Employees can report their own absences in myCority. (This functionality is only available for the myCority SSO and LDAP authentication methods.) For more information, please refer to the myCority documentation.

These reports are then reviewed in Cority and posted to a new or existing case.

Viewing Absence Reports Sent from myCority

When an absence report has been submitted through myCority, it will display in the Absence Reporting Inbox module in Cority's Occupational Health menu. You must add this module to your menu (see Customizing Your Menu), and you must be granted the appropriate permission. 

  1. In the Occupational Health menu, click Absence Reporting Inbox. The list displays all submitted but non-posted absence reports.

    2. The myCority user can update or cancel the report before it is posted to a case. A cancelled absence report continues to display in the Absence Reporting Inbox list in Cority, with the Cancelled checkbox selected. The Post and Go to Case actions will be disabled for the record.

  2. Click an Employee link to open the absence report.

    3. The absence report is assigned the “myCority_AbsenceReport” Case Type (unless the related business rule is changed). Any to-do activities linked to this case type (in the CaseType look-up table) are listed on the To Do List tab. If a to-do activity associated with this case type is flagged Assign to Employee, the activity is assigned to the employee when they submit the absence report. These to-do activities are not added to the main To-Do List module until the absence report is posted to a case record.

    The record also includes any documents that the myCority user attached to the report.

  3. Choose the appropriate action:

  • Go to Case – If the absence report is already posted to a case, choose this to view the case record.

  • Post and Create a New Case – On the new case record, the Case Managed checkbox will be selected, and the Enrollment Date will display the date the absence report was submitted. If there are any documents or to-do activities linked to the absence report, they will display on the case’s Documents and To-Do List tabs respectively.
    On the absence report, the Case Number field will display the new case number and all fields will become read-only.

  • Post and Link to Existing Case – You are prompted to select the case record. All absence, document, and to-do information will be copied to the selected case.
    On the absence report, the Case Number field will display the linked case number, and the Post actions will be disabled.

When an absence report is posted to a case, the Absence Status will be “myCority_AbsenceReport” (unless the related business rule is changed); this absence status is associated with the “Lost Work Day” absence type.
An absence must be manually ended by updating the absence status on the case record.
