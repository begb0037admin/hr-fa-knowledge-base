HazardSeverityRating

This table lists hazard rating classification value assigned to the agent; includes values to be used in calculations. It also identifies any risk factor qualifiers available based on assessment category. These value are also used in assessing FMEA studies in the Quality module.

Identify which Clouds/modules/finding types the rating is available in, or if it is associated with a work permit.

There are views in the Findings and Actions module, as well as on the Incident report’s Incident Category and Risk tab, that can display risk-related information; however, this information will only appear if the Incident Finding assessment type is selected in this table.
