About the Business Intelligence Cloud

The Business Intelligence Cloud provides several options to report on information in Cority:

  • Use your Dashboard to monitor multiple indicators for various types of Cority data (see Using the Dashboards).

  • Use the Metrics module to capture and analyze data in a Data Cube (see Using Metrics).

  • Use standard Cority reports specific to each module (see Generating Standard Reports).

  • Create ad hoc reports by selecting fields in a particular table view in the Query Builder or Report Writer (see Working with Ad Hoc Reports).

  • Schedule automatic generation of standard or ad hoc reports or Dashboard views (see Scheduling Reports).

The Query Builder is an intuitive interface that replaces the Report Writer, which will eventually be removed from the Cority application. In the interim, you can use either module and any queries/reports will appear in both.

Another reporting option is to view an employee’s Problem List, which includes all medical information that has been identified as a problem (see Working with the Problem List).
