SafetyCultureMeasure

This table holds the measures that are used to calculate your Safety Culture Score. These are not editable but you can:

  • view the Calculation Logic applied to the measure as well as the version code

  • specify GDDLOFB combinations to be measured

  • make the measure Inactive if you do not want it to be factored in the calculation.
