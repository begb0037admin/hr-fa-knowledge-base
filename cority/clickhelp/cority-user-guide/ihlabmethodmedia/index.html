This table is used to link laboratories with appropriate analytical methods and collection media.

  1. To filter the list of records, enter a few characters in one or more of the fields at the top followed by an asterisk, then press Enter.

  2. Click a link to edit a record, or click New to add a new record.

  3. Select the lab, analytical method, and collection media.

  4. Click Save.
