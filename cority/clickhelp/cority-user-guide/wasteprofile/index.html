WasteProfile

This table is used to create profiles for chemical and radioactive waste that determine how such waste should be disposed of and where. A waste profile can be associated with a container in the Waste Management / Waste Container Management modules.

To create a new profile:

  1. Click a link in the list view to modify an existing profile, or click New.

  2. Enter a Code and Description for the profile.

  3. Select the UN Number and Waste Code from the corresponding look-up tables.

  4. Enter the transportation information. The Primary TDSF Facility field lists records in the Vendor look-up table that are marked as Waste Disposal Facility. The Primary Transporter field lists records in the Vendor look-up table that are marked as Waste Hauler.

  5. In the Lab Data field, select any emission source test data results.

  6. Select the relevant Permit.

  7. Enter the characteristics of the waste.

  8. On the Chemical Composition tab, identify the ingredients and indicate the percentage that each ingredient is part of the whole.

    9. If the “Display Additional Decimal Values for Ingredient %” system setting is enabled, the % Ingredient, High Percentage and Low Percentage fields will round to 10 decimal places.

  9. Use the Documents tab to link an external file to the record to provide easy access to the file (for more information, see Linking or Importing a Document).
