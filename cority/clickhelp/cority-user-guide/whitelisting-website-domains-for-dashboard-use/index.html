Whitelisting Website Domains for Dashboard Use

Advanced Dashboard users can add an indicator on their dashboard that displays a website (see Embedding a Web Page on the Dashboard). Only website domains that have been approved by your organization can be embedded.

To add a website domain to your organization’s whitelist:

  1. In the Administrator menu, click Whitelists.

  2. Click New and enter the domain. Here you can enter a base domain (allowing users to enter a URL to a page within that domain), or a full web page URL.
