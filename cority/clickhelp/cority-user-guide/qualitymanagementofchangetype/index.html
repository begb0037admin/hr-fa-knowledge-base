QualityManagementofChangeType

This table lists the possible change request types that may be created in the Change Request module. Five standard types are included (Equipment, Material, Personnel, Procedure and Process). If necessary, edit these or add new types to suit your requirements.

For each type:

  1. Optionally, select an icon to be shown with the change request type name on the change request start page (must be included in the UserIcon table).

  2. The Approval Sequence tab provides a default list of approvals and their sequence; change this as required.

  3. Select the layouts to be used when accessing change requests in Cority.
