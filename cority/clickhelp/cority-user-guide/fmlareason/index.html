FMLAReason

This table is used by the Case module. It contains the reasons for an FMLA and the default number of days allowed for each.

  1. To filter the list of records, enter a few characters in one or more of the fields at the top followed by an asterisk, then press Enter.

  2. Click a link to edit, or click New.

  3. Enter the Code and Description.

  4. The Number of Days Allowed for this type of FMLA defaults to 60; change this if necessary. This value appears in the case form, but can be changed.

  5. Click Save.
