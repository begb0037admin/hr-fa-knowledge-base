ImmunizationSeries

This table defines immunizations that require completion of an entire series before the employee can be considered or tested for immunity.

  1. To filter the list of records, enter a few characters in one or more of the fields at the top followed by an asterisk, then press Enter.

  2. Click a link to edit, or click New.

  3. Enter a Code and Description of the immunization series.

  4. To add the immunizations that are part of the series, click New on the Linked Immunizations tab and select the appropriate immunization codes.

  5. Click Save.
