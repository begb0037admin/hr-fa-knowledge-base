Employer Access

Employer Access is limited access to GX2 that provides access to the Invoices, Billing Documents, Dashboard, and Demographics modules.

This allows an employer to:

  • view and manage their invoices and dispute individual items or entire invoices
  • manage their employee population directly in the Demographics module (the GX2 Administrator can provide a template to import demographics)
  • access myCority to book appointments
  • set up their dashboard, e.g. to track metrics related to billing.
