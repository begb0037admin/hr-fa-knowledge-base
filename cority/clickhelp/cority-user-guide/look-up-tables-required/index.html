Look-Up Tables Required

The Emissions Inventory Cloud relies on several tables that should be set up before using the Emissions Inventory Cloud to analyze emissions:

  • EmissionFactor - set up emission factor values by location and effective date; these factors are available for use in creating an equation in the Equation look-up table.
    Accessed from the Emissions Inventory menu.

  • Equation Library - set up all the equations you will need for emissions inventory calculations.
    Accessed from the Emissions Inventory menu.

  • EquationSet - create a set of equations that will apply to fields in an asset table; these are specific to an asset which will be used in a source profile.
    Accessed from the Look-up Tables list in the Administrator menu.

  • ReportingPeriod - define the reporting periods to be used in emission calculations.
    Accessed from the Look-up Tables list in the Administrator menu.

  • Asset Types (EquipmentType) - define the types of assets to categorize your assets.
    Accessed from the Emissions Inventory menu.
