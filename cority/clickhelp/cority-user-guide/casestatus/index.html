CaseStatus

This table lists codes for case status (e.g. open, closed, pending, etc.).

Optionally, select the Standardized Value (from the CaseStatusStandardizedValue look-up table) to categorize each record. This value will be used by the predictive Analytics module to compare your data to that of other organizations and determine your relative performance.
