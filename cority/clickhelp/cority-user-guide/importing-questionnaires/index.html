Importing Questionnaires

Import one or multiple questionnaires from an Excel spreadsheet.

Importing an employee’s responses to a questionnaire does not affect the questionnaire stored in the Questionnaire look-up table.

Importing a Single Questionnaire

To import a questionnaire from Excel, on the questionnaire list choose Actions»Import Questionnaire. Select the Excel file from which you want to import responses, then click Import. The responses in the Excel file are transferred to the questionnaire stored in the Cority database.

Importing Multiple Questionnaires

To import multiple responses in a single multi-sheet Excel file, on the Questionnaire Inbox choose Actions»Bulk Import Questionnaire Responses. Select the Excel file from which you want to import responses, then click Import.

Each sheet must contain the required header information and a different set of answers to the same questionnaire. If one sheet does not match the format of the questionnaire, that sheet is not imported and the next one is validated and imported.

Each sheet is saved as a new Questionnaire Inbox entry or record.

If more than one import request has been submitted, they will be performed in FIFO order. You can check the status of a request in the Process Status log (see Viewing Import Logs). You are notified by email when the import process is finished.
