Storing Source Test Data

Use the Emission Source Test Data module to store and use emission source test data results in emission inventory calculations.

Recording the Test Sample

  1. In the Emissions Inventory menu click Emission Source Test Data.

  2. Click a link to view a test sample, or click New to enter a new sample.

    3. Use the Site Selector (at the top of the Emissions Inventory menu) to view just the source test data records related to a particular GDDLOFB node.

  3. On the Sample Properties tab, enter information about the sample including the Sample Date, Sample Number, Emission Source, properties of the sample, laboratory information, and ambient data.

  4. Use the Documents tab to link an external file to the record to provide easy access to the file (for more information, see Linking or Importing a Document).

  5. The Forms tab displays all forms in the PDFForm look-up table that have a linked module of “Source Profile” and a status of Preview or Published. Open and complete these as required.

  6. If added to your layout, you can use the Corrective Actions tab to associate finding and actions with the test results and assign corrective actions. For information about recording an action, see About Findings and Actions.

  7. Click Save.

The Related Assets tab displays any assets that this test data record was added to.

Recording the Sample Test Results

  1. Retrieve the source test sample record, if it’s not already open.

  2. In the Sample Results sublist:

    • Click New to record results for a new pollutant, or

    • Click  to retrieve an existing pollutant from the AgentHazard look-up table and then click the Sample Number link.

  3. In the Sample Results form, record the results as well as any testing method and QA/QC information required.

  4. Click Save.
