Using the Microsoft Outlook Integration

This integration, provided with the GX2 OH license, can improve scheduling efficiency, prevent double-bookings, and expand virtual care options with a built-in Microsoft Teams integration. It provides:

  • Seamless calendar sync: Overlay Outlook calendars within GX2 and automatically send Outlook meeting invites.
  • Integrated virtual care: Link GX2 appointments with Microsoft Teams for secure, efficient telehealth visits.
  • A New Scheduling Assistant: Checks employee availability within Outlook to prevent double-booking.
  • Streamlined communication: Outlook meeting responses feed directly back into GX2 for real-time status updates.
  • Time savings: Automates scheduling and notifications, reducing administrative effort for clinicians and employees.
  • A Notification Bell: Displays meeting status in a Bell icon within the Appointments module.

Configuration

  • An Azure App is required to connect GX2 with Outlook. Engagement between your IT Team and Cority Professional Services is required for the Azure App build and initial testing/setup. Contact your Cority Account Manager or Customer Success Manager for more information. The following system settings require information from the Azure App:
    • Microsoft Graph Client ID → from the Azure ‘Application (client) ID“
    • Microsoft Graph Client Secret → from the Azure value
    • Microsoft Graph Tenant ID → from the Azure ‘Directory (tenant)’

     Configuring these Microsoft Graph system settings will effectively turn on the Outlook Integration for every user. Meeting invitation emails will begin to be sent automatically.

  • Ensure that the "Enable OAuth 2.0 Authentication" system setting is selected.
  • Ensure that the "Synchronize Appointments from Outlook Exchange Server" system setting is selected.
  • The following system settings are now deprecated for Outlook use with the Appointments module but should remain populated, especially if using the Inbox feature:
    • Exchange AAD Client ID
    • Exchange AAD Client Secret
    • Exchange AAD Tenant ID

Once the integration is configured, the Appointments module will automatically send meetings created within GX2 to Outlook.

Turn on the Outlook toggle in the Appointments module to display the user's Outlook calendar in the GX2 Appointments calendar. The Outlook events will display.

The following fields have been added to the Schedule Entry layout:

  • Scheduling Assistant
  • MS Teams – Telehealth
  • MS Teams Meeting Link
  • Outlook Event ID
  • Outlook iCalUid

Using the Scheduling Assistant

For the Scheduling Assistant to populate, the following fields must have values:

  • Scheduling user
  • Employee
  • Date
  • Time

Scheduling Assistant – Time Slots — The available times will be displayed as chips for up to 10 days in the future, which mimics Outlook behavior. Availability slots respect the workday/worktime for users as configured in Outlook. Navigation arrows are provided for displaying additional timeslots.

  The system does not verify the Scheduling User against GX2 availability because it is assumed the person creating the appointment is looking at that calendar. If no availability is displayed, you must select a new date and time.

Scheduling Assistant – Statuses:

  • “All users are available at the selected time” – the users are available 
  • “Not all users are available at the selected time” – either the Scheduling User or the employee is not available
  • “No users are available for the next 10 days” – the users are unavailable

Microsoft Teams Integration

Microsoft Teams fields can be added to custom Schedule Entry layouts.

To link the appointment record to a Teams meeting, you must first obtain the license key for Remote Expert users.

  • If you add Teams fields to a custom layout but do not have a license key that includes the Remote Expert license, those fields will be disabled.
  • If you have Teams as part of your corporate license, have configured the Outlook Integration in GX2, but do not have the Remote Expert license:
    • If booking within GX2, the default email will not include a Teams link.
    • If booking within Outlook, the default email will have a Teams link.

Fields for Troubleshooting

These fields are optional, but should be used for troubleshooting. When a meeting is successfully sent to Outlook, these two fields populate:

  • Outlook Event ID: This is the ID of an event resource type, which is a unique identifier for an individual event on a particular calendar.
    Important  This ID is specific to the calendar in which the event is stored and could change if the event is moved to a different calendar.
  • Outlook iCal UID: This is returned by the calendar event resource type in Microsoft Graph, and is a unique, read-only identifier shared by all instances of an event across different calendars.

Automated Meeting Emails

There is a system setting to "Define the Email template to be used with Outlook integration".

The system will merge the BRA's email body with the Outlook meeting details (subject, additional recipients, any Teams information, etc.).
Note  If the Subject is blank, an error will occur. Ensure you always populate the recipients, subject, and email body.

The Send Email field on the Schedule Entry layout is to be used for resending ics files (if necessary) or for recurring GX2 appointments. Recurrences are otherwise not supported. Responses for recurrences from Outlook will be given the status TBD within the Notification Bell (described below).

The GX2 Appointments module invitation will map to the Outlook invitation: The current logged in GX2 user will be the Organizer, the Scheduling User will be Attendee #1, and the Employee will be Attendee #2. The integration automatically includes Teams meeting information (if applicable) in the body of the invitation.
Note If you do not have a Remote Expert license, the Teams meeting details will be omitted.

If you have not configured a custom version of BRA-000542 (business rule email action) and defined it in system settings, the system will instead send out a default email that contains the basic appointment information.

Meetings booked within GX2 will be sent automatically to Outlook, and any edits made within GX2 will be reflected in Outlook.

Notification Bell (Meeting Responses)

The notification bell in the Appointments module:

  • Provides a count of the inbound notifications for all Accepted, Declined, and Tentative responses that have not been viewed
  • Provides the status of the meeting
  • Updates every 5 minutes

 The notifications are for meetings the logged-in user created. Reports and business rules can be configured for this functionality and will apply for all responses received by GX2, regardless of the meeting creator (organizer). The entity for this data table is Inbound Notifications.
