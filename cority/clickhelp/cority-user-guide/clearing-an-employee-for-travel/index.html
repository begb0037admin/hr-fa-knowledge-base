Clearing an Employee for Travel

When the employee has received all necessary immunizations, they can be cleared to travel to their destination.

  1. If necessary, retrieve the clearance request from the list as described in Entering a Travel Clearance Request for an Employee.

  2. Enter the Date of Clearance.

  3. Select the practitioner who has cleared the request, and change the Clearance Status.

  4. Click Save.
