DocumentLibrary

This table lists the controlled document libraries and the approval workflow for each. For each reviewer, indicate if their approval is required to move the review to the next stage, and if they have authority to publish a document.

You can assign more than one user to each workflow status (or step) on the Approval Workflow tab. The configuration must be identical for each user, i.e. the same workflow status, sequence, and setting of the Publisher checkbox. When multiple users are assigned to a workflow status and the status is met, each user will receive an email notification informing them of the assignment and any of those users will be able to review, reject, approve, or publish (depending on the workflow status) the document. 

Once the document has been dealt with by one of its assigned users, the other assigned uses will not be able to execute the option(s) for that status and the document will move to the next step/status in the workflow. However, if an assigned user rejects a document, the document owner will be notified of the rejection and any one of the users assigned to the workflow status will again be able to review, reject, approve, or publish (depending on the workflow status) the document.

To create a swimlane view for the library, on the Document Library tab, choose Actions»Create Swimlane View. In the Document Control module, all documents in the selected library will display in a swimlane view, with a column for each reviewer in the same order as they appear in the Approval Workflow tab in this table.

Configuring the Appearance

Some appearance aspects can be defined at the final "Published" step.

If the Publisher checkbox is selected, the Render as PDF checkbox is also selected by default (but can be unselected); if both are selected, files of supported types will be converted to PDF.

If Render as PDF checkbox is selected:

  • A Watermark of up to 40 characters can be defined. The watermark will overlay diagonally from the bottom left to top right of the page and will be grey and transparent.
  • If the Headers and Footers checkbox is selected, a rich text HTML editor (similar to the one in the Letters module) and a merge table selector become enabled. The text editor can be used to create, format, and display free text and add a logo in the document's header and/or footer. The merge table can be used to add any metadata from the Document Control record (the main form and/or the Approval History section) to the header and/or footer.
    For example, you could have "Published Date: <<PublishedDate>>", "Document Status: <<Status>>", etc.
