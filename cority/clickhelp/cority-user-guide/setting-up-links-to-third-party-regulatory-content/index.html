Setting Up Links to Third Party Regulatory Content

Regulatory content can be imported from ENHESA or RegScan into in the Legal & Other Requirements module in the Safety and Environmental Clouds, and updated regularly.

The "Regulatory Content Type" system setting determines whether imported regulatory content is stored as Environmental regulations or Safety legal requirements.

Setting Up an ENHESA Connection

To set up the connection to the ENHESA web server:

  1. Make sure the RegionalCode look-up table includes the country regions for which you want to download regulations.

  2. Make sure the CountryRegionalCode look-up table includes the appropriate pairing of country and regional codes, and that the pairing is active.

  3. Select ENHESA in the "Content Provider" system setting.

  4. Provide values for all of the ENHESA system settings (Client ID, Password, Username, and Company Name). The ENHESA Company Name is used to generate the ENHESA Content link on the Legal Requirements record; this URL links to the associated ENHESA regulatory requirements web page.

When these system settings are defined, applicability data from ENHESA will be refreshed and will continue to refresh every 30 days; an update can also be  forced  in the Legal Requirements list (see ENHESA Content).

Setting Up a RegScan Connection

To set up the connection to the RegScan web server:

  1. Complete the following Compliance system settings:

    • Select RegScan in the “Content Provider” system setting.

    • Enter the “RegScan End-User License” and “RegScan Feed Name”.

    • If you map regulations to the user's location, select the location type (GDDLOFB) in the “Map RegScan Profile To” system setting. If additional profiles are added to RegScan, when they imported into the system, if a regulation exists for two or more profiles that regulation will be mapped to the proper location for each profile based on the corresponding 'Map RegScan Profile To' system setting value.

  2. Refresh the browser window to initiate a web service call that imports the appropriate regulatory content from the RegScan web server into the Legal Requirements data table.

After the initial import, a web service call that automatically updates the regulatory content will be made on the first day of every month.

Whenever necessary, a user can initiate a manual RegScan web service call by updating any of the system settings and refreshing the browser window, or by using the Refresh action on the Legal Requirements list view (see RegScan Content).
