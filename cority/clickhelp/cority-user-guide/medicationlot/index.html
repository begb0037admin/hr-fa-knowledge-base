MedicationLot

This table tracks information about medication lots such as strength, form, and expiration date.

A lot record is automatically added to this table if a user enters a lot number using free text in Medication Inventory. A lot record is also created from free text lot entry on the Employee Medication record if the related system setting is enabled.

  1. To filter the list of records, enter a few characters in one or more of the fields at the top followed by an asterisk, then press Enter.

  2. Click a link to edit, or click New.

  3. Select the Medication.

  4. Enter the Strength, Expiration Date, and Lot number.

  5. Select the Medication Form, Geographic Location, and Health Center.

    6. To have picklists for this table only show values corresponding to the user’s geographic location, ensure the "Filter Look-up Tables by Geographic Location" system setting is enabled.

  6. Click Save.
