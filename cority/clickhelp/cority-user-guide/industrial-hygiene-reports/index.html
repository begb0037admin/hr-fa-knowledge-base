Industrial Hygiene Reports

For general information on working with Cority reports, see Generating Standard Reports.

The following reports are available:

Any reports that show the OEL will include an asterisk if the OEL was adjusted.

Technicians/consultants do not have access permission to create notification letters from the Report menu.

Report Title

Description

Batch Letter Monitoring
Batch Letter Noise Monitoring

Generates batch letters for multiple samples that meet query parameters.

If you click Batch/Email Letters, Cority creates a letter record for approved samples and sends (via email) a PDF version of the new letter records to related employees.

Note: Do not select any merge tables when using batch letters.
Do not use batch letters for samples that have multiple agents, because letters will not be sent for all agent results. For samples with multiple agents, you must send the letters manually.

To limit letters to only be sent if data exists for the type of results specified, select the Send Only If the Results Are Populated checkbox.

If you want to send the letter to an alternate email address instead of to the employee. select the Send Email only to Backup Delivery Email Address checkbox (and enter the email address).

Hygienists in Australia should select the “Australian” merge Results Table to comply with regulatory standards.

Bayesian Decision Analysis Report
Bayesian Decision Analysis Report (Noise Monitoring)

Bayesian and traditional statistical data for sample data in the Projected Dose sections of monitoring/noise monitoring records. Available to EASi users only.

Biological Sampling Results

Clinical testing results from the Clinical Testing module. Data in this report is restricted and only displays clinical tests medical has authorized to share with industrial hygiene in the ClinicalTestUnit table.

Detailed Mixture TLV Report

Calculates and displays mixture TLVs for sample data stored in Monitoring module.

Detailed Monitoring Results

Detailed exposure monitoring results from the Monitoring module.

Detailed Monitoring Results by Agent

Exposure monitoring results from the Monitoring module by agent. Options to include list of tasks and PPE for the sample.

Detailed Monitoring Results by Employee

Exposure monitoring results from the Monitoring module by employee.

Detailed Monitoring Results by Survey/Campaign

Exposure monitoring results from the Monitoring module by survey.

Detailed Noise Monitoring Results

Detailed noise monitoring data from the Noise Monitoring module. Report includes the ability to run statistical analysis using the following statistical tools-AIHA LogNorm, AIHA Spreadsheet or Logan. Options to include list of tasks and PPE for the sample.

When you click the stat button (AIHA/Lognorm/Logan) or Bayesian Export, the initial data set will not include samples that have Exclude from Statistics selected, but you can override that by selecting Include Samples Excluded from Statistics in the query.
When you click Report all samples are included (even if set to Exclude from Statistics).

Detailed Noise Monitoring Results by Survey

Detailed noise monitoring results from the Noise Monitoring module by survey.

Exposure Groups List

List of all exposure groups in the ExposureGroup table.

Exposure Group Statistical Report

Numerical tally of people in an exposure group; average exposures by agent for people in an exposure group.

Exposure Group Statistical Report (Australian)

Numerical tally of people in an exposure group; average exposures by agent for people in an exposure group. This report is adjusted for extended shifts and complies with AS/NZ 1269.

IH Exposure Group Completion

Summary, or detailed activity compliance, which only includes exposure groups flagged for non-medical use.

IH Questionnaire Out of Range Responses

Numeric questions and employee responses where those responses fall outside the low and high range of acceptable responses in the IH modules.

IH Questionnaire Response Counts

Textual count and percentage report of user responses to questions in questionnaires in the IH modules. Graphs of responses can also be generated.

IH Questionnaire Responses

Questions and user responses to questionnaires in the IH module.

IH Samples Details Report

Detailed sample information for samples stored in the Monitoring module.

Individual Monitoring Results Notification Letter

Employee notification letter informing the employee of their sample results from the Monitoring module.

Individual Monitoring Results Notification Letter by TLV, PEL, Company

Employee notification letter informing the employee of their sample results from the Monitoring module. Sample results are compared against three occupational exposure limits (TLV, PEL and Company).

Individual Samples Noise Results Notification Letter

Employee notification letter informing the employee of their sample results from the Noise Monitoring module.

List of Active Agents With Exposure Limits

Current occupational exposure limits and special notations for active agents.

List of Agent Groups

List of analytical scans.

List of Analytical Methods by Laboratory

List of analytical methods by laboratory.

List of Employees with Potential Exposure

List of employees and the agents they may be exposed to based on exposure groups.

Monitoring Notification Letter for Supervisor/Employee Group

Notification letter informing the supervisor or employee group of sample results from the Monitoring module.

Monitoring Results Graph by Employee

Graphs sample results from the Monitoring module by employee.

Monitoring Results Graph by Job

Graphs sample results from the Monitoring module by job position.

Noise Samples Notification Letter for Supervisor/Employee Group

Notification letter informing the supervisor or employee group of sample results from the Noise Monitoring module.

Noise Samples Report

Detailed noise sample data from the Noise Monitoring module.

Noise Sampling Plan Completion Status Report

Detailed noise monitoring plan data from the Survey module along with completion status.
The “Survey % Complete Logic Based On” system setting determines if the % Complete Monitoring calculation includes all sample statuses (default) or approved samples only.

Sampling Plan Completion Status Report

Detailed monitoring plan data from the Survey module along with completion status.
The “Survey % Complete Logic Based On” system setting determines if the % Complete Monitoring calculation includes all sample statuses (default) or approved samples only.

SEG Statistical Report’

Summary or detailed statistical analysis of Monitoring data by SEG.

Summary Monitoring Results by Agent

Statistical analysis of sample data stored in the Monitoring module. Report includes the ability to run statistical analysis using the following statistical tools-AIHA LogNorm, AIHA Spreadsheet or Logan.

Unapproved Samples Report

List of unapproved samples.
