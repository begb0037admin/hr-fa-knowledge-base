If you migrated to GX2 from OES

You can view legacy data in the "Legacy Ergo Data Log" available in the Ergonomics menu (with appropriate security permissions). The log displays Employee ID, Activity Type, Activity, Date, Details, and Attachments (with a hover-over preview).
