Clinical Testing Reports

For general information on working with Cority reports, see Generating Standard Reports.

The following reports are available:

Clinical tests will only appear on reports if they are signed.

Report Title

Description

Abnormal Results

List of employees with abnormal test results.

Clinical Test History

History of clinical test results for one or more employees.

Clinical Test Trending Analysis Cross Tab

The last five results for clinical tests for an employee, grouped by employee and then battery.

Clinical Tests Delinquent Report (Without Results Entered)

Clinical tests/batteries for the records where no results entered.
