Language

This table is for the languages into which the system interface can be translated (if translations have been entered for the language selected). If a phrase does not have a translation for the language selected, it will display in English.

To use Google Translate to translate phrases and field labels, select the Google Translation Language code that corresponds to the Language record.
To use Microsoft Azure to translate phrases and field labels, select the Microsoft Azure Translation Language code that corresponds to the Language record.

If you are capturing Safety Data Sheets in different languages, select the SDS Language with which this language should be associated. You will need to add this field to your custom layout.

The Data Cube can only be translated into specific languages. For each Language record, you must use the Language Local ID field to specify the language to be used for the Data Cube entities. For example, you might have two language records for English: the default (US) and UK. For both of these languages, the Language Locale ID would have to be set to the default English. To use the Language Locale ID field, it must be added to your custom layout.

If the Master Locale field has been added to your custom layout and a master locale is available given the other settings you have provided (for a Google or Azure translation language, for example), it will be provided in this field.

To specify a locale for myCority calendars and time controls, you must add the Kendo Locale field to your custom layout.
