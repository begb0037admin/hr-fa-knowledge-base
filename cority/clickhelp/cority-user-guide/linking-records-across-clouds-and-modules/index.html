Linking Records Across Clouds and Modules

Organizations that want integrated QEHS systems can establish bidirectional connections between associated records across the platform. This allows for more comprehensive data reporting and analysis, for example to identify links across many different functions. This will help to leverage Query Builder for enhanced reporting and data analysis across your organization.

Setting Up Linking

An Administrator with appropriate permission must add a "Linked Records" tab (sublist) to applicable layouts (Ergonomics "Risk Assessment", Safety "Incident Investigation", IH "Monitoring", etc.) in the Layout Editor. While adding the sublist, the Administrator will configure, using a tree of clouds and solutions/modules, the records that can be linked.

The Administrator will also add the "Link Record" action to applicable layouts.

Linking Records

A user with the appropriate permission can initiate the Link Record action, which prompts them to select the records to be linked. The records that can be linked will be organized by cloud and solution, according to the configuration (through the Layout Editor) of the associated "Linked Records" tab.

To use this action, the user must have write access to the linking record, as well as specific permissions to link records, unlink records, and edit comments for linked records.
