FiscalPeriod

This table identifies your corporate fiscal periods, used by the data cube in the Metrics module (see Using the Data Cube). Each row of this table represents a fiscal calendar date. Dates that are not included in this table will not be processed by the data cube.

Instead of manually creating each calendar date in the fiscal period, Cority can populate the table for you: choose Actions»Populate Calendar Dates and enter the Start and End dates.
