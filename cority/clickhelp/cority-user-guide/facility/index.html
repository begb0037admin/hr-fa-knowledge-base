Facility

This table allows you to create facility groups based on combinations of GDDLOFB values for use in several Incident reports.

  1. To filter the list of records, enter a few characters in one or more of the fields at the top followed by an asterisk, then press Enter.

  2. Click a link to edit, or click New.

  3. Enter a Code and Description of the facility grouping.

  4. Click Save.

  5. On the Linked GDDLO tab, click New and select the Geographic Location, Department, Division, Location, and Organization. If you select Root for any value, the facility will be included whenever a null value is entered in a report for that GDDLOFB value.

To have picklists for this table only show values corresponding to the user’s geographic location, ensure the "Filter Look-up Tables by Geographic Location" system setting is enabled.
