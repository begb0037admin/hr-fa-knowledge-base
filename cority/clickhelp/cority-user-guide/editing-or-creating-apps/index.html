Editing or Creating Apps

Admin/Creator users can edit or create apps, either building from scratch using the built-in measures and calculations, or by duplicating an existing app as a starting point. Apps that you edit or create are accessible in the Personal>Work section in the left menu.

The editing/creating process is documented in the Qlik Continuous Classroom documentation (learning.qlik.com/qcc). You will need to create a Qlik account. For more information, contact Cority Support.
