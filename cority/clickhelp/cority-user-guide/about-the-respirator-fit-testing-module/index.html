About the Respirator Fit Testing Module

You can enter (or import) information about an employee’s fit tests and monitor their pulmonary medical status and clearance.

 

This chapter explains how to:

  • record respirator fit tests (see Entering Respirator Fit Results Manually)

  • import respirator fit test results (see Importing Respirator Fit Test Results).

To see the look-up tables used by this module, see Look-up Tables Used by This Module. There may also be system settings that affect your use of this module; for more information, see Changing Your System Settings.

Respirator Fit records may also be created as an activity in the Clinic Visit or Appointments/Scheduling modules. If you are licensed for both the Safety and IH Clouds, use the “Respirator Fit record from Exam Activities Store to” system setting to define where these respirator fit records should be stored.
