Restriction

This table is used by several modules to identify work restrictions.

  1. To filter the list of records, enter a few characters in one or more of the fields at the top followed by an asterisk, then press Enter.

  2. Click a link to edit, or click New.

  3. Enter a Code and Description for the restriction.

  4. If this restriction is medical related only, select Hide Restriction in Respirator Fit module.

  5. Click Save.
