Delegating Cases to Another Case Manager

A case manager can delegate all of their cases to another case manager for a specific time period, e.g. to cover a vacation or other absence.

An administrator can change the delegation periods or assignments as required, and can also delegate cases from one case manager to another, e.g. if a case manager has left the company (see Managing Delegations).

To delegate your cases to another case manager:

  1. On the Cases list view, choose Actions»Delegate Case Manager (do not select any cases - a subquery and system setting identify the cases to be reassigned).

  2. Select the case manager that you want to Delegate To and the Start Date. The End Date is not necessary.

  3. Click Save. The case(s) and any records linked to them will be assigned to the new case manager.

If the delegation has an end date, the case will be reassigned to you on that date.
