Viewing a Linked or Imported Document

When you choose Documents in a Cloud’s menu, you will only see the documents for modules that you have security access to. For example, if you do not have access to the Pulmonary module, the Documents list via the Occupational Health menu will not show any documents attached to Pulmonary records.

A document's security is determined by its parent (e.g. the incident it is attached to), so only users with security to see that parent record can view the attached document. If a document is not attached to a specific record (e.g. it was added at the Cloud level), then any user can view it.

For medical documents, security is determined by its parent (e.g. the clinic visit it is attached to) OR the employee it is related to. Only users with security to see that parent record (or that employee) can view the attached document. If a medical document was added at the Cloud level, security is determined by the employee the document is related to.

  • To see a preview of attachments in the document list, hover over the icon to the left of the record.

  • To open the document from the document list, select the checkbox beside the document record, then choose Actions»Open Document.

  • To open the document from within the document record, click the icon beside the file name or URL.

  • To print or email one or more document (image, Word, Excel, text or PDF), select the checkbox beside each document and then choose Actions»Print. All selected documents are compiled into a single PDF that you can print locally or download to send via email.
