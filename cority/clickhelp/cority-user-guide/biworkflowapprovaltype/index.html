BIWorkflowApprovalType

This table lists approval workflow types that may be assigned to campaigns in the Business Intelligence module. You may require multiple approval types to be associated with different sets of approvers.

For each type:

  1. Optionally, select an icon to be shown with the approval workflow (must be included in the UserIcon table).

  2. Select the layouts to be used when accessing the approval workflows in Cority.
