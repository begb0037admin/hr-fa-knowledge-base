Managing Cases

When you create a new clinic visit record, a new case record is also created if:

  • any field on the Case/Incident tab is completed

  • there is any absence record

  • there is any case-related diagnosis on the Dx tab (except for pre-existing medical conditions)

  • there is any Part of Body/Nature of Injury record.

If this visit should be linked to previous visits of the same case, choose Actions»Create Revisit, then select the appropriate case number.

The case number will be shown on the Clinic Visit tab. This number links clinic visits, cases and incidents; however, the clinic visit is case managed only if the Case Managed checkbox is selected on the Case/Incident tab. Case management is used to record and track the progress of occupational or non-occupational injuries.

If the case later becomes case managed, select this checkbox in the case master (to open the related case master, choose Actions»Go to Case Record). The use of the Case Master is described in the Case Management module. See Working with a Case Master File.
