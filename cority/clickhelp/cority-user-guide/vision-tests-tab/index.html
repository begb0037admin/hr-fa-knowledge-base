Vision Tests Tab

The default view of this list displays all vision tests that have not been signed. The To Be Reviewed By column is filtered by the user's default practitioner. For more information, see Recording Vision Results for an Employee.

To view a particular vision test, click the employee name link.

  • If you are the user identified as the Reviewer in the test, you can sign the note (choose Actions»Sign and enter your login password if prompted). A signed note is locked from further edits.
