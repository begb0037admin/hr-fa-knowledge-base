Using the Dashboards

Dashboards allow you to monitor indicators for various types of Cority data.

Want to go deeper? Watch the Dashboards course in Cority Academy (12 mins)

You can have an indicator appear multiple times, with differing criteria for each (for example, if you are monitoring different sites). There are two different dashboards available: the Advanced Dashboard and the “regular” Dashboard. Their differences and similarities are as follows:

* If a Query Builder query set to display as a table uses the aggregation functionality, the table in the dashboard indicator will not have the drilldown functionality others do. This applies in both dashboard types.

A system setting defines the maximum number of rows of data an indicator will retrieve automatically. If the indicator is about to display more rows of data than this, you will receive a message and can choose whether you want to load that indicator or not. This limit does not apply to Number Only, Radial Gauge, and Circular indicator types.

You can set up multiple views of each type of dashboard.

For OH users: Cority provides an out-of-the-box advanced dashboard view that can be pinned to your Occupational Health menu; see Using the OH Home Dashboard.

Dashboard views may be scheduled for generation as a snapshot report; see Scheduling Reports.

An administrator can migrate dashboards from one environment to another; see Migrating Configurations.

Although the Advanced Dashboard can be viewed on mobile devices, Cority does not officially support this.
You may be prohibited from viewing or creating Dashboard views; contact your administrator for more information. An administrator may be granted permission to view, modify, or delete Dashboard views created by other users.
The indicators available to you and graph values are limited by your user access privileges, site security and case type security.
