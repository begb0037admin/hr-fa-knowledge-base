Immunizations Tab

The default view of this list displays all immunizations that have not been signed. The To Be Reviewed By column is filtered by the user's default practitioner. For more information, see Entering an Immunization Record.

To view a particular immunization, click the employee name link.

  • If you are the user identified as the Reviewer in the test, you can sign the note (choose Actions»Sign and enter your login password if prompted). A signed note is locked from further edits.
