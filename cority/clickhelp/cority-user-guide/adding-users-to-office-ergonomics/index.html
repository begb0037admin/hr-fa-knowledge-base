Adding Users to Office Ergonomics

Enrollment in the office ergonomics program is managed using groups and teams. Typically this is done automatically using linked queries based on a user’s HR attributes, but it can also be done manually.

Adding Users with Linked Queries

In this method, a linked query is created and users are added or removed from the program automatically based on their HR attributes. For example: A linked query is created that includes all employees who work in the Finance department. When employee is added or transferred that has “Finance” as their department, they will automatically be enrolled in the office ergo program. Similarly, if an employee in the Finance department transfers to a different department that does not participate, they would be automatically removed from the group because their HR attributes would no longer meet the criteria of the linked query.

  1. In the GroupandTeam look-up table, create a new group or open an existing group.
  2. Ensure that the Training checkbox is selected.
  3. On the Linked Queries tab, select the desired linked query/queries.
  4. On the Group and Team tab, click the Ergonomics icon and click Risk Profiles. Select the profile you want to add to the group you just edited.
  5. Add the group that you want to add to the risk profile.
  6. Click Save.

Employees managed using linked queries are done so in batches. A job runs nightly to update the list of employees in a group and team. Keep in mind that adding an employee using linked queries will take one day to process.

Adding Users Manually

  1. In the GroupandTeam look-up table, create a new group or open an existing group.
  2. Ensure that the Training checkbox is selected.
  3. On the Employees tab, select the employee(s) that you want to add to the group.
  4. On the Group and Team tab, click the Ergonomics icon and click Risk Profiles. Select the profile you want to add to the group you just edited.
  5. Add the group that you want to add to the risk profile.
