Vision Reports

For general information on working with Cority reports, see Generating Standard Reports.

The following reports are available:

Report Title

Description

Vision Fit/Unfit

Employee’s Fit/Unfit results from vision tests.

Vision Testing Employee History - Keystone (US)

Employee's vision test results using the Keystone (US) vision standard.

Vision Testing Employee History - Titmus

Employee's vision test results using the Titmus vision standard.

Vision Warning/Failure

Overall status of vision test(s).
