Completing the Sample Record - Common Tabs

The following tabs are common to both monitoring and noise monitoring sample records. The mandatory fields on the initial tab of the sample record must be completed and the sample saved before you can access these tabs. For more information, see Recording a Monitoring Sample Record or Recording a Noise Monitoring Sample Record.

Tasks tab

Use the Tasks tab to identify the tasks the employee was performing at the time of monitoring. You can limit the tasks to those related to the employee’s job position; see Changing Your System Settings.

Controls tab

Use the Controls tab to identify the types of controls in use at the time of monitoring.

PPE tab

Use the PPE tab to identify the personal protection equipment in use at the time of monitoring.

Questionnaires tab

The Questionnaires tab allows you to associate questionnaires with a record. For information about creating and administering questionnaires, see Questionnaires.

Findings and Actions tab

The Findings and Actions tab displays all findings and actions recommended (or required) for this record. A sample cannot be approved until all actions are also closed.

  • For information about recording a finding and its actions, see Recording a New Finding.

  • To view an action’s attachment, open the finding and choose Actions»Open Document.

Documents tab

Use the Documents tab to link a file containing information about an employee’s work environment to the employee’s monitoring samples. Linking a file to a sample offers industrial hygiene and environmental professionals working with the employee easy access to the file. For more information, see Linking or Importing a Document.

Letters tab

The Letters tab allows you to view past letters or generate new letters to employees. Form letters are stored in the LettersTemplate look-up table. For information about creating letters, see Generating a Letter.

You can only create a letter when the record is Approved. However, if you have appropriate security permissions, you can create a letter for a sample that is not approved; for example, for a voided sample, you can send an employee verification that the sample was collected and the reason why it was voided.
Technicians/consultants cannot create a letter or copy or email an existing letter; they can only open and view a letter.

Notes tab

The Notes tab allows you to record additional information that does not fit elsewhere in the form. For more information, see Adding Notes to a Form.

SEG tab

Use the SEG tab to view the SEGs that an employee is enrolled in, or to assign an employee to a SEG based on the work group the employee was assigned to at the time the sample was taken. For more information, see Associating an Employee with an SEG.

For quick access to the SimilarExposureGroup table, choose SEG Management from the Industrial Hygiene menu.

Representative Employees tab

Use the Representative Employees tab to record any employees interviewed in the process of this assessment.
