InvestigationEHS

This table identifies the EHS responsible for various areas of the organization in order to auto-populate the incident form for the approval process. You should also record the email address of the EHS in the IncidentInvestigationEmail table, which controls who receives notifications.

You can create entries with GDDLOFB values that overlap, e.g. assign the “Canada” location to one EHS investigator and the “Toronto” location to another. When the system searches for an EHS investigator to assign to an incident, it will search from the bottom of the organizational tree up.

You cannot create two entries with an identical GDDLOFB node (for example, more than one record with the Toronto node).

Indicate whether the EHS works with Environmental or Safety incidents, or both.
