SafetyEventReportType

This table lists the possible event report types that may be included in the SafetyEventReportSelection and/or the myCorityEventReportSelection look-up table(s) for display to event reporting users.

For each report type:

  1. Enter a Code and Description for the report type.

  2. Optionally, select the incident Category to be used if the event report is later turned into an incident.

  3. Optionally, select an Icon to be shown with the event report type name on the event reporting start page (must be included in the UserIcon table).

  4. Optionally, enter any instructions for users to complete event reports of this type.

  5. Select the appropriate options for Incident Workflow:

    • Indicate if this event type is related to an MVA or employee Injury/Illness.

    • If you want an incident to be created automatically when this event report is submitted, select Auto Posting to Incident.

    • If you want the supervisor to be notified automatically (whether the incident is created manually or automatically), select Auto Start Investigation Workflow Email. You will also need to create the email template for this email (see Letters).

    • By default, a user must save the event report before they can submit it. If you want to disable this workflow for this event report type, you must add the Require Save before Submit checkbox to a custom view or layout in order to deselect the checkbox.

      • If you deselect the checkbox on a layout and the event type is configured to Auto Post, you will be prompted to confirm. This is because any business rules would then be processed after the Submit, which may cause issues.

      • If you deselect the checkbox and Save is on the layout, it will still appear for users but will be optional.

      • If you leave the checkbox selected, the Save button appears for users even if it's not on the layout, and the Submit button is disabled until after Save is clicked.

      See below for further guidelines about selecting or disabling this workflow.

  6. Select the layouts to be used when accessing event reporting in Cority and via standalone access and the Portal.

  7. Optionally, select an associated questionnaire. You can select an Incident Questionnaire or, if the report type has been identified as related to Injury/Illness or MVA above, you can select their corresponding questionnaire. Only one questionnaire can be embedded with an event report.
    Depending on the form layout, the questionnaire may be included at the bottom of the report (standalone only), or there may be a separate Questionnaire tab.

 

Guidelines for determining whether ‘Require Save before Submit’ should be selected:  

This is not a complete listing of all possibilities; you may have some event reports that require Save first and others that do not.

Require Save Before Submit = selected when: 

Require Save Before Submit = deselected when

  • Auto Post to Investigation or Audit (Ergo) is required and there are Update BRA
    NOTE:  BRA occur after the Investigation or Audit is created, so change doesn’t flow over to Incident Investigation or Audit
  • Create New Record BRA is applied to Event Report e.g. adding a Questionnaire to Event Report for completion prior to submission
  • Sublist records need to be completed prior to submission
  • Geared to Guest User (may not even want Save button) since they cannot leave record and come back later to finish and submit
  • Simple Event Reports to reduce clicks
