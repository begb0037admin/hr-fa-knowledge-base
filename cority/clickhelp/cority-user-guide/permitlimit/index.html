PermitLimit

This table allows you to record the emission limits for your permitted emission sources. A Permit Limits tab can be added to custom versions of the Environmental Permit layout.

  1. Enter a Code (up to 20 characters).

  2. Select the Pollutant from the AgentHazard look-up table.

  3. Enter the Permit Limit and Unit of Measure from the UnitsOfMeasure look-up table.

  4. Enter a Description (up to 100 characters).

  5. Select an Emission Point and Source from the records in the EI Asset Management module that have Equipment Type = “Emission Point”.

  6. Enter the Start Date (and End Date, if applicable) for this limit record.
