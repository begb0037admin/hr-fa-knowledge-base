Entering a Sample

  1. In the Occupational Health menu, click Clinical Testing.

    2. If a record has been signed, it is locked from further edits.

  2. Select a sample from the list, or click New to record a new sample.

  3. If necessary, change the Sample Date, and enter the Time the sample was taken, for example 10:00 AM or 3:00 PM.

  4. Select the Sample Type.

  5. In the Specimen ID field, enter the identifier for the specimen.

  6. Select the Health Center and the appropriate person for Administered By and To Be Reviewed By.

    7. Only the user identified as the reviewer can sign the record (choose Actions»Sign). A signed record is locked from further edits.

  7. If the sample was taken while the employee was fasting, select Fasting.

  8. Indicate whether the data is private (private data can be included or excluded in reports where indicated).

  9. The Batteries tab lists all clinical test batteries that have been added to this test sample. For information about changing or adding batteries, see Adding Test Batteries.

  10. The Results tab lists all tests for all batteries added to the sample, and allows you to enter the results for each. For more information, see Entering Test Results.

  11. The Allergies tab displays all allergies recorded for this employee in the Demographics, Body Fluid Exposure, Medical Chart, Clinic Visits, Clinical Testing, or Immunization modules. For information about entering an allergy, see Recording Allergies.

  12. The Rx tab displays all medications and contraindications recorded for this employee in the Demographics, Body Fluid Exposure, Medical Chart, Clinic Visits, Clinical Testing, or Immunization modules. For information about entering a medication or contraindication, see Recording Medications (non-eRx).

  13. The Notes tab allows you to record additional information that does not fit elsewhere in the form. For more information, see Adding Notes to a Form.

  14. Use the Documents tab to link an external file to the record to provide easy access to the file (for more information, see Linking or Importing a Document).

  15. The Letters tab allows you to view past letters or generate new letters to employees. Form letters are stored in the LettersTemplate look-up table. For information about creating letters, see Generating a Letter.
