Opening or Creating a Clinic Visit Record

The Clinic Visits module stores information for all visits to the health clinic by an employee.

Using the Short Form Entry Screen to Create a Clinic Visit Record

  1. In the My Favorites menu, click Demographics to open the employee list.

  2. Select an employee, then choose Actions»New Short Form Visit.

  3. Select the visit reason, health center, and case number (if you want to link the clinic visit to an existing case), and click Save. The layout may change if a specific layout has been associated with the chosen clinic visit reason.

The clinic visit record can be retrieved and finalized from the Clinic Visit list as described below.

The Short Form is only available if enabled in the system settings (see Changing Your System Settings).

Creating a Full Clinic Visit Record

  1. In the Occupational Health menu, click Clinic Visit and use the provided fields to generate a list of employees who have had clinic visits.

    2. The Clinic Visit List may be sorted or filtered using any of the provided fields in combination. For example, select a date from the calendar (e.g. August 10, 2025) and select a Visit Reason (e.g. Audiogram) to view all Audiogram visits for August 10, 2025.

  2. Do one of the following:

  • To filter the list to Revisits, Original Visits, or All Visits, choose the appropriate View.

  • To open an existing single clinic visit record, click the name link.

  • To open multiple related visits, select the checkbox beside an employee name, then choose either Actions»Open All Visits for Selected Case, or Actions»Open All Visits for Selected Employee. In the Clinic Visit form, arrows appear at the top (beside the Actions button) on the Clinic Visit tab, which you can use to navigate through the records you have opened.

  • To create a new visit that is linked to a previous visit of the same case, choose Actions»Create Revisit.

  • To record a new clinic visit, click New.

If a clinic visit has already been entered for the same day, you will be asked if you want to save the record.

Refer to Entering Details of a Clinic Visit for information about completing the clinic visit record tabs.
