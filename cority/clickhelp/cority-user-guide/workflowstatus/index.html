WorkflowStatus

This table can be used as a Swimlane Source when creating a workflow swimlane view for supporting modules, such as Incident approval, IH surveys or monitoring, Findings & Actions, Risk Assessment/JHA, Environmental/Safety Event Reporting, Change Requests, Legal Requirements, Permits, Chemical Management, etc. (see Working with Swimlane Views). Define the various workflow steps, e.g. Draft, In Progress, Done.

If the Workflow field has been added to a form layout, it will be updated with the appropriate step from this look-up table when the record is moved from one swimlane to another.
