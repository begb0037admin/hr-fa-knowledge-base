Updating Third Party Chemical Information

Chemical information content can be imported, from SiteHawk or Actio, into in the Chemical Management module and related look-up tables, and updated regularly.

The appropriate connection must be configured; see Setting Up Links to Third Party Chemical Content.

To download (or update) content, on the Chemical Products list view, choose Actions»Refresh Chemical Content. This action is also available from the AgentHazard look-up table list view.

All relevant entries and fields in the AgentHazard, ChemicalPhrase, ChemicalSymbol and Agent Ingredient look-up tables are updated.

When the refresh process is complete, you can check the Process Status & Log (SiteHawk Content Log/Actio Import View) to see which records were added or updated (see Viewing Import Logs).

SiteHawk: If an organizational tree node is selected in the “Map SiteHawk Chemical Area to” system setting, when you refresh chemical content, in the AgentHazard look-up table list, an “Applicable Location” record will be added to the “Applicable Locations” sublist of each chemical for which SiteHawk specifies a Chemical Area. In this “Applicable Location” record, the tree node specified in the system setting will display the Chemical Area value.
