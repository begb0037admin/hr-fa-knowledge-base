IHSampleType

This table lists types of monitoring samples (e.g. area, field spike, personal, wipe).

  1. To filter the list of records, enter a few characters in one or more of the fields at the top followed by an asterisk, then press Enter.

  2. Click a link to edit, or click New.

  3. Enter a Code and Description for the sample type.

  4. If this sample type is to be used to print a blank sample, select the Blank Sample Type checkbox. When this sample type is chosen on the IH Monitoring form, the Blank ID field will display which can be used to determine which sample in a collection of samples is the Blank Sample.

  5. Select the Type of sample which determines which layout to use (Area, Personal, or Other). The layouts for these three types are configured in system settings.

  6. Click Save.
