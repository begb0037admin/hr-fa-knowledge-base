Adding a Product to Inventory

  1. To add a product to inventory:

    • open the product record and click New in the Chemical Inventory tab; or

    • on the Chemical Inventory list, click New. Choose the product you are adding to inventory.

    If you need to inventory a bulk shipment into multiple containers, see Inventorying a Bulk Chemical Shipment below.

  2. Select the appropriate GDDLOFB to identify where this product will be located.

  3. Enter the Average Amount (including Units) to be stored at this location.

  4. Enter the Date this inventory was last reviewed.

  5. Select the employee who is Designated as responsible for this product at this location. The phone number is populated from the employee’s demographic information.

  6. Select the Related Asset as well the maximum and average Daily Amounts expected to be used.

  7. Enter the Current Inventory Amount and UOM and the Effective Date.

    8. To update the inventory amount on an existing record, choose Actions»Add a New Inventory Version.

    When you save the record, a new version is created, one for each inventory effective date. When you open the record the currently effective version is displayed; to view a different version, use the Go To Version fields at the top and bottom of the form.

  8. Click Save.

Inventorying a Bulk Chemical Shipment

If you receive a large shipment of a chemical and need to inventory it into different containers, you can do this in a single action that will generate an individual inventory record and corresponding barcode labels for each new container.

  1. On the Chemical Inventory list view, choose Actions»Inventory Chemicals in Bulk.

  2. Select the Chemical Product.

  3. Enter the Number of Containers to be created and select the Container Type.

  4. Select the Barcode Type (or select to not print barcode labels).

  5. If necessary, change the Inventory Date.

  6. Enter the Amount Per Container and the UOM.

  7. If necessary, select the user to be the Designate and assign the GDDLOFB (all containers created will be associated with this location).

  8. Click Update.

If you selected a barcode type, a PDF opens in a new browser tab that contains a barcode for each container in the new inventory.

A new chemical inventory record and related asset record will be created for each container added, and a PDF with the barcode for that record will be listed on the Documents tab.
