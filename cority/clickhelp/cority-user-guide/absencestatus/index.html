AbsenceStatus

This table allows you to enter multiple absence statuses, and relate them to an absence type for counting purposes.

  1. To filter the list of records, enter a few characters in one or more of the fields at the top followed by an asterisk, then press enter.

  2. Click a link to edit a record, or click New to add a new record.

  3. Enter a Code and Description for the absence status.

  4. Select the Absence Type; this dictates how the absence is counted.

  5. Indicate if this absence status is OSHA Recordable.

  6. Optionally, select the Standardized Value (from the AbsenceStatusStandardizedValue look-up table) to categorize this record. This value will be used by the predictive Analytics module to compare your data to that of other organizations and determine your relative performance.

  7. Click Save.
