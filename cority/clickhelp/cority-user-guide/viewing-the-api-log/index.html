Viewing the BR API Log

Every API call that was made by Cority related to business rules is stored in the BR API log, viewable by any user with administrator privileges.

In the Administrator menu, click BR API Log. Click a link to view details of the API call (in read-only format).

The maximum number of daily Cority API requests is currently 1000, subject to change.
