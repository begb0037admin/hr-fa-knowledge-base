Case Management Reports

For general information on working with Cority reports, see Generating Standard Reports.

The following reports are available. Note that if case type security has been applied to your role, you will only see data that falls within your granted case types.

Report Name

Description

Absence FMLA, STD and State FMLA Report

Displays FMLA, STD, and State FMLA time lost calculations for employees, based on the Time Lost Calculation setting selected in system settings.

Absences by Case Type, Case Manager

List of cases involving absences by case type or case manager or by average time lost by case type including calculated days lost and days restricted and $ lost and $ saved.

Absences By Primary Diagnosis

Count of Absences by Primary Diagnosis with the option to include Average Lost Days where the Absence Start Date falls within the user's parameters.

Absences Returns Before Expected Date

List of employees who were returned to Full Duty work status before the Expected Date of Return.

Appeals and Hearings

Display data related to appeals captured via Questionnaires in the Case Management module.

Average Length of Disability by Primary Diagnosis

Comparison of the average Length (duration) of Disability to the average Disability Duration Guidelines by Primary Diagnosis.

Case Activities List By Case Manager

Case activities list by case manager.

Case Activities List By Employee

List of case activities for Employee.

Case Counts By Primary Diagnosis

Count of each primary diagnosis.

Case Progress Notes

Summary of Case Notes by Employee or Clinic Visit ID.

Case Provider To Do List

List of incomplete To Do items for a selected case provider.

Case Return To Work Statistics

Case time lost statistics in relation to PMD, DDG and NEG estimates, based on the user's Time Lost Calculation setting selected in system settings.

Currently Absent, Restricted Employees

List of employees currently absent or restricted as of a certain date (defaults current date) displaying the Start Date of absence or restriction and the total count of days lost or restricted plus whether the absence is Occ or Non-Occ.

Employee Restrictions

List of temporary, permanent, or all restrictions employees have been assigned.

New/Open/Closed Case Details

List by Case Manager of New Cases, Open Cases or Closed Cases based on Date Opened and Date Closed fields.

New/Open/Closed Case Summary Report

Summary count of New, Open and Closed Cases and Number of Employees by Group By Column selection (GDDLO).

Required Capabilities by Job Position

List of required physical capabilities by Job Position including the Level/Amount of physical capability required and the Start Date.

Restriction Counts

Count of each employee restriction.

Time Lost By Case Type, GDDLO

List of cases with lost/restricted time, displays calculated Lost and Restricted time for each Case based on Start and Full Duty Dates plus calculated Costs Saved and Lost.

Time Lost By Primary Diagnosis

List of Work Time Lost by Primary Diagnosis including # of Case per Diagnosis and Average Lost Days and Average Cost per Diagnosis.

Treatment Costs vs. Time Lost

List of cases with associated Treatment Costs (Activities and Procedures) vs. Time Lost. Also provides a graph format.

The “Injuries by Part of Body” Report Writer report provides a heat map view of injuries that displays the number of injuries by body part. The heat map can be viewed in the Report Writer or as a dashboard indicator. For more information, see Monitoring Injuries by Part of Body on a Heat Map.
