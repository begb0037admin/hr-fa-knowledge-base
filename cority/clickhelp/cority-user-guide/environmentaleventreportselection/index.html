EnvironmentalEventReportSelection

This table lists the groups of report types that can be displayed to event reporting users. Identify which group should be displayed when accessing event reporting in Cority and via standalone access.

For each group, indicate which report types are included, and change the order if required. The report types are defined in the EnvironmentalEventReportType look-up table.

Only the group marked as Default Standalone Selection is available in the Portal.

A URL is created for each report type. This allows you to provide a direct link to a specific report type independent of the default group set up for standalone use. To see the URLs, open a group and choose Actions»Display Standalone Event Reporting Links.
