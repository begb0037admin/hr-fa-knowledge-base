Documents Tab

The default view of this list displays all documents that have not been signed. The To Be Reviewed By column is filtered by the user's default practitioner.

  • To view the document record, click the employee name link. To view the document itself, select the record’s checkbox and choose Actions»Open Document.

  • To add a new document record, click New.

  • If you are the user identified as the reviewer (To Be Reviewed By) in the document record, you can sign the document (choose Actions»Sign and enter your login password if prompted). A signed note is locked from further edits.
