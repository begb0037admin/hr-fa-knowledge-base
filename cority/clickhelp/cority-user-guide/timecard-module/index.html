Timecard Module

The Timecard is used in myCority by staff to record their time, and by their supervisors to approve the time submission.

These records are visible in GX2 where they can be reviewed, associated with monitoring samples and the data can be used in the Equation Library.

A Timecard Location tab can be added to custom versions of applicable Monitoring Sample layouts. This tab can include calculated fields used for Equation Library calculation outputs. A related system setting, "Dimension to be used for the Timecard Location field", sets the dimension you want to use for linking Timecard Location records to an associated Monitoring Sample record.
