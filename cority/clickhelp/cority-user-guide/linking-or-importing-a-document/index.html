Linking or Importing a Document

The Documents function is available from all Cloud menus. Each provide the same functionality (view documents already generated or create new ones), but just filter documents related to those Clouds. Some modules also have a Documents tab, where you can view or attach documents related to that specific record.

Regardless how you access the Documents function, the procedure is the same. For example, you can link a document to record from the Documents tab in an incident record, or by clicking Documents in the Safety menu.

You can link almost any type of file (see Supported File Types) to a record or keep it as an external link.

The maximum file size is 30 MB or less, depending on your system settings. Files must not be encrypted. The Default Document Type must be defined in the system settings.

  1. If you are in a module record and want to link a document to that record, click New on the Documents tab.
    Alternatively, click Documents in any Cloud menu and then click New.

  2. Click a link to edit a document record, or click New.

  3. Enter the following information about the document:

    • If applicable, select the Employee (if not already selected) the document relates to.

    • Select the Document Type (e.g. Questionnaire, X-ray, etc.) and enter the Date of the file.

    • Identify who the document was Received From, and select the person that the document is To Be Reviewed By.

  4. Identify the location of the file:

    • To attach a file to the employee record, click Browse beside the Doc. Import File field. Locate the file you want to attach and click Open.

    • To link to a web site, enter the URL in the Doc. HTTP Link field.

  5. Enter a Description of the file you’re linking to the employee, and add any additional Notes as required (see Adding Notes to a Form).

  6. For Medical Documents, indicate if the document should be included on the Problem List (see Working with the Problem List) and if the data is Private (private data can be included or excluded in reports where indicated).

    7. Only the user identified as the reviewer (To Be Reviewed By) can sign the record (choose Actions»Sign). A signed record is locked from further edits.

  7. Click Save.

You may sign a document to prevent it from being replaced with another version (see Securing Records, Notes, and Documents).

To view the document, see Viewing a Linked or Imported Document.

A "Scan Document" action can be added to custom versions of Medical Document layouts. This action can be used to replace an existing document unless the corresponding document record is locked. The Health Center and GDDLOFB of the associated parent record will be applied to the scanned document record. Please contact Cority support for assistance setting this up.
