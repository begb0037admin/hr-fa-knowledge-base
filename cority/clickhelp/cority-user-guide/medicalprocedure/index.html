MedicalProcedure

This table stores medical procedures that may be performed during a clinic visit.

  1. To filter the list of records, enter a few characters in one or more of the fields at the top followed by an asterisk, then press Enter.

  2. Click a link to edit, or click New.

    3. A medical procedure record cannot be edited if it is currently in use in employee or other related records.

  3. Enter a Code and Description.

  4. Select the Category that the procedure belongs to.

  5. Enter the Cost of this procedure and the RVU (relative value unit).

  6. Indicate if this procedure is OSHA Recordable.

  7. Click Save.
