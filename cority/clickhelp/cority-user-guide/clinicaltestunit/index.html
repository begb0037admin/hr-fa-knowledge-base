ClinicalTestUnit

To set up clinical tests and batteries, you first create or edit a test in the ClinicalTestUnit look-up table, then use the ClinicalTestBattery table to create or edit a clinical test battery by assigning, editing, or removing the tests that define it.

  1. To filter the list of records, enter a few characters in one or more of the fields at the top followed by an asterisk, then press Enter.

  2. Click a link to open a clinical test, or click New.

  3. Enter a Code and Description for the test.

  4. Select the Category the test falls under.

  5. If the test is related to IH monitoring, select the Biological Exposure Index (BEI) checkbox so that the test appears on the Biological Sampling Results report.

  6. Select the Test Type. If you select:

    • Multiple Choice: a Valid Choices tab appears; click New on this tab and enter the choice, and a description of the choice.

    • Numeric: a Valid Ranges tab appears; click New on this tab and enter the age range, and low and high ranges, for each sex (or for both sexes).

    • Numeric or Text: a Systems and Units tab appears that allows you to define other units of measure that are used by different systems (countries). You should also provide the conversion factors (in the UnitsOfMeasure table) for each possible units of measure pair.

  7. If this is a cholesterol test, select “Total Cholesterol” or “HDL Cholesterol” in the Unit Test Indicator field.

  8. In the Agent field, select the agent the test is designed to monitor.

  9. Enter the default Units of Measure for the test, for example ppm.

  10. Click Save.

If the optional Converted Result and Converted Unit of Measure fields are added to the Results form layout (and the Systems and Units tab in the ClinicalTestUnit table, the SystemofUnits table, and conversion factors in the UnitsOfMeasure table are defined), then results are shown in the unit of measure in which they were entered, and converted results are shown based on the configuration of the system setting, the system and units, and the UnitsOfMeasure conversion factors.
