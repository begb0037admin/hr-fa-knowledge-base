Probability

This table lists the levels of probability of a hazard occurring; includes the values to be used in calculations. It also identifies any risk factor qualifiers available based on assessment category.

Identify which Clouds/modules/finding types the probability level is available in, or if it is associated with a work permit.

There are views in the Findings and Actions module, as well as on the Incident report’s Incident Category and Risk tab, that can display risk-related information; however, this information will only appear if the Incident Finding assessment type is selected in this table.
