Using the OH Home Dashboard

The OH Home is a pre-built dashboard of your occupational health tasks, such as items to review or sign and your appointments and visits for the day. It provides the same functionality as the Inbox (except Email and eRx), and is filtered to the user logged in. Open the related records directly from the dashboard; for example, double-click on My Unsigned Audiometric Test to view each audiometric record that you must review.

The OH Home is not available in the OH menu by default; it must be made available to each user through their menu configuration (enable Occupational Health>OH Home).
You can pin this dashboard to your Occupational Health menu and customize to suit your needs, e.g. delete any indicators that you do not need. See Using the Advanced Dashboard for information about customizing the dashboard.

The default OH Home dashboard provides the following indicators:

  • My Unsigned Audiometric Tests (number only)

  • My Unsigned Pulmonary Tests (number only)

  • My Unsigned Immunizations (number only)

  • My Unsigned Clinical Tests (number only)

  • My Unsigned Drug Tests (number only)

  • My Unsigned Vision Tests (number only)

  • My Unsigned Documents (number only)

  • My Unsigned Questionnaires (number only)

  • My Visits Today (table listing Employee, Visit Reason, Status, and Arrival Time)

  • My Appointments This Month (calendar)

The “My Unsigned...” indicators only include records for which you are the “To Be Reviewed By” user. The Appointments calendar only shows appointments for which you are the Scheduled User.
