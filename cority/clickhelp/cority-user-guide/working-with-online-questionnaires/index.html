Working with Online Questionnaires

Employees can fill out a questionnaire online using a separate web application (a separate web site must be set up; for information see Setting Up Online Questionnaires). See Completing a Public Online Questionnaire.

A user logged into the Portal in Guest mode may also complete and submit public questionnaires.

You can then review these completed questionnaires in the appropriate Cloud’s Questionnaire Inbox and “post” them to add them to the main Questionnaire database. See Posting Online Questionnaires.

When answering public online questionnaires, there is no authentication that the user is the intended recipient, and the user must select the questionnaire to answer. If you want to send a questionnaire targeted to specific users, consider using a survey instead. The email link they receive opens the questionnaire directly, and you can track who has responded.
