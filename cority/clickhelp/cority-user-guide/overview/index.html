Overview

What is CorAnalytics?

CorAnalytics is a powerful BI, data visualization, and predictive analytics solution that offers a curated data set with simple to use and lightning-fast querying filtering and charting. CorAnalytics runs on an embedded third-party engine, Qlik Sense® — one the world’s top BI engines.

CorAnalytics provides a full-featured presentation layer, a large charting library, and the ability to easily create functions for users to expand the business analysis from their EHS data, as well as out of the box content available for users to leverage for baseline analysis.

What Can I Do in CorAnalytics?

There are two types of licenses that control what you can do:

  • Viewer users can view data in the standard apps and dashboards: use the interactive dashboards to easily navigate through charts, drill down with a click, and filter by any field to narrow data sets and extract meaningful insights.
  • Admin/Creator users can create new apps and dashboards or edit existing ones; create dashboards and provide them to stakeholders with shareable links; or create presentations with interactive data storytelling that provides users with access to live analytics to make data driven decisions.
