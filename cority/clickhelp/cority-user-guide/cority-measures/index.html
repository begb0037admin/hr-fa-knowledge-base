Cority Measures

Cority provides a list of standard measures that can be used as values in the Data Cube. While many are self-evident “count” measures, the following are the calculated measures and the formula for each.

Measure Name

Formula

# Days Since Last Lost Time Incident

today's date minus date of injury of most recent LWD absence

# Days Since Last OSHA Recordable

today's date minus date of injury of most recent occupational checked/OSHA recordable checked record

Incident Count

# of incidents records (in selected time frame)

Incident Frequency Rate

# of incidents records x 200000 / employee hours worked (in selected time frame)

Incident Frequency Rate YTD

cumulative # of incidents records x 200000 / cumulative employee hours worked (in selected time frame)

Injury and Illness Count

# of occupational checked case records (in selected time frame)

Injury and Illness Frequency Rate

# of occupational checked case records x 200000 / employee hours worked (in selected time frame)

Injury and Illness Frequency Rate YTD

cumulative # occupational checked case records x 200000 / cumulative employee hours worked (in selected time frame)

Lost and Restricted Case Count

# of occupational checked case records with either a LWD or RWD absence (in selected time frame)

Lost and Restricted Case Frequency Rate

# of occupational checked case records with either a LWD or RWD absence x 200000 / employee hours worked (in selected time frame)

Lost and Restricted Case Frequency Rate YTD

cumulative # of occupational checked case records with either a LWD or RWD absence x 200000 / cumulative employee hours worked (in selected time frame)

Lost and Restricted Day Rate

# of LWD and RWD absence days for occupational checked cases x 200000 / employee hours worked (in selected time frame)

Lost and Restricted Day Rate YTD

cumulative # of LWD and RWD absence days for occupational checked cases x 200000 / cumulative employee hours worked (in selected time frame)

Lost Time Case Count

# of occupational checked case records with a LWD absence (in selected time frame)

Lost Time Case Frequency Rate

# of occupational checked case records with a LWD absence x 200000 / employee hours worked (in selected time frame)

Lost Time Case Frequency Rate YTD

cumulative # of occupational checked case records with a LWD absence x 200000 / cumulative employee hours worked (in selected time frame)

Lost Time Day Rate

# of LWD absence days for occupational checked cases x 200000 / employee hours worked (in selected time frame)

Lost Time Day Rate YTD

cumulative # of LWD absence days for occupational checked cases x 200000 / cumulative employee hours worked (in selected time frame)

Lost Work Days

# of LWD absence days for occupational checked cases

OSHA Recordable Count

# of occupational checked/OSHA recordable checked case records (in selected time frame)

OSHA Recordable Rate

# of occupational checked/OSHA recordable checked case records x 200000 / employee hours worked (in selected time frame)

OSHA Recordable Rate YTD

cumulative # of occupational checked/OSHA recordable checked case records x 200000 / cumulative employee hours worked (in selected time frame)

Restricted Case Count

# of occupational checked case records with a RWD absence (in selected time frame)

Restricted Case Frequency Rate

# of occupational checked case records with a RWD absence x 200000 / employee hours worked (in selected time frame)

Restricted Case Frequency Rate YTD

cumulative # of occupational checked case records with a RWD absence x 200000 / cumulative employee hours worked (in selected time frame)

Restricted Day Rate

# of RWD absence days for occupational checked cases x 200000 / employee hours worked (in selected time frame)

Restricted Day Rate YTD

cumulative # of RWD absence days for occupational checked cases x 200000 / cumulative employee hours worked (in selected time frame)

Restricted Work Days

# of RWD absence days for occupational checked cases
