CorrectivePlan

This table allows you to create an action plan that can be used in the Incident or Audit modules.

  1. To filter the list of records, enter a few characters in one or more of the fields at the top followed by an asterisk, then press enter.

  2. Click a link to edit, or click New.

  3. Enter a Code and Description for the plan.

  4. Select the Geographic Location and Health Center.

  5. Identify which Cloud(s) the plan is available in.

    6. To have picklists for this table only show values corresponding to the user’s geographic location, ensure the "Filter Look-up Tables by Geographic Location" system setting is enabled.

  6. To associate an action with this plan, click New on the Corrective Plan Actions tab and choose an action (from the PreventiveAction table). Select the action and the person it should be assigned to, as well as the target and due date gaps. If applicable, select Is Recurrent and set up the recurrence settings; daily and weekly recurrence generates tasks for the next year, while monthly and yearly recurrence generates tasks for the next five years. When this corrective action plan is selected, the related actions are added to the Actions tab.

    7. If you want to link a corrective plan to a legal requirement or permit in order to automatically generate and assign the associated actions, you must create a custom layout for this look-up table to include the Assign to Group and Effective Date fields. Complete the Assign to Group instead of Assigned To field. For more information, see Linking a Corrective Plan’s Actions to a Requirement. If the action is set up as recurring, a safety permit associated with the corrective plan will list all the recurring compliance action tasks generated from the corrective plan action.
    When actions are assigned to a group or team member, site security will not be applied to them.

  7. Click Save.
