EmployeeType

This table identifies codes used to group employees.

It can also set the parameters used to automatically generate employee numbers. When creating a new employee in the Demographics cloud (see Recording Basic Employee Information), a user can choose to automatically generate the employee number. This number will consist of the Prefix and the next available number according to the Sequence field in the EmployeeType look-up table. For example, if the EmployeeType table lists Prefix=EE and Sequence=10300, the next automatically created employee number will be EE10300. Once that employee number is assigned, the Sequence field in the EmployeeType table is incremented and will now display as 10301. This Prefix and Sequence is also used by myCority to auto-create employees.

Optionally, select the Standardized Value (from the EmployeeTypeStandardizedValue look-up table) to categorize each record. This value will be used by the predictive Analytics module to compare your data to that of other organizations and determine your relative performance.
