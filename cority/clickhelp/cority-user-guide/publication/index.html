Publication

This table lists resources that may be referenced by a regulation applicability assessment record. If the Publications tab is added to a custom Applicability Assessment layout, the tab on an assessment record will be populated with publications that match the Country, State/Province, or County.

If you have an ENHESA license and your Content Provider system setting is set to ENHESA, you can choose Actions»Update Applicability Data to refresh applicability data, including the creation of audit questionnaires. Any required compliance audits will be inserted in the Applicability Assessment > Results > Related Compliance Audits subsection (see Identifying Applicable Regulations). Corresponding regulatory audit and applicability assessment questionnaires will be translated into the appropriate language for each entry in the CountryRegionalCode look-up table that has the ENHESA checkbox selected. This will also add the required translation entries to the Translations tab of each applicable SingleQuestion record. If any imported questions have an Advice Popup Message (additional info), that message will be translated into the language specified in the user's Language system setting.

If you have a RegScan license and your Content Provider system setting is set to RegScan, you can choose Actions»Import RegScan Applicability Data to import RegScan applicability questionnaires. The import file must be structured with the following columns, in the order shown:

Library ID | Screening Name | Country | State | Screening Question ID | Parent Screening Question ID | Screening Question | SID Definitions | Subject Name | Topic | Subject Description | Audit QID | StaticDocID | Product Code | Product Description
