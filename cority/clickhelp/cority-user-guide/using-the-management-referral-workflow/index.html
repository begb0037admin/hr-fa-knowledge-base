Using the Management Referral Workflow

Cority provides functionality for a Management Referral workflow that integrates the Appointments and Case Management modules to make it easy for:

  • A manager to refer an employee to a clinic
  • The clinician(s) to address and carry out the referral and any clinic visits
  • The manager and clinician(s) to communicate throughout the process.

Related fields and actions must be added to custom form layouts. Please contact your system administrator for assistance.

This article provides an overview of the workflow functionality. The following is a general example of the workflow:

  1. A manager submits a referral questionnaire (in myCority) to refer an employee to a clinic.
  2. The auto-post to Case feature is configured, so a case is created for the referral.
  3. A clinician opens the Case record and from that record starts a referral appointment using the Appointments module. When creating the appointment, the clinician links it to a clinic-visit-related activity, which creates a Clinic Visit record. These records maintain a link through the case number which is added to the appointment and clinic visit records.
  4. The case continues with added information, perhaps one or more additional clinic visits, and messages back and forth between the clinicians (using GX2) and the referring manager (using myCority). The clinician's assessment is shared with the employee, and includes consent fields so that the employee can indicate if the medical assessment questionnaire may be shared with the supervisor.
  5. The case is eventually closed.

Configuration (High-Level)

Schedule Entry

The Case Number field must be added to a custom layout. When you select an employee, the Case Number field is filtered by that employee.

If the relevant schedule case type security action is granted to the user, case type security will apply on schedule entry: if a Schedule Entry is linked to a case to which the user does not have access, they will not be able to see that Schedule Entry. They will only be able to reassign and/or cancel appointments, when linked to cases, that are linked to cases they can see. To view the Schedule Entry, the user's role must be granted the appropriate permissions.

Clinic Visit

The Schedule Follow-up action will open the Appointments calendar, but if the Clinic Visit record is linked to a case (the Case Number field is populated on the visit record), the case number will populate on the schedule entry.

Case

  • A Schedule History tab may be added to the Case layout to show all appointment history for the case record or current and upcoming appointments.
  • A Schedule Referral action may be added that functions the same as the Schedule Follow-Up Appointment in the Clinic Visit module. For example:
  1. Select this action, the Appointments calendar opens. 
  2. Click New to create the referral appointment and populate the Schedule Entry with date, time, and health center. The employee's name and the case number are populated automatically. Select a clinic-visit-related activity and save the appointment.
  3. The appointment is listed on the Schedule History tab on the case record. After the appointment occurs, open it and designate it completed by selecting the Link action to create the corresponding Clinic Visit record, which will open that new record. 
  4. The Clinic Visit record will have the case number, treatment date and visit reason populated automatically. When the Clinic Visit record is saved, a notification advises that the clinic visit is linked to a case.
  5. If the employee requires another clinic visit, use the New action on the Case's Schedule History tab, or the Schedule Referral action, to create the revisit. Both Clinic Visit records will be listed on the Clinic Visit tab for the original Case record.
  • A Messages tab may be added to allow conversations between the clinicians and the supervisor/manager.

Additional fields may be added to a Case layout to capture values used to measure clinic efficiency and the efficiency and proactiveness of the clinicians when attending to and completing management referrals (for analysis and reporting).
