Emissions Inventory Reporting

The Emissions Inventory Cloud menu includes direct links to several reporting functions in Cority:

  • Emissions Dashboard - set up and monitor indicators for various types of Cority data. You can have an indicator appear multiple times, with differing criteria for each (for example, if you are monitoring different sites). For more information, refer to Using the Dashboards.

  • Emissions Inventory Reports - access any standard reports provided by Cority (see Generating Standard Reports) or Report Writer reports that have been published for general use.

  • Report Writer / Query Builder - set up custom reports using different filters and criteria than what is used for the source profile’s aggregate Emission Calculation Report (see Working with Ad Hoc Reports)

  • Data Cube - build a data cube to combine measures, dimensions, and filters, for a specific period of time for data comparison and visualization (see Using the Data Cube).
