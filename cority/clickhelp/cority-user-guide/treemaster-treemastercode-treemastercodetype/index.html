TreeMaster, TreeMasterCode, TreeMasterCodeType

These tables define the organizational hierarchy. They can be edited directly, populated via the Generic Import Utility, or populated via the Organizational Tree builder function.

You can customize a TreeMasterCode (or TreeMasterCode with Attributes) layout to include Related fields so that a node may be related to other nodes. When that node is selected in a form, its related fields are automatically populated.

For more information, see Setting Up An Organizational Tree.
