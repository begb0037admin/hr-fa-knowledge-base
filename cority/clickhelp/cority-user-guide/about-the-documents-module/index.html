About the Documents Module

Use the Documents module to link external documents (e.g. scanned documents, images etc.) to records to allow easy access to the file. For example, you can link information

  • about an employee’s health to the employee record or to a case or incident

  • about a work environment to the an air or noise monitoring sample.

Documents are classified by employee, the document date and type, who the documents were received from and a description of the document. Documents can be accessed directly through the Cority system. The document types are defined in the DocumentType look-up table.

There are two ways to create a document record in Cority:

  • Linking a file saves the location of the file path (not the content). You can link any type of file and view it in the corresponding software.

  • Importing a file saves the content as a binary image in the database, allowing the file to be moved, renamed or deleted. All imported documents are scanned for viruses and are backed up with the database. This approach does not support encrypted files.

You may sign a document to prevent it from being replaced with another version (see Signing Documents).

 

This chapter explains how to:

  • link a document or image file to a Cority record (see Linking or Importing a Document)

  • view a linked document (see Viewing a Linked or Imported Document).

To view controlled documents that have been published from the Document Control module, click Published Documents in the My Favorites menu. . For more information, see Viewing Published Controlled Documents.
