Look-up Tables Used by This Module

The following look-up tables are used by this module. Global tables may already have been defined as part of the setup of other modules. For information on locating and setting up look-up tables, see Look-Up Tables.

Module-Specific Tables

Global Tables

Testing equipment and hearing protectors must be defined in the Equipment module (see Equipment).

The equipment must be associated with an equipment type flagged as Hearing Protector in the EquipmentType look-up table

 

There may also be system settings that affect your use of this module; for more information, see Changing Your System Settings.
