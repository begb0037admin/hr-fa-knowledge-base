Viewing Lab Requisitions

In the Industrial Hygiene menu, click Lab  Requisition.

The requisition list displays the requisition and sample numbers, requisition status, date sent, and which lab it was sent to.

From this list view, you can:

  • View the agents tested for the selected requisitions. Select the requisition(s), then choose Actions»Display Results. From the results list you can choose Actions»View Agent Details to see further details.

  • Click a link to edit an existing request (see Preparing a Lab Requisition for information about the form).

  • Export requisition forms to an Excel spreadsheet. To export an individual requisition when you are viewing it, choose Actions»Export to Excel. To export one or more requisition forms from the requisition list, select the requisition(s) and choose Actions»Export Lab Requisition.
