Capability

This table contains information about functional capabilities and the levels of abilities that employees may be required to meet to perform those capabilities.

  1. To filter the list of records, enter a few characters in one or more of the fields at the top followed by an asterisk, then press enter.

    2. Entries in the Capability table become available for selection in the JobPosition table.

  2. Click a link to edit a record, or click New to add a new record.

  3. Enter a Code and Description for the capability.

  4. In the Category list, select either Multiple Choice or Discrete to describe the kinds of levels of abilities.

    • If you chose Multiple Choice, enter the levels of abilities in the Level fields (see screen shot above).

    • If you chose Discrete, enter the Units of Measure.

  5. Click Save.
