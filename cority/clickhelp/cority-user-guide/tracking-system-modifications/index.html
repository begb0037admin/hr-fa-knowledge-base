Tracking System Modifications

If you find your organization makes frequent modifications to Cority (e.g. new layouts, forms, change requests), use the Mod function to track the changes along with any related documentation. In the Mods menu, click Mod.

You will need to define the following look-up tables:

  • ModModule

  • ModPriority

  • ModProduct

  • ModProgrammer

  • ModSource

  • ModSpecAuthor

  • ModVersion
