Setting Up Links to Third Party Chemical Content

Chemical information content can be imported into and updated in the Chemical Management module in the Environmental Cloud. Related fields may be added to custom versions of the Agent Hazard and Chemical Product layouts.

While the system settings described below set up the connection to the third party, the download and subsequent update must be performed manually in the Chemical Products list view or the Agent Hazards look-up table list view. A regular web service call may be set up to check for updates periodically: If your implementation of Cority is hosted by Cority, contact the Help Desk for assistance. If your implementation is hosted by you, ask your IT department to set up this call.

Setting Up SiteHawk Links

To set up the connection to the SiteHawk FTP site, provide values for all of the SiteHawk system settings (FTP Address, FTP Username and FTP Password).

Select the organizational tree node in the "Map SiteHawk Chemical Area to" system setting. This node will inherit the Chemical Area description wen you refresh your SiteHawk chemical product information.

Setting Up Actio Links

To set up the connection to Actio, provide values for all of the Actio system settings (Actio API URL, Actio Username and Actio Password).
