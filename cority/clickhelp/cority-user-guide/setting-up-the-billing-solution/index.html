Setting Up the Billing Solution

The GX2 Administrator must set up the following for the Billing solution:

  • Arrange for a new/updated license key to include the Billing solution.
  • Select which dimension of your Organization Tree will be used as the employer. For example, you might use the Organization dimension; you can rename it for more clarity, e.g. "Employer (Organization)"). Then specify this dimension in the system setting "Select which dimension will be used as the Employer for the Billing Module."
  • Set up the related look-up tables: PayerType, Payer, PaymentType, FeeSchedule, Modifier.
  • Customize the appropriate layouts: for example, the Billing tab must be added to a custom clinic visit layout, and you may want custom views for the Uninvoiced Items and Invoices lists for each employer and/or payer, etc. You will also need to create custom letter templates to be used for invoices.
  • Assign the appropriate granted modules to the role(s) that will be using Billing modules.
  • Add the Billing menu to each user or profile.
