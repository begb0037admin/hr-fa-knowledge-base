Setup

The following must be set up to use CorAnalytics:

  • Grant the appropriate role to individual users. Role names can be defined by client; we suggest CorAnalytics Viewer and CorAnalytics Admin.
  • Roles can be assigned the following granted modules:
    • CorAnalytics Admin
    • CorAnalytics Creator
    • CorAnalytics Viewer

    For users who do not need to create dashboards, assign the CorAnalytics Viewer security module. For admins and creators of dashboards, assign the CorAnalytics Admin, Creator and Viewer granted modules so a user is granted an additional license key to view, create, and publish dashboards.

  • Enable the CorAnalytics menu option within the Business Intelligence cloud menu if necessary.
