About the Vision Module

Use the Vision module to establish vision test criteria for specific occupation groups, enter vision test criteria for employees, and compare employee results to the group.

Data captured includes test date, name of practitioner, type of correction (if applicable) and last prescription date. The module uses standard vision criteria including acuity, stereo depth, color, and perimeter measurements according to the Titmus or Titmus V4, Keystone (US or UK version), or Depisteo test interfaces -- the layout you see is granted according to your user security role. The module also permits employees to be classified as Fit or Unfit and will display both corrected and uncorrected values.

For the Titmus vision test, the results and their status (pass, fail or warn) are user-defined for each occupational group. Vision test results that fall outside of accepted values for an employee's occupational group are flagged as Pass, Warn or Fail. 

This chapter explains how to enter vision results for an employee and compare those results to the group (see Recording Vision Results for an Employee), and how to transfer results from a testing device (see Transferring Vision Results From a Testing Device).

To see the look-up tables used by this module and the reports available, see Look-up Tables Used by This Module. There may also be system settings that affect your use of this module; for more information, see Changing Your System Settings.
