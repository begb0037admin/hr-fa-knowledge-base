Working with the Medical Chart

In the Occupational Health menu, click Medical Chart and retrieve an employee record from with the module.

The default layout is a split screen layout, which allows you to drag sections to view side-by-side. If you make such changes, be sure to choose Actions»Save Layout. For more information, see Changing Layouts or Creating a Split Screen Layout.

Tabs will be highlighted when records are present; the Schedule tab, since it is a custom form that varies day to day, will not be highlighted even if there are appointments today.

Employees are prevented from viewing or editing their own medical record (provided their Login ID has been entered in their Demographics); for more information, see Recording Basic Employee Information).

To see the reports available, see Medical Chart Reports.
