Destination

This table is used by the Travel module. You can also use this table to link destinations to SEGs to standardize immunization requirements.

  1. To filter the list of records, enter a few characters in one or more of the fields at the top followed by an asterisk, then press enter.

  2. Click a link to edit, or click New.

  3. Enter a Code and Description for the destination.

  4. Select the Exposure Group.

  5. Click Save.
