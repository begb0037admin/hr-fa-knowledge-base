TypeofWork

This table lists types of work that can be captured in a risk assessment. It also identifies which risk assessment types the type of work applies to, if work authorization is required, and any related questionnaires, permits (and permit layout), and/or risk assessments. If you link a questionnaire to a type of work entry, it will display on the Questionnaires tab or any permit records with that type of work.

A type of work may also be associated with a Contractor record.
