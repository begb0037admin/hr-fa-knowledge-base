Checking the Disability Guidelines

Cority offers access to two external disability guidelines resources which can help case managers determine recommended return to work guidelines:

  • Reed Group’s MDGuidelines

  • Work Loss Data Institute’s Official Disability Guidelines (ODG).

Both must be licensed and the relevant systems settings defined. For descriptions of the system settings, refer to the Cority System Guide.

To view the guidelines, in the Occupational Health menu, click MD Guidelines or ODG Guidelines.

Alternatively, if you have entered a diagnostic ICD9 code in the Dx tab of the Clinic Visit or Case modules, you can choose Actions»Open ODG or Actions»Open MDG in those modules to display the guideline for a particular diagnosis.
