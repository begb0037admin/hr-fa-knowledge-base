Tracking Waste Shipments

The EPA requires a hazardous waste manifest to identify and track the transport of hazardous waste. Multiple containers for a waste stream are aggregated into a single line.

Record and track waste shipment information in order to comply with reporting requirements for each leg of the transport.

  1. In the Environmental menu, click Waste Shipment.

Use the Site Selector (at the top of the Environmental menu) to view jus tthe records related to a particular GDDLOFB node.

  1. Click a link to open a manifest, or click New to record a new waste manifest.

  2. On the Waste Shipment tab, record information about the manifest and disposal.

A custom action (Submit Paper Manifest) can be added to the tab layout that allows you to attach a manifest in PDF or TXT format to be submitted to the EPA.

  1. On the Waste Records tab, record the waste profile(s) that will be included in the shipment. For more information, see Recording a Waste Record.

    2. These fields may be pre-populated if the waste manifest was generated from a waste record (see Generating a Manifest from One or More Waste Records), but you can edit them.

  2. On the Transportation Log tab, enter a record for each leg of the shipment.

  3. The Forms tab contains any user-created forms added to the PDFForm look-up table. When you select a file, it will be downloaded to your computer.

Generating a Manifest from One or More Waste Records

If waste records already exist, you can generate a manifest from multiple waste records. Multiple containers for a waste stream are aggregated into a single line.

The waste manifest defaults to the same GDDLOFB (and therefore site security configuration) as the first waste record included in the manifest.

  1. In the Waste Management list, select up to 14 records to be included on the manifest.

  2. Choose Actions»Generate Waste Manifest for Selected Records.  

  3. If there is only one manifest number among the records selected for the manifest, the Manifest Number field will be populated with that number. If there is more than one manifest number among the selected records, you will be prompted to provide one for the manifest (or choose to Auto-generate it).

  4. If you generated the manifest from a single waste record, or from multiple records containing waste streams with matching Generator and TSDF values, the Generator field auto-populates with the generator that corresponds to the record's waste stream (waste profile), and the Disposal Facility (TSDF) auto-populates with the TSDF that corresponds to the record's waste stream.
    If you     generated from multiple waste records containing waste streams that do not have matching Generator and TSDF values, the Generator or Disposal Facility (TSDF) fields will not auto-populate.

  5. Remaining fields will be auto-populated from the first occurrence of those fields in the selected records; if none of the selected records has a value for a field or if a different value is preferred, select a value from the look-up table. Note that the values selected from the look-up table will be applied to each of the selected records, overwriting any existing values.

  6. By default, when the manifest is generated it opens in a new tab; if you do not want it to open, clear the Open auto-generated manifest in a separate window checkbox.

  7. Click Save. The manifest is generated and opens in a new tab unless the checkbox was cleared in step 2. 

  8. If the manifest opened, edit any fields in blue (if required), then save or print. If the manifest did not open, you can open and edit it at a later date from the Forms tab of the associated waste record.

  9. To attach the saved PDF to the waste record, click  in the Waste Manifest section of the Waste Profile tab of the waste record.

Adding Waste Records to an Existing Manifest

You can add waste records to an existing manifest in two ways:

  • In the Waste Management list, select the records to be added to the manifest, then choose Actions»Add to Waste Manifest. Select the waste manifest and click OK. You will be alerted if any of the selected records were previously added to a waste manifest. The manifest number is listed on the Waste Management list view beside each record you added.

  • In the Waste Shipment list, retrieve the manifest you want to add waste records to, and add them on the Waste Records tab.

Recording the Date that the Manifest was Returned

  1. Retrieve the manifest from the Waste Shipment list.

  2. Record the date Manifest Returned from Regulator and click Save.

Submitting and Signing Manifests Electronically

You can submit and sign waste manifests electronically to the Environmental Protection Agency (EPA).

A Waste Container record is not required: all information required can be retrieved from the Waste Management and Waste Shipment records. If an associated Waste Container record is not present, the container type entered on the Waste Management record will be used for submission.

In order to set up the connection to the EPA system:

  • The associated generator(s) and transporter(s) must be set up in the EPA system, and their codes must match the equivalent values (for Firm Code and Vendor EPA ID) in the Cority system.
  • All of the e-Manifest system settings must be defined (e-Manifest API ID, e-Manifest API Key, and e-Manifest API URL).

To submit a manifest electronically:

  1. Open the manifest record and choose Actions»Submit Manifest Electronically.
  2. The connection parameters are validated within Cority and with the EPA e-Manifest system. You will be notified either that the manifest updated successfully or that validation failed.
  3. If successful, you will be provided with a "Click here" link for signing it electronically.
  4. When you click the link for signing, provided validations pass and the record was not previously signed, a separate tab will open to enable you to sign the manifest.

To electronically sign a manifest that has previously been submitted electronically, open the manifest record and choose Actions»Sign Manifest Electronically, then see step 4 above. This action is not available if the manifest was not submitted electronically, or if it was signed when it was submitted.

If a related waste record's "Waste Stream" has a value set for "PCB Type", the PCB Weight and PCB Removal field values are submitted with the manifest.

An e-Manifest log table records API interaction with the EPA e-Manifest system. You can query the contents of this table via Report Writer or Query Builder.
