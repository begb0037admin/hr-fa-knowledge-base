How Logan Determines the Parameters for the Risk Criteria

Logan uses risk criteria to determine what is or is not an acceptable exposure risk. Logan must use statistics to infer the parameters for the risk criteria for an exposure level (EL), since there is rarely enough data to derive the parameters directly from the data. Logan derives the parameters from lognormal probability plotting—ordering sampling data (results) from high to low, calculating cumulative probabilities (see How Logan Calculates Cumulative Probability), and producing a linear plot. The lognormal plot is used to set the following parameters for the risk criteria:

  • mean

  • standard deviation (SD)

  • Accept value (A)—acceptable risk of exposure (equal to or less than 5%)

  • Reject value (R)—unacceptable risk of exposure

If A<EL, the risk of exposure is acceptable.

If R>EL, the risk of exposure is unacceptable.

If EL is between A and R, there is not enough data to estimate the risk.
