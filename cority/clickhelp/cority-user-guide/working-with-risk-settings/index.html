Working with Risk Settings

The Risk Settings determine if risk will be calculated and displayed using a matrix, a formula, or an equation set (if added to a custom layout).

Selecting Risk Settings

  1. In the Administrator menu, click Risk Settings.

  2. For each assessment type, select how risk should be calculated and displayed:

    • Matrix – if necessary, change the risk factors used for the matrix axes (e.g. Severity, Probability) and which axes they appear on. Define the values and colors for each cell in the RiskMatrix table.

    • Formula – if necessary, change the default formula as required using the symbols shown in the Legend and the operators */+-()^. In the Null Factor column, enter a factor to be used if a value is not entered for one of the formula elements (e.g. Frequency). If a value is not entered and the Null Factor setting is blank, the formula will not be calculated.

    • Neither/Equation Set allows users to select the risk value instead of having it calculated (or use the risk value calculated using an equation set if added on a custom layout). If you select this method, any formulas defined in the Formula section are ignored.

  3. When you are finished making your changes, click Save.

For more information, see Working with Risk Assessment Results.
