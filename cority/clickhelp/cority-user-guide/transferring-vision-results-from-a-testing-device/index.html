Transferring Vision Results From a Testing Device

There are two methods for obtaining test results from a vision testing device:

  • To transfer files directly from a device connected to a Windows computer, use the Cority Vision Import Utility. The program must be properly installed and configured with a user name, the URL for receiving test results, and the device activation key. Contact your Cority representative to obtain the application, log-in and activation credentials, and instructions.

  • To transfer data using a Depisteo VT1 vision tester, use the method described below.

Contact your Cority representative for a list of supported devices. Before transferring test results, the type of equipment must be defined in the Equipment module (see Equipment) and in the system settings (see Changing Your System Settings).

If you use employees’ social security numbers on the device instead of their employee number, the appropriate system setting should be set by your administrator so Cority can match the tests to the employees. See Changing Your System Settings for more information.

Using the Cority Vision Import Utility Transfer Program

To transfer test results from a connected device:

  1. In the Occupational Health menu, click Vision Testing.

  2. On the Vision Tests list, choose Actions»Transfer from Vision Tester.

Refer to the separate guide provided by your Cority representative.

Using a Depisteo VT1 Vision Tester

If you are importing from a Depisteo VT1 vision tester:

On the Vision Test list, select an employee and then choose Actions»Transfer from Vision Tester with Employee Data.
or
On the Exam Activities tab of a Clinic Visit record, choose Actions»Transfer from Vision Tester with Employee Data.

The employee data from the record moves through the Cority Vision Import Utility, through the Depisteo software, and then back into GX2.
