Using Custom Calculations in a Record

Organizations can create and execute complex exposure calculations for unique workplace hazards (such as extreme heat, or ionizing radiation) to quickly and accurately assess unique work exposures to physical and chemical agents, helping them to intervene early before exposures lead to workplace harm while ensuring strict compliance to regulatory requirements.

Monitoring, noise monitoring, and sampling equipment data collected from the field flows seamlessly into the pre-set equations to calculate exposure or efficiency results. 

This requires two components: set up your equations, then add the calculated fields to a monitoring record layout where you want to view the calculated results.

Setting Up Your Equation Library

The equation library serves as an equation database or centralized hub where you can create and store equations common to your industry or workflows. Once you set up your equation library, you will not have to visit it often.

You build your equations to pull information from your monitoring sample records and configure them to be used on and display the data on those records. This involves creating an equation, then tying it to an equation set:

  • Creating a New Equation:
    The Equation Library is accessible from the IH Cloud menu, as well as from the list of look-up tables in the Administrator menu. Please see IH Equation; highlights as follows:
    • Entity – This dictates where on records it can be configured to display the calculated result. For example, if you want your equation to be viewed on the parent tab of the IH sample record, then you would select the IHSample entity. Similarly you may want to view the calculated fields on the IHSampleResults.
    • Field – Choose one of the four calculated fields that you want the calculation to appear within.
    • The Equation Formula can be built from a combination of fields, constants, and operators, including UDF fields that can be added to an IH monitoring layout to input required data.
  • Creating an Equation Set:
    An equation set allows you to run up to four equations at the same time on a monitoring record. Each equation must be tied to an equation set.
    Create an equation set via the EquationSet look-up table and add the equations to it. Alternatively you may add a Related Equation Set tab to a custom layout of the IH Equation table and create the equation set from an equation.

Customizing Your IH Monitoring Layouts to Include the Calculated Fields

You can choose where to display the calculated fields. For example, you may want to add any UDF input fields to the Monitoring tab, but display the results of the calculations on the Results tab.

To the appropriate layout:

  • Add up to four of the calculated fields as required to run up to four different equations within an IH record. These fields default to generic naming (e.g. Calculated Field 1) but you can rename them on the IH monitoring layout, e.g. Radon Gas Exposure, to make clear what the calculation is.
  • Add the Equation Set field.
  • Add and rename any UDF fields to input data required for the calculation(s).

For more information about customizing layouts, see Defining Form Layouts.

Running and Editing the Calculations

On the layout where you added the Equation Set field, select the appropriate equation set. Click Save. The calculated field(s) will be updated. Note that even if all four of the calculated fields are displayed on the layout, only the fields with equations tied to the selected equation set will be calculated and displayed.

If the result is not what you expected, click the icon next to the calculated field to view the equation formula as well as the entities and data inputs that were used in the calculation. You can easily see if any fields were left blank thus affecting the calculated outcome. If the inputs look ok, there may be an error in the formula itself: perhaps a parenthesis is missing, or an incorrect operator was used. The formula displayed is a live link to the equation definition in the equation library where you can modify the equation. Make any changes as necessary and save the equation, then click the Back button to return to the monitoring record. Save the record and the calculation will re-run.
