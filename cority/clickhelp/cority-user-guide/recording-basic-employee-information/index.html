Recording Basic Employee Information

If multiple records have been created for the same employee, you can merge them. In the Employees list view, choose Actions»Employee Merge, then choose the employee record to merge from and the record to merge it into.

Each employee record should include basic personal and job information.

  1. In the My Favorites menu, click Demographics.

  2. Click a link to edit an existing employee record, or click New.

  3. On the Employee tab, enter the employee’s personal and employment information. Most fields are self-explanatory, but you should know the following:

    • The Employee Number must be a unique identifier. To automatically generate the employee number, select the Employee Type and choose Actions»Create Employee #. The number is assigned a prefix and the next available number according to the sequence set in the EmployeeType look-up table.

    • In the Mail Stop field, enter the P.O. box number, e.g. WS 3E-75A.

    • If this employee has access to the Cority system, enter the user name in the Login ID field.

    • Cority uses the employee’s main address (in the Home section) for all reports and documents, but you can capture any alternate address(es) on the Alternate Address tab.

    • GDDLOFB refers to the grouping of job/location-related demographic information (Geographic location, Department, Division, Location, Organization, Floor, Building). These are used throughout the Cority system. Be sure to capture the Health Centre the employee is associated with, to ensure only users with appropriate security permission can view this employee’s information.

    • The fields in the Additional Information section are available to capture information specific to your organization. The fields are labelled UDF (User Defined Field) by default, but may have been renamed by your system administrator.

  4. Click Save.

    5. At any time, you can click New to clear all the entries and start a new employee record.

  5. To add (and later, to view) a photo of the employee, choose Actions»Photo. You can later Replace or Delete the photo from this form as well.

  6. The Allergies tab displays all allergies recorded for this employee in the Demographics, Body Fluid Exposure, Medical Chart, Clinic Visits, Clinical Testing, or Immunization modules. For information about entering an allergy, see Recording Allergies.

  7. The Rx tab displays all medications and contraindications recorded for this employee in the Demographics, Body Fluid Exposure, Medical Chart, Clinic Visits, Clinical Testing, or Immunization modules. For information about entering a medication or contraindication, see Recording Medications (non-eRx).

  8. The Dx tab displays all medical diagnoses recorded for this employee in the Demographics, Medical Chart, Clinic Visits, Case Management, or Immunization modules. For information about entering a diagnosis, see Recording Medical Conditions.

  9. The Restrictions tab displays all work restrictions recorded for this employee in the Demographic, Medical Chart, Clinic Visits, Case Management, Pulmonary, and Respirator Fit modules. For information about entering a work restriction, see Recording Work Restrictions.

    10. To quickly end all listed restrictions, choose Actions»End All Active Restrictions.

  10. The Surveillance tab displays any SEG information as it relates to the employee. For more information, see Associating an Employee with an SEG.

  11. The Job Position tab allows you to record additional information about an employee's job position, associate the employee to multiple job positions, and identify the primary job position. This tab does not appear by default and must be added to the form layout. If the "Allow users to leave start date blank in multiple job positions" system setting is enabled, you can create duplicate job positions with no start date.

The Employees list, along with the list views in several OH modules, includes “Multi-job” views that allow you to quickly identify employees who work in more than one job position. If the Additional Jobs field exists on a custom layout of these OH modules, it will default to the employee’s main job but you can select one of their other jobs for that record. The GDDLOFB stored with the selected job position will be transferred to that medical record for the employee.
A Letters sublist may be added to a custom version of the Employee Job Position layout so that a clinician can attach documentation (e.g. Medical Clearance Certificate) to a specific job position so that the posts for which the employee is medically cleared are readily evident. Letters added in this sublist are not accessible from letters lists in the rest of GX2, and are only accessible if the user has access to the Demographics module. If a corresponding Letters sublist is added to a custom My Applicants layout in myCority, the recruiter will also be able to access the clearance certificate. 

  1. The PPE tab shows all Personal Protective Equipment (PPEs) that are required by the employee. These have been assigned as part of an SEG that the employee belongs to.

  2. The Job Position Capabilities tab displays the functional capabilities associated with the employee’s job. Capabilities are associated with jobs in the JobPosition look-up table.
    To add information about the functional capabilities of the selected employee, select the capability in the list and enter/select the level (if necessary), the start and end dates, and any comments.

To view all medical letters attached to an employee, click Medical Letters in the Occupational Health menu, select All, and choose Actions»Print.

Employees Who Work for Multiple Employers

A person may work for multiple employers with different employee numbers at each. The Global Passport module links these records and assigns a unifying Global Passport ID that allows the Occupational Health team to view all of the person’s medical records regardless of employer.

How are employee records linked? The “Conditions to Match Employees with Global Passport Record” system setting identifies the criteria used by Cority (via a daily process) to identify matching employee records. These may be matched based on National Security ID or Medical Insurance Number, and optionally Date of Birth and/or First and Last Name. A Global Passport record is then created or updated for them.

Can I see which employees have linked records? Yes, if you have appropriate permissions and have enabled Global Passport in your My Favorites menu:

  1. In the My Favorites menu, click Global Passport. The list view displays the Global Passport ID, Full Name, National Security ID, and Date of Birth.
  2. Click a Global Passport ID to open a global record. The record displays basic data that typically does not change regardless of the employer (e.g. First/Last Name, SSN, DOB, etc.).
    The Linked Employees tab displays all employee records that have been matched together. You can open employee records from this tab if needed.

How Do I See All of an Employee’s Medical Records? A Global Passport ID field may be added to most of the main list views of Health Cloud modules. You may search and filter for all records (e.g. all clinic visits) for that Global Passport ID, regardless of the Employee number.

You cannot create records against a Global Passport ID; this functionality is solely to link employee records for searchability.

Rehiring a Terminated Employee

If the employee is keeping their original employee number, simply remove the date of termination to reactivate them.

If they have been rehired with a different ID, a new demographic record will be required.
