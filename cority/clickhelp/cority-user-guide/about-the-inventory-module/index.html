About the Inventory Module

Use the Inventory module to view and update inventory levels for each health center that you have access to. Inventory is updated as vaccines are used (in immunization records) or as medications are dispensed (in the Rx tab of multiple medical modules).

 

This chapter explains how to:

  • view inventory in a particular health center (see Viewing the Inventory)

  • enter or update inventory of a vaccine or medication (see Recording or Updating Inventory)

  • update minimum inventory thresholds (see Changing the Threshold Level of a Vaccine or Medication).

To see the look-up tables used by this module, see Look-up Tables Used by This Module. There may also be system settings that affect your use of this module; for more information, see Changing Your System Settings.
