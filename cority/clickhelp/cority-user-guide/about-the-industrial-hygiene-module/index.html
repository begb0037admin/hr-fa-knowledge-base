About the Industrial Hygiene Module

Use the Industrial Hygiene module to record surveys and sample results for chemical, biological, and physical stressors. See also About the Survey Module, About the Monitoring Module and About the Noise Monitoring Module and Functionality by IH User Type.

 

This chapter explains how to:

  • create surveys and sampling plans within the Survey module (see Creating a Survey).

  • create and manage samples within the Monitoring and Noise Monitoring modules (see Recording a Monitoring Sample Record or Recording a Noise Monitoring Sample Record).

  • use the laboratory interface to create requisitions and electronically load sample results (see Preparing a Lab Requisition and Entering Laboratory Results).

  • report and run statistical analysis using Logan, LogNorm or the AIHA Spreadsheet. The three statistical tools are available through your local system settings. See About the Logan Program for details about the Logan program; documentation for LogNorm and the AIHA spreadsheet can be obtained from AIHA and/or standard industrial hygiene text.

To see the look-up tables used by this module, see Look-up Tables Used by This Module. There may also be system settings that affect your use of this module; for more information, see Changing Your System Settings.
