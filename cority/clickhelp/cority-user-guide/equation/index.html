Equation / IHEquation

The Equation Library table allows you to set up a collection of equations that can be used for emissions inventory or industrial hygiene calculations, pulling information from the record. The Equation Formula can be built from a combination of fields and constants, including UDF fields that can be added to a layout to input required data.

There are two separate tables, one for each Cloud, but they function in the same manner. The IH Equation library is accessible from the IH Cloud menu, and the Equation library is accessible from the Emissions Inventory Cloud menu. Both are also accessible from the list of look-up tables in the Administrator menu.

Equations are then tied to an Equation Set defined with the same entity, which allows you to run multiple equations at the same time on a record. For example, you may have three calculations using different variations of the same inputs. Even if you only have one equation, it must be tied to an equation set in order to be viewed in a record.

To create a new version of an existing equation:

  1. Click a link to edit a record.

  2. Choose Actions»Add a New Equation Data Version.

  3. Change the formula details as required and click Save.
    A new version is created for the new effective date. When you open the record the currently effective version is displayed; to view an older version use the Go To Version fields at the top and bottom of the form.

To create a new equation:

  1. Click New.

  2. Enter a Code and Description for the equation.

  3. Select the Entity to which the equation applies (which directs where you are going to view the calculation output), and select the text or number Field that the equation result will be displayed in. For IH equations, you will choose from one of the four calculated fields.

  4. Click Save.

  5. Enter the Equation Formula or click to use the formula builder to compose the formula:

    • Select an element from the tabs on the left (other equations, EmissionFactors, fields (from the selected entity as well as from related entity), or emission parameter variables) and click Add to Formula, along with the calculator buttons in the bottom right.

    • Repeat as required to build your formula.

    • When you click OK the builder closes and the formula is inserted into the Equation Formula field.

  6. Enter the Effective Date and Unit of Measure for the formula and click Save.

You must tie the equation to an Equation Set that is defined with the same entity. An equation set allows you to run multiple equations at the same time on a record. For example, you may have three calculations using different variations of the same inputs.
