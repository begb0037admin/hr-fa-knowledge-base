Rounding of Entered and Calculated Fields

Numeric values in some fields of some entry screens are rounded before being stored. The following table shows which fields are rounded for which modules, and how rounding is applied. “Float” means that the entered/calculated value is used without rounding.

When rounding to decimal places, trailing zeros are not included.

Monitoring/Requisition

OEL

As Stored or Calculated

Where there are no unit conversions, OEL presented as stored in OEL library.
Example:
Benzene (OEL = 1 ppm)

OELs that are converted from mg/m3 to ug/m3 will not be rounded.
Example:
.0025 will change to 2.5

OELs that are converted from ug/m3 to mg/m3 will not have trailing zeros added.
Example:
250 ug/m3 converted to .25 mg/m3

OELs that are converted from ppm to mg/m3 or calculated via % Mineral or OEL adjustment factor should present as follows:

• When value is = or > 1, display in application and reports out to 2 decimals (e.g. 12.53)
Example:
12.53 mg/m

• When value is < 1, display in application and reports out to 3 decimals (e.g. 0.025)
Example:
0.025 mg/m3
