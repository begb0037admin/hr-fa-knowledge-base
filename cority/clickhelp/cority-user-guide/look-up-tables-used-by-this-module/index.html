Look-up Tables Used by This Module

Look-up table records referenced by the Analytics module can be mapped to standardized values to categorize the data and allow it to be compared to that of other organizations to determine relative performance. For example, the EmployeeType look-up table includes a field that can be set to a value from the EmployeeTypeStandardizedValue table.

There may also be system settings that affect your use of this module; for more information, see Changing Your System Settings.
