Chemical Reports

The following canned reports are available (see Generating Standard Reports):

Report Title

Description

Chemical Inventory List

Chemical inventories stored within the Chemical module.

Chemical Inventory Report (SARA Tier II)

Displays chemical inventories for the purposes of SARA Tier II reporting.

Chemical Product Labels

NFPA, WHIMIS and GHS compliant product labels.

Non-Updated Inventories Report

Chemical inventories that have not been reviewed.

SDS

The most current product Safety Data Sheets imported or scanned into Cority.

SDS Expiry Report

SDS expiry dates for products stored in the Chemical module.

The following Report Writer reports are available; you can use these queries as is or copy them to modify the definition (Editing or Creating an Ad Hoc Report in Report Writer):

Report Query Name

Description

Chemical Inventory Report (Current - Speciated)

Speciated compounds in inventory at a selected location

Chemical Inventory Report (Current)

Chemicals currently in inventory at a selected location

Chemical Inventory Report (Max and Avg)

The maximum and average chemicals in inventory at a selected location

Chemical Inventory Threshold Report (Speciated)

Speciated compounds that are currently inventoried at a site, against a threshold quantity
