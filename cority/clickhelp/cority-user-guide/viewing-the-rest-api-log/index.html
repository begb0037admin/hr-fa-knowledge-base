Viewing the REST API Log

This log displays all GX2 GET, POST, PUT, and DELETE requests and responses. For token calls, all sensitive token-related information is hidden.

The log is viewable by any user with administrator privileges.

In the Administrator menu, click REST API Log. Click a link to view details of the API call (in read-only format).

The maximum number of daily Cority API requests is currently 1000, subject to change.
