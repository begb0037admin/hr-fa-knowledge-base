IncidentInvestigator

This table lists investigators by type, associated with up to two GDDLOFB values.

An incident record will use an investigator from this table if the corresponding “Populate...” system setting is turned off and if the investigator type and GDDLOFB in the incident matches a record in this table.

A default investigator may be configured for the incident layout. The default investigator will be used if the “Populate...” system setting is turned off and there is no matching record in the IncidentInvestigation table.
