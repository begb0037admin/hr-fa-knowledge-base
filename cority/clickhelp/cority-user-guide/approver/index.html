Approver

This table identifies the users assigned to each approval role that may be required in a Change Request or Campaign Metric approval workflow. A user may be associated with more than one role. Select the GDDLOFB that they are responsible for.

Multiple users may be associated with the same role but for different GDDLOFB values—Cority determines which user should be assigned for a given record, taking into account the Location and Organization specified in the record.

Optionally, select the Secondary Approver for this Location checkbox to add one more approver per GDDLOFB location and MOC approver role. If selected and there is more than one approver for a given GDDLOFB location, a new Management Of Change record will auto-populate with the specified primary approver.
