About the Letters Function

Use the Letters function to generate form letters for employees or other users. A letter can be emailed or exported to PDF or HTML.

The Letters function is available from all Cloud menus. Each provide the same functionality (view letters already generated or create new ones), but just filter letters to those areas. Some modules also have a Letters tab, where you can view or generate letters that incorporate data from the module (e.g. follow-up instructions after a vaccine or test has been administered, advising employees of test results, or scheduling appointments).

When you choose Letters in a Cloud’s menu (“Communications” in the Environmental menu), you will only see the letters for modules that you have security access to. For example, if you do not have access to the Pulmonary module, the Letters list via the Occupational Health menu will not show any letters attached to Pulmonary records.

Regardless how you access the Letters function, the procedure is the same. For example, you can create a letter from the Letters tab in an incident record, or by clicking Letters in the Safety menu.

Letter content is defined in the LettersTemplate look-up table.
