About the Pulmonary Function Module

Use the Pulmonary Function module to record the results of employees’ pulmonary tests and chest x-rays either manually or through direct transfer from spirometers.

The module automatically calculates the predicted values based on the employee's relevant physical information and will display a text interpretation of the result. The interpretation standard (GOLD/Hardie 2008, NLHEP, ATS 1991, NICE, SEPAR 2013, ATS 2019), and the predicted values standard (Crapo, NHANESIII, Knudson 1976, Knudson 1983, Morris, European Respiratory Society (ERS), SEPAR 2013, Quanjer GLI-2012) to be used are defined in the system settings. An employee smoking history is also included and contains fields for type, quantity per day and start/stop dates.

Medical clearance for respirator use can be flagged and related data automatically transferred to the Respirator Fit Testing module (see Respirator Fit Testing).

 

This chapter explains how to:

  • enter information for pulmonary tests (see Entering Pulmonary Function Test Results)

  • transfer results directly from a spirometer (see Transferring Pulmonary Function Test Results from a Spirometer)

  • enter information for chest x-rays (see Entering Details of Chest X-rays).

To see the look-up tables used by this module, see Look-up Tables Used by This Module. There may also be system settings that affect your use of this module; for more information, see Changing Your System Settings.
