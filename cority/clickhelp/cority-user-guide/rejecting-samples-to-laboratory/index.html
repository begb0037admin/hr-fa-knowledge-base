Rejecting Samples To Laboratory

After viewing sample results entered by a laboratory, IH users or IH administrators can reject the sample back to the laboratory.

In the monitoring sample record, choose Actions»Reject. The sample status is changed to “Sent to Lab” and the results become editable for laboratory users manually using Excel import.

The Reject action is available if the sample status is:

  • “Incomplete” (only for records that have already been added to the lab requisition and whose history record has status “Sent to Lab” in the list, i.e. removed from the laboratory requisition)

  • “Lab Work Complete” (this is the key place when IH users will usually need to reject a sample)

  • “Hold” (only for records that have already been added to the lab requisition and whose History record has status “Sent to Lab” in the list).

The Reject action is also enabled, for IH Administrators only, if sample status is “Void”, “Approved” or “System Approved” (for records that have already been added to the lab requisition).

The Reject action is disabled if the sample status is “Send To Lab” or “Sent To Lab”.
