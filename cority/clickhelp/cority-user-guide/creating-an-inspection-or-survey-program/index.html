Creating an Inspection or Survey Program

  1. In the Safety or Ergonomics menu, click Inspections & Surveys,
    or
    in the Environmental or Quality menu, click Inspections.

    2. The administrator will see all programs created, but a regular user will only see the programs of inspections to which they have been assigned. Programs are only editable by an administrator.

  2. Click a link to edit an existing program, or click New.

  3. On the Inspections and Surveys tab, enter the following information:

    • Enter a Name and Description for the inspection.

    • Select the Type and Topic.

    • If applicable, select the Legal Requirement and/or Permit related to this inspection.

    • Select the Start Date and Recurrence Frequency.

    • Do not enter an End Date unless you want recurring inspections to stop or you want to limit the availability of a survey. An inactive inspection/survey is no longer due after this date (but any inspections/surveys assigned before the End Date will still be considered due). If you select Apply MAEN Settings, notifications will not be sent out after this date. Inspections can be completed even when overdue, but survey links become inactive after the End Date.

    • If you want the system to automatically notify assigned inspectors when they have an inspection due, select Apply MAEN Settings.
      If you select this checkbox, you can override the default notification settings if necessary: select Override System-wide MAEN Settings for this Inspection, and change the settings in the Automatic Email Notifications section as required. The settings in this section, whether default or overwritten, will apply to each assignment associated with the record.

      • When inspections will be completed at irregular intervals, select "Ad Hoc" recurrence. The assigned inspector(s) will always have an inspection to complete up to the End Date, if defined.

      • If the requirement is to complete a specific number of inspections within the Start and End dates, rather than complete inspections at a defined recurrence, select "Target #" and enter the required number of inspections in the Target # field (this field must be added to a custom layout).

      • If the requirement is for a frequency that doesn't match the predefined options (e.g. every two months), select "Every Number of Days" and enter the Number of Days (this field must be added to a custom layout). For example, while a month could be 28-31 days, the requirement may be specifically every 30 days.  If you want the next due date to be based off the completion date of the prior questionnaire, select Next Due Based Off Completion (this must also be added to a custom layout). If Next Due Based Off Completion is selected:

        • If assigning to a group, it must be assigned as a team.

        • There are limitations when assigning to an equipment group.

    • Select the Questionnaire to be used to complete the inspection/survey.

    • Indicate if this is a Survey. The start and end date of the survey will populate the start and end date for the selected recipients. The link to complete the survey will not work after this date.

    • To disguise the assignee/recipient names on both the due and completed lists, select Anonymous. The names will be replaced with a system-generated random code.

    • If necessary, identify a particular Location or Organization that the inspection/survey applies to.

    • If added to a custom layout, you can indicate if the inspection is an Observation (these will appear as Observations in myCority), or define Expiration Days (the number of days after the Due Date when an incomplete inspection assignment will be removed from the user’s task list in Portal/myCority).

  4. On the Assignees/Recipients tab, click New:

    • Safety/Environmental only: Choose whether you want to assign the inspection to an asset or not (the “Enable Layout Workflow” system setting must be selected to allow this choice).

    • Select the person Assigned to complete the inspection/survey and their Start Date. You can select people in one of the following ways:

    • To render the assignee/recipient inactive for this program, enter an End Date. An inactive inspection no longer accumulates due inspections, but any inspections accumulated before this date will still be considered due. For surveys, the End Date is populated from the End Date entered on the Inspections and Surveys tab. The link to complete the inspection/survey will no longer work after this date.

    • Safety/Environmental only: If you chose to assign the inspection to an asset, select the Asset Association. A link to this inspection record is added to the Related Inspections tab of the Equipment record.

      • select User name(s)

      • select from Employee list

      • enter Email address(es), separated by a comma

      • select a Group or team of employees (defined in the GroupandTeam look-up table). If you want to create a single action for the group/team, select the Assign as Team check box; if the checkbox is not selected, an action is created for each employee in the group/team. If Next Due Based Off Completion is selected, Assign as Team must also be selected when assigning to a group.

      • Survey only: choose Actions»Add Assignees/Recipients by Demographics (to choose recipients at, above, or below particular nodes in the organization tree)

      • Survey only: choose Actions»Add Assignees/Recipients by Email Distribution List (to choose recipients from your Outlook account).

    If added to a custom layout, you can assign the inspection to an asset or a group of assets (if defined in the EquipmentGroup look-up table).
    If you attempt to create more than one assignment with the same asset, GDDLOFB and time period, you will receive an error message.
    If you create more than one assignment with the same GDDLOFB and time period but with unique assets, you will be advised that the assignment may result in duplicate aggregations for this tree combination if reported data is not filtered or displayed by asset.
    There are other limitations if Next Due Based Off Completion is selected. 

    • Select the specific location where this inspection/survey is to take place. This is often a sub-location to the location identified for the program.
      Safety/Environmental only: If you chose to assign the inspection to an asset, the inspection inherits the GDDLOFB of the asset.

    Only one assignee/recipient is permitted per inspection/survey program/location for a particular time period.

  5. The Completion/ History tab shows all inspections/surveys (regular users will only see inspections/surveys to which they have been assigned).

    6. Click to display fields that allow you to filter the list by specific field values.

    • The top list shows Due and Overdue Inspections/Surveys (but you can change the view to just Due Inspections). Click a link to view the questionnaire (assignee/recipient can complete the questionnaire from this link). Be sure that the In Progress checkbox is selected for these so that they flow to the assignee.

    • The bottom list shows Completed Inspections/Surveys (but you can change the view to show In-Progress Inspections/Surveys). From this list you can:

      • Create findings and actions for, or attach a document to, a selected inspection/survey. Select the inspection/survey and choose the appropriate Action.

      • Click a link to view the questionnaire responses.

      • Select one or more records and choose Actions»Approve. The inspection/survey is locked from further edits.

      • View a pie graph displaying percentage and count of completed and not completed inspections/surveys (choose Actions»Completion Status Report).

      • View a questionnaire response count report for an inspection/survey. Select the inspection/survey and choose Actions»Response Summary Report.

  6. The Findings and Actions tab displays all findings and actions relating to all inspections/surveys of this inspection program. An inspection/survey cannot be approved by the administrator until all actions are also closed. For information about recording a finding and its actions, see Recording a New Finding.

  7. The Documents tab displays all documents attached to all inspections/surveys of this inspection program. To view an action’s attachment, open the finding and choose Actions»Open Document. For more information, see Linking or Importing a Document.

On the start date, the assignees/recipients will receive an email message with a link to open the inspection/survey record in a standalone version of Cority (no menus, restricted functionality). The link becomes inactive after the inspection/survey’s end date. When they finish the questionnaire, they will deselect the In Progress checkbox which moves the questionnaire to the Completed section and the next inspection is added to the Due section. A business rule may be activated that will automatically set the Response Date to reflect the completion date rather than the start date (myCority automatically selects the In Progress checkbox when the questionnaire is first saved, and clears it and sets the Response Date when the user submits it upon completion). This is useful both for reporting and for calculating due dates in some circumstances (see below).

If an inspector/recipient was assigned after a due date has passed, the next due date applies. In the monthly example above, the first due date is March 31. An inspector assigned on April 15 will only have one due inspection (due April 30) -- any inspections of this program before April 15 will not be deemed due/overdue.

If the inspection frequency is "Every Number of Days":
- If "Next Due Based Off Completion" is not selected, then the next due date will be the inspection profile start date plus the Number of Days, then increment.
- If "Next Due Based Off Completion" is selected, the initial due date will be the later of the start date for the assignee record or the inspection profile start date plus number of days. Subsequent due dates will be the prior Completed Date plus the Number of Days (if completed early), or the prior due date plus number of days (if not completed early).
