Summary of Enhancements

The table below describes the enhancements we have made in 2023.2.0.

Item #Component(s)Description
CCC-13003Platform – Administrator

CMS cookie management has been added to myCority SAML login.

 

CCC-10312Platform – AdministratorSeveral enhancements have been made in an effort to eventually conform with WCAG 2.0/2.1.

These include:

  • Save (Alt+S), Submit (Alt+M), Next Tab/List (Alt+L), and Back (Alt+B) keyboard shortcuts
  • A ‘Skip to main content’ link
  • Search using the first few characters within text and picklist (look-up) fields
  • Arrow navigation for picklist (look-up) values

Additional information will be provided in the myCority User and Administrator Guide, which will be updated for the Production release.
