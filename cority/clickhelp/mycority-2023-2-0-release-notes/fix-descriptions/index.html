Fix Descriptions

The table below describes the fixes we have made for 2023.2.0.

Item #Component(s)Reported VersionDescription
CCC-12764Event ReportingN/A

With 'Event Report Type' set to 'Auto Post to Incident', a user with the required security configuration can now successfully submit an Event Report of that type that has a questionnaire with attached documents.

 

CCC-12840Ergonomics2023.1.0

When applicable, a myCority guest user can now successfully submit an Ergonomics 'Event Report' that has an attachment.

 

CCC-12758ErgonomicsN/A

For OES 'Risk Inventory', when a user attempts to update the Discomfort value and translations have been provided for the options, the options will now translate.

 

CCC-8259Industrial HygieneN/A

A user with the proper security configuration can now link an IH Sample to an 'IH Sample Type' that has a code of 'BLANK'.

 

CCC-13047
Platform – Administrator
N/A

Caching issues with the myCority index.html file have been resolved.


CCC-11430
Platform – End-User
2023.1.0

When the number of records to be displayed per screen is set and the user performs a search that returns more records, the setting number will now be respected and navigation between the screens will now function properly.


CCC-13282Questionnaires
N/A

When a user is filling out a questionnaire that has 'Enable Branching' and 'Public Questionnaire' selected, a set of required 'Yes No' questions configured to branch, and at least one with a required checkbox question as its child, if the user clicks Save while the checkbox child is open, all displayed questions will remain visible. Also, the user will now be able to submit the questionnaire successfully without generating an unexpected error.

 

CCC-12994Questionnaires
N/A

For a questionnaire with 'Enable Branching' selected and a 'Yes No' question as the parent of a 'Numeric' question, if the user enters a value for the 'Numeric' question outside of the question's range and submits the questionnaire, the resulting error message now indicates the issue.

 

CCC-12747Questionnaires
N/A

For a questionnaire with the 'Enable Branching' checkbox selected, a 'Yes No' question as a parent to a 'Normal Abnormal' question, a 'Multiple Choice' question as a parent to a 'Date' question, and an additional 'Draw' question, when the user selects responses for any or all questions and clicks Save and/or Submit, the questionnaire will now Save/Submit without generating any unexpected errors. Also, buttons on the saved questionnaire will no longer become disabled.
